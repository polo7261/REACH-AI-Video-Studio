# shaw-comedy-style

做抖音快节奏邵氏港片风格喜剧短片时用本 skill。核心玩法:**萌宠/动物拟人化 + 武侠壳 + 市井喜剧内核**。用户上传角色参考图(人物/萌宠/动物)、剧本或一句话灵感,生成 10–30s(默认 15s)复古港味短片。**风格致敬,不复刻具体邵氏版权作品。**

> 本环境适配:GPT Image/ImageToImage → `generate_image_v3`;Seedance/MultiModalToVideo → `generate_video_v3`;武侠 BGM/配音 → `generate_audio`;text_editor → `write_file_v2`;video_assembler → `composite_video`;`<<<image_n>>>` → `reference_nodes`+`{{NodeKey}}`。**prompt 工艺与拟人造型工艺全部内联本 skill,不外包 image-prompt-director / cartoon-flow**。超分(1080p via MediaKit)本环境无该能力——默认 720p 交付。24fps/胶片颗粒等若基座无参数位,转为 prompt 内描述并注明。

## 流程(分阶段串行,每阶段暂停确认;全程称呼用户"编导",阶段标题用【模块名】,Markdown 表格呈现,不跳步)

0. **【全局简报】**(`write_file_v2` → Final_Video_Spec.md,字段从用户输入推断、不足用默认):片名(暂定或指定)/风格基调(80 年代邵氏胶片港味武侠喜剧,萌宠拟人混搭)/总时长(默认 15s,可 10–30s 或更长)/输出分辨率(720p 默认)/**画面比例 16:9(固定不可改)**/叙事语言(中文)/**全局硬性规则:全程无字幕、无 BGM(除非明确要求)**/角色输入方式(参考图上传-人物萌宠动物/文字描述/内置角色库,按实际填)/叙事内核(喜剧优先武侠为壳;萌宠动物保留本能行为与武侠造型形成反差)/音频规则(默认保留环境音-市井嘈杂/刀剑/风声等,无 BGM;配音港式普通话腔调+老麦克风颗粒感处理;用户要求时可生成轻快武侠感 BGM)。⏸ 确认再进阶段 1。
1. **【剧本大纲】**〔⏸〕:(如有素材)`analyze` 素材解析,再生成邵氏风格故事大纲——按**起承转合**四段(起相遇/建置→承追杀/冲突→转身世秘密/反派阴谋→合决战/侠义传承)+ 情绪曲线 + 建议镜头数(4–8,适配总时长);优化规则见「剧本智能优化」;Markdown 表格呈现,⏸ 确认进阶段 2。
2. **【分镜设计】**(`storyboard`,见"分镜"节):生成结构化分镜表(key elements + shots + audio layers)。每批 4–6 镜呈现,⏸「确认/修改/重生成」后再续,全部确认进阶段 3。
3. **【元素资产】**(`generate_image_v3`,见"资产生成"节)〔⏸〕:上传参考图注册 asset_id 绑定 key_element;**现代服饰先提示用户确认风格转换、确认后 ImageToImage 转武侠造型**;内置侠客库或仅文字则生成形象图。全部就绪⏸ 告知后进阶段 4。
4. **【逐镜视频】**(`generate_video_v3`):按分镜表逐镜生成,小批次展示、单镜可请求重生成;全部通过进阶段 5。
5. **【音频(如需)】**:若要求 BGM 用 `generate_audio` 生武侠感纯音乐;环境音(风声/刀剑/马蹄)在视频生成阶段随镜头产出、无需单独步骤。
6. **【剪辑合成与输出】**(`composite_video`,见"剪辑"节):按分镜时长顺序拼接、混音、输出,附质检摘要表。
> 依赖:1→0;2→1;3→2;4→3;5→2;6→4,5。

## 素材解析(`analyze`)

- **人物/动物参考图**:提取并结构化输出供 key_element 用——面部特征(五官/发型/发色/年龄感)、体型与姿态、服饰(若现代服饰标记"需转换武侠风格")、物种(动物则提毛色/体型/神态气质供拟人化武侠造型)、气质关键词(冷峻/热血/神秘/威猛等)。
- **文字剧本/脚本**:提取梗概、角色名、关键场景、情绪节点,输出结构化摘要供 Planner 生成大纲。
- **一句话灵感**:识别核心人物关系(如"侠客 vs 反派")、核心冲突与情绪基调,输出扩写种子。
- **参考视频(如上传)**:提取运镜风格、色调特征、节奏感作视觉参考基准,而非直接复制内容。

## 剧本智能优化

一句话灵感 → 扩为起(相遇/建置)→承(追杀/冲突)→转(身世秘密/反派阴谋)→合(决战/侠义传承);粗糙脚本 → 优化对话 + 补武侠细节(剑穗/斗笠/酒壶/残阳/客栈/竹林/破庙等);仅角色图无文字 → 按角色视觉气质自动设计侠义故事;未上传任何素材 → 回复"编导好,请至少上传一张角色参考图或一段文字灵感,才能开始创作。"

## 分镜(`storyboard`)

**key elements 设计**:
- 每个主要角色建独立 element character:外貌(面部/发型/肤色)、武侠造型(服饰/兵器/配件:斗笠/剑穗/酒壶/披风等)、**武功气质标签**(如"内敛剑客,出招前总习惯压低眼睛");动物角色补拟人化武侠服饰方案。
- 关键场景建 element scene:破庙/竹林/客栈/悬崖/山林等,描述光源方向(侧逆光/月光/烛光)、雾效强度、地面材质。
- 重要道具(兵器/令牌等)建独立 key_element。

**邵氏镜头时长结构(以 15s 为例,其他时长按比例缩放)**:开场建置 2–3s(全景或低角度仰拍,建立环境与主角);发展/冲突 6–8s(2–3 个快切打斗/对峙镜头,每镜 1–2s);高潮 3–4s(慢镜头关键动作或面部特写);结尾收束 2s(背影远去/刀剑入鞘/残阳定格)。

**情绪与表演规范(全镜通用)**:人物/萌宠情绪必须真实自然,通过微表情、肢体细节、呼吸节奏体现,非夸张或刻板;**严禁机械感**——动作必须有**起势-过渡-收势三段节奏**,避免"瞬间到位"式描写,写出动作过渡的流畅弧线(如"右手从腰间缓缓抬起,指尖微微颤动,才握住剑柄"而非"握剑");眼神与面部表情须有细节层次(视线方向/眼皮松紧/嘴角细微变化),**内心情绪拆解为可见的身体信号**;萌宠角色拟人动作须保留动物本能惯性感(猫科出手前重心下沉、犬类耳朵竖立),动作自然可信。

**每个 shot 五要素**:
1. **景别**:全景/中景/近景/特写。
2. **运镜**(从以下 7 种规范选取):低角度仰拍(凸显英雄气概,人物出场首选) / 慢镜头(兵器出鞘/轻功飞掠/关键一击) / 快切(打斗节奏,每镜 1–2s) / 推镜头(出场/眼神逼近) / 摇移跟拍(追逐/轻功) / 固定机位(对话/对峙/压抑氛围);**禁止**:手持晃动、无人机航拍、过于流畅的稳定器滑动。
3. **动作描述**:具体到肢体("右手缓缓握住剑柄,食指关节泛白"而非"拔剑")。
4. **台词/内心独白**(如有):格式 (情绪描述,如"声音低沉压抑,像忍了很久"):"台词…(停顿)…台词。";情绪词必须转化为具体动作/声音("愤怒"→"额头青筋凸起,嗓音像砂纸磨过")。
5. **环境音**:精确到具体音效(风声/竹叶沙沙/刀剑撞击/马蹄声/滴水声等)。

**视觉风格(每镜必须贯彻 6 条)**:①**色调基准**暖黄偏暗复古调色为主,不追求冷暖极端分裂,对红黄色系做轻微色彩衰减模拟老胶片褪色感;②**光影**硬光勾勒人物/萌宠轮廓,暗部偏沉亮部柔和(低饱和+强光影的港片胶片逻辑),侧逆光为主、烛光月光场景适用;③**胶片颗粒**不均匀分布,暗部更密集亮部稀疏(模拟感光度不足),强度中等可见不过噪,不磨皮不降噪;④**动态模糊**推摇镜头运动时加入模拟快门速度不足的动态模糊、运动边缘轻微拖影;⑤**轻微画面抖动**偶尔加入极轻微镜头抖动还原老胶片粗糙质感,不可明显手持晃动;⑥**关键场景雾效**市井餐馆烟气/竹林晨雾/月夜破庙等场景必须添加轻量雾效或烟气。

**叙事基调(与纯武侠的核心区别)**:①**喜剧优先**武侠壳是包装、喜剧内核才是爆点,冲突优先选"反差萌"——严肃武侠场景插入萌宠/动物日常逻辑制造荒诞落差(大侠一声断喝、对面猫咪只是舔爪);②**叙事节奏**抖音快节奏,前 3 秒必须建立冲突或反差,不做邵氏式慢热铺垫、直接入戏;③**常见喜剧场景**市井餐馆争执/街头萌宠扮侠客/厨房食材"决战"/掌柜与客人互怼等港式市井喜剧,江湖恩怨作背景动机不作主表达;④**角色反差**萌宠/动物角色必须同时携带"武侠造型"与"动物本能行为"两层描述,两者冲突即产生喜剧效果。

**场景风格补充**:优先港式市井场景元素(木质雕花门窗/复古餐具/红绸装饰/背景食客的民国七八十年代港式穿着);搭配武侠外景时保留一处"市井细节"作喜剧锚点(如竹林里有人卖包子)。

**audio layers**:①**默认音效**保留环境音(市井嘈杂/餐具碰撞/风声/刀剑声),在 shot 描述中精确定义、由视频生成阶段随镜头产出,无默认 BGM;②**配音风格**台词配音采用港式普通话腔调(咬字略带软糯感,声调起伏贴合港片市井角色,尾音可轻微上扬),情绪词拆解为具体动作/声音;③**可选 BGM**若要求,设计 music 类型 audio_layer,描述为"80 年代港式武侠轻喜剧配乐,古筝+琵琶+轻快打击乐,整体旋律感强,节奏轻快而非厚重,可加入轻松音效点缀,无现代电子元素",绑定全片时间轴;④**可选旁白(VO)**若有旁白,narration_speaker_profile(如"【港式说书腔,语速适中,带轻微市井幽默感,偶有顿挫】")+ 逐字台本。

## 资产生成(`generate_image_v3` / `generate_video_v3`)

**元素资产**:上传参考图注册 asset_id 绑定 key_element;现代服饰图先 `generate_image_v3`(图生图,源 Nano Banana Pro 2K)转武侠造型、需用户确认后再绑定;需生成形象图时文生图或图生图(有参考图优先)。**角色图一律横向双格参考图**:左格面部特写(五官/发型/肤色/眼神),右格全身(服饰/兵器/姿态);场景图生成全景视图体现光源与雾效。

**逐镜视频**(`generate_video_v3`,源 Seedance 2.0 720p):
- **参考输入优先级与绑定顺序**:①**角色 key_element 形象图(最高优先级,必选)**——出现在该镜头的所有角色,必须将其双格参考图(面部特写+全身)作首要参考绑定,确保五官/发型/服饰/兵器跨镜一致,多角色时每人各自绑定独立 `{{NodeKey}}`;②**场景 key_element 图(必选)**——绑定该镜头场景元素图统一光源色温/雾效/场景细节;③**前一镜头视频作 reference_video(谨慎)**——仅当与前镜角色状态/动作连贯性极强(慢镜紧接特写/同动作弧跨镜延续)时才加,通常不加避免样式漂移(本环境不支持视频参考则退回关键帧衔接)。
- **跨镜角色一致性保障 4 规则**:①**元素图锁定**——阶段 3 每张角色 key_element 图一经确认即成为该角色全片外观锚点,后续所有 shot 必须引用同一 asset_id、不得用其他版本;②**双格参考图拆分引用**——单镜若景别为特写/近景优先引用左格(面部特写)作主参考,全景/中景优先引用右格(全身),需兼顾面部与全身时同时引用双格分配至不同 `{{NodeKey}}`;③**服饰配件一致性描述**——每 shot 提示词必须复述角色标志性服饰细节(颜色/材质/兵器/配件)不依赖模型记忆,萌宠角色须同时复述动物特征(毛色/体型)+武侠造型防跨镜漂移;④**一致性失败处理**——外观与参考图差异明显(面部走形/服饰色偏)优先加强提示词外观细节后重生成,连续两次失败则提示用户重新确认 key_element 参考图是否清晰。
- 时长:严格按分镜表该 shot 设定(4–15s);若生成失败,源回退 Seedance 2.0 Fast、仍失败则停止告知(本环境映射为同工具重试→失败告知用户)。

**BGM(如需)**:`generate_audio`,提示词中不得出现知名音乐人名字。

## 提示词写法(全部内联,不外包)

**最高优先级(全局)**:所有提示词用中文书写;台词/旁白遵循 Final_Video_Spec 语言设定(中文)。

**元素形象图**(`generate_image_v3`):自然语言描述,结构=主体外貌+武侠服饰与配件+光线与色调+构图与景别+质感标签。
- **核心视觉锁定词、角色图示例结构、萌宠拟人侠客描述法、场景图写法**全文见 `references/prompt-templates.md`。

**镜头视频**(`generate_video_v3`):
- **参考图绑定**:每个角色/场景对应 `{{NodeKey}}`,提示词开头明确说明各占位符指向的角色或场景。
- **提示词结构**(按顺序叠加,不分节标注):①运镜(含是否加轻微抖动/动态模糊)→②主体动作(精确到肢体,含幅度速度;萌宠动作保留动物本能反应与武侠动作的反差)→③场景与环境(光源/烟气/市井细节)→④音效(环境音,台词用 `{...}` 包裹)。
- **Seedance 音效标记规范、邵氏运镜 7 关键词逐字、情绪动作真实感 3 条、35mm 胶片质感强制词全文、BGM prompt 全文、配音老麦克风描述**:见 `references/prompt-templates.md`(英文/固定词组原文保留)。

## 剪辑(`composite_video`)

- **拼接顺序与节奏**:严格按分镜表 shot 顺序拼接不得调换;每 shot 时长以分镜表为准、总时长与锁定时长对齐(±0.5s);快切段落(打斗/冲突)相邻 shot 无过渡或硬切、保留节奏紧张感;慢镜头/高潮 shot 衔接处可加 2–4 帧叠化(cross-dissolve)柔化冲击;开场第一帧从黑场淡入(fade-in ~8 帧),结尾最后一帧淡出至黑场(fade-out ~12 帧)。
- **分镜间丝滑衔接**:①**动作连贯性优先**切点须落在动作弧的自然间歇处(出招后短暂停顿/视线转移瞬间),而非动作正中强行截断;②**光线与色调匹配**同场景相邻 shot 亮度/色温过渡平滑,避免跳切曝光跳变,场景切换则允许轻度色调差异;③**音效连续性**环境音(风声/市井背景)在 shot 切换时淡入淡出交叠(~4–8 帧)不硬切截断,保持声音空间连续;④**禁止出现**字幕、BGM(除非明确要求)——全片强制,不得因默认设置引入任何文字覆盖层或背景音轨。
- **音频混合(dB 层级)**:各 shot 环境音保留原生不做默认压缩;有 BGM 时 BGM 音量低于环境音约 6dB、打斗高潮段可提升至相当水平;有旁白(VO)时旁白优先级最高、环境音自动降至 -10dB 以下、BGM 降至 -15dB 以下;shot 内有台词(dialogue)的片段该片段环境音维持原生、不额外叠加 BGM。
- **导出**:MP4,**帧率 24fps(维持胶片感)**,分辨率按锁定值(默认 720p)。
- **质检输出摘要表**(最终呈现给用户):故事类型(侠义/恩仇/忠义按实际)、总时长(XX 秒)、总镜头数、运镜类型(低角度仰拍/快切/慢镜/推摇移跟)、色调风格(暖黄偏暗,红黄色系轻微褪色,硬光轮廓)、胶片颗粒 ✅、雾效使用 ✅/❌、角色一致性 ✅、BGM(无/已生成)。
