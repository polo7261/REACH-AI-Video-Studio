# premium-ad-posters

做高端海报、广告创意图、社媒广告图（带文字叠加）时用本 skill。图片专用，用 `generate_image_v3`。

> 本环境适配：源主模型 `imagegen_2_0`（GPT Image 2.0）+ 回落 `flux_2`/`nano_banana_2` → 我方无对应外部模型选型，统一收敛为 `generate_image_v3`（`无该模型`，见适配删除台账 #41）。

## 模型与规格

海报/广告成败在排版保真、硬件精度、布局纪律、品牌一致。用 `generate_image_v3`，\*\*质量选高、清晰度 2k（或 4k）\*\*以保证字形与硬件接缝清晰。

比例按投放位选择：

- `1:1` —— 方形 Meta feed / 轮播广告
- `9:16` —— Stories / Reels / TikTok 广告
- `4:5` —— Instagram feed
- `3:4` —— 竖版海报
- `16:9` —— 横幅

## 技术与写实清单（场景专属工艺·内联，主动在 prompt 里规避 AI 常见瑕疵）

设计带硬件与文字整合的产品广告时，必须主动引导 prompt 规避以下常见 AI 瑕疵：

1. **硬件完整性/机械对称**

   - 问题：智能手表表圈不对称、表冠/表盘看起来扭曲或"熔化"进表壳、表带与表壳无缝融合。
   - 对策：明写「完美机械对称、均匀表圈、清晰定义的机械件。电子表冠/表盘必须是独立的金属实体，有精确纹路，与表圈分离；表带耳连接自然，把表带接到表壳」。

2. **屏幕层 UI 集成（非平贴纸）**

   - 问题：屏幕图形（录音波形、数字、按钮）贴在显示玻璃上显得完全扁平、缺乏真实玻璃深度、或像后期合成上去的。
   - 对策：明写「界面渲染在表镜玻璃之下，在保护玻璃层上呈现细微自然眩光、反射与光折射。发光 UI 元素（波形、数字）应真实地从光泽反光屏幕玻璃后方发光」。

3. **解剖正常**

   - 问题：手腕缺骨感、表带下过渡关节软塌、佩戴设备时手指变形。
   - 对策：明写「清晰的手腕骨骼解剖（尺骨突起）、自然指节、真实皮肤毛孔与自然肤质，处于柔和过滤窗光下」。

4. **背景伪影防护**

   - 问题：背景虚化中的键盘、手机等物件按键/按钮扭曲或比例怪异，破坏专业广告质感。
   - 对策：明确指定背景形状，写「背景干净整洁无杂物。若失焦背景中出现键帽等物体，须遵循标准矩形形态，或简化背景为浅木纹理以减少杂乱」。

5. **高对比排版**

   - 问题：文字叠加直接压在浅色纹理（如浅木桌面）上时对比度不足，导致文字难以辨认。
   - 对策：明写「所有文字叠加须用干净、现代、深色无衬线字体，高对比度。若叠在多变纹理上，文字层后加细微投影或环境光遮蔽以保证最大可读性」。

6. **参考映射 vs 目标格式**

   - 问题：用户提供某一设备的美学参考（如 iPhone 锁屏），但要求生成另一具体目标产品（如 CarPlay 显示屏）时，模型直接生成了参考设备而非目标产品。
   - 对策：只提取并映射参考图的**美学属性**（排版、配色分区、纹理、UI 元素形状）到**请求产品的格式与环境**上，绝不把主体设备改成参考平台的设备，除非用户明确要求。

## Prompt 结构模板

把 prompt 逻辑上拆成以下独立分段，帮助模型正确构建布局与美学要求：

```
[主体/Hero]：详细描述产品与手/模特的锐利细节。在此加入解剖与结构规则。

[风格]：高端产品摄影、柔和窗光、通透的厨房/办公台面、窄景深、克制的编辑设计感、真实暖色调。

[指令]：硬件机械对称、表带耳连接定义、屏幕深度真实感（水晶表镜上的眩光/折射）、背景键盘形状约束、标题周围干净的留白。

[文字]：引号内给出确切的文案文本块——标题/副标/字幕，包含具体字号、字重描述、颜色细节、位置区（顶部/底部/叠加）。

[约束]：宽高比为 [1:1/9:16]；无扭曲按钮、无熔化外壳、无糊字、无变形按键。
```

成组批量出多张、需要统一锁定品牌视觉资产（色板/字体/光感）时，见 brand-visual-kit。
