# ink-wuxia-animation

做寫意水墨武俠動漫短片時用本 skill。張大千式潑墨寫意山水 + 五行武俠 + 焦墨飛白動態。

> **風格致敬,非精確模仿**:借鑑《霧山五行》式寫意水墨武俠美學,**不復刻其角色/具體鏡頭/版權名稱**,創作原創角色與故事。以下"水行使者"等為示例型別,非特定作品角色。 本環境適配:\*\*\* Image 2 → `generate_image_v3`(2K);Seedance 2.0 → `generate_video_v3`(720p、16:9);MiniMax Speech/ElevenLabs → `generate_audio`(配音/旁白/BGM/SFX);`text_editor` → `write_file_v2`;`video_assembler` → `composite_video`;`resource_prepare_and_analyze` → `analyze`;`<<<image_x>>>` → `reference_nodes`+`{{NodeKey}}`。**容錯:全程鎖定單一影片生成能力(Seedance 等價),報錯不降級換模型,直接暫停反饋使用者由其決定。** 雙語 prompt 模板(影象/五行特效/影片武招/防分屏)與剪輯卡點+五行 EQ 表見 `references/prompt-library.md` 與 `references/editing-and-audio.md`。

## 語系規範

中文互動/中文 UI 時**提示詞本體用中文**,但關鍵藝術術語/風格標籤/五行特效標籤用**中英雙語對照或括號標註**(如 traditional Chinese ink wash painting (水墨寫意));對白/旁白配音文字嚴格遵循 Final_Video_Spec 輸出語言。

## 五行色彩體系編碼(element character 設定原則)

角色嚴格按五行色彩編碼;各使者\*\*爆發態(Outburst State)\*\*有專屬 色彩明暗配比 + 運動物理質感 + 微觀光影渲染 三層:

- **火**:約 70% 硃砂紅/熔金烈焰 + 30% 粗獷焦墨勾線與重陰影。**運動物理**:烈焰自下高頻舔舐、熔金高粘稠流體滾動、滾燙熱對流引起宣紙熱浪扭曲(heat distortion),邊緣乾裂飛白+炸裂噴濺墨點。**微觀光影**:火焰為強自發光核(self-illuminating core),周身/肢體邊緣投超高對比赤紅/熔金反光(kinetic glow)+強動態背光,把 30% 焦墨骨架邊緣勾出金紅鋒芒,陰影極速閃爍硬邊緣跳動。
- **水(極寒)**:約 60% 深群青/靛藍潑墨 + 25% 凜冽飛白霜(留白) + 15% 極鋒利晶瑩散射冷光冰刃。**運動物理**:液固雙態轉換張力——水流高粘滯重墨潑灑(fluid wash drag)、冰錐瞬間急凍脆斷(brittle crystal snapping),水汽在宣紙漸次滲透擴散寫意阻尼感。**微觀光影**:冰刃半透明(translucent)介質光澤+內部折射(internal refraction),深藍潑墨背景下外部冷光產銳利鏡面折射(specular scatter)+剔透碎光,焦墨輪廓被冰冷側光(icy rim light)反襯如刀鋒晶瑩尖銳。
- **木**:約 65% 高飽和石綠/翠綠能量流 + 20% 狂草焦墨藤蔓骨架 + 15% 激射亮金飛葉/金色木屑。**運動物理**:藤蔓狂鞭揮擊(whip-like cursive strike)有機彈韌高頻鞭打、植物生長高速摩擦張力與纖維撕裂、飛葉劃出利落書法劈叉枯筆飛白。**微觀光影**:翠綠能量流強葉綠素次表面散射(subsurface scattering)+微光自發光(ambient moss glow),亮金飛葉在暗焦墨背景反射碎金眩光(golden glints),光穿藤蔓形成斑駁光斑(dappled rim light)投側面輪廓破開深色。
- **土**:約 55% 枯筆飛白焦墨巨石 + 35% 赭石/雄黃潑彩漫天沙塵 + 10% 裂隙迸射大地裂紋光。**運動物理**:巨石極重阻尼翻滾崩落動能(colossal tumbling inertia)+地表開裂重力摩擦(ground shear),飛沙走石粗糙硬質枯筆劃痕、塵土炭灰摩擦重阻滯質感。**微觀光影**:巨石硬朗陽角浮雕陰影(relief shadow/AO),黃沙塵暴物理遮擋與散射衰減(ray attenuation)成昏暗壓抑氣氛,大地脈動裂紋高能自發光(glowing earth veins)在岩石底部投熔岩般由下至上熾熱金色返照光。
- **金**:約 50% 耀眼亮白鋒刃與閃電光軌 + 35% 漫天灑金流金碎屑/金箔 + 15% 潑墨鐵骨般深濃焦墨重色壓陣。**運動物理**:絕對線性純幾何高速切割動能(linear slicing energy),金屬鋒刃利落不規則書法枯筆刮擦撕裂痕,灑金碎屑極高頻振動摩擦+金屬碰撞火花四濺慣性。**微觀光影**:亮白鋒刃極致刺眼閃電強光+鏡面高光(blinding specular glints),漫天激射流金碎屑散射耀眼碎金點光源(glimmering golden sparkles),把 15% 壓陣潑墨鐵骨邊緣照亮產鋒利冷光金屬邊緣反光,冷暖色調極高對比產眩光。

若使用者已提供人設或人物三檢視,故事板須嚴格提煉遵循其視覺特徵保持高度一致;未提供則系統原創構思(角色五官/髮型/代表色彩/中式武俠服飾)。

## 面部微表情與水墨介質情緒外化(微觀水墨細節鐵律)

- **日常與對峙文戲(情緒微表情)**:眉尖微蹙/眼波流轉/下頜線緊繃,勻稱精緻工筆細線捕捉溫潤古意。
- **大招碰撞/爆發/受擊瞬態(極端情緒)**:緊咬牙齒、咬肌劇烈收縮、額頭太陽穴青筋突起(bulging facial veins)、眼瞳縮至針尖或爆發高自發光五行異彩。
- **面部水墨介質融合(汗/淚/血嚴禁寫實)**:以寫意水墨介質重塑——眼角/嘴角半乾宿墨乾枯血淚痕(viscous dry ink-wash trails)、順骨骼炸裂的飛白枯筆抓痕、極高頻噴濺墨點(kinetic ink splatters)、重度陰影焦墨斑塊,把情緒爆發與肉體痛苦外化為宣紙濃淡筆墨撕裂。

## 畫風與運動張力動態耦合(核心鐵律,畫風不得一成不變)

按鏡頭運動速度與動力量感做"筆墨張力"動態縮放:

- **靜態/慢速運鏡(文戲/意境空鏡/極慢推拉平移)**:精細工筆勾邊,線條纖細勻稱稜角分明,墨色溫潤清雅,保留宣紙細膩紋理——東方儒雅空靈。
- **極速運鏡/強力打擊(急推 Whip Zoom/急掃 Whip Pan/拳腳命中/招式爆發瞬態)**:畫風瞬間蛻變——極粗獷狂亂焦墨枯筆+飛白排線,線條驟粗、邊緣乾裂筆鋒、大量噴濺黑墨點,極強視覺衝擊的手繪原畫風骨與動態破壞力。

## 場景 element scene:多角度無人物四宮格(核心鐵律)

背景為張大千式大氣潑墨寫意山水;場景參考圖必須為**多角度無人物四宮格(Multi-angle Character-free 4-Grid Scene Reference)**,四格固定分配:Grid1 全景定場(宏觀輪廓/地貌/天際線比例) / Grid2 陳設特寫(古松/石碑/案几微觀水墨質感) / Grid3 縱深透視(前中遠景層次+透視引導線) / Grid4 氣氛光效(主色調暈染範圍與光影對比氣氛)。已提供場景圖則精準提取地貌/各視角空間層次/色彩傾向細化沉澱;不符規範或未提供則原創設計四宮格方案。

**經典中式陳設水墨設定(微觀質感與明暗對比鐵律)**:

- **萬古勁松**:枝幹粗礪帶頓挫焦墨枯筆(rough dry-brush)橫向掃拂顯皴裂鱗皮,松針高頻極細工筆排線(fine-line gongbi)聚團高對比刺芒;松枝底部宿墨/焦墨深色壓陣,受光面留白或敷極淡礦物淺金,濃淡墨激烈衝撞透鋼骨傲意。
- **滄桑孤碑**:碑身不規則碎裂硬角,碑面大面積淡墨溼暈(wet-on-wet)打底再幹焦枯筆勾裂隙斑駁刻痕,碑文/青苔用高飽和石青硃砂潑彩點綴成刺眼微觀亮點,側面稜角用強烈寫意側光切出硬朗陽角浮雕陰影。
- **寫意竹林**:遠景竹林大片溼墨極淡潑墨漸變虛化,近景竹竿爽利飽滿中鋒幹筆(dry calligraphic stroke)拔地而起、竹節焦墨橫點頓挫,竹葉快意"個/介"字撇葉法邊緣毛鋒開裂飛白,微風下半透明水墨透光疊層(translucent layered shadows)縫隙灑駁雜碎光。

## 水墨色彩潑彩比例三檔(明暗比例)

- **非戰鬥/意境空鏡(文戲最高美學·三維一體)**:工筆細描 35%–40%(主體/關鍵道具/近景樹石邊緣極細工筆勾勒保溫潤細節)+ 意境留白 35%–40%(大面積純淨宣紙留白,雲霧煙雨遠水淡墨漸變虛化"虛實相生",嚴禁背景畫滿)+ 古典寫意潑彩 20%–25%(僅遠山/竹林邊緣/飛瀑兩側點綴極淡礦物色 石青石綠淺赭石礦物淡金,墨分"焦濃重淡清"五色,光影柔和拒硬邊強光)。
- **常規對打/文武過渡**:均衡比例 約 50%–60% 黑白灰基底 + 40%–50% 潑彩;背景山水墨色大塊面潑墨,視覺焦點/地貌層次疊染孔雀藍或石綠潑彩;強明暗對比(一束強光穿焦墨陰雲投戰場中央,黑白重墨破呼吸感)。
- **高潮決戰/五行大沖撞**:色彩主導+重墨壓陣 約 30% 焦墨骨架 + 70% 爆裂潑彩疊彩;高飽和硃砂紅/亮金/石青大面積潑灑激烈碰撞,但用粗曠力量感焦墨宿墨勾結構線條(**墨骨綵衣**),深墨重色把控重心防色彩過載廉價;明暗極致高反差,光影如閃電撕裂漆黑宣紙。

## 分鏡時長動態規劃(解決全量 5s 單一時長痛點)

**嚴禁全量套用 5s 預設時長**;須據動作激烈度/資訊量/臺詞字數動態顯式設每 shot duration。**牢記 4s 硬性最低時長限制,單鏡嚴格控制 4s–12s,絕對嚴禁任何低於 4s 的超短分鏡。** 匹配規則:

- **極速打鬥/瞬發切招/特寫(急推/單發重擊/瞬移/閃白瞬間)**:4s–6s(側重爆發力衝擊,短時長保高頻緊湊武打力道)。
- **連擊/招式交匯死鎖角力/大招大對碰**:6s–9s(為複雜動量變化/多段打擊/粒子爆散/鏡頭推拉留充足畫面生長時值)。
- **臺詞對白/蓄勢文戲/寫意空鏡/妖獸吐息大爆轟**:9s–12s(臺詞單句 ≤10 字按每秒 2–3 字算保唇形對齊時長,文戲/意境山水慢速平移/雲霧暈開留呼吸舒展)。

## 場景強繫結與一致性(從源頭防跳畫)

- **顯式指向場景 ID**:每 shot 必須顯式宣告所屬 scene_id(如 `[Element_Scene_01]`),嚴禁無場景歸屬或模糊泛指的鏡頭。
- **連續場景完全複用**:相鄰鏡頭同地點同時值、或屬同一打鬥/對話回合,則所指 scene ID **必須絕對一致(完全相同 ID)**;下游據該 ID 強制載入複用同一四宮格資產,從源頭根除場景跳畫/背景前後不一致/突變穿幫。

## 打鬥風格分級與五行招式呈現

- **風格分級**:人類角色=武俠寫實(刀劍拳腳行雲流水、拳拳到肉);妖獸角色=魔幻誇張(肉身突變解構、非線性軌跡、撕裂地貌碎裂破壞力);五行使者=虛實結合(法術與真實武術並重)。
- **五行招式呈現形式**:金(金屬鋒刃/漫天灑金碎屑/亮白光軌、大開大合無堅不摧)、木(狂草藤蔓纏繞/飛葉如刀/翠綠生機能量流、靈動閃避體術)、水(流體水流/冰錐凝結/水墨暈染、水勢與冰刃交替攻守兼備)、火(熊熊烈焰邊緣焦墨頓挫、爆裂極速位移打擊)、土(崩裂巨石/飛揚沙塵/拔地巖壁、岩石輪廓厚重枯筆飛白)。

**核心招式流派分鏡規則 8 類**、**五行相剋對決與 5 組剋制轉場**、**標誌性鏡頭語言(黑白水墨閃/Whip Zoom·Pull·Pan 三急速運鏡/連擊動能向量軸線對齊+墨色殘影 0.2–0.5s/寫意碎落粒子/焦墨煙塵/低角度仰拍/書法大字定格卡 4s)**、**非戰鬥詩意轉場(空鏡/墨滴暈染/飛白拖尾/長卷平移呼吸感/陳設特寫)** 見 `references/storyboard-rules.md`。

## 對話與音訊軌規劃

- **對話**:每鏡若有角色發言,臺詞獨立寫在 dialogue 屬性。臺詞斷句用精簡有力契合武俠氣息的短句(單句 ≤10 字),避免長難句為生成引擎留足音節吐字時長,顯式標停頓呼吸口(……/,);臺詞強繫結說話角色(element character)並指定特寫/中景看清唇部開合。
- **配音音色設定與聲音憑證**:含臺詞角色須顯式規劃配音音色描述(如「堅毅果敢中高音青年男聲,帶一絲沙啞水墨俠客質感」)作聲音特徵地基,指導下游生成並繫結 key_element_audio;使用者提供樣例則優先提取其音色。
- **audio_layer**:BGM(古箏/二胡/笛子古典樂器為主,融電子搖滾+重打擊樂,為高潮大沖撞預留節奏重音卡點 downbeats 與聽覺留白氣口 drop/rests)、環境音效層(風過竹林/細雨拍葉/紙張沙沙/水滴融開,建空靈宣紙空間底噪,文武戲轉換動態呼吸強弱)、打擊與相剋音效層(常規武招:刀劍擊鳴/肉體悶擊/輕功風掠;五行剋制大沖撞:據碰撞型別顯式規劃雙層特徵寫意打擊音效,如 \[金克木\]=利刃切碎藤蔓金屬割裂+草木斷裂複音、\[水克火\]=怒濤拍擊+烈焰碳化高壓蒸汽嘶鳴)。

## 流程與自檢鐵律

1. **規格**(`write_file_v2`:16:9 / 720p / 水墨武俠風格定位 / 配音字幕語言)。
2. **故事板**(`storyboard_designer`:五行角色 key_element + 鏡頭列表含書法大字定格卡 + 獨立音訊軌)。⏸ **節點 A**:故事板輸出後暫停,引導確認情節與分鏡後方可後續。
3. **繫結/分析參考素材**(`analyze`:核對人設圖是否標準正/側/背三檢視、場景圖是否多角度無人物四宮格、畫風是否相符;提取礦物顏料 石青石綠硃砂 配比分佈、線條筆觸粗細頓挫飛白潑墨比例、動作影片幀級節奏 攻擊前搖/出招/碰撞打擊點/收招幀級時間跨度;沉澱入 Final_Video_Spec 指導下游)。
4. **影象元素風格化重塑與系統補全**(`generate_image_v3`):角色圖**非標準三檢視或畫風不符**、場景圖**非多角度無人物四宮格(或含人物)**——**嚴禁直接繫結為最終參考**,須 ImageToImage 以原圖作空間佈局/色彩參考重構為規範三檢視或規範四宮格(Grid1 全景定場/Grid2 陳設特寫/Grid3 縱深透視/Grid4 氣氛光效,2K 無人物);完全缺失則 TextToImage 補全;三檢視統一為終極人設規範,後續多姿態生成必引其作核心 reference_image;四宮格提示詞強制 `4-grid layout, no characters` 且固定四格內容。**繫結與閉環自檢(嚴防遺漏)**:所有重塑/補全/原圖 asset_id 綁至相應 key_element,進下一步前**必須逐一核對**故事板所有 key_element(角色/場景/關鍵道具)均已生成並繫結、無一遺漏,發現遺漏立即補全/補綁,**嚴禁資產未完全對齊就啟動逐鏡影片生成**。
5. **逐鏡影片生成與連貫性**(`generate_video_v3`,720p):**逐鏡前置一致性自檢(鐵律)** 生成每鏡前須將提示詞與故事板深度對齊核對:①人物參考(所有角色已用 `<<<image_x>>>` 或特徵描述指代繫結,防遺漏/無關人物);②**場景參考強繫結防跳畫鐵律**(shot 已顯式關聯特定 scene ID、該場景四宮格已生成繫結並在提示詞用佔位符絕對繫結;**絕對嚴禁**場景參考未繫結/ID 缺失/同地點 asset_id 不一致就啟動;自檢發現漏綁強制回溯先補四宮格資產再生成);③臺詞對白 100% 完整封裝進語法塊(`{dialogue}`)且對應 key_element_audio 作 reference_audio;④動作/五行特效/急速運鏡/SFX 與分鏡吻合;任何漏項立即修正,嚴禁帶錯啟動。視覺一致性:每鏡必輸入對應 element character 圖+element scene 圖作 reference_image;相鄰鏡頭動作/場景極高連貫需求可將前一鏡影片作 reference_video。聲音口型:含臺詞鏡頭綁對應角色 key_element_audio 作 reference_audio 保跨鏡口型音色一致。**時值**:嚴格讀取繼承 shot duration,嚴格 4s–12s,嚴禁低於 4s 或全量套 5s,動作切換明顯時主動切鏡。
6. **聲音與配樂**(`generate_audio`):角色對白配音(MiniMax Speech 2.8 HD 等,註冊/繫結為 key_element_audio 保跨鏡音色)+ 說書人宿命感老者旁白 VO;傳統中國風 BGM + 高頻刀劍打擊/招式爆發 SFX。有使用者樣例則提取音色克隆。
7. **時間線剪輯合成**(`composite_video`):嚴格按武打卡點與"黑白水墨閃"時值快速剪輯與音畫對齊。詳見 `references/editing-and-audio.md`。

**執行控制暫停節點**:**資產生成前置確認(核心鐵律)**——生成任何新資產(元素圖/逐鏡影片/音訊)前**必須暫停**告知使用者生成計劃(含提示詞或參考關係),獲確認許可後方可調工具;**節點 B(資產核對確認)**——每批次/重要資產生成或重塑完成後向使用者展示,所有影象元素資產生成完畢後**全域性自檢核對繫結狀態**、向使用者展示完整角色與場景繫結關係,獲確認滿意後方可推進。
