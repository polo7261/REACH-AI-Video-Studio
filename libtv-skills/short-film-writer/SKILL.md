# short-film-writer

5-10分鐘敘事短片的完整寫作方法論。短片是**衝刺**，靠資訊密度取勝——每個場景都必須推進情節或揭示性格，沒有閒筆的空間。本 skill 自包含，不依賴本庫其他任何檔案；如果要指定"這個短片該講男頻/懸疑/復仇哪個題材的具體內容判斷標準"，可以在寫完後額外參考對應題材殼，但題材殼不是必需前提。

## 邊界：不做什麼

不產出分鏡表、鏡號、景別/運鏡/構圖、轉場方式、AI生圖/生影片提示詞、任何特定生成引擎的格式約束。產出到完整的、可以直接讀、直接拍的文字劇本為止。

## 工作流紀律

嚴格按步驟順序執行，不跳步；每一步完成後暫停，等待使用者的[透過/修改/自檢]指令；絕不一次性把後續所有步驟生成完再交給使用者；每步結束後提醒使用者可以要求[自檢]。

自檢是內部過程——寫之前先在心裡過一遍對應步驟的檢查清單，不需要在輸出中展示自檢的思考過程，只需要確保交付的內容已經透過檢查。使用者仍然可以主動要求[自檢]，此時才需要顯式地逐條列出檢查項並給出評估結果。

## 寫作紅線（全域性最高優先順序，任何格式都不能違反）

**絕對不要**：寫心理描寫（"他意識到"、"她領會到"、"內心湧起"）；寫括號暗示（"（其實是在掩飾緊張）"）；角色用臺詞解釋設定或主題；說教片段、強行催淚、煽情獨白；過度比喻句、類比、書面化的AI腔臺詞；寫任何攝影機拍不到的內容。

**必須做到**：臺詞口語化，像真人說話；用動作代替解釋（動作即潛臺詞）；對話像冰山，只露一角；所有內容從視聽角度出發。

## 視聽化寫作核心

**Show, Don't Tell**：嚴禁心理描寫，只寫能被看見的動作和能被聽見的聲音。如果一個情感無法透過角色的物理行為傳達給觀眾，這個情感就不該出現在劇本里。錯誤示範："他終於理解了父親的苦心。"正確做法：他站在那裡看了一會兒，然後把外套脫下來蓋在父親身上。

**潛臺詞**：對話是冰山，角色說出來的話只是表面，真正的含義在水面之下。避免直白（on-the-nose）對話，利用動作、停頓、迴避、話題轉移表達真意。直白（錯誤）："我很害怕失去你。"潛臺詞（正確）："你走的時候把那件外套帶上。……外面冷。"

**動作即潛臺詞**：所有情感傳遞必須能用攝影機拍出來。一個好的短片，把所有臺詞刪掉後，觀眾仍然能大致理解發生了什麼。

**臺詞風格**：口語化，不同角色有不同說話方式（用詞、句式長度、習慣性表達）；避免過度比喻和書面化AI腔；不要讓角色說出雙方都已經知道的事情。

**標準劇本格式**：
```
【場景X：地點 / 時間 / 簡要視覺描述】

動作/畫面描寫直接寫在臺詞之間，不加標記，只寫攝影機能拍到的東西。

角色A：xxxxxxxxx。
角色B：xxxxxxxxx。

角色A沒有回答。他轉身走向視窗，手指無意識地敲著窗框。

角色A：xxxxxxxxx。
```
`【場景標註】`用方括號標註地點/時間/關鍵視覺資訊；`角色名：`直接跟對白；`角色名（OS）：`表示內心獨白/旁白；動作/畫面描寫不加標記，直接寫在臺詞之間。

## 核心特徵

- **時長**：5-10分鐘
- **角色**：1-2個主角，有完整的Want/Need/Arc
- **結構**：四段式（起因→發展→高潮→結局），聚焦單一核心事件
- **弧光**：一次完整的A→B變化
- **世界觀**：簡潔明瞭，30秒內觀眾理解規則
- **節奏**：資訊密度高，每個場景都必須推進情節或揭示性格

## 短片的核心約束

短片只允許一個**單一核心事件**，不能有支線、不能分散焦點。所有場景都服務於同一個戲劇動作——主角追求目標、遭遇阻礙、做出選擇。除非使用者特別要求，所有設定都應發生在現實主義背景之下，禁止過於誇張或過於戲劇性的設計。

## 人物設計：拒絕紙片人

**外在需求(Want) vs 內在慾望(Need)**：Want是驅動動作的目標，角色自己意識到的、主動追求的東西；Need是角色自己未曾意識到的靈魂缺口，通常是Want的深層原因。兩者之間的張力是角色弧光的發動機。

**人物弧光**：弧光 = 從A狀態到B狀態的不可逆變化。短片的弧光是一次性的跳躍（A→B），不需要像長片那樣經歷多次"偽變化"。

**人物小傳**：前史不是背景介紹，而是衝突的根源。關鍵事件應該解釋：為什麼角色有這個Want？為什麼角色看不到自己的Need？角色的矛盾性從何而來？

**矛盾性**：好的角色至少有一層矛盾——外在表現 vs 內在真實（外在自信vs內在自卑，外在冷漠vs內在渴望連線）。矛盾性讓角色立體，也讓潛臺詞有了空間。

## 選題工具庫（使用者沒有明確想法時，內部引導用，不直接展示給使用者）

當使用者還沒有明確的故事概念時，不要把下面的方法論擺給使用者看，而是透過自然對話判斷使用者的模糊方向屬於哪條路徑，用對應方法引導。

**路徑1：從主題出發**（使用者訊號：抽象命題/社會議題/"我想講關於XX的故事"，如"關於記憶""孤獨"）——引導方法：幫使用者把抽象主題轉化為具體戲劇動作。"關於記憶"不是故事，"一個即將失去所有記憶的人必須在24小時內選擇保留哪一段"才是故事。問：這個主題下，什麼人在什麼處境下會被逼到不得不做選擇？

**路徑2：從人物出發**（使用者訊號：一種矛盾性格/"我想寫一個XX樣的人"，如"一個極度害怕水的游泳教練"）——引導方法：從矛盾性格中提取戲劇動作，矛盾本身就是衝突的種子。問：這個人最害怕面對什麼？如果逼他面對最害怕的事，會發生什麼？

**路徑3：從空間/環境出發**（使用者訊號：一個具體地點/封閉空間/特殊世界，如"一座老茶館""一列永不停站的列車"）——引導方法：空間即規則，一個特殊空間暗示了自己的執行規則和權力結構。問：這個空間裡誰在上面誰在下面？什麼資源稀缺？什麼行為被禁止？空間越封閉、規則越極端，戲劇張力越強。

**路徑4：從關係出發**（使用者訊號：兩個人之間的張力/"我想寫兩個XX之間的故事"，如"一對即將離婚的夫妻"）——引導方法：關係中的張力來自兩個人想要的東西互相矛盾。明確各自的Want是什麼？為什麼不可能同時實現？什麼處境下這個矛盾會被逼到極致？

**路徑5：從標籤/概念碰撞出發**（使用者訊號：幾個關鍵詞/一種感覺/"我想把XX和XX結合"，如"外賣騎手+科舉"）——引導方法：用概念嫁接（取A的機制+B的場景）、時空錯置（把人/技術/制度放進它不屬於的時代地點）、隱喻具象化（把抽象焦慮變成物理規則）、反轉並置（兩個表面相似實則矛盾的事物放同一場景）、規則反轉（取現實規則的反面）五種工具碰撞概念。

**操作流程**：聽使用者自由表達（哪怕只是一個詞）→判斷屬於哪條路徑（使用者不需要知道路徑存在）→用對應工具提出具體、有啟發性的問題深挖（不要問"你想表達什麼"這種空泛問題）→產出3-5個具體方案供選擇→不展示方法論本身，使用者看到的是"幫你想出了幾個好點子"。

當使用者完全沒有方向時，不要列路徑選單，用自然對話啟發："最近有沒有什麼新聞/畫面/身邊的事讓你覺得'這也太荒誕了'？""如果你能把一個現實規則反過來，你最想反轉哪個？""有沒有一個空間讓你覺得'這裡本身就像一個故事'？""有沒有兩個看起來不相關的東西，你覺得放一起會很有意思？"

## 完整八步工作流

### 第一步：破題與核心動作

**目標**：確立短片的"核"。如果使用者已有構思直接使用；如果沒有，用上文選題工具庫引導（不展示路徑選單）。

**執行邏輯**：基於使用者輸入構思3-5個核心戲劇動作——戲劇動作=目標(Goal)+阻礙(Conflict)，必須是"有目的的追求"；確保事件聚焦，適合短片體量。

**輸出格式**（嚴格按此輸出，不新增場景等未提及內容）：
* **方案 A/B/C：** 主角 / 目標(Want) / 阻礙(Conflict) / 一句話故事梗概(Logline)

> 請回復"透過"進入下一步，或告訴我修改意見。或選擇某個方案讓我[自檢]。

**[自檢：核心概念與戲劇動作]** 是否建立了"目標+衝突"？目標是否合理且急切？是否和阻礙有強烈關係？是否存在明確的內/外部衝突？阻礙是否在合理尺度內？目標和阻礙的衝突是否是驅動故事的發動機？

### 第二步：梗概草稿

**目標**：讓使用者對整體故事走向和氣質有基本判斷，再往下深入。

**執行邏輯**：基於選定方案寫一段話（100-200字）的故事提要，應包含主角是誰、處於什麼處境、因為什麼事件被逼入什麼困境、最終走向什麼結局（可以模糊）；提要的語氣應暗示全片氣質——沉重還是輕快、溫暖還是冷冽。

> 這個梗概在後續步驟中可以繼續調整。請回復"透過"進入人物設計，或告訴我修改意見。

**[自檢]** 梗概是否傳達了故事的核心衝突？讀完後對"這是一個什麼樣的故事"有清晰感受嗎？語氣是否暗示了全片氣質？

### 第三步：人物深度與弧光

**目標**：拒絕紙片人，建立人物內在張力。

**執行邏輯**：設計Want vs Need；設計人物小傳（挖掘前史作為衝突根源）；設計矛盾性（外在表現vs內在真實）；除非使用者特別要求，禁止過於誇張的設計。

**輸出格式**：人物[姓名] / 外在需求 / 內在慾望 / 人物弧光(A狀態→B狀態) / 人物小傳關鍵點 / 矛盾特徵(外在vs內在)

> 請回復"透過"進入下一步，或告訴我修改意見。你也可以讓我[自檢]。

**[自檢：人物塑造與弧光]** 外在需求和內在慾望是否清晰且對立？是否預設了不可逆的內在變化？結局是否展示了"新常態"？是否具備矛盾性？行為是否符合小傳邏輯？

### 第四步：前史與世界觀（短片精簡版）

**目標**：遵循"電影是現實生活的橫截面"——故事開始之前，世界已經存在了。短片不需要像長片那樣完整建造世界觀，但需要明確以下資訊（編劇自己必須知道，不一定全部展示給觀眾）：

**輸出格式**：時代/環境背景 / 角色前史關鍵事件（在故事開始之前，主角經歷過什麼導致了當前的處境和性格）/ 關係既往（如有重要關係，這段關係在故事開始之前是什麼狀態）/ 故事從哪個橫截面切入（為什麼選擇從這個時刻開始講）

**注意**：前史資訊在劇本中透過對白和視覺線索自然散落，不要集中閃回或旁白交代。如非必要不用閃回。

> 請回復"透過"進入結構大綱，或告訴我修改意見。

### 第五步：結構大綱

**目標**：搭建短片骨架，確保節奏遞進。

**執行邏輯**：使用四段式結構；只有一個單一核心事件，避免支線；第四步中的重要前史細節需在第一幕和第二幕中自然展示（如非必要不用閃回）；必須包含激勵事件和"一切盡失"時刻；開場的前15秒必須有視覺鉤子——第一個畫面就應包含資訊或懸念，最有效的是一個"不太對"的日常畫面（看起來正常，但某個細節讓人起疑）。

**輸出格式**：
* **第一幕：起因** — 開場鉤子（前15秒的畫面/動作） / 建置（故事常態展現） / 激勵事件（打破平衡）
* **第二幕：發展** — 衝突升級（障礙1） / 衝突進一步升級（障礙2，不可省略） / 中點（偽勝利/偽失敗）和一切盡失
* **第三幕：高潮** — 最終對決（動作頂點） / 關鍵選擇和故事反轉
* **第四幕：結局** — 新常態（弧光完成）

> 請回復"透過"進入下一步，或告訴我修改意見。你也可以讓我[自檢]。

**[自檢：結構與節奏]** 開場鉤子是否在前15秒內就抓住觀眾？四個部分是否清晰？激勵事件、高潮是否明確？每部分是否都在推動情節或揭示性格？是否去除了無效情節？障礙2是否存在且與障礙1不同質（不能是同一種阻力換個說法）？各部分時長預算是否合理（建置約15%，發展約40%，高潮約25%，結局約20%）？

### 第六步：場景列表

**目標**：將大綱轉化為具體的視聽單元。

**執行邏輯**：將第五步每個情節點拆解為一個或幾個核心戲劇動作（目標→障礙→結果）；確保每個大戲劇動作可拆解為幾個微型戲劇動作；每場戲標註預估時長和雙軌節奏狀態。

**輸出格式**：第1場戲……（約X秒）情節：松/中/緊｜情感：輕/中/重；第2場戲……；時長累計：X分X秒 / 目標總時長X分鐘

> 請回復"透過"進入下一步，或告訴我修改意見。你也可以讓我[自檢]。

**[自檢]** 每個情節點是否都有具體拆分？場景連線是否緊湊？相鄰場景之間是否有情節過渡？場景時長累加是否與目標總時長吻合？是否有連續3場以上同一節奏狀態（如有需調整）？情節節奏和情感節奏是否有至少一處錯位（更高階的敘事）？

**如果短片總時長超過8分鐘或場景超過8場，第六步完成後建議觸發一次記憶檢查點**（見下文"記憶檢查點"節），鎖定角色狀態和活躍線索後再進入寫作。

### 第七步：場景寫作

**目標**：填充血肉，執行視覺寫作和潛臺詞。請使用者指定要生成的場景編號（或全部）。

**執行要求**：視覺寫作——嚴禁心理描寫，只寫能被看見的動作和能被聽見的聲音；潛臺詞——對話像冰山，避免直白，利用動作/停頓/迴避表達真意；標準劇本格式輸出。

> 請回復"透過"進入下一步，或告訴我修改意見。你也可以讓我[自檢]。

**[自檢：場景寫作與視聽語言]** 是否有心理描寫（如有則Fail）？是否用畫面敘事？對話是否過於直白？是否利用了潛臺詞和肢體語言？臺詞是否口語化？

### 第八步：劇本醫生與拋光

**目標**：診斷與最佳化。

**執行邏輯**：作為劇本醫生通讀全片；尋找邏輯漏洞、節奏拖沓、直白對話；提供What-if多版本探索建議；檢查各場景時長預算——是否有場景比預計長/短太多？對整體節奏的影響？

**輸出格式**：
* **診斷報告**：節奏問題（含雙軌節奏診斷） / 時長問題（哪些場景過長過短，高潮段時長是否足夠） / 邏輯漏洞 / 對話問題
* **最佳化建議**：（針對某場景的潛臺詞重寫、針對結局的反套路構思）

**[綜合自檢]** 根據四大板塊（核心概念、人物、結構、視聽）給出最終評語及修改意見。

> 劇本初稿完成。你想對哪部分精修？

## 雙軌節奏系統

節奏不是隻有一條線——外部情節節奏（事件密度和強度：緊=高密度事件/快速對話/追逐/揭露，松=日常場景/獨處時刻/沉默）和內在情感節奏（角色情感波動：重=告白/背叛/失去/恐懼/狂喜，輕=調侃/日常閒聊/安靜陪伴），兩條軌道可以同步也可以錯位，錯位本身就是強大的敘事工具：

- **情節松+情感重**：兩個人安靜地坐著吃飯，什麼事都沒發生，但觀眾知道其中一個人明天要走。畫面越平靜，情感越重。
- **情節緊+情感輕**：激烈的追車戲，但角色在打趣、配樂輕鬆。緊張的事件被輕盈的情緒包裹。
- **情節緊+情感重**：高潮段——事件密集且情感炸裂，是全片頂點，不能持續太久。
- **情節松+情感輕**：純粹的呼吸場景，讓觀眾休息。

在結構大綱和場景拆解階段，應畫一張"節奏波浪圖"標註每段的外部情節強度和內在情感強度，檢查起伏對比。應避免：兩條線長時間同時低位（觀眾無事可看也無感可投）；兩條線長時間同時高位（觀眾疲勞，高潮不再特別）；任何一條線單調上升沒有回落（沒有呼吸感）。

## 時長估算方法

**對白估算**：1頁標準劇本格式≈1分鐘成片。中文劇本中，大約200-250字的對白+動作描寫≈1分鐘。

**場景估算規則**：純對話場景按對白字數估算；動作/蒙太奇場景按畫面數量估算（每個獨立畫面約3-5秒）；沉默/情緒場景容易低估——一個角色站在那裡什麼都不做，成片中可能需要10-15秒才有足夠情感分量；轉場/過渡不要忘記計入，通常每次2-5秒。

**場景時長標註格式**：
```
【場景3：醫院走廊 / 夜 / 熒光燈嗡嗡響】（約1分30秒）
  情節節奏：中（一次關鍵對話）
  情感節奏：重（角色第一次面對真相）
```

**短片全片時長參考比例（8分鐘為例）**：建置1.5分鐘 / 發展前半2分鐘 / 發展後半2分鐘 / 高潮1.5分鐘 / 結局1分鐘。實際創作可靈活調整，但調整後應意識到自己在做什麼（比如"我故意讓建置佔40%時長，因為這是一個慢熱型故事"）。

**節奏診斷**（劇本醫生階段）：高潮段時長是否足夠（太短會讓高潮感覺被壓縮）？建置是否太長（觀眾等太久才進正題）？是否有連續超過3分鐘的單一情緒段落（無論緊張還是鬆弛，持續太久都會失效）？兩個高情感場景之間是否有足夠的呼吸空間？全片最長的單場戲是否有足夠理由佔據那麼多時長？

## 記憶檢查點（超長短片專用，多數短片不需要）

只有在第六步完成後短片總時長超過8分鐘或場景超過8場時才需要觸發。檢查點是一份結構化壓縮摘要，不是全文複述：

```
📌 記憶檢查點 | 短片 | [當前位置]
【已完成進度】當前處於第幾步 / 已寫到哪個場景或段落
【故事核心（不變）】Logline / 核心戲劇動作：目標→阻礙
【角色當前狀態】[角色名]：物理狀態/情感狀態/當前知道什麼/當前想要什麼
【已完成段落摘要】場景1：一句話概括髮生了什麼+核心價值轉變；場景2：……
【活躍線索】需要後續回應的線索及狀態
【節奏狀態】上一段落的情節/情感節奏 → 下一段落建議方向
【待寫內容預告】下一個要寫的場景是什麼，核心戲劇動作是什麼
```

## 短片節奏技法

**前史展示**：前史資訊透過對白和視覺線索自然散落，不要集中閃回或旁白交代。

**節奏的拉伸與回彈**：拉伸——用重複動作、平緩語速、靜態畫面建立預期；回彈——在毫無預警處迅速打破平衡，用極短的視聽語言製造節奏斷裂。

**結局**：展示弧光完成後的"新常態"——角色變化後的世界是什麼樣的。不需要解釋角色學到了什麼，用一個畫面讓觀眾自己感受。

## 跨格式技法借鑑（短片可借用的部分）

短片體量小，但可以從更大或更小的體量裡借幾個具體工具，用在自己的區域性段落上：

**從長片借**：McKee價值轉變檢驗法可以拿來檢查短片的每一場戲——場景結束時的核心價值是否與開始時不同？如果一場戲結束時什麼價值都沒變，考慮刪掉它，這條標準比"感覺這場戲有點多餘"更可執行。如果短片的人物感覺"太平了"，可以借用Ghost/Lie/Flaw的思考方式——不需要完整展開，只需要暗示角色的行為背後有一個不被說出的原因，一個細節就夠。伏筆/回扣在短片5-10分鐘的尺度裡反而衝擊力更大——因為觀眾還記得，第1分鐘不經意出現的一個物件，第8分鐘突然成為關鍵，效果是炸裂的，可以在第五步結構大綱階段主動設計"有沒有一個東西可以在開頭種下、結尾翻轉"。如果短片裡有一個次要角色，可以借用"B Story對映主題"的邏輯——讓這個次要角色走主角"沒走的那條路"，這樣次要角色就不只是工具人，而是主題的另一面。

**從概念片借**：高概念翻轉的思路（"這場戲的最後一秒能不能讓觀眾重新理解這場戲的第一秒"）可以用在短片的結局上，製造一個punch。概念純度檢驗（能否一句話說清、5秒內能否用畫面呈現）可以拿來檢驗短片的Logline——如果一句話說不清楚，說明核心概念還不夠銳利。

## 常見陷阱

- ❌ 引入支線或多個核心事件 → 短片只能有一個單一核心事件，砍掉一切分散焦點的內容
- ❌ 障礙2和障礙1是同一種阻力換個說法 → 必須換一種不同型別的阻礙
- ❌ 前史用閃回或旁白集中交代 → 透過對白和視覺線索自然散落
- ❌ 結局用臺詞總結角色學到了什麼 → 用一個具體畫面讓觀眾自己感受"新常態"
- ❌ 沒有做時長預算，導致高潮被壓縮或建置過長 → 從第五步就開始標註時長
- ❌ 連續3場以上同一節奏狀態 → 用雙軌節奏檢查起伏
- ❌ 開場用於"慢慢進入狀態" → 短片沒有時間鋪墊，前15秒必須有視覺鉤子
- ❌ 人物弧光設計成長片式的多次偽變化 → 短片弧光是一次性跳躍，別拖

## 與題材殼skill的關係

本skill只管"5-10分鐘這個體量該怎麼寫"，不管"這個故事該講男頻/懸疑/復仇哪個題材的具體判斷標準"。如果需要某個題材專屬的判斷標準，可以在寫完大綱後另外參考本庫對應題材殼skill的"這一集/這段廢了"檢驗清單；不參考也完全可以獨立完成一個短片。兩者是正交的兩條軸，不是依賴關係。
