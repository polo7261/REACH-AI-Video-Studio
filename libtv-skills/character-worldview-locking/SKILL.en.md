### 1. Purpose

Designed for comic-drama and short-drama development, this skill deeply analyzes scripts and reference images to generate structured character bibles, complex relationship networks, worldbuilding setting tables, and "no-modification red lines," ensuring creative consistency from script to post-production assets and preventing character persona collapse.

### 2. Applicable Inputs

- **Script content**: Full scripts, episode synopses, or script excerpts.
- **Setting materials**: Existing character design drafts, actor profiles, or personality keyword text.
- **Visual references**: Character concept art, scene mood images, and costume reference images (jpg/png).

### 3. Operating Steps

- **Visual feature analysis**: Extract appearance tags (hairstyle, body type), temperament descriptions (e.g., cold and stern, sweet), and the visual tone of the scene's worldview from reference images.
- **Character bible construction**: Integrate visual and textual information to generate detailed character biographies containing core desires, character arcs, secrets, and "immutable settings."
- **Relationship network modeling**: Output a multi-dimensional relationship map between characters (including surface and true relationships), and provide Mermaid rendering code.
- **Red-line setting lock**: List setting items that must be locked down, such as physiological features, skill ceilings, and dialogue-style fingerprints (speech pace, sentence patterns, verbal tics).
- **Worldview structuring**: Integrate the era, location, social rules, and core conflicts, and output a visual self-check checklist and a consistency check report.

### 4. Output Requirements

- **Multi-section output**: Includes character biographies, three-tier identity tags, relationship strength tables, no-modification rules, and worldbuilding tables.
- **Dialogue fingerprints**: Provide 3-5 example signature lines matching each character's personality.
- **Conflict annotation**: If script details conflict with the established settings, clearly mark them in the check report and provide revision suggestions.

### 5. Notes

- The relationship network must include emotional intensity scores (1-10) and the episode numbers of key turning points.
- The generated Mermaid code can be used directly for rendering in visualization tools.
- If the user's input contains logically ambiguous points, the output will automatically be marked with 【Requires Director Confirmation】.
