# high-md-flow

做高能 / 超動態（kinetic / hyperkinetic）品牌 reel 時用本 skill——峰值動作、狂放運鏡、smash cut，用於運動 / 時尚上新 / 科技揭幕 / SaaS reveal 一類需要爆發力的品牌片。三段式推進。

**high 檔的定位**：高動能混沌（hyperkinetic chaos）。運動主要來自相機與主體的爆發式動作——與 classic-md-flow 的"穩而剋制內部編排"正相反。下面的分鏡板 / 片段規則據此校準；凡是漂移鎖定、慢速優雅滑行、不可察覺微推軌這類語言都不屬於 high 檔（那是 classic / typography / infographic 的語言，混進來會破壞能級）。

## 三段

1. **風格板（Stage A）**：有圖作基底則上傳（`upload`）、跳過風格板；無圖用 `generate_image_v3`（可用 `style_display_board`）出一張 4 格風格板，風格提示帶"高動態 / 高能"傾向，使用者選定一幀（`ask_human`）作視覺世界基底，其餘備選幀忽略。
2. **分鏡板（Stage B）**：以選定基底為準，`generate_image_v3`（`storyboard_panel`）出 6 格分鏡板，引用基底幀。
3. **動效片段（Stage C）**：`generate_video_v3` 以分鏡板為參考生成連續片段；多段用 `composite_video` 合成。

## 分鏡板規則（Stage B 深度）

- **網格與基底**：6 格 3×2 橫向（上排 1-2-3、下排 4-5-6），整板 3:2；格間細髮絲分隔（1pt / 12-20px 間隙）、格內無邊框、畫面純淨（去日期 / 偽資料晶片 / 拉丁副標 / 等寬時間碼 / 後設資料標籤）。從風格板選定的那一幀作整板視覺世界基底。
- **文字下限**：格內任何文字字號不低於格高約 10-12%（cap-height）；小號拉丁副標 / 等寬時間碼一律去掉。
- **峰值動作強制（PEAK-ACTION）**：每格都定格在動作頂點——起跳最高點、飛濺、粉碎、爆發、拉絲的瞬間。不要靜置主體、不要休止狀態、不要"空場裡的產品"。
- **環境密度強制（AMBIENT DENSITY）**：每格主體後至少 2 層氛圍填充——① 粒子飄移（火花 / 塵 / 拉絲粒子 / 霧靄）② 背景漸變呼吸（調色飽和度迴圈）③ 體積光束（邊緣光 / 神光 / 聚光）④ 表面質感（混凝土 / 沙 / 液麵 / 鏡面地）⑤ 前景景深元素（主體前的虛焦道具）。
- **文字錨點（Pattern A · 奇數格模式）**：第 1 / 3 / 5 格承載 2-4 詞大字標（display 字型），第 2 / 4 / 6 格無字、純峰值氛圍。文案由專案主題生成，不用固定樣板句。
- **六格內容弧（每格一峰值 + 一特技運鏡，逐格校準）**：
  - P01 鉤子（0-2.5s）· CRASH-OUT REVEAL：極特寫細節瞬切到寬景、主體起跳（頂點）；配甩鏡拖影 + 頓幀凍結；承載首個大字標。
  - P02 · SHATTER PUSH-THROUGH（2.5-5s）：相機穿膜推進、主體在碎裂瞬間衝出；折射碎屑 + 色散邊緣；無字。
  - P03 · VERTIGO PULL（5-7.5s）：主體縱跳到頂點、相機同步推拉變焦；速度斜坡 + 鏡頭拉絲；承載第二個大字標。
  - P04 · DROP-DIVE PAST（7.5-10s）：相機垂直俯衝掠過下墜 / 旋轉的主體；粒子裡的漩渦 + 輕微畸變漏斗；無字。
  - P05 · HYPERKINETIC ORBITAL SWEEP（10-12.5s）：相機繞爆發 / 飛濺中的主體高速環繞；衝擊波環 + 折射薄霧；承載第三個大字標。
  - P06 收束（12.5-15s）：終寬景、主體收成乾淨英雄剪影、餘粒沉降；殘霧 + 柔體積光束；無字。
- **五鎖（跨格一致，寫進提示詞並逐格複述）**：主體鎖（基底的英雄主體 / 母題）、材質鎖（復刻基底主材質身份）、風格鎖（Tier-1 高階動效 3D / 2.5D 打磨的 hyperkinetic chaos 調性）、調色鎖（基底取約 3 個主導 hex 色）、氛圍鎖（復刻基底的光照情緒 + 霧密度 + 景深）。
- **禁寫實真人（HR-3）**：照相寫實真人 / ARRI Alexa / 35mm 顆粒 / 真皮質感嚴禁。用剪影 / 抽象形體 / 風格化 3D / 2D 插畫 / 運動拖影形體 / 粒子形體 / 打光體積剪影替代。照相寫實質感僅 product-md-flow 例外。

## 動效片段規則（Stage C 深度）

- **形態**：一段連續全幀 16:9，分鏡板只作規劃參考、不是面板網格；每鏡填滿全幀。
- **相機基調（high 檔核心 · HYPERKINETIC CHAOS）**：每鏡一個峰值動作時刻（跳躍最高點 / 飛濺 / 粉碎 / 爆炸），絕不漂移鎖定、慢速優雅滑行或不可察覺微推軌。相機詞彙——眩暈拉近 VERTIGO PULL（約 2m 推近同時拉遠）、CRASH-OUT REVEAL（極特寫 0.4s 內切寬、約 3m 後拉）、穿膜推進 SHATTER PUSH-THROUGH、高速軌道環繞 ORBITAL SWEEP、垂直俯衝 DROP-DIVE PAST（約 6m）、鐘擺甩弧 MATCH-FRAME SWING（約 90°）、甩鏡拖影 WHIP-PAN。允許速度斜坡（慢動作→極速）+ 撞擊時刻約 2 幀頓幀凍結。強視差：前 / 中 / 背景約 100 / 40 / 15 的位移比。
- **6 鏡弧線**：每鏡約 2-2.5s，一個峰值動作配一種特技運鏡（如 ① 抽象材質英雄 CRASH-OUT + 甩鏡 0.2s、② 動能環境 VERTIGO PULL 1.5s + 環繞 180°、③ 硬表面宏觀到寬景 MATCH-FRAME SWING 90° + 凍結閃光、④ 建築 / 抽象深度走廊 DROP-DIVE PAST 6m、⑤ 能量核心 ORBITAL SWEEP 120° + 穿膜、⑥ 最終英雄幀 VERTIGO PULL 0.8s→鎖定）。鏡間用強衝擊轉場：穿膜推進 / 熱光斑光掃 / 物體形變 / 向內坍塌 / 粒子溶解（禁 cross-fade）。
- **尾幀凍結**：13.7-15s 強制定格末幀，畫素一致，無新動作 / 元素 / 轉場 / 淡出。
- **音訊**：僅動能 SFX 混音——重低音撞擊 / 玻璃碰撞 / 稜鏡閃光；無音樂、無 VO、無對話、無自動字幕。

## 比例預設與通用

| 步 | 預設比例 |
|---|---|
| Stage A 風格板 | `3:2` 恆定 |
| Stage B 分鏡板（3×2 六格） | 16:9→`3:2` / 9:16→`9:16` / 1:1→`1:1` |
| Stage C 片段 | `16:9` 預設，未指定就問 |

Stage C 生成預設 `count: 2`（同 prompt 兩份變體）。有圖作基底則跳過風格板。Stage B/C 的創作（分鏡 / 片段 prompt）源裡在後端 enhancer，本環境由 agent 自己寫——board 網格紀律與 hyperkinetic 相機基調工藝已內聯在上兩節，不外包。
