# award-ceremony-video

做"頒獎典禮"這類個性化榮譽/趣味影片時用本 skill。一條 15 秒電影感一鏡：主持人在臺上宣佈 → 聚光燈掃到人群中的獲獎者 → 起身走向領獎臺 → 領獎 → LED 屏亮出名字與獎項。**圖序 = 身份序：第一張 = 獲獎者 =** `@image_1`**，第二張 = 主持人 =** `@image_2`**；調換會把"宣佈者"與"上臺者"對調。**

> 本環境適配：源為 MUAPI/Seedance 2.0 圖生影片 recipe，表達已按 MIT 重寫。Seedance → `generate_image_v3`（角色錨點）+ `generate_video_v3`（圖生影片，一次呼叫 ≤15 秒）；`@image_1/@image_2` → `reference_nodes` + prompt 裡 `{{NodeKey}}`；技術規格（`aspect_ratio`/`resolution`/`duration_sec`/生成音訊）走欄位，不寫進 prompt 正文。

## 輸入

名稱必需預設說明獲獎者照是—清晰正臉照。作 `@image_1`（第一張），全片身份嚴格鎖定。主持人照是—清晰正臉照。作 `@image_2`（第二張），臺上唯一主持人。獲獎者名字否Olivia主持人念出，並渲染在 LED 屏 "THE BEST ACTOR" 之上。生成前先跟使用者確認拼寫（音訊與 LED 屏兩處都出現）。獎項名否THE BEST ACTORLED 屏顯示的獎項標題。

## 流程

### 一、確認輸入

兩張照片任一缺失 → 請使用者先上傳。生成前確認獲獎者名字與獎項名——兩者都會在成片裡出現（音訊 + LED 屏文字），拼寫錯了要重燒。

### 二、註冊雙人錨點

用 `generate_image_v3` 為獲獎者、主持人各出一張穩定角色設定圖，作持久身份錨點（獲獎者 `{{Winner}}`、主持人 `{{Host}}`）。**順序即身份**：獲獎者錨點先入 `reference_nodes`（對映 `@image_1`），主持人次之（對映 `@image_2`）。若兩人此前已有可複用錨點，直接複用 node_key、跳過重建。

### 三、生成成片

用 `generate_video_v3` 圖生影片，一步出片：`reference_nodes` 按 \[獲獎者, 主持人\] 順序傳入；`aspect_ratio=16:9`、`resolution=720p`、`duration_sec=15`、開啟生成音訊。prompt 覆蓋下述五軸 + 15 秒時間線：

**風格與基調**：極寫實真人頒獎典禮現場，多機位廣播質感——在精修的電視轉播機位與貼身手持紀錄片鏡頭之間切換；奧斯卡/格萊美級製作水準；真實人類反應，不過度表演。

**布光**：宏大室內頒獎場館。戲劇性舞臺光——舞臺暖金聚光、觀眾席偏冷環境光、廣播攝像機燈、LED 屏投出彩色光。宣佈獲獎者瞬間——一束暖光掃過並鎖定人群中的獲獎者。

**場景**：格萊美/奧斯卡規模的頂級頒獎場館。高聳 LED 屏的大舞臺、優雅講臺、現場樂池、成千正裝觀眾成排就座、過道兩側的媒體攝像機、頭頂大屏播直播畫面——整個場館散發氣派與規模感。

**身份嚴格鎖定**：

- `@image_1` 獲獎者「{名字}」——以 @image_1 為嚴格身份，正裝出席、無墨鏡、不改臉不改身形，初始坐在觀眾席正裝人群中。
- `@image_2` 主持人——以 @image_2 為嚴格身份，講臺唯一主持人，保持精確面部/身形/特徵，正裝、不改臉不改身形。

**音訊**：優雅管絃背景樂、主持人話筒聲經場館揚聲器投射、人群低語後轉為爆發的掌聲歡呼、椅動聲、上臺腳步聲、獎盃/獎牌遞接聲、觀眾情緒反應。

**15 秒時間線（跨鏡每處重標身份錨點，防漂移）**：

- **0–3s 宣佈**：@image_2 面部廣播特寫（緊、電影感），立於講臺話筒前暖金聚光下，神情從容有魅力、刻意積蓄懸念；手持信封/卡片，最後瞥一眼，直視鏡頭，一拍靜默，湊近話筒緩緩說"And the winner is..."；鏡頭鎖在 @image_2 臉上——唇、表情、張力；背景人群低語。
- **3–6s 獲獎者**：硬切到觀眾席——低角度電視機位穿過成排座位推進，找到坐在賓客中、放鬆未預期的 @image_1；@image_2 聲音繼續經揚聲器轟響出名字；聚光從上方驟然鎖定 @image_1，其表情由真實錯愕（睜大眼、微張口）轉為忘我笑容，左右看向身旁難以置信；全場掌聲歡呼爆發，周圍人起立鼓掌拍肩。
- **6–9s 起身與行進**：@image_1 挺身、平復、起立；手持紀錄片鏡頭立刻從過道跟上——隨人前行朝舞臺移動，微晃、貼身、真實；掌聲持續轟鳴；頭頂廣播大屏切到其面部直播；@image_1 從容前行——正裝整潔、身姿挺直、神情溫暖略動情。
- **9–12s 抵臺**：手持鏡頭隨 @image_1 登臺階，明亮舞臺聚光在其登臺時完全打上；@image_2 從講臺前迎、暖笑、雙手捧獎牌；@image_1 抵講臺、雙手接過、低頭看一眼真實一刻；兩人自然一笑與短握手；身後巨型 LED 屏：@image_1 面部大幅肖像、其名字以粗體優雅字型呈現「{名字}」、下方「{獎項名}」，屏面輝光並跳動慶祝圖形。
- **12–15s 定格**：鏡頭落到全舞臺廣播全景——@image_1 立於講臺手持獎牌、@image_2 立其旁、身後 LED 牆以其名字與面部灼亮；聚光鎖 @image_1；掌聲充滿全場、起立鼓掌層層擴散；@image_1 略舉獎牌望向人群、笑容從容真誠；@image_2 在旁領掌；末幀定格——全舞臺、灼亮 LED、轟鳴人群、@image_1 立於中心；不淡出黑場。

出片後把這條 15 秒成片交付使用者。
