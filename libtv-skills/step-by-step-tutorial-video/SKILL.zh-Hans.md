# ugc-tutorial-flow

做 UGC 风格教程视频（达人**分步演示某产品用法**、画面带「Step N」步骤字幕）时用本 skill。创作（人设 / 独白 / 分镜 prompt）由你自己做——源里委托给后端 enhancer，本环境没有。你管控制流、门控、时序、拼接。

一条管线覆盖所有 UGC 教程 / 产品用法视频：**每个分镜槽 = 使用产品的一个物理步骤**。

## 分镜结构（教程专属 · 与口播底不同）

- 每块**分镜板 = 一条 21:9 横条，内含 4 个竖排 9:16 槽**（口播底是 16:9 含 3 槽；教程覆盖为 21:9 含 4 槽）。
- 每槽显示一个「Step N — Heading」字幕。
- **总步数 = 4 × 板数**；**步骤编号全局连续**（跨板不重置）。
- **CTA 尾**只出现在**最后一板的最后一格**。

## 流程

1. **解析需求 + 产品用法分析**（product-analyzer）：从真实使用流程导出步骤，产出 `step_captions` 数组。**必做**。
2. **人设生成**：`generate_image_v3` 出达人角色锚点（或用户给照片）。身份锁定为**单一 character 锚点节点**（`character_media_id` 概念），全程复用同一 `{{NodeKey}}`，见 character-consistency。
3. **上传 / 登记产品**为锚点。
4. **独白脚本**：写完整口播词，逐步对应各使用步骤。
5. **分镜板生成**：按时长定板数（见下），`generate_image_v3` **串行**出板（后板参考前板保持连贯）——**21:9 横条，内含 4 个竖 9:16 槽**，每槽带「Step N — Heading」字幕。
6. **逐镜写 prompt + 生成**：并行写各板 Seedance 风格 prompt（一批），`generate_video_v3` **一批并行提交**，`reference_nodes` 引人设 / 产品 / 分镜板锚点。
7. **拼接**：N≥2 段 `composite_video`（见 montage）；配音用 `generate_audio`。
8. **报告**。

## 人设生成规则（Step 2 深度 · UGC 家族通用）

达人锚点要做成**真实手机自拍**质感，不是杂志肖像：

- **构图**：手臂伸直的前置自拍，头肩填满画面，略微偏心 / 不完美构图（非摆拍、非影棚居中），持手机的手 / 腕可在画面边缘隐约出现。
- **真实感**：保留手机传感器颗粒与皮肤毛孔纹理，不修图、不磨皮滤镜、无影棚光 / 专业光泽；主体清晰、背景自然虚化。
- **服装**：全覆盖胸前 / 躯干，无 logo、无可见文字。
- **打光 / 环境**：柔和冷中性日光（侧窗），干净、无暖调、无修饰光晕。

## 手数 / POV 规则（UGC 家族通用 · 关键）

- 角色**恰好两只手**。
- **Selfie POV**：一只手拿手机（画外或边缘隐约可见），另一只手做动作——**绝不在 selfie POV 里同时拿两个物体**。
- 需要**双手**的动作（如实际操作 / 使用产品的步骤）→ 切 **Tripod POV**（手机不在画面）。
- POV 可在镜 / 槽间切换，切换**对齐硬切**。

## 镜头 / 渲染规则

- 每槽 = 演示的一个使用步骤；真实摄影风格 UGC、自然光、随意真实感。
- 演示步骤按实际使用顺序推进，槽内动作贴合该 Step 的 Heading。
- **握持物理**：产品的重 / 轻按实物表现，抓握、承重要真实。
- 产品呈现时 **label 朝前、不旋转**，画面恰好一个产品。
- **能量基调**：默认高能达人，**可按品牌调性调整**（不强制夸张尖叫）。
- 无镜子 / 反射镜头；无变形手 / 第三只手臂；画面上**无任何多余文字 / 品牌 / 标志**（「Step N」步骤字幕除外）。

## 关键规则

- **English-only**：字幕、独白、CTA 均英文；步骤字幕用「**Step N — Heading**」格式、**en-dash（—）分隔**。
- **产品用法分析必做**：步骤从真实使用流程导出，不臆造。
- **CTA 尾**（末板末格最后约 0.5–1s）：达人出镜 + 手势 + "Link in bio" / "Subscribe!"。
- **人设身份锁定**：单一 character 锚点节点贯穿全片，不要每镜重生成达人。
- **板串行、片并行**：分镜板串行生成（保连贯），Seedance 片段一批并行提交。
- **开场词约束**：口播第一个词**不要**用 OK / Okay / So / Um 等虚词起头，直接进钩子。
- **音频 / 稳定度**：自拍镜手持微抖、三脚架镜锁定定帧；成片无画面文字、无字幕、无水印（步骤字幕除外）。
- Seedance 逐镜默认 `count: 2`。
