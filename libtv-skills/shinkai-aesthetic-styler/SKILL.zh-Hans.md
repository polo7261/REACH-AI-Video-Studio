# 新海诚剧场版动画 影片流水线

> 🔴 **请严格按照该 SKILL 分步执行。** 版本：2.0.8

## 底层 DNA（无条件，每条画面都带）
1. 🔴 **光是主角（新海诚签名，最重要）**：每一帧都被光雕刻——强烈的逆光与半逆光、太阳的镜头光斑（lens flare）、光的开花（bloom）、玻璃与水面与金属的高光反射、空气中漂浮的发光尘埃粒子。光源方向明确且戏剧化，人物发丝与轮廓被光勾出金边，**主动追求逆光开花与炫光签名感**。但光是"美到心颤的光"而非"过曝的废片"——高光可开花、主体信息仍可读。
2. 🔴 **写实级精细动画背景 + 天空占比巨大**：新海诚的背景是"比现实更美的现实"——剧场版动画的手绘精细背景，一砖一瓦一根电线都刻画入微，透视精准、细节密度极高。天空是永远的主角：巨大的积雨云、蓝到发紫的天顶、magic hour 的橙紫渐变、星空与银河、飞机云与彗星。构图常给天空一半以上画幅，人物渺小地立于天地之间。
3. **深远景深、天地可读**：常用广角大远景把人放进巨大的天空与城市之间，纵深拉到地平线；近景时背景依然精细可辨（动画背景不虚化成光斑，最多轻微空气透视）。人物与天地的尺度对比本身就是叙事。
4. 🔴 **情绪内核：外放而诗意的青春情感（新海诚灵魂，务必拉住）**：这是新海诚最核心的气质——少年少女之间横亘着距离、时间、命运的思念与追寻。情感**是外放的、汹涌的、抒情的**：奔跑、呼喊、仰望天空、在人海中寻找一个人。底下流动的是相遇与错过、距离与羁绊、平行时空般无法触及的彼此、以及"世界如此美丽而我在想你"。⚠️ 绝不能做成克制疏离的冷淡日常、也绝不能做成廉价狗血偶像剧——差别全在"用整个天空和光来盛放情感"：情绪大，但被极致的美学与诗意托住,壮阔而不尴尬。
5. **让世界与情绪共振**：云在延时般流动、雨滴砸开水花、电车驶过铁道口、彗星划破夜空、光随情绪明灭。天气与天象是情绪的放大器，世界随人物内心一同呼吸。

## 质感尾词（🔴 完整版仅模卡与道具合图默认带；moodboard 不挂——风格由 sref 种子锚定；场景图只挂流程第 3 步的轻量风格稳定尾词、不挂本完整版）
`新海诚剧场版动画质感，写实级精细手绘背景细节密度极高，人物干净赛璐璐动画风格描线清晰、眼睛大而清澈有高光与天空倒影，强烈逆光与轮廓光、lens flare 镜头光斑、bloom 光晕开花、空气中发光尘埃，天空占比大（积雨云/magic hour 渐变/星空），色彩高饱和浓郁通透（蓝青为底、橙紫金作情绪高光），高对比、阴影透蓝紫不死黑，深远景深、背景与地平线精细可辨；不要真人实拍、不要3D渲染塑料感、不要写实照片质感、不要灰暗低饱和、不要平光无光影、不要背景虚化成光斑、不要粗糙低帧网页动画`

## 流程
0. **入口**：🔴 **所有向用户的询问与确认一律以选择卡/按钮形式呈现，不用纯文本提问**（执行 agent 优先调用其选择卡组件；开放输入项配一张"我来填/交给你"二选卡，选前者再展开输入框）。一次问清 ① 时长（选择卡：给几档常用时长如 15秒 / 30秒 / 60秒 / 自定义→展开输入）② 执行模式（选择卡：全自动/手动确认）③ 视频画幅分辨率（选择卡：4:3 / 16:9默认 / 21:9 / 自定义）④ 对白语言（选择卡：中文/英文/日文/其他→展开输入）⑤ 🔴 **人声模式**（选择卡：纯氛围〔无对话无旁白〕/ 纯对话 / 纯旁白 / 对话+旁白穿插）——作为剧本与全片硬约束 ⑥ **想讲什么故事**（选择卡：我来讲〔选后展开输入框〕/ 交给你自拟〔跳过、后续 agent 自拟不再追问〕）。写入 memory。
1. **风格确认**：不向用户征集元素、也不就 moodboard 向用户确认——moodboard 的天气/舞台/情感基调由 agent 依据入口第⑥问的故事输入提炼（用户跳过了则自拟一版），直接生成并默认作为全片风格锚，进入场景图生成。🔴 **moodboard 生成铁律（与其他图像资产不同，单独走这套）**：
   - **模型强制 Midjourney v7**（不走 libimage），MJ 语法出 prompt。
   - 🔴 **prompt 全英文输出**（MJ 对英文响应最佳）：moodboard 的 prompt 正文与所有描述词一律用英文写，仅此 moodboard 一处；场景图/模卡/道具/视频 prompt 的语言不受此条影响、维持原样。
   - **正文只写内容、不写风格**：只描述场景内容、构图、画面元素与氛围主体（可含"云/彗星"等作为画面元素的客观存在），**删除一切影调与色调类风格描述**——配色、饱和度、色温、对比度、明暗风格、阴影颜色、渲染质感词一律不写，也**不挂质感尾词**。风格全部交由风格种子统一锚定。
   - 🔴 **尾部强制拼接固定尾缀**：`--niji 7 --sref 3581618356 --sv 4`（写法照抄、参数不可改动、不可省略）。画幅参数（--ar）按所选画幅自行表达，不写死进尾缀。
   - 🔴 **MJ prompt 模板（照填，禁改结构与尾部种子，只换 [] 占位）**：
```
[weather & sky], [scene content & environmental objects, developed per the film's story direction], [figure or silhouette position & scale within frame (may have no figure)], [composition: viewing angle, depth of field, sky-or-subject share of frame, foreground/mid/background relationship], [lighting mood: light-source direction, backlight / lens flare / bloom, the shape of light in the air], single unified image bleeding to full frame, no borders no collage no panels [--ar per chosen aspect ratio, e.g. --ar 16:9] --niji 7 --sref 3581618356 --sv 4
```
   - 版式要求不变：单一融合画面铺满出血、禁白边/拼贴/分格（写进正文）。
   - 出 prompt 后自查：尾部种子在否？正文是否混入色调/影调/质感词（混入则删）？
   → 存为风格锚资产、记下归档标记。
2. **故事**：按入口第⑥问的答案走——用户有故事输入则遵循、仅叠加新海诚风格化；用户跳过了则不追问、agent 直接从母题中自选生成（相遇与错过/距离与思念/时空与命运/追寻与奔跑/世界之美与个人之小），与 moodboard 的天气/舞台/情感基调保持一致。🔴 故事定稿后按「剧本制作」章节产出剧本（含人声内容与角色表演基调表），剧本是后续分镜与视频 prompt 的唯一叙事依据。
3. **资产**：有戏角色必产白底棚拍模卡定妆图（锁脸/服装/发型），后续镜头一律 @角色名 引用。场景图单张空镜、绝不分屏。🔴 **场景图生成铁律（配合 moodboard 新锚定逻辑）**：
   - **模型用 libimage**（不变）。
   - 🎨 **每张场景图强制挂 moodboard 风格锚作参考**（仅锚色调/光感/质感、不锚构图，统一全片色调）——moodboard 已由 sref 种子锚死风格，场景图的风格**全部经此参考图传递**。
   - **正文四类描述为主 + 轻量风格稳定词**：色调/配色/饱和度/影调/对比度/阴影颜色等**色彩影调类**风格词仍不写（交由 moodboard 锚统一），但每张场景图 prompt 尾部固定挂一句**轻量风格稳定尾词**（防单靠参考图挂不住画风漂移）：`新海诚剧场版动画风格，精细手绘背景质感，干净的动画描线`；负面(独立框)固定带：`真人实拍、写实照片质感、3D渲染塑料感`。仅此，不再加更多风格词。
   - **正文保留四类描述**：①天气与天象（晴/雨/雪/云/黄昏/星空）②场景内容（空间、物件、环境细节）③构图（视角、景深、画幅占比、前中远景关系）④光线氛围（光源方向、逆光/lens flare/bloom、光在空气中的形态、明暗关系的客观描述）。
   - 出 prompt 后自查：是否挂了 moodboard？轻量风格尾词与负面在否？色彩影调类风格词是否混入（混入则删）？四类描述齐否？
   具名道具汇总一张白底道具合图。
4. **生成视频**：场景图+角色图（+含具名道具时挂道具合图）作参考锁一致性，分镜写进 prompt 时间轴。🔴 **视频生成不挂 moodboard 风格锚**（moodboard 只用于场景图生成阶段，视频参考只有场景图/人物图/道具图）。
5. **音乐**：等视频人物全定稿后再确认方向、再生成（默认 mureka）。🔴 **生成后先不合成进视频**——因当前 agent 工具在含音乐的视频上加字幕会出问题，音乐须暂存、等第 7 步字幕加完后再询问用户是否合成。
6. **合成**：跨 15 秒才拆多条、串行后用视频合成能力拼接。
7. **后期剪辑**（合成后或用户指定时，工具：agent.tool.edit_video；用户未提及则不擅自调用）：
   - **字幕** add_subtitle：白字黑色描边；语言跟对白语言，用户指定则翻译后加。人声模式为纯氛围时全片无台词无旁白、跳过字幕环节不询问。
   - **转场** transition：用户提及但未指定方式→默认直接硬切（新海诚剪辑以硬切与匹配剪辑为主）；可选硬切/淡入淡出/黑场；AI转场不在此列。⚠️禁溶解叠化只约束视频生成阶段，合成后可正常加转场。
   - **抽帧** extract_frames：agent 自动调用辅助判断转场；用户也可主动要求。
   - **裁剪** clip：秒级精度，用户描述需裁剪内容后执行。
   - **文字贴片** text_overlay：片名/章节 title card、cast 名单、人名条；用户可自定义文字内容与样式。
8. **音乐合成（字幕之后）**：🔴 字幕全部加完后，以选择卡询问用户是否把第 5 步已生成的音乐合成进视频（选择卡：合成/暂不）。用户确认后再执行音乐合成，收尾出片。⚠️ 顺序不可颠倒——必须"先字幕、后音乐"，因当前工具在有音乐的视频上加字幕会出问题。

## 剧本制作（故事定稿后、资产生成前执行）
- 🔴 **人声模式是硬约束（入口第⑤问选定，全剧本全片遵守）**：
  - **纯氛围**：不写任何台词与旁白，情绪全靠画面表演、光线与环境音承载；剧本只写动作、表情、视线与环境事件。
  - **纯对话**：该交流处**必须写出实际对白**，不得以"两人交谈"之类动作描述带过。
  - **纯旁白**：**必须写出实际旁白文本**；旁白是画外音、画面中人物不开口型（防视频模型给无声口型配错语种）。
  - **对话+旁白穿插**：两者并存，逐段标明是对白还是旁白。
- 🔴 **对白落地铁律（禁默片化）**：模式含对话/旁白时，剧本必须真写台词与旁白全文——对白标注说话人（@角色名："台词"），旁白标注（旁白："文本"）。只有动作描述、没有实际文本的剧本视为不合格、重写。
- **对白调性（本 skill 美学）**：短句、生活化、留白多——诗意藏在平常话里，情感浓度靠情境与光线托住而非台词直给；重要的话往往说一半、或用天气与景物代说。禁说教腔、禁狗血直白告白体、禁长篇大论。
- **旁白调性（本 skill 美学）**：第一人称内心独白式抒情（"世界如此美丽而我在想你"的声部），与画面互补而非复述画面——画面给世界之大、旁白给内心之近。句子短、有呼吸感留白。
- 🔴 **角色表演基调表（每个有戏角色必产）**：为每个有戏角色定 2-3 个**性格化的标志性小动作/习惯姿态**（由该角色性格决定，如：紧张时攥住衣角、思考时望向窗外、开心时脚跟离地半拍），随剧本归档。**全片跨镜一致**：视频 prompt 每镜的 @角色动作优先从基调表取用；标志性动作优先用作动作衔接切点素材（习惯动作起→下一镜承接）。
- **剧本格式**：分场编号 + 场景/时间 + 在场角色 + 场内容（动作与事件）+ 人声内容（按模式写对白/旁白全文）。每场落点对应一个可拍的生活/情绪片段，供分镜时间轴直接取用。

## 画幅与画质（写死）
可选比例统一为 4:3 / 16:9 / 21:9 三种，用户也可自定义输入并保留其选择。默认全部首推 16:9：moodboard 16:9；场景图 16:9；人物模卡 16:9；视频默认 16:9（可改）。图像默认 libimage 模型、2K 分辨率、标准画质（用户可改）；🔴 **moodboard 例外：强制 Midjourney v7**（见流程第 1 步，画幅经 --ar 参数表达）。视频默认 720p 分辨率（用户可改）。

## 图像 prompt 语言
主体中文；技术词（lens flare/god rays/bloom/cel shading）必要时留英文。负面词与正文物理分离、放独立负面字段。

## 人物铁律
- **锁质感、放身份**：新海诚剧场版赛璐璐动画质感是硬约束；发色/发型/服装/身份气质尊重用户设定、不做新海诚化纠偏。
- **表演基调跨镜一致**：每个有戏角色在剧本阶段定 2-3 个性格化标志性小动作/习惯姿态（见「剧本制作」章节），全片跨镜一致；模卡只锁外形、表演基调由剧本管、视频 prompt 取用。
- **脸是干净通透的动画脸**：赛璐璐柔和明暗、描线干净、肤色透亮偏暖粉；**眼睛是灵魂**——大而清澈、瞳孔层次丰富、必带高光点与环境光倒影（天空/夕阳的颜色映在眼里）。绝不做成真人写实脸、3D 渲染脸、厚涂油画脸。
- **模卡 ≠ 出片**：模卡用纯白底 + 明亮均匀正面光（脸充分照亮、面部细节优先），**模卡阶段绝不用逆光/剪影/炫光**——逆光开花是出片签名、不是定妆需求，模卡要的是把脸看清楚锁死。版式 16:9：左三视图（正/侧/背）+ 右大面部特写（必出、不可省、不可画成全身）。
- 🔴 **模卡模板（照填，禁改结构与质感尾词，只换 [] 占位；若版式散架/视图不全退回英文版）**：
```
纯白无缝背景动画角色三视图定妆图，16:9 横向排版，严格分为必须同时存在的两个区域。左区：同一角色正面/侧面/背面三个全身视图并排站立，高度一致、脚部对齐。右区（必须存在、不可省略）：同一角色的大幅面部特写占据右区大部分，清晰呈现脸部与上胸，用于锁定脸型、眼神、发色与瞳色——右区特写与左区三视图同等重要、必须渲染出来。新海诚剧场版动画质感，应用于[角色身份与气质]，明亮柔和均匀的正面光充分照亮面部、五官描线清晰干净，赛璐璐柔和明暗、肤色透亮健康（不灰不暗、不3D塑料、不真人写实），眼睛大而清澈、瞳孔层次丰富带高光点，[体态]，[发型与发色]，[服装]，[神态与眼神]，不持有任何道具书包饰品（仅人物本身，道具单独出道具图），自然放松中性站姿，色彩干净通透以[主色调1]和[主色调2]为基调（饱和明快不寡淡不脏），剧场版级别高精度作画、线条干净稳定，明亮均匀的白底定妆风格，高细节动画面部，清晰五官，所有视图与特写保持同一角色一致性
```
  负面(独立框)：`真人实拍、写实照片脸、3D渲染塑料感、厚涂油画、逆光、剪影、lens flare、bloom过曝、戏剧化打光、灰暗低饱和、脏旧做旧、线条崩坏、五官畸变、背包书包手持物饰品道具、面部不一致、换了另一个人、多个不同角色、两张分开的角色卡、右区出现全身像、缺少面部特写、复杂背景、水印`
- 🔴 **人物图不带任何道具**：模卡只出人物本身（身形/服装/发型/脸），绝不背包/拿手机伞书本/戴非必需饰品——道具一律由道具合图统一管、后续镜头再引用（防人物图自带道具与道具图冲突）。贴身服装不算道具；负面加"背包、书包、手持物、饰品、道具"。
- **儿童安全**：禁"未成年年龄数字+身体围度词+暴露服装"三连，改学龄气质词。新海诚作品多为中学生/高中生主角，尤须严守此条；校服等设定用"学生气质、校园制服"类中性描述。

## 场景卡（按场景取用；风格已由 sref→moodboard 锚死，卡只供取材要素——天气/场景/构图/光线四类，落 prompt 时组合即可）
- ☁️ **天空/云海**：积雨云堆叠如山/星空银河/彗星飞机云；逆光云缘金边；广角、天空占画幅一半以上、人物渺小于地平线。用户一提天空/云/彗星/星空无条件套此卡。
- 🌆 **Magic hour 黄昏（招牌）**：日落前后、云被夕阳点燃；暖金逆光、lens flare、长影拖地、玻璃反射夕阳；人物浸在逆光里、轮廓金边全开。
- 🏙️ **都市/电车/铁道口**：电线杆与电线、电车车窗流光、铁道口红灯、便利店与贩卖机灯光；背景细节密度拉满；人物穿行或等待于大场景中。
- 🌧️ **雨/雨后**：雨滴可见、水洼涟漪、伞与玻璃挂水；路面反光、车灯拉丝；雨后云破光出、湿街满是反光。
- 🏫 **校园/日常抒情**：教室窗边、走廊天台、樱花或夏日绿；窗光斜切、灰尘在窗光里漂浮、窗帘被风掀起。
- 🌌 **夜/星空**：星空银河与城市灯火对望；月光、流星、灯火 bloom；人物于天台/山坡/桥上仰望、深远景深。

## 运镜（每镜配一种，与情绪咬合，默认动感冲击）
快速冲刺跟拍（贴身追奔跑）/ 急推急拉（推向眼睛或拉出天地）/ 环绕人物旋转 / 低空俯冲穿越场景（FPV 式掠过街道/云层/铁轨）/ 甩镜 whip pan 衔接动作 / 大幅快速横摇扫过天空与城市 / 升降机大幅升起展现天地尺度 / 镜头随冲击轻微震动（落地/撞开门/列车掠过）。⚙️ 动感运镜全段可用、不限高潮段；缓慢推近与固定大远景保留为凝望时刻的点缀（一条 15 秒内至多 1-2 镜），其余镜头必须动起来。新海诚的镜头是"和世界一起奔跑的抒情诗"，宁涌勿静。

## 剪辑节奏（抒情起伏、切点走动作衔接）
- 🔴 **镜数目标：15 秒目标 5-6 个分镜**（单镜约 2-3 秒），情绪起伏靠镜内运镜与动作密度体现、而非拉长单镜——凝望段用长一点的镜（3 秒档）、高潮段用短镜（2 秒档），但总镜数守住 5-6。
- 🔴 **切点逻辑：动作衔接（match cut）**：每个硬切点必须咬合前后镜头的动作——上一镜动作到达顶点或转折处切出，下一镜从该动作的延续或呼应动作起头（如：仰头看天的视线方向→切天空俯瞰；手伸向门把→切门被推开；奔跑脚踏地→切远景人飞奔）。**切点由动作决定，不是时间到了就切**。
- 空镜是正文不是过场：天空、云、电车、街角的空镜承担情绪，可独立成镜、与人物镜头以动作/视线衔接交切。
- 景别可大幅跳跃：大远景（人渺小于天地）直切眼睛特写是新海诚常用语法，不受"跳一档"限制，但跳跃须由动作衔接驱动、不乱跳。
- 每镜内动作完整发生、切在动作节点上，不无意义碎切。

## 音乐（默认 mureka；可含人声主题曲段）
- 气质：抒情、汹涌、有明确的情绪推进与高潮释放——音乐与画面互为引擎（RADWIMPS 式影乐一体），在高潮处音乐可以冲到情感最前面。
- 🎹 **第一支·钢琴抒情主线**（钢琴主导+弦乐推进）三子支：
  - A·日常与心动：明亮轻快的钢琴动机、弦乐轻托，青春的透明感。用于校园/日常/相遇。
  - B·思念与距离：钢琴慢板、旋律绵长带憾意、弦乐渐入，留白后再起。用于分隔两地/凝望天空/回忆。
  - C·奔跑与追寻（高潮）：钢琴+弦乐+节奏组层层推进、情绪逐步拉满至爆发，配快剪蒙太奇。用于奔跑/寻找/时空交错/告白。
- 🌠 **第二支·壮阔天象**：弦乐与合成器铺底的宏大织体、带神圣感与命运感,缓慢推进至恢弘。用于彗星/星空/超自然天象/世界级景观。
- 🎤 **第三支·主题曲人声段（唯一允许人声）**：流行摇滚编曲+人声旋律，用于全片情绪最高点或片尾——仅在用户确认后启用（以选择卡询问：启用/不启用），默认前两支纯器乐。⚠️ 配乐人声属音乐层，与剧本"人声模式"互不约束——纯氛围模式的片子也可用主题曲人声段。
- **选支**：校园日常相遇→A；思念凝望回忆→B；奔跑追寻高潮→C；天象奇观→第二支；全片最高点/片尾→询问用户是否上第三支。同一片多支并存随段落切换、须有"起-承-爆-落"的整体情绪曲线。
- 禁平淡氛围底噪式配乐贯穿全片、禁全程无起伏。新海诚的音乐必须"推着情绪走",高潮必须给到。

## 生成后自查（不达标则重做）
剧本：人声模式遵守否（纯氛围无台词旁白/含对话旁白处有实际文本、非默片化）？对白标注说话人否？每个有戏角色的表演基调表产出否？
moodboard：prompt 尾部固定尾缀（--niji 7 --sref 3581618356 --sv 4）在否？正文是否混入色调/影调/质感风格词（须删净）？模型是否为 Midjourney v7？
场景图：是否挂了 moodboard 风格锚？轻量风格尾词与负面在否？正文是否只含天气/场景/构图/光线氛围四类、色彩影调类风格词删净否？模型是否为 libimage？
其余图像与视频：光是否是主角——逆光/lens flare/bloom 至少占其一（须有）？是否做成了真人实拍或3D塑料感（禁，须剧场版动画）？背景是否达到写实级精细密度、天空占比够否？视频 prompt 的音频锁声明与 BGM 负面词两处齐否（缺一即重写）？

## 视频铁律
- 🔴 **单条多分镜（默认强制）**：seedance 单次最长 15 秒、原生支持单条内多分镜+镜间硬切，**不走"一镜一条+后期拼接"**。🔴 **镜数目标：15 秒 5-6 镜、单镜约 2-3 秒**（凝望段可到 3 秒档、高潮段 2 秒档，总镜数守住 5-6）；不足 15 秒的短条按同密度折算（8 秒约 3 镜/10-12 秒约 4-5 镜）。**只有跨 15 秒才拆多条、串行后用视频合成能力拼接**。prompt 按秒推进、每镜=景别+@角色动作+运镜+环境+**与下一镜的动作衔接切点**，镜间硬切显式断开。
- 🔴 **绝对禁止生成背景音乐（铁律，无例外）**：视频生成阶段音频**只允许环境音+对白**，任何形式的背景音乐、配乐、旋律、哼唱、鼓点节拍一律禁止——即使镜头情绪强烈、即使画面出现乐器或耳机、即使模型倾向自动配乐，也绝不允许。BGM 只在第 8 步合成阶段叠加。新海诚的环境音（雨声/电车驶过/蝉鸣/风/城市底噪/铁道口警示音）极重要，每条视频 prompt **常驻声明（不管本条有无对白都写、一字不省）**："音频只保留丰富真实的环境音与对白，绝对无背景音乐、无配乐、无旋律、无哼唱、无节拍鼓点"；负面**常驻**："背景音乐、配乐、BGM、旋律、哼唱、节拍鼓点、music、background music、score、soundtrack、melody、humming"。出 prompt 后自查：声明与负面两处都在否（缺一即重写）。
- 🔴 **语言锁+人声模式锁**：每条视频 prompt 常驻声明"人物对白/旁白一律 [选定语言]，模型自主补话也只用此语言，禁其他语种台词/字幕/口型"（不管本镜有无对白都写）；负面加"其他语种台词、混合语言口型"。防无对白镜头被模型自主加话时蹦错语种。同时按人声模式追加：纯氛围→常驻声明"全片无对白无旁白、人物不说话不开口型"、负面加"对白、旁白、说话口型"；纯旁白→常驻声明"人物不开口型"（旁白为画外音、合成阶段处理）；纯对话/穿插→对白台词按剧本写进对应分镜。
- **人物一致性靠参考图 + 动作要有爆发力**：人物质感与风格由挂载的角色图/场景图参考传递，prompt 正文不写风格词；正文约束动作与稳定性——**动作幅度拉满**：全速奔跑冲刺、跳跃跨越、急停急转身、攀爬翻越、俯身冲出门框，发丝与衣摆大幅甩动飘扬、脚步带起水花或落叶尘土，静态镜头里人物也要有明确的动作进行时（转头/伸手/起身），面部不崩坏。负面常驻：真人化、3D化、线条崩坏、五官畸变、僵硬摆拍、原地不动呆立。
- **禁溶解叠化**：镜间硬切，负面常驻 no dissolve/cross-fade/fade。
- **光影必须在场**：视频里每镜都要有明确光源与光效（逆光/反光/灯火），绝不平光。快速运镜与光影快速变化（光斑扫过脸、明暗穿越、车窗流光拉丝）全段可用、鼓励使用。负面常驻：平光无光影、真人实拍质感。
