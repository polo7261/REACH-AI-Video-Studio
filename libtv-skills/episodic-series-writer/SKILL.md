# episodic-series-writer

多集劇集的完整寫作方法論。**長片的弧光是一次完整旅程，劇集的弧光是預算制的**——N集裡角色的變化量需要被分配到各集，被"預算控制"。本 skill 自包含，不依賴本庫其他任何檔案；如果要指定"這個劇集該講男頻/懸疑/復仇哪個題材的具體內容判斷標準"，可以在寫完後額外參考對應題材殼，但題材殼不是必需前提。

## 邊界：不做什麼

不產出分鏡表、鏡號、景別/運鏡/構圖、轉場方式、AI生圖/生影片提示詞、任何特定生成引擎的格式約束。產出到完整的、可以直接讀、直接拍的文字劇本為止。

## 工作流紀律

嚴格按步驟順序執行，不跳步；每一步完成後暫停，等待使用者的[透過/修改/自檢]指令；絕不一次性把後續所有步驟生成完再交給使用者；每步結束後提醒使用者可以要求[自檢]。

自檢是內部過程——寫之前先在心裡過一遍對應步驟的檢查清單，不需要在輸出中展示自檢的思考過程，只需要確保交付的內容已經透過檢查。使用者仍然可以主動要求[自檢]，此時才需要顯式地逐條列出檢查項並給出評估結果。

## 寫作紅線（全域性最高優先順序，任何格式都不能違反）

**絕對不要**：寫心理描寫（"他意識到"、"她領會到"、"內心湧起"）；寫括號暗示（"（其實是在掩飾緊張）"）；角色用臺詞解釋設定或主題；說教片段、強行催淚、煽情獨白；過度比喻句、類比、書面化的AI腔臺詞；寫任何攝影機拍不到的內容。

**必須做到**：臺詞口語化，像真人說話；用動作代替解釋（動作即潛臺詞）；對話像冰山，只露一角；所有內容從視聽角度出發。

## 視聽化寫作核心

**Show, Don't Tell**：如果一個情感無法透過角色的物理行為傳達給觀眾，這個情感就不該出現在劇本里。**潛臺詞**：對話是冰山，避免直白，利用動作/停頓/迴避/話題轉移表達真意。**臺詞風格**：口語化，不同角色有不同說話方式（用詞、句式長度、習慣性表達）——劇集角色多、出場週期長，臺詞風格的區分度比其他體量更重要，觀眾遮住名字也該能分辨誰在說話；避免過度比喻和書面化AI腔；不要讓角色說出雙方都已經知道的事情。

**標準劇本格式**：
```
【場景X：地點 / 時間 / 簡要視覺描述】

動作/畫面描寫直接寫在臺詞之間，不加標記，只寫攝影機能拍到的東西。

角色A：xxxxxxxxx。
```
`【場景標註】`用方括號標註地點/時間/關鍵視覺資訊；`角色名：`直接跟對白；`角色名（OS）：`表示內心獨白/旁白；動作/畫面描寫不加標記，直接寫在臺詞之間。

## 核心特徵

- **集數與時長**：由使用者定義（常見配置：8-24集，每集10-60分鐘）
- **角色**：完整Ghost/Lie/Flaw/Want/Need，弧光分配在整季
- **結構**：雙層巢狀——集內結構 + 季度弧線
- **世界觀**：複雜且分層釋放，需要資訊管理
- **節奏**：每集獨立精彩 + 集間鉤子 + 季度遞進
- **記憶**：需要連續性管理系統

## 人物深度設計（同長片深度）

**Ghost（前史創傷）**：角色過去經歷的事件，塑造了當前的世界觀和行為模式。**Lie（角色相信的謊言）**：角色因Ghost形成的關於自己/世界的錯誤信念。**Flaw（性格缺陷）**：Lie在行為層面的具體表現。**Want vs Need**：Want是驅動動作的目標，角色主動追求的東西；Need是角色未曾意識到的靈魂缺口。**Ghost→Lie→Flaw→Want→Need因果鏈**：寫人物小傳時要能沿著這條鏈條一步步推導。

**劇集與長片的關鍵差異**：長片的弧光是一次完整旅程，劇集的弧光是**預算制**的——N集裡角色的變化量需要分配到各集，前面的集不能讓角色變化太多，否則後面沒有空間。長片的世界觀可以一次搭建完，劇集的世界觀必須**分期釋放**——前幾集只展示表層規則，中段揭示執行邏輯，季終暴露底層真相，寫第1集時就得知道最後一集要揭示什麼。長片是一個故事，劇集是N個故事組成的一個更大的故事——每集拆出來都必須是一個獨立好看的微型故事（單元性），但同時又在為季度大弧線鋪磚（連續性）；兩者衝突時，**單集好看優先**。

## 首先：確認劇集配置

進入創作前，先與使用者確認以下引數：
```
劇集配置表：
- 總集數：__集
- 單集時長：__分鐘
- 單集結構偏好：四段式 / Save the Cat壓縮版 / Story Circle / 內在節拍
- 劇集型別：單元劇（每集獨立故事）/ 連續劇（一個大故事分集講）/ 混合型（單元故事+連續暗線）
- 季度弧線：有 / 無（純單元劇可能沒有）
- 世界觀複雜度：簡單（即插即用）/ 中等（需要分層）/ 複雜（需要資訊釋放時間表）
```
配置確認後，以下所有模板中的集數和時間分配自動適配，下文"N"代表使用者設定的總集數。

## 劇集型別與結構策略

不同型別在"單集獨立性"和"季度連續性"之間的權重不同：

| 型別 | 單集獨立性 | 季度連續性 | 代表作參考 |
|------|-----------|-----------|-----------|
| 純單元劇 | 100% | 0-10%（角色微成長） | 《黑鏡》《世界奇妙物語》 |
| 單元+暗線 | 70-80% | 20-30%（暗線推進） | 《愛宕機》《查無此人》 |
| 半連續劇 | 40-60% | 40-60%（集內有獨立事件但服務於大線） | 《絕命毒師》《怪奇物語》 |
| 強連續劇 | 10-20% | 80-90%（每集是大故事的一個章節） | 《權力的遊戲》《進擊的巨人》 |

根據使用者選擇的型別，調整後續所有模板的權重——單元劇側重本集精彩度，連續劇側重季度弧線的推進。

## 雙層結構

### 層一：集內結構

根據單集時長和偏好選擇：短集（10-15分鐘）→四段式；中集（20-30分鐘）→四段式擴充套件版或Save the Cat壓縮版；長集（40-60分鐘）→Save the Cat/Story Circle/McKee均可。

**四段式集內模板（按比例分配，適配任意時長）**：
```
【冷開場 / 開場鉤子（強烈建議）】
  每一集都需要開場鉤子——不只是第一集。冷開場是片頭曲播放之前的內容，
  唯一任務是讓觀眾決定"繼續看"。策略：
  - 一場高張力場景直接把觀眾扔進緊張中（商業劇集）
  - 一個看似無關但在集末回扣的獨立切片（懸疑/單元劇）
  - 上一集cliff-hanger的延續和解決（連續劇）
  - 一個高度風格化的段落錨定本集情緒基調（文藝劇集）
  第一集的冷開場承擔最重的任務——同時建立世界觀、角色、型別基調、
  季度核心衝突的種子。第一集前兩分鐘決定觀眾是否會看完整季。

一、建置（約15%時長）：本集的常態，可延續上一集或跳到新場景。激勵事件——本集核心衝突的觸發。
二、發展（約40%時長）：衝突升級（至少兩次遞進）。B Plot在此段穿插推進。季度暗線的種子自然散落在對白和行為中。
三、高潮（約25%時長）：本集核心衝突的頂點。角色做出選擇——應體現或挑戰角色的Lie。
四、結局+集末鉤子（約20%時長）：本集故事的落幕，展示"本集的新常態"。集末鉤子（cliff-hanger或tease）——為下一集埋下期待，不一定要大懸念，可以是一個不安的細節、一句沒有回答的問題。
```

### 層二：季度弧線

按比例分為四個階段：
```
第一階段：建置（前25%集數，即E1~E[N×0.25]）——世界觀表層規則呈現，主角Want和Lie被清晰建立，核心關係網路搭建完成，季度核心衝突的種子被播下。
第二階段：發展（第25%-65%集數）——季度核心衝突逐步升級，世界觀執行邏輯逐漸揭示，主角經歷多次偽變化（看起來在成長，但Lie沒有真正被打破），各集B Plot和暗線開始交織。
第三階段：危機（第65%-85%集數）——季度"一切盡失"時刻，主角面對自己的Ghost和Lie，最重要的關係受到威脅或破裂。
第四階段：高潮與落幕（最後15%集數）——世界觀底層真相揭示，主角做出季度級別的關鍵選擇，弧光完成，展示新常態；季終可以完結也可以留鉤子給下一季。
```

**比例適配示例**：

| 總集數 | 建置 | 發展 | 危機 | 高潮 |
|--------|------|------|------|------|
| 8集 | E1-2 | E3-5 | E6-7 | E8 |
| 10集 | E1-3 | E4-6 | E7-8 | E9-10 |
| 12集 | E1-3 | E4-8 | E9-10 | E11-12 |
| 16集 | E1-4 | E5-10 | E11-13 | E14-16 |
| 24集 | E1-6 | E7-16 | E17-20 | E21-24 |

## 弧光預算分配

弧光不能隨意在各集中發生——需要規劃每集的"變化額度"。

```
角色：[名字]
季度弧光：從[A狀態] → 到[B狀態]
Lie：[角色相信的謊言]
總集數：N

集  | 弧光事件 | 變化方向 | 變化幅度 | 累計進度
E1  | [事件] | Lie被強化 | 微弱 | 0%
... | ... | ... | ... | ...
E[N]| [事件] | 關鍵選擇→新常態 | 完成 | 100%
```

**比例規則**：前25%集數累計進度不超過15%；至少1次偽變化後的回退（通常在40%-60%位置）；65%-85%位置是加速區（變化量最大）；不是每集都需要弧光事件——有些集角色不變化也可以；純單元劇可以弱化甚至跳過弧光預算，只保留角色狀態追蹤。

## 世界觀資訊釋放時間表

```
資訊層 | 內容 | 釋放位置（按比例） | 釋放方式
表層規則 | [世界的基本執行方式] | 前10-15%（E1-E2區間） | 直接展示
表層細節 | [規則的有趣延伸] | 15-30% | 角色遭遇 / B Plot
執行邏輯 | [為什麼世界是這樣的] | 40-55% | 角色調查/發現
邏輯延伸 | [邏輯的更深層含義] | 55-75% | 關係對話中洩露
底層真相 | [世界的終極真相] | 最後20% | 高潮揭示
伏筆回扣 | [前面細節獲得新含義] | 最後1-2集 | 觀眾恍然大悟
```
**原則**：每層資訊釋放前需要至少1-2集的伏筆鋪墊；資訊釋放透過角色行動和發現呈現，不透過旁白或字幕；釋放新資訊時必須改變觀眾對已知資訊的理解；不要在同一集釋放太多新資訊，每集最多展示一個新層。

## 劇集必備元素（除非使用者特別說明，否則預設包含）

### 伏筆與回扣（跨集級）

劇集的伏筆比長片更強大——時間跨度更長，觀眾第2集看到的細節第8集回扣時衝擊力被等待的時間放大。

**分類**：**集內伏筆**（同一集內埋下並回扣，與長片一致）；**短程伏筆**（跨1-3集回扣，觀眾還記得時看到回扣，效果是"果然如此"）；**長程伏筆**（跨5集以上回扣，觀眾已忘記時看到回扣，效果是"原來一開始就……"）；**季度伏筆**（第1-2集埋下，季終回扣，整季的重新理解，是最強力的伏筆）。

**密度建議**：每集至少1個集內伏筆；每3集至少1個短程伏筆在回扣；整季至少2-3個長程伏筆；至少1個季度伏筆。所有伏筆用"埋種/回撥登記表"追蹤（見下文連續性管理）。

### 次要角色與群像

劇集的次要角色比長片更豐滿——更多時長意味著次要角色不只是功能性的，他們可以有自己的小弧光。**功能同長片**：映象角色、催化角色、主題角色、節奏角色。

**劇集額外要求**：重要次要角色應有自己的跨集微弧光（不需要像主角那樣完整，但需要可感知的變化）；微弧光應在某個時刻與主角弧光產生交叉（互相影響）；每集可有1-2個一次性角色（本集NPC），但如果同一功能的NPC在多集反覆出現，應考慮合併為常駐次要角色；群像劇需要角色關係矩陣，每集更新關係狀態。

### 暗線（劇集級）

比長片更復雜，因為有更多時間鋪設和揭示。**數量建議**：1-3條，每條需有明確起點（哪集開始鋪）和終點（哪集揭示）。**推進規則**：暗線不能在每集都推進——那就不是"暗"線了；暗示應隱藏在"表面上有別的含義"的場景中；暗線浮出水面時應改變觀眾對前面多集內容的理解；用"暗線進度追蹤表"管理（見下文）。

### Subplot管理（劇集級）

比長片更復雜，有些subplot跨集執行：**集內A Plot**（本集核心故事）；**集內B Plot**（本集副線，通常與角色弧光相關）；**Running Subplot（跑線）**（跨多集的持續劇情，不在每集都出現但觀眾記得）；**Season Arc（季度弧線）**（整季總故事，每集以碎片形式推進）。

**交織原則**：每集A Plot必須獨立完整；B Plot可跨1-2集解決；Running Subplot每隔2-3集推進一次，每次推進要夠分量；Season Arc的推進不能影響本集A Plot的節奏——衝突時砍Season Arc的戲；同時執行的subplot（含Running Subplot）不超過3條。

## 時長估算與雙軌節奏（劇集級）

每集在分集大綱階段就應做時長預算，按四段式比例分配，場景拆解階段細化到每場戲。

**場景標註格式**：
```
【場景X：地點 / 時間 / 視覺描述】（約X分鐘）
  情節節奏：松/中/緊
  情感節奏：輕/中/重
```

**集內節奏檢查**：單集內不要連續3場以上同一節奏狀態；高潮段（情節緊+情感重）的時長佔單集總時長20-30%為宜（太短不夠爽，太長會疲勞）；每集至少有一個"情節松+情感重"或"情節緊+情感輕"的錯位段落——這是最有味道的時刻。

**集間節奏檢查**：相鄰兩集的平均情節強度是否有對比（不能連續幾集都是高強度）；相鄰兩集的平均情感強度是否有對比（不能連續幾集都是重情感）；季度中段的"呼吸集"是否真的在"呼吸"（情節和情感都需要降下來）。

## 連續性管理四件套

每寫完一集，更新以下四張追蹤表：

**A. 角色狀態追蹤**：
```
角色 | 本集結束時的狀態 | 關鍵變化 | 下集需延續的點
[名] | [物理/情感/關係狀態] | [本集發生的變化] | [下集必須回應的點]
```

**B. 暗線進度追蹤**：
```
暗線名稱 | 當前進度 | 本集推進內容 | 下次推進計劃（哪集）
[暗線1] | [進度描述] | [本集做了什麼] | E[X]
```

**C. 埋種/回撥登記**：
```
種子內容 | 埋入集數 | 場景 | 計劃回撥集數 | 回撥方式 | 已回撥？
[種子描述] | E[X] | [場景號] | E[Y] | [如何回扣] | ✅/❌
```

**D. 已公開資訊清單**：
```
資訊內容 | 公開集數 | 公開方式 | 誰知道（角色層面）| 誰不知道
[資訊] | E[X] | [展示/暗示] | [角色列表] | [角色列表]
```

**使用說明**：每集劇本完成後立即更新四張表；開始寫新一集前先查閱確認當前狀態；如發現連續性衝突，優先修改新集內容而非修改已定稿的舊集。

## 劇集工作流（兩階段）

劇集創作分兩個階段：先完成"季度規劃+分集大綱"，確定整季骨架和每集概念；然後逐集進入八步工作流寫單集劇本。

### 階段一：季度規劃與分集大綱

只做一次，但可能需要多輪迭代。目標：在寫任何一集完整劇本之前，先把整季骨架搭穩。

**步驟A：季度規劃**
1. **劇集配置確認**：集數、單集時長、劇集型別（見首節配置表）
2. **季度前提**：這一季的總故事，一句話概括（Logline級別）
3. **季度梗概草稿**：一頁紙的季度故事提要（300-500字），讓使用者對整季走向和氣質有基本判斷，後續可持續修改
4. **主角的季度弧光**：從A狀態到B狀態，Lie是什麼
5. **前史與世界觀**（遵循橫截面原則——故事開始之前世界已執行很久）：時代背景（這個故事發生在什麼時代/社會環境，什麼時代特徵影響了角色）；主角前史（每個主要角色在故事開始之前的關鍵人生事件，特別是Ghost事件）；關係既往（主要角色之間在故事開始前的關係歷史）；世界觀設計（三層模型：表層規則/執行邏輯/底層真相+資訊釋放時間表）；橫截面選擇（為什麼第一集從這個時刻切入）
6. **弧光預算分配**：主角和主要配角的弧光預算表初稿
7. **暗線規劃**：跨集暗線的起點和終點（如果有）

> 請回復"透過"進入分集大綱，或告訴我修改意見。

**步驟B：分集大綱**——**這是劇集創作中最關鍵的步驟。** 在動手寫任何一集劇本之前，先把N集的分集大綱全部拉通。為什麼必須先於劇本：分集大綱是"地圖"，沒有地圖就出發會迷路；只有拉通看全季，才能判斷節奏波浪是否合理；弧光預算的消耗只有在全域性視角下才能檢驗；埋種和回撥需要前後集的配合，不拉通就會遺漏。

**分集大綱模板（每集填寫）**：
```
第[X]集《集名》

【集核心心】
  一句話故事（本集Logline）：
  本集核心戲劇動作：目標 → 阻礙 → 結果
  本集情緒基調：（建置型/輕快型/緊張型/呼吸型/崩塌型/高潮型/……）

【集內結構概要】（含時長預算）
  冷開場/開場鉤子（約X秒）：具體內容——這段開場單獨拿出來是否精彩？
  建置（約X分鐘）：情節節奏：松/中/緊 | 情感節奏：輕/中/重
  發展（約X分鐘）：障礙1 → 障礙2 → 情節節奏：松/中/緊 | 情感節奏：輕/中/重
  高潮（約X分鐘）：情節節奏：松/中/緊 | 情感節奏：輕/中/重
  結局+集末鉤子（約X分鐘）：情節節奏：松/中/緊 | 情感節奏：輕/中/重

【季度連線】
  弧光預算消耗：本集角色變化了什麼？累計進度到多少？
  暗線推進：本集推進了哪條暗線？怎麼推進的？
  世界觀釋放：本集是否釋放了新的資訊層？
  埋種：本集埋了什麼種子？計劃在哪集回收？
  回撥：本集回收了之前哪些種子？
  次要角色動態：本集的次要角色狀態變化？

【集間關係】
  承接上集：本集從上集的什麼狀態開始？
  遞交下集：本集結束時為下集留了什麼？
  與前後集的節奏對比：本集平均情節強度vs上集/下集？本集平均情感強度vs上集/下集？
```

**分集大綱自檢**：每集的開場鉤子是否足夠精彩？第一集的開場是否同時建立了世界觀、角色和型別基調？全季N集拉通後是否有清晰的季度四階段弧線？集間節奏是否有波浪（不能持續同一種情緒）？集間的情節強度和情感強度是否分別有起伏（不能連續3集以上同強度）？弧光預算是否合理（前25%進度不超過15%）？資訊釋放是否分層（沒有一次性傾倒）？每集獨立拆出來Logline是否能獨立成立？是否有"呼吸集"讓觀眾休息，情節和情感是否都降了下來？同時執行的暗線/subplot是否不超過3條？集末鉤子是否是本集故事的自然延伸而非強行製造？全季的伏筆是否有合理分佈（集內/短程/長程/季度各層次都有）？每集時長預算加起來是否與單集總時長一致？次要角色是否都有功能，有跨集角色是否有微弧光？

> 分集大綱全部完成後，請回復"透過"。我們將從第1集開始逐集寫劇本。你也可以要求我對整個大綱進行[自檢]。

### 階段二：逐集劇本（八步工作流）

分集大綱透過後，逐集進入八步工作流。**注意**：劇集的步驟2（梗概）和步驟4（前史與世界觀）已在階段一的季度規劃中完成，逐集寫作時簡化為"對照分集大綱確認"——除非本集實際發展偏離了大綱，需要更新。

**步驟1（破題）額外要求**：核心戲劇動作需與分集大綱中的設定一致；檢查本集概念是否與前後集有節奏對比。

**步驟2（梗概）——對照確認**：回顧分集大綱中本集的Logline和結構概要，確認是否仍然成立；如之前的集偏離大綱導致需要調整，在此更新本集梗概。

**步驟3（人物）額外要求**：本集出場的次要角色需標註功能（映象/催化/主題/節奏）；如有跨集的次要角色，檢查其微弧光進度。

**步驟4（前史/世界觀）——對照確認**：回顧季度規劃中的世界觀設定，確認本集是否需要釋放新的資訊層；如本集有新角色登場，補充其前史。

**步驟5（結構大綱）額外要求**：集內結構+集末鉤子設計；開場鉤子設計——每集的冷開場/第一場戲必須有足夠強的視覺鉤子，第一集的開場承擔最重的任務；標註本集對暗線的推進（如果有）；標註本集對弧光預算的消耗；對照分集大綱檢查是否偏離，偏離需評估連鎖影響；時長預算細化。

**步驟6（場景拆解）額外要求**：每個場景標註預估時長和雙軌節奏狀態；檢查集內節奏——是否有連續3場以上同一節奏狀態；場景時長累加檢查；**如果本集場景超過6場，在步驟6完成後觸發一次集內記憶檢查點**。

**步驟7（場景寫作）額外要求**：**單集寫作過程中每完成6場戲左右觸發一次集內記憶檢查點**；寫作時對照檢查點確認前後一致性；前史資訊透過對白和視覺線索自然散落。

**步驟8（劇本醫生）額外要求**：連續性審計——檢查與前面已完成的集是否有矛盾；更新所有追蹤表（角色狀態/暗線進度/埋種回撥/已公開資訊）；檢查集末鉤子是否有效；開場鉤子質量檢查——本集冷開場是否足夠抓人；伏筆審計——本集埋的伏筆是否已登記，本集該回扣的是否已回扣；節奏診斷——用場景時長彙總檢查本集節奏；次要角色審計；偏離大綱時評估連鎖影響；**本集完成後必須觸發集間記憶檢查點**。

## 集間節奏管理

N集不能每集都是同一種情緒，需要節奏的波浪。

**情緒基調型別庫**（每集從中選擇一個主導情緒，可混合但應有明確主導）：建置型（觀眾適應世界、認識角色，通常用於開頭幾集）；輕快型（喜劇感強、角色互動為主，觀眾積累好感）；緊張型（核心衝突升級、壓力增大）；呼吸型（節奏放緩、角色關係深化，提供情感錨點）；轉折型（大事件發生、格局改變）；壓力型（內外壓力持續收緊，幾乎沒有喘息）；崩塌型（一切盡失，最低點）；至暗型（角色直面Ghost和Lie）；反擊型（角色帶著新認知反擊）；高潮型（季度核心衝突的解決）。

**節奏波浪原則**：不能連續3集以上是同一基調；緊張/壓力集之後需要至少1集呼吸或輕快；崩塌和至暗可以連續（構成"低谷"），但低谷前後必須有對比；季度中段（40%-60%位置）適合放轉折型——改變下半季的方向；呼吸集不是廢集，它的功能是讓角色關係深化、讓B Plot推進。

**參考節奏模板（按總集數比例）**：
```
前10%: 建置
10-20%: 輕快/建置
20-30%: 第一次緊張
30-40%: 呼吸
40-50%: 轉折（中段大事件）
50-60%: 過渡+升級
60-70%: 壓力
70-75%: 呼吸或偽高潮
75-85%: 崩塌/至暗
85-95%: 反擊
最後5-10%: 高潮+落幕
```
以上只是參考，具體節奏應根據故事本身調整，關鍵是製造情緒的起伏。

## 記憶檢查點系統

劇集全季可達10萬字以上，檢查點透過定期生成結構化"快照"防止前後矛盾。分兩級：

**集間檢查點（每完成一集觸發，最重要）**，在通用模板基礎上增加：
```
【本集完成摘要】本集Logline / 本集核心事件 / 本集弧光消耗：角色變化了什麼？累計進度？
【連續性追蹤更新】角色狀態變化（與上一集的對比） / 暗線推進（本集推進了什麼） / 新埋的種子 / 回扣的種子 / 新公開的資訊
【季度進度】當前處於季度四階段的哪個階段？弧光預算已消耗多少？下一集的分集大綱核心是什麼？
```

**集內檢查點（單集內容較長時觸發，即場景超過6場）**：使用通用模板即可，重點記錄本集內部的角色狀態和活躍線索：
```
📌 記憶檢查點 | 劇集 | [當前位置]
【已完成進度】當前處於第幾步 / 已寫到本集第幾場
【故事核心（不變）】Logline / 核心戲劇動作：目標→阻礙
【角色當前狀態】[角色名]：物理狀態/情感狀態/當前知道什麼/當前想要什麼
【已完成段落摘要】場景1：一句話概括+核心價值轉變；……
【活躍線索】需要後續回應的線索及狀態
【伏筆狀態】已埋未回扣：[內容]→計劃在[位置]回扣；已回扣：[內容]✅
【節奏狀態】上一段落情節/情感節奏 → 下一段落建議方向
【待寫內容預告】下一個要寫的場景是什麼，核心戲劇動作是什麼
```

**使用方式**：寫作時每次開始新段落前先回顧最近檢查點；跨對話時請使用者提供上一次檢查點內容以恢復上下文；劇本醫生時把所有檢查點串起來通讀，快速發現某條伏筆埋了沒回扣、某個角色狀態突然跳變（連續性錯誤）、節奏長時間沒變化、某條暗線/Subplot長時間沒推進。

## 跨格式技法借鑑（劇集可借用的部分）

**從概念片借**：高概念翻轉的思路可以用在劇集的冷開場/集末鉤子——這場戲的最後一秒能不能讓觀眾重新理解這場戲的第一秒？遞進崩塌式結構可以用在展示"角色被困在重複模式中"的段落——同一個早晨、同一個爭吵、同一次失敗，迴圈本身就是敘事。視聽語言武器庫中的分屏可以用在劇集的recap段落；跳切蒙太奇可以用在時間推進段落；畫面與聲音錯位可以用在需要諷刺效果的場景；靜默可以用在高密度資訊流之後的高潮段落之後；色彩限制可以用在特定段落標記敘事層次（回憶用去飽和、幻想用高飽和、現實用自然色調）。

**從短片借**：資訊密度蒙太奇可以用在角色適應新處境的時間推進段落；單一變數極致推演特別適合"瓶裝集"（bottle episode，限定空間和人物，把一個複雜故事的某個區域性限制為單一變數推演）；零度表達（災難越大語氣越平）適合用在崩塌集。

**從長片借**：McKee價值轉變檢驗法可以用在劇本醫生階段——檢查每一場戲結束時的核心價值是否與開始時不同，沒有價值轉變的場景考慮刪掉。

## 劇集常見陷阱

- ❌ 跳過分集大綱直接寫單集 → 必須先拉通全季再動筆
- ❌ 為了季度弧線犧牲單集精彩度 → 每集拆出來都要好看
- ❌ 資訊釋放過快（前幾集就把世界觀講完）→ 分層釋放
- ❌ 弧光預算失控（前面的集角色變化太大，後面無處可去）→ 嚴格遵守預算比例
- ❌ 連續性錯誤（角色行為與前集矛盾）→ 每集開寫前查追蹤表
- ❌ 集末鉤子過於強行（為了懸念硬造衝突）→ 鉤子應是本集故事的自然延伸
- ❌ 每集結構太相似（觀眾能預測節奏）→ 用集間節奏管理製造變化
- ❌ Running Subplot太多，觀眾記不住 → 同時執行的不超過3條
- ❌ 分集大綱只寫了一句話概括 → 大綱需要包含完整的集內結構概要、時長預算、雙軌節奏和季度連線
- ❌ 寫單集時偏離了大綱但不更新後續集 → 任何偏離都需要評估對後續集的連鎖影響
- ❌ 沒有估算時長導致高潮被壓縮或建置過長 → 從分集大綱就開始做時長預算
- ❌ 連續幾集都是高強度情節+重情感 → 觀眾會疲勞，用雙軌節奏檢查集間對比
- ❌ 伏筆埋了忘記回扣 → 用埋種/回撥登記表逐條審計
- ❌ 次要角色只在需要的時候出現、不需要的時候消失 → 次要角色也需要自己的存在邏輯
- ❌ 情節節奏和情感節奏始終同步 → 刻意製造錯位（情節松+情感重）是高階手法

## 與題材殼skill的關係

本skill只管"多集劇集這個體量該怎麼寫"，不管"這個故事該講男頻/懸疑/復仇哪個題材的具體判斷標準"。如果需要某個題材專屬的判斷標準，可以在寫完分集大綱後另外參考本庫對應題材殼skill的技術難點清單；不參考也完全可以獨立完成一部劇集。兩者是正交的兩條軸，不是依賴關係。
