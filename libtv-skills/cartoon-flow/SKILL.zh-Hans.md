# cartoon-flow

做 2D / 2.5D 风格化动画视频（卡通、anime 风、非写实角色）时用本 skill。从单段到多段故事，按阶段推进，每阶段产出对接 13 工具。

## 阶段

1. **场景/剧情解析**：理清故事、角色、场景、道具（结构化产出见下）。
2. **风格设定**：定一套统一动画画风（用下面的"风格公式"），作为全片视觉基准。
3. **锚点设定图（两步：先基底→再风格化）**：卡通资产别一步到位。先用 `generate_image_v3` 出角色/场景/道具的**中性基底图**（结构、比例、构图对，模板见下），再用它作参考**风格化**到第 2 步的画风。`tag` 对应 character/scene/prop，风格化后的图作跨镜锚点；角色一致性见 character-consistency。
4. **分镜**：多段故事按 SP 分镜切割原则拆镜（CLIP 字段见下），定节奏与首尾衔接。
5. **逐镜生成**：用 `generate_video_v3` 逐镜生成，`reference_nodes` 引用对应锚点、prompt 里 `{{NodeKey}}` 绑定，单镜 ≤15s；数量锁见下。
6. **合成**：多段用 `composite_video` 拼成成片（见 montage，`Skill("montage")`）。

## 场景解析结构（Stage 1 深度）

解析产出：叙述摘要；**角色**（简称 shorthand 供跨模块引用、性别、年龄段、是否来自上传）；**场景**（简称、室内/外、时段）；**候选道具**；风格预设倾向 + 理由；总时长；**格式路径**（single-video 单段 / multi-clip 多段）+ 选择理由。简称贯穿后续所有阶段，别中途改名。

## 风格公式（Stage 2 深度）

把画风写成一条单行公式，固定这几段拼接：

> **[画风基底]** 动画，参考 **[风格参照]** —— [线条技法]、[上色技法]、[调色板]、[点缀特效]、[背景处理]、[动画节奏/timing]、[相机描述]

- 各段由需求驱动；无法映射或缺输入时回退到通用默认（现代 2D 手绘 + 粗细变化的手绘墨线 + 三值平涂赛璐珞硬阴影 + 饱和大地色 + 阴影区半色调点 + 手绘线沸腾、动作走二拍 + 24fps）。
- **只限 2D / 手绘 / 卡通范围**；像素、3D、写实风不在此。

## 基底描述模板（Stage 3 基底步）

- **角色基底**：年龄性别+表情 → 发型 → 体型体态 → 面部细节 → 服装（上→下→鞋，无 logo/文字、全覆盖、肘腰膝真实褶皱、干净轮廓）→ 姿态；**全身站立肖像**、纯色背景柔和正面漫射光、头顶脚底留边距、无道具/无场景。
- **场景基底**：标识行 → 建筑（墙/地/关键结构/陈设/空间布局：左…右…后景…前景…）→ 布光 → 氛围 → 静态广角建立镜（前景锚 + 背景锚）；**空场锁**：无人物/剪影/动态、16:9 水平。
- **道具基底**：标识行 → 材质/表面细节/特征 → 孤立产品样照构图、纯色背景上方漫射光；**孤立锁**：无人/无手/无其他物体/无场景；通常 1:1。
- **风格化步**：保留基底的身份/空间布局/形状精确不变，**只改渲染**到风格公式画风。

## CLIP / beat 结构（Stage 4 深度）

每个 CLIP 记：叙事功能（建立/激励事件/上升/高潮/收束）、角色想要（Want）、地点 + 地点模式（锁定/转场）、转场类型、**相机模式**（单锁定/多切锁定/视差滚动）、**音频模式**（氛围/旁白/动作/对话）、角色与道具锁、场景描述、取景、高潮标记（climax-token）、**收束状态**（本镜结束时角色的最终姿态/位置/表情，带空间位置）。
CLIP 内再拆 **beats**（每 beat：want / 取景提示 WS·MS·CU / 描述 prose / 高潮标记 / **空间锚点**）。
**跨镜连续性**：靠"空间锚点词汇 + 上一镜的空间锚点"桥接（bridge-rule），保证角色位置/朝向不跳变。

## 逐镜数量锁（Stage 5 深度）

生成 prompt 里显式锁死：本镜**角色数恰好 N**——无额外角色/路人/背景人群，角色单一实例、绝不克隆/复制/同框出现两次；**道具唯一**（每个叙事道具单一实例）；**场景锁定**（全镜动作发生在本地点内，不切换空间）。

## 原则

- 全片统一动画画风，跨镜不漂移。
- 风格公式、镜头节拍等关键决策按 SP 导演经验自己做，不外包。
- 暂停点：风格设定图、分镜确认后再进生成（见 SP）。

## 风格专项（有专属技法体系，直接走独立 skill）

本 skill 是通用 2D/2.5D 动画流程；以下风格有各自独特技法体系（风格致敬非精确模仿），命中时优先用专项 skill：

- **宫崎骏式手绘**（赛璐珞质感/自然生命力/飞行与风/色彩插槽/视觉状态账本）→ ghibli-anime-style
- **羊毛毡动画**（羊毛毡材质复刻现实/造型三级分级/镜头内时间分段）→ needle-felt-animation
- **水墨武侠动画**（五行色彩爆发态/四宫格场景/画风运动张力耦合/水墨情绪外化）→ ink-wuxia-animation
- **90s 魔法少女**（日常/变身双形态/双层世界观/仪式化变身序列/反派视觉层次）→ mahou-shoujo-90s
