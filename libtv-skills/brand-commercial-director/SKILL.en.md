# brand-tvc-director

Use this skill when producing high-luxury/fashion/sports/automotive/3C big-brand tonal-emotional TVC global ad films. Unlike tv-ad (15s single-spec fast ads): this skill is a **brand-level TVC full-process director**, including the brand tonality/philosophy analysis layer, multiple 15s tabular storyboards with clip head-tail continuity, the spokesperson/product three-view asset strategy, the visual reverse-derivation terminology library, and the universal formula prompts.

> Environment adaptations: GPT Image 2 → `generate_image_v3` (all images forced onto the same image engine for consistency); Seedance 2.0 → `generate_video_v3`; `multimodal_analyze_tool` → multimodal image-reading reverse derivation (directly reads uploaded images / with `analyze_video_clip_storyboard` as an aid), with the JSON reverse-derivation document as the output contract; `text_editor` → `write_file_v2`; `video_assembler` → `composite_video`; `@素材`(asset)/placeholder → `reference_nodes`+`{{NodeKey}}`; the three-view can be configured with the `character_turnaround_3view`/`product_turnaround_3view`/`scene_turnaround_3view` gameplay (cross-checked against the "three views in one image" requirement). The VIP/credits semantics of the source "Seedance 2.0 VIP" have been stripped out.

## Hard Preconditions

**Must exist: spokesperson image + scene tonality reference image.** If either is missing, terminate the process immediately and prompt for supplementation. Optional: product images, brand visual reference images, brand color reference images, material reference images, space reference images, existing ad reference images. **When required materials are missing, generating any reverse-derivation documents/brand analyses/plot directions/scripts/storyboard tables/Storyboard Shots/asset images/video Prompts/video materials is not allowed.**

## Core Concept Boundaries (9-Concept Responsibility Chain)

- **【Visual Reverse-Derivation Document】** Output by the reverse-derivation stage; it is the **foundational basis** for the subsequent brand tonality analysis, brand philosophy analysis, TVC narrative creativity, story script, storyboard tables, asset prompts, and video prompts.
- **【Brand Tonality Analysis】** Based on the reverse-derivation document, determines the high-luxury/fashion/sports/automotive/3C advertising temperament.
- **【Brand Philosophy Analysis】** Based on the reverse-derivation document + user brand information, distills the brand spirit, audience emotion, advertising proposition, and global communication tone.
- **【TVC Narrative Creative Directions】** Proposed based on tonality/philosophy/spokesperson image/product image/scene tonality image, for the user to choose a narrative path.
- **【Preliminary Story Script】** Output after the user confirms direction, duration, aspect ratio, and media parameters; confirms the narrative structure.
- **【Tabular Storyboard Table】** Output based on the confirmed script; one table per 15s, each table about 1000 words, containing 5-12 shots. **Must be in table format, must be output to the user, and must pause for confirmation.**
- **【Storyboard Shot】** Only after the user confirms the tabular storyboards, register each 15s table **in its entirety** as one Shot; no deletion/rewriting/compression/reordering/format changes allowed.
- **【Asset Image Registration】** Does not take individual shots as the unit, does not register shot asset images, does not generate keyframe images; only registers spokesperson full-body three-views, product three-views, different-scene asset images, and props/new figures/costumes/visual elements that repeat across tables and are not covered by uploads.
- **【Asset Image Generation】** All images are forced onto the same image engine; after generation, must pause and wait for user confirmation before moving to video.
- **Without user confirmation, do not by default advance the registration of Storyboard Shots and the various assets.**

## Storyboard and Shot Registration Specifications (Stage 5 + Stage 7)

**Responsibility boundary**: register Shots only after the user has confirmed the table storyboard; not responsible for brand analysis/narrative direction/asset image generation; **must not register any planner-stage output directly as a Shot**.

**Table storyboard design requirements**: one table per 15s, containing 5-12 shots, total duration strictly 15s, description volume approximately 1000 characters. Table columns are the same as in Stage 5. One visual feedback point every 3s (shot-size change/micro close-up/light-shadow displacement/camera movement speed change); one visual or emotional climax every 7s (Push-in/Pull-out/Orbit/action burst/product function reveal). **Long takes must never be placed at the beginning or end; they must sit in the middle segment to carry emotional continuity.** All shots must form a continuous, physically plausible action chain, **using the six seamless transition types: motion matching / physical occlusion / geometric overlap / light-shadow continuation / sound bridge / beat continuation**. **Black frames, white frames, fade-ins, fade-outs, cross-dissolves, and meaningless empty shots are strictly forbidden.** After each table, append a rhythm check: 3s feedback points, 7s climax points, quadruple-goal completion status, and the segment's opening-ending continuation strategy.

**Quadruple commercial expression goals (every 15s must cover all)**:

- **Spokesperson temperament**: established through entrance manner, action rhythm, gaze direction, micro-expressions, outfit, and interaction with the product.
- **Brand worldview**: established through environment, spatial layers, lighting structure, color and material language, and camera blocking.
