# time-freeze-effect

做"時間靜止"特效短影片時用本 skill。經典結構:**場景中時間驟停 → 主角是唯一還在動的人、在凝固的世界裡穿行 → 一個響指/一句話時間恢復**。上傳主角參考圖,全片外貌一致。一鏡到底、圖生影片完成。

> 本環境適配:圖生影片走 `generate_video_v3`(引用主角參考圖、生成內嵌音效);源 MIT,表達重寫、非 1:1。

## 輸入

- **主角參考圖**(必填):清晰露臉的人臉/身形照,全片外貌須一致。
- **場景**(選填):時間將凝固的環境。選**人群能量足、且空中有大量可"凍住"的小物**(液體、彩紙、火花、爆米花)的場景效果最好——擁擠昏暗、帶霓虹的運動酒吧/夜店/婚禮現場/體育場人群。
- **凝固瞬間視覺**(選填):時間停住那一刻懸在空中的標誌畫面(懸浮的金色啤酒弧線/漂浮靜止的爆米花/定格在歡呼中的人群表情)。
- **收尾臺詞**(選填):主角恢復時間前低語的一個詞/短句。
- **畫幅**:16:9 電影感 / 9:16 豎屏社媒。
- **時長**:10 或 15s(豎屏社媒建議 10s、節奏更緊)。

## 工藝:一鏡三段 + 響指機制 + 音效弧

**一鏡內完成三段式**,圖生影片(引用主角參考圖、720p、開啟內嵌音效)。

**超寫實電影調(貫穿全片)**:仿電影機 + 35mm 鏡頭的超寫實質感、體積霧(volumetric haze)、動態硬陰影、淺景深。這套質感是"凍住的世界"可信的前提,不可省。

三段時間線:

1. **常態與觸發**:開場場景時間正常流動;斯坦尼康正面中景跟拍主角自信穿過人群,人群在其周圍爆發歡呼;主角舉起右手、打一個響指。
2. **凝固**:響指瞬間,指尖迸出一道球形衝擊波——空氣扭曲、光線折射向外漣漪擴散;萬物驟然靜止在動作中途;凝固瞬間視覺懸在空中(液體弧線/漂浮顆粒/定格表情);霓虹光打亮懸停的塵埃與液體;絕對靜默。
3. **穿行**:只有主角在動;腳步聲輕而帶回響;鏡頭後退跟隨主角平靜地穿過凝固的場景、觀察,並從空中拈起一個懸停的細節。
4. **恢復**:主角在一個表情狂喜、凝固的旁觀者面前停下、側頭端詳,低語出收尾臺詞;隨後轉身面向鏡頭、壞笑,再打一次響指——一道更強的反向衝擊波向外擴散,運動瞬間恢復(聲音炸回、跳起的人落地);主角走開,鏡頭穿過重新歡慶的人群推進。收黑。

**音效弧(本特效的簽名,務必開啟內嵌音效、不可靜音)**:震耳的環境歡慶 → 響指 → 深沉衝擊波/低頻轟鳴 → 絕對靜默 → 腳步聲 → 低語 → 響指 → 反向衝擊波 → 歡慶聲炸回。這條"響指→靜默→響指"的聲音弧是整個效果的靈魂,若靜音則效果崩塌。

**主角一致性**:在提示詞裡顯式繫結"此人來自參考圖,面部特徵與身形比例在全片各鏡保持一致"。若模型拒絕寫實人臉,退到更寬鬆的身份匹配設定(不強綁寫實相似度)重生成。

## 流程

1. 收主角圖 + 場景/凝固視覺/收尾臺詞/畫幅/時長;缺主角圖先要。
2. `generate_video_v3` 圖生影片:參考圖綁主角;提示詞按上面三段時間線寫清(常態觸發→凝固→穿行→恢復)、寫清響指球形衝擊波與反向衝擊波、寫清凝固瞬間的具體懸浮視覺、寫清超寫實電影調那套引數、把音效弧作為 sound design 段落寫進提示詞;開啟內嵌音效;720p;畫幅/時長按輸入。
3. 展示成片;可調場景/凝固視覺/臺詞重生成。
