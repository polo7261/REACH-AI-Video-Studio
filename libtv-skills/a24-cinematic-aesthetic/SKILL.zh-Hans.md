# A24电影美学

> 🔴 严格按本 SKILL 分步执行。版本 2.5.1 lean（Seedance 2.5 适配）

## 底层 DNA（每条画面无条件带）

1. 🔴 **真实胶片质感为绝对底**：真人实拍级、16mm/35mm 颗粒、皮肤有毛孔与自然油光。禁 CGI/动漫/3D/塑料皮肤/过度磨皮/数码硬锐。🔴 分辨率越高越不等于干净——720p/1080p 下同样须保留可见颗粒、halation、低对比曲线。
2. 🔴 **情绪优先于情节**，画面服务内在情感、不做信息交代。整体节奏快而紧绷、有压迫感，不给喘息；但紧张来自情绪压迫，非剪辑花活。
3. **亲密 + 不安并存**：美丽与不适同框，浅景深贴近、面部凝视、日常中的诡异。
4. **构图克制，留白即绷紧**：负空间与静默是蓄能（暴风雨前的静），非松弛；对称几何但不炫技。
5. **光源动机化**：自然光/实用光源（窗/灯/烛/霓虹/荧光），只见光效不见灯具。
6. **介质必须动**：雾/尘/雨/雪/光尘写明方向+速度，衣物头发同步受风。
7. 🔴 **气质底 + 参考库**：参考只取方向锚（光色/质感/辨识点），产出始终原创、绝不逐镜复刻。
8. **配色随情绪定**，允许大胆饱和或冷静自然；唯一负面锁：避开默认黄褪色廉价感。
9. 只做 A24 作者性胶片一脉，不做商业快切炫技、纯类型片视觉。

## 质感尾词（每条图像 prompt 默认带）

`16mm 或 35mm 胶片拍摄，天然胶片颗粒，低对比胶片曲线，真实皮肤呈现（真实毛孔与纹理），柔和光晕（halation），真实粗粝质感，情绪化电影级色彩，亲密浅景深，动机化自然光/实用光源，无过度锐化，无 CG 渲染感；非动漫、非 CGI、非 3D 渲染、非塑料皮肤、非过度磨皮、非数码高清硬锐，无默认黄褪色调，无高分辨率数码干净感（保留颗粒与噪点结构），画面内无影棚灯具，无黑边遮幅（画面铺满整帧出血）`

## 语言规则（🔴 全局，优先于本文档其余语言表述）

- **会话语种锁**：入口第一动作，按用户首次文字输入的语种判定一次（无文字取 skill 名语种），写入 memory 全程锁定；中途不重判（点选卡片、短词、他语种素材均不改变），仅用户明确要求时更换。
- 🔴 **唯一来源 = 会话语种，覆盖全部可见输出**：以下一律按会话语种书写——① agent 的每一句对话回复、进度说明、确认与报错 ② 选择卡的问题/选项/说明 ③ 故事梗概、scene list、剧本正文、分镜说明、资产与场景说明 ④ 全部 prompt（图像/视频/音乐，含每条重试）。本文档文案仅是内容规范，一律译写、**禁照抄原文语种**。
- 🔴 **唯一例外（保留原文的白名单）**：① 引号内台词/旁白引文（用⑧语种）② 技术标识符（model 串、duration、asset_id、MAXDUR、@图1/@音频1 等参数与引用名）③ 摄影与制作术语（halation、dolly、push-in、compose、moodboard、underscore 等）④ 参考片原名。负面词沿用本文档给定串（默认即会话语种，禁改为第三语种）。白名单之外一律会话语种。
- 🔴 **与对白语种双向隔离**：⑧只决定**片内口语**。用户选英文对白 ≠ 全局转英文——**只有引号内台词/旁白是英文**，对话回复、卡片、prompt 全部描述文字、故事与剧本正文一律仍是会话语种。例：首输中文 + 对白英文 → 全程中文、仅台词引文英文；首输韩文 + 对白日文同理。图像 prompt 无台词、全文会话语种。
- **禁例外禁继承**："模型更懂英文"不采纳；下游只继承上游的风格与内容、绝不继承书写语种；发现语种不符先译写再使用，禁下传。
- 🔴 **复用与自查**：每条 prompt 绑 asset_id 存 memory；失败重试与重生成一律读回原 prompt 在其基础上微调，禁重写禁改语种。**每次输出前（含对话回复）两问**：书写语种 == 会话语种？台词引文 == ⑧语种？不符则改写后再输出。

## 时长档 MAXDUR（🔴 优先于本文档所有时长数字）

1. **来源 = 入口⓪的用户选择**：Seedance 2.5 → MAXDUR=30；Seedance 2.0 → MAXDUR=15。写入 memory 全程沿用，不自行改动。🔴 **发第一条任务时核对**：所选模型是否真在工具列表中、duration 是否真接受该值（被回落则走"模型闸门"停下问用户，不静默降级）。
2. 🔴 **时间轴末段结束时间 == 本条提交的 duration**：既不许留"…"，也不许超出 MAXDUR（超出会被压缩或截断，是"时长上不去"的主因）。
3. **按档取值**（本文档其余处的 30s / 5–8 镜 / t30s 均为 MAXDUR=30 的示例）：

MAXDUR 单条分镜数 写到 成片换算 跨段接法 30s 5–8（下限 ≥3） t30s 30–60s≈2 条 / 1–2 分≈2–4 条 拆条 + compose 15s 3–4（下限 ≥2） t15s 条数加倍 拆条 + compose ≤10s 2–3 该时长 按比例上推 拆条+compose

MAXDUR 变化时回第 2 步重切段落，不把 30s 的段硬塞进 15s 任务。其余规则（四轨、切分动因、参考纪律、语言、声音）不变。

## 流程

 1. **入口**：🔴 先锁会话语种。🔴 **一轮合并问完以下 9 项**（每项独立呈现、带可选项，问题与选项均译写为会话语种），答案入 memory。 ⓪ 🔴 **视频模型（必问，排在最前，决定下游全部时长编排）**：**Seedance 2.5**（默认，单条 30s）/ **Seedance 2.0**（单条 15s）。答案即 `MAXDUR`（2.5→30、2.0→15）写入 memory，第 2 步分段、第 5 步时间轴、分镜数与跨段接法全部按此档走，中途不得混用。 ① **时长**（只呈现成片时长、不露分镜数）：30–60 秒 / 1–2 分 / 2–3 分 / 其他。内部按 MAXDUR 表换算条数。 ② **执行模式**：全自动 / 手动确认。 ③ **画幅**：21:9（默认）/ 16:9 / 9:16 / 3:4 / 其他。 ④ **分辨率**（与画幅分开问）：480p / **720p（默认）** / 1080p；图像 2K。仅此三档，不提供 4K。 ⑤ **故事梗概**：用户自带 / 自动生成。 ⑥ **风格方向**：🔴 从参考库**两两随机融合**出 3–4 个方案作选项（每次纯随机、附一句融合气质说明），🔴 只写"片名 × 片名"、不露 REF 编号，**禁把单一片名直接列为选项**；末位留"我有自己的想法或指定参考"。仅当用户明确只要一种时走单一风格。 ⑦ **人声模式**（必问）：①纯氛围 ②纯对话（默认）③纯旁白 ④对话+旁白穿插。 ⑧ **对白语言**：英文（默认）/ 韩文 / 日文 / 其他 / 无语言。（2.5 支持十余种语言口型对齐。）
 2. **故事**（先于 moodboard、必须定稿）：情绪优先、张力递进、开放结尾。输出 scene list + emotional arc + 🔴 **动作线**（每场肢体动作起→中→止，动作必挂动机）+ 🎭 **角色表演基调**（标志性小动作/身体习惯/情绪临界反应，全片跨镜一致），遵循⑦人声模式。🔴 故事来自用户方向、**不照搬参考片剧情**。🔴 **定稿闸门**：弹卡①确认通过 ②需要修改（附输入项，改后再弹，循环至通过），未通过不得下行。🔴 **按 MAXDUR 分段**：切成每段 ≤MAXDUR 的连续段，逐段标注**同场景延续**（compose 时无缝相接）或**跨场景硬切**（转场处硬切）。风格：清晰有目的、场与场压茬推进，紧张挂在情绪与动机上。
 3. **moodboard**：风格已在⑥定，不再询问。故事通过后生成（融合方案以一种为主色调锚、另一种作气质叠加；单一画面铺满出血，禁白边/拼贴/分格）→ 🔴 **不确认、直接存为风格锚**入 memory。
 4. **资产（图像）**：🔴 全部图像 prompt 用会话语种。🔴 **时序**：moodboard 与人物图可并行；**场景图必须等 moodboard 完成后才开始**（要挂它作风格锚）。
    - **角色**：有戏角色必产锚定图（锁脸/服装/发型），后续 @角色名 引用。
    - **场景**：🔴 **一个空间只出一张图**、该空间所有戏共用（换地点才新增），不按场次数生成。🔴 **动作依赖要素必须画进去——尤其是门**：剧本用到门/窗/楼梯/镜子/走廊口时该图必须明确出现且位置可用；生成前先提取"动作依赖要素清单"写进 prompt，生成后逐项核对，缺失重生成。🔴 **一律纯空镜、绝无任何生物**：严禁任何人物、人形、机器人、AI、类人形象、动物（背景远景、群演、橱窗模型也不行），一切生命/类生命体只走人物图、靠 @角色名 合成。🎨 **强制挂 moodboard 风格锚——只参考风格（色调/光感/质感/气质），不参考构图/内容/布局，也不继承其书写语种**；可按 REF 偏移主色。🔴 禁黑边遮幅，直接用目标比例出图铺满整帧。
    - **道具**按需生成、asset_id 绑定。🔊 **声线锚（可选）**：用户提供角色声线音频则登记绑角色，第 5 步作 @音频N 锁跨条声音；未提供则靠性别锁+角色描述定声。
 5. **生成视频（按入口⓪选定的模型）**：🔴 时间轴严格按 ⓪ 对应的 MAXDUR 写——2.5 走 30s / 5–8 分镜，2.0 走 15s / 3–4 分镜，不混用。🔴 **单条内嵌多个连续分镜**（MAXDUR=30 时 5–8 个），严禁一镜一条；末段结束 == 提交的 duration。🔴 **跨 MAXDUR 一律另起独立条**、交第 8 步 compose 拼接；🔴 **禁用延长续写**——绝不把前一段视频垫作续写源，本 skill 不调用该功能。跨条一致性只靠场景图/角色图/声线锚维持：逐条核对脸/服装/光位/色调/声线/介质方向，漂移则用同组参考重生成。🔴 **参考素材只能是场景图 + 角色图（+ 道具图、可选声线音频），严禁把 moodboard 挂进视频任务**——它是图像层给场景图用的风格锚，视频阶段一律不挂；挂了会让模型复现它画面里的元素、污染构图与内容。风格已由场景图承载。🔴 **绝不含 BGM**：只出环境音+人声，配乐留第 9 步；@音频 参考禁传音乐类。
 6. **不达标处理（只有整条重生成）**：🔴 **本 skill 不调用 2.5 的任何编辑与续写功能**——无 timestamp 修镜、无运镜编辑、无局部重塑、无延长续写。某条不合格 → 读回原 prompt **在其基础上微调后整条重跑**（禁从头重写、禁改语种）；超出 MAXDUR 的内容一律另起独立条。🔴 **运镜、速度变化、慢动作全部只能靠改 prompt 重跑**（后期也没有变速/超分）。🔴 **重跑闸门**：同一条重跑 ≥3 次仍不达标 → 回上游查病根（场景图缺要素？动作线不可拍？参考冲突？角色图不清？），修上游再重发，禁无脑刷条。
 7. **音乐**（Mureka V8）：🔴 prompt 用会话语种。🔴 **方向不问用户**，按剧本节奏与风格自动匹配（紧张→低音心跳/合成器脉冲/渐强织体持续 underscore；慢暗涌→极简氛围织体）；静默只作骤停对比。禁流行编曲/管弦爆炸/廉价惊悚音效。BGM 可先生成、默认不合成。🔴 绝不作为 @音频 参考回灌视频。
 8. **成片合成**（media-platform）：compose 串接全部独立条——同场景延续段无缝相接、跨场景处硬切；接入环境音，**不含 BGM**，产出纯净成片（含人声）。
 9. **后期增补**：🔴 弹选择卡（可多选，非文本提问）：①加字幕 ②加 BGM ③都要 ④都不要。选了含字幕的项后**追加字幕语种卡**：Ⓐ跟随对白语种（单语，默认）Ⓑ指定其他语种 Ⓒ双语（上轨指定、下轨对白）。🔴 **混音**：原声（环境音+对白）+8dB、BGM −2dB。🔴 **顺序不可颠倒：先字幕、最后合 BGM**（含 BGM 成片上生成字幕会出错）。🔴 旁白已在视频阶段烧录，此处不再询问或追加。
10. **后期链限制**：可用字幕/转场（默认硬切）/抽帧/裁剪/文字贴片/混音；**无变速、无降噪、无超分**——所有镜头运动须在 prompt 内完成，要改走第 6 步。人声随视频烧录、非后期配。剪辑气质：快而紧、压茬推进、不泄压。

## 视频铁律

- 🔴 **分镜切分 = 内容事件驱动**：出现 ①动作节拍变化 ②情绪转折点 ③需变景别或视角 ④注意力焦点转移 之一即切新分镜。跟着内容走，不为凑数硬切、不为省事不切；数量与时长是**结果**（MAXDUR=30 时 5–8 镜、每镜 2–5 秒），紧张偏多镜、慢暗涌偏长镜。🔴 下限见 MAXDUR 表；真正一镜到底须在 prompt 明写"单镜不切"并说明理由。时间轴用全片连续绝对时间、每段标注切分动因。
- 🔴 **四轨强制**，时间轴每段必写：
  1. **主体动作**：从故事 Action 继承（不临时编）=动作+动机+过程分解（"停下转身"→脚步渐停/肩膀先转头跟上/目光定住）。
  2. 🔴 **情绪外化**：面部(眉眼/嘴角/呼吸)+微表情停顿(迟疑/目光飘移后归位)+肢体(肩颈松紧/手指小动作/重心偏移)。🎭 用角色表演基调的标志性小动作。⚠️ 具体到可演（非"表情紧张"而是"喉结滚动、指节抵桌沿泛白"），要有层次转折（递进/克制/决堤），停顿是绷紧非松弛。💡 2.5 表演收敛、微表情可读——写细微层次，不用瞪眼皱眉张嘴去"保证看得出来"。
  3. **镜头运动**：运镜库选 1 个，写类型+速度+方向。
  4. **介质/环境动态**：风/光尘/雨持续运动。
- **人物实体性**：全程实体清晰，不溶解/半透明/消失/被光或环境吞没。
- 🔴 **风格来源 = 场景图（及道具、角色图），禁挂 moodboard**：场景图已在图像层吃过 moodboard，视频忠实参考场景图即继承其风格；跨镜共用同组参考、气质不漂移。发任务前逐条核对参考清单里没有 moodboard。
- 🔴 **参考纪律**：硬上限 30 图/10 音频（🔴 视频参考不用），**实用 3–8 条**（场景图 1 + 出场角色分屏图 + 关键道具 +（可选）声线音频）。每条必须写明用途，不写用途的不挂。🔴 **一律不挂 @视频 参考**（既不作续写源、也不作运镜参考），视频阶段只吃图与可选声线音频。
- 🔴 **绝无 BGM**：只出环境音+对白（+旁白），禁配乐/音效垫乐、禁音乐类 @音频 参考；负面词须含"背景音乐、配乐"。
- 🎙️ **双人声轨（③/④）**：对白=带口型轨，旁白=画外不带口型轨；④在时间轴给两轨各自分配时间段（旁白填对白空隙、不同时出声），同一条 prompt 一次写清；跨条声线须保持一致。
- 🔴 **语言锁**：每条 prompt 常驻"对白/旁白一律用选定语言，模型补话也只用此语言，禁其他语种台词/字幕/口型"。⚠️ 只锁片内口语，不改 prompt 本身的书写语种。
- 🔴 **别摊平**：时长翻倍是分镜数上抬、非每镜变长；检查有无"为填满时长而拉长的空转段"。同一动作跨镜须状态离散变化、节拍间不留空转。

## 剧本

- 🔴 **默认节奏 = 紧张压迫递进**：首场即带悬而未决的张力，逐场升级不泄压；场与场压茬推进、信息克制；结尾开放不给解答。张力来自"处境不对劲/关系在崩/某事将至"的暗涌，非情节反转或悬疑解谜。
- 🎬 **可选慢暗涌**（伊尼舍林/Aftersun/伯德小姐一路）：长呼吸、留白、日常细节堆叠，张力在平静下渗出；"快而紧"让位，仍守情绪优先+开放结尾+拒绝说教。🎥 此范式优先用 MAXDUR 长镜做"一镜到底凝视"（缓推/缓移/微环绕不切）。
- ⚠️ **一片一节奏**：开头即定"紧张压迫"或"慢暗涌"，全片统一（可有局部骤停/爆发对比，主基调唯一）。
- 节奏与 emotional arc 对齐并传导到切分与运镜；只影响事件密度，不改"按内容事件切"。
