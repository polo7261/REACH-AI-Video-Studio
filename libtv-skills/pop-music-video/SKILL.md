## 三套影調預設(階段 1 選一,全片統一)

三套**共用固定種子**,只換調色/光質/情緒語言。下面的中文子句直接取用:**「調色子句」用於 MJ 場景圖,「前置風格句」放在 Seedance prompt 第一句。**

### A · 冷調雕塑

冷色電影調(鋼藍/青冷、去飽和、深對比)為主;硬質單光、教堂式光束、留黑;極簡 brutalist + 宗教感神聖空間/空曠巨構;肅穆莊嚴。**黑白為可選子模式。**

- 調色子句(冷調):`冷調去飽和電影調色,鋼藍-青冷色調,深對比、壓死暗部,單一硬質雕塑感主光,空曠肅穆的粗野主義或神聖空間,莊嚴靜默,細膩 35mm 膠片顆粒`
- 調色子句(黑白可選,替換上句):`高對比黑白,深邃壓黑,單一硬質主光`
- 前置風格句(冷調):`冷調去飽和電影感 MV 畫面,鋼藍-青冷色調,深對比與硬質雕塑感主光,空曠肅穆的粗野主義或神聖空間,莊嚴靜默氛圍,細膩 35mm 膠片顆粒,自然手持帶輕微呼吸感。`
- 前置風格句(黑白):`高對比黑白 MV 畫面,深壓黑與單一硬質主光,肅穆宏大的空間,細膩 35mm 膠片顆粒,自然手持帶輕微呼吸感。`

### B · 暖調膠片

35mm 暖調、金光、自然膚色、豐富中間調、顆粒;可彩色/黑白混用;家鄉街區寫實 + 戲劇符號;宜 4:3,可編舞/人群。

- 調色子句:`暖調 35mm 電影膠片調色,金色自然光,豐富中間調,真實的街區寫實感,厚重膠片顆粒,輕微光暈 halation`
- 前置風格句:`暖調 35mm 電影感 MV 畫面,金色自然光與豐富中間調,接地氣的街區寫實加一點戲劇化擺佈,厚重膠片顆粒,自然手持帶有機運動。`

### C · 銳閃顆粒

酸綠/lime 偏色或冷藍 club 調、lo-fi、顆粒重、汗味高光;機內閃光燈硬閃 + club 頻閃/霓虹;俏皮挑釁 candid。

- 調色子句:`lo-fi 顆粒派對質感,酸性青檸綠偏色,機內閃光燈硬光,club 式高對比,汗溼高光,厚重顆粒`

## 固定種子與出圖規格(速查)

> **全域性預設**:**MJ 平臺畫質"自適應"、Lib Image"標準畫質"**;**每條 MJ prompt ≤ 1024 字元**(含尾串/引數,超了精簡描述別堆詞)。所有用到 MJ 的地方統一 **V8.2**。**提示詞一律中文(引數/種子程式碼不譯);服裝用正向合規詞,負面區不寫敏感詞。**

- **造型圖 = Seedream 5.0 Pro**(**2K,無任何尾串/引數**):出**一張 16:9、白底的造型圖,從左到右並排 4 個全身造型,4 套明顯各不相同**,真人模特、臉與全身清晰;使用者從這 4 個裡**選 1 個**(選中那套鎖定為全片主造型)。**有造型參考圖則作 Seedream 的圖參考;人像/人臉參考圖一律不喂 Seedream。** prompt 純中文自然語言(性別/人種/造型方向 + 著裝/人物底線),**不帶** `--sref` **/** `--ar` **/** `--v` **/** `--no` **等任何尾串**。\
  示例:`一張 16:9、2K 高畫質、白底的造型參考圖;同一位[性別][人種]真人模特,從左到右並排 4 個全身造型、4 套明顯各不相同;臉與全身清晰、自然的手,得體大方的時裝、私密部位有遮擋、面料不透視、非情色,皮膚乾淨無紋身、無穿孔;純白無縫背景,均勻影棚光,攝影寫實`
- **三檢視 = Lib Image**(強制,預設**標準畫質**),造型確認後**據所選那套全身造型擴寫白底全身三檢視**;**必須把上游【所選那套造型圖】節點連線到 Lib Image 的影象參考(image reference)輸入口——硬性要求,不連線 Lib Image 就不依據選定造型、會跑偏成另一套**。**真人模特**;**排版強制:所有內容在一張圖內、16:9,全身左/中/右三視(正/側/背),不要頭部特寫/表情大頭三視**;**有人像參考圖→三視人臉用純白圓形貼紙完全遮住 + 右下角中文小字"人臉單獨提供 · 此圖僅用於服裝造型參考"**(真臉由原圖在 Seedance 鎖)、**無人像參考圖→保留所選那套 Seedream 造型的臉**(臉即身份)。\
  要點:`根據選定的那套全身造型擴寫的單張角色三檢視,16:9,同一真人攝影模特的全身左/中/右(正/側/背)三視,據所選造型一致地推斷側面與背面,只要全身三視、不要頭部特寫三視,各檢視造型與身材比例完全一致;皮膚乾淨無紋身、無穿孔,著裝得體大方、私密部位有遮擋、面料不透視、非情色,純白無縫背景,均勻柔和影棚光,攝影寫實,(僅當有原臉參考時:每個檢視的臉用一個純白實心圓形貼紙完全蓋住五官,圖片右下角標一行中文小字"人臉單獨提供 · 此圖僅用於服裝造型參考")`
- **場景圖 = Midjourney V8.2**(預設**自適應**,prompt ≤ 1024 字),固定種子 `--sref 5822120099`,**全景無人、零文字**。\
  尾串:`… --sref 5822120099 --ar <16:9|4:3|9:16> --v 8.2 --no 文字, 字母, 數字, 字幕, 招牌文字, logo, 水印, 卡通, 插畫`
- **影片 = Seedance 2.5**,輸入 = 場景圖 + 白底三檢視(鎖造型/身形)+ **人臉參考**(有人像參考圖→原圖/影片;無人像→所選那套 Seedream 造型的臉;**人像參考圖不喂造型模型、只在此處喂**)。

## 流程(逐階段暫停確認)

### 階段 0 · 開拍前

**開拍前問詢卡(下面每一問都是「獨立的一問」,在同一張卡里一問接一問問完;絕不把兩個問題的內容揉進同一問的選項裡,也絕不拆成多張卡。問完停下等上傳)**:

> 規則:**每一問只問一件事、給自己那一問的乾淨選項**;**條件問(第 2 問風格主題、第 5 問人種)一律照常顯示,不適用時讓使用者"留空/跳過"即可,絕不合並進別的問**。

1. **音訊(單選,只給這兩個選項,別塞別的內容進來)**:你有現成的歌曲 / BGM 嗎?
   - 選項 A:`我有現成音訊,稍後上傳`
   - 選項 B:`沒有,幫我生成`
2. **歌曲風格 + 主題(自由輸入框;僅當第 1 問選 B「沒有,幫我生成」時才需填,選 A 的留空)**:這首歌想要什麼風格和主題?(例:`清爽青春感,關於初戀與告別` / `暗黑酷感,關於孤獨與反叛`)——**無論填什麼,生成音樂一律鎖在大 POP 語境**(pop / rap / hip-hop / R&B)。
3. **人聲(性別 + 語言)**:要用 / 要生成的人聲是哪種?**選性別(男 / 女)+ 演唱語言**(中文 / 英文 / 韓文 / …)。(上傳了音訊可自動聽辨來預填,使用者可改)
4. **有無人像 / 造型參考圖**:有人臉參考圖(或 &lt;15s 影片)/ 造型參考圖嗎?——**只要有人像參考圖 → 主角性別、人種一律以人像參考圖為準,第 5 問「人種」留空/跳過**;沒有則第 5 問照填。
5. **角色人種(自由輸入;僅當第 4 問「沒有人像參考圖」時才填,有人像參考圖就留空)**:主角人種是?**按第 3 問的語言優先推薦**(中文→亞洲、英文→歐美、韓文→亞洲、西語→拉丁…),可自行輸入 / 修正。
6. **字幕**:成片要不要字幕?要→選語言(中文 / 英文 / …);不要→無字幕。(字幕只在階段 5 疊加,生成畫面永遠零文字)
7. **影調預設**:**A 冷調雕塑/ B 暖調膠片/ C 銳閃顆粒**,選一,全片統一。
8. **畫幅**:16:9 / 4:3 / 9:16?
9. **畫質**:480p / 720p / 1080p?(粗糲感靠顆粒與調色,不靠低解析度)

> 結論:**主角性別 = 人聲性別**;**主角人種 = 有人像參考圖→一律隨參考圖(第 5 問留空)/ 無人像參考圖→按第 5 問語言推薦並經使用者確認**。**時長不單獨問——由後面【選段】自動定。以上 9 問全在這同一張卡里問,一問一件事、各給各的乾淨選項,不要相互揉進選項、也不要另開卡。**

**音訊就緒 / 音樂確認(先於切片)**:

- **有音訊**:用使用者上傳的音訊。
- **無音訊**:按上面的\*\*歌曲風格 + 主題 + 人聲(性別/語言)\*\*生成一版帶歌詞人聲歌曲(**一律鎖定大 POP 語境**)→ **生成後必須暫停,等使用者確認音樂沒問題(可要求重做/微調),滿意後才繼續切片**。
  - **⚠️ 生成音樂時嚴格區分「風格控制」與「歌詞」兩個欄位,別讓模型把描述詞唱出來**:
    - **風格/主題/情緒/BPM/曲風/人聲性別/語言** 這些只填進**風格描述 / 標籤 / style 欄位(控制項)**,**絕對不要放進會被演唱的歌詞欄位**。
    - **歌詞欄位單獨另寫成一首正經的歌**:按所選**語言**寫、貼合**主題**、有**主歌/副歌(Verse / Chorus)結構**、用結構標籤(如 ``` [Verse]``[Chorus] ```)分段;這些標籤是結構提示、不會被唱。
    - **絕不能把 prompt 裡的風格/主題/描述詞(如"青春感 indie-pop、關於成長與告別、女聲、韓文")一字不差地當歌詞唱出來**——那是控制項,不是歌詞內容。
    - 如果工具只有單一輸入框,就在框裡**明確分割槽**:先寫風格標籤,再用清晰分隔寫真正的歌詞,並註明"僅演唱歌詞部分、風格標籤不演唱"。
    - **音樂提示詞整體 ≤ 1024 字元**(風格控制 + 歌詞合計);超了就精簡描述、歌詞取主歌+副歌核心段,別硬堆。

**音訊確認後必做兩步(先於分鏡與生影片)**:

- **① 音訊切片(+ 拿歌詞)**:把音訊切成**多段連續、每段 ≤30s 的切片(按對應影片的條數/秒數一一切分,每段多長取決於該 part/場景需要)**,同時**拿到準確歌詞**(**只供內部對齊口型/選段用,絕不寫進任何發給模型的 prompt**)——後續對口型段**每段切片作為音訊錨點餵給 Seedance 2.5(sd2.5)驅動口型**。**切完必須停下,等使用者確認切片再繼續。**
- **② 選段**:問"**你想用哪幾段來做這支 MV?**"讓使用者選。**推薦選連續的幾段(每段 ≤30s)**(便於段間銜接順);**推薦挑有 rap/人聲/歌詞的段做對口型,純器樂段(intro/beat 間奏)預設不做 lipsync**。**使用者選完即自動算出時長(= 所選各段秒數之和 = 影片段數),不用再問"想做多長"**;段數由此步確定。

**造型分流**:按問詢卡 Q3 有沒有上傳人像 / 造型參考圖,走下面四種情況。

**四種情況(按使用者上傳了什麼分;都先"理解造型方向 + 結合下方預設造型語言補寫成完整文字 spec",不丟圖照搬。統一流程:Seedream 5.0 Pro 出一張 16:9 白底 2K、橫排 4 個不同全身造型 → 使用者選 1 個確認 → Lib Image 據所選造型擴寫三檢視)**:

> **鐵律:人像/人臉參考圖一律不喂造型模型(Seedream)**(Seedream 只接受**造型參考圖**作圖參考);**人臉參考圖只在最後 Seedance 生影片時**與造型三檢視一起喂(鎖真臉;**髮型由使用者選:保持參考圖髮型 / 換成造型三檢視的髮型**)。**三檢視人臉怎麼處理,只看"有沒有真人像參考圖":有→用純白圓形貼紙遮臉 + 右下角中文小字標註,無→保留所選 Seedream 造型的臉。**

- **① 只有人像參考圖**:人像**不喂 Seedream**;Seedream 按文字 spec 出四造型圖(無尾串)→ 使用者選 1 → Lib Image 出三檢視、**人臉用純白圓形貼紙完全遮住 + 右下角中文小字"人臉單獨提供 · 此圖僅用於服裝造型參考"**;人像參考圖**僅在 Seedance 時**與三檢視一起喂(鎖真臉;**髮型由使用者選:參考圖髮型 / 造型三檢視髮型**)。
- **② 只有造型參考圖**:造型圖**作 Seedream 圖參考** + 補寫 spec → Seedream 出四造型圖 → 使用者選 1 → Lib Image 據所選造型的**人臉 + 造型**出三檢視、**人臉不打碼**(所選造型的臉即身份,也作 Seedance 人臉參考)。
- **③ 人像 + 造型都有**:**只把造型圖作 Seedream 圖參考、人像不喂** + 補寫 spec → Seedream 出四造型圖 → 使用者選 1 → Lib Image 出三檢視、**人臉用純白圓形貼紙完全遮住 + 右下角中文小字"人臉單獨提供 · 此圖僅用於服裝造型參考"**;人像參考圖**僅在 Seedance 時**與三檢視一起喂(鎖真臉;**髮型由使用者選:參考圖髮型 / 造型三檢視髮型**)。
- **④ 都沒有**:用**第一步據人聲語言+性別推薦、使用者確認過的人種 + 性別** + 補寫 spec,Seedream 出四造型圖(無尾串)→ 使用者選 1 → Lib Image 三檢視、**人臉不打碼**(所選造型的臉即身份,並作 Seedance 人臉參考)。不單獨問"主角性別/人種"。

- A:`極簡雕塑感 × 山本耀司(Yohji Yamamoto)式先鋒暗黑:以黑為主(黑 / 炭灰),oversized 垂墜、層疊、不對稱解構剪裁,飄逸大廓形,寬鬆闊腿 / 飛機褲等有流動感的褲型,面料帶份量與褶皺的戲劇性,和風侘寂的詩意暗黑感,editorial 高階時裝、造型感強;**不要大衣 / 長大衣,不要白色直筒長褲**`

### 階段 1 · Final_Video_Spec(已併入開拍前問詢卡)

影調預設 / 畫幅 / 畫質**已在開拍前那一張問詢卡里一起問過**(第 6\~8 項),此處不再另開卡。**時長不問——段數/總長由階段 0【選段】確定**(選了幾段 ≤30s = 幾段影片 = 總長),每段 = 一條 ≤30s,裝配順接。粗糲感靠顆粒與調色,不靠低解析度。
