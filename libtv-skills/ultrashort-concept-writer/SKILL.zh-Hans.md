# ultrashort-concept-writer

1-3分钟概念超短片的完整写作方法论。**这是纯粹的"idea delivery"**——不靠故事，靠概念本身的锐度和视听语言的冲击力击中观众。本 skill 自包含，不依赖本库其他任何文件；如果要指定"这个概念超短片该讲男频/悬疑/复仇哪个题材的具体内容判断标准"，可以在写完概念后额外参考对应题材壳，但题材壳不是必需前提。

## 边界：不做什么

不产出分镜表、镜号、景别/运镜/构图、转场方式、AI生图/生视频提示词、任何特定生成引擎的格式约束。产出到完整的、可以直接读、直接拍的文字剧本为止。

## 工作流纪律

严格按步骤顺序执行，不跳步；每一步完成后暂停，等待用户的[通过/修改/自检]指令；绝不一次性把后续所有步骤生成完再交给用户；每步结束后提醒用户可以要求[自检]。

自检是内部过程——写之前先在心里过一遍对应步骤的检查清单，不需要在输出中展示自检的思考过程，只需要确保交付的内容已经通过检查。用户仍然可以主动要求[自检]，此时才需要显式地逐条列出检查项并给出评估结果。

## 写作红线（全局最高优先级，任何格式都不能违反）

**绝对不要**：
- 写心理描写（"他意识到"、"她领会到"、"内心涌起"）——超短片尤其致命，3分钟里每一秒都该是画面，不是解释
- 写括号暗示（"（其实是在掩饰紧张）"）
- 角色用台词解释设定或概念规则
- 说教片段、强行催泪、煽情独白
- 过度比喻句、类比、书面化的AI腔台词
- 写任何摄影机拍不到的内容

**必须做到**：
- 台词口语化，像真人说话（超短片往往台词极少甚至没有台词，更要珍惜每一句）
- 用动作代替解释（动作即潜台词）
- 所有内容从视听角度出发

## 视听化写作核心

**Show, Don't Tell**：如果一个情感/规则无法通过画面或声音传达给观众，它就不该出现在剧本里。错误示范："他终于理解了这个世界的规则。"正确做法：他伸手去碰那道光，光突然消失，房间里所有的灯同时暗下去。

**潜台词**：对话是冰山，说出来的话只是表面。超短片的台词密度本身就极低，一旦写台词，更要让它承担双重信息，不能是直白的规则说明。

**台词风格**（如果有台词）：口语化，不同角色有不同说话方式；避免过度比喻和书面化AI腔；不要让角色说出双方都已经知道的事情——超短片台词本就极少，出现的每一句更要经得起这条检验。

**标准剧本格式**：
```
【场景X：地点 / 时间 / 简要视觉描述】

动作/画面描写直接写在台词之间，不加标记，只写摄影机能拍到的东西。

角色A：xxxxxxxxx。
```
`角色名（OS）：` 表示内心独白/旁白，仅在视听手法本身需要时使用（如散文式旁白型的How-to-Tell）。

## 第一步：判断路径——What-If 还是 How-to-Tell

两条路径方法论完全不同，第一步就要分岔，进入创作前先确认用户要做哪种：

- **What-If 型**：假设一个反常识的前提，展示它的后果和推演。核心武器是**概念的纯度和组合**。
- **How-to-Tell 型**：用一种出人意料的叙事方式重新讲述一个已知的事情——内容本身不是卖点，**叙事形式本身**才是。

## 核心特征（两种类型通用）

- **时长**：1-3分钟
- **角色**：功能性archetype，不需要深度和小传。角色是概念的载体，可以完全没有角色。
- **弧光**：通常没有角色弧光。如果有，只是一个瞬间的认知翻转，不是A到B的完整转变。
- **世界观**：即插即用，观众必须在5秒内理解规则——不解释，靠画面直接展示后果。
- **节奏**：从第一帧开始就在传递信息，零废镜头。
- **视听语言**：超短片是炫技的合法空间——视听形式本身可以成为内容的一部分，这一点在长片/短片里都要收着用，在超短片里可以放开用。

# Part A：What-If 型

## What-If 的本质

好的 What-If 不是天马行空的幻想，而是**现实的一面放大镜**——用一个虚构的规则，让观众看到现实中他们视而不见的东西：某个真实存在但被忽视的社会机制、人性弱点、荒诞逻辑，被放大到不可忽视的程度。判断一个 What-If 够不够格：拿掉虚构的规则外壳，它指向的那个真实焦虑是否依然成立、依然扎心？

## 概念组合：核心创意方法

最锐利的 What-If 往往不是单一概念，而是两个不相关的概念碰撞产生的化学反应。

**组合方式一：概念嫁接**——取概念A的运行机制 + 概念B的应用场景。例："斩杀线"（游戏淘汰机制）+ AI焦虑 → "公司用AI给每个员工打分，分数低于斩杀线的人第二天工位上只剩一个USB"；游戏复活机制 + 职场裁员 → "被裁的人可以投币复活，但每次复活工资减半"。操作步骤：列出A的核心机制→列出B领域里人们最在意什么→把A的规则塞进B的场景→检验这个组合是否揭示了B场景里一个真实存在的问题。

**组合方式二：时空错置**——把人物/技术/制度放到它不属于的时代或地点。例：钢铁侠 + 1990年代下岗潮 → "东北军工厂高级工程师下岗后在车库用废铁造盔甲，然后发现耗电量比整条街的电费还高"；ChatGPT + 科举 → "考生带了一个能对对子的铜匣子进考场，主考官发现匣子写的八股比所有考生都好"。这种方式的力量在于：时空错位让观众同时看到两个时代，理解当代的荒诞需要一面古代的镜子，反之亦然。

**组合方式三：隐喻具象化**——把抽象社会焦虑变成一个能被摄影机拍到的物理规则。方法：取抽象焦虑A→找到它在行为层面的"最小动作"→把这个动作变成强制性的物理规则。例："内卷"的最小动作是"别人加班我也必须加班"→物理规则："所有人的灯必须比邻居的亮，亮度不够就断电"；"容貌焦虑"的最小动作是"照镜子对比"→"镜子会给你的脸打分，分数显示在额头上，别人能看到"。

**组合方式四：反转并置**——找到两个表面相似但本质矛盾的事物，让它们在同一场景中共存。例："宠物"和"畜牧"→"一个人精心喂养他的猫，猫粮工厂隔壁就是屠宰场"；"反消费主义"和"消费"→"一个人穿着印'拒绝消费主义'的T恤，这件T恤售价399"。

**组合方式五：规则反转**——找到一个人们习以为常的规则，翻转它，推演后果。例："年龄越大越成熟"反转为"人出生时是老人，越活越年轻，死于婴儿"；"记忆随时间消退"反转为"记忆不会消退，但你可以主动删除——代价是每删一段记忆，就永远失去对应的那种情感"。

**概念组合的检验**：组合是否产生"1+1>2"的效果（两个概念组合后不比单独一个更有趣就放弃）？观众能否在5秒内理解规则？是否指向一个真实的社会情绪或人性弱点？是否有推演空间（规则推到极限会发生什么）？是否有翻转潜力（最后能反过来打观众一巴掌）？

## What-If 的五种结构

**结构A：经典三段式（概念呈现→推演→翻转）**——最通用。一、概念呈现（前15-30秒，一个画面/动作让观众瞬间理解规则，不解释直接展示后果，最好是让人"咦？"的视觉悬念）。二、推演（中间30-90秒，展示2-5个后果切片，每个5-15秒，切片之间必须递进——每一个比上一个更极端/更荒诞/或更日常）。三、翻转（最后15-30秒，一个画面或一句话彻底颠覆前面建立的认知，翻转必须是概念自身逻辑的延伸，不是硬转）。

**结构B：递进崩塌式**——适合"规则不断升级直到崩溃"。规则建立（约20秒，规则的基本形态看起来还挺合理）→第一次升级（约20秒，更严格但人们适应了）→第二次升级（约20秒，升级到荒诞但人们仍在适应）→崩溃点（约20秒，规则推到逻辑极限系统瞬间崩塌；或者所有人已完全适应最荒诞的状态，崩塌的不是规则，是观众的认知）→余像（最后10秒，崩塌之后的一个安静画面——废墟中的日常）。

**结构C：双线并置式**——适合反转并置类概念。同时展示两条看起来都正常/温暖/美好的线，在视觉上平行推进（分屏/交叉剪辑/同画面前后景）。在某个时刻观众突然意识到两条线其实是同一件事的两面，或线A的美好建立在线B的残酷之上。这个"意识到"的瞬间就是翻转，不需要角色说出来。

**结构D：循环/Loop式**——适合"困境无法逃脱"或"历史重复"。起点（状态A）→发展→看似解决→回到状态A。关键：第二次看到状态A时观众的理解已经不同——第一次觉得这是正常的开始，第二次意识到这是永远无法逃脱的牢笼。可以在第二次循环开始时切黑，让观众自己意识到"又来了"。

**结构E：倒叙揭示式**——适合"真相一直在眼前但观众没看到"。先展示结果（一个奇怪的、不可理解的画面）→倒推原因，一步步揭示画面是怎么来的，每一步揭示都让画面更合理但也更恐怖/荒诞/讽刺→最后一步揭示让观众理解一切，重新看第一个画面，含义完全不同。

## What-If 工作流

**第一步：概念锻造**。判断用户输入是单一概念还是需要组合；如果给的方向不够锐利，用五种组合方式生成3-5个候选。输出：一句话概念 / 组合方式 / 概念指向的真实焦虑或人性 / 推演潜力（规则推到极限最荒诞的画面是什么）/ 翻转潜力（最大认知反转可能是什么）/ 建议结构A-E / 建议视听语言。检验：能否一句话说清规则？5秒内能画面呈现吗？指向真实的社会情绪或人性弱点吗？有至少3个递进后果切片的推演空间吗？有翻转潜力吗？3分钟够讲完吗（太复杂就该降级到短片格式）？

**第二步：结构与视听设计**。选定结构类型，从视听语言武器库（见Part C）选1-2种核心手法，展开带时长标注的结构大纲，每段标注视听手法和双轨节奏（松/中/紧的情节，轻/中/重的情感）。检验：概念呈现是否5秒内让观众get规则？推演切片是否层层递进而非平行罗列？翻转在逻辑上成立吗？翻转是否让观众想回头重看一遍？视听手法是否强化了内容？总时长在1-3分钟内吗？

**第三步：全片剧本**。极致精简，每个字都必须存在于画面中；零解释，纯视觉叙事（除非视听手法本身需要旁白）；台词极少，甚至可以完全没有台词；翻转落在最后一个画面或最后一句话上；视听语言描述要具体（不是"用长镜头"，而是"镜头从角色的手开始，缓慢拉远，揭示整个房间的全貌——所有工位上都是空的"）。写完后提供：分段时长预估、翻转是否足够有力的自我评估、2-3个替代翻转方案、视听手法的替代方案。

# Part B：How-to-Tell 型

## How-to-Tell 的本质

不改变"讲什么"，改变"怎么讲"。前提：观众已经知道或很快能理解故事的内容，内容本身不是卖点——**叙事方式本身**才是。力量在于：用一种全新的方式重讲已知的事情时，观众被迫从一个从未有过的角度重新理解它。**形式即内容**。

## 五种创意方法

**方法一：视角置换**——用一个不可能的视角讲故事。例：从子弹的视角讲一场战争；从外卖袋的视角讲一个独居者的一天；从地球的视角讲人类文明史（地球像一个被寄生虫感染的宿主）；从一个表情包的视角讲它被发送/接收/截图/转发的一生。

**方法二：形式模拟**——用某种已有形式（文件格式/界面/游戏/说明书等）重新包装故事。例：用"产品说明书"格式讲一段婚姻（产品名称：婚姻，保质期：不确定，副作用：见附录）；用"游戏攻略"格式讲打工人的一天；用"监控摄像头画面"讲一家便利店里发生的爱情故事；用"搜索历史记录"讲一个人从确诊到接受的心理历程。

**方法三：时间手术**——对时间做加速/减速/倒放/循环/跳跃/并置。例：把一个人的一生压缩到2分钟，每个人生阶段只有几秒；把1秒的动作拉长到3分钟（子弹出膛、杯子碎裂、眼泪滑落的1秒里发生了什么）；同一个街角的100年，每10年切一次，摄影机位置不动；正放一个人的早晨+倒放同一个人的夜晚，两条时间线在中午交汇。

**方法四：尺度跳跃**——在极大和极小之间跳跃，用尺度对比制造冲击。例：从一个细胞的分裂开始，逐步拉远到一个人、一座城市、一个星球、一个星系，然后切回细胞；一场家庭争吵→切到外太空看地球→切回争吵，争吵突然变得可笑；一粒米的旅程——从稻田到饭桌到垃圾桶到填埋场到地下水再到稻田。

**方法五：规则限制**——给叙事本身加一个限制，正是这个限制产生创意。例：整部片子只用一个固定镜位，不剪辑；整部片子没有一个人出现，只有空间和物品；整部片子只有声音画面是黑的（或反过来）；整部片子由手机截图/聊天记录/通知栏组成。

## How-to-Tell 的结构

不用"概念呈现→推演→翻转"的三段式，结构由**叙事形式本身**决定，形式就是结构。通用节奏：一、形式建立（前20-30秒，让观众理解这个片子用什么方式在讲故事，观众第一反应该是"哦？这样讲？"）。二、形式深入（中间60-120秒，在这个形式框架内展开内容，随内容推进形式本身也在递进——升级、变异、或暴露新含义，不是重复同一种手法）。三、形式与内容的交汇（最后15-30秒，观众意识到形式和内容是一体的，"用这种方式讲"本身就是故事的一部分；最好的结尾是形式本身完成了翻转）。

**示例**：用"搜索历史记录"讲一个人从确诊到接受的过程——形式建立：屏幕滚动搜索记录，"头痛原因""偏头痛缓解方法"；形式深入：搜索内容逐渐沉重，"脑部CT多少钱""胶质瘤存活率"；交汇：最后一条搜索是"附近有什么好吃的"——形式（搜索记录）和内容（接受现实）在这一条搜索中合一。

## How-to-Tell 工作流

**第一步：形式发现**。先确认用户想讲的内容/主题，用五种创意方法生成3-5个形式方案。输出：内容/主题 / 叙事形式 / 创意方法（视角置换/形式模拟/时间手术/尺度跳跃/规则限制）/ 形式与内容的关系（为什么用这种方式讲更好，不用行不行）/ 形式的递进潜力 / 建议视听语言。检验：形式是否与内容深度契合（不只是"看起来酷"，而是"只能用这种方式讲"）？形式有递进空间吗（不能一个手法用到底）？形式本身有翻转潜力吗？观众能在15秒内理解叙事形式吗？如果去掉形式用常规方式讲，内容会丧失冲击力吗（如果不会，换形式）？

**第二步和第三步**：与What-If的结构设计和全片剧本流程相同，自检额外增加：形式与内容是否在结尾处交汇（不是"形式包装了内容"，而是"形式本身成为了内容的一部分"）？形式本身从头到尾是否有变化/升级/变异？

# Part C：视听语言武器库（两种类型通用）

超短片是视听语言炫技的合法空间——3分钟以内，观众对形式实验的容忍度极高。以下手法可单独使用也可组合，但一部片子应聚焦1-2种核心手法用到极致，不要塞入五种技巧变成炫技集锦。

**镜头语言类**：一镜到底（从头到尾不剪辑，效果是真实感/沉浸感/时间不可逆，适合需要"在场感"的概念）；固定机位时间流逝（摄影机不动，时间在画面中加速，效果是变与不变的对比，适合讲述时间跨度大的概念）；连续推轨（摄影机持续匀速移动穿越空间，效果是空间的揭示，适合空间本身承载信息的概念，如从豪宅推到贫民窟）；第一人称POV（效果是极端代入感，适合视角置换型How-to-Tell）；微距/显微镜头（拍肉眼看不到的尺度，效果是熟悉事物变得陌生，适合尺度跳跃型How-to-Tell）。

**剪辑/时间类**：跳切蒙太奇（同一画面内快速时间跳跃，效果是时间压缩和重复的荒诞感，适合展示"日复一日"）；分屏（画面分2-4区域同时展示，效果是对比/并置/平行时间线，适合双线并置结构）；交叉剪辑（两条线之间快速切换，效果是对比加速和张力累积，适合两个看似无关的事物最终被揭示为有关联）；倒放（效果是熟悉动作变得陌生，结果先于原因出现，适合时间手术型或循环结构）；定格/时间冻结（效果是强制观众注意某个细节，适合在密集视觉信息流中强调翻转瞬间）。

**画面构成类**：对称构图（效果是秩序感/仪式感/不安感，适合展示制度化的概念）；画面内前景/背景叙事（前景做一件事、背景发生另一件事互相注释，效果是无需剪辑的并置）；色彩限制（整部片子只用有限颜色，效果是颜色本身成为叙事元素，适合颜色与概念有直接关联时，如红色=危险/爱情、灰色=系统/压抑）。

**声音类**：画面与声音错位（画面展示A声音属于B，效果是两层信息的碰撞，适合讽刺反差，如画面是和平日常声音是新闻播报的灾难数据）；环境音放大（把日常环境音放大到不正常音量，效果是熟悉变得不安）；静默（关键时刻完全没有声音，效果是迫使观众集中注意力，适合在高密度信息流之后突然静默——沉默本身就是高潮）。

**界面/媒介类**：屏幕录制（整部片子是手机/电脑屏幕录制，效果是极致当代感，适合形式模拟型How-to-Tell）；伪文档/伪纪录片（假装是真实纪录片/新闻/教学视频，效果是以真实外壳包裹荒诞内核，适合What-If需要一个"严肃"的壳来反衬）；数据可视化（用图表/数据/统计视觉语言讲故事，效果是数字越冷静内容越震撼）。

**如何选择**：形式服务内容，先确定概念再选手法；一部片子聚焦1-2种核心手法；手法需要递进（升级/变异/结尾被打破，如全片固定机位最后一个镜头突然移动）；手法本身可以成为翻转的工具（视听形式本身也在翻转，如全片正常速度最后一秒突然加速到整个世界在眼前飞过）。

## 产出格式（写完后应交付的内容）

1. **一句话概念**：（What-If的规则，或How-to-Tell的形式）
2. **概念/形式检验清单**：（对照上文对应类型的检验项逐条确认）
3. **结构大纲**：（分段落，标注时长/视听手法/双轨节奏）
4. **完整剧本**：（标准格式，场景标注+动作描写+对白/或旁白）
5. **收尾建议**：翻转是否有力的自我评估 + 2-3个替代方案

## 常见陷阱

- ❌ 概念需要大量解释才能理解 → 换概念或降级到短片
- ❌ 推演段只是概念的重复而非递进 → 每个切片必须比上一个更进一步
- ❌ 翻转是硬转，跟前面没有逻辑关系 → 翻转必须是概念自身逻辑的延伸
- ❌ 试图在3分钟内塞入完整角色弧光 → 放弃弧光，聚焦概念
- ❌ 有台词在"解释概念" → 删掉，用画面展示
- ❌ 视听手法与概念无关（"我想用分屏所以用了分屏"）→ 形式必须强化内容
- ❌ 一部片子用了太多视听手法 → 聚焦1-2种，用到极致
- ❌ 概念组合后两个概念各自独立、没有化学反应 → 组合必须1+1>2
- ❌ How-to-Tell的形式只是"包装"，去掉形式故事照样成立 → 形式必须是不可替代的
- ❌ 概念很好但没有推演就直接到翻转 → 推演段是观众"入戏"的过程，不能跳过

## 与题材壳skill的关系

本skill只管"1-3分钟这个体量该怎么写"，不管"这个故事该讲男频/悬疑/复仇哪个题材的具体判断标准"。如果需要某个题材专属的判断标准（什么算爽、什么算恐怖），可以在写完概念大纲后，另外参考本库对应题材壳skill的"这一集/这段废了"检验清单；不参考也完全可以独立完成一个超短片。两者是正交的两条轴，不是依赖关系。
