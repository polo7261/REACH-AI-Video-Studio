## 一、品類分類（從上傳的產品識別品類，拿預設）

每個品類附「節奏基調 / 產品出現時機 / 單鏡時長」三個欄位（詳見下方節奏表），定品類即一併拿到。注意：「單鏡時長」指的是**一個 clip 內部**各鏡頭的建議時長（供模型在這一個 15s clip 內自動切分參考），**不是**讓你按這個時長逐鏡發起生成。

美妝 / 護膚 — 特點：微距特寫、質地流動、膚感光澤、面部情緒、奢華氛圍；預設創意手法：演示 + 情感；節奏：中·漸入 / 產品第 3–5s / 單鏡 2–3s；品牌：Dior、SK-II、La Mer

奢侈品 / 時尚 — 特點：電影短片式敘事、藝術化構圖、極簡主義、大量留白；預設創意手法：故事 / 情感（視聽奇觀風格）；節奏：慢·留白 / 產品第 4–6s / 單鏡 3–5s；品牌：Hermès、Chanel、Prada

食品 / 飲料 — 特點：食慾感特寫、液體流動、蒸汽/水珠、高飽和、節奏明快；預設創意手法：演示 + 情感；節奏：快·卡點 / 產品第 1–3s / 單鏡 1–2s；品牌：Coca-Cola、McDonald's

科技 / 電子 — 特點：產品懸浮、360° 環繞、暗調+霓虹光、未來感、介面動畫；預設創意手法：演示 + 動畫；節奏：中快·精準 / 產品第 2–4s / 單鏡 1.5–2.5s；品牌：Apple、Samsung、Sony

酒類 / 香氛 — 特點：慢動作、光影折射、液體質感、氛圍感優先於功能；預設創意手法：情感（視聽奇觀風格）；節奏：慢·氛圍 / 產品第 4–6s / 單鏡 3–5s；品牌：茅臺、Chivas、Jo Malone

運動 / 戶外 — 特點：高速攝影、極限場景、汗水/肌肉特寫、勵志情緒；預設創意手法：情感 / 故事；節奏：極快·衝擊 / 產品第 1–2s / 單鏡 0.5–1.5s；品牌：Nike、Adidas、The North Face

汽車 — 特點：大場景、航拍、速度感、極致光影、lifestyle 敘事；預設創意手法：故事（視聽奇觀風格）+ 演示；節奏：慢起漸快 / 產品第 3–5s / 單鏡 2–4s→收快；品牌：BMW、Mercedes、Tesla

金融 / 保險 — 特點：家庭場景、溫情敘事、信任感、穩重調性；預設創意手法：故事 + 情感；節奏：中·溫情 / 產品視情節 / 單鏡 2–4s；品牌：平安、Prudential

地產 / 酒店 — 特點：航拍全景、室內光影、生活方式想象、空間感；預設創意手法：情感 / 故事；節奏：中·舒展 / 空間即產品 / 單鏡 2.5–4s；品牌：萬科、Four Seasons

定了品類即拿到：預設特點 + 建議創意手法 + 一組旋鈕預設檔位（見第三節括注）+ 節奏三欄位（見第五節節奏表）。客戶有特殊要求再覆蓋預設。

> 品類名裡的真實品牌僅作**抽象風格描述**用（說明這類廣告長什麼調性），成片不得復現任何特定品牌真實 campaign 的可識別元素（標誌性佈景、專屬視覺符號、真實 slogan/logo），logo 一律換成產品自有 logo。

## 二、五個維度（與使用者對話逐項確認）

TVC 商業廣告片的 5 個維度。定品類後多數已有預設值，對話只需補齊/修正，不重複問已知項。

1. 廣告目的：產品 · 品牌 · 形象 · 促銷 · 公益 → 決定資訊密度與收尾落點：促銷=強 CTA；品牌/形象=logo 收尾；產品=賣點+CTA。

2. 創意手法（＝ prompt 生成骨架）：故事 · 情感 · 演示 · 動畫

   故事：完整劇情，建立 → 衝突 → 解決，產品融入情節。

   情感：情緒弧打動人，建立人物/處境 → 情緒高點 → 產品作為解法 → 落主張。用 {{Mixed N}} 鎖角色。

   演示：賣點直給，痛點/場景 → 產品登場 → 一鏡一賣點 → 效果呈現 → logo + CTA。產品每鏡清晰。

   動畫：二維 / 三維 / 定格，風格鎖定句寫最前，風格一致 &gt; 角色一致。

   「視聽奇觀 / 時尚片」不是單獨手法，而是高製作美學風格（運鏡密集、美學優先、慢動作、大量留白），常疊加在 故事/情感/演示 上（奢侈、美妝、汽車），靠第三節拆解要素堆出來。

3. 影片時長：15s · 30s · 60s → **決定 clip 數（15s=1 clip / 30s=2 clips / 60s=4 clips）**，並觸發生成分流（見工作流 Step 3）。每個 clip 內部再由模型按節奏自動切分鏡頭（15s≈4–5 鏡 / 快節奏 6–8 鏡），**這是 clip 內部的事，不是拆成獨立生成任務**。

4. 製作方式：實拍 · 動畫 · CG 合成 · 混剪 → 決定風格鎖定句基底：實拍=電影感商業片基底；動畫/CG=對應風格鎖定句。

5. 投放場景：TV · OTT · 社媒豎屏 · 戶外大屏 → 決定畫幅與節奏：TV/OTT=16:9；社媒豎屏=9:16 且前 3 秒更狠；戶外大屏=強視覺、弱依賴聲音。需要時一稿出雙版。

## 三、拆解要素（7 個旋鈕 · 選項選單）

每個維度選一檔；斜體括注是「按品類預設」。

1. 燈光設計

   光源：自然光 / 棚拍人工光 / 混合光

   方向：順光 / 側光 / 側逆光 / 逆光 / 頂光 / 底光

   布光：主光 Key、輔光 Fill、輪廓光 Rim/Edge、背光 Backlight、髮絲光、體積光/丁達爾 Volumetric、美妝光 Beauty dish、入畫實用光源 Practical

   色溫：冷調(藍白) / 暖調(金橙) / 中性 / 冷暖對撞

   特殊光效：霓虹、RGB 染色、耀斑 lens flare、折射光斑、流動光帶、頻閃

   預設：妝/食=柔光通透暖調；科/汽=暗調 Rim+霓虹；奢=自然窗光；金/地=暖柔自然光

2. 畫面色調

   色溫：暖調 / 冷調 / 中性 / 冷暖分離 split-tone

   色調：film-scan 自然膠片色、teal-orange 電影調、復古褪色、日系清新、莫蘭迪低飽和、賽博霓虹、黑白

   飽和度：高飽和 / 標準 / 低飽和 / 去色單色

   質感疊加：膠片顆粒、漏光 halation、柔光暈、故障噪點

   預設：食=高飽和暖；奢/時尚=低飽和 film-scan；科=冷藍暗調；汽=teal-orange

3. 鏡頭語言

   運鏡：固定、推/拉、搖 pan、移 dolly、升降 crane、環繞 orbit、跟拍 tracking、手持、穩定器、FPV 穿越

   景別：微距/大特寫、特寫、近景、中景、全景、大遠景、航拍

   角度：平視、仰拍、俯拍、頂視平鋪、荷蘭角(傾斜)

   構圖：居中對稱、三分法、框架式、大量留白、滿構圖、前景遮擋

   鏡頭特性：廣角畸變、長焦壓縮、移軸微縮、魚眼

   預設：妝/科=微距+orbit；汽/運=航拍+tracking+FPV；奢=留白+緩推；食=頂視+升格微距

   補充運鏡（按用途分組 · 視聽語言更豐富）

   A. 動感/衝擊類（適合 食/運/科/促銷）

   - 速度變化 speed ramp：正常速→突然升格→再回速，卡點神器
   - 甩鏡 whip pan：快速橫甩轉場，兩鏡之間「唰」一下
   - 推入接特寫 push-in to macro：一鏡從中景懟進產品微距
   - 彈動變焦 snap zoom：焦距猛地一頓，強調瞬間
   - FPV 穿越：一鏡穿過場景/產品內部，沉浸感拉滿

   B. 精密/展示類（適合 科技/美妝/產品 hero）

   - 產品環繞拆解：半環繞 + 部件逐個高亮（治「只懟 logo」）
   - 頂視平鋪 flat-lay + 升降：俯拍產品陣列，配升降揭示
   - 軌道橫移 dolly/slider：平滑側移掃過產品排列
   - 微距滑軌：貼著產品表面/質地緩移
   - 對焦轉移 rack focus：前景虛→實，把視線引到產品

   C. 情緒/電影感類（適合 奢/酒/汽/金融）

   - 緩慢推近 slow push-in：一點點逼近人物/產品，凝聚情緒
   - 升降鏡 crane up/down：垂直運動帶出場面或收束
   - 手持微晃 subtle handheld：紀實感、貼近真實（金融/生活流）
   - 反打/過肩：人物互動、對視，建立關係
   - 航拍環繞 aerial orbit：大場景氣勢（汽車/地產）

   D. 轉場/銜接類（替代疊畫）

   - 匹配剪輯 match cut：形狀/動作/顏色對齊，兩鏡無縫
   - 動作銜接 action match：上鏡的動作在下鏡接著完成
   - 遮擋轉場 whip/物體擦過：物體掃過鏡頭切下一場

   以上每種運鏡仍要帶上運動質量約束（運鏡絲滑、不掉幀、環繞/360/旋轉類放慢勻速）。

4. 音效音樂

   音樂風格：管絃史詩、電子、流行、嘻哈、lo-fi、爵士、民謠、無音樂留白

   音樂功能：驅動卡點 beat-synced、氛圍鋪底、情緒烘托

   音效 SFX：產品 ASMR(咬/倒/滋滋/噴霧)、環境音、擬音 foley、機械音、轉場 whoosh、UI 提示音

   人聲：男/女聲旁白 VO、對白、群聲、無人聲

   混音：空間混響、靜音留白、低頻氛圍 drone

   預設：食=ASMR+明快；科/汽=電子+機械音；奢=稀疏器樂；金=溫暖絃樂+旁白

5. 剪輯節奏

   切換速度：快切、中速、慢長鏡、一鏡到底

   節拍：卡點踩鼓點、自由敘事節奏

   轉場：硬切、淡入淡出、匹配剪輯 match cut、遮擋甩切 whip、跳切 jump cut、液體/光效轉場（禁止疊畫/疊化）

   時間處理：正敘、倒敘、平行剪輯、蒙太奇、定格強調

   特殊手法：定格 freeze frame、變速 speed ramp、故障 datamosh

   預設：食/運/促銷=快切卡點；奢/酒=慢長鏡；汽=慢起漸快

6. 演員模特

   有無人物：有人 / 無人(純產品) / 僅手部或區域性

   人群定位：年輕、都市白領、家庭多代、兒童、運動人群

   氣質風格：高階冷感、親和溫暖、力量運動、潮酷街頭、清純鄰家

   多元：本土、國際化混搭、多元族裔

   表演基調：剋制寫實、生活流、戲劇誇張（表情務必自然可信，禁止誇張怪異表情）

   情緒焦點：面部微表情、眼神、肢體動作、互動關係

   服裝（按品類）：貼合品類調性——美妝 = 有一定露膚度但不暴露、時尚大氣簡約、顏色不跳脫；奢侈/時尚 = 高階極簡；運動 = 機能運動裝；金融/地產 = 得體生活裝

   預設：妝=高階臉+面部微表情+皮膚光澤是重點；運=運動員+肢體；金/地=多代家庭；科/酒=常無人

7. 故事型別

   敘事型別：強敘事(完整劇情) / 弱敘事(氛圍奇觀串聯) / 無敘事(純展示)

   結構：三段式、線性、非線性蒙太奇、單點演示、問題—解決

   視角：第一人稱、旁觀者、產品視角、多線並行

   題材原型：生活片段、英雄旅程、before/after 對比、證言代言、演示 demo、品牌宣言 manifesto

   落點收尾：logo 定版、產品 hero、主張字幕、CTA

   預設：金/保險=溫情三段式；運=英雄旅程；妝/科/酒=弱敘事；食=生活片段或純展示

## 四、鏡頭節奏（治「太慢/產品出太晚/切換生硬」）

> 以下節奏規則規範的是**一個 15s clip 內部**的鏡頭編排（鏡頭數、單鏡時長、產品出現時機），供模型在這一個 clip 內自動切分參考。它**不改變生成粒度**——生成單位永遠是整段 15s clip，不是單鏡。

通用節奏原則（不分品類）

第一鏡禁止純場景空鏡：有模特 → 第一鏡必須是模特在場景裡（人 + 環境同框，可帶動作）；無模特（純產品）→ 第一鏡可用氛圍/懸念開場，但第二鏡必須出現產品。

前 3 秒必須出鉤子，產品最晚在第 5–8 秒露臉（促銷/演示型第 3 秒就要見產品）。

一個 15s clip 內控制在 4–6 個鏡頭，單鏡別超 3–4 秒；快節奏品類（食/運/科/促銷）一個 clip 內必須 6–8 鏡（見下方硬規則）。

景別按「跳三級」切（大遠景→中景→大特寫），別在相鄰兩級之間小碎步挪，切換才不肉、不生硬。

硬切為主，禁疊畫/疊化；需要順滑就用匹配剪輯 match cut 或動作銜接 action match，不用溶解。

分品類節奏表（均指單個 15s clip 內部）

品類 ｜ 節奏基調 ｜ 產品出現 ｜ 單鏡時長 ｜ 情緒帶動手法

食品/飲料 ｜ 快·卡點 ｜ 第 1–3s ｜ 1–2s ｜ 咬/倒/滋滋音效卡拍點，升格+驟停製造饞感

美妝/護膚 ｜ 中·漸入 ｜ 第 3–5s ｜ 2–3s ｜ 慢起→質地特寫→睜眼對視→收束到光澤落點

科技/電子 ｜ 中快·精準 ｜ 第 2–4s ｜ 1.5–2.5s ｜ 硬切+機械音效同步，功能一鏡一賣點

運動/戶外 ｜ 極快·衝擊 ｜ 第 1–2s ｜ 0.5–1.5s ｜ 高速攝影+速度變化 speed ramp 推腎上腺素

汽車 ｜ 慢起漸快 ｜ 第 3–5s ｜ 2–4s→收快 ｜ 大場景鋪氣勢→細節切近→尾段加速點燃

奢侈/時尚 ｜ 慢·留白 ｜ 第 4–6s ｜ 3–5s ｜ 長鏡+緩推，靠氛圍和留白養情緒，不追快

酒類/香氛 ｜ 慢·氛圍 ｜ 第 4–6s ｜ 3–5s ｜ 慢動作光影折射，液體質感鋪沉浸感

金融/保險 ｜ 中·溫情 ｜ 視情節 ｜ 2–4s ｜ 生活片段敘事，情緒弧遞進，產品作解法

地產/酒店 ｜ 中·舒展 ｜ 空間即產品 ｜ 2.5–4s ｜ 航拍舒展→室內光影→生活方式想象

快節奏品類硬規則（強約束 · 食品/飲料、運動/戶外、科技/電子，以及任何品類的促銷目的）：

一個 15s clip 內必須 6–8 鏡（不是 4–6），單鏡一律 ≤ 2s（運動/戶外 ≤ 1.5s），不允許出現超過 2.5s 的鏡頭（收尾產品定版鏡除外，且也不超過 3s）。

一個 clip 的分鏡裡必須用上至少 2 種動感運鏡/切換（speed ramp、whip pan、snap zoom、push-in to macro、卡點硬切、action match 任選），不能整條都是緩推/固定鏡。

禁止「緩慢推近」「緩緩」「悠然」這類慢詞主導快節奏品類的分鏡；鏡頭動詞用「猛推」「疾切」「甩至」「瞬間懟近」等快詞，讓模型生成的畫面動勢跟上。

每鏡必須有明確動作發生（倒、咬、開、跑、亮、彈），不允許靜態擺拍鏡連排。

寫完一個 clip 的分鏡自查一遍總鏡數 × 單鏡時長 ≈ 15s，湊不齊鏡數就說明節奏太慢，回去拆鏡（**在這一個 clip 的 prompt 內多寫幾鏡，不是拆成多個生成任務**）。

核心：該快的品類（食/運/科/促銷）把產品和鉤子往前提、單鏡壓短、卡點切；該慢的品類（奢/酒）保留長鏡留白，但也要有情緒落點、不能平。

## 工作流

### Step 1 · 生成產品三檢視 + 同時彈出合併詢問卡

使用者上傳產品圖（或產品描述 / 參考片）。識別品類（第一節）、形態/材質/賣點、是否需要 {{Mixed N}} 角色，拿到品類即帶出預設特點 + 建議創意手法 + 旋鈕預設檔位 + 節奏三欄位（第四節）。

① 生成產品參考圖（貼合產品，建議 GPT Image 以保真；白底、16:9）作一致性錨點：

產品三檢視 {{產品三檢視}}：正面 / 側面 / 背面。生成後固定命名為「產品三檢視」，供 Step 3 的 @產品三檢視 直接掛用。

產品細節三檢視 {{產品細節圖}}：按功能性取關鍵細節（榨汁機 = logo / 刀片 / 按鍵；護膚品 = 瓶身 / 泵頭 / 質地）。生成後固定命名為「產品細節三檢視」，供 @產品細節三檢視 掛用。

後續分鏡產品畫面一律以這兩張為準。

地產 / 酒店等"空間即產品"：無實體產品，改為上傳或虛擬生成 5–8 張實景圖 {{空間實景}}（虛擬生成按 16:9），替代產品三檢視併兼作場景錨點。

反推參考片：先 scripts/extract\_[frames.sh](http://frames.sh) 抽幀讀規格，再產同款；**按 15s 一個 clip 整段生成，30s / 60s 拆成 2 / 4 個 15s clip（每個 clip 的 prompt 一次寫全、整段生成），絕不拆成很多單鏡逐個生成。**

② 生成三檢視的同時，立刻彈出一張 ask_human 合併詢問卡（不等圖生成完，節省時間），一次問全（品類已給預設的只需確認 / 修改，留"你幫我定"；"全你定"就按預設走完）：

時長：15s / 30s / 60s（→ 對應 1 / 2 / 4 個 15s clip）

廣告目的：產品 / 品牌 / 形象 / 促銷 / 公益

製作方式：實拍 / 動畫 / CG 合成 / 混剪

創意手法：故事 / 情感 / 演示 / 動畫（可疊加視聽奇觀 / 時尚片風格）

投放場景：TV / OTT / 社媒豎屏 / 戶外大屏（據此定畫幅 16:9 或 9:16）

品牌 slogan：有則填（結尾落點用）

旁白：要不要 + 人聲（男 / 女 / 中性 + 風格）+ 旁白語言二選一（中文 / 英文）；一律後期配音（影片靜音生成）

字幕：無 / 單語（哪種語言）/ 雙語（主 + 副兩種）

選模特形象（若有模特）：給 3 個選項 =「族裔/地域 + 年齡 + 性別 + 髮型」（先不含穿著）；純產品則跳過

選場景氛圍：給 3 個文字選項（場景 + 色調 + 燈光 + 質感 綜合成一句），挑 1

選風格種子：只顯示中文風格名（藍橙調電影風 / 高階中性色電影風 / 高飽和復古暖藍調 / 日系電影風），絕不暴露程式碼

是否上傳服裝參考圖：有則上傳（後續角色三檢視用 GPT Image 2 還原）

（各維度含義見第二、三節；旁白文案在 Step 3 出片前寫出、給使用者確認。）

### Step 2 · 出 moodboard（場景氛圍圖 + 服裝圖並行生成 · 需使用者確認）

詢問卡答完後，場景氛圍圖與服裝圖同時生成（並行，節省時間）：

場景氛圍圖（必須用 Midjourney v8.1）：把選定場景氛圍擴寫成具體描繪（只寫場景/環境，畫面不出現產品）作 MJ prompt，末尾拼上選中風格種子程式碼，並加 --v 8.1 版本引數；MJ 預設出 4 張可挑。風格種子對映：

藍橙調電影風 → --sref 1998077430

高階中性色電影風 → --sref 1804771136

高飽和復古暖藍調 → --sref 2498372592

日系電影風 → --sref 1998077430

> 風格種子僅用可公開復用的數字 --sref，不繫結任何個人 --profile 賬號檔案；如需專屬風格請換成自己賬號的 profile。

服裝圖（若有模特，必須用 GPT Image 2）：每人一張【白底、全身展示、16:9】、含 4 套全身 look 的圖，據角色設定 + 品類要求用 GPT Image 2 生成（與場景氛圍圖並行出，不互相等待）；若產品是可穿戴（衣/鞋/包/帽/鏡/飾品/表），4 套 look 均以該產品為核心搭配（look = 產品 + 配搭單品，產品以 @產品三檢視 為準還原）。

使用者選定場景氛圍圖 + 選定第幾套 look 後：

角色三檢視（每人一張；白底；16:9；必須用 GPT Image 2 生成，以保證形象/服裝還原一致）：按選定形象 + 選定 look 生成，參考服裝圖並講清第幾套 look（如"採用服裝圖中第 2 套"）；從左到右 面容特寫 ｜ 全身正面 ｜ 全身背面，鎖定形象作 {{Mixed N}} 錨點；若上傳了服裝參考圖，同樣用 GPT Image 2 按參考圖還原。表情自然不奇怪。

可穿戴產品（衣服 / 鞋 / 包 / 帽 / 眼鏡 / 首飾 / 手錶等穿戴在身的產品）：角色三檢視裡模特直接穿上 / 背上 / 戴上該產品（以 @產品三檢視 為準還原產品外觀），產品上身效果與人物形象一次性鎖進同一張錨點圖——後續分鏡裡"人 + 產品"的同框狀態以這張人物三檢視為準；服裝圖的 4 套 look 也要圍繞該產品搭配（look = 產品 + 配搭單品），不與產品調性打架。產品單獨特寫鏡仍以 @產品三檢視 / @產品細節三檢視 為準。

生成後固定命名為「人物三檢視」（多角色為「人物三檢視1 / 人物三檢視2…」），供 Step 3 的 @人物三檢視(N) 直接掛用。

使用者確認視覺方向後鎖定，再進入下一步——後面分鏡嚴格按選定的模特、場景來寫；使用者選定的那張場景氛圍圖固定命名為「場景氛圍圖」（空間品類實景圖命名為「空間實景」），供 @場景氛圍圖 / @空間實景 掛用。moodboard 是出 prompt 前的把關閘口，也是 @ 錨點的定名閘口。

### Step 3 · 出分鏡 prompt → 滿意即生成 → 合成成片 → 自動生成字幕

① 時長分流（以 15s 為一個 clip · 生成粒度鐵律）

**生成單位 = 一個 15s clip。** 一個 clip = 一條完整連續 prompt（內部含編號分鏡，交給模型在這一個 clip 內自動切分）。

- **15s = 1 個 clip**：一條 prompt 整段直出。
- **30s = 2 個 clip**：寫 2 條 prompt（前後內容不同、不重複，logo 只在第 2 個 clip 結尾）。
- **60s = 4 個 clip**：寫 4 條 prompt（內容各不重複，logo 只在第 4 個 clip 結尾）。

**嚴禁逐鏡生成（強規則）**：編號鏡頭「鏡頭1 / 鏡頭2 / 鏡頭3…」只是**一個 clip 內部**給模型看的分鏡指令碼，**絕不允許把每個鏡頭當成一次獨立生成任務一個個去生成**；每個 15s clip 只發起**一次**生成、一次產出整段 15s 畫面（內部多鏡由模型自動切分與銜接）。凡是「一個鏡頭一個鏡頭生成」「按鏡頭逐條呼叫 Seedance」都是錯的。

**多 clip 並行生成（強規則）**：多個 clip 的 prompt 一次性全部寫完、一併給使用者確認，確認後所有 clip 同時呼叫 Seedance 2.0 並行生成——不等第 1 個 clip 出片再生成後續。（若使用者明確要求逐 clip 確認再續，可改為逐 clip 生成，但**單位始終是整段 15s clip，絕不降到單鏡**。）

**並行/多 clip 下的段間一致性**：不依賴末幀續接，改由錨點承載——各 clip 的 prompt 引用同一 {{場景氛圍圖}} / {{產品三檢視}} / 角色三檢視，並寫明同一 {{Mixed N}}、同一服裝（第幾套 look）、同一光線時段；clip 間銜接靠寫 prompt 時預先設計好首尾鏡頭的動作/景別呼應，不穿幫。

② 輸出格式（中文編號分鏡 · 一條 prompt = 一個 15s clip）

開頭固定句（每條 prompt 第一句原樣寫，不得改動措辭）：參考@場景氛圍圖作為場景、影調參考，參考@人物三檢視作為人物主體，參考@產品三檢視、@產品細節三檢視作為產品參考。 —— 按實際情況裁剪引用物件：無模特則去掉「參考@人物三檢視作為人物主體，」；地產/酒店等空間品類把場景引用改為「參考@空間實景作為場景、影調參考」且每鏡須在實拍場景內、不得虛構空間；多個角色寫 @人物三檢視1、@人物三檢視2。除此之外句式與用詞固定不變。

@ 引用必須實掛錨點（強約束）：每個 @名稱 都必須真實繫結到前面步驟已生成、且使用者已確認的對應錨點圖——@場景氛圍圖 = Step 2 使用者選定的那張場景氛圍圖；@人物三檢視(N) = Step 2 生成的角色三檢視（第 N 位角色）；@產品三檢視 / @產品細節三檢視 = Step 1 生成的兩張產品參考圖；@空間實景 = Step 1 的實景圖。呼叫 Seedance 2.0 時把這些圖作為參考圖隨 prompt 一併掛上，@名稱 與掛圖一一對應、名稱完全一致。出 prompt 前先核對：句中引用的每個錨點都已生成且已確認——缺哪張就先回對應步驟補生成，絕不允許 @ 一個不存在的圖空引用。多 clip 並行生成時，所有 clip 掛同一套錨點圖。

場景由圖承載，正文不再用文字描述場景氛圍 / 環境 / 色調（否則與圖引用互斥）；正文只寫品質鎖定（電影感 / 廣告級）+ 主體 / 動作 / 鏡頭 / 產品。人物與產品同理：形象以 @人物三檢視 為準、產品以 @產品三檢視 / @產品細節三檢視 為準，正文不再重複描述人物長相與產品外觀。

**每個 clip 內部**按 鏡頭1 / 鏡頭2 / 鏡頭3… 編號，每鏡寫明 景別 + 運鏡 + 內容（{{Mixed N}} 或產品的動作與畫面）。**這些編號只是這一個 clip 交給模型的內部分鏡，整段一次生成，不逐鏡發起。**

節奏落地：一個 clip 內的鏡頭數量、單鏡時長、產品出現時機按第四節該品類節奏表來；景別跳三級切、硬切為主、禁疊化。快節奏品類（食/運/科 + 促銷目的）每個 clip 必須執行第四節「快節奏品類硬規則」：一個 15s clip 出 6–8 鏡、單鏡 ≤ 2s、至少 2 種動感運鏡、鏡頭動詞用快詞、每鏡有動作。

第一鏡規則：每個 clip 的第一鏡不得是純場景空鏡——有模特必須是模特在場景裡；無模特則第二鏡必須出現產品。

人物運動速度：人物動作按正常速度自然運動，禁止無故慢動作、遲緩漂浮感；升格/慢動作只用於明確設計的強調鏡頭（如質地拉絲、水花定格），並在該鏡寫明，其餘鏡頭一律正常速度。

運動質量句（每條 clip prompt 末尾固定加）：運鏡絲滑流暢、幀率穩定連貫、不掉幀、不卡頓、不抖動、自然動態模糊；人物動作正常速度、自然流暢，不遲緩；環繞 / 旋轉放慢勻速。鏡與鏡不跳幀、不越軸（守 180° 軸線）。

禁止生成背景音效（每條 clip prompt 固定寫明）：影片靜音生成，不自動生成任何背景音效 / 環境音；音樂、音效、旁白全部留到 ④ 後期。

旁白文案在此寫出給使用者確認（按選定旁白語言：中文或英文撰寫）；旁白一律留到 ④ 後期配音。

③ 滿意即生成

中文 prompt 輸出、使用者確認後直接呼叫 Seedance 2.0 生成影片，不需手動貼上；**每次呼叫生成一個完整 15s clip（不逐鏡）**，呼叫時把開頭固定句引用的全部錨點圖（場景氛圍圖 / 人物三檢視 / 產品三檢視 / 產品細節三檢視，或空間實景）作為參考圖隨 prompt 一併掛上，@名稱 與圖一一對應；30s / 60s 的多 clip prompt 一次性全部確認、所有 clip 同時並行生成（不逐段等待、更不逐鏡，各 clip 掛同一套錨點圖），出片後一起給使用者過目。

④ 合成成片 → 自動生成字幕

拼接：30s / 60s 的多個 15s clip 按順序拼接，統一畫幅幀率、處理 clip 間銜接；15s 單 clip 直接成片。

配樂（一律後期生成）：影片靜音、無背景音效，音樂後期加——拼片後生成一段，時長嚴格匹配成片、依實際節奏與調性（食 / 運 / 促銷卡點 beat-sync，奢 / 酒 / 香氛鋪底，金 / 地溫暖器樂）。

旁白後期配音：按選定人聲 + 選定旁白語言（中文 / 英文二選一）用 TTS / 配音生成，對齊畫面混入；旁白文案按選定語言撰寫並已在 ② 給使用者確認。

合成完成後自動進入下一步生成字幕（無需使用者再觸發）：按 Step 1 卡的字幕選擇疊加字幕（無 / 單語 / 雙語），並在結尾疊品牌 slogan / logo 落點，輸出最終成片。

## 完整範例（美妝/護膚 · 演示+情感 · 15s = 1 個 clip · 9:16）

```

鏡頭3｜特寫／橫移：膏體沿其顴骨滑過，留下水潤光澤，塗抹動作正常速度。
鏡頭4｜面部特寫／緩慢推近：她睜眼望向鏡頭，露出自信的微笑。
```

## 通用約束

出 prompt 前請對照文末《輸出前自檢清單》逐項自檢（即下列約束的清單版）。

- 每條 prompt 中文交付；使用者確認後直接呼叫 SD2 生成、不需手動貼上。
- **生成粒度鐵律**：**一條 prompt = 一個 15s clip = 一次生成**；15s=1 clip、30s=2 clips、60s=4 clips；編號分鏡只是單個 clip 內部分鏡、交模型自動切分；**絕不逐鏡生成 / 絕不單鏡頭逐個生成**。30s / 60s 多 clip prompt 一次寫全、一併確認、所有 clip 並行生成（如使用者要逐 clip 確認可逐個生成，但單位仍是整段 clip）。
- 角色用 {{Mixed N}}，首現寫全、後續複用、主賓清晰；演示型確保產品每鏡清晰。
- 各 15s clip 之間（並行生成，不逐段續接），務必靠共同錨點（同一 {{場景氛圍圖}} / {{產品三檢視}} / 角色三檢視）保持 {{Mixed N}}、服裝、場景、光線一致，clip 間首尾鏡頭在寫 prompt 時預先設計呼應，銜接不穿幫。
- 開頭固定句（強約束）：每條影片 prompt 第一句原樣寫「參考@場景氛圍圖作為場景、影調參考，參考@人物三檢視作為人物主體，參考@產品三檢視、@產品細節三檢視作為產品參考。」（無模特去掉人物段；空間品類改 @空間實景；措辭其餘固定不變）。每個 @名稱 必須實掛前面步驟已生成、使用者已確認的對應錨點圖，呼叫 Seedance 時隨 prompt 一併掛上、名稱一一對應；禁止空引用不存在的圖，缺圖先回對應步驟補生成。場景/人物/產品全部由引用圖承載，prompt 正文不再用文字描述場景氛圍 / 環境 / 色調 / 人物長相 / 產品外觀（避免與圖引用互斥）；對錯以選定圖為準。
- 實拍場景（地產 / 酒店等）：用實拍圖的品類，開頭固定句改引用 @空間實景，最終 prompt 的每個鏡頭都必須基於 @空間實景 實拍場景，不得另造虛構 / 想象的空間。
- 人物表情務必自然可信，禁止誇張怪異表情。
- 第一鏡規則：每個 clip 的第一鏡禁止純場景空鏡——有模特時第一鏡必須是模特在場景裡（人 + 環境同框）；無模特（純產品）時第二鏡必須出現產品。
- 人物運動正常速度：人物動作按現實正常速度自然運動，不能遲緩、漂浮、無故慢動作；升格/慢動作僅限明確設計的強調鏡頭並寫明，其餘鏡頭正常速度。
- 禁止疊畫 / 疊化轉場。
- 禁止粒子特效（太土）；要做奇觀或轉場，改用乾淨的光效或材質質感。
- 可穿戴產品（衣/鞋/包/帽/鏡/飾品/表）：模特在角色三檢視階段就直接穿戴該產品（以 @產品三檢視 還原），產品上身狀態鎖進 @人物三檢視 錨點；分鏡中人物同框鏡的產品穿戴狀態以 @人物三檢視 為準，產品單獨特寫鏡以 @產品三檢視 / @產品細節三檢視 為準，兩者不得衝突（同一件、同一配色）。
- 無模特（純產品）時：運鏡要豐富（多角度、環繞、推拉、微距），不要不停懟 logo；要展示產品的方方面面（如手機 = 鏡頭 / 螢幕 / 邊緣；墨鏡 = 鏡腿 / 鏡片 / 人物佩戴效果），logo 只在收尾落點出現。
- 節奏與切換：一個 clip 內的鏡頭數量、單鏡時長、產品出現時機按第四節該品類節奏表控；景別按「跳三級」切（不在相鄰兩級碎步挪），硬切為主，需要順滑用 match cut / action match，禁疊畫/疊化。快節奏品類（食/運/科 + 促銷目的）每個 clip 強制走「快節奏品類硬規則」：6–8 鏡、單鏡 ≤ 2s、動感運鏡 ≥ 2 種、快詞動詞、每鏡有動作，絕不允許寫成慢節奏。
- 運鏡要絲滑：每條 clip prompt 末尾固定加運動質量句（不掉幀 / 不卡頓 / 絲滑 + 自然動態模糊）；環繞、旋轉類鏡頭尤其易掉幀，寫明"緩慢勻速環繞、平滑連續旋轉"並放慢速度。
- 鏡頭銜接：鏡與鏡之間不要跳幀、不要越軸（守 180° 軸線規則），機位與運動邏輯連貫。
- 禁止生成背景音效：影片靜音生成，不出任何環境音 / 背景音效；音樂 / 音效 / 旁白全部後期加入。
- 一條片只承載一個核心資訊點；前 3 秒抓人，結尾必有落點（logo/CTA/主張）。
- 真實品牌名僅作抽象風格參考，不復現特定品牌真實廣告的可識別元素、不杜撰真實品牌虛假主張；風格種子只用可公開復用的數字 --sref、不繫結個人 profile；不做涉及真實公眾人物的內容；保持適當無害。
