## 一、分析框架（三塊底座；細化見三/四/五節）

**1. 風格本質**：笑點靠**臺詞機鋒 + 處境誤會 + 現場反應**，不靠視覺變形；話劇 + 現場觀眾的多機位棚拍傳統；表演略外放、說完梗留一拍等笑聲、不破第四面牆。

**2. 畫面與聲音**：明亮偏暖、輕微高飽和的電視質感；**高調平光、幾乎無陰影、全場可見**；固定主場景（客廳沙發/吧檯/餐桌）+ 正面鏡框舞臺；制服化造型一眼看性格；多機位中寬景、穩定、靠剪輯在「說話 ↔ 反應」間切；**現場觀眾/罐頭笑聲**是身份標識、定節奏。

**3. 劇情（一梗到底，三拍）**：鋪墊（正常處境）→ 轉（離譜臺詞/誤會/升級）→ 落（punchline，收在**反應 + 笑聲**）。一條只一個笑點；引擎挑一個（升級/誤會/反高潮/cringe）；壓到兩人——混亂製造者 + 正常人（捧哏），笑點長在「正常人怎麼反應」。

## 二、工作流

### Step 1 · 前期確認（先敲定全部配置，再進 Step 2）

所有需要使用者選的配置**必須在生成角色/場景之前全部確認**——角色三檢視、場景圖要花算力生成並繫結，配置一旦回改前面資產就白做；尤其**畫幅由投放場景決定，必須先定**，否則三檢視/場景圖構圖要重來。壓成 **2 輪** `ask_user_input`（每輪 ≤3 題、都帶預設值和"你幫我定"逃生口），別連環追問；使用者說"全你定"就按預設一次跑完。

**先分流入口：**

- **A. 從零開始（最常見）** — 沒角色/場景/段子/參考 → 走兩輪確認 + 引導定段子。
- **B. 已有點子** — 給了一句話點子 → 只補缺的配置，已知項不重複問；笑點引擎從點子裡推斷、不問。
- **C. 反推參考影片** — 先跑第六節抽幀指令碼讀三拍/畫風/機位，再產出同款；配置裡能從影片看出的（畫幅/時長/語言）直接沿用、只補沒有的。

**第 1 輪 · 定框架（3 題）：**

1. **目的 + 投放場景 → 畫幅與調性**：豎屏 9:16（抖音/TikTok/Reels，預設）｜橫屏 16:9（YouTube/官網/橫板）｜方形 1:1。目的（純搞笑 / 品牌植入 / 角色 IP / 帶貨…）隻影響調性輕重，不改畫風。
2. **時長**：15s / 30s / 60s / 自填。**生成以 15s 為一段**，超 15s 分多段、每段一條獨立連續 prompt（≈3-4 鏡），共用同一套角色/場景繫結與風格鎖定句，逐段生成後剪輯銜接：15s=1段、30s=2段、60s=4段、自填按 15s 取整。**每 15s 就是一個完整笑點**（自己的三拍 + punchline + 笑聲），節奏緊湊；30s/60s＝同一對角色/同一場景下連著抖 2/4 個小段子，每段都落一次，別把一個梗硬拖長（拖長很尷尬）。
3. **笑點引擎**：升級 / 誤會 / 反高潮 / cringe（**僅"從零開始"拋**；"已有點子"從點子推斷）。

**第 2 輪 · 定語言與呈現（2 題）：** 4. **臺詞語言**：英文（預設，最貼美式情景喜劇口型）/ 中文。寫進生成 prompt。 5. **字幕語言**：雙語（預設，上中下英）/ 中文 / 英文。**字幕只在成片後剪輯燒錄，不進生成 prompt**（見 Step 7）。

**製作方式固定圖生影片**（本 skill 已生成三檢視+場景圖供繫結，不再詢問）：生成時帶上繫結圖，prompt 側重運鏡/走位/動作/臺詞/切鏡，外觀佈景交給參考圖。

**旁白**：預設**關**（情景喜劇少用，單機位才有）；使用者主動要才開，開則加畫外音，不影響其餘流程。

**分段生成節奏**（僅 &gt;15s 時問）：**一次性生成全部段** / **逐段確認**（生成一段、滿意了再生下一段，更穩但慢）。預設逐段確認。

兩輪確認完 → 從零開始再引導定段子：一輪拋 ① 場景（客廳/吧檯/餐桌/辦公室）② 二人組性格；據此從第四節點子庫挑/改一個**一句話 premise** + 分配 {{Mixed N}}，確認即進 Step 2。

### Step 2 · 定角色與場景（三檢視 + 場景圖）

**先做選角引導（兩問，用** `ask_user_input` **點選，留"你幫我定"逃生口）：**

1. **要幾個角色**：1 / 2 / 3 / 自填。情景喜劇段子**建議 2 人**（混亂製造者 + 正常人/捧哏），但按使用者選的來；人多時仍指定一個"正常人"負責反應。
2. **每個角色要哪種形象（含國籍）**：逐個確認 ① 形象原型（見第三節造型選單：整潔書呆型/邋遢慵懶型/自信浮誇型/毒舌酷姐…）② **國籍/族裔**（如美國、亞裔/華裔、日裔、韓裔、拉丁裔、非裔、歐洲…，**開放選擇，亞裔同樣適用**）。可一題一角色或合併成一輪。

**再定角色來源（二選一）：**

- ① 使用者**自行上傳照片** → 直接繫結到對應 {{Mixed N}}，**跳過三檢視生成**、以上傳圖為準。
- ② 沒有圖 → 按下面模板生成三檢視設定圖再繫結（把上面選的形象+國籍寫進外觀描述）。

**然後落到 token 與參考圖：**

- 每個角色一個 token：`{{Mixed 1}}`（混亂製造者）、`{{Mixed 2}}`（正常人/捧哏）…。首現寫全外觀（含國籍/族裔特徵 + 制服化標誌裝），之後只用 token、只寫動作/表情；互動寫清主賓。
- **（無上傳時）給每個角色出一張三檢視角色設定圖**（版式：**左側一張大頭正臉特寫，右側並排全身正面 + 全身背面**，統一造型、純淨淺色背景），用作 Seedance 的 {{Mixed N}} 繫結參考圖——這樣多鏡頭裡人物才穩定一致。三檢視按**本風格的高調平光、明亮乾淨電視質感**渲染（不是日劇暖調膠片），模板與範例見第三節「三檢視參考圖」。原型選單見第三節。
- **再出一張固定主場景的場景圖**（無人定場全景 establishing shot，正面鏡框、高調平光），用作 Seedance 的場景/背景繫結參考，保證多鏡頭裡**同一套佈景一致**。場景選單與模板見第三節「場景圖參考」。

### Step 3 · 設計段子

按「劇情內容」框架（第四節）：三拍落到多個編號鏡頭，從四類引擎選一個，套「混亂製造者 + 正常人」二人組。

### Step 4 · 套畫面與聲音元素

按框架（第三節）補全：明亮高調平光、幾乎無陰影 + 暖調輕微高飽和的電視質感 + 固定主場景正面鏡框 + 制服化造型 + 多機位中寬景、在說話/反應間切 + 收尾的罐頭笑聲拍子。

### Step 5 · 按 Seedance 2.0 格式輸出

按第五節格式：中文風格鎖定句 + 全域性設定 → 「嚴格按 \[N\] 個鏡頭順序：」編號分鏡（景別，含 {{Mixed N}}，用 `【切】` 切反應）→ 中文收尾句。**prompt 用中文寫（你能直接看懂）；臺詞按所選語言保留原文；明確"無字幕或螢幕文字"，字幕絕不進生成**。字幕另列「字幕清單」附後（Step 7 燒錄）。prompt 包在程式碼塊裡。**時長 &gt;15s 時按 15s 分段，每段各出一條 prompt（段1/段2… 各一個程式碼塊）+ 對應字幕清單**，共用角色/場景繫結與風格鎖定句，**每段自成一個笑點、各自落 punchline**。

### Step 6 · 確認後上 libtv 畫布生成

prompt（中文）出來後，**先讓使用者看懂內容，再問 OK 不 OK**：

- 不 OK → 按反饋改（換臺詞/引擎/造型/語言等），再給一版。
- OK → 在 **libtv 畫布**上生成（每段帶繫結的角色三檢視/上傳圖 + 場景圖），**按 Step 1 所選節奏**：一次性生成全部段 / 逐段確認（每段滿意再生下一段）；最後按順序剪輯銜接。

### Step 7 · 生成後加字幕（成片必備，字幕只在這一步出現）

libtv 出片（無任何字幕/螢幕文字）後，**成片必須帶字幕**——在剪輯裡按所選**字幕語言（中/英/雙語）燒錄，這是唯一**出字幕的環節、不省略：

- 用 Step 5 附的**字幕清單**逐句上字，按每鏡臺詞的時間軸，在**底部居中**打上**白字、細黑描邊**的電視字幕。雙語＝上中下英，且**英文行明顯小於中文行**（中文為主、英文為輔）。
- 文案按喜劇語感微調，落點那句務必在所選語言裡都好笑。
- 生成階段已禁字（`No subtitles or on-screen text`），所以畫面乾淨，直接上剪輯版字幕即可。
- 同時可在這一步疊上標準罐頭笑聲/起鬨聲，讓節奏更穩（見第三節「聲音音效」）。

## 三、畫面與聲音元素細化（含 {{Mixed N}}、三檢視、原型選單）

始終守住：明亮高調平光、幾乎無陰影、暖調輕微高飽和的電視質感、多機位中寬景。

### {{Mixed N}} 角色錨點

- 一個角色一個 token（`{{Mixed 1}}`、`{{Mixed 2}}`），繫結參考圖保持一致。
- 首次出現寫**全外觀**（髮型 + 制服化標誌裝 + 配飾）；之後只用 token、只寫動作/表情。
- 互動寫清主賓：`{{Mixed 1}} proudly announces the news to {{Mixed 2}}`。

### 三檢視參考圖（{{Mixed N}} 繫結用）

定完角色，先給每個 {{Mixed N}} 出一張三檢視設定圖，作為 Seedance 繫結的參考圖，保證多鏡頭裡人物不跑臉。**版式固定**：左側一張大頭正臉特寫，右側並排全身正面 + 全身背面。**按本風格渲染**（高調平光、明亮乾淨電視質感），不要日劇暖調膠片，否則會把色調帶進成片。

模板（EN，單角色單圖）：

```
Character reference sheet of one single character on a clean light seamless background, composed
as three panels: a large close-up head-and-shoulders portrait on the LEFT, then a full-body front
view and a full-body back view side by side on the RIGHT. Same outfit, same proportions, neutral
standing pose, gentle natural expression. [外觀：國籍/族裔 + 髮型髮色 + 制服化標誌裝 + 配飾]. Bright high-key
even lighting with minimal shadows, clean glossy television look, consistent character design,
no props.
```

模板（ZH）：

```
單個角色的角色設定圖，純淨淺色無縫背景，三欄構圖：左側一張大的頭肩特寫正臉，右側並排
全身正面 + 全身背面。同一套服裝、同樣身材比例、自然站姿、柔和自然表情。[外觀：國籍/族裔 + 髮型髮色 +
制服化標誌裝 + 配飾]。明亮高調均勻布光、陰影極弱，乾淨有光澤的電視質感，角色設定一致，無道具。
```

要點：版式＝左大頭正臉 + 右全身正背；一張圖只放一個角色（二人組分開出、防混臉）；外觀描述跟 prompt 裡 {{Mixed N}} 首現的寫法**逐字保持一致**；出圖工具 GPT Image-2 / Midjourney 均可，拿到後繫結到對應 token。

### 場景圖參考（固定主場景繫結用）

角色定完，給**固定主場景**出一張場景圖作為背景繫結參考，保證多鏡頭佈景不變。預設**無人定場全景**（乾淨背景板便於複用），需要時也可放 {{Mixed N}} 出帶人的定場幀。場景內容從下文「場景佈置」選單取（客廳 / 吧檯 / 餐桌 / 辦公室），渲染按本風格：正面鏡框、高調平光、暖調電視質感。**畫幅須與 Step 1 投放場景一致**（豎屏 9:16 / 橫屏 16:9 / 方形 1:1），否則繫結後構圖會錯。

模板（EN，末尾按需加 `vertical 9:16 / 16:9 / 1:1 aspect ratio`）：

```
Establishing wide shot of a classic multi-camera American sitcom set: [場景，如 a cozy lived-in
apartment living room with a big couch, warm lamps, a cluttered coffee table and a small kitchenette
in the back], no people. Frontal proscenium staging, bright high-key three-point lighting, soft even
illumination with minimal shadows, warm slightly-saturated colors, clean glossy television look,
[vertical 9:16 / 16:9 / 1:1] aspect ratio.
```

模板（ZH）：

```
經典美式多機位情景喜劇佈景的全景定場鏡頭：[場景，如 溫馨有生活感的公寓客廳，大沙發、暖色檯燈、
雜物茶几，後景小廚房]，畫面無人。正面鏡框式舞臺排程，明亮高調三點布光、柔和均勻、陰影極弱，
暖調輕微高飽和，乾淨有光澤的電視質感，[豎屏 9:16 / 橫屏 16:9 / 方形 1:1] 畫幅。
```

要點：預設無人、正面鏡框、和成片同一畫風（高調平光暖調）**同一畫幅**；一個段子一張主場景圖；場景描述跟成片 prompt 的全域性設定**逐字一致**；拿到後作為場景參考繫結。

### 色彩與質感

- 明亮、偏暖、輕微高飽和；乾淨有光澤的電視質感，不寫實。
- 生成詞：`bright high-key, warm slightly-saturated colors, clean glossy television look`。
- 避免：電影級低調暗部、紀錄片去飽和發青、膠片顆粒（那是別的風格）。

### 光線和氛圍（固定原則：高調平光、幾乎無陰影）

- 三點均勻布光 `high-key three-point lighting`、低反差 `soft even illumination`。
- `minimal shadows / everything clearly visible`——為多機位任意角度服務，不藏暗部。
- 整體明亮、暖、安全輕鬆，**不**做戲劇性明暗對比。

### 場景佈置（固定主場景、正面鏡框）

- 客廳：大沙發、暖色檯燈、雜物茶几、可見家居細節（lived-in）。
- 吧檯 / 咖啡館：固定吧檯、卡座、霓虹招牌、常客位。
- 餐桌 / 廚房：餐桌、開放式廚房、端菜動線。
- 辦公室（棚拍版）：會議桌、隔間、休息區——**注意**保持高調平光，別滑進偽紀錄片熒光冷光。
- 一律 `frontal proscenium staging`、`shot on a studio set`，場景反覆出現、觀眾熟悉。
- **背景群演**（增強美劇現場感）：酒吧客人/辦公室同事/餐廳食客等，只做**低調環境活動**（喝酒、打字、走過），**不與主角互動、不看鏡頭、不搶戲、動作幅度小**，避免干擾"說話↔反應"切鏡（英文寫法見骨架可選項）。

### 人物造型（制服化、一眼看性格）

配「混亂製造者 + 正常人」二人組時，挑兩個反差大的：

型別 造型要點（標誌裝，幾乎不換） 整潔書呆型 整齊開衫/格紋衫、眼鏡、規矩髮型，認真拘謹 邋遢慵懶型 oversized 衛衣、亂髮髻、拖鞋，deadpan 自信浮誇型 亮色襯衫、誇張配飾、油頭，姿態張揚 樸素老好人 家常 T 恤牛仔褲、親切日常 職場拘謹型 西裝/職業套裝、公文包，神情緊繃 戲精時髦型 浮誇時裝、墨鏡，時刻在演 怪咖宅男 印花卡通 T、運動外套，沉迷自己的世界 毒舌酷姐 利落穿搭、抱臂，隨時準備吐槽

- 標誌裝意義：瞬間可讀 + 強化原型，所以同一角色裝扮基本不變。
- **國籍/族裔與形象原型是兩回事**：原型（呆子/毒舌…）在這張選單選，國籍/族裔（美國/亞裔/日裔/拉丁裔…）在 Step 2 單獨問，兩者組合寫進角色外觀。
- 膚質可省略或寫 `natural healthy skin under bright studio light`，不追求 porcelain 磨皮。

### 鏡頭語言

- 機位：**多機位中景與寬景為主** `medium and wide shots`、穩定 `stable framing`、正面觀眾視角；無炫酷運鏡、無手持、無急推。
- 切鏡：靠剪輯在「說話的人 ↔ 反應的人」之間切——`Cut to Medium Shot` / `Cut to Reaction Close-up` / `Static Two-Shot`。

### 聲音音效（這類劇的身份標識）

- **現場觀眾/罐頭笑聲**：落點處必到，提示何時笑、定節奏。
- **緊跟不拖**：punchline 一落笑聲幾乎立刻起（和反應幾乎同拍），只留極短一拍，別磨蹭太久才響（拖久冷場）。
- **停頓寫進表演**：說完梗 → 極短一拍 → 笑聲立刻 → 收尾。
- 起鬨聲：接吻、反轉、曖昧時刻。
- Seedance 聲畫同出但笑聲"乾淨度"不穩；標準罐頭笑聲/起鬨聲更穩妥在剪輯時疊加。

## 四、劇情內容細化（一梗到底）

笑點在落差與時機，不在堆料、不在故事。**每個 15s 段只承載一個梗**，用不上單集骨架（冷開場/A線B線/片尾 tag 全不需要）。先想清「正常人為什麼會做出這個反應」，再寫鏡頭。**每 15s 一個完整笑點**、三拍打完就落 punchline + 笑聲，節奏要緊（拖長會尷尬）；30s/60s＝同一對角色同一場景連著抖 2/4 個小段子，每段各自落一次。

### 三拍結構（落到多個編號鏡頭）

```
鋪墊  約前 1/3：建立一個正常處境，一兩句話/一個動作交代清楚（中寬景，正常表演）
轉    中間：一句離譜臺詞 / 一個誤會 / 一下升級（切到說話/出事的人）
落    最後 1/3：punchline，切回正常人的反應 + 一拍停頓 + 罐頭笑聲
```

> 黃金法則：鋪墊越正常 + 轉得越離譜 + 反應越剋制 = 越好笑。落點幾乎都在「正常人的臉」上，而不是混亂本身。

### 故事結構

- 極簡，一條短片只承載一個笑點。
- 母版：「正常人和混亂製造者在某個熟悉場景裡，發生一次錯位。」

### 四類笑點引擎（挑一個）

- **升級 escalation**——小事突然失控。例：「我只是稍微動了一下」→ 鏡頭搖到一片狼藉。
- **誤會 misunderstanding**——兩人資訊不對稱、各說各的。例：A 宣佈好訊息，B 完全聽成壞事。
- **反高潮 anticlimax**——鋪得很隆重、一下戳破。例：莊嚴端出"大餐" → 是焦黑一坨 → 全桌沉默。
- **cringe**——說錯話後的死亡沉默。例：A 想誇 B → 越誇越錯 → 沒人接話。

> 收尾手法：切到捧哏（正常人）的反應 + 停頓 + 罐頭笑聲。**不要**用對鏡頭一瞥/對鏡頭 deadpan（那是偽紀錄片）；可用反應停頓，少用定格。

### 人物關係

- 壓到**兩人**：一個**混亂製造者**（說/做離譜事）+ 一個**正常人/捧哏**（負責反應）。
- 笑點幾乎都長在「正常人怎麼反應」上。
- 長期關係底色可借（找到的家人 / 曖昧拉扯 / 上司×下屬），但一條短片只演**這一對的一次化學反應**，不鋪關係線。

### 段子點子庫（引導從零使用者時直接拋/改）

按"場景 × 引擎"挑一條改成具體 premise（替換角色/臺詞即可）；沒選場景就隨機推一條。

**客廳沙發**

- 誤會：A 興奮宣佈大好訊息 →【切】B 完全誤解成天塌了、抱枕痛哭 →【切回】A 笑容凝固成困惑 → 沉默 + 笑聲。
- 升級：A 淡定說"我只是稍微整理了一下" →【切】鏡頭搖過去客廳一片狼藉 → B 表情凝固。

**吧檯 / 咖啡館**

- cringe：A 自信地對吧檯另一頭搭話 →【切】對方回一句讓 A 社死的話 →【切回】A 僵在原地舉著杯子 → 笑聲。
- 反高潮：A 神秘兮兮說"我有個絕妙計劃" →【切】下一拍計劃當場翻車 → B 面無表情喝咖啡。

**餐桌 / 廚房**

- 反高潮：A 莊嚴揭開餐蓋宣佈"驚喜大餐" →【切】是焦黑一坨 →【切回】全桌死寂 → A 強行微笑 + 笑聲。
- 誤會：A 說"我做了你最愛吃的" →【切】端出 B 最討厭的東西 → B 禮貌假笑逐漸崩塌。

**辦公室（棚拍版，保持高調平光）**

- 升級：老闆交代"就改一個小地方" →【切】下屬理解成把整個專案推翻重做、抱來一摞檔案 → 老闆凝固。
- cringe：A 在會議上想拍馬屁 →【切】把上司名字叫錯 →【切回】滿屋沉默 → A 想鑽桌底 + 笑聲。

變體鈕：換場景、換二人組造型、換離譜臺詞、把單次錯位升級成"誤會套誤會"（但仍是一個落點）。

## 五、Seedance 2.0 輸出格式

最終交付 = **一條中文編號分鏡式 prompt**（Seedance 支援中文，方便你看懂；**臺詞按所選語言保留原文**，說英文就寫英文原句），包在可複製程式碼塊。

### 標準骨架

生成 prompt 裡**只寫臺詞口型，絕不寫任何字幕/螢幕文字**，並明確 `no subtitles or on-screen text`（防模型自己亂出字）。字幕另列清單，成片後在 Step 7 燒錄。

```

1. [景別]：[鋪墊——正常處境，{{Mixed N}} 首現寫全外觀，定好相對位置如"在左/在右"]。{{Mixed 1}} 說[所選語言]臺詞："[臺詞原文]"。
2. 【切】[景別]：[轉]。{{Mixed 2}} 說[所選語言]臺詞："[臺詞原文]"。
3. 【切】反應特寫：[正常人的反應放大]。

```

另附**字幕清單（後期燒錄用，不進 prompt）**，預設雙語上中下英：

```

1. [中文] / [EN line]
2. [中文] / [EN line]
...
```

要點：

- 編號鏡頭，每鏡以景別開頭；機位以**中景/寬景**為主，穩定、正面。**每 15s 一段、每段 ≈3-4 鏡**；30s=2段、60s=4段，各一條 prompt（見 Step 1）。
- 用 `【切】` 切鏡，核心節奏是**說話的人 ↔ 反應的人**之間切。
- **位置鎖定**：一個段子裡角色相對位置（誰左誰右、誰坐誰站）從頭固定，切鏡絕不互換（多機位來回切最易穿幫）；首鏡寫死"{{Mixed 1}} 在左、{{Mixed 2}} 在右，全程不變"。
- 角色用 `{{Mixed N}}`，首現寫全外觀，之後只寫動作/表情。
- **臺詞寫進 prompt 且按所選語言保留原文；字幕不進 prompt**（明確"無字幕或螢幕文字"），字幕另列清單、成片後燒錄。
- 全域性必帶：風格鎖定句、高調平光、**畫幅**、"無字幕或螢幕文字"、收尾句、落點"輕微現場觀眾笑聲"帶節奏。

### 詞彙（中文，括號附英文備用）

- 景別：定場全景 · 雙人中景 · 中景 · 反應特寫 · 靜止大遠景。
- 切鏡：`【切】`（切至反應特寫 / 靜止雙人鏡頭）。
- 表演：得意宣佈 · 會錯意 · 表情僵住 · deadpan 呆臉 · 強行假笑 · 停頓一拍。
- **禁用**（屬偽紀錄片）：對鏡頭一瞥、手持、急推 snap zoom、採訪鏡頭。

### {{Mixed N}} 規則

一角色一 token，整條一致；互動寫清主賓；二人組用 `{{Mixed 1}}`（混亂製造者）+ `{{Mixed 2}}`（正常人/捧哏）。

### 聲音（罐頭笑聲是這類劇的標誌）

- **笑聲緊跟 punchline，不拖延**：落點一到、笑聲幾乎立刻起（和反應幾乎同拍），只留極短一拍停頓，別等演員反應磨蹭半天才響——拖久就冷場。prompt 寫"punchline 落下瞬間、現場觀眾笑聲立刻湧起"。
- 起鬨聲（反轉/曖昧時刻）；Seedance 笑聲"乾淨度"不穩，prompt 帶拍子即可，標準笑聲/起鬨聲剪輯時疊加。

### 臺詞與字幕（語言可選；字幕一律後期）

預設**英文臺詞 + 雙語字幕（上中下英）**。**字幕絕不在生成階段出現，全部等成片後剪輯燒錄（Step 7）。**

- **臺詞語言（中 / 英）**——決定口型/語音；**即使 prompt 是中文，臺詞也按所選語言保留原文**（說英文就在引號裡寫英文原句）。寫"{{Mixed 1}} 說英文臺詞：…" 或 "說中文臺詞：…"。
- **生成 prompt 裡明確"無字幕或螢幕文字"**——主動禁止模型出任何字（防亂碼/缺字/糊字）。
- **字幕語言（中/英/雙語，預設雙語上中下英）**——隻影響**後期字幕清單**（逐句、附在 prompt 後、供 Step 7 燒錄），不進 prompt。
- 翻譯不必逐字直譯，按喜劇語感意譯，落點那句務必在所選語言裡都好笑。
- 後期字幕樣式（Step 7）：底部居中、白字、細黑描邊、電視字幕感；雙語＝上中下英，**英文比中文小一號**（中文主、英文輔）。

### 繫結與旁白

- **固定圖生影片**：帶上三檢視 + 場景圖繫結，**prompt 側重運鏡/走位/動作/臺詞/切鏡**，外觀佈景交給參考圖（全域性設定與場景圖逐字一致）。
- **旁白**：預設關。開了才加畫外音（也算臺詞、字幕後期）。


## 六、反推參考影片（抽幀指令碼）

入口 C 用：先抽幀看清三拍與切鏡，再寫同款 prompt——不要憑空描述沒看過的畫面。把下面指令碼存成 `extract_frames.sh` 執行，用法 `./extract_frames.sh <video> [outdir]`。它會讀規格、按節奏抽幀、拼 contact sheet，並提示判斷：① 三拍（鋪墊/轉/反應+笑聲）② 切鏡在「說話 ↔ 反應」之間怎麼切、景別多大 ③ 畫風是否高調平光暖調幾乎無陰影、固定主場景（確認是棚拍情景喜劇而非偽紀錄片）④ 二人組誰是混亂製造者、誰是正常人、造型標誌。

```bash
#!/usr/bin/env bash
# 反推參考影片用：讀規格 + 抽幀 + 拼接成 contact sheet，看清三拍與切鏡節奏。
# 用法: ./extract_frames.sh <video> [outdir]
set -euo pipefail

VIDEO="${1:?用法: extract_frames.sh <video> [outdir]}"
OUT="${2:-./refframes}"
mkdir -p "$OUT"

echo "=== 規格 ==="
ffprobe -v error -show_entries format=duration,size,bit_rate \
  -show_entries stream=codec_type,codec_name,width,height,r_frame_rate \
  -of default=noprint_wrappers=0 "$VIDEO"

DUR=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$VIDEO" | cut -d. -f1)
echo "=== 時長約 ${DUR}s，按節奏抽幀 ==="

# 短片每 1.5s 一幀；過長則每 2.5s 一幀
if [ "${DUR:-0}" -le 35 ]; then RATE="1/1.5"; else RATE="1/2.5"; fi
ffmpeg -v error -i "$VIDEO" -vf "fps=${RATE}" "$OUT/f_%03d.jpg"

# 拼接 contact sheet 便於一眼看全片節奏與切鏡
if command -v montage >/dev/null 2>&1; then
  N=$(ls "$OUT"/f_*.jpg | wc -l)
  COLS=5; ROWS=$(( (N + COLS - 1) / COLS ))
  montage "$OUT"/f_*.jpg -tile "${COLS}x${ROWS}" -geometry 320x180+2+2 \
    -background black "$OUT/contact.jpg"
  echo "contact sheet: $OUT/contact.jpg"
```

## 七、通用約束

- **前期全部配置在 Step 1 敲定**（目的+投放場景/畫幅、時長、笑點引擎、臺詞語言、字幕語言、旁白、分段節奏），再進 Step 2 出角色/場景；壓成 2 輪點選、不連環追問。
- **畫幅由投放場景定**（豎屏 9:16 / 橫屏 16:9 / 方形 1:1）；三檢視（版式固定）、場景圖、成片 prompt 統一同一畫幅。
- 一條 prompt 用一種主語言整條交付，需要時附映象；包在可複製程式碼塊。
- 角色：**先問數量**（建議 2 人）**再問每個的形象 + 國籍/族裔**（開放，含亞裔）；用 {{Mixed N}}，首現寫全（含國籍/族裔 + 制服化標誌裝）、後續複用、互動主賓清晰；角色圖可**使用者上傳照片**或生成三檢視，二選一後繫結；每個段子先出固定主場景的場景圖繫結。
- 多機位中寬景、穩定；切「說話 ↔ 反應」；**角色相對位置鎖定不互換**；**不用**對鏡頭一瞥/手持/急推/採訪。
- **每 15s 一個完整笑點**、三拍、收尾落反應 + 笑聲，節奏緊湊；30s/60s＝連著抖 2/4 個小段子，每段各落一次。
- **prompt 用中文寫**（臺詞按所選語言保留原文）；**字幕絕不在生成階段出現**——prompt 明確"無字幕或螢幕文字"，字幕單列清單、僅成片後剪輯燒錄。
- 確認 OK 後才上 **libtv 畫布**生成（帶繫結的角色/場景圖）；背景可加低調群演（不互動/不看鏡頭/不搶戲）。
- 常配「混亂製造者 + 正常人」二人組。
- 不做涉及真實公眾人物的內容；保持適當無害。
