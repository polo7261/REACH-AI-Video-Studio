# 功能用途

本 Skill 旨在将粗糙的原始剧本进行工厂化拆解，转化为可直接用于漫剧、短剧制作的拍摄底稿。核心特色在于将演员动作与台词彻底解耦，并自动识别分集、场景、人物及情绪，大幅提升前期筹备效率。

# 适用输入

- 完整长剧本或已分集的剧本片段。
- 格式可包含：txt、word 内容或直接粘贴的文本。

# 操作步骤

1. **分集识别**：按剧本标记或情节闭环（约800-1200字）自动切分。每集需提炼核心钩子与爆点。
2. **场景拆分**：根据地点、时间变化切分场景，标注内外景、日夜及主次场景名。
3. **元素提取**：识别所有角色（主/配/龙套）、关键道具及转场方式。
4. **动作与台词解耦**：从描述中提取独立动作（以“△”开头），并将台词独立列出，标注对应的极致情绪标签（如：甜、虐、爽、燃等）。
5. **镜头细化**：为每个场景生成景别、运镜及画面内容描述。

# 输出要求

输出包含三份核心表格，确保字段完整：

### 1. 分集大纲

包含集数、核心钩子（≤15字）、本集爆点、卡点情绪及关键人物。

### 2. 场景表

包含集-场号、场景名称、内外日夜、角色、关键道具、转场方式及剧情摘要。

### 3. 镜头拆解底稿

- **字段**：镜号、景别、运镜、画面内容、演员动作（必须以 △ 开头）、台词、情绪标签、备注。
- **动作规范**：若无明确动作则填“△静立”或“△注视”，禁止为空。
- **情绪高峰**：针对冲突镜头标注“【情绪高峰】建议升格/定格”。

# 注意事项

- 动作必须从台词语境中反向拆解（如“冷笑说”拆分为“△冷笑”+台词）。
- 缺失的内外景或日夜信息需根据上下文补全，并标注“\*”。
- 确保每个镜头的信息密度符合短剧快节奏需求。
