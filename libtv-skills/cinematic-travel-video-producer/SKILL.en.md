# travel-vlog

Translates any vague travel-shoot theme/copy/prose/script idea from the user into a Flova-executable cinematic aesthetic travel-videography workflow. **Real-person live-action style (not anime/CG)**, positive emotional energy; multiple 15-second "auto shot-cutting units" are stitched into the final film. Author: Huang Xinbo / AIDIR creator community (source attribution disclosed).

> Environment mapping: text_to_instrumental (Suno 5/Mureka 8) / ElevenLabs v3 / Doubao narration → `generate_audio`; Seedance 2.0/Fast → `generate_video_v3`; GPT Image 2 three-view sheets/posters → `generate_image_v3`; video_assembler → `composite_video`; Final_Video_Spec.md/text_editor → `write_file_v2`; multimodal_analyze → agent self-analysis; video frame extraction (final frame as reference image) → `reference_nodes` in `generate_video_v3` referencing the preceding video node. If the ElevenLabs/Doubao concrete Voice ID list reads `无该模型` (no such model), delete it and switch to `ask_human` voice cards (take a representative sentence, generate 3–5 voice samples to audition, user picks by ear).

## 11-Stage Pipeline (strict order, with 11 mandatory pause-confirmation points; skipping ahead is forbidden)

 1. **Input parsing + parameter confirmation**〔Pause 1〕: Deeply analyze the user's input; extract location/characters/emotion/style/platform purpose/whether specific copy is provided. Use `ask_human` to confirm the short film's total duration, aspect ratio, and whether narration is wanted. **Video model selection**: give the user two options and require an explicit choice before starting — Seedance 2.0 (highest quality) / Seedance 2.0 Fast (faster; previews / time pressure); **record the chosen model in the Spec; all subsequent video generation must use it mandatorily, and switching on your own is forbidden**. **Check whether the uploaded image is a full-body photo**. Ask whether the user will upload real-scene reference images of the destination.
 2. **Reference material deconstruction + three-view assets**〔Pause 2〕: Deconstruct character/scene reference images (if any); **automatically complete the lower-body and footwear design**; use `generate_image_v3` to produce a 16:9 full-body character three-view sheet, **which must be real-person live-action style (photorealistic, real person, live-action style); illustration/anime/cartoon/any non-photorealistic style is strictly forbidden**. Send to the user for confirmation.
 3. **Creative directions + narration copy**〔Pause 3〕: Output 3 creative directions; generate the standalone narration copy in advance per the 【Influencer-Grade Viral Copy Rules】 (5-part structure, 60% rhyme, 100–520 characters, uplifting positive energy). Confirm the creative direction and the exact wording of the narration.
 4. **Pure instrumental music (execute with priority)**〔Pause 4〕: Use `generate_audio` (text_to_instrumental; Suno 5; fallback Mureka 8) to generate the full film's instrumental. Send for audition and confirmation.
 5. **Write Final_Video_Spec + Chinese prompt construction**: Use `write_file_v2` to lock film title/video type/aspect ratio/total duration/visual style/output language/chosen video model as global anchors; write an extremely detailed four-part prompt for the chosen model (see below). **Mandatory red line: whenever the frame contains spoken lines, always append (no subtitles) after the lines.**
 6. **Dynamic timeline + flexible storyboard table**〔Pause 5〕: Split the total runtime into several 15-second "auto shot-cutting units"; apply the **Absolute Pacing Rule** (fast cuts at the opening / build-up in the middle / dense at the climax / relaxed at the end); annotate each unit's function (opening / build-up / observation / transition / climax / coda); **continuity markers**: indicate which adjacent 15-second materials count as "scene continuation" and which contain "character dialogue"; register each 15-second four-part structure as a generation task for the chosen model; bind the Step 2 assets into the elements. Confirm the storyboard table.
 7. **Video material generation + industrial-grade self-QC (core loop)**〔Pause 6〕: **Continuity extraction — when a scene continues, a video frame (Video Frame) must be grabbed from the previous video clip as the next clip's reference image**; **voice extraction — when there is spoken dialogue, a voice asset must be extracted from the first clip containing that character's dialogue, to serve as that character's voice reference thereafter**; feed the 【Master Prompt】 into the chosen model for auto shot-cutting (one call per unit; **do not break it apart**); the video material itself carries **no background music**. **QA rating** (background self-check across five dimensions: ① whether it matches the plot ② whether it is visually appealing (composition/lighting) ③ whether there are goofs (logic/limbs) ④ whether it contains subtitles ⑤ whether there are audio flaws (noise/gaps) → overall rating → action):
    - **【Error】** (goofs / serious defects / inconsistent with the plot) → discard directly in the background and **auto-regenerate; showing it to the user is strictly forbidden**.
    - **【Usable】** (no hard flaws and no goofs, but average visual appeal/tension, or it contains subtitles) → **must pause, send it to the user, and proactively ask whether to regenerate**.
    - **【Excellent】** (perfectly matches the plot, stunningly beautiful, high-grade lighting, flawless) → keep and send directly to the user.
    - Only send "Usable" or "Excellent" material to the user for final confirmation.
 8. **Voiceover gender confirmation, auditioning, and generation**〔Pause 7〕: ① Gender confirmation — first use `ask_human` to ask for a male or female voice; proceed to the next step only after an explicit reply; ② Engine selection — default to ElevenLabs v3; the user may switch to Doubao (native Chinese voices); ③ Audition comparison — take a 10–20-character representative sentence from the narration, pick 3–5 voices from the voice card matching the chosen gender, and generate one audition clip for each; send them to the user together for playback comparison; **the user chooses by ear, with no need to look up any ID**; ④ After the user has chosen, generate the full narration
