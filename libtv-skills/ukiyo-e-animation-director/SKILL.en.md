# Ukiyo-e Aesthetic Animation-Style Director Skill

## 1. Skill Name

Ukiyo-e Aesthetic Animation-Style Director

Recognizable aliases:

- Ukiyo-e Animation Director
- Woodblock Print Animation Aesthetics Director
- Japanese Classical Decorative Animation Director
- Ukiyo-e Image-to-Video Director

---

## 2. Skill Overview

This Skill helps users start from a vague idea and complete the full image and video production workflow in the "Ukiyo-e aesthetic animation style." It emphasizes woodblock print texture, washi paper grain, flat color blocks, clear outlines, decorative composition, classical Japanese elements, and a sense of animated storytelling.

It is not ordinary Japanese illustration, not a modern anime filter, and not a realistic period drama—it is an execution system that transforms visual elements such as ukiyo-e, woodblock prints, emaki picture scrolls, folding screens, waves, cloud motifs, bridges, mountain scenery, yokai, and mythological figures into generatable images and image-to-video output.

Suitable for:

- Folding-screen-style scene illustrations

Not suitable for:

## 4. Input Assessment Rules

After receiving a user request, first determine the input type.

### 4.1 No Reference Image

When the user only has a vague idea, do not write prompts directly. First output 3-5 creative directions, each containing:

- Direction name
- Main subject
- Core elements
- Emotional atmosphere
- Animatable actions
- Suitable output format

### 4.2 With Reference Image

When the user provides an image, first analyze:

- Main subject
- Composition
- Color
- Scene
- Emotion
- Which elements need to be preserved
- Which elements need to be ukiyo-e-fied

Then perform original transformation; do not copy the reference image.

### 4.3 User Wants Images Only

Output:

- Creative directions
- Asset planning
- Image prompts
- Chinese negative prompts
- English negative prompts
- Review checklist

### 4.4 User Wants 5-Second Image-to-Video

Output:

- First-frame image prompt
- 5-second Seedance 2.0 video prompt
- Action control
- Camera movement control
- Keep items
- Forbidden items
- Editing / sound suggestions

### 4.5 User Wants 15 Seconds or Longer Video

Must be split into shots; generating the entire video in one go is not recommended.

Recommended:

- 15 seconds = 3 five-second shots
- 30 seconds = 6 five-second shots
- 60 seconds = 12 five-second shots

Each shot must be labeled with:

- Shot function
- Rhythm type
- Visual content
- Action
- Camera movement
- Sound
- Video prompt

## 5. Creative Guidance Without Reference Image

Without a reference image, proactively offer the user the following types of directions:

### Direction A: Waves and the Traveler

A traveler wearing a straw hat stands before giant decorative waves, with Mount Fuji and curling cloud motifs in the distance forming a horizontal picture scroll. Suitable for grand, fateful travel visuals.

### Direction B: Fox Spirit Girl on a Bridge

On a vermilion wooden bridge on a moonlit night, a fox spirit girl gently looks back, paper lanterns sway, cherry blossoms drift down. Suitable for character posters, yokai short films, and mysterious mood pieces.

### Direction C: Night Parade of a Hundred Demons Street

Paper lanterns sway on an Edo night street as small yokai emerge from behind folding screens, eaves, and fabric curtains. Suitable for 15-second yokai concept animation.

### Direction D: Girl on a Cherry Blossom Mountain Road

A girl walks along a cherry blossom mountain road, distant mountains rendered as flat color blocks, cloud motifs drifting horizontally, sleeves swaying gently. Suitable for travel visuals and lyrical short films.

### Direction E: A God Descends Upon the Sea

A sea god, wind god, or moon god appears between ocean waves and a full moon—overall solemn, mythological, epic. Suitable for mythology posters and concept animation openings.

## 6. Style Analysis and Original Transformation with Reference Image

### 6.1 Preservation Layer

Preserve from the reference image:

- Subject identity
- Pose relationships
- Overall composition
- Emotion
- Key props
- Elements the user explicitly requires to be kept

### 6.2 Transformation Layer

Transform the reference image into:

- Woodblock print texture
- Washi paper grain
- Flat color registration
- Clear ink-line outlines
- Decorative borders
- Scroll / folding-screen composition
- Patterned elements such as seigaiha waves, rolling cloud motifs, cherry blossom motifs, mountain motifs, and flowing water motifs

### 6.3 Prohibition Layer

Do not convert the reference image into:

- Ordinary modern anime
- Realistic cinematic footage
- 3D rendering
- Impasto oil painting
- Cyber Japanese style
- Modern commercial illustration

## 7. Standard Workflow

### Step 1: Requirements Understanding

Extract: theme, subject, scene, characters, emotion, purpose, aspect ratio, duration, presence of reference image, whether assets are needed.

### Step 2: Creative Direction

If the user's requirements are vague, offer 3-5 directions; if the user is already clear, directly refine them into a ukiyo-e animation plan.

### Step 3: Asset Planning

Output characters, scenes, props, patterns, and animatable elements.

### Step 4: First-Frame Image Prompt

Generate an image prompt suitable for use as a video first frame, emphasizing stable composition and clearly defined animatable elements.

### Step 5: Video Storyboarding

Split the duration into 5-second shots, defining the rhythm type and shot function for each shot.

### Step 6: Seedance 2.0 Video Prompts

Output a directly copyable video prompt for each shot, containing subject, style, composition, action, camera movement, keep items, and forbidden items.

### Step 7: Editing and Sound

Provide suggestions for transitions, rhythm, sound effects, BGM, subtitles, or a seal-stamp ending.

### Step 8: Review

Check for style, action, video stability, and model drift risk.

## 9. Image Prompt Rules

Image prompt structure:

```text
Subject + Scene + Ukiyo-e style + Woodblock print texture + Flat color blocks + Clear outlines + Decorative elements + Composition + Color palette + Animatable potential + Negative prompt
```

Style anchors that must appear:

- Ukiyo-e aesthetics
- Japanese woodblock print
- Washi paper grain
- Woodcut printing texture
- Flat color registration
- Clear ink-line outlines
- Low light and shadow
- Slight color misregistration
- Uneven hand-printing
- Decorative composition
- Classical emaki scroll feel

Avoid:

- Realistic highlights
- Strong gradients
- Realistic skin texture
- Modern anime big eyes
- 3D rendering
- Impasto brushstrokes
- Cyber neon

### Single Image Prompt Template

[Subject] placed within [Scene], with an overall ukiyo-e aesthetic animation style, Japanese woodblock print texture, clear ink-line outlines, large flat color blocks, low contrast, minimal gradients, the image carries washi paper fiber grain and woodcut printing texture, with slight color registration misalignment and uneven hand-printed feel at the edges of color blocks. The image incorporates [waves / cloud patterns / cherry blossoms / mountains / bridges / folding screens / lanterns], the composition carries the decorative quality and flat layered feel of classical woodblock prints, the foreground [foreground elements] forms a natural border, the midground highlights the [Subject], and the background reveals [distant mountains / full moon / sea surface / streets]. The colors are dominated by [indigo / vermilion / cream white / ink black / light gold / cherry pink], classical, restrained, and narrative, like an animated ukiyo-e picture scroll.

## 10. Storyboard Design Rules

The core of ukiyo-e animation style videos is not fast cuts, but a "moving woodblock print scroll."

### Shot Function Types

- Establishing shot: introduces the space, weather, and world of the image
- Revealing shot: the subject emerges from occlusion or blank space
- Emotional shot: subtle character movements, gazes, sleeves, falling flowers
- Suspense shot: lanterns, reflections, or shadows behind folding screens move strangely
- Grand shot: ocean waves, mountains, deities, and a large moon establish grandeur
- Transition shot: flower petals, fabric curtains, waves, or cloud patterns occlude the scene transition

### Camera Movement Priority

1. Fixed camera position
2. Horizontal scroll-style extremely slow pan
3. Extremely slow push-in
4. Extremely slow pull-out
5. Foreground occlusion transition

Forbidden: fast whip pans, handheld shaking, large orbiting shots, complex 3D orbits, modern MV-style fast cuts.

---

## 11. 5-Second Image-to-Video Rules

### 11.1 Universal 5-Second Rhythm

- 0-1 seconds: establish composition, image almost static
- 1-3.5 seconds: 1-3 elements move slowly
- 3.5-5 seconds: movement concludes, emotion lingers or suspense remains

### 11.2 Motion Principles

Each shot has at most 2-3 types of main movements. Do not make the entire image move.

Suitable:

- Waves rising and falling
- Cloud patterns drifting slowly
- Flower petals falling
- Sleeves swaying gently
- Fox tail swaying slowly
- Lanterns swaying gently
- Fabric curtains swaying gently
- Character slightly turning head
- Water reflections subtly changing

Not suitable:

- Running
- Large-scale fighting
- Fast jumping
- Exaggerated expressions
- Realistic water splashing
- Modern light effect bursts

### 11.3 Seedance 2.0 Video Prompt Template

Based on the first frame image, generate a 5-second ukiyo-e aesthetic animation style video. The subject is [Subject], located in [Scene]. Maintain the overall Japanese ukiyo-e woodblock print style, with washi paper grain, woodcut printing texture, clear ink-line outlines, large flat color blocks, slight color registration misalignment, and classical decorative composition; do not convert to modern anime or realistic 3D. The image composition is [foreground / midground / background], with [foreground elements] in the foreground, the midground subject is [Subject], and the background has [background elements]. Motion design: within 5 seconds, [Action 1] occurs slowly, while [Action 2] occurs slightly, and [Action 3] occurs in small amounts; overall movement is restrained and delicate, not exaggerated. Camera design: use [fixed camera position / horizontal scroll-style extremely slow pan / extremely slow push-in]; the camera speed is very slow, like a classical woodblock print scroll being slowly unrolled. The atmosphere and mood is [emotion words]. Keep [character appearance / scene structure / prop positions / color relationships] unchanged. No fast movements, no intense camera rotation, no face changes, no modern cinematic lighting, no cyber elements, no realistic water or 3D rendering.

## 12. Editing and Sound Suggestions

### Editing

Recommended:

- Slow cuts
- Fade in and fade out
- Folding screen unfolding
- Cloud pattern occlusion
- Cherry blossom occlusion
- Wave occlusion
- Fabric curtain occlusion
- Paper page turning
- Seal stamp falling at the end

Not recommended:

- Glitch transitions
- Flash cuts
- Neon flickering
- Fast zooming
- Intense shaking

### Sound

Recommended ambient sounds:

- Wind
- Ocean waves
- Wooden bridge footsteps
- Fabric curtain rustling
- Wind chimes
- Paper lanterns gently swaying
- Night insect chirping

Recommended music:

- Shakuhachi
- Shamisen
- Taiko low frequencies
- Minimalist percussion
- Ambient music with ample negative space

Yokai / mythology themes should not use horror movie sounds; it should be "light kaidan, classical, mysterious."

## 13. Review Checklist

### Style Review

Must have:

- Ukiyo-e aesthetics
- Woodblock print texture
- Washi paper grain
- Flat color registration
- Clear ink-line outlines
- Low contrast
- Decorative composition
- Classical Japanese narrative feel

### Generic Japanese Illustration Risk

If the following occur, it has gone off track:

- Characters look like modern anime
- Colors too digital
- Lighting too 3D
- Background looks like ordinary travel illustration
- No woodblock print texture
- No washi paper texture
- No wave / cloud pattern / folding screen style composition

### Video Review

Check:

- Whether the original image composition is maintained
- Whether characters change faces
- Whether the 2D flat woodblock print texture is maintained
- Whether movements are too large
- Whether camera movement is too fast
- Whether modern elements appear
- Whether water, clouds, and light are overly realistic
