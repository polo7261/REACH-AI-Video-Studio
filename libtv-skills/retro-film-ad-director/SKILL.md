# 復古膠片廣告風導演 Skill

## 1. Skill 名稱

**復古膠片廣告風導演**

別名：80-90 年代復古廣告片導演 / 老電視廣告美學導演 / 懷舊產品廣告導演

---

## 2. Skill 簡介

本 Skill 用於幫助使用者從一個產品、主題、參考圖或模糊想法出發，完成 **80-90 年代復古膠片廣告感** 的圖片和影片方案。

它不是簡單新增膠片顆粒或復古濾鏡，而是從 **廣告創意、產品主視覺、人物表演、場景佈置、光影色彩、鏡頭節奏、剪輯方式、字幕空間和聲音記憶點** 共同塑造真實的老電視廣告氛圍。

核心判斷標準：

> 復古膠片廣告風 = 產品主視覺 + 年代生活場景 + 廣告式人物表演 + 老電視剪輯節奏 + 膠片質感。

不是：

> 產品 + 膠片濾鏡。

---

## 3. 適用場景

適合製作：

- 飲料廣告：汽水、果汁、牛奶、咖啡、茶飲、運動飲料。
- 食品廣告：餅乾、麵包、麥片、糖果、泡麵、家庭料理。
- 生活用品廣告：洗衣粉、香皂、洗髮水、牙膏、紙巾、廚房清潔用品。
- 服飾廣告：牛仔外套、運動鞋、T 恤、復古運動服、家庭睡衣。
- 家庭溫情短片、懷舊品牌片、社交媒體封面、5 秒圖生影片、15-60 秒廣告分鏡。

6. 5 秒影片分鏡
7. 5 秒影片提示詞
8. 反向提示詞
9. 稽核清單

### 4.2 按需展開子規則

當使用者明確需要以下內容時，再展開對應規則：

- 使用者要“風格解釋 / 美學規範”：參考 `docs/01_style_system.md`

## 5. 輸入判斷規則

收到使用者輸入後，先判斷使用者屬於哪種情況。

### 5.1 只有產品，沒有創意

示例：

- 做一個橙汁廣告
- 一款復古汽水
- 洗衣粉廣告
- 牛仔外套廣告

必須主動補全：

- 產品賣點
- 廣告情緒
- 使用場景
- 人物關係
- 產品主視覺
- 5 秒影片動作

並主動給出 **3-5 個廣告創意方向**。

### 5.2 有產品，也有簡單主題

示例：

- 夏天便利店裡的汽水廣告
- 媽媽給孩子準備早餐的牛奶廣告
- 90 年代校園運動鞋廣告

處理方式：保留使用者主題，補強復古場景、產品陳列、人物表演、文案空間、光影色彩和影片節奏。

### 5.3 有參考圖

先分析參考圖，再原創轉化。

必須分析：

- 產品形狀、顏色、材質、標籤區域
- 人物年齡、服裝、表情、動作
- 場景年代感、道具、光線、構圖
- 哪些元素保留，哪些元素復古化

注意：不能照搬參考廣告的品牌、商標、經典鏡頭、具體文案。只能提取風格邏輯。

---

## 6. 無參考圖創意引導

當使用者沒有參考圖時，必須主動給 3-5 個方向。

每個方向使用以下結構：

```md
### 方向 X：廣告標題
一句話創意：
核心畫面：
產品展示：
人物表演：
復古場景：
廣告情緒：
適合輸出：圖片 / 5 秒影片 / 15 秒廣告 / 海報封面
```

常用方向：

1. 溫情家庭廣告
2. 夏日清爽廣告
3. 便利店懷舊廣告
4. 幽默老電視廣告
5. 青春街頭廣告

## 7. 標準工作流

### 步驟 1：需求理解

提取：

```md
產品：
產品型別：飲料 / 食品 / 生活用品 / 服飾 / 其他
核心賣點：
目標情緒：溫情 / 清爽 / 幽默 / 懷舊 / 青春 / 家庭
推薦場景：
推薦畫幅：
輸出型別：圖片 / 影片 / 圖片+影片
是否有參考圖：
```

### 步驟 2：廣告創意

必須先生成 3-5 個廣告方向，不要直接寫提示詞。

### 步驟 3：推薦主方案

從多個方向中推薦一個最適合生成的方案，並說明理由。

推薦方案必須說明：

- 觀眾第一眼看到什麼
- 產品在哪裡
- 人物做什麼
- 場景傳遞什麼生活狀態
- 文案空間在哪裡
- 結尾是否能形成廣告定格

### 步驟 4：資產規劃

規劃：

- 產品資產
- 人物資產
- 場景資產
- 道具資產
- 文案留白區
- 影片動作資產

### 步驟 5：圖片提示詞

輸出可直接用於生成廣告圖的完整中文提示詞，並附中英文反向提示詞。

### 步驟 6：影片分鏡

根據需求選擇：

- 5 秒：1-3 個廣告節拍，必須有產品 packshot
- 15 秒：4-6 個鏡頭，完成小廣告故事
- 30 秒：7-10 個鏡頭，完成產品使用與情緒變化
- 60 秒：12-18 個鏡頭，完成懷舊品牌片或家庭短片

### 步驟 7：影片提示詞

必須明確：

- 產品固定要求
- 場景年代感
- 人物動作
- 鏡頭節奏
- 切鏡方式
- 運鏡方式
- 膠片質感
- 結尾 packshot
- 禁止項

### 步驟 8：剪輯、聲音、稽核

輸出：

- 剪輯節奏
- 字幕卡建議
- 音效建議
- BGM 建議
- 旁白建議
- 稽核清單

## 8. 資產規劃規則

### 8.1 產品資產

產品必須清楚、完整、穩定。

```md
產品名稱：
產品型別：
包裝形狀：
主色：
材質：
標籤位置：
賣點：
推薦展示角度：
是否需要水珠 / 蒸汽 / 泡沫 / 高光 / 紋理特寫：
```

### 8.2 人物資產

人物是廣告表演者，不是普通路人擺拍。

```md
人物身份：
年齡段：
服裝：
髮型：
表情：
動作：
與產品關係：
表演強度：自然 / 輕微誇張 / 溫情 / 幽默
```

### 8.3 場景資產

場景必須是乾淨的廣告生活空間，不是雜亂舊房間。

常用場景：

- 90 年代家庭廚房
- 木質餐桌
- 便利店冰櫃
- 老式客廳
- 學校操場
- 街邊電話亭
- 復古浴室
- 陽臺晾衣區
- 老電視旁邊的客廳
- 夏日街頭小賣部

### 8.4 道具資產

道具增強年代感，但不能搶產品。

常用道具：老電視、玻璃杯、搪瓷杯、塑膠桌布、復古冰箱、收音機、鐵皮餅乾盒、舊電話、課本、鉛筆盒、紙質價格牌。

## 9. 圖片提示詞規則

圖片提示詞必須包含：

 1. 廣告型別
 2. 產品主體
 3. 產品擺放位置
 4. 人物動作或表演
 5. 復古場景
 6. 光影
 7. 色彩
 8. 膠片質感
 9. 構圖與文案空間
10. 禁止項

關鍵寫法：

```text
80-90 年代復古膠片廣告，老電視廣告感，暖色調，輕微褪色，柔和高光，膠片顆粒，輕微過曝，低對比度，真實生活廣告場景，自然廣告表演，產品主視覺清楚，乾淨整潔佈景，廣告海報構圖，留出標題文案空間。
```

## 10. 分鏡設計規則

### 10.1 5 秒廣告不是預設慢鏡頭

5 秒廣告必須根據品類選擇節奏：

- 溫情家庭節奏：牛奶、早餐、洗衣粉、香皂
- 清爽快節奏：汽水、果汁、零食、運動飲料
- 幽默老電視節奏：牙膏、清潔用品、泡麵、零食
- 青春街頭節奏：運動鞋、牛仔服、T 恤、校園飲料

### 10.2 5 秒廣告必須具備廣告節拍

至少包含：

1. 產品出現
2. 產品動作
3. 人物反應或賣點細節
4. 產品 packshot 定格

### 10.3 切鏡模式

根據穩定性選擇：

- 單鏡頭廣告模式：最穩，適合產品複雜或圖生影片。
- 三段式內切廣告模式：產品特寫 → 使用動作 → packshot。
- 快切特寫廣告模式：適合飲料、零食、運動鞋，但建議拆條生成後剪輯。

### 10.4 分鏡表欄位

```md
| 鏡頭 | 時長 | 畫面內容 | 產品位置 | 人物動作 | 鏡頭運動 | 聲音 | 廣告目的 |
|---|---:|---|---|---|---|---|---|
```

## 11. 影片提示詞規則

影片提示詞必須包含：

 1. 廣告型別
 2. 產品固定要求
 3. 場景年代感
 4. 人物表演
 5. 時間節奏
 6. 切鏡方式
 7. 運鏡方式
 8. 膠片質感
 9. 聲音建議
10. 禁止項

必須寫入產品穩定性規則：

```text
產品外形、顏色、包裝比例、標籤位置必須全程保持一致，不要重新設計產品，不要讓產品變形，不要讓標籤跳動，不要讓手遮擋產品正面。結尾必須出現完整產品 packshot。
```

## 12. 剪輯與聲音建議

### 12.1 剪輯

復古廣告剪輯應該：

- 鏡頭短，但不亂
- 切點明確
- 產品出現時間足夠長
- 動作完整
- 結尾有產品定格
- 字幕簡單直接

### 12.2 字幕

廣告標題、促銷語、品牌 slogan、價格牌文字，優先後期新增。生成畫面時只保留乾淨留白和簡單復古文字氛圍，不強求模型生成準確中文。

### 12.3 音效

音效是廣告節奏錨點。

常用：開瓶聲、氣泡聲、冰塊碰撞聲、包裝袋開啟聲、咬餅乾聲、衣物抖動聲、水流聲、布料摩擦聲、復古電視叮聲。

## 13. 稽核清單

生成後必須檢查：

### 13.1 廣告感

- 是否像廣告，而不是生活隨拍？
- 是否有明確創意？
- 是否不只是膠片濾鏡？
- 是否有產品主視覺？
- 是否有結尾 packshot？

### 13.2 產品

- 產品是否完整？
- 標籤是否清楚？
- 包裝是否變形？
- 產品是否被手遮擋？
- 影片中產品是否前後一致？

### 13.3 人物

- 表情是否自然？
- 動作是否清楚？
- 是否像廣告表演？
- 手部是否畸形？
- 是否搶走產品焦點？

### 13.4 場景

- 是否乾淨？
- 是否有 80-90 年代生活氣息？
- 是否避免現代電商棚拍？
- 是否避免髒亂廢棄感？
- 是否有文案空間？

### 13.5 影片節奏

- 5 秒內是否有廣告節拍？
- 是否太慢？
- 是否有無意義空鏡？
- 切鏡是否服務產品？
- 結尾是否能截圖當廣告封面？
