# Japan Camedy Film

把创意变成 **一条 Seedance 2.0 直接可粘贴的编号分镜式 prompt**。先用下面的「分析框架」对齐风格，再按工作流产出。

---

## 分析框架（这类视频的三块底座）

### 1. 风格本质

- **核心机制**：以精致考究的复古影像，营造一个看似正经的情境；前后转折的强烈落差即为笑点，铺垫越像正剧，反转越有冲击力。
- **视觉来源**：整体借用二〇〇〇年前后日本流行文化，融合该时期的电影、音乐录影带、广告与时尚杂志；兼收 Y2K、洛丽塔、视觉系等街头风格。不绑定单一作品。
- **表演基调**：始终克制而认真，人物一本正经、毫不出戏，以此为结尾的荒诞铺垫。

### 2. 画面元素

- **色彩与质感**：轻微胶片质感与颗粒，色彩中间调，饱和度低，整体色调偏一点点蓝。
- **光线和氛围**：外景白天多为自然光，夜晚/室内多为环境光；**人物面光自然柔和、无阴影**（这是固定原则）。
- **场景布置**：繁复且充满复古细节。室外——街道、公园、校园；室内——日式和室、老派咖啡馆、悬挂红灯笼的居酒屋、乡间庭院等。
- **人物造型**：符号鲜明、辨识度高，一眼看出性格。常见：洛丽塔少女、校园学生、视觉系青年、上班族、和服造型等。**服装按"角色身份 + 所处场景"重新设定，不沿用参考图/角色原本的服装**。
- **镜头语言 + 特效**：多为固定镜头，少量推拉摇移跟镜，无炫酷运镜。**反转主要靠硬切 + 表演完成**；若用到特效，须融进真实画面、共用同一套光线材质颗粒、无合成边（不跳脱），不抢戏。

### 3. 剧情内容

- **三段式叙事**：先认真铺陈一件日常小事 → 将表情/动作层层放大（常借超慢动作）→ 通过一次**硬切或表演的急转**完成反转 → 反转后以一个面无表情的停顿收尾。
- **故事结构**：极简，一条短片只承载一个笑点；大体不外乎"人物在做一件平常的事，随后发生意外"。
- **常见反转方式（七类，均为真人情景、不靠魔幻变形）**：① 情绪急转（**须有前因后果、不能莫名其妙**）② 身份反转 / 反差萌（凶大佬其实怕猫、柔弱少女实为拳击冠军）③ 反高潮（郑重铺垫一件大事，落点却极小）④ 对话反转（一句台词翻转全场）⑤ 尴尬反转（脚趾抠地的社死 / 冷场）⑥ 攻守逆转 / 反客为主（气势强的一方突然崩、弱的反压）⑦ 小题大做 / 尺度反转（用史诗级慢镜配乐去做一件极小的事）。「层层嵌套」是结构、不是类型：任一类都能再叠一轮。笑点可由对白、表演或特效任一承载；**反转主要靠硬切 + 表演完成**。
- **人物关系**：多为一对性格相反、形象差距大的搭档（一强一弱、一动一静）；冲突在结尾以荒诞反转化解或逆转。

## 工作流

**Step 1 · 输入**：用户给一句话点子；做广告可上传产品图 + 卖点。入口三选一：从零（走引导：场景 / 角色 / 反转三问）/ 已有点子（只补缺项）/ 反推参考视频（先抽帧看节拍再仿写，不凭空描述没看过的画面）。

**Step 2 · 产品处理（上传了产品图才做）**：立刻生成产品**三视图 + 细节特写**，锁定 `{Product1}` 保全片一致、清晰露出；并问清**核心卖点 1–3 个**（第 1 步已写则不问）。**红线**：段子须正向凸显卖点，**不得虚构 / 夸大 / 贬低 / 污蔑产品**，笑点不落在产品缺点上、须符合真实卖点。

**Step 3 · 一次性问完可提前选项**（用 `ask_human`，能不追问就不追问）：时长 **15 / 30 / 60s** · 目的（涨粉 / 带货 / 品牌）· 创意手法（七类反转选一，或"你帮我定"）· 投放场景（抖音 / 小红书 / YouTube…）· 语言（日语 / 中文；选中文再选**中国场景 / 继续日本场景**）· 字幕（中文 / 中日 / 中英，**生成时不烧、成片后合成时加**）· slogan（可选）。

**Step 4 · 形象与画面**：模特形象——先问 **① 我生成三视图 / ② 你上传**（生成则每人一张、左→右 **面容特写 ｜ 全身正面 ｜ 全身背面**、换装后）；出场景图 `{Scene1}`（16:9、白平衡中性不偏黄）；风格种子（复古日影 / 中式复古，色彩中性不偏黄、面光柔和无阴影）；服装按"身份 + 场景"重设、不沿用原服装。三视图 / 场景图作参考图喂回，绑 `{roleN}` / `{Product1}` / `{Scene1}` 保一致不穿帮。

**Step 5 · 设计段子 + 套画面**：三段式（认真铺垫 → 层层升级 → **硬切 / 表演急转**反转 → deadpan 余韵）落到编号镜头，用所选反转、配性格相反的搭档；写清"怎么演"；对白按所选语言**只说、不烧字幕**；节奏紧凑无废镜。画面按定调补全（面光柔和无阴影 / 复古场景 / 重设服装 / 固定机位为主 / 特效不跳脱）。

**Step 6 · 出分镜 prompt → 满意即生成 → 合成视频**：出 prompt（整条**中文**、**16:9**、首句固定 `画面内容请参考场景氛围图 {Scene1}`、含 `{roleN}` 与产品露出）；**整段直出、每 15s 为一个片段生成**（片段内部分镜交模型自动切、不锁死机位）：15s = 1 段，30s = 2 段，60s = 4 段；**逐段续接**（后段以前段末帧 / 同一 `{roleN}` 参考接上），先出一段、确认后再续下一段，全程 `{roleN}` / 服装 / 光线 / 场景一致不穿帮。出完问"满意 / 要改"——**满意 → 直接调用已连接的视频生成连接器以 16:9 发起生成**，不用手动；再**合成视频**：叠字幕（Step 3 所选）+ 旁白 + slogan / 产品结尾露出（剪辑或 `ffmpeg`）；无工具则交付 prompt + 字幕文本 / SRT。

```
1. 中景（缓推、超慢动作）：气场强大的大佬 {role1} 神情肃杀，缓缓卷起袖子、拿起一把菜刀，眼神凶狠，气氛剑拔弩张。

4. 过肩中景：对面瘦小的店员 {role2} 怯怯开口，用日语说"…不用切得这么认真啦"。

```

## 通用约束

- 整条 prompt 用中文撰写；对白按 Step 1 所选语言、**只说不烧字幕**；字幕在 Step 6 成片后合成时按用户所选（中文 / 中日双语 / 中英双语）加；包在可复制代码块。
- 角色用 {roleN}，首现写全、后续复用、互动主宾清晰；**服装按角色身份+场景重设，不沿用原服装**。
- 表演写清楚（怎么演）；**笑点可由对白、表演或特效任一承载**；对白只说不烧字幕、简短自然；剧情推进紧凑无废镜。
- 固定机位为主；反转主要靠**硬切 + 表演**；若用到特效务必不跳脱（共用光线材质颗粒、无合成边）。
- 一条短片承载一个反转（层层嵌套算其延伸）；常配性格相反的搭档。
- 15s 一条直出；30s 先出前 15s、确认后再续后 15s；60s 分四段续接；全程不穿帮。
- 产品广告：先问清卖点；段子须正向凸显卖点、产品清晰露出；**不得虚构/夸大/贬低/污蔑产品**，笑点不落在产品缺点上、须符合产品真实卖点。
- **内容道德红线（务必遵守）**：不得包含色情、性暗示、裸露；不得包含暴力、血腥、打斗伤人、武器伤害、犯罪教程；**不得出现纹身**；不得涉及死亡、自杀、自残、尸体、灵异惊悚等；不美化烟酒毒品；不涉及仇恨、歧视、政治敏感。笑点只落在情境、表演与反差上，保持轻松、适龄、无害。
- 不做涉及真实公众人物的内容；保持适当无害。
