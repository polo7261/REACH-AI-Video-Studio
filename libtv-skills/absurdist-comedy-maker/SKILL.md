# Japan Camedy Film

把創意變成 **一條 Seedance 2.0 直接可貼上的編號分鏡式 prompt**。先用下面的「分析框架」對齊風格，再按工作流產出。

---

## 分析框架（這類影片的三塊底座）

### 1. 風格本質

- **核心機制**：以精緻考究的復古影像，營造一個看似正經的情境；前後轉折的強烈落差即為笑點，鋪墊越像正劇，反轉越有衝擊力。
- **視覺來源**：整體借用二〇〇〇年前後日本流行文化，融合該時期的電影、音樂錄影帶、廣告與時尚雜誌；兼收 Y2K、洛麗塔、視覺系等街頭風格。不繫結單一作品。
- **表演基調**：始終剋制而認真，人物一本正經、毫不出戲，以此為結尾的荒誕鋪墊。

### 2. 畫面元素

- **色彩與質感**：輕微膠片質感與顆粒，色彩中間調，飽和度低，整體色調偏一點點藍。
- **光線和氛圍**：外景白天多為自然光，夜晚/室內多為環境光；**人物面光自然柔和、無陰影**（這是固定原則）。
- **場景佈置**：繁複且充滿復古細節。室外——街道、公園、校園；室內——日式和室、老派咖啡館、懸掛紅燈籠的居酒屋、鄉間庭院等。
- **人物造型**：符號鮮明、辨識度高，一眼看出性格。常見：洛麗塔少女、校園學生、視覺系青年、上班族、和服造型等。**服裝按"角色身份 + 所處場景"重新設定，不沿用參考圖/角色原本的服裝**。
- **鏡頭語言 + 特效**：多為固定鏡頭，少量推拉搖移跟鏡，無炫酷運鏡。**反轉主要靠硬切 + 表演完成**；若用到特效，須融進真實畫面、共用同一套光線材質顆粒、無合成邊（不跳脫），不搶戲。

### 3. 劇情內容

- **三段式敘事**：先認真鋪陳一件日常小事 → 將表情/動作層層放大（常借超慢動作）→ 透過一次**硬切或表演的急轉**完成反轉 → 反轉後以一個面無表情的停頓收尾。
- **故事結構**：極簡，一條短片只承載一個笑點；大體不外乎"人物在做一件平常的事，隨後發生意外"。
- **常見反轉方式（七類，均為真人情景、不靠魔幻變形）**：① 情緒急轉（**須有前因後果、不能莫名其妙**）② 身份反轉 / 反差萌（兇大佬其實怕貓、柔弱少女實為拳擊冠軍）③ 反高潮（鄭重鋪墊一件大事，落點卻極小）④ 對話反轉（一句臺詞翻轉全場）⑤ 尷尬反轉（腳趾摳地的社死 / 冷場）⑥ 攻守逆轉 / 反客為主（氣勢強的一方突然崩、弱的反壓）⑦ 小題大做 / 尺度反轉（用史詩級慢鏡配樂去做一件極小的事）。「層層巢狀」是結構、不是型別：任一類都能再疊一輪。笑點可由對白、表演或特效任一承載；**反轉主要靠硬切 + 表演完成**。
- **人物關係**：多為一對性格相反、形象差距大的搭檔（一強一弱、一動一靜）；衝突在結尾以荒誕反轉化解或逆轉。

## 工作流

**Step 1 · 輸入**：使用者給一句話點子；做廣告可上傳產品圖 + 賣點。入口三選一：從零（走引導：場景 / 角色 / 反轉三問）/ 已有點子（只補缺項）/ 反推參考影片（先抽幀看節拍再仿寫，不憑空描述沒看過的畫面）。

**Step 2 · 產品處理（上傳了產品圖才做）**：立刻生成產品**三檢視 + 細節特寫**，鎖定 `{Product1}` 保全片一致、清晰露出；並問清**核心賣點 1–3 個**（第 1 步已寫則不問）。**紅線**：段子須正向凸顯賣點，**不得虛構 / 誇大 / 貶低 / 汙衊產品**，笑點不落在產品缺點上、須符合真實賣點。

**Step 3 · 一次性問完可提前選項**（用 `ask_human`，能不追問就不追問）：時長 **15 / 30 / 60s** · 目的（漲粉 / 帶貨 / 品牌）· 創意手法（七類反轉選一，或"你幫我定"）· 投放場景（抖音 / 小紅書 / YouTube…）· 語言（日語 / 中文；選中文再選**中國場景 / 繼續日本場景**）· 字幕（中文 / 中日 / 中英，**生成時不燒、成片後合成時加**）· slogan（可選）。

**Step 4 · 形象與畫面**：模特形象——先問 **① 我生成三檢視 / ② 你上傳**（生成則每人一張、左→右 **面容特寫 ｜ 全身正面 ｜ 全身背面**、換裝後）；出場景圖 `{Scene1}`（16:9、白平衡中性不偏黃）；風格種子（復古日影 / 中式復古，色彩中性不偏黃、面光柔和無陰影）；服裝按"身份 + 場景"重設、不沿用原服裝。三檢視 / 場景圖作參考圖喂回，綁 `{roleN}` / `{Product1}` / `{Scene1}` 保一致不穿幫。

**Step 5 · 設計段子 + 套畫面**：三段式（認真鋪墊 → 層層升級 → **硬切 / 表演急轉**反轉 → deadpan 餘韻）落到編號鏡頭，用所選反轉、配性格相反的搭檔；寫清"怎麼演"；對白按所選語言**只說、不燒字幕**；節奏緊湊無廢鏡。畫面按定調補全（面光柔和無陰影 / 復古場景 / 重設服裝 / 固定機位為主 / 特效不跳脫）。

**Step 6 · 出分鏡 prompt → 滿意即生成 → 合成影片**：出 prompt（整條**中文**、**16:9**、首句固定 `畫面內容請參考場景氛圍圖 {Scene1}`、含 `{roleN}` 與產品露出）；**整段直出、每 15s 為一個片段生成**（片段內部分鏡交模型自動切、不鎖宕機位）：15s = 1 段，30s = 2 段，60s = 4 段；**逐段續接**（後段以前段末幀 / 同一 `{roleN}` 參考接上），先出一段、確認後再續下一段，全程 `{roleN}` / 服裝 / 光線 / 場景一致不穿幫。出完問"滿意 / 要改"——**滿意 → 直接呼叫已連線的影片生成聯結器以 16:9 發起生成**，不用手動；再**合成影片**：疊字幕（Step 3 所選）+ 旁白 + slogan / 產品結尾露出（剪輯或 `ffmpeg`）；無工具則交付 prompt + 字幕文字 / SRT。

## 通用約束

- 整條 prompt 用中文撰寫；對白按 Step 1 所選語言、**只說不燒字幕**；字幕在 Step 6 成片後合成時按使用者所選（中文 / 中日雙語 / 中英雙語）加；包在可複製程式碼塊。
- 角色用 {roleN}，首現寫全、後續複用、互動主賓清晰；**服裝按角色身份+場景重設，不沿用原服裝**。
- 表演寫清楚（怎麼演）；**笑點可由對白、表演或特效任一承載**；對白只說不燒字幕、簡短自然；劇情推進緊湊無廢鏡。
- 固定機位為主；反轉主要靠**硬切 + 表演**；若用到特效務必不跳脫（共用光線材質顆粒、無合成邊）。
- 一條短片承載一個反轉（層層巢狀算其延伸）；常配性格相反的搭檔。
- 15s 一條直出；30s 先出前 15s、確認後再續後 15s；60s 分四段續接；全程不穿幫。
- 產品廣告：先問清賣點；段子須正向凸顯賣點、產品清晰露出；**不得虛構/誇大/貶低/汙衊產品**，笑點不落在產品缺點上、須符合產品真實賣點。
- **內容道德紅線（務必遵守）**：不得包含色情、性暗示、裸露；不得包含暴力、血腥、打鬥傷人、武器傷害、犯罪教程；**不得出現紋身**；不得涉及死亡、自殺、自殘、屍體、靈異驚悚等；不美化菸酒毒品；不涉及仇恨、歧視、政治敏感。笑點只落在情境、表演與反差上，保持輕鬆、適齡、無害。
- 不做涉及真實公眾人物的內容；保持適當無害。
