# Y2K 果冻数码美学导演 Skill

## 1. Skill 名称

**Y2K 果冻数码美学导演**\
别名：千禧果冻数码视觉导演 / Jelly Digital Y2K Visual Director / 未来复古潮流影像导演

---

## 2. Skill 简介

这个 Skill 用于帮助用户从一个主题、人物、产品、音乐情绪或参考图开始，完整制作 **Y2K 千禧年数码美学、果冻材质、透明塑料、银色金属、镭射反光、蓝紫粉渐变、复古电脑 UI、潮流海报、虚拟偶像视觉、产品广告、音乐 MV 和 5 秒图生视频**。

它不是关键词堆叠工具，而是一套视觉导演工作流：

1. 判断用户需求与使用场景
2. 给出 3-5 个原创创意方向
3. 规划人物 / 产品 / 道具 / 场景资产
4. 输出图片生成提示词
5. 设计分镜与镜头节奏
6. 输出 5 秒或更长视频的分镜提示词
7. 给出剪辑、声音、字体、UI 与审核规则

核心目标：做出 **明亮、干净、闪亮、甜酷、透明、镭射、未来复古、年轻潮流** 的 Y2K 数码视觉，避免跑成普通赛博朋克、暗黑霓虹、廉价塑料或杂乱 UI。

---

## 3. 适用场景

适合制作：

- Y2K 潮流海报
- 虚拟偶像视觉
- 音乐 MV / 混剪视觉
- 产品广告：香水、护肤品、美妆、耳机、饮料、数码产品、潮玩
- 社交媒体封面：小红书、抖音、B站、短视频封面
- 5 秒图生视频
- 15 秒 / 30 秒 / 60 秒 / 75 秒潮流广告或 MV 分镜
- 复古电脑 UI、光盘、MP3、翻盖手机、数码相机主题视觉

不适合：

- 黑暗赛博朋克城市
- 雨夜霓虹街道
- 废土工业风
- 恐怖黑客房
- 大量机械义体改造
- 脏乱、压抑、反乌托邦视觉

## 4. 输入判断规则

### 4.1 用户只给主题

例如：\
“做一个 Y2K 风格女孩海报”\
“做一个果冻数码风产品广告”\
“做一个千禧年 MV 视觉”

执行规则：

- 不要直接只给一个提示词。
- 先输出 3-5 个创意方向。
- 每个方向包含：画面概念、主体、场景、道具、色彩、动效潜力。
- 如果用户没有选择，默认选择最适合传播和生成稳定的方向继续。

### 4.2 用户给了产品

重点分析：

- 产品类型
- 产品形状
- 产品材质
- 包装色彩
- 受众气质
- 卖点是否适合透明、果冻、镭射、UI 化表达

必须输出：

- 产品主视觉方案
- 产品陈列方式
- 产品周围道具
- 产品广告图提示词
- 产品 5 秒视频提示词

### 4.3 用户给了人物 / 角色

重点分析：

- 角色身份
- 发型妆容
- 服装材质
- 姿势
- 画面情绪
- 背景 UI 层次

必须输出：

- 人物资产设定
- 服装与配饰规则
- 人物海报提示词
- 人物 5 秒视频提示词

### 4.4 用户给了参考图

必须先分析，再原创转化。

只提取：

- 色彩关系
- 材质方向
- 构图逻辑
- 光影方式
- 道具类型
- UI 层次
- 情绪气质

不能照搬：

- 具体人物身份
- 真实 logo
- 商标
- 原图文字
- 原图特殊构图
- 原图角色或品牌元素

### 4.5 信息不足时

不反复追问，自动补全默认值：

- 默认风格：中度 Y2K 果冻数码风
- 默认色彩：蓝紫粉渐变 + 银色金属 + 透明冰蓝
- 默认材质：半透明塑料、透明亚克力、果冻凝胶、镭射膜
- 默认道具：光盘、翻盖手机、MP3、数码相机、复古电脑 UI
- 默认视频：镜头推进 + UI 闪动 + 镭射高光 + 主体定格
- 默认画幅：海报 3:4 / 4:5，MV 16:9，短视频 9:16，产品广告 16:9 或 1:1

## 6. 参考图分析与原创转化

参考图分析时使用以下结构：

1. 主体类型
2. 构图方式
3. 色彩关系
4. 材质特征
5. UI / 图形元素
6. 道具信息
7. 情绪气质
8. 可保留与需转化部分

原创转化规则：

- 普通背景转为蓝紫粉数码空间
- 普通材质转为果冻、透明塑料、银色金属、镭射膜
- 普通道具替换为 Y2K 数码道具
- 普通光效转为屏幕光、光盘反射、透明折射、镭射扫光
- 普通 UI 转为复古电脑弹窗、加载条、鼠标指针、像素图标
- 保留风格逻辑，不复制具体内容

## 7. 标准工作流

每次执行按以下顺序：

1. **需求理解**\
   判断用户做图、做海报、做产品广告、做 MV、做视频还是做完整分镜。

2. **风格定位**\
   选择轻度 / 中度 / 重度 Y2K。默认中度。

3. **创意方向**\
   无参考图给 3-5 个方向；有参考图先分析再转化。

4. **资产规划**\
   输出人物、产品、道具、场景资产。

5. **图片提示词**\
   输出单图、人物海报、产品广告、场景图等对应提示词。

6. **分镜设计**\
   如果用户要视频，先按时长和用途拆镜头。

7. **视频提示词**\
   根据镜头节奏输出单镜头提示词。

8. **剪辑与声音**\
   给出转场、声音、字体、UI 叠加建议。

9. **审核纠偏**\
   检查是否跑成赛博朋克、廉价塑料、UI 混乱、主体不清。

详见：`docs/02_workflow_assets_prompts.md`

## 10. 分镜设计规则

如果用户要视频，必须先判断视频类型：

- 动态海报
- 产品广告
- MV / 虚拟偶像
- 潮流短片
- 社交媒体封面

分镜表必须包含：

镜头时长节奏景别画面内容主体动作镜头运动UI 动效材质动效转场声音生成提示词重点避免问题

节奏可选：

- 慢：动态海报、产品英雄镜头、结尾定格
- 中：产品展示、人物轻动作、场景建立
- 快：MV、道具蒙太奇、UI 闪屏、广告开头
- 很快：高潮卡点、闪白、快切蒙太奇

详见：`docs/03_video_rhythm_storyboard.md`

## 11. 5 秒视频提示词规则

5 秒视频不能只有一种“慢推”。必须根据用途选择节奏模式。

### 11.1 慢节奏：动态海报模式

适合：人物海报、社交媒体封面、产品主视觉。

节奏：

- 0-1 秒：首帧建立，屏幕光轻微亮起
- 1-2 秒：镜头缓慢推进，材质高光流动
- 2-3 秒：UI 弹窗轻微闪烁
- 3-4 秒：光盘反射或镭射扫光
- 4-5 秒：主体定格，形成封面感

### 11.2 中节奏：产品广告模式

适合：香水、护肤、美妆、耳机、饮料、数码产品。

节奏：

- 0-0.5 秒：数码开机闪光
- 0.5-1.5 秒：产品快速亮相
- 1.5-2.5 秒：镭射高光扫过产品
- 2.5-3.8 秒：产品轻微旋转或高光变化
- 3.8-5 秒：加载条完成，产品英雄定格

### 11.3 快节奏：MV / 潮流短片模式

适合：音乐 MV、虚拟偶像、时尚短片。

节奏：

- 0-0.4 秒：UI 快速闪出
- 0.4-1.2 秒：snap zoom 推近人物
- 1.2-2 秒：光盘旋转、音频波形跳动
- 2-3 秒：人物小幅 pose 变化
- 3-4.2 秒：UI 遮挡或镭射扫光形成镜头内转场
- 4.2-5 秒：人物定格，封面感收束

完整模板见：`docs/03_video_rhythm_storyboard.md` 与 `docs/04_templates_negative_prompts.md`

## 12. 剪辑与声音建议

### 剪辑节奏

- 海报：慢推、轻闪、定格
- 产品广告：开头快吸睛，中段稳展示，结尾定格
- MV：0.5-1.5 秒一次视觉变化，卡点闪白、UI 弹窗、光盘扫光
- 长视频：按段落拆镜，不要一个长提示词生成到底

### 转场建议

- UI 弹窗遮挡转场
- 光盘反光扫屏转场
- 翻盖手机开合转场
- 数码相机闪光转场
- 加载条完成转场
- 鼠标点击窗口转场
- 像素爱心闪屏转场

### 声音建议

适合：

- 复古电脑开机声
- 鼠标点击声
- UI 弹窗提示音
- 电子 beep
- 光盘旋转声
- 数码相机快门声
- 翻盖手机打开声
- 镭射扫光 whoosh
- 果冻轻弹声
- 甜酷电子鼓点

不适合：

- 黑暗工业噪音
- 恐怖音效
- 废土环境声
- 过强赛博朋克低频

## 13. 审核清单

生成后必须检查：

### 风格

- 是否明显是 Y2K 千禧数码美学？
- 是否有果冻、透明塑料、银色金属、镭射反光？
- 是否是蓝紫粉、冰蓝、珠光白、银色体系？
- 是否干净、闪亮、潮流？
- 是否避免了普通赛博朋克？

### 材质

- 果冻是否有透光感？
- 透明塑料是否高级干净？
- 银色金属是否有镜面反光？
- 镭射是否自然不过曝？
- 光盘反射是否有彩虹层次？

### UI

- UI 是否过多？
- 是否遮挡主体？
- 是否有乱码？
- 是否服务构图？
- 是否像复古电脑界面而不是黑客屏幕？

### 视频

- 主体是否稳定？
- 是否没有换脸、换装、换场景？
- UI 是否只是节奏性动效？
- 光效是否自然流动？
- 产品是否不变形？
- 结尾是否能定格成封面？

详见：`docs/05_review_troubleshooting.md`
