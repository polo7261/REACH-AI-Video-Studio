# miniature-world

以微型道具与模型场景为舞台,讲有人物弧光的温柔小故事(节日祝福/生活故事)。画风精致细腻、镜头克制、**移轴摄影美学**,适合情感短片。默认 9:16、60–90s、温暖柔和。

> 本环境适配(Flova→我方 13 工具):GPT Image 2/Nano Banana/Seedream/MJ → `generate_image_v3`;Seedance/Kling/MultiModalToVideo/FirstFrameToVideo → `generate_video_v3`;text_to_instrumental/text to narration → `generate_audio`;text_editor(Final_Video_Spec) → `write_file_v2`;video_assembler → `composite_video`。源里"需要会员"的分辨率/模型档 = `无积分系统`,不设门。 \*\***本 skill 自足内联,不依赖任何其他 skill。** 长内容(图像/视频 prompt 结构、多模态分析、装配规范)见 `references/`(属本 skill 内部文件,非依赖)。

## 5 段管线(5 个强制 checkpoint,不可跳)

- **阶段 0 规格确认**〔CP0〕:先向用户展示并收明确选择——
  - **画面比例**(单选):9:16(竖屏,推荐·适合手机)/ 16:9(横屏)/ 1:1(方形,社交)。
  - **视频分辨率**(单选):720p(标准)/ 1080p(高清)。
  - **目标时长**(单选):60s(精简,约 10–12 镜)/ 90s(标准,约 14–18 镜)/ 自定义(用户输入秒数)。
  - **图片生成模型 / 视频生成模型**:本环境统一走 `generate_image_v3` / `generate_video_v3`(源的五选模型菜单→我方模型档,详见 references/pipeline-and-generation.md 的模型档说明)。
  - 收到选择后 `write_file_v2` 建 **Final_Video_Spec.md**,写入:视频类型=微缩生活故事片(情感短片)、画面比例\[选\]、目标时长\[选\]、视频分辨率\[选\]、图片模型(分辨率 2K)、视频模型+分辨率\[选\]、视觉风格=微缩模型摄影风格·移轴镜头感·精致细腻·色调温暖柔和、音频风格=轻音乐 BGM(钢琴/弦乐为主)·温柔旁白或无旁白、输出语言=与用户交互语言一致。
  - **强制暂停 CP0**:展示已确认参数摘要,收到明确确认前不得进入阶段 1。
- **阶段 1 故事脚本**〔CP1〕:引导用户给梗概或 AI 自动起草(人物/场景/情感弧光);完成关键元素定义(主角/配角/主要场景/核心道具)+ 分镜规划(景别/运镜/时长/叙事节奏,时长对齐 Spec)+ 音频层设计(BGM 条数/旁白规则)。展示完整故事脚本与分镜方案(每镜景别/运镜/叙事内容摘要)确认。
- **阶段 2 关键元素图**〔CP2〕:优先生成所有角色关键元素图(正面参考图 + 动作/表情变体),用 Spec 指定模型;再生成场景关键元素图(微缩街景/室内布景);如有旁白,在此阶段同步 `generate_audio` 生成旁白音频作后续音频条件。**所有元素图集中展示确认**,用户要求重生成某张则重生成后再确认。
- **阶段 3 分镜视频 + BGM**〔CP3〕:按分镜顺序**批量**生成所有镜头视频,**无需逐批暂停确认**;所有镜头均携带对应角色图 + 场景图作视觉参考,用 Spec 指定模型;BGM `generate_audio` 与视频并行。全部完成集中展示预览确认再进组装。
- **阶段 4 粗剪预览**〔CP4〕:`composite_video` 将所有镜头视频 + 旁白 + BGM 组装为粗剪时间线,以「粗剪预览」形式请用户确认整体节奏与情绪;有修改回对应阶段调整后再组装。
- **阶段 5 最终输出**:确认满意后 `composite_video` 最终合成,告知导出。

> **阶段依赖**:CP0→CP1→CP2→CP3→CP4→阶段5。**旁白音频(阶段 2)须早于视频(阶段 3)完成**以作音频条件;**BGM 与分镜视频(阶段 3)可并行**。

## 叙事:4–6 环节弧

先把故事拆成 **4–6 个关键环节**(不少于 4)成弧光骨架,再据此分配镜头。

- 环节数量:建议 4(精简主题)–6(情节丰富主题),不得少于 4。
- 每环节对应一个**叙事功能节点**,常见结构:**建立世界 → 触发事件 → 情节推进 → 情感高潮 → 余韵收尾**;或针对具体主题拆流程(如"节日礼物":寻找材料→制作礼物→包装等待→赠送惊喜→温暖余韵)。
- 每环节须含 **核心场景/参与角色/关键动作或道具/情绪基调**;环节间**逻辑连贯、情绪递进**,禁无因果跳跃。
- 内部规划格式(不对用户展示):`环节一:[名称]—[场景]—[核心动作]—[情绪]`…确认骨架合理后按各环节展开镜头,每环节通常 2–4 镜。

## 关键元素(微缩人偶美学)

- **角色**:每位主角独立 element——正面全身参考图(清晰展示造型/服装/发型/肤色)+ ≥1 张表情/动作变体图(展示情绪变化);须符合微缩人偶美学:比例略卡通化、材质感细腻(布料纹理/皮肤光泽)、与模型场景自然融合。
- **场景**:每主场景独立 element——全景参考图(空间结构/光线氛围/道具摆放)+ 可选白天/夜晚变体。
- **道具**:有叙事功能的核心道具(信件/花束/小桌)单独建 element,确保跨镜头一致。

## 分镜(shot_list)规范

- **时长节奏**:单镜 4–8s(情感高潮可延至 10s);整片 60–90s、通常 10–18 镜。
- **景别与运镜**:开场大远景/俯瞰全景建微缩空间感(移轴感强);叙事推进以中景为主展角色互动;情感特写用面部近景/道具特写捕捉细节情绪;运镜克制(缓慢推拉、轻微横摇为主),避免快速剪辑破坏温柔氛围。
- **叙事结构**:遵循「开篇建立世界 → 情节展开 → 情感高潮 → 余韵收尾」四段式;每镜描述含 景别/摄像机运动/画面内容/角色情绪/与前后镜的叙事关联。

## 尺寸一致性与动作主体铁律(跨镜强制 · 微缩专属)

- **大道具须众人合力**:凡尺寸远大于单个人偶的道具(咖啡杯/信封/花盆),须明确"多人合力"完成操作,**禁单人轻松使用大型道具**(否则生成出比例失调的巨大手臂/人物)。
- **动作对应具体主体**:每个动作须明确是谁(哪位角色或"两人一同")执行,禁"有人/某人"等模糊表达。
- **禁违背常理元素**:不得发光道具、悬浮物体、骑乘虫类等破坏微缩写实感的内容。
- **跨镜一致**:同角色服装/发型/道具状态全程一致;场景内固定道具位置不无故移位。

## 音频层规范

- **BGM**:1–2 条轨道(开场 + 高潮可切换);风格钢琴独奏 / 钢琴+弦乐,轻柔温暖无人声;时长须覆盖整片(建议生成 90s 以上),渐入渐出;`generate_audio` 的 prompt 中不可出现知名音乐人姓名。
- **旁白(可选)**:如使用须在分镜阶段标注旁白文本对应的 **shot_id**;语气温柔叙事(第三/第一人称皆可);音色选型方法:温柔女声叙事 / 温暖男声叙事 / 中性清澈女声(按情绪选用,由 `generate_audio` 指定);旁白须在视频生成前完成作音频条件。
- **旁白与自带音频镜头共存**:用 FirstFrameToVideo/VideoInterp 一类生成的镜头自带音频,该类镜头的旁白轨须**静音或错开**,避免重叠。
