## 一套韋氏底質 + 一句可選主色(階段 1 提煉,全片統一)

韋氏只有**一套渲染底質**(對稱、平面、正面平打光、35mm 質感、真人寫實),由場景種子鎖死,保證全片一致。色板**不做固定預設**(種子已嵌入風格),而是**從劇本情緒提煉一句主色傾向**附到 MJ prompt;使用者不指定就讓種子原生色板說了算。

- **底質子句(用於 MJ 場景圖)**:`對稱的故事書式電影畫面,完美居中的正中單點透視構圖,像劇場佈景般平面化的舞臺排程,真人實拍照片級寫實,精細的美術置景,正面均勻柔和的平打光,剋制精調的粉彩色板,細膩的 35mm 膠片質感,精準而工整`
- **前置風格句(放 Seedance prompt 第一句)**:`對稱的故事書式電影畫面,完美居中的正中單點透視構圖,平面化舞臺排程,真人實拍照片級寫實,正面均勻柔和的平打光,精調粉彩色板,細膩 35mm 膠片質感,精準工整的運鏡。`

**可選一句主色傾向(從劇本情緒提煉,接在底質子句後,非強制)**:

- 暖糖喜劇:`色板偏暖——腮紅粉、奶油色、黃油黃,點綴一抹正紅`
- 冷調憂鬱:`色板偏冷——青綠、褪色藏青、粉藍,配奶油白`
- 秋日土系:`色板偏秋——芥末黃、赭石、暖棕、森林綠`
- 復古褪色:`色板偏復古褪色——灰玫瑰、橄欖、棕褐、暗金`
- 或按劇本另寫一句,最多一個稍亮點綴色,其餘壓在協調色盤裡。

## 固定種子與出圖規格(速查)

- **四選一方位標註(僅限 MJ 出圖)**:凡 **MJ 出的一組 4 張場景圖(2×2 網格)**,在 agent 選項裡必須**標明 1/2/3/4 對應方位**——**1(左上)、2(右上)、3(左下)、4(右下)**,例:`1(左上)`、`2(右上)`、`3(左下)`、`4(右下)`,方便使用者準確指認。**Lib Image 出的角色造型圖不按 2×2 網格、不標方位。**

- **場景/影調圖 = Midjourney V8.1**,固定種子 `--sref 4926062650 --profile rhc51rh`,**全景無人、零文字、對稱、真人實拍寫實**(人物後續在 Seedance 合成進畫面)。\
  尾串:`… --sref 4926062650 --profile rhc51rh --ar <4:3|16:9|1:1|9:16> --v 8.1 --no 人物, 文字, 詞語, 字母, 數字, 字幕條, 招牌文字, logo, 水印, 多餘圖案, 卡通, 插畫, 微縮模型, 不對稱`

- **人物 + 造型三檢視 = Lib Image**(強制,替代 MJ 出人):**所有角色一次性一起出**——每個角色一張 **16:9 橫構圖**(內含 **4 套正面全身造型**),全部角色出齊後一次性各四選一/確認;確認後**把各角色選定的造型圖作為影象輸入(編輯/圖生圖),用它直接當三視的正面、只補生側/背**,全部角色的白底正 / 側 / 背三檢視一起出,**真人模特**;**只含正、側、背三個全身檢視,不出大頭照/頭部特寫**;**絕不憑文字重新描述生三視**——臉與服裝細節(髮型髮色、款式版型、領口袖口、釦子口袋、印花紋樣、面料、鞋襪、配飾、每處顏色)逐項照選定圖照搬,只換視角。

  - **有原臉素材** → 三視用**白色圓形貼紙遮住臉部**,並在圖**右下角加中文小字:「人臉單獨提供 · 此圖僅用於服裝造型參考」**(身份由原臉在 Seedance 鎖);**無原臉** → 保留所選造型像的臉(臉即身份,不遮)。
  - 要點(以選定造型圖為影象輸入的編輯指令,非從頭描述):`以選定的造型圖作為影象輸入,保持完全相同的人物與服裝,原樣複用為正面檢視不做改動,僅生成同一模特的側視與背視全身圖;整張圖只含正、側、背三個全身檢視,不要出現任何大頭照/頭部特寫/臉部近景;每處細節與參考圖 1:1 一致——相同的臉、髮型與髮色、服裝剪裁與廓形、領口/袖口/下襬、釦子/拉鍊/口袋、印花與紋樣、面料質感、鞋、襪、每一件配飾、每一處顏色;不得重畫臉部,不得重新設計或增刪任何服裝細節;純白無縫背景,均勻柔和的影棚光,照片級寫實(僅當有原臉時:用一個白色圓形貼紙蓋住臉部,並在畫面右下角加中文小字「人臉單獨提供 · 此圖僅用於服裝造型參考」)`
  - 多角色逐個生,維護一份 **cast sheet**(姓名/身份/服裝)。注:Lib Image 無 `--sref`,一致性靠詳細角色卡 + 參考圖 + “跨檢視保持同一模特”。

- **影片 = Seedance 2.0**,輸入 = 場景圖 + 相關角色白底三檢視(鎖造型/身形)+ **人臉參考**(有原臉→原臉圖/影片;無原臉→所選造型像);多角色鏡頭喂多個角色參考。

## 流程(逐階段暫停確認)

### 階段 0 · 開拍前三問(分次問,一次一個,答完再問下一個)

1. **劇本 / 文字**(主驅動):

   - **有劇本 / 文字** → 直接進階段 1 解析成分鏡與人物。
   - **無劇本** → 先問使用者「能不能用**一句話**說一個想法/概念?」。拿到這句話後,**據此草擬一版短劇本**(含人物、場景、關鍵敘事節拍、幾句對白與旁白,貼合 15–30s 短片體量),交使用者確認/修改 → 確認後再進階段 1 解析。
   - 使用者連一句話也給不出時,再和其聊出一個小品概念後照上面草擬。

   > 草擬劇本後暫停確認,再繼續。

2. **角色 + 造型**:① 有無人臉/角色參考(圖或 &lt;15s 影片)?② 有無造型方向/造型參考圖?按下面三 Case 分流。

3. **口語語言**:人物/旁白預設說**劇本本身的語言**;如需另指定則記下。

**三 Case(都先“理解造型方向 + 結合韋氏服裝語言補寫成完整文字 spec”,再生,不丟圖照搬;之後統一:Lib Image 出正面全身造型 → 確認 → Lib Image 出白底三檢視)**:

- **Case 1 有造型參考圖**:造型圖作 Image Reference + 補寫 spec,Lib Image 出造型/三視;無人臉則三視保留臉(臉=身份)。
- **Case 2 有人臉、無造型圖**:人臉圖作 Image Reference + 補寫 spec,Lib Image 出造型/三視;**原臉圖帶進 Seedance 鎖臉;三視用白色圓形貼紙遮臉 + 右下角中文小字「人臉單獨提供 · 此圖僅用於服裝造型參考」**。
- **Case 3 都沒有**:追問**性別(男/女)+ 人種(亞洲/歐美/其他)**,補寫 spec,Lib Image 直接生造型/三視;**所選造型像的臉即身份(三視保留臉),並作 Seedance 人臉參考**。

**韋氏服裝語言(補寫 spec 時對齊)**:`韋氏服裝語言——復古中世紀/vintage 剪裁合身的服裝,制服感的成套搭配,有個性的配飾(貝雷帽、及膝襪、字母花押、剪裁外套、圓框眼鏡),年代考究的道具,精準對稱的造型,配色統一在全片色板之內`;情緒檔不改造型基線,只隨劇本微調配色。

### 階段 1 · 劇本解析 + Final_Video_Spec

**劇本解析(敘事主幹,必出、需確認)**:

- 敘事結構:是否章節式 / 是否有**旁白(narrator)** / 敘事節拍(15s 取 1–2 拍,30s 取 2–3 拍)。
- **人物清單**:列出全部出場人物 + 各自身份/關係。
- **場景清單**:逐場景空間。
- **對白逐句**:標明說話人、原文(劇本語言)。**判斷對白是否過長/繁瑣**——上傳劇本若臺詞冗長,**提煉精簡為貼合 15/30s 的短促臺詞**(保留戲核與人物關係,刪枝蔓),精簡改動需向使用者說明並確認。
- **情緒基調**:逐場景/逐角色情緒走向(用於階段 4 表演賦予)。
- **一句主色傾向**:從基調提煉(見上)。

**Final_Video_Spec(讓使用者定)**:**畫幅**(預設 **4:3 Academy**,開放 16:9 / 1:1 / 9:16)/ **質量**(480p · 720p · 1080p)/ **時長**(**15 或 30s** 二選一)。時長定段數:15→1 段、30→2 段,每段 = 一條 15s。

> 暫停確認(劇本解析結果 + spec)。

### 階段 2 · 角色設計(Lib Image)

**一次性出齊所有角色**(不要一個角色出完確認再出下一個):對每個角色寫角色卡,然後 Lib Image **把全部角色的造型圖一起生出來**(每個角色一張 16:9 橫構圖、內含 4 套正面全身造型)→ **一次性暫停,讓使用者為每個角色各四選一** → **暫停確認(全部角色一起)** → 把各角色選定的造型圖作為影象輸入(編輯/圖生圖):選定正面圖直接當三視正面、只補生側/背,**全部角色的白底三檢視一起出**(真人模特,**只含正/側/背三個全身檢視、不出大頭照或頭部特寫**;有原臉→白色圓形貼紙遮臉 + 右下角中文小字「人臉單獨提供 · 此圖僅用於服裝造型參考」、無原臉→保留臉),**臉與服裝細節嚴格照選定圖、絕不重畫正臉或重設計衣服**;出圖後**逐項核對臉與服裝細節**(髮型、款式版型、領口袖口、釦子口袋、印花、面料、鞋襪、配飾、顏色),任一處歪了就以選定圖為輸入重補該角色的側/背,反覆漂則該角色直接用「選定正面圖 + 側/背兩張」拼三視 → **一次性再暫停確認(全部角色三視一起)**。維護 cast sheet。換裝則再出“造型1/造型2”。

### 階段 3 · MJ 場景影調圖(V8.1,種子 `--sref 4926062650 --profile rhc51rh`)

按場景清單**把所有場景一起出**(不要一場出完確認再出下一場):每個場景各出 1 組 4 張對稱全景空場景(空間型別 + 對稱佈局 + 重要物體 + 正中單點透視構圖),**全景無人、零文字、真人實拍寫實**,接底質子句 + 一句主色 + 場景種子尾串(見速查)。\
**全部場景圖一次性出齊 → 一次性暫停,讓使用者為每個場景各四選一(選項須按** `1(左上)/2(右上)/3(左下)/4(右下)` **標註方位)→ 收齊所有場景的選擇後才進階段 4**,**嚴禁未經四選一就進階段 4**。

> 🛑 強制門:所有場景圖出齊後一次性停下,等使用者逐場四選一;沒收齊全部場景的選擇前不得進下一階段。

### 階段 4 · 分鏡指令碼(生影片前必出、需確認)—— 重頭戲

**以表格逐段逐鏡輸出**,每段一張表、每鏡一行,列如下:

鏡號畫面(角色排程+表演+場景+對稱構圖)對白/旁白(標說話人·劇本語言)投遞語氣秒數運鏡與上鏡轉場連戲要點鏡1………\~Xs鎖定/橫軌/急搖/猛推/俯拍平鋪/定格慢走硬切/急搖/match cut站位·軸線·道具·色板·節拍

欄位說明:

- **投遞語氣**按劇本情緒賦予,不預設 deadpan。
- **秒數**每鏡相加 = 15s;每段 **每 15s 鏡數見下表**,標好急搖/硬切位置與定格慢走落點;轉場基本不溶解。
- **連戲要點**填:角色身份-服裝-手持道具 / 銀幕方向-180°軸線-角色 L-R 站位-佈景地理 / 同一場景種子-主色-打光方向-時辰 / 當前節拍-情緒延續 /(30s 時)seg1 尾幀→seg2 頭幀的動作銜接。

> 暫停確認(造型圖 + 三檢視 + 場景圖 + 分鏡指令碼表)。

### 階段 4b · 30s 尾幀續接(逐條生的關鍵機制)

生完第 1 條 → 用 ffmpeg 抽**尾幀** → **解析尾幀**(角色站位/表情/光線/景別/進行中的動作)→ 按分鏡宣告的接縫模式生第 2 條:

- **(A) 連續動作**:尾幀作 Seedance **起始幀**,第 2 條續上動作,無縫。
- **(B) 乾淨硬切到新機位**:尾幀僅作連戲參考(角色/服裝/色板/光線),第 2 條全新對稱設定;裝配處硬切/急搖/match cut 相接。

> 大的對稱硬切儘量放在兩條接縫處(單條 15s 內部做差異巨大的對稱硬切對模型偏難)。

### 階段 5 · Seedance 影片(每段一條 15s,一條一條生)

prompt 結構(順序):

1. **前置風格句**(全片統一,見上)。
2. **角色組裝**:白底三檢視鎖造型/身形 + 人臉參考鎖身份(有原臉→原臉圖/影片;Case 3→所選造型像);多角色喂多個參考。寫明“每個角色臉取自其人臉參考、造型取自其三檢視,放進場景圖,保留真實長相”。
3. **分鏡**:`鏡1 … 切至/急搖至 鏡2 …`,一條連續 15s、鏡數達標;**轉場以硬切/急搖/match cut 為主,基本不溶解**。每鏡 = 景別(對稱機位)+ 運動 + 表演(**按劇本情緒賦予**)。
4. **口語層**:逐句對白(標說話人、**口型同步**、**臺詞文字用劇本語言,可中可英**)+ 旁白 VO + 投遞語氣。例(指令用中文,臺詞填劇本原文):`人物開口說出臺詞並精準對口型,旁白畫外音;臺詞內容:「<劇本原文臺詞>」`。
5. **運動**:`精準工整的運鏡——鎖定的對稱定格、平穩的橫向軌道滑軌、急搖轉場、猛推猛拉變焦、俯拍平鋪插入、偶爾的定格慢走`;一鏡到底僅按需。
6. **音訊 + 文字規則**:對白/旁白隨影片生,**音樂/SFX 不生(裝配鋪)**:`對白與旁白在影片內開口說出,無背景音樂,無音效(後期新增)`;**出場人數嚴格等於劇本人物數(紅線 5)**;負面 `字幕, 字幕條, 多餘人物, 背景群演, 人群, 額外的人, 畫面文字, 招牌文字, logo, 水印, 多餘圖案, 卡通, 插畫, 微縮模型, 不對稱, 多餘手指, 畸形的手`。

**表演賦予(按劇本,不強制 deadpan)**:逐鏡≥1 表情 + 1 動作,情緒強度按場景走(雀躍/焦慮/溫柔/失落/剋制皆可),只是包進韋氏工整外殼(對稱、平穩排程)。\
**通用治僵硬(每鏡都加)**:`輕微呼吸使胸口自然起伏,細微的頭部移動,自然眨眼,表情隨該鏡情緒緩緩變化,放鬆自然的姿態,富有生氣、有緩入緩出的自然動作`。

> 一條一條生,逐條確認。

### 階段 5(實現備註) · 旁白兜底

旁白預設隨影片生(VO 層);若模型對“無對應嘴部的 VO 旁白”支援不穩,**退回裝配 VO**(TTS/錄音疊加),其餘規則不變。

### 階段 6 · 裝配

1. **順接**:兩段 15s **硬切 / 急搖 / match cut 順接**(韋氏不溶解);生成片段已含對白/旁白。
2. **鋪音**:統一**鋪 BGM / SFX**(生成片段本就無 BGM/SFX)。
3. **加字幕(**`add_subtitle`**)**:給**角色臺詞**加字幕——問使用者**中文 / 英文 / 雙語 / 不要**,按選擇把臺詞原文/譯文做成字幕軌疊加到畫面(不燒進生成幀,作為可編輯疊加層);臺詞文案取自階段 1/4 已記錄的對白(旁白是否上字幕隨使用者)。字幕**只在此步加**,SD2 生影片階段絕不出現(見紅線 3)。
4. **疊圖**:logo / 標題 / credits PNG 可疊(絕不燒進生成畫面)。
5. 引導匯出。
