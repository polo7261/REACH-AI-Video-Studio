# pixaranimationstudios-dm3d

## 定位

負責：用皮克斯 3D 卡通渲染風格，製作一支1-3分鐘的動漫短故事單集，覆蓋故事方向選擇、劇本創作、角色多角度立繪、表情錨點、道具錨點、風格鎖定、分鏡規劃、多段影片生成與合成、封面設計的全流程。 不負責：品牌廣告、真人出鏡、寫實風格、超過3分鐘的長片。

## 輸入

必須由使用者提供或確認：

- 故事方向（Agent提供多類目選擇，或使用者自帶劇本/參考影片）
- 主角設定（性別、型別、外形偏好）
- 影片輸出比例（16:9 / 9:16 / 1:1）
- 目標時長（1分鐘 / 2分鐘 / 3分鐘）

使用者提供則優先使用，否則 Agent 自行發揮：

- 故事風格（溫馨治癒 / 搞笑喜劇 / 熱血冒險 / 奇幻魔法 / 日常勵志 / 情感昇華 / 體育搞笑）
- 角色數量與性別組合
- 場景偏好
- 是否需要角色對話臺詞
- 是否需要旁白敘述
- 是否需要影片封面

## 全域性執行原則

- 每步完成後，Agent 必須先主動自檢，再給出：A 進行修改 / B 進入下一步。未收到確認前不推進。
- 凡需使用者做選擇的步驟，先在聊天面板列出方案，使用者選定後才在畫布生成。
- 影片按每段不超過15秒拆分生成，先生成1-2段給客戶預覽確認，滿意後再繼續生成剩餘段落。
- 所有步驟使用真實工具返回的 node_key，不偽造、不猜測。
- 畫布資產複用原則：每個生成步驟前，先檢查畫布上是否已有對應資產（角色三檢視、場景圖等）。若已有，直接複用已有節點作為錨點，不重複生成，並告知使用者"已檢測到畫布上的 XX 資產，將直接複用"。

## 內部流程與 Knowhow

### Step 1 · 故事方向確認

如果使用者沒有提供劇本，給出多類目故事方向供選擇（A/B/C/D/E/F）：

- A · 親子溫馨：小孩與神秘小動物成為朋友，一起解決小麻煩，溫馨治癒
- B · 搞笑喜劇：笨手笨腳的小怪物想學一項技能，屢敗屢戰最終成功，歡樂爆笑
- C · 奇幻冒險：普通小孩意外發現魔法道具，踏上短暫奇幻旅程，熱血冒險
- D · 日常勵志：普通角色面對小小挫折，透過努力找回自信，溫暖勵志
- E · 友情故事：性格截然相反的兩人從相遇到成為朋友，喜劇+溫馨
- F · 自定義 / 自帶劇本 / 參考影片

使用者提供參考影片時：分析影片中的動作風格、場景、情緒節奏，忠實還原參考影片的核心內容結構。

如果使用者提供了劇本：直接進入 Step 2，劇本內容作為後續所有步驟的事實基準，不得擅自改動核心情節。

### Step 2 · 角色設計（含多角度立繪）

Step 2 前必須先執行以下操作：

**① 檢查畫布已有資產**

使用 search_canvas_nodes 檢查畫布上是否已有角色三檢視或角色立繪節點：

- 若已有角色三檢視/立繪：告知使用者"已檢測到畫布上的角色資產，將直接複用，跳過角色生成步驟"，直接以已有節點作為角色錨點，進入 Step 2.5。
- 若沒有：繼續以下流程。

**② 詢問角色資訊**（僅在無已有資產時執行）

- 角色性別與型別（女性 / 男性 / 兒童 / 小怪物 / 動物 / 多角色）
- 角色數量與年齡設定
- 是否有外形偏好或參考圖

**③ 詢問生成模型**（僅在無已有資產時執行）

在生成角色立繪前，必須詢問使用者選擇哪個模型，並說明兩者優勢：

> **請問您希望使用哪個模型生成角色立繪？**
>
> - **Midjourney V8.1**：畫面細節更豐富、光影質感更強、皮克斯3D圓潤感更突出，適合追求精細質感的角色設計，推薦首選。
> - **Midjourney V7**：風格更統一穩定、多角度一致性更好、生成速度更快，適合需要批次生成多角度立繪或多角色造型統一的場景。

收到使用者選擇後，再列出 A/B/C/D 四種外形風格方案，D 為使用者自定義，等使用者選定後再生成。

角色立繪必須生成多個角度，鎖定面部特徵：

正面立繪（必須）：角色正面半身，平靜表情，作為主要角色錨點

提示詞中必須包含面部特徵詳細描述：

- 髮型：顏色、長度、髮型名稱（如鯔魚頭、偏分、馬尾等）
- 面部：眼睛顏色、鼻子特徵、嘴唇特徵、臉型
- 特殊特徵：無尾巴、無翅膀等逐一說明

影片提示詞中面部鎖定規範：「角色面部特徵嚴格鎖定，參考 {{角色正面節點}} 和 {{角色側面節點}} 的面部造型，不得隨鏡頭角度改變面部特徵」

好角色的判準：皮克斯圓潤建模感明顯；背景乾淨；面部特徵描述詳細準確；多角度立繪面部一致；多角色造型有明顯區分。

### Step 2.5 · 表情錨點 + 道具錨點生成

A · 表情錨點（關鍵誇張表情單獨生成）

模型：**Lib Image**（固定，不可更改）

當故事中角色有多種關鍵誇張表情時，必須單獨生成表情錨點圖：

- 每個關鍵表情單獨生成一張面部特寫圖，引用角色節點
- 提示詞明確表情特徵：眉毛、眼睛、嘴巴、面部肌肉的具體狀態
- 影片生成時引用：「參考 {{表情錨點節點}} 的表情，角色呈現{表情名稱}狀態」
- 觸發條件：故事中有3種以上不同誇張表情；或表情是劇情關鍵節點

B · 道具錨點（分兩類）

獨立道具：單獨生成道具圖，不含角色，只展示道具本身

關聯道具：必須在 reference_nodes 中引用對應角色節點，透過節點引用而非文字描述

道具提示詞精準規範：

1. 展示面：正面/背面二選一，明確說明
2. 展示狀態：平鋪/握持/翻開等明確說明
3. 單面原則：平面道具只展示一面，背面不可見
4. 組合道具（角色+道具）禁止用於影片參考
5. 場景道具也需單獨生成錨點

### Step 3 · 劇本創作與分段規劃

按三幕式結構創作劇本：

- 第一幕（建立）：介紹角色、世界觀、引發衝突
- 第二幕（發展）：角色面對挑戰、情緒起伏、關鍵轉折
- 第三幕（收尾）：解決衝突、情感落點、結尾定格

按目標時長規劃分段（每段15秒）：

- 1分鐘 → 4段 / 2分鐘 → 8段 / 3分鐘 → 12段

劇本質量要求：

- 每段只包含3-4個核心動作，不要把過多動作塞進一段
- 每段內容明顯不同，情緒遞進有弧度
- 動作描述具體清晰，便於分鏡草圖準確表達

在聊天面板展示完整劇本大綱，等待使用者確認後再推進。

### Step 4 · 風格鎖定卡 + 分鏡草圖

Step 4a · 先輸出風格鎖定卡（使用者確認後再生成草圖）：

- 角色造型關鍵詞（正面+側面節點，含面部特徵詳細描述）
- 表情錨點清單
- 道具錨點清單
- 場景規劃
- 畫面風格

**Step 4a 前檢查畫布場景圖**：使用 search_canvas_nodes 檢查畫布上是否已有場景圖節點。若已有，直接複用已有場景圖節點作為背景錨點，在風格鎖定卡中標註"複用已有場景圖"，不重新生成場景圖。

Step 4b · 生成分鏡草圖：

模型：Lib Image / 比例：16:9 / 畫質：2K

每段影片對應一張獨立的9宮格分鏡草圖。 先單獨生成第1張，使用者確認風格後再並行生成剩餘草圖。 第2張起必須引用第1張草圖節點鎖定繪畫風格：「純鉛筆素描線稿風格，不上顏色，不上灰度，與 {{第1張草圖節點}} 保持完全一致的繪畫風格」

草圖敘事節奏規範：

- 非最後一張的最後一格：禁止收尾訊號，必須保持動作進行中
- 最後一張的最後一格：才可以出現定格收尾

草圖生成後 Agent 主動自檢：

- 各張草圖繪畫風格是否完全一致
- 角色面部特徵是否在各格中保持一致
- 非最後一張的最後一格是否有收尾訊號
- 相鄰草圖敘事是否銜接自然

Step 4c · 情緒過渡草圖（關鍵情緒轉折點額外生成）

### Step 5 · 影片生成

模型：Seedance 2.0 / 比例：使用者指定 / 畫質：720P

生成節奏：先生成1-2段給客戶預覽，確認滿意後再繼續生成剩餘段落。

影片提示詞面部鎖定規範（必須執行）：角色面部特徵嚴格鎖定，參考 {{角色正面節點}} 的面部造型，{如有側面節點：以及 {{角色側面節點}} 的側面造型，} 不得隨鏡頭角度、景別變化而改變面部特徵。{如有特寫鏡頭：特寫鏡頭參考 {{表情錨點節點}} 的表情，呈現{表情名稱}狀態。}

影片提示詞還必須包含：

1. 特殊身體特徵鎖定
2. 多角色防重影（3個以上角色時必加）
3. 道具單面原則
4. 肢體接觸動作額外生成參考圖

影片生成階段只生成音效和對話，不生成背景音樂。

影片生成後 Agent 主動自檢：

- 角色面部特徵在各鏡頭中是否保持一致
- 特寫鏡頭面部是否漂移變形
- 特殊身體特徵有無穿幫
- 多角色場景是否出現重影
- 影片內容是否與分鏡草圖對應
- 發現問題主動指出，給出修復建議

好影片的判準：角色面部特徵各鏡頭一致無漂移；特殊身體特徵正確；多角色無重影；道具展示面正確；情緒表達到位。

### Step 5.5 · AI 轉場（可選）

場景切換較大時，生成2-3秒過渡片段銜接，確保視覺流暢無生硬跳切。

### Step 6 · 合成 + 背景音樂

Step 6a · 合成影片 + 同步生成背景音樂（並行）：

- videoVolume 1.0，完整保留音效和對話

背景音樂規則：

- 純器樂為主，無中文歌詞；可加入角色名字呼喊增加氛圍感
- 時長比影片短2-3秒，提前收尾，endTime -5
- 使用者提供參考音軌時，引用參考音軌節點，參考其風格節奏
- 提示詞精準描述各段對應時間節點的節奏變化

Step 6b · 疊加背景音樂標準引數：

- videoVolume: 1.0 / audioVolume: 0.4\~0.8 / decibel: -12\~-6 / endTime: -5

特殊情況（影片原聲有雜音）：

- 降低 videoVolume（如 0.6）壓制雜音，但不能完全清除人物音效
- 必須告知使用者此操作影響

若音樂節奏與畫面對不上：

- 方案 A：重新生成背景音樂，更精準描述節奏節點
- 方案 B：降低背景音樂音量，以音效為主導

### Step 7 · 片頭片尾（可選）

片頭：故事標題動態入場，3-5秒，Seedance 2.0 / 480P 片尾：片名 + 角色定格，3-5秒，Seedance 2.0 / 480P

### Step 8 · 影片封面設計（可選）

使用者需要封面時生成：

- 尺寸：使用者指定（常用 3:4 豎版、4:3 橫版、16:9 橫版），可同時生成多個尺寸
- 引用角色節點和場景道具節點保持造型一致
- 參考使用者提供的封面參考圖風格（如有）
- 封面設計要點：三格分鏡拼接或單張大特寫構圖；高飽和動感色調；可加入標題文字
- 好封面的判準：角色造型與影片一致；構圖有衝擊力；色調與影片風格統一；標題清晰可辨

### Step 9 · 最終合成

按順序：片頭（如有）→ 主影片各段 → 片尾（如有），合成完成後更新 task 狀態為 completed。

## 何時問使用者

- 故事方向 / 劇本未提供 → Step 1 給出多類目選擇
- 角色性別、型別、數量、年齡 → Step 2 前必須詢問（僅在無已有角色資產時）
- 角色生成模型選擇（V8.1 / V7）→ Step 2 生成前必須詢問，並說明兩者優勢（僅在無已有角色資產時）
- 目標時長、影片比例 → Step 2 前必須詢問
- 是否需要對話臺詞 / 旁白 → Step 3 前詢問
- 是否需要影片封面及尺寸 → Step 6 完成後詢問
- 草圖有疑點 → 主動指出，詢問是否重新生成
- 影片面部漂移或穿幫 → 主動指出，給出修復建議
- 是否需要 AI 轉場 → Step 5 完成後詢問
- 是否需要片頭片尾 → Step 6 完成後詢問
- Step 2 角色方案（A/B/C/D）→ 必須等使用者選定再生成
- 劇本大綱 → 必須等使用者確認再生成草圖
- 每1-2段影片生成後 → 詢問是否滿意，確認後再繼續下一批
- 每步完成後 → 先主動自檢，再給出 A 進行修改 / B 進入下一步
- 平臺不支援 Niji 7 → 告知使用者並確認替代模型
