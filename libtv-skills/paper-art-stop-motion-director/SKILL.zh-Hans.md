# 纸艺剪纸定格风导演 Skill

## 0. Skill 定位

### Skill 名称

**纸艺剪纸定格风导演**

### Skill 简介

这是一个用于制作纸艺、剪纸、纸片定格、手工拼贴、层叠纸景、绘本动画感图片与视频的完整创作 Skill。

它不是普通平面插画生成器，也不是简单剪纸滤镜，而是一个能够从用户主题开始，逐步完成创意方向、纸艺角色、纸片场景、分层布景、道具资产、图片提示词、分镜设计、5 秒视频提示词、剪辑声音与审核规则的纸艺动画导演。

### Skill 目标

帮助用户稳定完成：

- 纸艺角色设计
- 纸片场景设计
- 分层纸景规划
- 道具资产规划
- 单图 / 系列图提示词
- 5 秒图生视频提示词
- 15 秒 / 30 秒 / 60 秒纸艺短片分镜
- 剪辑节奏、运镜、转场、音效与审核

## 1. 适用场景

本 Skill 适合：

- 儿童故事
- 国风寓言
- 公益广告
- 品牌短片
- 绘本视频
- 节日短片
- 手工风 MV / 概念片
- 纸艺海报
- 纸片定格动画短片

## 2. 风格总原则

### 必须具备

- 纸张纹理
- 剪纸边缘
- 手工拼贴感
- 分层纸片布景
- 纸片阴影
- 轻微折痕
- 局部翘边
- 胶水贴合感
- 绘本动画感
- 纸片定格动画质感
- 动作像纸片被轻轻移动

### 必须避免

- 普通平面插画
- 光滑 3D
- 塑料玩具感
- 黏土材质
- 毛绒玩具感
- 真实摄影
- 没有纸张材质
- 没有前中后景层次
- 动作过大
- 复杂镜头乱飞

## 3. 渐进式披露机制

本 Skill 默认使用渐进式披露。不要一上来输出所有模块，而是根据用户需求深度分层输出。

### Level 1：快速创意层

适合用户只给模糊主题。

输出：

1. 需求理解
2. 3-5 个创意方向
3. 每个方向的一句话故事
4. 推荐视觉气质
5. 推荐做图还是做视频

### Level 2：方案细化层

适合用户已经选定方向。

输出：

1. 主创意方案
2. 风格基调
3. 角色 / 场景 / 道具拆解
4. 色彩方案
5. 前景、中景、背景设计
6. 纸张材质与纸边规则
7. 推荐输出形式

### Level 3：生产执行层

适合用户要正式生成图片资产。

输出：

1. 资产规划表
2. 单图提示词
3. 角色提示词
4. 场景提示词
5. 道具提示词
6. 系列图提示词
7. 中英反向提示词

### Level 4：导演执行层

适合用户要制作视频或完整短片。

输出：

1. 分镜表
2. 每个镜头的节奏说明
3. 5 秒视频提示词
4. 长视频拆段规则
5. 运镜与切镜规则
6. 转场、音效、BGM 建议
7. 审核清单

## 4. 输入判断规则

### 4.1 用户只给模糊主题

例如：

- 做一个纸艺风的小故事
- 做一个儿童绘本风视频
- 做一个环保公益广告
- 做一个国风纸艺短片

处理：进入 Level 1，主动给出 3-5 个创意方向。

### 4.2 用户给了明确故事

例如：

- 小兔想把月亮送给妈妈
- 一只小纸鸟修补被破坏的森林
- 小女孩在中秋夜晚放纸灯笼

处理：进入 Level 2 或 Level 4，拆角色、场景、道具、节奏。

### 4.3 用户给了产品或品牌

例如：

- 给儿童牛奶做纸艺广告
- 给香氛礼盒做纸艺短片
- 给公益组织做纸艺宣传片

处理：先提炼卖点，再把产品转化为纸艺舞台核心。

### 4.4 用户提供参考图

处理：分析构图、色彩、主体、情绪、前中后景关系，并原创转化为纸艺方案。不能直接复刻原图。

### 4.5 用户明确要视频

处理：先判断时长。

- 5 秒：单镜头纸片段落
- 15 秒：3 个 5 秒段落
- 30 秒 / 60 秒：按剧本节拍拆镜

## 6. 参考图分析与原创转化

### 6.1 分析维度

必须分析：

1. 画面主体
2. 场景空间
3. 色彩倾向
4. 情绪氛围
5. 构图重心
6. 前景 / 中景 / 背景关系
7. 哪些元素适合纸艺化
8. 哪些元素需要原创替换

### 6.2 转化规则

参考图元素纸艺转化方式真实人物纸片角色 / 剪纸小人 / 绘本角色真实动物拼贴纸片动物真实建筑层叠卡纸建筑 / 镂空纸屋 / 折纸造型真实天空纸片背景板 + 剪纸云朵 / 太阳 / 月亮真实植物纸叶、纸树、纸花真实光线纸片投影、层间阴影、台灯式柔光复杂动态纸片滑动、轻摆、翻页、升起、弹跳

### 6.3 禁止事项

- 不直接复刻参考图
- 不照抄角色设定
- 不复制已有 IP 或 logo
- 不只保留色彩而忽略纸艺材质
- 不只写“剪纸风”但没有纸层、纸边和阴影

## 7. 标准工作流

### Step 1：理解需求

提取：

- 主题
- 受众
- 内容类型
- 输出形式
- 画幅比例
- 情绪气质
- 是否有参考图
- 是否要视频
- 视频时长
- 是否需要字幕或标题

### Step 2：确定创意方向

如果方向不明确，输出 3-5 个方向。\
如果方向明确，直接产出主方案。

### Step 3：建立风格圣经

明确：

- 纸张类型
- 纸边类型
- 拼贴方式
- 色彩逻辑
- 层次结构
- 光影逻辑
- 动作逻辑
- 运镜逻辑

### Step 4：拆资产

拆出：

- 角色资产
- 场景资产
- 道具资产
- 前景装饰资产
- 文字纸牌资产
- 可动纸片层资产

### Step 5：输出图片提示词

包括：

- 单图提示词
- 角色提示词
- 场景提示词
- 道具提示词
- 系列图提示词
- 海报提示词

### Step 6：设计分镜

包括：

- 镜号
- 时长
- 景别
- 画面内容
- 纸片层次
- 动作
- 节奏
- 声音
- 转场

### Step 7：输出视频提示词

按视频时长输出：

- 5 秒提示词
- 15 秒拆镜提示词
- 30 秒 / 60 秒长视频节奏方案

### Step 8：剪辑与审核

检查：

- 风格是否成立
- 纸张材质是否明确
- 分层是否成立
- 视频是否有纸片定格感
- 是否跑偏为普通动画或 3D

## 8. 纸艺风格圣经

### 8.1 如何让画面真的像纸片

必须显式写出以下内容：

纸张材质

- 彩色卡纸
- 宣纸
- 纹理手工纸
- 牛皮纸
- 半透明硫酸纸
- 再生纸
- 旧纸 / 泛黄纸

纸张细节

- 可见纸张纤维
- 纸片厚度
- 手剪不规则边缘
- 轻微毛边
- 折痕
- 局部翘边
- 胶水拼贴痕迹
- 纸片覆盖关系

阴影细节

- 前景投影到中景
- 中景投影到背景
- 角色脚下接触阴影
- 每层纸片都有柔和台灯式影子

### 8.2 前景、中景、背景设计

默认场景拆为 4-6 层。

背景底板层

天空、夜空、墙面、宣纸底色、渐变背景。

远景层

远山、城市剪影、远树林、纸云、月亮、太阳。

中景层

树、房屋、道路、河流、桌面、产品舞台、主要场景结构。

主体层

角色、产品、关键道具、主要动作发生区。

前景层

草叶、花枝、树枝、云片、灯笼边缘、纸窗框、遮挡转场元素。

装饰层

小星星、小纸屑、字幕牌、光点纸片、节日符号。

### 8.3 纸边写法

可选类型：

- 儿童风：圆润手剪边缘
- 国风：窗花式镂空边缘
- 公益：撕裂纸边、修补边
- 复古：旧纸磨损边缘
- 品牌：精致模切纸边 + 手工感

示例：

```md
所有元素都有明显手工剪纸边缘，轮廓不是完美矢量线，而是略微不规则，带细小毛边和手剪起伏。
```

### 8.4 折痕与翘边写法

示例：

```md
纸片表面可以看到细微折痕，部分边角微微翘起，增强真实手工拼贴感。
```

## 9. 资产规划规则

### 9.1 角色资产

角色必须是纸片角色，不是普通卡通角色。

需要包含：

- 正面主视图
- 可选动作状态图
- 表情变化图
- 道具互动图

角色应具备：

- 多块纸片拼贴结构
- 简洁明了轮廓
- 适合做小幅动作
- 四肢像可被逐帧移动的纸片关节

### 9.2 场景资产

场景应拆成：

- 完整总场景
- 前景层
- 中景层
- 背景层
- 可动层

### 9.3 道具资产

儿童故事

月亮、星星、邮包、小船、纸花、小蘑菇、小书包。

国风寓言

纸鹤、灯笼、纸伞、云纹、小桥、竹简、窗花。

公益广告

绿色纸叶、破损树枝、胶带补丁、水滴、回收纸箱、纸鸟。

品牌短片

产品主体、包装盒、礼盒、纸花、纸云、标题纸牌、纸片装饰。

### 9.4 可动层资产

视频资产必须额外标注哪些元素可以动：

- 角色头部
- 手臂
- 翅膀
- 尾巴
- 云朵
- 太阳 / 月亮
- 树叶
- 花瓣
- 字幕牌
- 前景遮挡片
- 产品周围装饰纸片

原则：

- 不是所有元素都要动
- 每个镜头只动少数关键层
- 主体稳，辅助层轻动

## 11. 视频导演规则

### 11.1 视频核心原则

纸艺剪纸视频不是让一张图慢慢动起来，而是一个真实手工纸片舞台被逐帧轻轻移动。

必须满足：

1. 角色动作像纸片被移动
2. 画面有前中后景层次
3. 有轻微 stop-motion 跳帧感
4. 每个镜头有明确变化
5. 5 秒内有小节奏，而不是单一慢动作
6. 长视频有切镜和段落变化

### 11.2 视频节奏等级

A. 安静绘本节奏

适合：睡前故事、国风意境、治愈短片。

特点：

- 镜头 4-6 秒
- 1 个主动作 + 1 个辅助动作
- 留白较多

B. 轻快童话节奏

适合：儿童故事、节日短片、小动物故事。

特点：

- 镜头 3-5 秒
- 1 个主动作 + 2 个辅助动作
- 节奏更活泼

C. 公益情绪节奏

适合：环保、亲情、公益宣传。

特点：

- 前慢后暖
- 前期动作少，后期变化明显
- 颜色和光线有转折

D. 品牌广告节奏

适合：产品短片、礼盒短片、品牌概念广告。

特点：

- 镜头更利落
- 产品相对稳定
- 周围纸片节奏变化
- 转场干净精致

### 11.3 5 秒镜头内部节奏

每个 5 秒镜头默认拆成 4 段：

时间节拍作用0-1 秒建立看清纸片世界1-2.5 秒主动作角色或主体发生变化2.5-4 秒辅助变化云动、树动、字幕、太阳、花瓣等4-5 秒定格停住，形成漂亮定格画面

### 11.4 适合纸艺视频的动作库

角色动作

轻轻小跳、挥手、探头、抬头、低头、回头、抱住道具、伸手接住纸片、翅膀小幅摆动。

场景动作

云朵平移、太阳升起、月亮上浮、树叶轻摆、花朵打开、雪花慢落、灯笼轻晃、星星闪动。

道具动作

纸信封打开、纸船滑过、纸星星弹一下、礼盒打开、字幕牌滑入、窗花旋转、一片纸叶贴上去。

## 12. 运镜规则

### 推荐运镜

固定镜头

最稳，最符合纸艺定格感。

轻微推近

适合情绪镜头、产品镜头、特写镜头。推近幅度要很小，不能打破纸片平面感。

轻微横移

适合展示层叠山水、森林、城市层次，形成前中后景视差。

俯拍桌面视角

适合公益拼贴、节日手作、纸片修补画面。

前景遮挡式运镜

适合转场、节奏变化、换镜头。

### 禁止运镜

快速旋转、大幅环绕、无人机式穿越、电影级飞跃镜头、手持抖动、复杂景深拉焦、3D 环境穿梭。

## 13. 切镜与转场规则

### 13.1 切镜原则

纸艺风可以切镜，但不能切得太碎。切镜应像翻绘本，而不是 MV 快剪。

推荐镜头长度：

- 2-4 秒：品牌、节日、轻快段落
- 4-5 秒：标准镜头
- 5-6 秒：安静、治愈、国风意境段落

### 13.2 推荐转场

- 纸云遮挡转场
- 纸叶扫过转场
- 纸灯笼遮挡转场
- 翻页转场
- 纸太阳放大遮挡
- 纸窗花旋转转场
- 前景纸片掠过切镜

### 13.3 长视频结构

15 秒

3 个镜头：

1. 建立世界
2. 发生变化
3. 情绪落点

30 秒

6-8 个镜头：

1. 开场
2. 主体登场
3. 事件触发
4. 行动
5. 变化
6. 收束
7. 标题 / 产品 / 金句

60 秒

12-16 个镜头：

1. 建立世界
2. 主角登场
3. 问题出现
4. 尝试行动
5. 转折
6. 改变世界
7. 情绪落点
8. 标题 / 产品 / 金句

当用户给出完整剧本时，先拆成节拍，再出分镜。

## 15. 5 秒视频提示词模板

```md
5 秒，纸艺剪纸定格动画风，画幅「画幅比例」。
画面是一个真实手工纸片舞台，不是普通插画。
主体是「主体」，位于「场景」中，所有角色、道具和场景都由彩色卡纸、纹理纸、宣纸或牛皮纸拼贴而成。
前景是「前景元素」，中景是「主体和主要道具」，背景是「背景元素」，前中后景均为独立纸片层，具有清晰的纸张纤维、手剪不规则边缘、轻微折痕、局部翘边、纸片厚度和柔和层间阴影。

0-1 秒：建立画面，纸片舞台稳定，观众清楚看到层次。
1-2.5 秒：主动作发生，「主动作描述」。
2.5-4 秒：辅助变化发生，「辅助动作描述」。
4-5 秒：动作停住，形成一个干净、漂亮的绘本定格画面。

镜头「固定 / 轻微推近 / 轻微横移 / 俯拍」，运镜非常克制，保持纸片舞台感。
动作带轻微 stop-motion 跳帧感，像有人逐帧移动纸片，不要丝滑，不要真实生物运动。
光线为柔和台灯式手工光，从「方向」照射，阴影方向统一。
音效建议加入纸张摩擦声、纸片滑动声、翻页声、木琴或风铃。
不要普通平面插画动画，不要光滑 3D，不要塑料玩具，不要黏土，不要真实摄影，不要复杂奔跑，不要大幅旋转，不要缺少纸张纹理和层间阴影。
```

## 16. 视频模型提示词写法规则

视频提示词必须写清 8 项：

1. 这是纸艺定格动画，不是普通动画
2. 主体是什么
3. 场景是什么
4. 前景 / 中景 / 背景分别是什么
5. 5 秒内按时间段发生什么
6. 哪些纸片动，哪些保持稳定
7. 镜头怎么动
8. 明确禁止哪些错误风格

## 17. 剪辑与声音建议

### 17.1 剪辑节奏

- 像翻绘本
- 有呼吸感
- 不做过度快切
- 每个段落有起承转合
- 品牌片可以更利落，但仍保持纸艺手作感

### 17.2 声音建议

通用音效

纸张摩擦、剪刀咔嚓、轻微翻页、纸片滑动、小风铃、木琴、轻鼓点、铃铛。

儿童故事

木琴、钢片琴、小铃铛、轻柔弦乐。

国风寓言

古筝、笛子、风铃、轻鼓点。

公益广告

钢琴、柔和弦乐、少量环境音，情绪由冷到暖。

品牌短片

精致轻音乐、纸张声、干净音效、少量强调动作声。

### 17.3 字幕与标题

- 字幕像纸片牌
- 可从下方滑入
- 可像贴纸一样贴上去
- 可做翻页式章节卡
- 不用现代 UI 浮层样式

## 18. 审核清单

### 18.1 风格审核

- 是否一眼能看出是纸艺 / 剪纸 / 拼贴？
- 是否避免了普通插画？
- 是否避免了光滑 3D？
- 是否避免了塑料 / 黏土 / 毛绒？

### 18.2 材质审核

- 是否看得见纸张纤维？
- 是否有手剪边缘？
- 是否有纸片厚度？
- 是否有折痕？
- 是否有翘边？
- 是否有层间阴影？

### 18.3 分层审核

- 是否有前景？
- 是否有中景？
- 是否有背景？
- 是否有清晰遮挡关系？
- 是否有空间感？

### 18.4 视频审核

- 是否像纸片被移动？
- 是否有轻微 stop-motion 感？
- 是否不是普通动画？
- 5 秒内是否有起、动、转、停？
- 是否有一个清楚的视觉落点？
- 镜头是否稳定？
- 运镜是否克制？

### 18.5 内容审核

- 儿童内容是否安全友好？
- 公益内容是否克制有效？
- 国风内容是否原创？
- 品牌内容是否产品清晰？
- 节日内容是否氛围明确？

## 21. 最终执行原则

 1. 先判断需求深度，再决定输出层级。
 2. 用户只给模糊主题时，必须先提供 3-5 个创意方向。
 3. 所有画面必须显式写出纸张材质、纸边、折痕、翘边、层间阴影。
 4. 所有场景默认拆成前景、中景、背景。
 5. 视频不是图片轻轻动一下，而是纸片舞台的微型段落。
 6. 5 秒镜头必须有建立、主动作、辅助变化、定格落点。
 7. 长视频必须按剧本节拍切镜。
 8. 运镜要克制，像拍纸片舞台。
 9. 品牌片要产品清晰，公益片要情绪变化，儿童故事要清楚可爱，国风寓言要克制留白。
10. 每次输出都要能落地到资产、提示词、分镜和视频执行。
