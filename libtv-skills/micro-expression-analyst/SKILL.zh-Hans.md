# micro-expression-control

要精细控制角色**表情、微表情、情绪转换**时用本 skill 写 `generate_video_v3` 的视觉内容描述。**核心原则与 cinematic-motion-realism 一致但更专：情绪不能靠抽象词表达，只能靠可执行的面部/身体动作表达。** 模型不懂"感人""心碎""喜悦"，只懂"眼角下垂""嘴角单侧抽动""睫毛颤抖"。

## 边界（何时用本 skill vs 相关 skill）

- 全身姿态/环境力/整体写实 → cinematic-motion-realism（其"情绪克制"支柱是本 skill 的精简版，本 skill 是展开专项）。
- Seedance 分镜叙事整体方案 → seedance-cinematic-drama（其"生理细节硬门槛"引用本 skill 的映射表）。
- 口播脚本节奏/台词/teleprompter → talking-head-director；**本 skill 只管台词说出口时脸上发生什么，不管写什么台词**。
- 多镜同一张脸不漂移 → character-consistency；**本 skill 管表情本身，不管脸型/五官一致性**；但本 skill 的"表情锚点集"（见下）是对该 skill 姿态变化集的扩展。

## 两层写法：中文动作库（默认主用） vs FACS/AU 编码（进阶精控）

| 层 | 怎么写 | 何时用 |
|---|---|---|
| **中文情绪→动作库**（默认，直接可用） | 用本 skill 下方按情绪归类的中文微表情短句，直接拼进叙事 prompt | 绝大多数场景的默认选择——地道、可直接理解、不依赖引擎认不认编码 |
| **FACS/AU 编码**（进阶，社区实测有效但非官方承诺） | 把动作单元编号写进 prompt，如 `AU12+AU6`，用于需要精确排多个节拍或中文描述总被忽略某细节时 | 独白多节拍排程、跨模型/跨引擎迁移需要一套通用编号体系时 |

两层不互斥，可以同一账号内 A/B 测试哪种在 `generate_video_v3` 上命中率更高。**日常写 prompt 优先用中文动作库，FACS/AU 是备用武器，不是必须。**

## 情绪→微表情动作库（核心，按情绪归类）

每条是可直接拼进 prompt 的中文短句范式，不是要全部塞进一镜——**一镜按下面"克制自检"控制在 1–2 个关键动作**，下面每个情绪列出的多条是同义/递进选项，按场景挑，不是全写。

| 情绪 | 关键动作（挑 1–2 个） | 范例短句 |

| 失望 | 目光慢垂（不是骤垂）、鼻息轻泄、嘴角疲惫落下、不再追问 | 「她的目光慢慢垂下，鼻息很轻地泄出一口气，嘴角疲惫地落下，眼神不再追问」 |
| 释然 | 长长呼气、下颌与眉头松开、眼眶湿润但平静、肩膀微沉、笑容在张力散去后才出现 | 「她长长地舒了一口气，紧绷的肩膀完全放松下来，脸上浮起淡淡的微笑，抬头望向远方」 |
| 疲惫 | 揉太阳穴、靠墙、眼皮下沉、长呼气、动作迟缓 | 「他靠在墙上，长长呼出一口气，眼皮沉沉地垂下」 |
| 专注 | 眉头微皱、眼神锁定一点、嘴唇抿紧、身体前倾 | 「她眉头微皱，眼神锁定屏幕一点，嘴唇抿紧，身体不自觉前倾」 |
| 犹豫 | 张嘴又闭、视线游移、手悬在半空、脚下踱步 | 「他张嘴又闭上，视线游移不定，手悬在半空迟迟没有落下」 |
| 惊喜 | 眼睛瞬间睁大、嘴张成O形、双手捂嘴、笑容缓慢绽放（不是瞬间） | 「她的眼睛瞬间睁大，嘴巴微张成O形，双手下意识捂住嘴，笑容缓慢地在脸上绽放开」 |

> 每条范例都符合"具体动作而非情绪形容词"的硬要求——出现"她很难过""他非常生气"这类词，直接对照上表换成动作短句。

## 长镜头单表情演化时间线（表演是内容本身时用）

当整镜的内容就是"一张脸的表演"（独白、静默特写、情绪转折的高潮镜），别写成一句静态描述，改用**分时间段的演化模板**，让表情自然过渡而不是突然跳变：
```

0–2s：\[起始状态，通常是平静或未察觉\] 2–4s：\[情绪开始的最初信号，极轻微\] 4–6s：\[情绪明显但仍克制，加 1–2 个细节\] 6–8s：\[情绪稳定在某个状态，可加一个身体反应如泪痕/呼吸\]

```

范例（隐忍难过）：「0-2s：人物保持平静的表情，眼神轻轻低垂，嘴唇自然放松。2-4s：情绪开始轻微变化，嘴唇慢慢轻轻抿住，嘴角开始一点点下压，眼神变得失落。4-6s：难过逐渐明显但仍然克制，眉头轻轻皱起，眼神带着委屈和隐忍，眼眶微微湿润。6-8s：人物稳定在隐忍难过的表情中，脸颊出现一两滴细小自然的泪痕，没有大哭，没有抽泣，情绪安静克制。」全程要求**自然过渡、没有突然变化、没有夸张哭泣**——这是本模板的核心约束，比具体用哪几个动作更重要。

同一结构可换情绪骨架复用：震惊定格（放松脸→笑容停住→眼神失焦→呼吸停→下颌锁住）；愧疚（视线躲→眨眼变慢→嘴角收紧→眉心内折→低头）；压抑的愤怒（目光静→鼻翼扇动→下颌绷紧→手指收紧→眼睛湿润但不眨）。**用这个镜头时保持运镜极简**：固定或极慢推，浅景深，别在表情特写里加复杂运镜或多余肢体动作分散焦点。

## 微表情的时间尺度（不同颗粒度对应不同写法，别混用）

- **一闪而过的泄露（0.25–0.5秒）**：鼻息、下颌绷紧、眼神一瞥、笑容抽动——用于"话没说但脸先说了"的瞬间信号，写"极快闪过随即恢复/被盖住"。
- **可读的过渡动作（0.5–1秒）**：视线改变、眨眼停顿、泪水成形、嘴角收紧——正常一次情绪转折的过渡颗粒度。
- **完整情绪转换（1–1.5秒）**：一个表情彻底换成另一个，如笑容彻底褪去、强装镇定崩塌。
- **复合式表情叠变（1.5–2秒）**：两层情绪的转换，如温情变算计、微笑变阴冷——需要给够时间让"面具切换"这件事本身被看清。

**始终保持自然过渡，不要突然的表情跳跃，除非剧情就是要"猛然变脸"这个冲击点本身。**

## 情绪混合与潜台词泄露（比单一情绪更高级的写法）

真正有戏剧张力的表演往往不是单一情绪，而是**两种情绪在同一张脸上同时存在、互相打架**——嘴在演一种情绪，眼睛在泄露另一种，或身体姿态在反驳台词的字面意思。写法：把两种情绪各自的动作都列出来，让"矛盾"本身成为要传达的内容，不要试图把它们调和成一个"中间情绪"：

- **强撑的温暖**：嘴角上扬带笑意 + 眼周绷紧、瞳孔不放松（恐惧/紧张的动作）同时出现——观众读出"这个笑是撑出来的"。
- **口是心非的软拒绝**：台词是拒绝的话，但视线躲开又偷偷看回、身体没有真的后退、笑意压在嘴角泄出——整体传达"嘴上拒绝、心里已经软了"，不是真正的反感。**这类反差表演强度建议控制在克制区间（十分打三分左右），避免读成真的抗拒/恐惧。**
- **审视变冷冷了然**：笑意从眼底一点点抽走，眼神变阴，嘴角原本上扬的弧度慢慢拉平甚至反向——本性从和善表演里"剥离"出来的效果，别一步到位，要给"抽走"这个过程时间。

这是"真笑假笑判定"（下一节）的进阶版：不是先一种情绪后另一种，而是**两种情绪同时叠在一张脸上，或一层表情下慢慢露出另一层**。适合表现"言不由衷""死撑""图谋不轨的伪装"类潜台词场景。

## 真笑 vs 假笑：判定示范（可套用到其他情绪）

真笑必然带眼周参与（脸颊被笑意托起、眼角浮现细纹）；只有嘴角上扬、眼周不动 = 礼貌笑/敷衍笑/假笑。眼周肌肉几乎无法被意识控制，这是判定"演得真不真"最硬的一条线，也是所有其他情绪判定的示范模板——**任何情绪都要问：眼睛有没有参与，不只是嘴或眉毛在动。** 只写嘴部动作的表情，是 AI 生成里最常见的"假脸感"来源。

## FACS/AU 编码（进阶精控层，独白多节拍/需要编号体系时用）

想更精确地按"肌肉单元"排多节拍表情，或中文描述总被引擎忽略某个细节时，换成 FACS（面部动作编码系统）的 AU 编号。AU 对应哪块肌肉是稳定科学事实；但"把编号直接写进 prompt 文本能生效"是社区实测结论，非引擎官方承诺，不要向用户保证"写了编号就精确"。

| 情绪 | 核心 AU 组合 |
|---|---|
| 真心笑（Duchenne） | AU6（脸颊提升）+ AU12（嘴角上提） |
| 礼貌假笑 | 仅 AU12，无 AU6 |
| 悲伤 | AU1（内眉上扬）+ AU4（眉头压低）+ AU15（嘴角下压） |
| 愤怒 | AU4+AU5+AU7+AU23（眉压低+眼睑收紧+嘴唇收紧） |
| 惊讶 | AU1+AU2+AU5+AU26（双眉上扬+眼睑全开+下颌松落） |
| 恐惧 | AU1+AU2+AU4+AU5+AU7+AU20 | 
| 厌恶 | AU9+AU15+AU16（鼻梁皱+嘴角下压+下唇后压） |
| 轻蔑（唯一单侧通用表情） | AU12+AU14，仅单侧——双侧对称就不是轻蔑 |

独白多节拍排程结构（一镜最多 3–4 拍，拍数越多单拍精度越差）：
```

拍1（0–Xs）：\[AU组合或中文动作\] ——（可选）配合台词"..." 拍2（X–Ys）：\[AU组合或中文动作\] 拍3（Y–Zs）：\[AU组合或中文动作\]

```
节拍时间加总须等于本镜总时长；这是**同一镜内的表情变化，不是分镜切镜**，运镜保持单一动作，否则引擎会把节拍表当成多镜头理解。

## 眼神语汇（表演信号强度最高，单独抓）

- **注视方向即叙事**：直视镜头=坦白/挑战；视线略低于镜头=脆弱/回避；视线越过镜头看向画外=分心/回忆。写清楚看向哪，不写"深情地看"。
- **眨眼频率**：正常对话节奏 3–4 秒一次；紧张/说谎/情绪波动时频率加快或骤降（如愤怒克制时反而"眨眼变少"）；极度平静或专注时可长时间不眨。
- **躲开又看回是最常用的信号组合**：写"视线躲开半秒又偷偷看回去"比"眼神游移"具体得多，适用于羞怯、嫉妒、口是心非等大量场景。
- **对镜头说话的专项技巧**（数字人/口播场景，衔接 talking-head-director）：真人演员对镜头常用"视线锁定耳垂到镜头的连线"防止游移，同时用余光扫过镜头制造"虚拟对视感"；写 prompt 可直接借这个具体动作，比"看着镜头"更可控。

## 跨镜情绪连续性 + 表情锚点集（扩展 character-consistency）

同一角色连续几镜的情绪必须有前因后果，不能镜与镜之间情绪突变：**上一镜的表情"余量"要在下一镜开头被承接**（如上一镜结尾是"眼眶微红未落泪"，下一镜开头就该是"仍带着未散的红眼眶"而非重置为平静脸）。

**表情锚点集**：character-consistency 的"姿态变化集"默认只变角度/姿态，同一角色若要在多镜里**精确复现某几个特定表情**（不是自然情绪流），可额外生成一组"表情锚点图"——用同一角色锚点，只变表情（如"中性放松""自然微笑""专注严肃"，或从本 skill 动作库挑 3–6 个场景要用到的表情），后续镜头引用对应那张锚点图。只在需要反复精确复现同几个特定表情（虚拟主播固定表情包、反复出现的"标志性苦笑"）时才值得做，一次性/自然流动的情绪不需要。

跨镜同一张脸的技术实现（不漂移）走 character-consistency 的锚点机制；本 skill 只管情绪衔接/复现是否到位。

## 与对口型/lip-sync 的分工协同

台词情绪基调必须和脸上的微表情匹配，否则会出现"嘴在笑、眼睛在演别的情绪"的割裂感（除非这正是"情绪混合"想要的效果）。**分工原则**：台词配音/lip-sync 驱动嘴唇/下颌随音素开合，本 skill 的表情描述应**优先落在眉毛/眼周/脸颊**这些不直接参与发音的肌肉上，不要抢同一块肌肉——确实要控制嘴部的表情性动作（如说话时嘴角始终带压抑的笑意），当成"叠加在发音之上的表情层"来写，不是替代口型。

镜头场景下的对话演员真实做法是：把注意力集中在台词的**潜台词**上而不是字面表情——先确定角色真正想要什么/在隐藏什么，微表情从潜台词反推，而不是从台词字面情绪直接映射（这正是"情绪混合"一节的应用场景）。

## Prompt 落地公式
```

\[起始/基础状态\] + \[触发或原因，一句\] + \[1–2个关键微表情动作，从动作库挑\] + \[眼神方向与动作\] + \[身体呼吸类反应，如有\] + \[克制程度提示：如"不落泪""不咬牙""动作幅度极小"\]

```

## 克制自检（表演过度 vs 到位）

- 一镜只放 1–2 个关键动作，超过就是堆砌，会显得"用力过猛"。
- 多节拍独白最多 3–4 拍，拍数越多单拍精度越差。
- 双侧脸完全对称的表情（除了纯惊讶一瞬）大多不真实——允许写"单侧""略偏"；轻蔑本身就该是单侧的。
- 动作和触发之间要有延迟（0.3–1秒），零延迟的"听到就立刻切换表情"最像 AI 感；情绪要**自然过渡**，禁止突然跳变（除非剧情就是要"猛然变脸"的冲击）。
- 眼睛必须参与情绪，只有嘴部在动的表情是最常见的失败模式。
- 舞台式的夸张（大开大合、拉满全脸）是给剧场观众远距离看的，镜头前的表演要往回收——**镜头能看到剧场观众看不到的细节，所以镜头前用更小的动作就够**。

## 故障排查

| 症状 | 病因 | 修 |
|---|---|---|
| 数字人像蜡像/瘫脸 | 只写了台词没写表情 | 补至少 1 个基础状态动作，哪怕是"平静专注" |
| 表情夸张失真/像默剧 | 用了"狂笑""痛哭""怒目而视"类夸张动词 | 换成动作库里的克制动作 |
| 假笑感/塑料感 | 只写了嘴部动作 | 补一句眼周动作，参照真笑假笑判定 |
| 长镜头表情演化很糊/看不出变化 | 整段只写了一句静态描述 | 改用分时间段演化模板，4 个时间段递进 |
| 独白里表情该变但没变 | 没分节拍，整段一句糊过去 | 改用 FACS/AU 或中文动作库的分节拍排程，≤4拍 |
| 中文描述总被引擎忽略某个细节 | 该细节在自然语言里权重太低 | 换成 FACS/AU 编码重试，同一账号 A/B 对比 |
| 情绪转折太突兀 | 两个表情间无过渡段 | 补过渡动作，参照"微表情的时间尺度"选对应颗粒度 |
| 眼神空洞/无神 | 只描述了嘴部/眉毛 | 单独补一句眼神语汇 |
| 对镜头说话时眼神游移 | 没给视线锁定的具体动作 | 用"锁在耳垂-镜头连线"式具体描述替代"看着镜头" |
| 说话时表情和口型互相打架 | 表情描述抢了嘴部/下颌肌肉，和lip-sync冲突 | 把表情描述移到眉眼脸颊，嘴部交给对口型驱动 |
| 表情与台词情绪不匹配（非故意） | 直接从台词字面映射表情 | 先想潜台词再定表情 |
| 多镜情绪像被重置 | 每镜独立写情绪没接上一镜余量 | 承接上一镜结尾状态作本镜开头 |
| "泄露情绪"效果看不出来 | 把一闪而过的信号写成了完整表情 | 改成 0.25–0.5秒量级的极快闪过 |
| 需要反复精确复现同一表情但总是漂 | 只有角色身份锚点，没有表情锚点 | 补建"表情锚点集" |
