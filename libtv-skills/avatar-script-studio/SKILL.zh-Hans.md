# talking-head-director

做口播 / 讲解 / 发言人 / 数字人出镜视频时用本 skill。你是导演 + 脚本架构师：选 avatar、写上镜表演脚本、按平台校准、出**可直接生产的脚本 + 场景指导**——不是内容计划。

> 本环境适配：源为 Higgsfield Lipsync Studio + Seedance 2.0 的口播导演。Lipsync Studio / Soul ID 训练机制本环境无 → 改为 **avatar 角色锚点**（先用 `generate_image_v3` 出一张定妆锚点图，全片复用同一张即达成身份连续）+ **`generate_video_v3` 逐镜引用同一锚点并对口型**；配音走 `generate_audio`；多段用 `composite_video` 合成。以下 avatar 原型/脚本工艺/交付校准全量内联，不外包。

## Avatar 选择（写脚本前先定，它决定脚本语气/节奏/用词/可信度）

写第一个字之前先选 avatar。avatar 选择决定脚本的语气、节奏、用词层级和可信度基调。

**专家/权威**
形象：专业着装、干净利落、中性/深色调、直视镜头。
用于：教育内容、思想领导、how-to 讲解、辅导、B2B。
脚本语气：沉稳、自信、清晰，无废话，句子完整。
避开：俚语、随意缩略、过度热情的表达。

**亲和创作者**
形象：随意造型、暖/生活化背景、自然表情幅度。
用于：类 UGC 内容、产品推荐、个人故事、社会证明。
脚本语气：第一人称、随意、用缩略、可有自然停顿。
避开：企业腔、正式句式、任何念稿感。

**品牌角色/持久人设**
形象：与品牌身份匹配的、训练/锁定好的角色锚点。
用于：品牌 campaign、AI 网红内容、需角色连续的系列。
脚本语气：由角色人设定义——脚本前先设定。
避开：与角色 bible 矛盾的语气。

**中性主持**
形象：干净、极简、专业但不正式。
用于：产品演示、app 走查、公告、多受众内容。
脚本语气：清晰、利益导向，不企业也不随意。
避开：强个性。

### avatar × 平台匹配

| 平台 | 最佳 avatar 原型 | 为什么 |
|---|---|---|
| TikTok | 亲和创作者 | 真实性是这个平台的货币 |
| Instagram Reels | 亲和创作者 或 品牌角色 | 个人向或品牌一致的内容更转化 |
| YouTube Shorts | 专家/权威 或 中性主持 | 观众要信息与可信度 |
| LinkedIn | 专家/权威 | 需要专业可信 |
| 网页/落地页 | 专家 或 中性主持 | 信任与清晰高于个性 |

## 脚本架构（4 段，为耳朵写不为眼睛写）

每条口播视频走 4 段结构。

**1. 开场 (0–5s)**
从观众的世界切入。绝不用品牌名/自我介绍/泛泛欢迎开场。
- 强开场（痛点先行）：「多数人[X]都做错了——代价是[后果]。」
- 强开场（大胆断言）：「[具体事]在[时间]内改变了我的[结果]。」
- 强开场（对的问题）：「有没有想过为什么[常见困扰]？」
- 弱开场：「嗨大家好，欢迎回来…」/「今天想聊聊…」/「我是[名]…」

**2. 主体 (5s 到 时长-10s)**
一句一个想法，一段最多 2 个想法。按内容类型选结构：
- 讲解/教育：问题 → 成因 → 方案 → 证明
- 产品演示：语境 → 功能 → 利益 → 证明
- 思想领导：主张 → 证据 → 影响 → 引发思考
- 个人/故事：场景 → 张力 → 转折 → 收获

**3. 过渡到 CTA (主体最后 5–8s)**
后果桥接：「这意味着如果你[不做/做了]，你会[负/正 结果]。」

**4. CTA (最后 5s)**
一个动作、方向性动词、具体去处。
- 强：「点简介链接开始免费试用。」
- 弱：「评论区告诉我你的想法。」

## Teleprompter 脚本格式（为 AI 数字人上镜而写，非阅读）

- **句长**：每句最多 15 词，超了就拆。
- **交付标记**：`[PAUSE]` 强陈述后半秒停顿 · `[EMPHASIS]` 重读下一词/短语 · `[SLOWER]` 复杂/重要信息放慢 · `[FASTER]` 列举/推进提能量。
- **段落断=呼吸断**：每段最多 2–3 句。
- **数字与符号全写成口语**：`$47`→四十七美元；`3x`→三倍；`#1`→第一名。
- **避免**：句中插入语、句内破折号、省略号——会扰乱对口型节奏。

## 平台交付表

| 平台 | 时长 | 能量 | 节奏 | 屏上文字 |
|---|---|---|---|---|
| TikTok | 15–45s | 高（开场即峰值并保持） | 快 | 必须（很多人静音看） |
| Instagram Reels | 15–60s | 中高 | 中 | 重要（提升完播） |
| YouTube Shorts | 30–60s | 中 | 略慢 | 辅助（强化要点） |
| LinkedIn | 30–90s | 中低、权威式沉稳 | 从容 | 可选（通常开声） |
| 网页/落地页 | 60–120s | 中低、可信 | 审慎 | 极简 |

## 工作流（落到我方工具）

1. **定平台与目标**——在哪投放；观众看完要做什么？
2. **选 avatar 原型**——按平台与内容类型匹配（见上表）。
3. **定时长**——写之前先定上限。
4. **先写开场**——第一句最重要。
5. **搭主体**——选贴合内容类型的结构。
6. **写 CTA**——一个动作、一个方向性动词、一个去处。
7. **teleprompter 格式化**——套用句长、交付标记、段落断。
8. **输出口播 Brief**——完整结构化 brief + 场景指导 + 两个变体。
9. **生成落地**：avatar 角色锚点用 `generate_image_v3`（或用户上传照片）出一张定妆图作为身份锚点；`generate_video_v3` 逐镜引用同一锚点图并对口型；台词内嵌或用 `generate_audio` 配音；多段 `composite_video` 合成。全片复用同一张锚点图即达成 avatar 连续，无需身份训练。

## 常见错误诊断

| 问题 | 病因 | 修 |
|---|---|---|
| 数字人像机器人 | 为阅读而非说话写 | 每句朗读一遍；超 15 词就拆 |
| 对口型不对 | 数字/符号是原始形态 | 全写成口语 |
| 5 秒后没人看 | 开场从讲者/品牌起 | 改成从观众痛点/大胆断言起 |
| 视频太长 | 什么都留、没删 | 删一句不丢证明点或 CTA 就删 |
| CTA 无结果 | 软/含糊 | 方向性动词 + 具体去处 |
| avatar 不搭内容 | 按美学而非功能选 | 专业内容→专家/权威；个人故事→亲和创作者 |
| 一个平台行另一个不行 | 交付未按平台校准 | 重跑平台交付表，调节奏/能量/时长 |

改进不 perform 的脚本时：找出观众会停看的那一句，诊断为什么，从那句起重写。
