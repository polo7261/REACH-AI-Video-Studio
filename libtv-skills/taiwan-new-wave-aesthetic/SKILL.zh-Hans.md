# 台湾新浪潮（侯孝贤 × 杨德昌 × 蔡明亮）影片流水线

> 🔴 **请严格按该 SKILL 分步执行。** 版本 2.5.7-rc1（候选版；在 2.5.6-rc1 基础上移植 A24 剧本撰写模块并作新浪潮风格化适配：入口新增人声模式、故事步补动作线/表演基调、新增"剧本撰写·叙事节奏与对白"小节）。工具均以自然语言意图描述（图像生成能力/视频生成能力/视频合成能力/后期剪辑能力/向用户提问确认/读写文件），由 agent 映射到实际可用工具。

## 底层 DNA（无条件，每条画面都带）
1. 🔴 **长镜头 + 固定机位**：镜头找个位置放着、让事情发生，固定机位为主、极少运镜；长镜内靠人物走位与景深调度叙事，而非剪辑或快速运镜。
2. **自然光 + 写实**：自然光为主（窗光/天光/室内实用光），不打戏剧化人工光；真实自然质感、生活化、非精致摆拍。
3. 🔴 **中远景 + 框式构图 + 留白**：以中远景为主、**极少特写**，人物与环境是不可分割的整体；门框/窗栏/走廊/隧道摄入画面形成画框层次与纵深；注重平衡、留白、略带俯视的客观凝视。
4. **低饱和褪色胶片质感**：色彩偏灰偏褪、低饱和、低对比、暗部微微提亮不死黑（lifted blacks），中画幅般极细腻胶片颗粒（几乎不可见）+ 高光柔晕（halation/bloom）——**绝非鲜艳数码 HDR**。⚠️ **褪色≠脏、旧≠破**：褪色是干净通透的低饱和不蒙灰，旧是朴素陈旧、有人在住的体面（除蔡明亮潮湿破败方向外），非墙皮剥落/发霉/废弃失修；暗部微微提亮保层次、绝不死黑糊成一团；整体曝光偏亮不压暗，冷调方向（杨/蔡）别拉过冷发青、保留一丝暖底。旧而干净、暗而通透、冷而不寒。
5. **场景即叙事**：环境写实、陈旧但整洁体面（有生活痕迹但干净、有人在住，非破败脏乱），承载时代感。
6. **细微环境运动让画面呼吸**：风让窗帘动、光影移、烟飘、水流、雨落——主体外的细微运动让静止长镜有时间感。
7. 🔴 **克制疏离的情感（灵魂）**：含蓄压抑不表演，情绪藏在动作快慢/停顿/视线/姿态里，靠调度而非面部特写。
8. 🔴 **节奏明快偏快、单镜短、切换勤、但每镜内容完整演完**：视觉语言（固定机位/长镜/低饱和/框式构图）忠于原作；节奏明快适配网络短视频、单镜短（一个动作 3~5 秒）不拖沓，但一个动作/对话/进出/凝视要在**一个镜头里完整发生、给足时长不切断**。明快靠单镜短/切换勤/转场利落，**绝不靠一条塞更多内容、切碎动作加快**（那会导致画面跳跃、动作半途消失）。镜头语言固定克制。

**通用负面（每条都带）**：`anime、CGI、卡通、3D 渲染、塑料感皮肤、过度风格化、戏剧化人工打光、过多特写、快速炫技运镜、手持晃动、甩镜、fake HDR、过饱和、鲜艳刺目色彩、数码清晰视频感、光鲜现代感、戏剧化表演腔、僵死不动的画面、墙皮剥落、霉斑、水渍、破败废弃、暗部死黑糊成一团`

## 质感尾词（每条图像 prompt 默认带）
`胶片拍摄、低饱和褪色色调、低饱和低对比、暗部微微提亮保层次（lifted blacks 不死黑）、中画幅般极致细腻几乎不可见的胶片颗粒、高光柔和 halation 光晕、自然光写实、固定机位长镜、中远景观察式极少特写、框式构图留白、旧而干净不脏、暗而通透、肤色在低饱和中仍真实鲜活有血色；不要鲜艳数码 HDR、不要过饱和、不要墙皮剥落发霉、不要暗部死黑`

## 流程（8 步；🔴 所有面向用户的询问一律用选项卡形式弹出、给可点选选项含默认项，不用开放式提问）
1. **统一入口问询（弹选项卡）**：一个框问清九项、答完写 memory：① 时长（单镜≤15秒/单集30-60秒/多集数分钟/自定义）② 执行模式（全自动/手动）③ 画幅（**默认 16:9**，可选 4:3/16:9/21:9/自定义；分辨率默认 720p）④ 导演方向（通用底/侯/杨/蔡，默认通用底）⑤ 情绪基调（沉静克制/轻快诙谐，默认沉静克制；诙谐则套第五支冷面幽默配乐等轻快调整）⑥ 🔴 **人声模式**（① 纯氛围·无对话无旁白 ② 纯对话·只有对白 ③ 纯旁白·只有画外音、人物不出声 ④ 对话+旁白穿插；**默认 ②**，存 `VOICE_MODE`；此项决定剧本写不写对白/旁白，详见第 3 步与"剧本撰写"小节）⑦ 对白/旁白语言（默认台味中文，存 `DIALOGUE_LANG`；⑥选纯氛围则此项为"无语言"）⑧ 3 个核心元素（生活空间/家庭关系/日常物件）⑨ 故事梗概（有/无：有则提供遵循、无则据 3 元素生成）。moodboard 与故事生成留到第 2、3 步。
2. **风格确认（生成动作）**：据 3 元素生成 moodboard（图像生成能力，4:3，单一融合画面铺满出血、禁白边/拼贴/分格）→ 存为风格锚资产、记归档标记。
3. **故事（生成动作）**：有梗概遵循、仅叠加台湾新浪潮风格化；无则据 3 元素生成（生活流/时代/家庭/克制疏离/留白）。🔴 每场写明可被拍到的具体生活化动作过程（含情境），非情绪心理。输出 scene list + emotional arc + 🔴 **动作线** + 🎭 **角色表演基调**，并**遵循入口⑥选定的人声模式**（纯氛围不写台词旁白、纯对话写对白、纯旁白写旁白、穿插两者交织；详见下方"剧本撰写"小节）。
   - 🔴 **动作线必填**：每场写生活化肢体动作过程（起→中→止），可被镜头拍到的具体行为；动作必挂情境动机（"听到门响而放下碗抬头"非只"抬头"）。
   - 🎭 **表演基调必填**：每个有戏角色定一套克制内收的表演签名——标志性小动作/习惯姿态（沉默时摩挲碗沿、为难时挪开视线、等待时反复整理衣角），贯穿全片跨镜一致，供视频阶段人物动作发挥。情绪外化靠动作快慢/停顿/视线/姿态，不靠面部特写与表演腔。
   - 🔴 **叙事节奏对齐**：故事的 emotional arc 须与"剧本撰写"小节的节奏范式一致（默认沉静克制生活流；诙谐题材走冷面幽默），并向下传导到分镜切分。
   **第 2+3 步完成后弹一张合并确认卡**（moodboard+故事一起确认：无误进下一步/调 moodboard/调故事/都调）——通过才进第 4 步，早纠偏。
4. **资产 + 分镜表（弹选项卡统一确认）**：先产资产——角色模卡（锁脸）、场景参考图（一个场景只一张大全景定场、挂 moodboard 锚、所有分镜引用它角度靠文字取景）、道具合图；再基于故事和资产**列完整分镜表**（每镜：景别+@角色动作+运镜+环境+时长）；两者**打包弹选项卡统一确认（确认无误/需要调整；moodboard/故事已在前一卡确认过不重复），通过才进第 5 步**（全自动模式亦保留此门）。
5. **生成视频**：按已确认分镜表逐条生成，挂该场景参考图/角色图/道具图锁一致性，🔴 **不挂 moodboard**。🔴 参考节点在 prompt 内一律以 **`{{node_key}}`**（双花括号+节点实际键名，如 `{{Mixed 1}}`）占位、与资产参考顺序一致——框架唯一认可格式，首次提交就用它、禁〈〉/[ ]/自创格式（格式不对必然生成失败）。
6. **音乐**：视频定稿后**弹选项卡确认方向**（列可选支+按导演/基调预选默认项）、生成 BGM（**默认 mureka 模型**）——🔴 生成好**先存着不叠**，等第 8 步决定。
7. **合成**：跨 15 秒才拆多条、串行拼成完整成片。🔴 首次合成只含视频+环境音+对白/旁白、不叠 BGM。
8. **成片后统一处理与询问（弹选项卡）**：一个框多选：① 加字幕 ② 合成背景音乐 ③ 改音乐后再合成。关键约束：
   - 🔴 **字幕选项文案按语言正确写**：中文→"加中文字幕"；**非中文→必须写"加双语字幕（原语言+中文）"、禁写单语**。
   - 🔴 **执行顺序强制先字幕、后音乐**（工具限制：有音乐时加字幕出问题）；改音乐则先重生成再按此序叠。
   - 🔴 **混音默认**：原声 +8dB、BGM -2dB（用户可改）。
   - 下挂后期剪辑工具：字幕（中文单语/非中文双语）、转场（默认硬切、用户提及才加；可选淡入淡出/黑场/白场/噪点溶解）、抽帧、裁剪、文字贴片（年代片名卡/地点字幕条/人名条）。

## 画幅与画质（写死）
moodboard/场景图 4:3；人物模卡 16:9；视频默认画幅 16:9、默认分辨率 720p（可改）。图像默认 libimage 模型、2K 分辨率、标准画质（用户可改）。

## 剧本撰写 · 叙事节奏与对白（🔴 移植自 A24 模块并作台湾新浪潮风格化适配）
- 🔴 **默认节奏 = 沉静克制 · 生活流 · 留白**：不做压迫递进、不给强情节钩子；情绪藏在日常里缓慢渗出，靠时间累积与留白而非反转。张力来自"处境的暧昧""关系的疏离""某事悬而未说"的持续暗涌，不靠爽感、不靠悬疑解谜。结尾开放、不闭合、不给解答——生活继续，情绪未收拢。
- **情绪优先、信息克制**：画面与剧本服务内在情感而非交代信息，观众常比角色晚一步理解处境（制造克制的疏离感）；避免类型片式强钩子与信息交代式场景。
- 🎭 **诙谐题材（入口⑤选轻快诙谐时）**：切换为**冷面幽默（deadpan）生活流**——一本正经的荒诞、错位的日常，幽默来自处境与反应的反差、不靠角色搞笑或耍宝；仍守新浪潮底：克制、留白、开放结尾、拒绝说教（配乐走第五支冷面幽默小品）。
- ⚠️ **一片一节奏、不混用**：单片开头即定"沉静克制"或"冷面幽默"，全片统一；可有局部骤停/对比，但主基调唯一。
- **节奏落到可执行**：叙事节奏须与故事步 emotional arc 对齐、向下传导到分镜切分——沉静克制→事件稀疏、单镜完整凝视、切换勤但每镜演完；冷面幽默→靠错位处境与克制反应的时机制造反差。分镜仍按内容事件切（详见视频铁律与剪辑节奏），节奏只影响事件密度与凝视时长、不改"按内容切、每镜演完"这一原则。
- 💬 **对白（人声模式含对话，即 ②/④）**：🔴 凡两人及以上同场、或人物有交流动机处，都要写出实际台词，别只写动作把人物写成哑巴；整片不能通篇无对话干剩动作。对白量按场景定（独处/极端克制场景可无台词，靠沉默与调度）。每句台词标注说话人。对白文本走 `DIALOGUE_LANG`、用 {} 包裹（承视频铁律）。（纯氛围①、纯旁白③模式下不写对白。）
- 🎭 **对白风格（台湾新浪潮质感）**：生活化、口语、简短，像台湾人日常会讲的话（台味自然、少书面腔）；🔴 **留潜台词**——重要情绪藏在话面之下，人物常答非所问、说半句、用日常琐事（吃了没、天气、家务）包裹真实心事；**反金句**：不写总结主题的漂亮台词、不写解释自己情绪的话（"我很难过""我很寂寞"这类直白交代禁用，改用具体的日常话或沉默带出）；克制、有停顿、有欲言又止、有沉默。避免信息交代式对白（把剧情用嘴说明白）。侯偏乡土温厚、杨偏都市知性冷静、蔡偏极简近乎无言——按导演方向微调语域。
- 🎙️ **旁白（人声模式含旁白，即 ③/④）**：风格克制、私密、像写给自己听或自言自语，非全知解说、非情节旁述；不复述画面已表达的内容；语气自然台味、少播音腔。🔴 **旁白文本在剧本阶段写定，并统一写进视频 prompt 时间轴**（承新浪潮视频铁律：写作 `画外旁白{旁白文本}` 并紧跟"旁白是画外音、画面人物不开口、口型不动"，由 seedance 原生生成，不走独立 TTS/音轨、不留后期追加），同受 `DIALOGUE_LANG` 与 {} 包裹约束。④穿插模式：在时间轴里给对白与旁白**分配各自时间段**，旁白只填对白到不了的内心/回望空隙、不与对白同时出声抢戏。（纯氛围①、纯对话②模式下不写旁白。）
- 🚫 **不写役割表/人物表**：默认不产出人物表，除非用户明确要求。

## 人物铁律
- **锁质感、放身份**：低饱和褪色胶片 + 中画幅细腻颗粒 + 自然非塑料皮肤是硬约束；发色/发型/服装/年代造型尊重用户设定、不做台湾新浪潮化纠偏。
- 🔴🔴 **族裔硬锁**：默认锁**东亚/台湾人面孔**（East Asian/Taiwanese），模卡与镜头都显式写、负面排西方脸（不锁则模型偏西方脸）；族裔独立于造型、不随发型服装漂移。例外：用户明确指定非东亚角色时按用户来。
- **皮肤例外**：整体低饱和褪色，但肤色保持真实血色、绝不拖成蜡黄/青灰/死气。
- **模卡≠出片**：纯白底 + 明亮均匀棚拍正面光（脸提亮、细节优先），绝不逆光/昏暗。版式 16:9：左三视图（正/侧/背）+ 右大面部特写（必出、不可省、不可画成全身）。
- 🔴 **人物图不带道具**：模卡只出人物本身（身形/服装/发型/脸），绝不背包/拿伞书本随身听手机/戴非必需饰品——道具交道具合图统一管、镜头再引用。贴身服装不算道具。

## 场景图（🔴🔴 一个场景只出一张参考图 · v2.3.2 起，从根上消灭多图矛盾）

## 剪辑节奏（明快但不切碎）
保留固定机位/长镜内调度/中远景框式凝视/克制留白；节奏**明快偏快、单镜短、切换勤、适配网络短视频**（明显比原作明快、不做数分钟极慢长镜），但**每镜那段内容必须完整演完**——一个动作/对话/进出/凝视在一个镜头里给足时长完整发生、不拆到几个机位递进。明快靠单镜短/切换勤/转场利落，绝不靠一条塞更多内容切碎动作（切碎会导致 seedance 画面跳跃、动作半途消失）。🔴🔴 **景别默认跳两档**（如 大全景→中景/全景→中近景）——只跳一档画面变化太小、切下去仍像跳切，跳两档才够明显、才像真换了镜头；**禁暴跳**（跳三档以上如大全景↔近景）；**同机位/同角度静止时至少跳一档**（同角度切镜靠跳一档景别区分、绝不原地零档硬切），不换景别也不换角度就用一个长镜连拍别切。以中远景为主。v2.3.2 起共用一张场景参考图后尤其要防两镜写成只差一点点像跳切。镜间显式硬切、靠动作与调度延续、不依赖后期转场。

## 视频铁律
- 🔴 **单条多分镜（默认强制）**：seedance 单次最长 15 秒、原生支持单条内多分镜+镜间衔接，不走"一镜一条+后期拼接"。🔴🔴 **时长-内容预算核算（写分镜前最先做、防塞太多切碎）**：先定总时长（≤15s），按"每个完整片段需几秒演完"倒推这条最多放几个片段，而非先定N镜再硬塞。手感锚点：一个完整生活动作（推门进来/坐下点烟/端碗吃饭/递接物）通常需 **3~5 秒**演完，单条通常 **3~5 个分镜**（3镜×5s/4镜×3~4s/5镜×3s）；每镜仍是一段完整动作演完、不切碎——切得勤但不切碎。内容超了减片段不减单镜时长、剩下的另起一条。单条时长 4~15 秒任意整数秒，只有跨 15 秒才拆多条串行拼接。🔴 有明确起止的完整动作（进出画/开关门/起身/递接物）仍给足3~5秒单独占一镜完整发生，别挤一条里被切断（治顾客进门影子晃一下消失、镜头跳跃）。prompt 按秒推进、每镜=景别（引用对应角度的场景参考图）+@角色动作+运镜+环境、镜间显式硬切。单条内多分镜共享同一场景：🔴🔴 人物位置**一律用固定参照物锚定**（窗/门/神明桌/橱柜），如"妈妈靠窗侧、儿子背对门、爸爸靠神明桌侧"，**每镜复述这组不变关系**；**跨镜禁用"画面左/右"描述人物座位**（画面左右随机位翻转，seedance 会按新镜头字面左右重新安排座位——多人换座位的元凶）；单条内所有镜头默认**从同一侧拍**（[整体场景与氛围]写一句"本条均从X侧拍向Y"），不绕对面。🔴🔴 **首镜（分镜1）必须有主要人物在场并有动作（哪怕远景渺小背影），绝不写成纯空镜定场**——[整体场景与氛围]已负责钉空间，首镜时间轴若只写空间不写人，seedance 会出成没人的空景；空镜只放镜间过渡或末镜留白。每镜默认至少一个 @角色+动作，空镜是例外需标注意图。🔴🔴 **在场角色全提及（治漏人/路人化/消失）**：一镜画面里凡在场的人物（含背景/次要/无台词的）都要在该镜 prompt 用 `@角色名` 点出+写位置动作（位置用参照物：如"@老爸 靠神明桌侧看报、@老妈 厨房门口擦手"，禁"画面左/右"），漏提的人会被 seedance 生成成路人脸或消失；本镜在场每个角色的模卡都挂进参考（受≤7上限时按重要性取舍）。🔴🔴 **群像全员动态**：多人镜头每个在场人物都必须有动作——主角主动作、其他人至少各一个生活化微动作（夹菜/擦手/翻报/点头/摇扇），**禁任何人雕塑式僵住**（漏写动作的人会僵直呆立）；唯一例外：用户特殊要求静止时按用户来并显式写"刻意静止"。
- **空间连续性**：靠 prompt 文字复述同一组空间事实（布局/光源/人物相对位置与朝向）保持一致、换角度引用对应场景参考图。
- **不出 BGM**：视频生成只要环境音+对白，BGM 合成阶段叠加。prompt 常驻"只保留环境音与对白、无背景音乐"；负面加"背景音乐、配乐"。
- 🔴 **语言锁**：每条视频 prompt 常驻声明"对白/旁白一律 [DIALOGUE_LANG]，模型补话也只用此语言，禁其他语种台词/字幕/口型"（无论有无对白都写），对白用 {} 包裹；负面加"其他语种台词、混合语言口型"。
- 🔴 **旁白统一写入视频 prompt**：不走独立 TTS/独立音轨——旁白文本直接写进时间轴、由 seedance 原生生成，写作 `画外旁白{旁白文本}` 并紧跟"**旁白是画外音，画面人物不开口、口型不动**"（强约束防安到人物嘴上）；同受语言锁与 {} 包裹约束，语气自然台味少播音腔。
- **禁溶解叠化**：镜间硬切，负面常驻 no dissolve/cross-fade/fade。

## 视频 prompt 标准模板（强制照此，每镜四件套=景别+@角色动作+运镜+环境，缺一不可）
```

@image1 @scene名（该场景唯一参考图，所有分镜都引用它、角度靠文字取景，置最前）
@image2 @角色名（服装/发型/气质关键词）
```
