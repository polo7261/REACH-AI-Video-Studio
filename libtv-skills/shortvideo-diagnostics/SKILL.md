# content-analyzer

工具型 skill——一組內容分析模式，逐步生長。每個模式把使用者**已有的一件具體內容素材**（影片、片段、URL 指向的成片）解析成**結構化、面向下游用途**的分析。在分析階段被工作流（或直接）呼叫，位於任何下游編輯/營銷/生成步驟之前：當一件具體內容必須先被拆成結構化、面向用途的分析時用它。

按你的意圖選**一個**模式，只跑匹配的那個，不要兩個都拉。

## 模式選擇

| 意圖 | 產出 |
|---|---|
| 為營銷分析一段影片 | 影片的營銷拆解——鉤子（視覺/聽覺/語義）、留存節拍、CTA、可傳播性（STEPPS） |
| 為編輯分析一段影片 | 針對單個增/刪/改/替的改動點分析，落到重生成對應分鏡的指令 |

先用 `analyze_video_clip_storyboard` 拿到分鏡、節奏、鏡頭語言，作為兩種模式共同的**結構底座**；再在結構之上做對應模式的提煉。

## 模式一 · 營銷拆解（marketing-analyze）

在結構底座之上，逐層提煉：

- **鉤子（前 1-3 秒抓人）**——分三路各自定位：
  - 視覺鉤子：開場畫面的反常/張力/資訊缺口（誰/什麼/異常狀態）。
  - 聽覺鉤子：開場音效/口播/音樂的抓耳點。
  - 語義鉤子：文案/口播丟擲的懸念、承諾或衝突命題。
- **留存節拍（retention beats）**——沿時間軸標出維持觀看的節點：資訊釋放的節奏、反轉/揭曉點、視覺換擋、"再等一下就有"的懸置，指出哪幾拍在防跳出。
- **CTA**——行動號召出現的時機、形式（畫面/口播/字幕）、措辭與指向的下一步動作。
- **可傳播性（STEPPS 六要素）**——逐條判定這條內容觸發分享的機制：
  1. **社交貨幣 Social currency**：分享它能讓人顯得懂行/前衛/有品位嗎？
  2. **觸發物 Triggers**：有沒有把內容與日常高頻場景/物件繫結，讓人反覆被提醒？
  3. **情緒 Emotion**：喚起的是高喚醒情緒（驚歎/憤怒/好笑/焦慮）還是低喚醒（滿足）？高喚醒更易被轉發。
  4. **公開性 Public**：內容/產品的使用是否可見、可被模仿、留下公開痕跡？
  5. **實用價值 Practical value**：是否提供可轉告他人的實用資訊（省錢/省事/有用技巧）？
  6. **故事 Stories**：核心資訊是否被包進一個會被複述的故事載體裡？

輸出為結構化要點（分條/表），而非散文式複述。

## 模式二 · 編輯改動分析（edit-video-analyze）

針對使用者想對成片做的**單個改動點**（增加 / 刪除 / 替換 / 修改某元素）做分析。

- 先在結構底座上**定位改動落在哪一分鏡/哪一段時間軸**，說清改動的物件、位置、期望效果。
- **本環境無 video-to-video 直接編輯能力**：影片靠 `generate_video_v3` 用文字 + 錨點重新生成。因此改動分析的產出不是一條 v2v 編輯指令，而是**把受影響的分鏡改寫成新的生成指令**——保留不動的分鏡錨點不變，只重寫被改動分鏡的提示詞/構圖/動作/時長，交給下游重生成該分鏡後再拼接。
- 一次只處理一個改動點；多個改動點逐條拆開、各自落到對應分鏡的重生成指令。

## 輸出去向

兩種模式的結構化分析都寫進目標分鏡表 / 錨點清單（`write_file_v2`），供 video-generation 或復刻流程直接消費。

## 邊界（勿用本 skill，改道）

- 只針對**已有的具體內容**做分析；趨勢 / 爆款 / 創作者發現類研究不在此。
- 產品輸入預處理（把產品圖/URL 解析成品類/用途/開場機制）→ product-analyzer。
- 品牌資產提取（從品牌主頁拿 logo、配色）→ brand-analyzer。
- 影象 / 影片生成本身 → 對應生成能力或 workflow 流程。
