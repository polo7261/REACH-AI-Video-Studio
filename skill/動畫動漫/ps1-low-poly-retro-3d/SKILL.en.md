# PS1 Low Poly Retro 3D Video Director Skill

## 1. Skill Name

**PS1 Low Poly Retro 3D Video Director**

Also known as:

- Early 3D Console Game Style Director
- Low Poly Retro Game Visuals Director
- PS1 Horror / Dreamcore Low Poly Director
- Low-Res Texture Retro 3D Video Director

---

## 2. Skill Introduction

This Skill helps users start from a vague theme and create images, game first frames, character designs, scene assets, 5-second image-to-video clips, and long video storyboards with a **PS1 / early 3D console game look**.

Its goal is not generic retro style, not 8-bit flat pixel art, and not modern 3D game CG, but a strict simulation of the following elements from early 3D games:

- Low poly modeling
- Rough faceted characters
- Low-res textures
- Blurry textures
- Low-resolution rendering
- Jagged edges
- Fixed camera angles / old-game hard cuts
- Low frame rate character animations
- Stiff turns
- UI / HUD / item bar / dialogue boxes
- Slight texture warping, localized Z-fighting, CRT scanlines

The final output must be directly usable for image generation, first frame generation, video generation, or storyboard production.

Suitable for creating:

11. 15-second, 30-second, 60-second, or longer low poly video storyboards

## 4. Input Judgment Rules

After receiving a user request, first determine which type of input the user has provided.

### 4.1 Theme Only

For example:

- "Make a PS1-style abandoned hospital"
- "Make a low poly horror convenience store"
- "Make a dreamcore amusement park"

Handling approach:

1. Automatically fill in the style direction.
2. Provide 3-5 creative directions.
3. Select the direction best suited for visualization.
4. Output character, scene, prop, first frame, and 5-second video prompts.

Default direction:

> PS1 low poly + low-res textures + fixed game camera + mild horror / dreamcore / nostalgia feel + old-game UI.

---

### 4.2 Clear Plot Provided

For example:

- "A girl searches for her vanished friend in an old school"
- "The protagonist enters an abandoned mall, and the elevator opens by itself"
- "A low poly puppy gets lost in a dreamcore room"

Handling approach:

1. Extract the protagonist.
2. Extract the scene.
3. Extract the key actions.
4. Extract the emotion.
5. Break it down into 3-6 shots.
6. Generate first frame prompts and 5-second video prompts for each shot.

---

### 4.3 Reference Image Provided

Handling approach:

1. Analyze the subject, scene, composition, lighting, color, and mood in the reference image.
2. Extract only the elements that can be converted into PS1 low poly.
3. Never directly copy specific IPs, characters, brands, or copyrighted elements from the reference image.
4. Transform the reference image into original low poly assets.
5. Output "reference image analysis → original transformation plan → prompts".

## 5. Style Boundary Judgment

Always maintain:

> This is PS1 / early 3D console game imagery, not 8-bit flat pixel art, and not modern high-definition 3D CG.

### Core Features of PS1 Low Poly

- 3D space
- Low poly characters
- Blurry textures applied to models
- Fixed cameras or room-based cuts
- Low-resolution rendering
- Jagged edges
- Simplified lighting
- Stiff character animations
- Old-game UI / HUD

### Must Avoid

- 8bit pixel art
- 2D sprite
- tilemap
- Modern 3D game CG
- Unreal Engine look
- High-definition realistic materials
- Smooth motion capture
- Cinematic camera work
- Smooth, polished modeling

## 6. Standard Workflow

### Step 1: Requirement Understanding

Extract:

- User theme
- Content type: character / scene / first frame / video / storyboard
- Style direction: horror / dreamcore / nostalgia / bizarre / sci-fi / adventure
- Subject: person / animal / monster / product / building / prop
- Scene: indoor / outdoor / corridor / room / small town / forest / space capsule
- Mood: oppressive / nostalgic / uneasy / absurd / gentle / lonely
- Duration: default 5 seconds
- Aspect ratio: default 16:9, short videos can use 9:16
- Whether a reference image is provided

- Suitable use

5. Retro sci-fi

---

### Step 6: 5-Second Video Prompts

Output a separate prompt for each 5-second shot.

Must include:

- PS1 low poly 3D gameplay footage feel
- Fixed camera / old-game hard cuts / slow panning
- Low frame rate character animations
- Stiff turns
- Blurry textures
- Low resolution
- Jagged edges
- CRT scanlines
- Old-game UI
- Sound design
- No high-definition modern 3D

---

### Step 7: Long Video Splitting

Videos longer than 15 seconds must not be written as a single long prompt. They must be split into multiple 5-second segments.

Recommended structure:

- 15 seconds: 3 five-second shots
- 30 seconds: 6 five-second shots
- 60 seconds: 12 five-second shots
- 75 seconds: 15 five-second shots
- 90 seconds: 18 five-second shots

Each 5-second shot chooses a different pacing type based on the plot.

---

## 7. Core Video Pacing Rules

A PS1 low poly video is not a modern film turned low-res, but rather like a piece of early 3D game gameplay footage.

Core pacing:

> Fixed camera observation + low frame rate character movement + old-game hard cuts + UI interruptions + sudden anomalies + brief pauses.

The video can be slow, but it must not be slow all the time.\
The video can use fixed cameras, but not every shot should contain only one action.\
The video can be low-res, but it must have event progression.

---

## 8. 5-Second Video Pacing Types
When generating 5-second videos, you must select a rhythm type.

### A. Exploration Type

Best for: corridors, rooms, dreamcore spaces, nostalgic adventures.

Structure:

- 0-1.5 seconds: fixed camera showing the space
- 1.5-3 seconds: character walks into frame at low frame rate
- 3-4 seconds: character stops and turns head stiffly
- 4-5 seconds: distant anomaly / UI pop-up

---

### B. Hard Cut Type

Best for: horror shorts, game trailers, plot progression.

Structure:

- 0-1.5 seconds: shot 1, character standing in the scene
- 1.5 seconds: old-game-style hard cut
- 1.5-3 seconds: shot 2, item / door / monster close-up
- 3 seconds: brief black screen or screen flicker
- 3.2-5 seconds: shot 3, anomaly appears, UI pop-up

---

### C. UI Interruption Type

Best for: item discovery, quest updates, save points.

Structure:

- 0-1 second: character approaches the item
- 1-2 seconds: item flickers at low frequency
- 2-3 seconds: screen freezes, UI pops up
- 3-4 seconds: inventory / dialog box / map interface
- 4-5 seconds: back to the scene, character steps back or turns head

---

### D. Glitch Scare Type

Best for: retro horror, weirdcore, experimental animation.

Structure:

- 0-2 seconds: quiet fixed frame
- 2-2.5 seconds: texture flicker, slight image misalignment
- 2.5-3 seconds: monster / figure briefly appears
- 3-4 seconds: black screen, stutter, or UI error message
- 4-5 seconds: scene restored, but the anomaly is closer

---

### E. Chase Type

Best for: horror climax, escape sequences, game trailers.

Structure:

- 0-1 second: character runs across the frame at low frame rate
- 1-2 seconds: hard cut to another fixed camera position
- 2-3 seconds: monster chases forward in a stuttering manner
- 3-4 seconds: cut to a door or stairs
- 4-5 seconds: door won't open / UI displays LOCKED

---

## 9. Camera Movement Specifications

Allowed:

 1. Fixed camera
 2. Slow lateral pan
 3. Slow push-in
 4. Hard cut between rooms
 5. Corridor camera position switch
 6. Hard cut to item close-up
 7. UI menu interruption
 8. Black screen loading transition
 9. Slight screen shake
10. Extremely slow orbit around items

Prohibited:

 1. Drone shots
 2. High-speed fly-through shots
 3. Cinematic handheld camera work
 4. Smooth Steadicam tracking
 5. Modern game over-the-shoulder shots
 6. Large depth-of-field changes
 7. Advanced motion blur
 8. Complex long-take choreography
 9. Flashy music video transitions
10. Realistic film cinematography look

## 14. Output Format Requirements

Each time this Skill is executed, the output should follow this order:

 1. Requirement understanding
 2. Style judgment
 3. Creative direction
 4. Asset planning
 5. Image prompt
 6. Storyboard
 7. 5-second video prompt
 8. Editing and sound suggestions
 9. Negative prompt
10. Review checklist

The simpler the user's request, the shorter the output.\
The more complex the user's request, the more it unfolds layer by layer.\
Do not output all the appendix content right away.

---

## 15. Core Execution Principles

 1. Prefer rough over polished.
 2. Prefer low resolution over high definition.
 3. Prefer stiff over silky smooth.
 4. Prefer fixed camera over cinematic camera movement.
 5. Prefer blurry textures over realistic materials.
 6. Prefer old game screenshots over modern CG.
 7. Must be 3D low-poly, not 2D pixel.
 8. Video rhythm comes from game events, not from modern film editing.
 9. 5-second videos can also include hard cuts, UI, black screens, inventory, and anomaly events.
10. All outputs must be directly usable for image or video generation.
