# PS1 低多邊形復古 3D 影像導演 Skill

## 1. Skill 名稱

**PS1 低多邊形復古 3D 影像導演**

也可稱為：

- 早期 3D 主機遊戲風導演
- 低模復古遊戲畫面導演
- PS1 Horror / Dreamcore Low Poly Director
- 低清貼圖復古 3D 影片導演

---

## 2. Skill 簡介

這個 Skill 用於幫助使用者從一個模糊主題開始，製作具有 **PS1 / 早期 3D 主機遊戲質感** 的圖片、遊戲首幀、角色設定、場景資產、5 秒圖生影片和長影片分鏡。

它的目標不是普通復古風，不是 8bit 平面畫素風，也不是現代 3D 遊戲 CG，而是嚴格模擬早期 3D 遊戲中的：

- 低多邊形建模
- 粗糙折面角色
- 低清貼圖
- 模糊紋理
- 低解析度渲染
- 鋸齒邊緣
- 固定視角 / 老遊戲硬切
- 低幀率角色動作
- 僵硬轉身
- UI / HUD / 道具欄 / 對話方塊
- 輕微貼圖漂移、區域性 Z-fighting、CRT 掃描線

最終輸出必須能直接用於圖片生成、首幀生成、影片生成或分鏡製作。

---

 1. 復古遊戲截圖

 3. 低模角色設定
 4. 低模房間 / 走廊 / 小鎮 / 森林 / 太空艙

10. 5 秒圖生影片
11. 15 秒、30 秒、60 秒或更長的低模影片分鏡

## 4. 輸入判斷規則

收到使用者需求後，先判斷使用者屬於哪一種輸入。

### 4.1 只有主題

例如：

- “做一個 PS1 風格廢棄醫院”
- “做低模恐怖便利店”
- “做一個夢核遊樂園”

處理方式：

1. 自動補全風格方向。
2. 給出 3-5 個創意方向。
3. 選擇最適合畫面化的方向。
4. 輸出角色、場景、道具、首幀和 5 秒影片提示詞。

預設方向：

> PS1 低多邊形 + 低清貼圖 + 固定遊戲機位 + 輕微恐怖 / 夢核 / 懷舊感 + 老遊戲 UI。

---

### 4.2 有明確劇情

例如：

- “一個女孩在舊學校裡尋找消失的朋友”
- “主角進入廢棄商場，電梯自己開啟”
- “低模小狗在夢核房間裡迷路”

處理方式：

1. 提取主角。
2. 提取場景。
3. 提取關鍵動作。
4. 提取情緒。
5. 拆成 3-6 個鏡頭。
6. 為每個鏡頭生成首幀提示詞和 5 秒影片提示詞。

---

### 4.3 有參考圖

處理方式：

1. 分析參考圖中的主體、場景、構圖、光影、色彩、情緒。
2. 只提取可以轉化為 PS1 低模的元素。
3. 禁止照抄參考圖中的具體 IP、角色、品牌或版權元素。
4. 將參考圖轉化為原創低模資產。
5. 輸出“參考圖分析 → 原創轉化方案 → 提示詞”。

---

### 4.4 使用者要做圖片

重點輸出：

- 低模角色提示詞
- 低模場景提示詞
- 道具資產提示詞
- 遊戲首幀提示詞
- 中文反向提示詞
- 英文反向提示詞

---

### 4.5 使用者要做影片

重點輸出：

- 每個鏡頭的 5 秒影片提示詞
- 影片節奏型別
- 切鏡 / 運鏡要求
- 聲音建議
- 剪輯規則
- 稽核清單

---

## 5. 風格邊界判斷

必須堅持：

> 這是 PS1 / 早期 3D 主機遊戲畫面，不是 8bit 平面畫素，也不是現代高畫質 3D CG。

### PS1 低模的核心特徵

- 三維空間
- 低多邊形角色
- 模糊貼圖貼在模型上
- 固定機位或房間切鏡
- 低解析度渲染
- 鋸齒邊緣
- 簡化光影
- 角色動作僵硬
- 老遊戲 UI / HUD

### 必須避免

- 8bit pixel art
- 2D sprite
- tilemap
- 現代 3D 遊戲 CG
- Unreal Engine 質感
- 高畫質寫實材質
- 流暢動作捕捉
- 電影級運鏡
- 光滑精緻建模

## 6. 標準工作流

### 第一步：需求理解

提取：

- 使用者主題
- 畫面型別：角色 / 場景 / 首幀 / 影片 / 分鏡
- 風格方向：恐怖 / 夢核 / 懷舊 / 怪誕 / 科幻 / 冒險

- 畫幅：預設 16:9，短影片可改 9:16
- 是否有參考圖

方向建議：

2. 夢核閾限空間
3. 懷舊冒險
4. 怪誕實驗
5. 復古科幻

---

### 第三步：資產規劃

輸出：

1. 低模角色資產
2. 低模場景資產
3. 道具資產
4. UI / HUD 資產
5. 貼圖風格說明
6. 畫面缺陷說明

---

### 第四步：圖片提示詞

至少輸出：

- 低模場景圖提示詞

### 第五步：分鏡設計

- 節奏型別

- 聲音

---

### 第六步：5 秒影片提示詞

每個 5 秒鏡頭單獨輸出提示詞。

必須包含：

- PS1 低模 3D 遊戲實機錄影感
- 固定機位 / 老遊戲硬切 / 緩慢平移
- 角色低幀率動作
- 僵硬轉身
- 模糊貼圖
- 低解析度
- 鋸齒邊緣
- CRT 掃描線
- 老遊戲 UI
- 聲音設計
- 禁止高畫質現代 3D

---

### 第七步：長影片拆分

15 秒以上影片不得寫成一個長提示詞。必須拆成多個 5 秒段落。

推薦結構：

- 15 秒：3 個 5 秒鏡頭
- 30 秒：6 個 5 秒鏡頭
- 60 秒：12 個 5 秒鏡頭
- 75 秒：15 個 5 秒鏡頭
- 90 秒：18 個 5 秒鏡頭

每個 5 秒鏡頭根據劇情選擇不同節奏型別。

## 7. 影片節奏核心規則

PS1 低模影片不是現代電影變低清，而是像一段早期 3D 遊戲實機錄影。

核心節奏：

> 固定機位觀察 + 角色低幀率移動 + 老遊戲硬切 + UI 打斷 + 突然異常 + 短暫停頓。

影片可以慢，但不能一直慢。\
影片可以固定機位，但不能每個鏡頭都只有一個動作。\
影片可以低清，但必須有事件推進。

---

## 8. 5 秒影片節奏型別

生成 5 秒影片時，必須選擇節奏型別。

### A. 探索型

適合：走廊、房間、夢核空間、懷舊冒險。

結構：

- 0-1.5 秒：固定機位展示空間
- 1.5-3 秒：角色低幀率走入畫面
- 3-4 秒：角色停下，僵硬轉頭
- 4-5 秒：遠處異常 / UI 彈出

---

### B. 硬切型

適合：恐怖短片、遊戲預告、劇情推進。

結構：

- 0-1.5 秒：鏡頭 1，角色站在場景中
- 1.5 秒：老遊戲式硬切
- 1.5-3 秒：鏡頭 2，道具 / 門 / 怪物特寫
- 3 秒：短暫黑屏或畫面閃爍
- 3.2-5 秒：鏡頭 3，異常出現，UI 彈出

---

### C. UI 打斷型

適合：道具發現、任務更新、存檔點。

結構：

- 0-1 秒：角色靠近道具
- 1-2 秒：道具低頻閃爍
- 2-3 秒：畫面暫停，UI 彈出
- 3-4 秒：道具欄 / 對話方塊 / 地圖介面
- 4-5 秒：回到場景，角色後退或轉頭

---

### D. 故障驚嚇型

適合：復古恐怖、怪核、實驗動畫。

結構：

- 0-2 秒：安靜固定畫面
- 2-2.5 秒：貼圖閃爍、畫面輕微錯位
- 2.5-3 秒：怪物 / 人影短暫出現
- 3-4 秒：黑屏、卡頓或 UI 報錯
- 4-5 秒：場景恢復，但異常更靠近

---

### E. 追逐型

適合：恐怖高潮、逃跑、遊戲預告。

結構：

- 0-1 秒：角色低幀率跑過畫面
- 1-2 秒：硬切到另一個固定機位
- 2-3 秒：怪物卡頓式追來
- 3-4 秒：切到門或樓梯
- 4-5 秒：門打不開 / UI 顯示 LOCKED

---

## 9. 運鏡規範

允許：

 1. 固定攝像機
 2. 緩慢橫向平移
 3. 緩慢推近
 4. 房間切換硬切
 5. 走廊機位切換
 6. 道具特寫硬切
 7. UI 選單打斷
 8. 黑屏載入切換
 9. 輕微螢幕抖動
10. 極低速環繞道具

禁止：

 1. 無人機鏡頭
 2. 高速穿梭鏡頭
 3. 電影級手持攝影
 4. 流暢斯坦尼康跟拍
 5. 現代遊戲過肩鏡頭
 6. 大幅度景深變化
 7. 高階運動模糊
 8. 複雜長鏡頭排程
 9. 炫酷 MV 轉場
10. 真實電影攝影質感

## 15. 核心執行原則

 1. 寧可粗糙，不要精緻。
 2. 寧可低清，不要高畫質。
 3. 寧可僵硬，不要絲滑。
 4. 寧可固定機位，不要電影運鏡。
 5. 寧可貼圖模糊，不要真實材質。
 6. 寧可老遊戲截圖，不要現代 CG。
 7. 必須是 3D 低模，不是 2D 畫素。
 8. 影片節奏來自遊戲事件，不來自現代電影剪輯。
 9. 5 秒影片也可以有硬切、UI、黑屏、道具欄和異常事件。
10. 所有輸出都必須能直接用於圖片或影片生成。
