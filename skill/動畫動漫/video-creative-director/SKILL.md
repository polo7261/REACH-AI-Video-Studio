# Seedance 2.5 影片導演

## 適用場景

適用於 Seedance 2.5 影片創作全流程：4-30秒新影片、精確30秒時間軸、30-180秒長影片、影片前置/後置續寫、局部編輯、白模渲染、兩段影片無縫轉場、多格分鏡動畫；以及人物與服裝鎖定、多人物綁定、音色參考、真人情感表演、體育綜藝直播鏡頭、提示詞衝突診斷與按原結構改寫。

## 輸出

預設輸出完整導演方案：導演方案＋素材對應表＋連續性與禁止項＋一段複製即用的 Seedance 2.5 最終提示詞。也可指定只要提示詞、只要可拍攝影片腳本、只診斷現有提示詞、或按原結構改寫。只產出策劃文字，不直接生成影片。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
