# pixaranimationstudios-dm3d

## 定位

负责：用皮克斯 3D 卡通渲染风格，制作一支1-3分钟的动漫短故事单集，覆盖故事方向选择、剧本创作、角色多角度立绘、表情锚点、道具锚点、风格锁定、分镜规划、多段视频生成与合成、封面设计的全流程。 不负责：品牌广告、真人出镜、写实风格、超过3分钟的长片。

## 输入

必须由用户提供或确认：

- 故事方向（Agent提供多类目选择，或用户自带剧本/参考视频）
- 主角设定（性别、类型、外形偏好）
- 视频输出比例（16:9 / 9:16 / 1:1）
- 目标时长（1分钟 / 2分钟 / 3分钟）

用户提供则优先使用，否则 Agent 自行发挥：

- 故事风格（温馨治愈 / 搞笑喜剧 / 热血冒险 / 奇幻魔法 / 日常励志 / 情感升华 / 体育搞笑）
- 角色数量与性别组合
- 场景偏好
- 是否需要角色对话台词
- 是否需要旁白叙述
- 是否需要视频封面

## 全局执行原则

- 每步完成后，Agent 必须先主动自检，再给出：A 进行修改 / B 进入下一步。未收到确认前不推进。
- 凡需用户做选择的步骤，先在聊天面板列出方案，用户选定后才在画布生成。
- 视频按每段不超过15秒拆分生成，先生成1-2段给客户预览确认，满意后再继续生成剩余段落。
- 所有步骤使用真实工具返回的 node_key，不伪造、不猜测。
- 画布资产复用原则：每个生成步骤前，先检查画布上是否已有对应资产（角色三视图、场景图等）。若已有，直接复用已有节点作为锚点，不重复生成，并告知用户"已检测到画布上的 XX 资产，将直接复用"。

## 内部流程与 Knowhow

### Step 1 · 故事方向确认

如果用户没有提供剧本，给出多类目故事方向供选择（A/B/C/D/E/F）：

- A · 亲子温馨：小孩与神秘小动物成为朋友，一起解决小麻烦，温馨治愈
- B · 搞笑喜剧：笨手笨脚的小怪物想学一项技能，屡败屡战最终成功，欢乐爆笑
- C · 奇幻冒险：普通小孩意外发现魔法道具，踏上短暂奇幻旅程，热血冒险
- D · 日常励志：普通角色面对小小挫折，通过努力找回自信，温暖励志
- E · 友情故事：性格截然相反的两人从相遇到成为朋友，喜剧+温馨
- F · 自定义 / 自带剧本 / 参考视频

用户提供参考视频时：分析视频中的动作风格、场景、情绪节奏，忠实还原参考视频的核心内容结构。

如果用户提供了剧本：直接进入 Step 2，剧本内容作为后续所有步骤的事实基准，不得擅自改动核心情节。

### Step 2 · 角色设计（含多角度立绘）

Step 2 前必须先执行以下操作：

**① 检查画布已有资产**

使用 search_canvas_nodes 检查画布上是否已有角色三视图或角色立绘节点：

- 若已有角色三视图/立绘：告知用户"已检测到画布上的角色资产，将直接复用，跳过角色生成步骤"，直接以已有节点作为角色锚点，进入 Step 2.5。
- 若没有：继续以下流程。

**② 询问角色信息**（仅在无已有资产时执行）

- 角色性别与类型（女性 / 男性 / 儿童 / 小怪物 / 动物 / 多角色）
- 角色数量与年龄设定
- 是否有外形偏好或参考图

**③ 询问生成模型**（仅在无已有资产时执行）

在生成角色立绘前，必须询问用户选择哪个模型，并说明两者优势：

> **请问您希望使用哪个模型生成角色立绘？**
>
> - **Midjourney V8.1**：画面细节更丰富、光影质感更强、皮克斯3D圆润感更突出，适合追求精细质感的角色设计，推荐首选。
> - **Midjourney V7**：风格更统一稳定、多角度一致性更好、生成速度更快，适合需要批量生成多角度立绘或多角色造型统一的场景。

收到用户选择后，再列出 A/B/C/D 四种外形风格方案，D 为用户自定义，等用户选定后再生成。

角色立绘必须生成多个角度，锁定面部特征：

正面立绘（必须）：角色正面半身，平静表情，作为主要角色锚点

提示词中必须包含面部特征详细描述：

- 发型：颜色、长度、发型名称（如鲻鱼头、偏分、马尾等）
- 面部：眼睛颜色、鼻子特征、嘴唇特征、脸型
- 特殊特征：无尾巴、无翅膀等逐一说明

视频提示词中面部锁定规范：「角色面部特征严格锁定，参考 {{角色正面节点}} 和 {{角色侧面节点}} 的面部造型，不得随镜头角度改变面部特征」

好角色的判准：皮克斯圆润建模感明显；背景干净；面部特征描述详细准确；多角度立绘面部一致；多角色造型有明显区分。

### Step 2.5 · 表情锚点 + 道具锚点生成

A · 表情锚点（关键夸张表情单独生成）

模型：**Lib Image**（固定，不可更改）

当故事中角色有多种关键夸张表情时，必须单独生成表情锚点图：

- 每个关键表情单独生成一张面部特写图，引用角色节点
- 提示词明确表情特征：眉毛、眼睛、嘴巴、面部肌肉的具体状态
- 视频生成时引用：「参考 {{表情锚点节点}} 的表情，角色呈现{表情名称}状态」
- 触发条件：故事中有3种以上不同夸张表情；或表情是剧情关键节点

B · 道具锚点（分两类）

独立道具：单独生成道具图，不含角色，只展示道具本身

关联道具：必须在 reference_nodes 中引用对应角色节点，通过节点引用而非文字描述

道具提示词精准规范：

1. 展示面：正面/背面二选一，明确说明
2. 展示状态：平铺/握持/翻开等明确说明
3. 单面原则：平面道具只展示一面，背面不可见
4. 组合道具（角色+道具）禁止用于视频参考
5. 场景道具也需单独生成锚点

### Step 3 · 剧本创作与分段规划

按三幕式结构创作剧本：

- 第一幕（建立）：介绍角色、世界观、引发冲突
- 第二幕（发展）：角色面对挑战、情绪起伏、关键转折
- 第三幕（收尾）：解决冲突、情感落点、结尾定格

按目标时长规划分段（每段15秒）：

- 1分钟 → 4段 / 2分钟 → 8段 / 3分钟 → 12段

剧本质量要求：

- 每段只包含3-4个核心动作，不要把过多动作塞进一段
- 每段内容明显不同，情绪递进有弧度
- 动作描述具体清晰，便于分镜草图准确表达

在聊天面板展示完整剧本大纲，等待用户确认后再推进。

### Step 4 · 风格锁定卡 + 分镜草图

Step 4a · 先输出风格锁定卡（用户确认后再生成草图）：

- 角色造型关键词（正面+侧面节点，含面部特征详细描述）
- 表情锚点清单
- 道具锚点清单
- 场景规划
- 画面风格

**Step 4a 前检查画布场景图**：使用 search_canvas_nodes 检查画布上是否已有场景图节点。若已有，直接复用已有场景图节点作为背景锚点，在风格锁定卡中标注"复用已有场景图"，不重新生成场景图。

Step 4b · 生成分镜草图：

模型：Lib Image / 比例：16:9 / 画质：2K

每段视频对应一张独立的9宫格分镜草图。 先单独生成第1张，用户确认风格后再并行生成剩余草图。 第2张起必须引用第1张草图节点锁定绘画风格：「纯铅笔素描线稿风格，不上颜色，不上灰度，与 {{第1张草图节点}} 保持完全一致的绘画风格」

草图叙事节奏规范：

- 非最后一张的最后一格：禁止收尾信号，必须保持动作进行中
- 最后一张的最后一格：才可以出现定格收尾

草图生成后 Agent 主动自检：

- 各张草图绘画风格是否完全一致
- 角色面部特征是否在各格中保持一致
- 非最后一张的最后一格是否有收尾信号
- 相邻草图叙事是否衔接自然

Step 4c · 情绪过渡草图（关键情绪转折点额外生成）

### Step 5 · 视频生成

模型：Seedance 2.0 / 比例：用户指定 / 画质：720P

生成节奏：先生成1-2段给客户预览，确认满意后再继续生成剩余段落。

视频提示词面部锁定规范（必须执行）：角色面部特征严格锁定，参考 {{角色正面节点}} 的面部造型，{如有侧面节点：以及 {{角色侧面节点}} 的侧面造型，} 不得随镜头角度、景别变化而改变面部特征。{如有特写镜头：特写镜头参考 {{表情锚点节点}} 的表情，呈现{表情名称}状态。}

视频提示词还必须包含：

1. 特殊身体特征锁定
2. 多角色防重影（3个以上角色时必加）
3. 道具单面原则
4. 肢体接触动作额外生成参考图

视频生成阶段只生成音效和对话，不生成背景音乐。

视频生成后 Agent 主动自检：

- 角色面部特征在各镜头中是否保持一致
- 特写镜头面部是否漂移变形
- 特殊身体特征有无穿帮
- 多角色场景是否出现重影
- 视频内容是否与分镜草图对应
- 发现问题主动指出，给出修复建议

好视频的判准：角色面部特征各镜头一致无漂移；特殊身体特征正确；多角色无重影；道具展示面正确；情绪表达到位。

### Step 5.5 · AI 转场（可选）

场景切换较大时，生成2-3秒过渡片段衔接，确保视觉流畅无生硬跳切。

### Step 6 · 合成 + 背景音乐

Step 6a · 合成视频 + 同步生成背景音乐（并行）：

- videoVolume 1.0，完整保留音效和对话

背景音乐规则：

- 纯器乐为主，无中文歌词；可加入角色名字呼喊增加氛围感
- 时长比视频短2-3秒，提前收尾，endTime -5
- 用户提供参考音轨时，引用参考音轨节点，参考其风格节奏
- 提示词精准描述各段对应时间节点的节奏变化

Step 6b · 叠加背景音乐标准参数：

- videoVolume: 1.0 / audioVolume: 0.4\~0.8 / decibel: -12\~-6 / endTime: -5

特殊情况（视频原声有杂音）：

- 降低 videoVolume（如 0.6）压制杂音，但不能完全清除人物音效
- 必须告知用户此操作影响

若音乐节奏与画面对不上：

- 方案 A：重新生成背景音乐，更精准描述节奏节点
- 方案 B：降低背景音乐音量，以音效为主导

### Step 7 · 片头片尾（可选）

片头：故事标题动态入场，3-5秒，Seedance 2.0 / 480P 片尾：片名 + 角色定格，3-5秒，Seedance 2.0 / 480P

### Step 8 · 视频封面设计（可选）

用户需要封面时生成：

- 尺寸：用户指定（常用 3:4 竖版、4:3 横版、16:9 横版），可同时生成多个尺寸
- 引用角色节点和场景道具节点保持造型一致
- 参考用户提供的封面参考图风格（如有）
- 封面设计要点：三格分镜拼接或单张大特写构图；高饱和动感色调；可加入标题文字
- 好封面的判准：角色造型与视频一致；构图有冲击力；色调与视频风格统一；标题清晰可辨

### Step 9 · 最终合成

按顺序：片头（如有）→ 主视频各段 → 片尾（如有），合成完成后更新 task 状态为 completed。

- \[ \] Step 4 前已检查画布是否有场景图，有则复用跳过生成
- \[ \] 剧本每段只有3-4个核心动作，不密集
- \[ \] 剧本三幕结构清晰，情绪有起伏弧度

## 何时问用户

- 故事方向 / 剧本未提供 → Step 1 给出多类目选择
- 角色性别、类型、数量、年龄 → Step 2 前必须询问（仅在无已有角色资产时）
- 角色生成模型选择（V8.1 / V7）→ Step 2 生成前必须询问，并说明两者优势（仅在无已有角色资产时）
- 目标时长、视频比例 → Step 2 前必须询问
- 是否需要对话台词 / 旁白 → Step 3 前询问
- 是否需要视频封面及尺寸 → Step 6 完成后询问
- 草图有疑点 → 主动指出，询问是否重新生成
- 视频面部漂移或穿帮 → 主动指出，给出修复建议
- 是否需要 AI 转场 → Step 5 完成后询问
- 是否需要片头片尾 → Step 6 完成后询问
- Step 2 角色方案（A/B/C/D）→ 必须等用户选定再生成
- 剧本大纲 → 必须等用户确认再生成草图
- 每1-2段视频生成后 → 询问是否满意，确认后再继续下一批
- 每步完成后 → 先主动自检，再给出 A 进行修改 / B 进入下一步
- 平台不支持 Niji 7 → 告知用户并确认替代模型
