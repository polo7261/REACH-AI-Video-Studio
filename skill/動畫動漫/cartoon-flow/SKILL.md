# cartoon-flow

做 2D / 2.5D 風格化動畫影片（卡通、anime 風、非寫實角色）時用本 skill。從單段到多段故事，按階段推進，每階段產出對接 13 工具。

## 階段

1. **場景/劇情解析**：理清故事、角色、場景、道具（結構化產出見下）。
2. **風格設定**：定一套統一動畫畫風（用下面的"風格公式"），作為全片視覺基準。
3. **錨點設定圖（兩步：先基底→再風格化）**：卡通資產別一步到位。先用 `generate_image_v3` 出角色/場景/道具的**中性基底圖**（結構、比例、構圖對，模板見下），再用它作參考**風格化**到第 2 步的畫風。`tag` 對應 character/scene/prop，風格化後的圖作跨鏡錨點；角色一致性見 character-consistency。
4. **分鏡**：多段故事按 SP 分鏡切割原則拆鏡（CLIP 欄位見下），定節奏與首尾銜接。
5. **逐鏡生成**：用 `generate_video_v3` 逐鏡生成，`reference_nodes` 引用對應錨點、prompt 裡 `{{NodeKey}}` 繫結，單鏡 ≤15s；數量鎖見下。
6. **合成**：多段用 `composite_video` 拼成成片（見 montage，`Skill("montage")`）。

## 場景解析結構（Stage 1 深度）

解析產出：敘述摘要；**角色**（簡稱 shorthand 供跨模組引用、性別、年齡段、是否來自上傳）；**場景**（簡稱、室內/外、時段）；**候選道具**；風格預設傾向 + 理由；總時長；**格式路徑**（single-video 單段 / multi-clip 多段）+ 選擇理由。簡稱貫穿後續所有階段，別中途改名。

## 風格公式（Stage 2 深度）

把畫風寫成一條單行公式，固定這幾段拼接：

> **[畫風基底]** 動畫，參考 **[風格參照]** —— [線條技法]、[上色技法]、[調色盤]、[點綴特效]、[背景處理]、[動畫節奏/timing]、[相機描述]

- 各段由需求驅動；無法對映或缺輸入時回退到通用預設（現代 2D 手繪 + 粗細變化的手繪墨線 + 三值平塗賽璐珞硬陰影 + 飽和大地色 + 陰影區半色調點 + 手繪線沸騰、動作走二拍 + 24fps）。
- **只限 2D / 手繪 / 卡通範圍**；畫素、3D、寫實風不在此。

## 基底描述模板（Stage 3 基底步）

- **角色基底**：年齡性別+表情 → 髮型 → 體型體態 → 面部細節 → 服裝（上→下→鞋，無 logo/文字、全覆蓋、肘腰膝真實褶皺、乾淨輪廓）→ 姿態；**全身站立肖像**、純色背景柔和正面漫射光、頭頂腳底留邊距、無道具/無場景。
- **場景基底**：標識行 → 建築（牆/地/關鍵結構/陳設/空間佈局：左…右…後景…前景…）→ 布光 → 氛圍 → 靜態廣角建立鏡（前景錨 + 背景錨）；**空場鎖**：無人物/剪影/動態、16:9 水平。
- **道具基底**：標識行 → 材質/表面細節/特徵 → 孤立產品樣照構圖、純色背景上方漫射光；**孤立鎖**：無人/無手/無其他物體/無場景；通常 1:1。
- **風格化步**：保留基底的身份/空間佈局/形狀精確不變，**只改渲染**到風格公式畫風。

## CLIP / beat 結構（Stage 4 深度）

每個 CLIP 記：敘事功能（建立/激勵事件/上升/高潮/收束）、角色想要（Want）、地點 + 地點模式（鎖定/轉場）、轉場型別、**相機模式**（單鎖定/多切鎖定/視差滾動）、**音訊模式**（氛圍/旁白/動作/對話）、角色與道具鎖、場景描述、取景、高潮標記（climax-token）、**收束狀態**（本鏡結束時角色的最終姿態/位置/表情，帶空間位置）。
CLIP 內再拆 **beats**（每 beat：want / 取景提示 WS·MS·CU / 描述 prose / 高潮標記 / **空間錨點**）。
**跨鏡連續性**：靠"空間錨點詞彙 + 上一鏡的空間錨點"橋接（bridge-rule），保證角色位置/朝向不跳變。

## 逐鏡數量鎖（Stage 5 深度）

生成 prompt 裡顯式鎖死：本鏡**角色數恰好 N**——無額外角色/路人/背景人群，角色單一例項、絕不克隆/複製/同框出現兩次；**道具唯一**（每個敘事道具單一例項）；**場景鎖定**（全鏡動作發生在本地點內，不切換空間）。

## 原則

- 全片統一動畫畫風，跨鏡不漂移。
- 風格公式、鏡頭節拍等關鍵決策按 SP 導演經驗自己做，不外包。
- 暫停點：風格設定圖、分鏡確認後再進生成（見 SP）。
