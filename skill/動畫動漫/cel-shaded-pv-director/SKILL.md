# 賽璐璐風格PV導演

在平台內完成“創意訪談 → 分段影片提示詞 → 核心角色／主體圖提示詞 → 生圖 → 影片首段試跑 → 餘段生成”。固定日式硬邊賽璐璐、抽象 Editorial MG、遊戲UI和平面海報運動；題材、角色、色彩、世界觀與聲音隨專案變化。

## 工作流

## 統一互動規則

凡是確認、是／否決定或有限列舉選擇，必須呼叫平台內建智慧體的結構化選擇元件，以按鈕、單選卡或下拉彈窗展示選項並等待點選；不得要求使用者輸入序號、選項名稱或“確認”等文字。推薦項放在首位並標註“推薦”，schema固定值提供“使用固定值”和“返回更換模型”。模型候選較多時使用可搜尋單選列表，不截斷候選。

首輪故事、角色目標、時長、色調、節奏、鉤子和聲音問題也必須先使用彈窗；每題提供2—3個根據當前創意推導的互斥具體方案，推薦項排首位並寫明影響，同時提供“自定義”。使用者只有點選“自定義”後才進入文字輸入。模型、參考圖開關、畫幅、畫質、解析度、是否生成、確認執行、重試和停止同樣必須使用彈窗。當前執行環境沒有結構化選擇元件時停止並說明原因，不得退化為讓使用者打字確認。

### 1. 建立當前PV雛形

提取一句話故事與衝突、角色目標、用途、總時長、畫幅、情緒與色調、節奏、聲音模式、開頭鉤子、標題和參考素材。不得重複詢問已提供的資訊。

首次回覆先輸出：

```markdown
## 當前PV雛形
**一句話故事：** 已知內容；無法判斷則標“待定”
**已經明確：** 使用者已給出的關鍵決定
**暫時待定：** 只列會顯著改變成片的缺口
```

隨後立即呼叫結構化選擇元件，元件標題固定為 `這一輪需要確認`；正文不得再列編號問題。一次只彈出2—4個未明確的高影響問題；元件單次容量不足時分成連續彈窗，但仍屬於同一輪訪談。優先確認故事與衝突、角色目標、時長、色調、鉤子和聲音模式，已說明的內容不得重複詢問。

- 故事與衝突、角色目標、色調、節奏和鉤子：根據已知創意生成2—3個可直接採用的具體方案，不用“方案A”之類空標籤。
- 總時長：預設提供“15秒”“30秒”“45秒”和“自定義”；已有時長時不再詢問。
- 聲音模式：提供“背景音樂＋音效（推薦）”“純鼓點／音效”“使用者自定方案”。
- 每個選項用一句短說明寫清對故事、節奏或畫面的影響；推薦項必須放第一。

🔴 **CHECKPOINT · STOP — 單輪創意訪談**

首次回覆到此停止。使用者回答後直接成稿；使用者說“你來定”時採用與已知設定一致的明確原創方案。漏答聲音模式時預設“背景音樂＋音效”。只有回答存在實質衝突時才補問衝突項。畫幅未指定時預設16:9。

### 2. 讀取製作語法

生成前完整讀取 references/style-grammar.md。進入平台生成階段前完整讀取 references/generation.md。參考素材只提供段落組織、構圖、色彩職能、平面化、圖層關係與節奏方法；不得繼承具體題材、角色外觀、配色、道具、標題或鏡頭編排。

### 3. 鎖定絕對純二維

人物、場景、道具、UI與特效必須是二維插畫或平面圖形。只允許圖層平移、縮放、旋轉、平面推拉、魚眼式圖形變形、剪影反相、負形、畫面切割、遮罩揭示、紙片翻轉、圖形替換與版面重組。

禁止3D、2.5D、裸眼3D、三維攝影機、立體建模、真實縱深、視差、三維透視渲染、CG材質、體積光、真實景深與鏡頭穿越。強透視、魚眼和極端視角只能寫成“二維插畫變形”或“平面版式變形”。三維訴求自動替換：

| 使用者表達 | 純二維替代 |
|---|---|
| 2.5D、景深、視差 | 平面遮擋、大小跳變、分層錯位、色塊切割 |
| 裸眼3D | 衝出螢幕輪廓超框、固定畫框、負形遮罩、圖形突然放大 |
| 三維攝影機穿越 | 圖層橫移、平面推拉、版面拆解後重組 |
| 立體旋轉 | 正反面切換、紙片翻面、二維形變、剪影反相 |

### 4. 拆分時長與規劃節奏

- 總時長≤15秒輸出1段；總時長&gt;15秒時按每段≤15秒拆分。
- 若末段&lt;5秒，平均重分最後兩段；16秒拆為8秒＋8秒，31秒拆為15秒＋8秒＋8秒。
- 標題使用：`第N段（全片X—Y秒｜本段Z秒）`。段內時間碼從0秒連續閉合到本段時長。
- 每段重複純二維邊界、色彩職能、3—5個角色錨點和必要場景圖形，能夠獨立生成。
- 中間段以動作、圖形或聲音橋接；下一段首鏡回應橋接。僅最終段出現完整標題和最終聲音收束。

每段開頭0.5—1.5秒設定故事鉤子。按本段敘事任務選擇節奏檔：

| 節奏檔 | 任務 | 鏡頭數 | 主鏡頭 | 強調鏡頭 |
|---|---|---|---|---|
| 氛圍檔 | 抒情、神秘、世界觀建立 | 7—9鏡 | 1.5—2.5秒 | 0—1個 |
| 均衡檔 | 劇情推進、角色展示、懸念調查 | 8—10鏡 | 1.0—2.0秒 | 1—2個 |
| 動作檔 | 追逐、戰鬥、熱血爆發 | 10—11鏡 | 1.1—1.9秒 | 2—3個 |

非15秒片段按 `本段時長÷15` 等比縮放鏡數和強調鏡頭數並四捨五入，至少3鏡。0.8秒及以下均計為快鏡，數量不得超過30%。動作檔保留1—2個判斷、蓄力或情緒停頓。30—45秒專案按建立、衝突、爆發、收束遞進，不得逐段複製相同鏡數和快鏡位置。

### 5. 生成全部影片提示詞

輸出以 `最終影片提示詞：` 開始，不附分析、備選版本或AE教程。每段按以下連續段落順序書寫，不使用1—10編號：

 1. 導演總述與規格：片種、段長、畫幅、情緒、敘事任務、節奏檔、純二維邊界和原創要求。
 2. 主題、世界觀與色彩：核心概念、原創暫定標題、情緒曲線、顏色職能及2—3個母題。
 3. 聲音與節奏：已確認的音樂、鼓點、環境聲、動作聲、靜默、卡點與段尾聲音。
 4. 畫面總體風格：硬邊賽璐璐、純色、剪影、負形、描邊、Editorial MG、UI、留白與視覺中心。
 5. 題材圖形庫：6—10種原創圖形、圖示、刻度、網格、UI或紋樣及其敘事職能。
 6. 平面空間表現：把場景實體轉換為背景圖形、展開版面、漫畫分割槽、圖層覆蓋和切割關係。
 7. 逐角色設計；無人物專案改為“核心主體設計”。
 8. 分秒鏡頭：逐鏡寫連續時間碼和完整鏡頭資訊。
 9. 二維動效與轉場：統一圖形運動、動作／聲音觸發與段間橋接。
10. 嚴格限制：再次鎖定純二維、原創性、可讀性與連續性黑名單。

每鏡必須包含：時間範圍、主體狀態與主要動作、細節動作或道具反饋、平面場景錨點、構圖與景別、二維畫面運動、圖形或蒙版響應、轉場觸發、聲音節點。相鄰角色鏡不得重複同一動作；動作必須引發圖形、蒙版、聲音或轉場中的至少一種響應。

每段目標3800—4600個Unicode字元，硬上限4999。視覺風格、圖形空間和角色佔45%—55%，時間軸佔35%—45%，聲音、動效和限制使用剩餘篇幅。不得刪除純二維三重門禁、角色錨點、題材圖形庫、節奏檔或時間碼。

### 6. 生成核心角色／主體圖提示詞

全部影片提示詞之後立即輸出 `核心角色圖提示詞：`；無人物時改為 `核心主體圖提示詞：`。只生成一份提示詞：有人物時選擇敘事核心主角，多角色專案不生成群像；無人物時選擇推動故事的核心主體。

提示詞按固定順序寫成一個可直接生圖的連續段落：身份與敘事職能 → 年齡段、頭身比與體型 → 臉型、五官、眼神與表情 → 髮型髮色、外輪廓與線條邏輯 → 服裝層次、不對稱結構與色塊比例 → 配飾和標誌道具 → 姿態、手勢、動作趨勢與性格 → 3—5個連續性錨點 → 硬邊賽璐璐與Editorial MG方法 → 色彩、背景圖形和受控紋理 → 原創與純二維負面限制。

只補齊不會改變身份、劇情或世界觀的低風險視覺細節。不得套用參考案例中的具體年齡、臉型、異色瞳、髮型、服裝、配色、硬幣或標記。預設全身角色設定圖、單一視覺中心、極簡平面背景；無人物主體按輪廓、部件、色塊、標誌符號和靜態展示姿態改寫。

### 7. 選擇圖片模型並生成

生成提示詞後讀取平台當前圖片模型列表。若存在名稱精確匹配（忽略大小寫）的 `Lib Image`，且其當前schema支援生成1張圖，則預設選中並允許使用者更換；不可用或不相容時說明原因，再讓使用者從相容模型中選擇。讀取所選模型完整schema，只展示真實存在的圖片尺寸（畫幅比例）、`quality` 和 `resolution` 選項；固定值標明不可修改。圖片數量固定為1。

圖片階段必須按狀態順序推進：`提示詞已完成 → 引數已逐項選擇 → 等待最終確認 → 已授權 → 建立並執行節點`。預設模型、schema預設值、首輪迴答、此前的“可以／繼續／你來定”或生成影片的授權都不算生圖授權。輸出全部影片與角色／主體圖提示詞的同一輪禁止建立或執行圖片節點。

🔴 **IMAGE CHECKPOINT · STOP — 圖片引數確認**

用結構化彈窗依次選擇圖片模型、圖片尺寸（畫幅比例）、畫質和解析度／清晰度；每個schema可配置欄位都必須收到本輪點選事件，固定欄位也必須點選確認。引數齊全後展示模型、尺寸、畫質、解析度、數量和提示詞物件彙總，再彈出“確認生成圖片”“返回修改”“停止”，並在此停止當前輪。

只有收到當前圖片檢查點中“確認生成圖片”的獨立點選事件，才把狀態改為“已授權”，並在下一輪建立、執行一個圖片節點。未收到該事件時不得呼叫任何圖片節點建立或執行能力。生成成功後展示圖片或結果節點；生成失敗時彈出“重試”“修改引數”“停止”，不進入影片階段。

### 8. 確認是否生成影片

圖片成功後彈出“繼續生成影片”“重新生成角色／主體圖”“停止”三個選項。

🔴 **VIDEO DECISION · STOP**

使用者選擇停止時保留全部提示詞和圖片結果並結束。選擇重新生圖時返回圖片引數檢查點。選擇繼續時彈出“使用剛生成的參考圖”“不使用參考圖”“返回”三個選項。

### 9. 選擇影片模型與引數

按參考圖選擇和所有原分段時長篩選平台影片模型：

- 使用參考圖：優先 `singleImage2video`，其次使用schema允許的 `image2video` 或 `mixed2video`。
- 不使用參考圖：只使用 `text2video`。
- 只展示其 `duration` 能覆蓋每個原分段時長的模型。無相容模型時停止並請求允許按模型最大時長重分段，禁止靜默修改。
- 在相容候選中優先顯示並預設選中名稱精確匹配（忽略大小寫）的 `Minimax H3`；它不相容當前參考模式或分段時長時不得強選，必須說明排除原因並讓使用者選擇其他相容模型。

用單選彈窗展示相容影片模型；使用者點選模型後讀取完整schema，再為每個引數建立獨立的結構化選項。模型在列表中預設選中不等於引數已確認，schema預設值也不等於使用者選擇；所有當前可配置欄位都必須收到本輪點選事件，固定欄位也必須點選“使用固定值”。

- `Minimax H3`：必須逐項確認影片尺寸／比例、解析度／清晰度、影片時長和生成數量。當前介面可能出現自適應、21:9、16:9、4:3、1:1、3:4、9:16，768P／2K，時長滑桿及1／2／4個；這些只作為欄位識別線索，實際選項必須以當前schema為準。
- `Seedance` 系列：必須逐項確認影片尺寸／比例、解析度／清晰度、影片時長、生成音訊開關和生成數量。當前介面可能出現Auto、16:9、4:3、1:1、3:4、9:16、21:9，480P／720P／1080P／4K，時長滑桿、音訊開啟／關閉及1／2／4個；這些只作為欄位識別線索，實際選項必須以當前schema為準。
- 其他影片模型：逐項確認schema實際宣告的 `ratio`、`quality`／`resolution`、`duration`、`enableSound`、`count` 及其他影響結果或費用的生成欄位。

不得把提示詞原時長、模型預設時長、預設比例、預設清晰度、預設聲音或預設數量直接寫入節點。若影片畫幅不同於提示詞畫幅，自動同步改寫各段規格、構圖、版式運動和畫面切割；故事、角色、色彩、聲音、分段時長與時間碼不變。

🔴 **VIDEO PARAM CHECKPOINT · STOP — 影片引數確認**

彙總影片模型、模式、解析度／清晰度、畫幅比例、參考圖、影片時長、生成音訊、生成數量和各段時長；同時保留每項對應的schema原始值，不能只儲存介面展示文案。模型不支援的欄位明確標為“不支援”，不得省略造成誤解。最終彈窗固定提供“確認生成首段”“返回修改”“停止”，並在此停止當前輪。只有收到當前檢查點中“確認生成首段”的獨立點選事件，才允許在下一輪建立第一段影片節點，不同時提交餘段。

建立首段節點時先寫入全部已確認的schema原始值，但禁止立即執行；隨後回讀節點並逐項比對實際落庫值。H3選擇768P時，執行前必須讀到 `data.params.settings.resolution="768P"`，讀到缺失或 `2K` 均視為失敗。只有模型、模式、比例、清晰度、時長、聲音、數量和參考圖均與本輪選擇一致，才執行節點；不一致時先修正並再次回讀，仍不一致則停止，不得用模型預設值繼續生成。

### 10. 首段試跑與餘段生成

首段成功後展示影片或結果節點，並彈出“繼續生成全部餘段”“調整提示詞或引數後重試首段”“停止”。

🔴 **PILOT CHECKPOINT · STOP**

- 繼續：為每個餘段建立獨立節點並提交生成；不得重跑已成功首段。
- 調整：只更新首段提示詞或生成引數並重試，確認透過後再次詢問是否繼續。
- 停止：保留所有節點和結果。
- 餘段失敗：僅對失敗節點按原引數自動重試一次；仍失敗則報告原因並保留其他成功片段。

## 交付前檢查

- 訪談、圖片引數、影片決策、影片引數和首段試跑五個檢查點均未被跳過。
- 所有有限選擇與確認均使用結構化彈窗；沒有要求使用者輸入序號、選項名稱或確認文字。
- 圖片模型、尺寸、畫質和解析度均有本輪點選記錄，且節點建立前收到當前檢查點的“確認生成圖片”事件；預設值和歷史同意未被當作授權。
- 所有影片段時間軸閉合、鏡數符合節奏檔、快鏡不超過30%，中間段橋接且僅最終段出現完整標題。
- 核心角色／主體圖提示詞資訊完整，不含參考案例專有設計；只有一份、只生成一張圖。
- 圖片與影片模型、比例、解析度、時長、模式、聲音和生成數量選項全部來自當前平台 schema，沒有寫死或偽造。
- H3的比例、清晰度、時長和數量，或Seedance系列的比例、清晰度、時長、音訊和數量，均有本輪逐項點選記錄；模型預設值未被視為使用者確認。
- 選擇參考圖時已建立圖片到影片節點的入邊；不使用參考圖時沒有多餘圖片入邊。
- 影片畫幅變化已同步重排提示詞；故事、錨點、聲音和時間碼未漂移。
- 首段在影片引數確認後先建立、回讀並校驗引數，再單獨執行；餘段必須等待首段檢查點。
- 所有畫面保持純二維；沒有正向3D、2.5D、裸眼3D、三維攝影機、視差或真實縱深指令。

## 失敗模式與兜底

| 觸發條件 | 一線處理 | 仍失敗兜底 |
|---|---|---|
| 新PV首次回覆 | 輸出PV雛形並問2—4個問題 | 未完成訪談則停止首輪 |
| 某項無法可靠推導具體方案 | 提供“由導演生成原創方案”“保持概念留白”“自定義” | 不把推測寫成已確認設定 |
| 時長或主體缺失 | 在同一輪補齊 | 仍缺失則停止，不猜測 |
| 畫布不可用 | 請求使用者開啟或繫結目標平台畫布 | 未就緒則不建立節點 |
| 結構化選擇元件不可用 | 停止並說明無法彈出選項 | 不用文字輸入代替確認 |
| 模型列表或schema讀取失敗 | 重讀一次當前Generic配置 | 仍失敗則停止，不展示快取猜測值 |
| `Lib Image` 不存在或不相容單圖任務 | 說明原因並列出相容圖片模型 | 由使用者改選，不偽造該模型 |

- 使用者提供參考圖或影片時，只提煉構圖、色彩、角色平面化、圖層、節奏和轉場方法，不復制專有內容。
