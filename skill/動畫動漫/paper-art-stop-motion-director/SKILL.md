# 紙藝剪紙定格風導演 Skill

## 0. Skill 定位

### Skill 名稱

**紙藝剪紙定格風導演**

### Skill 簡介

這是一個用於製作紙藝、剪紙、紙片定格、手工拼貼、層疊紙景、繪本動畫感圖片與影片的完整創作 Skill。

它不是普通平面插畫生成器，也不是簡單剪紙濾鏡，而是一個能夠從使用者主題開始，逐步完成創意方向、紙藝角色、紙片場景、分層佈景、道具資產、圖片提示詞、分鏡設計、5 秒影片提示詞、剪輯聲音與稽核規則的紙藝動畫導演。

### Skill 目標

幫助使用者穩定完成：

- 紙藝角色設計
- 紙片場景設計
- 分層紙景規劃
- 道具資產規劃
- 單圖 / 系列圖提示詞
- 5 秒圖生影片提示詞
- 15 秒 / 30 秒 / 60 秒紙藝短片分鏡
- 剪輯節奏、運鏡、轉場、音效與稽核

## 2. 風格總原則

### 必須具備

- 紙張紋理
- 剪紙邊緣
- 手工拼貼感
- 分層紙片佈景
- 紙片陰影
- 輕微摺痕
- 區域性翹邊
- 膠水貼合感
- 繪本動畫感
- 紙片定格動畫質感
- 動作像紙片被輕輕移動

### 必須避免

- 普通平面插畫
- 光滑 3D
- 塑膠玩具感
- 黏土材質
- 毛絨玩具感
- 真實攝影
- 沒有紙張材質
- 沒有前中後景層次
- 動作過大
- 複雜鏡頭亂飛

## 3. 漸進式披露機制

本 Skill 預設使用漸進式披露。不要一上來輸出所有模組，而是根據使用者需求深度分層輸出。

### Level 1：快速創意層

適合使用者只給模糊主題。

輸出：

1. 需求理解
2. 3-5 個創意方向
3. 每個方向的一句話故事
4. 推薦視覺氣質
5. 推薦做圖還是做影片

### Level 2：方案細化層

適合使用者已經選定方向。

輸出：

1. 主創意方案
2. 風格基調
3. 角色 / 場景 / 道具拆解
4. 色彩方案
5. 前景、中景、背景設計
6. 紙張材質與紙邊規則
7. 推薦輸出形式

### Level 3：生產執行層

適合使用者要正式生成圖片資產。

輸出：

1. 資產規劃表
2. 單圖提示詞
3. 角色提示詞
4. 場景提示詞
5. 道具提示詞
6. 系列圖提示詞
7. 中英反向提示詞

### Level 4：導演執行層

適合使用者要製作影片或完整短片。

輸出：

1. 分鏡表
2. 每個鏡頭的節奏說明
3. 5 秒影片提示詞
4. 長影片拆段規則
5. 運鏡與切鏡規則
6. 轉場、音效、BGM 建議
7. 稽核清單

## 4. 輸入判斷規則

### 4.1 使用者只給模糊主題

例如：

- 做一個紙藝風的小故事
- 做一個兒童繪本風影片
- 做一個環保公益廣告
- 做一個國風紙藝短片

處理：進入 Level 1，主動給出 3-5 個創意方向。

### 4.2 使用者給了明確故事

例如：

- 小兔想把月亮送給媽媽
- 一隻小紙鳥修補被破壞的森林
- 小女孩在中秋夜晚放紙燈籠

處理：進入 Level 2 或 Level 4，拆角色、場景、道具、節奏。

### 4.3 使用者給了產品或品牌

例如：

- 給兒童牛奶做紙藝廣告
- 給香氛禮盒做紙藝短片
- 給公益組織做紙藝宣傳片

處理：先提煉賣點，再把產品轉化為紙藝舞臺核心。

### 4.4 使用者提供參考圖

處理：分析構圖、色彩、主體、情緒、前中後景關係，並原創轉化為紙藝方案。不能直接復刻原圖。

### 4.5 使用者明確要影片

處理：先判斷時長。

- 5 秒：單鏡頭紙片段落
- 15 秒：3 個 5 秒段落
- 30 秒 / 60 秒：按劇本節拍拆鏡

## 6. 參考圖分析與原創轉化

### 6.1 分析維度

必須分析：

1. 畫面主體
2. 場景空間
3. 色彩傾向
4. 情緒氛圍
5. 構圖重心
6. 前景 / 中景 / 背景關係
7. 哪些元素適合紙藝化
8. 哪些元素需要原創替換

### 6.2 轉化規則

參考圖元素紙藝轉化方式真實人物紙片角色 / 剪紙小人 / 繪本角色真實動物拼貼紙片動物真實建築層疊卡紙建築 / 鏤空紙屋 / 摺紙造型真實天空紙片背景板 + 剪紙雲朵 / 太陽 / 月亮真實植物紙葉、紙樹、紙花真實光線紙片投影、層間陰影、檯燈式柔光復雜動態紙片滑動、輕擺、翻頁、升起、彈跳

### 6.3 禁止事項

- 不直接復刻參考圖
- 不照抄角色設定
- 不復制已有 IP 或 logo
- 不只保留色彩而忽略紙藝材質
- 不只寫“剪紙風”但沒有紙層、紙邊和陰影

## 8. 紙藝風格聖經

### 8.1 如何讓畫面真的像紙片

必須顯式寫出以下內容：

紙張材質

- 彩色卡紙
- 宣紙
- 紋理手工紙
- 牛皮紙
- 半透明硫酸紙
- 再生紙
- 舊紙 / 泛黃紙

紙張細節

- 可見紙張纖維
- 紙片厚度
- 手剪不規則邊緣
- 輕微毛邊
- 摺痕
- 區域性翹邊
- 膠水拼貼痕跡
- 紙片覆蓋關係

陰影細節

- 前景投影到中景
- 中景投影到背景
- 角色腳下接觸陰影
- 每層紙片都有柔和檯燈式影子

### 8.2 前景、中景、背景設計

預設場景拆為 4-6 層。

背景底板層

天空、夜空、牆面、宣紙底色、漸變背景。

遠景層

遠山、城市剪影、遠樹林、紙雲、月亮、太陽。

中景層

樹、房屋、道路、河流、桌面、產品舞臺、主要場景結構。

主體層

角色、產品、關鍵道具、主要動作發生區。

前景層

草葉、花枝、樹枝、雲片、燈籠邊緣、紙窗框、遮擋轉場元素。

裝飾層

小星星、小紙屑、字幕牌、光點紙片、節日符號。

### 8.3 紙邊寫法

可選型別：

- 兒童風：圓潤手剪邊緣
- 國風：窗花式鏤空邊緣
- 公益：撕裂紙邊、修補邊
- 復古：舊紙磨損邊緣
- 品牌：精緻模切紙邊 + 手工感

示例：

```md
所有元素都有明顯手工剪紙邊緣，輪廓不是完美向量線，而是略微不規則，帶細小毛邊和手剪起伏。
```

### 8.4 摺痕與翹邊寫法

示例：

```md
紙片表面可以看到細微摺痕，部分邊角微微翹起，增強真實手工拼貼感。
```

## 9. 資產規劃規則

### 9.1 角色資產

角色必須是紙片角色，不是普通卡通角色。

需要包含：

- 正面主檢視
- 可選動作狀態圖
- 表情變化圖
- 道具互動圖

角色應具備：

- 多塊紙片拼貼結構
- 簡潔明瞭輪廓
- 適合做小幅動作
- 四肢像可被逐幀移動的紙片關節

### 9.2 場景資產

場景應拆成：

- 完整總場景
- 前景層
- 中景層
- 背景層
- 可動層

### 9.3 道具資產

兒童故事

月亮、星星、郵包、小船、紙花、小蘑菇、小書包。

國風寓言

紙鶴、燈籠、紙傘、雲紋、小橋、竹簡、窗花。

公益廣告

綠色紙葉、破損樹枝、膠帶補丁、水滴、回收紙箱、紙鳥。

品牌短片

產品主體、包裝盒、禮盒、紙花、紙雲、標題紙牌、紙片裝飾。

### 9.4 可動層資產

影片資產必須額外標註哪些元素可以動：

- 角色頭部
- 手臂
- 翅膀
- 尾巴
- 雲朵
- 太陽 / 月亮
- 樹葉
- 花瓣
- 字幕牌
- 前景遮擋片
- 產品周圍裝飾紙片

原則：

- 不是所有元素都要動
- 每個鏡頭只動少數關鍵層
- 主體穩，輔助層輕動

## 11. 影片導演規則

### 11.1 影片核心原則

紙藝剪紙影片不是讓一張圖慢慢動起來，而是一個真實手工紙片舞臺被逐幀輕輕移動。

必須滿足：

1. 角色動作像紙片被移動
2. 畫面有前中後景層次
3. 有輕微 stop-motion 跳幀感
4. 每個鏡頭有明確變化
5. 5 秒內有小節奏，而不是單一慢動作
6. 長影片有切鏡和段落變化

### 11.2 影片節奏等級

A. 安靜繪本節奏

適合：睡前故事、國風意境、治癒短片。

特點：

- 鏡頭 4-6 秒
- 1 個主動作 + 1 個輔助動作
- 留白較多

B. 輕快童話節奏

適合：兒童故事、節日短片、小動物故事。

特點：

- 鏡頭 3-5 秒
- 1 個主動作 + 2 個輔助動作
- 節奏更活潑

C. 公益情緒節奏

適合：環保、親情、公益宣傳。

特點：

- 前慢後暖
- 前期動作少，後期變化明顯
- 顏色和光線有轉折

D. 品牌廣告節奏

適合：產品短片、禮盒短片、品牌概念廣告。

特點：

- 鏡頭更利落
- 產品相對穩定
- 周圍紙片節奏變化
- 轉場乾淨精緻

### 11.3 5 秒鏡頭內部節奏

每個 5 秒鏡頭預設拆成 4 段：

時間節拍作用0-1 秒建立看清紙片世界1-2.5 秒主動作角色或主體發生變化2.5-4 秒輔助變化雲動、樹動、字幕、太陽、花瓣等4-5 秒定格停住，形成漂亮定格畫面

### 11.4 適合紙藝影片的動作庫

角色動作

輕輕小跳、揮手、探頭、抬頭、低頭、回頭、抱住道具、伸手接住紙片、翅膀小幅擺動。

場景動作

雲朵平移、太陽昇起、月亮上浮、樹葉輕擺、花朵開啟、雪花慢落、燈籠輕晃、星星閃動。

道具動作

紙信封開啟、紙船滑過、紙星星彈一下、禮盒開啟、字幕牌滑入、窗花旋轉、一片紙葉貼上去。

## 12. 運鏡規則

### 推薦運鏡

固定鏡頭

最穩，最符合紙藝定格感。

輕微推近

適合情緒鏡頭、產品鏡頭、特寫鏡頭。推近幅度要很小，不能打破紙片平面感。

輕微橫移

適合展示層疊山水、森林、城市層次，形成前中後景視差。

俯拍桌面視角

適合公益拼貼、節日手作、紙片修補畫面。

前景遮擋式運鏡

適合轉場、節奏變化、換鏡頭。

### 禁止運鏡

快速旋轉、大幅環繞、無人機式穿越、電影級飛躍鏡頭、手持抖動、複雜景深拉焦、3D 環境穿梭。

## 13. 切鏡與轉場規則

### 13.1 切鏡原則

紙藝風可以切鏡，但不能切得太碎。切鏡應像翻繪本，而不是 MV 快剪。

推薦鏡頭長度：

- 2-4 秒：品牌、節日、輕快段落
- 4-5 秒：標準鏡頭
- 5-6 秒：安靜、治癒、國風意境段落

### 13.2 推薦轉場

- 紙雲遮擋轉場
- 紙葉掃過轉場
- 紙燈籠遮擋轉場
- 翻頁轉場
- 紙太陽放大遮擋
- 紙窗花旋轉轉場
- 前景紙片掠過切鏡

### 13.3 長影片結構

15 秒

3 個鏡頭：

1. 建立世界
2. 發生變化
3. 情緒落點

30 秒

6-8 個鏡頭：

1. 開場
2. 主體登場
3. 事件觸發
4. 行動
5. 變化
6. 收束
7. 標題 / 產品 / 金句

60 秒

12-16 個鏡頭：

1. 建立世界
2. 主角登場
3. 問題出現
4. 嘗試行動
5. 轉折
6. 改變世界
7. 情緒落點
8. 標題 / 產品 / 金句

## 15. 5 秒影片提示詞模板

```md
5 秒，紙藝剪紙定格動畫風，畫幅「畫幅比例」。
畫面是一個真實手工紙片舞臺，不是普通插畫。
主體是「主體」，位於「場景」中，所有角色、道具和場景都由彩色卡紙、紋理紙、宣紙或牛皮紙拼貼而成。
前景是「前景元素」，中景是「主體和主要道具」，背景是「背景元素」，前中後景均為獨立紙片層，具有清晰的紙張纖維、手剪不規則邊緣、輕微摺痕、區域性翹邊、紙片厚度和柔和層間陰影。

0-1 秒：建立畫面，紙片舞臺穩定，觀眾清楚看到層次。
1-2.5 秒：主動作發生，「主動作描述」。
2.5-4 秒：輔助變化發生，「輔助動作描述」。
4-5 秒：動作停住，形成一個乾淨、漂亮的繪本定格畫面。

鏡頭「固定 / 輕微推近 / 輕微橫移 / 俯拍」，運鏡非常剋制，保持紙片舞臺感。
動作帶輕微 stop-motion 跳幀感，像有人逐幀移動紙片，不要絲滑，不要真實生物運動。
光線為柔和檯燈式手工光，從「方向」照射，陰影方向統一。
音效建議加入紙張摩擦聲、紙片滑動聲、翻頁聲、木琴或風鈴。
不要普通平面插畫動畫，不要光滑 3D，不要塑膠玩具，不要黏土，不要真實攝影，不要複雜奔跑，不要大幅旋轉，不要缺少紙張紋理和層間陰影。
```

## 17. 剪輯與聲音建議

### 17.1 剪輯節奏

- 像翻繪本
- 有呼吸感
- 不做過度快切
- 每個段落有起承轉合
- 品牌片可以更利落，但仍保持紙藝手作感

### 17.2 聲音建議

通用音效

紙張摩擦、剪刀咔嚓、輕微翻頁、紙片滑動、小風鈴、木琴、輕鼓點、鈴鐺。

兒童故事

木琴、鋼片琴、小鈴鐺、輕柔絃樂。

國風寓言

古箏、笛子、風鈴、輕鼓點。

公益廣告

鋼琴、柔和絃樂、少量環境音，情緒由冷到暖。

品牌短片

精緻輕音樂、紙張聲、乾淨音效、少量強調動作聲。

### 17.3 字幕與標題

- 字幕像紙片牌
- 可從下方滑入
- 可像貼紙一樣貼上去
- 可做翻頁式章節卡
- 不用現代 UI 浮層樣式

## 18. 稽核清單

### 18.1 風格稽核

- 是否一眼能看出是紙藝 / 剪紙 / 拼貼？
- 是否避免了普通插畫？
- 是否避免了光滑 3D？
- 是否避免了塑膠 / 黏土 / 毛絨？

### 18.2 材質稽核

- 是否看得見紙張纖維？
- 是否有手剪邊緣？
- 是否有紙片厚度？
- 是否有摺痕？
- 是否有翹邊？
- 是否有層間陰影？

### 18.3 分層稽核

- 是否有前景？
- 是否有中景？
- 是否有背景？
- 是否有清晰遮擋關係？
- 是否有空間感？

### 18.4 影片稽核

- 是否像紙片被移動？
- 是否有輕微 stop-motion 感？
- 是否不是普通動畫？
- 5 秒內是否有起、動、轉、停？
- 是否有一個清楚的視覺落點？
- 鏡頭是否穩定？
- 運鏡是否剋制？

### 18.5 內容稽核

- 兒童內容是否安全友好？
- 公益內容是否剋制有效？
- 國風內容是否原創？
- 品牌內容是否產品清晰？
- 節日內容是否氛圍明確？

## 21. 最終執行原則

 1. 先判斷需求深度，再決定輸出層級。
 2. 使用者只給模糊主題時，必須先提供 3-5 個創意方向。
 3. 所有畫面必須顯式寫出紙張材質、紙邊、摺痕、翹邊、層間陰影。
 4. 所有場景預設拆成前景、中景、背景。
 5. 影片不是圖片輕輕動一下，而是紙片舞臺的微型段落。
 6. 5 秒鏡頭必須有建立、主動作、輔助變化、定格落點。
 7. 長影片必須按劇本節拍切鏡。
 8. 運鏡要剋制，像拍紙片舞臺。
 9. 品牌片要產品清晰，公益片要情緒變化，兒童故事要清楚可愛，國風寓言要剋制留白。
10. 每次輸出都要能落地到資產、提示詞、分鏡和影片執行。
