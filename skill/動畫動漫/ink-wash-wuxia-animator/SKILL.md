# ink-wuxia-animation

做写意水墨武侠动漫短片时用本 skill。张大千式泼墨写意山水 + 五行武侠 + 焦墨飞白动态。

> **风格致敬,非精确模仿**:借鉴《雾山五行》式写意水墨武侠美学,**不复刻其角色/具体镜头/版权名称**,创作原创角色与故事。以下"水行使者"等为示例类型,非特定作品角色。 本环境适配:\*\*\* Image 2 → `generate_image_v3`(2K);Seedance 2.0 → `generate_video_v3`(720p、16:9);MiniMax Speech/ElevenLabs → `generate_audio`(配音/旁白/BGM/SFX);`text_editor` → `write_file_v2`;`video_assembler` → `composite_video`;`resource_prepare_and_analyze` → `analyze`;`<<<image_x>>>` → `reference_nodes`+`{{NodeKey}}`。**容错:全程锁定单一视频生成能力(Seedance 等价),报错不降级换模型,直接暂停反馈用户由其决定。** 双语 prompt 模板(图像/五行特效/视频武招/防分屏)与剪辑卡点+五行 EQ 表见 `references/prompt-library.md` 与 `references/editing-and-audio.md`。

## 语系规范

中文交互/中文 UI 时**提示词本体用中文**,但关键艺术术语/风格标签/五行特效标签用**中英双语对照或括号标注**(如 traditional Chinese ink wash painting (水墨写意));对白/旁白配音文本严格遵循 Final_Video_Spec 输出语言。

## 五行色彩体系编码(element character 设定原则)

角色严格按五行色彩编码;各使者\*\*爆发态(Outburst State)\*\*有专属 色彩明暗配比 + 运动物理质感 + 微观光影渲染 三层:

- **火**:约 70% 朱砂红/熔金烈焰 + 30% 粗犷焦墨勾线与重阴影。**运动物理**:烈焰自下高频舔舐、熔金高粘稠流体滚动、滚烫热对流引起宣纸热浪扭曲(heat distortion),边缘干裂飞白+炸裂喷溅墨点。**微观光影**:火焰为强自发光核(self-illuminating core),周身/肢体边缘投超高对比赤红/熔金反光(kinetic glow)+强动态背光,把 30% 焦墨骨架边缘勾出金红锋芒,阴影极速闪烁硬边缘跳动。
- **水(极寒)**:约 60% 深群青/靛蓝泼墨 + 25% 凛冽飞白霜(留白) + 15% 极锋利晶莹散射冷光冰刃。**运动物理**:液固双态转换张力——水流高粘滞重墨泼洒(fluid wash drag)、冰锥瞬间急冻脆断(brittle crystal snapping),水汽在宣纸渐次渗透扩散写意阻尼感。**微观光影**:冰刃半透明(translucent)介质光泽+内部折射(internal refraction),深蓝泼墨背景下外部冷光产锐利镜面折射(specular scatter)+剔透碎光,焦墨轮廓被冰冷侧光(icy rim light)反衬如刀锋晶莹尖锐。
- **木**:约 65% 高饱和石绿/翠绿能量流 + 20% 狂草焦墨藤蔓骨架 + 15% 激射亮金飞叶/金色木屑。**运动物理**:藤蔓狂鞭挥击(whip-like cursive strike)有机弹韧高频鞭打、植物生长高速摩擦张力与纤维撕裂、飞叶划出利落书法劈叉枯笔飞白。**微观光影**:翠绿能量流强叶绿素次表面散射(subsurface scattering)+微光自发光(ambient moss glow),亮金飞叶在暗焦墨背景反射碎金眩光(golden glints),光穿藤蔓形成斑驳光斑(dappled rim light)投侧面轮廓破开深色。
- **土**:约 55% 枯笔飞白焦墨巨石 + 35% 赭石/雄黄泼彩漫天沙尘 + 10% 裂隙迸射大地裂纹光。**运动物理**:巨石极重阻尼翻滚崩落动能(colossal tumbling inertia)+地表开裂重力摩擦(ground shear),飞沙走石粗糙硬质枯笔划痕、尘土炭灰摩擦重阻滞质感。**微观光影**:巨石硬朗阳角浮雕阴影(relief shadow/AO),黄沙尘暴物理遮挡与散射衰减(ray attenuation)成昏暗压抑气氛,大地脉动裂纹高能自发光(glowing earth veins)在岩石底部投熔岩般由下至上炽热金色返照光。
- **金**:约 50% 耀眼亮白锋刃与闪电光轨 + 35% 漫天洒金流金碎屑/金箔 + 15% 泼墨铁骨般深浓焦墨重色压阵。**运动物理**:绝对线性纯几何高速切割动能(linear slicing energy),金属锋刃利落不规则书法枯笔刮擦撕裂痕,洒金碎屑极高频振动摩擦+金属碰撞火花四溅惯性。**微观光影**:亮白锋刃极致刺眼闪电强光+镜面高光(blinding specular glints),漫天激射流金碎屑散射耀眼碎金点光源(glimmering golden sparkles),把 15% 压阵泼墨铁骨边缘照亮产锋利冷光金属边缘反光,冷暖色调极高对比产眩光。

若用户已提供人设或人物三视图,故事板须严格提炼遵循其视觉特征保持高度一致;未提供则系统原创构思(角色五官/发型/代表色彩/中式武侠服饰)。

## 面部微表情与水墨介质情绪外化(微观水墨细节铁律)

- **日常与对峙文戏(情绪微表情)**:眉尖微蹙/眼波流转/下颌线紧绷,匀称精致工笔细线捕捉温润古意。
- **大招碰撞/爆发/受击瞬态(极端情绪)**:紧咬牙齿、咬肌剧烈收缩、额头太阳穴青筋突起(bulging facial veins)、眼瞳缩至针尖或爆发高自发光五行异彩。
- **面部水墨介质融合(汗/泪/血严禁写实)**:以写意水墨介质重塑——眼角/嘴角半干宿墨干枯血泪痕(viscous dry ink-wash trails)、顺骨骼炸裂的飞白枯笔抓痕、极高频喷溅墨点(kinetic ink splatters)、重度阴影焦墨斑块,把情绪爆发与肉体痛苦外化为宣纸浓淡笔墨撕裂。

## 画风与运动张力动态耦合(核心铁律,画风不得一成不变)

按镜头运动速度与动力量感做"笔墨张力"动态缩放:

- **静态/慢速运镜(文戏/意境空镜/极慢推拉平移)**:精细工笔勾边,线条纤细匀称棱角分明,墨色温润清雅,保留宣纸细腻纹理——东方儒雅空灵。
- **极速运镜/强力打击(急推 Whip Zoom/急扫 Whip Pan/拳脚命中/招式爆发瞬态)**:画风瞬间蜕变——极粗犷狂乱焦墨枯笔+飞白排线,线条骤粗、边缘干裂笔锋、大量喷溅黑墨点,极强视觉冲击的手绘原画风骨与动态破坏力。

## 场景 element scene:多角度无人物四宫格(核心铁律)

背景为张大千式大气泼墨写意山水;场景参考图必须为**多角度无人物四宫格(Multi-angle Character-free 4-Grid Scene Reference)**,四格固定分配:Grid1 全景定场(宏观轮廓/地貌/天际线比例) / Grid2 陈设特写(古松/石碑/案几微观水墨质感) / Grid3 纵深透视(前中远景层次+透视引导线) / Grid4 气氛光效(主色调晕染范围与光影对比气氛)。已提供场景图则精准提取地貌/各视角空间层次/色彩倾向细化沉淀;不符规范或未提供则原创设计四宫格方案。

**经典中式陈设水墨设定(微观质感与明暗对比铁律)**:

- **万古劲松**:枝干粗砺带顿挫焦墨枯笔(rough dry-brush)横向扫拂显皴裂鳞皮,松针高频极细工笔排线(fine-line gongbi)聚团高对比刺芒;松枝底部宿墨/焦墨深色压阵,受光面留白或敷极淡矿物浅金,浓淡墨激烈冲撞透钢骨傲意。
- **沧桑孤碑**:碑身不规则碎裂硬角,碑面大面积淡墨湿晕(wet-on-wet)打底再干焦枯笔勾裂隙斑驳刻痕,碑文/青苔用高饱和石青朱砂泼彩点缀成刺眼微观亮点,侧面棱角用强烈写意侧光切出硬朗阳角浮雕阴影。
- **写意竹林**:远景竹林大片湿墨极淡泼墨渐变虚化,近景竹竿爽利饱满中锋干笔(dry calligraphic stroke)拔地而起、竹节焦墨横点顿挫,竹叶快意"个/介"字撇叶法边缘毛锋开裂飞白,微风下半透明水墨透光叠层(translucent layered shadows)缝隙洒驳杂碎光。

## 水墨色彩泼彩比例三档(明暗比例)

- **非战斗/意境空镜(文戏最高美学·三维一体)**:工笔细描 35%–40%(主体/关键道具/近景树石边缘极细工笔勾勒保温润细节)+ 意境留白 35%–40%(大面积纯净宣纸留白,云雾烟雨远水淡墨渐变虚化"虚实相生",严禁背景画满)+ 古典写意泼彩 20%–25%(仅远山/竹林边缘/飞瀑两侧点缀极淡矿物色 石青石绿浅赭石矿物淡金,墨分"焦浓重淡清"五色,光影柔和拒硬边强光)。
- **常规对打/文武过渡**:均衡比例 约 50%–60% 黑白灰基底 + 40%–50% 泼彩;背景山水墨色大块面泼墨,视觉焦点/地貌层次叠染孔雀蓝或石绿泼彩;强明暗对比(一束强光穿焦墨阴云投战场中央,黑白重墨破呼吸感)。
- **高潮决战/五行大冲撞**:色彩主导+重墨压阵 约 30% 焦墨骨架 + 70% 爆裂泼彩叠彩;高饱和朱砂红/亮金/石青大面积泼洒激烈碰撞,但用粗旷力量感焦墨宿墨勾结构线条(**墨骨彩衣**),深墨重色把控重心防色彩过载廉价;明暗极致高反差,光影如闪电撕裂漆黑宣纸。

## 分镜时长动态规划(解决全量 5s 单一时长痛点)

**严禁全量套用 5s 默认时长**;须据动作激烈度/信息量/台词字数动态显式设每 shot duration。**牢记 4s 硬性最低时长限制,单镜严格控制 4s–12s,绝对严禁任何低于 4s 的超短分镜。** 匹配规则:

- **极速打斗/瞬发切招/特写(急推/单发重击/瞬移/闪白瞬间)**:4s–6s(侧重爆发力冲击,短时长保高频紧凑武打力道)。
- **连击/招式交汇死锁角力/大招大对碰**:6s–9s(为复杂动量变化/多段打击/粒子爆散/镜头推拉留充足画面生长时值)。
- **台词对白/蓄势文戏/写意空镜/妖兽吐息大爆轰**:9s–12s(台词单句 ≤10 字按每秒 2–3 字算保唇形对齐时长,文戏/意境山水慢速平移/云雾晕开留呼吸舒展)。

## 场景强绑定与一致性(从源头防跳画)

- **显式指向场景 ID**:每 shot 必须显式声明所属 scene_id(如 `[Element_Scene_01]`),严禁无场景归属或模糊泛指的镜头。
- **连续场景完全复用**:相邻镜头同地点同时值、或属同一打斗/对话回合,则所指 scene ID **必须绝对一致(完全相同 ID)**;下游据该 ID 强制加载复用同一四宫格资产,从源头根除场景跳画/背景前后不一致/突变穿帮。

## 打斗风格分级与五行招式呈现

- **风格分级**:人类角色=武侠写实(刀剑拳脚行云流水、拳拳到肉);妖兽角色=魔幻夸张(肉身突变解构、非线性轨迹、撕裂地貌碎裂破坏力);五行使者=虚实结合(法术与真实武术并重)。
- **五行招式呈现形式**:金(金属锋刃/漫天洒金碎屑/亮白光轨、大开大合无坚不摧)、木(狂草藤蔓缠绕/飞叶如刀/翠绿生机能量流、灵动闪避体术)、水(流体水流/冰锥凝结/水墨晕染、水势与冰刃交替攻守兼备)、火(熊熊烈焰边缘焦墨顿挫、爆裂极速位移打击)、土(崩裂巨石/飞扬沙尘/拔地岩壁、岩石轮廓厚重枯笔飞白)。

**核心招式流派分镜规则 8 类**、**五行相克对决与 5 组克制转场**、**标志性镜头语言(黑白水墨闪/Whip Zoom·Pull·Pan 三急速运镜/连击动能矢量轴线对齐+墨色残影 0.2–0.5s/写意碎落粒子/焦墨烟尘/低角度仰拍/书法大字定格卡 4s)**、**非战斗诗意转场(空镜/墨滴晕染/飞白拖尾/长卷平移呼吸感/陈设特写)** 见 `references/storyboard-rules.md`。

## 对话与音频轨规划

- **对话**:每镜若有角色发言,台词独立写在 dialogue 属性。台词断句用精简有力契合武侠气息的短句(单句 ≤10 字),避免长难句为生成引擎留足音节吐字时长,显式标停顿呼吸口(……/,);台词强绑定说话角色(element character)并指定特写/中景看清唇部开合。
- **配音音色设定与声音凭证**:含台词角色须显式规划配音音色描述(如「坚毅果敢中高音青年男声,带一丝沙哑水墨侠客质感」)作声音特征地基,指导下游生成并绑定 key_element_audio;用户提供样例则优先提取其音色。
- **audio_layer**:BGM(古筝/二胡/笛子古典乐器为主,融电子摇滚+重打击乐,为高潮大冲撞预留节奏重音卡点 downbeats 与听觉留白气口 drop/rests)、环境音效层(风过竹林/细雨拍叶/纸张沙沙/水滴融开,建空灵宣纸空间底噪,文武戏转换动态呼吸强弱)、打击与相克音效层(常规武招:刀剑击鸣/肉体闷击/轻功风掠;五行克制大冲撞:据碰撞类型显式规划双层特征写意打击音效,如 \[金克木\]=利刃切碎藤蔓金属割裂+草木断裂复音、\[水克火\]=怒涛拍击+烈焰碳化高压蒸汽嘶鸣)。

## 流程与自检铁律

1. **规格**(`write_file_v2`:16:9 / 720p / 水墨武侠风格定位 / 配音字幕语言)。
2. **故事板**(`storyboard_designer`:五行角色 key_element + 镜头列表含书法大字定格卡 + 独立音频轨)。⏸ **节点 A**:故事板输出后暂停,引导确认情节与分镜后方可后续。
3. **绑定/分析参考素材**(`analyze`:核对人设图是否标准正/侧/背三视图、场景图是否多角度无人物四宫格、画风是否相符;提取矿物颜料 石青石绿朱砂 配比分布、线条笔触粗细顿挫飞白泼墨比例、动作视频帧级节奏 攻击前摇/出招/碰撞打击点/收招帧级时间跨度;沉淀入 Final_Video_Spec 指导下游)。
4. **图像元素风格化重塑与系统补全**(`generate_image_v3`):角色图**非标准三视图或画风不符**、场景图**非多角度无人物四宫格(或含人物)**——**严禁直接绑定为最终参考**,须 ImageToImage 以原图作空间布局/色彩参考重构为规范三视图或规范四宫格(Grid1 全景定场/Grid2 陈设特写/Grid3 纵深透视/Grid4 气氛光效,2K 无人物);完全缺失则 TextToImage 补全;三视图统一为终极人设规范,后续多姿态生成必引其作核心 reference_image;四宫格提示词强制 `4-grid layout, no characters` 且固定四格内容。**绑定与闭环自检(严防遗漏)**:所有重塑/补全/原图 asset_id 绑至相应 key_element,进下一步前**必须逐一核对**故事板所有 key_element(角色/场景/关键道具)均已生成并绑定、无一遗漏,发现遗漏立即补全/补绑,**严禁资产未完全对齐就启动逐镜视频生成**。
5. **逐镜视频生成与连贯性**(`generate_video_v3`,720p):**逐镜前置一致性自检(铁律)** 生成每镜前须将提示词与故事板深度对齐核对:①人物参考(所有角色已用 `<<<image_x>>>` 或特征描述指代绑定,防遗漏/无关人物);②**场景参考强绑定防跳画铁律**(shot 已显式关联特定 scene ID、该场景四宫格已生成绑定并在提示词用占位符绝对绑定;**绝对严禁**场景参考未绑定/ID 缺失/同地点 asset_id 不一致就启动;自检发现漏绑强制回溯先补四宫格资产再生成);③台词对白 100% 完整封装进语法块(`{dialogue}`)且对应 key_element_audio 作 reference_audio;④动作/五行特效/急速运镜/SFX 与分镜吻合;任何漏项立即修正,严禁带错启动。视觉一致性:每镜必输入对应 element character 图+element scene 图作 reference_image;相邻镜头动作/场景极高连贯需求可将前一镜视频作 reference_video。声音口型:含台词镜头绑对应角色 key_element_audio 作 reference_audio 保跨镜口型音色一致。**时值**:严格读取继承 shot duration,严格 4s–12s,严禁低于 4s 或全量套 5s,动作切换明显时主动切镜。
6. **声音与配乐**(`generate_audio`):角色对白配音(MiniMax Speech 2.8 HD 等,注册/绑定为 key_element_audio 保跨镜音色)+ 说书人宿命感老者旁白 VO;传统中国风 BGM + 高频刀剑打击/招式爆发 SFX。有用户样例则提取音色克隆。
7. **时间线剪辑合成**(`composite_video`):严格按武打卡点与"黑白水墨闪"时值快速剪辑与音画对齐。详见 `references/editing-and-audio.md`。

**执行控制暂停节点**:**资产生成前置确认(核心铁律)**——生成任何新资产(元素图/逐镜视频/音频)前**必须暂停**告知用户生成计划(含提示词或参考关系),获确认许可后方可调工具;**节点 B(资产核对确认)**——每批次/重要资产生成或重塑完成后向用户展示,所有图像元素资产生成完毕后**全局自检核对绑定状态**、向用户展示完整角色与场景绑定关系,获确认满意后方可推进。
