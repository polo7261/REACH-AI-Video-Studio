# 新海誠劇場版動畫 影片流水線

> 🔴 **請嚴格按照該 SKILL 分步執行。** 版本：2.0.8

## 底層 DNA（無條件，每條畫面都帶）
1. 🔴 **光是主角（新海誠簽名，最重要）**：每一幀都被光雕刻——強烈的逆光與半逆光、太陽的鏡頭光斑（lens flare）、光的開花（bloom）、玻璃與水面與金屬的高光反射、空氣中漂浮的發光塵埃粒子。光源方向明確且戲劇化，人物髮絲與輪廓被光勾出金邊，**主動追求逆光開花與炫光簽名感**。但光是"美到心顫的光"而非"過曝的廢片"——高光可開花、主體資訊仍可讀。
2. 🔴 **寫實級精細動畫背景 + 天空佔比巨大**：新海誠的背景是"比現實更美的現實"——劇場版動畫的手繪精細背景，一磚一瓦一根電線都刻畫入微，透視精準、細節密度極高。天空是永遠的主角：巨大的積雨雲、藍到發紫的天頂、magic hour 的橙紫漸變、星空與銀河、飛機雲與彗星。構圖常給天空一半以上畫幅，人物渺小地立於天地之間。
3. **深遠景深、天地可讀**：常用廣角大遠景把人放進巨大的天空與城市之間，縱深拉到地平線；近景時背景依然精細可辨（動畫背景不虛化成光斑，最多輕微空氣透視）。人物與天地的尺度對比本身就是敘事。
4. 🔴 **情緒核心：外放而詩意的青春情感（新海誠靈魂，務必拉住）**：這是新海誠最核心的氣質——少年少女之間橫亙著距離、時間、命運的思念與追尋。情感**是外放的、洶湧的、抒情的**：奔跑、呼喊、仰望天空、在人海中尋找一個人。底下流動的是相遇與錯過、距離與羈絆、平行時空般無法觸及的彼此、以及"世界如此美麗而我在想你"。⚠️ 絕不能做成剋制疏離的冷淡日常、也絕不能做成廉價狗血偶像劇——差別全在"用整個天空和光來盛放情感"：情緒大，但被極致的美學與詩意托住,壯闊而不尷尬。
5. **讓世界與情緒共振**：雲在延時般流動、雨滴砸開水花、電車駛過鐵道口、彗星劃破夜空、光隨情緒明滅。天氣與天象是情緒的放大器，世界隨人物內心一同呼吸。

## 質感尾詞（🔴 完整版僅模卡與道具合圖預設帶；moodboard 不掛——風格由 sref 種子錨定；場景圖只掛流程第 3 步的輕量風格穩定尾詞、不掛本完整版）
`新海誠劇場版動畫質感，寫實級精細手繪背景細節密度極高，人物乾淨賽璐璐動畫風格描線清晰、眼睛大而清澈有高光與天空倒影，強烈逆光與輪廓光、lens flare 鏡頭光斑、bloom 光暈開花、空氣中發光塵埃，天空佔比大（積雨雲/magic hour 漸變/星空），色彩高飽和濃鬱通透（藍青為底、橙紫金作情緒高光），高對比、陰影透藍紫不死黑，深遠景深、背景與地平線精細可辨；不要真人實拍、不要3D渲染塑膠感、不要寫實照片質感、不要灰暗低飽和、不要平光無光影、不要背景虛化成光斑、不要粗糙低幀網頁動畫`

## 流程
0. **入口**：🔴 **所有向使用者的詢問與確認一律以選擇卡/按鈕形式呈現，不用純文字提問**（執行 agent 優先呼叫其選擇卡元件；開放輸入項配一張"我來填/交給你"二選卡，選前者再展開輸入框）。一次問清 ① 時長（選擇卡：給幾檔常用時長如 15秒 / 30秒 / 60秒 / 自定義→展開輸入）② 執行模式（選擇卡：全自動/手動確認）③ 影片畫幅解析度（選擇卡：4:3 / 16:9預設 / 21:9 / 自定義）④ 對白語言（選擇卡：中文/英文/日文/其他→展開輸入）⑤ 🔴 **人聲模式**（選擇卡：純氛圍〔無對話無旁白〕/ 純對話 / 純旁白 / 對話+旁白穿插）——作為劇本與全片硬約束 ⑥ **想講什麼故事**（選擇卡：我來講〔選後展開輸入框〕/ 交給你自擬〔跳過、後續 agent 自擬不再追問〕）。寫入 memory。
1. **風格確認**：不向使用者徵集元素、也不就 moodboard 向使用者確認——moodboard 的天氣/舞臺/情感基調由 agent 依據入口第⑥問的故事輸入提煉（使用者跳過了則自擬一版），直接生成並預設作為全片風格錨，進入場景圖生成。🔴 **moodboard 生成鐵律（與其他影象資產不同，單獨走這套）**：
   - **模型強制 Midjourney v7**（不走 libimage），MJ 語法出 prompt。
   - 🔴 **prompt 全英文輸出**（MJ 對英文響應最佳）：moodboard 的 prompt 正文與所有描述詞一律用英文寫，僅此 moodboard 一處；場景圖/模卡/道具/影片 prompt 的語言不受此條影響、維持原樣。
   - **正文只寫內容、不寫風格**：只描述場景內容、構圖、畫面元素與氛圍主體（可含"雲/彗星"等作為畫面元素的客觀存在），**刪除一切影調與色調類風格描述**——配色、飽和度、色溫、對比度、明暗風格、陰影顏色、渲染質感詞一律不寫，也**不掛質感尾詞**。風格全部交由風格種子統一錨定。
   - 🔴 **尾部強制拼接固定尾綴**：`--niji 7 --sref 3581618356 --sv 4`（寫法照抄、引數不可改動、不可省略）。畫幅引數（--ar）按所選畫幅自行表達，不寫死進尾綴。
   - 🔴 **MJ prompt 模板（照填，禁改結構與尾部種子，只換 [] 佔位）**：
```
[weather & sky], [scene content & environmental objects, developed per the film's story direction], [figure or silhouette position & scale within frame (may have no figure)], [composition: viewing angle, depth of field, sky-or-subject share of frame, foreground/mid/background relationship], [lighting mood: light-source direction, backlight / lens flare / bloom, the shape of light in the air], single unified image bleeding to full frame, no borders no collage no panels [--ar per chosen aspect ratio, e.g. --ar 16:9] --niji 7 --sref 3581618356 --sv 4
```
   - 版式要求不變：單一融合畫面鋪滿出血、禁白邊/拼貼/分格（寫進正文）。
   - 出 prompt 後自查：尾部種子在否？正文是否混入色調/影調/質感詞（混入則刪）？
   → 存為風格錨資產、記下歸檔標記。
2. **故事**：按入口第⑥問的答案走——使用者有故事輸入則遵循、僅疊加新海誠風格化；使用者跳過了則不追問、agent 直接從母題中自選生成（相遇與錯過/距離與思念/時空與命運/追尋與奔跑/世界之美與個人之小），與 moodboard 的天氣/舞臺/情感基調保持一致。🔴 故事定稿後按「劇本製作」章節產出劇本（含人聲內容與角色表演基調錶），劇本是後續分鏡與影片 prompt 的唯一敘事依據。
3. **資產**：有戲角色必產白底棚拍模卡定妝圖（鎖臉/服裝/髮型），後續鏡頭一律 @角色名 引用。場景圖單張空鏡、絕不分屏。🔴 **場景圖生成鐵律（配合 moodboard 新錨定邏輯）**：
   - **模型用 libimage**（不變）。
   - 🎨 **每張場景圖強制掛 moodboard 風格錨作參考**（僅錨色調/光感/質感、不錨構圖，統一全片色調）——moodboard 已由 sref 種子錨死風格，場景圖的風格**全部經此參考圖傳遞**。
   - **正文四類描述為主 + 輕量風格穩定詞**：色調/配色/飽和度/影調/對比度/陰影顏色等**色彩影調類**風格詞仍不寫（交由 moodboard 錨統一），但每張場景圖 prompt 尾部固定掛一句**輕量風格穩定尾詞**（防單靠參考圖掛不住畫風漂移）：`新海誠劇場版動畫風格，精細手繪背景質感，乾淨的動畫描線`；負面(獨立框)固定帶：`真人實拍、寫實照片質感、3D渲染塑膠感`。僅此，不再加更多風格詞。
   - **正文保留四類描述**：①天氣與天象（晴/雨/雪/雲/黃昏/星空）②場景內容（空間、物件、環境細節）③構圖（視角、景深、畫幅佔比、前中遠景關係）④光線氛圍（光源方向、逆光/lens flare/bloom、光在空氣中的形態、明暗關係的客觀描述）。
   - 出 prompt 後自查：是否掛了 moodboard？輕量風格尾詞與負面在否？色彩影調類風格詞是否混入（混入則刪）？四類描述齊否？
   具名道具彙總一張白底道具合圖。
4. **生成影片**：場景圖+角色圖（+含具名道具時掛道具合圖）作參考鎖一致性，分鏡寫進 prompt 時間軸。🔴 **影片生成不掛 moodboard 風格錨**（moodboard 只用於場景圖生成階段，影片參考只有場景圖/人物圖/道具圖）。
5. **音樂**：等影片人物全定稿後再確認方向、再生成（預設 mureka）。🔴 **生成後先不合成進影片**——因當前 agent 工具在含音樂的影片上加字幕會出問題，音樂須暫存、等第 7 步字幕加完後再詢問使用者是否合成。
6. **合成**：跨 15 秒才拆多條、序列後用影片合成能力拼接。
7. **後期剪輯**（合成後或使用者指定時，工具：agent.tool.edit_video；使用者未提及則不擅自呼叫）：
   - **字幕** add_subtitle：白字黑色描邊；語言跟對白語言，使用者指定則翻譯後加。人聲模式為純氛圍時全片無臺詞無旁白、跳過字幕環節不詢問。
   - **轉場** transition：使用者提及但未指定方式→預設直接硬切（新海誠剪輯以硬切與匹配剪輯為主）；可選硬切/淡入淡出/黑場；AI轉場不在此列。⚠️禁溶解疊化只約束影片生成階段，合成後可正常加轉場。
   - **抽幀** extract_frames：agent 自動呼叫輔助判斷轉場；使用者也可主動要求。
   - **裁剪** clip：秒級精度，使用者描述需裁剪內容後執行。
   - **文字貼片** text_overlay：片名/章節 title card、cast 名單、人名條；使用者可自定義文字內容與樣式。
8. **音樂合成（字幕之後）**：🔴 字幕全部加完後，以選擇卡詢問使用者是否把第 5 步已生成的音樂合成進影片（選擇卡：合成/暫不）。使用者確認後再執行音樂合成，收尾出片。⚠️ 順序不可顛倒——必須"先字幕、後音樂"，因當前工具在有音樂的影片上加字幕會出問題。

## 劇本製作（故事定稿後、資產生成前執行）
- 🔴 **人聲模式是硬約束（入口第⑤問選定，全劇本全片遵守）**：
  - **純氛圍**：不寫任何臺詞與旁白，情緒全靠畫面表演、光線與環境音承載；劇本只寫動作、表情、視線與環境事件。
  - **純對話**：該交流處**必須寫出實際對白**，不得以"兩人交談"之類動作描述帶過。
  - **純旁白**：**必須寫出實際旁白文字**；旁白是畫外音、畫面中人物不開口型（防影片模型給無聲口型配錯語種）。
  - **對話+旁白穿插**：兩者並存，逐段標明是對白還是旁白。
- 🔴 **對白落地鐵律（禁默片化）**：模式含對話/旁白時，劇本必須真寫臺詞與旁白全文——對白標註說話人（@角色名："臺詞"），旁白標註（旁白："文字"）。只有動作描述、沒有實際文字的劇本視為不合格、重寫。
- **對白調性（本 skill 美學）**：短句、生活化、留白多——詩意藏在平常話裡，情感濃度靠情境與光線托住而非臺詞直給；重要的話往往說一半、或用天氣與景物代說。禁說教腔、禁狗血直白告白體、禁長篇大論。
- **旁白調性（本 skill 美學）**：第一人稱內心獨白式抒情（"世界如此美麗而我在想你"的聲部），與畫面互補而非複述畫面——畫面給世界之大、旁白給內心之近。句子短、有呼吸感留白。
- 🔴 **角色表演基調錶（每個有戲角色必產）**：為每個有戲角色定 2-3 個**性格化的標誌性小動作/習慣姿態**（由該角色性格決定，如：緊張時攥住衣角、思考時望向窗外、開心時腳跟離地半拍），隨劇本歸檔。**全片跨鏡一致**：影片 prompt 每鏡的 @角色動作優先從基調錶取用；標誌性動作優先用作動作銜接切點素材（習慣動作起→下一鏡承接）。
- **劇本格式**：分場編號 + 場景/時間 + 在場角色 + 場內容（動作與事件）+ 人聲內容（按模式寫對白/旁白全文）。每場落點對應一個可拍的生活/情緒片段，供分鏡時間軸直接取用。

## 畫幅與畫質（寫死）
可選比例統一為 4:3 / 16:9 / 21:9 三種，使用者也可自定義輸入並保留其選擇。預設全部首推 16:9：moodboard 16:9；場景圖 16:9；人物模卡 16:9；影片預設 16:9（可改）。影象預設 libimage 模型、2K 解析度、標準畫質（使用者可改）；🔴 **moodboard 例外：強制 Midjourney v7**（見流程第 1 步，畫幅經 --ar 引數列達）。影片預設 720p 解析度（使用者可改）。

## 影象 prompt 語言
主體中文；技術詞（lens flare/god rays/bloom/cel shading）必要時留英文。負面詞與正文物理分離、放獨立負面欄位。

## 人物鐵律
- **鎖質感、放身份**：新海誠劇場版賽璐璐動畫質感是硬約束；髮色/髮型/服裝/身份氣質尊重使用者設定、不做新海誠化糾偏。
- **表演基調跨鏡一致**：每個有戲角色在劇本階段定 2-3 個性格化標誌性小動作/習慣姿態（見「劇本製作」章節），全片跨鏡一致；模卡只鎖外形、表演基調由劇本管、影片 prompt 取用。
- **臉是乾淨通透的動畫臉**：賽璐璐柔和明暗、描線乾淨、膚色透亮偏暖粉；**眼睛是靈魂**——大而清澈、瞳孔層次豐富、必帶高光點與環境光倒影（天空/夕陽的顏色映在眼裡）。絕不做成真人寫實臉、3D 渲染臉、厚塗油畫臉。
- **模卡 ≠ 出片**：模卡用純白底 + 明亮均勻正面光（臉充分照亮、面部細節優先），**模卡階段絕不用逆光/剪影/炫光**——逆光開花是出片簽名、不是定妝需求，模卡要的是把臉看清楚鎖死。版式 16:9：左三檢視（正/側/背）+ 右大面部特寫（必出、不可省、不可畫成全身）。
- 🔴 **模卡模板（照填，禁改結構與質感尾詞，只換 [] 佔位；若版式散架/檢視不全退回英文版）**：


## 場景卡（按場景取用；風格已由 sref→moodboard 錨死，卡只供取材要素——天氣/場景/構圖/光線四類，落 prompt 時組合即可）
- ☁️ **天空/雲海**：積雨雲堆疊如山/星空銀河/彗星飛機雲；逆光雲緣金邊；廣角、天空佔畫幅一半以上、人物渺小於地平線。使用者一提天空/雲/彗星/星空無條件套此卡。
- 🌆 **Magic hour 黃昏（招牌）**：日落前後、雲被夕陽點燃；暖金逆光、lens flare、長影拖地、玻璃反射夕陽；人物浸在逆光裡、輪廓金邊全開。
- 🏙️ **都市/電車/鐵道口**：電線杆與電線、電車車窗流光、鐵道口紅燈、便利店與販賣機燈光；背景細節密度拉滿；人物穿行或等待於大場景中。
- 🌧️ **雨/雨後**：雨滴可見、水窪漣漪、傘與玻璃掛水；路面反光、車燈拉絲；雨後雲破光出、溼街滿是反光。
- 🏫 **校園/日常抒情**：教室窗邊、走廊天台、櫻花或夏日綠；窗光斜切、灰塵在窗光裡漂浮、窗簾被風掀起。
- 🌌 **夜/星空**：星空銀河與城市燈火對望；月光、流星、燈火 bloom；人物於天台/山坡/橋上仰望、深遠景深。

## 運鏡（每鏡配一種，與情緒咬合，預設動感衝擊）
快速衝刺跟拍（貼身追奔跑）/ 急推急拉（推向眼睛或拉出天地）/ 環繞人物旋轉 / 低空俯衝穿越場景（FPV 式掠過街道/雲層/鐵軌）/ 甩鏡 whip pan 銜接動作 / 大幅快速橫搖掃過天空與城市 / 升降機大幅升起展現天地尺度 / 鏡頭隨衝擊輕微震動（落地/撞開門/列車掠過）。⚙️ 動感運鏡全段可用、不限高潮段；緩慢推近與固定大遠景保留為凝望時刻的點綴（一條 15 秒內至多 1-2 鏡），其餘鏡頭必須動起來。新海誠的鏡頭是"和世界一起奔跑的抒情詩"，寧湧勿靜。

## 剪輯節奏（抒情起伏、切點走動作銜接）
- 🔴 **鏡數目標：15 秒目標 5-6 個分鏡**（單鏡約 2-3 秒），情緒起伏靠鏡內運鏡與動作密度體現、而非拉長單鏡——凝望段用長一點的鏡（3 秒檔）、高潮段用短鏡（2 秒檔），但總鏡數守住 5-6。
- 🔴 **切點邏輯：動作銜接（match cut）**：每個硬切點必須咬合前後鏡頭的動作——上一鏡動作到達頂點或轉折處切出，下一鏡從該動作的延續或呼應動作起頭（如：仰頭看天的視線方向→切天空俯瞰；手伸向門把→切門被推開；奔跑腳踏地→切遠景人飛奔）。**切點由動作決定，不是時間到了就切**。
- 空鏡是正文不是過場：天空、雲、電車、街角的空鏡承擔情緒，可獨立成鏡、與人物鏡頭以動作/視線銜接交切。
- 景別可大幅跳躍：大遠景（人渺小於天地）直切眼睛特寫是新海誠常用語法，不受"跳一檔"限制，但跳躍須由動作銜接驅動、不亂跳。
- 每鏡內動作完整發生、切在動作節點上，不無意義碎切。

## 音樂（預設 mureka；可含人聲主題曲段）
- 氣質：抒情、洶湧、有明確的情緒推進與高潮釋放——音樂與畫面互為引擎（RADWIMPS 式影樂一體），在高潮處音樂可以衝到情感最前面。
- 🎹 **第一支·鋼琴抒情主線**（鋼琴主導+絃樂推進）三子支：
  - A·日常與心動：明亮輕快的鋼琴動機、絃樂輕託，青春的透明感。用於校園/日常/相遇。
  - B·思念與距離：鋼琴慢板、旋律綿長帶憾意、絃樂漸入，留白後再起。用於分隔兩地/凝望天空/回憶。
  - C·奔跑與追尋（高潮）：鋼琴+絃樂+節奏組層層推進、情緒逐步拉滿至爆發，配快剪蒙太奇。用於奔跑/尋找/時空交錯/告白。
- 🌠 **第二支·壯闊天象**：絃樂與合成器鋪底的宏大織體、帶神聖感與命運感,緩慢推進至恢弘。用於彗星/星空/超自然天象/世界級景觀。
- 🎤 **第三支·主題曲人聲段（唯一允許人聲）**：流行搖滾編曲+人聲旋律，用於全片情緒最高點或片尾——僅在使用者確認後啟用（以選擇卡詢問：啟用/不啟用），預設前兩支純器樂。⚠️ 配樂人聲屬音樂層，與劇本"人聲模式"互不約束——純氛圍模式的片子也可用主題曲人聲段。
- **選支**：校園日常相遇→A；思念凝望回憶→B；奔跑追尋高潮→C；天象奇觀→第二支；全片最高點/片尾→詢問使用者是否上第三支。同一片多支並存隨段落切換、須有"起-承-爆-落"的整體情緒曲線。
- 禁平淡氛圍底噪式配樂貫穿全片、禁全程無起伏。新海誠的音樂必須"推著情緒走",高潮必須給到。

## 生成後自查（不達標則重做）
劇本：人聲模式遵守否（純氛圍無臺詞旁白/含對話旁白處有實際文字、非默片化）？對白標註說話人否？每個有戲角色的表演基調錶產出否？
moodboard：prompt 尾部固定尾綴（--niji 7 --sref 3581618356 --sv 4）在否？正文是否混入色調/影調/質感風格詞（須刪淨）？模型是否為 Midjourney v7？
場景圖：是否掛了 moodboard 風格錨？輕量風格尾詞與負面在否？正文是否只含天氣/場景/構圖/光線氛圍四類、色彩影調類風格詞刪淨否？模型是否為 libimage？
其餘影象與影片：光是否是主角——逆光/lens flare/bloom 至少佔其一（須有）？是否做成了真人實拍或3D塑膠感（禁，須劇場版動畫）？背景是否達到寫實級精細密度、天空佔比夠否？影片 prompt 的音訊鎖宣告與 BGM 負面詞兩處齊否（缺一即重寫）？

## 影片鐵律
- 🔴 **單條多分鏡（預設強制）**：seedance 單次最長 15 秒、原生支援單條內多分鏡+鏡間硬切，**不走"一鏡一條+後期拼接"**。🔴 **鏡數目標：15 秒 5-6 鏡、單鏡約 2-3 秒**（凝望段可到 3 秒檔、高潮段 2 秒檔，總鏡數守住 5-6）；不足 15 秒的短條按同密度折算（8 秒約 3 鏡/10-12 秒約 4-5 鏡）。**只有跨 15 秒才拆多條、序列後用影片合成能力拼接**。prompt 按秒推進、每鏡=景別+@角色動作+運鏡+環境+**與下一鏡的動作銜接切點**，鏡間硬切顯式斷開。
- 🔴 **絕對禁止生成背景音樂（鐵律，無例外）**：影片生成階段音訊**只允許環境音+對白**，任何形式的背景音樂、配樂、旋律、哼唱、鼓點節拍一律禁止——即使鏡頭情緒強烈、即使畫面出現樂器或耳機、即使模型傾向自動配樂，也絕不允許。BGM 只在第 8 步合成階段疊加。新海誠的環境音（雨聲/電車駛過/蟬鳴/風/城市底噪/鐵道口警示音）極重要，每條影片 prompt **常駐宣告（不管本條有無對白都寫、一字不省）**："音訊只保留豐富真實的環境音與對白，絕對無背景音樂、無配樂、無旋律、無哼唱、無節拍鼓點"；負面**常駐**："背景音樂、配樂、BGM、旋律、哼唱、節拍鼓點、music、background music、score、soundtrack、melody、humming"。出 prompt 後自查：宣告與負面兩處都在否（缺一即重寫）。
- 🔴 **語言鎖+人聲模式鎖**：每條影片 prompt 常駐宣告"人物對白/旁白一律 [選定語言]，模型自主補話也只用此語言，禁其他語種臺詞/字幕/口型"（不管本鏡有無對白都寫）；負面加"其他語種臺詞、混合語言口型"。防無對白鏡頭被模型自主加話時蹦錯語種。同時按人聲模式追加：純氛圍→常駐宣告"全片無對白無旁白、人物不說話不開口型"、負面加"對白、旁白、說話口型"；純旁白→常駐宣告"人物不開口型"（旁白為畫外音、合成階段處理）；純對話/穿插→對白臺詞按劇本寫進對應分鏡。
- **人物一致性靠參考圖 + 動作要有爆發力**：人物質感與風格由掛載的角色圖/場景圖參考傳遞，prompt 正文不寫風格詞；正文約束動作與穩定性——**動作幅度拉滿**：全速奔跑衝刺、跳躍跨越、急停急轉身、攀爬翻越、俯身衝出門框，髮絲與衣襬大幅甩動飄揚、腳步帶起水花或落葉塵土，靜態鏡頭裡人物也要有明確的動作進行時（轉頭/伸手/起身），面部不崩壞。負面常駐：真人化、3D化、線條崩壞、五官畸變、僵硬擺拍、原地不動呆立。
- **禁溶解疊化**：鏡間硬切，負面常駐 no dissolve/cross-fade/fade。
- **光影必須在場**：影片裡每鏡都要有明確光源與光效（逆光/反光/燈火），絕不平光。快速運鏡與光影快速變化（光斑掃過臉、明暗穿越、車窗流光拉絲）全段可用、鼓勵使用。負面常駐：平光無光影、真人實拍質感。
