 2. 統一生成「無字版」，所有標題與中文小字後期 PS 新增；Flux 若必須內建文字，僅生成大號英文標題。
 3. 矩陣小圖出現五官崩壞，可提高 CFG 至 8.5 或增加 3-5 步取樣。
 4. 修改髮色直接改寫 base_style 中「黑色凌亂層次短髮」描述。
 5. 佈局以 canvas_layout 為準，positive_prompt 不再複述佈局細節。
 6. 若仍然出現人臉漂移：優先採用拆分生成方案（主視覺→三視圖→表情矩陣分開生成，PS 拼合），一致性最高。
 7. SDXL 使用 params_sdxl，Flux 使用 params_flux，兩組參數請勿混用。
 8. 右側上方名稱區必須保持與背景同色留白，模型若在此處生成文字、人物、邊框、底塊、色差，請在 negative_prompt 中強化「右側名稱區生成文字，右側名稱區生成人物，右側名稱區生成頭像，右側名稱區出現邊框，右側名稱區出現底塊，右側名稱區出現色差」。
 9. Q 版人物若出現風格漂移（如變成純卡通、比例崩壞），可在 positive_prompt 中強化“3D 半寫實國漫 CG 的 Q 版化，大頭小身，保留真人版髮型與服裝配色”，並在 negative_prompt 中強化“卡通平塗，Q 版比例崩壞，Q 版與主人物不一致”。
10. 若 Q 版人物始終無法與主人物統一，建議拆分生成：先按原 YAML 生成“無 Q 版”的完整設定稿，再單獨生成 Q 版男主小頭像（IP-Adapter FaceID 權重 0.6\~0.7），最後 PS 拼合到主視覺右側下方。
11. 暖光白背景若偏黃，可在 negative_prompt 中加入「過黃，土黃，橙黃，色溫過高」；若偏冷，可加入「偏藍，冷灰，色溫過低」；若光影過強，可加入「強烈暖光，強烈冷光，硬光」。
12. 表情矩陣若出現崩壞，優先採用拆分生成方案：先單獨生成主視覺確定臉，再單獨生成表情矩陣（IP-Adapter FaceID 權重 0.85\~0.9），最後 PS 拼合。
13. 表情矩陣的表情建議選擇微表情，如“冷靜審視、輕微疏離、剋制失神、淡淡淺笑”，避免“大笑、皺眉、驚訝”等大幅表情導致五官變形。
14. 表情矩陣若仍然四人臉不一致，可在 negative_prompt 中繼續強化「表情矩陣四個人臉不一致，表情矩陣像四個人，表情矩陣人物身份漂移」。
15. 需要白底三視圖時，使用 positive_prompt\_白底三視圖版 與 negative_prompt\_白底三視圖版，單獨生成，不要與完整設定稿版混用。
16. 白底三視圖版建議使用 IP-Adapter FaceID 權重 0.8\~0.9，確保三視圖與主視覺為同一張臉。
17. 白底三視圖版生成後，可直接摳圖用於排版、建模參考、服裝設計參考，也可與完整設定稿版拼合使用。
18. 真人感強化若仍偏塑膠，可在 positive_prompt 中繼續強化「真實皮膚紋理，細膩毛孔，自然微瑕疵，次表面散射，真實光影層次」，並在 negative_prompt 中強化「塑膠皮膚，矽膠皮膚，假面感，過度磨皮，蠟像臉」。
19. 真人感強化若偏寫實照片過度、失去國漫CG感，可適當降低「電影級真實人像」權重，保留「3D半寫實國漫CG」基礎風格。
20. Flux 模型對真人感支援更好，建議優先使用 flux.1-dev；SDXL 建議搭配真實系 Checkpoint（如 Realistic Vision、Juggernaut XL）使用。
21. 若參考圖中的服裝、道具帶有文字、Logo、品牌名，建議先用 PS 抹除，或降低參考圖權重，並在 negative_prompt 中強化「服裝上的文字，道具上的文字，品牌名，Logo，標語，亂碼文字」。
22. 服裝、道具若仍出現文字，可在 positive_prompt 中繼續強化「服裝無文字，無Logo，無標語，無品牌名，無印花文字，道具無文字，無Logo，無品牌名」。
23. 若必須保留某些文字（如角色名），請後期 PS 新增，不要依賴模型生成。
24. 右側上方名稱區必須與背景完全同色，無邊框、無底塊、無色差、無陰影、無漸變；若模型仍畫出邊界，請在 negative_prompt 中強化「右側名稱區出現邊框，右側名稱區出現底塊，右側名稱區出現色差，右側名稱區出現陰影，右側名稱區出現漸變，右側名稱區出現分割線，右側名稱區出現色塊，右側名稱區出現圖案，右側名稱區出現紋理」。
25. 若產出偏真人照片、失去國漫CG感，請在 negative_prompt 中強化「純真人照片，過度寫實，歐美CG，真人攝影，照片感過強，CG感過弱，國漫CG感缺失，半寫實感缺失」。
26. 若產出偏日系二次元或韓系厚塗，請在 negative_prompt 中強化「日系二次元，韓系厚塗，純2D，純3D寫實」。
27. 若想進一步強化國漫CG質感，可在 positive_prompt 中繼續強化「3D半寫實國漫CG，國漫CG質感，半寫實風格，保留國漫CG特有的光影、材質與皮膚質感」。
28. 若模型不支援 13:19，請直接使用預設的 2:3（832×1248）；若模型支援 13:19，可手動改為 832×1216，視覺比例更接近原設定。
29. 【v3.9.7 新增】後期 PS 加字請統一使用 **PingFang‑SC 蘋方（中文）+ Montserrat / Inter（英文）**，英文標籤推薦 **FRONT VIEW / EXPRESSIONS / CLOSE‑UP**；排版保持工整清晰，無多餘裝飾。
30. 【v3.9.7 新增】附件男主庫已擴展至 10 人：徐知珩、李瑞、韓敘源、姜碩、宋聿青、謝聞弦、陸然、裴川、沈硯清、顧淮，可直接替換【人物氣質】【服裝穿搭】【主視覺姿態】【表情1-4】【配色1-6】【細節1-5】【道具1-5】；**canvas_layout 嚴格按附件執行，排版不做任何更改。**
