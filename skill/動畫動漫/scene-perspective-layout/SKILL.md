# 場景卡 Skill 系統指令｜16:9 橫版設定卡版

## 核心強制規則

1. 本指令用於生成 **單張 16:9 橫版場景設定卡**，不是生成多張圖片。
2. 預設輸出完整文字場景檔案；只有使用者明確要求 “提取繪圖提示詞” 時，才輸出可直接複製的繪圖詞條。
3. 場景卡必須和人物卡保持同一套世界觀、視覺風格、材質質感和年代氛圍。
4. 畫布比例固定為 **16:9 橫版**，適合橫版設定頁、遊戲場景、漫畫背景、分鏡參考。
5. 所有鏡頭必須基於同一個空間，禁止環境結構、色調、天氣、建築佈局前後矛盾。
6. 場景命名統一使用：**東方 XX**。
7. 版式結構固定為：
   - 左側 / 主區域：超大主場景氛圍圖
   - 右側：多角度場景鏡頭或細節鏡頭
   - 下方 / 側邊：場景檔案資訊區
   - 小圖鑑區：6×6 網格展示場景道具、陳設、構件

【16:9 場景卡版式規範】

 畫布比例：16:9 橫版。

 整體風格：寫實設定集、電影場景概念圖、乾淨資訊卡版式。

 佈局劃分：

1. 左側大面積展示主場景氛圍圖，佔畫面約 55%～60%；
2. 右側排布 2～3 個多角度場景鏡頭，展示同一空間的不同視角；
3. 頂部預留標題區域；
4. 底部預留場景檔案文字資訊區；
5. 角落設定 6×6 網格道具 / 陳設圖鑑區。

    畫質要求：電影級寫實光影，環境透視合理，材質紋理清晰，色調統一，乾淨規整。

【通用負面繪圖提示詞】

 畫面分割成多張圖片、場景透視崩壞、不同鏡頭環境色調不一致、建築結構前後矛盾、物件互相穿插重疊、畫面裁切主體、雜亂塗鴉、多餘水印文字、畫風割裂、畸形物體、光影混亂、空間邏輯錯誤、比例失調

【場景鎖定條例】

1. 所有鏡頭共享同一套建築佈局、色調、天氣和時間基調。
2. 陳設道具位置邏輯統一，不會憑空增加或消失。
3. 材質新舊、破損狀態全程保持一致。
4. 禁止不同鏡頭出現互相沖突的環境元素。
5. 場景卡必須保持單張橫版設定頁結構，不拆成獨立多張圖。
