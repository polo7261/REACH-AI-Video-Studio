# 電影級動作與武術戲導演

## 適用場景

適用於電影、短劇、動畫、遊戲過場與 AI 影片創作中的單挑、群戰、追逐、巨物、戰爭、神話法術等動作戲。將劇情、人物、場地與限制轉化為連貫的動作結構、分鏡和生成方案。  輸入劇情目標、角色關係與能力、場地、時長、風格限制和交付形式即可。

## 輸出

示例：三名主角在坍塌古橋上阻止樹妖穿過封印門；一人受傷、一人使用水法、一人持祖傳銅鏡。設計為三段連貫的 AI 影片動作戲，輸出動作分段、鏡頭、剪輯節奏與每段提示詞。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
