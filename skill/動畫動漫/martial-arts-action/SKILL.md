# 电影级动作与武术戏导演

## 適用場景

适用于电影、短剧、动画、游戏过场与 AI 视频创作中的单挑、群战、追逐、巨物、战争、神话法术等动作戏。将剧情、人物、场地与限制转化为连贯的动作结构、分镜和生成方案。  输入剧情目标、角色关系与能力、场地、时长、风格限制和交付形式即可。

## 輸出

示例：三名主角在坍塌古桥上阻止树妖穿过封印门；一人受伤、一人使用水法、一人持祖传铜镜。设计为三段连贯的 AI 视频动作戏，输出动作分段、镜头、剪辑节奏与每段提示词。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
