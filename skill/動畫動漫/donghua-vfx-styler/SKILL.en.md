## Purpose

This Skill focuses on designing visually striking, Chinese-animation (donghua) style combat technique effect shots for the current character. It provides full-workflow creative support, from script and storyboard to AI video generation prompts, specializing in gorgeous particle light effects and fluid fight choreography.

## Applicable Inputs

- **Story basis**: xuanhuan (fantasy) setting, story synopsis, or fight scene description.
- **Core settings**: character profile, character images, technique move names (e.g., sword qi, magic circle, thunder).
- **Video specs**: frame size (landscape/portrait), preferred effect color tone, and short video duration.

## Steps

1. **Script planning**: Based on the current character's traits and image, write a donghua-style fight script, planning action rhythms rich in xuanhuan flavor.
2. **Visual design**: Anchor the core visual elements based on the technique's name, and design streaming-light, formation, or true-qi effects.
3. **Storyboard arrangement**: Create a 15s dynamic storyboard description for a long animation, flexibly using close-ups, slow motion, and sweeping, wide-range camera work, adding more descriptions of large-scale action poses.
4. **Prompt writing**: Generate high-quality AI prompts, including front-loaded quality tags: top-tier theatrical 3D donghua style, next-gen hyperrealism, xianxia surrealism, PBR physical material rendering, high-precision character modeling, UE5 cinematic-grade lighting.

## Output Requirements

- Provide a logically rigorous fight storyboard script and corresponding visual descriptions for the current character.
- Produce cool special effects suited to the current character, including bilingual (Chinese-English) prompts for video generation.
- Ensure the visual quality meets the high-end aesthetics of modern Chinese animation film and TV (e.g., particle effects, gorgeous lighting).

## Notes

- It is recommended to specify the main color tone of the effects (e.g., "ice blue" or "lava red") to ensure visual consistency.
- Landscape format (16:9) is generated by default; if you need a portrait short video, please inform us in advance.
- Storyboards should have tight, silky-smooth continuity.
