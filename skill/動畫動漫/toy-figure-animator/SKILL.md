# 手办动画短视频生成 Skill（LibTV 版）
 
## ⚠️ 最高优先级输出规则
 
选项只输出一次，不得重复打印。所有确认问题必须与上方内容分开成独立消息发出。
 
---
 
## 整体流程概览
 
```
用户上传手办图片/视频
        ↓
[Step 1] 规格 + 背景设定 + 风格选择（一次性问完）
        ↓（用户回复）
[Step 2] 内部解析 → 输出创意剧本 + 分镜脚本 + BGM方向，用户一次确认
        ↓（用户确认）
[Step 3] 询问三视图 + 场景图（合并问）→ 生成 → 一起确认
        ↓（用户确认）
[Step 4] 输出分组方案和完整视频提示词，直接同时生成所有片段 + BGM → 合并输出成片
```

## Step 2：创意剧本 + 分镜脚本 + BGM方向
 
用户确认规格和风格后，**一次性输出三项内容**，然后问用户确认。
 
### 创意维度（内部选择，不输出给用户）
 
选创意前先问自己：**这个手办的气质最像生活里的哪种人/哪个时刻？** 从那里出发找故事，而不是套公式。
 
**禁止使用的烂梗**：霸气摆POSE被人无视、打工人摸鱼、变身打败坏蛋然后胜利、"其实内心很脆弱"的硬凹反差。这些是最无聊的套路，一律不用。
 
| 维度 | 核心逻辑 | 适合信号 |
|------|---------|---------|
| **开箱活过来** | 玩具刚被拆出来，第一次看见这个世界——对所有东西都新鲜好奇，走路还不稳，会被最普通的东西惊到 | 任何手办都可以用，特别适合萌系/Q版 |
| **就是享受生活** | 没有剧情，没有目的，就是一个小家伙在享受某件很小的事——吃东西、晒太阳、发呆、听音乐。不需要反转，氛围本身就是内容 | 软萌/毛绒质感/可爱造型 |
| **卖萌日常** | 角色做了一件很普通的日常小事，但因为是玩具来做就莫名可爱——比如认真擦桌子、把自己装进杯子里、对着镜子练习表情 | Q版/有表情特点的手办 |
| **枯燥生活切片** | 截取某个无聊但真实的日常瞬间——等公交、排队、手机没电、外卖还没到。不需要解决，就是那种感觉 | 打工人气质/日常造型 |
| **热梗套进去** | 把当下流行的梗/场景/情绪直接套进手办世界——比如"班味""发疯文学""i人社恐""ootd打卡"。用手办演一遍，反差感自然就有了 | 有时代感气质的手办 |
| **脑洞宇宙** | 完全不按常理——恐龙是保护公主的战士、橡皮鸭是深海侦探、可爱小熊其实统治了整个城市。越荒诞越认真演，越好看 | 外形有强烈视觉冲击或造型奇特的手办 |
| **模仿人类活动** | 玩具角色认真地做人类才做的事——打网球、看球赛、做裁判、开会、约会、买咖啡。越认真越好笑，尺寸反差和动作认真度是核心笑点，不需要剧情，场景本身就是内容 | 任何手办都适合，特别是有手有脚能做动作的 |
| **多角色关系** | 多个手办之间有一段明确的关系设定，关系本身就是故事——警匪、伙伴、吃饭搭子、上班搭子、对手、一个努力一个摆烂。把这段关系放进一个具体场景里演一遍就够了 | 多个手办，气质有互补或对比 |
 
### 三大视觉风格（内部参考）
 
| 代号 | 风格名称 | 核心特征 |
|------|---------|---------|
| A | 定格动画风 | 材质肌理可见、关节微小律动、固定机位、无配音纯肢体表达 |
| B | 现代潮玩风 | 3D建模角色+真实大空间渲染，整体像品牌动画短片，非微缩摄影 |
| C | 特摄风 | 4:3画幅、磁带颗粒质感，模拟昭和棚拍特摄视觉感，色调跟随剧情 |

## Step 3：三视图 + 场景图
 
用户确认 Step 2 后，合并询问三视图和场景图：
 
```
接下来需要准备两类参考图，用于保证视频里角色和场景的一致性：
```
 
```
📸 角色三视图（正面/侧面/背面 + 表情变化）：
  · 📎 我有三视图，直接上传
  · ❌ 没有，帮我生成
```
 
```
🎨 场景参考图（先生成场景图，视频置景、道具、色调一致性会更强）：
  · ✅ 要，帮我生成
  · ❌ 不用
```
 
### 三视图生成规范（用户没有时）
 
**生成模型**：Lib Image，以手办原图作为输入。每个角色生成**一张16:9角色参考图**，纯白背景，上区三视图（正/侧/背，占60%）+ 下区4-6个表情变化（占35%，每个标注情绪词）。表情克制，幅度符合玩具实际可动范围。多形态手办每种形态分别生成一张。
 
三视图生成/上传后立即建立**角色资产档案**：角色ID格式 `[CHAR-01]`、多形态 `[CHAR-01-FORM-A/B]`。配音参数（风格 C 默认开口，其他风格默认无台词仅语气词）：建档时锁定声线特征、语速节奏、情绪基调、专属语气词（3-5个）；有台词时额外锁定说话风格/语音语调/音色描述/禁止变化项；所有参数后续片段严格沿用。
 
### 场景图生成规范（用户选"要"时）
 
**每个场景只生成一张主要构图**——就是这个场景最核心的画面，包含主要背景、道具位置、整体色调。**同一个地点不管有几个时刻或镜头，只算一个场景，只生一张图**，严禁把同一地点的不同时刻/角度分别做成多个子图。所有不同地点的场景各一张，全部合并在同一张图里，横向并排，每张子图下方标注场景名称，**严禁生成多张独立图片**。
 
 
**场景图必须卡通化，严禁霓虹灯/霓虹色彩/霓虹光效，禁止写实摄影风格，禁止使用 MJ 模型生成：**
- 风格 A：手工感微缩布景，纸板/毛毡/布料材质，卡通化色彩
- 风格 B：卡通化3D渲染大空间，色彩鲜艳饱和、造型圆润夸张
- 风格 C：卡通化昭和微缩模型质感，颜色明快、造型简化。生成场景图时提示词必须包含："1970-80s昭和日本儿童特摄TV风格，画面质感模拟昭和效果：轻微磁带颗粒感、低饱和复古滤镜、色彩略显褪色感。"
**生成场景图时必须同时挂载所有角色参考图。**
 
### 场景设计规则
 
**规则一**：角色高饱和时，背景自动降为低饱和灰调，严禁背景抢戏。
**规则二**：强调手工温润感，非纯数字工业感。
**规则三**：场景材质与角色材质匹配：
- 风格 A：毛绒角色→毛毡背景；黏土角色→纸板背景；树脂角色→木板背景
- 风格 B：3D渲染大空间，材质光滑精致
- 风格 C：昭和微缩模型质感，手工粗糙感
生成完成后，三视图和场景图一起呈现给用户确认：
 
```
角色参考图和场景参考图已全部生成，请在画布里查看。
```
 
```

  · ✅ 没问题，进入视频生成
  · ✏️ 需要调整
```

## Step 4：分组生成视频
 
用户确认参考图后，直接输出分组方案和完整视频提示词，**无需用户确认，立即开始生成**。
 
### 风格专属剪辑语法
 
**风格 A｜定格动画风**：摄影机几乎不动，运动感来自角色帧间跳跃。**可用**：`[Fixed Camera]` `[Step-frame Pan/Tilt]`。**禁止**：流畅运镜、运动模糊。材质肌理清晰可见，允许轻微帧间闪烁。
 
**风格 B｜现代潮玩风**：商业级流畅运镜。**可用**：`[Crash Zoom]` `[Smooth Dolly In/Out]` `[Snorricam]` `[360° Orbit]` `[Dutch Angle]`。**禁止**：抽帧感、复古低保真、微缩摄影质感。高饱和高对比，正常比例大空间。
 
**风格 C｜特摄风**：三脚架机械感运动。**可用**：`[Fixed Shot]` `[Mechanical Pan]` `[Mechanical Tilt]` `[Crash Zoom]` `[Low-angle Fixed]`。**禁止**：Orbit/Dolly/手持晃动。4:3画幅+磁带颗粒感。表情无夸张，戏剧性靠音效/镜头/肢体，禁止在提示词中描述面部细节。
 
### 分组规则与提示词铁律
 
**合并规则（严格执行）**：所有相邻镜头，只要合并后总时长不超过15秒，就必须合并为一个片段，不得每个镜头单独生成一个片段。不管场景是否相同，时长够就合并。只有超过15秒时才新建片段。
 
例如：镜头1（3s）、镜头2（4s）、镜头3（4s），总时长11s < 15s，必须合并为片段01，而不是分成三个片段。
 
**同时生成**：所有片段的提示词确认后，**同时启动所有片段的生成**，不得生好一个再生下一个。
 
**视频提示词铁律**：
- 写入"视频内容不包含背景音乐，只保留环境音、音效和配音，音频轨道保持开启"
- 所有镜头描述完整合并，不得删减任何一个镜头
- 每条片段提示词逐字带入所有角色完整配音锁定描述
- 所有提示词使用中文
- 挂载场景图时，提示词中必须明确写明参考场景图里的**哪个子场景**（如"参考场景图中的场景一：观影中"），因为场景图是一图多场景，不指定子场景模型无法判断参考哪部分
**置景连续性**（所有片段同时生成，必须在提示词阶段就写好一致性描述）：
- 在输出分组方案时，根据分镜脚本提前撰写每个片段的置景描述（场景/布局/地面/墙面/灯光/色调/角色站位/道具列表）
- 同一场景的所有片段，置景描述必须完全一致，逐字复制，只更新镜头运动/角色动作/叙事内容
- 场景切换片段单独撰写置景描述，视觉风格调性与全片保持一致
### 分组方案输出格式
 
```
为了保证镜头节奏连贯性和同场景画面一致性，以下是分组方案及完整视频提示词：
 
📦 视频片段分组方案
 
[片段01] 镜头 X、X | 总时长：Xs | 场景：[场景名]
  → 出现角色：[中文名] | 挂载：角色参考图 + 场景图子场景[X]：[子场景名称]
  → 完整提示词：[合并所有镜头描述+置景档案+配音参数+无BGM声明]
 
[片段02] 镜头 X、X | 总时长：Xs | 场景：[场景名]
  → 出现角色：[中文名] | 挂载：角色参考图 + 场景图子场景[X]：[子场景名称]
  → 完整提示词：[合并所有镜头描述+置景延续+配音参数+无BGM声明]
 
共 [X] 个片段，立即开始同时生成所有片段。
```

## Step 5：同时生视频和BGM，合并输出成片
 
分组方案输出后直接启动，无需用户确认：
 
1. **同时启动所有片段生成**：Seedance 2.0 同时生成所有片段（不是顺序生成），同时生成BGM（依据Step 2锁定的BGM提示词）
2. 每条片段生成后在画布呈现供用户查看，自动继续，无需用户逐条确认
3. 所有片段生成完成后顺序拼接
4. 视频与BGM对位合成，输出完整成片
---
 
## 全局约束
 
1. **阶段门控**：Step 1/2/3必须等用户确认后才推进；Step 4输出分组方案后直接生成，无需确认
2. **创意维度内部选择**：用户已在Step 1选定风格，创意维度由AI内部根据手办气质和风格选择，不输出给用户
3. **角色资产ID全程贯穿**：所有分镜和片段生成节点必须引用
4. **多形态手办单独建档**：每种形态独立三视图和ID
5. **视觉风格全程一贯**：风格确认后，剪辑语法/音效/BGM调性必须一致
6. **手办外貌高保真还原**：始终基于用户上传实际图片
7. **选项不重复输出**
8. **不暴露内部风格代号**：对用户只说风格名称，不说"风格A/B/C"
9. **不主动加画面文字/标题**：除非用户要求
10. **不引用真实品牌或受版权保护的IP名称**
11. **所有提示词使用中文**
