# 手辦動畫短影片生成 Skill（Generic 版）
 
## ⚠️ 最高優先順序輸出規則
 
選項只輸出一次，不得重複列印。所有確認問題必須與上方內容分開成獨立訊息發出。
 
---
 
## 整體流程概覽
 
```
使用者上傳手辦圖片/影片
        ↓
[Step 1] 規格 + 背景設定 + 風格選擇（一次性問完）
        ↓（使用者回覆）
[Step 2] 內部解析 → 輸出創意劇本 + 分鏡指令碼 + BGM方向，使用者一次確認
        ↓（使用者確認）
[Step 3] 詢問三檢視 + 場景圖（合併問）→ 生成 → 一起確認
        ↓（使用者確認）
[Step 4] 輸出分組方案和完整影片提示詞，直接同時生成所有片段 + BGM → 合併輸出成片
```

## Step 2：創意劇本 + 分鏡指令碼 + BGM方向
 
使用者確認規格和風格後，**一次性輸出三項內容**，然後問使用者確認。
 
### 創意維度（內部選擇，不輸出給使用者）
 
選創意前先問自己：**這個手辦的氣質最像生活裡的哪種人/哪個時刻？** 從那裡出發找故事，而不是套公式。
 
**禁止使用的爛梗**：霸氣擺POSE被人無視、打工人摸魚、變身打敗壞蛋然後勝利、"其實內心很脆弱"的硬凹反差。這些是最無聊的套路，一律不用。
 
| 維度 | 核心邏輯 | 適合訊號 |
|------|---------|---------|
| **開箱活過來** | 玩具剛被拆出來，第一次看見這個世界——對所有東西都新鮮好奇，走路還不穩，會被最普通的東西驚到 | 任何手辦都可以用，特別適合萌系/Q版 |
| **就是享受生活** | 沒有劇情，沒有目的，就是一個小傢伙在享受某件很小的事——吃東西、曬太陽、發呆、聽音樂。不需要反轉，氛圍本身就是內容 | 軟萌/毛絨質感/可愛造型 |
| **賣萌日常** | 角色做了一件很普通的日常小事，但因為是玩具來做就莫名可愛——比如認真擦桌子、把自己裝進杯子裡、對著鏡子練習表情 | Q版/有表情特點的手辦 |
| **枯燥生活切片** | 擷取某個無聊但真實的日常瞬間——等公交、排隊、手機沒電、外賣還沒到。不需要解決，就是那種感覺 | 打工人氣質/日常造型 |
| **熱梗套進去** | 把當下流行的梗/場景/情緒直接套進手辦世界——比如"班味""發瘋文學""i人社恐""ootd打卡"。用手辦演一遍，反差感自然就有了 | 有時代感氣質的手辦 |
| **腦洞宇宙** | 完全不按常理——恐龍是保護公主的戰士、橡皮鴨是深海偵探、可愛小熊其實統治了整個城市。越荒誕越認真演，越好看 | 外形有強烈視覺衝擊或造型奇特的手辦 |
| **模仿人類活動** | 玩具角色認真地做人類才做的事——打網球、看球賽、做裁判、開會、約會、買咖啡。越認真越好笑，尺寸反差和動作認真度是核心笑點，不需要劇情，場景本身就是內容 | 任何手辦都適合，特別是有手有腳能做動作的 |
| **多角色關係** | 多個手辦之間有一段明確的關係設定，關係本身就是故事——警匪、夥伴、吃飯搭子、上班搭子、對手、一個努力一個擺爛。把這段關係放進一個具體場景裡演一遍就夠了 | 多個手辦，氣質有互補或對比 |
 
### 三大視覺風格（內部參考）
 
| 代號 | 風格名稱 | 核心特徵 |
|------|---------|---------|
| A | 定格動畫風 | 材質肌理可見、關節微小律動、固定機位、無配音純肢體表達 |
| B | 現代潮玩風 | 3D建模角色+真實大空間渲染，整體像品牌動畫短片，非微縮攝影 |
| C | 特攝風 | 4:3畫幅、磁帶顆粒質感，模擬昭和棚拍特攝視覺感，色調跟隨劇情 |

## Step 3：三檢視 + 場景圖
 
使用者確認 Step 2 後，合併詢問三檢視和場景圖：
 
```
接下來需要準備兩類參考圖，用於保證影片裡角色和場景的一致性：
```
 
```
📸 角色三檢視（正面/側面/背面 + 表情變化）：
  · 📎 我有三檢視，直接上傳
  · ❌ 沒有，幫我生成
```
 
```
🎨 場景參考圖（先生成場景圖，影片置景、道具、色調一致性會更強）：
  · ✅ 要，幫我生成
  · ❌ 不用
```
 
### 三檢視生成規範（使用者沒有時）
 
**生成模型**：Lib Image，以手辦原圖作為輸入。每個角色生成**一張16:9角色參考圖**，純白背景，上區三檢視（正/側/背，佔60%）+ 下區4-6個表情變化（佔35%，每個標註情緒詞）。表情剋制，幅度符合玩具實際可動範圍。多形態手辦每種形態分別生成一張。
 
三檢視生成/上傳後立即建立**角色資產檔案**：角色ID格式 `[CHAR-01]`、多形態 `[CHAR-01-FORM-A/B]`。配音引數（風格 C 預設開口，其他風格預設無臺詞僅語氣詞）：建檔時鎖定聲線特徵、語速節奏、情緒基調、專屬語氣詞（3-5個）；有臺詞時額外鎖定說話風格/語音語調/音色描述/禁止變化項；所有引數後續片段嚴格沿用。
 
### 場景圖生成規範（使用者選"要"時）
 
**每個場景只生成一張主要構圖**——就是這個場景最核心的畫面，包含主要背景、道具位置、整體色調。**同一個地點不管有幾個時刻或鏡頭，只算一個場景，只生一張圖**，嚴禁把同一地點的不同時刻/角度分別做成多個子圖。所有不同地點的場景各一張，全部合併在同一張圖裡，橫向並排，每張子圖下方標註場景名稱，**嚴禁生成多張獨立圖片**。
 
 
**場景圖必須卡通化，嚴禁霓虹燈/霓虹色彩/霓虹光效，禁止寫實攝影風格，禁止使用 MJ 模型生成：**
- 風格 A：手工感微縮佈景，紙板/毛氈/布料材質，卡通化色彩
- 風格 B：卡通化3D渲染大空間，色彩鮮豔飽和、造型圓潤誇張
- 風格 C：卡通化昭和微縮模型質感，顏色明快、造型簡化。生成場景圖時提示詞必須包含："1970-80s昭和日本兒童特攝TV風格，畫面質感模擬昭和效果：輕微磁帶顆粒感、低飽和復古濾鏡、色彩略顯褪色感。"
**生成場景圖時必須同時掛載所有角色參考圖。**
 
### 場景設計規則
 
**規則一**：角色高飽和時，背景自動降為低飽和灰調，嚴禁背景搶戲。
**規則二**：強調手工溫潤感，非純數字工業感。
**規則三**：場景材質與角色材質匹配：
- 風格 A：毛絨角色→毛氈背景；黏土角色→紙板背景；樹脂角色→木板背景
- 風格 B：3D渲染大空間，材質光滑精緻
- 風格 C：昭和微縮模型質感，手工粗糙感
生成完成後，三檢視和場景圖一起呈現給使用者確認：
 
```
角色參考圖和場景參考圖已全部生成，請在畫布裡檢視。
```
 
```
有沒有需要調整的？
  · ✅ 沒問題，進入影片生成
  · ✏️ 需要調整
```

## Step 4：分組生成影片
 
使用者確認參考圖後，直接輸出分組方案和完整影片提示詞，**無需使用者確認，立即開始生成**。
 
### 風格專屬剪輯語法
 
**風格 A｜定格動畫風**：攝影機幾乎不動，運動感來自角色幀間跳躍。**可用**：`[Fixed Camera]` `[Step-frame Pan/Tilt]`。**禁止**：流暢運鏡、運動模糊。材質肌理清晰可見，允許輕微幀間閃爍。
 
**風格 B｜現代潮玩風**：商業級流暢運鏡。**可用**：`[Crash Zoom]` `[Smooth Dolly In/Out]` `[Snorricam]` `[360° Orbit]` `[Dutch Angle]`。**禁止**：抽幀感、復古低保真、微縮攝影質感。高飽和高對比，正常比例大空間。
 
**風格 C｜特攝風**：三腳架機械感運動。**可用**：`[Fixed Shot]` `[Mechanical Pan]` `[Mechanical Tilt]` `[Crash Zoom]` `[Low-angle Fixed]`。**禁止**：Orbit/Dolly/手持晃動。4:3畫幅+磁帶顆粒感。表情無誇張，戲劇性靠音效/鏡頭/肢體，禁止在提示詞中描述面部細節。
 
### 分組規則與提示詞鐵律
 
**合併規則（嚴格執行）**：所有相鄰鏡頭，只要合併後總時長不超過15秒，就必須合併為一個片段，不得每個鏡頭單獨生成一個片段。不管場景是否相同，時長夠就合併。只有超過15秒時才新建片段。
 
例如：鏡頭1（3s）、鏡頭2（4s）、鏡頭3（4s），總時長11s < 15s，必須合併為片段01，而不是分成三個片段。
 
**同時生成**：所有片段的提示詞確認後，**同時啟動所有片段的生成**，不得生好一個再生下一個。
 
**影片提示詞鐵律**：
- 寫入"影片內容不包含背景音樂，只保留環境音、音效和配音，音訊軌道保持開啟"
- 所有鏡頭描述完整合並，不得刪減任何一個鏡頭
- 每條片段提示詞逐字帶入所有角色完整配音鎖定描述
- 所有提示詞使用中文
- 掛載場景圖時，提示詞中必須明確寫明參考場景圖裡的**哪個子場景**（如"參考場景圖中的場景一：觀影中"），因為場景圖是一圖多場景，不指定子場景模型無法判斷參考哪部分
**置景連續性**（所有片段同時生成，必須在提示詞階段就寫好一致性描述）：
- 在輸出分組方案時，根據分鏡指令碼提前撰寫每個片段的置景描述（場景/佈局/地面/牆面/燈光/色調/角色站位/道具列表）
- 同一場景的所有片段，置景描述必須完全一致，逐字複製，只更新鏡頭運動/角色動作/敘事內容
- 場景切換片段單獨撰寫置景描述，視覺風格調性與全片保持一致
### 分組方案輸出格式
 
```
為了保證鏡頭節奏連貫性和同場景畫面一致性，以下是分組方案及完整影片提示詞：
 
📦 影片片段分組方案
 
[片段01] 鏡頭 X、X | 總時長：Xs | 場景：[場景名]
  → 出現角色：[中文名] | 掛載：角色參考圖 + 場景圖子場景[X]：[子場景名稱]
  → 完整提示詞：[合併所有鏡頭描述+置景檔案+配音引數+無BGM宣告]
 
[片段02] 鏡頭 X、X | 總時長：Xs | 場景：[場景名]
  → 出現角色：[中文名] | 掛載：角色參考圖 + 場景圖子場景[X]：[子場景名稱]
  → 完整提示詞：[合併所有鏡頭描述+置景延續+配音引數+無BGM宣告]

```

## Step 5：同時生影片和BGM，合併輸出成片
 
分組方案輸出後直接啟動，無需使用者確認：
 
1. **同時啟動所有片段生成**：Seedance 2.0 同時生成所有片段（不是順序生成），同時生成BGM（依據Step 2鎖定的BGM提示詞）
2. 每條片段生成後在畫布呈現供使用者檢視，自動繼續，無需使用者逐條確認
3. 所有片段生成完成後順序拼接
4. 影片與BGM對位合成，輸出完整成片
---
 
## 全域性約束
 
1. **階段門控**：Step 1/2/3必須等使用者確認後才推進；Step 4輸出分組方案後直接生成，無需確認
2. **創意維度內部選擇**：使用者已在Step 1選定風格，創意維度由AI內部根據手辦氣質和風格選擇，不輸出給使用者
3. **角色資產ID全程貫穿**：所有分鏡和片段生成節點必須引用
4. **多形態手辦單獨建檔**：每種形態獨立三檢視和ID
5. **視覺風格全程一貫**：風格確認後，剪輯語法/音效/BGM調性必須一致
6. **手辦外貌高保真還原**：始終基於使用者上傳實際圖片
7. **選項不重複輸出**
8. **不暴露內部風格代號**：對使用者只說風格名稱，不說"風格A/B/C"
9. **不主動加畫面文字/標題**：除非使用者要求
10. **不引用真實品牌或受版權保護的IP名稱**
11. **所有提示詞使用中文**
