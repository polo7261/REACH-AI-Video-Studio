# 玄幻技能氛圍特效

## 適用場景

使用者提供一段玄幻/仙俠打鬥場景的文字描述，需要生成帶氛圍特效的 3D 國漫風格畫面時使用。僅適用於玄幻打鬥、法術對轟類場景；日常文戲、非戰鬥場景不適用。

## 輸出

一張統一 3D 國漫質感的打鬥畫面，氛圍特效與動作、鏡頭呼應，特效剋制不遮擋主體。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
