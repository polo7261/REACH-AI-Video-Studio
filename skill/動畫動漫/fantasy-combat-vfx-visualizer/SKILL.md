# 玄幻技能氛围特效

## 適用場景

用户提供一段玄幻/仙侠打斗场景的文字描述，需要生成带氛围特效的 3D 国漫风格画面时使用。仅适用于玄幻打斗、法术对轰类场景；日常文戏、非战斗场景不适用。

## 輸出

一张统一 3D 国漫质感的打斗画面，氛围特效与动作、镜头呼应，特效克制不遮挡主体。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
