# 上美影工筆重彩畫風

## 風格定義

**中國傳統工筆重彩動畫風格 · 上海美術電影製片廠（上美影）美學**

本風格以老上美影經典美術片為視覺正規化，融合國畫工筆重彩技法與傳統戲曲妝容審美，適用於古典題材的影象與動畫生成。

---

## 核心風格錨點

### 1. 線條 · 鐵線描

- 人物輪廓與結構線均以**流暢乾淨的墨線**勾勒（鐵線描）
- 線條**利落柔和**，粗細均勻，無毛刺感
- 衣褶、髮絲、器物邊緣均以白描手法處理，線條本身具有表現力

### 2. 面部妝容 · 京劇青衣妝感

- **眼型**：細長吊梢鳳眼，眼尾上挑，眼線細長
- **腮紅**：淡腮紅，暈染自然，不濃豔
- **額飾**：額間花鈿，點綴精緻
- 整體妝感參照老上美影仕女人物正規化，清冷高雅，不現代感

### 3. 上色 · 工筆重彩平塗

- 上色方式為**平塗**，無漸變過渡，色塊邊界清晰
- 色彩飽和度**適中偏高**，濃郁鮮明
- 主色系參考國畫重彩顏料：
  - 硃紅（人物服飾、點綴）
  - 石青（天空、水面、男性服飾）
  - 藤黃（燈光、金飾、暖調場景）
  - 翠綠（植物、配飾）
  - 赭石（建築、木質器物）
  - 墨色（輪廓線、陰影極簡處理）

### 4. 光影 · 隨類賦彩

- **無強烈明暗陰影**，不使用寫實光影體積感
- 遵循國畫"隨類賦彩"原則：色彩服從物象固有色，而非光源色
- 保持畫面**雅緻質感**，整體色調和諧統一

### 5. 整體美學參照

- 上海美術電影製片廠經典美術片風格（參考《大鬧天宮》《哪吒鬧海》《金色的海螺》等）
- 國風工筆手繪動畫 / 新中式古典美術片
- 人物造型扁平化，具有裝飾性，不追求三維立體感

## 使用方式

在影象或影片生成節點的 prompt 中，將以下風格描述作為**固定字首**附加：

```
中國傳統工筆重彩動畫風格，上海美術電影製片廠（上美影）美學，鐵線描墨線勾勒輪廓，線條利落柔和，京劇青衣妝感（細長吊梢鳳眼、淡腮紅、額間花鈿），工筆重彩平塗上色，硃紅/石青/藤黃/翠綠國畫重彩色，色彩飽和度適中偏高，無強烈明暗陰影，隨類賦彩雅緻質感，國風工筆手繪動畫風格
```

## 適用節點型別

節點型別使用建議角色設定圖（三檢視）全量應用，重點保證面部妝容與線條風格一致場景設定圖全量應用，重點保證色彩體系與光影處理一致道具設定圖全量應用，重點保證線條與重彩平塗一致分鏡/關鍵幀影象全量應用，確保與角色/場景設定圖風格統一動畫影片生成作為風格參考圖（reference image）輸入，同時附加風格描述字首

---

## 風格一致性注意事項

1. **跨節點複用時**：建議將同一專案的風格參考板影象作為 reference image 輸入，確保色彩體系統一
2. **多角色同框時**：各角色的線條粗細、妝容規範需保持一致，避免風格割裂
3. **場景與人物搭配時**：場景色調應與人物服飾色彩形成呼應，遵循整體色彩規劃
4. **避免混入的風格元素**：寫實光影、賽璐璐高光、日系動漫線條、3D 渲染質感

## 分鏡製作規則

### 核心敘事原則：以人物自然對話驅動劇情

> **本 Skill 的分鏡敘事方式以人物之間的自然對話為核心驅動力**。情節的展開、轉折、人物關係的揭示、資訊的傳遞，均應透過角色之間符合其性格與所處情境的自然對話來完成，而非依賴旁白敘述或字幕說明。

**具體要求：**

- **情節推進靠對話**：每一個敘事節點（如衝突爆發、關係轉變、資訊揭露）都應設計成角色開口說話的場景，讓觀眾從對話中自然感知劇情走向
- **轉折靠對話呈現**：故事的關鍵轉折點，透過角色說出的一句話、一個反問、一聲沉默後的回應來觸發，而不是用旁白"告訴"觀眾發生了什麼
- **禁止用旁白代替敘事**：旁白不得用於交代背景資訊、推進情節或解釋人物動機；這些內容必須透過對話和畫面動作自然呈現

**旁白轉化為人物臺詞的操作規則（重要）：**

> 凡是在寫分鏡時腦子裡冒出"用旁白來說……"的念頭，都必須先停下來，問自己：**"這句話，能不能讓某個角色自己說出來？"** 答案几乎永遠是"可以"。

轉化方法參考：

原本想用旁白說的內容轉化為人物臺詞的方式交代人物身份背景讓另一個角色在對話中自然提及，或讓主角在對話中自我表露說明時間/地點/情境讓角色透過對話反應出當下處境（如抱怨、感嘆、詢問）解釋人物內心動機讓角色在對話中說出自己的想法、顧慮或決定推進情節轉折讓關鍵角色說出那句"觸發轉折"的話，而不是由旁白宣告表達情緒與感受讓角色直接說出來，或透過與他人的對話中流露

- **旁白的唯一例外**：僅在全片結尾的情緒性收束鏡頭中，可酌情使用極簡旁白（不超過2句），且須是**人物自己的內心獨白**（第一人稱），絕不是第三方敘述者的聲音

### 判斷入口：使用者提供的是精確分鏡還是故事概要？

情況 A · 使用者提供了精確分鏡

**判定標準**：使用者輸入中包含明確的鏡號、景別、運鏡描述、臺詞或畫面動作說明，每個鏡頭有獨立的具體內容。

**處理方式**：

- **嚴格按照使用者提供的分鏡執行**，不得自行增刪鏡頭、調整順序或修改臺詞
- 僅在畫風 prompt 字首、技術引數層面做適配，內容層面完全尊重使用者原稿
- 如使用者分鏡中有模糊表達（如"某個動作"），可在不改變意圖的前提下補充技術描述，但須標註"補充說明"

情況 B · 使用者只提供了一段話或故事概要

**判定標準**：使用者輸入是一段敘述性文字、故事梗概或情節描述，沒有具體的鏡頭劃分。

**處理方式**：在開始寫分鏡之前，必須先向使用者詢問以下兩項資訊：

**第一步 · 詢問目標時長**

向使用者提問：

> 請問這條短片的目標時長是多少？（例如：30秒 / 1分鐘 / 2分鐘 / 3分鐘以上）

根據時長推算鏡頭數量參考（**每個分鏡預設時長15秒**）：

目標時長建議鏡頭數說明30秒2個每鏡15秒，內容需高度凝練1分鐘4個每鏡15秒，每鏡承載完整的一段對話或動作2分鐘8個每鏡15秒，可有充分的情節鋪墊與對話展開3分鐘12個每鏡15秒，適合完整敘事弧線3分鐘以上12個以上按15秒/鏡遞推，特殊情緒鏡頭可酌情延長

**第二步 · 推薦故事型別並讓使用者選擇**

根據故事內容，向使用者推薦 2～3 種敘事節奏風格，例如：

- **快節奏戲劇型**：鏡頭切換頻繁，衝突感強，適合高潮密集的故事
- **抒情慢敘型**：長鏡頭為主，情緒鋪墊充分，適合情感細膩的故事
- **古典章回型**：仿古典敘事結構，有起承轉合，適合改編自古典文學的題材

使用者選擇後，按所選風格最佳化分鏡結構。

**第三步 · 撰寫大師導演級分鏡**

獲得使用者確認後，按以下欄位逐一撰寫每個分鏡：

---

**① 鏡號**如「鏡頭01」，按順序編號。

**② 景別**從以下選項中選擇，並說明選擇理由（服務於什麼敘事目的）： 遠景 / 全景 / 中景 / 近景 / 特寫 / 大特寫

**③ 運鏡方式**從以下選項中選擇，並說明運鏡意圖： 固定 / 推鏡 / 拉鏡 / 搖鏡 / 移鏡 / 跟鏡 / 升鏡 / 降鏡 / 旋轉 / 手持晃動

**④ 環境描述**描述該鏡頭所處的場景環境，包括：

- 地點與空間感（室內/室外、開闊/逼仄、明亮/昏暗）
- 時間與光線（白晝/黃昏/夜晚、燭光/月光/日光）
- 氛圍細節（風、雨、煙霧、水波、帷幔飄動等可感知的環境元素）

**⑤ 人物狀態與表情**對鏡頭中每位出現的角色，分別描述：

- **身體狀態**：站/坐/行走/轉身/顫抖等具體動作
- **面部表情**：眼神（低垂/直視/迴避/怒視）、嘴角（緊抿/微顫/冷笑）、整體情緒外顯
- **肢體細節**：手勢、持物狀態、與他人的空間距離與位置關係

**⑥ 臺詞與對話**

- 寫出該鏡頭中所有角色的完整對話，格式為「角色名：臺詞內容」
- 每句臺詞後標註**語速**（緩慢 / 正常 / 急促）和**語氣**（平靜 / 顫抖 / 壓抑 / 憤怒 / 諷刺 / 哽咽 等）
- 臺詞須符合人物性格與所處情境，古典題材使用文白相間的語言風格
- **嚴格禁止使用旁白交代情節或背景**
- 如該鏡頭為純動作/氛圍鏡頭（無對話），註明「無臺詞」並說明畫面如何傳遞資訊

示例格式：

> 杜十娘：「你當真要如此？」（語速：緩慢；語氣：壓抑剋制，眼神直視李甲，聲音微微發顫） 李甲：「十娘……我……」（語速：遲疑停頓；語氣：愧疚，目光遊移，不敢對視）

**⑦ 音效**列出該鏡頭中應出現的音效，區分：

- **環境音**：持續性背景聲（如：江水流動聲、風聲、燭火噼啪聲、人群嘈雜聲）
- **動作音效**：與畫面動作同步的聲音（如：箱蓋開啟聲、珠寶落水聲、腳步聲、衣物摩擦聲）
- **情緒強化音效**（可選）：用於高潮時刻的單一強音效，替代音樂渲染情緒

**⑧ 情緒基調**用1～2個詞概括該鏡頭傳遞的核心情緒（如：壓抑、溫柔、憤怒、悲壯、諷刺、絕望等）

**⑨ 時長與時間軸拆解**

- **預設時長：15秒**，優先用滿15秒
- 僅當內容天然極短（如純氛圍過場）時才可低於15秒，須註明原因
- **15秒分鏡必須按時間點拆解**，寫清楚每個時間段內發生的具體內容，格式如下：

```
00:00～00:03  [畫面內容/動作描述]
00:03～00:07  [角色A臺詞 + 動作]
00:07～00:11  [角色B臺詞 + 動作]
00:11～00:15  [收尾動作/表情/氛圍]
```

時間軸拆解要求：

- 每個時間段的內容要具體到"誰在做什麼/說什麼"，不能只寫"對話繼續"
- 臺詞分配要符合正常語速，不要在2秒內塞入一大段話
- 動作與臺詞的時間節點要自然銜接，不要出現"說完話後站著不動5秒"的空白

---

**分鏡撰寫總原則：**

- **對話是第一敘事工具**：每個需要傳遞資訊的鏡頭，首先考慮"哪個角色能開口說出這件事"
- 對話要有來有往，符合人物身份與情緒狀態
- 運鏡設計要有敘事意圖，服務於情緒或資訊傳遞，不隨意堆砌
- 景別變化要有節奏感，避免連續相同景別造成視覺疲勞
- 高潮鏡頭可使用慢鏡頭、特寫疊化等手法強化情緒
- 整體分鏡要有完整的起承轉合結構

## 音訊規範

本風格短片的音訊構成規則如下：

音訊型別是否使用說明**人物說話聲音**✅ 保留臺詞配音，符合人物性格與古典語境**音效**✅ 保留環境音效（風聲、水聲、器物碰撞等）及動作音效**BGM / 背景音樂**❌ 不使用不新增任何背景音樂**字幕**❌ 不使用不新增任何字幕軌道

**音效設計建議**：

- 優先使用與場景強相關的自然音效（如：江水流動聲、船槳划水聲、燭火噼啪聲）
- 情緒高潮處可使用單一強音效（如：珠寶落水聲、投江水聲）代替音樂渲染情緒
- 人物臺詞配音語速適中，古典題材可略帶戲曲韻律感，不使用現代口語化語調
