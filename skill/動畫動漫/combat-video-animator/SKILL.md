# 雙人打鬥影片生成

## 用途

把一段雙人對戰的設定，生成一套可用的雙人對戰影片。

**適用**：兩名角色的對戰，需要體現雙方兵器、技能特點與打鬥過程。

**不適用**：單人動作、群戰（三人及以上混戰）。遇到這類需求不要套用本 skill。

## 輸入

一次性向使用者收齊以下資訊，缺哪項就明確追問，不要自行編造：

項說明戰鬥場景對戰發生的地點、環境、氛圍對戰雙方兩名角色的身份與外形特徵雙方兵器各自使用的武器雙方技能特點真氣顏色與形態、特殊格鬥技巧、特殊武器用途開始站點陣圖雙方開局的相對位置與朝向

## 硬要求（必須滿足，不滿足就重做）

1. **動作不粘連**：兩人動作必須各自獨立、邊界清晰，不能出現肢體互相穿插、粘連成一團的情況。
2. **動作不變形**：角色的身形、兵器形態在整個打鬥過程中保持穩定，不能扭曲、拉長、崩壞。
3. **極具爆發力**：打擊要有力量感與速度感，動作乾脆，不能軟綿綿、拖沓。
4. **場景破壞感**：打鬥對周圍環境造成可見的破壞與衝擊（碎裂、揚塵、衝擊波等），強化爆發力。

## 生成流程

1. 確認輸入資訊完整，尤其是雙方技能特點與開始站點陣圖。
2. 依據站點陣圖確定開局構圖，保證兩名角色位置、朝向與使用者提供的一致。
3. 按雙方的兵器與技能特點設計打鬥動作，確保兩人的動作線各自獨立、互不粘連。
4. 生成影片時，把「動作不粘連、不變形」作為首要校驗項，把「爆發力、場景破壞感」作為表現強化項。
5. 產出整套雙人對戰影片後，逐條對照上面的硬要求自檢，不合格則調整重生成。

## 測試用例

**輸入**：

- 戰鬥場景：夜晚的古城牆廢墟，地面碎石遍佈
- 對戰雙方：黑衣劍客（瘦高，長髮束起）、赤甲力士（魁梧，光頭）
- 雙方兵器：黑衣劍客用雙短劍；赤甲力士用一柄重錘
- 雙方技能特點：黑衣劍客真氣為青藍色、呈細長絲線狀，擅長貼身快攻與瞬步；赤甲力士真氣為暗紅色、呈塊狀護體，擅長重擊與震地
- 開始站點陣圖：黑衣劍客在畫面左側、面朝右；赤甲力士在畫面右側、面朝左，兩者相距約五步

**期望產出**：一套雙人對戰影片，兩人動作各自獨立不粘連、身形兵器不變形，打擊具爆發力，打鬥過程中城牆與地面出現碎裂、揚塵等破壞效果。
