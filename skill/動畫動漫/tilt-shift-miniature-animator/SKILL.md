# miniature-world

以微型道具與模型場景為舞臺,講有人物弧光的溫柔小故事(節日祝福/生活故事)。畫風精緻細膩、鏡頭剋制、**移軸攝影美學**,適合情感短片。預設 9:16、60–90s、溫暖柔和。

> 本環境適配(Flova→我方 13 工具):GPT Image 2/Nano Banana/Seedream/MJ → `generate_image_v3`;Seedance/Kling/MultiModalToVideo/FirstFrameToVideo → `generate_video_v3`;text_to_instrumental/text to narration → `generate_audio`;text_editor(Final_Video_Spec) → `write_file_v2`;video_assembler → `composite_video`。源裡"需要會員"的解析度/模型檔 = `無積分系統`,不設門。 \*\***本 skill 自足內聯,不依賴任何其他 skill。** 長內容(影象/影片 prompt 結構、多模態分析、裝配規範)見 `references/`(屬本 skill 內部檔案,非依賴)。

## 5 段管線(5 個強制 checkpoint,不可跳)

- **階段 0 規格確認**〔CP0〕:先向使用者展示並收明確選擇——
  - **畫面比例**(單選):9:16(豎屏,推薦·適合手機)/ 16:9(橫屏)/ 1:1(方形,社交)。
  - **影片解析度**(單選):720p(標準)/ 1080p(高畫質)。
  - **目標時長**(單選):60s(精簡,約 10–12 鏡)/ 90s(標準,約 14–18 鏡)/ 自定義(使用者輸入秒數)。
  - **圖片生成模型 / 影片生成模型**:本環境統一走 `generate_image_v3` / `generate_video_v3`(源的五選模型選單→我方模型檔,詳見 references/pipeline-and-generation.md 的模型檔說明)。
  - 收到選擇後 `write_file_v2` 建 **Final_Video_Spec.md**,寫入:影片型別=微縮生活故事片(情感短片)、畫面比例\[選\]、目標時長\[選\]、影片解析度\[選\]、圖片模型(解析度 2K)、影片模型+解析度\[選\]、視覺風格=微縮模型攝影風格·移軸鏡頭感·精緻細膩·色調溫暖柔和、音訊風格=輕音樂 BGM(鋼琴/絃樂為主)·溫柔旁白或無旁白、輸出語言=與使用者互動語言一致。
  - **強制暫停 CP0**:展示已確認引數摘要,收到明確確認前不得進入階段 1。
- **階段 1 故事指令碼**〔CP1〕:引導使用者給梗概或 AI 自動起草(人物/場景/情感弧光);完成關鍵元素定義(主角/配角/主要場景/核心道具)+ 分鏡規劃(景別/運鏡/時長/敘事節奏,時長對齊 Spec)+ 音訊層設計(BGM 條數/旁白規則)。展示完整故事指令碼與分鏡方案(每鏡景別/運鏡/敘事內容摘要)確認。
- **階段 2 關鍵元素圖**〔CP2〕:優先生成所有角色關鍵元素圖(正面參考圖 + 動作/表情變體),用 Spec 指定模型;再生成場景關鍵元素圖(微縮街景/室內佈景);如有旁白,在此階段同步 `generate_audio` 生成旁白音訊作後續音訊條件。**所有元素圖集中展示確認**,使用者要求重生成某張則重生成後再確認。
- **階段 3 分鏡影片 + BGM**〔CP3〕:按分鏡順序**批次**生成所有鏡頭影片,**無需逐批暫停確認**;所有鏡頭均攜帶對應角色圖 + 場景圖作視覺參考,用 Spec 指定模型;BGM `generate_audio` 與影片並行。全部完成集中展示預覽確認再進組裝。
- **階段 4 粗剪預覽**〔CP4〕:`composite_video` 將所有鏡頭影片 + 旁白 + BGM 組裝為粗剪時間線,以「粗剪預覽」形式請使用者確認整體節奏與情緒;有修改回對應階段調整後再組裝。
- **階段 5 最終輸出**:確認滿意後 `composite_video` 最終合成,告知匯出。

> **階段依賴**:CP0→CP1→CP2→CP3→CP4→階段5。**旁白音訊(階段 2)須早於影片(階段 3)完成**以作音訊條件;**BGM 與分鏡影片(階段 3)可並行**。

## 敘事:4–6 環節弧

先把故事拆成 **4–6 個關鍵環節**(不少於 4)成弧光骨架,再據此分配鏡頭。

- 環節數量:建議 4(精簡主題)–6(情節豐富主題),不得少於 4。
- 每環節對應一個**敘事功能節點**,常見結構:**建立世界 → 觸發事件 → 情節推進 → 情感高潮 → 餘韻收尾**;或針對具體主題拆流程(如"節日禮物":尋找材料→製作禮物→包裝等待→贈送驚喜→溫暖餘韻)。
- 每環節須含 **核心場景/參與角色/關鍵動作或道具/情緒基調**;環節間**邏輯連貫、情緒遞進**,禁無因果跳躍。
- 內部規劃格式(不對使用者展示):`環節一:[名稱]—[場景]—[核心動作]—[情緒]`…確認骨架合理後按各環節展開鏡頭,每環節通常 2–4 鏡。

## 關鍵元素(微縮人偶美學)

- **角色**:每位主角獨立 element——正面全身參考圖(清晰展示造型/服裝/髮型/膚色)+ ≥1 張表情/動作變體圖(展示情緒變化);須符合微縮人偶美學:比例略卡通化、材質感細膩(布料紋理/皮膚光澤)、與模型場景自然融合。
- **場景**:每主場景獨立 element——全景參考圖(空間結構/光線氛圍/道具擺放)+ 可選白天/夜晚變體。
- **道具**:有敘事功能的核心道具(信件/花束/小桌)單獨建 element,確保跨鏡頭一致。

## 分鏡(shot_list)規範

- **時長節奏**:單鏡 4–8s(情感高潮可延至 10s);整片 60–90s、通常 10–18 鏡。
- **景別與運鏡**:開場大遠景/俯瞰全景建微縮空間感(移軸感強);敘事推進以中景為主展角色互動;情感特寫用面部近景/道具特寫捕捉細節情緒;運鏡剋制(緩慢推拉、輕微橫搖為主),避免快速剪輯破壞溫柔氛圍。
- **敘事結構**:遵循「開篇建立世界 → 情節展開 → 情感高潮 → 餘韻收尾」四段式;每鏡描述含 景別/攝像機運動/畫面內容/角色情緒/與前後鏡的敘事關聯。

## 尺寸一致性與動作主體鐵律(跨鏡強制 · 微縮專屬)

- **大道具須眾人合力**:凡尺寸遠大於單個人偶的道具(咖啡杯/信封/花盆),須明確"多人合力"完成操作,**禁單人輕鬆使用大型道具**(否則生成出比例失調的巨大手臂/人物)。
- **動作對應具體主體**:每個動作須明確是誰(哪位角色或"兩人一同")執行,禁"有人/某人"等模糊表達。
- **禁違背常理元素**:不得發光道具、懸浮物體、騎乘蟲類等破壞微縮寫實感的內容。
- **跨鏡一致**:同角色服裝/髮型/道具狀態全程一致;場景內固定道具位置不無故移位。

## 音訊層規範

- **BGM**:1–2 條軌道(開場 + 高潮可切換);風格鋼琴獨奏 / 鋼琴+絃樂,輕柔溫暖無人聲;時長鬚覆蓋整片(建議生成 90s 以上),漸入漸出;`generate_audio` 的 prompt 中不可出現知名音樂人姓名。
- **旁白(可選)**:如使用須在分鏡階段標註旁白文字對應的 **shot_id**;語氣溫柔敘事(第三/第一人稱皆可);音色選型方法:溫柔女聲敘事 / 溫暖男聲敘事 / 中性清澈女聲(按情緒選用,由 `generate_audio` 指定);旁白鬚在影片生成前完成作音訊條件。
- **旁白與自帶音訊鏡頭共存**:用 FirstFrameToVideo/VideoInterp 一類生成的鏡頭自帶音訊,該類鏡頭的旁白軌須**靜音或錯開**,避免重疊。
