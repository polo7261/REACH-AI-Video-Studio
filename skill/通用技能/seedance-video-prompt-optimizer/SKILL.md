# Seedance 2.5 提示詞導演｜原版模板保留增強版

## 增強版範圍與維護

本檔案以 sd25-pe 0.1.1 為底，保留原版生成、編輯、關鍵幀、白模、情緒與攝影模板，精簡重複案例並增強時間分鏡。為第三方改編版，非官方新版本。對所有片型統一增強時間分段、景別與攝影機行為，不只適用於白模。原版與本版使用不同名稱，不自動執行原版自升級命令，避免定製規則被更新覆蓋。無需其他 skill、配套檔案或腳本即可最佳化 Prompt；不實際生成影片。

來源：https://arkdocs.tos-cn-beijing.volces.com/skills/

使用者請求和宿主規則優先。下述「分鏡與時間段增強規則」替代原版預設無數字階段的組織偏好；真實影片編輯、聲音編輯、延長與參考繼承的約束仍然有效。不改變使用者身份、事件因果、數量與故事結果。

## 目的

把使用者的原始文字、小說片段和可選的圖片、影片、音訊參考，編譯為一條可直接提交給 Seedance 2.5 的乾淨 Prompt。保留使用者核心意圖，明確素材職責、主體對映、事件狀態和需要保持的關係。

本 Skill 的職責止於理解輸入並輸出 Prompt，任何情況下都不自行呼叫生成介面。使用者明確要求生成影片時，先由本 Skill 產出乾淨 Prompt，再由獨立的生成工具或流程提交。本 Skill 始終保持素材只讀，不修改原素材，也不自動製作輔助素材。

## 適用場景

在以下情況載入本 Skill：

- 使用者要求最佳化、改寫或補全 Seedance 2.5 Prompt。
- 使用者給出簡略想法、長篇劇情、小說片段或未經整理的複雜 Prompt。
- 使用者給出圖片、影片、音訊、檔案路徑或多模態請求，需要建立素材職責。
- 使用者要做多素材生成、長影片、關鍵幀控制、宮格分鏡、白模渲染、影片編輯、聲音編輯或影片延長。
- 使用者希望改善情緒表演、運鏡、聲音、臺詞語言或產品流程表達。

不要在以下情況自動執行本 Skill：

- 使用者只詢問介面引數、價格、配額、報錯或模型能力，不需要生成 Prompt。
- 使用者只要求評價成片，不要求重寫 Prompt。

使用者明確要求直接生成影片時，仍先用本 Skill 把原始輸入編譯為乾淨 Prompt，再交給後續生成流程。本 Skill 本身不提交任務。

## 不可違反的原則

 1. **意圖優先**：不得改變人物身份與數量、關鍵道具、場景、事件因果、空間關係、編輯物件、延長方向和故事結果。
 2. **模板優先**：無論原 Prompt 是否完整，都要進入當前任務對應的模板重新組織，不能只做同義改寫。
 3. **素材逐份負責**：每份實際使用的素材說明採用什麼；實際可用但未分配職責的素材必須逐個列入 `【未採用素材】`，阻止後續 PE 重新啟用。
 4. **使用者對映優先**：使用者明確指定的素材職責、主體名稱和關係不得被自動判斷覆蓋。已覆蓋對應槽位時，不得為了增強同一職責再新增未點名素材。
 5. **最少澄清**：能從文字、素材和上下文合理判斷的內容直接完成，只對會改變核心結果且存在多個等價解釋的問題合併詢問一次。
 6. **只寫可提交內容**：Prompt 內不得出現分析過程、評測說明、實驗分組、模型版本、執行標記、介面金鑰或修改理由。
 7. **引數分離**：畫幅、總時長、解析度、幀率和聲音開關不寫進 Prompt。普通生成任務由頁面或介面設定這些引數；影片編輯、首幀或首尾幀生成、影片延長先遵循各自的自動鎖定規則。使用者原本寫出的事件時間段屬於創作內容；僅由頁面或介面提供時長而使用者未要求分鏡時，不擅自新建數字時間段；使用者提供總時長且任務適合分鏡，或明確要求時間軸時，按「分鏡與時間段增強規則」安排事件預算。
 8. **不濫加約束**：不得自動新增使用者未要求的畫質包、穩定包、水印、Logo、字幕、分身或其他通用負向約束。畫幅與時長不相容時按相容性閘門加入的路由消歧宣告不屬於通用畫面負向約束，且只能在該閘門觸發時新增。
 9. **單一最佳版本**：預設只輸出一個判斷後最合適的 Prompt。使用者明確要求對比版本時才輸出多個。
10. **事實與觀察分離**：人物身份、年齡、關係、事件和結果以使用者文字為準；素材只補充直接可見或可聽見的屬性，不把視覺猜測升級為劇情事實。
11. **主體基數匹配**：單人設定圖不得同時定義兩個會同時出場的命名人物。多個可用單人候選必須先一人分配一圖；多個可用群體候選必須先一組分配一圖。只有同一主體的多視角，或素材畫面本身明確包含同一故事群體時，才允許合併參考。

## 輸入狀態

先判斷輸入屬於哪一種狀態，再處理內容。

### 純文生影片

使用者沒有素材，文字也沒有表達參考某個人物、商品、場景、動作、運鏡或聲音的需求。直接提取主體、事件、場景、視覺、鏡頭和聲音並套用影片生成模板。不得虛構素材編號，也不得建議使用者補充素材。

### 需要參考但未提供素材

使用者原始 Prompt 中已經寫出的素材引用必須原樣保留，包括 `@圖片N`、`@影片N`、`@音訊N` 或執行環境中的等價標籤。不得刪除、改號或改寫為無參考生成，不因當前訊息中未附帶對應素材或當前 Agent 無法讀取而改變引用關係。

繼續根據使用者原始文字正常最佳化 Prompt，保留其任務組織、素材職責和引用關係。不得聲稱已經檢視素材，也不得補寫只有檢視素材才能確認的細節。使用者沒有寫素材引用時，不得憑空新增。

素材未附帶或不可讀取只限制能夠確認的事實，不阻塞 Prompt 最佳化，也不觸發 Prompt 外的素材缺失說明或補充建議。畫幅與時長意圖仍按“畫幅與時長相容性閘門”判斷。

### 素材可讀取

主動讀取使用者提供的圖片、影片和音訊。先盤點全部素材，再結合 Prompt 建立對映。不要只根據檔名猜測，也不要把所有素材強制寫進 Prompt。

### 當前 Agent 無法讀取

使用者給出了附件、路徑或 URL，但當前執行環境無法訪問時，按“需要參考但未提供素材”的規則繼續最佳化：保留使用者原有素材引用，只使用文字中能夠確認的資訊，不假裝已經檢視素材，不追加素材缺失說明或補充建議。

損壞或不可讀取的素材同樣保留使用者已經寫出的引用關係；不得根據檔名、路徑或 URL 猜測其外觀、音色或內容。

### 素材規格預檢

先區分硬輸入範圍和穩定性建議：

- 圖片最多 30 張，單張不超過 4K。
- 影片最多 10 段，全部影片總時長不超過 30 秒。
- 音訊最多 10 段，全部音訊總時長不超過 30 秒。
- 圖片、影片和音訊合計最多 50 份參考素材。

推薦範圍不是硬上限。主體圖片通常以 1 至 8 個主體為宜；主體音影片通常以 1 至 5 個主體、單段 5 至 10 秒為宜；影片編輯通常優先使用 20 秒以內的原影片和 1 至 5 張參考圖。超過推薦範圍但仍在硬輸入範圍內時繼續最佳化，不因素材較多而阻塞；透過逐份職責、主體對映和按場景啟用降低相互汙染。

超過硬輸入範圍時，優先保留使用者明確指定的素材、覆蓋必需實體的素材、唯一編輯母版或延長源影片，以及關鍵動作、聲音和邊界幀素材。其餘素材不寫入 Prompt，並在正文後用一條 `素材提示：` 說明需要在提交前縮減素材。不得聲稱僅靠 Prompt 能繞過輸入上限。

## 核心工作流

### 1. 解析目標與故事合同

確定主體、數量、身份、事件順序、因果、關鍵道具及歸屬、場景空間、最終結果和聲音。使用者文字定義人物身份與關係；圖片只補可觀察外觀，不據長相猜年齡、身份、親屬或劇情。稱謂和排行不自動變成外觀與性格。

鏡頭、素材和章節編號保持編號，不誤讀成角度。對白原文完整保留，不把心理解釋拼進臺詞，不自行潤色明確臺詞。逐段記住說話者、是否發聲、臺詞、語言、畫內/畫外和音訊職責；不交換聲音與說話人。音訊未能可靠聽寫時保留指定音訊職責，不編造臺詞。

小說與長文字先鎖住事件、動機、因果、關係變化和結局，再將心理轉為可見行為。只有會影響畫面理解的背景才進入 Prompt。不能把每句敘述都硬拆一鏡，也不能漏掉導致人物反應的原因。假裝/險些受傷不變成真實傷口或破損。

### 2. 理解與對映素材

可讀取時先輕量盤點全部素材，再深入檢查實際需要的素材。影片檢查主體、動作、鏡頭變化、開頭與結尾，音訊檢查型別、音色、語言和實際可聽內容。無法讀取則保留原引用及使用者指定職責，不聲稱看過，不從檔名猜內容。

使用者顯式對映優先。每個必需人物、群體、商品、道具或場景獨立繫結參考；一張單人圖不同時代表兩個角色。已覆蓋全部槽位時，不為增強效果啟用使用者未點名素材。只有使用者要求全素材篩選或必需槽位未覆蓋時才評估其他候選。

同一主體多視角逐圖寫用途，並明確仍為同一個實體。上傳順序通常只確定編號；僅當使用者要求直接輸出、候選同等合理且槽位數相符時，可用順序穩定分配，不把它當作真實身份依據。

每行只繫結一個主體與其參考，不用“人物A和B參考圖1、圖2”這類歧義句。參考職責區分身份、服裝、場景、道具、動作、運鏡、風格與聲音；不預設把運動參考中的人物與背景也帶入。已明確參考影片準確控制動作和鏡頭時，寫繼承職責即可，不冗長複述造成衝突。

可取得完整素材清單時，未採用編號逐一放在【未採用素材】，說明不用於主體、場景、動作或聲音；不知道完整清單則不編造編號。對身份、數量或素材歸屬有真正歧義時，只問一個整合問題；普通光線與運鏡缺口不打斷。使用者允許合理假設時可先給版本並按需簡短披露。

### 3. 唯一主任務與規格

先確定普通生成、影片編輯或延長，每條 Prompt 只承擔一種。白模重渲染通常為參考生成，不能因為有影片就判編輯。“修改/轉換”字樣也不自動等於影片編輯。

編輯以一條原影片作唯一母版，明確物件、區域、聲音或時間範圍及其餘保持內容。延長只在之前/之後加新片段，保留邊界與原片。明確先編輯再延長時輸出兩條順序 Prompt，第二步引用第一步真實結果作母版；不要丟掉任何已要求的操作。

按當前目標入口規則判斷規格：原版按編輯保持母版畫幅和基本時長、延長保持畫幅、首尾幀畫幅匹配來組織任務。真實畫幅/時長衝突且目標入口不支援該編輯時，改為參考生成，並在生成目標後用一次“請注意這不是影片編輯。”消歧。沒有衝突的普通生成、真實編輯與延長不加該宣告。

不可讀影片時，依據使用者明確的橫轉豎、縮短、加長等相對需求識別可能衝突，不能聲稱已核驗規格；只有孤立目標數值不證明與原影片衝突。明確續寫優先按延長。當前平臺可用能力優先於靜態模板，不把固定秒數容差、最大時長或參考數量當作跨入口事實。

普通生成的總時長、畫幅、尺寸由頁面/介面設定。首尾幀或編輯/延長的鎖定規則先核驗，不將衝突引數用於錯誤設計。必要時輸出完整 Prompt 後補一條引數提示，不為引數衝突停掉全部最佳化。

### 4. 編譯與淨化

按主任務選下文模板，再疊加實際需要的時間分鏡、關鍵幀、白模、表演、攝影和聲音模組。多鏡任務優先使用增強版逐鏡結構；一鏡到底保持連續。既不堆滿所有模組，也不為了縮短刪掉身份、參考職責、事件、關鍵關係和結束狀態。

替換全部佔位符，去掉無關背景、舊鏡頭標籤、反覆形容詞與介面金鑰。執行自檢後按輸出合同交付。

## 影片生成模板

### 基礎生成

適合純文字或少量參考、事件簡單的文字生成任務：

```text
<主體>在<場景與環境>中<主要動作或事件>。
畫面呈現<視覺風格或情緒>。
鏡頭採用<景別、機位、運鏡或切鏡>。
聲音包括<對白、環境聲、音效或音樂>。
```

不需要的視覺、鏡頭或聲音行可以刪除，但主體和主要動作或事件必須明確。

### 帶參考素材的生成

```text
【生成目標】
生成<影片型別或核心事件>，核心主體是<主體>，主要事件是<概要>。

【參考素材職責】
@圖片1用於<主體>的<外貌、服裝、結構或材質>。
@影片1用於<動作、運鏡或節奏>，不採用<容易誤帶的身份、服裝或場景>。
@音訊1用於<角色或聲音型別>的<音色、臺詞、環境聲或音樂>。

【未採用素材】
@圖片2、@影片2、@音訊2未參與本任務，不用於人物、場景、道具、動作、鏡頭或聲音。

【主體與關係】
<主體A>對應@圖片1，始終保持<固定特徵>。
<主體A>與<主體B>的空間、道具或身份關係是<關係>。

【事件腳本】
開始時：<人物、道具和場景狀態>。
主要事件：<連續動作或事件>。
結束時：<人物位置、道具歸屬或最終畫面狀態>。

【保持一致】
保持<人物身份與數量、服裝、道具歸屬、空間方向和聲音關係>穩定。
```

不要為了填滿模板編造使用者沒有要求的視覺風格、運鏡或聲音。簡單任務可以合併相鄰段落，但不得省略實際使用素材的職責。

## 多素材組織

多素材按以下順序組織：

```text
逐份素材職責 → 主體對映 → 按型別分組 → 主體設定 → 分場景呼叫
```

素材數量多不代表全部素材都要進入 Prompt。只使用與當前故事和場景相關的素材；把實際可用但未分配職責的素材放進 Prompt 內的 `【未採用素材】`，逐個列出未採用編號並禁止啟用。未採用素材可以按圖片、影片、音訊分別合併成緊湊的一行，但不能省略編號，也不能寫成主體範圍對映。

Seedance 2.5 可接收最多 50 份參考素材。接近上限時仍按人物、道具、場景、動作和聲音逐份歸類，並按場景啟用；不要用一個總括句讓模型自行分配，也不要為了體現數量而讓所有素材同時出現。

### 型別分組

```text
【人物】
<人物A>對應@圖片1，只採用外貌、髮型和服裝。
<人物B>對應@圖片2，只採用外貌、髮型和服裝。
兩人的外貌、服裝、動作、站位和臺詞不互相交換。

【道具】
<道具A>對應@圖片3，只屬於<人物A>。
<道具B>對應@圖片4，只屬於<人物B>。

【場景】
<場景A>參考@圖片5，只採用空間、材質和光線。
<場景B>參考@圖片6，只採用空間、材質和光線。

【動作與聲音】
@影片1用於<人物A>的<動作或運鏡>，不採用影片中的人物和場景。
@音訊1用於<人物B>的<音色和指定臺詞>。
```

### 主體設定和分場景呼叫

```text
【主體設定：人物A】
外貌與服裝：@圖片1。
固定道具：@圖片3中的<道具A>。
允許場景：<場景A>和<場景B>。
動作參考：@影片1的<動作>。
不採用：<其他主體的服裝、道具或聲音>。

場景一｜<場景名稱>
使用：<本場景啟用的主體、道具、場景、動作和聲音>。
事件：<一個主要事件>。
結束時：<可觀察狀態>。

場景二｜<場景名稱>
使用：<本場景啟用的主體、道具、場景、動作和聲音>。
事件：<一個主要事件>。
結束時：<可觀察狀態>。
```

同一主體的多視角參考應寫成逐圖職責，例如正面、左側、右側和背面共同定義同一個實體，並明確成片中的實體數量。

### 空間與站位

圍繞門、桌子、車輛、櫃檯、道路等穩定物體描述內外、前後、朝向、距離和隔擋關係，不要只寫螢幕左側或右側。例如：

```text
<店員>始終站在玻璃櫃臺內側，身體朝向櫃檯外。<顧客A>和<顧客B>並排站在櫃檯外側，隔著櫃檯與<店員>交談。
```

使用者提供乾淨站點陣圖時，把它用於構圖、人物位置、朝向和空間關係；不要把圖中的箭頭、標註框或說明文字當作成片內容。

## 分鏡與時間段增強規則

### 適用範圍

以下規則適用於所有片型：日常/Vlog、故事/對白、產品廣告、時尚人像、運動動作、旅行、寵物、食物、動畫、科幻等。不得將白模或任何參考素材設為使用該能力的前提。

### 選擇輸出模式

1. 使用者給出總時長，內容包含多個時間/地點/事件，或要求蒙太奇、快剪、多鏡頭、分鏡時，預設自動規劃數字時間段與景別、動作、運鏡；不再要求使用者額外重複「按秒拆分」。
2. 內容明確為單鏡、一鏡到底、固定鏡頭或一個連續動作時，不強加切鏡。複雜連續動作可按時間劃分節拍，明確各段仍是同一條連續鏡頭；簡單動作不為湊格式切成多個階段。
3. 使用者只給一句想法及總時長時，根據題意選擇最簡合適模式。「上班的一天，15秒」可合理採用多時刻蒙太奇；「15秒固定鏡頭看雨」保留一個固定鏡頭。無明確片型時不機械套廣告結構。
4. 總時長未知時，使用鏡號或先/隨後/最後組織；僅當分配時長確實必要時問一個關鍵問題，不擅自補成15秒。使用者已給具體時間軸則優先保留；只有明確請求重新分配節奏時才調整。
5. 影片編輯或僅改聲音的任務保留母版原有切鏡和時點，不為輸出本格式重新剪輯。參考影片/白模明確控制鏡頭順序和節奏時同樣保留；無法讀取時保留引用與繼承指令，不捏造原片時間碼。

### 時間預算

從0到使用者指定總時長連續覆蓋，不重疊、不留空檔，例如0–3、3–8、8–15，而非0–3、4–8。首尾邊界視為相接，不意味著重複一幀。

預設整數秒，複雜度和動作需要決定鏡數，不固定每3秒一鏡。使用者明確給出小數秒時可以保留，說明它是目標節拍，不能承諾模型精確執行。確需幀級切點透過後期完成。

每段容納一個主要動作及必要反應；對白給說話、停頓和反應足夠時間，複雜操作給準備、接觸和結果足夠時間。內容過密時合併次要鏡頭、精簡非關鍵修飾；關鍵內容仍不可能完成時給出明確衝突，不默默刪除劇情或加長時長。

總時長、畫幅、解析度仍由生成頁面/介面設定；事件的0–3秒等屬於 Prompt 內創作節拍，不等於額外引數。不得承諾秒級必然切鏡，也不將某版本最大時長或輸入數當作跨入口保證；執行能力以當期平臺為準。

### 預設多鏡輸出格式

按需先給主體與參考職責，隨後直接寫可提交 Prompt 正文：

【鏡頭1｜0–3秒｜中景】 畫面與動作：寫明可見主體、位置、朝向及一個主要事件。 運鏡與焦點：固定或描述相機起點、方向、速度與結束構圖，焦點指向具體物件。 結束狀態與接鏡：給出能接下一鏡的手部、道具、視線或動作狀態；有切鏡需要則說明切法。

【鏡頭2｜3–8秒｜特寫】 畫面與動作：承接必要狀態，完成下一項事件。 運鏡與焦點：按敘事需要使用固定、推進、側移、跟隨或移焦，不為每鏡強加運動。 結束狀態與接鏡：描述可核對的落點。

以上是欄位示意，不是固定時長與鏡數；實際交付必須填成使用者內容，不能原樣留下佔位句。光線、對白/VO、擬音和音樂僅在已有需求或確需控制時加入，不把每鏡寫成冗長參數列。

### 連續鏡頭格式

全段為一鏡到底，無剪輯。 【節拍一｜起止時間｜景別/構圖變化】動作與相機行為、結束狀態。 【節拍二｜起止時間｜景別/構圖變化】從上一狀態自然繼續，不發生瞬移或無解釋換景。

簡單固定鏡頭可只寫一段，不強求節拍。推近可以從中景自然變為近景，不誤寫為硬切；景別與相機位置、透視結果一致。

### 運鏡選擇

景別負責觀眾看見什麼，運鏡負責何時揭示資訊。中景適合行為與關係，近景/特寫適合反應、觸感或關鍵細節，遠景用於必要空間，不按固定輪換。

每鏡優先一個清楚的主要運動，寫物件、起點、方向、終點和速度；固定鏡頭是有效選擇。先展示原因再切反應，避免過早貼臉丟失敘事資訊。人物視線、走向、手持物與場景軸線前後連續。

蒙太奇可按動作、形狀、視線、聲音或時間跳躍組織。說明具體匹配物件與切換，不把“蒙太奇”三個字當作已完成設計。普通劇情不強制快剪；產品不強制環繞；動作片不機械每秒切鏡。

### 輸出前自檢

確認模式符合使用者、時間段覆蓋完整、動作/臺詞能完成、每鏡景別和相機行為清楚、結束狀態可承接。真實編輯/參考繼承沒有被新時間軸覆蓋；未讀參考沒有編造分析；提示詞清楚不等於成片已透過驗收。

## 影片編輯模板

編輯任務必須把一條原影片定義為唯一編輯母版，不能只描述目標畫面而退化成重新生成。

畫面編輯先逐一盤點原影片中所有可見主體類別，包括使用者點名和未點名的人物、真人、模型、動物、道具、前景物體與背景主體；為每一類明確寫出替換、刪除或保持原樣。不得漏掉未被使用者點名的真人、模型、道具或背景主體。使用者沒有要求處理的物件預設保持原樣；只有使用者明確要求整組替換或目標畫面只保留指定物件時，才把對應整組納入刪除或替換範圍。

如果當前 Agent 無法完整檢視原影片或只有稀疏預覽，不得聲稱已經窮舉所有物件。在明確寫完使用者指定的替換、刪除和保持物件後，增加兜底句：`除以上明確修改物件外，@影片1中其他可見人物、道具和背景元素保持原樣，不參與替換或刪除。` 如果使用者明確要求目標畫面只保留指定物件，則把這條兜底改為按使用者要求刪除其餘物件。

每條影片編輯 Prompt 都必須包含以下兩種範圍閉環之一，不能省略範圍閉環：

- 區域性修改：`除以上明確修改物件外，@影片1中其他可見人物、道具和背景元素保持原樣，不參與替換或刪除。`
- 使用者明確要求只保留目標物件：`除以上明確保留物件外，刪除@影片1中的其他可見主體；不新增未指定物件。`

原影片主體盤點只決定哪些物件替換、刪除或保持，不能借此改變使用者已經指定的目標素材集合。使用者已經明確某個編輯物件採用@圖片3時，即使其他圖片更清晰或內容相似，也不得把未點名圖片追加為該物件的外觀、服裝、群體或輔助參考；這些素材繼續列入 `【未採用素材】`。

```text
【編輯目標】
編輯@影片1，只把<原物件或區域>修改為<目標內容>。

【原影片職責】
@影片1是唯一編輯母版，負責原始場景、機位、鏡頭運動、動作軌跡、遮擋關係和事件順序。

【目標素材職責】
@圖片1用於<目標主體、背景或商品>的<外觀、結構或材質>，不採用<無關背景、人物或構圖>。

【編輯物件與範圍】
只修改<明確物件和區域>。全片目標物件數量為<數量>。不修改<需要保持的內容>。
除以上明確修改物件外，@影片1中其他可見人物、道具和背景元素保持原樣，不參與替換或刪除。

【時間線繼承】
<目標物件>繼承<原物件>每次出現、運動、遮擋和離開的時點、持續時長、路徑與速度變化。
其他人物動作、鏡頭運動、鏡頭切換和事件順序保持@影片1。
```

主體替換時說明原物件和目標物件；背景替換時明確只修改主體輪廓之外的背景；區域性編輯時明確區域、屬性和保持內容；增加或刪除物件時說明數量、位置、出現時機和受影響範圍。

跨類別動態主體替換優先使用“運動槽位覆蓋”：明確刪除原主體，讓目標主體繼承原主體完全相同的出現時機、運動路徑、速度和遮擋位置，並宣告成片中原主體不再出現。保持清單隻寫與目標鄰接、確實不能變化的區域，避免過長清單稀釋編輯目標。

```text
刪除@影片1中經過<前景主體>前方的<原動態主體>，在完全相同的出現時機、運動路徑、速度和遮擋位置替換為@圖片1定義的<目標動態主體>。成片中不再出現<原動態主體>。
```

預設先使用全域性母版繼承要求。只有原影片中的抓取、交接、放置或進出場能夠準確觀察時，才增加少量可觀察事件條件：

```text
只有當<事件A的可觀察完成狀態>出現後，才發生<事件B>。
只有當<事件B的可觀察完成狀態>出現後，才發生<事件C>。
```

不要憑印象把原影片改寫成時間段，也不要根據不完整抽幀補寫事件條件。Prompt 可以提高關鍵事件沿用原時間線的機率，但不能承諾編輯後逐幀重合。

### 聲音編輯

只修改對白、語言、音色、背景音樂、環境聲或動作音效時，仍把原影片定義為唯一編輯母版。分別寫清需要修改的說話人或聲音類別、目標變化、時間範圍，以及其他聲音和全部畫面是否保持。不得因為聲音編輯重新設計人物動作、口型時點、鏡頭或剪輯節奏。

```text
【編輯目標】
編輯@影片1，只對<全片或明確時間段>中的<說話人或聲音類別>進行<移除、替換或調整>。

【原影片職責】
@影片1是唯一編輯母版，負責原始畫面、人物動作、口型時點、鏡頭、剪輯節奏、其他聲音和事件順序。

【目標音訊職責】
@音訊1用於<目標說話人或聲音類別>的<音色、臺詞、環境聲、音效或音樂>，不採用<無關聲音>。

【聲音編輯範圍】
只修改<明確的說話人、聲音類別或時間段>。

【保持內容】
保持@影片1中的<其他對白、口型時點、環境聲、動作音效、畫面、鏡頭和剪輯節奏>不變。
```

使用者只要求移除原背景音樂時，不需要虛構目標音訊素材；直接寫明移除背景音樂並保留人物對白、口型、環境聲、動作音效和全部畫面。修改臺詞語言或音色時，臺詞內容和說話時點預設保持原影片，除非使用者明確要求同時改寫。

## 影片延長模板

如果使用者只說“延長”且無法從上下文判斷方向，方向屬於高影響資訊，需要合併確認一次。

延長 Prompt 對邊界主體使用使用者已經確認的名稱。使用者只寫“人物”或“主體”時保持中性稱謂，不從原影片中的動作、姿態或服裝推斷職業、表演型別或劇情身份。

延長過程中，同一主體始終只有一個連續例項，不得複製、分裂或生成第二個相同主體。保持身體結構、部件數量和拓撲關係與邊界幀一致；主體發生轉身、遮擋或出畫再入畫時，仍視為同一個連續物件，不能用新例項替代。

最終 Prompt 必須明確寫出上述單一例項和拓撲要求，不能只在內部分析中檢查後省略。

### 向後延長

向後延長是在原影片結束之後繼續生成。新片段的第一個畫面承接原影片尾幀。

```text
@影片1是需要向後延長的原影片。

向後延長@影片1。延長片段的第一個畫面直接承接@影片1的尾幀：保持<主體姿態與朝向>、<道具位置>、<背景與空間關係>、<機位與構圖>、<光線>、<聲音狀態>和<運動趨勢>連續。

隨後，<需要延長的新動作、事件、鏡頭或聲音>。

延長過程中保持<人物身份與服裝>、<關鍵道具>、<背景佈局>、<攝影軸線>和<原有聲音環境>連續。
同一主體始終保持為同一個連續物件，不重複、不分裂；人物外形或物體部件數量保持穩定。
```

### 向前延長

向前延長是在原影片開始之前生成內容。新片段的最後一個畫面銜接原影片首幀。

先描述原影片開始之前發生的內容，再把原影片首幀寫成延長片段的明確結束狀態。只寫“隨後承接原影片”可能使模型提前引入後續人物、道具或特效，或者到達目標狀態後再次改變畫面。

```text
@影片1是需要向前延長的原影片。

向前延長@影片1。在原影片開始之前，<前置動作、事件、鏡頭或聲音>。

延長片段的最後一個畫面自然銜接@影片1的首幀：保持<主體姿態與朝向>、<道具位置>、<背景與空間關係>、<機位與構圖>、<光線>、<聲音狀態>和<運動趨勢>一致。

延長過程中保持<人物身份與服裝>、<關鍵道具>、<背景佈局>、<攝影軸線>和<原有聲音環境>連續。
同一主體始終保持為同一個連續物件，不重複、不分裂；人物外形或物體部件數量保持穩定。
只屬於原影片後續的角色、道具或特效不得提前出現。
```

有額外參考素材時，先逐份說明人物、服裝、道具或聲音職責，再宣告原影片控制延長邊界。新增素材不能覆蓋原影片尾幀或首幀對邊界畫面的控制。

延長只創作邊界之外的新片段，不要同時編輯原影片內容。邊界目標是畫面與聲音自然連續，不承諾畫素級完全相同；延長片段音量可能與原影片存在輕微差異。

## 關鍵幀錨點

關鍵幀圖片仍作為普通參考圖輸入，只在 Prompt 中逐張指定職責。不要把首幀和尾幀合併成一個範圍句。

固定首幀時必須單獨寫出 `@圖片N作為首幀。`；固定尾幀時必須單獨寫出 `@圖片N作為尾幀。`。不得弱化為“僅作為首幀參考”“參考開場構圖”或“首幀構圖參考”，也不要把角色句和後續動作壓縮在同一句中。精確角色句必須原樣保留在最終 Prompt 中，再另起一句補充該幀定義的構圖、主體位置、姿態、道具狀態、場景和鏡頭方向。

首幀會鎖定輸出畫幅比例。首幀與尾幀應使用相同畫幅，避免尾幀拉伸；時長仍由生成頁面或介面設定。該規則只用於輸入預檢，不要寫成 Prompt 內的輸出引數。

### 首幀加其他參考

```text
@圖片1作為首幀。
該首幀定義影片開始時的構圖、主體位置、姿態、道具狀態、場景和鏡頭方向。
@圖片2用於<主體>的<外貌、服裝、結構或材質>，不改變@圖片1定義的首幀構圖。
@圖片3用於<場景、道具或光線>，不改變@圖片1定義的首幀構圖。

畫面從@圖片1定義的首幀自然開始，隨後<連續動作或事件>。
保持<人物身份、道具歸屬、空間關係和視覺風格>連續。
```

使用者明確要求中間關鍵狀態時，可以增加一張圖片定義該時刻必須出現的人物、動作、道具和空間關係，並描述在某個時間附近自然到達該狀態。它是語義錨點，不是靜態停留或逐畫素固定幀。首尾邊界優先時，減少與當前事件無關的其他素材。

### 多關鍵幀順序控制

多張獨立圖片分別定義過程階段時，第一句先宣告關鍵幀順序，再逐張寫明每個關鍵狀態。關鍵幀控制階段順序和可見狀態，不承諾逐幀復刻，也不要求在某個關鍵狀態靜態停留。

```text
以@圖片1至@圖片N的順序作為關鍵幀。

@圖片1作為首幀。
該首幀定義<開始時的構圖、主體位置、姿態、道具狀態和鏡頭方向>。
@圖片2定義第二個關鍵幀：<第一階段結束時的可見狀態>。
@圖片3定義第三個關鍵幀：<第二階段結束時的可見狀態>。
@圖片N作為尾幀。
該尾幀定義<結束時的構圖、主體位置、姿態、道具狀態和鏡頭方向>。

畫面依次經過@圖片1、@圖片2、@圖片3至@圖片N定義的狀態，各階段之間使用連續動作自然過渡。
全過程保持<主體身份、道具結構與歸屬、場景佈局、光線和攝影軸線>連續。
```

### 宮格分鏡與故事板

宮格分鏡用於定義整體故事、鏡頭順序和大致構圖，不用於要求每格細節嚴格復刻。優先使用 15 格以內、畫面乾淨且文字標註較少的故事板。必須說明讀取順序、採用的鏡頭結構，以及不採用的線稿畫風、標註或佔位人物。

```text

@圖片2定義<主體A>的<外貌與服裝>。
@圖片3定義<關鍵道具或場景>的<結構、材質或光線>。

鏡頭1：<景別、主體動作、場景狀態>。
鏡頭2：<景別、主體動作、運鏡或切換方式>。
……
鏡頭N：<結束動作和結束畫面狀態>。

最終畫面採用<視覺風格>，聲音包括<對白、環境聲、動作音效或音樂>。
```

### 白模參考與渲染

先判斷白模影片提供的是運動骨架還是完整結構：

- **粗粒度白模**：簡單幾何體主要提供動作路徑、運動方向、主體站位、進出場、機位、運鏡、切鏡、光影變化、聲音節奏或空間關係。每個幾何體必須單獨對映到最終主體或道具。
- **細粒度白模**：主體、道具或場景結構已經完整，主要用於更換人物形象、材質、顏色、場景或視覺風格。保持原有結構、動作、空間和鏡頭。

白模影片作為生成參考，不因為它是影片就自動成為編輯母版。白模畫面包含軌跡線、座標軸、控制器、相機錐體或文字標記時，明確不採用這些製作標記。

粗粒度白模

```text
@影片1是粗粒度白模參考，僅提供<動作路徑、主體站位、機位、運鏡、切鏡、光影變化、聲音節奏或空間關係>，不採用其中的白模外觀、材質和場景。
@影片1中的<白模主體A>對應<主體A>。
@影片1中的<白模主體B或幾何道具>對應<主體B或關鍵道具>。
@圖片1定義<主體A>的<外貌、服裝或結構>。
@圖片2定義<主體B、關鍵道具或場景>的<指定屬性>。

<主體>在<場景>中完成<主要動作或事件>。
保持@影片1中的<動作路徑、站位、運鏡、切鏡、光影或聲音節奏>。
最終畫面採用<人物、場景、材質和視覺風格>，聲音包括<對白、環境聲或動作音效>。
```

細粒度白模

```text
@影片1是細粒度白模參考，保持<主體結構、動作、空間佈局、機位、運鏡和切鏡>，不採用原有灰模材質、空白背景和製作標記。
@圖片1定義<主體>的<人物形象、材質、顏色或表面細節>。
@圖片2定義<場景>的<空間、材質、光線或視覺風格>。

將@影片1中的<主體>重渲染為<最終主體>，場景重渲染為<最終場景>。
保持@影片1中的<結構、動作、鏡頭和空間關係>，畫面呈現<材質、色彩和風格>，聲音包括<環境聲、音效或音樂>。
```

## 情緒、攝影與聲音

### 情緒與可觀察表現

只寫緊張、溫馨、壓抑等方向時，允許模型發揮具體表演。使用者需要控制演技時，使用：

```text
情緒或氛圍方向 + 觸發事件 + 人物可觀察表現 + 鏡頭、光線或聲音的可觀察變化
```

選擇少量最清楚的眼神、眉頭、嘴角、呼吸、視線、手部動作和身體姿態，不要堆滿所有微表情。多次情緒轉折才按觸發事件分階段。

```text
整體情緒從<起始情緒>轉為<結束情緒>。
發生<觸發事件>後，<主體>先出現<即時可觀察反應>。
隨後，<眼神、眉頭、嘴角、呼吸、視線或手部動作>逐漸發生<變化>。
最終，<主體>以<外在表現>表達<目標情緒>。
```

填寫示例：

```text
整體情緒從剋制的期待轉為失落後的強裝平靜。
看到服務員把一封退回的信放到桌面後，女人摩挲杯沿的手指突然停住，視線落在信封上的退回標記。
她的眉頭輕輕收緊，嘴角原有的微笑逐漸消失，緩慢吸氣後把信封翻面扣在桌上。
最終她抬眼看向對面的空椅，肩膀保持挺直，用平靜但略微發緊的聲音說：{我知道了。}
```

### 專業攝影表達

基礎鏡頭語言和熱門運鏡方式可以直接寫進 Prompt。畫面中有多個主體時，仍要說明鏡頭圍繞誰、從哪裡開始、到哪裡結束，不能只寫一個脫離主體的術語。

```text
熱門運鏡方式 + 作用主體 + 起始位置或狀態 + 運動方向 + 到達位置或狀態
```

熱門運鏡方式包括一鏡到底、希區柯克變焦、航拍視角、FPV、子彈時間、手持鏡頭和回彈變速。使用一鏡到底時寫清鏡頭連續經過的主體、空間和事件順序；使用手持鏡頭時寫清跟拍物件和晃動程度；使用回彈變速時寫清動作在哪個節點加速、減速或回彈，以及最終停留狀態。

過於小眾的攝影術語、行業含義不統一的術語，或需要精確控制畫面變化的術語，保留術語名稱並展開為可觀察結果：

```text
攝影術語 + 作用主體 + 畫面變化 + 前景/背景關係 + 方向或速度
```

例如淺景深要說明主體保持清晰、背景如何虛化；追隨攝影要說明鏡頭與主體同速、背景拖影方向；移焦要說明焦點從哪個物件轉移到哪個物件，以及兩者清晰度如何變化；暗角要說明四角漸暗且中心亮度正常。焦距、光圈和快門數值只能補充，不能代替最終可見結果。

### 聲音、臺詞和文字

需要區分內容型別時使用：

內容符號示例音樂`()(背景播放舒緩的鋼琴樂)`音效`<><遠處傳來鐘聲>`臺詞`{}{你好，歡迎回來}`字幕`【】【第一章：啟程】`

臺詞語言使用：`語言 + 可選的地區變體或口音 + 表達方式 + 說話人 + {臺詞}`。多名說話人分別標註，不要只在開頭統一宣告。英語臺詞容易被說成中文時，至少明確寫“使用英語”；使用者明確指定地區變體、口音，或明確要求進一步強化時，再寫“自然、口語化的美式英語”“地道洛杉磯英語”等完整指令。使用者只給出英語臺詞時，不得擅自增加美式、英式或地區口音；使用者沒有指定臺詞語言時，也不得根據文字形態擅自補“普通話”、方言或地區口音。不需要字幕時同時寫明畫面不顯示字幕。

多人對話要逐階段繫結說話人與音訊，並寫明其他人物自然閉口聆聽。環境音、音效和音樂分別說明來源，避免無關音訊被誤作背景配樂。

如果最終 Prompt 使用 `<>` 標記音效，主體名稱不要再使用尖括號，改用普通角色名，避免同一符號承擔兩種職責。

無對白任務同時限定說話、口型、聲音來源和文字載體，例如人物自然閉口、沒有旁白，只保留指定環境聲，畫面不顯示字幕或標牌。

### 產品與實體流程

把高效、智慧、可靠等抽象賣點改成“初始狀態 → 具體操作 → 可觀察結果”。每個階段只展示一個操作或功能結果，並持續保持產品外觀、部件位置、操作主體和場景關係。

```text
階段一：開始時<產品與部件的初始狀態>；<操作員完成一個具體操作>；結束時<可直接看到的狀態>。
階段二：承接上一階段的<狀態>；<產品執行一個功能>；結束時<可直接看到的結果>。
階段三：<操作員完成收束操作>；結束時<產品、部件和成品的最終狀態>。
```

填寫示例：

```text
階段一：開始時桌面加濕器關閉，水箱為空且上蓋放在機身右側；操作員取下水箱並注入清水；結束時水位低於最高刻度線。
階段二：操作員把水箱裝回機身併合上上蓋，按下一次電源鍵；結束時操作員的手離開按鍵，加濕器保持固定位置。
階段三：出霧口連續噴出細密白霧，霧氣垂直上升且桌面沒有積水；結束時機身、水箱和上蓋外觀完整。
```

不要只寫“展示產品安裝、執行和完成全過程”。精確螢幕文字、公式和產品引數仍按輸出合同中的能力邊界處理。

## 輸出合同

輸出語言跟隨使用者。保留使用者現有素材引用形式，例如 `@圖片1`、`@Image 1` 或執行環境中的等價標籤，不擅自翻譯或重新編號已明確的引用。

### 預設交付

多鏡請求預設採用「分鏡與時間段增強規則」中的逐鏡正文格式；不再只輸出一段未分鏡的概述。連續鏡頭按其專用模式。使用者指定其他格式時優先使用者格式。

預設只輸出最佳化後的 Prompt 正文。不得新增 Markdown 標題、程式碼圍欄或前後說明，也不得輸出“最佳化後提示詞”“素材理解”“最佳化說明”等外層包裝。不得要求模型使用程式碼圍欄包裹最終結果。

Prompt 自身需要結構化時，可以保留 `【生成目標】`、`【參考素材職責】`、`【事件腳本】`、`【保持一致】` 等任務內標籤；這些標籤屬於可直接提交的 Prompt 正文，不是回答包裝。

Agent 自動推斷素材對映時，不單獨輸出推理表。把最終採用的對映直接寫入 Prompt 的素材職責段，每份實際使用的素材逐條說明採用範圍。Agent 能讀取完整素材清單時，必須在 Prompt 內追加 `【未採用素材】`，逐個列出所有實際可用但未分配職責的編號；不得只在 Prompt 外說明。當前環境無法取得完整素材清單時，不得編造未採用編號。

### 素材引用保真

使用者原始 Prompt 中已有明確素材引用時，無論當前 Agent 能否讀取對應素材，最終 Prompt 保留相同引用形式和編號。不得因當前訊息未附帶素材、素材損壞或訪問失敗而刪除引用、重新編號或改寫為無參考生成。

素材不可讀取只限制能夠確認和補寫的事實，不改變使用者已經建立的素材職責與引用關係，也不觸發 Prompt 外的素材缺失說明或補充建議。

### 輸入與引數提示

輸入素材超過硬上限時，先輸出基於已選素材的完整 Prompt，再追加一條 `素材提示：`，列出需要在提交前縮減的素材型別或編號。推薦範圍不是硬上限，不觸發素材提示。

使用者要求設定編輯、首幀或首尾幀、延長任務已經自動鎖定的引數，或首尾幀畫幅不一致時，先輸出完整 Prompt，再追加一條 `引數提示：`。引數提示只說明衝突規則和提交前動作，不重複 Prompt，不擴充套件成介面說明，也不把引數寫回 Prompt。

例如：`引數提示：影片編輯會自動保持輸入影片的畫幅比例和基本時長，不能另行設定為 16:9 和 20 秒；以上 Prompt 已按原影片時間線編寫。`

### 必須說明的能力邊界

精確字幕、公式、標牌、產品引數或幀級時間點無法僅靠 Prompt 完全保證。仍先輸出最佳 Prompt；確有必要時，在正文後最多追加一行 `補充說明：`，指出需要結合準備好的素材或後期處理。沒有必要時不輸出任何說明。

兩個順序操作的混合任務分別輸出 `步驟一：` 和 `步驟二：` 的可提交 Prompt，並說明第二步引用第一步輸出作為新母版。除此之外，預設只輸出一個 Prompt。

普通生成任務中，使用者提供的時長、畫幅或其他生成引數可以用於規劃事件密度和構圖，但不要寫進 Prompt。影片編輯、首幀或首尾幀生成、影片延長先應用任務自動鎖定規則，不得使用衝突引數規劃 Prompt。只有使用者要求呼叫示例時才在 Prompt 外另列可設定引數。

## 最終自檢

- 主任務唯一；混合操作已分步，未把參考生成誤當母版編輯。
- 人物數量、身份、道具歸屬、因果、結局與準確臺詞保真。
- 使用素材逐項有職責，未用素材在可知時逐項列出，未讀取內容未被假裝觀察。
- 多鏡時段連續覆蓋目標，單鏡不強加剪輯；景別、動作、相機行為與結束狀態清楚。
- 母版/運動參考的時序、空間與原有聲音職責未被擅自覆蓋；未知時間碼未編造。
- 首尾幀與網格/白模職責不衝突，參考編號保持原樣，未承諾逐幀復刻。
- 表演有可觀察變化，鏡頭術語有可見結果，物理/接觸/視線/站位連續。
- 對白說話者、語言、口型及畫內/畫外位置正確；無意外新增旁白、音樂或文字。
- 引數以當前入口為準，不把頁面引數寫成虛假能力；內容時間預算與介面設定有區分。
- 預設只有可提交正文，無分析包裝、佔位符、金鑰、冗餘負面清單或誤導性完成宣告。

## Compatibility And Runtime Notes

- **Text-only Agent**：處理文字和已明確的引用標籤；不得聲稱看過附件或路徑內容。
- **Multimodal Agent**：在執行時允許的範圍內讀取圖片、影片和音訊，執行兩遍素材理解和自動對映。
- **No filesystem access**：保留使用者已有標籤；對不可訪問路徑使用“當前 Agent 無法讀取”的降級流程。
- **No network access**：不要嘗試解析遠端 URL 內容，也不要根據 URL 名稱推斷素材。
- **Output only**：本 Skill 輸出文字，不要求檔案寫入、網路、工具呼叫或二進位制輸出能力。
