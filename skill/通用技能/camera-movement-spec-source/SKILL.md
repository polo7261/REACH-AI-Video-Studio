# 运镜规格

## 適用場景

当需要撰写或校验镜头描述时使用：按镜头规格 5 要素输出镜头描述，并在写入节点前自检越轴、空间感铁律、景别衔接、多人同框比例与运镜同风况光影是否协调；其他创作类 Skill 引用本规格执行运镜，不复制正文。

## 輸出

逐条五要素齐全的镜头描述，并附自检结论：是否越轴、是否违反空间感铁律、景别衔接是否成立、多人比例基准是否复核、运镜与风况光影是否协调

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
