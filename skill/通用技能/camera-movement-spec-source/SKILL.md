# 運鏡規格

## 適用場景

當需要撰寫或校驗鏡頭描述時使用：按鏡頭規格 5 要素輸出鏡頭描述，並在寫入節點前自檢越軸、空間感鐵律、景別銜接、多人同框比例與運鏡同風況光影是否協調；其他創作類 Skill 引用本規格執行運鏡，不復制正文。

## 輸出

逐條五要素齊全的鏡頭描述，並附自檢結論：是否越軸、是否違反空間感鐵律、景別銜接是否成立、多人比例基準是否複核、運鏡與風況光影是否協調

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
