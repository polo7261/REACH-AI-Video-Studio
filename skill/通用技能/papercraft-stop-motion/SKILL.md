# 紙藝組裝定格動畫

## 適用場景

適用於歷史、自然、科技、商業、科普、品牌故事、文化傳播、藝術短片等需要獨特視覺表達的內容。透過紙張裁切、分層組裝和定格動畫，將普通敘事轉化為具有手工質感和視覺節奏的紙藝短片。

## 輸出

帶統一旁白的紙藝組裝定格動畫影片。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
