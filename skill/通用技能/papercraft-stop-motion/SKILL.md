# 纸艺组装定格动画

## 適用場景

适用于历史、自然、科技、商业、科普、品牌故事、文化传播、艺术短片等需要独特视觉表达的内容。通过纸张裁切、分层组装和定格动画，将普通叙事转化为具有手工质感和视觉节奏的纸艺短片。

## 輸出

带统一旁白的纸艺组装定格动画视频。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
