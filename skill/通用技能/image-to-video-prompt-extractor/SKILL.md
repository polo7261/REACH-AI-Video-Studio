# 參考圖轉影片提示詞

## 適用場景

當使用者提供 1–7 張參考圖，希望綜合提煉主體、風格、動作、鏡頭與氛圍，並生成可直接用於圖生影片節點的中文提示詞時使用。

## 輸出

預設輸出一條綜合多張參考圖的中文影片提示詞，包含主體場景、鏡頭運動、環境動效、動作表情、光影材質、氛圍和必要約束。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
