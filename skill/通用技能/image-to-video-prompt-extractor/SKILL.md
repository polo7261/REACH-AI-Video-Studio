# 参考图转视频提示词

## 適用場景

当用户提供 1–7 张参考图，希望综合提炼主体、风格、动作、镜头与氛围，并生成可直接用于图生视频节点的中文提示词时使用。

## 輸出

默认输出一条综合多张参考图的中文视频提示词，包含主体场景、镜头运动、环境动效、动作表情、光影材质、氛围和必要约束。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
