# 小杰AIGC｜角色设定图提示词

## 適用場景

适合原创人物、动物、拟人角色、机器人和幻想生物的角色设定；也适合已有角色换装、替换发型或鞋子，以及为后续视频制作统一角色素材。有参考图时分析脸部、发型、服饰和配饰各自的用途；没有参考图时，从文字想法开始设计。

## 輸出

一份可直接复制的完整角色生图提示词，以及实际需要上传的素材与用途说明。默认2K目标、16:9、纯白背景：左40%为头部及半身特写，右60%并排展示无头全身正视图与保留后脑的全身背视图。三个区域保持同一角色、同一套服装。最终产物是提示词；生成图片需另行调用生图模型。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
