# 小傑AIGC｜角色設定圖提示詞

## 適用場景

適合原創人物、動物、擬人角色、機器人和幻想生物的角色設定；也適合已有角色換裝、替換髮型或鞋子，以及為後續影片製作統一角色素材。有參考圖時分析臉部、髮型、服飾和配飾各自的用途；沒有參考圖時，從文字想法開始設計。

## 輸出

一份可直接複製的完整角色生圖提示詞，以及實際需要上傳的素材與用途說明。預設2K目標、16:9、純白背景：左40%為頭部及半身特寫，右60%並排展示無頭全身正檢視與保留後腦的全身背檢視。三個區域保持同一角色、同一套服裝。最終產物是提示詞；生成圖片需另行呼叫生圖模型。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
