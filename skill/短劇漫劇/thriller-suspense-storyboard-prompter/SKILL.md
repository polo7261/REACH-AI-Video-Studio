# 惊悚微恐悬疑分镜模板

## 適用場景

适用于惊悚、微恐、悬疑、都市怪谈、民俗怪谈、规则怪谈、老宅、医院、校园、密室、地下空间、失踪调查等剧情类 AI 视频创作。可将剧本、剧情段落或故事梗概自动拆解为专业视频分镜，重点处理恐怖递进、悬疑留白、人物恐惧反应、空间轴线、门窗与镜面连续性、画外空间、异常信息和前后镜头衔接。适合短剧、短视频、AI漫剧、AI电影感剧情视频等创作场景。

## 輸出

输出一套可直接用于 AI 视频生成的完整惊悚微恐悬疑分镜提示词，包括项目风格、叙事功能、恐惧核心、人物初始状态、固定空间关系、异常连续线、情绪连续线以及逐镜详细提示词。每个镜头包含时间、景别、机位、构图、背景、人物状态、主动作、微动作、双手与道具、台词口型、异常等级、人物与观众信息差、环境动态、声音、运镜及镜头结束状态，并附带统一连续性限制和必要的负面提示词。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
