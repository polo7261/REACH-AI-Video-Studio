# 驚悚微恐懸疑分鏡模板

## 適用場景

適用於驚悚、微恐、懸疑、都市怪談、民俗怪談、規則怪談、老宅、醫院、校園、密室、地下空間、失蹤調查等劇情類 AI 影片創作。可將劇本、劇情段落或故事梗概自動拆解為專業影片分鏡，重點處理恐怖遞進、懸疑留白、人物恐懼反應、空間軸線、門窗與鏡面連續性、畫外空間、異常資訊和前後鏡頭銜接。適合短劇、短影片、AI漫劇、AI電影感劇情影片等創作場景。

## 輸出

輸出一套可直接用於 AI 影片生成的完整驚悚微恐懸疑分鏡提示詞，包括專案風格、敘事功能、恐懼核心、人物初始狀態、固定空間關係、異常連續線、情緒連續線以及逐鏡詳細提示詞。每個鏡頭包含時間、景別、機位、構圖、背景、人物狀態、主動作、微動作、雙手與道具、臺詞口型、異常等級、人物與觀眾資訊差、環境動態、聲音、運鏡及鏡頭結束狀態，並附帶統一連續性限制和必要的負面提示詞。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
