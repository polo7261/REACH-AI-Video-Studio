# 角色無頭三檢視設定卡

## 這個技能做什麼

為**任意人物**生成一張影視/遊戲用的角色設定卡（character turnaround sheet）。固定排版、固定工藝，人物身份完全來自使用者輸入——本技能與任何具體角色題材（如白衣仙俠）無繫結。

## 固定排版（寫死，不隨人物變化）

1. **左側約四分之一**：人物頭部與肩胸近景定妝特寫，完整面部、真人質感。
2. **右側四分之三**：橫向等分為三個**等寬豎欄**，自左向右依次為**正面、左側面、背面**全身檢視。
3. **正面欄與左側面欄 = 無頭素體**：頭部與面部完全不存在，脖頸在衣領上方平切收尾，頸部斷面被衣領自然遮擋；但雙肩、雙臂、雙手、軀幹、雙腿、雙腳全部完整保留，自然直立站姿，雙手垂於身側，腳穿鞋。這兩欄內不得出現任何頭髮、髮絲、發冠或髮飾。
4. **背面欄 = 帶頭部的背面全身檢視**：背對鏡頭站立，保留完整頭部與髮型背影（頭髮自然垂落的後部形態、髮飾後部結構），不露出任何面部五官。
5. **三檢視比例一致性（最高優先順序）**：三欄嚴格同比例、同縮放係數，如同服裝工藝單上的等比三檢視；正交平視視角，無透視變形、無鏡頭推拉、機位距離與焦距完全一致；對齊以身體為準——三欄的肩線、腰線、裙襬下緣（或衣襬下緣）與腳底分別落在同一組水平線上，身形體量完全相同，背面欄在肩線之上額外向上延伸出完整頭部與髮型；任何一欄的身體都不得比其他欄更大或更小。
6. **背景與光線**：純淺灰色攝影棚無縫背景，柔和均勻頂光，地面輕微投影，剪裁、面料與髮型結構細節清晰可讀。
7. **禁止項**（必須逐條寫進 prompt）：禁止任何文字、字母、數字、標註線、水印、Logo、介面按鈕、邊框；**禁止畫面中出現分割線、欄間分隔線、豎線、網格線、白線或任何將三個檢視隔開的線條**（三個檢視之間只靠留白與背景過渡自然分隔）；禁止正面欄與側面欄出現頭部、面部、頭髮、發冠或髮飾；禁止背面欄露出面部五官；禁止三欄身體大小不一、比例不同或透視遠近差異。

## 變數部分（由使用者輸入決定，需引導填充）

- 人物：性別 / 年齡 / 氣質
- 髮型與髮色
- 髮飾
- 服裝款式與結構
- 面料材質
- 配色
- 紋樣細節
- 鞋履

若使用者提供了參考圖，則以參考圖為**唯一人物與服裝依據**，並在 prompt 中註明忽略參考圖內可能存在的播放器介面、關閉按鈕、左右箭頭等任何 UI 元素。

## 技術預設值

- 影象模板：`character_turnaround_3view`（角色三檢視）
- 寬高比：`16:9` 橫版
- 模型：`Lib Image 2.5 Pro`
- 節點 tag：`character`

## 執行流程

1. **接收素材**：拿到使用者的新人物參考圖（若有）或文字描述。
2. **填充變數**：把使用者輸入填進下文的變數槽位；未提供的項可自行合理補全或向使用者確認。若給了參考圖，prompt 中以 `{{參考圖節點key}}` 引用，並寫明忽略 UI 元素。
3. **建立 image 節點**：`tag=character`，掛載 `character_turnaround_3view` 模板，寬高比 `16:9`，模型 `Lib Image 2.5 Pro`，prompt 用下方模板。
4. **申請使用者批准後執行生成**（執行節點需使用者批准）。
5. **生成後自檢**，重點看三處：
   - 是否出現欄間分割線 / 豎線 / 網格線；
   - 正面欄、側面欄是否殘留頭髮、發冠或髮飾；
   - 三欄比例是否一致（背面是否比正側更大或更小）。
   若有問題，**在原節點修正 prompt 後重新生成**。

## 已知易翻車點與對策

- **正/側欄殘留頭髮**：模型會把長髮當角色識別特徵保留。對策：正向描述「這兩欄內不得出現任何頭髮、髮絲、發冠或髮飾」，並在禁止行重複一遍，雙向夾住。
- **背面欄露出五官**：明確「背對鏡頭、不露出任何面部五官」，只描述髮型背影與髮飾後部。
- **三欄比例不一**：靠「等寬三欄 + 正交同焦距 + 肩線/腰線/裙襬/腳底四條同一水平線」三重約束；仍不行時可拆成三個獨立節點分別生成後再排版合成。
- **出現分割線**：禁止行裡逐項列出「分割線、欄間分隔線、豎線、網格線、白線」，並說明只靠留白與背景過渡分隔。
