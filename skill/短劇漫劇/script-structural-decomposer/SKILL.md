# 功能用途

本 Skill 旨在將粗糙的原始劇本進行工廠化拆解，轉化為可直接用於漫劇、短劇製作的拍攝底稿。核心特色在於將演員動作與臺詞徹底解耦，並自動識別分集、場景、人物及情緒，大幅提升前期籌備效率。

# 適用輸入

- 完整長劇本或已分集的劇本片段。
- 格式可包含：txt、word 內容或直接貼上的文字。

# 操作步驟

1. **分集識別**：按劇本標記或情節閉環（約800-1200字）自動切分。每集需提煉核心鉤子與爆點。
2. **場景拆分**：根據地點、時間變化切分場景，標註內外景、日夜及主次場景名。
3. **元素提取**：識別所有角色（主/配/龍套）、關鍵道具及轉場方式。
4. **動作與臺詞解耦**：從描述中提取獨立動作（以“△”開頭），並將臺詞獨立列出，標註對應的極致情緒標籤（如：甜、虐、爽、燃等）。
5. **鏡頭細化**：為每個場景生成景別、運鏡及畫面內容描述。

# 輸出要求

輸出包含三份核心表格，確保欄位完整：

### 1. 分集大綱

包含集數、核心鉤子（≤15字）、本集爆點、卡點情緒及關鍵人物。

### 2. 場景表

包含集-場號、場景名稱、內外日夜、角色、關鍵道具、轉場方式及劇情摘要。

### 3. 鏡頭拆解底稿

- **欄位**：鏡號、景別、運鏡、畫面內容、演員動作（必須以 △ 開頭）、臺詞、情緒標籤、備註。
- **動作規範**：若無明確動作則填“△靜立”或“△注視”，禁止為空。
- **情緒高峰**：針對衝突鏡頭標註“【情緒高峰】建議升格/定格”。

# 注意事項

- 動作必須從臺詞語境中反向拆解（如“冷笑說”拆分為“△冷笑”+臺詞）。
- 缺失的內外景或日夜資訊需根據上下文補全，並標註“\*”。
- 確保每個鏡頭的資訊密度符合短劇快節奏需求。
