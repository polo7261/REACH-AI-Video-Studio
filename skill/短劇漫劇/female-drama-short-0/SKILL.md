# 女性向甜寵短劇 · 單集

## 定位（只負責一件可複用的事 / 不負責什麼）
- 只負責：「女性向甜寵短劇·單集」這一形態——把一個甜寵鉤子，拍成一條有完整情感弧線的 16:9 橫屏短劇片段（分鏡 + 成片）。核心是讓觀眾把自己放進女主位置，體驗「不講道理、為她一人破例」的熾熱偏愛。
- 只負責節奏：**分步產出、逐步確認**——指令碼 → 人物 / 角色板 → 場景色板 → 故事板 → 按分鏡出成片，每一步先給使用者確認、可編輯可回改，絕不一路自動跑到底。
- 只負責成片底盤：一條片內部的**連貫主線、鏡頭縫合、多機位、畫風與色調統一**——這些是"像同一條真劇"的基本盤，由本 skill 鎖死。
- 不負責：多集連續劇與整劇四幕鋪陳（平臺暫不支援多集拆分）；通用拆鏡與錨點一致性機制、模型規格（底座已兜，走預設或聽使用者）；**選哪一種畫風品類**（自由，聽使用者 / 風格層，本 skill 只保證選定後全片一致）；非女性向、非甜寵的題材。

## 它怎麼被用
使用者給一個甜寵設定或只給一句「想要的那種上頭感」，本 skill 分步產出一條單集甜寵短劇：指令碼 → 人物 / 角色板 → 場景色板 → 故事板 → 按分鏡出成片，每一步先確認再往下。

## 輸入（開工前用 `ask_human` 問清，一次一個、用大白話）
- **故事場景 / 背景**：這個故事發生在什麼場景下？時代、地點、行業環境。
- **男女主名字**：男主、女主分別叫什麼？
- **一個開頭**：用一句話說清"開場是個什麼局"就行（如"婚禮上被悔婚"、"入職第一天認錯了大老闆"）。留空則由 Agent 提 1-2 個開頭供使用者選。
- **整體畫風 / 色調基調**：想要什麼調性的畫面（暖金奢華 / 冷調都市 / 柔光膠片…）。這會定成全片統一的視覺基準。說不清就讓 Agent 提一版供選。
- **繫結裝置**：兩人為什麼被迫朝夕相處（先婚後愛、合作契約、權力從屬、破鏡重逢、身份錯位…）。說不清就讓 Agent 按設定定。
- **男女主參考臉**：給 1 張以上真人參考臉（用來混出不存在的虛擬人，全片鎖臉）。
- **人物設定 / 核心鉤子**（可選）：性格外貌、最想要的那個心動瞬間（公開護短 / 醋意質問 / 深夜告白 / 強勢男主破功…）。說不清就讓 Agent 按 knowhow 補一版，補完先確認。
- 不問：用什麼模型、檔案怎麼存—這些底座預設管。**全片畫幅統一 16:9**，**時長不預設**、跟著內容走（見下）。

## 內部流程與 Knowhow（正文主體）

### 分階段推進（鎖死：每一步先出東西、交使用者確認，確認後才進入下一步；使用者沒點頭，禁止啟動下一階段的任何生成）

**階段一 · 立意**
- 用 `ask_human` 把上面「輸入」問齊，一次一個：故事場景、男女主名字、一個開頭、整體畫風 / 色調基調，以及繫結裝置 / 參考臉。缺一項會顯著改變成片的，先問，不猜著往下做。

**階段二 · 出文字指令碼 → 確認**
- 基於使用者給的開頭，用 AI 發散生成短劇指令碼。**時長不框死**——跟著內容走（60、90 秒或更長都行），以把主線講順、情緒做透為準，別為湊進一分鐘砍掉過渡。
- 指令碼一次給齊**四件套**，讓使用者在文字階段就把內容、人、景、調都對齊：
  1. **劇情分鏡**：按下方「單集五步弧線」推進、且是一條「因為→所以」的因果主線（見「連貫性」），含場景標註、人物動作、鏡頭建議，且**每個鏡頭都寫 1-2 句臺詞**（見「臺詞」），靠臺詞把劇情串起來。
  2. **人物形象提示詞表**：每個角色一段可直接喂 `generate_image` 的提示詞（長相、氣質、造型）。
  3. **場景提示詞表**：每個場景一段提示詞，寫清空間 look + **這場戲需要的戲劇地形**（可退的角落 / 能望向的窗 / 第三方出現的門口…，由五步弧線的動作倒推），並標出需要哪幾個機位 / 景別。
  4. **統一視覺基準**：一段全片共用的畫風 / 色調字首（色溫、明度、飽和、光質、影調、鏡頭質感、畫幅），後面每張圖、每個鏡頭都套它。
- 🔒 交使用者確認，給**可操作選項**（如「這版可以，繼續 / 換個更狠的開頭 / 第 X 場改一下 / 臺詞太文縐縐 / 色調換冷一點」），不是開放式甩一句"OK 嗎"。
- 使用者沒確認前，**絕不呼叫任何 `generate_*` 工具**。

**階段三 · 生成人物形象 → 確認 → 出角色識別板**
- 指令碼確認後，用 `generate_image` 按人物提示詞表 + **統一視覺基準字首**，把參考臉混成男女主的虛擬人形象供確認。**不要出白底證件照式的圖**——要能看清臉型、氣質、色調的正經人像（皮膚紋理、自然光、真實質感，不要塑膠假人感；男女主放同一光線、同一視覺基準下生成，後圖參考前圖，避免"一深一淺、不像同一條片"）。
- 🔒 交使用者確認角色：臉對不對 + 氣質對不對 + 色調是否統一（「就用這版 / 換一版 / 男主再清冷點 / 女主更鄰家 / 兩人色調不一致，統一一下」）。**沒確認前不生成角色板、不進下一步。**
- **確認之後**，為每個主要角色出一張 **《角色識別板》**（CHARACTER IDENTITY BOARD，16:9）——這是全片角色一致性的**錨點資產**，後續所有場景圖和影片都以它為身份參考來鎖人鎖造型。**進入角色板生成時，按文末《角色識別板框架》**填入該角色資訊生成。

**階段四 · 生成場景色板（建立並鎖定空間，每場 4 張） → 確認**
- 角色確認後，先把**故事發生的空間釘死**（它是後面排故事板和成片的空間真相源）。按指令碼的場景提示詞表，用 `generate_image` + 統一視覺基準，為每個場景**針對不同位置、不同機位、不同角度各生成 4 張實景色板**（廣角建立 / 中景 / 特寫 / 過肩反打），鎖定這場的空間 look 與戲劇地形（可退的角落 / 能望向的窗 / 第三方出現的門口…），保持同一空間、同一色調一致。
- **進入場景生成時，每個場景按文末《場景色板框架》**填本場資訊生成。
- 🔒 交使用者確認場景與色調。空間定了，故事板才有據可排。

**階段五 · 生成故事板（在確定的空間裡排鏡） → 確認**
- 場景確認後，把兩位角色的**《角色識別板》**作為唯一固定主角、把**已確認的場景色板**作為空間參考，用 `generate_image` 生成一張 **16:9 黑白電影感故事板（12 格導演分鏡）**，在這個確定的空間裡把鏡頭排程、雙角色走位"預演"出來——人和景都是現成錨點，故事板只定"怎麼拍、怎麼走"。
- **進入故事板階段後，按文末《故事板框架》**填本片資訊生成。故事板與成片畫幅一致（全片統一 16:9），成片按其鏡頭排程直接生成，不用再換畫幅。
- 🔒 交使用者確認故事板：分鏡順序、鏡頭語言、走位對不對（「這版分鏡可以 / 第 X 格改機位 / 高潮往後挪」）。**沒確認前不進下一步。**

**階段六 · 按故事板分鏡出成片**
- **嚴格按故事板每一格分鏡逐鏡生成**：以《角色識別板》鎖人鎖造型、以場景色板鎖景鎖色、全程套統一視覺基準。每次 `generate_video` 單鏡 ≤15s，整片由多鏡 `composite_video` 合成（總時長按內容，不受 15s 限制）；`generate_audio` 按指令碼**逐鏡臺詞**配音 + BGM（別隻有配樂沒有臺詞）。按「連貫性」做鏡頭縫合，心動名場面用特寫、慢鏡、淺景深表達五感細節。
- **這條鏈（故事板 → 分鏡 → 逐鏡生成）是把控成片率的核心**：先在便宜的靜態分鏡上把鏡頭和走位定死，再去生成影片，避免直接生成時的失控。

### 連貫性：一條因果主線 + 鏡頭縫合（順滑不割裂）
- **劇情因果**：五步不是五個並列的名場面，是一條「因為→所以」的鏈子——每一步都是上一步的直接結果。寧可少一個轉折，也要主線順；**連貫優先於名場面數量**。
- **給過渡留時間**：時長彈性就是為這個——別為塞進一分鐘砍掉鋪墊和緩衝，情緒要有呼吸。
- **鏡頭縫合**：相鄰鏡頭用「動作接」（上鏡動作沒做完、下鏡接著做）、「視線接」（看向畫外 → 下鏡給到所看之物 / 人）、「聲音先入」（下鏡的聲音提前半秒進）、「同場景多機位順剪」（正反打、景別由遠及近遞進）來銜接，不是硬拼貼。
- **判準**：把相鄰兩鏡連著看，第二鏡的出現是不是"順理成章"？如果像換了個片子，就是沒縫好。

### 臺詞：靠臺詞串劇情，別隻放畫面
- **密度**：原則上**每個鏡頭配 1-2 句臺詞**（對白 / 獨白 / 畫外音），讓劇情靠臺詞往前推，而不是讓觀眾盯著畫面猜發生了什麼。片子不能一直是"配樂 + 畫面"。
- **臺詞幹三件事**：交代資訊（誰、要幹嘛、衝突在哪）、推進因果（這句讓下一步發生）、縫合上下鏡（上鏡尾句拋個鉤，下鏡臺詞接住）——臺詞是繼畫面之後的**第二條縫合線**，和「連貫性」咬合。
- **質量不降**：臺詞短、口語、單句能出圈；是"人會那麼說的話"，不是旁白解說腔、不是為湊數的廢話。
- **留白是例外不是常態**：個別純情緒鏡頭（一個對視特寫、一次怔忪）可以無臺詞，但那是刻意的呼吸點，不是通篇沒詞。
- **配音落原文**：`generate_audio` 按指令碼臺詞逐句配，口語感，避開 AI 電臺腔。

### 全片畫風與色調統一（像同一條片子）
- **定一個視覺基準**（look）：色溫（暖 / 冷）、明度、飽和、光質（自然光 / 黃昏金光 / 影棚硬光）、影調、鏡頭質感、畫幅——在階段二寫成一段所有圖和影片**共用的風格字首**。
- **選擇自由、一致鎖死**：選哪種畫風品類聽使用者 / 風格層；一旦選定，**全片每一張人物圖、每一組場景圖、每一個鏡頭都套這同一套基準**，這條鎖死、不放開。
- **互為參考**：生成多個人物 / 多個場景時，後圖參考前圖的色調與光線，別各調各的。

### 單集五步弧線（指令碼階段照這個寫，串成一條因果主線）
1. **困境開場**：女主開場即陷入具體、可感的困境（被脅迫 / 被羞辱 / 被刁難，三選一或組合）。開場前幾秒就要讓目標觀眾「代入」——這是她的處境，不是背景介紹。
2. **高能解圍**：男主以出人意料的方式登場，用碾壓級方式擺平麻煩。他是女主的退路，不是代理人——所以女主在他出手前，自己已經先開口 / 先還擊了一下，男主是「錦上添花的最後一擊」。
3. **名場面級心動**：全片心動濃度最高的一場戲，混用下面三種彈藥中的至少兩種，做足特寫和留白，讓它「可截圖、可傳播」。
4. **小高潮反轉**：安排一次強勢男主「破功」的人設反轉，或一次醋意升級——製造記憶錨點，也讓甜度有起伏、不發膩。
5. **鉤子結尾**：以一句分量十足的宣示 / 一個曖昧留白 / 一個反轉預告收尾，替代整劇的「加冕禮」，把觀眾的意猶未盡留在最後一秒。

### 心動三彈藥（每片混用，別隻靠一種）
- **接觸型**：失衡時的攙扶、狹小空間的對視、替她撥頭髮 / 擦嘴角 / 系圍巾、告別時的額頭吻。要點：男方動作自然主動，女方反應是怔住或臉紅，不是誇張推拒。
- **臺詞型**：護短髮言、脫口而出的醋意反問、只屬於兩人的專屬稱呼、當眾毫不掩飾的袒護。臺詞要短、要狠、要能單句出圈。
- **行為型**：默默記下她隨口提過的喜好、為她破例下廚、暗中掃清她的職場障礙、吃醋後做出與身份反差極大的幼稚舉動。

### 用五感寫心動（拍出來，不是寫形容詞）
判準：不要生成「他很有魅力」這種畫面，要把魅力拆成鏡頭能拍、觀眾身體能共鳴的細節——
- 視覺：喉結的滾動、似笑非笑的唇角弧度、解袖釦時垂下的眼睫。
- 聽覺：貼近耳廓的低音、一聲短促的輕笑。
- 觸覺：偏涼的指尖劃過皮膚的戰慄、外套殘留的體溫與重量。
- 嗅覺（轉成可見的反應）：他聞到她髮間氣息時的一瞬失神、她被他身上冷香籠罩時的怔忪。

### 男主的落差（每片至少閃現一次，這是最強興奮點）
男主對外界是一套規則（疏離、強勢、滴水不漏），對女主是另一套（耐心、縱容、笨拙、孩子氣）。「全世界只有她能讓他破功」的瞬間——不可一世的人第一次做飯手忙腳亂、能鎮全場的人被她一句話治得服服帖帖、病弱時纏著她像只大型犬——每一個都是記憶錨點，用鏡頭單獨給到。

### 醋意三段式（按片內階段升級，展現獨佔欲）
- 入門：目睹女主與異性交談，眼神驟然降溫，無言離場。
- 進階：直接帶走女主，逼近質問「剛才那位是誰」，距離壓迫感拉滿。
- 大師：表面雲淡風輕，暗地讓情敵寸步難行；或故意製造場面試探她的反應。

### 矛盾怎麼用（判準，不是禁令堆砌）
- 衝突製造者是外部第三方（覬覦男主的對家、捧高踩低的親戚、使絆子的同僚），男女主之間不寫深層價值觀對立。
- 即便有誤會，當面說開，不靠「我不解釋你別問」硬撐——當代觀眾對拉扯零容忍。
- 每一次衝突的落點，都是給男主一個「表演偏愛」的舞臺：有人刁難她 → 男主碾壓級反擊 → 轉化成一次大型心動投放。

## 輸出
一條 16:9 橫屏單集甜寵短劇，時長按內容走：五步弧線串成因果主線、心動高頻、矛盾外接、鉤子結尾，全片畫風色調統一、鏡頭縫合順滑。過程中逐步交付：指令碼四件套 → 人物形象 + 角色識別板 → 場景色板（每場 4 張，釘死空間）→ 故事板（12 格黑白分鏡）→ 按分鏡出成片；每步附對應確認。

## 自檢（這一類片的專屬質量項）
- 開工前是不是先問了**故事場景**和**男女主名字**、拿到開頭和**畫風 / 色調基調**，才動手？
- 是不是**先出文字指令碼（含人物提示詞、場景提示詞、視覺基準四件套）、拿到使用者確認，才開始生成任何畫面**？
- 人物、場景、鏡頭之間**色溫 / 明度 / 影調是否一致**，看起來像不像同一條片、同一場裡的人？（別再出現一深一淺）
- 有沒有一個全片共用的**視覺基準**，並套到了每一張圖和每個鏡頭上？
- 人物確認圖是不是**正經人像**（不是白底證件照）？確認角色後是不是出了**《角色識別板》**，後續場景圖和影片有沒有以它為身份參考鎖人？

- 故事板是不是用**兩張角色板 + 已確認的場景色板**排的 **12 格黑白分鏡**、鎖了空間連續性和雙角色身份？成片是不是**嚴格按故事板每一格分鏡**生成？
- 相鄰鏡頭之間有沒有**縫合**（動作 / 視線 / 聲音 / 多機位順剪），還是硬拼？連著看順不順？
- 是不是**基本每個鏡頭都有 1-2 句臺詞**、靠臺詞把劇情串起來了？有沒有大段只有畫面 / 配樂、沒有臺詞？
- 五步是不是一條**因果主線**（因為→所以），而不是五個並列的名場面？時長有沒有給過渡留呼吸，而不是硬塞進一分鐘？
- 開場前幾秒是不是先讓觀眾代入女主的**具體困境**，而不是先做背景交代？
- 女主遇誤會 / 被欺負，是不是**自己先開口澄清、先還擊**了？男主的出手是「最後一擊」還是替她把事全辦了（後者要改）？
- 男主的落差瞬間有沒有至少閃現一次，並用鏡頭單獨給到？心動是不是落在**可見可聽的五感細節**上，而不是形容詞？
- 衝突是不是來自外部第三方、且當面說開了？男主的強勢是不是建立在**尊重**上——任何輕浮 / 控制 / 越界的畫面一律不出（這條鎖死，不放開）。
- 換一個不同題材的甜寵設定（先婚後愛換成破鏡重逢），這套還成立嗎—還是隻會跑舉例那個？

## 何時問使用者
- **每一階段都必須停下來確認，這不是可選項**：指令碼、人物形象、場景、故事板，各是一道硬門，確認了才進下一步。
- 立意階段：故事場景 / 男女主名字 / 開頭 / 畫風色調 / 繫結裝置 / 參考臉缺失——會顯著改變成片，先問。
- 核心鉤子方向有多個合理選擇且影響開局——給推薦再確認。
- 給選項用 A/B/C/D、標籤用業務動作（如「按這個開頭 / 換個更狠的 / 第 3 場改一下 / 換張臉 / 色調換冷一點」），不暴露內部機制。
- 時長、格式、檔名、工具欄位—Agent 按內容自己定，別問。
