# 女性向甜宠短剧 · 单集

## 定位（只负责一件可复用的事 / 不负责什么）
- 只负责：「女性向甜宠短剧·单集」这一形态——把一个甜宠钩子，拍成一条有完整情感弧线的 16:9 横屏短剧片段（分镜 + 成片）。核心是让观众把自己放进女主位置，体验「不讲道理、为她一人破例」的炽热偏爱。
- 只负责节奏：**分步产出、逐步确认**——脚本 → 人物 / 角色板 → 场景色板 → 故事板 → 按分镜出成片，每一步先给用户确认、可编辑可回改，绝不一路自动跑到底。
- 只负责成片底盘：一条片内部的**连贯主线、镜头缝合、多机位、画风与色调统一**——这些是"像同一条真剧"的基本盘，由本 skill 锁死。
- 不负责：多集连续剧与整剧四幕铺陈（平台暂不支持多集拆分）；通用拆镜与锚点一致性机制、模型规格（底座已兜，走默认或听用户）；**选哪一种画风品类**（自由，听用户 / 风格层，本 skill 只保证选定后全片一致）；非女性向、非甜宠的题材。

## 它怎么被用
用户给一个甜宠设定或只给一句「想要的那种上头感」，本 skill 分步产出一条单集甜宠短剧：脚本 → 人物 / 角色板 → 场景色板 → 故事板 → 按分镜出成片，每一步先确认再往下。

## 输入（开工前用 `ask_human` 问清，一次一个、用大白话）
- **故事场景 / 背景**：这个故事发生在什么场景下？时代、地点、行业环境。
- **男女主名字**：男主、女主分别叫什么？
- **一个开头**：用一句话说清"开场是个什么局"就行（如"婚礼上被悔婚"、"入职第一天认错了大老板"）。留空则由 Agent 提 1-2 个开头供用户选。
- **整体画风 / 色调基调**：想要什么调性的画面（暖金奢华 / 冷调都市 / 柔光胶片…）。这会定成全片统一的视觉基准。说不清就让 Agent 提一版供选。
- **绑定装置**：两人为什么被迫朝夕相处（先婚后爱、合作契约、权力从属、破镜重逢、身份错位…）。说不清就让 Agent 按设定定。
- **男女主参考脸**：给 1 张以上真人参考脸（用来混出不存在的虚拟人，全片锁脸）。
- **人物设定 / 核心钩子**（可选）：性格外貌、最想要的那个心动瞬间（公开护短 / 醋意质问 / 深夜告白 / 强势男主破功…）。说不清就让 Agent 按 knowhow 补一版，补完先确认。
- 不问：用什么模型、文件怎么存—这些底座默认管。**全片画幅统一 16:9**，**时长不预设**、跟着内容走（见下）。

## 内部流程与 Knowhow（正文主体）

### 分阶段推进（锁死：每一步先出东西、交用户确认，确认后才进入下一步；用户没点头，禁止启动下一阶段的任何生成）

**阶段一 · 立意**
- 用 `ask_human` 把上面「输入」问齐，一次一个：故事场景、男女主名字、一个开头、整体画风 / 色调基调，以及绑定装置 / 参考脸。缺一项会显著改变成片的，先问，不猜着往下做。

**阶段二 · 出文字脚本 → 确认**
- 基于用户给的开头，用 AI 发散生成短剧脚本。**时长不框死**——跟着内容走（60、90 秒或更长都行），以把主线讲顺、情绪做透为准，别为凑进一分钟砍掉过渡。
- 脚本一次给齐**四件套**，让用户在文字阶段就把内容、人、景、调都对齐：
  1. **剧情分镜**：按下方「单集五步弧线」推进、且是一条「因为→所以」的因果主线（见「连贯性」），含场景标注、人物动作、镜头建议，且**每个镜头都写 1-2 句台词**（见「台词」），靠台词把剧情串起来。
  2. **人物形象提示词表**：每个角色一段可直接喂 `generate_image` 的提示词（长相、气质、造型）。
  3. **场景提示词表**：每个场景一段提示词，写清空间 look + **这场戏需要的戏剧地形**（可退的角落 / 能望向的窗 / 第三方出现的门口…，由五步弧线的动作倒推），并标出需要哪几个机位 / 景别。
  4. **统一视觉基准**：一段全片共用的画风 / 色调前缀（色温、明度、饱和、光质、影调、镜头质感、画幅），后面每张图、每个镜头都套它。
- 🔒 交用户确认，给**可操作选项**（如「这版可以，继续 / 换个更狠的开头 / 第 X 场改一下 / 台词太文绉绉 / 色调换冷一点」），不是开放式甩一句"OK 吗"。
- 用户没确认前，**绝不调用任何 `generate_*` 工具**。

**阶段三 · 生成人物形象 → 确认 → 出角色识别板**
- 脚本确认后，用 `generate_image` 按人物提示词表 + **统一视觉基准前缀**，把参考脸混成男女主的虚拟人形象供确认。**不要出白底证件照式的图**——要能看清脸型、气质、色调的正经人像（皮肤纹理、自然光、真实质感，不要塑料假人感；男女主放同一光线、同一视觉基准下生成，后图参考前图，避免"一深一浅、不像同一条片"）。
- 🔒 交用户确认角色：脸对不对 + 气质对不对 + 色调是否统一（「就用这版 / 换一版 / 男主再清冷点 / 女主更邻家 / 两人色调不一致，统一一下」）。**没确认前不生成角色板、不进下一步。**
- **确认之后**，为每个主要角色出一张 **《角色识别板》**（CHARACTER IDENTITY BOARD，16:9）——这是全片角色一致性的**锚点资产**，后续所有场景图和视频都以它为身份参考来锁人锁造型。**进入角色板生成时，按文末《角色识别板框架》**填入该角色信息生成。

**阶段四 · 生成场景色板（建立并锁定空间，每场 4 张） → 确认**
- 角色确认后，先把**故事发生的空间钉死**（它是后面排故事板和成片的空间真相源）。按脚本的场景提示词表，用 `generate_image` + 统一视觉基准，为每个场景**针对不同位置、不同机位、不同角度各生成 4 张实景色板**（广角建立 / 中景 / 特写 / 过肩反打），锁定这场的空间 look 与戏剧地形（可退的角落 / 能望向的窗 / 第三方出现的门口…），保持同一空间、同一色调一致。
- **进入场景生成时，每个场景按文末《场景色板框架》**填本场信息生成。
- 🔒 交用户确认场景与色调。空间定了，故事板才有据可排。

**阶段五 · 生成故事板（在确定的空间里排镜） → 确认**
- 场景确认后，把两位角色的**《角色识别板》**作为唯一固定主角、把**已确认的场景色板**作为空间参考，用 `generate_image` 生成一张 **16:9 黑白电影感故事板（12 格导演分镜）**，在这个确定的空间里把镜头调度、双角色走位"预演"出来——人和景都是现成锚点，故事板只定"怎么拍、怎么走"。
- **进入故事板阶段后，按文末《故事板框架》**填本片信息生成。故事板与成片画幅一致（全片统一 16:9），成片按其镜头调度直接生成，不用再换画幅。
- 🔒 交用户确认故事板：分镜顺序、镜头语言、走位对不对（「这版分镜可以 / 第 X 格改机位 / 高潮往后挪」）。**没确认前不进下一步。**

**阶段六 · 按故事板分镜出成片**
- **严格按故事板每一格分镜逐镜生成**：以《角色识别板》锁人锁造型、以场景色板锁景锁色、全程套统一视觉基准。每次 `generate_video` 单镜 ≤15s，整片由多镜 `composite_video` 合成（总时长按内容，不受 15s 限制）；`generate_audio` 按脚本**逐镜台词**配音 + BGM（别只有配乐没有台词）。按「连贯性」做镜头缝合，心动名场面用特写、慢镜、浅景深表达五感细节。
- **这条链（故事板 → 分镜 → 逐镜生成）是把控成片率的核心**：先在便宜的静态分镜上把镜头和走位定死，再去生成视频，避免直接生成时的失控。

### 连贯性：一条因果主线 + 镜头缝合（顺滑不割裂）
- **剧情因果**：五步不是五个并列的名场面，是一条「因为→所以」的链子——每一步都是上一步的直接结果。宁可少一个转折，也要主线顺；**连贯优先于名场面数量**。
- **给过渡留时间**：时长弹性就是为这个——别为塞进一分钟砍掉铺垫和缓冲，情绪要有呼吸。
- **镜头缝合**：相邻镜头用「动作接」（上镜动作没做完、下镜接着做）、「视线接」（看向画外 → 下镜给到所看之物 / 人）、「声音先入」（下镜的声音提前半秒进）、「同场景多机位顺剪」（正反打、景别由远及近递进）来衔接，不是硬拼贴。
- **判准**：把相邻两镜连着看，第二镜的出现是不是"顺理成章"？如果像换了个片子，就是没缝好。

### 台词：靠台词串剧情，别只放画面
- **密度**：原则上**每个镜头配 1-2 句台词**（对白 / 独白 / 画外音），让剧情靠台词往前推，而不是让观众盯着画面猜发生了什么。片子不能一直是"配乐 + 画面"。
- **台词干三件事**：交代信息（谁、要干嘛、冲突在哪）、推进因果（这句让下一步发生）、缝合上下镜（上镜尾句抛个钩，下镜台词接住）——台词是继画面之后的**第二条缝合线**，和「连贯性」咬合。
- **质量不降**：台词短、口语、单句能出圈；是"人会那么说的话"，不是旁白解说腔、不是为凑数的废话。
- **留白是例外不是常态**：个别纯情绪镜头（一个对视特写、一次怔忪）可以无台词，但那是刻意的呼吸点，不是通篇没词。
- **配音落原文**：`generate_audio` 按脚本台词逐句配，口语感，避开 AI 电台腔。

### 全片画风与色调统一（像同一条片子）
- **定一个视觉基准**（look）：色温（暖 / 冷）、明度、饱和、光质（自然光 / 黄昏金光 / 影棚硬光）、影调、镜头质感、画幅——在阶段二写成一段所有图和视频**共用的风格前缀**。
- **选择自由、一致锁死**：选哪种画风品类听用户 / 风格层；一旦选定，**全片每一张人物图、每一组场景图、每一个镜头都套这同一套基准**，这条锁死、不放开。
- **互为参考**：生成多个人物 / 多个场景时，后图参考前图的色调与光线，别各调各的。

### 单集五步弧线（脚本阶段照这个写，串成一条因果主线）
1. **困境开场**：女主开场即陷入具体、可感的困境（被胁迫 / 被羞辱 / 被刁难，三选一或组合）。开场前几秒就要让目标观众「代入」——这是她的处境，不是背景介绍。
2. **高能解围**：男主以出人意料的方式登场，用碾压级方式摆平麻烦。他是女主的退路，不是代理人——所以女主在他出手前，自己已经先开口 / 先还击了一下，男主是「锦上添花的最后一击」。
3. **名场面级心动**：全片心动浓度最高的一场戏，混用下面三种弹药中的至少两种，做足特写和留白，让它「可截图、可传播」。
4. **小高潮反转**：安排一次强势男主「破功」的人设反转，或一次醋意升级——制造记忆锚点，也让甜度有起伏、不发腻。
5. **钩子结尾**：以一句分量十足的宣示 / 一个暧昧留白 / 一个反转预告收尾，替代整剧的「加冕礼」，把观众的意犹未尽留在最后一秒。

### 心动三弹药（每片混用，别只靠一种）
- **接触型**：失衡时的搀扶、狭小空间的对视、替她拨头发 / 擦嘴角 / 系围巾、告别时的额头吻。要点：男方动作自然主动，女方反应是怔住或脸红，不是夸张推拒。
- **台词型**：护短发言、脱口而出的醋意反问、只属于两人的专属称呼、当众毫不掩饰的袒护。台词要短、要狠、要能单句出圈。
- **行为型**：默默记下她随口提过的喜好、为她破例下厨、暗中扫清她的职场障碍、吃醋后做出与身份反差极大的幼稚举动。

### 用五感写心动（拍出来，不是写形容词）
判准：不要生成「他很有魅力」这种画面，要把魅力拆成镜头能拍、观众身体能共鸣的细节——
- 视觉：喉结的滚动、似笑非笑的唇角弧度、解袖扣时垂下的眼睫。
- 听觉：贴近耳廓的低音、一声短促的轻笑。
- 触觉：偏凉的指尖划过皮肤的战栗、外套残留的体温与重量。
- 嗅觉（转成可见的反应）：他闻到她发间气息时的一瞬失神、她被他身上冷香笼罩时的怔忪。

### 男主的落差（每片至少闪现一次，这是最强兴奋点）
男主对外界是一套规则（疏离、强势、滴水不漏），对女主是另一套（耐心、纵容、笨拙、孩子气）。「全世界只有她能让他破功」的瞬间——不可一世的人第一次做饭手忙脚乱、能镇全场的人被她一句话治得服服帖帖、病弱时缠着她像只大型犬——每一个都是记忆锚点，用镜头单独给到。

### 醋意三段式（按片内阶段升级，展现独占欲）
- 入门：目睹女主与异性交谈，眼神骤然降温，无言离场。
- 进阶：直接带走女主，逼近质问「刚才那位是谁」，距离压迫感拉满。
- 大师：表面云淡风轻，暗地让情敌寸步难行；或故意制造场面试探她的反应。

### 矛盾怎么用（判准，不是禁令堆砌）
- 冲突制造者是外部第三方（觊觎男主的对家、捧高踩低的亲戚、使绊子的同僚），男女主之间不写深层价值观对立。
- 即便有误会，当面说开，不靠「我不解释你别问」硬撑——当代观众对拉扯零容忍。
- 每一次冲突的落点，都是给男主一个「表演偏爱」的舞台：有人刁难她 → 男主碾压级反击 → 转化成一次大型心动投放。

## 输出
一条 16:9 横屏单集甜宠短剧，时长按内容走：五步弧线串成因果主线、心动高频、矛盾外置、钩子结尾，全片画风色调统一、镜头缝合顺滑。过程中逐步交付：脚本四件套 → 人物形象 + 角色识别板 → 场景色板（每场 4 张，钉死空间）→ 故事板（12 格黑白分镜）→ 按分镜出成片；每步附对应确认。

## 自检（这一类片的专属质量项）
- 开工前是不是先问了**故事场景**和**男女主名字**、拿到开头和**画风 / 色调基调**，才动手？
- 是不是**先出文字脚本（含人物提示词、场景提示词、视觉基准四件套）、拿到用户确认，才开始生成任何画面**？
- 人物、场景、镜头之间**色温 / 明度 / 影调是否一致**，看起来像不像同一条片、同一场里的人？（别再出现一深一浅）
- 有没有一个全片共用的**视觉基准**，并套到了每一张图和每个镜头上？
- 人物确认图是不是**正经人像**（不是白底证件照）？确认角色后是不是出了**《角色识别板》**，后续场景图和视频有没有以它为身份参考锁人？
- 是不是**先把场景空间钉死**（每场 4 张不同机位色板、同一空间同一色调、含这场需要的戏剧地形），再去排故事板？
- 故事板是不是用**两张角色板 + 已确认的场景色板**排的 **12 格黑白分镜**、锁了空间连续性和双角色身份？成片是不是**严格按故事板每一格分镜**生成？
- 相邻镜头之间有没有**缝合**（动作 / 视线 / 声音 / 多机位顺剪），还是硬拼？连着看顺不顺？
- 是不是**基本每个镜头都有 1-2 句台词**、靠台词把剧情串起来了？有没有大段只有画面 / 配乐、没有台词？
- 五步是不是一条**因果主线**（因为→所以），而不是五个并列的名场面？时长有没有给过渡留呼吸，而不是硬塞进一分钟？
- 开场前几秒是不是先让观众代入女主的**具体困境**，而不是先做背景交代？
- 女主遇误会 / 被欺负，是不是**自己先开口澄清、先还击**了？男主的出手是「最后一击」还是替她把事全办了（后者要改）？
- 男主的落差瞬间有没有至少闪现一次，并用镜头单独给到？心动是不是落在**可见可听的五感细节**上，而不是形容词？
- 冲突是不是来自外部第三方、且当面说开了？男主的强势是不是建立在**尊重**上——任何轻浮 / 控制 / 越界的画面一律不出（这条锁死，不放开）。
- 换一个不同题材的甜宠设定（先婚后爱换成破镜重逢），这套还成立吗—还是只会跑举例那个？

## 何时问用户
- **每一阶段都必须停下来确认，这不是可选项**：脚本、人物形象、场景、故事板，各是一道硬门，确认了才进下一步。
- 立意阶段：故事场景 / 男女主名字 / 开头 / 画风色调 / 绑定装置 / 参考脸缺失——会显著改变成片，先问。
- 核心钩子方向有多个合理选择且影响开局——给推荐再确认。
- 给选项用 A/B/C/D、标签用业务动作（如「按这个开头 / 换个更狠的 / 第 3 场改一下 / 换张脸 / 色调换冷一点」），不暴露内部机制。
- 时长、格式、文件名、工具字段—Agent 按内容自己定，别问。
