# 漫剧分镜创作Agent v8

## 適用場景

需要将故事一键拆解为影视级漫剧分镜，并生成全片锚点集和可直接复制的视频提示词时使用；创作前必须确认画风与画幅；不适合纯文字创作或非视频生成场景

## 輸出

两份可下载MD文档：《锚点集》（角色/场景/道具详细描述+生图提示词）+《分镜总表》（每镜含完整自洽视频提示词，可直接复制用于LibTV/Seedance生成）

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
