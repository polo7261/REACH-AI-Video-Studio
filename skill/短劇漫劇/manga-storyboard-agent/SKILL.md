# 漫劇分鏡創作Agent v8

## 適用場景

需要將故事一鍵拆解為影視級漫劇分鏡，並生成全片錨點集和可直接複製的影片提示詞時使用；創作前必須確認畫風與畫幅；不適合純文字創作或非影片生成場景

## 輸出

兩份可下載MD文件：《錨點集》（角色/場景/道具詳細描述+生圖提示詞）+《分鏡總表》（每鏡含完整自洽影片提示詞，可直接複製用於平台/Seedance生成）

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
