# 劇情短劇分鏡提示詞寫作規範

本 Skill 用於為劇情短劇（以盛唐背景為典型語境）撰寫影片生成提示詞。每次呼叫時，按照以下 11 個欄位依次填寫，輸出一份可直接貼上進影片生成節點的完整提示詞。

---

## 使用前準備

在開始寫提示詞之前，先確認以下資訊已就緒：

- **分鏡場次名稱**（如"入局""出門踩點""拔刀"）
- **本場涉及的所有角色節點 key**（人物定妝圖，含面部/服裝/氣質鎖定）
- **場景/空間節點 key**（室內/室外環境參考圖）
- **道具節點 key**（如屠刀、花車等關鍵道具）
- **音訊節點 key**（配音演員聲線，如有）
- **上一場尾幀節點 key**（用於連續性錨點，如有）
- **本場臺詞文字**（一字不差，含說話人標註；若本場確實無對白，請明確註明"本場無對白"）
- **劇情銜接說明**（上一場結尾狀態 → 本場開場狀態）
- **本場核心戲劇目標**（心理/權力/資訊博弈層面，不是表面動作）

> **⚠️ 開始前必須檢查以下兩項，任一不滿足則暫停：**\*\***① 節點 key 檢查：** 如果使用者未提供任何節點 key（角色/場景/道具均無），**立即暫停**，列出本場需要的節點型別清單（如：主角定妝圖節點、場景環境節點、關鍵道具節點），請使用者補充後再繼續。不得用文字描述替代節點引用，不得填寫佔位符。 \*\***② 臺詞檢查：** 如果使用者未提供臺詞，且未註明"本場無對白"，**立即暫停並詢問**："本場是否有對白？如有，請提供臺詞原文（含說話人）；如確實無對白，請註明，屆時各分鏡臺詞欄填寫'無對白'。"不得自行編造臺詞內容。

## 提示詞模板

### 1. 標題

```
【場次名稱】
```

用分鏡/場次簡稱，直接點明本段戲份。例：`【入局】`、`【出門踩點】`、`【拔刀】`。

---

### 2. SCENE CONTEXT

```
SCENE CONTEXT
時代背景：[朝代/年號語境，如"盛唐開元天寶年間，長安城內"]
時間：[白日/黃昏/夜間，精確到時段]
地點：[具體場所，如"劉三算命鋪內→鋪門口街道"]
劇情銜接：[上一場結尾狀態]→[本場開場狀態]，[承接關係說明]
本場核心戲劇目標：[不是表面動作，而是背後的心理/權力/資訊博弈]
```

**寫法要求：**

- 時代背景不要泛泛寫"古代"，要鎖定具體朝代語境（影響服飾、建築、語言風格）
- 劇情銜接必須寫清楚"從哪裡來、到哪裡去"，讓模型理解場景切換的因果
- 核心戲劇目標要寫人物的內在動機和博弈關係，不要寫"主角走出門"這類表面動作

**示例：**

```
SCENE CONTEXT
時代背景：盛唐開元天寶年間，長安城東市坊間，繁華但暗流湧動
時間：午後白日，陽光斜射
地點：劉三算命鋪內 → 鋪門口 → 王家肉鋪對面街道
劇情銜接：劉三剛接到線報，得知王大頭近日在街上耀武揚威→本場劉三以"出門踩點"為名，實為首次近距離觀察王家肉鋪佈局與人員配置
本場核心戲劇目標：劉三完成對王家肉鋪的空間認知建立，同時保持身份掩護不被察覺，為後續入局埋下資訊優勢
```

### 3. ACTIVE REFERENCES

```
ACTIVE REFERENCES
@{{角色A節點key}} — 鎖定：[臉型/髮式/體型/服裝/氣質，列出不可修改項]
@{{角色B節點key}} — 鎖定：[同上]
@{{場景節點key}} — 鎖定：[空間佈局/光線/建築細節]
@{{道具節點key}} — 鎖定：[道具精確形制]
@{{音訊節點key}} — 鎖定：[聲線特徵]
@{{尾幀節點key}} — 鎖定：[上一鏡結尾構圖，用於本場開場連續性]
```

**寫法要求：**

- 每個引用節點必須註明鎖定的具體內容，不能只寫 `@{{key}}`
- 人物鎖定項至少包含：臉型特徵、髮式、服裝顏色/款式、體型、氣質關鍵詞
- 場景鎖定項至少包含：空間佈局（門窗位置）、主要光源方向
- 道具鎖定項要寫到"精確形制"，避免模型自由發揮
- **節點 key 必須是畫布上真實存在的節點。若使用者未提供節點 key，按「使用前準備」的檢查規則暫停，不得用文字描述或佔位符替代。**

**示例：**

```
ACTIVE REFERENCES
@{{i-DH6U2vm93I}} — 鎖定：劉三，中年男，面容清瘦，頭戴方巾，青灰色布衫，身形偏瘦，眼神沉穩帶算計感，不可改變髮式與服裝顏色
@{{i-PyPe3pi4RD}} — 鎖定：王大頭，壯年男，體型魁梧，絡腮鬍，深色圓領袍，氣質霸道，不可改變體型與鬍鬚形態
@{{i-KVfyRUGZmD}} — 鎖定：王家肉鋪，門面朝南，木質招牌，鋪前有案板，左側掛豬肉，光線從右側街道射入
@{{i-7w50u7Wfsw}} — 鎖定：屠刀，寬背厚刃，刀柄纏黑布，刀身無花紋，長約50cm，不可替換為其他刀型
@{{a-egAZneqYNi}} — 鎖定：劉三配音聲線，中年男聲，略帶沙啞，語速平穩，不急不緩
@{{i-H947hs4DsS}} — 鎖定：上一場尾幀，劉三站在鋪門口，背對鏡頭，視線朝向街道右側，本場開場需從此構圖接續
```

### 4. CONTINUITY RULE

```
CONTINUITY RULE
道具因果鏈：[道具出現/消失的邏輯]
人物出入場順序：[誰先出現、誰後出現、誰始終在場]
螢幕方向穩定性：[人物相對位置，防止越軸]
身份關係穩定性：[層級/關係，如"王大頭（東家）> 掌櫃 > 幫工 > 小二"]
空間連續性：[鏡頭切換時空間邏輯]
```

**寫法要求：**

- 道具因果鏈：每件關鍵道具都要寫清楚"它在哪裡、什麼時候出現、什麼時候可以消失"
- 人物出入場：按時間順序寫，避免模型在某個鏡頭裡憑空多出或少了人物
- 螢幕方向：鎖定主要人物的左右位置，防止越軸
- 身份關係：明確層級，防止模型把掌櫃演成東家

**示例：**

```
CONTINUITY RULE
道具因果鏈：屠刀在王大頭腰間，全程可見刀柄，未經明確拔刀動作不得出現刀身；劉三手中無道具，不得憑空出現摺扇或其他物件
人物出入場順序：劉三全程在場（視角人物）；王大頭在第二鏡出現，第四鏡離開；掌櫃和幫工在王大頭在場時保持低頭忙碌狀態
螢幕方向穩定性：劉三在畫面左側或左前方，王家肉鋪在畫面右側，不得越軸
身份關係穩定性：王大頭（東家）氣場壓制所有人，掌櫃見到王大頭需有明顯低頭/側身禮讓動作
空間連續性：從算命鋪內切到街道，鋪門始終在畫面左後方，街道縱深向右延伸
```

### 5. FORMAT

```
FORMAT
總時長：[秒數，通常18–24秒]
剪輯模式：Timed multishot（多鏡頭定時剪輯）
語言：中文對白，半文言但通俗，不用現代網路用語
NO項：
- 無旁白
- 無字幕
- 無英語
- 無配樂煽情（不得在對白段落加背景音樂）
- 無背景群眾雜聲（除非明確寫入AUDIO欄位）
- 無特效（無光效爆閃、無慢動作濾鏡）
```

**寫法要求：**

- 總時長要與 CAMERA/EDITING 裡各分鏡時間碼加總一致
- NO 項要具體，寫清楚"不要做什麼"

---

### 6. CAMERA/EDITING

```
CAMERA/EDITING
[整段鏡頭排程邏輯概述：情緒或權力轉折的起承轉合，2–3句話]

時間碼分鏡：
0.0s–Xs｜鏡頭1｜[場景/位置]
  FOV：[焦距/視角]
  景別：[特寫/近景/中景/全景/大全景]
  動作：[可拍到的身體/手/物件/視線，具體到部位]
  臺詞：[見下方臺詞填寫規則]
  表演要點：[心理狀態描述，不用抽象形容詞]
  剪輯標記：[HARD CUT / MATCH CUT / 無]
```

**臺詞填寫規則（三種情況，必須區分）：**

情況處理方式使用者提供了臺詞原文一字不差填入，含說話人標註，如 `劉三：「今日天氣不錯。」`使用者明確註明"本場無對白"所有分鏡臺詞欄填寫 `無對白`使用者未提供臺詞，且未註明無對白**立即暫停，詢問使用者**："本場是否有對白？如有請提供臺詞原文；如確實無對白請註明。" 不得自行編造任何臺詞。

**寫法要求：**

- 先寫整段排程邏輯概述，讓模型理解這段戲的情緒走向
- 每個分鏡必須包含：FOV、景別、動作、臺詞、表演要點
- 表演要點用可觀察的行為描述，不用"緊張""激動"等抽象詞
- 時間碼要連續，各鏡頭加總等於 FORMAT 裡的總時長
- HARD CUT 用於場景/情緒突變；MATCH CUT 用於動作/視線的連續性剪輯

**示例（節選）：**

```
CAMERA/EDITING
整段排程邏輯：從劉三主觀視角的"觀察"切入，逐步推近王家肉鋪，在王大頭出現的瞬間完成權力關係的視覺建立；全段保持劉三的冷靜旁觀基調，不用快切製造緊張感，用景別推進代替情緒煽動。

0.0s–3.5s｜鏡頭1｜算命鋪門口，劉三背對鏡頭
  FOV：35mm廣角，平視
  景別：中景
  動作：劉三站在鋪門口，右手搭在門框上，視線朝向街道右側，身體未動
  臺詞：無對白
  表演要點：劉三的視線是"掃視"而非"盯視"，像在看街景，不讓旁人察覺他在觀察特定目標
  剪輯標記：無

3.5s–7.0s｜鏡頭2｜街道，劉三主觀視角→王家肉鋪正面
  FOV：85mm中長焦，平視，輕微手持晃動模擬主觀視角
  景別：全景→中景（緩慢推進）
  動作：鏡頭從街道人流中穿過，落在王家肉鋪招牌上，停留，再緩慢下移到鋪前案板
  臺詞：無對白
  表演要點：鏡頭運動要"剋制"，推進速度慢，像一個有經驗的人在不動聲色地記錄空間
  剪輯標記：MATCH CUT（接劉三視線方向）
```

### 7. PERFORMANCE LOCK

```
PERFORMANCE LOCK
[角色A]：
  不要演成：[過火/型別化的錯誤方向]
  而要演成：[正確的表演基調]
  關鍵動作邊界：[具體動作的上限]

[角色B]：
  不要演成：...
  而要演成：...
  關鍵動作邊界：...
```

**寫法要求：**

- 每個有臺詞或重要動作的角色都要寫
- "不要演成"要具體指出型別化陷阱
- "而要演成"要給出可操作的替代方向
- "關鍵動作邊界"要寫清楚動作的上限，防止過火

**示例：**

```
PERFORMANCE LOCK
劉三：
  不要演成：偵探片裡的神探，眼神銳利、動作誇張、明顯在"調查"
  而要演成：一個出門散步的算命先生，漫不經心，偶爾停步，像在想事情
  關鍵動作邊界：視線停留在王家肉鋪不超過2秒，隨即自然移開；不得有摸下巴、皺眉等"思考"的程式化動作

王大頭：
  不要演成：臉譜化的反派，一出場就凶神惡煞
  而要演成：一個習慣了被人怕的地頭蛇，威壓是自然流露的，不需要刻意表演
  關鍵動作邊界：說話時音量正常但語氣篤定；不得有拍桌子、指人鼻子等誇張動作
```

### 8. AUDIO

```
AUDIO
環境聲：[真實存在的環境聲]
道具聲：[關鍵道具的聲音]
呼吸/氣息：[關鍵情緒節點的呼吸處理]
臺詞音量處理：[關鍵臺詞的音量/混響]
明確排除：
  - [不要出現的聲音]
  - [不要出現的聲音]
```

**寫法要求：**

- 只列真實存在於場景中的聲音，不要寫"配樂烘托氣氛"
- 道具聲要具體到"什麼道具、什麼動作、產生什麼聲音"
- 明確排除項要具體

---

### 9. LIGHTING

```
LIGHTING
色溫：[如"4800K，偏暖白"]
主色調：[如"暗部青綠墨藍，亮部暖膚色，整體低飽和"]
光源方向：[主光來源與方向]
特殊光效：[如"輕微bloom/halation，高光邊緣有輕微暈散，非HDR過曝"]
穩定性要求：基礎光效不因劇情緊張程度改變，不得在對峙場景突然壓暗或加紅光
```

**寫法要求：**

- 色溫和色調在整個系列裡保持一致（固定為4800K + 青綠墨藍暗部 + 暖膚色）
- 明確寫出"不因劇情緊張而改變基礎光效"
- bloom/halation 是這套風格的標誌性光效，每場都要寫

---

### 10. ENDING FRAME

```
ENDING FRAME
構圖：[具體描述結尾停留的畫面]
人物位置：[各人物在畫面中的位置]
道具狀態：[關鍵道具的最終狀態]
情緒基調：[這個結尾畫面傳遞的情緒]
下一場銜接提示：[這個尾幀如何作為下一場的連續性起點]
```

**寫法要求：**

- 結尾幀要具體到"誰在哪裡、做什麼、看哪裡"
- 道具狀態要寫清楚，確保下一場引用時有據可查
- 下一場銜接提示是給下一條提示詞的寫作者看的，不是給模型的指令

---

### 11. NO/LOCKS（彙總禁止項）

```
NO/LOCKS
視覺禁止：
  - 不要英語字幕或英語文字出現在畫面中
  - 不要現代元素（手錶、眼鏡、現代建築）
  - 不要憑空生成未在 ACTIVE REFERENCES 中引用的道具
  - 不要誇張表情（哭泣、大笑、瞪眼）
  - 不要特效（光效爆閃、粒子、慢動作濾鏡）
  - 不要改變角色服裝顏色或髮式

表演禁止：
  - 不要型別化的"壞人表演"（獰笑、陰險眼神）
  - 不要型別化的"好人表演"（無辜眼神、委屈表情）
  - 不要過度肢體語言（指手畫腳、誇張手勢）

音訊禁止：
  - 不要背景音樂
  - 不要旁白
  - 不要現代音效（電子音、合成器）

敘事禁止：
  - 不要在單條提示詞裡跨越超過3個場景
  - 不要讓未出場角色的聲音出現在畫面外
```

```
SCENE CONTEXT

```

## 使用說明

1. **每次只寫一個場次**，不要把多個場次合併進一條提示詞
2. **臺詞必須一字不差**；若本場無對白，請在輸入時明確註明"本場無對白"；若未註明，將暫停詢問，不自行編造
3. **ACTIVE REFERENCES 裡的節點 key 必須是真實存在的節點**；若未提供任何節點 key，將暫停並列出所需節點型別清單，不用文字描述替代
4. **CONTINUITY RULE 要在每場之間保持一致**，特別是螢幕方向和道具狀態
5. **LIGHTING 色調在整個系列裡固定**，不要因為場景不同而改變基礎色調
6. **ENDING FRAME 是下一場的起點**，寫完一場後立即記錄尾幀狀態，供下一場引用
