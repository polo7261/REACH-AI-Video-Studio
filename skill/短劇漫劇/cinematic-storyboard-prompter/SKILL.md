# 分镜提示词

## 適用場景

用于把短剧本、分镜表、镜头清单或已有画面设定，转换成一份可直接复制到图像生成工具中的电影感分镜图提示词。适合短视频、短漫剧、广告和剧情片段的前期可视化。

## 輸出

输出一份完整、可直接复制使用的分镜图提示词，按 P01、P02…逐格描述景别、机位、当前动作、人物关系、场景、光线与必要的参考图绑定；信息不足时先列出需补充项。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
