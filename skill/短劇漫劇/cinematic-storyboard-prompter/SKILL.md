# 分鏡提示詞

## 適用場景

用於把短劇本、分鏡表、鏡頭清單或已有畫面設定，轉換成一份可直接複製到圖像生成工具中的電影感分鏡圖提示詞。適合短影片、短漫劇、廣告和劇情片段的前期視覺化。

## 輸出

輸出一份完整、可直接複製使用的分鏡圖提示詞，按 P01、P02…逐格描述景別、機位、當前動作、人物關係、場景、光線與必要的參考圖綁定；資訊不足時先列出需補充項。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
