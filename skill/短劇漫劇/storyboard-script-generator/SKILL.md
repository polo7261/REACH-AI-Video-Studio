# 分鏡腳本生成器
## Skill 定位
- 只負責：把"想做個XX影片"的模糊需求，轉成可直接AI生成/拍攝的逐秒分鏡
- 不呼叫繪圖/影片模型，只產出文字，零額外積分成本
## 輸入
- 主題 / 時長 / 風格（三項必填）
## 內部流程和 Knowhow
- 按"前3秒鉤子→展開→收尾"三段切秒數
- 每鏡：鏡號 / 秒數 / 畫面描述 / 旁白 / BGM類型 / 音效
- 畫面描述可直接喂MJ/即夢出圖，附工具建議
- 自檢：所有鏡頭秒數之和 = 總時長
## 輸出
- 逐秒分鏡表（文字）：鏡號 / 秒數 / 畫面 / 旁白 / 音樂
- 末尾附「可複用資產清單」：本片可直接複用的MJ提示詞 × N、BGM類型 × N、鉤子模板 × 1
## 自檢
- 總時長對齊、每鏡含畫面+旁白、前3秒有鉤子
## Ask User
- 風格或時長缺失時，先問再生成
