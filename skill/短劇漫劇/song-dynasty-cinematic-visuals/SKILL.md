# 宋韻國風影片 · 公開版

作者：**Sim**

以真實古裝電影攝影為視覺目標，讓環境有空間、人物有身份、光影有來源、材料有觸感。既能創作完整影片，也能準備後續製作需要的場景與角色圖片。

## 先確定這次交付什麼

沿用使用者已有主題、人物、畫幅、時長和模型。根據用途選擇工作流，不把影片提示詞擷取一段當作所有圖片的提示詞。

| 請求 | 主要任務 | 讀取資料 |
|------|----------|----------|
| 主題、場景提案、故事 | 給具體世界、人物關係和事件；按使用者所需深度交付本文與視覺語言 | — |
| 場景底圖、環境資產、空鏡 | 讓場所結構、視點和行動空間成為主體 | 圖片資產與模型適配 |
| 角色、定妝、人物資產、角色多角度 | 先固定身份、臉、髮式和服裝，再派生所需角度 | 圖片資產與模型適配 |
| 帶人物的劇情圖、影片首幀 | 一個可見時刻，交代人物位置、動作物件和下一步 | 空間圖片資產與模型適配 |
| 分鏡、Seedance 等影片提示詞 | 可見的事件、動作交接、人物反應與時間銜接 | — |
| 影片創作覆盤 | 已有影像或成片，看實際結果，優先修影響目標的少量偏差 | 檢查與修正 |

“場景圖”若未說明帶人，先按環境為主體設計；純場景底圖不新增主角。使用者明確要人物活動時保留它，不能一律清空人群。若使用者只要一張圖片，就給一張的提示詞，不自動擴成定妝包或分鏡。

關鍵用途或參考關係不清楚時，只問影響結果的一兩項；其餘條件可簡短說明假設後繼續。模型只是平臺標籤時，不擅自判定底層版本。先提供可用的正文，再處理依賴平臺能力的設定。

## 貫穿影像與影片的視覺原則

1. **具體光源。** 寫清天光、窗光、鋪簷或其他場景光源如何照亮人物和環境。柔和中保留方向與明暗，不把全部陰影抹平。
2. **柔潤而可辨。** 近處有皮膚、衣料和器物細節，遠處隨距離自然變柔。適度空氣透視與亮部過渡，不靠濃霧、泛白或大片金光。
3. **空間隨用途安排。** 場景資產優先讀清建築、水路、道路和物件位置；角色資產優先讀清臉與衣裝；劇情幀優先讀懂人物當下的關係。
4. **材料各有反應。** 絲織物、粗布、木材、陶器、溼土和水面有不同反光、重量與紋理，衣服不統一變成透光薄紗。
5. **服裝服務身份。** 具體說明領口、袖型、衣層、繫帶、裙或褲的結構，避免只寫“古風美女、白衣、飄逸”。不預設年輕女性、宮廷華服、固定畫幅或固定景別。
6. **生活與表演有因果。** 劇情裡人物有動作物件與可讀反應；定妝資產允許自然正面站立和看鏡頭，不為了“抓拍”犧牲可複用性。
7. **畫幅本身承載影像。** 預設無生成字幕、標題、水印和額外電影黑邊；文字需要時另按使用者要求設計。

具體構圖、光影與材質見視覺語言。靜態資產與劇情鏡頭可以使用不同景深和燈光安排，不能強制每張都側逆光、大光圈、大前景虛焦。

## 生圖交付必須完整

先給一句用途與主要畫面決定，再給使用者能獨立複製的最終提示詞。Image、Banana、Midjourney 三路共用同一套內容約束，但按各自寫法組織；使用者點名哪幾種，就交付哪幾種。

- Image：自然語言寫清主體、構圖、空間、光影與材料，按需要短分段。
- Banana：自然語言說明參考素材各自負責什麼、哪些特徵保留、當前只生成或修改什麼；沒有附件時輸出完整文生圖正文。
- Midjourney：常規生圖優先緊湊英文畫面描述，重要主體和景別前置；編輯模式另用明確修改指令。正文與可選設定分開，不能只給引數或泛化審美詞。

可按需參考場景圖片示例、角色資產示例、劇情關鍵幀示例。這些是試跑起點，不表示每種模型的最終出圖都已驗證。

## 影片創作保留完整排程

影片仍按風格與環境 → 人物和道具初態 → 分鏡/時間段 → 動作、接觸、反應與末態 → 聲音 → 連續性要求組織。不給靜態圖寫完整時間軸，也不把影片壓縮成一張定妝照。

鏡頭數、總時長、情緒和關係服從故事，不強制溫情、贈物、微笑或大景開場。需要完整影片示例時，選擇花市《贈春》或田園《春野一盞》。

## 交付邊界

只要創作文字時，不自動執行生成、編輯或釋出。工具、引數和參考圖只使用實際存在且當前入口支援的項；不虛構圖片編號、圖片地址、固定身份能力或已透過的生成結果。

圖片完成前檢查“是否滿足資產用途”；影片完成前檢查“事件、空間與時間是否成立”。視覺風格不等於歷史考據，要求嚴格復原時再核查具體時期、地區和物件。沒有原始提示詞與設定時，不從一組失敗圖反推確定的模型原因。
