# 10大風格錨點圖片生成器

## 適用場景

當使用者手頭有小說章節、劇本或短劇大綱，需要把裡面出現的所有角色、場景/環境、道具，轉化為可直接用於AI影象/影片生成的高精度視覺設定，防止後續批次跑圖/跑影片時出現"角色崩臉""場景色調不一致"等連續性問題時使用。也適用於專案已經開始生成、但發現角色或場景在不同鏡頭間對不上，需要重新建立統一視覺基準的返工場景。

## 輸出

一份結構化視覺錨點文件：專案風格總綱 + 角色/場景/道具三張錨點表，每項包含核心特徵、服裝道具細節、多視角提示語和可直接複製貼上的完整prompt；如當前環境接入了可用的生圖工具，還會直接跑出對應的定妝圖，供後續所有分鏡生成複用同一套人設與場景基準。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
