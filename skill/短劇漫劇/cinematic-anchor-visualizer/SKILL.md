# 10大风格锚点图片生成器

## 適用場景

当用户手头有小说章节、剧本或短剧大纲，需要把里面出现的所有角色、场景/环境、道具，转化为可直接用于AI图像/视频生成的高精度视觉设定，防止后续批量跑图/跑视频时出现"角色崩脸""场景色调不一致"等连续性问题时使用。也适用于项目已经开始生成、但发现角色或场景在不同镜头间对不上，需要重新建立统一视觉基准的返工场景。

## 輸出

一份结构化视觉锚点文档：项目风格总纲 + 角色/场景/道具三张锚点表，每项包含核心特征、服装道具细节、多视角提示语和可直接复制粘贴的完整prompt；如当前环境接入了可用的生图工具，还会直接跑出对应的定妆图，供后续所有分镜生成复用同一套人设与场景基准。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
