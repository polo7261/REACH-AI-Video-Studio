# AI繪圖Prompt最佳化器
## Skill 定位
- 只負責：把使用者的大白話描述翻譯成MJ/即夢能直接用的專業英文Prompt
- 純文字輸出，不呼叫繪圖模型，零額外積分成本
## 輸入
- 中文描述（如"一個穿黑風衣的男人站在雨裡"）
- 風格偏好（如"電影感/國潮/賽博"）
- 用途（如"人物立繪/場景/產品"）
## 內部流程和 Knowhow
- 解析使用者描述的核心元素：主體+環境+光影+構圖+色調
- 補充專業引數：--ar --style --v 等
- 提供3個變體（不同構圖/色調/氛圍）
- 附中文釋義，讓使用者知道每段英文的作用
## 輸出
- 3組最佳化後的英文Prompt（含引數）+ 中文釋義 + 風格關鍵詞
- 末尾附「Prompt調參指南」：常用引數說明及適用場景速查
## 自檢
- 每組Prompt含主體+環境+光影+構圖+引數、英文語法正確
## Ask User
- 描述或風格缺失時，先問再生成
