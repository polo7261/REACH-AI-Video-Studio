# 霸总狗血剧

## 適用場景

适合快速创作20-45秒竖屏霸总短剧，尤其适合“霸总爱上XX的我”、狗血台词、无厘头反转、短视频剧情等场景。用户不需要上传参考视频，只输入一个主题也能使用。

## 輸出

先输出剧情方案、角色设定和分镜表供用户确认；用户确认后，继续生成锚点图和最终竖屏短剧视频。默认不加字幕，除非用户明确要求字幕版。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
