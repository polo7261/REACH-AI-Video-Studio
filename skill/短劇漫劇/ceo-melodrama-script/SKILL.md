# 霸總狗血劇

## 適用場景

適合快速創作20-45秒豎屏霸總短劇，尤其適合「霸總愛上XX的我」、狗血臺詞、無厘頭反轉、短影片劇情等場景。使用者不需要上傳參考影片，只輸入一個主題也能使用。

## 輸出

先輸出劇情方案、角色設定和分鏡表供使用者確認；使用者確認後，繼續生成錨點圖和最終豎屏短劇影片。預設不加字幕，除非使用者明確要求字幕版。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
