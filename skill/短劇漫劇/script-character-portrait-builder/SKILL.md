## 核心原則

1. 禁止生成明星臉、影視同款角色、真實人物復刻臉，全部角色五官、骨相原創設計，無撞臉風險；
2. 嚴格區分有對話角色 / 無臺詞群演，輸出劇本中所有對話角色和無臺詞群演的獨立人設的角色；
3. 所有角色統一遵循固定構圖規範：全身正面、九頭身、190cm 身高、雙手自然垂於身側、無手持道具 / 武器、純灰純色背景、無地面投影、無表情；\
   畫面左側是人物全身三檢視+右側面部正面特寫，背景無接縫。
4. 人設適配短劇當下主流審美，妝容、服飾貼合短劇賽道熱門風格，不使用廉價影樓風、誇張二次元造型；
5. 人設分層邏輯固定：風格定調→角色核心屬性→年齡性別→短劇熱門妝容→成套服裝 + 配套鞋子→視覺光影氛圍細節→硬性構圖畫質約束；
6. 五官遵循「一主記憶點，兩輔助五官」設計邏輯，每個角色具備專屬辨識度，避免全部五官精緻同質化；
7. 提示詞結構標準化，多角色分開獨立輸出，格式清晰可批次複製；
8. 不新增多餘劇情動作、手部道具，嚴格鎖定全身正面立繪要求，

## 使用者輸入資訊

使用者需提供以下內容，缺失項自動結合短劇主流人設補全，不生成網紅化畸形五官：

1. 完整短劇劇本（分集 / 單集均可，包含人物臺詞、角色名、人設標註）

2. 劇本題材（都市甜寵 / 豪門復仇 / 古風仙俠 / 民國虐戀 / 校園逆襲 / 科幻短劇等）

3. 可選補充要求：角色額外氣質（清冷 / 腹黑 / 溫柔 / 桀驁 / 溫婉等）、專屬配色偏好、特殊身份配飾

   若使用者未補充題材 / 氣質，自動根據劇本對話語境推導角色身份與氣質。

## 工作流程

### 第一步：劇本拆解 & 對話角色篩選

通讀完整短劇劇本，逐條識別所有出現的所有角色，整理角色清單：

- 所有對話的角色和無臺詞群演（包含僅出場無任何對話的路人、傭人、背景群演、無名龍套等）；
- 標註每個角色核心身份（男主 / 反派 / 女主 / 白月光 / 管家 / 豪門長輩 / 古風王爺等）；
- 提取角色性格氣質、人物定位、劇中身份標籤；
- 統計角色數量，為每個角色單獨建立一套獨立人設繪圖提示詞。

### 第二步：風格定調匹配題材

根據短劇題材統一整體畫風基調，貼合當下短劇商業攝影寫實風：

- 都市豪門短劇：高階真人商業寫實質感，輕奢光影，低飽和高階配色；

- 古風短劇：古風寫實影視定妝質感，柔和國風柔光，莫蘭迪古風配色；

- 民國短劇：復古膠片人像質感，柔和暖調光影，復古大地色系；

- 校園短劇：清新生活化寫實，乾淨柔光，淺馬卡龍低飽和色系；

- 科幻短劇：未來科技寫實，冷調幹淨光影，銀灰 / 淺藍主色系；

  統一基礎風格：真人寫實，短劇影視級角色立繪，拒絕卡通、二次元、厚塗手繪。

- 

### 第三步：角色主體屬性構建（核心物件 + 年齡 + 性別）

1. 核心物件：標註角色名 + 劇中身份定位（如豪門腹黑男主、溫婉嫡女、職場復仇女主）；
2. 年齡感：根據劇本人設匹配標準年齡區間（18/22/25/30/35/40+）；
3. 性別：男 / 女，統一固定身高標準：190cm，九頭身比例，全身人體結構標準協調，無畸形拉伸。

### 第四步：適配當下短劇熱門妝容設計

分性別、題材匹配 2026 短劇主流妝容，規避網紅濃妝、過度假面妝：

女性角色通用熱門妝

清透低飽和底妝，保留原生皮膚紋理，弱化厚重遮瑕；淡野生眉，細淡內眼線不誇張上揚；低飽和豆沙 / 裸粉唇釉，淡淡收縮色腮紅，無誇張亮片閃片；古風搭配淡胭脂眼妝，民國搭配復古啞光紅唇，豪門搭配極簡裸妝。

男性角色通用熱門妝

偽原生男士淡妝，乾淨啞光底妝遮蓋痘印，無厚重磨皮；眉形利落平直，淡修容勾勒骨相，無眼影；淺裸色潤唇，無油光，乾淨少年 / 成熟男士質感。

### 第五步：成套服裝 + 配套鞋子搭配

貼合角色身份、短劇題材設計完整穿搭，上下裝成套（符合角色的高雅的有設計感的服裝），搭配同風格適配鞋履，服裝不遮擋全身身形，凸顯九頭身比例：

- 都市豪門男：符合角色的高雅的有設計感的服裝(如：高定西裝 / 垂感休閒襯衫 等)+ 西褲，搭配符合服裝的鞋；

- 都市女主：輕奢連衣裙 / 簡約通勤套裝（服裝符合歷史和影視劇的審美需求），搭配符合服裝的鞋；

- 古風角色：制式古風斜襟長衫 / 襦裙/（服裝符合古風劇/仙俠劇/影視劇的審美需求），搭配複合服裝的鞋；

- 民國角色：中山裝 / 改良旗袍等服裝（服裝符合歷史和影視劇的審美需求），復古小皮鞋、粗跟布鞋、符合服裝的鞋；

- 校園角色：簡約校服 / 休閒衛衣套裝（服裝符合歷史和影視劇的審美需求），小白鞋、帆布鞋、符合服裝的鞋；

  約束：服裝簡約不繁雜，不堆砌誇張配飾，重點突出人物身形。

### 第六步：視覺要素（色彩光影 + 氛圍 + 細節）

1. 色彩：整體低飽和主色調，1 個主色 + 3 個輔助色，配色協調不衝突，注意冷暖對比；
2. 光影：均勻柔和影棚柔光，無硬陰影、無地面投影，面部光線均勻通透，保留輕微骨相層次；
3. 氛圍：乾淨剋制、無故事氛圍感，純人設立繪，簡約高階，無雜亂場景；
4. 細節：髮絲層次清晰，面料紋理真實，皮膚肌理自然，服飾走線、紐扣、布料褶皺細節完整。

### 第七步：統一硬性構圖 & 人物約束（強制固定）

所有角色提示詞強制植入統一硬性要求，不可刪減：

全身正面完整立繪，從頭到腳完整呈現，身高 190cm，標準九頭身比例；人物自然筆直站立，雙手自然垂落緊貼身體兩側，手上無任何物品、不持武器、不拿道具；眼睛有神，但全程無表情，面部平直無笑意、無挑眉、無冷邪神態；純色純灰色背景，背景乾淨無雜物；地面無人物影子；正常膚色，皮膚通透自然；畫面無多餘肢體動作，不歪頭、不側身、不抬手、不交叉手臂。

### 第八步：畫質統一標準

超高 8K 畫質，商業人像攝影，85mm 人像鏡頭，淺景深，高畫質細節，銳化自然，無損人像，原生皮膚毛孔清晰，髮絲根根分明，人體結構標準，無畸形肢體，面部結構穩定統一，原創人物無撞臉。

### 第九步：分角色生成完整正向提示詞 + 專屬負面提示詞

每個對話角色獨立分組，正向提示詞完整覆蓋「風格定調 + 角色主體屬性 + 年齡性別 + 短劇熱門妝容 + 成套服裝 + 配套鞋履 + 視覺色彩光影氛圍細節 + 硬性構圖約束 + 畫質要求」；
