## One Xianxia Base Style + One Optional Primary-Color Line (Distilled in Stage 1, Unified Across the Entire Film)

The entire film uses one set of rendering foundation (extreme epic scale, white-jade super-megastructures for architecture-bearing locations, mirror symmetry, cinematic aerial perspective); **scene images do not apply a style seed — consistency is maintained by repeatedly applying the same shared style description text**; **the final tonality of the entire film is governed by the user-confirmed set of scene images**, and character images / prop images / video generation must all align with the color tone of the selected scene images. From the script's emotional register, further distill one primary-color sentence to attach to the scene-image prompt.

- **Shared style description (common base for scenes and Seedance, applicable to any location, condensed version, Chinese)**: `Eastern-mythology megastructuralist cinematic imagery. Clear pale cyan-blue sky, clouds kept neutral to slightly white, with an optional restrained pale-gold backlit rim outline on the right side; no overall warm-orange filter. Extreme long shot or strong-perspective composition; characters or near-foreground elements occupy only 0.3%-0.8% of the frame height. Four layers of aerial perspective — foreground, midground, distant haze, extreme distance — volumetric clouds, cinematic photorealistic texture, HDR, 8K detail, structurally credible with true physical weight, vast in scale.`
- **Architecture clause (appended only when the location's script setting includes architecture/palaces/halls; never applied to architecture-free locations)**: `A Hanbaiyu white-marble super-megastructure building or heavenly palace rising out of a sea of clouds, the architecture occupying more than 60% of the frame height or even running past the edge; colossal walls, dark timber beam frameworks, tiered dougong brackets, broad flying eaves, restrained gilding — never fully gilded.`
- **Scene-image additional appendage**: `85-100mm medium-telephoto compressed space (or 50-70mm for a stronger one-point perspective; choose one of the two as composition requires)`, appended after the shared description (+ the architecture clause, if applicable), then followed by that location's own terrain/environment details (e.g., ice fields, bamboo groves, deserts, etc. — see the scene-list descriptions) and the primary color. **Interior scenes** (sect main-hall interiors, cave-abode interiors, etc., which belong to the "with architecture" category) reuse the same lighting/tone/cinematic-texture language; their sense of scale is rendered according to the interior space's own dimensions, without forcing "super-megastructure" scale.
- **Seedance lead-in style sentence additional appendage**: `Live-action cinematic film texture, wide-sleeved garments drifting in the wind, slow-motion overcrank at battle/emotional climaxes, extreme-wide compositions keeping characters at a very small proportion of the frame when they walk through megastructure corridors or halls, smooth camera movement but shot changes only via hard cuts, no transition effects of any kind.`, placed as the first sentence of the Seedance prompt, right after the shared description.
- **Optional primary-color tendencies (appended after the base description; pick one sentence or write your own)**: ethereal-immortal cool tones "pale jade, moon white, misty cyan"; heavenly-fire warm tones "molten gold, crimson lightning, deep-purple storm clouds"; blue-green landscape "mineral green, azurite blue, warm golden sunset"; demonic netherworld "blood red, mystic black, sickly green miasma".

## Fixed Seeds and Image-Generation Specs (Quick Reference)

- **Scene/tonality images = Midjourney V8.2** (**this version must be specified; if Midjourney V8.2 cannot be connected, the only fallback is V8.1 — do not use any other version or any other tool**), **no style seed applied** (no `--sref`/`--profile`), wide shots with no people and no props, zero text. **Each location gets 1 set of 4 images**, pick one of four. Prompt = shared style description (universal) + **the architecture clause appended only if the location contains architecture — never appended for architecture-free locations** + scene-image additional appendage + the location's own terrain description + primary color + aspect-ratio requirement (written in words, e.g., "16:9 horizontal composition") + condensed negative words (written as plain text in the prompt body, without the `--no` prefix; architecture-free locations do not need architecture-related negatives such as "no ordinary small palace as a substitute" — include or omit them per the scene's actual situation; universal negatives such as: no oversized figures, no thick-fog occlusion, no overall orange filter, no text/watermark/logo) + **the tail string keeps only** `--v 8.2` (switch to `--v 8.1` if V8.2 is unavailable; no other flags). **The entire prompt (description sentences + negatives + tail string) ≤ 1024 characters**; if it exceeds the limit, trim only the description sentences and leave the key negatives and the tail string untouched; the architecture description appears only when needed; **consistency relies on fully applying the same shared style description text every time + aligning toward the tonality of the chosen scene images**.
- **Character + three-view sheets = Seedream 5.0 Pro** (character-only): all characters generated in one pass — per character, **one 16:9, single pure-white continuous canvas** containing 4 sets of front-facing full-body looks (**full body must be in frame — no half-body or big-head shots**; the entire outfit combo + hairstyle/hair ornaments clearly different; changing only the robe color while everything else stays the same is forbidden), **no divider lines/borders between the four sets; visually one continuous white-background photograph rather than four stitched images** → one-time pick-one-of-four confirmation → the chosen image is fed in as the reference image to generate only the missing side/back views, producing a **16:9 single pure-white-background three-view sheet, laid out in one of two ways depending on whether an original face exists**: **No original face (Case1 faceless/Case3)** → left side is a front-facing large-head close-up (close head-and-shoulders shot) + right side a full-body three-view (front/side/back side by side), the whole sheet continuous with no stitching seams, the face kept visible (the face is the identity); **With an original face reference (Case2)** → **output only the full-body three-view (front/side/back side by side), without the left-side large-head close-up panel**, the head area **completely covered by a circular sticker**, with **small text noted in the bottom-right corner** (in the user's language) "face provided separately · for costume reference only"; identity is locked on the Seedance side via the original face image/video. **Pick-one-of-four rendering presets (must be stacked, emphasizing cinematic-grade rather than short-drama feel)**: anti-oily skin `matte realistic skin, visible pores, no retouching, subtle film grain`; cinematic feel `cinematic film still, filmic contrast, luminous colour grade, movie-grade cinematography`; film-grade casting and styling `a real film-actor face with dignified screen presence, NOT a modern idol/K-beauty/short-drama influencer face, no glass-skin filter, no heavy web-drama makeup, natural film-grade styling`; layout positive-word supplement `single seamless white background canvas, no panel dividers, no borders between poses, continuous studio photograph, not a collage`. Maintain the **cast sheet**. Seedream has no `--sref`; consistency relies on the character card + reference images.
- **Prop Anchor Image = Lib Image** (only generated for core props requiring cross-shot locking; **generated independently, without referencing character or scene images as references**, based directly on the prop card's text description): a single continuous 16:9 canvas on a pure white background, containing the prop's complete front view + three-view details (front/side/back; magical treasures may add 1–2 corner-placed close-ups of patterns/mechanisms), with no sense of separately stitched panels. Layout prompt (i2i, English base): `pure white seamless background, product-style photography, single continuous canvas with no panel dividers; main panel shows the exact prop large and centred (front view); to the right, smaller side and back views; add close-up insets for intricate details if present; replicate every detail 1:1, do not redesign; no text, no watermark`. Maintain a **props sheet**: prop name / owning character / 【Locked/Unlocked】 / three-view image link.
- **Video = Seedance 2.5 (mandatory, must not be replaced with any other version)**, maximum **30s** per run; internal shot changes use hard cuts only, with no transition effects or subtitles generated. Inputs = scene images of the locations involved in that segment (multiple for cross-location, one for a single location, including indoor scenes) + **the same three-view image** for each character (locking face + costume) + **the same three-view image** for each locked prop (unlocked props get no image, conveyed via text) + (when an original face exists) the original face image as an identity anchor.

## Workflow (Pause for Confirmation at Each Stage)

### Stage 0 · Pre-Shoot Question Card (asked all at once, no pausing item by item)

One card asks 4 items (**character styling, props, and spoken language are not asked here; Stage 1 will extract them automatically when parsing the script**):

1. **Script/Text**: A complete script? A one-sentence idea (drafted from it)? Or no idea at all? After upload, Stage 1 automatically parses characters/props/scenes/language. **If there is no script/idea at all, first ask the user for the desired style and tone** (e.g., xianxia romance, xianxia combat/hot-blooded action, xianxia mystery/revenge, xianxia growth/enlightenment, xianxia homeland-and-righteousness, etc.; multiple choices allowed or the user may write their own), **then draft a short xianxia script based on that tone + the user's supplementary fragments**; if a one-sentence idea already exists, draft directly from it without asking about tone again.
2. **Subtitles**: Yes/no; if yes, choose Simplified/Traditional/English/bilingual (Stage 6 will add them directly according to this, without asking again).
3. **Aspect ratio**: List 16:9/4:3/1:1/9:16 equally with no recommendation; the user must choose.
4. **Duration**: 30s/60s/90s/custom (fill in the blank, e.g., 150s → rounded up to the nearest 30s, split into 5 segments).

> **Resolution is not asked; defaults to 720p**. Draft the script (characters/sects/scenes/beat reversals/sound division, fitting the established style and tone; hooks such as tribulation-crossing ascension, magic treasure acknowledging its master, sect grand tournament, mystery of one's origins, heavenly tribulation countdown, demonic path invasion, past-life reincarnation, spiritual root awakening, etc. may be mixed in) → user confirms → proceed to Stage 1.

**Three Cases for Character Styling (asked only when Stage 1 produces the character list, not here)**: Case1 has a styling reference image → generate from the reference image + supplemented spec, no original face, three-view = left large head close-up + right full-body three-view; Case2 has a face but no styling → face reference + supplemented spec, original face carried into Seedance for face locking, **three-view produces only the full-body three-view (no large head close-up panel), with a circular sticker covering the head + small-text annotation in the bottom-right corner**; Case3 has neither → supplement the spec based on the script's identity/sect/gender and generate directly, no original face, three-view = left large head close-up + right full-body three-view, the face itself is the identity. All three cases require cinematic-level casting and makeup/styling, avoiding short-drama influencer faces.

**Xianxia Ancient-Style Costume Language (used when supplementing specs; dynasty not locked, by gender)**: Female `flowing wide-sleeve hanfu or Taoist robe, silk ribbon sash drifting, layered cloud-shoulder cape, jade or gold hairpin, flowing high bun`; Male `Taoist/cultivator robe with wide sleeves, waist sash with jade pendant or sword tassel, topknot with jade or wooden hair crown`; Common `real silk/brocade/gauze textures with natural drape, no contemporary fabric/cut/accessories`. Identity and sect may fine-tune colors and patterns (demonic path leans darker, righteous path leans plainer and brighter), without altering the styling baseline.

### Stage 1 · Script Parsing + Final_Video_Spec

Read the full text and parse it into a narrative structure + three tables for characters/props/scenes; **output the tables and pause once, without generating any images**.

- **Deduplicate and merge**: Entities appearing repeatedly are merged into a single entry, with supplementary descriptions folded into the final description.
- **Insufficient information requires stopping to ask; do not guess-fill**: Entries missing appearance descriptions are marked **⚠️Information insufficient**, listing the specific questions needing supplementation; design for that entry begins only after the user supplies the information; "complete" entries are unaffected.
- **Output format**: First report "Detected X characters/Y scenes/Z props," with a one-sentence narrative structure (number of beats by duration: 30s takes 1–2 beats, 60s takes 2–3 beats, and so on incrementally); character table (number/name/appearance scenes/identity-sect-relationship-appearance/status), prop table (number/name/owner/appearance/appearance description/locking decision/status), scene table (number/name/appearance/indoor or outdoor/**contains architecture or not**/environment description/dedicated establishing shot or not/status). **The scene table must include all indoor scenes appearing in the script**, and must not omit indoor scenes merely because they make it harder to convey a sense of monumental scale. **"Contains architecture or not" is judged from the script's description of that location**: palaces, halls, long corridors, cave abodes, etc. fill in 【Contains architecture】; purely natural environments such as wilderness, ice fields, mountains and rivers, bamboo forests, oceans, etc. fill in 【Does not contain architecture】—this decides whether to append the architecture clause when generating images in Stage 3.
- **Prop locking decision**: Life-bound magic artifacts, key tokens, and repeatedly appearing weapons default to 【Locked】; one-off set pieces and group background props default to 【Unlocked】; when unsure, default to unlocked.
- **Spoken language**: Defaults to the language the script itself is written in; only append one question when it is mixed/unclear.
- **Face reference image question** (asked here, not in Stage 0): For the character list, ask "Do you have any face reference images/videos you'd like to designate? If not, original designs will be created based on the script + xianxia costume language (cinematic-level casting); after the first version is confirmed, it serves as the consistency baseline for all subsequent stages."
- **Line-by-line distillation of narration/inner monologue/dialogue**: Displayed together with the three tables—narration (third-person storyteller, covering background/cause-and-effect/time jumps), inner monologue (first-person emotion), dialogue (mark the speaker; if verbose lines are condensed into punchy short sentences, this must be stated and confirmed), sound division per beat (narration/monologue/dialogue/overlapping), emotional reversal tone, and one sentence on the dominant color tendency.
- **Batch processing**: If any category of characters/props/scenes exceeds 8, automatically split into batches of ≤8, in order of first appearance, with the batching plan noted below the tables; **affects the pacing of Stages 2/2.5/3**—pause once after each batch is done to ask whether to continue, unless the user says no batch-by-batch confirmation is needed.
- **Final_Video_Spec**: Aspect ratio (Stage 0 question 3) / resolution (default 720p) / duration (Stage 0 question 4, in 30s segments).
> Pause for confirmation (three tables + status annotations + face-reference-image inquiry + spec, all paused together at once).

### Phase 2 / 2.5 / 3 · Character · Prop · Scene Asset Generation (three lines launched in parallel; confirmation order unchanged)

> **The three production lines (characters/props/scenes) may launch generation calls simultaneously to save time**, independent of and not referencing one another; however, **the order for showing results to the user and confirming them one by one still follows 2→2.5→3**, and the confirmation rhythm must not be thrown off just because generation runs in parallel. Any category exceeding 8 items follows the Phase 1 batching plan; after each batch is done, pause once to ask whether to continue.

**Phase 2 · Character Design (Seedream 5.0 Pro)**: write a character card for each character → generate the pick-one-of-four look sheets for all characters together (**16:9, a single continuous pure-white-background canvas, all 4 looks must show the full body in frame**, clearly distinct, cinematic casting baseline, no stitching seams) → one-time pick-one-of-four confirmation → with the selected image as the reference input, only regenerate the side/back, then generate all turnaround views together (16:9, single pure-white-background canvas with no stitching seams; **characters without an original face** = large head close-up on the left + full-body turnaround on the right; **characters with an original face** = full-body turnaround only, head covered by a round sticker + small-text annotation in the lower-right corner) → verify face/costume item by item; if drift occurs, re-supplement using the selected image; if drift repeats, composite into a combined plate → one-time confirmation of all turnarounds. Maintain the cast sheet; when costumes change, produce a new version.

> The four looks must be clearly differentiated in overall outfit combination + hairstyle (e.g., ① formal Taoist robe with a high topknot ② battle armor with tied-up hair ③ plain-colored ruqun with loose hair and a flower hairpin ④ ornate ceremonial gown with elaborate hair ornaments); it is forbidden to change only the robe color while leaving everything else unchanged; facial features and makeup must carry a cinematic quality, avoiding influencer faces / short-drama looks; **the image must be a single continuous white background — no four-grid or three-grid feel created by columns/borders/stitching**.

**Phase 2.5 · Prop Design (Lib Image, needed only for locked props, fully independent of character images/scene images)**: [Unlocked] props are skipped and left to be brought in via text at the storyboard/scene stage; [locked] props are generated item by item — write a prop card (material/pattern/dimensions/key mechanisms) → **generate directly from the prop card's text description, without referencing any character turnaround or scene image** → generate all locked props at once on a single continuous pure-white-background canvas (front view + turnaround detail views, no stitching seams) → one-time confirmation (verify material, pattern, proportions) → if there are deviations, regenerate side/back from the front view. Maintain the prop list. Props added midway are supplemented at any time.

**Phase 3 · Scene Tone Images (Midjourney V8.2, or V8.1 if unavailable; no style seed applied)**: generate all together per the scene list (do not finish one scene and then start the next): each location (indoor scenes included) gets **1 group of 4 images**; **use the corresponding template according to "whether architecture is included" in the scene table** — [with architecture] append the shared style description + the architecture clause + that location's own details; [without architecture] append only the shared style description + that location's own terrain details (wasteland, glacier, bamboo forest, etc.), **never force-applying the architecture clause**; append the main color + aspect-ratio text description (e.g., "16:9 horizontal composition") + a tail string containing only `--v 8.2` (`--v 8.1` if unavailable); **keep the prompt concise (≤1024 characters)**. **Scene images are generated as panoramas per "location" — one group per location, reused across shots and segments; a video segment may involve multiple locations, with no restriction that each 30s maps to only one scene image**; do not generate separate images for close-ups/partial views — those are left to Seedance to frame on the same panorama; the number of groups = the number of deduplicated locations (indoor included). Dedicated empty-shot locations are specially marked in the scene list. **Once all are generated → pause once to let the user pick one of four per location** (labeled 1 top-left / 2 top-right / 3 bottom-left / 4 bottom-right) → proceed to Phase 4 only after all are collected; it is strictly forbidden to move on without the pick-one-of-four. **Once a scene image is finalized, its tone becomes the tonal baseline for the entire film**, and all subsequent character/prop/video generation must align with its color texture.\
**Once all are generated → pause once to let the user confirm per location** (if satisfied, it passes; if unsatisfied, the user may point out issues and have that one image for that location regenerated, with no pick-one-of-four) → proceed to Phase 4 only after all confirmations are collected.

### Phase 4 · Storyboard Tables (must be produced before video generation; requires confirmation)

**Produce all storyboard tables in one go** (per the number of segments; do not pause after each segment), one table per segment, with columns: Shot No. / Duration / Shot Type (empty shot / mega-structure figure camera move / close-up / other) / Picture (staging, performance, composition) / **Prop Anchor** (the prop-list number used in that shot, for binding to the prop turnaround) / **Scene Anchor** (the scene-table number of the location where that shot takes place, for binding to the scene image) / Sound Layer (narration · monologue · dialogue, original text + tone) / Motion. **Transitions are uniformly hard cuts; no transition column is set**. The "Shot Type" column takes one of four values: pure empty shot / mega-structure figure camera move / close-up / other — **each segment must contain at least 1 pure empty shot and at least 1 mega-structure figure camera move, and neither may substitute for the other; shots whose Sound Layer is "dialogue" default to close-up in the Shot Type column** (to show the speaking character's expression and lip movements; do not by default use empty shots / mega-structure figure camera moves to render dialogue moments), while the remaining shots alternate between close-ups and extreme long shots as the plot requires, avoiding an entire segment crammed with extreme long shots. For empty-shot rows, the Picture column only describes landscape staging, the Sound Layer may be left blank with only ambient sound effects, and the Prop Anchor is left empty; for mega-structure figure camera-move rows, spell out the character's concrete staging and proportion within the long corridor / grand hall / sky bridge.\
Below the table, attach a **continuity bible** (not part of the table): character identity, sect, styling, held props / 180° axis and blocking / scene main color, lighting effects, time of day / current beat, emotional reversal / for multi-segments, tail-frame→head-frame linkage.\
Each segment: ≥3 shots per 30s, at least 1 empty shot, at least 1 mega-structure figure camera move; record the spoken original text sentence by sentence for subtitle production in Phase 6.

> **Pause for confirmation (one time)**: all storyboard tables + look sheets + turnarounds + prop images + scene images pause together. **Storyboard tables are output all at once with a single pause; video (Phase 5) is the opposite — generate and confirm segment by segment**.

### Phase 4b · Multi-Segment Tail-Frame Continuation (key mechanism for 60s+; generate one by one)

After each seg_n is generated → stop and wait for confirmation → extract and analyze the tail frame (blocking/positioning, expression, lighting, shot type, prop state) → generate seg_n+1 according to the seam mode declared in the storyboard. Seam modes: **(A) continuous action** — the tail frame serves as the starting frame for a seamless continuation; **(B) scene change** — the tail frame serves only as a continuity reference (character/costume/props/color palette/lighting consistent), with a new composition, joined by a **hard cut** (no stylized transition effects of any kind).

### Phase 5 · Seedance 2.5 Video (this version is mandatory; one 30s clip per segment, generated one by one)
prompt structure: ① a leading style sentence; ② **assembly** — feed scene images of the locations involved in the segment (selected via the storyboard's "scene anchors", including indoor scenes) + three-view images for each character (locking face and look, no longer using the pick-one-of-four images) + three-view images for each locked prop (selected via the storyboard's "prop anchors"; non-locked props are conveyed through text) + when an original face exists, the original-face image additionally serves as an identity anchor, stating explicitly that "face and look are taken from the three-views, prop designs are taken from the prop three-views"; ③ **storyboard**: `Shot1…hard cut to Shot2…`, one continuous 30s clip, shot count meeting the requirement, at least 1 empty scenery shot + at least 1 megastructure figure camera move, **shot changes use hard cuts only; absolutely no dissolve/cross-dissolve/fade-in-fade-out or any other transition animation or effect footage may appear — no exceptions**; ④ **spoken layer**: filled in according to that shot's sound-layer division — narration/monologue (no lip-sync required), dialogue (mark the speaker, lip-synced); the prompt follows the user's language, dialogue lines are filled in with the original script text; ⑤ **motion** (including megastructure figure camera moves, dialogue close-ups, and combat-specific keywords, selected to match each shot's framing): `sweeping wide-angle and aerial epic vista shots, two tiny figures walking along a vast palace corridor or hall high above the clouds occupying a very small fraction of the frame, medium close-up or close-up on the speaking character with the vast background softly blurred during dialogue, flying-sword or floating traversal within a single continuous shot, camera moving through drifting mist as part of one shot, fast whip-pan between combatants with motion blur, low-angle shot conveying dominance, speed ramping between slow-motion and real-time at the moment of impact, close tracking shot following rapid close-quarters combat, camera pushes back sharply as a shockwave of energy erupts, glowing spirit-qi and sword-qi trails, orbiting camera during power reveal or combat exchange, high bird's-eye shots`; ⑥ **audio + text rules**: the positive prompt states narration/monologue/dialogue + scene sound effects; the negative prompt appends the standard negative prompt library (already covering BGM/subtitles/transition effects/crowds/modern elements, etc.).\
**Acting**: ≥1 expression + 1 action per shot, assigned according to the script's emotional turns, with cinematic acting quality. **General anti-stiffness (add to every shot)**: `natural subtle atmospheric sway, breathing on wide/close shots, micro head movement, natural blink, expression shifting per scene emotion, robes/sleeves/ribbons/hair/mist drifting subtly`.

> **Segment-by-segment generation + mandatory confirmation gate**: generate one segment at a time; after each segment is generated, you must stop and wait for confirmation before generating the next; strictly forbidden to generate continuously without confirmation.\
> \*\***Narration/monologue fallback**: if the model's support for non-lip-synced VO is unstable, fall back to the assembly stage to overlay TTS/recorded audio; all other rules remain unchanged.

### Stage 6 · Assembly

1. **Sequencing**: join all segments with **hard cuts**; **absolutely no dissolve/cross-dissolve/fade-in-fade-out or any other transition effects — no exceptions**; the clips already contain voice + sound effects, no BGM, no transition footage.
2. **Pre-compositing step**: ① **add subtitles** `add_subtitle` — added directly in the language confirmed at Stage 0 (editable overlay layer, not burned into frames); **fixed style**: pure white text, **no stroke (no black border, no outline/stroke)**, font size **28px**, **single line with no wrapping** (overly long lines must be trimmed to a length that fits one line, using the same line-trimming principle as in Stage 1), font **Source Han Serif** (serif typeface; used as the closest substitute when the server lacks SimSun); ② **lay in a Chinese-style score** — guzheng/xiao-dizi flutes/bianzhong chimes/majestic strings or ethereal chanting, rising and falling with the beat; describe the style only without naming specific tracks, at a volume that keeps the vocals clear; ③ **image overlays** — film title/timestamp/credits/logo PNGs (not burned into the generated footage).
3. **Composite and export**: flatten the composite into the final film.

### Prop Library Reference (Locking Decision)

Usually locked: the protagonist's magic treasure/life-bound artifact, key tokens (jade pendant/ancient scroll/teleportation array diagram), recurring weapons. Usually not locked: one-off set dressing, background props for crowds. When in doubt, default to not locking.
