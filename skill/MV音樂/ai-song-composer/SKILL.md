# songwriting-and-ai-music

使用者要寫歌詞、作曲、生成歌曲/主題曲/有人聲的音樂時讀本 skill。最終音樂由 `generate_audio`（音樂）生成；本 skill 覆蓋兩件事：詞曲創作工藝本身，以及怎麼把音樂意圖寫成能被生成引擎正確執行的音樂 prompt。

以下都是指南，不是鐵律。藝術本就會刻意打破規則——服務於歌，而非服務於清單本身；哪條不服務這首歌，就丟開它。

## 1. 歌曲結構（任選一種或自造）

常見骨架，可混用/改造/整個丟開：

```
ABABCB  主歌/副歌/主歌/副歌/橋段/副歌     （多數流行/搖滾）
AABA    主歌/主歌/橋段/主歌（副歌型疊句）   （爵士標準曲、抒情曲）
ABAB    主歌/副歌交替                      （簡單直接）
AAA     主歌/主歌/主歌（無副歌、敘事體）    （民謠、說故事）
```

六個積木：
- **Intro** —— 定調、把聽者拉進來
- **Verse（主歌）** —— 故事、細節、世界觀鋪陳
- **Pre-Chorus（導歌）** —— 可選，副歌前的張力斜坡
- **Chorus（副歌）** —— 情緒核心，被記住的部分
- **Bridge（橋段）** —— 一次繞道，視角或調性的轉折
- **Outro** —— 告別，可呼應或顛覆前文

不必六件都用。有些好歌只有一段反覆演化的素材。**結構服務情緒，不是反過來。**

## 2. 押韻、格律與聲音

**韻型（從緊到松）：**
- 完美韻 Perfect：lean/mean
- 家族韻 Family：crate/braid
- 母音諧音 Assonance：had/glass（母音相同、結尾不同）
- 子音諧音 Consonance：scene/when（母音不同、結尾相近）
- 近似/斜韻 Near/slant：足以暗示關聯但不鎖死

混用為佳：全用完美韻容易像兒歌；全用斜韻容易顯得敷衍。混合處才是活的。

**內韻**：不只押行尾，行內也押。"We pruned the lies from bleeding trees / Distilled the storm from entropy" —— "lies/flies"、"trees/entropy" 製造行內回聲。

**格律（Meter）**：重音與非重音音節的節奏。
- 平行句之間音節數匹配有助於可唱性
- **重音位置比總音節數更重要**
- 念出聲——卡殼的地方就是格律要修的地方
- 刻意打破格律可製造強調或意外感

## 3. 情緒動態弧

把一首歌當成一段旅程，而非一條平路。

**能量對映（粗略參考，非硬性規定）：**
```
Intro: 2-3  |  Verse: 5-6  |  Pre-Chorus: 7
Chorus: 8-9  |  Bridge: 視情況  |  Final Chorus: 9-10
```

最強的動態手法是**對比**：
- 尖叫前先耳語，比一路尖叫更有衝擊力
- 密集前先稀疏；快前先慢；高前先低
- "落地"之所以有效，是因為前面有鋪墊
- **靜默本身也是一件樂器**

"耳語→咆哮→耳語"：從親密開始，推到全力，再退回脆弱。適用於抒情曲、史詩曲、讚歌。

## 4. 寫詞的手藝

**Show, don't tell（多數情況下）：**
- "我很難過" = 扁平
- "門口掛鉤上還留著你的衛衣" = 有生命力
- 但有時候直白地說"我付出我的生命"本身就是力量所在——不是鐵律

**Hook（記憶點）：**
- 被記住、被哼唱、被反覆唸叨的那一句
- 通常是標題或核心短語
- 旋律 + 歌詞 + 情緒三者對齊時效果最好
- 放在最該落地的位置（常是副歌的第一句或最後一句）

**Prosody（歌詞與音樂互相配合）：**
- 穩定情緒（解決感、平靜）配解決式旋律、完美韻、已解決和絃
- 不穩定情緒（渴望、疑慮）配遊移旋律、近似韻、未解決和絃
- 主歌旋律通常偏低，副歌走高——但如果服務於歌，可以反過來

**要避免的（除非你是故意為之）：**
- 自動駕駛式的陳詞濫調（"heart of gold" 沒有鋪墊地直接用）
- 為湊韻硬拗語序（"Yoda 式"倒裝）
- 每段能量都一樣（動態扁平）
- 把初稿當聖旨——修改本身就是創作的一部分

## 5. 改編與仿寫（Parody and Adaptation）

用新詞改寫一首已有歌曲時：

**先畫骨架**：對映原曲結構——
- 數每行音節數
- 標出韻式（ABAB、AABB 等）
- 識別哪些音節是**重音**
- 記下長音/延音落在哪裡

**填新詞對齊骨架：**
- 讓重音音節對齊原曲同樣的拍點
- 總音節數可有 1-2 個非重音音節的浮動空間
- 長音處儘量匹配原曲的**母音音**（原曲長音是 "LOOOVE" 的 "oo" 音，"FOOOD" 比 "LIFE" 更貼合）
- 單音節位置的換詞是保節奏最乾淨的手法（Crime → Code、Snake → Noose）
- 把新詞唱到原曲旋律上——卡殼就改

**概念（Concept）：**
- 選一個足以撐起整首歌的概念
- 從標題/Hook 出發向外搭建
- 先大量發想原料（雙關、短語、意象），再挑最好的填進結構
- 若某處必須落一句特定臺詞，可反向從韻式倒推搭建前文

**保留少量原句**：留幾句原曲的臺詞或結構完整不改，能增加辨識度，讓聽者感受到與原曲的連線。

## 6. 寫音樂 Prompt（交給 `generate_audio` · 音樂生成）

### 風格/流派描述欄位

**公式（按需調整）：** 流派 + 情緒 + 年代 + 樂器 + 人聲特徵 + 製作質感 + 動態

```
差：  "悲傷搖滾歌曲"
好：  "電影感管絃樂間諜驚悚風，1960 年代冷戰時期，煙燻性感女聲，
       大樂隊爵士，銅管聲部（小號+法國號），恢弘絃樂，小調，
       復古模擬溫暖質感"
```

**描述"旅程"，而非只列流派：**
```
"以幽靈般的耳語聲、稀疏鋼琴開場。逐漸疊入弱音銅管。
 副歌處推向全編制管絃樂。第二段主歌以原始咆哮式強唱爆發。
 尾奏收回到孤單鋼琴與脆弱耳語，漸弱至寂靜。"
```

**要點：**
- 風格欄位可以寫得較長——把預算都用在描述"旅程"上，不要只堆流派詞
- **不得出現知名音樂人姓名或商標**——描述聲音本身，而非引用作品/藝人
  - 用 "1960 年代冷戰諜戰銅管" 而非某具體電影配樂師風格名
  - 用 "90 年代油漬搖滾（grunge）" 而非某具體樂隊名
- 有偏好時明確寫出 BPM 與調性
- 用"排除風格"類描述說明你**不**要什麼
- 反直覺的流派組合常能出彩："bossa nova + trap"、"阿巴拉契亞哥特"、"chiptune 爵士"
- 建一個**人聲人設（persona）**，而不只是給性別："一位飽經風霜的駐唱歌手，煙嗓帶沙啞，從脆弱起唱、逐漸推向毀滅性的爆發力"

### Metatags（放在歌詞欄位的方括號內 `[標籤]`）

**結構類：**
`[Intro] [Verse] [Verse 1] [Pre-Chorus] [Chorus] [Post-Chorus] [Hook] [Bridge] [Interlude] [Instrumental] [Instrumental Break] [Guitar Solo] [Breakdown] [Build-up] [Outro] [Silence] [End]`

**演唱表現類：**
`[Whispered] [Spoken Word] [Belted] [Falsetto] [Powerful] [Soulful] [Raspy] [Breathy] [Smooth] [Gritty] [Staccato] [Legato] [Vibrato] [Melismatic] [Harmonies] [Choir] [Harmonized Chorus]`

**動態類：**
`[High Energy] [Low Energy] [Building Energy] [Explosive] [Emotional Climax] [Gradual swell] [Orchestral swell] [Quiet arrangement] [Falling tension] [Slow Down]`

**性別類：**
`[Female Vocals] [Male Vocals]`

**氛圍類：**
`[Melancholic] [Euphoric] [Nostalgic] [Aggressive] [Dreamy] [Intimate] [Dark Atmosphere]`

**音效類：**
`[Vinyl Crackle] [Rain] [Applause] [Static] [Thunder]`

**使用規則：**
- 標籤同時放風格欄位和歌詞欄位兩處，互相強化
- 每段最多 5-8 個標籤——太多會讓引擎困惑
- 不要自相矛盾（同一段落裡不要同時 `[Calm]` 又 `[Aggressive]`）

### 分離風格/歌詞的創作模式

- 正式創作請始終使用"分離 Style + Lyrics"的模式（而非單欄簡易模式）
- 歌詞欄位容量上限大致在 ~3,000 字元（約 40-60 行）以內規劃
- 務必加結構標籤——沒有結構標籤時引擎會預設退化成平鋪的主歌/副歌/主歌、沒有情緒弧

## 7. AI 歌手的咬字技巧（Phonetic Tricks）

AI 人聲模型不是"讀"字，是"發音"字——要主動引導它：

**按讀音拼寫：**
- 按實際發音重新拼寫詞語（如 "through" → "thru"）
- 專有名詞失敗率最高——務必提前小段測試
- 用近音詞強制正確發音（如把易錯的詞換成同音但更易讀對的拼法）
- 用連字元引導音節切分（如 "Re-search"、"bio-engineering"）

**演唱控制：**
- 全大寫 = 更響、更強烈
- 母音拉長（"lo-o-o-ove"）= 延音/花腔（melisma）
- 省略號（"I... need... you"）= 戲劇性停頓
- 連字元拉伸（"ne-e-ed"）= 情感延展

**始終注意：**
- 數字拼寫成文字（"24/7" → "twenty four seven"）
- 縮寫詞加空格分開字母（"AI" → "A I" 或 "A-I"）
- 專有名詞/生僻詞先用一段 30 秒左右的短片單獨測試
- **一旦生成，發音已經定型**——要改先改歌詞文字再重新生成，而非事後修正

## 8. 創作工作流

1. 先寫概念/Hook——這首歌的情緒核心是什麼？
2. 若是改編，先對映原曲結構（音節、韻式、重音）
3. 自由發想原料——先不設結構地頭腦風暴
4. 把詞填進結構草稿
5. 念/唱出聲——抓卡殼的地方，修格律
6. 寫 Suno 風格描述——把動態旅程畫出來
7. 給歌詞加 metatags 做演唱指導
8. 至少生成 3-5 個版本——當成"錄音 take"來對待
9. 挑最好的一版，用續寫/延展功能在有潛力的段落上繼續build
10. 若無意中出現了神來之筆，留下它

**預期心理準備**：大約每 3-5 次生成才出一個滿意結果。反覆修改是常態。風格在續寫/延展中會漂移——續寫時要重新申明流派/情緒。

## 9. 經驗教訓（Lessons Learned）

- 在風格欄位裡描述**動態弧**（"耳語→咆哮→耳語"）比單純堆流派詞重要得多——它相當於給引擎一張"演唱地圖"。
- 仿寫時保留幾句原詞能增加辨識度和情感重量——聽眾能感受到原曲的"幽靈"還在。
- 橋段（Bridge）是轉換意象的最佳位置：把原曲具體指代換成你主題的隱喻，同時保留其情感功能（反思/轉折/頓悟）。
- Hook/標籤處的單音節替換是既保持節奏又改變含義的最乾淨手法。
- 一段強有力的人聲人設描述，比任何單個 metatag 都更能左右效果。
- 不要拘泥於規則本身。如果某一句打破了格律但打動人心，就留著它——**感覺才是本體，工藝服務於藝術，而非反過來**。

## 工具適配說明

最終音樂生成統一走本環境的 `generate_audio`（音樂）；本 skill 交付的是寫給它的音樂 prompt（風格描述 + 結構化歌詞/metatags），不涉及具體平臺 UI 操作（如某平臺的字數上限、"排除風格"輸入框等屬該平臺運維細節，非創作工藝，不在本 skill 範圍內——工藝本身與平臺無關，照常適用）。歌名/藝人名/商標類規則維持源意圖：不得在音樂 prompt 中出現知名音樂人姓名或商標，一律描述聲音本身。

按 SP：影片片段不內嵌 BGM，音樂由 `generate_audio` 單獨生成，合成階段混音。
