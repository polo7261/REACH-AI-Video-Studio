# MV 製作紀律

## 適用場景

任務屬於「帶演唱／配樂的多分鏡影片」（MV、歌曲短片、Live 舞臺＋劇情插片、口播配樂分鏡）時使用。疊加在基礎影片製作編排之上，不替代它：編排負責規劃與生成推進，本 Skill 負責在每一步逐條自查音樂基準、總長守恆、詞級切點、鎖臉三件套等紀律。純對白無演唱、無配樂卡點需求的影片不適用。

## 輸出

一條音樂與畫面嚴格對齊的多分鏡成片：連續演唱音軌＋按樂句邊界劃分的畫面段＋鎖臉不崩的人物＋卡點插片，以及配套的錨點集、分鏡表、聲部地圖、成片時間軸與避坑記錄。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
