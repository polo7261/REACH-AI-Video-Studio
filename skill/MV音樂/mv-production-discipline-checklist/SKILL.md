# MV 制作纪律

## 適用場景

任务属于「带演唱／配乐的多分镜视频」（MV、歌曲短片、Live 舞台＋剧情插片、口播配乐分镜）时使用。叠加在基础视频制作编排之上，不替代它：编排负责规划与生成推进，本 Skill 负责在每一步逐条自查音乐基准、总长守恒、词级切点、锁脸三件套等纪律。纯对白无演唱、无配乐卡点需求的视频不适用。

## 輸出

一条音乐与画面严格对齐的多分镜成片：连续演唱音轨＋按乐句边界划分的画面段＋锁脸不崩的人物＋卡点插片，以及配套的锚点集、分镜表、声部地图、成片时间轴与避坑记录。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
