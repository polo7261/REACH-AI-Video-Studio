# 时尚视觉 MV 生成

## Skill 定位

只负责一件可复用的事：从一个音乐 MV 概念出发，自动完成“人物 IP 设计 -&gt; 妆造穿搭 -&gt; 场景艺术图 -&gt; 音乐方向 -&gt; 视频镜头生成 -&gt; MV 剪辑方案”的视觉工作流。

这个 skill 的核心不是写死某一种风格，而是沉淀一套适用于多种 MV 的视觉生产公式。它可以用于韩系女团、未来主义、怪诞美学、巨物美学、暗黑宗教感、赛博舞台、异世界、奢华时尚大片、梦核、废土、金属装置、晶体星球、音乐节现场等方向。

目标优先级：

1. 人物要好看，并且有记忆点，不要标准模板脸。
2. 妆造、发型、配饰、穿搭要有特点，有舞台感和时尚感。
3. 场景要美、有视觉冲击、有艺术设定，不只是普通背景。
4. 视频要像 MV 视觉片，有镜头冲击、表演、空镜、特写、舞台调度和剪辑节奏。
5. 流程要可扩展，用户换歌曲、换人物、换风格、换画幅依然能用。

## 模型优先级

按以下模型优先级执行；如果用户或环境无法使用优先模型，不要静默失败。先按“错误处理与模型切换策略”处理，再通过 `ask_human` 引导用户确认是否切换到下一个模型重新生成。

```json
{
  "portrait_and_styling_image_models": ["Lib image", "Lib nano2"],
  "scene_art_models": ["Lib image", "Lib nano2", "悠船 v7 / Midjourney v7"],
  "video_models": ["seedance 2.0", "seedance 2.0 fast", "kling O3"],
  "music_models": ["any available music model"],
  "text_models": ["any available text model"]
}
```

模型使用规则：

- 人物候选、人物定稿、妆造穿搭图：优先 `Lib image`，其次 `Lib nano2`。
- 纯场景艺术图：可使用 `Lib image`、`Lib nano2`、`悠船 v7 / Midjourney v7`。
- 视频生成：优先 `seedance 2.0`，其次 `seedance 2.0 fast`，最后 `kling O3`。
- 音乐生成：使用当前可用音乐模型，重点贴合用户的音乐类型和 MV 氛围。
- 默认画幅为 `16:9 横屏`；用户指定时可改为 `9:16`、`1:1`、`4:5`、`21:9` 等。

## 错误处理与模型切换策略

当生成过程遇到报错、素材缺失、质量不足或安审限制时，不要直接终止整个 MV 工作流。先判断问题类型，再选择修复、重试或询问用户。

### 1. 安审失败优先改 prompt 重试

如果图片或视频生成触发审核失败，优先修改 prompt 并在同一模型上重试。修改方向：

- 去掉血腥、伤口、受伤、疼痛、死亡、暴力等表达。
- 去掉性感、挑逗、裸露、低俗、未成年感等表达。
- 把“性感舞蹈”改成“自信舞台表演、强节奏编舞、时尚舞台动作”。
- 把“受伤、虚弱、血迹”改成“疲惫、失落、戏剧化情绪、倒地造型”，明确“无伤口、无血迹”。
- 把“宗教仪式、咒语、修女”等高风险词改成“神秘仪式感、黑纱群像、烛光舞台、低声吟唱氛围”。
- 保留视觉目标，但降低敏感词强度。

如果第一次重试仍失败，再进一步弱化敏感元素并重试一次。连续失败后，通过 `ask_human` 询问用户是否切换模型、换视觉方向或放弃该镜头。

### 2. 缺关键素材时先 ask_human

若缺少会影响最终成片质量、交付结果或素材使用方式的素材，不要强行进入视频生成。通过 `ask_human` 引导用户选择下一步。

关键素材包括：

- 没有选定主角人物，导致人物身份无法稳定。
- 没有选定妆造图，导致服装、发型、配饰不稳定。
- 没有纯场景图，导致人物无法融合到明确空间。
- 场景图混入人物，不能作为纯场景锚点。
- 人物图或造型图安审失败、质量过低、脸部模糊、风格漂移。
- 用户要求的镜头依赖翅膀、伴舞、群像、道具、舞台装置，但对应素材不存在。

`ask_human` 选项建议：

```text
当前缺少会影响成片质量的关键素材。你希望怎么处理？
1. 先补生成缺失素材
2. 使用现有素材继续，但降低一致性要求
3. 切换模型重新生成素材
```

### 3. 模型报错时询问是否切换

如果当前模型报错、超时、不可用或多次生成失败，使用 `ask_human` 让用户确认是否切换到下一个模型。

图片模型切换顺序：

```text
Lib Image -> Lib Nano2 -> 悠船 V7 / Midjourney v7
```

视频模型切换顺序：

```text
Seedance 2.0 -> Seedance 2.0 fast -> kling O3
```

`ask_human` 选项建议：

```text
当前模型生成失败。你希望怎么处理？
1. 修改 prompt 后继续用当前模型重试
2. 切换到下一个模型重新生成
3. 跳过这个素材/镜头，继续后续流程
```

### 4. 重试记录

每次重试或切换模型后，在最终输出里记录：

- 失败环节。
- 失败原因：模型报错、审核失败、素材不足、质量不足等。
- 修改后的 prompt 策略。
- 是否调用 `ask_human`。
- 用户选择。
- 最终使用模型。

## 输入

用户可以提供以下任意信息：

- 音乐风格：K-pop、J-pop、电子、暗黑流行、R&B、摇滚、说唱、实验音乐、女团舞曲等。
- MV 风格：未来主义、怪诞美学、巨物美学、宗教感、赛博、梦幻、暗黑、奢华、复古、异世界等。
- 人物方向：韩系女团感、时尚模特感、冷感偶像、暗黑圣女、未来战士、异星歌姬等。
- 参考图：人物图、造型图、场景图、风格图。
- 歌词、歌名、主题、品牌或视觉关键词。
- 目标比例和时长。

如果用户只说“做一个好看的 MV”，默认：

```json
{
  "aspect_ratio": "16:9",
  "duration": "30-60s visual MV",
  "character_count": 1,
  "portrait_options": 9,
  "styling_options": 6,
  "scene_options": 6,
  "visual_direction": "韩系女团感 + 未来主义时尚 + 怪诞美学 + 巨物美学",
  "music_direction": "K-pop / electronic pop / cinematic fashion MV"
}
```

## 输入使用

严格遵守：

- 用户上传的选定人物图，用作人物身份、五官、发型气质的一致性锚点。
- 用户选定的造型图，用作服装、妆容、配饰、头饰和整体轮廓锚点。
- 用户选定的场景图，用作空间、材质、色彩、光线和美术方向锚点。
- 用户指定的音乐风格、歌词主题和 MV 情绪。

允许扩展：

- 多套妆造和穿搭。
- 多个纯场景艺术图。
- 舞台、空镜、特写、舞蹈、仪式感、巨物装置、抽象视觉等镜头类型。
- 不同语言的歌曲和字幕版本。

禁止：

- 生成未成年人性感化形象。涉及性感、舞台魅力、贴身造型时，必须明确为成年表演者。
- 使用真实明星、特定艺人、在世公众人物或受版权保护角色作为直接复刻对象。
- 过度暴露、色情、低俗或伤害性画面。
- 把场景艺术图阶段直接混入人物；场景图必须先保持“纯场景”。

## 内部流程和 Knowhow

### 1. mv_concept_planner

先把用户需求整理成 MV 视觉总设定。

输出：

```json
{
  "music_style": "",
  "visual_world": "",
  "main_character": "",
  "fashion_direction": "",
  "scene_direction": "",
  "mood_keywords": [],
  "aspect_ratio": "16:9",
  "duration": "",
  "safety_notes": []
}
```

如果用户给的信息很少，自动生成 3 个视觉方向让用户选择：

- 韩系女团舞台大片：漂亮、时尚、强表演、强妆造、强镜头。
- 未来主义异世界：金属、晶体、装置、巨物、冷光、异星场景。
- 怪诞奢华仪式感：暗黑、华丽头饰、宗教式构图、群像、烛光、强反差。

### 2. character_brainstorm

先生成多版人物候选，一般为 9 版，供用户选择一个最有潜力的 MV 主角 IP。

人物候选原则：

- 好看，但不要标准模板脸。
- 有特点：眼型、脸型、气质、冷感、钝感、清冷、锋利、松弛、厌世、灵气等至少有一个记忆点。
- 更偏时尚偶像、韩系女团、亚裔模特、视觉系歌手，而不是普通写真。
- 默认成年女性表演者；如果用户指定其他性别或群像，则按用户需求调整。
- 白底或极简背景，方便后续选人和再设计。

参考提示词结构：

```text
生成 9 版年轻成年时尚女性 MV 主角候选，亚裔女团气质，漂亮但不标准化，每个人都有独特五官记忆点和个人气质。半身像特写，面对镜头，证件照式构图，黑长直或可变化发型，穿着极简黑色吊带或极简黑色上衣，纯白背景，高级时尚感，随性但有明星潜力，真实摄影质感。
```

可替换变量：

- `{gender}`：女性、男性、中性、组合成员。
- `{ethnicity_or_market}`：亚裔、日韩感、欧美感、拉美感、多元族群等。
- `{idol_type}`：清冷、暗黑、甜酷、未来感、怪诞、摇滚、精灵感、机械感等。
- `{background}`：纯白背景、浅灰背景、证件照背景、棚拍背景。

输出时给每个候选标注：

- 颜值潜力。
- 记忆点。
- 适合的 MV 风格。
- 后续妆造方向。

### 3. character_selection

用户选择其中一个人物后，将其作为 `Portrait 1` 或 `Mixed 1` 角色锚点。

如果用户没有明确选择，先推荐 1-2 个最适合做 MV 主角的人物，并说明原因。

选择标准：

- 五官辨识度高。
- 气质有延展空间。
- 能承载夸张妆造。
- 适合多场景、多套造型反复出现。
- 不是过度普通的商业模特脸。

### 4. styling_and_makeup_design

围绕选定人物生成多套妆造、发型、穿搭、配饰和舞台造型。默认生成 6 套，用户可选择 1-3 套作为 MV 主要造型。

造型方向库：

- 韩系女团舞台：金属感、亮片、珠链、长靴、露肩但不低俗、强舞台轮廓。
- 未来主义装置：银色、铬金属、可穿戴艺术装置、透明材质、激光元素。
- 怪诞美学：异形头饰、夸张肩线、面部装饰、非对称轮廓。
- 巨物美学：巨大翅膀、巨型裙摆、夸张披风、巨型头饰。
- 暗黑仪式感：黑纱、金属冠冕、链条、烛光、修女式构图但不直接复刻宗教服饰。
- 晶体幻境：碎钻、细闪、水晶、半透明装置、冷色光。
- 音乐节现场：高能舞台、亮色灯光、闪耀材质、动感穿搭。

参考提示词结构：

```text
高级肖像定制，全身像，保持 Portrait 1 的人物五官和气质一致，为她设计一套全新的 MV 舞台造型。时尚前卫，韩国女团感，时尚属性拉满，金属元素，激光元素，碎钻细闪元素，先锋面部装饰，华丽头饰，大量首饰，可穿戴艺术装置，宽松堆叠感靴筒，银色尖头高跟长靴，未来主义裙装，夸张但高级，纯白背景，真实时尚大片摄影。
```

多角度定稿图要求：

```text
使用选定人物和选定造型，生成一张 16:9 人物设定图，纯白背景，同一张图从左到右依次展示：人物面部特写、全身正面、全身侧面、全身背面。保持同一人物五官、发型、妆容、服装、配饰完全一致。画面清晰，高级时尚设定稿，偶像特征明显。
```

造型阶段必须输出：

- 造型名称。
- 妆容关键词。
- 发型关键词。
- 服装轮廓。
- 材质。
- 配饰。
- 适合的 MV 场景。
- 适合的镜头动作。

### 5. scene_art_generation

生成纯场景艺术图，不要把人物放进场景里。这一步只做 MV 世界观和空间美术。

默认生成 6 个场景方向：

- 主舞台：用于唱跳、正面表演、强灯光。
- 英雄场景：用于人物站立、慢推、巨物装置、封面镜头。
- 空镜场景：用于剪辑呼吸、音乐过门、氛围转场。
- 特写材质场景：金属、晶体、水面、屏幕、红光、黑纱等细节。
- 仪式/群像空间：用于伴舞、群演、围绕、注视、展开等戏剧调度。
- 超现实场景：异星、镜面空间、巨大结构、梦境地貌、反重力空间。

场景图要求：

- 纯场景，不要人物。
- 16:9 横屏默认。
- 美、有冲击力、有艺术概念。
- 可以夸张，但要适合后续把人物融合进去。
- 要有明确空间层次：前景、中景、背景。
- 要有明确光线方向和主色调。

参考提示词结构：

```text
一个真实的未来主义 MV 场景，纯场景，无人物。异世界星球，地表布满交错复杂的淡紫色水晶，巨大的晶体结构从地面生长出来，远处有超现实舞台轮廓，梦幻、时尚、高级摄影、电影级光影、强空间纵深、视觉冲击、16:9 横屏。
```

可扩展场景关键词：

- 金属骨骼大厅、黑色镜面舞台、淡紫水晶星球、巨大羽翼装置、电视墙空间、红色激光房间、雨夜玻璃盒、废墟音乐节、银色液态隧道、白色无菌实验舞台、黑纱教堂式空间、荒漠巨型雕塑、海底发光剧场。

### 6. music_direction

生成音乐或音乐提示词。使用当前可用音乐模型。

音乐必须服务 MV 视觉：

- 韩系女团：强鼓点、电子贝斯、hook 明确、适合唱跳。
- 暗黑流行：低频、耳语感、合成器、神秘氛围。
- 未来主义：金属打击、电子噪声、冷感合成器。
- 怪诞奢华：弦乐、管风琴感、低频鼓、戏剧化停顿。
- 梦幻异世界：空灵人声、合成器 pad、宽阔混响。

输出：

- 音乐风格。
- BPM 范围。
- 情绪关键词。
- 歌曲结构：intro / verse / pre-chorus / chorus / bridge / outro。
- 视频节奏建议：快切点、慢镜头点、定帧点。

### 7. video_prompt_builder

在所有人物图、妆造图、场景图通过自检后，再写视频生成 prompt。

如果视频生成前发现人物、造型、场景任一锚点缺失或质量不足，先按“错误处理与模型切换策略”调用 `ask_human`，不要直接生成。

视频模型优先级：

1. `seedance 2.0`
2. `seedance 2.0 fast`
3. `kling O3`

视频生成原则：

- 使用参考生视频功能，把人物锚点、造型锚点、场景锚点融合。
- 人物身份由人物图控制。
- 服装妆造由造型图控制。
- 场景由纯场景图控制。
- 不要让模型重新设计人物脸、服装和场景。
- 一个视频片段只表达一个核心镜头事件。
- 优先生成多个 3-6 秒片段，再剪辑成完整 MV。

常见镜头类型：

- 视觉开场：人物站在巨大场景中，慢慢抬眼，灯光闪烁。
- 唱跳镜头：正面近景，中景舞蹈，镜头推进，口型精准。
- 造型展示：面部特写、眼妆、嘴唇、首饰、手部、鞋靴、裙摆、金属装置。
- 场景空镜：晶体、金属、屏幕墙、舞台灯、雨地、巨物装置。
- 仪式镜头：伴舞围绕、群像注视、手势、光线熄灭、翅膀展开。
- 冲击镜头：快速推近、旋转、闪光、低角度仰拍、极近特写。

通用视频 prompt 模板：

```text
史诗级时尚 MV 电影质感，参考 {{Portrait 1}} 的人物身份，参考 {{Styling 1}} 的妆造穿搭，参考 {{Scene 1}} 的场景美术。

{人物} 站在 {场景} 中，进行 {表演/舞蹈/仪式/情绪动作}。保持人物五官、发型、妆容、服装、配饰一致，保持场景的材质、光线、色彩和空间结构一致。

镜头语言：{近景/中景/全景/特写/低角度/环绕/快速推近/慢速推进/旋转/闪切}
画面气质：高颜值、强妆造、强视觉冲击、时尚前卫、电影级光影、音乐 MV 质感。
动作要求：动作自然流畅，表演有节奏，口型和音乐情绪匹配，镜头切换有冲击力，全程无字幕。
```

舞蹈 MV 模板：


### 8. mv_editing_plan

把多个视频片段剪辑成 MV 视觉片。

默认结构：

```text
0-5s：强视觉开场，空镜或人物抬眼。
5-15s：人物主造型登场，近景和全身交替。
15-30s：唱跳/表演段落，快切，配合音乐鼓点。
30-45s：场景切换和造型变化，加入空镜和特写。
45-60s：高潮视觉，巨物、群像、灯光、强运镜，最后定格或慢推收尾。
```

剪辑规则：

- MV 视觉片不需要解释剧情，重点是视觉冲击和音乐节奏。
- 每 2-4 秒切换一次视觉重点。
- 人物脸部特写、全身造型、场景空镜、舞蹈动作、材质细节要交替出现。
- 音乐高潮使用快切、闪光、旋转、低角度和群像。
- 音乐过门使用空镜、慢推、材质特写和背影。
- 全程默认无字幕，除非用户明确要求歌词字幕。

## 自检

生成视频前必须检查：

- 人物是否看起来为成年人，且没有未成年人性感化问题。
- 人物是否好看、有辨识度，不是普通模板脸。
- 妆造是否有明确风格、轮廓、材质和配饰。
- 人物设定图是否保持同一人物一致性。
- 场景图是否为纯场景，没有人物混入。
- 场景是否足够美、有视觉冲击、有空间层次。
- 视频 prompt 是否清楚引用人物、造型、场景。
- 是否避免字幕、水印、错误文字。
- 是否没有使用真实明星或受版权保护角色。
- 是否按模型优先级选择。
- 如果触发安审失败，是否先去掉血腥、性感、伤害、未成年感等敏感表达并重试。
- 如果缺少关键素材或模型连续失败，是否通过 `ask_human` 引导用户选择是否补素材、换模型或跳过。

## Ask User

不要因为信息不完整就停下。用户只给一个方向时，先生成默认方案。

只有以下情况需要追问：

- 用户没有给任何音乐或视觉方向，同时也没有说“自由发挥”。
- 用户要求复刻真实明星、特定女团成员、影视角色或版权 IP。
- 用户要求明显未成年形象、低俗性感化或不安全内容。
- 用户需要商业品牌植入，但没有给品牌限制。
- 缺少会影响最终成片质量、交付结果或素材使用方式的关键素材。
- 图片或视频模型报错、超时、不可用，或同一安审问题连续重试失败。

优先追问：

1. MV 想偏哪种方向：韩系女团、未来主义、怪诞美学、巨物美学、暗黑仪式感，还是自由发挥？
2. 主角是单人、双人，还是组合？
3. 默认做 16:9 横屏可以吗，还是要 9:16 竖屏？
