# 時尚視覺 MV 生成

## Skill 定位

只負責一件可複用的事：從一個音樂 MV 概念出發，自動完成“人物 IP 設計 -&gt; 妝造穿搭 -&gt; 場景藝術圖 -&gt; 音樂方向 -&gt; 影片鏡頭生成 -&gt; MV 剪輯方案”的視覺工作流。

這個 skill 的核心不是寫死某一種風格，而是沉澱一套適用於多種 MV 的視覺生產公式。它可以用於韓系女團、未來主義、怪誕美學、巨物美學、暗黑宗教感、賽博舞臺、異世界、奢華時尚大片、夢核、廢土、金屬裝置、晶體星球、音樂節現場等方向。

目標優先順序：

1. 人物要好看，並且有記憶點，不要標準模板臉。
2. 妝造、髮型、配飾、穿搭要有特點，有舞臺感和時尚感。
3. 場景要美、有視覺衝擊、有藝術設定，不只是普通背景。
4. 影片要像 MV 視覺片，有鏡頭衝擊、表演、空鏡、特寫、舞臺排程和剪輯節奏。
5. 流程要可擴充套件，使用者換歌曲、換人物、換風格、換畫幅依然能用。

## 模型優先順序

按以下模型優先順序執行；如果使用者或環境無法使用優先模型，不要靜默失敗。先按“錯誤處理與模型切換策略”處理，再透過 `ask_human` 引導使用者確認是否切換到下一個模型重新生成。

```json
{
  "portrait_and_styling_image_models": ["Lib image", "Lib nano2"],
  "scene_art_models": ["Lib image", "Lib nano2", "悠船 v7 / Midjourney v7"],
  "video_models": ["seedance 2.0", "seedance 2.0 fast", "kling O3"],
  "music_models": ["any available music model"],
  "text_models": ["any available text model"]
}
```

模型使用規則：

- 人物候選、人物定稿、妝造穿搭圖：優先 `Lib image`，其次 `Lib nano2`。
- 純場景藝術圖：可使用 `Lib image`、`Lib nano2`、`悠船 v7 / Midjourney v7`。
- 影片生成：優先 `seedance 2.0`，其次 `seedance 2.0 fast`，最後 `kling O3`。
- 音樂生成：使用當前可用音樂模型，重點貼合使用者的音樂型別和 MV 氛圍。
- 預設畫幅為 `16:9 橫屏`；使用者指定時可改為 `9:16`、`1:1`、`4:5`、`21:9` 等。

## 錯誤處理與模型切換策略

當生成過程遇到報錯、素材缺失、質量不足或安審限制時，不要直接終止整個 MV 工作流。先判斷問題型別，再選擇修復、重試或詢問使用者。

### 1. 安審失敗優先改 prompt 重試

如果圖片或影片生成觸發稽核失敗，優先修改 prompt 並在同一模型上重試。修改方向：

- 去掉血腥、傷口、受傷、疼痛、死亡、暴力等表達。
- 去掉性感、挑逗、裸露、低俗、未成年感等表達。
- 把“性感舞蹈”改成“自信舞臺表演、強節奏編舞、時尚舞臺動作”。
- 把“受傷、虛弱、血跡”改成“疲憊、失落、戲劇化情緒、倒地造型”，明確“無傷口、無血跡”。
- 把“宗教儀式、咒語、修女”等高風險詞改成“神秘儀式感、黑紗群像、燭光舞臺、低聲吟唱氛圍”。
- 保留視覺目標，但降低敏感詞強度。

如果第一次重試仍失敗，再進一步弱化敏感元素並重試一次。連續失敗後，透過 `ask_human` 詢問使用者是否切換模型、換視覺方向或放棄該鏡頭。

### 2. 缺關鍵素材時先 ask_human

若缺少會影響最終成片質量、交付結果或素材使用方式的素材，不要強行進入影片生成。透過 `ask_human` 引導使用者選擇下一步。

關鍵素材包括：

- 沒有選定主角人物，導致人物身份無法穩定。
- 沒有選定妝造圖，導致服裝、髮型、配飾不穩定。
- 沒有純場景圖，導致人物無法融合到明確空間。
- 場景圖混入人物，不能作為純場景錨點。
- 人物圖或造型圖安審失敗、質量過低、臉部模糊、風格漂移。
- 使用者要求的鏡頭依賴翅膀、伴舞、群像、道具、舞臺裝置，但對應素材不存在。

`ask_human` 選項建議：

```text
當前缺少會影響成片質量的關鍵素材。你希望怎麼處理？
1. 先補生成缺失素材
2. 使用現有素材繼續，但降低一致性要求
3. 切換模型重新生成素材
```

### 3. 模型報錯時詢問是否切換

如果當前模型報錯、超時、不可用或多次生成失敗，使用 `ask_human` 讓使用者確認是否切換到下一個模型。

圖片模型切換順序：

```text
Lib Image -> Lib Nano2 -> 悠船 V7 / Midjourney v7
```

影片模型切換順序：

```text
Seedance 2.0 -> Seedance 2.0 fast -> kling O3
```

`ask_human` 選項建議：

```text
當前模型生成失敗。你希望怎麼處理？
1. 修改 prompt 後繼續用當前模型重試
2. 切換到下一個模型重新生成
3. 跳過這個素材/鏡頭，繼續後續流程
```

### 4. 重試記錄

每次重試或切換模型後，在最終輸出裡記錄：

- 失敗環節。
- 失敗原因：模型報錯、稽核失敗、素材不足、質量不足等。
- 修改後的 prompt 策略。
- 是否呼叫 `ask_human`。
- 使用者選擇。
- 最終使用模型。

## 輸入

使用者可以提供以下任意資訊：

- 音樂風格：K-pop、J-pop、電子、暗黑流行、R&B、搖滾、說唱、實驗音樂、女團舞曲等。
- MV 風格：未來主義、怪誕美學、巨物美學、宗教感、賽博、夢幻、暗黑、奢華、復古、異世界等。
- 人物方向：韓系女團感、時尚模特感、冷感偶像、暗黑聖女、未來戰士、異星歌姬等。
- 參考圖：人物圖、造型圖、場景圖、風格圖。
- 歌詞、歌名、主題、品牌或視覺關鍵詞。
- 目標比例和時長。

如果使用者只說“做一個好看的 MV”，預設：

```json
{
  "aspect_ratio": "16:9",
  "duration": "30-60s visual MV",
  "character_count": 1,
  "portrait_options": 9,
  "styling_options": 6,
  "scene_options": 6,
  "visual_direction": "韓系女團感 + 未來主義時尚 + 怪誕美學 + 巨物美學",
  "music_direction": "K-pop / electronic pop / cinematic fashion MV"
}
```

## 輸入使用

嚴格遵守：

- 使用者上傳的選定人物圖，用作人物身份、五官、髮型氣質的一致性錨點。
- 使用者選定的造型圖，用作服裝、妝容、配飾、頭飾和整體輪廓錨點。
- 使用者選定的場景圖，用作空間、材質、色彩、光線和美術方向錨點。
- 使用者指定的音樂風格、歌詞主題和 MV 情緒。

允許擴充套件：

- 多套妝造和穿搭。
- 多個純場景藝術圖。
- 舞臺、空鏡、特寫、舞蹈、儀式感、巨物裝置、抽象視覺等鏡頭型別。
- 不同語言的歌曲和字幕版本。

禁止：

- 生成未成年人性感化形象。涉及性感、舞臺魅力、貼身造型時，必須明確為成年表演者。
- 使用真實明星、特定藝人、在世公眾人物或受版權保護角色作為直接復刻物件。
- 過度暴露、色情、低俗或傷害性畫面。
- 把場景藝術圖階段直接混入人物；場景圖必須先保持“純場景”。

## 內部流程和 Knowhow

### 1. mv_concept_planner

先把使用者需求整理成 MV 視覺總設定。

輸出：

```json
{
  "music_style": "",
  "visual_world": "",
  "main_character": "",
  "fashion_direction": "",
  "scene_direction": "",
  "mood_keywords": [],
  "aspect_ratio": "16:9",
  "duration": "",
  "safety_notes": []
}
```

如果使用者給的資訊很少，自動生成 3 個視覺方向讓使用者選擇：

- 韓系女團舞臺大片：漂亮、時尚、強表演、強妝造、強鏡頭。
- 未來主義異世界：金屬、晶體、裝置、巨物、冷光、異星場景。
- 怪誕奢華儀式感：暗黑、華麗頭飾、宗教式構圖、群像、燭光、強反差。

### 2. character_brainstorm

先生成多版人物候選，一般為 9 版，供使用者選擇一個最有潛力的 MV 主角 IP。

人物候選原則：

- 好看，但不要標準模板臉。
- 有特點：眼型、臉型、氣質、冷感、鈍感、清冷、鋒利、鬆弛、厭世、靈氣等至少有一個記憶點。
- 更偏時尚偶像、韓系女團、亞裔模特、視覺系歌手，而不是普通寫真。
- 預設成年女性表演者；如果使用者指定其他性別或群像，則按使用者需求調整。
- 白底或極簡背景，方便後續選人和再設計。

參考提示詞結構：

```text
生成 9 版年輕成年時尚女性 MV 主角候選，亞裔女團氣質，漂亮但不標準化，每個人都有獨特五官記憶點和個人氣質。半身像特寫，面對鏡頭，證件照式構圖，黑長直或可變化髮型，穿著極簡黑色吊帶或極簡黑色上衣，純白背景，高階時尚感，隨性但有明星潛力，真實攝影質感。
```

可替換變數：

- `{gender}`：女性、男性、中性、組合成員。
- `{ethnicity_or_market}`：亞裔、日韓感、歐美感、拉美感、多元族群等。
- `{idol_type}`：清冷、暗黑、甜酷、未來感、怪誕、搖滾、精靈感、機械感等。
- `{background}`：純白背景、淺灰背景、證件照背景、棚拍背景。

輸出時給每個候選標註：

- 顏值潛力。
- 記憶點。
- 適合的 MV 風格。
- 後續妝造方向。

### 3. character_selection

使用者選擇其中一個人物後，將其作為 `Portrait 1` 或 `Mixed 1` 角色錨點。

如果使用者沒有明確選擇，先推薦 1-2 個最適合做 MV 主角的人物，並說明原因。

選擇標準：

- 五官辨識度高。
- 氣質有延展空間。
- 能承載誇張妝造。
- 適合多場景、多套造型反覆出現。
- 不是過度普通的商業模特臉。

### 4. styling_and_makeup_design

圍繞選定人物生成多套妝造、髮型、穿搭、配飾和舞臺造型。預設生成 6 套，使用者可選擇 1-3 套作為 MV 主要造型。

造型方向庫：

- 韓系女團舞臺：金屬感、亮片、珠鏈、長靴、露肩但不低俗、強舞臺輪廓。
- 未來主義裝置：銀色、鉻金屬、可穿戴藝術裝置、透明材質、鐳射元素。
- 怪誕美學：異形頭飾、誇張肩線、面部裝飾、非對稱輪廓。
- 巨物美學：巨大翅膀、巨型裙襬、誇張披風、巨型頭飾。
- 暗黑儀式感：黑紗、金屬冠冕、鏈條、燭光、修女式構圖但不直接復刻宗教服飾。
- 晶體幻境：碎鑽、細閃、水晶、半透明裝置、冷色光。
- 音樂節現場：高能舞臺、亮色燈光、閃耀材質、動感穿搭。

參考提示詞結構：

```text
高階肖像定製，全身像，保持 Portrait 1 的人物五官和氣質一致，為她設計一套全新的 MV 舞臺造型。時尚前衛，韓國女團感，時尚屬性拉滿，金屬元素，鐳射元素，碎鑽細閃元素，先鋒面部裝飾，華麗頭飾，大量首飾，可穿戴藝術裝置，寬鬆堆疊感靴筒，銀色尖頭高跟長靴，未來主義裙裝，誇張但高階，純白背景，真實時尚大片攝影。
```

多角度定稿圖要求：

```text
使用選定人物和選定造型，生成一張 16:9 人物設定圖，純白背景，同一張圖從左到右依次展示：人物面部特寫、全身正面、全身側面、全身背面。保持同一人物五官、髮型、妝容、服裝、配飾完全一致。畫面清晰，高階時尚設定稿，偶像特徵明顯。
```

造型階段必須輸出：

- 造型名稱。
- 妝容關鍵詞。
- 髮型關鍵詞。
- 服裝輪廓。
- 材質。
- 配飾。
- 適合的 MV 場景。
- 適合的鏡頭動作。

### 5. scene_art_generation

生成純場景藝術圖，不要把人物放進場景裡。這一步只做 MV 世界觀和空間美術。

預設生成 6 個場景方向：

- 主舞臺：用於唱跳、正面表演、強燈光。
- 英雄場景：用於人物站立、慢推、巨物裝置、封面鏡頭。
- 空鏡場景：用於剪輯呼吸、音樂過門、氛圍轉場。
- 特寫材質場景：金屬、晶體、水面、螢幕、紅光、黑紗等細節。
- 儀式/群像空間：用於伴舞、群演、圍繞、注視、展開等戲劇排程。
- 超現實場景：異星、鏡面空間、巨大結構、夢境地貌、反重力空間。

場景圖要求：

- 純場景，不要人物。
- 16:9 橫屏預設。
- 美、有衝擊力、有藝術概念。
- 可以誇張，但要適合後續把人物融合進去。
- 要有明確空間層次：前景、中景、背景。
- 要有明確光線方向和主色調。

參考提示詞結構：

```text
一個真實的未來主義 MV 場景，純場景，無人物。異世界星球，地表佈滿交錯複雜的淡紫色水晶，巨大的晶體結構從地面生長出來，遠處有超現實舞臺輪廓，夢幻、時尚、高階攝影、電影級光影、強空間縱深、視覺衝擊、16:9 橫屏。
```

可擴充套件場景關鍵詞：

- 金屬骨骼大廳、黑色鏡面舞臺、淡紫水晶星球、巨大羽翼裝置、電視牆空間、紅色鐳射房間、雨夜玻璃盒、廢墟音樂節、銀色液態隧道、白色無菌實驗舞臺、黑紗教堂式空間、荒漠巨型雕塑、海底發光劇場。

### 6. music_direction

生成音樂或音樂提示詞。使用當前可用音樂模型。

音樂必須服務 MV 視覺：

- 韓系女團：強鼓點、電子貝斯、hook 明確、適合唱跳。
- 暗黑流行：低頻、耳語感、合成器、神秘氛圍。
- 未來主義：金屬打擊、電子噪聲、冷感合成器。
- 怪誕奢華：絃樂、管風琴感、低頻鼓、戲劇化停頓。
- 夢幻異世界：空靈人聲、合成器 pad、寬闊混響。

輸出：

- 音樂風格。
- BPM 範圍。
- 情緒關鍵詞。
- 歌曲結構：intro / verse / pre-chorus / chorus / bridge / outro。
- 影片節奏建議：快切點、慢鏡頭點、定幀點。

### 7. video_prompt_builder

在所有人物圖、妝造圖、場景圖透過自檢後，再寫影片生成 prompt。

如果影片生成前發現人物、造型、場景任一錨點缺失或質量不足，先按“錯誤處理與模型切換策略”呼叫 `ask_human`，不要直接生成。

影片模型優先順序：

1. `seedance 2.0`
2. `seedance 2.0 fast`
3. `kling O3`

影片生成原則：

- 使用參考生影片功能，把人物錨點、造型錨點、場景錨點融合。
- 人物身份由人物圖控制。
- 服裝妝造由造型圖控制。
- 場景由純場景圖控制。
- 不要讓模型重新設計人物臉、服裝和場景。
- 一個影片片段只表達一個核心鏡頭事件。
- 優先生成多個 3-6 秒片段，再剪輯成完整 MV。

常見鏡頭型別：

- 視覺開場：人物站在巨大場景中，慢慢抬眼，燈光閃爍。
- 唱跳鏡頭：正面近景，中景舞蹈，鏡頭推進，口型精準。
- 造型展示：面部特寫、眼妝、嘴唇、首飾、手部、鞋靴、裙襬、金屬裝置。
- 場景空鏡：晶體、金屬、螢幕牆、舞臺燈、雨地、巨物裝置。
- 儀式鏡頭：伴舞圍繞、群像注視、手勢、光線熄滅、翅膀展開。
- 衝擊鏡頭：快速推近、旋轉、閃光、低角度仰拍、極近特寫。

通用影片 prompt 模板：

```text
史詩級時尚 MV 電影質感，參考 {{Portrait 1}} 的人物身份，參考 {{Styling 1}} 的妝造穿搭，參考 {{Scene 1}} 的場景美術。
```

### 8. mv_editing_plan

把多個影片片段剪輯成 MV 視覺片。

預設結構：

```text
0-5s：強視覺開場，空鏡或人物抬眼。
5-15s：人物主造型登場，近景和全身交替。
15-30s：唱跳/表演段落，快切，配合音樂鼓點。
30-45s：場景切換和造型變化，加入空鏡和特寫。
45-60s：高潮視覺，巨物、群像、燈光、強運鏡，最後定格或慢推收尾。
```

剪輯規則：

- MV 視覺片不需要解釋劇情，重點是視覺衝擊和音樂節奏。
- 每 2-4 秒切換一次視覺重點。
- 人物臉部特寫、全身造型、場景空鏡、舞蹈動作、材質細節要交替出現。
- 音樂高潮使用快切、閃光、旋轉、低角度和群像。
- 音樂過門使用空鏡、慢推、材質特寫和背影。
- 全程預設無字幕，除非使用者明確要求歌詞字幕。

## 自檢

生成影片前必須檢查：

- 人物是否看起來為成年人，且沒有未成年人性感化問題。
- 人物是否好看、有辨識度，不是普通模板臉。
- 妝造是否有明確風格、輪廓、材質和配飾。
- 人物設定圖是否保持同一人物一致性。
- 場景圖是否為純場景，沒有人物混入。
- 場景是否足夠美、有視覺衝擊、有空間層次。
- 影片 prompt 是否清楚引用人物、造型、場景。
- 是否避免字幕、水印、錯誤文字。
- 是否沒有使用真實明星或受版權保護角色。
- 是否按模型優先順序選擇。
- 如果觸發安審失敗，是否先去掉血腥、性感、傷害、未成年感等敏感表達並重試。
- 如果缺少關鍵素材或模型連續失敗，是否透過 `ask_human` 引導使用者選擇是否補素材、換模型或跳過。

## Ask User

不要因為資訊不完整就停下。使用者只給一個方向時，先生成預設方案。

只有以下情況需要追問：

- 使用者沒有給任何音樂或視覺方向，同時也沒有說“自由發揮”。
- 使用者要求復刻真實明星、特定女團成員、影視角色或版權 IP。
- 使用者要求明顯未成年形象、低俗性感化或不安全內容。
- 使用者需要商業品牌植入，但沒有給品牌限制。
- 缺少會影響最終成片質量、交付結果或素材使用方式的關鍵素材。
- 圖片或影片模型報錯、超時、不可用，或同一安審問題連續重試失敗。

優先追問：

1. MV 想偏哪種方向：韓系女團、未來主義、怪誕美學、巨物美學、暗黑儀式感，還是自由發揮？
2. 主角是單人、雙人，還是組合？
3. 預設做 16:9 橫屏可以嗎，還是要 9:16 豎屏？
