## 流程(逐阶段暂停确认)

### 阶段 0 · 开拍前

**开拍前问询卡(下面每一问都是「独立的一问」,在同一张卡里一问接一问问完;绝不把两个问题的内容揉进同一问的选项里,也绝不拆成多张卡。问完停下等上传)**:

> 规则:**每一问只问一件事、给自己那一问的干净选项**;**条件问(第 2 问风格主题、第 5 问人种)一律照常显示,不适用时让用户"留空/跳过"即可,绝不合并进别的问**。

1. **音频(单选,只给这两个选项,别塞别的内容进来)**:你有现成的歌曲 / BGM 吗?
   - 选项 A:`我有现成音频,稍后上传`
   - 选项 B:`没有,帮我生成`
2. **歌曲风格 + 主题(自由输入框;仅当第 1 问选 B「没有,帮我生成」时才需填,选 A 的留空)**:这首歌想要什么风格和主题?(例:`清爽青春感,关于初恋与告别` / `暗黑酷感,关于孤独与反叛`)——**无论填什么,生成音乐一律锁在大 POP 语境**(pop / rap / hip-hop / R&B)。
3. **人声(性别 + 语言)**:要用 / 要生成的人声是哪种?**选性别(男 / 女)+ 演唱语言**(中文 / 英文 / 韩文 / …)。(上传了音频可自动听辨来预填,用户可改)
4. **有无人像 / 造型参考图**:有人脸参考图(或 &lt;15s 视频)/ 造型参考图吗?——**只要有人像参考图 → 主角性别、人种一律以人像参考图为准,第 5 问「人种」留空/跳过**;没有则第 5 问照填。
5. **角色人种(自由输入;仅当第 4 问「没有人像参考图」时才填,有人像参考图就留空)**:主角人种是?**按第 3 问的语言优先推荐**(中文→亚洲、英文→欧美、韩文→亚洲、西语→拉丁…),可自行输入 / 修正。
6. **字幕**:成片要不要字幕?要→选语言(中文 / 英文 / …);不要→无字幕。(字幕只在阶段 5 叠加,生成画面永远零文字)
7. **影调预设**:**A 冷调雕塑/ B 暖调胶片/ C 锐闪颗粒**,选一,全片统一。
8. **画幅**:16:9 / 4:3 / 9:16?
9. **画质**:480p / 720p / 1080p?(粗粝感靠颗粒与调色,不靠低分辨率)

> 结论:**主角性别 = 人声性别**;**主角人种 = 有人像参考图→一律随参考图(第 5 问留空)/ 无人像参考图→按第 5 问语言推荐并经用户确认**。**时长不单独问——由后面【选段】自动定。以上 9 问全在这同一张卡里问,一问一件事、各给各的干净选项,不要相互揉进选项、也不要另开卡。**

**音频就绪 / 音乐确认(先于切片)**:

- **有音频**:用用户上传的音频。
- **无音频**:按上面的\*\*歌曲风格 + 主题 + 人声(性别/语言)\*\*生成一版带歌词人声歌曲(**一律锁定大 POP 语境**)→ **生成后必须暂停,等用户确认音乐没问题(可要求重做/微调),满意后才继续切片**。
  - **⚠️ 生成音乐时严格区分「风格控制」与「歌词」两个字段,别让模型把描述词唱出来**:
    - **风格/主题/情绪/BPM/曲风/人声性别/语言** 这些只填进**风格描述 / 标签 / style 字段(控制项)**,**绝对不要放进会被演唱的歌词字段**。
    - **歌词字段单独另写成一首正经的歌**:按所选**语言**写、贴合**主题**、有**主歌/副歌(Verse / Chorus)结构**、用结构标签(如 ``` [Verse]``[Chorus] ```)分段;这些标签是结构提示、不会被唱。
    - **绝不能把 prompt 里的风格/主题/描述词(如"青春感 indie-pop、关于成长与告别、女声、韩文")一字不差地当歌词唱出来**——那是控制项,不是歌词内容。
    - 如果工具只有单一输入框,就在框里**明确分区**:先写风格标签,再用清晰分隔写真正的歌词,并注明"仅演唱歌词部分、风格标签不演唱"。
    - **音乐提示词整体 ≤ 1024 字符**(风格控制 + 歌词合计);超了就精简描述、歌词取主歌+副歌核心段,别硬堆。

**音频确认后必做两步(先于分镜与生视频)**:

- **① 音频切片(+ 拿歌词)**:把音频切成**多段连续、每段 ≤30s 的切片(按对应视频的条数/秒数一一切分,每段多长取决于该 part/场景需要)**,同时**拿到准确歌词**(**只供内部对齐口型/选段用,绝不写进任何发给模型的 prompt**)——后续对口型段**每段切片作为音频锚点喂给 Seedance 2.5(sd2.5)驱动口型**。**切完必须停下,等用户确认切片再继续。**
- **② 选段**:问"**你想用哪几段来做这支 MV?**"让用户选。**推荐选连续的几段(每段 ≤30s)**(便于段间衔接顺);**推荐挑有 rap/人声/歌词的段做对口型,纯器乐段(intro/beat 间奏)默认不做 lipsync**。**用户选完即自动算出时长(= 所选各段秒数之和 = 视频段数),不用再问"想做多长"**;段数由此步确定。

**造型分流**:按问询卡 Q3 有没有上传人像 / 造型参考图,走下面四种情况。

> **铁律:人像/人脸参考图一律不喂造型模型(Seedream)**(Seedream 只接受**造型参考图**作图参考);**人脸参考图只在最后 Seedance 生视频时**与造型三视图一起喂(锁真脸;**发型由用户选:保持参考图发型 / 换成造型三视图的发型**)。**三视图人脸怎么处理,只看"有没有真人像参考图":有→用纯白圆形贴纸遮脸 + 右下角中文小字标注,无→保留所选 Seedream 造型的脸。**

- **① 只有人像参考图**:人像**不喂 Seedream**;Seedream 按文字 spec 出四造型图(无尾串)→ 用户选 1 → Lib Image 出三视图、**人脸用纯白圆形贴纸完全遮住 + 右下角中文小字"人脸单独提供 · 此图仅用于服装造型参考"**;人像参考图**仅在 Seedance 时**与三视图一起喂(锁真脸;**发型由用户选:参考图发型 / 造型三视图发型**)。

- **③ 人像 + 造型都有**:**只把造型图作 Seedream 图参考、人像不喂** + 补写 spec → Seedream 出四造型图 → 用户选 1 → Lib Image 出三视图、**人脸用纯白圆形贴纸完全遮住 + 右下角中文小字"人脸单独提供 · 此图仅用于服装造型参考"**;人像参考图**仅在 Seedance 时**与三视图一起喂(锁真脸;**发型由用户选:参考图发型 / 造型三视图发型**)。
