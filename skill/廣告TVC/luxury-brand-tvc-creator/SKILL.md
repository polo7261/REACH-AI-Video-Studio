## 一、品类分类（从上传的产品识别品类，拿默认）

每个品类附「节奏基调 / 产品出现时机 / 单镜时长」三个字段（详见下方节奏表），定品类即一并拿到。注意：「单镜时长」指的是**一个 clip 内部**各镜头的建议时长（供模型在这一个 15s clip 内自动切分参考），**不是**让你按这个时长逐镜发起生成。

美妆 / 护肤 — 特点：微距特写、质地流动、肤感光泽、面部情绪、奢华氛围；默认创意手法：演示 + 情感；节奏：中·渐入 / 产品第 3–5s / 单镜 2–3s；品牌：Dior、SK-II、La Mer

奢侈品 / 时尚 — 特点：电影短片式叙事、艺术化构图、极简主义、大量留白；默认创意手法：故事 / 情感（视听奇观风格）；节奏：慢·留白 / 产品第 4–6s / 单镜 3–5s；品牌：Hermès、Chanel、Prada

食品 / 饮料 — 特点：食欲感特写、液体流动、蒸汽/水珠、高饱和、节奏明快；默认创意手法：演示 + 情感；节奏：快·卡点 / 产品第 1–3s / 单镜 1–2s；品牌：Coca-Cola、McDonald's

科技 / 电子 — 特点：产品悬浮、360° 环绕、暗调+霓虹光、未来感、界面动画；默认创意手法：演示 + 动画；节奏：中快·精准 / 产品第 2–4s / 单镜 1.5–2.5s；品牌：Apple、Samsung、Sony

酒类 / 香氛 — 特点：慢动作、光影折射、液体质感、氛围感优先于功能；默认创意手法：情感（视听奇观风格）；节奏：慢·氛围 / 产品第 4–6s / 单镜 3–5s；品牌：茅台、Chivas、Jo Malone

运动 / 户外 — 特点：高速摄影、极限场景、汗水/肌肉特写、励志情绪；默认创意手法：情感 / 故事；节奏：极快·冲击 / 产品第 1–2s / 单镜 0.5–1.5s；品牌：Nike、Adidas、The North Face

汽车 — 特点：大场景、航拍、速度感、极致光影、lifestyle 叙事；默认创意手法：故事（视听奇观风格）+ 演示；节奏：慢起渐快 / 产品第 3–5s / 单镜 2–4s→收快；品牌：BMW、Mercedes、Tesla

金融 / 保险 — 特点：家庭场景、温情叙事、信任感、稳重调性；默认创意手法：故事 + 情感；节奏：中·温情 / 产品视情节 / 单镜 2–4s；品牌：平安、Prudential

地产 / 酒店 — 特点：航拍全景、室内光影、生活方式想象、空间感；默认创意手法：情感 / 故事；节奏：中·舒展 / 空间即产品 / 单镜 2.5–4s；品牌：万科、Four Seasons

定了品类即拿到：默认特点 + 建议创意手法 + 一组旋钮默认档位（见第三节括注）+ 节奏三字段（见第五节节奏表）。客户有特殊要求再覆盖默认。

> 品类名里的真实品牌仅作**抽象风格描述**用（说明这类广告长什么调性），成片不得复现任何特定品牌真实 campaign 的可识别元素（标志性布景、专属视觉符号、真实 slogan/logo），logo 一律换成产品自有 logo。

## 二、五个维度（与用户对话逐项确认）

TVC 商业广告片的 5 个维度。定品类后多数已有默认值，对话只需补齐/修正，不重复问已知项。

1. 广告目的：产品 · 品牌 · 形象 · 促销 · 公益 → 决定信息密度与收尾落点：促销=强 CTA；品牌/形象=logo 收尾；产品=卖点+CTA。

2. 创意手法（＝ prompt 生成骨架）：故事 · 情感 · 演示 · 动画

   故事：完整剧情，建立 → 冲突 → 解决，产品融入情节。

   情感：情绪弧打动人，建立人物/处境 → 情绪高点 → 产品作为解法 → 落主张。用 {{Mixed N}} 锁角色。

   演示：卖点直给，痛点/场景 → 产品登场 → 一镜一卖点 → 效果呈现 → logo + CTA。产品每镜清晰。

   动画：二维 / 三维 / 定格，风格锁定句写最前，风格一致 &gt; 角色一致。

   「视听奇观 / 时尚片」不是单独手法，而是高制作美学风格（运镜密集、美学优先、慢动作、大量留白），常叠加在 故事/情感/演示 上（奢侈、美妆、汽车），靠第三节拆解要素堆出来。

3. 视频时长：15s · 30s · 60s → **决定 clip 数（15s=1 clip / 30s=2 clips / 60s=4 clips）**，并触发生成分流（见工作流 Step 3）。每个 clip 内部再由模型按节奏自动切分镜头（15s≈4–5 镜 / 快节奏 6–8 镜），**这是 clip 内部的事，不是拆成独立生成任务**。

4. 制作方式：实拍 · 动画 · CG 合成 · 混剪 → 决定风格锁定句基底：实拍=电影感商业片基底；动画/CG=对应风格锁定句。

5. 投放场景：TV · OTT · 社媒竖屏 · 户外大屏 → 决定画幅与节奏：TV/OTT=16:9；社媒竖屏=9:16 且前 3 秒更狠；户外大屏=强视觉、弱依赖声音。需要时一稿出双版。

## 三、拆解要素（7 个旋钮 · 选项菜单）

每个维度选一档；斜体括注是「按品类默认」。

1. 灯光设计

   光源：自然光 / 棚拍人工光 / 混合光

   方向：顺光 / 侧光 / 侧逆光 / 逆光 / 顶光 / 底光

   布光：主光 Key、辅光 Fill、轮廓光 Rim/Edge、背光 Backlight、发丝光、体积光/丁达尔 Volumetric、美妆光 Beauty dish、入画实用光源 Practical

   色温：冷调(蓝白) / 暖调(金橙) / 中性 / 冷暖对撞

   特殊光效：霓虹、RGB 染色、耀斑 lens flare、折射光斑、流动光带、频闪

   默认：妆/食=柔光通透暖调；科/汽=暗调 Rim+霓虹；奢=自然窗光；金/地=暖柔自然光

2. 画面色调

   色温：暖调 / 冷调 / 中性 / 冷暖分离 split-tone

   色调：film-scan 自然胶片色、teal-orange 电影调、复古褪色、日系清新、莫兰迪低饱和、赛博霓虹、黑白

   饱和度：高饱和 / 标准 / 低饱和 / 去色单色

   质感叠加：胶片颗粒、漏光 halation、柔光晕、故障噪点

   默认：食=高饱和暖；奢/时尚=低饱和 film-scan；科=冷蓝暗调；汽=teal-orange

3. 镜头语言

   运镜：固定、推/拉、摇 pan、移 dolly、升降 crane、环绕 orbit、跟拍 tracking、手持、稳定器、FPV 穿越

   景别：微距/大特写、特写、近景、中景、全景、大远景、航拍

   角度：平视、仰拍、俯拍、顶视平铺、荷兰角(倾斜)

   构图：居中对称、三分法、框架式、大量留白、满构图、前景遮挡

   镜头特性：广角畸变、长焦压缩、移轴微缩、鱼眼

   默认：妆/科=微距+orbit；汽/运=航拍+tracking+FPV；奢=留白+缓推；食=顶视+升格微距

   补充运镜（按用途分组 · 视听语言更丰富）

   A. 动感/冲击类（适合 食/运/科/促销）

   - 速度变化 speed ramp：正常速→突然升格→再回速，卡点神器
   - 甩镜 whip pan：快速横甩转场，两镜之间「唰」一下
   - 推入接特写 push-in to macro：一镜从中景怼进产品微距
   - 弹动变焦 snap zoom：焦距猛地一顿，强调瞬间
   - FPV 穿越：一镜穿过场景/产品内部，沉浸感拉满

   B. 精密/展示类（适合 科技/美妆/产品 hero）

   - 产品环绕拆解：半环绕 + 部件逐个高亮（治「只怼 logo」）
   - 顶视平铺 flat-lay + 升降：俯拍产品阵列，配升降揭示
   - 轨道横移 dolly/slider：平滑侧移扫过产品排列
   - 微距滑轨：贴着产品表面/质地缓移
   - 对焦转移 rack focus：前景虚→实，把视线引到产品

   C. 情绪/电影感类（适合 奢/酒/汽/金融）

   - 缓慢推近 slow push-in：一点点逼近人物/产品，凝聚情绪
   - 升降镜 crane up/down：垂直运动带出场面或收束
   - 手持微晃 subtle handheld：纪实感、贴近真实（金融/生活流）
   - 反打/过肩：人物互动、对视，建立关系
   - 航拍环绕 aerial orbit：大场景气势（汽车/地产）

   D. 转场/衔接类（替代叠画）

   - 匹配剪辑 match cut：形状/动作/颜色对齐，两镜无缝
   - 动作衔接 action match：上镜的动作在下镜接着完成
   - 遮挡转场 whip/物体擦过：物体扫过镜头切下一场

   以上每种运镜仍要带上运动质量约束（运镜丝滑、不掉帧、环绕/360/旋转类放慢匀速）。

4. 音效音乐

   音乐风格：管弦史诗、电子、流行、嘻哈、lo-fi、爵士、民谣、无音乐留白

   音乐功能：驱动卡点 beat-synced、氛围铺底、情绪烘托

   音效 SFX：产品 ASMR(咬/倒/滋滋/喷雾)、环境音、拟音 foley、机械音、转场 whoosh、UI 提示音

   人声：男/女声旁白 VO、对白、群声、无人声

   混音：空间混响、静音留白、低频氛围 drone

   默认：食=ASMR+明快；科/汽=电子+机械音；奢=稀疏器乐；金=温暖弦乐+旁白

5. 剪辑节奏

   切换速度：快切、中速、慢长镜、一镜到底

   节拍：卡点踩鼓点、自由叙事节奏

   转场：硬切、淡入淡出、匹配剪辑 match cut、遮挡甩切 whip、跳切 jump cut、液体/光效转场（禁止叠画/叠化）

   时间处理：正叙、倒叙、平行剪辑、蒙太奇、定格强调

   特殊手法：定格 freeze frame、变速 speed ramp、故障 datamosh

   默认：食/运/促销=快切卡点；奢/酒=慢长镜；汽=慢起渐快

6. 演员模特

   有无人物：有人 / 无人(纯产品) / 仅手部或局部

   人群定位：年轻、都市白领、家庭多代、儿童、运动人群

   气质风格：高级冷感、亲和温暖、力量运动、潮酷街头、清纯邻家

   多元：本土、国际化混搭、多元族裔

   表演基调：克制写实、生活流、戏剧夸张（表情务必自然可信，禁止夸张怪异表情）

   情绪焦点：面部微表情、眼神、肢体动作、互动关系

   服装（按品类）：贴合品类调性——美妆 = 有一定露肤度但不暴露、时尚大气简约、颜色不跳脱；奢侈/时尚 = 高级极简；运动 = 机能运动装；金融/地产 = 得体生活装

   默认：妆=高级脸+面部微表情+皮肤光泽是重点；运=运动员+肢体；金/地=多代家庭；科/酒=常无人

7. 故事类型

   叙事类型：强叙事(完整剧情) / 弱叙事(氛围奇观串联) / 无叙事(纯展示)

   结构：三段式、线性、非线性蒙太奇、单点演示、问题—解决

   视角：第一人称、旁观者、产品视角、多线并行

   题材原型：生活片段、英雄旅程、before/after 对比、证言代言、演示 demo、品牌宣言 manifesto

   落点收尾：logo 定版、产品 hero、主张字幕、CTA

   默认：金/保险=温情三段式；运=英雄旅程；妆/科/酒=弱叙事；食=生活片段或纯展示

## 四、镜头节奏（治「太慢/产品出太晚/切换生硬」）

> 以下节奏规则规范的是**一个 15s clip 内部**的镜头编排（镜头数、单镜时长、产品出现时机），供模型在这一个 clip 内自动切分参考。它**不改变生成粒度**——生成单位永远是整段 15s clip，不是单镜。

通用节奏原则（不分品类）

第一镜禁止纯场景空镜：有模特 → 第一镜必须是模特在场景里（人 + 环境同框，可带动作）；无模特（纯产品）→ 第一镜可用氛围/悬念开场，但第二镜必须出现产品。

前 3 秒必须出钩子，产品最晚在第 5–8 秒露脸（促销/演示型第 3 秒就要见产品）。

一个 15s clip 内控制在 4–6 个镜头，单镜别超 3–4 秒；快节奏品类（食/运/科/促销）一个 clip 内必须 6–8 镜（见下方硬规则）。

景别按「跳三级」切（大远景→中景→大特写），别在相邻两级之间小碎步挪，切换才不肉、不生硬。

硬切为主，禁叠画/叠化；需要顺滑就用匹配剪辑 match cut 或动作衔接 action match，不用溶解。

分品类节奏表（均指单个 15s clip 内部）

品类 ｜ 节奏基调 ｜ 产品出现 ｜ 单镜时长 ｜ 情绪带动手法

食品/饮料 ｜ 快·卡点 ｜ 第 1–3s ｜ 1–2s ｜ 咬/倒/滋滋声卡拍点，升格+骤停制造馋感

美妆/护肤 ｜ 中·渐入 ｜ 第 3–5s ｜ 2–3s ｜ 慢起→质地特写→睁眼对视→收束到光泽落点

科技/电子 ｜ 中快·精准 ｜ 第 2–4s ｜ 1.5–2.5s ｜ 硬切+机械音效同步，功能一镜一卖点

运动/户外 ｜ 极快·冲击 ｜ 第 1–2s ｜ 0.5–1.5s ｜ 高速摄影+速度变化 speed ramp 推肾上腺素

汽车 ｜ 慢起渐快 ｜ 第 3–5s ｜ 2–4s→收快 ｜ 大场景铺气势→细节切近→尾段加速点燃

奢侈/时尚 ｜ 慢·留白 ｜ 第 4–6s ｜ 3–5s ｜ 长镜+缓推，靠氛围和留白养情绪，不追快

酒类/香氛 ｜ 慢·氛围 ｜ 第 4–6s ｜ 3–5s ｜ 慢动作光影折射，液体质感铺沉浸感

金融/保险 ｜ 中·温情 ｜ 视情节 ｜ 2–4s ｜ 生活片段叙事，情绪弧递进，产品作解法

地产/酒店 ｜ 中·舒展 ｜ 空间即产品 ｜ 2.5–4s ｜ 航拍舒展→室内光影→生活方式想象

快节奏品类硬规则（强约束 · 食品/饮料、运动/户外、科技/电子，以及任何品类的促销目的）：

一个 15s clip 内必须 6–8 镜（不是 4–6），单镜一律 ≤ 2s（运动/户外 ≤ 1.5s），不允许出现超过 2.5s 的镜头（收尾产品定版镜除外，且也不超过 3s）。

一个 clip 的分镜里必须用上至少 2 种动感运镜/切换（speed ramp、whip pan、snap zoom、push-in to macro、卡点硬切、action match 任选），不能整条都是缓推/固定镜。

禁止「缓慢推近」「缓缓」「悠然」这类慢词主导快节奏品类的分镜；镜头动词用「猛推」「疾切」「甩至」「瞬间怼近」等快词，让模型生成的画面动势跟上。

每镜必须有明确动作发生（倒、咬、开、跑、亮、弹），不允许静态摆拍镜连排。

写完一个 clip 的分镜自查一遍总镜数 × 单镜时长 ≈ 15s，凑不齐镜数就说明节奏太慢，回去拆镜（**在这一个 clip 的 prompt 内多写几镜，不是拆成多个生成任务**）。

核心：该快的品类（食/运/科/促销）把产品和钩子往前提、单镜压短、卡点切；该慢的品类（奢/酒）保留长镜留白，但也要有情绪落点、不能平。

## 工作流

### Step 1 · 生成产品三视图 + 同时弹出合并询问卡

用户上传产品图（或产品描述 / 参考片）。识别品类（第一节）、形态/材质/卖点、是否需要 {{Mixed N}} 角色，拿到品类即带出默认特点 + 建议创意手法 + 旋钮默认档位 + 节奏三字段（第四节）。

① 生成产品参考图（贴合产品，建议 GPT Image 以保真；白底、16:9）作一致性锚点：

产品三视图 {{产品三视图}}：正面 / 侧面 / 背面。生成后固定命名为「产品三视图」，供 Step 3 的 @产品三视图 直接挂用。

产品细节三视图 {{产品细节图}}：按功能性取关键细节（榨汁机 = logo / 刀片 / 按键；护肤品 = 瓶身 / 泵头 / 质地）。生成后固定命名为「产品细节三视图」，供 @产品细节三视图 挂用。

后续分镜产品画面一律以这两张为准。

地产 / 酒店等"空间即产品"：无实体产品，改为上传或虚拟生成 5–8 张实景图 {{空间实景}}（虚拟生成按 16:9），替代产品三视图并兼作场景锚点。

反推参考片：先 scripts/extract\_[frames.sh](http://frames.sh) 抽帧读规格，再产同款；**按 15s 一个 clip 整段生成，30s / 60s 拆成 2 / 4 个 15s clip（每个 clip 的 prompt 一次写全、整段生成），绝不拆成很多单镜逐个生成。**

② 生成三视图的同时，立刻弹出一张 ask_human 合并询问卡（不等图生成完，节省时间），一次问全（品类已给默认的只需确认 / 修改，留"你帮我定"；"全你定"就按默认走完）：

时长：15s / 30s / 60s（→ 对应 1 / 2 / 4 个 15s clip）

广告目的：产品 / 品牌 / 形象 / 促销 / 公益

制作方式：实拍 / 动画 / CG 合成 / 混剪

创意手法：故事 / 情感 / 演示 / 动画（可叠加视听奇观 / 时尚片风格）

投放场景：TV / OTT / 社媒竖屏 / 户外大屏（据此定画幅 16:9 或 9:16）

品牌 slogan：有则填（结尾落点用）

旁白：要不要 + 人声（男 / 女 / 中性 + 风格）+ 旁白语言二选一（中文 / 英文）；一律后期配音（视频静音生成）

字幕：无 / 单语（哪种语言）/ 双语（主 + 副两种）

选模特形象（若有模特）：给 3 个选项 =「族裔/地域 + 年龄 + 性别 + 发型」（先不含穿着）；纯产品则跳过

选场景氛围：给 3 个文字选项（场景 + 色调 + 灯光 + 质感 综合成一句），挑 1

选风格种子：只显示中文风格名（蓝橙调电影风 / 高级中性色电影风 / 高饱和复古暖蓝调 / 日系电影风），绝不暴露代码

是否上传服装参考图：有则上传（后续角色三视图用 GPT Image 2 还原）

（各维度含义见第二、三节；旁白文案在 Step 3 出片前写出、给用户确认。）

### Step 2 · 出 moodboard（场景氛围图 + 服装图并行生成 · 需用户确认）

询问卡答完后，场景氛围图与服装图同时生成（并行，节省时间）：

场景氛围图（必须用 Midjourney v8.1）：把选定场景氛围扩写成具体描绘（只写场景/环境，画面不出现产品）作 MJ prompt，末尾拼上选中风格种子代码，并加 --v 8.1 版本参数；MJ 默认出 4 张可挑。风格种子映射：

蓝橙调电影风 → --sref 1998077430

高级中性色电影风 → --sref 1804771136

高饱和复古暖蓝调 → --sref 2498372592

日系电影风 → --sref 1998077430

> 风格种子仅用可公开复用的数字 --sref，不绑定任何个人 --profile 账号档案；如需专属风格请换成自己账号的 profile。

服装图（若有模特，必须用 GPT Image 2）：每人一张【白底、全身展示、16:9】、含 4 套全身 look 的图，据角色设定 + 品类要求用 GPT Image 2 生成（与场景氛围图并行出，不互相等待）；若产品是可穿戴（衣/鞋/包/帽/镜/饰品/表），4 套 look 均以该产品为核心搭配（look = 产品 + 配搭单品，产品以 @产品三视图 为准还原）。

用户选定场景氛围图 + 选定第几套 look 后：

角色三视图（每人一张；白底；16:9；必须用 GPT Image 2 生成，以保证形象/服装还原一致）：按选定形象 + 选定 look 生成，参考服装图并讲清第几套 look（如"采用服装图中第 2 套"）；从左到右 面容特写 ｜ 全身正面 ｜ 全身背面，锁定形象作 {{Mixed N}} 锚点；若上传了服装参考图，同样用 GPT Image 2 按参考图还原。表情自然不奇怪。

可穿戴产品（衣服 / 鞋 / 包 / 帽 / 眼镜 / 首饰 / 手表等穿戴在身的产品）：角色三视图里模特直接穿上 / 背上 / 戴上该产品（以 @产品三视图 为准还原产品外观），产品上身效果与人物形象一次性锁进同一张锚点图——后续分镜里"人 + 产品"的同框状态以这张人物三视图为准；服装图的 4 套 look 也要围绕该产品搭配（look = 产品 + 配搭单品），不与产品调性打架。产品单独特写镜仍以 @产品三视图 / @产品细节三视图 为准。

生成后固定命名为「人物三视图」（多角色为「人物三视图1 / 人物三视图2…」），供 Step 3 的 @人物三视图(N) 直接挂用。

用户确认视觉方向后锁定，再进入下一步——后面分镜严格按选定的模特、场景来写；用户选定的那张场景氛围图固定命名为「场景氛围图」（空间品类实景图命名为「空间实景」），供 @场景氛围图 / @空间实景 挂用。moodboard 是出 prompt 前的把关闸口，也是 @ 锚点的定名闸口。

### Step 3 · 出分镜 prompt → 满意即生成 → 合成成片 → 自动生成字幕

① 时长分流（以 15s 为一个 clip · 生成粒度铁律）

**生成单位 = 一个 15s clip。** 一个 clip = 一条完整连续 prompt（内部含编号分镜，交给模型在这一个 clip 内自动切分）。

- **15s = 1 个 clip**：一条 prompt 整段直出。
- **30s = 2 个 clip**：写 2 条 prompt（前后内容不同、不重复，logo 只在第 2 个 clip 结尾）。
- **60s = 4 个 clip**：写 4 条 prompt（内容各不重复，logo 只在第 4 个 clip 结尾）。

**严禁逐镜生成（强规则）**：编号镜头「镜头1 / 镜头2 / 镜头3…」只是**一个 clip 内部**给模型看的分镜脚本，**绝不允许把每个镜头当成一次独立生成任务一个个去生成**；每个 15s clip 只发起**一次**生成、一次产出整段 15s 画面（内部多镜由模型自动切分与衔接）。凡是「一个镜头一个镜头生成」「按镜头逐条调用 Seedance」都是错的。

**多 clip 并行生成（强规则）**：多个 clip 的 prompt 一次性全部写完、一并给用户确认，确认后所有 clip 同时调用 Seedance 2.0 并行生成——不等第 1 个 clip 出片再生成后续。（若用户明确要求逐 clip 确认再续，可改为逐 clip 生成，但**单位始终是整段 15s clip，绝不降到单镜**。）

**并行/多 clip 下的段间一致性**：不依赖末帧续接，改由锚点承载——各 clip 的 prompt 引用同一 {{场景氛围图}} / {{产品三视图}} / 角色三视图，并写明同一 {{Mixed N}}、同一服装（第几套 look）、同一光线时段；clip 间衔接靠写 prompt 时预先设计好首尾镜头的动作/景别呼应，不穿帮。

② 输出格式（中文编号分镜 · 一条 prompt = 一个 15s clip）

开头固定句（每条 prompt 第一句原样写，不得改动措辞）：参考@场景氛围图作为场景、影调参考，参考@人物三视图作为人物主体，参考@产品三视图、@产品细节三视图作为产品参考。 —— 按实际情况裁剪引用对象：无模特则去掉「参考@人物三视图作为人物主体，」；地产/酒店等空间品类把场景引用改为「参考@空间实景作为场景、影调参考」且每镜须在实拍场景内、不得虚构空间；多个角色写 @人物三视图1、@人物三视图2。除此之外句式与用词固定不变。

@ 引用必须实挂锚点（强约束）：每个 @名称 都必须真实绑定到前面步骤已生成、且用户已确认的对应锚点图——@场景氛围图 = Step 2 用户选定的那张场景氛围图；@人物三视图(N) = Step 2 生成的角色三视图（第 N 位角色）；@产品三视图 / @产品细节三视图 = Step 1 生成的两张产品参考图；@空间实景 = Step 1 的实景图。调用 Seedance 2.0 时把这些图作为参考图随 prompt 一并挂上，@名称 与挂图一一对应、名称完全一致。出 prompt 前先核对：句中引用的每个锚点都已生成且已确认——缺哪张就先回对应步骤补生成，绝不允许 @ 一个不存在的图空引用。多 clip 并行生成时，所有 clip 挂同一套锚点图。

场景由图承载，正文不再用文字描述场景氛围 / 环境 / 色调（否则与图引用互斥）；正文只写品质锁定（电影感 / 广告级）+ 主体 / 动作 / 镜头 / 产品。人物与产品同理：形象以 @人物三视图 为准、产品以 @产品三视图 / @产品细节三视图 为准，正文不再重复描述人物长相与产品外观。

**每个 clip 内部**按 镜头1 / 镜头2 / 镜头3… 编号，每镜写明 景别 + 运镜 + 内容（{{Mixed N}} 或产品的动作与画面）。**这些编号只是这一个 clip 交给模型的内部分镜，整段一次生成，不逐镜发起。**

节奏落地：一个 clip 内的镜头数量、单镜时长、产品出现时机按第四节该品类节奏表来；景别跳三级切、硬切为主、禁叠化。快节奏品类（食/运/科 + 促销目的）每个 clip 必须执行第四节「快节奏品类硬规则」：一个 15s clip 出 6–8 镜、单镜 ≤ 2s、至少 2 种动感运镜、镜头动词用快词、每镜有动作。

第一镜规则：每个 clip 的第一镜不得是纯场景空镜——有模特必须是模特在场景里；无模特则第二镜必须出现产品。

人物运动速度：人物动作按正常速度自然运动，禁止无故慢动作、迟缓漂浮感；升格/慢动作只用于明确设计的强调镜头（如质地拉丝、水花定格），并在该镜写明，其余镜头一律正常速度。

运动质量句（每条 clip prompt 末尾固定加）：运镜丝滑流畅、帧率稳定连贯、不掉帧、不卡顿、不抖动、自然动态模糊；人物动作正常速度、自然流畅，不迟缓；环绕 / 旋转放慢匀速。镜与镜不跳帧、不越轴（守 180° 轴线）。

禁止生成背景音效（每条 clip prompt 固定写明）：视频静音生成，不自动生成任何背景音效 / 环境音；音乐、音效、旁白全部留到 ④ 后期。

旁白文案在此写出给用户确认（按选定旁白语言：中文或英文撰写）；旁白一律留到 ④ 后期配音。

③ 满意即生成

中文 prompt 输出、用户确认后直接调用 Seedance 2.0 生成视频，不需手动粘贴；**每次调用生成一个完整 15s clip（不逐镜）**，调用时把开头固定句引用的全部锚点图（场景氛围图 / 人物三视图 / 产品三视图 / 产品细节三视图，或空间实景）作为参考图随 prompt 一并挂上，@名称 与图一一对应；30s / 60s 的多 clip prompt 一次性全部确认、所有 clip 同时并行生成（不逐段等待、更不逐镜，各 clip 挂同一套锚点图），出片后一起给用户过目。

④ 合成成片 → 自动生成字幕

拼接：30s / 60s 的多个 15s clip 按顺序拼接，统一画幅帧率、处理 clip 间衔接；15s 单 clip 直接成片。

配乐（一律后期生成）：视频静音、无背景音效，音乐后期加——拼片后生成一段，时长严格匹配成片、依实际节奏与调性（食 / 运 / 促销卡点 beat-sync，奢 / 酒 / 香氛铺底，金 / 地温暖器乐）。

旁白后期配音：按选定人声 + 选定旁白语言（中文 / 英文二选一）用 TTS / 配音生成，对齐画面混入；旁白文案按选定语言撰写并已在 ② 给用户确认。

合成完成后自动进入下一步生成字幕（无需用户再触发）：按 Step 1 卡的字幕选择叠加字幕（无 / 单语 / 双语），并在结尾叠品牌 slogan / logo 落点，输出最终成片。

## 完整范例（美妆/护肤 · 演示+情感 · 15s = 1 个 clip · 9:16）

（中文、编号分镜；**一个 15s clip 内部含 5 镜，整段一次生成、不逐镜**。）

```
参考@场景氛围图作为场景、影调参考，参考@人物三视图作为人物主体，参考@产品三视图、@产品细节三视图作为产品参考。高端美妆广告片，电影级杰作，画面干净锐利，浅景深。竖屏 9:16。

镜头2｜大特写微距／固定：指尖从莹润膏体中挑起一缕，质地在升格慢动作中缓缓拉丝（此镜为设计的质地强调镜头）。
镜头3｜特写／横移：膏体沿其颧骨滑过，留下水润光泽，涂抹动作正常速度。
镜头4｜面部特写／缓慢推近：她睁眼望向镜头，露出自信的微笑。
```

## 通用约束

出 prompt 前请对照文末《输出前自检清单》逐项自检（即下列约束的清单版）。

- 每条 prompt 中文交付；用户确认后直接调用 SD2 生成、不需手动粘贴。
- **生成粒度铁律**：**一条 prompt = 一个 15s clip = 一次生成**；15s=1 clip、30s=2 clips、60s=4 clips；编号分镜只是单个 clip 内部分镜、交模型自动切分；**绝不逐镜生成 / 绝不单镜头逐个生成**。30s / 60s 多 clip prompt 一次写全、一并确认、所有 clip 并行生成（如用户要逐 clip 确认可逐个生成，但单位仍是整段 clip）。
- 角色用 {{Mixed N}}，首现写全、后续复用、主宾清晰；演示型确保产品每镜清晰。
- 各 15s clip 之间（并行生成，不逐段续接），务必靠共同锚点（同一 {{场景氛围图}} / {{产品三视图}} / 角色三视图）保持 {{Mixed N}}、服装、场景、光线一致，clip 间首尾镜头在写 prompt 时预先设计呼应，衔接不穿帮。
- 开头固定句（强约束）：每条视频 prompt 第一句原样写「参考@场景氛围图作为场景、影调参考，参考@人物三视图作为人物主体，参考@产品三视图、@产品细节三视图作为产品参考。」（无模特去掉人物段；空间品类改 @空间实景；措辞其余固定不变）。每个 @名称 必须实挂前面步骤已生成、用户已确认的对应锚点图，调用 Seedance 时随 prompt 一并挂上、名称一一对应；禁止空引用不存在的图，缺图先回对应步骤补生成。场景/人物/产品全部由引用图承载，prompt 正文不再用文字描述场景氛围 / 环境 / 色调 / 人物长相 / 产品外观（避免与图引用互斥）；对错以选定图为准。
- 实拍场景（地产 / 酒店等）：用实拍图的品类，开头固定句改引用 @空间实景，最终 prompt 的每个镜头都必须基于 @空间实景 实拍场景，不得另造虚构 / 想象的空间。
- 人物表情务必自然可信，禁止夸张怪异表情。
- 第一镜规则：每个 clip 的第一镜禁止纯场景空镜——有模特时第一镜必须是模特在场景里（人 + 环境同框）；无模特（纯产品）时第二镜必须出现产品。
- 人物运动正常速度：人物动作按现实正常速度自然运动，不能迟缓、漂浮、无故慢动作；升格/慢动作仅限明确设计的强调镜头并写明，其余镜头正常速度。
- 禁止叠画 / 叠化转场。
- 禁止粒子特效（太土）；要做奇观或转场，改用干净的光效或材质质感。
- 可穿戴产品（衣/鞋/包/帽/镜/饰品/表）：模特在角色三视图阶段就直接穿戴该产品（以 @产品三视图 还原），产品上身状态锁进 @人物三视图 锚点；分镜中人物同框镜的产品穿戴状态以 @人物三视图 为准，产品单独特写镜以 @产品三视图 / @产品细节三视图 为准，两者不得冲突（同一件、同一配色）。
- 无模特（纯产品）时：运镜要丰富（多角度、环绕、推拉、微距），不要不停怼 logo；要展示产品的方方面面（如手机 = 镜头 / 屏幕 / 边缘；墨镜 = 镜腿 / 镜片 / 人物佩戴效果），logo 只在收尾落点出现。
- 节奏与切换：一个 clip 内的镜头数量、单镜时长、产品出现时机按第四节该品类节奏表控；景别按「跳三级」切（不在相邻两级碎步挪），硬切为主，需要顺滑用 match cut / action match，禁叠画/叠化。快节奏品类（食/运/科 + 促销目的）每个 clip 强制走「快节奏品类硬规则」：6–8 镜、单镜 ≤ 2s、动感运镜 ≥ 2 种、快词动词、每镜有动作，绝不允许写成慢节奏。
- 运镜要丝滑：每条 clip prompt 末尾固定加运动质量句（不掉帧 / 不卡顿 / 丝滑 + 自然动态模糊）；环绕、旋转类镜头尤其易掉帧，写明"缓慢匀速环绕、平滑连续旋转"并放慢速度。
- 镜头衔接：镜与镜之间不要跳帧、不要越轴（守 180° 轴线规则），机位与运动逻辑连贯。
- 禁止生成背景音效：视频静音生成，不出任何环境音 / 背景音效；音乐 / 音效 / 旁白全部后期加入。
- 一条片只承载一个核心信息点；前 3 秒抓人，结尾必有落点（logo/CTA/主张）。
- 真实品牌名仅作抽象风格参考，不复现特定品牌真实广告的可识别元素、不杜撰真实品牌虚假主张；风格种子只用可公开复用的数字 --sref、不绑定个人 profile；不做涉及真实公众人物的内容；保持适当无害。
