# 场景多视角资料卡

## 適用場景

适用于影视美术、AI视频前期、广告、游戏及室内外场景规划。把文字或参考图整理为同一空间的六视图资料卡，锁定结构、出入口、固定道具和主光，按需增加俯视、产品区与角色活动区。

## 輸出

一张空间与风格一致的场景多视角资料卡，附简明场景分析、方向基准、生成设置和完整提示词。标明未知背面等合理补全项，生成后检查视角关系、主光、道具及实际尺寸；支持少量功能标注或纯画面模式，不自动生成视频。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
