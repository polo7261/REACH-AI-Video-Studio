# 場景多視角資料卡

## 適用場景

適用於影視美術、AI影片前期、廣告、遊戲及室內外場景規劃。把文字或參考圖整理為同一空間的六檢視資料卡，鎖定結構、出入口、固定道具和主光，按需增加俯視、產品區與角色活動區。

## 輸出

一張空間與風格一致的場景多視角資料卡，附簡明場景分析、方向基準、生成設定和完整提示詞。標明未知背面等合理補全項，生成後檢查視角關係、主光、道具及實際尺寸；支援少量功能標註或純畫面模式，不自動生成影片。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
