## 一、國潮子型別（從上傳的產品識別子型別，拿預設；美學基調統一為新中式國潮）

本 skill 只做**新中式國潮**這一種視覺語言，不做歐美時尚片 / 賽博科技感等其他風格。以下按產品所屬子型別給預設特點，但**色彩、紋樣、器物、造型語言一律收攏到新中式國潮**（水墨留白、飛簷斗拱、榫卯窗欞、雲紋/回紋/纏枝紋、宣紙絹帛、中國紅與國潮金、瓷器漆器、書法印章、絲綢刺繡）。**置景偏好「潮」的一面**：優先讓這些東方元素與未來主義/極簡/銀白/鏡面/金屬質感（不鏽鋼、霧面金屬、亞克力透光、懸浮結構、極簡大留白、冷光）碰撞出新意，而非純古典復刻——傳統符號打底，現代材質點睛。

- **茶飲 / 白酒 / 傳統食品** — 特點：茶煙氤氳、酒液掛杯、器皿特寫（茶盞/杯盞/瓷罐）、木質/竹編場景、慢鏡頭意境；預設創意手法：情感 + 演示；參考：茅臺、觀夫山、茶裡
- **美妝 / 國貨護膚** — 特點：微距質地流動、東方膚感、妝造融入國風元素（髮簪/絨花/戲曲妝容意象）、奢華留白；預設創意手法：演示 + 情感；參考：花西子、毛戈平、觀夏
- **服飾 / 新中式穿搭** — 特點：改良漢服/新中式褂衫、面料垂墜特寫、庭院/園林走位、寫意運鏡；預設創意手法：故事 / 情感（視聽奇觀風格）；參考：蓋婭傳說、密扇、朋克大爺
- **家居 / 香氛 / 文創** — 特點：榫卯結構特寫、香爐煙霧、宣紙/木質/銅器質感、靜謐留白；預設創意手法：情感（視聽奇觀風格）；參考：觀夏、失物招領
- **珠寶 / 配飾** — 特點：金銀鏨刻、玉石光澤、慢速環繞特寫、暗調打亮細節；預設創意手法：演示 + 情感；參考：老鳳祥、夢金園
- **地產 / 文旅 / 空間體驗** — 特點：飛簷輪廓航拍、園林借景、光影漏窗、生活方式想象；預設創意手法：情感 / 故事；參考：中式合院專案、古鎮文旅
- **國貨 3C / 潮玩** — 特點：產品本體嫁接國風紋樣、懸浮展示 + 水墨轉場、傳統與現代對撞；預設創意手法：演示 + 情感

> 定了子型別即拿到：預設特點 + 建議創意手法 + 一組旋鈕預設檔位（見第三節括注）；**東方美學基調與固定風格種子對所有子型別統一生效**，客戶有特殊要求可覆蓋具體細節，但不脫離新中式國潮的大方向。

## 二、五個維度（與使用者對話逐項確認）

TVC 商業廣告片的 5 個維度（製作方式不再詢問，固定實拍）。定品類後多數已有預設值，對話只需補齊/修正，不重複問已知項；**影片比例與解析度無預設值，必須問使用者**。

**1. 廣告目的**：產品 · 品牌 · 形象 · 促銷 · 公益\
→ 決定資訊密度與收尾落點：促銷=強 CTA；品牌/形象=主張/slogan 收尾；產品=賣點+CTA。（預設不加 logo，收尾以 slogan 字幕或畫面/產品自然收束為主。）

**2. 創意手法**（＝ prompt 生成骨架）：故事 · 情感 · 演示

- **故事**：完整劇情，建立 → 衝突 → 解決，產品融入情節。
- **情感**：情緒弧打動人，建立人物/處境 → 情緒高點 → 產品作為解法 → 落主張。用 `{{Mixed N}}` 鎖角色。
- **演示**：賣點直給，痛點/場景 → 產品登場 → 一鏡一賣點 → 效果呈現 → slogan/CTA 收尾（預設不加 logo）。產品每鏡清晰。

> 「視聽奇觀 / 時尚片」不是單獨手法，而是**高製作美學風格**（運鏡密集、美學優先、慢動作、大量留白），常疊加在 故事/情感/演示 上（服飾、美妝、珠寶、家居香氛），靠第三節拆解要素堆出來。

**3. 影片時長**：15s · 30s · 60s\
→ 決定分鏡數（15s≈3–5 鏡 / 30s≈6–9 / 60s 更多），並觸發**按 15s 分段生成**（見工作流 Step 4）。

**4. 影片比例**：16:9 · 4:3 · 9:16 · 3:4\
→ 決定成片畫幅（同時用於場景氛圍圖與 Seedance 生成的 `--ar`）：16:9 橫屏（TV/OTT/橫版）、9:16 豎屏（社媒豎版，前 3 秒更狠）、4:3 復古方屏、3:4 豎版。此項**必須讓使用者選**。需要多版時可一稿出雙版（如 16:9 + 9:16）。

> **製作方式不再作為維度詢問**——本 skill 一律走**實拍風格**（電影感商業片基底 + 新中式國潮實拍質感），不做動畫/CG，風格鎖定句固定為實拍基底。

**5. 生成解析度**：480p · 720p · 1080p\
→ 決定 SD2 呼叫時的輸出解析度引數，直接影響成片清晰度與生成耗時/成本；此項**必須讓使用者選擇**，不套預設。

## 三、拆解要素（7 個旋鈕 · 選項選單）

每個維度選一檔；斜體括注是「按品類預設」。

**1. 燈光設計**

- 光源：自然光 / 棚拍人工光 / 混合光
- 方向：順光 / 側光 / 側逆光 / 逆光 / 頂光 / 底光
- 布光：主光 Key、輔光 Fill、輪廓光 Rim/Edge、背光 Backlight、髮絲光、體積光/丁達爾 Volumetric、美妝光 Beauty dish、入畫實用光源 Practical（燈籠/燭火/漏窗光）
- 色溫：冷調(藍白) / 暖調(金橙) / 中性 / 冷暖對撞
- 特殊光效：漏窗光斑、燭火煙霧體積光、絹紗柔光、水墨式明暗暈染、耀斑 lens flare
- *預設：茶飲/白酒/食品=暖調燭光感+體積光；美妝/國貨=柔光通透暖調+髮絲光；服飾=自然窗光+絹紗柔光；家居/香氛=暖木質光+煙霧體積光；珠寶=暗調側逆光打亮細節；地產/文旅=暖柔自然光+漏窗光斑*

**2. 畫面色調**

- 色溫：暖調 / 冷調 / 中性 / 冷暖分離 split-tone
- 色調：水墨黑白灰、中國紅與國潮金對撞、莫蘭迪低飽和國風灰、青綠山水冷調、宣紙米白低飽和、復古做舊絹帛色
- 飽和度：高飽和(節慶/紅金) / 標準 / 低飽和(水墨/文人) / 去色單色(水墨)
- 質感疊加：宣紙紋理、絹絲柔光暈、煙霧氤氳、膠片顆粒
- *預設：茶飲/白酒/食品=暖調+中國紅與金對撞；美妝/國貨=低飽和暖調+宣紙質感；服飾=水墨低飽和+絹絲柔光；家居/香氛=莫蘭迪國風灰；珠寶=暗調高對比+金屬光澤；地產/文旅=青綠山水冷調*

**3. 鏡頭語言**

- 運鏡：固定、推/拉、搖 pan、移 dolly、升降 crane、環繞 orbit、跟拍 tracking、手持、穩定器、FPV 穿越
- 景別：微距/大特寫、特寫、近景、中景、全景、大遠景、航拍
- 角度：平視、仰拍、俯拍、頂視平鋪、荷蘭角(傾斜)
- 構圖：居中對稱、三分法、框架式、大量留白、滿構圖、前景遮擋
- 鏡頭特性：廣角畸變、長焦壓縮、移軸微縮、魚眼
- *預設：美妝/國貨=微距+緩慢 orbit；服飾=庭院移動+跟拍+留白構圖；珠寶=微距+緩慢環繞；茶飲/白酒=頂視+升格微距；地產/文旅=航拍+框架式構圖（漏窗/門洞）*

**4. 音效音樂**

- **BGM 固定為"融合樂"，不開放選擇**：「中國古典樂器演奏的電子音樂」——古箏/琵琶/笛簫/二胡/編鐘等**傳統樂器真實音色**為旋律主體，**深度融合現代電子**（節拍/合成器/低頻律動/取樣），是國風 × 電子的 fusion，非純民樂、非純電子，兩者交織。關鍵詞：`traditional Chinese instruments (guzheng/pipa/dizi/erhu) fused with modern electronic music, neo-Chinese electronic fusion`。
- **BPM 跟片走**：由成片實際節奏/調性定——明快/卡點片偏快強律動，舒緩/情感片偏慢有空間感，片內可變速，不設固定 BPM。
- **生成時機**：**SD2 生影片階段完全靜音**——不生成 BGM、不生成音效/環境音、不生成旁白，只出純畫面；BGM 與旁白全部放到 Step 6 後期合成時加入。
- 音樂功能：驅動卡點 beat-synced、氛圍鋪底、情緒烘托——按子型別和創意手法選功能檔位，但"古典樂器 × 電子融合"的音色基底不變。
- **不做音效層**：成片不含任何音效/環境音（SD2 靜音、後期也不加音效）；成片聲音只有 **BGM + 旁白（如有）** 兩層。
- 人聲：男/女聲旁白 VO、無人聲
- 混音：BGM + 旁白分層混音，旁白清晰度優先（BGM 不可蓋過人聲）。
- *預設：茶飲/白酒=國風電子融合（偏舒緩律動）；美妝/國貨=國風電子融合（電子感更強、節拍清晰）；服飾/家居=國風電子融合（絲竹音色+柔和電子鋪底）；珠寶=稀疏國風電子融合；地產/文旅=國風電子融合（大氣、低頻律動）+旁白*

**5. 剪輯節奏**

- 切換速度：快切、中速、慢長鏡、一鏡到底
- 節拍：卡點踩鼓點、自由敘事節奏
- 轉場：硬切、淡入淡出、匹配剪輯 match cut、無縫變形 morph、遮擋甩切 whip、跳切 jump cut、液體/光效轉場（**禁止疊畫/疊化**）
- 時間處理：正敘、倒敘、平行剪輯、蒙太奇、定格強調
- 特殊手法：定格 freeze frame、變速 speed ramp、故障 datamosh
- *預設：茶飲/促銷=中速卡點；服飾/家居/珠寶=慢長鏡寫意；地產/文旅=慢起漸快*

**6. 演員模特**

- **有無人物：強制有人像介入**——不管什麼子型別、什麼創意手法，每條廣告都必須有人的存在（可以是正面出鏡的模特，也可以只露手部/區域性肢體，比如倒茶的手、佩戴首飾的動作、拂過面料的指尖），**不允許純產品無人化呈現**。
- 人群定位：年輕、都市白領、家庭多代、兒童、運動人群
- 氣質風格：高階冷感、親和溫暖、力量運動、潮酷街頭、清純鄰家
- 多元：本土、國際化混搭、多元族裔
- 表演基調：剋制寫實、生活流、戲劇誇張（**表情務必自然可信，禁止誇張怪異表情**）
- 情緒焦點：面部微表情、眼神、肢體動作、互動關係
- 服裝（按子型別）：貼合新中式國潮調性——**統一以改良漢服/新中式褂衫/立領盤扣等為基底，顏色取中國紅、國潮金、青綠、水墨灰**；美妝 = 有一定露膚度但不暴露、妝造融入國風元素（髮簪/絨花）；服飾 = 高階新中式成衣、面料垂墜感強；珠寶/家居/地產 = 得體新中式生活裝
- *預設：美妝/國貨=東方高階臉+面部微表情+**皮膚光澤是重點**；服飾=新中式造型+肢體儀態；地產/文旅=多代家庭；茶飲/白酒/珠寶=以**手部/區域性人物動作**為主介入（如執壺倒茶的手、佩戴首飾的動作），器物/產品仍是視覺主角，但每鏡保證有人的存在*

**7. 故事型別**

- 敘事型別：強敘事(完整劇情) / 弱敘事(氛圍奇觀串聯) / 無敘事(純展示)
- 結構：三段式、線性、非線性蒙太奇、單點演示、問題—解決
- 視角：第一人稱、旁觀者、產品視角、多線並行
- 題材原型：生活片段、英雄旅程、before/after 對比、證言代言、演示 demo、品牌宣言 manifesto
- 落點收尾：產品 hero、主張/slogan 字幕（有 slogan 時用影片模型直出）、CTA（**預設不加 logo 定版**，除非使用者明確要求）
- *預設：地產/文旅=溫情三段式；服飾=意境線性敘事；美妝/珠寶/茶飲=弱敘事(氛圍奇觀串聯)；家居/香氛=弱敘事或純展示*

## 工作流

### Step 1 · 使用者上傳產品

使用者上傳產品圖（或產品描述 / 參考片）。從產品識別：所屬子型別（查第一節表）、產品形態/材質/賣點、是否需要 `{{Mixed N}}` 角色。拿到子型別即帶出預設特點 + 建議創意手法 + 旋鈕預設檔位。\
**【強制步驟 · 不可跳過】上傳後隨即生成兩張產品錨點圖**（後續所有分鏡產品一致性的基礎）：**必須以【使用者上傳的產品圖】作參考圖（image reference / 圖生圖），絕不憑空文生圖**——把原圖餵給生成模型（建議 GPT Image 保真），據真實外形/顏色/材質/比例/品牌標生成；多張則全部喂入。**白底、16:9**，作為錨點 `{{產品三檢視}}`（正/側/背）+ `{{產品細節圖}}`（按功能取關鍵細節，如護膚品=瓶身/泵頭/質地）。兩張缺一不可，生成後與原圖比對，外形/配色/logo 對不上就重出；進 Step 2 前須已產出這兩張。後續分鏡產品畫面一律以此為準。

> 若**只給文字描述、無產品圖**：先告知"只能按描述文生圖、可能與真實產品有出入"，追問關鍵外觀後再生成；使用者補傳圖後須重做。\
****地產/酒店等"空間即產品"品類**：無實體產品，改讓使用者**上傳 5–8 張實景圖**（或 skill 虛擬生成 5–8 張，按 16:9），作為 `{{空間實景}}`——**替代產品三檢視，並同時充當場景錨點**。後續分鏡空間/佈景/光線一律以此為準；空間本身無人，但仍須選定人物形象，讓人以生活方式場景（漫步/品茶/伏案）出現，不通篇空鏡。\
****反推參考片**：先 `scripts/extract_frames.sh` 抽幀讀規格（前 3 秒鉤子 / 節奏 / 運鏡 / 落點 / 屬於哪個子型別），再產同款，並統一改寫為新中式國潮美學（不改變原片敘事結構與節奏，只替換色彩/紋樣/器物/造型為國潮語言）；絕不憑空描述沒看過的畫面。**反推同樣按 15s 一段整段生成（編號分鏡，一段連續 prompt 出一整段），30s / 60s 拆成多個 15s 段順接——不要拆成很多單鏡分別生成。**

### Step 2 · 一張問詢卡一次性確認所有維度（連續問詢，統一記錄）

**用一個** `ask_user_input` **問詢卡把下列各項一次性拋給使用者**（連續觸發、一張卡收齊），**不要問一步停一步**；使用者在同一張卡里填完，統一記錄後再往下走。需要確認的項：

1. **目的**（品牌/形象、產品賣點、促銷帶貨…）
2. **創意手法**（故事 / 情感 / 演示；製作方式不問，固定實拍）
3. **時長**（15s / 30s / 60s）
4. **影片比例**（16:9 / 4:3 / 9:16 / 3:4，單選，無預設，必選）
5. **生成解析度**（480p / 720p / 1080p，單選，無預設，必選）
6. **品牌 slogan**（有則填、用於結尾落點字幕；無則留空。**預設不加 logo，不詢問 logo**，除非使用者主動要求）
7. **旁白**：是否需要旁白 → 若需要：人聲（男/女/中性、風格、語言）+ **是否需要字幕（中文 / 英文 / 中英雙語 / 不要）**。（旁白一律後期用 TTS/配音加入，無"寫進 prompt"選項；字幕也在最後合成前加入；旁白文案不在此卡填，留到分鏡表格階段由 skill 先擬、給使用者過目確認。**未選旁白則不問字幕。**）

品類已給預設的項只需確認有無修改、不重複追問；除影片比例/解析度外各項可選"你幫我定"，使用者說"全你定"就按預設填其餘項，但影片比例、解析度仍需明確選。**收齊這一張卡後，維度與旁白偏好一次性鎖定，進入 Step 3。**

### Step 3 · 出 moodboard（先問參考圖 → 逐項選文字 → 按分流生成圖 · 需使用者確認）

**0. 先問角色參考圖（在選文字方向之前，問完必須停下等使用者上傳**）若有模特，先用 `ask_user_input` 問一句：**"你有人臉參考圖或造型參考圖嗎？（人臉照片、想參考的服裝/造型圖都可以傳，也可以兩者都傳）"** 問完必須停頓，讓使用者把參考圖上傳到對話方塊（有的話）再往下走。

**鐵律：人臉/人像參考圖一律不喂 MJ**（MJ 只接受**造型參考圖**作 image reference）；人臉圖只在最後 SD2 生影片時與三檢視一起喂，鎖真臉真發。**三檢視人臉是否遮擋只看有無真人臉圖：有→用白色圓形貼紙遮臉+右下角中文標註（詳見下方角色三檢視），無→不遮**（MJ 臉即身份，也作 SD2 人臉參考）。

按使用者上傳情況分四種（都先"理解參考圖/文字意圖 + 補寫成完整國潮造型 spec"，不丟圖照搬；流程統一為 **MJ 出正面圖 → LibImage 出三檢視**）：

- **① 只有人臉參考圖**：人臉不喂 MJ，MJ 按文字 spec 出圖；三檢視**貼紙遮臉+標註**，人臉圖僅 SD2 階段與三檢視一起喂（鎖真臉真發）。
- **② 只有造型參考圖**：造型圖**作 image reference 喂 MJ**；三檢視**不遮臉**（MJ 臉即身份，也作 SD2 人臉參考）。
- **③ 人臉+造型都有**：**只喂造型圖、人臉不喂**；三檢視**貼紙遮臉+標註**，人臉圖僅 SD2 階段喂。
- **④ 都沒有**：走「選模特形象文字」正常問；三檢視**不遮臉**（MJ 臉即身份）。

**先一步步用文字選定方向，全部選完再生成圖。** 文字選擇逐項 `ask_user_input`，一次一項，每項 3 個選項 + "換一批"口子：

1. **選模特形象文字（④都沒有時必問；①③有人臉參考圖時只問年齡段/氣質/髮型方向，長相以參考圖為準，不必再選族裔）**：給 3 個形象選項，每個 =「族裔/地域（東亞 / 亞裔混血 / 國際化…）+ 年齡 + 性別 + 髮型」，**此處先不寫穿著**（服裝/造型留到 MJ 正面圖環節，且統一為新中式國潮造型），例如：

   - 東亞青年女性，盤髮簪花
   - 東亞中年男性，利落短髮
   - 亞裔混血青年女性，長直髮

   形象要貼產品/品牌調性，不隨機。**本 skill 強制每條廣告都要有人像介入，此項不可跳過**（即便以器物/產品為視覺主角，也要選定負責手部/區域性出鏡的人物形象）。

2. **選場景氛圍**：給 3 個文字選項，每個把「場景/置景 + 色調 + 燈光 + 質感」綜合成一句。**方向不走純古典復刻，而是「中式美學元素 × 未來主義/極簡/金屬質感」的碰撞**——把東方符號（窗欞/月洞門/水墨/雲紋/園林輪廓/器物）與現代材質語言（銀白/鏡面/不鏽鋼/亞克力/霧面金屬/極簡大留白/冷光/懸浮結構）結合，出新意。\
   **尺度硬要求：必須是能容納全身模特走位的大場景（全景 / 大遠景尺度）**——是"可走進去的空間/建築/環境"，不是桌面裝置或區域性檯面；要有縱深、地面、可站立活動的餘量，讓後面含模特的分鏡能把人完整放進畫面。例如：

   - 極簡銀白挑高展廳，懸浮巨型月洞門鏡面裝置貫穿全景，冷調柔光 + 一線暖金描邊，大留白縱深
   - 未來感金屬長廊/水景大廳，水墨煙霧漫過不鏽鋼地面，冷白頂光 + 低飽和青灰，可容人行走
   - 霧面亞克力屏風矩陣圍合的開闊空間，隱約雲紋透光，中國紅點綴於銀灰冷調間，硬朗定向光 + 地面延展

   （若品類/客戶更偏傳統，也可給偏古典的一版，但同樣須是大場景；預設優先給這種"新中式 × 未來極簡"的創新置景。）使用者挑 1。

**文字方向鎖定後，按順序生成參考圖：**

- **場景氛圍圖**：**呼叫 Midjourney 生成**。把選定的場景氛圍**擴寫成具體描繪**（場景細節/光線/色調/質感/構圖）。**東方符號 × 現代材質碰撞**：東方元素（窗欞/月洞門/水墨留白/雲紋回紋/園林輪廓/宣紙絹帛/中國紅與國潮金等）**結合**未來主義/極簡/金屬語言（銀白/鏡面/不鏽鋼/霧面金屬/亞克力透光/懸浮結構/極簡大留白/冷光），避免純古典堆砌。**尺度必須是大場景**：MJ prompt 裡顯式寫全景 / 大遠景 / 廣角、挑高開闊、有地面與縱深（如 `wide establishing shot, expansive interior, high ceiling, spacious, deep perspective, room to fit a full-body figure`），確保這張空鏡背景後續能完整塞下全身模特走位——不要出成桌面裝置或區域性特寫。**必須純空鏡**：只有環境，禁產品/人物/人影/手部/動物/文字/logo，prompt 顯式加否定詞（`empty scene, no people, no product, no text, uninhabited`），供後續所有鏡頭複用為背景。**風格種子固定** `--sref 4608797467 --profile nn1ntrp` **+** `--v 8.1`（不詢問、不展示程式碼），`--ar` 取 Step 2 所選比例。**最終 MJ prompt = 大場景描繪 + 空鏡否定詞 + 固定種子（含** `--v 8.1` **與** `--ar`**）**。（預設出 4 張可挑；帶出主體、或場景太小塞不下人，判不合格重出。使用者自帶參考圖可疊 `--cref`/`--iw`，但不可去掉固定種子、不可放寬空鏡與大場景約束。）
- **MJ 造型圖（若有模特）**：**MJ V8.1 + 固定風格種子** `--sref 4608797467 --profile nn1ntrp`**，**`--ar 3:4`。**只出一組正面圖，構圖儘量全身/大半身**（看清整套造型搭配/下裝/鞋履/廓形，至少大腿以上，能全身則全身），臉部清晰；同一段 prompt 跑一次（預設 4 張），不拆分放大，直接 4 選 1。取景顯式寫"全身或大半身正面站姿，完整展示整套造型與鞋履"。**分流按①-④：僅②③把造型圖作 image reference 喂 MJ，人臉圖任何情況不喂**；spec 結合場景氛圍+模特形象+國潮造型語言（改良漢服/立領盤扣/中國紅國潮金/雲紋回紋）。**生成後停下，用 4 選 1 選項讓使用者挑**——選項須標明每張對應 MJ 四宮格的位置：**1（左上）、2（右上）、3（左下）、4（右下）**（對應 MJ 預設 2×2 出圖順序），選定後再往下。
- **角色三檢視（每人一張，16:9）**：**用 LibImage 生成**（不用 MJ），**據使用者選定正面圖擴寫**——白底、**全身左/中/右（正/側/背）三視，非頭部特寫**，比例/造型（含服裝）與所選正面圖一致。**人臉處理按 Step 3.0 分流**：①③有人臉參考圖 → **用白色圓形貼紙完整遮住每個人臉（三個檢視的臉都遮），並在圖片右下角加中文小字標註"人臉單獨提供 · 此圖僅用於服裝造型參考"**（真臉留給 SD2 階段的人臉參考圖去鎖）；②④無人臉參考圖 → 保留 MJ 正面圖的臉、不遮。三檢視即 `{{Mixed N}}` 一致性錨點，表情自然。**造型參考圖與 MJ 結果有出入時，以使用者選定的 MJ 正面圖為準。**

隨圖附一句概念關鍵詞 + 鎖定的旋鈕檔位清單（7 維各一檔）。\
**使用者確認後視覺方向鎖定，才進入下一步**——後面分鏡嚴格按選定的模特、場景氛圍來寫。moodboard 是出 video prompt 前的把關閘口。

### Step 4 · 按時長分段（不問模式，統一 15s 整段生成）

**只有一種生成方式：以 15s 為單位，每段一條連續 prompt 一次性整段生成**（內部按 鏡頭1 / 鏡頭2 / 鏡頭3… 編號分鏡，每鏡寫明景別 + 運鏡 + 內容，格式見 Step 5）。**不做逐鏡分幀生成、不讓使用者選模式。**

- **15s**：整片一張分鏡表格（Step 5.0）→ 確認 → 展開 prompt 生成整段。
- **30s**：分鏡表格**整片一次出完**（第1段 0–15s、第2段 15–30s 全列在一張表）→ 使用者一次確認 → **兩段 prompt 併發同時生成**（各段以統一 `{{Mixed N}}`/服裝/場景/光線為錨點保持一致，按順序可拼接）。**兩段必須不同內容、推進敘事，不重複鏡頭或動作；前 15 秒結尾不做落點定版，落點（有 slogan 則 slogan 字幕，預設不加 logo）只放在後 15 秒結尾。**
- **60s**：分鏡表格**整片一次出完**（四段全列在一張表）→ 使用者一次確認 → **四段 prompt 併發同時生成**（統一錨點、可順序拼接）。**只在最後一段結尾做落點定版（有 slogan 則 slogan 字幕，預設不加 logo），中間各段不收落點。**

> **兩條必含鏡頭（見 Step 5，多段時按整片計）**：① 全片**至少一鏡是產品使用特寫**（可放在任意一段）；② **尾版（最後一段的最後一鏡）必須是模特與產品同框的中近景**（能穿戴則佩戴、只能用/吃喝則手持）。

### Step 5 · 按 Seedance 2.0 格式輸出（先出分鏡表格 → 再展開 prompt）

**5.0 分鏡表格確認（整片一次出完；確認關口在此）分鏡表格一口氣出完整片**——該多少秒就列多少：15s 一段、30s 兩段、60s 四段，**全部鏡頭列在同一張表裡**（按 15s 分段標註段落，如「第1段 0–15s」「第2段 15–30s」），讓使用者一次看到全片全貌、一次確認或修改。**分鏡表格是本環節唯一需要使用者確認鏡頭內容的關口**；表格確認後，展開 prompt 與調 SD2 生成屬於內部執行，**不再把 prompt 拋給使用者二次確認**。表格列：**鏡號 ｜ 段落 ｜ 景別 ｜ 運鏡 ｜ 畫面內容（**`{{Mixed N}}`**/產品動作）｜ 旁白/VO ｜ 時長(s) ｜ 備註**。

- **旁白/VO 列**：把該鏡對應的旁白文案寫在這一行（按鏡分行、畫面與詞對齊）；連貫長句跨數鏡時可合併寫在相應幾行。旁白鬚貼合已確認的目的與落點、卡住時長（約 15s 30–40 字 / 30s 60–80 字 / 60s 120–160 字，按語速調整）。**不需要旁白**（Step 2 未選旁白）則此列留空/標"無"。
- 表格須體現兩條必含鏡頭（產品使用特寫、尾版模特與產品同框）與收尾落點。**每一鏡（含產品特寫）的畫面/備註都要標明發生在選定場景內**，產品特寫註明"場景內承託物 + 淺景深虛化"，不允許出現白棚/純色底。

> 旁白的**是否需要 / 人聲**已在 Step 2 問詢卡確認；此處只是把文案隨分鏡一起過目。旁白**一律後期加入**（SD2 靜音，不寫進 prompt），留到 Step 6 配音。（BGM 也不在此處理：固定國風電子融合樂、BPM 隨片，留到 Step 6 合成前生成；**SD2 生影片完全靜音、無任何聲音**。）

**5.1 展開 prompt 並多條併發生成（表格已確認；不逐段停頓**）整片表格既已在 5.0 一次確認，**把整片按 15s 分成的所有段一次性全部展開成各自的連續 prompt，多條併發同時提交 SD2 生成**——**不再一段一段等使用者確認**。各段仍以統一的 `{{Mixed N}}` / 服裝 / 場景 / 光線為錨點保持一致、按順序可拼接、銜接不穿幫；生成完成後一併交付、進入 Step 6 合成。15s 單段則單條生成。

**★ 產品一致性強約束（防飄核心，最高優先順序）**★產品"越到後段越飄、結構/比例走樣"的根因是後續段落丟了產品參考。因此：

- **每一段 15s 生成都必須把同一組產品參考作為 image reference 餵給 SD2——不是隻在開頭喂一次**：每段輸入都帶上 `{{產品三檢視}}` + `{{產品細節圖}}`，**全片各段喂的是完全相同的這兩張，不得替換、不得省略、不得只餵給第一段**。併發的每一條 prompt 都要獨立帶齊這組產品參考。
- **prompt 正文對產品顯式鎖定**：凡出現產品的鏡頭，都要寫明"產品外形/比例/結構/配色/logo 嚴格以 `{{產品三檢視}}`+`{{產品細節圖}}` 為準，保持與參考圖完全一致，不得變形、不得改色、不得挪動或杜撰 logo/文字"。
- **保證產品可對齊**：產品出現時**完整入畫、清晰、不被過度遮擋**（使用鏡可露手，但產品主體與 logo 要看得清），避免因殘缺/糊/大面積遮擋讓模型自行腦補而走樣。
- 生成後**逐段比對**產品與錨點圖，形狀/比例/logo 一飄就**重生該段**（並檢查該段是否漏餵了產品參考）。

嚴格按已確認的 moodboard + 分鏡表格來寫。**每條輸出 prompt 的第一句固定為引用場景圖**：

> 請參考 `{{場景氛圍圖}}` 作為場景氛圍。\
****地產 / 酒店等需實拍圖的品類**：第一句改為引用 `{{空間實景}}`，且**每個鏡頭必須發生在該實拍場景內**，不得使用虛構 / 想象的空間。

隨後正文**只寫品質鎖定（電影感/廣告級）+ 主體 / 動作 / 鏡頭 / 產品**，**不再文字描述場景氛圍 / 環境 / 色調**（場景一律由選定的 `{{場景氛圍圖}}` 承載，寫進正文會與圖引用互斥；場景對錯以選定圖為準）。

- **所有鏡頭都在選定場景內，產品特寫也不例外（禁跳白棚）**：**包括產品特寫 / 微距 / 使用鏡頭在內的每一個鏡頭，背景都必須是選定的** `{{場景氛圍圖}}` **那個環境**，絕不能突然切到白棚 / 純色底 / 與全片割裂的空間。產品特寫可讓產品"靜置於場景中的合理承託物上"（如竹林裡的展示臺/石臺、茶室的案几、展廳的懸浮臺座）並對背景做**淺景深虛化**，既突出產品又保留可辨認的場景氛圍。prompt 裡對產品特寫鏡顯式寫"背景為 `{{場景氛圍圖}}` 的環境、淺景深虛化，非純色棚拍"。
- **角色人臉鎖定**：①③"有人臉參考圖"時，`{{Mixed N}}` 首現寫明"臉取自人臉參考圖（真臉真發），造型/身形取自三檢視"，並把人臉圖+三檢視一併作輸入；②④"無人臉參考圖"則直接以三檢視（含 MJ 臉）為準。
- **輸出語言 = 中文。**
- **編號分鏡格式**：一段 prompt 內按 **鏡頭1 / 鏡頭2 / 鏡頭3 / 鏡頭4…** 順序排列，每個鏡頭寫明：**景別**（微距/特寫/近景/中景/全景/航拍…）+ **運鏡**（固定/推拉/環繞/跟拍/升降…）+ **內容**（`{{Mixed N}}` 或產品的動作與畫面）。
- **必含鏡頭 1 · 產品使用特寫（不可缺）**：分鏡裡**至少要有一鏡是"正在使用產品"的特寫/微距畫面**——刷子掃過眼影盒的粉、手指輕觸乳霜抹過肌膚的質地、執壺將茶湯注入杯盞、指尖劃過面料等，按品類對應產品的真實使用動作，突出質地/觸感/功能細節。**此鏡背景同樣在選定場景內、淺景深虛化，不許跳白棚。**
- **必含鏡頭 2 · 尾版模特與產品同框（不可缺）**：**最後一鏡（尾版）必須是模特與產品一起露出的中近景**——**能穿戴的就佩戴**（項鍊/首飾=模特佩戴後的中近景、服飾=上身效果），**只能用/吃喝的就手持**（美妝護膚=手持產品、茶飲酒水=舉杯/持瓶），讓產品與人同框收尾。此鏡可與結尾落點句（slogan 字幕）疊合。
- **整段連續 prompt（唯一格式）**：每段 15s = 一條連續 prompt = 第一句引用 `{{場景氛圍圖}}` → 品質鎖定句（電影感/廣告級，不含場景氛圍與色調描述）→ **鏡頭1 / 鏡頭2 / 鏡頭3…（每鏡景別+運鏡+內容）** → 收尾落點句（**有 slogan 則用影片模型直出該 slogan 字幕；預設不加 logo，除非使用者明確要求**）。中文整條交付，一次性整段生成，不逐鏡分幀。
- **兩級節奏：表格一次確認、影片多條併發**：鏡頭內容的確認關口只有 5.0 的整片表格（一次過全片，prompt 不再二次確認）；**影片生成為多條 15s prompt 併發同時跑，不逐段停頓確認**，各段保持錨點一致、可順序拼接。
- **聲音處理：SD2 階段完全靜音（無任何聲音）**：所有時長的 SD2 prompt 都**不寫任何聲音**——不要 BGM/背景音樂、不要音效/環境音、不要旁白、不要單音/音階/樂器音/節拍等一切聲音；**SD2 只生成純畫面（靜音影片）**。旁白與 BGM 全部留到 Step 6 後期合成時加入。prompt 正文只寫畫面（主體/動作/鏡頭/產品），不出現任何聲音描述。
- **旁白**：SD2 靜音，旁白**一律不寫進 prompt**，全部留到 Step 6 後期用 TTS/配音加入（文案已在 5.0 表格確認，人聲按 Step 2 問詢卡的選擇）。
- **生成解析度**：按 Step 2 確認的 480p / 720p / 1080p，呼叫 SD2 時設定對應輸出解析度引數（不寫進 prompt 正文，作為生成呼叫的獨立引數）。
- **影片比例**：按 Step 2 確認的 16:9 / 4:3 / 9:16 / 3:4，呼叫 SD2 時設定對應畫幅（Step 3 的場景氛圍圖 `--ar` 也應與此一致，保證背景圖與成片同畫幅）；正文可在開頭點明畫幅（如"橫屏 16:9"/"豎屏 9:16"）。
- **影調強化句（品質句後固定追加）**：如"廣告級商業調色，畫面通透明亮、層次分明，色彩飽和自然不發灰，高光與材質光澤銳利，避免發暗/發灰/對比不足的下沉感"，核心訴求（通透/明亮/銳利/不發灰）必留。
- **運動質量句（末尾固定加）**：運鏡絲滑、幀率穩定、不掉幀/卡頓/抖動、自然動態模糊；環繞/旋轉鏡頭額外寫"緩慢勻速環繞、平滑連續旋轉"並放慢（最易卡頓，寧慢勿快）。
- 詳見 `references/seedance-output.md`（景別/運鏡/Cut 詞彙、續接寫法、各手法範例）。

### Step 6 · 影片合成、旁白配音、字幕與配樂（成片輸出）

使用者用上面 prompt 在 Seedance 生成片段後，回到本步收尾成片：

- **剪輯合成**：**30s / 60s 的多段按分鏡順序拼接成完整成片**（用 ffmpeg / 剪輯管線），統一畫幅與幀率、處理段間銜接；15s 單段可直接成片。
- **旁白後期配音（Step 2 選了需要旁白時）**：SD2 影片靜音，按選定人聲用 TTS / 配音生成旁白（文案已在分鏡表格確認），對齊畫面後混入。
- **加字幕（Step 2 選了需要字幕時）**：按選擇加旁白字幕——**中文 / 英文 / 中英雙語**，與旁白文案一致、隨旁白節奏對齊上屏；樣式簡潔不搶畫面（貼合新中式國潮氣質）。字幕在本步合成前加入；未選字幕則不加。
- **生成配樂（所有時長都在此步統一生成，不隨 SD2 出）**：鏡頭完成、拼接成片後，生成一段國風電子融合樂（古典樂器 × 現代電子，見第三節），**BPM 依成片實際節奏/調性定**（快片強律動、慢片有空間感，片內可變速），時長嚴格匹配成片；SD2 影片為靜音畫面，將 BGM 與後期旁白（如有）一併混入，旁白優先、BGM 不蓋人聲，輸出最終帶樂+旁白版本。

## 通用約束（速查 · 詳見對應 Step）

- **產品錨點兩圖必做**：上傳產品後、確認維度前，\*\*必須以上傳產品圖為參考（圖生圖，非文生圖）\*\*生成 `{{產品三檢視}}`+`{{產品細節圖}}`（白底 16:9），外形/配色/品牌標對不上就重出，不可跳過；空間即產品（地產/酒店）以 `{{空間實景}}` 替代。
- **產品防飄（每段必喂參考）**：SD2 生影片時，**每一段 15s 都要把同一組** `{{產品三檢視}}`**+**`{{產品細節圖}}` **作 image reference 喂進去**——不是隻喂開頭一段；產品出現鏡要完整清晰不被過度遮擋，prompt 顯式寫"產品嚴格以錨點圖為準、不變形/不改色/不動 logo"；逐段比對，一飄就查是否漏喂並重生該段。
- **只做新中式國潮**：場景/道具/紋樣/色彩/造型都不脫離國潮語言，不混歐美時尚/賽博等。
- **風格種子固定**：MJ 統一 `--sref 4608797467 --profile nn1ntrp` + `--v 8.1`，不展示程式碼、不給選項、不許更換。
- **造型分流**：先問人臉/造型參考圖，按①只人臉②只造型③都有④都沒有決定 MJ 是否帶 image reference 及三檢視人臉是否遮擋（**人臉圖永不喂 MJ，只在 SD2 階段喂**；有人臉圖→三檢視用白色圓形貼紙遮臉+右下角中文小字"人臉單獨提供 · 此圖僅用於服裝造型參考"，無→留 MJ 臉）。MJ 只出一組正面圖（儘量全身/大半身、`--ar 3:4`）跑一次 4 選 1（選項標 1 左上/2 右上/3 左下/4 右下），選定後 LibImage 擴寫全身三檢視鎖 `{{Mixed N}}`。
- **場景氛圍圖必為純空鏡 + 大場景**：只有環境、禁產品/人物/人影/手部/動物/文字/logo，prompt 顯式寫否定詞（no people/no product/no text/empty scene）；且必須是**能容納全身模特走位的全景/大遠景空間**（挑高開闊、有地面縱深，非桌面裝置或區域性檯面），帶主體或太小塞不下人即不合格重出。
- **場景由圖承載**：分鏡場景一律由選定的 `{{場景氛圍圖}}`（或 `{{空間實景}}`）承載，**正文不再文字描述場景/環境/色調**；實拍圖品類每鏡必須發生在 `{{空間實景}}` 內，不得另造虛構空間。**產品特寫/微距/使用鏡頭也必須在選定場景內**（產品可靜置於場景中的承託物上 + 淺景深虛化），**嚴禁跳白棚/純色底**。
- **兩級節奏：表格一次確認、影片多條併發**：鏡頭內容的唯一確認關口是 5.0 的**整片分鏡表格**（該多少秒列多少、全片一次出、一次確認；prompt 不再二次確認）；**影片為多條 15s prompt 併發同時生成、不逐段停頓確認**，各段以統一錨點保持一致、可順序拼接。prompt 中文交付、作模型內部執行層，不需使用者手動貼上。
- **兩條必含鏡頭**：全片**至少一鏡產品使用特寫**（刷子掃粉/指尖抹乳霜/執壺注茶等真實使用動作，突出質地/功能）；**尾版必須模特與產品同框中近景**（能穿戴則佩戴、只能用/吃喝則手持），多段時按整片計（尾版在最後一段末鏡）。
- **強制人物介入**：每條片必有人像（完整出鏡或手部/區域性肢體），絕不通篇無人；運鏡仍豐富展示產品/空間。
- **預設不加 logo**：結尾不放 logo、不詢問，除非使用者明確要求；有 slogan 則影片模型隨片直出字幕，無則產品 hero/畫面自然收尾。
- **SD2 生影片完全靜音、聲音全後期**：SD2 階段**只出純畫面，不生成任何聲音**（無 BGM、無音效/環境音、無旁白、無單音/樂器音/節拍）；成片聲音只有 **BGM + 旁白（如有）** 兩層，全部在 Step 6 後期加：BGM 固定為「中國古典樂器×現代電子的國風電子融合樂」（非純民樂非純電子）、BPM 隨片、不詢問使用者、合成前按成片節奏/調性生成；旁白按 Step 2 選擇後期 TTS/配音；**不做任何音效層**；混音旁白優先、BGM 不蓋人聲。
- **字幕（選了旁白才有）**：僅當 Step 2 選了旁白時才可選字幕（中文/英文/中英雙語/不要）；字幕與旁白文案一致，在 Step 6 合成前加入，樣式簡潔貼合國潮氣質；未選旁白則不涉及字幕。
- **影片比例 + 解析度必須使用者選**：比例（16:9/4:3/9:16/3:4）與解析度（480p/720p/1080p）無預設，Step 2 必問，SD2 按此設定畫幅與輸出。
- **影調強化**：每條 prompt 品質句後固定追加——通透明亮、層次清晰、色彩不發灰、光澤銳利，避免發悶/下沉，維持國潮高階通透感。
- **運鏡絲滑**：末尾固定加運動質量句（不掉幀/不卡頓/絲滑+自然動態模糊）；環繞/旋轉類尤易掉幀，寫"緩慢勻速環繞、平滑連續旋轉"並放慢。
- **鏡頭銜接**：不跳幀、不越軸（守 180°），機位與運動邏輯連貫；15s 段間續接保持 `{{Mixed N}}`/服裝/場景/光線一致不穿幫。
- 角色用 `{{Mixed N}}`，首現寫全、後續複用、主賓清晰；演示型確保產品每鏡清晰。
- 一條片只承載一個核心資訊點，前 3 秒抓人，結尾必有落點。
- **表情自然可信，禁誇張怪異**；**禁疊畫/疊化轉場**；**禁粒子特效**（太土，改用乾淨光效/無縫變形/材質質感）。
- 不做真實公眾人物內容；不杜撰真實品牌虛假主張；保持適當無害。
