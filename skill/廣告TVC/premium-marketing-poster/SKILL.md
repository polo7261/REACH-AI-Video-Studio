# premium-ad-posters

做高階海報、廣告創意圖、社媒廣告圖（帶文字疊加）時用本 skill。圖片專用，用 `generate_image_v3`。

> 本環境適配：源主模型 `imagegen_2_0`（GPT Image 2.0）+ 回落 `flux_2`/`nano_banana_2` → 我方無對應外部模型選型，統一收斂為 `generate_image_v3`（`無該模型`，見適配刪除臺賬 #41）。

## 模型與規格

海報/廣告成敗在排版保真、硬體精度、佈局紀律、品牌一致。用 `generate_image_v3`，\*\*質量選高、清晰度 2k（或 4k）\*\*以保證字形與硬體接縫清晰。

比例按投放位選擇：

- `1:1` —— 方形 Meta feed / 輪播廣告
- `9:16` —— Stories / Reels / TikTok 廣告
- `4:5` —— Instagram feed
- `3:4` —— 豎版海報
- `16:9` —— 橫幅

## 技術與寫實清單（場景專屬工藝·內聯，主動在 prompt 裡規避 AI 常見瑕疵）

設計帶硬體與文字整合的產品廣告時，必須主動引導 prompt 規避以下常見 AI 瑕疵：

1. **硬體完整性/機械對稱**

   - 問題：智慧手錶表圈不對稱、錶冠/錶盤看起來扭曲或"熔化"進錶殼、錶帶與錶殼無縫融合。
   - 對策：明寫「完美機械對稱、均勻表圈、清晰定義的機械件。電子錶冠/錶盤必須是獨立的金屬實體，有精確紋路，與表圈分離；錶帶耳連線自然，把錶帶接到錶殼」。

2. **螢幕層 UI 整合（非平貼紙）**

   - 問題：螢幕圖形（錄音波形、數字、按鈕）貼在顯示玻璃上顯得完全扁平、缺乏真實玻璃深度、或像後期合成上去的。
   - 對策：明寫「介面渲染在表鏡玻璃之下，在保護玻璃層上呈現細微自然眩光、反射與光折射。發光 UI 元素（波形、數字）應真實地從光澤反光螢幕玻璃後方發光」。

3. **解剖正常**

   - 問題：手腕缺骨感、錶帶下過渡關節軟塌、佩戴裝置時手指變形。
   - 對策：明寫「清晰的手腕骨骼解剖（尺骨突起）、自然指節、真實皮膚毛孔與自然膚質，處於柔和過濾窗光下」。

4. **背景偽影防護**

   - 問題：背景虛化中的鍵盤、手機等物件按鍵/按鈕扭曲或比例怪異，破壞專業廣告質感。
   - 對策：明確指定背景形狀，寫「背景乾淨整潔無雜物。若失焦背景中出現鍵帽等物體，須遵循標準矩形形態，或簡化背景為淺木紋理以減少雜亂」。

5. **高對比排版**

   - 問題：文字疊加直接壓在淺色紋理（如淺木桌面）上時對比度不足，導致文字難以辨認。
   - 對策：明寫「所有文字疊加須用乾淨、現代、深色無襯線字型，高對比度。若疊在多變紋理上，文字層後加細微投影或環境光遮蔽以保證最大可讀性」。

6. **參考對映 vs 目標格式**

   - 問題：使用者提供某一裝置的美學參考（如 iPhone 鎖屏），但要求生成另一具體目標產品（如 CarPlay 顯示屏）時，模型直接生成了參考裝置而非目標產品。
   - 對策：只提取並對映參考圖的**美學屬性**（排版、配色分割槽、紋理、UI 元素形狀）到**請求產品的格式與環境**上，絕不把主體裝置改成參考平臺的裝置，除非使用者明確要求。

## Prompt 結構模板

把 prompt 邏輯上拆成以下獨立分段，幫助模型正確構建佈局與美學要求：

```
[主體/Hero]：詳細描述產品與手/模特的銳利細節。在此加入解剖與結構規則。

[風格]：高階產品攝影、柔和窗光、通透的廚房/辦公檯面、窄景深、剋制的編輯設計感、真實暖色調。

[指令]：硬體機械對稱、錶帶耳連線定義、螢幕深度真實感（水晶表鏡上的眩光/折射）、背景鍵盤形狀約束、標題周圍乾淨的留白。

[文字]：引號內給出確切的文案文字塊——標題/副標/字幕，包含具體字號、字重描述、顏色細節、位置區（頂部/底部/疊加）。

[約束]：寬高比為 [1:1/9:16]；無扭曲按鈕、無熔化外殼、無糊字、無變形按鍵。
```

成組批次出多張、需要統一鎖定品牌視覺資產（色板/字型/光感）時，見 brand-visual-kit。
