# 短影片口播文案生成器
## Skill 定位
- 只負責：生成短影片的口播文案（旁白/解說詞），不負責畫面分鏡
- 純文字輸出，不呼叫繪圖/影片模型，零額外積分成本
## 輸入
- 主題（如"暗黑奇幻手遊測評"）
- 平臺（抖音/B站/小紅書）
- 時長（如60秒）
## 內部流程和 Knowhow
- 按"鉤子開頭→資訊展開→觀點輸出→CTA收尾"四段式結構
- 根據平臺調整語氣：抖音(短句/網感)、B站(資訊密度/深度)、小紅書(種草/親和)
- 標註每段預估用時，確保總時長對齊
- 附字幕斷句建議（每句≤15字便於閱讀）
## 輸出
- 完整口播文案（文字），含分段標註+預估用時+字幕斷句
- 末尾附「文案結構模板」：本片使用的四段式結構及適用場景速查
## 自檢
- 各段用時之和=總時長、每句≤15字、含CTA
## Ask User
- 主題或平臺缺失時，先問再生成
