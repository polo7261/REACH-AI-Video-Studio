# high-md-flow

做高能 / 超动态（kinetic / hyperkinetic）品牌 reel 时用本 skill——峰值动作、狂放运镜、smash cut，用于运动 / 时尚上新 / 科技揭幕 / SaaS reveal 一类需要爆发力的品牌片。三段式推进。

**high 档的定位**：高动能混沌（hyperkinetic chaos）。运动主要来自相机与主体的爆发式动作——与 classic-md-flow 的"稳而克制内部编排"正相反。下面的分镜板 / 片段规则据此校准；凡是漂移锁定、慢速优雅滑行、不可察觉微推轨这类语言都不属于 high 档（那是 classic / typography / infographic 的语言，混进来会破坏能级）。

## 三段

1. **风格板（Stage A）**：有图作基底则上传（`upload`）、跳过风格板；无图用 `generate_image_v3`（可用 `style_display_board`）出一张 4 格风格板，风格提示带"高动态 / 高能"倾向，用户选定一帧（`ask_human`）作视觉世界基底，其余备选帧忽略。
2. **分镜板（Stage B）**：以选定基底为准，`generate_image_v3`（`storyboard_panel`）出 6 格分镜板，引用基底帧。
3. **动效片段（Stage C）**：`generate_video_v3` 以分镜板为参考生成连续片段；多段用 `composite_video` 合成。

## 分镜板规则（Stage B 深度）

- **网格与基底**：6 格 3×2 横向（上排 1-2-3、下排 4-5-6），整板 3:2；格间细发丝分隔（1pt / 12-20px 间隙）、格内无边框、画面纯净（去日期 / 伪数据芯片 / 拉丁副标 / 等宽时间码 / 元数据标签）。从风格板选定的那一帧作整板视觉世界基底。
- **文字下限**：格内任何文字字号不低于格高约 10-12%（cap-height）；小号拉丁副标 / 等宽时间码一律去掉。
- **峰值动作强制（PEAK-ACTION）**：每格都定格在动作顶点——起跳最高点、飞溅、粉碎、爆发、拉丝的瞬间。不要静置主体、不要休止状态、不要"空场里的产品"。
- **环境密度强制（AMBIENT DENSITY）**：每格主体后至少 2 层氛围填充——① 粒子飘移（火花 / 尘 / 拉丝粒子 / 雾霭）② 背景渐变呼吸（调色饱和度循环）③ 体积光束（边缘光 / 神光 / 聚光）④ 表面质感（混凝土 / 沙 / 液面 / 镜面地）⑤ 前景景深元素（主体前的虚焦道具）。
- **文字锚点（Pattern A · 奇数格模式）**：第 1 / 3 / 5 格承载 2-4 词大字标（display 字体），第 2 / 4 / 6 格无字、纯峰值氛围。文案由项目主题生成，不用固定样板句。
- **六格内容弧（每格一峰值 + 一特技运镜，逐格校准）**：
  - P01 钩子（0-2.5s）· CRASH-OUT REVEAL：极特写细节瞬切到宽景、主体起跳（顶点）；配甩镜拖影 + 顿帧冻结；承载首个大字标。
  - P02 · SHATTER PUSH-THROUGH（2.5-5s）：相机穿膜推进、主体在碎裂瞬间冲出；折射碎屑 + 色散边缘；无字。
  - P03 · VERTIGO PULL（5-7.5s）：主体纵跳到顶点、相机同步推拉变焦；速度斜坡 + 镜头拉丝；承载第二个大字标。
  - P04 · DROP-DIVE PAST（7.5-10s）：相机垂直俯冲掠过下坠 / 旋转的主体；粒子里的漩涡 + 轻微畸变漏斗；无字。
  - P05 · HYPERKINETIC ORBITAL SWEEP（10-12.5s）：相机绕爆发 / 飞溅中的主体高速环绕；冲击波环 + 折射薄雾；承载第三个大字标。
  - P06 收束（12.5-15s）：终宽景、主体收成干净英雄剪影、余粒沉降；残雾 + 柔体积光束；无字。
- **五锁（跨格一致，写进提示词并逐格复述）**：主体锁（基底的英雄主体 / 母题）、材质锁（复刻基底主材质身份）、风格锁（Tier-1 高端动效 3D / 2.5D 打磨的 hyperkinetic chaos 调性）、调色锁（基底取约 3 个主导 hex 色）、氛围锁（复刻基底的光照情绪 + 雾密度 + 景深）。
- **禁写实真人（HR-3）**：照相写实真人 / ARRI Alexa / 35mm 颗粒 / 真皮质感严禁。用剪影 / 抽象形体 / 风格化 3D / 2D 插画 / 运动拖影形体 / 粒子形体 / 打光体积剪影替代。照相写实质感仅 product-md-flow 例外。

## 动效片段规则（Stage C 深度）

- **形态**：一段连续全帧 16:9，分镜板只作规划参考、不是面板网格；每镜填满全帧。
- **相机基调（high 档核心 · HYPERKINETIC CHAOS）**：每镜一个峰值动作时刻（跳跃最高点 / 飞溅 / 粉碎 / 爆炸），绝不漂移锁定、慢速优雅滑行或不可察觉微推轨。相机词汇——眩晕拉近 VERTIGO PULL（约 2m 推近同时拉远）、CRASH-OUT REVEAL（极特写 0.4s 内切宽、约 3m 后拉）、穿膜推进 SHATTER PUSH-THROUGH、高速轨道环绕 ORBITAL SWEEP、垂直俯冲 DROP-DIVE PAST（约 6m）、钟摆甩弧 MATCH-FRAME SWING（约 90°）、甩镜拖影 WHIP-PAN。允许速度斜坡（慢动作→极速）+ 撞击时刻约 2 帧顿帧冻结。强视差：前 / 中 / 背景约 100 / 40 / 15 的位移比。
- **6 镜弧线**：每镜约 2-2.5s，一个峰值动作配一种特技运镜（如 ① 抽象材质英雄 CRASH-OUT + 甩镜 0.2s、② 动能环境 VERTIGO PULL 1.5s + 环绕 180°、③ 硬表面宏观到宽景 MATCH-FRAME SWING 90° + 冻结闪光、④ 建筑 / 抽象深度走廊 DROP-DIVE PAST 6m、⑤ 能量核心 ORBITAL SWEEP 120° + 穿膜、⑥ 最终英雄帧 VERTIGO PULL 0.8s→锁定）。镜间用强冲击转场：穿膜推进 / 热光斑光扫 / 物体形变 / 向内坍塌 / 粒子溶解（禁 cross-fade）。
- **尾帧冻结**：13.7-15s 强制定格末帧，像素一致，无新动作 / 元素 / 转场 / 淡出。
- **音频**：仅动能 SFX 混音——重低音撞击 / 玻璃碰撞 / 棱镜闪光；无音乐、无 VO、无对话、无自动字幕。

## 比例默认与通用

| 步 | 默认比例 |
|---|---|
| Stage A 风格板 | `3:2` 恒定 |
| Stage B 分镜板（3×2 六格） | 16:9→`3:2` / 9:16→`9:16` / 1:1→`1:1` |
| Stage C 片段 | `16:9` 默认，未指定就问 |

Stage C 生成默认 `count: 2`（同 prompt 两份变体）。有图作基底则跳过风格板。Stage B/C 的创作（分镜 / 片段 prompt）源里在后端 enhancer，本环境由 agent 自己写——board 网格纪律与 hyperkinetic 相机基调工艺已内联在上两节，不外包。
