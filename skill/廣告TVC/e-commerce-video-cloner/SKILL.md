# 电商带货视频克隆创作

## 適用場景

需要快速复制爆款带货视频结构、替换为自己产品内容时使用；适合新手卖家、有经验的主播/运营、品牌方批量生产带货内容

## 輸出

可直接发布的带货短视频（含画面、配音、字幕、BGM、封面、CTA），符合目标平台规格

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
