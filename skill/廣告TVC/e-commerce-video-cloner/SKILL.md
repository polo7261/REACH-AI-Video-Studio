# 電商帶貨影片克隆創作

## 適用場景

需要快速複製爆款帶貨影片結構、替換為自己產品內容時使用；適合新手賣家、有經驗的主播/運營、品牌方批次生產帶貨內容

## 輸出

可直接釋出的帶貨短影片（含畫面、配音、字幕、BGM、封面、CTA），符合目標平臺規格

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
