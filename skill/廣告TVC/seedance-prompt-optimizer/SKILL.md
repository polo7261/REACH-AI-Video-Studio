# SD2.0提示词优化

## 適用場景

适用于即梦Seedance 2.0的视频创作场景。覆盖文生视频、图片参考生成、视频动作/运镜复刻、音频驱动节奏、角色替换编辑、视频延长衔接等。适合短视频创作者、广告从业者、自媒体人群，帮助将简单创意转化为时间线清晰、情绪标注、运镜可控的结构化提示词，提升生成质量与可控性。

## 輸出

输出可直接粘贴至即梦Seedance 2.0输入框的完整视频生成提示词，含六大模块：素材@引用及用途、场景动作概述、按秒分段的时间线描述（画面、动作、情绪）、镜头语言与剪辑逻辑、风格色调光影氛围、音乐音效与节奏建议。同时附使用建议：推荐素材类型与数量、生成时长（4-15秒）及限制注意事项，确保一次生成即可用、可控、高质感。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
