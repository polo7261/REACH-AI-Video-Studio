# SD2.0提示詞最佳化

## 適用場景

適用於即夢Seedance 2.0的影片創作場景。覆蓋文生影片、圖片參考生成、影片動作/運鏡復刻、音訊驅動節奏、角色替換編輯、影片延長銜接等。適合短影片創作者、廣告從業者、自媒體人群，幫助將簡單創意轉化為時間線清晰、情緒標註、運鏡可控的結構化提示詞，提升生成質量與可控性。

## 輸出

輸出可直接貼上至即夢Seedance 2.0輸入框的完整影片生成提示詞，含六大模組：素材@引用及用途、場景動作概述、按秒分段的時間線描述（畫面、動作、情緒）、鏡頭語言與剪輯邏輯、風格色調光影氛圍、音樂音效與節奏建議。同時附使用建議：推薦素材類型與數量、生成時長（4-15秒）及限制注意事項，確保一次生成即可用、可控、高質感。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
