# 音乐MV制作全流程

## 適用場景

适合制作时尚穿搭、品牌宣传、音乐MV等风格短片的创作者。无论是单一Look展示还是多套换装合集，均可使用本Skill快速建立创作体系。典型场景：小红书竖屏穿搭短片、品牌形象宣传片、多风格换装MV、节日主题短视频。确保风格统一、运镜专业、画面商业级质感。

## 輸出

①成片视频：竖屏9:16或横屏16:9，60-90秒，MV级运镜；②分镜表文件：含镜头描述、运镜方式、锚点引用；③锚点清单：角色+场景锚点全程复用；④封面图：3:4竖版+16:9横版；⑤BGM音频：与成片节拍匹配。（96字）

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
