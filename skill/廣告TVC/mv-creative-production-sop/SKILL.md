# 音樂MV製作全流程

## 適用場景

適合製作時尚穿搭、品牌宣傳、音樂MV等風格短片的創作者。無論是單一Look展示還是多套換裝合集，均可使用本Skill快速建立創作體系。典型場景：小紅書豎屏穿搭短片、品牌形象宣傳片、多風格換裝MV、節日主題短影片。確保風格統一、運鏡專業、畫面商業級質感。

## 輸出

①成片影片：豎屏9:16或橫屏16:9，60-90秒，MV級運鏡；②分鏡表檔案：含鏡頭描述、運鏡方式、錨點引用；③錨點清單：角色+場景錨點全程複用；④封面圖：3:4豎版+16:9橫版；⑤BGM音訊：與成片節拍匹配。（96字）

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
