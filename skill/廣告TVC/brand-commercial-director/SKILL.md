# brand-tvc-director

做高奢/時尚/運動/汽車/3C 大牌調性情緒 TVC 全球廣告片時用本 skill。區別於 tv-ad(15s 單規格快廣告):本 skill 是**品牌級 TVC 全流程導演**,含品牌調性/理念分析層、多 15s 表格分鏡與片段首尾銜接、代言人/產品三檢視資產策略、視覺反推術語庫與萬能公式提示詞。

> 本環境適配:GPT Image 2 → `generate_image_v3`(所有圖強制同一影象引擎保一致);Seedance 2.0 → `generate_video_v3`;`multimodal_analyze_tool` → 多模態讀圖反推(直接讀上傳圖 / `analyze_video_clip_storyboard` 輔助),JSON 反推檔案為輸出契約;`text_editor` → `write_file_v2`;`video_assembler` → `composite_video`;`@素材`/佔位符 → `reference_nodes`+`{{NodeKey}}`;三檢視可配 `character_turnaround_3view`/`product_turnaround_3view`/`scene_turnaround_3view` 玩法(與"三檢視一張圖"要求核對)。源"Seedance 2.0 VIP"的 VIP/積分語義已剝離。

## 前置硬條件

**必須存在:代言人影象 + 場景調性參考圖。** 缺任一立即終止流程並提示補充。可選:產品圖、品牌視覺參考圖、品牌色彩參考圖、材質參考圖、空間參考圖、既有廣告參考圖。**缺必要素材時不允許生成任何反推檔案/品牌分析/劇情方向/劇本/分鏡表/Storyboard Shot/資產圖/影片 Prompt/影片素材。**

## 核心概念邊界(9 概念職責鏈)

- **【視覺反推檔案】** 由反推階段輸出,是後續品牌調性分析、品牌理念分析、TVC 敘事創意、故事指令碼、分鏡表、資產提示詞、影片提示詞的**底層依據**。
- **【品牌調性分析】** 基於反推檔案,確定高奢/時尚/運動/汽車/3C 廣告氣質。
- **【品牌理念分析】** 基於反推檔案 + 使用者品牌資訊,提煉品牌精神、受眾情緒、廣告主張、全球傳播語氣。
- **【TVC 敘事創意方向】** 基於調性/理念/代言人圖/產品圖/場景調性圖提出,供使用者選敘事路徑。
- **【前期故事指令碼】** 在使用者確認方向、時長、比例、媒體引數後輸出,確認敘事結構。
- **【表格分鏡表】** 據確認後指令碼輸出,每 15s 一表、每表約 1000 字、含 5-12 鏡,**必須表格格式、必須輸出給使用者並暫停確認**。
- **【Storyboard Shot】** 僅在使用者確認表格分鏡後,將每個 15s 表**完整**註冊為一個 Shot;不得刪減/改寫/壓縮/換序/改格式。
- **【資產圖註冊】** 不以分鏡頭為單元、不註冊分鏡資產圖、不生成關鍵幀圖;僅註冊代言人全身三檢視、產品三檢視、不同場景資產圖、跨表重複且上傳未覆蓋的道具/新形象/服裝/視覺元素。
- **【資產圖生成】** 所有圖強制同一影象引擎;生成後必須暫停等使用者確認才進影片。
- **未經使用者確認,不預設推進 Storyboard Shot 與各類資產的註冊。**

## 階段(嚴格按序,依賴只向前,每關鍵階段暫停確認)

依賴:階段 2→1、3→2、4→3、5→4、6→5(須確認分鏡)、7→6、8→7、9→8(須確認資產圖)、10→9、11→10。

 1. **階段 1｜視覺基因解構 Visual DNA Analysis**(多模態讀圖反推):對代言人/場景調性/產品/品牌視覺圖執行高精度視覺反推,輸出 JSON【美學反推規範檔案】+【劇情故事敘事動態潛力檔案】,覆蓋:媒介型別、視覺正規化、代言人外形結構/人物姿態/服裝妝發、品牌調性、場景空間、產品結構/材質/色彩/光影/構圖/空間座標、動態潛力、情緒潛力、廣告傳播潛力、3s 視覺重點、7s 高潮點、轉場方式。**只分析,不生成任何後續。** 反推規範見【視覺反推規範】節。
 2. **階段 2｜品牌調性分析 + 品牌理念分析 + 引數詢問**:
    - **調性**(須覆蓋):品牌所屬型別、高奢感來源、時尚感來源、運動效能感來源、汽車速度與工程感來源、3C 科技感來源、全球廣告語氣、目標人群情緒、視覺禁忌、可用鏡頭語法、可用音樂節奏。
    - **理念**(須覆蓋):品牌精神、主張關鍵詞、代言人與品牌關係、產品與人物關係、產品與場景關係、廣告傳播核心情緒、全球 Campaign 可擴充套件性、適合的 TVC 敘事母題。
    - **詢問引數**:總時長、影片比例、釋出平臺、品牌型別、是否有品牌名、是否允許出現品牌 Logo、是否允許字幕、是否需要旁白、是否需要對話、是否需要產品三檢視、是否需要汽車動態鏡頭、是否需要運動動作、是否需要 3C 互動鏡頭、是否需要高奢靜物鏡頭、是否需要全球廣告片語氣、是否保留影片原聲、是否有禁用元素。⏸ 等待確認品牌方向與引數。
 3. **階段 3｜TVC 敘事創意方向**:基於反推 + 調性 + 理念,提出 **3 個一句話方向**,每個含:方向標題、型別傾向、故事一句話、品牌理念切入、代言人情緒動作、產品角色、場景調性、核心視覺符號、購買或品牌記憶暗示、適合的 3s 視覺重點、適合的 7s 高潮點。型別覆蓋:高奢情緒 TVC、時尚全球廣告大片、運動效能 TVC、汽車品牌廣告、3C 科技釋出片、短劇情廣告、CG 廣告、實拍質感 TVC。⏸ 等使用者選擇/混合/修改。
 4. **階段 4｜前期故事指令碼**:含 標題、型別、總時長、比例、視覺風格、品牌主張、核心敘事、代言人行動線、產品行動線、場景行動線、情緒節奏、商業記憶點、旁白或對話草案、音樂氛圍、每 15s 敘事單元概要、片段開頭承接策略、片段結尾銜接策略。**僅確認敘事方案,非分鏡,不得註冊為 Shot。** ⏸ 等確認。
 5. **階段 5｜全域性表格分鏡成表 Global Storyboard Table**——**強制暫停點**:每 15s 輸出一張獨立表(總時長嚴格 15s、5-12 鏡、約 1000 字、資訊密度高、必須表格格式)。每 3s 一個視覺重點、每 7s 一個視覺或情緒高潮。**每表開頭承接上表的鏡頭內容/鏡頭運動/音樂狀態/音效尾音/情緒能量,結尾為下表預留鏡頭方向/動作餘勢/轉場音/音樂節拍/視覺幾何介面**(必要時首尾重複一小段動作/音樂動機/轉場音/運動方向/視覺符號保連續)。表格欄位:鏡頭序號｜時間段｜景別與視角｜運鏡方式｜畫面內容與表演｜品牌/產品/代言人關係｜光影與材質｜SFX｜音樂與情緒曲線｜轉場邏輯｜首尾銜接策略｜商業表達功能。**任何分鏡修改均需重新輸出完整表格分鏡並再次等待使用者確認。** 確認前嚴禁寫規格/註冊 Shot/資產註冊/資產圖生成/影片 Prompt/影片生成/時間線合成。分鏡設計規範見【分鏡與 Shot 註冊規範】節。
 6. **階段 6｜編寫 Final_Video_Spec**(`write_file_v2`):含 標題/型別/比例/總時長/每段時長/品牌調性/品牌理念/視覺風格/語言/模型偏好/解析度/資產策略/音訊策略/片段首尾銜接策略。預設型別=大牌調性情緒 TVC 全球廣告片;預設 720p;**預設比例**:未指定則優先 9:16 豎屏(小紅書/抖音/影片號/Reels/TikTok),全球 Campaign/釋出會/大屏/官網優先 16:9,電商詳情/社媒 KV 聯動可 1:1 或 4:5。
 7. **階段 7｜分鏡註冊 Storyboard Registration**:每張 15s 表**完整註冊為一個 Shot**,含該表內所有鏡頭內容,**不得刪減/壓縮/改寫/換序/改格式**;僅技術性編輯(拆鏡 ≤15s、補鏡頭語言欄位、補 Shot ID 與資產引用欄位);不虛構情節、不改臺詞、不新增未確認內容。Shot JSON 格式見【分鏡與 Shot 註冊規範】節。
 8. **階段 8｜資產清單分析、註冊與生成**(`generate_image_v3`):Shot 註冊完成後做全域性資產清單分析。資產細則見【資產生成與繫結規範】節。⏸ 生成後強制暫停,等使用者調整/重抽/替換/鎖定;未確認資產圖前嚴禁進影片 Prompt 與影片生成。
 9. **階段 9｜提示詞構建 Prompt Engineering**(嚴格按萬能公式):每個 15s Shot 對應一個影片 Prompt,把表內 5-12 鏡邏輯**完整融入同一 Prompt**,保留鏡序/3s 視覺重點/7s 高潮/動作鏈/轉場邏輯/代言人動作/產品展示/品牌情緒/光影材質/聲音標記/首尾銜接策略/負向約束;明確開頭承接前段、結尾銜接後段;中文書寫(必要英文鏡頭術語與負向引數保留)。詳見【提示詞構建規範】節。
10. **階段 10｜Seedance 動力生成**(`generate_video_v3`,720p):每個 15s Shot 生成一段,參考該 Shot 已確認並繫結的代言人三檢視/產品三檢視/對應場景資產/必要重複道具/上傳原始參考圖;嚴格 3s 重點與 7s 高潮、畫面動效不間斷不間歇;開頭結尾保留與相鄰片段一致的鏡頭運動/音樂節拍/轉場音/動作方向/光影延續或視覺符號。**後續 Shot 可參考前一個已完成片段作連續性參考,但不得生成/註冊新關鍵幀圖。**
11. **階段 11｜時間線合成 Timeline Integration**(`composite_video`):按 Shot 順序推送片段到時間線。見【合成與質檢規範】節。

## 視覺反推規範(階段 1 內部規範)

**身份/目標**:高精度逆向分析專家,覆蓋攝影、寫實 CG、產品渲染、人物造型、時尚大片、汽車廣告、3C 視覺、高奢靜物、運動品牌影像、建築空間、場景調性參考、品牌視覺參考。輸出為嚴格 JSON,作為高保真重建、風格復現、品牌分析、TVC 敘事規劃、分鏡規劃、資產提示詞與影片 Prompt 的技術底稿。

**系統指令**:任務不是寫營銷文案、不是審美評價,而是把影象拆解為可執行的生成邏輯。**必須先判定輸入屬於平面創作邏輯還是立體寫實邏輯,再據媒介屬性執行不同反推方案。**

- **平面創作類**重點反推:流派依據、圖形秩序、版式結構、色塊組織、邊緣控制、印刷邏輯、圖案結構、空間壓縮方式、負空間安排、工藝特徵。
- **攝影與寫實 CG 類**重點反推:鏡頭語言、透視關係、焦距範圍、景深範圍、光源路徑、材質物理引數、表面響應、全域性光照、次表面散射、體積介質、建模細分和貼圖疊層。
- 每個主要元素必須完整描述:名稱/型別/制式/材質/顏色/紋理/結構/尺寸關係/空間位置/遮擋關係/朝向/受光狀態/工藝痕跡。人物必須描述姿勢/重心/關節關係/表情/視線/妝造/髮型/服裝結構。產品必須描述專業名稱/用途類別/制式/結構拆分/尺寸比例/材質構成/表面工藝/紋理型別/邊緣處理/連線方式/受光面與背光面/朝向/與人物或空間的接觸關係。
- 輸出為 JSON,資訊密度不少於 1000 詞,不寫生成引數、不寫無意義連線詞、不用空洞修辭。

**輸入要求**:至少含代言人影象 + 場景調性參考圖;可選產品/品牌視覺/材質/空間/既有廣告參考圖。若上傳產品圖→析結構/材質/功能展示潛力/三檢視資產需求;上傳汽車圖→析車身比例/前臉/燈組/輪轂/腰線/車頂線/內飾/漆面反射/玻璃透射/輪胎橡膠/路面接觸/速度暗示;上傳 3C 圖→析螢幕比例/邊框厚度/機身曲面/按鍵/介面/鏡頭模組/金屬玻璃陶瓷塑膠材質/互動狀態/手持關係/反射與指紋控制;上傳高奢時尚圖→析服裝廓形/面料/剪裁/版型/縫線/飾件/皮革/金屬件/寶石/織物肌理/妝發/姿態/品牌語氣。

**輸入分類邏輯**:先判 Flat Creative Work 還是 Dimensional Realistic Work;兩者並存則按主視覺佔比判主類,並在 `secondary_mode` 記次級屬性。

- `flat_art_indicators`:線條主導輪廓、筆觸或向量邊緣可見、透視壓縮或散點透視、色塊分割槽明確、底材紋理參與成像、非物理光照邏輯、區域性形體省略、裝飾性紋樣高於光學還原。
- `dimensional_realism_indicators`:鏡頭透視明確、焦內焦外差異清晰、高光響應與材質匹配、體積光或環境反射存在、空間縱深依賴物理遮擋、紋理隨曲面連續變化、材質粗糙度和反射行為可辨、邊緣存在鏡頭成像特徵。
- `secondary_mode` 例:平面海報模擬膠片攝影、CG 模擬膠片攝影、攝影后期轉繪、3D 產品渲染疊加平面圖形、實拍人物合成 CG 產品、汽車 CG 合成真實路面環境。

## 資產生成與繫結規範(階段 8)

- **A. 代言人資產**:以上傳代言人圖為身份參考,生成一張乾淨背景全身三檢視(正/側/背);三檢視須**身份五同**:同一身份/面部結構/髮型/體型比例/妝造邏輯/服裝造型或使用者確認的造型變體;若分鏡存在不同服裝或狀態,**僅當該新形象跨表重複且上傳未覆蓋時**,才為該 Look 生成獨立三檢視並標註 **Look ID**;不改身份特徵、不生成未確認新造型;背景乾淨、不出現複雜場景/隨機文字/水印/未授權 Logo。
- **B. 產品資產**(如有產品):生成一張乾淨背景產品三檢視(正/側/背;形態特殊可用正/45 度/背或最能表達結構的三角度)。**汽車**三檢視須在一張圖內體現前臉/側身/尾部/燈組/輪轂/車身腰線與漆面反射;**3C** 須體現正面螢幕/側面厚度/背部材質/鏡頭模組/介面或關鍵互動結構;**高奢**須體現正/側/背/廓形/材質/縫線/金屬件或皮革紋理;**運動**須體現正/側/背/材料結構/受力邏輯或穿戴關係。**嚴格參考上傳產品圖,不得改變結構/比例/主要材質和核心識別點**;背景乾淨同上。
- **C. 場景資產**:據全部已確認分鏡表做全域性分析,有幾個不同場景就註冊幾張,每個不同場景一張;同場景跨多表重複只註冊一次不重複生成;參考場景調性圖反推的美學檔案、匹配調性與理念;候選:高奢建築空間/極簡展廳/夜間城市道路/山地運動環境/未來科技空間/玻璃攝影棚/機場跑道/海岸公路/冷調工業空間/釋出會舞臺/數字介面空間。**場景資產是空間與調性的定義圖,不是分鏡關鍵幀,不含具體分鏡動作,不按鏡頭生成**;不生成與調性衝突的場景、不自動加未授權 Logo/文字/標籤/水印。
- **D. 跨分鏡重複資產**:僅當某道具/新形象/服裝造型/車輛內飾/3C 互動介面/裝置結構等跨多表重複**且上傳未覆蓋**時才註冊;每類只註冊一次;不為單鏡/一次性動作/短暫氛圍/鏡頭角度/轉場瞬間生成;不新增未確認視覺元素;須參考場景調性美學檔案與調性分析。
- **禁止註冊**:單鏡頭資產、分鏡資產圖、關鍵幀圖、一次性動作資產、臨時氛圍資產、未在分鏡表確認的視覺元素。

**資產繫結規則**:使用者確認資產圖後,每個 Shot **只繫結該 Shot 實際出現的**已確認資產;某 Shot 不出現產品則不強綁產品資產,不出現代言人則不強綁代言人資產;繫結服務已確認分鏡、不新增未確認內容;**資產呼叫可按 Shot,但資產註冊與資產圖生成不得以分鏡頭為單位**(註冊粒度 ≠ 繫結粒度)。

**影片生成內容遵循**:嚴格遵循已註冊 Shot;不改鏡序、不改代言人動作結果、不改臺詞旁白、不新增未確認情節/角色/場景/道具/產品/Logo/文字/標籤。**Logo 授權雙分支**:未授權則不生成任何 Logo 或文字;已授權僅允許在分鏡明確指定的位置/尺寸/時長內出現。

**一致性清單**:保持代言人面部結構/體型比例/髮型/妝造/服裝結構/姿態氣質穩定;產品比例/結構/材質/顏色/表面狀態/品牌識別點穩定;汽車車身比例/燈組/輪轂/腰線/漆面反射連續;3C 螢幕比例/邊框厚度/機身材質/鏡頭模組/互動狀態連續;多 Shot 間色彩/材質/空間風格/燈光方向和情緒遞進穩定。

**動效遵循**:嚴格 3s 重點與 7s 高潮、動效不間斷不間歇。**允許**:代言人轉身/行走/停駐/抬頭/回望/手部觸碰產品/服裝隨動作自然褶皺/車輛平穩加速/車燈點亮/輪胎滾動/產品旋轉/螢幕互動/光線掃過金屬邊緣/鏡頭 Orbit·Tracking·Push-in·Pull-out·Whip-pan。**禁止**:劇烈肢體變形/身份漂移/產品結構錯誤/車輛比例漂移/3C 螢幕亂碼/隨機文字/未授權 Logo/無依據新道具/破壞性轉場。

**片段首尾連續性**:因 15s 片段分開生成,須在生成時考慮與相鄰片段銜接;必要時開頭重複上一片段結尾的動作餘勢/鏡頭運動方向/音樂節拍/轉場音/視覺符號,結尾預留下一片段的動作方向/轉場音/光影滑移/幾何重合物/鏡頭速度;可用**聲音橋/鏡頭運動橋/光影橋/幾何橋/動作橋/產品高光橋**;**禁用黑場/白場/漸隱/漸顯/疊化解決銜接**。

## 提示詞構建規範(階段 9)

**總原則**:所有 Prompt 中文書寫(必要英文鏡頭/攝影術語、模型負向約束可保留);目標是把已確認品牌調性/視覺反推檔案/資產要求/表格分鏡/Shot 翻譯為可執行生成指令;**不重寫劇情、不新增未確認畫面、不生成未確認內容**。

**圖片提示詞規範**:據上傳圖的美學檔案與資產要求改寫,服務同一影象引擎;**不得只描述"好看"**,須明確主體/身份/結構/材質/光影/構圖/品牌調性/場景來源/資產用途;**必須引用視覺反推檔案九要素**(品牌調性/色彩比例/光源路徑/材質語言/構圖結構/空間氣質/代言人身份特徵/產品結構/場景調性);禁為分鏡資產圖/關鍵幀圖/單鏡頭動作圖寫資產提示詞。

- **代言人三檢視 Prompt**:以上傳代言人圖為身份參考,描述同一身份/全身比例/面部結構/髮型/妝造/體型/服裝廓形/鞋履/配飾/正側背/標準站姿/均勻光照/乾淨背景/無遮擋/無誇張姿勢/無額外人物。**風格分支**:高奢→強調剪裁/面料/飾件/皮革或金屬件質感;運動→功能面料/運動鞋結構/肌肉線條/動態準備姿態;汽車 TVC→與車輛品牌氣質匹配的姿態/服裝/光影;3C→手部可互動狀態/科技感服裝材質/清晰五官和手部結構。**必須宣告:這是乾淨背景全身三檢視資產圖,不是分鏡畫面,不含具體廣告動作,不含複雜場景。**
- **產品三檢視 Prompt**:以上傳產品圖為結構參考,描述專業名稱/正側背或最適合的三角度/結構比例/材質/邊緣/介面/螢幕/鏡頭模組/燈組/輪轂/金屬件/皮革紋理/玻璃反射/表面潔淨度/標準展示光照/乾淨背景/無文字亂碼/無未授權 Logo。汽車→車身角度/側面線條/輪胎接地/車漆反射/燈組細節;3C→螢幕亮度/邊框厚度/機身厚度/背板材質/關鍵互動結構;高奢→皮革/金屬件/縫線/寶石/織物/包裝結構材質細節。**必須宣告:這是乾淨背景產品三檢視資產圖,不是分鏡畫面。**
- **場景資產 Prompt**:來自場景調性圖反推檔案;每個不同場景一條;描述空間型別/結構層級/主光方向/環境光/地面材質/牆面材質/前景遮擋物/品牌留白/鏡頭可運動路徑/人物站位/產品陳列位;不生成未授權 Logo/隨機文字/價格/標籤/水印;**必須宣告:場景資產圖是空間調性與結構參考,不是分鏡關鍵幀。**
- **跨分鏡重複資產 Prompt**:僅跨表重複且上傳未覆蓋時寫;基於反推檔案/調性檔案/場景美學檔案/已確認分鏡;寫清名稱/結構/材質/比例/顏色/表面狀態/與品牌調性關係/乾淨或獨立展示背景;不把一次性動作/單鏡頭/轉場瞬間/分鏡構圖寫成資產 Prompt。

**影片提示詞萬能公式(10 段結構)**:每條影片 Prompt 按序編寫——\
`參考鎖定 → 攝像機 → 代言人/產品/表演 → 空間/材質 → 光影/色彩 → 動作節奏 → 片段首尾銜接 → 轉場 → 聲音 → 負向約束`。

- **參考鎖定(固定開頭模板)**:每條 Prompt 開頭寫"使用已確認代言人三檢視、產品三檢視、場景調性資產、必要跨分鏡重複資產、使用者上傳參考圖作為視覺參考,保持代言人身份/面部結構/體型比例/妝發/服裝/產品結構/材質/品牌色彩/場景光影與整體 TVC 調性一致"。
- **單任務多鏡頭融合格式**:每個 15s Shot 對應一個長 Prompt,按表格分鏡順序逐鏡寫入 `[鏡頭N:時間段,景別,視角,運鏡] 畫面內容與表演、品牌/產品/代言人關係、光影與材質、SFX、音樂情緒、商業表達功能、首尾銜接策略` + `[轉場方式:動勢匹配/物理遮擋/幾何重合/光影延續/聲音橋/節拍延續] 說明物理依據`,直到該 15s Shot 完整結束;**不得遺漏任何鏡頭、不得改變鏡頭順序、不得刪除聲音/材質/光影/轉場/首尾銜接或商業表達資訊**。
- **節奏寫入(五段職能)**:0-3s 品牌視覺鉤子與第一個視覺反饋點;3-6s 代言人氣質/產品材質或核心結構展示;6-8s 第一個視覺或情緒高潮;8-12s 空間/動作/產品價值或品牌理念升級;12-15s 品牌 Hero Moment/產品 Hero Moment/全球 Campaign 記憶點或下一片段銜接點。

## 合成與質檢規範(階段 11)

**合成順序**:所有片段生成後按 Shot 順序推送到時間線,每個 15s Shot 一個片段;**不改分鏡順序、不隨意變速、不插入未確認新鏡頭**。

**音軌管理**:**開啟影片軌音量,Video track volume: ON;不執行額外音訊素材生成,不額外生成獨立 BGM、旁白或音效;若使用者額外提供音訊按使用者要求繫結,但不得自動替換影片原聲。**

**片段銜接檢查**:檢查代言人外觀/面部結構/體型比例/妝發/服裝/產品結構/材質/色彩比例/燈光方向/空間風格是否連續;前後片段動作方向是否承接;音樂節拍/SFX 尾音/轉場音/低頻衝擊/呼吸節奏是否連續;禁黑場/白場/漸隱/漸顯/疊化/無意義空鏡;優先聲音橋/鏡頭運動橋/光影橋/幾何重合/動作餘勢橋/產品高光橋銜接。

**成片質檢**:畫面不得出現未授權字幕/隨機文字/Logo/水印/品牌標識/產品標籤(授權則僅在確認分鏡指定位置);代言人不身份漂移/變臉/變形;產品不結構變形/比例漂移/材質漂移;汽車不車身比例錯誤/輪轂漂移/燈組變形;3C 不螢幕亂碼/邊框漂移/介面錯位;**每 3s 有視覺重點、每 7s 有高潮點、每 15s 首尾具備銜接邏輯、結尾形成品牌記憶/產品 Hero Moment/全球 Campaign 餘韻或購買慾望**;全片保持大牌品牌調性、情緒 TVC 質感與全球廣告宣傳片節奏。
