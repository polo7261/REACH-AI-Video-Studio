# 脫口秀吐槽口播短影片

## 適用場景

適合脫口秀愛好者、喜劇創作者、吐槽、知識口播 UP 主、品牌商單製作、短影片博主、經營團隊批次出片。可用於抖音 / 快手搞笑段子、小紅書觀點分享、B 站知識科普、影音號情感共鳴內容、品牌軟植入廣告、線下開放麥宣傳物料等全平台內容生產。（適合新手豆包練習、高手批次出片）

## 輸出

包含定妝圖及完整脫口秀文案（帶氣口節奏標註）、分鏡腳本、舞台視覺全案（場景 + 佈光 + 道具）、兩套可直接複製的生成影片提示詞（標準版 + 商單極致版）、分層沉浸式音效方案、字幕規範、3 個爆款標題、10 個話題標籤及發布最佳化建議，拿到即可直接落地生成。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
