## 適用場景

适合脱口秀爱好者、喜剧创作者、吐槽、知识口播 UP 主、品牌商单制作、短视频博主、运营团队批量出片。可用于抖音 / 快手搞笑段子、小红书观点分享、B 站知识科普、视频号情感共鸣内容、品牌软植入广告、线下开放麦宣传物料等全平台内容生产。（适合新手豆包练习、高手批量出片）

## 輸出

包含定妆图及完整脱口秀文案（带气口节奏标注）、分镜镜头脚本、舞台视觉全案（场景 + 布光 + 道具）、两套可直接复制的生视频提示词（标准版 + 商单极致版）、分层沉浸式音效方案、字幕规范、3 个爆款标题、10 个话题标签及发布优化建议，拿到即可直接落地生成。

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
