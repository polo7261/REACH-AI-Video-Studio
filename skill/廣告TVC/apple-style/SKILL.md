## 二、镜头手法（模特镜头打底 + 细节穿插）

### A. 模特镜头（有人模式 · 打底）

> **★ 焦点原则（硬约束）**：模特与产品互动时，**焦点与视觉中心始终在产品上**——产品清晰、居于视觉重心、被光与景别强调；**模特的面部与形象只是辅助/衬托**（负责氛围、气质、比例与真实感），不喧宾夺主。构图与对焦优先给产品：浅景深虚化模特、实焦压在产品上；人物可只入镜局部（手、肩、侧脸、佩戴部位）。

> **★★ 互动判断（硬约束 · 先想清楚"人怎么用它"再写镜头）**：**禁止让人物呆站着只是"举着/拿着"产品、没动作没表情。** 出模特镜头前，必须先判断产品的**真实用途、常见场景、正确握持/佩戴/接触位置、需要哪只手/身体部位、人物视线与身体重心如何自然跟随**，再推出一个**具体、有动机的动作与情境**，让人物真正"用起来"，并带**明确表情/情绪**。例如：
>
> - 耳机 → 戴上耳机、随节奏点头/闭眼沉浸/跟着律动跳舞
> - 汽车/钥匙 → 拉开车门坐进去、点火、握方向盘起步加速/飙车
> - 吹风机 → 拿起吹风机吹头发，头发被气流吹动
> - 相机 → 举起相机取景、按下快门拍照，回看照片露出满意神情
> - 口红/美妆 → 对镜涂抹、抿唇、端详效果
> - 运动鞋 → 系鞋带、起跑/腾空
> - 手机 → 解锁、滑动、举起拍摄、看到内容的反应
> ****动作合理性检查（必须先做）**：`谁在什么场景为什么用 → 正确握持/佩戴/接触点 → 起势→接触/操作→反馈/结果 → 视线、肩肘手腕、身体重心与微表情自然跟随 → 产品始终是焦点`。动作要有预备、操作、停顿反馈和自然表情，禁站桩举物、手指悬空、身体僵直、用法错误。若全身使用不合常理，自动改成手部/半身/局部佩戴或无人 hero+细节，不硬塞模特。
> ****必须完整展示使用过程（硬约束）**：有人模式下，视频里一定要拍出人物**使用产品的完整过程**（起始 → 使用中 → 结果/反应），不能只给一个"持有/静态展示"画面、也不能跳过使用动作直接切细节。使用过程本身就是内容主线。

- **动作要具体连贯**：写清起始→过程→结果的小动作链（如"拿起相机→举到眼前取景→按下快门→放下相机看回放微笑"），同时写握持/接触部位、视线、肩肘手腕或重心随动，不是静态 pose。
- **表情要到位**：沉浸、专注、惊喜、满意、享受……与动作匹配、自然可信，**禁止面瘫呆滞，也禁止夸张怪异**。
- **产品仍是焦点**：动作服务于"把产品用起来、被看见"；对焦压产品、浅景深虚化人物，人物可只入镜局部。
- 用 `{{Mixed N}}` 绑定选定模特，全程一致。

### B. 产品细节镜头（穿插 · 以材质为主）

1. **微距材质特写（主力）**：极致微距一镜一细节，掠射光扫过表面**呈现真实材质**——拉丝、阳极氧化、玻璃菲涅尔反射、陶瓷釉面、编织纹理。产品片高级感的主要来源。
2. **微距飞掠（Macro Fly-through）**：镜头快速飞掠网面 / 材质表面。
3. **暗场揭晓（Reveal from Black）**：产品从纯黑中被光逐渐点亮、缓缓浮现的 hero 登场（不用星空/深空）。
4. **半圈慢环绕（Half Orbit）**：缓慢匀速环绕产品**最多半圈**（≤180°），欣赏外形与轮廓。

> **不做 3D 拆解**：不做 3D 爆炸视图、内部剖切/透视、镜头穿梭进入产品内部等"拆解/看内部"镜头。产品靠**外部材质、光影、使用动作**来展示。
>
> 典型顺接：**模特使用（焦点在产品）→ 半圈环绕 → 微距材质细节 → 微距飞掠 → 落版**。
>
> 细节段落写法：**单向推近产品（只推不回拉）→ 逐一展示各部分细节（一镜一个，材质微距，可配最多半圈微环绕）→ 微距飞掠**，镜头连贯不跳帧；推与拉分属不同镜头；**不进入内部、不拆解**。

### C. 运镜精华（从优质 prompt 提炼）

- **暗场微距擦光**：极高精细度微距，纯黑/暗色渐变背景；一道锐利银色轮廓光或掠射光缓慢扫过产品边缘、孔洞、纹理，让结构内部产生深邃几何阴影，捕捉泡沫/织物/金属/陶瓷的触感纹理；高反差、慢动作、拒绝大面积照亮。
- **线性高光扫材质**：近景锁定金属/玻璃/陶瓷局部，让一条线性高光沿表面缓慢滑过，显出拉丝、镀铬、菲涅尔反射和真实高光衰减。
- **产品全貌亮相**：产品从底部或暗处缓慢升起，四分之三侧转到正面并居中定格；保持同一套暗调擦光，只勾边、不泛白，悬浮优雅，无直冲镜头、无机械抖动。
- **多点联动特写**：全貌开场 → 半圈环绕联动 → 3 个焦点特写（保持约 15–20cm 距离，不贴脸怼）→ 拉回全貌。转场利用产品旋转、镜头转角、平移和拉升自然“滑入”下一焦点；锁定焦点后产品短暂停稳。
- **运动分工**：镜头移动时产品可短暂停稳；产品旋转时镜头顺势滑行；最后快速但平滑 pull-back 回到广角全貌，产品定格在最佳展示姿态，亮度微调做品牌感收尾。

## 三、背景 与 光（暗色纯色/渐变预设）

**背景（全片统一；渐变不以白色为基调）**

- **纯黑**：100% 纯黑无缝背景，产品与模特被光从黑暗中雕刻出来。
- **黑橙渐变**：黑色 → 深焦橙/燃烧橙，像暗场里的余烬，只作背景色温，不抢产品。
- **黑红渐变**：黑色 → 深红/酒红，戏剧张力强，适合耳机、香水、汽车、潮流数码。
- **黑金渐变**：黑色 → 暗金/琥珀金，偏奢华，适合美妆、香水、腕表。
- **黑灰烟熏**：黑色 → 炭灰，最低风险，保留极简高级感。

> 不用星空/深空、广袤空间、摄影棚场景、几何装饰；不要白色基调渐变。纯白只在用户明确指定时使用，不作为默认推荐。

**光**

- **边缘光 Rim**：干净中性白的边缘光勾勒产品光滑轮廓（纯黑背景首选，**不偏蓝**）。
- **柔和均匀光**：通透无生硬阴影（仅用户明确要纯白时使用）。
- **顶光 + 侧逆光**：戏剧性雕刻轮廓与侧影（纯黑背景）。
- **掠射光**：显材质纹理（极致微距）。

> **所有光用中性白，不偏蓝**；影调保持中性（可微暖），避免整体发蓝/冷蓝调。

## 四、DNA 硬规则（不可妥协 · 每条 prompt 必守）

 1. **有人 / 无人由用户选**：开工先问是否需要模特（见 Step 2）。**有人模式**——用 `{{Mixed N}}` 绑定、用户挑 1–3 人，模特是气质/氛围的**辅助衬托**，产品始终是焦点与视觉中心（同框时对焦与构图重心压产品、浅景深虚化人物、面部/形象不喧宾夺主）。**无人模式**——不出现任何人（有些产品让人互动反而奇怪），全片由产品 hero 镜头 / 暗场揭晓 / 微距材质 / 半圈环绕撑起。
 2. **开场即抓人 + 每镜都是有效镜头（硬约束）**：**开场节奏就要很快，第一帧就出现产品**（不要空镜/环境铺垫再慢慢引出）；**每一个镜头都必须是有效镜头**——服务于展示产品或推进节奏，**禁止废镜、无意义过场、纯氛围空镜、拖沓停留**；镜头一多就快切，不浪费任何一秒。
 3. **★ 材质是高级感的命根（最高优先级 · 硬约束）**：**"丑/廉价"绝大多数是材质塑料感、假高光、CGI 塑料质感。** 每条 prompt 都**必须写清产品的具体材质与真实光学表现**，而不是笼统一句"高级质感"：
    - 金属＝拉丝铝 / 阳极氧化 / 磨砂或抛光金属 + **真实高光衰减与各向异性反射**；
    - 玻璃＝抛光玻璃 + **菲涅尔反射、清晰环境反射（如 HDRI 反射）、真实折射**；
    - 陶瓷/塑胶＝哑光陶瓷釉面 / 软触感涂层，**避免廉价亮塑料感**；
    - 硅胶/织物＝真实次表面散射 / 编织纹理。\
      固定词：`photorealistic PBR materials, physically-based rendering, true-to-life reflections, realistic fresnel and specular falloff, fine micro-surface texture, no plastic-looking material, no fake highlights, no CGI plastic look`。**材质对了，片子就不廉价——这条优先级高于运镜、光效、构图。**
 4. **戏剧化布光服务材质**：干净中性白的边缘光 / 顶光+侧逆光 / 柔和均匀光；**布光的首要目的是让材质的反射、纹理、轮廓被看见**（真实反光 &gt; 花哨光效）；浅景深、film-grade、4K 超高清。**光用中性白，不偏蓝。**
 5. **运镜平滑电影感（硬约束）**：平滑慢动作运镜为主，运动连续顺滑、有电影呼吸感、**绝不跳帧**。**① 环绕最多半圈（≤180°），禁止绕产品一整圈；② 推镜头与拉镜头不放在同一镜内——一个镜头只做推近或只做拉远，不要又推又拉（要变向就切下一镜）；③ 面部特写抓神态（仅有人模式）。** 不生硬卡顿 / 抖动 / 甩镜。
 6. **不做 3D 拆解（硬约束）**：不做 3D 爆炸视图、内部剖切/透视、穿梭进入产品内部等拆解镜头。产品靠外部材质、光影、使用动作展示。
 7. **色彩（硬约束）**：自然真实、电影调——**绝不过暖滤镜、也绝不整体发蓝/冷蓝调**；影调保持中性（可微暖），避免蓝色偏色；光用中性白（true-to-life color, neutral grade, no blue cast, no over-warm filter）。
 8. **概念光效默认不用（易致丑 · 硬约束）**：发光光轨 / 粒子圆环 / 流动光带这类特效**极容易被 AI 生成成廉价土味、拉低质感——默认一律不加**。高级科技感应来自**干净的光比 + 真实材质反射**，不是满屏发光粒子。**仅**当产品本身概念强需要（如音频类可视化空间音频/降噪）**且用户明确要**时，才**极克制地用一次**（一个干净、优雅、克制的光效点，绝不铺满、绝不多处），否则宁可不用。
 9. **极简留白 + 极简字幕**：构图干净、负空间讲究、一镜一信息；产品细节镜头要丰富（微距/材质/飞掠）展示方方面面，**但不要不停怼 logo**；字幕仅 SF Pro / Helvetica 极简 callout，少字、留白。
10. **视频 prompt 音频规则（强制）**：每条 Seedance/视频生成 prompt 必须静音，末尾必须原样加入：`不生成背景音乐，不要任何声音。` 正文不要写 whoosh、click、环境音、拟音、提示音、chime、对白、旁白或任何声音设计。
11. **收尾定版**：银色 / 深空灰**品牌 logo**（金属质感居中，换成产品自有 logo）于纯净背景 + 产品名 SF 字淡入 + 大量留白。
12. **禁止**：废镜/无效空镜、单镜头逐个生成、3D 拆解/爆炸/剖切、叠化/叠画转场、过暖或发蓝滤镜、杂乱构图、塑料感材质、夸张怪异表情、廉价土味特效、塞满画面。

## 五、节奏规则（按时长 · 一律 15s 为一个生成片段）

视频**一律以 15s 为一个生成片段**（不做单镜头逐个生成）；每个 15s 片段内部可含多镜头，交给模型自动切分。

- **15s（快节奏）**：1 段。节奏一定要快——**人物动作与产品细节快速交替**，多镜头快切，剪辑点清晰。开场 3 秒即抓人（产品 hero / 暗场揭晓 / 使用动作）。
- **30s（内容灵活编排）**：分 2 段 15s，**内容顺序自由**——不强制"先人物、后细节"，可按创意穿插（人物使用、hero 镜头、细节任意编排）；**有人模式下必须完整展示人物使用产品的过程**。**logo 落版只放最后一段结尾。**
- **60s（内容灵活编排）**：分 4 段 15s，**内容顺序自由编排**（不强制固定顺序），逐段确认再续；有人模式确保含完整使用过程；**只在最后一段结尾做 logo 定版。**

## 七、词汇库

- **景别**：面部特写 face close-up / 极致微距 extreme macro / 特写 close-up / 中近 medium / 全景 wide clean shot。
- **运镜（硬约束）**：单向推近 push-in（不回拉）/ 单向拉远 pull-out（与推分属不同镜）/ 半圈慢动作环绕 half orbit ≤180° / 微距飞掠 macro fly-through / 稳定跟拍 steady tracking。**禁**：绕一整圈 full 360° orbit、同一镜又推又拉 push-then-pull in one shot、穿梭进入内部/拆解。
- **光**：干净中性白边缘光 clean neutral-white rim light（不偏蓝）/ 柔和均匀光 soft even light / 顶光+侧逆光 top + side-backlight / 掠射光 raking light。
- **材质（每条必带 · 越具体越不廉价）**：photorealistic PBR materials / physically-based rendering / true-to-life reflections 真实反射 / realistic fresnel reflection 菲涅尔反射 / accurate specular falloff 真实高光衰减 / anisotropic brushed metal 各向异性拉丝金属 / anodized aluminium 阳极氧化铝 / polished glass with clear environment reflections 抛光玻璃带清晰环境反射 / matte ceramic glaze 哑光陶瓷釉 / soft-touch coating 软触涂层 / woven mesh 编织网眼 / subsurface scattering 次表面散射 / fine micro-surface texture 细微表面纹理。**防丑禁词**：`no plastic-looking material, no fake highlights, no CGI plastic look, no cheap glossy plastic`。
- **色彩**：自然真实 true-to-life color / 中性影调 neutral grade / **no blue cast 无冷蓝偏色** / no over-warm filter 无过暖。
- **静音（视频 prompt）**：每条视频生成 prompt 末尾固定加：`不生成背景音乐，不要任何声音。` 不写环境音、拟音、提示音、chime、对白、旁白。
- **后期配乐（仅 Step 6）**：参考 SneakyFreak - Subway surf 的快节奏、鬼马、紧凑、surf rock + electronic groove；instrumental only, no vocals, no lyrics, no singing, no spoken voice；只参考节奏气质，不复制旋律、采样或可识别段落。
- **Cut / 转场**：干净硬切 clean hard cut / 【硬切】 / 匹配剪辑 match cut / 无缝变形 morph（**禁 dissolve/叠化**）。
- **运动质量（固定句，每条末尾加）**：`smooth fluid cinematic camera motion, steady consistent frame rate, no stutter, no frame drops, no jitter, seamless continuous coherent movement with natural motion blur.` 环绕镜头加 `slow steady cinematic half orbit up to 180 degrees, never a full circle`；推/拉镜头写明**单一方向**（`a single slow push-in` 或 `a single slow pull-out`，不在同镜又推又拉）。

## 工作流

### Step 1 · 用户上传产品 / 给参考

识别产品类型（查第一节）、形态/材质/卖点、关键细节看点、是否需要 `{{Mixed N}}`。**此阶段只识别与整理，不生成任何图片。反推参考片**：先抽帧读规格，再产同款。抽帧一行命令：

```
ffmpeg -i input.mp4 -vf fps=1 -q:v 2 frames/frame_%04d.jpg   # 每秒1帧；密集分镜调 fps=2~4
```

逐帧读：模特镜头与细节怎么配、用了哪些手法、背景与光、节奏（15s 是否够快）、Cut、收尾定版，据此填回旋钮。

### Step 2 · 一次性确认所有可提前选择项（生成图片前完成）

在生成产品图、模特图、服装图、背景图之前，**一次性收集所有能提前选的内容**，不要逐题慢慢问、不要边生成边补问。给每项都留「你帮我定」：

1. **模特与形象（第一题一次问完）**：有人/无人；若有人，同一题里立刻问完模特数量 1/2/3、性别、年龄段、国籍/人种形象、气质关键词、发型/身材倾向、服装参考/服装风格。禁止只问“是否出现模特”后，锁定选项再单独追问“模特形象偏好”。
2. 产品类型、核心卖点、镜头组合、是否允许概念光效（默认否）。
3. 时长 15s/30s/60s、画幅 16:9/9:16（视频一律 15s 为一段生成，无需再选生成模式）。
4. 背景预设：纯黑 / 黑橙渐变 / 黑红渐变 / 黑金渐变 / 黑灰烟熏；纯白只在用户明确要时可选。
5. slogan、产品名、logo/落版字、是否有背景参考图。
6. 运镜偏好：暗场微距擦光 / 线性高光扫材质 / 全貌亮相 / 多点联动特写 / 你帮我定。\
   确认后输出一份「锁定选择清单」，后续图片与视频 prompt 严格按清单执行。若用户选择有人模式但漏填形象细节，先按同一轮里的「你帮我定」自动补全为自然上镜、日常休闲、不浮夸的模特设定，不要二次打断追问。

### Step 3 · 生成参考图与 moodboard（按已锁定清单）

> **所有参考图一律 16:9 输出**：产品三视图、产品细节三视图、服装 3-look 图、角色三视图、背景氛围图，全部按 16:9 生成（背景图用 image2，其余建议 GPT Image 保真/保一致）。

1. `{{产品三视图}}`：正面 / 侧面 / 背面。
2. `{{产品细节三视图}}`：3 个关键可见细节（耳机=充电盒/耳塞/网面腔体；手机=摄像头/屏幕/接口；手表=表盘/表冠/表带）。
3. 有人模式：按锁定形象生成服装 3-look 图，服装偏日常休闲、放松自然（基础款、素色、针织/衬衫/卫衣/牛仔等），严禁暴露/情色/过度裸露；用户从 3 look 中选 1 套后生成角色白底三视图（面容特写｜全身正面｜全身背面）。
4. 背景图：按锁定背景预设扩写，只写背景/环境，不出现产品与人物；以此生成 `{{场景氛围图}}`。

随图附概念关键词 + 锁定的旋钮档位清单。**用户确认后视觉方向锁定，才进下一步。** moodboard 是把关闸口。

### Step 4 · 以 15s 为单位生成视频（统一片段化）

**一律以 15s 为一个生成片段，不做单镜头逐个生成**：**15s = 1 段；30s = 2 段 15s；60s = 4 段 15s**。每个 15s 片段一条连续 prompt，内部多镜头交给模型自动切分、给意图与节奏不锁死机位；**各段内容顺序自由编排，不强制"先人物后细节"**；**有人模式下务必含完整的人物使用过程**；多段之间以末帧 / 同 `{{Mixed N}}` 续接，逐段确认后再出下一段，保持 `{{Mixed N}}`、服装、产品、背景、光一致，衔接不穿帮。**logo 落版只放最后一段结尾。**

### Step 5 · 按 Seedance 2.0 格式输出（严格按 moodboard）

> 严格按 Step 2 的锁定选择清单输出；不要再临时更换背景、模特、时长或画幅。每条 = 一个 15s 片段。

每条第一句引用背景图：`请参考 {{场景氛围图}} 作为背景氛围。`（EN：`Use {{scene_mood_ref}} as the background atmosphere reference.`）随后接**基底块 + 背景/光/句块 + 分镜**，末尾加运动质量句。要点：

- **一致性（强约束）**：背景=`{{场景氛围图}}`；模特=`{{Mixed N}}`（脸/发/服装一致）；产品=`{{产品三视图}}`/`{{产品细节三视图}}`；逐镜不漂移。段与段之间**内容/景别/节奏错开**，别前后雷同。
- **★ 材质（每条必写 · 最高优先级）**：写清产品的具体材质与真实反射（DNA 3 与第七节材质词库），如"拉丝阳极氧化铝边框带真实高光衰减""抛光玻璃背板带清晰环境反射（菲涅尔）""哑光陶瓷釉面"；每条固定带防丑禁词 `photorealistic PBR, true-to-life reflections, no plastic-looking material, no fake highlights, no CGI plastic look`。**防"廉价/丑"的第一道闸。**
- **人物互动（有人模式 · 强约束）**：写模特镜头前先按二 A「动作合理性检查」推出真实使用动作，写清**正确握持/佩戴/接触点 + 起势→操作→反馈/结果 + 匹配表情 + 视线/身体随动**（如"戴上耳机闭眼随节奏点头"、"拉门坐进点火起步"、"举起相机取景按快门后看回放微笑"）；**禁呆站举着、无动作无表情、用法不合常理**；产品仍是对焦焦点。
- **运镜（强约束）**：环绕\*\*≤半圈\*\*、推拉**不同镜**、连贯**不跳帧**；细节段落走"单向推近→一镜一细节→微距飞掠"；**不做拆解/进入内部**。
- **运镜精华**：优先用"暗场微距擦光 / 线性高光扫材质 / 全貌亮相 / 多点联动特写 / pull-back 回归全貌"；特写保持 15–20cm 距离，转场靠产品旋转和镜头转角自然滑入，避免机械抖动和直冲镜头。
- **色彩**：影调中性、**无冷蓝偏色**、无过暖；光用中性白。
- **光效**：默认**不加**发光光轨/粒子圆环等；仅用户明确要且产品概念确需时极克制写一次（干净单点，绝不铺满）。
- **每段 prompt** = 引用背景图 → 基底+块+句 + 全局设定 → 15s 内多镜头意图与节奏（含硬切、景别变化）→ 收尾落点句（仅最后一段带 logo 定版）。多段续接写明与上一段一致（`same {{Mixed 1}} / same wardrobe / same background / same lighting, seamless match`）。
- **静音（强制）**：每条视频生成 prompt 不写任何声音设计；末尾必须原样加：`不生成背景音乐，不要任何声音。`
- **运动质量**：每条 prompt 末尾固定加运动质量句（第七节）。

### Step 6 · 视频合成与统一后期配乐（成片输出）

- **剪辑合成**：所有 15s 片段（15s 单段、30s/60s 多段）先按顺序拼接，统一画幅帧率、处理段间衔接。视频生成片段本身必须无声。
- **配乐（强制后期统一生成）**：任何时长都不允许在视频生成 prompt 内带背景音乐或任何声音。合成后**先看一遍成片、分析实际节奏与情绪**，再生成一条为整片量身匹配的背景音乐：
  - **风格参考**：类似 SneakyFreak - Subway surf 的快节奏、鬼马、紧凑、灵动、带 surf rock 弹跳感与电子 groove 的广告配乐；只参考节奏气质，不复制旋律、采样或可识别段落；
  - **必须纯音乐**：no vocals / no lyrics / no singing / no spoken voice / 无人声唱歌 / 无念白；
  - **卡点**：对齐关键剪辑点（使用动作、推近、揭晓、落版），轻快但不喧宾夺主；
  - **时长严格匹配成片**，结尾用音乐自身的短促收束做品牌感。输出最终带乐版。

## 通用约束

- 一条 prompt 用一种主语言整条交付（示例用中文，Seedance/即梦 原生友好），需要时附英文镜像；包在可复制代码块。**每条 = 一个 15s 片段，不做单镜头逐个生成。**
- **有人/无人由用户选**：有人时用 `{{Mixed N}}`（首现写全、后续复用）、产品以 `{{产品三视图}}`/`{{产品细节三视图}}` 为准、每镜清晰；无人时用产品 hero / 暗场揭晓 / 微距材质撑起。
- 分段续接时，务必保持 `{{Mixed N}}`、服装、产品、背景、光一致，衔接不穿帮；**段间内容/景别/节奏错开、不雷同**。
- **背景一致性（强约束）**：所有分镜背景须与**选定并生成的** `{{场景氛围图}}` 严格一致（纯黑或暗色渐变，全片统一；不要白色基调渐变）。
- **★ 材质（防丑第一条）**：每条 prompt 必写产品具体材质与真实反射（PBR、菲涅尔、真实高光衰减、微表面纹理），固定带 `no plastic-looking material / no fake highlights / no CGI plastic look`；材质优先级高于运镜、光效、构图。
- **运镜（硬约束）**：环绕最多半圈（禁一整圈）；推镜与拉镜不同镜、绝不同镜又推又拉；连贯**绝不跳帧**；**不做 3D 拆解/进入内部**；面部特写抓神态（仅有人）。
- **色彩（硬约束）**：影调中性、**避免整体发蓝/冷蓝调**、无过暖；光用中性白。
- **模特（有人模式 · 辅助 · 产品才是焦点）**：Step 2 第一题必须把有人/无人与模特形象一次问完；有人时同题确认 1–3 人、性别、年龄段、国籍/人种形象、气质、发型/身材倾向、服装参考/服装风格，禁止锁定后再单独追问模特形象；选国籍形象后直接选服装：3 套全身 look 同框于一张纯白 16:9 图，**服装偏日常休闲、不商业不浮夸潮流、严禁暴露**；不再单独出形象图，人物由换装后白底三视图锚定；**必须先判断产品真实用法，再推出具体连贯的互动动作 + 正确握持/接触点 + 匹配表情/情绪 + 身体自然随动（禁呆站举着、禁面瘫呆滞、禁夸张怪异、禁用法不合常理）、且完整展示使用过程**；**人物与产品同框时对焦与视觉中心压在产品上，浅景深柔化人物，模特面部/形象只作气质衬托、不喧宾夺主**。
- **音频（强制）**：视频生成 prompt 必须静音，不写环境音、拟音、提示音、chime、对白、旁白；末尾必须加：`不生成背景音乐，不要任何声音。`
- **概念光效（默认不用）**：发光光轨/粒子圆环等易致丑，**默认不加**；仅用户明确要且产品概念确需时极克制用一次，绝不铺满、绝不多处。
- 一条片承载一个核心信息点；前 3 秒抓人、第一帧即出产品；每镜有效无废镜；结尾必有落点（品牌 logo + 产品名 + 后期配乐收束）。
- 不做涉及真实公众人物的内容；不杜撰真实品牌虚假主张或具体内部参数；不模仿或暗示任何特定品牌身份；保持适当无害。
