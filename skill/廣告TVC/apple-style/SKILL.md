## 一、產品型別分類（識別產品 → 拿預設鏡頭組合）

產品型別細節看點人物互動動作（示例·需現推）預設鏡頭組合耳機 / 音訊陶瓷/金屬輪廓·網面·腔體戴上耳機、閉眼隨節奏點頭/律動/跳舞模特戴耳機律動 → 半圈環繞 → 微距材質細節 → 微距飛掠網面 → 落版手機 / 平板 / 筆電邊框倒角·螢幕·攝像頭·介面解鎖滑動、舉起拍攝、看到內容的反應模特使用(有反應) → 單向推/拉+半圈環繞 → 微距細節 → 材質特寫 → 落版智慧穿戴 / 手錶錶盤·錶冠·感測器·錶帶抬腕看錶、運動檢視資料、轉動錶冠模特抬腕檢視 → 半圈環繞 → 微距 → 材質特寫 → 落版相機 / 影像鏡組·卡口·轉盤·握把舉起取景、按快門、看回放微笑模特取景拍照 → 微距飛掠鏡組 → 半圈環繞 → 材質特寫美妝 / 個護瓶身·質地·塗抹·光澤對鏡塗抹、抿唇、端詳效果；吹風機吹髮模特使用(塗抹/吹髮) → 微距質地 → 半圈環繞 → 材質特寫汽車 / 出行車身線條·內飾·輪轂·燈組拉門坐進、點火、握方向盤起步/飆車模特上車啟動 → 內飾微距 → 半圈環繞 → 疾馳鏡頭運動 / 戶外材質·結構·功能繫鞋帶、起跑騰空、發力使用模特起跑/發力 → 微距材質 → 半圈環繞 → 落版數碼配件 / 其他消費品設計·材質·結構按真實用途現推一個使用動作模特使用 → 半圈環繞+單向推/拉 → 微距材質 → 落版

## 二、鏡頭手法（模特鏡頭打底 + 細節穿插）

### A. 模特鏡頭（有人模式 · 打底）

> **★ 焦點原則（硬約束）**：模特與產品互動時，**焦點與視覺中心始終在產品上**——產品清晰、居於視覺重心、被光與景彆強調；**模特的面部與形象只是輔助/襯託**（負責氛圍、氣質、比例與真實感），不喧賓奪主。構圖與對焦優先給產品：淺景深虛化模特、實焦壓在產品上；人物可只入鏡區域性（手、肩、側臉、佩戴部位）。

> **★★ 互動判斷（硬約束 · 先想清楚"人怎麼用它"再寫鏡頭）**：**禁止讓人物呆站著只是"舉著/拿著"產品、沒動作沒表情。** 出模特鏡頭前，必須先判斷產品的**真實用途、常見場景、正確握持/佩戴/接觸位置、需要哪隻手/身體部位、人物視線與身體重心如何自然跟隨**，再推出一個**具體、有動機的動作與情境**，讓人物真正"用起來"，並帶**明確表情/情緒**。例如：
>
> - 耳機 → 戴上耳機、隨節奏點頭/閉眼沉浸/跟著律動跳舞
> - 汽車/鑰匙 → 拉開車門坐進去、點火、握方向盤起步加速/飆車
> - 吹風機 → 拿起吹風機吹頭髮，頭髮被氣流吹動
> - 相機 → 舉起相機取景、按下快門拍照，回看照片露出滿意神情
> - 口紅/美妝 → 對鏡塗抹、抿唇、端詳效果
> - 運動鞋 → 繫鞋帶、起跑/騰空
> - 手機 → 解鎖、滑動、舉起拍攝、看到內容的反應
> ****動作合理性檢查（必須先做）**：`誰在什麼場景為什麼用 → 正確握持/佩戴/接觸點 → 起勢→接觸/操作→反饋/結果 → 視線、肩肘手腕、身體重心與微表情自然跟隨 → 產品始終是焦點`。動作要有預備、操作、停頓反饋和自然表情，禁站樁舉物、手指懸空、身體僵直、用法錯誤。若全身使用不合常理，自動改成手部/半身/區域性佩戴或無人 hero+細節，不硬塞模特。
> ****必須完整展示使用過程（硬約束）**：有人模式下，影片裡一定要拍出人物**使用產品的完整過程**（起始 → 使用中 → 結果/反應），不能只給一個"持有/靜態展示"畫面、也不能跳過使用動作直接切細節。使用過程本身就是內容主線。

- **動作要具體連貫**：寫清起始→過程→結果的小動作鏈（如"拿起相機→舉到眼前取景→按下快門→放下相機看回放微笑"），同時寫握持/接觸部位、視線、肩肘手腕或重心隨動，不是靜態 pose。
- **表情要到位**：沉浸、專注、驚喜、滿意、享受……與動作匹配、自然可信，**禁止面癱呆滯，也禁止誇張怪異**。
- **產品仍是焦點**：動作服務於"把產品用起來、被看見"；對焦壓產品、淺景深虛化人物，人物可只入鏡區域性。
- 用 `{{Mixed N}}` 繫結選定模特，全程一致。

### B. 產品細節鏡頭（穿插 · 以材質為主）

1. **微距材質特寫（主力）**：極致微距一鏡一細節，掠射光掃過表面**呈現真實材質**——拉絲、陽極氧化、玻璃菲涅爾反射、陶瓷釉面、編織紋理。產品片高階感的主要來源。
2. **微距飛掠（Macro Fly-through）**：鏡頭快速飛掠網面 / 材質表面。
3. **暗場揭曉（Reveal from Black）**：產品從純黑中被光逐漸點亮、緩緩浮現的 hero 登場（不用星空/深空）。
4. **半圈慢環繞（Half Orbit）**：緩慢勻速環繞產品**最多半圈**（≤180°），欣賞外形與輪廓。

> **不做 3D 拆解**：不做 3D 爆炸檢視、內部剖切/透視、鏡頭穿梭進入產品內部等"拆解/看內部"鏡頭。產品靠**外部材質、光影、使用動作**來展示。
>
> 典型順接：**模特使用（焦點在產品）→ 半圈環繞 → 微距材質細節 → 微距飛掠 → 落版**。
>
> 細節段落寫法：**單向推近產品（只推不回拉）→ 逐一展示各部分細節（一鏡一個，材質微距，可配最多半圈微環繞）→ 微距飛掠**，鏡頭連貫不跳幀；推與拉分屬不同鏡頭；**不進入內部、不拆解**。

### C. 運鏡精華（從優質 prompt 提煉）

- **暗場微距擦光**：極高精細度微距，純黑/暗色漸變背景；一道銳利銀色輪廓光或掠射光緩慢掃過產品邊緣、孔洞、紋理，讓結構內部產生深邃幾何陰影，捕捉泡沫/織物/金屬/陶瓷的觸感紋理；高反差、慢動作、拒絕大面積照亮。
- **線性高光掃材質**：近景鎖定金屬/玻璃/陶瓷區域性，讓一條線性高光沿表面緩慢滑過，顯出拉絲、鍍鉻、菲涅爾反射和真實高光衰減。
- **產品全貌亮相**：產品從底部或暗處緩慢升起，四分之三側轉到正面並居中定格；保持同一套暗調擦光，只勾邊、不泛白，懸浮優雅，無直衝鏡頭、無機械抖動。
- **多點聯動特寫**：全貌開場 → 半圈環繞聯動 → 3 個焦點特寫（保持約 15–20cm 距離，不貼臉懟）→ 拉回全貌。轉場利用產品旋轉、鏡頭轉角、平移和拉昇自然“滑入”下一焦點；鎖定焦點後產品短暫停穩。
- **運動分工**：鏡頭移動時產品可短暫停穩；產品旋轉時鏡頭順勢滑行；最後快速但平滑 pull-back 回到廣角全貌，產品定格在最佳展示姿態，亮度微調做品牌感收尾。

## 三、背景 與 光（暗色純色/漸變預設）

**背景（全片統一；漸變不以白色為基調）**

- **純黑**：100% 純黑無縫背景，產品與模特被光從黑暗中雕刻出來。
- **黑橙漸變**：黑色 → 深焦橙/燃燒橙，像暗場裡的餘燼，只作背景色溫，不搶產品。
- **黑紅漸變**：黑色 → 深紅/酒紅，戲劇張力強，適合耳機、香水、汽車、潮流數碼。
- **黑金漸變**：黑色 → 暗金/琥珀金，偏奢華，適合美妝、香水、腕錶。
- **黑灰煙燻**：黑色 → 炭灰，最低風險，保留極簡高階感。

> 不用星空/深空、廣袤空間、攝影棚場景、幾何裝飾；不要白色基調漸變。純白只在使用者明確指定時使用，不作為預設推薦。

**光**

- **邊緣光 Rim**：乾淨中性白的邊緣光勾勒產品光滑輪廓（純黑背景首選，**不偏藍**）。
- **柔和均勻光**：通透無生硬陰影（僅使用者明確要純白時使用）。
- **頂光 + 側逆光**：戲劇性雕刻輪廓與側影（純黑背景）。
- **掠射光**：顯材質紋理（極致微距）。

> **所有光用中性白，不偏藍**；影調保持中性（可微暖），避免整體發藍/冷藍調。

## 四、DNA 硬規則（不可妥協 · 每條 prompt 必守）

 1. **有人 / 無人由使用者選**：開工先問是否需要模特（見 Step 2）。**有人模式**——用 `{{Mixed N}}` 繫結、使用者挑 1–3 人，模特是氣質/氛圍的**輔助襯託**，產品始終是焦點與視覺中心（同框時對焦與構圖重心壓產品、淺景深虛化人物、面部/形象不喧賓奪主）。**無人模式**——不出現任何人（有些產品讓人互動反而奇怪），全片由產品 hero 鏡頭 / 暗場揭曉 / 微距材質 / 半圈環繞撐起。
 2. **開場即抓人 + 每鏡都是有效鏡頭（硬約束）**：**開場節奏就要很快，第一幀就出現產品**（不要空鏡/環境鋪墊再慢慢引出）；**每一個鏡頭都必須是有效鏡頭**——服務於展示產品或推進節奏，**禁止廢鏡、無意義過場、純氛圍空鏡、拖沓停留**；鏡頭一多就快切，不浪費任何一秒。
 3. **★ 材質是高階感的命根（最高優先順序 · 硬約束）**：**"醜/廉價"絕大多數是材質塑膠感、假高光、CGI 塑膠質感。** 每條 prompt 都**必須寫清產品的具體材質與真實光學表現**，而不是籠統一句"高階質感"：
    - 金屬＝拉絲鋁 / 陽極氧化 / 磨砂或拋光金屬 + **真實高光衰減與各向異性反射**；
    - 玻璃＝拋光玻璃 + **菲涅爾反射、清晰環境反射（如 HDRI 反射）、真實折射**；
    - 陶瓷/塑膠＝啞光陶瓷釉面 / 軟觸感塗層，**避免廉價亮塑膠感**；
    - 矽膠/織物＝真實次表面散射 / 編織紋理。\
      固定詞：`photorealistic PBR materials, physically-based rendering, true-to-life reflections, realistic fresnel and specular falloff, fine micro-surface texture, no plastic-looking material, no fake highlights, no CGI plastic look`。**材質對了，片子就不廉價——這條優先順序高於運鏡、光效、構圖。**
 4. **戲劇化布光服務材質**：乾淨中性白的邊緣光 / 頂光+側逆光 / 柔和均勻光；**布光的首要目的是讓材質的反射、紋理、輪廓被看見**（真實反光 &gt; 花哨光效）；淺景深、film-grade、4K 超高畫質。**光用中性白，不偏藍。**
 5. **運鏡平滑電影感（硬約束）**：平滑慢動作運鏡為主，運動連續順滑、有電影呼吸感、**絕不跳幀**。**① 環繞最多半圈（≤180°），禁止繞產品一整圈；② 推鏡頭與拉鏡頭不放在同一鏡內——一個鏡頭只做推近或只做拉遠，不要又推又拉（要變向就切下一鏡）；③ 面部特寫抓神態（僅有人模式）。** 不生硬卡頓 / 抖動 / 甩鏡。
 6. **不做 3D 拆解（硬約束）**：不做 3D 爆炸檢視、內部剖切/透視、穿梭進入產品內部等拆解鏡頭。產品靠外部材質、光影、使用動作展示。
 7. **色彩（硬約束）**：自然真實、電影調——**絕不過暖濾鏡、也絕不整體發藍/冷藍調**；影調保持中性（可微暖），避免藍色偏色；光用中性白（true-to-life color, neutral grade, no blue cast, no over-warm filter）。
 8. **概念光效預設不用（易致醜 · 硬約束）**：發光光軌 / 粒子圓環 / 流動光帶這類特效**極容易被 AI 生成成廉價土味、拉低質感——預設一律不加**。高階科技感應來自**乾淨的光比 + 真實材質反射**，不是滿屏發光粒子。**僅**當產品本身概念強需要（如音訊類視覺化空間音訊/降噪）**且使用者明確要**時，才**極剋制地用一次**（一個乾淨、優雅、剋制的光效點，絕不鋪滿、絕不多處），否則寧可不用。
 9. **極簡留白 + 極簡字幕**：構圖乾淨、負空間講究、一鏡一資訊；產品細節鏡頭要豐富（微距/材質/飛掠）展示方方面面，**但不要不停懟 logo**；字幕僅 SF Pro / Helvetica 極簡 callout，少字、留白。
10. **影片 prompt 音訊規則（強制）**：每條 Seedance/影片生成 prompt 必須靜音，末尾必須原樣加入：`不生成背景音樂，不要任何聲音。` 正文不要寫 whoosh、click、環境音、擬音、提示音、chime、對白、旁白或任何聲音設計。
11. **收尾定版**：銀色 / 深空灰**品牌 logo**（金屬質感居中，換成產品自有 logo）於純淨背景 + 產品名 SF 字淡入 + 大量留白。
12. **禁止**：廢鏡/無效空鏡、單鏡頭逐個生成、3D 拆解/爆炸/剖切、疊化/疊畫轉場、過暖或發藍濾鏡、雜亂構圖、塑膠感材質、誇張怪異表情、廉價土味特效、塞滿畫面。

## 五、節奏規則（按時長 · 一律 15s 為一個生成片段）

影片**一律以 15s 為一個生成片段**（不做單鏡頭逐個生成）；每個 15s 片段內部可含多鏡頭，交給模型自動切分。

- **15s（快節奏）**：1 段。節奏一定要快——**人物動作與產品細節快速交替**，多鏡頭快切，剪輯點清晰。開場 3 秒即抓人（產品 hero / 暗場揭曉 / 使用動作）。
- **30s（內容靈活編排）**：分 2 段 15s，**內容順序自由**——不強制"先人物、後細節"，可按創意穿插（人物使用、hero 鏡頭、細節任意編排）；**有人模式下必須完整展示人物使用產品的過程**。**logo 落版只放最後一段結尾。**
- **60s（內容靈活編排）**：分 4 段 15s，**內容順序自由編排**（不強制固定順序），逐段確認再續；有人模式確保含完整使用過程；**只在最後一段結尾做 logo 定版。**

真實反射、菲涅爾反射與真實高光衰減、細微表面紋理，杜絕塑膠感、假高光、CGI 塑膠質感；

## 七、詞彙庫

- **景別**：面部特寫 face close-up / 極致微距 extreme macro / 特寫 close-up / 中近 medium / 全景 wide clean shot。
- **運鏡（硬約束）**：單向推近 push-in（不回拉）/ 單向拉遠 pull-out（與推分屬不同鏡）/ 半圈慢動作環繞 half orbit ≤180° / 微距飛掠 macro fly-through / 穩定跟拍 steady tracking。**禁**：繞一整圈 full 360° orbit、同一鏡又推又拉 push-then-pull in one shot、穿梭進入內部/拆解。
- **光**：乾淨中性白邊緣光 clean neutral-white rim light（不偏藍）/ 柔和均勻光 soft even light / 頂光+側逆光 top + side-backlight / 掠射光 raking light。
- **材質（每條必帶 · 越具體越不廉價）**：photorealistic PBR materials / physically-based rendering / true-to-life reflections 真實反射 / realistic fresnel reflection 菲涅爾反射 / accurate specular falloff 真實高光衰減 / anisotropic brushed metal 各向異性拉絲金屬 / anodized aluminium 陽極氧化鋁 / polished glass with clear environment reflections 拋光玻璃帶清晰環境反射 / matte ceramic glaze 啞光陶瓷釉 / soft-touch coating 軟觸塗層 / woven mesh 編織網眼 / subsurface scattering 次表面散射 / fine micro-surface texture 細微表面紋理。**防醜禁詞**：`no plastic-looking material, no fake highlights, no CGI plastic look, no cheap glossy plastic`。
- **色彩**：自然真實 true-to-life color / 中性影調 neutral grade / **no blue cast 無冷藍偏色** / no over-warm filter 無過暖。
- **靜音（影片 prompt）**：每條影片生成 prompt 末尾固定加：`不生成背景音樂，不要任何聲音。` 不寫環境音、擬音、提示音、chime、對白、旁白。
- **後期配樂（僅 Step 6）**：參考 SneakyFreak - Subway surf 的快節奏、鬼馬、緊湊、surf rock + electronic groove；instrumental only, no vocals, no lyrics, no singing, no spoken voice；只參考節奏氣質，不復制旋律、取樣或可識別段落。
- **Cut / 轉場**：乾淨硬切 clean hard cut / 【硬切】 / 匹配剪輯 match cut / 無縫變形 morph（**禁 dissolve/疊化**）。
- **運動質量（固定句，每條末尾加）**：`smooth fluid cinematic camera motion, steady consistent frame rate, no stutter, no frame drops, no jitter, seamless continuous coherent movement with natural motion blur.` 環繞鏡頭加 `slow steady cinematic half orbit up to 180 degrees, never a full circle`；推/拉鏡頭寫明**單一方向**（`a single slow push-in` 或 `a single slow pull-out`，不在同鏡又推又拉）。

## 工作流

### Step 1 · 使用者上傳產品 / 給參考

識別產品型別（查第一節）、形態/材質/賣點、關鍵細節看點、是否需要 `{{Mixed N}}`。**此階段只識別與整理，不生成任何圖片。反推參考片**：先抽幀讀規格，再產同款。抽幀一行命令：

```
ffmpeg -i input.mp4 -vf fps=1 -q:v 2 frames/frame_%04d.jpg   # 每秒1幀；密集分鏡調 fps=2~4
```

逐幀讀：模特鏡頭與細節怎麼配、用了哪些手法、背景與光、節奏（15s 是否夠快）、Cut、收尾定版，據此填迴旋鈕。

### Step 2 · 一次性確認所有可提前選擇項（生成圖片前完成）

在生成產品圖、模特圖、服裝圖、背景圖之前，**一次性收集所有能提前選的內容**，不要逐題慢慢問、不要邊生成邊補問。給每項都留「你幫我定」：

1. **模特與形象（第一題一次問完）**：有人/無人；若有人，同一題裡立刻問完模特數量 1/2/3、性別、年齡段、國籍/人種形象、氣質關鍵詞、髮型/身材傾向、服裝參考/服裝風格。禁止只問“是否出現模特”後，鎖定選項再單獨追問“模特形象偏好”。
2. 產品型別、核心賣點、鏡頭組合、是否允許概念光效（預設否）。
3. 時長 15s/30s/60s、畫幅 16:9/9:16（影片一律 15s 為一段生成，無需再選生成模式）。
4. 背景預設：純黑 / 黑橙漸變 / 黑紅漸變 / 黑金漸變 / 黑灰煙燻；純白只在使用者明確要時可選。
5. slogan、產品名、logo/落版字、是否有背景參考圖。
6. 運鏡偏好：暗場微距擦光 / 線性高光掃材質 / 全貌亮相 / 多點聯動特寫 / 你幫我定。\
   確認後輸出一份「鎖定選擇清單」，後續圖片與影片 prompt 嚴格按清單執行。若使用者選擇有人模式但漏填形象細節，先按同一輪裡的「你幫我定」自動補全為自然上鏡、日常休閒、不浮誇的模特設定，不要二次打斷追問。

### Step 3 · 生成參考圖與 moodboard（按已鎖定清單）

> **所有參考圖一律 16:9 輸出**：產品三檢視、產品細節三檢視、服裝 3-look 圖、角色三檢視、背景氛圍圖，全部按 16:9 生成（背景圖用 image2，其餘建議 GPT Image 保真/保一致）。

1. `{{產品三檢視}}`：正面 / 側面 / 背面。
2. `{{產品細節三檢視}}`：3 個關鍵可見細節（耳機=充電盒/耳塞/網面腔體；手機=攝像頭/螢幕/介面；手錶=錶盤/錶冠/錶帶）。
3. 有人模式：按鎖定形象生成服裝 3-look 圖，服裝偏日常休閒、放鬆自然（基礎款、素色、針織/襯衫/衛衣/牛仔等），嚴禁暴露/情色/過度裸露；使用者從 3 look 中選 1 套後生成角色白底三檢視（面容特寫｜全身正面｜全身背面）。
4. 背景圖：按鎖定背景預設擴寫，只寫背景/環境，不出現產品與人物；以此生成 `{{場景氛圍圖}}`。

隨圖附概念關鍵詞 + 鎖定的旋鈕檔位清單。**使用者確認後視覺方向鎖定，才進下一步。** moodboard 是把關閘口。

### Step 4 · 以 15s 為單位生成影片（統一片段化）

**一律以 15s 為一個生成片段，不做單鏡頭逐個生成**：**15s = 1 段；30s = 2 段 15s；60s = 4 段 15s**。每個 15s 片段一條連續 prompt，內部多鏡頭交給模型自動切分、給意圖與節奏不鎖宕機位；**各段內容順序自由編排，不強制"先人物後細節"**；**有人模式下務必含完整的人物使用過程**；多段之間以末幀 / 同 `{{Mixed N}}` 續接，逐段確認後再出下一段，保持 `{{Mixed N}}`、服裝、產品、背景、光一致，銜接不穿幫。**logo 落版只放最後一段結尾。**

### Step 5 · 按 Seedance 2.0 格式輸出（嚴格按 moodboard）

> 嚴格按 Step 2 的鎖定選擇清單輸出；不要再臨時更換背景、模特、時長或畫幅。每條 = 一個 15s 片段。

每條第一句引用背景圖：`請參考 {{場景氛圍圖}} 作為背景氛圍。`（EN：`Use {{scene_mood_ref}} as the background atmosphere reference.`）隨後接**基底塊 + 背景/光/句塊 + 分鏡**，末尾加運動質量句。要點：

- **一致性（強約束）**：背景=`{{場景氛圍圖}}`；模特=`{{Mixed N}}`（臉/發/服裝一致）；產品=`{{產品三檢視}}`/`{{產品細節三檢視}}`；逐鏡不漂移。段與段之間**內容/景別/節奏錯開**，別前後雷同。
- **★ 材質（每條必寫 · 最高優先順序）**：寫清產品的具體材質與真實反射（DNA 3 與第七節材質詞庫），如"拉絲陽極氧化鋁邊框帶真實高光衰減""拋光玻璃背板帶清晰環境反射（菲涅爾）""啞光陶瓷釉面"；每條固定帶防醜禁詞 `photorealistic PBR, true-to-life reflections, no plastic-looking material, no fake highlights, no CGI plastic look`。**防"廉價/醜"的第一道閘。**
- **人物互動（有人模式 · 強約束）**：寫模特鏡頭前先按二 A「動作合理性檢查」推出真實使用動作，寫清**正確握持/佩戴/接觸點 + 起勢→操作→反饋/結果 + 匹配表情 + 視線/身體隨動**（如"戴上耳機閉眼隨節奏點頭"、"拉門坐進點火起步"、"舉起相機取景按快門後看回放微笑"）；**禁呆站舉著、無動作無表情、用法不合常理**；產品仍是對焦焦點。
- **運鏡（強約束）**：環繞\*\*≤半圈\*\*、推拉**不同鏡**、連貫**不跳幀**；細節段落走"單向推近→一鏡一細節→微距飛掠"；**不做拆解/進入內部**。
- **運鏡精華**：優先用"暗場微距擦光 / 線性高光掃材質 / 全貌亮相 / 多點聯動特寫 / pull-back 迴歸全貌"；特寫保持 15–20cm 距離，轉場靠產品旋轉和鏡頭轉角自然滑入，避免機械抖動和直衝鏡頭。
- **色彩**：影調中性、**無冷藍偏色**、無過暖；光用中性白。
- **光效**：預設**不加**發光光軌/粒子圓環等；僅使用者明確要且產品概念確需時極剋制寫一次（乾淨單點，絕不鋪滿）。
- **每段 prompt** = 引用背景圖 → 基底+塊+句 + 全域性設定 → 15s 內多鏡頭意圖與節奏（含硬切、景別變化）→ 收尾落點句（僅最後一段帶 logo 定版）。多段續接寫明與上一段一致（`same {{Mixed 1}} / same wardrobe / same background / same lighting, seamless match`）。
- **靜音（強制）**：每條影片生成 prompt 不寫任何聲音設計；末尾必須原樣加：`不生成背景音樂，不要任何聲音。`
- **運動質量**：每條 prompt 末尾固定加運動質量句（第七節）。

### Step 6 · 影片合成與統一後期配樂（成片輸出）

- **剪輯合成**：所有 15s 片段（15s 單段、30s/60s 多段）先按順序拼接，統一畫幅幀率、處理段間銜接。影片生成片段本身必須無聲。
- **配樂（強制後期統一生成）**：任何時長都不允許在影片生成 prompt 內帶背景音樂或任何聲音。合成後**先看一遍成片、分析實際節奏與情緒**，再生成一條為整片量身匹配的背景音樂：
  - **風格參考**：類似 SneakyFreak - Subway surf 的快節奏、鬼馬、緊湊、靈動、帶 surf rock 彈跳感與電子 groove 的廣告配樂；只參考節奏氣質，不復制旋律、取樣或可識別段落；
  - **必須純音樂**：no vocals / no lyrics / no singing / no spoken voice / 無人聲唱歌 / 無唸白；
  - **卡點**：對齊關鍵剪輯點（使用動作、推近、揭曉、落版），輕快但不喧賓奪主；
  - **時長嚴格匹配成片**，結尾用音樂自身的短促收束做品牌感。輸出最終帶樂版。

## 通用約束

- 一條 prompt 用一種主語言整條交付（示例用中文，Seedance/即夢 原生友好），需要時附英文映象；包在可複製程式碼塊。**每條 = 一個 15s 片段，不做單鏡頭逐個生成。**
- **有人/無人由使用者選**：有人時用 `{{Mixed N}}`（首現寫全、後續複用）、產品以 `{{產品三檢視}}`/`{{產品細節三檢視}}` 為準、每鏡清晰；無人時用產品 hero / 暗場揭曉 / 微距材質撐起。
- 分段續接時，務必保持 `{{Mixed N}}`、服裝、產品、背景、光一致，銜接不穿幫；**段間內容/景別/節奏錯開、不雷同**。
- **背景一致性（強約束）**：所有分鏡背景須與**選定並生成的** `{{場景氛圍圖}}` 嚴格一致（純黑或暗色漸變，全片統一；不要白色基調漸變）。
- **★ 材質（防醜第一條）**：每條 prompt 必寫產品具體材質與真實反射（PBR、菲涅爾、真實高光衰減、微表面紋理），固定帶 `no plastic-looking material / no fake highlights / no CGI plastic look`；材質優先順序高於運鏡、光效、構圖。
- **運鏡（硬約束）**：環繞最多半圈（禁一整圈）；推鏡與拉鏡不同鏡、絕不同鏡又推又拉；連貫**絕不跳幀**；**不做 3D 拆解/進入內部**；面部特寫抓神態（僅有人）。
- **色彩（硬約束）**：影調中性、**避免整體發藍/冷藍調**、無過暖；光用中性白。
- **模特（有人模式 · 輔助 · 產品才是焦點）**：Step 2 第一題必須把有人/無人與模特形象一次問完；有人時同題確認 1–3 人、性別、年齡段、國籍/人種形象、氣質、髮型/身材傾向、服裝參考/服裝風格，禁止鎖定後再單獨追問模特形象；選國籍形象後直接選服裝：3 套全身 look 同框於一張純白 16:9 圖，**服裝偏日常休閒、不商業不浮誇潮流、嚴禁暴露**；不再單獨出形象圖，人物由換裝後白底三檢視錨定；**必須先判斷產品真實用法，再推出具體連貫的互動動作 + 正確握持/接觸點 + 匹配表情/情緒 + 身體自然隨動（禁呆站舉著、禁面癱呆滯、禁誇張怪異、禁用法不合常理）、且完整展示使用過程**；**人物與產品同框時對焦與視覺中心壓在產品上，淺景深柔化人物，模特面部/形象只作氣質襯託、不喧賓奪主**。
- **音訊（強制）**：影片生成 prompt 必須靜音，不寫環境音、擬音、提示音、chime、對白、旁白；末尾必須加：`不生成背景音樂，不要任何聲音。`
- **概念光效（預設不用）**：發光光軌/粒子圓環等易致醜，**預設不加**；僅使用者明確要且產品概念確需時極剋制用一次，絕不鋪滿、絕不多處。
- 一條片承載一個核心資訊點；前 3 秒抓人、第一幀即出產品；每鏡有效無廢鏡；結尾必有落點（品牌 logo + 產品名 + 後期配樂收束）。
- 不做涉及真實公眾人物的內容；不杜撰真實品牌虛假主張或具體內部引數；不模仿或暗示任何特定品牌身份；保持適當無害。
