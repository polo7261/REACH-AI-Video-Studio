# 電影運鏡設計

## 適用場景

適用於AI短片、品牌廣告、TVC、MV、影視劇情、產品展示、空間展示、舞蹈動作等場景，尤其解決“畫面能生成，但鏡頭不會拍”的問題。

## 輸出

電影級Camera Plan、專業運鏡方案、Camera Path、九宮格Camera Storyboard、AI影片生成Prompt及15秒連續影片，可擴展為30秒、60秒等多段連續影片。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
