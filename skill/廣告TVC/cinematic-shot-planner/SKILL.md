# 电影运镜设计

## 適用場景

适用于AI短片、品牌广告、TVC、MV、影视剧情、产品展示、空间展示、舞蹈动作等场景，尤其解决“画面能生成，但镜头不会拍”的问题。

## 輸出

电影级Camera Plan、专业运镜方案、Camera Path、九宫格Camera Storyboard、AI视频生成Prompt及15秒连续视频，可扩展为30秒、60秒等多段连续视频。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
