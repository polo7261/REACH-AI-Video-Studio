# 一、Skill 概述

## 1.1 這個 Skill 解決什麼問題

把使用者意圖轉成可見、相互一致、適合目標用途的畫面描述。專業性體現為選擇有依據、約束清楚、資訊可讀，而不是攝影術語或技術引數的數量。

本技能處理文生圖提示詞寫作、已有提示詞最佳化、參考畫面的文字重建，以及使用者明確要求的診斷與比較。可根據一個片段寫單張圖，但不自動把整份劇本拆成資產庫或完整分鏡。

## 1.2 適用場景

- 根據文字主題編寫攝影、插畫、產品、海報和功能影象的文生圖提示詞。
- 整理或最佳化已有 prompt，檢查畫面關係、視覺選擇和約束。
- 根據參考畫面反推可見效果，區分觀察、推斷和設計補充。
- 開發人物辨識特徵，維護多個角色或系列圖的文字設定。
- 回答與提示詞有關的診斷、比較、原理和修改建議。

## 1.3 不適用場景

不執行生圖，不處理原圖的換裝、合圖、刪物、蒙版、保留清單或多輪影象編輯。不選擇模型或給出 API、解析度、質量檔位等工程設定；使用者問起時，區分工具引數與畫面描述，不把引數語法塞進 prompt。橫豎構圖、畫面比例和主體佔比屬於可描述的視覺約束，可以按需寫入。

# 三、執行流程

## 步驟 1：理解需求與確認邊界

1. 遵守使用者明確要求、提供的事實和已確認的系列設定。參考只承擔使用者指定的作用；風格參考不自動提供人物身份、場景或文字內容。
2. 用途與媒介決定採用哪些表達方法。先識別攝影、繪畫、動畫、三維渲染或平面設計等媒介，再判斷人物設定、產品展示、故事靜幀、海報或資訊圖等用途。
3. 風格與氛圍解釋已知內容如何呈現，不能自行改掉時間、天氣、主體、動作、文字或空間事實。不要機械套用情緒與顏色、景別、布光的對應關係。
4. 普通空缺可作與任務一致的合理設計補充；重要推斷不能冒充已知事實。整理已有設定時避免重設計主體；使用者要求設計人物或畫面時，可以提出具體方案。

把輸入區分為：明確設定、合理推斷、允許的設計補充、待確認的關鍵衝突。這是內部工作方法，不要求每次輸出表格。

遇到“夜晚的陽光”這類組合，先判斷是否是有意的超現實設定或特殊光源，不自動改成月光。若明確要求之間無法相容，且取捨會改變核心目標，簡要說明並澄清；其餘細節按一致的方案推進。只問會顯著改變結果的問題，避免對每個細節逐項提問。

使用者未說明商業用途時，只明確影象型別，不編造品牌定位、受眾或投放場景。使用者要求抽象、夢境或風格化畫面時，遵守其視覺邏輯，不強制改成自然主義攝影。

## 步驟 2：制定畫面方案

先確定這張圖必須傳達什麼，再組織視覺手段：

- **資訊**：必須看見、辨認或有意隱藏的主體、動作、物體、文字和關係。
- **取景與佈局**：用適當範圍容納這些資訊，確定觀察位置、主次、遮擋與留白。
- **清晰與明暗**：決定哪些內容同時可讀、哪些退居背景；再安排景深與光線。
- **風格與顏色**：根據媒介、場景材料、光源、參考和專案方向選擇；不自動低飽和、青橙調色或膠片化。
- **約束檢查**：解決互相沖突的要求，刪除無關修飾，保留全部必要資訊。

按任務讀取第六部分列出的現有參考檔案，不將所有任務統一為攝影或統一風格。

## 步驟 3：編寫、最佳化或重建提示詞

### 八類資訊覆蓋（內部檢查）

以下八類資訊用於內部檢查遺漏，**不再規定另一套成文順序**。成文按下節五項內部順序組織為自然語言，不把內部專案名變成提示詞標題。

類別檢查重點用途與影象型別使用者要得到什麼交付物；用途未知時只確定影象型別主體與行為身份、形狀、比例、姿勢、視線、接觸方式、相對尺度；只寫本次可見且有用的特徵空間、觀察與佈局取景邊界、機位或版式、主體位置、距離、遮擋、必要背景與留白媒介與風格表現媒介、時代語境、色彩方向、使用者要求的視覺特點光線必要的來源、方向、軟硬、明暗分配和光色；可用於顯示或隱藏資訊材質與成像物件表面與畫面呈現分開；顆粒、銳度、焦外或特殊效果按需選擇畫面文字確切原文、位置、樣式、層級、出現次數；沒有需求時省略限制與一致性使用者真正要求保留或排除的內容、系列錨點、不可改變的事實；不附固定負面詞串

八類資訊對映到五項模板：用途、主體與必要環境進入“主體”；空間關係和版式進入“景別與構圖”；光線單列；色彩與必要風格進入“色調”；鏡頭、清晰範圍、材質與呈現方式進入“鏡頭與成像”。明確的表現媒介可在主體開頭交代。準確文字的內容隨所屬主體寫，位置與層級在構圖中寫；適用限制隨對應欄目寫，不另附固定負面詞串。

同一資訊不重複堆寫，不為填項創造文字、背景、光效或排除項。分析時先考慮什麼與最終按何順序輸出是兩件事。

### 五項內部組織與最終輸出

預設中文自然語言；按使用者要求切換英文或中英對照。保留必要的專名、準確文字和常用術語，避免無目的中英混排。

標準版：五項內部模板，無標題自然語言

寫作、改寫或重建 prompt 放在回答最前面，按以下五項的相對順序寫成可直接使用的自然語言。**專案名只是內部組織和自檢依據，預設不輸出“主體：”“景別與構圖：”“光線：”“色調：”“鏡頭與成像：”等標籤、加粗小標題或編號。** 不把寫作指令或自檢記錄放進 prompt。

預設可按資訊量分成 2–4 個無標題自然段，不要求每項獨佔一段，也不把合併段落當作省略內容。使用者明確要求一段時，寫一個連續段落；明確要求標題、欄位或表格時，才採用其指定形式。

內部專案必須檢查的內容**主體**影象型別或明確用途、人物或物體、必要外形與結構、當場動作、表情、視線、接觸方式及必要環境。不要額外編造出行目的或劇情來代替可見行為。**景別與構圖**分別寫清取景範圍、觀察位置與實際畫面佈局。攝影類不能只寫“全身、斜側面”；還需明確主體或主要資訊在畫面中的位置，以及適用的留白、層次、遮擋、尺度或空間關係。其他媒介寫對應的取景或版式關係。**光線**根據用途交代光源或可見明暗特徵、方向及適用的軟硬與明暗分配。不能只寫“陽光”“電影光”。可有意隱藏資訊，不一律補亮。**色調**具體主要顏色關係、飽和程度、對比及必要的冷暖傾向，尊重固定顏色和使用者風格。“日系”“清新”“高階”不能單獨充當色調描述。**鏡頭與成像**攝影類寫與目標一致的視角或必要焦段線索、對焦重點與清晰範圍、成像方向及有用的材質細節；其他媒介寫相應的線條、筆觸、邊緣或呈現質感，不硬填攝影引數。

攝影類五項均需實質覆蓋，不能以一句空泛形容詞充數。相機型號、光圈數值、顆粒等不是必填答案，依任務選擇。非攝影任務真正不適用的光學或照明子項可省略；整項確實不適用時，內部註明原因，成文省略對應內容而保持其餘相對順序，不輸出空欄或“無／不適用”佔位。

構圖不強制三分法、橫構圖、低地平線或前景遮擋；選適合本圖的佈局，並把佈局實際寫出來。獨立圖形可以寫居中、主體佔比和邊距；開放場景可以寫主體位置、行動空間和層次。

攝影類的內容覆蓋

標準攝影 prompt 應分別交代主體、景別與機位、實際構圖佈局、光線、具體色彩關係，以及鏡頭觀察和成像方式；清晰範圍放在“鏡頭與成像”中。不能只靠“日系”“電影感”“清新明快”等概括詞代替，不另附一串相機引數。

色彩根據場景寫清主導與輔助顏色、飽和程度及明暗關係；成像根據任務明確乾淨數字、細膩膠片或其他適合的方向。它們是本圖的設計選擇，不是所有圖片統一使用的答案。顆粒僅在選擇膠片或其他有依據的顆粒表現時寫明細密程度與強弱；相機型號只在使用者指定或確有表達價值時採用。不能為滿足模板強行新增顆粒、漏光、失焦或器材名。

反推攝影畫面時，光線和成像可以用有依據的可見外觀表達；真實光源、器材或媒介無法確認時說明不確定性，不為填欄目偽造數字、光源位置或膠片來源。插畫、平面設計及功能影象使用對應媒介與呈現描述，不填攝影器材和光學引數。

短版、分節與多版本

- **一句話或一段版**：使用者要求“寫一段”“一段即可”“一句話”等時，按五項順序壓入一個連續段落，預設不帶欄目標籤，不再分段。壓縮非必要修飾和術語，不將構圖、色調或成像整體刪掉後保留空泛形容詞；極短字數限制下先保留使用者硬要求和關鍵畫面關係，不編造細節充數。
- **複雜內容與指定格式**：預設仍以無標題自然段按五項順序承載，必要的人物、版式和文字要求融入相應位置。使用者明確指定分節標題、欄位、順序、段落數或表格時優先遵守；五項仍用於內部覆蓋檢查，不擅自新增一套可見標籤。
- **多版本**：每個版本使用相同模板和適用項順序，便於比較；版本名稱放在 prompt 外。保持已確定身份、事實與必要文字，只變化允許探索的視覺內容。未指定數量且確實需要多個方向時，通常給 2–3 個即可。

按任務交付

- **寫作請求**：先交付統一模板中的完整 prompt；必要時在後面簡短說明重要設計補充，不搶在 prompt 前展開分析。
- **反推請求**：重建 prompt 使用同一五項標準版、使用者指定的短版或格式，隨後按需附拆解表；重要的不確定項不能隱藏在確定語氣裡。
- **診斷請求**：先回答問題或指出影響，不為了“提示詞優先”跳過使用者需要的解釋。

具體寫清可見關係，替代空泛標籤。例如“腰部以上，雙手握住車把並完整入鏡，視線投向前方”比“自信而有活力”更可檢查。靜態圖描述一個可見瞬間，不把連續多步動作和相互排斥的姿勢擠在同一身體上。

限制冗餘風格指令，不限制關鍵約束數量。人物身份、雙手入鏡、物體接觸、結構比例與文字可讀可以同時是必要條件。

## 步驟 4：自檢、修訂與交付

對實際準備傳送的內容執行第 4.2 節的完整自檢。發現漏項、空泛描述或衝突，先按原規則修訂；隨後按使用者要求交付提示詞、拆解表或診斷意見，不把內部欄目名和自檢過程寫進 prompt。

# 四、規則與約束

## 4.1 風格規範與成像選擇

真實感可來自可信的光照、材質、人體結構和空間關係。清晰對焦、受控曝光、自然色彩與嚴謹構圖同樣可以真實；也不把這些效果強加給有意模糊或抽象的任務。

區分：物件材質（如織物與金屬）、成像特徵（如景深與顆粒）、特殊效果或缺陷（如拖影、失焦、過曝、漏光、壓縮損傷）。後兩類按用途、使用者要求、參考或具體表達需要選擇，不成套新增。

抓拍不等於失焦，復古不等於漏光，電影靜幀不等於膠片或寬銀幕，街頭攝影不必高反差。攝影、插畫、設定圖與功能影象各自服從任務。

對黃金時刻、溼地反射、眼淚、輪廓光、大光圈虛化等慣性選擇，檢查：是否與已知事實相容、是否服務本圖、是否遮住必要內容。有事實或設計依據就保留；無作用的填充可刪。合理設計不需要偽裝成輸入事實，也不因怕套路而刪除使用者明確要求的元素。

## 4.2 質量檢查點：輸出前的固定格式自檢（必須執行）

生成草稿後，針對**實際準備傳送的最終 prompt**逐項核對，而不是隻確認自己想過這些內容。多版本、批次提示詞和中英對照的各版本分別檢查。

自檢項透過標準常見未透過情況格式與順序五項適用內容按相對順序融入自然語言；預設無欄目標籤或編號，合併段落不漏項；一段版只有一個連續段落，使用者自定格式則遵守其要求把內部專案名寫成提示詞標題；合併後漏掉構圖、光線或色調；要求一段卻分段主體必要身份、行為、物體與場景可理解，符合已給事實用“開心”“孤獨”代替全部行為，或新增無依據劇情景別明確取景範圍或可檢查的身體、物體邊界只有“35mm”，無法確定取景範圍機位明確適用的觀察方向、位置或角度只寫“電影鏡頭”，沒有觀察關係構圖在實際文字中寫出主體或資訊位置，以及適用的留白、層次、遮擋、尺度或空間關係只寫“全身、前方斜側面”，把景別和機位當作構圖；只說“構圖好看”光線有可理解的光源或可見明暗特徵，適用的方向、軟硬與分配明確只有“陽光”“柔美光線”，沒有實際表現色調有具體顏色關係與適用的飽和、對比或冷暖處理只有“清新日系”“高階電影色”鏡頭與成像攝影類的視角或必要鏡頭線索、對焦與清晰關係、成像方向可理解；非攝影為對應媒介的呈現只堆器材名稱，或整項缺失；為了填項自動加顆粒和失焦交叉一致性主體位置與運動方向、取景與細節尺度、虛實與必要文字、光色與固定設定不矛盾人物向右跑卻只在左側留行動空間；門牌必須可讀卻寫全部背景完全虛化適用性與真實性尊重媒介和使用者要求，區分觀察、推斷與設計補充；必要文字與身份設定穩定給標誌硬加攝影引數，或從參考偽造精確器材與未知文字

內部將各項判斷為“透過／需修訂／不適用／不可確認”。不適用必須有題材或使用者要求依據，不能把攝影構圖漏寫解釋成不適用；參考資訊不足時可記錄不可確認，並在需要處如實說明，不能偽造後宣稱透過。

發現漏項、空泛佔位或衝突，先修訂再重新核對受影響項；完成檢查後才交付。原始要求本身存在無法合理消解的關鍵衝突時，簡要說明取捨或澄清，不以虛構細節硬湊透過。使用者明確字數或格式限制優先，檢查的是在該限制下保留關鍵要求，不為湊模板突破限制。

自檢預設在內部完成，不輸出逐項判斷、評分或思考過程，也不在 prompt 裡追加“已透過自檢”。使用者明確要驗收說明時，只提供簡短的結果依據和仍存在的限制。

## 4.3 禁止事項與技術邊界

需要準確呈現的文字使用引號，按需寫位置、字型調性、顏色、層級和次數；照抄原文，不自行翻譯或改字。無法辨認或缺失的關鍵文字不編造。

區分必要的場景文字與額外字幕、水印和無關標識。不要在要求門牌、編號或包裝文字後，再寫“禁止所有文字、數字”。使用者要無文字影象時，才寫對應限制。

將“不要廉價”“不要 AI 味”等模糊意見儘量轉成具體畫面目標；需要排除的物件可以明確說明。否定表達的效果依賴模型與上下文，不宣稱必然有效或必然適得其反。優先少量、相關且無衝突的約束。

品牌和器材名稱按任務處理：不自動往畫面中加入無關商標；使用者指定的產品或準確文字應保留。攝影器材、膠片型號若作為外觀線索，需確有幫助，不作為必填或真實拍攝證明。不要以本地寫作習慣強制排除使用者需要的名稱。

相機、焦段與光圈描述只是外觀線索，不承諾精確光學模擬。數字不能取代對取景、透視關係與清晰範圍的描述；避免無意義的“8K、傑作、最高質量”堆砌。

# 五、示例

示例只展示現有功能與輸出形式，其中的服裝、佈局、配色及成像不是所有圖片的固定答案。

## 示例 1：正向寫作與一段輸出

輸入：寫一段女生在草原奔跑的圖片提示詞，開心、陽光。

輸出：一張戶外人像照片，女生穿白色上衣、藏藍色半裙和運動鞋，在草原上向畫面右側輕快奔跑，笑著望向前方。全身取景，從前方斜側面觀察，人物位於畫面左側，右邊留出奔跑空間，遠處草坡與天空形成開闊背景。柔和日光從左前上方照亮臉頰和衣服，背光側保留淺淡陰影。以草地綠、天空藍及衣服的白與藏藍構成配色，飽和度適中、明暗對比柔和。自然透視，對焦人物，遠處草坡逐漸柔化，採用細膩清晰的數字攝影成像。

## 示例 2：反推中的未知資訊

輸入：反推參考圖，並告訴我真實相機型號和門上模糊小標籤的文字。

處理方式：按圖中可見的主體、佈局、明暗、顏色與成像外觀重建提示詞；清晰文字準確引用。真實相機無法確認時說明無法確認，小標籤無法可靠辨認時不猜寫；必要的不確定性放在提示詞外簡短說明。是否附拆解表遵守使用者本次要求。

# 六、附錄

## 6.1 現有參考檔案

攝影、電影靜幀、空間場景，或使用者要求具體討論景別、景深、構圖、色調、布光時，閱讀 視覺選擇依據，使用與本次任務有關的部分。平面設計和插畫不為湊專案而新增攝影引數。

人物設計、多個角色或系列圖，閱讀 人物與系列設定。只有反推或拆解任務才閱讀 逆向解析。文字密集、產品、海報、資訊圖、UI、標誌或歷史題材任務，閱讀 專用影象寫法。不要每次載入全部參考。
