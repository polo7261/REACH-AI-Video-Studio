# A24電影美學

> 🔴 嚴格按本 SKILL 分步執行。版本 2.5.1 lean（Seedance 2.5 適配）

## 底層 DNA（每條畫面無條件帶）

1. 🔴 **真實膠片質感為絕對底**：真人實拍級、16mm/35mm 顆粒、皮膚有毛孔與自然油光。禁 CGI/動漫/3D/塑膠皮膚/過度磨皮/數碼硬銳。🔴 解析度越高越不等於乾淨——720p/1080p 下同樣須保留可見顆粒、halation、低對比曲線。
2. 🔴 **情緒優先於情節**，畫面服務內在情感、不做資訊交代。整體節奏快而緊繃、有壓迫感，不給喘息；但緊張來自情緒壓迫，非剪輯花活。
3. **親密 + 不安並存**：美麗與不適同框，淺景深貼近、面部凝視、日常中的詭異。
4. **構圖剋制，留白即繃緊**：負空間與靜默是蓄能（暴風雨前的靜），非鬆弛；對稱幾何但不炫技。
5. **光源動機化**：自然光/實用光源（窗/燈/燭/霓虹/熒光），只見光效不見燈具。
6. **介質必須動**：霧/塵/雨/雪/光塵寫明方向+速度，衣物頭髮同步受風。
7. 🔴 **氣質底 + 參考庫**：參考只取方向錨（光色/質感/辨識點），產出始終原創、絕不逐鏡復刻。
8. **配色隨情緒定**，允許大膽飽和或冷靜自然；唯一負面鎖：避開預設黃褪色廉價感。
9. 只做 A24 作者性膠片一脈，不做商業快切炫技、純型別片視覺。

## 質感尾詞（每條影象 prompt 預設帶）

`16mm 或 35mm 膠片拍攝，天然膠片顆粒，低對比膠片曲線，真實皮膚呈現（真實毛孔與紋理），柔和光暈（halation），真實粗糲質感，情緒化電影級色彩，親密淺景深，動機化自然光/實用光源，無過度銳化，無 CG 渲染感；非動漫、非 CGI、非 3D 渲染、非塑膠皮膚、非過度磨皮、非數碼高畫質硬銳，無預設黃褪色調，無高解析度數碼乾淨感（保留顆粒與噪點結構），畫面內無影棚燈具，無黑邊遮幅（畫面鋪滿整幀出血）`

## 語言規則（🔴 全域性，優先於本檔案其餘語言表述）

- **會話語種鎖**：入口第一動作，按使用者首次文字輸入的語種判定一次（無文字取 skill 名語種），寫入 memory 全程鎖定；中途不重判（點選卡片、短詞、他語種素材均不改變），僅使用者明確要求時更換。
- 🔴 **唯一來源 = 會話語種，覆蓋全部可見輸出**：以下一律按會話語種書寫——① agent 的每一句對話回覆、進度說明、確認與報錯 ② 選擇卡的問題/選項/說明 ③ 故事梗概、scene list、劇本正文、分鏡說明、資產與場景說明 ④ 全部 prompt（影象/影片/音樂，含每條重試）。本檔案文案僅是內容規範，一律譯寫、**禁照抄原文語種**。
- 🔴 **唯一例外（保留原文的白名單）**：① 引號內臺詞/旁白引文（用⑧語種）② 技術識別符號（model 串、duration、asset_id、MAXDUR、@圖1/@音訊1 等引數與引用名）③ 攝影與製作術語（halation、dolly、push-in、compose、moodboard、underscore 等）④ 參考片原名。負面詞沿用本檔案給定串（預設即會話語種，禁改為第三語種）。白名單之外一律會話語種。
- 🔴 **與對白語種雙向隔離**：⑧只決定**片內口語**。使用者選英文對白 ≠ 全域性轉英文——**只有引號內臺詞/旁白是英文**，對話回覆、卡片、prompt 全部描述文字、故事與劇本正文一律仍是會話語種。例：首輸中文 + 對白英文 → 全程中文、僅臺詞引文英文；首輸韓文 + 對白日文同理。影象 prompt 無臺詞、全文會話語種。
- **禁例外禁繼承**："模型更懂英文"不採納；下游只繼承上游的風格與內容、絕不繼承書寫語種；發現語種不符先譯寫再使用，禁下傳。
- 🔴 **複用與自查**：每條 prompt 綁 asset_id 存 memory；失敗重試與重生成一律讀回原 prompt 在其基礎上微調，禁重寫禁改語種。**每次輸出前（含對話回覆）兩問**：書寫語種 == 會話語種？臺詞引文 == ⑧語種？不符則改寫後再輸出。

## 時長檔 MAXDUR（🔴 優先於本檔案所有時長數字）

1. **來源 = 入口⓪的使用者選擇**：Seedance 2.5 → MAXDUR=30；Seedance 2.0 → MAXDUR=15。寫入 memory 全程沿用，不自行改動。🔴 **發第一條任務時核對**：所選模型是否真在工具列表中、duration 是否真接受該值（被回落則走"模型閘門"停下問使用者，不靜默降級）。
2. 🔴 **時間軸末段結束時間 == 本條提交的 duration**：既不許留"…"，也不許超出 MAXDUR（超出會被壓縮或截斷，是"時長上不去"的主因）。
3. **按檔取值**（本檔案其餘處的 30s / 5–8 鏡 / t30s 均為 MAXDUR=30 的示例）：

MAXDUR 單條分鏡數 寫到 成片換算 跨段接法 30s 5–8（下限 ≥3） t30s 30–60s≈2 條 / 1–2 分≈2–4 條 拆條 + compose 15s 3–4（下限 ≥2） t15s 條數加倍 拆條 + compose ≤10s 2–3 該時長 按比例上推 拆條+compose

MAXDUR 變化時回第 2 步重切段落，不把 30s 的段硬塞進 15s 任務。其餘規則（四軌、切分動因、參考紀律、語言、聲音）不變。

## 流程

 1. **入口**：🔴 先鎖會話語種。🔴 **一輪合併問完以下 9 項**（每項獨立呈現、帶可選項，問題與選項均譯寫為會話語種），答案入 memory。 ⓪ 🔴 **影片模型（必問，排在最前，決定下游全部時長編排）**：**Seedance 2.5**（預設，單條 30s）/ **Seedance 2.0**（單條 15s）。答案即 `MAXDUR`（2.5→30、2.0→15）寫入 memory，第 2 步分段、第 5 步時間軸、分鏡數與跨段接法全部按此檔走，中途不得混用。 ① **時長**（只呈現成片時長、不露分鏡數）：30–60 秒 / 1–2 分 / 2–3 分 / 其他。內部按 MAXDUR 表換算條數。 ② **執行模式**：全自動 / 手動確認。 ③ **畫幅**：21:9（預設）/ 16:9 / 9:16 / 3:4 / 其他。 ④ **解析度**（與畫幅分開問）：480p / **720p（預設）** / 1080p；影象 2K。僅此三檔，不提供 4K。 ⑤ **故事梗概**：使用者自帶 / 自動生成。 ⑥ **風格方向**：🔴 從參考庫**兩兩隨機融合**出 3–4 個方案作選項（每次純隨機、附一句融合氣質說明），🔴 只寫"片名 × 片名"、不露 REF 編號，**禁把單一片名直接列為選項**；末位留"我有自己的想法或指定參考"。僅當使用者明確只要一種時走單一風格。 ⑦ **人聲模式**（必問）：①純氛圍 ②純對話（預設）③純旁白 ④對話+旁白穿插。 ⑧ **對白語言**：英文（預設）/ 韓文 / 日文 / 其他 / 無語言。（2.5 支援十餘種語言口型對齊。）
 2. **故事**（先於 moodboard、必須定稿）：情緒優先、張力遞進、開放結尾。輸出 scene list + emotional arc + 🔴 **動作線**（每場肢體動作起→中→止，動作必掛動機）+ 🎭 **角色表演基調**（標誌性小動作/身體習慣/情緒臨界反應，全片跨鏡一致），遵循⑦人聲模式。🔴 故事來自使用者方向、**不照搬參考片劇情**。🔴 **定稿閘門**：彈卡①確認透過 ②需要修改（附輸入項，改後再彈，迴圈至透過），未透過不得下行。🔴 **按 MAXDUR 分段**：切成每段 ≤MAXDUR 的連續段，逐段標註**同場景延續**（compose 時無縫相接）或**跨場景硬切**（轉場處硬切）。風格：清晰有目的、場與場壓茬推進，緊張掛在情緒與動機上。
 3. **moodboard**：風格已在⑥定，不再詢問。故事透過後生成（融合方案以一種為主色調錨、另一種作氣質疊加；單一畫面鋪滿出血，禁白邊/拼貼/分格）→ 🔴 **不確認、直接存為風格錨**入 memory。
 4. **資產（影象）**：🔴 全部影象 prompt 用會話語種。🔴 **時序**：moodboard 與人物圖可並行；**場景圖必須等 moodboard 完成後才開始**（要掛它作風格錨）。
    - **角色**：有戲角色必產錨定圖（鎖臉/服裝/髮型），後續 @角色名 引用。
    - **場景**：🔴 **一個空間只出一張圖**、該空間所有戲共用（換地點才新增），不按場次數生成。🔴 **動作依賴要素必須畫進去——尤其是門**：劇本用到門/窗/樓梯/鏡子/走廊口時該圖必須明確出現且位置可用；生成前先提取"動作依賴要素清單"寫進 prompt，生成後逐項核對，缺失重生成。🔴 **一律純空鏡、絕無任何生物**：嚴禁任何人物、人形、機器人、AI、類人形象、動物（背景遠景、群演、櫥窗模型也不行），一切生命/類生命體只走人物圖、靠 @角色名 合成。🎨 **強制掛 moodboard 風格錨——只參考風格（色調/光感/質感/氣質），不參考構圖/內容/佈局，也不繼承其書寫語種**；可按 REF 偏移主色。🔴 禁黑邊遮幅，直接用目標比例出圖鋪滿整幀。
    - **道具**按需生成、asset_id 繫結。🔊 **聲線錨（可選）**：使用者提供角色聲線音訊則登記綁角色，第 5 步作 @音訊N 鎖跨條聲音；未提供則靠性別鎖+角色描述定聲。
 5. **生成影片（按入口⓪選定的模型）**：🔴 時間軸嚴格按 ⓪ 對應的 MAXDUR 寫——2.5 走 30s / 5–8 分鏡，2.0 走 15s / 3–4 分鏡，不混用。🔴 **單條內嵌多個連續分鏡**（MAXDUR=30 時 5–8 個），嚴禁一鏡一條；末段結束 == 提交的 duration。🔴 **跨 MAXDUR 一律另起獨立條**、交第 8 步 compose 拼接；🔴 **禁用延長續寫**——絕不把前一段影片墊作續寫源，本 skill 不呼叫該功能。跨條一致性只靠場景圖/角色圖/聲線錨維持：逐條核對臉/服裝/光位/色調/聲線/介質方向，漂移則用同組參考重生成。🔴 **參考素材只能是場景圖 + 角色圖（+ 道具圖、可選聲線音訊），嚴禁把 moodboard 掛進影片任務**——它是影象層給場景圖用的風格錨，影片階段一律不掛；掛了會讓模型復現它畫面裡的元素、汙染構圖與內容。風格已由場景圖承載。🔴 **絕不含 BGM**：只出環境音+人聲，配樂留第 9 步；@音訊 參考禁傳音樂類。
 6. **不達標處理（只有整條重生成）**：🔴 **本 skill 不呼叫 2.5 的任何編輯與續寫功能**——無 timestamp 修鏡、無運鏡編輯、無區域性重塑、無延長續寫。某條不合格 → 讀回原 prompt **在其基礎上微調後整條重跑**（禁從頭重寫、禁改語種）；超出 MAXDUR 的內容一律另起獨立條。🔴 **運鏡、速度變化、慢動作全部只能靠改 prompt 重跑**（後期也沒有變速/超分）。🔴 **重跑閘門**：同一條重跑 ≥3 次仍不達標 → 回上游查病根（場景圖缺要素？動作線不可拍？參考衝突？角色圖不清？），修上游再重發，禁無腦刷條。
 7. **音樂**（Mureka V8）：🔴 prompt 用會話語種。🔴 **方向不問使用者**，按劇本節奏與風格自動匹配（緊張→低音心跳/合成器脈衝/漸強織體持續 underscore；慢暗湧→極簡氛圍織體）；靜默只作驟停對比。禁流行編曲/管絃爆炸/廉價驚悚音效。BGM 可先生成、預設不合成。🔴 絕不作為 @音訊 參考回灌影片。
 8. **成片合成**（media-platform）：compose 串接全部獨立條——同場景延續段無縫相接、跨場景處硬切；接入環境音，**不含 BGM**，產出純淨成片（含人聲）。
 9. **後期增補**：🔴 彈選擇卡（可多選，非文字提問）：①加字幕 ②加 BGM ③都要 ④都不要。選了含字幕的項後**追加字幕語種卡**：Ⓐ跟隨對白語種（單語，預設）Ⓑ指定其他語種 Ⓒ雙語（上軌指定、下軌對白）。🔴 **混音**：原聲（環境音+對白）+8dB、BGM −2dB。🔴 **順序不可顛倒：先字幕、最後合 BGM**（含 BGM 成片上生成字幕會出錯）。🔴 旁白已在影片階段燒錄，此處不再詢問或追加。
10. **後期鏈限制**：可用字幕/轉場（預設硬切）/抽幀/裁剪/文字貼片/混音；**無變速、無降噪、無超分**——所有鏡頭運動須在 prompt 內完成，要改走第 6 步。人聲隨影片燒錄、非後期配。剪輯氣質：快而緊、壓茬推進、不洩壓。

## 影片鐵律

- 🔴 **分鏡切分 = 內容事件驅動**：出現 ①動作節拍變化 ②情緒轉折點 ③需變景別或視角 ④注意力焦點轉移 之一即切新分鏡。跟著內容走，不為湊數硬切、不為省事不切；數量與時長是**結果**（MAXDUR=30 時 5–8 鏡、每鏡 2–5 秒），緊張偏多鏡、慢暗湧偏長鏡。🔴 下限見 MAXDUR 表；真正一鏡到底須在 prompt 明寫"單鏡不切"並說明理由。時間軸用全片連續絕對時間、每段標註切分動因。
- 🔴 **四軌強制**，時間軸每段必寫：
  1. **主體動作**：從故事 Action 繼承（不臨時編）=動作+動機+過程分解（"停下轉身"→腳步漸停/肩膀先轉頭跟上/目光定住）。
  2. 🔴 **情緒外化**：面部(眉眼/嘴角/呼吸)+微表情停頓(遲疑/目光飄移後歸位)+肢體(肩頸鬆緊/手指小動作/重心偏移)。🎭 用角色表演基調的標誌性小動作。⚠️ 具體到可演（非"表情緊張"而是"喉結滾動、指節抵桌沿泛白"），要有層次轉折（遞進/剋制/決堤），停頓是繃緊非鬆弛。💡 2.5 表演收斂、微表情可讀——寫細微層次，不用瞪眼皺眉張嘴去"保證看得出來"。
  3. **鏡頭運動**：運鏡庫選 1 個，寫型別+速度+方向。
  4. **介質/環境動態**：風/光塵/雨持續運動。
- **人物實體性**：全程實體清晰，不溶解/半透明/消失/被光或環境吞沒。
- 🔴 **風格來源 = 場景圖（及道具、角色圖），禁掛 moodboard**：場景圖已在影象層吃過 moodboard，影片忠實參考場景圖即繼承其風格；跨鏡共用同組參考、氣質不漂移。發任務前逐條核對參考清單裡沒有 moodboard。
- 🔴 **參考紀律**：硬上限 30 圖/10 音訊（🔴 影片參考不用），**實用 3–8 條**（場景圖 1 + 出場角色分屏圖 + 關鍵道具 +（可選）聲線音訊）。每條必須寫明用途，不寫用途的不掛。🔴 **一律不掛 @影片 參考**（既不作續寫源、也不作運鏡參考），影片階段只吃圖與可選聲線音訊。
- 🔴 **絕無 BGM**：只出環境音+對白（+旁白），禁配樂/音效墊樂、禁音樂類 @音訊 參考；負面詞須含"背景音樂、配樂"。
- 🎙️ **雙人聲軌（③/④）**：對白=帶口型軌，旁白=畫外不帶口型軌；④在時間軸給兩軌各自分配時間段（旁白填對白空隙、不同時出聲），同一條 prompt 一次寫清；跨條聲線須保持一致。
- 🔴 **語言鎖**：每條 prompt 常駐"對白/旁白一律用選定語言，模型補話也只用此語言，禁其他語種臺詞/字幕/口型"。⚠️ 只鎖片內口語，不改 prompt 本身的書寫語種。
- 🔴 **別攤平**：時長翻倍是分鏡數上抬、非每鏡變長；檢查有無"為填滿時長而拉長的空轉段"。同一動作跨鏡須狀態離散變化、節拍間不留空轉。

## 劇本

- 🔴 **預設節奏 = 緊張壓迫遞進**：首場即帶懸而未決的張力，逐場升級不洩壓；場與場壓茬推進、資訊剋制；結尾開放不給解答。張力來自"處境不對勁/關係在崩/某事將至"的暗湧，非情節反轉或懸疑解謎。
- 🎬 **可選慢暗湧**（伊尼舍林/Aftersun/伯德小姐一路）：長呼吸、留白、日常細節堆疊，張力在平靜下滲出；"快而緊"讓位，仍守情緒優先+開放結尾+拒絕說教。🎥 此正規化優先用 MAXDUR 長鏡做"一鏡到底凝視"（緩推/緩移/微環繞不切）。
- ⚠️ **一片一節奏**：開頭即定"緊張壓迫"或"慢暗湧"，全片統一（可有區域性驟停/爆發對比，主基調唯一）。
- 節奏與 emotional arc 對齊並傳導到切分與運鏡；隻影響事件密度，不改"按內容事件切"。
- 💬 **對白（②/④）**：🔴 兩人以上同場或有交流動機處必寫實際臺詞，別把人物寫成啞巴；對白量按場景定，每句標說話人。🎭 生活化、口語、簡短；🔴 **留潛臺詞**（答非所問、說半句、用瑣事包裹心事）；**反金句**：不寫總結主題或解釋情緒的臺詞（"我很難過"禁用），改用具體的話或沉默帶出。
- 🎙️ **旁白（③/④）**：剋制私密如寫給自己，非全知解說、不復述畫面。🔴 文字在劇本階段寫定、隨影片燒錄，不留後期。
- 🔴 **段落寫作**：一條任務承載"一個完整情緒小起落"（鋪墊→推進→轉折→未解的收束），非把短鏡硬拉長；臺詞密度按實際時長配，停頓與靜默同樣佔時長。
