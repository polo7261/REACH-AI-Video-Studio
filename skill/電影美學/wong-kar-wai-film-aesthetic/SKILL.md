- **场景图 = 按「地点」出大全景,一个地点一张**:每张必须是该地点的**大场景/整体全景**(如"房间"就出整间房的全景、"地铁"就出地铁车厢内部全景);**绝不为特写 / 局部 / 机位变化单独出场景图**(如窗前特写、桌面局部、某个角落),这些交给 Seedance 在同一张全景基础上取景。
- **同一地点只出一张场景图,跨镜/跨段复用**:哪怕多段视频、多镜都发生在同一地点(同一个房间 / 同一节地铁),**只需要这一个地点的一张全景图**,不再重复出。
- **场景图张数 = 剧本里不同「地点」的数量**(去重后),不是镜数、也不是段数。\
  **全部场景图一次性出齐 → 一次性暂停,让用户为每个地点各四选一 → 收齐所有地点的选择后才进阶段 4**,**严禁未经四选一就进阶段 4**。
- **四选一呈现格式(强制)**:MJ 出的 4 张是 2×2 网格,给用户列选项时必须标明**序号 + 对应位置**——**1(左上)、2(右上)、3(左下)、4(右下)**,例如按"1(左上)/ 2(右上)/ 3(左下)/ 4(右下)"逐张说明,用户按位置报选择。

> 🛑 强制门:所有场景图出齐后一次性停下,等用户逐地点四选一;没收齐全部地点的选择前不得进下一阶段。

### 阶段 4 · 分镜表格(生视频前必出、需确认)—— 重头戏

**一次性出全部分镜表格**(按段数:15/30/45/60s = 1/2/3/4 张,全部一起出,不要一段一停),每段一张表、一行 = 一个镜头,列如下:

镜号时长画面(调度/表演/构图)内心独白 + 对白(原文 + 语气)运动转场(与上镜)1\~Xs角色调度 + 表演 + 场景 + 框中框/失衡构图要点 + 前景遮挡元素 + 焦点游移落点独白者/说话人 + 台词原文(剧本语言)+ 投递语气(按剧本情绪,默认迷离/惆怅,不机械朗读)抽帧拖影 / 慢快门拖影 / 手持呼吸 / 长焦压缩 / 焦点游移 / 框中框定镜 / 镜面反射 / 加速光流车流拖影 / 失衡定镜留白抽帧拖影 smear / 跳切 / 硬切(**禁叠化**)2………………

表格下方另附**该段的连戏 bible 字段**(不进表、单列):角色身份-服装-手持道具 / 银幕方向-180°轴线-角色 L-R 站位-布景地理 / 同一场景种子-主色-钨丝霓虹光向-时辰 / 当前节拍-情绪延续 /(多段时)每段尾帧→下一段头帧的动作衔接。

每段 **每 15s 镜数见下表(每 15s ≥ 4 镜,硬底线)**,标好拖影/跳切/硬切位置。

**记录口语原文**:把每镜的内心独白 + 稀疏对白的**原文(剧本语言)逐句记进分镜**,供阶段 6"合成前一步"的 `add_subtitle` 做字幕(语种已在阶段 0 确认;生成阶段不出任何字幕,见红线 ③)。**若口语是粤语**:除粤语原文外,**另记一份普通话书面语的中文译文(简/繁按阶段 0 所选)**,字幕用这份译文而非粤语逐字转写。

> **暂停确认(一次性)**:全部分镜表格出齐后停下,连同造型图 + 三视图 + 场景图一起、**一次性**待用户确认。\
****⚠️ 分镜表格与视频的节奏不同**:分镜表格**一次性全出、只停一次确认**;而**视频(阶段 5)相反——逐段生成,生一段停一段、确认一段再生下一段**(见阶段 4b / 阶段 5)。

### 阶段 4b · 多段尾帧续接(30/45/60s 的关键机制,逐条生)

**逐条链式续接**:每生完一条(seg_n)→ **先停下等用户确认**;收到确认后 → 用 ffmpeg 抽该条**尾帧** → **解析尾帧**(角色站位/表情/光线/景别/进行中的动作)→ 按分镜声明的接缝模式生下一条(seg_n+1);如此 seg1→seg2→…→segN 逐条推进(30s 到 seg2、45s 到 seg3、60s 到 seg4)。每条的接缝:

- **(A) 连续动作**:上一条尾帧作 Seedance **起始帧**,下一条续上动作,无缝。
- **(B) 干净换场到新机位**:尾帧仅作连戏参考(角色/服装/色板/光线),下一条全新失衡框中框设置;装配处以抽帧拖影 / 跳切 / 硬切相接。

> 大的换场尽量放在段间接缝处(单条 15s 内部做差异巨大的转场对模型偏难);**接缝也不叠化,一律用硬切 / 跳切 / 抽帧拖影**。

### 阶段 5 · Seedance 视频(每段一条 15s,一条一条生)

prompt 结构(顺序):

1. **前置风格句**(全片统一,见上)。
2. **场景图 + 角色组装**:先喂**该段分镜牵涉到的所有地点的场景图**(跨多个地点就喂多张、只在一个地点就一张;同一地点的不同镜/机位共用同一张全景);再喂每个角色**其同一张三视图**(**人像 + 服装造型都参考它**,既锁脸又锁造型/身形);**不再引用四选一造型选择图**;有原脸时原脸图/视频**另作身份锚点**(三视脸已用白色圆贴纸遮住),Case 3 用三视本身的脸;多角色喂多个角色各自的三视图。写明“每个角色的脸与造型都取自其三视图,放进对应地点的场景图,保留真实长相”。
3. **分镜**:`镜1 …(抽帧拖影切至/跳切至/硬切至)… 镜2 …`,一条连续 15s、镜数达标;**转场以抽帧拖影 / 跳切 / 硬切为主,禁用叠化 dissolve**。每镜 = 景别(框中框/失衡机位)+ 运动 + 表演(**按剧本情绪赋予**)。
4. **口语层**:逐句**内心独白(VO,第一人称,无对应嘴部)为主** + 稀疏对白(标说话人、**口型同步**)+ 投递语气;**指令用中文、独白与对白的台词内容填剧本原文(可中可英),画面不出任何字幕**。例(指令中文、台词填原文):`第一人称内心独白画外音;人物开口说出台词并精准对口型;独白内容:「<剧本原文独白>」;对白内容:「<剧本原文对白>」`。
5. **运动**:`抽帧拖影慢动作并带残影拖尾,慢快门长曝光运动模糊与光痕拖尾,手持相机自然轻微晃动与呼吸感、镜头细微漂移非绝对锁定,长焦压缩,浅景深焦点游移,透过前景遮挡拍摄,失衡偏置构图,同一主体的镜中倒影,背景有飞速流动的灯光/车流光痕,偶尔近乎定镜的惆怅空镜(仍带手持微晃)`;**尽量避免完全锁死机位的大景别呆板静止镜头**;一镜到底仅按需。
6. **音频 + 文字规则**:**独白/对白 + 环境音效随视频生,一切音乐禁生(BGM 到合成前那步铺)**:`内心独白与对白在视频内发声,允许贴合画面的环境音效,无背景音乐、无任何音乐、无配乐、无歌曲、无乐器声(BGM 后期加)`;**画面零文字(含字幕),字幕在合成前那步加(红线 3)**;**出场人数严格等于剧本人物数、不加人潮、不分身(红线 5)**;负面 `背景音乐, BGM, 配乐, 音乐, 歌曲, 唱歌, 哼唱, 乐器声, 旋律, 香烟, 吸烟, 抽烟, 烟雾缭绕, 打火机, 字幕, 字幕条, 画面文字, 招牌文字, 标志, 水印, 额外人物, 背景群演, 人群, 多余的人, 分身, 克隆人, 双胞胎, 同一个人重复出现, 卡通, 插画, 微缩模型, 平面对称构图, 粉彩, 明亮均匀平光, 多余手指, 畸形的手`。

**表演赋予(按剧本,迷离/惆怅基线)**:逐镜≥1 表情 + 1 动作,情绪强度按场景走(longing/躁动不安/温柔/失落/克制皆可),包进王氏氛围外壳(框中框、失衡、长焦浅景、拖影)。\
**通用治僵硬(每镜都加)**:`手持相机自然轻微晃动与呼吸感、镜头细微漂移非绝对锁定,轻微呼吸使胸口自然起伏,细微的头部移动,自然眨眼,表情随场景情绪缓慢变化,放松自然的体态,动作有自然的起伏缓入缓出,衣料、发丝或环境雾气轻微飘动`。

> **分段生成 + 强制确认门**:一段一段生;**每段视频生完后必须停下、等用户确认,收到确认后才生下一段**(30/45/60s 的后续每段都同理),严禁未经确认就接着生下一段。

### 阶段 5(实现备注) · 内心独白兜底

内心独白默认随视频生(VO 层);王氏 VO 是核心,若模型对“无对应嘴部的 VO 独白”支持不稳,**退回装配 VO**(TTS/录音叠加),其余规则不变——务必保住独白这条命脉。

### 阶段 6 · 装配

1. **顺接**:各段 15s(1/2/3/4 条)**以抽帧拖影 smear / 跳切 / 硬切拼到一条时间线(不叠化)**;生成片段已含独白/对白/环境音效(**无 BGM、无任何音乐**)。
2. **合成前一步(加字幕 + 王家卫风 BGM,在最终合成之前完成)**:
   - **加字幕(**`add_subtitle`**)**:**按阶段 0 问询卡已确认的字幕语种(简体/繁体/英文/双语/不要)直接加,不再重复问**;把台词原文/译文做成**可编辑字幕轨叠加**到画面(不烧进生成帧);台词文案取自阶段 1/4 已记录的口语原文。字幕**只在此步加**,Seedance 生视频阶段绝不出现(红线 3)。
     - **粤语特例**:若口语选的是**粤语**,字幕不做粤语口语逐字转写,而是**翻译成普通话书面语的中文**,按阶段 0 已选的**简体 / 繁体**出对应版本。
   - **铺王家卫风 BGM**:按剧本情绪选**一段王家卫式氛围配乐**——慵懒、怀旧、缓慢惆怅,弦乐 / 爵士 / 拉丁或华尔兹式的迷离氛围;**只描述风格、不指定具体版权曲目或艺人**;垫在旁白与音效之下,音量让人声清晰。环境音效已随视频生成,如缺可在此补 SFX。
   - **叠图**:王氏式日期 / 时间戳 / 片名 / chapter / credits / logo PNG 可叠(绝不烧进生成画面)。
3. **合成 + 导出**:把字幕、BGM、音效、叠图与画面**压平合成**为成片,引导导出。
