### 階段 5 · Seedance 影片(每段一條 15s,一條一條生)

prompt 結構(順序):

2. **場景圖 + 角色組裝**:先喂**該段分鏡牽涉到的所有地點的場景圖**(跨多個地點就喂多張、只在一個地點就一張;同一地點的不同鏡/機位共用同一張全景);再喂每個角色**其同一張三檢視**(**人像 + 服裝造型都參考它**,既鎖臉又鎖造型/身形);**不再引用四選一造型選擇圖**;有原臉時原臉圖/影片**另作身份錨點**(三視臉已用白色圓貼紙遮住),Case 3 用三視本身的臉;多角色喂多個角色各自的三檢視。寫明“每個角色的臉與造型都取自其三檢視,放進對應地點的場景圖,保留真實長相”。

1. **順接**:各段 15s(1/2/3/4 條)**以抽幀拖影 smear / 跳切 / 硬切拼到一條時間線(不疊化)**;生成片段已含獨白/對白/環境音效(**無 BGM、無任何音樂**)。

     - **粵語特例**:若口語選的是**粵語**,字幕不做粵語口語逐字轉寫,而是**翻譯成普通話書面語的中文**,按階段 0 已選的**簡體 / 繁體**出對應版本。
   - **鋪王家衛風 BGM**:按劇本情緒選**一段王家衛式氛圍配樂**——慵懶、懷舊、緩慢惆悵,絃樂 / 爵士 / 拉丁或華爾茲式的迷離氛圍;**只描述風格、不指定具體版權曲目或藝人**;墊在旁白與音效之下,音量讓人聲清晰。環境音效已隨影片生成,如缺可在此補 SFX。
   - **疊圖**:王氏式日期 / 時間戳 / 片名 / chapter / credits / logo PNG 可疊(絕不燒進生成畫面)。
3. **合成 + 匯出**:把字幕、BGM、音效、疊圖與畫面**壓平合成**為成片,引導匯出。
