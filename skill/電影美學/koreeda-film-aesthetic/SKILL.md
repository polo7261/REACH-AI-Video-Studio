# 是枝裕和电影美学

>
> 底层 DNA（无条件，每条画面都带）

1. 🔴 **自然漫射生活光为主光（是枝签名，最重要）**：光是"这个空间本来就有的光"——窗户透进的天光、屋檐下的散射、纸窗/纱帘过滤的柔光、室内一盏灯的暖。光源自然、方向可辨但不戏剧化，**绝不追求逆光开花/过曝签名感**。人脸被均匀柔和地照亮、五官清晰可读，暗部保留细节与空气。**平实而非高调**：既不刻意提亮往亮里推、也不压暗低调，还原眼睛看到日常空间时的真实明度。
2. 🔴 **平实通透 + 呼吸感空气**：画面整体平实、干净、通透，有生活空间的纵深与空气感，但**没有柔光滤镜、没有 halation 开花、没有光雾朦胧**。清澈但不冷硬，柔和但不糊。杜绝一切数字硬锐高清纪实的塑料感，也杜绝一切梦幻柔化的糖水感——要的是"清醒的、可信的日常"。
3. **65mm 胶片干净质感（务必干净，不脏不旧）**：细腻高解析的胶片密度感 + 极干净通透的层次，色彩自然真实、有胶片的温润与厚度但**绝不粗颗粒、不脏、不做旧、不复古怀旧滤镜**。65mm 的精髓是"胶片的温度 + 极高的干净度与细节保留"——颗粒极细几乎不可见、暗部干净、层次丰富。去掉的是数码的火气与廉价感，不是清晰度。
4. **暖调可用铁律（与岩井相反）**：**不禁暖色**。是枝的日常里本就有大量暖——木质地板与家具、榻榻米的草黄、饭菜的热气与油光、傍晚的暖灯、夏日的皮肤。暖色是生活的体温，自然出现即保留，不做冷调纠偏。但**暖而不腻不夸张**：是"生活里真实的暖"而非"调色调出的橙黄膜"，整体仍以自然中性为底、暖色作为空间与情感的呼吸点。
5. **中等对比 + 层次丰富**：对比自然真实，明部暗部都有细节与层次，暗部干净不闷、不死黑也不刻意提亮，还原真实空间的光影分布。
6. **中等景深、空间可读**：不做极浅焦柔化。背景保留可辨的生活环境（房间、街巷、庭院），景深服务于"人在空间里"的关系,而非把背景全糊成光斑。人物与其所处的生活空间同等重要。
7. 🔴 **情绪内核：日常肌理包裹克制情感（是枝灵魂，务必拉住）**：这是是枝最核心的气质——镜头是一个温柔的旁观者，安静地凝视普通人的吃饭、走路、对话、沉默。情感**藏在日常动作与留白里**，从不外放、从不煽情、从不给特写强调。底下流动的是家庭的羁绊、生与死、缺席与陪伴、时间的流逝与无法言说的遗憾。⚠️ 绝不能做成煽情催泪、也绝不能做成冷漠疏离的纪实——差别全在这层"克制的温柔凝视"：镜头爱着这些人，但保持恰当的距离，让观众自己看见、自己感受。
8. **让日常自然流动**：饭菜的热气、晾晒的衣物在风里、孩子跑过走廊、蝉鸣与远处的声音。时间在以生活本身的节奏流逝，不催促、不停顿。
9. **范围**：只做日常写实一支，不做类型化戏剧冲突/强情节奇观。

## 质感尾词（每条图像 prompt 默认带）

## 流程

> 🔴 **全局询问规范（所有确认环节强制）**：本 SKILL 中每一次需要用户确认或选择的环节，一律以**选项卡**形式跳出（可点击的选项按钮），不要用纯文字提问让用户打字作答。封闭式问题（时长/模式/画幅/语言/字幕/音乐等）给出预设可点选项 + 必要时附"自定义"选项；开放式内容（3 核心元素、故事大纲）也用选项卡承载（如"我来提供"/"帮我生成"等入口选项，用户选"我来提供"再补充文字）。⚠️ 曾出现多个确认环节未跳选项卡的问题，此规范用于杜绝，任何确认都不得退化为纯文字问答。

1. **统一入口问询（单一选项卡询问框）**：一次问清 ① 时长（单镜≤15秒 / 单集30-60秒 / 多集数分钟 / 自定义）② 执行模式（全自动/手动确认）③ 视频画幅分辨率（默认 16:9，可选 4:3 / 16:9 / 21:9 / 自定义输入）④ 对白语言 ⑤ 3 个核心元素（生活空间/家庭关系/日常物件锚点）⑥ 是否已有故事大纲（有则请用户提供）。全部以选项卡形式跳出、写入 memory。⚠️ 仅"信息征集"合并到此框；moodboard 与故事的**生成动作**须等用户答完后在第 2、3 步执行，不并入询问。
2. **风格确认（生成动作）**：据入口的 3 核心元素 → 生成 moodboard（图像生成能力，默认 16:9，单一融合画面铺满出血、禁白边/拼贴/分格）→ 存为风格锚资产、记下归档标记。
3. **故事（生成动作）**：入口已提供大纲则遵循、仅叠加是枝风格化；无大纲则按 3 元素生成（家庭/日常/生死离别/时间流逝/克制的羁绊）。🔴 **必须写足日常对白/旁白，禁止一刀切拍成无台词默片**：是枝的"克制"指对白平实生活化、不写戏剧化煽情台词，**不是不说话**——他大量使用饭桌闲聊、家常絮语、答非所问的日常对话，这正是其味道所在。基调按"该说话则说足、该沉默则留白"平衡：饭桌/相处/对话等场景必须写出生活化对白，独处/凝视/过渡/时间流逝等场景才保持沉默留白；沉默镜须是有意为之、不得作为省略对白的偷懒。⚠️ 生成故事与分镜时逐场检查：该有对白的场景不许空着。
4. **资产 + 分镜表（一并产出、统一确认）**：
   - **先产资产**：有戏角色必产白底棚拍模卡定妆图（锁脸/服装/发型），后续镜头一律 @角色名 引用。🔴 **场景图必须为纯环境空景、绝不出现任何人物**（含背景路人、人影、剪影、模糊人形、镜中人影一律禁止）——人物只在第 5 步视频生成阶段经角色图引入；场景图一旦带人会与角色模卡冲突、导致视频里人物脸/身份漂移、一致性锁不住。场景图单张、绝不分屏。🎨🔴 **场景图生成时必须在 prompt 里显式 @moodboard（第 2 步存下的风格锚资产）作为参考图垫入**——这是硬约束、不是可选项，缺失即重做。moodboard 仅锚色调/光感/质感、不锚构图，用于统一全片色调。⚠️ **务必区分"哪些阶段挂 moodboard"**：**只有场景图这一处挂 moodboard**；人物模卡、道具合图、以及第 5 步视频生成阶段**一律不挂 moodboard**（视频参考只有场景图/人物图/道具图，见第 5 步与视频模板）。本 SKILL 中多处"不挂 moodboard"的约束仅针对视频/人物/道具，**不得**泛化覆盖到场景图。负面加"人物、人影、路人、剪影、人形"。具名道具汇总一张白底道具合图。
   - **再列分镜表**：基于故事与已产资产，列出完整分镜表（每镜：景别 + @角色动作 + 运镜 + 环境 + 时长），分镜须 @角色名、引用对应场景图。
   - 🔴 **统一确认（单一选项卡询问框）**：资产图与分镜表一并打包给用户，用选项卡一次性确认（确认无误 / 需要调整）；用户选"需要调整"则据反馈修订后再确认。确认通过才进入第 5 步，让视频生成更丝滑。
5. **生成视频**：按**已确认的分镜表**逐条生成，场景图+角色图（+含具名道具时挂道具合图）作参考锁一致性，分镜写进 prompt 时间轴。🔴 **视频生成不挂 moodboard 风格锚**（moodboard 只用于场景图生成阶段，视频参考只有场景图/人物图/道具图）。
6. **音乐**：等视频人物全定稿后再确认方向、再生成（默认 mureka）。🔴 **生成后先不合成进视频**——因当前 agent 工具在含音乐的视频上加字幕会出问题，音乐须暂存、等第 8 步成片后统一询问框里再由用户决定是否合成（且执行时必先字幕后音乐）。
7. **合成**：跨 15 秒才拆多条、串行后用视频合成能力拼接。
8. **成片后统一处理与询问（单一选项卡询问框）**：🔴 所有视频节点生成完、并按第 7 步合成成完整成片后，用**同一个选项卡询问框**一次性让用户选择（可多选）：① 是否需要加字幕 ② 是否需要合成背景音乐（第 6 步已生成的）③ 是否需要修改背景音乐后再合成。
   - 🔴🔴 **字幕选项卡文案必须按对白语言正确生成（易错点，重点核对）**：生成"加字幕"这个选项时，文案里描述的字幕类型必须与下方 add_subtitle 的语言策略一致——对白**中文**才写"单语中文字幕"；对白**非中文（含日语、英语等）必须写"双语字幕：中文 + X语（如中日双语）"，严禁写成"单语X语字幕"**。⚠️ 曾出现日语对白却把选项写成"单语日语字幕"的错误，生成此选项前先回读 add_subtitle 策略再落文案。
   - 🔴 **执行顺序强制"先字幕、后音乐"**：即便用户在同一框里同时勾选了字幕与音乐，实际执行也必须先完成字幕、再合成音乐——因当前 agent 工具在含音乐的视频上加字幕会出问题，顺序不可颠倒。
   - 🔴 **音频合成默认混音值**：合成背景音乐时，默认将视频原始声音（环境音+对白）音量 **+8dB**、背景音乐音量 **-2dB**，让对白与环境音清晰在前、音乐退在生活后面（契合是枝"音乐不抢戏"的原则）。用户另有指定则从其要求。
   - 若选"修改背景音乐"：先按用户意见重新生成/调整音乐，再在字幕完成后合成。
   - **后期剪辑工具**（工具：agent.tool.edit_video；用户未提及的处理不擅自调用，仅按上方询问结果与用户明确要求执行）：
     - **字幕** add_subtitle：白字黑色描边。🔴 **字幕语言策略按对白语言分情况（硬约束，选项卡文案与实际生成都须遵守）**：对白为**中文**→默认只生成**中文单语字幕**；对白为**非中文**（日语/英语等）→默认生成**双语字幕，上轨中文、下轨影片使用语言**（例：日语对白→中日双语，上中文下日语；英语对白→中英双语，上中文下英语）。⚠️ 非中文对白**绝不可**只出单语原文字幕。用户另有指定则从其要求（如只要单语、或调整语言）。
     - **转场** transition：用户提及但未指定方式→默认直接硬切（是枝极少用花哨转场）；可选硬切/淡入淡出/黑场；AI转场不在此列。⚠️禁溶解叠化只约束视频生成阶段，合成后可正常加转场。

## 人物铁律

- **锁质感、放身份**：65mm 干净胶片质感是硬约束；发色/发型/服装/身份气质尊重用户设定、不做是枝化纠偏。
- **皮肤是自然真实的血色**：整体自然中性调，肤色真实健康、有血色与生活质感（可微暖），不刻意美白也不青灰暗沉、不磨皮塑料。是枝的脸是"生活里的真实的脸"——有细节、有年龄、有呼吸。
- **模卡 ≠ 出片**：模卡用纯白底 + 明亮均匀棚拍正面光（脸充分提亮、面部细节优先），绝不用逆光/戏剧光。版式 16:9：左三视图（正/侧/背）+ 右大面部特写（必出、不可省、不可画成全身）。
- 🔴 **模卡模板（照填，禁改结构与质感尾词，只换 \[\] 占位；若版式散架/视图不全退回英文版）**：

## 场景卡（按场景取用，共享底层 DNA）

- **家宅室内（招牌）**：日式或普通民居室内，天光从窗/纸窗漫射进来是主光，木质地板家具与榻榻米的暖、生活物件杂而有序、真实居住痕迹。柔和均匀、层次丰富、暖调自然保留、中等景深保留房间纵深。人物在空间里做日常动作（坐、走、忙碌），非摆拍。
- **饭桌/厨房（是枝灵魂场景）**：一家人围坐吃饭或厨房备餐，饭菜热气与油光、餐具碗筷、家常的暖。头顶或窗侧自然光，暖调温润、氛围松弛日常，多人同框、关系在空间里展开。⚠️ 是枝最标志性的场景，务必拍出"生活的温度与松弛"，不摆拍、不刻意、有声音有动作有热气。
- **走廊/檐廊/庭院过渡空间**：室内外之间的过渡地带（走廊、缘侧、门口、庭院），光线明暗过渡自然，人物穿行或停留、常有留白与等待的静默。是枝爱用这类"空间的呼吸口"。
- **外景日常**：街巷/坡道/河边/上学放学路。晴天自然软光（非戏剧逆光）/ 阴天柔和漫射 / 傍晚暖光（暖调自然保留、不做冷调纠偏）。人物走在真实生活街景里，环境与人同等重要。
- 🌊 **海街/夏日日常（招牌，必出高水准）**：夏日的明亮日常——蓝天、绿植、蝉鸣感、晾晒的白衣物在风里、海边或坡道或庭院，自然强日光但**柔和真实不开花不过曝**、暖调自然保留（皮肤的暖、木色的暖）、色彩自然饱满有生活感、中等景深保留环境。人物在日常里走动/停留/相处。负面锁：逆光开花、过曝死白、柔光滤镜朦胧、粗颗粒做旧、冷调纠偏、浅焦全糊。用户一提夏日/海街日常无条件套此卡、出图自查光柔和真实、暖调保留、环境可辨。
  - 完整 prompt（可直接用）：`是枝裕和式夏日日常场景，明亮温润的自然日光（柔和真实、绝不逆光开花绝不过曝死白、无柔光滤镜无光雾），蓝天与浓郁自然的绿植、晾晒的白色衣物在风中轻摆，日式民居庭院或海边坡道或安静街巷，暖调自然保留（皮肤的暖、木质的暖、阳光的暖，不做冷调纠偏也不夸张成橙黄膜），色彩自然饱满有生活质感与胶片温润密度（干净通透不脏不做旧不复古滤镜），中等景深、背景生活环境清晰可辨（非浅焦全糊成光斑），中等对比、明暗层次丰富、暗部干净不死黑，细腻65mm胶片干净质感、颗粒极细几乎不可见，克制平实的日常凝视，画面有生活的呼吸与温度`

## 运镜（每镜配一种，与情绪咬合，默认静观）

固定长镜凝视 / 缓慢横移跟随 / 缓慢推近（克制、几乎不易察觉）/ 固定中景等待 / 轻微手持生活呼吸感（非冲击式）/ 定点旁观。⚙️ 快速运镜、手持冲击跟拍、急推拉、跳切默认禁用，仅用户点名时启用。是枝的镜头是"安静的旁观者"，动得越少越对。

## 剪辑节奏（默认静观长镜一支）

- 默认实时速度、镜头较长、给动作与沉默留出完整时间，禁快剪、禁频繁切换、禁跳切（仅用户点名时启用）。
- 镜头可以长时间停留在一个日常动作或一段沉默上，让时间自然流逝。
- 景别变化区间：**硬切时相邻镜头景别至少要有肉眼可辨的落差、避免"切了等于没切"**——紧挨的一档（如中景↔中近景、中近景↔近景）差别太小不算有效切换，硬切时景别至少隔一档（如中景→近景、全景→中景）才有落差感。但**上限仍是禁暴跳**（近景↔大全景这类跨度过大禁用）。即：硬切景别变化落在"隔一档"到"跳两档"之间，既有区分度又不突兀。若剧情就是要同一景别静静停留，则不切、用一个长镜到底，而非切到一个几乎相同的景别。
- 让一个动作/一段对话/一次沉默完整发生，不打断、不催促。每镜承载一段完整的生活时间，而非一个动作节拍。

## 音乐（纯器乐无歌词，默认 mureka）

- 气质：克制、温润、留白、绝不煽情，靠音色与氛围而非旋律推进，音乐是日常的底色而非情绪的强调。
- 🎹 **第一支·日常温润**（钢琴/木吉他+弦乐辅底）三子支：
  - A·家庭日常：钢琴或木吉他简单温暖的动机、弦乐暖底、旋律亲切不复杂。用于饭桌/家宅/日常相处。
  - B·流动的时间：钢琴单音有空间感、留白多、旋律稀疏、有时间缓缓流逝的呼吸。用于走路/等待/季节转换/独处。
  - C·离别/思念：弦乐长音克制内敛、旋律隐忍不外放、留白处即情感。用于告别/缺席/怀念/生死。
- 🌾 **第二支·安静留白**：极简，钢琴单音或环境音或近乎无声的织体，弱旋律强空间，让环境声（蝉鸣/水声/风）成为主角。用于凝视/沉默/空镜/时间流逝。
- 🌿 **第三支·温暖日常律动**：木吉他或钢琴带轻柔的节奏感（非强节拍）+温暖明亮、有生活的轻盈流动感。唯一允许有轻微律动的支，但仍克制——是"平常日子里的轻快"、非欢快煽动。用于孩子玩耍/夏日出行/轻松的家庭时刻。
- **选支**：家宅饭桌→A；走路等待独处→B；离别思念生死→C；凝视沉默空镜→第二支；孩子玩耍夏日轻松→第三支。同一片多支并存随段落切换。
- 禁强鼓点/流行编曲/强卡点/管弦爆炸/煽情弦乐洪流/催泪高潮/歌词人声。是枝的音乐永远退在生活后面、绝不冲到情感前面。

## 生成后自查（不达标则重做）

光是否自然漫射生活光而非戏剧逆光开花（须自然）？是否有柔光滤镜/halation/光雾（禁，须平实通透）？五官是否被均匀照亮清晰可读？暖调是否自然保留而非被冷调纠偏（暖可用）？质感是否干净通透而非粗颗粒脏旧做旧（须干净65mm）？暗部是否有层次不死黑不闷？景深是否保留生活环境而非全糊成光斑？情绪是否克制凝视而非煽情戏剧化？镜头是否够静够长、给了时间与留白否？夏日/家宅镜头光够柔和真实、暖调在、环境可辨否？

## 视频铁律

- 🔴 **单条多分镜（默认强制）**：seedance 单次最长 15 秒、原生支持单条内多分镜+镜间硬切，**不走"一镜一条+后期拼接"**。总时长按故事节拍自评估、不硬凑 15 秒：是枝节奏偏慢，镜头长、分镜少——先估生活段落数（一段落=一个完整的日常时间片段：一次对话/一段动作/一次沉默）定镜数定时长（1段落→8秒1-2镜/2→10-12秒2镜/3→15秒3镜）。**只有跨 15 秒才拆多条、串行后用视频合成能力拼接**。prompt 按秒推进、每镜=景别+@角色动作+运镜+环境，镜头长、镜间硬切显式断开。
- **不出 BGM**：视频生成只要环境音+对白，BGM 合成阶段叠加。是枝的环境音（蝉鸣/水声/餐具/脚步）极重要，prompt 常驻声明"只保留丰富真实的环境音与对白、无背景音乐无配乐"；负面加"背景音乐、配乐"。
- 🔴 **对白不可省（治"全默片"惰性）**：写分镜与 prompt 时，凡有人物互动/相处/饭桌/对话的镜头，默认须写出生活化对白（平实、家常、不煽情），不得因追求"克制留白"就把镜头一律拍成无台词默片。仅在独处/凝视/过渡/时间流逝等设计意图明确为沉默的镜头才留白，且沉默是有意为之、非省略对白的偷懒。对白内容直接写进该镜 prompt 时间轴、受下方语言锁约束。
- 🔴 **旁白统一写入视频 prompt**：旁白不单独走配音/TTS、不后期叠加，一律作为视频 prompt 的一部分交由视频模型随画面一起生成（与角色对白同处理）。需要旁白的镜头，把旁白内容直接写进该镜的 prompt 时间轴里、并注明"旁白（画外音）："；旁白同受下方语言锁约束。⚠️ 是枝式旁白须克制平实、不抒情不煽情，宁少勿多。
- 🔴 **语言锁**：每条视频 prompt 常驻声明"人物对白/旁白一律 \[选定语言\]，模型自主补话也只用此语言，禁其他语种台词/字幕/口型"（不管本镜有无对白都写）；负面加"其他语种台词、混合语言口型"。防无对白镜头被模型自主加话时蹦错语种。
- 🔴 **群像/多人场景人人皆动**：一旦画面出现多人或群像（饭桌、街市、教室、家庭聚会等），必须确保画面中**每一个人都在自然地动**——各有各的日常动作（吃、说、转头、走动、忙碌、小动作），杜绝背景人物僵立不动、定格如蜡像/假人。prompt 里逐一或成组交代人物动作、并常驻声明"画面中所有人物均自然活动、无人僵立定格"；负面加"背景人物僵立、定格人像、蜡像、静止假人"。⚠️ 唯一例外：用户明确要求所有人保持静止或站立不动时才可静止。
- 🔴 **皮肤去脏（仅视频阶段，防 seedance/视频模型把真实肤质劣化成脏）**：静态图/模卡保持真实肤色不动，但视频 prompt 须做三件事防止皮肤在动态中变脏——① **提亮**：皮肤（尤其暗部）较静态基准轻微提亮约一档、暗部干净通透（这是"皮肤局部去脏性提亮"，不等于整体画面往高调推，全片明度仍守底层 DNA 的平实中性）；② **净化肤色**：肤色均匀干净、无杂色斑驳、无灰绿/蜡黄/发脏偏色、血色自然通透；③ **收敛过度质感**：保留自然肤质但适度收敛毛孔油光的过度锐化，不粗糙不油腻——同时**仍禁磨皮塑料假脸**（去脏≠磨皮）。prompt 常驻声明"人物皮肤干净通透、暗部提亮不脏、肤色均匀无杂色偏色、自然肤质不油腻不磨皮"；负面加"皮肤发脏、暗部脏污、肤色斑驳、灰绿蜡黄偏色、油腻油光、过度锐化毛孔"。
- **人物实体性与自然性**：人物全程实体清晰、动作自然生活化，不摆拍、不对镜、不表演式。日常动作（吃饭、走路、做家务、对话）要松弛真实。负面常驻：僵硬摆拍、对镜甜笑、表演式夸张动作。
- **禁溶解叠化**：镜间硬切，负面常驻 no dissolve/cross-fade/fade。
- **禁戏剧化打光与运镜**：视频里绝不执行逆光开花、戏剧强光、快速运镜、手持冲击。光是自然生活光、镜头是安静旁观。负面常驻：逆光过曝、柔光滤镜、快速运镜、剧烈晃动。

## v1.5.2 修复

> 针对"场景图生成时不垫入 moodboard 作风格锚"的实测问题。

- **根因**：① 第 2 步优化记录里"存锚、不单独确认"的措辞，易被理解成 moodboard 只是归档资产、生成场景图时无需再引用；② 全文多处"视频/人物/道具不挂 moodboard"的强约束语气过重、出现频率高，泛化污染到了场景图阶段，把"场景图须挂 moodboard"这唯一一条正向指令覆盖掉。
- **修复**：① 第 4 步"先产资产"里把场景图挂 moodboard 从描述性表述改为显式可执行硬约束（"必须在 prompt 里 @moodboard 垫入、缺失即重做"），并明确"只有场景图这一处挂、人物/道具/视频不挂"的边界，禁止把"不挂"泛化到场景图；② 第 4 条优化记录里给"存锚"补注，说明其仅指跳过单独确认、不代表不再引用。

 5. **默认字幕策略**：中文对白→中文单语字幕；非中文对白（日语/英语等）→双语字幕，上轨中文、下轨影片语言（日→中日双语、英→中英双语），非中文绝不只出单语原文。
 6. **镜间切换避免画面跳跃**：景别落差规则——硬切时相邻镜头景别至少隔一档、有可辨落差、禁暴跳；若需停留则用长镜不切，避免"切了等于没切"。（"人物占位漂移"本轮暂不处理。）
 7. **多人场景人物不动**：新增「群像/多人场景人人皆动」铁律，多人同框每人须有自然动作、杜绝背景僵立定格如蜡像，附常驻声明句与负面词；唯一例外为用户明确要求静止。
 8. **旁白策略**：旁白统一写入视频 prompt、随画面由视频模型生成（不单独配音/后期叠加），需要旁白的镜头写进时间轴并标"旁白（画外音）"，受语言锁约束，须克制平实、宁少勿多。
 9. **混音配比**：音频合成默认混音值——视频原声（环境音+对白）+8dB、背景音乐 -2dB，对白环境音在前、音乐退后。
10. **肤色表现（去脏）**：针对 seedance/视频模型把真实肤质劣化成脏的问题，仅在视频阶段三管齐下——①暗部轻微提亮约一档（局部去脏性提亮，不推高整体高调）；②净化肤色去杂色偏色；③收敛过度锐化油光但仍禁磨皮。静态图/模卡真实肤色不动。
