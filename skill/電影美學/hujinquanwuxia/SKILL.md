# 古典武俠電影全流程導演

## 核心任務

把使用者現有內容推進到恰好夠用的生產深度。先判斷輸入成熟度、已有素材和連續性風險，再選擇流程；不要因為使用者有劇本就假設沒有資產，也不要因為使用者沒有劇本就自動建立完整資產庫。

預設原則：

- 多鏡頭專案優先“分析 → 九宮格草稿 → Seedance 2.0 直生影片”。
- 單鏡頭專案直接寫單條提示詞，不強制寫劇本、九宮格或資產。
- 場景資產預設關閉；沒有使用者提供的完整劇本時，除非使用者明確要求，禁止生成場景資產。
- 首幀預設關閉，只把它用於多人站位、精確動作起點、強銜接或多次直生失敗的高風險鏡頭。
- 新生成的獨立人物、服裝、道具和武器資產統一使用中性淺灰乾淨背景；使用者已有資產不因背景不同而強制重做。
- 影片生成目標解析度預設 720p；生成解析度與最終匯出解析度分別記錄，不把後期超分冒充原生生成。
- 不在圖片或影片尚未獲得實際結果時聲稱“已經生成完畢”。

## 首次使用與幫助觸發

使用者只說“開始”“第一次用”“怎麼用”“幫助”“如何呼叫”，或只點名本 Skill 而沒有專案內容時，讀取 `references/quick-start.md`，顯示簡短快速開始卡並等待輸入。不要直接開始編故事或生成資產。

使用者已經給出可執行的劇本、想法或單鏡要求時，跳過整張說明卡，直接提取已知資訊並只詢問必要缺口。不要讓熟悉流程的使用者重複閱讀說明，也不要要求使用者填寫完整表格；自然語言和“其他按預設”都有效。

## 總流程

 1. 確認主風格、畫幅、生成目標解析度、任務型別、總時長策略、輸入型別和已有素材。
 2. 按完整劇本、簡單想法、模糊題材或單鏡請求分別分析。
 3. 建立文字風格鎖，並準備與生產路線匹配的驗證方式。
 4. 輸出分析摘要、連續性風險和推薦路線，暫停等待一次路線確認。
 5. 多鏡頭專案按選擇生成九宮格草稿並稽核；單鏡或使用者跳過時直接進入下一階段。
 6. 只生成缺失且必要的資產；預設不做場景資產和首幀。
 7. 細化分鏡、打鬥、智慧片段時長與逐鏡影片提示詞，生成並檢查影片。
 8. 全部影片透過基礎檢查後，暫停詢問是否加字幕。
 9. 獲得回答後完成剪輯、BGM、音效、調色和字幕。
10. 終審並定向返修。

不得跳過階段 0、3、6、7。階段 4、5 是否執行及執行深度由階段 3 的路線決定。

## 階段 0：規格確認與輸入盤點

從使用者訊息和附件中先提取已知項，只詢問缺失項，不讓使用者重複回答：

 1. **輸入型別**：完整劇本 / 簡單想法或故事梗概 / 只有題材、風格或一句話 / 單個獨立鏡頭。
 2. **已有素材**：完整資產 / 部分資產 / 沒有資產；區分角色、服裝、道具、武器、場景、分鏡和試片。
 3. **製作目標**：只做分析 / 圖片或提示詞 / 單鏡影片 / 完整短片 / 修改已有結果。
 4. **主風格**：古典武俠電影風 / 胡金銓意境武俠美學啟發風 / 邵氏棚拍武俠美學風。
 5. **成片畫幅**：16:9（預設）/ 9:16 / 2.39:1 / 4:3 / 1:1 / 自定義。
 6. **影片生成目標解析度**：720p（預設）/ 1080p / 當前模型最高可用 / 自定義。這裡只表示目標，不在未確認模型能力時承諾原生輸出。
 7. **最終匯出解析度**：保持原生生成解析度（預設）/ 1080p 超分交付 / 平臺規格 / 自定義；可在開始時指定，也可在剪輯前補定。
 8. **總成片時長**：使用者指定 / 有完整劇本時授權智慧體建議 / 簡單想法由使用者指定或授權建議。
 9. **影片模型與時長、解析度限制**：如使用者指定 Seedance 2.0 或其他模型，記錄可用檔位；未知時先按內容需要規劃，再適配模型。
10. **釋出平臺/交付用途（可選）**：使用者給出時用來調整畫幅、安全區和最終匯出；未給出不阻塞創作。

畫幅、`GEN_TARGET` 和 `DELIVERY_TARGET` 有安全預設值，使用者未提及時直接填入狀態卡並允許修改，不把它們變成阻塞問題。使用者說“按預設”或“其他按預設”時，使用 `16:9＋720p 生成目標＋保持原生解析度交付＋快速直生＋多鏡頭先九宮格＋場景資產 0＋首幀 0＋智慧片段時長`。主風格仍需從使用者內容推斷或簡短詢問；總時長需使用者指定或授權建議。使用者提供劇本時，單條片段由執行本 Skill 的大模型逐段判斷，不逐條追問。開始時只做素材盤點，不要詢問“資產是不是都做了”後仍預設重做；能從上傳內容判斷時直接填寫。

解析度選擇、各畫幅 720p/1080p 目標對映、模型限制與超分規則讀取 `references/resolution-delivery.md`。

### 三種主風格

- 古典武俠電影風：`references/style-classical.md`
- 胡金銓意境武俠美學啟發風：`references/style-king-hu.md`
- 邵氏棚拍武俠美學風：`references/style-shaw.md`

預設只選擇一個主風格。使用者明確要求融合時，設定“主風格不少於 80%，輔助風格不超過 20%”，並列出允許借用的具體元素。

### 畫幅影響

- 16:9：預設；適合橫向空間、雙人對峙與山水排程。
- 9:16：減少橫向並排，優先前中後景、上下平臺和縱深路線。
- 2.39:1：強調橫向留白、群像和寬銀幕動作，單獨規劃字幕安全區。
- 4:3：適合建築框景、復古電影和集中人物關係。
- 1:1：減少多人複雜排程，優先中心關係和短動作。

角色 1＋3 資產板如需生成，預設仍用橫向 16:9；九宮格每格、首幀和影片嚴格繼承成片畫幅。畫幅描述比例，解析度描述畫素目標，兩者不得混用。

## 階段 1：按輸入成熟度分析

必須讀取 `references/workflow-routing.md`，並選擇一種內容路線：

### A. 完整劇本

- 讀取全文，鎖定場次、人物關係、臺詞、動作、結局和不可改事實。
- 除非使用者要求改編，不擅自刪改劇情。
- 讀取 `references/script-duration-planning.md`，按場次、語義、臺詞、表演、動作和反應拆分，由大模型逐單元判斷時長。

### B. 簡單想法或故事梗概

- 補成最短可執行劇情節拍：觸發、判斷、動作、結果和餘味。
- 把新增內容明確標為“自動補齊假設”，先讓使用者確認路線，不直接擴寫成長劇本。
- 根據目標時長判斷需要幾個段落和鏡頭，不機械套模板。
- 智慧體補出的節拍或工作草稿不視為“使用者提供的完整劇本”，`USER_SCRIPT` 仍為否。

### C. 只有題材、風格或一句模糊需求

- 先給 2–3 個彼此明顯不同的一句話短片方向，每個說明人物、衝突、核心視覺和結尾。
- 暫停等待使用者選擇；選定後再形成簡短劇情節拍並進入路線確認。

### D. 單個獨立鏡頭

- 直接明確鏡頭目的、畫幅、時長、動作起止、風格和聲音。
- 預設跳過資產、場景圖、九宮格和首幀；只有身份或動作風險明確時才建議補一個最小參考。

所有路線都先寫創作脊柱：

> 誰，在什麼空間，因為看見或聽見什麼，判斷髮生怎樣的變化，於是做出什麼動作，最後停在哪個有餘味的畫面。

## 階段 2：建立風格鎖與驗證方案

讀取 `references/style-calibration.md`，並根據階段 0 的選擇讀取 `references/style-classical.md`、`references/style-king-hu.md` 或 `references/style-shaw.md`。先建立“前置風格身份錨 → 正文可見證據 → 結尾防稀釋鎖”的完整文字鎖，不要只寫風格名。此時只准備驗證方案；階段 3 確認生產路線後再實際執行對應驗證：

- 快速直生或單鏡路線：先建立完整文字風格鎖，用一條代表性測試片驗證；不強制先做三張定標圖。
- 連續性或嚴格控制路線：胡金銓與邵氏方向先製作空間遠景、中景人物關係、動作關鍵幀三張定標圖，選擇 `STYLE-REF-01` 後再批次生產。
- 只交付提示詞時：輸出完整定標提示詞和驗收證據，不聲稱已有實際參考圖。

## 階段 3：分析後只確認一次生產路線

根據輸入成熟度、已有素材、鏡頭數量、人物復現、關鍵道具、複雜打鬥和空間連續性，給出一條明確推薦及原因，再提供備選。使用 `references/workflow-routing.md` 的判定規則：

1. **快速直生路線（多鏡頭預設）**：九宮格 → 逐鏡提示詞 → Seedance 2.0 直生；不生成場景資產，不生成首幀，角色和道具也可全用文字錨點。
2. **角色連續性路線**：九宮格 → 只補主要角色 1＋3 灰底資產和劇情關鍵道具 → 直生影片；不生成場景資產，不生成首幀。
3. **嚴格控制路線**：九宮格/空間預演 → 只補必要角色/道具；只有滿足場景觸發條件時才做場景資產；只有高風險鏡頭才做首幀/尾幀。
4. **沿用已有資產路線**：稽核、編號和繫結已有素材，只補無法替代的缺口；不因背景或格式不同重複生成可用資產。

路線確認卡必須同時寫清：風格驗證方式、九宮格是否執行、需要新建哪些資產、場景資產是否為零、哪些高風險鏡頭需要首/尾幀。使用者確認後，先完成對應風格驗證，再進入九宮格或逐鏡生產；不在資產完成時再次詢問首幀。若使用者只說“直接做”，多鏡頭專案預設快速直生且保留九宮格；若明確說“直接生成影片/不要分鏡”，跳過九宮格。單鏡請求直接執行 D 路線。

## 階段 4：九宮格分鏡草稿

多鏡頭專案預設讀取 `references/storyboard-nine-grid.md`，在正式影片前生成一張嚴格 3×3 的鏡頭草稿接觸表：

- 每格保持成片畫幅，按左到右、上到下表達連續九個節拍。
- 九宮格是計劃與稽核圖，不是角色、場景或正式首幀資產；畫格展示實際劇情環境，不使用灰底資產背景。
- 圖內不要生成編號、字幕或對白氣泡；在外部表格用 `G01–G09` 對照劇情。
- 少於九個最終鏡頭時，九格可以表達建立、觸發、反應、動作和結果等節拍，後續允許合併；超過九個鏡頭時按段落製作多張九宮格。
- 不把整張九宮格直接作為每條 Seedance 影片參考。需要引用時，只能裁出、修復並稽核單格；預設仍使用文字提示詞直生。

稽核故事是否成立、景別是否重複、軸線是否清楚、動作是否遞進。使用者只要求提示詞時，輸出九宮格提示詞和格位表；有實際生成能力時先出草稿並等待簡短確認，再細化影片。

## 階段 5：最小必要資產與條件式首幀

讀取 `references/asset-system.md`，先稽核使用者已有素材，再只補缺口：

- 主要角色：跨多個片段、會被清楚辨認或需固定服裝/武器時，才生成 1＋3 標準資產板：左側臉部正面特寫，右側全身正視、90° 側視、背視。
- 一次性角色、遠景群演、背影和不需辨認者，預設只用文字錨點。
- 道具/武器：只有推動劇情、參與互動、反覆特寫或跨鏡必須一致時才生成。
- 所有新生成獨立資產使用 `中性淺灰 #B8B8B8 左右、純色、無漸變、無紋理、無環境、無文字、無水印`；允許極輕接觸陰影。
- 使用者已有資產只要身份和結構可用即可繫結，不因不是灰底而強制重做。
- 場景資產預設不生成。沒有使用者提供的完整劇本時，除非使用者明確要求，場景資產數量必須為 0；有完整劇本時也只有反覆出現的獨特地點、複雜地形打鬥或結構連續性多次失敗才允許生成。
- 首幀預設不生成。僅多人精確站位、兵器接觸起點、上一鏡結尾強繼承、特殊構圖或直生反覆失敗時，按階段 3 已確認的清單生成；不追加第二次路線詢問。

## 階段 6：分鏡、打鬥、影片生成與檢查

圖片提示詞讀取 `references/image-prompts.md`，影片提示詞讀取 `references/video-prompts.md`，解析度與交付讀取 `references/resolution-delivery.md`，完整表格讀取 `references/templates.md`。

有完整劇本時，先輸出目標可用時長、模型生成時長和計劃取用區間。若模型只有固定檔位，先判斷內容實際需要，再選擇不短於需求的最近檔位；禁止為了模型檔位把所有片段改成相同 5 秒或 10 秒。

出現打鬥、追逐、輕功、兵器交鋒或多人衝突時，讀取 `references/fight-choreography.md`，先完成敘事目標、文字空間圖、軸線、動作節拍和拆鏡。單條影片不承擔完整連續打鬥。

逐鏡生成，至少檢查：

- 人數、身份、服裝、武器和關鍵道具是否穩定；未使用資產時，文字身份錨是否每條完整重複。
- 場景文字錨、左右關係、光源、畫幅和動作軸線是否連續；不要因為沒有場景資產就省略空間描述。
- 提交給模型的實際原生解析度是否記錄；是否與 720p/1080p 目標、畫幅和模型能力相容。
- 動作是否有觸發、起點、終點、重量和可接下一鏡的結尾。
- 是否多手、多劍、穿模、瞬移、漂浮、人物互換或背景無故重構。
- 胡金銓/邵氏是否出現可見風格證據，而非只有風格名。

不合格時讀取 `references/quality-repair.md`，只返修失敗變數。只有計劃內片段都有實際結果、關鍵鏡頭可用且連續性透過，才標記為“可進入剪輯”。

## 階段 7：字幕確認門

全部影片片段生成並透過基礎檢查後，必須暫停詢問：

> 影片片段已經生成並透過基礎檢查，現在準備進入剪輯。請選擇：
>
> 1. 不加字幕
> 2. 只加對白/旁白字幕
> 3. 加對白/旁白字幕，並保留少量片名或章回卡
> 4. 只加片名或章回卡，不加對白字幕

使用者未回答前，不輸出最終剪輯時間線，不擅自新增或刪除字幕。

## 階段 8：剪輯、聲音、調色與字幕

獲得字幕選擇後，讀取 `references/editing-audio-subtitles.md`、`references/resolution-delivery.md`，並讀取階段 0 已選定的 `references/style-classical.md`、`references/style-king-hu.md` 或 `references/style-shaw.md`。輸出最終時間線、切點、聲音橋、環境聲/動作聲/BGM 分層、字幕或片名卡、調色、膠片方案與最終匯出解析度。需要超分時，原則上在畫面鎖定後、新增最終字幕與銳利圖形前完成。

胡金銓方向以空間、停頓、短爆發和聲音留白為主；邵氏方向以棚景排程、完整身體動作、短促變焦/搖攝和復古鑼鼓節拍為主。

## 階段 9：終審與定向返修

按“劇情事實 → 路線執行 → 身份與關鍵資產 → 空間連續 → 動作因果 → 風格證據 → 聲音字幕 → 美觀”終審：

- 是否正確區分完整劇本、簡單想法、模糊題材和單鏡請求。
- 是否先盤點已有資產，只補缺口；新獨立資產是否統一灰底。
- 無使用者劇本時是否保持場景資產為零；有劇本時是否說明每個場景資產的觸發理由。
- 九宮格是否只用於稽核，沒有把整張九宮格錯誤地餵給單條影片。
- 是否預設直生，並只為階段 3 已確認的高風險鏡頭製作首/尾幀。
- 有劇本時是否按語義拆分並獨立判斷每條時長。
