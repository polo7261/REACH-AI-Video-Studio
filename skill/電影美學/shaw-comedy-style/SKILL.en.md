# shaw-comedy-style

Use this skill when creating fast-paced, Douyin-style, Shaw Brothers Hong Kong cinema comedy shorts. Core formula: **anthropomorphized pets/animals + wuxia shell + street-life comedy core**. The user uploads character reference images (people/pets/animals), a script, or a one-line inspiration, and the skill generates retro Hong Kong-flavored shorts of 10–30s (default 15s). **Style homage only; never replicate specific copyrighted Shaw Brothers works.**

> This environment's mapping: GPT Image/ImageToImage → `generate_image_v3`; Seedance/MultiModalToVideo → `generate_video_v3`; wuxia BGM/voiceover → `generate_audio`; text_editor → `write_file_v2`; video_assembler → `composite_video`; `<<<image_n>>>` → `reference_nodes`+`{{NodeKey}}`. **All prompt craftsmanship and anthropomorphic-styling craftsmanship is inlined in this skill; do not outsource to image-prompt-director / cartoon-flow**. Super-resolution (1080p via MediaKit) is unavailable in this environment — deliver at 720p by default. For 24fps/film grain etc., if the base model has no parameter slot, convert them into in-prompt descriptions and note this.

## Workflow (phases run serially, pausing for confirmation at each phase; address the user as "Director" throughout, use 【Module Name】 as phase titles, present in Markdown tables, no skipping steps)

0. **【Global Brief】** (`write_file_v2` → Final_Video_Spec.md; fields inferred from user input, defaults used where missing): Title (tentative or specified) / Style & tone (1980s Shaw Brothers film-grain Hong Kong-flavored wuxia comedy, anthropomorphized-pet mashup) / Total duration (default 15s; can be 10–30s or longer) / Output resolution (720p default) / **Aspect ratio 16:9 (fixed, unchangeable)** / Narrative language (Chinese) / **Global hard rules: no subtitles and no BGM throughout (unless explicitly requested)** / Character input method (reference image upload — humans/pets/animals / text description / built-in character library; fill in per actual case) / Narrative core (comedy first, wuxia as the shell; pets/animals retain instinctive behaviors to create contrast with their wuxia styling) / Audio rules (by default keep ambient sound — street bustle/blades/wind etc., no BGM; voiceover in Hong Kong-accented Mandarin with old-microphone grain processing; a light, upbeat wuxia-flavored BGM may be generated on user request). ⏸ Confirm before entering Phase 1.
1. **【Script Outline】**〔⏸〕: (if materials exist) run `analyze` to parse materials, then generate a Shaw Brothers-style story outline — following the **qi-cheng-zhuan-he** four-part structure (qi: encounter/setup → cheng: pursuit/conflict → zhuan: secret origin/villain conspiracy → he: showdown/chivalric legacy) + emotion curve + suggested shot count (4–8, fitted to total duration); for optimization rules see "Smart Script Optimization"; present as a Markdown table, ⏸ confirm to enter Phase 2.
2. **【Storyboard Design】** (`storyboard`, see the "Storyboard" section): generate a structured storyboard table (key elements + shots + audio layers). Present 4–6 shots per batch, ⏸ wait for "Confirm/Revise/Regenerate" before continuing; once all are confirmed, enter Phase 3.
3. **【Element Assets】** (`generate_image_v3`, see the "Asset Generation" section)〔⏸〕: for uploaded reference images, register asset_id and bind to key_element; **for modern clothing, first prompt the user to confirm style conversion; after confirmation, use ImageToImage to convert to wuxia styling**; for the built-in hero library or text-only input, generate character portrait images. When everything is ready, ⏸ notify the user, then enter Phase 4.
4. **【Shot-by-Shot Video】** (`generate_video_v3`): generate shot by shot per the storyboard table, present in small batches; individual shots may be requested for regeneration; once all pass, enter Phase 5.
5. **【Audio (If Needed)】**: if BGM is requested, use `generate_audio` to generate wuxia-flavored instrumental music; ambient sounds (wind/blades/hooves) are produced along with each shot during the video generation phase — no separate step needed.
6. **【Editing, Compositing & Output】** (`composite_video`, see the "Editing" section): stitch in storyboard-duration order, mix audio, output, with an attached QC summary table.
> Dependencies: 1→0; 2→1; 3→2; 4→3; 5→2; 6→4,5.

## Material Analysis (`analyze`)

- **Human/animal reference images**: extract and output structured info for key_element use — facial features (features/hairstyle/hair color/perceived age), body type & posture, clothing (if modern clothing, mark as "needs conversion to wuxia style"), species (for animals, extract coat color/body size/demeanor for anthropomorphized wuxia styling), temperament keywords (cold/hotheaded/mysterious/imposing, etc.).
- **Text script/screenplay**: extract synopsis, character names, key scenes, and emotional beats; output a structured summary for the Planner to generate the outline.
- **One-line inspiration**: identify the core character relationships (e.g., "swordsman vs villain"), core conflict, and emotional tone; output an expansion seed.
- **Reference video (if uploaded)**: extract camera-movement style, color-tone traits, and rhythm as a visual reference baseline, rather than directly copying the content.

## Smart Script Optimization

One-line inspiration → expand into qi (encounter/setup) → cheng (pursuit/conflict) → zhuan (secret origin/villain conspiracy) → he (showdown/chivalric legacy); rough script → polish dialogue + add wuxia details (sword tassel/bamboo hat/wine flask/setting sun/inn/bamboo forest/ruined temple, etc.); character images only without text → automatically design a chivalric tale based on the characters' visual temperament; no materials uploaded → reply "Hello Director, please upload at least one character reference image or a line of text inspiration before we can begin creating."

## Storyboard (`storyboard`)

**key elements design**:
- Build an independent element character for each main character: appearance (face/hairstyle/skin tone), wuxia styling (costume/weapon/accessories: bamboo hat/sword tassel/wine flask/cape, etc.), **martial temperament tag** (e.g., "a restrained swordsman who habitually lowers his eyes before striking"); for animal characters, add an anthropomorphized wuxia costume plan.
- Build an element scene for key locations: ruined temple/bamboo forest/inn/cliff/mountain forest, etc.; describe light-source direction (side backlight/moonlight/candlelight), fog intensity, and ground material.
- Build an independent key_element for important props (weapons/tokens, etc.).

**Shaw Brothers shot-duration structure (15s as example; other durations scale proportionally)**: opening setup 2–3s (wide shot or low-angle upward shot, establishing environment and protagonist); development/conflict 6–8s (2–3 fast-cut fight/confrontation shots, 1–2s each); climax 3–4s (slow-motion key action or facial close-up); ending wind-down 2s (figure walking away into the distance/sword sheathed/setting-sun freeze frame).

**Emotion & performance spec (applies to all shots)**: human/pet emotions must feel genuine and natural, conveyed through micro-expressions, physical details, and breathing rhythm — not exaggerated or stereotyped; **mechanical feel is strictly forbidden** — actions must have a **three-beat rhythm of wind-up–transition–follow-through**, avoid "instantly in position" style descriptions, and write out the smooth arc of motion transitions (e.g., "the right hand slowly rises from the waist, fingertips trembling slightly, before it closes around the sword hilt" rather than "grips the sword"); gaze and facial expressions must have layered detail (direction of gaze/eyelid tension/subtle corner-of-mouth changes), **break inner emotions down into visible bodily signals**; anthropomorphic pet actions must retain instinctive animal habits (felines sink their center of gravity before striking, canines' ears perk up), so movements feel natural and believable.

**Five elements of every shot**:
1. **Shot size**: full shot/medium shot/close shot/close-up.
2. **Camera movement** (choose from the following 7 standard types): low-angle upward shot (highlights heroic presence, first choice for character entrances) / slow motion (weapon unsheathing / qinggong fly-by / the decisive strike) / fast cuts (fight pacing, 1–2s per shot) / push-in (entrances / approaching gaze) / panning tracking shot (chases / qinggong) / fixed camera (dialogue / standoffs / oppressive atmosphere); **Forbidden**: handheld shake, drone aerial shots, overly smooth gimbal gliding.
3. **Action description**: precise down to body parts ("the right hand slowly grips the sword hilt, the index finger's knuckle turning white" rather than "draws the sword").
4. **Dialogue / inner monologue** (if any): format (emotion description, e.g., "voice low and suppressed, as if held back for a long time"): "Line… (pause)… Line."; emotion words must be converted into concrete actions/sounds ("angry" → "veins bulging on the forehead, a voice like sandpaper scraping").
5. **Ambient sound**: precise down to specific sound effects (wind / rustling bamboo leaves / clashing blades / horse hooves / dripping water, etc.).

**Visual style (6 rules that must be carried through every shot)**: ①**Color grading baseline** primarily a warm-yellow, dark-leaning vintage grade, no pursuit of extreme warm-cold split, apply slight color attenuation to the red-yellow range to simulate the faded feel of old film stock; ②**Lighting** hard light outlines the silhouettes of characters/cute pets, shadows deep and highlights soft (the low-saturation + strong light-shadow logic of Hong Kong film stock), primarily side backlight, suited to candlelight and moonlight scenes; ③**Film grain** unevenly distributed, denser in shadows and sparser in highlights (simulating insufficient ISO), medium intensity, visible but not over-noisy, no skin smoothing, no denoising; ④**Motion blur** during push/pan camera movements, add motion blur simulating insufficient shutter speed, with slight edge trailing on moving subjects; ⑤**Slight frame shake** occasionally add extremely slight lens shake to recreate the rough texture of old film, without obvious handheld wobble; ⑥**Fog effects for key scenes** scenes such as streetside restaurant smoke / bamboo forest morning mist / moonlit ruined temple must include light fog or smoke effects.

**Narrative tone (core differences from pure wuxia)**: ①**Comedy first** the wuxia shell is just the packaging, the comedic core is the hook; conflicts should prioritize "contrast cuteness" — inserting cute-pet/animal everyday logic into serious wuxia scenes to create absurd dissonance (the hero lets out a stern shout, and the cat across from him just licks its paw); ②**Narrative pacing** Douyin-style fast rhythm; the first 3 seconds must establish conflict or contrast; no Shaw Brothers-style slow-burn buildup — dive straight into the story; ③**Common comedy scenes** Hong Kong-style street comedies such as streetside restaurant disputes / a cute pet playing hero on the street / a "showdown" among kitchen ingredients / shopkeepers trading barbs with customers; jianghu grudges serve as background motivation, not the main expression; ④**Character contrast** cute pet/animal characters must carry two layers of description simultaneously — "wuxia styling" and "animal instinct behavior"; the clash between the two produces the comedic effect.

**Scene style supplement**: prioritize Hong Kong-style street-scene elements (carved wooden doors and windows / vintage tableware / red silk decorations / background diners dressed in Republican-era to 1970s–80s Hong Kong fashion); when paired with wuxia exterior locations, keep one "street-life detail" as a comedic anchor (e.g., someone selling baozi in the bamboo forest).

**audio layers**: ①**Default sound effects** retain ambient sound (street bustle / clattering tableware / wind / blade sounds), precisely defined in the shot description and produced with the shot during the video-generation stage, no default BGM; ②**Voice acting style** dialogue dubbing uses a Hong Kong-style Mandarin accent (articulation slightly soft and mellow, tonal contour fitting Hong Kong film street-level characters, sentence endings may rise slightly), emotion words broken down into concrete actions/sounds; ③**Optional BGM** if requested, design a music-type audio_layer described as "1980s Hong Kong-style wuxia light-comedy score, guzheng + pipa + light percussion, strongly melodic overall, brisk rhythm rather than heavy, may include light sound-effect accents, no modern electronic elements", bound to the full-video timeline; ④**Optional narration (VO)** if there is narration, narration_speaker_profile (e.g., "【Hong Kong storyteller cadence, moderate pace, with a touch of street humor, occasional pauses】") + a verbatim script.

## Asset Generation (`generate_image_v3` / `generate_video_v3`)

**Element assets**: upload reference images to register an asset_id bound to a key_element; for modern-outfit images, first run `generate_image_v3` (image-to-image, source Nano Banana Pro 2K) to convert them into wuxia styling, then bind only after user confirmation; when character images need to be generated, use text-to-image or image-to-image (prefer image-to-image when reference images exist). **Character images are always horizontal two-panel reference images**: left panel a facial close-up (facial features / hairstyle / skin tone / gaze), right panel a full body (outfit / weapon / pose); scene images are generated as panoramic views that convey light sources and fog effects.

**Per-shot video** (`generate_video_v3`, source Seedance 2.0 720p):
- **Reference input priority and binding order**: ①**Character key_element image (highest priority, required)**——for every character appearing in that shot, its two-panel reference image (facial close-up + full body) must be bound as the primary reference to keep facial features / hairstyle / outfit / weapon consistent across shots; with multiple characters, each one is bound to its own independent `{{NodeKey}}`; ②**Scene key_element image (required)**——bind that shot's scene element image to unify light-source color temperature / fog effects / scene details; ③**Previous shot's video as reference_video (use with caution)**——add it only when continuity of character state/action with the previous shot is extremely strong (a slow shot immediately followed by a close-up / the same action arc continuing across shots); usually omit it to avoid style drift (if this environment does not support video references, fall back to keyframe linking).
- **4 rules guaranteeing cross-shot character consistency**: ①**Element image lock**——each character key_element image, once confirmed in Stage 3, becomes that character's appearance anchor for the entire video; all subsequent shots must reference the same asset_id and must not use other versions; ②**Split referencing of the two-panel reference image**——for a single shot, if the shot size is close-up/near shot, prioritize referencing the left panel (facial close-up) as the main reference; for wide/medium shots, prioritize the right panel (full body); when both face and full body matter, reference both panels and assign them to different `{{NodeKey}}`; ③**Outfit and accessory consistency description**——each shot's prompt must restate the character's signature outfit details (colors / materials / weapon / accessories) instead of relying on model memory; cute pet characters must also restate animal features (fur color / body build) + wuxia styling to prevent cross-shot drift; ④**Consistency failure handling**——when the appearance clearly deviates from the reference image (distorted face / shifted outfit colors), first strengthen the appearance details in the prompt and regenerate; after two consecutive failures, ask the user to re-confirm whether the key_element reference image is clear.
- Duration: strictly follow the duration set for that shot in the storyboard (4–15s); if generation fails, the source falls back to Seedance 2.0 Fast; if it still fails, stop and inform the user (in this environment this maps to retrying with the same tool → informing the user on failure).

**BGM (if needed)**: `generate_audio`; the prompt must not include the names of well-known musicians.

## Editing (`composite_video`)

- **Splicing order and rhythm**: strictly splice in storyboard shot order without swapping; each shot's duration follows the storyboard, total duration aligned with the locked duration (±0.5s); fast-cut passages (fighting/conflict) use adjacent shots with no transitions or hard cuts, preserving rhythmic tension; slow-motion/climax shot junctions may add 2–4 frame cross-dissolves to soften the impact; the opening first frame fades in from black (fade-in ~8 frames), the ending last frame fades out to black (fade-out ~12 frames).
- **Seamless transitions between shots**: ① **action continuity first** — cut points must fall at natural pauses in the action arc (brief pause after a strike / moment of gaze shift), not forcibly truncated mid-action; ② **lighting and color matching** — adjacent shots in the same scene have smooth brightness/color temperature transitions, avoiding jump-cut exposure jumps; scene changes may allow mild color tone differences; ③ **sound continuity** — ambient sound (wind/street background) cross-fades (~4–8 frames) at shot changes without hard-cut truncation, maintaining sound-space continuity; ④ **forbidden**: subtitles, BGM (unless explicitly requested) — mandatory across the entire film; no text overlays or background audio tracks may be introduced from default settings.
- **Audio mixing (dB levels)**: each shot's ambient sound is kept native with no default compression; when BGM is present, BGM volume sits about 6dB below ambient sound and may be raised to a comparable level during fight climax passages; when narration (VO) is present, narration has top priority, ambient sound automatically drops below -10dB and BGM below -15dB; for segments within a shot containing dialogue, that segment's ambient sound stays native with no additional BGM layering.
- **Export**: MP4, **frame rate 24fps (to maintain film feel)**, resolution per locked value (default 720p).
- **QC output summary table** (final deliverable to the user): story type (chivalric/grudge-vengeance/loyalty per actual), total duration (XX seconds), total shot count, camera movement types (low-angle upward shots/fast cuts/slow motion/push-pan-track-follow), color style (warm yellow tending dark, red-yellow tones slightly faded, hard-light outlines), film grain ✅, fog effect usage ✅/❌, character consistency ✅, BGM (none/generated).
