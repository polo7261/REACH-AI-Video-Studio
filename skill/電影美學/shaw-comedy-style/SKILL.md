# shaw-comedy-style

做抖音快節奏邵氏港片風格喜劇短片時用本 skill。核心玩法:**萌寵/動物擬人化 + 武俠殼 + 市井喜劇核心**。使用者上傳角色參考圖(人物/萌寵/動物)、劇本或一句話靈感,生成 10–30s(預設 15s)復古港味短片。**風格致敬,不復刻具體邵氏版權作品。**

> 本環境適配:GPT Image/ImageToImage → `generate_image_v3`;Seedance/MultiModalToVideo → `generate_video_v3`;武俠 BGM/配音 → `generate_audio`;text_editor → `write_file_v2`;video_assembler → `composite_video`;`<<<image_n>>>` → `reference_nodes`+`{{NodeKey}}`。**prompt 工藝與擬人造型工藝全部內聯本 skill,不外包 image-prompt-director / cartoon-flow**。超分(1080p via MediaKit)本環境無該能力——預設 720p 交付。24fps/膠片顆粒等若基座無引數位,轉為 prompt 內描述並註明。

## 流程(分階段序列,每階段暫停確認;全程稱呼使用者"編導",階段標題用【模組名】,Markdown 表格呈現,不跳步)

0. **【全域性簡報】**(`write_file_v2` → Final_Video_Spec.md,欄位從使用者輸入推斷、不足用預設):片名(暫定或指定)/風格基調(80 年代邵氏膠片港味武俠喜劇,萌寵擬人混搭)/總時長(預設 15s,可 10–30s 或更長)/輸出解析度(720p 預設)/**畫面比例 16:9(固定不可改)**/敘事語言(中文)/**全域性硬性規則:全程無字幕、無 BGM(除非明確要求)**/角色輸入方式(參考圖上傳-人物萌寵動物/文字描述/內建角色庫,按實際填)/敘事核心(喜劇優先武俠為殼;萌寵動物保留本能行為與武俠造型形成反差)/音訊規則(預設保留環境音-市井嘈雜/刀劍/風聲等,無 BGM;配音港式普通話腔調+老麥克風顆粒感處理;使用者要求時可生成輕快武俠感 BGM)。⏸ 確認再進階段 1。
1. **【劇本大綱】**〔⏸〕:(如有素材)`analyze` 素材解析,再生成邵氏風格故事大綱——按**起承轉合**四段(起相遇/建置→承追殺/衝突→轉身世秘密/反派陰謀→合決戰/俠義傳承)+ 情緒曲線 + 建議鏡頭數(4–8,適配總時長);最佳化規則見「劇本智慧最佳化」;Markdown 表格呈現,⏸ 確認進階段 2。
2. **【分鏡設計】**(`storyboard`,見"分鏡"節):生成結構化分鏡表(key elements + shots + audio layers)。每批 4–6 鏡呈現,⏸「確認/修改/重生成」後再續,全部確認進階段 3。
3. **【元素資產】**(`generate_image_v3`,見"資產生成"節)〔⏸〕:上傳參考圖註冊 asset_id 繫結 key_element;**現代服飾先提示使用者確認風格轉換、確認後 ImageToImage 轉武俠造型**;內建俠客庫或僅文字則生成形象圖。全部就緒⏸ 告知後進階段 4。
4. **【逐鏡影片】**(`generate_video_v3`):按分鏡表逐鏡生成,小批次展示、單鏡可請求重生成;全部透過進階段 5。
5. **【音訊(如需)】**:若要求 BGM 用 `generate_audio` 生武俠感純音樂;環境音(風聲/刀劍/馬蹄)在影片生成階段隨鏡頭產出、無需單獨步驟。
6. **【剪輯合成與輸出】**(`composite_video`,見"剪輯"節):按分鏡時長順序拼接、混音、輸出,附質檢摘要表。
> 依賴:1→0;2→1;3→2;4→3;5→2;6→4,5。

## 素材解析(`analyze`)

- **人物/動物參考圖**:提取並結構化輸出供 key_element 用——面部特徵(五官/髮型/髮色/年齡感)、體型與姿態、服飾(若現代服飾標記"需轉換武俠風格")、物種(動物則提毛色/體型/神態氣質供擬人化武俠造型)、氣質關鍵詞(冷峻/熱血/神秘/威猛等)。
- **文字劇本/指令碼**:提取梗概、角色名、關鍵場景、情緒節點,輸出結構化摘要供 Planner 生成大綱。
- **一句話靈感**:識別核心人物關係(如"俠客 vs 反派")、核心衝突與情緒基調,輸出擴寫種子。
- **參考影片(如上傳)**:提取運鏡風格、色調特徵、節奏感作視覺參考基準,而非直接複製內容。

## 劇本智慧最佳化

一句話靈感 → 擴為起(相遇/建置)→承(追殺/衝突)→轉(身世秘密/反派陰謀)→合(決戰/俠義傳承);粗糙指令碼 → 最佳化對話 + 補武俠細節(劍穗/斗笠/酒壺/殘陽/客棧/竹林/破廟等);僅角色圖無文字 → 按角色視覺氣質自動設計俠義故事;未上傳任何素材 → 回覆"編導好,請至少上傳一張角色參考圖或一段文字靈感,才能開始創作。"

## 分鏡(`storyboard`)

**key elements 設計**:
- 每個主要角色建獨立 element character:外貌(面部/髮型/膚色)、武俠造型(服飾/兵器/配件:斗笠/劍穗/酒壺/披風等)、**武功氣質標籤**(如"內斂劍客,出招前總習慣壓低眼睛");動物角色補擬人化武俠服飾方案。
- 關鍵場景建 element scene:破廟/竹林/客棧/懸崖/山林等,描述光源方向(側逆光/月光/燭光)、霧效強度、地面材質。
- 重要道具(兵器/令牌等)建獨立 key_element。

**邵氏鏡頭時長結構(以 15s 為例,其他時長按比例縮放)**:開場建置 2–3s(全景或低角度仰拍,建立環境與主角);發展/衝突 6–8s(2–3 個快切打鬥/對峙鏡頭,每鏡 1–2s);高潮 3–4s(慢鏡頭關鍵動作或面部特寫);結尾收束 2s(背影遠去/刀劍入鞘/殘陽定格)。

**情緒與表演規範(全鏡通用)**:人物/萌寵情緒必須真實自然,透過微表情、肢體細節、呼吸節奏體現,非誇張或刻板;**嚴禁機械感**——動作必須有**起勢-過渡-收勢三段節奏**,避免"瞬間到位"式描寫,寫出動作過渡的流暢弧線(如"右手從腰間緩緩抬起,指尖微微顫動,才握住劍柄"而非"握劍");眼神與面部表情須有細節層次(視線方向/眼皮鬆緊/嘴角細微變化),**內心情緒拆解為可見的身體訊號**;萌寵角色擬人動作須保留動物本能慣性感(貓科出手前重心下沉、犬類耳朵豎立),動作自然可信。

**每個 shot 五要素**:
1. **景別**:全景/中景/近景/特寫。
2. **運鏡**(從以下 7 種規範選取):低角度仰拍(凸顯英雄氣概,人物出場首選) / 慢鏡頭(兵器出鞘/輕功飛掠/關鍵一擊) / 快切(打鬥節奏,每鏡 1–2s) / 推鏡頭(出場/眼神逼近) / 搖移跟拍(追逐/輕功) / 固定機位(對話/對峙/壓抑氛圍);**禁止**:手持晃動、無人機航拍、過於流暢的穩定器滑動。
3. **動作描述**:具體到肢體("右手緩緩握住劍柄,食指關節泛白"而非"拔劍")。
4. **臺詞/內心獨白**(如有):格式 (情緒描述,如"聲音低沉壓抑,像忍了很久"):"臺詞…(停頓)…臺詞。";情緒詞必須轉化為具體動作/聲音("憤怒"→"額頭青筋凸起,嗓音像砂紙磨過")。
5. **環境音**:精確到具體音效(風聲/竹葉沙沙/刀劍撞擊/馬蹄聲/滴水聲等)。

**視覺風格(每鏡必須貫徹 6 條)**:①**色調基準**暖黃偏暗復古調色為主,不追求冷暖極端分裂,對紅黃色系做輕微色彩衰減模擬老膠片褪色感;②**光影**硬光勾勒人物/萌寵輪廓,暗部偏沉亮部柔和(低飽和+強光影的港片膠片邏輯),側逆光為主、燭光月光場景適用;③**膠片顆粒**不均勻分佈,暗部更密集亮部稀疏(模擬感光度不足),強度中等可見不過噪,不磨皮不降噪;④**動態模糊**推搖鏡頭運動時加入模擬快門速度不足的動態模糊、運動邊緣輕微拖影;⑤**輕微畫面抖動**偶爾加入極輕微鏡頭抖動還原老膠片粗糙質感,不可明顯手持晃動;⑥**關鍵場景霧效**市井餐館煙氣/竹林晨霧/月夜破廟等場景必須新增輕量霧效或煙氣。

**敘事基調(與純武俠的核心區別)**:①**喜劇優先**武俠殼是包裝、喜劇核心才是爆點,衝突優先選"反差萌"——嚴肅武俠場景插入萌寵/動物日常邏輯製造荒誕落差(大俠一聲斷喝、對面貓咪只是舔爪);②**敘事節奏**抖音快節奏,前 3 秒必須建立衝突或反差,不做邵氏式慢熱鋪墊、直接入戲;③**常見喜劇場景**市井餐館爭執/街頭萌寵扮俠客/廚房食材"決戰"/掌櫃與客人互懟等港式市井喜劇,江湖恩怨作背景動機不作主表達;④**角色反差**萌寵/動物角色必須同時攜帶"武俠造型"與"動物本能行為"兩層描述,兩者衝突即產生喜劇效果。

**場景風格補充**:優先港式市井場景元素(木質雕花門窗/復古餐具/紅綢裝飾/背景食客的民國七八十年代港式穿著);搭配武俠外景時保留一處"市井細節"作喜劇錨點(如竹林裡有人賣包子)。

**audio layers**:①**預設音效**保留環境音(市井嘈雜/餐具碰撞/風聲/刀劍聲),在 shot 描述中精確定義、由影片生成階段隨鏡頭產出,無預設 BGM;②**配音風格**臺詞配音採用港式普通話腔調(咬字略帶軟糯感,聲調起伏貼合港片市井角色,尾音可輕微上揚),情緒詞拆解為具體動作/聲音;③**可選 BGM**若要求,設計 music 型別 audio_layer,描述為"80 年代港式武俠輕喜劇配樂,古箏+琵琶+輕快打擊樂,整體旋律感強,節奏輕快而非厚重,可加入輕鬆音效點綴,無現代電子元素",繫結全片時間軸;④**可選旁白(VO)**若有旁白,narration_speaker_profile(如"【港式說書腔,語速適中,帶輕微市井幽默感,偶有頓挫】")+ 逐字臺本。

## 資產生成(`generate_image_v3` / `generate_video_v3`)

**元素資產**:上傳參考圖註冊 asset_id 繫結 key_element;現代服飾圖先 `generate_image_v3`(圖生圖,源 Nano Banana Pro 2K)轉武俠造型、需使用者確認後再繫結;需生成形象圖時文生圖或圖生圖(有參考圖優先)。**角色圖一律橫向雙格參考圖**:左格面部特寫(五官/髮型/膚色/眼神),右格全身(服飾/兵器/姿態);場景圖生成全景檢視體現光源與霧效。

**逐鏡影片**(`generate_video_v3`,源 Seedance 2.0 720p):
- **參考輸入優先順序與繫結順序**:①**角色 key_element 形象圖(最高優先順序,必選)**——出現在該鏡頭的所有角色,必須將其雙格參考圖(面部特寫+全身)作首要參考繫結,確保五官/髮型/服飾/兵器跨鏡一致,多角色時每人各自繫結獨立 `{{NodeKey}}`;②**場景 key_element 圖(必選)**——繫結該鏡頭場景元素圖統一光源色溫/霧效/場景細節;③**前一鏡頭影片作 reference_video(謹慎)**——僅當與前鏡角色狀態/動作連貫性極強(慢鏡緊接特寫/同動作弧跨鏡延續)時才加,通常不加避免樣式漂移(本環境不支援影片參考則退回關鍵幀銜接)。
- **跨鏡角色一致性保障 4 規則**:①**元素圖鎖定**——階段 3 每張角色 key_element 圖一經確認即成為該角色全片外觀錨點,後續所有 shot 必須引用同一 asset_id、不得用其他版本;②**雙格參考圖拆分引用**——單鏡若景別為特寫/近景優先引用左格(面部特寫)作主參考,全景/中景優先引用右格(全身),需兼顧面部與全身時同時引用雙格分配至不同 `{{NodeKey}}`;③**服飾配件一致性描述**——每 shot 提示詞必須複述角色標誌性服飾細節(顏色/材質/兵器/配件)不依賴模型記憶,萌寵角色須同時複述動物特徵(毛色/體型)+武俠造型防跨鏡漂移;④**一致性失敗處理**——外觀與參考圖差異明顯(面部走形/服飾色偏)優先加強提示詞外觀細節後重生成,連續兩次失敗則提示使用者重新確認 key_element 參考圖是否清晰。
- 時長:嚴格按分鏡表該 shot 設定(4–15s);若生成失敗,源回退 Seedance 2.0 Fast、仍失敗則停止告知(本環境對映為同工具重試→失敗告知使用者)。

**BGM(如需)**:`generate_audio`,提示詞中不得出現知名音樂人名字。

## 提示詞寫法(全部內聯,不外包)

**最高優先順序(全域性)**:所有提示詞用中文書寫;臺詞/旁白遵循 Final_Video_Spec 語言設定(中文)。

**元素形象圖**(`generate_image_v3`):自然語言描述,結構=主體外貌+武俠服飾與配件+光線與色調+構圖與景別+質感標籤。
- **核心視覺鎖定詞、角色圖示例結構、萌寵擬人俠客描述法、場景圖寫法**全文見 `references/prompt-templates.md`。

**鏡頭影片**(`generate_video_v3`):
- **參考圖繫結**:每個角色/場景對應 `{{NodeKey}}`,提示詞開頭明確說明各佔位符指向的角色或場景。
- **提示詞結構**(按順序疊加,不分節標註):①運鏡(含是否加輕微抖動/動態模糊)→②主體動作(精確到肢體,含幅度速度;萌寵動作保留動物本能反應與武俠動作的反差)→③場景與環境(光源/煙氣/市井細節)→④音效(環境音,臺詞用 `{...}` 包裹)。
- **Seedance 音效標記規範、邵氏運鏡 7 關鍵詞逐字、情緒動作真實感 3 條、35mm 膠片質感強制詞全文、BGM prompt 全文、配音老麥克風描述**:見 `references/prompt-templates.md`(英文/固定片語原文保留)。

## 剪輯(`composite_video`)

- **拼接順序與節奏**:嚴格按分鏡表 shot 順序拼接不得調換;每 shot 時長以分鏡表為準、總時長與鎖定時長對齊(±0.5s);快切段落(打鬥/衝突)相鄰 shot 無過渡或硬切、保留節奏緊張感;慢鏡頭/高潮 shot 銜接處可加 2–4 幀疊化(cross-dissolve)柔化衝擊;開場第一幀從黑場淡入(fade-in ~8 幀),結尾最後一幀淡出至黑場(fade-out ~12 幀)。
- **分鏡間絲滑銜接**:①**動作連貫性優先**切點須落在動作弧的自然間歇處(出招後短暫停頓/視線轉移瞬間),而非動作正中強行截斷;②**光線與色調匹配**同場景相鄰 shot 亮度/色溫過渡平滑,避免跳切曝光跳變,場景切換則允許輕度色調差異;③**音效連續性**環境音(風聲/市井背景)在 shot 切換時淡入淡出交疊(~4–8 幀)不硬切截斷,保持聲音空間連續;④**禁止出現**字幕、BGM(除非明確要求)——全片強制,不得因預設設定引入任何文字覆蓋層或背景音軌。
- **音訊混合(dB 層級)**:各 shot 環境音保留原生不做預設壓縮;有 BGM 時 BGM 音量低於環境音約 6dB、打鬥高潮段可提升至相當水平;有旁白(VO)時旁白優先順序最高、環境音自動降至 -10dB 以下、BGM 降至 -15dB 以下;shot 內有臺詞(dialogue)的片段該片段環境音維持原生、不額外疊加 BGM。
- **匯出**:MP4,**幀率 24fps(維持膠片感)**,解析度按鎖定值(預設 720p)。
- **質檢輸出摘要表**(最終呈現給使用者):故事型別(俠義/恩仇/忠義按實際)、總時長(XX 秒)、總鏡頭數、運鏡型別(低角度仰拍/快切/慢鏡/推搖移跟)、色調風格(暖黃偏暗,紅黃色系輕微褪色,硬光輪廓)、膠片顆粒 ✅、霧效使用 ✅/❌、角色一致性 ✅、BGM(無/已生成)。
