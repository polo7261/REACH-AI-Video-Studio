# 國風玄幻 · 漫劇CG影片生成Skill

## 📌 一句話說明

根據使用者描述的題材方向，自動生成國風玄幻劇本、分鏡圖及漫劇CG影片。

## 📌 短劇形態（使用者可選，預設B）

| 形態 | 時長 | 特點 | 適用場景 |
|---|---|---|---|
| A. 豎屏短劇 | 15–60s | 快節奏，強衝突，高情緒點 | 短影片平台 |
| B. 橫屏敘事短片 | 60–180s | 電影質感，重氛圍，完整敘事弧線 | 漫劇／概念片 |

## 🔄 完整工作流程

## 什麼時候問你

角色資訊不完整、場景時間/天氣模糊、題材描述過於模糊無法確定方向、劇本走向需要二選一確認、動作與身份不符、多角色位置關係不清、生成結果偏差過大時。

| 階段 | 執行動作 | 需要使用者確認 |
|---|---|---|
| 1. 引導確認 | 如輸入模糊，追問5個問題鎖定方向 | ✅ 確認題材方向 |
| 2. 生成劇本 | 根據確認資訊生成完整劇本 | ✅ 確認劇情／場景／分鏡偏好 |
| 3. 生成關鍵幀分鏡圖 | 提取關鍵場景，生成分鏡圖 | ✅ 確認構圖／光影／站位 |
| 4. 生成影片 | 用分鏡圖作首幀，逐段生成 | ❌（直接執行） |
| 5. 拼接交付 | 拼接成片，附全部資產 | ✅ 交付完成 |

## 🔍 各階段詳細說明

### 階段一：題材引導確認（僅當使用者輸入模糊時觸發）

**觸發條件**：使用者只提供了靈感關鍵詞，未提供詳細角色/場景/動作描述。

**自動追問（5個問題）** ：

1. 故事基調：甜虐/宿命/熱血/遺憾/成長/對抗？
2. 核心看點：最吸引人的地方是？（如師徒禁忌、神魔反轉、前世今生）
3. 角色關係：主角之間是？（師徒/宿敵/知己/戀人/兄妹/君臣）
4. 世界觀設定：有什麼特殊設定？（如重生、靈力反噬、契約共生）
5. 結局傾向：HE / BE / 開放式？

**確認話術**：

> "收到！我幫你做一個【基調】的【題材】故事，核心看點是【看點】，主角關係為【關係】，結局傾向【HE/BE】。請確認方向是否正確？"

### 階段二：劇本生成與確認

**執行動作**：

1. 根據確認資訊生成完整劇本（含角色設定、場景描述、劇情起承轉合、運鏡建議）
2. 根據短劇形態（A或B）調整節奏和時長分配

**確認話術**：

> "劇本已生成，共【N】個場景，預計時長約【X】秒。請確認以下內容：
>
> 1. 劇情走向是否符合預期？[符合 / 需調整]
> 2. 是否需要修改或增刪某個場景？[無需 / 需調整（請說明）]
> 3. 分鏡與鏡頭偏好：[直接使用 / 增加特寫 / 增加遠景 / 增加慢鏡頭 / 其他]
> 4. 是否有其他想修改的地方？"

### 階段三：關鍵幀分鏡圖生成與確認

**執行動作**：

1. 提取劇本中【N】個關鍵場景/動作
2. 生成對應數量的關鍵幀分鏡圖
3. 疊加固定視覺風格（國風3DCG、青橙色調、丁達爾光、體積霧、PBR材質、8K畫質、淺景深）

**確認話術**：

> "分鏡圖已生成，共【N】張，對應劇本中的【N】個關鍵場景。請確認：
>
> - 構圖和人物站位是否正確？
> - 光影氛圍是否符合預期？
> - 是否需要調整某個分鏡的提示詞重新生成？"

### 階段四：影片生成與拼接

**執行動作**：

1. 用確認後的分鏡圖作為首幀/參考圖，逐段生成影片
2. 按劇本順序拼接為完整成片
3. 附完整提示詞、分鏡圖集、生成引數記錄
