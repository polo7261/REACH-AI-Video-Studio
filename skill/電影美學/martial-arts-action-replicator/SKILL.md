# 武侠基础动作复刻

## 適用場景

设计武侠题材的武打动作、武打音效或武打镜头时使用；用户提到轻功、吊威亚、wire-fu、武侠打斗、两人武打、拳拳到肉、双手剑、单手剑、独孤九剑、剑尖柔韧、剑花、云剑、绞剑、手腕画圈、武侠定格 pose 时触发。不负责画质与美术风格（由画质类 Skill 提供），也不适用于写实竞技格斗、现代动作片、仙侠玄幻。

## 輸出

四类 85 张动作卡（拳脚 18／刀剑 44／轻功 14／pose 9）的动作要领＋武打音效分层与同步规则＋镜头语言与剪辑节奏律；输出动作、镜头、音效三段，并给出与画质类 Skill 的拼接顺序。全部按真人实拍港式武侠老片处理，不出现光环、虚影、分身等仙侠元素。
