# 武俠基礎動作復刻

## 適用場景

設計武俠題材的武打動作、武打音效或武打鏡頭時使用；使用者提到輕功、吊威亞、wire-fu、武俠打鬥、兩人武打、拳拳到肉、雙手劍、單手劍、獨孤九劍、劍尖柔韌、劍花、雲劍、絞劍、手腕畫圈、武俠定格 pose 時觸發。不負責畫質與美術風格（由畫質類 Skill 提供），也不適用於寫實競技格鬥、現代動作片、仙俠玄幻。

## 輸出

四類 85 張動作卡（拳腳 18／刀劍 44／輕功 14／pose 9）的動作要領＋武打音效分層與同步規則＋鏡頭語言與剪輯節奏律；輸出動作、鏡頭、音效三段，並給出與畫質類 Skill 的拼接順序。全部按真人實拍港式武俠老片處理，不出現光環、虛影、分身等仙俠元素。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
