## 一套韦氏底质 + 一句可选主色(阶段 1 提炼,全片统一)

韦氏只有**一套渲染底质**(对称、平面、正面平打光、35mm 质感、真人写实),由场景种子锁死,保证全片一致。色板**不做固定预设**(种子已嵌入风格),而是**从剧本情绪提炼一句主色倾向**附到 MJ prompt;用户不指定就让种子原生色板说了算。

- **底质子句(用于 MJ 场景图)**:`对称的故事书式电影画面,完美居中的正中单点透视构图,像剧场布景般平面化的舞台调度,真人实拍照片级写实,精细的美术置景,正面均匀柔和的平打光,克制精调的粉彩色板,细腻的 35mm 胶片质感,精准而工整`
- **前置风格句(放 Seedance prompt 第一句)**:`对称的故事书式电影画面,完美居中的正中单点透视构图,平面化舞台调度,真人实拍照片级写实,正面均匀柔和的平打光,精调粉彩色板,细腻 35mm 胶片质感,精准工整的运镜。`

**可选一句主色倾向(从剧本情绪提炼,接在底质子句后,非强制)**:

- 暖糖喜剧:`色板偏暖——腮红粉、奶油色、黄油黄,点缀一抹正红`
- 冷调忧郁:`色板偏冷——青绿、褪色藏青、粉蓝,配奶油白`
- 秋日土系:`色板偏秋——芥末黄、赭石、暖棕、森林绿`

- 或按剧本另写一句,最多一个稍亮点缀色,其余压在协调色板里。

## 流程(逐阶段暂停确认)

### 阶段 0 · 开拍前三问(分次问,一次一个,答完再问下一个)

1. **剧本 / 文本**(主驱动):

   - **有剧本 / 文本** → 直接进阶段 1 解析成分镜与人物。
   - **无剧本** → 先问用户「能不能用**一句话**说一个想法/概念?」。拿到这句话后,**据此草拟一版短剧本**(含人物、场景、关键叙事节拍、几句对白与旁白,贴合 15–30s 短片体量),交用户确认/修改 → 确认后再进阶段 1 解析。
   - 用户连一句话也给不出时,再和其聊出一个小品概念后照上面草拟。

   > 草拟剧本后暂停确认,再继续。

2. **角色 + 造型**:① 有无人脸/角色参考(图或 &lt;15s 视频)?② 有无造型方向/造型参考图?按下面三 Case 分流。

3. **口语语言**:人物/旁白默认说**剧本本身的语言**;如需另指定则记下。

**三 Case(都先“理解造型方向 + 结合韦氏服装语言补写成完整文字 spec”,再生,不丢图照搬;之后统一:Lib Image 出正面全身造型 → 确认 → Lib Image 出白底三视图)**:

- **Case 1 有造型参考图**:造型图作 Image Reference + 补写 spec,Lib Image 出造型/三视;无人脸则三视保留脸(脸=身份)。
- **Case 2 有人脸、无造型图**:人脸图作 Image Reference + 补写 spec,Lib Image 出造型/三视;**原脸图带进 Seedance 锁脸;三视用白色圆形贴纸遮脸 + 右下角中文小字「人脸单独提供 · 此图仅用于服装造型参考」**。
- **Case 3 都没有**:追问**性别(男/女)+ 人种(亚洲/欧美/其他)**,补写 spec,Lib Image 直接生造型/三视;**所选造型像的脸即身份(三视保留脸),并作 Seedance 人脸参考**。

**韦氏服装语言(补写 spec 时对齐)**:`韦氏服装语言——复古中世纪/vintage 剪裁合身的服装,制服感的成套搭配,有个性的配饰(贝雷帽、及膝袜、字母花押、剪裁外套、圆框眼镜),年代考究的道具,精准对称的造型,配色统一在全片色板之内`;情绪档不改造型基线,只随剧本微调配色。

### 阶段 1 · 剧本解析 + Final_Video_Spec

**剧本解析(叙事主干,必出、需确认)**:

- 叙事结构:是否章节式 / 是否有**旁白(narrator)** / 叙事节拍(15s 取 1–2 拍,30s 取 2–3 拍)。
- **人物清单**:列出全部出场人物 + 各自身份/关系。
- **场景清单**:逐场景空间。
- **对白逐句**:标明说话人、原文(剧本语言)。**判断对白是否过长/繁琐**——上传剧本若台词冗长,**提炼精简为贴合 15/30s 的短促台词**(保留戏核与人物关系,删枝蔓),精简改动需向用户说明并确认。
- **情绪基调**:逐场景/逐角色情绪走向(用于阶段 4 表演赋予)。
- **一句主色倾向**:从基调提炼(见上)。

**Final_Video_Spec(让用户定)**:**画幅**(默认 **4:3 Academy**,开放 16:9 / 1:1 / 9:16)/ **质量**(480p · 720p · 1080p)/ **时长**(**15 或 30s** 二选一)。时长定段数:15→1 段、30→2 段,每段 = 一条 15s。

> 暂停确认(剧本解析结果 + spec)。

### 阶段 2 · 角色设计(Lib Image)

**一次性出齐所有角色**(不要一个角色出完确认再出下一个):对每个角色写角色卡,然后 Lib Image **把全部角色的造型图一起生出来**(每个角色一张 16:9 横构图、内含 4 套正面全身造型)→ **一次性暂停,让用户为每个角色各四选一** → **暂停确认(全部角色一起)** → 把各角色选定的造型图作为图像输入(编辑/图生图):选定正面图直接当三视正面、只补生侧/背,**全部角色的白底三视图一起出**(真人模特,**只含正/侧/背三个全身视图、不出大头照或头部特写**;有原脸→白色圆形贴纸遮脸 + 右下角中文小字「人脸单独提供 · 此图仅用于服装造型参考」、无原脸→保留脸),**脸与服装细节严格照选定图、绝不重画正脸或重设计衣服**;出图后**逐项核对脸与服装细节**(发型、款式版型、领口袖口、扣子口袋、印花、面料、鞋袜、配饰、颜色),任一处歪了就以选定图为输入重补该角色的侧/背,反复漂则该角色直接用「选定正面图 + 侧/背两张」拼三视 → **一次性再暂停确认(全部角色三视一起)**。维护 cast sheet。换装则再出“造型1/造型2”。

### 阶段 3 · MJ 场景影调图(V8.1,种子 `--sref 4926062650 --profile rhc51rh`)

按场景清单**把所有场景一起出**(不要一场出完确认再出下一场):每个场景各出 1 组 4 张对称全景空场景(空间类型 + 对称布局 + 重要物体 + 正中单点透视构图),**全景无人、零文字、真人实拍写实**,接底质子句 + 一句主色 + 场景种子尾串(见速查)。\
**全部场景图一次性出齐 → 一次性暂停,让用户为每个场景各四选一(选项须按** `1(左上)/2(右上)/3(左下)/4(右下)` **标注方位)→ 收齐所有场景的选择后才进阶段 4**,**严禁未经四选一就进阶段 4**。

> 🛑 强制门:所有场景图出齐后一次性停下,等用户逐场四选一;没收齐全部场景的选择前不得进下一阶段。

### 阶段 4 · 分镜脚本(生视频前必出、需确认)—— 重头戏

**以表格逐段逐镜输出**,每段一张表、每镜一行,列如下:

镜号画面(角色调度+表演+场景+对称构图)对白/旁白(标说话人·剧本语言)投递语气秒数运镜与上镜转场连戏要点镜1………\~Xs锁定/横轨/急摇/猛推/俯拍平铺/定格慢走硬切/急摇/match cut站位·轴线·道具·色板·节拍

字段说明:

- **投递语气**按剧本情绪赋予,不默认 deadpan。
- **秒数**每镜相加 = 15s;每段 **每 15s 镜数见下表**,标好急摇/硬切位置与定格慢走落点;转场基本不溶解。
- **连戏要点**填:角色身份-服装-手持道具 / 银幕方向-180°轴线-角色 L-R 站位-布景地理 / 同一场景种子-主色-打光方向-时辰 / 当前节拍-情绪延续 /(30s 时)seg1 尾帧→seg2 头帧的动作衔接。

> 暂停确认(造型图 + 三视图 + 场景图 + 分镜脚本表)。

### 阶段 4b · 30s 尾帧续接(逐条生的关键机制)

生完第 1 条 → 用 ffmpeg 抽**尾帧** → **解析尾帧**(角色站位/表情/光线/景别/进行中的动作)→ 按分镜声明的接缝模式生第 2 条:

- **(A) 连续动作**:尾帧作 Seedance **起始帧**,第 2 条续上动作,无缝。
- **(B) 干净硬切到新机位**:尾帧仅作连戏参考(角色/服装/色板/光线),第 2 条全新对称设置;装配处硬切/急摇/match cut 相接。

> 大的对称硬切尽量放在两条接缝处(单条 15s 内部做差异巨大的对称硬切对模型偏难)。

### 阶段 5 · Seedance 视频(每段一条 15s,一条一条生)

prompt 结构(顺序):

1. **前置风格句**(全片统一,见上)。
2. **角色组装**:白底三视图锁造型/身形 + 人脸参考锁身份(有原脸→原脸图/视频;Case 3→所选造型像);多角色喂多个参考。写明“每个角色脸取自其人脸参考、造型取自其三视图,放进场景图,保留真实长相”。
3. **分镜**:`镜1 … 切至/急摇至 镜2 …`,一条连续 15s、镜数达标;**转场以硬切/急摇/match cut 为主,基本不溶解**。每镜 = 景别(对称机位)+ 运动 + 表演(**按剧本情绪赋予**)。
4. **口语层**:逐句对白(标说话人、**口型同步**、**台词文本用剧本语言,可中可英**)+ 旁白 VO + 投递语气。例(指令用中文,台词填剧本原文):`人物开口说出台词并精准对口型,旁白画外音;台词内容:「<剧本原文台词>」`。
5. **运动**:`精准工整的运镜——锁定的对称定格、平稳的横向轨道滑轨、急摇转场、猛推猛拉变焦、俯拍平铺插入、偶尔的定格慢走`;一镜到底仅按需。
6. **音频 + 文字规则**:对白/旁白随视频生,**音乐/SFX 不生(装配铺)**:`对白与旁白在视频内开口说出,无背景音乐,无音效(后期添加)`;**出场人数严格等于剧本人物数(红线 5)**;负面 `字幕, 字幕条, 多余人物, 背景群演, 人群, 额外的人, 画面文字, 招牌文字, logo, 水印, 多余图案, 卡通, 插画, 微缩模型, 不对称, 多余手指, 畸形的手`。

**表演赋予(按剧本,不强制 deadpan)**:逐镜≥1 表情 + 1 动作,情绪强度按场景走(雀跃/焦虑/温柔/失落/克制皆可),只是包进韦氏工整外壳(对称、平稳调度)。\
**通用治僵硬(每镜都加)**:`轻微呼吸使胸口自然起伏,细微的头部移动,自然眨眼,表情随该镜情绪缓缓变化,放松自然的姿态,富有生气、有缓入缓出的自然动作`。

> 一条一条生,逐条确认。

### 阶段 5(实现备注) · 旁白兜底

旁白默认随视频生(VO 层);若模型对“无对应嘴部的 VO 旁白”支持不稳,**退回装配 VO**(TTS/录音叠加),其余规则不变。

### 阶段 6 · 装配

1. **顺接**:两段 15s **硬切 / 急摇 / match cut 顺接**(韦氏不溶解);生成片段已含对白/旁白。
2. **铺音**:统一**铺 BGM / SFX**(生成片段本就无 BGM/SFX)。
3. **加字幕(**`add_subtitle`**)**:给**角色台词**加字幕——问用户**中文 / 英文 / 双语 / 不要**,按选择把台词原文/译文做成字幕轨叠加到画面(不烧进生成帧,作为可编辑叠加层);台词文案取自阶段 1/4 已记录的对白(旁白是否上字幕随用户)。字幕**只在此步加**,SD2 生视频阶段绝不出现(见红线 3)。
4. **叠图**:logo / 标题 / credits PNG 可叠(绝不烧进生成画面)。
5. 引导导出。
