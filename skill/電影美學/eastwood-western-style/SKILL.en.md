## Standoff Space Lock (Unique Iron Rule)

For any long-range duel scene, the storyboard **must first use wide shots/OTS to establish the "Standoff Space Lock"**: Party A's position, Party B's position, the distance between the two, the directions they face, the screen left-right/depth axes, **the camera axis, the bullet direction, and the direction the hit character falls**. All subsequent ECU/CU close-ups **may only change the shot scale, never the real distance between the characters or their positions**.

## Multimodal Analysis (User Reference Materials)

- **Character full-body three-view detection**: Check whether the upload is a **full-body** three-view containing front/side/back. If yes → extract body proportions / facial contours / hairstyle / skin texture / classic costume details (poncho/felt hat/holster) / color scheme / distinctive marks (scars/stubble) for each angle, and merge them into one high-completeness description. **If it is not a three-view, or is a half-body shot/avatar → rule "format mismatch" and start reconstruction.**
- **Scene reference image detection**: Check whether it is a **people-free, multi-angle "standard four-grid"** (4 independent panels). Extract spatial layout / core architecture / representative props (bar counter/tombstone) / color tone (faded earth tones) / light and shadow (strong contrast).
- **Aesthetic fit verification (core)**: Assess whether it carries the Western's visual foundation (high-hardness contrast lighting / dusty haze / weathered materials / sense of rugged age); hard format validation (characters must be full-body three-views, scenes must be people-free four-grids). Fits → mark as directly bindable; **does not fit (style mismatch / character is not a full-body three-view / scene is not a four-grid or contains people) → rule "format/style mismatch" and devise a "Western style conversion and format reconstruction plan"** (see the fixed four-panel allocation of the four-grid below).
- **Voice analysis**: Analyze whether the voice is raspy / deep / dry / weathered, and record it in key_element_audio to keep the dubbing consistent.
- **Reference video motion analysis (three items, written into the shot description)**: ① **camera movement trajectory** (ultra-slow facial push-in Slow Zoom-in/Push-in, low-angle pan Low-angle Pan/Dolly); ② **physical motion feedback** (transient frequency of the gun-draw motion, muzzle smoke diffusion rate, amplitude of physical body tremor on impact); ③ **light/shadow texture** (Chiaroscuro ratio of strong-contrast hard light, airborne dust density).

## Element Asset Management (key_element Visual Definitions)

**Processing strategy (two paths)**:
- **Path A — user has provided reference images**: Perfect fit (character standard full-body three-view + scene people-free four-grid + matching style) → directly register and bind an asset_id. **Not a fit / format mismatch → never bind directly**; use `generate_image_v3` (ImageToImage), reconstructing with the user's uploaded image as the physical/facial reference: rebuild the character as a canonical Western full-body three-view (side-by-side front/side/back full-body standing poses, incorporating wide-brim felt hat / heavy stubble / Mexican poncho / leather holster / leather boots, while making every effort to preserve the facial identity of the original image); rebuild the scene as a people-free standard four-grid.
- **Path B — user has not provided one**: `generate_image_v3` (TextToImage), 16:9.

**Character three-view composition spec**: Mandate **side-by-side front/side/back full-body standing poses on the same canvas** (frozen face / wary gaze / stubble and hat-brim shadow / cape and poncho / hip holster / leather boots, plus the overall silhouette), showcasing 360° costume and weapon details; **half-body shots / head close-ups / overlapping figures are strictly forbidden**.

**★Five hard constraints for the three-view prompt (verified repeatedly in testing; missing any one is guaranteed to break it)**:
1. **Photorealism anchor**: `photorealistic` must appear at the start (it is not the case that "portrait"/"reference sheet" automatically equal realism — these two words are neutral and carry no bias either way).
2. **Negative exclusion of render styles**: the end must include `No illustration, no anime, no cartoon.` — this is a separate matter from **composition** constraints like "no half-body/no cropping": **composition constraints govern framing, this one governs whether the result looks like a photo or a painting**; both must be written, and neither can substitute for the other. **Lesson from testing**: in the same version of the prompt, merely swapping "illustration of" for "reference sheet of" without adding this negative exclusion still produced cartoonish results — as long as `photorealistic` + `No illustration, no anime, no cartoon` never appear, no matter how subtle the wording, it is equivalent to having no protection.
3. **Hard-locked panel count**: The total panel count must be declared explicitly (default 3: front/side/back; if a hatless/no-accessory shot is needed as a facial reference, it can be extended to 4, with panel 4 written explicitly as "hatless headshot close-up" and noted as sharing the same lighting and skin texture as the first three panels) — `Exactly N panels only, no additional close-up insets beyond the N specified below`, otherwise the model will add its own face close-up insets and squeeze the layout into a mess.
4. **Proportional alignment**: Explicitly write `same character scale and same camera distance across all views, evenly spaced with equal margins`, otherwise the three views easily end up inconsistent in size / standing height.
5. **Solid background + anti-real-face**: For the background write `flat solid neutral grey background, no gradient, no vignette` (writing just "neutral background" alone is not enough — this guards against warm tones / vignetting); prepend one sentence to the character description: `Completely original fictional face, not based on any real person or celebrity` — **in real testing we found that without this sentence, strongly associated style words like "Sergio Leone spaghetti western" will make the generated face closely resemble actual historical actors**.

Signature accessories (hat/bandana, etc.) **must be written into the character description's lock checklist and must not be omitted** — omitting them causes random "hat or no hat" inconsistency for the same character across different batches.

**Scene four-panel composition spec (four panels with fixed assignments, maximizing information density)**:
- **Top-left (Establishing Shot)**: Desolate, expansive Western panorama/buildings, dead silent and completely empty, sun-baked wooden planks warped and cracked.
- **Top-right (Props Close-up)**: Weathered wooden furniture/old guns/saloon bar; a mottled wooden sign creaking, propped up by a single rusty iron nail; a rusted hitching post covered in copper patina.
- **Bottom-left (Depth Perspective)**: Dust-filled streets/canyon trails with strong linear perspective, tumbleweeds (Tumbleweeds) rolling across dry, cracked mud ground, dust whirlwinds (Dust devils) swirling through abandoned alleys.
- **Bottom-right (Atmospheric Lighting)**: Harsh direct midday light / backlit sunset / flying dust; under the strong sunset backlight at the horizon, an orange-gold halo, drifting dust, and tattered black cloth snapping in the wind.

## Shot design, pacing, and action logic

- **Extreme stillness → extreme motion pacing**: During the standoff phase, prioritize extremely shallow depth-of-field telephoto close-ups (eyes / hovering hands / spurs), using eyeline matches (Eyeline Match) and minimal camera movement to max out the tension.
- **Declare same-frame relationships for partial close-ups**: Whenever a partial close-up simultaneously references the body parts/weapons/actions of "both parties / the two people / each other", **you must specify whether it is "same frame in one picture" or "cross-cutting"**. Hand/spur/gaze/holster close-ups in a long-distance duel default to **intercut close-ups / hard cuts**; **vague phrasings like "both men's hands" or "the two gun holsters" are banned** for describing a single close-up, unless the plot explicitly requires a close-distance same-frame composition.
- **Minimal-dialogue pause aesthetics**: Dialogue is extremely restrained (the deadliest men say the least); long speeches are forbidden; **deliberately add dashes/ellipses ...** (e.g., `{No... I don't think so...}`) to guide the voiceover model into dramatic pauses and weathered, breathy enunciation.

## Two-phase eight-shot duel blueprint (standard duel template)

When designing a showdown storyboard, structure it according to this "two-phase, eight-shot" logic and dialogue details (the dialogue templates are examples and may be fine-tuned):

**Phase 1 · Eye-lock standoff (maximum psychological tension)**
1. **Shot 1 (establishing the spatial lock, OTS)**: **135mm+ telephoto medium shots (MS/OTS)** cut back and forth between the two parties, explicitly establishing the spatial lock (the two stand at opposite ends of the main street / on either side of the depth axis, a fair distance apart, facing each other; the axis line / left-right positions / depth / orientation remain unchanged in subsequent shots); sand blowing everywhere, poncho/duster coat trembling slightly in the heat shimmer, space compressed into a suffocating stare-down.
2. **Shot 2 (eye duel ECU cross-cutting)**: **Extreme close-ups (ECU)** cut rapidly and directly between both characters' pupils/micro-expressions (Eyeline Match); these are **intercut close-ups, not same-frame** — each ECU shows only one character's partial facial features, inheriting the long-distance relationship from Shot 1.
3. **Shot 3 (coiling hands / spurs, intercut partial close-ups)**: **Not "both men's hands in the same frame"** — split into 3A/3B/3C or describe an explicit hard cut/intercut — 3A locks only on the Gunfighter's right hand / Colt gun grip / holster / bandolier (the Villain's body must not appear in frame); 3B locks only on the Villain's fingers / black holster / black boots / cast-iron spurs, the lifted heel grinding against sand with a metallic echo (the Gunfighter's body must not appear in frame); 3C alternates between 3A and 3B with high-tension hard cuts, maintaining Shot 1's spatial relationship.
   - **Standoff dialogue pause blueprint** (minimal and icy, with plenty of breath pauses `...`): Villain template `{There are two kinds of people in this world... those with loaded guns... and those who dig...}` (extremely slow, breathy, metallic rasp); Gunfighter template `{You... dig...}` (extremely dry, weathered, low nasal delivery).

**Phase 2 · The strike erupts (lightning-quick transient moments)**
4. **Shot 4 (lightning-fast quick-draw)**: **1.5s transient extreme close-up** (trimmed to 1s–1.2s in the edit); the hand plunges down instantly onto the engraved gun grip, the revolver sliding out at explosive speed.
5. **Shot 5 (muzzle-flash and gunsmoke)**: **Medium close-up, low angle (MCU)**; the trigger is pulled, orange-gold fire spits from the muzzle, thick bluish-white gunsmoke bursting alongside a thunderous 0dB gunshot.
6. **Shot 6 (bullet grazing the hat, macro slow motion)**: **Macro Close-up slow motion**; a scorching-hot bullet grazes the edge of the felt hat, the shockwave tears the wool fabric, shredded fibers fly, and the hat tilts from the impact, spins, and tumbles away.
7. **Shot 7 (hit and falls — collapse)**:**low-angle medium-wide shot MWS**;**must inherit Shot 1's spatial lock**: the person hit faces the shooter head-on, the bullet strikes the chest from the shooter's direction, and the body **topples backward along the direction of force (away from the shooter), with the back touching the ground first — it must not lunge forward toward the shooter/camera**; both knees buckle, the body falls back on physical inertia, the back slams into the sandy soil with a muffled thud, and the ground bursts open with a thick ring of dust.

8. **Shot 8 (closing silhouette — aftermath)**:**slow pull-out WS/EWS**; the gunslinger calmly and slowly slides the smoking revolver back into its holster (crisp metallic clasp sound); the blood-red dying sun hangs low, the sky deep orange and crimson, the victor's lonely silhouette stretched endlessly by the raging wind, cloak snapping in the gusts.

## Video Prompt Writing Conventions (Seedance style, fully inline)

- **Dialogue language prefix tags (primary acoustic mechanism)**: when wrapping dialogue in `{...}`, **a language prefix is mandatory** — English `{en: "verbatim dialogue line"}`, Chinese `{zh: "the exact line, word for word"}`; **omitting the prefix is strictly forbidden** (otherwise lip sync/pronunciation drifts).
- **Placeholder–description consistency**: use `{{NodeKey}}` to bind characters/scenes; the prompt describes only transient actions/micro-expressions/environmental interactions, and **must never describe appearance that contradicts the element images** (if the image shows a black hat, don't write "brown hat").
- **Three rules for multi-character on-screen physical isolation**: ① **strong entity–placeholder binding** (the placeholder immediately follows the character noun/appellation, e.g. `The weathered hero {{Node1}} and the cold-eyed outlaw {{Node2}} face each other`); ② **hard spatial separation** (write absolute left/right/depth positions, e.g. `{{Node1}} stands on the left in close-up, while {{Node2}} is positioned on the right in medium shot`); ③ **reject vague plurals** (are/they/both are banned; describe each character's action separately to achieve absolute physical isolation).
- **Inheriting spatial locks and cross-cutting structure**: when the storyboard has already declared a long-range standoff/intercut/hard cut/3A-3C, the video prompt must **faithfully preserve the structure and must not merge multiple characters' hands/holsters/spurs/eyes/body parts into the same close-up frame**; a single generation containing intercut close-ups must explicitly state `a sequence of hard-cut intercut close-ups` and declare, segment by segment, that each sub-shot shows only one character's body part; if the engine is better suited to stable single-shot output, split it into multiple shots and join them with hard cuts via `composite_video`.
- **Triple anchoring of action vectors**: for getting shot/falling/drawing a gun/charging/dodging, the action direction must be **anchored simultaneously in three relations** — the character's body direction (falls toward the back), the opponent/shooter direction (away from the shooter), and the camera/screen direction (toward background / away from camera / screen left); **avoid writing only a single relative term such as backward/forward/left/right**.
- **Prompt cross-verification (bidirectional)**: ① scene/character reference check (the prompt contains every key_element placeholder from the script); ② dialogue line check (all dialogue embedded word-for-word in `{...}` to activate lip sync, with ambient sound effects in `<...>`).
- **Four-quadrant video prevention mechanism (Grid Reference Disambiguation)**: when calling a 4-quadrant scene reference image to generate storyboard video, to **thoroughly prevent the model from producing a split image with four panels** you must: ① a **semantic deconstruction declaration** (`{{Node}} is a 4-quadrant reference sheet containing establishing shot, props, depth, and lighting.`); ② immediately followed by an **explicit single-frame shot instruction** (`Generate a single-camera shot focusing on the depth perspective of the street and the atmospheric dust from the reference sheet {{Node}}. Do not generate a split screen or 4-grid video. Single view only.`).
- **Camera movement and action stack (Camera → Action → Environment)**: write in layers — camera movement → subject motion → physical environment — precisely controlling motion amplitude (Motion Amplitude) and camera trajectory. For extreme close-ups use `135mm+ telephoto lens, extremely shallow DoF, cinematic lens blur, blurred background bokeh`; for grand scenes use `extreme wide shot (EWS), low-angle perspective`; for dynamic bursts you can invoke `whip pan`.
- **Facial close-up anti-drift mechanism (Facial ECU Control)**: when generating large close-ups of eyes/facial micro-expressions, **even if the full body is not shown, you must force-bind the character's full-body three-view sheet** as reference; the prompt explicitly points the lens at `{{Node}}`'s specific facial features and confines micro-expressions to the facial area, and **must never describe the full body/limbs/large-scale actions** (to prevent extra body composition from being stuffed in, which would stretch and distort the face); example phrasing: `135mm telephoto extreme close-up (ECU) of {{Node}}'s face, razor-sharp focus on the squinting steel-blue eyes and sun-cracked lips, micro-expression of the face, completely ignoring the rest of the body.`
- **Three-phase close-range gun-draw anti-distortion (Anti-Distortion Syntax)**: when depicting subtle finger movements/pressing/sliding out of the holster, **pass in both the character's full-body three-view sheet + the scene 4-quadrant sheet (prop/set-dressing close-up panels) as bidirectional references**; **one-sentence summary jump words are strictly forbidden** (e.g. `he draws the gun directly`); you must deconstruct the hand's physical transition (state-to-state displacement) in three phases — "hovering with coiled intent → making contact and gripping → explosive slide-out" — to give the engine a basis for smooth trajectory interpolation: ① `hovering inches above the leather holster, fingers spread wide`; ② `fingers wrapping firmly around the engraved silver grip`; ③ `sliding smoothly out of the holster with explosive velocity`.
- **Sound embedding markers**: background sounds/sound effects in `<...>` (e.g. `<wind howling, squeaking wooden saloon door>`; add `<loud gunshot echoing, metal spurs clinking>` to the gun-draw shot); minimal dialogue in `{...}` (prefix the language).
- **Negative instructions**: add `no music` (music is handled by the global track) and `no subtitles`.
- **★ Restating style anchor words item by item (patch for a flaw found in real-world testing)**: the body of **every single** storyboard video generation prompt must **restate the condensed anchor words verbatim at its end** (see the ★ production-validated version at the top of references/prompt-word-stacks.md); **you cannot rely on `{{Node}}` reference-image citations alone to carry the style implicitly**. Real-world counter-example: in one evaluation case, the image phase (character three-view sheets/scene 4-quadrant sheets) spelled out the texture words in full, but not one of the 9 video prompt bodies restated the anchor words, citing only the `{{Node}}` scene image — and the final overall style judgment came out worse than the same-topic baseline, whereas **every single one** of that baseline's 12 video prompts repeated the anchor words verbatim in the body. Welding the style into the reference images at the image phase only solves character/scene appearance consistency; **the color tone/film grain/lighting texture of every shot must be guaranteed by writing the anchor words once more in the video prompt body** — both are indispensable.

## Compositing and Editing Dynamics (video_assembler → composite_video)

- **Four-stage editing dynamics (standoff sequence)**: ① Environmental establishing shot EWS ≈**10s**; ② Two-person face-off alternating OTS/MS, each shot ≈**8s**; ③ Local extreme close-ups alternating ECU/hand-on-holster close-ups, shot frequency tightening to **4–5s**; ④ Extreme variable-frequency rapid cutting on the eve of the burst: protagonist's eyes (2s) → antagonist's eyes (2s) → protagonist's hovering finger twitching (1.5s) → antagonist's hand clamping down on the pistol grip (1.5s), with physical shot lengths decreasing exponentially to the point of absolute suffocation.
- **Burst-sequence rapid-cut montage (1s–2s)**: The engine's minimum is 4s; the generation side cannot produce ultra-short shots → **at the assembly stage, perform high-precision Trim extraction on 4s+ source clips via `composite_video`'s startPosition/endPosition**, collaged into the four-shot rapid-cut structure: ① (1.0s) close-up of the palm pressing the revolver and snapping it out at lightning speed + the 24 frames before the muzzle flash; ② (1.0–1.2s) low-angle side medium shot firing + bluish-white gun smoke bursting; ③ (1.0s) extreme close-up of the hit—pupil dilating / fabric shreds splattering / hat knocked flying off; ④ (1.5–2.0s) low-angle medium-long shot looking up as the body falls backward and dust billows up. 〔**Local speed-up 1.5–2x: composite_video has no native parameter → downgrade to editing-guidance description · adaptation rewrite; Trim uses startPosition/endPosition natively as-is**〕. After the burst, the aftermath replays in slow motion; holstering / smoke dissipating / horizon silhouette held frozen for **5s+**, settling back into desolate silence.
- **Five-track vertical stack dB level chart** (`composite_video` audioList per-track `decibel` + `videoVolume:0` to mute the video's original sound):
  1. **Track1 Ambient bed (sandstorm + wind chimes)**: Loops throughout the entire film, **-15dB to -20dB**, low-frequency physical sound-field background.
  2. **Track2 Physical foley (heavy footsteps + spurs)**: **-6dB to -10dB**, dynamically fading in and out with the characters' movement (pushed up while walking, decaying to -30dB and riding under when they stop).
  3. **Track3 Theme melody (whistle)**: **-8dB to -12dB**, with deepened reverb to create ethereal depth.
  4. **Track4 Symphonic BGM**: Riding under at **-18dB to -24dB** during the standoff silence; at the duel climax / instant burst, a sharp crescendo at **+6dB** pushes straight to **0dB** for the explosive hit.
  5. **Track5 Vocals/Narration**: **0dB to -3dB**, clarity first; while vocals are articulating, Ducking temporarily lowers the BGM and ambience by **-6dB**.
  〔dB and Ducking: composite_video supports per-track `decibel`; muting the video's original sound uses `videoVolume:0`, copied as-is; if Ducking's dynamic lowering lacks a native auto sidechain → approximate with segmented audioList dB values or mark as editing-guidance · adaptation rewrite〕.
- **Acoustic silence / ice-breaking**: 3–4s before the burst, a dramatic acoustic fade-out/cut-off — the symphonic BGM and whistle **sharply fade out to silence within the 2s before the gunshot (Fade to -inf)**, leaving only the faintest rustle of wind + a single faint tinkle of a lone wind chime; at the draw and first shot, **the gunshot SFX erupts on frame 1 as a 0dB saturated transient**, while Track4's accented brass erupts, **frame-aligned** with the instant of the gun-drawing visual to achieve "ice-breaking in an instant from utter stillness to utter motion".
- **Transition rule lock**: All primary editing uses **high-contrast seamless hard cuts (Hard Cut)** (i.e., composite_video sequential concatenation — key to the cold, hardcore 1960s Italian Western temperament); **strictly forbidden**: Dissolve / Wipe / halo flicker / 3D flips; fades to/from black (Fade to Black/in) are permitted **only for large-span spatial displacement or large-scale time jumps**, with a black-screen duration of **1.5s–2s** 〔Black-screen transition: composite_video has no native parameter → insert black-screen material for large-span switches or mark as editing-guidance · adaptation rewrite〕.
