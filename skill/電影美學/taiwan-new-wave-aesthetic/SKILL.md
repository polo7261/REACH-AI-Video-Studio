# 臺灣新浪潮（侯孝賢 × 楊德昌 × 蔡明亮）影片流水線

> 🔴 **請嚴格按該 SKILL 分步執行。** 版本 2.5.7-rc1（候選版；在 2.5.6-rc1 基礎上移植 A24 劇本撰寫模組並作新浪潮風格化適配：入口新增人聲模式、故事步補動作線/表演基調、新增"劇本撰寫·敘事節奏與對白"小節）。工具均以自然語言意圖描述（影象生成能力/影片生成能力/影片合成能力/後期剪輯能力/向使用者提問確認/讀寫檔案），由 agent 對映到實際可用工具。

## 底層 DNA（無條件，每條畫面都帶）
1. 🔴 **長鏡頭 + 固定機位**：鏡頭找個位置放著、讓事情發生，固定機位為主、極少運鏡；長鏡內靠人物走位與景深排程敘事，而非剪輯或快速運鏡。
2. **自然光 + 寫實**：自然光為主（窗光/天光/室內實用光），不打戲劇化人工光；真實自然質感、生活化、非精緻擺拍。
3. 🔴 **中遠景 + 框式構圖 + 留白**：以中遠景為主、**極少特寫**，人物與環境是不可分割的整體；門框/窗欄/走廊/隧道攝入畫面形成畫框層次與縱深；注重平衡、留白、略帶俯視的客觀凝視。
4. **低飽和褪色膠片質感**：色彩偏灰偏褪、低飽和、低對比、暗部微微提亮不死黑（lifted blacks），中畫幅般極細膩膠片顆粒（幾乎不可見）+ 高光柔暈（halation/bloom）——**絕非鮮豔數碼 HDR**。⚠️ **褪色≠髒、舊≠破**：褪色是乾淨通透的低飽和不蒙灰，舊是樸素陳舊、有人在住的體面（除蔡明亮潮溼破敗方向外），非牆皮剝落/發黴/廢棄失修；暗部微微提亮保層次、絕不死黑糊成一團；整體曝光偏亮不壓暗，冷調方向（楊/蔡）別拉過冷發青、保留一絲暖底。舊而乾淨、暗而通透、冷而不寒。
5. **場景即敘事**：環境寫實、陳舊但整潔體面（有生活痕跡但乾淨、有人在住，非破敗髒亂），承載時代感。
6. **細微環境運動讓畫面呼吸**：風讓窗簾動、光影移、煙飄、水流、雨落——主體外的細微運動讓靜止長鏡有時間感。
7. 🔴 **剋制疏離的情感（靈魂）**：含蓄壓抑不表演，情緒藏在動作快慢/停頓/視線/姿態裡，靠排程而非面部特寫。
8. 🔴 **節奏明快偏快、單鏡短、切換勤、但每鏡內容完整演完**：視覺語言（固定機位/長鏡/低飽和/框式構圖）忠於原作；節奏明快適配網路短影片、單鏡短（一個動作 3~5 秒）不拖沓，但一個動作/對話/進出/凝視要在**一個鏡頭裡完整發生、給足時長不切斷**。明快靠單鏡短/切換勤/轉場利落，**絕不靠一條塞更多內容、切碎動作加快**（那會導致畫面跳躍、動作半途消失）。鏡頭語言固定剋制。

**通用負面（每條都帶）**：`anime、CGI、卡通、3D 渲染、塑膠感皮膚、過度風格化、戲劇化人工打光、過多特寫、快速炫技運鏡、手持晃動、甩鏡、fake HDR、過飽和、鮮豔刺目色彩、數碼清晰影片感、光鮮現代感、戲劇化表演腔、僵死不動的畫面、牆皮剝落、黴斑、水漬、破敗廢棄、暗部死黑糊成一團`

## 質感尾詞（每條影象 prompt 預設帶）
`膠片拍攝、低飽和褪色色調、低飽和低對比、暗部微微提亮保層次（lifted blacks 不死黑）、中畫幅般極致細膩幾乎不可見的膠片顆粒、高光柔和 halation 光暈、自然光寫實、固定機位長鏡、中遠景觀察式極少特寫、框式構圖留白、舊而乾淨不髒、暗而通透、膚色在低飽和中仍真實鮮活有血色；不要鮮豔數碼 HDR、不要過飽和、不要牆皮剝落髮黴、不要暗部死黑`

## 流程（8 步；🔴 所有面向使用者的詢問一律用選項卡形式彈出、給可點選選項含預設項，不用開放式提問）
1. **統一入口問詢（彈選項卡）**：一個框問清九項、答完寫 memory：① 時長（單鏡≤15秒/單集30-60秒/多集數分鐘/自定義）② 執行模式（全自動/手動）③ 畫幅（**預設 16:9**，可選 4:3/16:9/21:9/自定義；解析度預設 720p）④ 導演方向（通用底/侯/楊/蔡，預設通用底）⑤ 情緒基調（沉靜剋制/輕快詼諧，預設沉靜剋制；詼諧則套第五支冷麵幽默配樂等輕快調整）⑥ 🔴 **人聲模式**（① 純氛圍·無對話無旁白 ② 純對話·只有對白 ③ 純旁白·只有畫外音、人物不出聲 ④ 對話+旁白穿插；**預設 ②**，存 `VOICE_MODE`；此項決定劇本寫不寫對白/旁白，詳見第 3 步與"劇本撰寫"小節）⑦ 對白/旁白語言（預設臺味中文，存 `DIALOGUE_LANG`；⑥選純氛圍則此項為"無語言"）⑧ 3 個核心元素（生活空間/家庭關係/日常物件）⑨ 故事梗概（有/無：有則提供遵循、無則據 3 元素生成）。moodboard 與故事生成留到第 2、3 步。
2. **風格確認（生成動作）**：據 3 元素生成 moodboard（影象生成能力，4:3，單一融合畫面鋪滿出血、禁白邊/拼貼/分格）→ 存為風格錨資產、記歸檔標記。
3. **故事（生成動作）**：有梗概遵循、僅疊加臺灣新浪潮風格化；無則據 3 元素生成（生活流/時代/家庭/剋制疏離/留白）。🔴 每場寫明可被拍到的具體生活化動作過程（含情境），非情緒心理。輸出 scene list + emotional arc + 🔴 **動作線** + 🎭 **角色表演基調**，並**遵循入口⑥選定的人聲模式**（純氛圍不寫臺詞旁白、純對話寫對白、純旁白寫旁白、穿插兩者交織；詳見下方"劇本撰寫"小節）。
   - 🔴 **動作線必填**：每場寫生活化肢體動作過程（起→中→止），可被鏡頭拍到的具體行為；動作必掛情境動機（"聽到門響而放下碗抬頭"非只"抬頭"）。
   - 🎭 **表演基調必填**：每個有戲角色定一套剋制內收的表演簽名——標誌性小動作/習慣姿態（沉默時摩挲碗沿、為難時挪開視線、等待時反覆整理衣角），貫穿全片跨鏡一致，供影片階段人物動作發揮。情緒外化靠動作快慢/停頓/視線/姿態，不靠面部特寫與表演腔。
   - 🔴 **敘事節奏對齊**：故事的 emotional arc 須與"劇本撰寫"小節的節奏正規化一致（預設沉靜剋制生活流；詼諧題材走冷麵幽默），並向下傳導到分鏡切分。
   **第 2+3 步完成後彈一張合併確認卡**（moodboard+故事一起確認：無誤進下一步/調 moodboard/調故事/都調）——透過才進第 4 步，早糾偏。
4. **資產 + 分鏡表（彈選項卡統一確認）**：先產資產——角色模卡（鎖臉）、場景參考圖（一個場景只一張大全景定場、掛 moodboard 錨、所有分鏡引用它角度靠文字取景）、道具合圖；再基於故事和資產**列完整分鏡表**（每鏡：景別+@角色動作+運鏡+環境+時長）；兩者**打包彈選項卡統一確認（確認無誤/需要調整；moodboard/故事已在前一卡確認過不重複），透過才進第 5 步**（全自動模式亦保留此門）。
5. **生成影片**：按已確認分鏡表逐條生成，掛該場景參考圖/角色圖/道具圖鎖一致性，🔴 **不掛 moodboard**。🔴 參考節點在 prompt 內一律以 **`{{node_key}}`**（雙花括號+節點實際鍵名，如 `{{Mixed 1}}`）佔位、與資產參考順序一致——框架唯一認可格式，首次提交就用它、禁〈〉/[ ]/自創格式（格式不對必然生成失敗）。
6. **音樂**：影片定稿後**彈選項卡確認方向**（列可選支+按導演/基調預選預設項）、生成 BGM（**預設 mureka 模型**）——🔴 生成好**先存著不疊**，等第 8 步決定。
7. **合成**：跨 15 秒才拆多條、序列拼成完整成片。🔴 首次合成只含影片+環境音+對白/旁白、不疊 BGM。
8. **成片後統一處理與詢問（彈選項卡）**：一個框多選：① 加字幕 ② 合成背景音樂 ③ 改音樂後再合成。關鍵約束：
   - 🔴 **字幕選項文案按語言正確寫**：中文→"加中文字幕"；**非中文→必須寫"加雙語字幕（原語言+中文）"、禁寫單語**。
   - 🔴 **執行順序強制先字幕、後音樂**（工具限制：有音樂時加字幕出問題）；改音樂則先重生成再按此序疊。
   - 🔴 **混音預設**：原聲 +8dB、BGM -2dB（使用者可改）。
   - 下掛後期剪輯工具：字幕（中文單語/非中文雙語）、轉場（預設硬切、使用者提及才加；可選淡入淡出/黑場/白場/噪點溶解）、抽幀、裁剪、文字貼片（年代片名卡/地點字幕條/人名條）。

## 畫幅與畫質（寫死）
moodboard/場景圖 4:3；人物模卡 16:9；影片預設畫幅 16:9、預設解析度 720p（可改）。影象預設 libimage 模型、2K 解析度、標準畫質（使用者可改）。

## 劇本撰寫 · 敘事節奏與對白（🔴 移植自 A24 模組並作臺灣新浪潮風格化適配）
- 🔴 **預設節奏 = 沉靜剋制 · 生活流 · 留白**：不做壓迫遞進、不給強情節鉤子；情緒藏在日常裡緩慢滲出，靠時間累積與留白而非反轉。張力來自"處境的曖昧""關係的疏離""某事懸而未說"的持續暗湧，不靠爽感、不靠懸疑解謎。結尾開放、不閉合、不給解答——生活繼續，情緒未收攏。
- **情緒優先、資訊剋制**：畫面與劇本服務內在情感而非交代資訊，觀眾常比角色晚一步理解處境（製造剋制的疏離感）；避免型別片式強鉤子與資訊交代式場景。
- 🎭 **詼諧題材（入口⑤選輕快詼諧時）**：切換為**冷麵幽默（deadpan）生活流**——一本正經的荒誕、錯位的日常，幽默來自處境與反應的反差、不靠角色搞笑或耍寶；仍守新浪潮底：剋制、留白、開放結尾、拒絕說教（配樂走第五支冷麵幽默小品）。
- ⚠️ **一片一節奏、不混用**：單片開頭即定"沉靜剋制"或"冷麵幽默"，全片統一；可有區域性驟停/對比，但主基調唯一。
- **節奏落到可執行**：敘事節奏須與故事步 emotional arc 對齊、向下傳導到分鏡切分——沉靜剋制→事件稀疏、單鏡完整凝視、切換勤但每鏡演完；冷麵幽默→靠錯位處境與剋制反應的時機製造反差。分鏡仍按內容事件切（詳見影片鐵律與剪輯節奏），節奏隻影響事件密度與凝視時長、不改"按內容切、每鏡演完"這一原則。
- 💬 **對白（人聲模式含對話，即 ②/④）**：🔴 凡兩人及以上同場、或人物有交流動機處，都要寫出實際臺詞，別隻寫動作把人物寫成啞巴；整片不能通篇無對話幹剩動作。對白量按場景定（獨處/極端剋制場景可無臺詞，靠沉默與排程）。每句臺詞標註說話人。對白文字走 `DIALOGUE_LANG`、用 {} 包裹（承影片鐵律）。（純氛圍①、純旁白③模式下不寫對白。）
- 🎭 **對白風格（臺灣新浪潮質感）**：生活化、口語、簡短，像臺灣人日常會講的話（臺味自然、少書面腔）；🔴 **留潛臺詞**——重要情緒藏在話面之下，人物常答非所問、說半句、用日常瑣事（吃了沒、天氣、家務）包裹真實心事；**反金句**：不寫總結主題的漂亮臺詞、不寫解釋自己情緒的話（"我很難過""我很寂寞"這類直白交代禁用，改用具體的日常話或沉默帶出）；剋制、有停頓、有欲言又止、有沉默。避免資訊交代式對白（把劇情用嘴說明白）。侯偏鄉土溫厚、楊偏都市知性冷靜、蔡偏極簡近乎無言——按導演方向微調語域。
- 🎙️ **旁白（人聲模式含旁白，即 ③/④）**：風格剋制、私密、像寫給自己聽或自言自語，非全知解說、非情節旁述；不復述畫面已表達的內容；語氣自然臺味、少播音腔。🔴 **旁白文字在劇本階段寫定，並統一寫進影片 prompt 時間軸**（承新浪潮影片鐵律：寫作 `畫外旁白{旁白文字}` 並緊跟"旁白是畫外音、畫麵人物不開口、口型不動"，由 seedance 原生生成，不走獨立 TTS/音軌、不留後期追加），同受 `DIALOGUE_LANG` 與 {} 包裹約束。④穿插模式：在時間軸裡給對白與旁白**分配各自時間段**，旁白只填對白到不了的內心/回望空隙、不與對白同時出聲搶戲。（純氛圍①、純對話②模式下不寫旁白。）
- 🚫 **不寫役割表/人物表**：預設不產出人物表，除非使用者明確要求。

## 人物鐵律
- **鎖質感、放身份**：低飽和褪色膠片 + 中畫幅細膩顆粒 + 自然非塑膠皮膚是硬約束；髮色/髮型/服裝/年代造型尊重使用者設定、不做臺灣新浪潮化糾偏。
- 🔴🔴 **族裔硬鎖**：預設鎖**東亞/臺灣人面孔**（East Asian/Taiwanese），模卡與鏡頭都顯式寫、負面排西方臉（不鎖則模型偏西方臉）；族裔獨立於造型、不隨髮型服裝漂移。例外：使用者明確指定非東亞角色時按使用者來。
- **皮膚例外**：整體低飽和褪色，但膚色保持真實血色、絕不拖成蠟黃/青灰/死氣。
- **模卡≠出片**：純白底 + 明亮均勻棚拍正面光（臉提亮、細節優先），絕不逆光/昏暗。版式 16:9：左三檢視（正/側/背）+ 右大面部特寫（必出、不可省、不可畫成全身）。
- 🔴 **人物圖不帶道具**：模卡只出人物本身（身形/服裝/髮型/臉），絕不揹包/拿傘書本隨身聽手機/戴非必需飾品——道具交道具合圖統一管、鏡頭再引用。貼身服裝不算道具。

- 🔴 **單條多分鏡（預設強制）**：seedance 單次最長 15 秒、原生支援單條內多分鏡+鏡間銜接，不走"一鏡一條+後期拼接"。🔴🔴 **時長-內容預算核算（寫分鏡前最先做、防塞太多切碎）**：先定總時長（≤15s），按"每個完整片段需幾秒演完"倒推這條最多放幾個片段，而非先定N鏡再硬塞。手感錨點：一個完整生活動作（推門進來/坐下點菸/端碗吃飯/遞接物）通常需 **3~5 秒**演完，單條通常 **3~5 個分鏡**（3鏡×5s/4鏡×3~4s/5鏡×3s）；每鏡仍是一段完整動作演完、不切碎——切得勤但不切碎。內容超了減片段不減單鏡時長、剩下的另起一條。單條時長 4~15 秒任意整數秒，只有跨 15 秒才拆多條序列拼接。🔴 有明確起止的完整動作（進出畫/開關門/起身/遞接物）仍給足3~5秒單獨佔一鏡完整發生，別擠一條裡被切斷（治顧客進門影子晃一下消失、鏡頭跳躍）。prompt 按秒推進、每鏡=景別（引用對應角度的場景參考圖）+@角色動作+運鏡+環境、鏡間顯式硬切。單條內多分鏡共享同一場景：🔴🔴 人物位置**一律用固定參照物錨定**（窗/門/神明桌/櫥櫃），如"媽媽靠窗側、兒子背對門、爸爸靠神明桌側"，**每鏡複述這組不變關係**；**跨鏡禁用"畫面左/右"描述人物座位**（畫面左右隨機位翻轉，seedance 會按新鏡頭字面左右重新安排座位——多人換座位的元兇）；單條內所有鏡頭預設**從同一側拍**（[整體場景與氛圍]寫一句"本條均從X側拍向Y"），不繞對面。🔴🔴 **首鏡（分鏡1）必須有主要人物在場並有動作（哪怕遠景渺小背影），絕不寫成純空鏡定場**——[整體場景與氛圍]已負責釘空間，首鏡時間軸若只寫空間不寫人，seedance 會出成沒人的空景；空鏡只放鏡間過渡或末鏡留白。每鏡預設至少一個 @角色+動作，空鏡是例外需標註意圖。🔴🔴 **在場角色全提及（治漏人/路人化/消失）**：一鏡畫面裡凡在場的人物（含背景/次要/無臺詞的）都要在該鏡 prompt 用 `@角色名` 點出+寫位置動作（位置用參照物：如"@老爸 靠神明桌側看報、@老媽 廚房門口擦手"，禁"畫面左/右"），漏提的人會被 seedance 生成成路人臉或消失；本鏡在場每個角色的模卡都掛進參考（受≤7上限時按重要性取捨）。🔴🔴 **群像全員動態**：多人鏡頭每個在場人物都必須有動作——主角主動作、其他人至少各一個生活化微動作（夾菜/擦手/翻報/點頭/搖扇），**禁任何人雕塑式僵住**（漏寫動作的人會僵直呆立）；唯一例外：使用者特殊要求靜止時按使用者來並顯式寫"刻意靜止"。
- **空間連續性**：靠 prompt 文字複述同一組空間事實（佈局/光源/人物相對位置與朝向）保持一致、換角度引用對應場景參考圖。
- **不出 BGM**：影片生成只要環境音+對白，BGM 合成階段疊加。prompt 常駐"只保留環境音與對白、無背景音樂"；負面加"背景音樂、配樂"。
- 🔴 **語言鎖**：每條影片 prompt 常駐宣告"對白/旁白一律 [DIALOGUE_LANG]，模型補話也只用此語言，禁其他語種臺詞/字幕/口型"（無論有無對白都寫），對白用 {} 包裹；負面加"其他語種臺詞、混合語言口型"。
- 🔴 **旁白統一寫入影片 prompt**：不走獨立 TTS/獨立音軌——旁白文字直接寫進時間軸、由 seedance 原生生成，寫作 `畫外旁白{旁白文字}` 並緊跟"**旁白是畫外音，畫麵人物不開口、口型不動**"（強約束防安到人物嘴上）；同受語言鎖與 {} 包裹約束，語氣自然臺味少播音腔。
- **禁溶解疊化**：鏡間硬切，負面常駐 no dissolve/cross-fade/fade。
