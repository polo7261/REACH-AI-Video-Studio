# grid-cutsheet-film

故事驅動型影片工作流:用 GPT Image 2 生成"多鏡頭拼版圖"(一張圖承載一個鏡頭內的全部內部剪輯/節拍),再用 Seedance 依據拼版驅動生成該鏡頭影片。核心機制是**剪輯索引 = 時間順序的唯一真源**——拼版上磁貼的空間排列可以任意,只有列印在每個單元格固定角落的編號(1…N)才攜帶故事順序。基於單次工作流的人機協作,在關鍵階段暫停以供使用者確認。

> 本環境適配(Flova→我方 13 工具):GPT Image 2 → `generate_image_v3`;Seedance 2.0/MultiModalToVideo → `generate_video_v3`;text_editor(Final_Video_Spec) → `write_file_v2`;video_assembler → `composite_video`;`<<<image_n>>>` 角色參考標記 → `reference_nodes` + `{{NodeKey}}`;reply_to_user 卡片式確認 → 直接向使用者彙報並暫停。解析度 2K(圖)/720p(影片)保留為預設建議;"每鏡最多 15 秒"與本環境引擎單次時長上限天然吻合,保留。
>
> **本 skill 自足內聯,不依賴任何其他 skill。**

## 7 步管線(依賴關係 + 暫停點)

1. 編寫 `Final_Video_Spec.md`(標題、型別、寬高比、時長、視覺風格、語言)→ `write_file_v2`。
2. 生成故事板(storyboard):關鍵元素 key_elements、鏡頭列表 shot_list、音訊層 audio_layers。故事板準備好後,先掃描上下文查詢使用者提供的或先前的資源(元素影象、背景音樂等),在生成前把每個已有資源繫結到匹配的故事板插槽中,避免重複生成使用者已提供的內容。
3. **元素(Elements)**:如果使用者已上傳元素資源,繫結到 `key_elements`;否則生成元素影象。
4. **生成所有鏡頭的多鏡頭參考合成圖(每個鏡頭呼叫一次)**:對每個鏡頭,寫一個影象提示詞,把該鏡頭故事板中的每個內部剪輯/節拍放置在**一張畫布**上,作為一張**多鏡頭拼版(multi-cut sheet)**(清晰的單元格邊界)。**拼版上的空間平鋪順序不定義剪輯順序**——**故事順序僅由列印的剪輯索引攜帶**(與故事板剪輯列表編號相同)。**每個單元格的寬高比須與該鏡頭 Seedance 生成鎖定的寬高比相匹配**(見 `Final_Video_Spec.md`)。
5. **生成所有鏡頭影片**:引用該鏡頭的多鏡頭合成影象生成。
6. 從故事板生成所有 audio_layers。
7. 資源準備好後進行最終組裝,引導匯出。

**依賴關係**:2→1;3→2;4→3;5→2,4;6→2;7→2,5,6。

**何時暫停**:不要一次性執行所有步驟。在規格說明之後、故事板之後、元素之後、**每批或每組多鏡頭合成圖之後**(或所有合成圖完成後)、鏡頭影片之後、以及音訊之後停止——在階段之間與使用者確認。

**注意**:使用者提供的媒體,在重新生成前先繫結;避免重複使用者已經提供的內容。

## 故事板設計

**關鍵元素設計**
- 按需包含**關鍵主體**(角色、物體)、**關鍵地點/場景**、**關鍵道具**。
- **角色**:多種外觀(服裝、年齡)須清晰描述(例如:外觀 1:…;外觀 2:…)。
- **色調/色彩參考**:如果專案使用全域性調色或參考片段,在生成時註明(參考時長保持實用,建議 ~15 秒以內以便色調提取)。
- **地點/場景**:重要物體和表演區域的放置與方向。
- **使用者提供的資源**:描述必須與參考資料**匹配**,絕不能與所見或所聽內容相矛盾。

**鏡頭設計(長鏡頭優先)**
- 優先使用**包含多個內部剪輯的長鏡頭**:用足模型**每個鏡頭的完整預算**(每個鏡頭**最多 15 秒**),在故事支援時目標每個鏡頭**至少包含六個內部剪輯**。在長鏡頭**內部**設計,剪輯節奏遵循敘事;**不要**把可以在一個長鏡頭講完的內容拆成第二個鏡頭。每個鏡頭最多 15 秒(模型硬限制)。
- **每個鏡頭描述必須包括三要素**:
  - **場景**:透過元素 ID 確定的地點(例如 `[Element_Office_Noir]`,僅為格式示例)。
  - **故事內容**:動作、動態、對話——適用時須含**準確臺詞**;透過元素 ID 引用角色。
  - **攝影**:每個節拍的鏡頭尺寸、角度、攝影機移動。
- **內部剪輯清單**:按**時間順序**列出每個節拍,分配下游各處(拼版標籤、提示詞)統一使用的**穩定剪輯索引(1…N)**。此列表是該鏡頭單張 GPT Image 2 影象的**剪輯清單**:**一個網格單元 = 一個內部剪輯**(關鍵幀/狀態)。**合成圖上拼版位置可以遵循任何佈局**;編輯器和模型依賴的是**每個單元格上書寫的索引**,而不是左右位置。

**獨立音訊設計**
- **背景音樂**:至少一條全域性音軌;較長片段可用帶 `audio_id` 和範圍的多個段落。
- **旁白**:型別選 `narration`;須定語音、語調、確切指令碼、鏡頭範圍的 `layout_instruction`。

## 元素與拼版圖生成

**元素資源生成**
- 元素影象按需用 TextToImage / ImageToImage,推薦 `generate_image_v3`、2K,便於快速迭代並與其他流水線保持一致。
- **角色**:每個角色一張橫向 16:9 角色圖,畫面中從左到右包含**半身特寫 + 全身三檢視(正、側、背)**,便於 Seedance 讀取身份和服裝資訊。

**每個鏡頭的多鏡頭參考合成圖**
- 模型 `generate_image_v3`,解析度 2K(僅在簡報或流水線明確要求時用 1K/4K)。
- **模態**:存在元素參考影象時優先 ImageToImage——傳入角色/場景參考,使網格匹配鎖定的外觀;否則用帶完整視覺細節的 TextToImage。
- **規則——一個鏡頭,一張影象,一次呼叫**:提示詞必須在一次生成中描述完整的多鏡頭拼版和每個剪輯可見的內容。
- **單元格寬高比(優先順序最高)**:每個單元格的構圖必須使其寬:高與該鏡頭規定的輸出寬高比相匹配(如 16:9、9:16、1:1——以 `Final_Video_Spec.md` 為準)。**不要**把單元格壓縮成與最終影片幾何形狀不符的極端長條;匹配比例能減少將合成圖用作參考時的重構漂移。
- **佈局**:單個畫布;N 個單元格(每個內部剪輯一張關鍵靜幀);細的中性分隔線;空間排列靈活(行、列或不規則網格)——**不要**暗示閱讀方向等於故事順序。
- **剪輯順序標記(必需)**:在**每個**單元格的**固定角落**列印**故事板剪輯索引(1…N,與剪輯清單編號相同)**。索引是時間順序的**真理來源**,拼版順序是可選的。
- **剪輯數量**:保持 N 可讀,通常一張拼版上每個鏡頭 **2–6** 個內部剪輯。若故事板節拍更多,回故事板階段**合併**微小節拍或**拆分**鏡頭——不得超過一個網格能清晰讀取的數量。
- **風格要求**:每個鏡頭的多鏡頭合成圖須嵌入 `Final_Video_Spec.md` 中定義的視覺風格(型別、外觀、調色盤、時代、參考資料),一致應用於該拼版上的**所有剪輯**。

**鏡頭影片**
- 用 `generate_video_v3`(Seedance 2.0)、720p,使用與合成圖單元格和規格說明中相同的寬高比。
- **參考**:該鏡頭的多鏡頭合成圖(節拍路線圖 + 與輸出比例對齊的各剪輯幾何形狀)。
- **標記**:影片提示詞中按 `<<<image_n>>>`(本環境用 `reference_nodes` + `{{NodeKey}}`)對每個角色標記(對應元素拼版);**合成圖是主要的靜幀參考**——**透過拼版上可見的編號剪輯索引(1…N)驅動運動**,不要猜測拼版順序。

## 提示詞工藝 A:多鏡頭參考合成圖(GPT Image 2)

**意圖**:此鏡頭 N 張關鍵靜幀的**聯絡表(contact sheet)**。每張靜幀位於一個單元格內,其寬高比與鏡頭的最終影片寬高比相匹配(例如與 Seedance 將使用的 16:9 或 9:16 相同)。該表是**佈局參考**,不宣告磁貼按位置即為時間軸順序。

**單元格幾何形狀(優先順序)**:提示詞中明確說明每個單元格都被信箱格式化或裁剪為該鏡頭的目標輸出寬高比(寫明比例,例如"每個子幀均為原生 16:9")。這比磁貼在畫布上的排列方式更重要。

**剪輯順序標記 / 故事板索引(必需)**:每個單元格須在固定角落(整個拼版採用同一慣例,例如左上角)顯示與故事板剪輯清單中相同的剪輯編號(1…N)。**編輯順序僅遵循這些數字**——磁貼的空間順序是可選的,為佈局整潔可選任意空間排列。標記須**極簡、高對比度、小巧可讀**;屬於製作後設資料,除非劇本要求,否則不作畫面內標牌。

**開頭(必需的標準模板)**:示例格式:"單張影象,一張 [N] 個分隔電影靜幀的拼版。每個靜幀的構圖均為 [目標寬高比,例如 16:9],以匹配最終影片。單元格之間有細的中性分隔線。每個單元格在 [角落] 顯示一個匹配故事板剪輯列表的小索引 [1…N]。寫實真人電影風格;角色和服裝保持一致。"(僅為整潔排列調整行列;**不要**要求從左到右作為故事順序。)

**按剪輯(按清單索引)**:對每個索引 1…N,在一個流暢的英文段落中(或清晰編號為 Cut 1/Cut 2/… 並與影象上的標籤匹配),僅描述該靜幀中**可見的內容**:主體姿勢、環境、鏡頭尺寸、角度、光線、調色、鏡頭感——與下方"6 大核心規則"對齊(以自然語言編織,不要在輸出提示詞中作為帶標籤的要點標題)。

**6 大核心規則(全域性 + 每個剪輯)**:
1. 專業風格錨點(必要時引用作者電影/參考電影)。
2. 構圖與鏡頭。
3. 強調負補光/對比度的光線。
4. 剋制的調色(除非使用者另有要求,單一主色調約 90%;除非被要求,避免陳詞濫調的霓虹洋紅/青色衝突)。
5. 渲染質量(紋理、細節)。
6. 戲劇性節拍上的情緒與微表情。

**畫面內文字**:僅在必要時把確切文案放在引號內。

## 提示詞工藝 B:影片提示詞(Seedance 2.0)

**以 `live action` 開頭**:當**主要**參考是同一多鏡頭合成影象時,影片提示詞以短語 `live action` 開頭(小寫)。它會微妙地引導 Seedance 走向更真實的光線、皮膚/物體紋理和運動——比插圖或過度的"AI 光澤"靜幀更接近真實影像。它不能替代具體的運動或攝影語言,只是在正確方向上偏向模型解釋。

**然後**:針對元素參考(`<<<image_1>>>`,…,本環境為 `{{NodeKey}}`)標記角色。對於合成圖,明確說明:**遵循故事板上列印的剪輯編號 1→2→…→N**——**不要**假設拼版位置等於時間順序。描述這些編號節拍上的時間流,對動態部分使用**攝影機 → 主體 → 空間 → 音訊**四層結構:

1. **攝影機**:移動、重構、節拍間剪輯(根據索引對齊到 cut 1, cut 2, …,而不是根據網格位置)。
2. **主體**:動作、表情、逐拍描述。
3. **空間**:環境/深度/背景運動。
4. **音訊**:對話 `{...}`,音效 `<...>`,僅在有意圖時用音樂 `(...)`;否則執行下方的靜音規則。

**多節拍 / 鏡頭 1,鏡頭 2**:可標記節拍 Cut 1, Cut 2, … 與合成圖上的列印索引匹配。**不要**依賴精確的牆上時鐘計時(例如"3.0–5.0s"),按**數字**而不是按拼版位置描述有序的節拍。

**Seedance 包裝器**:`(...)` 音樂,`<...>` 音效,`{...}` 對話(若非專案語言須標註語言),`【...】` 螢幕標題。

**負面約束(始終適用)**:
- 故事板中的獨立旁白軌道——**不要**將該旁白文字放入影片提示詞中。
- 除非鏡頭確實需要內建配樂,否則幾乎總是 `no music`。
- 始終 `no subtitles`(字幕後期新增)。
