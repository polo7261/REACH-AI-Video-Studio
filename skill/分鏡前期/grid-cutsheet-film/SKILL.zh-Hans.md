# grid-cutsheet-film

故事驱动型视频工作流:用 GPT Image 2 生成"多镜头拼版图"(一张图承载一个镜头内的全部内部剪辑/节拍),再用 Seedance 依据拼版驱动生成该镜头视频。核心机制是**剪辑索引 = 时间顺序的唯一真源**——拼版上磁贴的空间排列可以任意,只有打印在每个单元格固定角落的编号(1…N)才携带故事顺序。基于单次工作流的人机协作,在关键阶段暂停以供用户确认。

> 本环境适配(Flova→我方 13 工具):GPT Image 2 → `generate_image_v3`;Seedance 2.0/MultiModalToVideo → `generate_video_v3`;text_editor(Final_Video_Spec) → `write_file_v2`;video_assembler → `composite_video`;`<<<image_n>>>` 角色参考标记 → `reference_nodes` + `{{NodeKey}}`;reply_to_user 卡片式确认 → 直接向用户汇报并暂停。分辨率 2K(图)/720p(视频)保留为默认建议;"每镜最多 15 秒"与本环境引擎单次时长上限天然吻合,保留。
>
> **本 skill 自足内联,不依赖任何其他 skill。**

## 7 步管线(依赖关系 + 暂停点)

1. 编写 `Final_Video_Spec.md`(标题、类型、宽高比、时长、视觉风格、语言)→ `write_file_v2`。
2. 生成故事板(storyboard):关键元素 key_elements、镜头列表 shot_list、音频层 audio_layers。故事板准备好后,先扫描上下文查找用户提供的或先前的资源(元素图像、背景音乐等),在生成前把每个已有资源绑定到匹配的故事板插槽中,避免重复生成用户已提供的内容。
3. **元素(Elements)**:如果用户已上传元素资源,绑定到 `key_elements`;否则生成元素图像。
4. **生成所有镜头的多镜头参考合成图(每个镜头调用一次)**:对每个镜头,写一个图像提示词,把该镜头故事板中的每个内部剪辑/节拍放置在**一张画布**上,作为一张**多镜头拼版(multi-cut sheet)**(清晰的单元格边界)。**拼版上的空间平铺顺序不定义剪辑顺序**——**故事顺序仅由打印的剪辑索引携带**(与故事板剪辑列表编号相同)。**每个单元格的宽高比须与该镜头 Seedance 生成锁定的宽高比相匹配**(见 `Final_Video_Spec.md`)。
5. **生成所有镜头视频**:引用该镜头的多镜头合成图像生成。
6. 从故事板生成所有 audio_layers。
7. 资源准备好后进行最终组装,引导导出。

**依赖关系**:2→1;3→2;4→3;5→2,4;6→2;7→2,5,6。

**何时暂停**:不要一次性运行所有步骤。在规格说明之后、故事板之后、元素之后、**每批或每组多镜头合成图之后**(或所有合成图完成后)、镜头视频之后、以及音频之后停止——在阶段之间与用户确认。

**注意**:用户提供的媒体,在重新生成前先绑定;避免重复用户已经提供的内容。

## 故事板设计

**关键元素设计**
- 按需包含**关键主体**(角色、物体)、**关键地点/场景**、**关键道具**。
- **角色**:多种外观(服装、年龄)须清晰描述(例如:外观 1:…;外观 2:…)。
- **色调/色彩参考**:如果项目使用全局调色或参考片段,在生成时注明(参考时长保持实用,建议 ~15 秒以内以便色调提取)。
- **地点/场景**:重要物体和表演区域的放置与方向。
- **用户提供的资源**:描述必须与参考资料**匹配**,绝不能与所见或所听内容相矛盾。

**镜头设计(长镜头优先)**
- 优先使用**包含多个内部剪辑的长镜头**:用足模型**每个镜头的完整预算**(每个镜头**最多 15 秒**),在故事支持时目标每个镜头**至少包含六个内部剪辑**。在长镜头**内部**设计,剪辑节奏遵循叙事;**不要**把可以在一个长镜头讲完的内容拆成第二个镜头。每个镜头最多 15 秒(模型硬限制)。
- **每个镜头描述必须包括三要素**:
  - **场景**:通过元素 ID 确定的地点(例如 `[Element_Office_Noir]`,仅为格式示例)。
  - **故事内容**:动作、动态、对话——适用时须含**准确台词**;通过元素 ID 引用角色。
  - **摄影**:每个节拍的镜头尺寸、角度、摄影机移动。
- **内部剪辑清单**:按**时间顺序**列出每个节拍,分配下游各处(拼版标签、提示词)统一使用的**稳定剪辑索引(1…N)**。此列表是该镜头单张 GPT Image 2 图像的**剪辑清单**:**一个网格单元 = 一个内部剪辑**(关键帧/状态)。**合成图上拼版位置可以遵循任何布局**;编辑器和模型依赖的是**每个单元格上书写的索引**,而不是左右位置。

**独立音频设计**
- **背景音乐**:至少一条全局音轨;较长片段可用带 `audio_id` 和范围的多个段落。
- **旁白**:类型选 `narration`;须定语音、语调、确切脚本、镜头范围的 `layout_instruction`。

## 元素与拼版图生成

**元素资源生成**
- 元素图像按需用 TextToImage / ImageToImage,推荐 `generate_image_v3`、2K,便于快速迭代并与其他流水线保持一致。
- **角色**:每个角色一张横向 16:9 角色图,画面中从左到右包含**半身特写 + 全身三视图(正、侧、背)**,便于 Seedance 读取身份和服装信息。

**每个镜头的多镜头参考合成图**
- 模型 `generate_image_v3`,分辨率 2K(仅在简报或流水线明确要求时用 1K/4K)。
- **模态**:存在元素参考图像时优先 ImageToImage——传入角色/场景参考,使网格匹配锁定的外观;否则用带完整视觉细节的 TextToImage。
- **规则——一个镜头,一张图像,一次调用**:提示词必须在一次生成中描述完整的多镜头拼版和每个剪辑可见的内容。
- **单元格宽高比(优先级最高)**:每个单元格的构图必须使其宽:高与该镜头规定的输出宽高比相匹配(如 16:9、9:16、1:1——以 `Final_Video_Spec.md` 为准)。**不要**把单元格压缩成与最终视频几何形状不符的极端长条;匹配比例能减少将合成图用作参考时的重构漂移。
- **布局**:单个画布;N 个单元格(每个内部剪辑一张关键静帧);细的中性分隔线;空间排列灵活(行、列或不规则网格)——**不要**暗示阅读方向等于故事顺序。
- **剪辑顺序标记(必需)**:在**每个**单元格的**固定角落**打印**故事板剪辑索引(1…N,与剪辑清单编号相同)**。索引是时间顺序的**真理来源**,拼版顺序是可选的。
- **剪辑数量**:保持 N 可读,通常一张拼版上每个镜头 **2–6** 个内部剪辑。若故事板节拍更多,回故事板阶段**合并**微小节拍或**拆分**镜头——不得超过一个网格能清晰读取的数量。
- **风格要求**:每个镜头的多镜头合成图须嵌入 `Final_Video_Spec.md` 中定义的视觉风格(类型、外观、调色板、时代、参考资料),一致应用于该拼版上的**所有剪辑**。

**镜头视频**
- 用 `generate_video_v3`(Seedance 2.0)、720p,使用与合成图单元格和规格说明中相同的宽高比。
- **参考**:该镜头的多镜头合成图(节拍路线图 + 与输出比例对齐的各剪辑几何形状)。
- **标记**:视频提示词中按 `<<<image_n>>>`(本环境用 `reference_nodes` + `{{NodeKey}}`)对每个角色标记(对应元素拼版);**合成图是主要的静帧参考**——**通过拼版上可见的编号剪辑索引(1…N)驱动运动**,不要猜测拼版顺序。

## 提示词工艺 A:多镜头参考合成图(GPT Image 2)

**意图**:此镜头 N 张关键静帧的**联系表(contact sheet)**。每张静帧位于一个单元格内,其宽高比与镜头的最终视频宽高比相匹配(例如与 Seedance 将使用的 16:9 或 9:16 相同)。该表是**布局参考**,不声明磁贴按位置即为时间轴顺序。

**单元格几何形状(优先级)**:提示词中明确说明每个单元格都被信箱格式化或裁剪为该镜头的目标输出宽高比(写明比例,例如"每个子帧均为原生 16:9")。这比磁贴在画布上的排列方式更重要。

**剪辑顺序标记 / 故事板索引(必需)**:每个单元格须在固定角落(整个拼版采用同一惯例,例如左上角)显示与故事板剪辑清单中相同的剪辑编号(1…N)。**编辑顺序仅遵循这些数字**——磁贴的空间顺序是可选的,为布局整洁可选任意空间排列。标记须**极简、高对比度、小巧可读**;属于制作元数据,除非剧本要求,否则不作画面内标牌。

**开头(必需的标准模板)**:示例格式:"单张图像,一张 [N] 个分隔电影静帧的拼版。每个静帧的构图均为 [目标宽高比,例如 16:9],以匹配最终视频。单元格之间有细的中性分隔线。每个单元格在 [角落] 显示一个匹配故事板剪辑列表的小索引 [1…N]。写实真人电影风格;角色和服装保持一致。"(仅为整洁排列调整行列;**不要**要求从左到右作为故事顺序。)

**按剪辑(按清单索引)**:对每个索引 1…N,在一个流畅的英文段落中(或清晰编号为 Cut 1/Cut 2/… 并与图像上的标签匹配),仅描述该静帧中**可见的内容**:主体姿势、环境、镜头尺寸、角度、光线、调色、镜头感——与下方"6 大核心规则"对齐(以自然语言编织,不要在输出提示词中作为带标签的要点标题)。

**6 大核心规则(全局 + 每个剪辑)**:
1. 专业风格锚点(必要时引用作者电影/参考电影)。
2. 构图与镜头。
3. 强调负补光/对比度的光线。
4. 克制的调色(除非用户另有要求,单一主色调约 90%;除非被要求,避免陈词滥调的霓虹洋红/青色冲突)。
5. 渲染质量(纹理、细节)。
6. 戏剧性节拍上的情绪与微表情。

**画面内文字**:仅在必要时把确切文案放在引号内。

## 提示词工艺 B:视频提示词(Seedance 2.0)

**以 `live action` 开头**:当**主要**参考是同一多镜头合成图像时,视频提示词以短语 `live action` 开头(小写)。它会微妙地引导 Seedance 走向更真实的光线、皮肤/物体纹理和运动——比插图或过度的"AI 光泽"静帧更接近真实影像。它不能替代具体的运动或摄影语言,只是在正确方向上偏向模型解释。

**然后**:针对元素参考(`<<<image_1>>>`,…,本环境为 `{{NodeKey}}`)标记角色。对于合成图,明确说明:**遵循故事板上打印的剪辑编号 1→2→…→N**——**不要**假设拼版位置等于时间顺序。描述这些编号节拍上的时间流,对动态部分使用**摄影机 → 主体 → 空间 → 音频**四层结构:

1. **摄影机**:移动、重构、节拍间剪辑(根据索引对齐到 cut 1, cut 2, …,而不是根据网格位置)。
2. **主体**:动作、表情、逐拍描述。
3. **空间**:环境/深度/背景运动。
4. **音频**:对话 `{...}`,音效 `<...>`,仅在有意图时用音乐 `(...)`;否则执行下方的静音规则。

**多节拍 / 镜头 1,镜头 2**:可标记节拍 Cut 1, Cut 2, … 与合成图上的打印索引匹配。**不要**依赖精确的墙上时钟计时(例如"3.0–5.0s"),按**数字**而不是按拼版位置描述有序的节拍。

**Seedance 包装器**:`(...)` 音乐,`<...>` 音效,`{...}` 对话(若非项目语言须标注语言),`【...】` 屏幕标题。

**负面约束(始终适用)**:
- 故事板中的独立旁白轨道——**不要**将该旁白文本放入视频提示词中。
- 除非镜头确实需要内置配乐,否则几乎总是 `no music`。
- 始终 `no subtitles`(字幕后期添加)。
