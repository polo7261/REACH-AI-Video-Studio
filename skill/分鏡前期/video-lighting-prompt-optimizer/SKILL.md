# AI 影片光影提示詞

把光寫成可執行的現場關係。優先交代光源、位置、受光表面、衰減與時間狀態，少用無法驗證的審美標籤。

## 按任務選擇工作方式

- 使用者提供場景想法時，從零設計光線模組。
- 使用者提供完整影片提示詞時，保留劇情、動作、角色和鏡頭，只重寫或補充光影相關內容。
- 使用者提供已有光影提示詞時，先診斷物理衝突和影片連續性，再給修訂版。
- 使用者要求某類常見光線時，讀取 references/lighting-presets.md，只載入相關類別。
- 使用者需要完整模板、前後對比或多鏡頭案例時，讀取 references/prompt-patterns.md。

如果關鍵資訊不足，先從場景裡的可見光源做保守推斷。只有光源身份或劇情效果存在兩種明顯不同的選擇時才詢問使用者。

## 建立光線設計

### 1. 讀取場景

提取以下資訊。

- 時間、天氣、室內外環境與可見光源
- 主體位置、朝向、動作路線和關鍵道具
- 景別、機位、鏡頭運動與剪輯方式
- 需要突出的臉、手、產品、武器或環境區域
- 情緒變化、劇情轉折與光線是否參與敘事
- 鏡頭數量、持續時間和必須保持不變的狀態

不要把使用者沒有提供的角色經歷或劇情動機寫成事實。

### 2. 建立光源層級

優先使用一套簡單且能解釋的層級。

1. 選擇環境光或主光，負責主體與空間的基礎曝光。
2. 需要時加入微弱補光，負責暗部結構與眼神光。
3. 只有主體需要分離或場景有明確實景燈時，再加入輪廓光、強調光或道具光。

預設控制在一至兩個主要光源，加一層剋制補光。每增加一束光，都要說明它來自哪裡並承擔什麼工作。

### 3. 為每個光源寫八個屬性

按場景需要寫清以下內容。

1. 身份，例如陰天天光、窗光、路燈、燭火、晶體內光。
2. 位置，例如左前方四十五度、右後方、正上方、胸前偏下。
3. 色彩，例如冷灰、藍白、暖金、橙紅或中性白。
4. 質地，例如大面積柔光、窄束硬光、漫射環境光。
5. 強弱關係，例如環境光佔主導、道具光只做局部強調。
6. 受光表面，例如左眼、鼻樑一側、髮絲、肩線、指尖或瓶身邊緣。
7. 衰減範圍，例如隻影響五到十釐米，超過範圍迅速變暗。
8. 時間狀態，例如恆定、輕微火焰跳動、車輛掠過或逐漸熄滅。

不要機械湊齊八項。對於不會改變結果的屬性直接省略。

### 4. 區分位置、功能與質地

這些術語可以組合，避免把它們當成互斥風格。

- 側逆光描述光源位置。
- 輪廓光描述主體邊緣得到的結果。
- 主光、補光和環境光描述光源功能。
- 硬光與柔光描述陰影邊緣和光源面積。
- 近身道具光描述光源身份與距離。

例如側後方的窄束硬光可以同時作為主光，並在人物一側產生輪廓光。

### 5. 把光對應到表面

用可見結果替代抽象詞。

- 寫清先照到哪一側臉、哪幾縷頭髮和哪一塊衣料。
- 指定暗區保留哪些結構，避免用籠統的暗部有細節結束。
- 根據玻璃、金屬、皮膚、溼地、雪、煙霧和織物寫出不同反射。
- 讓影子方向與光源方向相反。
- 讓近身小光源快速衰減，禁止無理由照亮遠景。
- 只有空氣中存在霧、煙、雨、雪或塵埃時，才讓光束變得可見。

## 處理影片時間與連續性

單張圖只需交代當前受光關係。影片還要鎖定光線狀態隨時間怎樣變化。

### 固定不變數

跨鏡頭鎖定以下專案。

- 環境光方向、色溫和相對亮度
- 實景燈或發光道具的顏色、強度與作用半徑
- 陰影方向與主要反射面
- 曝光基準和白平衡傾向
- 閃爍、跳動或漸變的節奏

### 描述合法變化

物體或人物移動時，重新指定最近的受光表面。光源被遮擋時，讓對應區域變暗。光源進入或離開畫面時，交代亮區怎樣轉移。除非劇情明確要求，禁止自動曝光抽動、白平衡漂移和無來源亮度跳變。

多鏡頭場景為每個鏡頭寫一行光線狀態，並把全域不變數單列為連續性模組。

## 控制情緒

先用物理關係建立畫面，再用色溫、光比和方向調整情緒。

- 溫暖、親密或懷舊可用暖色近身柔光和中低光比。
- 冷靜、孤獨或懸疑可用冷色側光、負空間與較高光比。
- 壓迫、審問或危險可用窄束硬光、頂部光或低位光。
- 神聖、浪漫或人物高光可用暖色側逆光與剋制體積光。

情緒詞只能收尾，不能替代光源說明。

## 輸出提示詞

預設按以下順序輸出。

1. 一句光影意圖，說明觀眾先看到什麼。
2. 可直接貼上的 `【光線佈置】` 模組。
3. 多鏡頭時增加 `【光線連續性】` 模組。
4. 只列會防止高機率失敗的限制詞。

使用者只要求提示詞時，不額外解釋。使用者要求分析時，先指出問題與原因，再給修訂版。

提示詞優先採用中文。使用者指定英文或特定影片模型時，再保持相同物理關係改寫語言與格式，不虛構模型不存在的控制引數。

## 品質檢查

交付前逐項檢查。

- 觀眾能否判斷每束主要光來自哪裡。
- 光源位置、亮區和陰影方向是否互相支援。
- 主體、背景和道具是否有清楚的曝光層級。
- 暗部是否保留必要結構，高光是否避免純白溢位。
- 小型發光物的照射範圍是否符合尺寸與距離。
- 輪廓光是否只出現在朝向光源的合理邊緣。
- 霧、煙、雨和雪是否只在有光經過時產生可見響應。
- 多鏡頭中的方向、色溫、強度、半徑和閃爍規律是否連續。
- 人物移動以後，亮區是否跟隨光源與遮擋關係變化。
- 是否刪除了衝突的光源、無意義的攝影師姓名和重複畫質詞。

發現衝突時，保留對劇情和主體最重要的光源，刪掉其餘裝飾光。
