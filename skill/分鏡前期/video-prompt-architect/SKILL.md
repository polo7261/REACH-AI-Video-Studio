# 小杰AIGC｜视频提示词

## 適用場景

适合4—30秒的人物叙事、角色短片、产品展示和创意镜头。只有一句想法时帮助构思；有人物图、场景图、道具图或参考视频时分析素材用途；已有脚本或精确分镜时，保留核心故事、顺序和秒点，补齐动作、运镜、转场、光影与音效。

## 輸出

一份总时长4—30秒、可直接复制的视频提示词，包含基础设定与画质参数、场景与角色光影设定、按秒展开的镜头动作与音效、核心强调与物理约束，并说明实际素材的参考职责。默认无BGM；用户要求音乐、对白或字幕时可调整。最终产物是提示词，不自动提交视频生成；单次时长与音频能力以目标平台为准。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
