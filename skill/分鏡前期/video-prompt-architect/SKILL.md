# 小杰AIGC｜影片提示詞

## 適用場景

適合4—30秒的人物敘事、角色短片、產品展示和創意鏡頭。只有一句想法時幫助構思；有人物圖、場景圖、道具圖或參考影片時分析素材用途；已有腳本或精確分鏡時，保留核心故事、順序和秒點，補齊動作、運鏡、轉場、光影與音效。

## 輸出

一份總時長4—30秒、可直接複製的影片提示詞，包含基礎設定與畫質參數、場景與角色光影設定、按秒展開的鏡頭動作與音效、核心強調與物理約束，並說明實際素材的參考職責。預設無BGM；使用者要求音樂、對白或字幕時可調整。最終產物是提示詞，不自動提交影片生成；單次時長與音訊能力以目標平台為準。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
