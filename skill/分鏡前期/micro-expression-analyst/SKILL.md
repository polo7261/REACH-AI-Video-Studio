# micro-expression-control

要精細控制角色**表情、微表情、情緒轉換**時用本 skill 寫 `generate_video_v3` 的視覺內容描述。**核心原則與 cinematic-motion-realism 一致但更專：情緒不能靠抽象詞表達，只能靠可執行的面部/身體動作表達。** 模型不懂"感人""心碎""喜悅"，只懂"眼角下垂""嘴角單側抽動""睫毛顫抖"。

## 邊界（何時用本 skill vs 相關 skill）

- 全身姿態/環境力/整體寫實 → cinematic-motion-realism（其"情緒剋制"支柱是本 skill 的精簡版，本 skill 是展開專項）。
- Seedance 分鏡敘事整體方案 → seedance-cinematic-drama（其"生理細節硬門檻"引用本 skill 的對映表）。
- 口播指令碼節奏/臺詞/teleprompter → talking-head-director；**本 skill 只管臺詞說出口時臉上發生什麼，不管寫什麼臺詞**。
- 多鏡同一張臉不漂移 → character-consistency；**本 skill 管表情本身，不管臉型/五官一致性**；但本 skill 的"表情錨點集"（見下）是對該 skill 姿態變化集的擴充套件。

## 兩層寫法：中文動作庫（預設主用） vs FACS/AU 編碼（進階精控）

| 層 | 怎麼寫 | 何時用 |
|---|---|---|
| **中文情緒→動作庫**（預設，直接可用） | 用本 skill 下方按情緒歸類的中文微表情短句，直接拼進敘事 prompt | 絕大多數場景的預設選擇——地道、可直接理解、不依賴引擎認不認編碼 |
| **FACS/AU 編碼**（進階，社群實測有效但非官方承諾） | 把動作單元編號寫進 prompt，如 `AU12+AU6`，用於需要精確排多個節拍或中文描述總被忽略某細節時 | 獨白多節拍排程、跨模型/跨引擎遷移需要一套通用編號體系時 |

兩層不互斥，可以同一賬號內 A/B 測試哪種在 `generate_video_v3` 上命中率更高。**日常寫 prompt 優先用中文動作庫，FACS/AU 是備用武器，不是必須。**

## 情緒→微表情動作庫（核心，按情緒歸類）

每條是可直接拼進 prompt 的中文短句正規化，不是要全部塞進一鏡——**一鏡按下面"剋制自檢"控制在 1–2 個關鍵動作**，下面每個情緒列出的多條是同義/遞進選項，按場景挑，不是全寫。

| 猶豫 | 張嘴又閉、視線遊移、手懸在半空、腳下踱步 | 「他張嘴又閉上，視線遊移不定，手懸在半空遲遲沒有落下」 |
| 驚喜 | 眼睛瞬間睜大、嘴張成O形、雙手捂嘴、笑容緩慢綻放（不是瞬間） | 「她的眼睛瞬間睜大，嘴巴微張成O形，雙手下意識捂住嘴，笑容緩慢地在臉上綻放開」 |

## 長鏡頭單表情演化時間線（表演是內容本身時用）

當整鏡的內容就是"一張臉的表演"（獨白、靜默特寫、情緒轉折的高潮鏡），別寫成一句靜態描述，改用**分時間段的演化模板**，讓表情自然過渡而不是突然跳變：
```

0–2s：\[起始狀態，通常是平靜或未察覺\] 2–4s：\[情緒開始的最初訊號，極輕微\] 4–6s：\[情緒明顯但仍剋制，加 1–2 個細節\] 6–8s：\[情緒穩定在某個狀態，可加一個身體反應如淚痕/呼吸\]

```

範例（隱忍難過）：「0-2s：人物保持平靜的表情，眼神輕輕低垂，嘴唇自然放鬆。2-4s：情緒開始輕微變化，嘴唇慢慢輕輕抿住，嘴角開始一點點下壓，眼神變得失落。4-6s：難過逐漸明顯但仍然剋制，眉頭輕輕皺起，眼神帶著委屈和隱忍，眼眶微微溼潤。6-8s：人物穩定在隱忍難過的表情中，臉頰出現一兩滴細小自然的淚痕，沒有大哭，沒有抽泣，情緒安靜剋制。」全程要求**自然過渡、沒有突然變化、沒有誇張哭泣**——這是本模板的核心約束，比具體用哪幾個動作更重要。

同一結構可換情緒骨架複用：震驚定格（放鬆臉→笑容停住→眼神失焦→呼吸停→下頜鎖住）；愧疚（視線躲→眨眼變慢→嘴角收緊→眉心內折→低頭）；壓抑的憤怒（目光靜→鼻翼扇動→下頜繃緊→手指收緊→眼睛溼潤但不眨）。**用這個鏡頭時保持運鏡極簡**：固定或極慢推，淺景深，別在表情特寫里加複雜運鏡或多餘肢體動作分散焦點。

## 微表情的時間尺度（不同顆粒度對應不同寫法，別混用）

- **一閃而過的洩露（0.25–0.5秒）**：鼻息、下頜繃緊、眼神一瞥、笑容抽動——用於"話沒說但臉先說了"的瞬間訊號，寫"極快閃過隨即恢復/被蓋住"。
- **可讀的過渡動作（0.5–1秒）**：視線改變、眨眼停頓、淚水成形、嘴角收緊——正常一次情緒轉折的過渡顆粒度。
- **完整情緒轉換（1–1.5秒）**：一個表情徹底換成另一個，如笑容徹底褪去、強裝鎮定崩塌。
- **複合式表情疊變（1.5–2秒）**：兩層情緒的轉換，如溫情變算計、微笑變陰冷——需要給夠時間讓"面具切換"這件事本身被看清。

**始終保持自然過渡，不要突然的表情跳躍，除非劇情就是要"猛然變臉"這個衝擊點本身。**

## 情緒混合與潛臺詞洩露（比單一情緒更高階的寫法）

真正有戲劇張力的表演往往不是單一情緒，而是**兩種情緒在同一張臉上同時存在、互相打架**——嘴在演一種情緒，眼睛在洩露另一種，或身體姿態在反駁臺詞的字面意思。寫法：把兩種情緒各自的動作都列出來，讓"矛盾"本身成為要傳達的內容，不要試圖把它們調和成一個"中間情緒"：

- **強撐的溫暖**：嘴角上揚帶笑意 + 眼周繃緊、瞳孔不放鬆（恐懼/緊張的動作）同時出現——觀眾讀出"這個笑是撐出來的"。
- **口是心非的軟拒絕**：臺詞是拒絕的話，但視線躲開又偷偷看回、身體沒有真的後退、笑意壓在嘴角洩出——整體傳達"嘴上拒絕、心裡已經軟了"，不是真正的反感。**這類反差表演強度建議控制在剋制區間（十分打三分左右），避免讀成真的抗拒/恐懼。**
- **審視變冷冷瞭然**：笑意從眼底一點點抽走，眼神變陰，嘴角原本上揚的弧度慢慢拉平甚至反向——本性從和善表演裡"剝離"出來的效果，別一步到位，要給"抽走"這個過程時間。

這是"真笑假笑判定"（下一節）的進階版：不是先一種情緒後另一種，而是**兩種情緒同時疊在一張臉上，或一層表情下慢慢露出另一層**。適合表現"言不由衷""死撐""圖謀不軌的偽裝"類潛臺詞場景。

## 真笑 vs 假笑：判定示範（可套用到其他情緒）

真笑必然帶眼周參與（臉頰被笑意托起、眼角浮現細紋）；只有嘴角上揚、眼周不動 = 禮貌笑/敷衍笑/假笑。眼周肌肉幾乎無法被意識控制，這是判定"演得真不真"最硬的一條線，也是所有其他情緒判定的示範模板——**任何情緒都要問：眼睛有沒有參與，不只是嘴或眉毛在動。** 只寫嘴部動作的表情，是 AI 生成裡最常見的"假臉感"來源。

## FACS/AU 編碼（進階精控層，獨白多節拍/需要編號體系時用）

想更精確地按"肌肉單元"排多節拍表情，或中文描述總被引擎忽略某個細節時，換成 FACS（面部動作編碼系統）的 AU 編號。AU 對應哪塊肌肉是穩定科學事實；但"把編號直接寫進 prompt 文字能生效"是社群實測結論，非引擎官方承諾，不要向使用者保證"寫了編號就精確"。

| 情緒 | 核心 AU 組合 |
|---|---|
| 真心笑（Duchenne） | AU6（臉頰提升）+ AU12（嘴角上提） |
| 禮貌假笑 | 僅 AU12，無 AU6 |
| 悲傷 | AU1（內眉上揚）+ AU4（眉頭壓低）+ AU15（嘴角下壓） |
| 憤怒 | AU4+AU5+AU7+AU23（眉壓低+眼瞼收緊+嘴唇收緊） |
| 驚訝 | AU1+AU2+AU5+AU26（雙眉上揚+眼瞼全開+下頜松落） |
| 恐懼 | AU1+AU2+AU4+AU5+AU7+AU20 | 
| 厭惡 | AU9+AU15+AU16（鼻樑皺+嘴角下壓+下唇後壓） |
| 輕蔑（唯一單側通用表情） | AU12+AU14，僅單側——雙側對稱就不是輕蔑 |

獨白多節拍排程結構（一鏡最多 3–4 拍，拍數越多單拍精度越差）：
```

拍1（0–Xs）：\[AU組合或中文動作\] ——（可選）配合臺詞"..." 拍2（X–Ys）：\[AU組合或中文動作\] 拍3（Y–Zs）：\[AU組合或中文動作\]

```
節拍時間加總須等於本鏡總時長；這是**同一鏡內的表情變化，不是分鏡切鏡**，運鏡保持單一動作，否則引擎會把節拍表當成多鏡頭理解。

## 眼神語彙（表演訊號強度最高，單獨抓）

- **注視方向即敘事**：直視鏡頭=坦白/挑戰；視線略低於鏡頭=脆弱/迴避；視線越過鏡頭看向畫外=分心/回憶。寫清楚看向哪，不寫"深情地看"。
- **眨眼頻率**：正常對話節奏 3–4 秒一次；緊張/說謊/情緒波動時頻率加快或驟降（如憤怒剋制時反而"眨眼變少"）；極度平靜或專注時可長時間不眨。
- **躲開又看回是最常用的訊號組合**：寫"視線躲開半秒又偷偷看回去"比"眼神遊移"具體得多，適用於羞怯、嫉妒、口是心非等大量場景。
- **對鏡頭說話的專項技巧**（數字人/口播場景，銜接 talking-head-director）：真人演員對鏡頭常用"視線鎖定耳垂到鏡頭的連線"防止遊移，同時用餘光掃過鏡頭製造"虛擬對視感"；寫 prompt 可直接借這個具體動作，比"看著鏡頭"更可控。

## 跨鏡情緒連續性 + 表情錨點集（擴充套件 character-consistency）

同一角色連續幾鏡的情緒必須有前因後果，不能鏡與鏡之間情緒突變：**上一鏡的表情"餘量"要在下一鏡開頭被承接**（如上一鏡結尾是"眼眶微紅未落淚"，下一鏡開頭就該是"仍帶著未散的紅眼眶"而非重置為平靜臉）。

**表情錨點集**：character-consistency 的"姿態變化集"預設只變角度/姿態，同一角色若要在多鏡裡**精確復現某幾個特定表情**（不是自然情緒流），可額外生成一組"表情錨點圖"——用同一角色錨點，只變表情（如"中性放鬆""自然微笑""專注嚴肅"，或從本 skill 動作庫挑 3–6 個場景要用到的表情），後續鏡頭引用對應那張錨點圖。只在需要反覆精確復現同幾個特定表情（虛擬主播固定表情包、反覆出現的"標誌性苦笑"）時才值得做，一次性/自然流動的情緒不需要。

跨鏡同一張臉的技術實現（不漂移）走 character-consistency 的錨點機制；本 skill 只管情緒銜接/復現是否到位。

## 與對口型/lip-sync 的分工協同

臺詞情緒基調必須和臉上的微表情匹配，否則會出現"嘴在笑、眼睛在演別的情緒"的割裂感（除非這正是"情緒混合"想要的效果）。**分工原則**：臺詞配音/lip-sync 驅動嘴唇/下頜隨音素開合，本 skill 的表情描述應**優先落在眉毛/眼周/臉頰**這些不直接參與發音的肌肉上，不要搶同一塊肌肉——確實要控制嘴部的表情性動作（如說話時嘴角始終帶壓抑的笑意），當成"疊加在發音之上的表情層"來寫，不是替代口型。

鏡頭場景下的對話演員真實做法是：把注意力集中在臺詞的**潛臺詞**上而不是字面表情——先確定角色真正想要什麼/在隱藏什麼，微表情從潛臺詞反推，而不是從臺詞字面情緒直接對映（這正是"情緒混合"一節的應用場景）。

## Prompt 落地公式
```

\[起始/基礎狀態\] + \[觸發或原因，一句\] + \[1–2個關鍵微表情動作，從動作庫挑\] + \[眼神方向與動作\] + \[身體呼吸類反應，如有\] + \[剋製程度提示：如"不落淚""不咬牙""動作幅度極小"\]

```
整句寫進 `generate_video_v3` 視覺內容欄位裡角色動作/表情的部分；與身體動作、環境力的描述（cinematic-motion-realism）拼在同一句敘事流裡，不單獨割裂成"表情：xxx"標籤式寫法。表演是內容本身的長鏡頭改用上面的分時間段演化模板；獨白多節拍改用 FACS/AU 排程結構。

## 剋制自檢（表演過度 vs 到位）

- 一鏡只放 1–2 個關鍵動作，超過就是堆砌，會顯得"用力過猛"。
- 多節拍獨白最多 3–4 拍，拍數越多單拍精度越差。
- 雙側臉完全對稱的表情（除了純驚訝一瞬）大多不真實——允許寫"單側""略偏"；輕蔑本身就該是單側的。
- 動作和觸發之間要有延遲（0.3–1秒），零延遲的"聽到就立刻切換表情"最像 AI 感；情緒要**自然過渡**，禁止突然跳變（除非劇情就是要"猛然變臉"的衝擊）。
- 眼睛必須參與情緒，只有嘴部在動的表情是最常見的失敗模式。
- 舞臺式的誇張（大開大合、拉滿全臉）是給劇場觀眾遠距離看的，鏡頭前的表演要往回收——**鏡頭能看到劇場觀眾看不到的細節，所以鏡頭前用更小的動作就夠**。

## 故障排查

| 症狀 | 病因 | 修 |
|---|---|---|
| 數字人像蠟像/癱臉 | 只寫了臺詞沒寫表情 | 補至少 1 個基礎狀態動作，哪怕是"平靜專注" |
| 表情誇張失真/像默劇 | 用了"狂笑""痛哭""怒目而視"類誇張動詞 | 換成動作庫裡的剋制動作 |
| 假笑感/塑膠感 | 只寫了嘴部動作 | 補一句眼周動作，參照真笑假笑判定 |
| 長鏡頭表情演化很糊/看不出變化 | 整段只寫了一句靜態描述 | 改用分時間段演化模板，4 個時間段遞進 |
| 獨白裡表情該變但沒變 | 沒分節拍，整段一句糊過去 | 改用 FACS/AU 或中文動作庫的分節拍排程，≤4拍 |
| 中文描述總被引擎忽略某個細節 | 該細節在自然語言裡權重太低 | 換成 FACS/AU 編碼重試，同一賬號 A/B 對比 |
| 情緒轉折太突兀 | 兩個表情間無過渡段 | 補過渡動作，參照"微表情的時間尺度"選對應顆粒度 |
| 眼神空洞/無神 | 只描述了嘴部/眉毛 | 單獨補一句眼神語彙 |
| 對鏡頭說話時眼神遊移 | 沒給視線鎖定的具體動作 | 用"鎖在耳垂-鏡頭連線"式具體描述替代"看著鏡頭" |
| 說話時表情和口型互相打架 | 表情描述搶了嘴部/下頜肌肉，和lip-sync衝突 | 把表情描述移到眉眼臉頰，嘴部交給對口型驅動 |
| 表情與臺詞情緒不匹配（非故意） | 直接從臺詞字面對映表情 | 先想潛臺詞再定表情 |
| 多鏡情緒像被重置 | 每鏡獨立寫情緒沒接上一鏡餘量 | 承接上一鏡結尾狀態作本鏡開頭 |
| "洩露情緒"效果看不出來 | 把一閃而過的訊號寫成了完整表情 | 改成 0.25–0.5秒量級的極快閃過 |
| 需要反覆精確復現同一表情但總是漂 | 只有角色身份錨點，沒有表情錨點 | 補建"表情錨點集" |
