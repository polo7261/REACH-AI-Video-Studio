# 專業運鏡指令生成器

## 這個 Skill 能做什麼

輸入場景描述和情緒意圖，輸出精確到每個鏡頭的運鏡指令方案——包含機位、景別、運動方式、轉場設計，以及平台影片生成模型可識別的運鏡指令代碼。讓 AI 生成的每一幀都有專業導演級的鏡頭語言。

## 怎麼做

### 第 1 步：場景拆解與情緒定位

分析輸入的場景描述，提取以下維度，形成場景拆解卡：

- **空間類型**：開闊（曠野/海洋/天空）/ 封閉縱深（走廊/隧道/車廂）/ 封閉平面（小房間/電梯）/ 半開放（庭院/陽台/窗邊）
- **角色配置**：人數、站位、移動方向、相對距離
- **情緒基調**：單一情緒 or 漸變情緒（標註變化方向和速度比）
- **敘事功能**：開場建立 / 衝突升級 / 情緒轉折 / 高潮爆發 / 收尾留白 / 資訊揭示
- **節奏權重**：整體節奏傾向（慢/中/快）+ 內部節奏變化曲線

輸出格式：

```
【場景編號】S-01
【空間類型】封閉縱深（走廊）
【角色配置】1人，居中，由遠及近移動
【情緒基調】壓抑→恐懼（2:1加速漸變）
【敘事功能】懸念建立
【節奏權重】慢起→急收
```

### 第 2 步：情緒—運鏡對應決策

根據情緒基調，從運鏡武器庫中匹配最優組合。

核心運鏡—情緒對應表：

| 情緒類型 | 首選運鏡 | 輔助運鏡 | 禁用運鏡 | 心理依據 |
|---|---|---|---|---|
| 壓抑/窒息 | [Push in] 慢推 | [Tilt down] 俯視 | [Crane up] 升鏡 | 收縮空間感，壓迫觀眾 |
| 恐懼/不安 | [Shake] 手持晃動 | [Zoom in] 急推 | [Dolly out] 平穩後拉 | 不穩定=失控感 |
| 震撼/史詩 | [Crane up] 升鏡 | [Tracking shot] 橫移 | [Tilt down] 俯視 | 擴展空間，製造敬畏 |
| 溫暖/親密 | [Dolly in] 緩推 | [Static] 固定 | [Shake] 晃動 | 穩定=安全感 |
| 懸疑/窺視 | [Zoom in] 緩慢 | [Pan] 緩慢橫移 | [Crane up] 升鏡 | 聚焦=放大未知 |
| 爆發/衝突 | [Push in] 急推 | [Shake] 劇烈晃動 | [Static] 固定 | 動能=衝擊力 |
| 孤獨/疏離 | [Dolly out] 後拉 | [Static] 長固定 | [Push in] 推鏡 | 拉遠=割裂感 |
| 追逐/緊迫 | [Tracking shot] 跟拍 | [Shake] 手持 | [Crane up] 升鏡 | 運動同步=臨場感 |
| 頓悟/揭示 | [Zoom in] 定推 | [Static] 固定 | [Shake] 晃動 | 聚焦=資訊鎖定 |
| 虛無/絕望 | [Tilt up] 仰視 | [Dolly out] 後拉 | [Push in] 推鏡 | 仰視=渺小感 |

運鏡指令速查表：

| 指令代碼 | 運鏡效果 | 速度建議 | 適用景別 |
|---|---|---|---|
| [Push in] | 推鏡（鏡頭向主體靠近） | 慢 0.5x / 中 1x / 快 2x | 全→中 / 中→近 |
| [Pull out] | 拉鏡（鏡頭遠離主體） | 慢 0.5x / 中 1x | 近→中 / 中→遠 |
| [Dolly in] | 推軌（平滑前移） | 慢 0.3x / 中 0.7x | 全→中 / 中→近 |
| [Dolly out] | 拉軌（平滑後移） | 慢 0.3x / 中 0.7x | 近→中 / 中→遠 |
| [Zoom in] | 光學變焦推 | 慢/急 | 任意→特寫 |
| [Zoom out] | 光學變焦拉 | 慢/急 | 特寫→任意 |
| [Pan left] | 左搖 | 慢 0.5x / 中 1x | 遠/全景 |
| [Pan right] | 右搖 | 慢 0.5x / 中 1x | 遠/全景 |
| [Tilt up] | 上仰 | 慢/中 | 中→遠 / 仰視 |
| [Tilt down] | 下俯 | 慢/中 | 遠→中 / 俯視 |
| [Tracking shot] | 跟拍 | 中 1x / 快 1.5x | 全/中景 |
| [Crane up] | 升鏡 | 慢 0.5x | 中→大遠 |
| [Crane down] | 降鏡 | 慢 0.5x | 大遠→中 |
| [Shake] | 手持晃動 | 微/中/劇烈 | 任意 |
| [Static] | 固定 | — | 任意 |
| [Orbit] | 環繞 | 慢 0.5x / 中 1x | 中/近景 |
| [Dolly zoom] | 推拉變焦（眩暈效果） | 中 1x | 中景特供 |
| [Roll] | 旋轉 | 慢/中 | 任意（慎用） |

景別—敘事功能對應表：

| 景別 | 敘事功能 | 適用時機 | 推薦切換 |
|---|---|---|---|
| 大遠景 | 建立空間/孤寂感 | 開場/轉場/高潮後 | 釋放→中景 |
| 遠景 | 角色與環境關係 | 場景切換/角色登場 | →中近景 |
| 全景 | 角色全身動作 | 動作戲/多人場景 | →中景 |
| 中景 | 對話/日常互動 | 對話場景主體 | →近景/特寫 |
| 近景 | 面部表情/情緒 | 情緒轉折點 | →特寫/中景 |
| 特寫 | 關鍵細節/強化鉤子 | 反轉/關鍵道具 | →近景/大遠景（反差） |
| 大特寫 | 極限聚焦/窒息感 | 恐懼頂點/關鍵資訊 | →遠景（釋放） |

**景別反差原則**：連續相同景別不超過 3 個；大特寫後接大遠景=最強情緒釋放；特寫後接中景=情緒沉澱。

### 第 3 步：運鏡指令序列設計

為每個鏡頭生成完整的運鏡指令包，包含 6 個必填維度：

```
【鏡頭01】
景別：遠景→中景（推鏡過渡）
運鏡：[Push in] 從遠景緩慢推至中景，速度0.5x
持續時間：3秒
情緒意圖：建立空間壓迫感，引導視線聚焦角色
轉場方式：硬切（保持緊張節奏）
平台指令：A wide shot of [場景描述], [Push in] slowly revealing [角色] standing in the center, dim lighting, tense atmosphere
```

**指令編寫四原則**：

1. **一個鏡頭一個主運鏡**：不要疊加 2 個以上運動指令，AI 模型會混亂
2. **運鏡服務於情緒**：每次運鏡必須有明確情緒理由，不為動而動
3. **景別遞進有邏輯**：遵循「建立→聚焦→釋放」或「聚焦→反差→釋放」模式
4. **平台指令含完整描述**：景別+運鏡+角色+環境+光影+氛圍，一段話寫完

### 第 4 步：轉場與節奏編排

設計鏡頭間的轉場方式和整體節奏曲線。

轉場武器庫：

| 轉場類型 | 情緒效果 | 適用場景 | 注意事項 |
|---|---|---|---|
| 硬切 | 緊張/衝擊/快節奏 | 動作戲/恐懼/衝突 | 連續硬切 ≤3 次，否則疲勞 |
| 疊化 | 時間流逝/回憶/夢幻 | 情緒過渡/閃回 | 持續 0.5-1 秒 |
| 淡入淡出 | 段落分隔/情緒沉澱 | 章節切換/開場結尾 | 淡出 ≥1 秒 |
| 匹配剪輯 | 視覺連貫/巧思 | 動作延續/場景轉換 | 需構圖元素匹配 |
| L-Cut/J-Cut | 音畫錯位/懸念 | 對話場景/預兆鋪墊 | 音訊先行 0.5-1 秒 |
| 閃白 | 震驚/記憶碎片 | 回憶閃回/衝擊瞬間 | 持續 0.2-0.3 秒 |
| 閃黑 | 恐懼/失去意識 | 昏迷/時間跳躍 | 持續 0.3-0.5 秒 |
| 溶解 | 緩慢變化/夢境 | 長時間過渡 | 持續 1-2 秒 |

節奏公式庫：

| 場景類型 | 節奏公式 | 效果說明 |
|---|---|---|
| 懸念建立 | 慢(3s)→慢(3s)→快(1s)→快(1s)→定格(2s) | 漸進收緊，最後突然加速製造驚嚇 |
| 追逐緊張 | 快(1s)→快(1s)→快(0.5s)→快(0.5s)→急停(2s) | 持續加速到極限後急停釋放 |
| 情感沉澱 | 中(2s)→慢(3s)→慢(4s)→中(2s) | 給觀眾足夠時間感受情緒 |
| 高潮爆發 | 慢(4s)蓄力→快(0.5s)→快(0.5s)→定格(3s) | 長時間蓄力後瞬間爆發 |
| 日常對話 | 中(2s)→中(2s)→中(2s) | 穩定節奏，靠內容而非剪輯驅動 |
| 資訊揭示 | 中(2s)→慢(3s)→特寫(1s)→定格(2s) | 逐漸聚焦到關鍵資訊點 |
| 夢境/幻覺 | 慢(4s)→慢(3s)→疊化→慢(4s) | 超現實感，時間感模糊 |

**節奏鐵律**：

- 單鏡頭最短 0.5 秒，最長 6 秒（超過 6 秒觀眾注意力流失）
- 同一節奏模式連續使用不超過 4 個鏡頭
- 情緒轉折點必須配合節奏變化（快→慢 or 慢→快）
- 結尾定格鏡頭比正文鏡頭長 30%-50%，製造餘韻

### 第 5 步：輸出完整運鏡方案

整合以上所有步驟，輸出可直接用於平台影片生成的完整方案。

輸出結構：

1. **場景拆解卡**：空間/角色/情緒/敘事/節奏五維度定位
2. **運鏡方案表**：每鏡頭 6 維度（景別/運鏡/時長/情緒/轉場/平台指令）
3. **轉場設計圖**：鏡頭間轉場類型+情緒效果+節奏說明
4. **節奏曲線**：文字版節奏波形 + 速度變化說明
5. **運鏡決策依據**：解釋每個運鏡選擇的心理依據
6. **平台執行指令包**：每鏡頭可直接複製到影片生成工具的完整 prompt

## 使用場景

- 寫好分鏡腳本，需要為每個鏡頭設計專業級運鏡方案
- 知道想要的情緒效果，但不確定用什麼運鏡實現
- 需要為不同鏡頭生成平台影片模型可識別的運鏡指令代碼
- 多鏡頭專案需要統一運鏡風格和轉場節奏
- 想讓 AI 影片從「能看」升級到「有電影感」
- 不同類型專案（短劇/廣告/MV/漫劇）需要不同運鏡策略

## 如何使用

輸入你要拍攝的場景描述和情緒意圖。

示例輸入：「深夜走廊，女主角獨自走向盡頭的房間，越來越害怕，推開門發現空無一人，情緒從壓抑到恐懼爆發。」

如果只給了場景沒給情緒，會主動分析場景中的情緒線索並追問確認。如果場景涉及多個情緒階段，會拆分為多個子場景分別設計。

然後自動完成：場景拆解→情緒運鏡對應→運鏡指令序列設計→轉場節奏編排→輸出完整運鏡方案。

支援輸入類型：文字描述 / 分鏡表 / 劇本片段。輸出語言跟隨輸入語言，預設中文。

## 輸出內容

1. **場景拆解卡**（空間類型/角色配置/情緒基調/敘事功能/節奏權重，五維度精確定位）
2. **運鏡方案表**（每鏡頭含：景別/運鏡指令代碼/持續時間/情緒意圖/轉場方式/可直接執行的平台生成 prompt）
3. **轉場設計圖**（鏡頭間轉場類型選擇+情緒效果說明+節奏銜接邏輯）
4. **節奏曲線**（文字版節奏波形圖+速度變化節點標註+峰值谷值說明）
5. **運鏡決策依據**（每個運鏡選擇的心理依據和替代方案，解釋「為什麼這樣拍」）
6. **平台執行指令包**（每鏡頭的完整可執行 prompt，複製即可使用，含景別+運鏡+角色+環境+光影+氛圍一體化描述）
