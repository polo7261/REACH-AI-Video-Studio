# 專業運鏡指令生成器

## 這個Skill能做什麼

輸入場景描述和情緒意圖，輸出精確到每個鏡頭的運鏡指令方案——包含機位、景別、運動方式、轉場設計，以及平臺影片生成模型可識別的運鏡指令程式碼。讓AI生成的每一幀都有專業導演級的鏡頭語言。

## 怎麼做

### 第1步：場景拆解與情緒定位

分析輸入的場景描述，提取以下維度，形成場景拆解卡：

- **空間型別**：開闊（曠野/海洋/天空）/ 封閉縱深（走廊/隧道/車廂）/ 封閉平面（小房間/電梯）/ 半開放（庭院/陽臺/窗邊）
- **角色配置**：人數、站位、移動方向、相對距離
- **情緒基調**：單一情緒 or 漸變情緒（標註變化方向和速度比）
- **敘事功能**：開場建立 / 衝突升級 / 情緒轉折 / 高潮爆發 / 收尾留白 / 資訊揭示
- **節奏權重**：整體節奏傾向（慢/中/快）+ 內部節奏變化曲線

輸出格式：

```
【場景編號】S-01
【空間型別】封閉縱深（走廊）
【角色配置】1人，居中，由遠及近移動
【情緒基調】壓抑→恐懼（2:1加速漸變）
【敘事功能】懸念建立
【節奏權重】慢起→急收
```

根據情緒基調，從運鏡武器庫中匹配最優組合。

**景別反差原則**：連續相同景別不超過3個；大特寫後接大遠景=最強情緒釋放；特寫後接中景=情緒沉澱。

### 第3步：運鏡指令序列設計

為每個鏡頭生成完整的運鏡指令包，包含6個必填維度：

```
【鏡頭01】
景別：遠景→中景（推鏡過渡）
運鏡：[Push in] 從遠景緩慢推至中景，速度0.5x
持續時間：3秒
情緒意圖：建立空間壓迫感，引導視線聚焦角色
轉場方式：硬切（保持緊張節奏）
平臺指令：A wide shot of [場景描述], [Push in] slowly revealing [角色] standing in the center, dim lighting, tense atmosphere
```

**指令編寫四原則**：

1. **一個鏡頭一個主運鏡**：不要疊加2個以上運動指令，AI模型會混亂
2. **運鏡服務於情緒**：每次運鏡必須有明確情緒理由，不為動而動
3. **景別遞進有邏輯**：遵循"建立→聚焦→釋放"或"聚焦→反差→釋放"模式
4. **平臺指令含完整描述**：景別+運鏡+角色+環境+光影+氛圍，一段話寫完

### 第4步：轉場與節奏編排

設計鏡頭間的轉場方式和整體節奏曲線。

轉場武器庫

轉場型別情緒效果適用場景注意事項硬切緊張/衝擊/快節奏動作戲/恐懼/衝突連續硬切≤3次，否則疲勞疊化時間流逝/回憶/夢幻情緒過渡/閃回持續0.5-1秒淡入淡出段落分隔/情緒沉澱章節切換/開場結尾淡出≥1秒匹配剪輯視覺連貫/巧思動作延續/場景轉換需構圖元素匹配L-Cut/J-Cut音畫錯位/懸念對話場景/預兆鋪設音訊先行0.5-1秒閃白震驚/記憶碎片回憶閃回/衝擊瞬間持續0.2-0.3秒閃黑恐懼/失去意識昏迷/時間跳躍持續0.3-0.5秒溶解緩慢變化/夢境長時間過渡持續1-2秒

節奏公式庫

場景型別節奏公式效果說明懸念建立慢(3s)→慢(3s)→快(1s)→快(1s)→定格(2s)漸進收緊，最後突然加速製造驚嚇追逐緊張快(1s)→快(1s)→快(0.5s)→快(0.5s)→急停(2s)持續加速到極限後急停釋放情感沉澱中(2s)→慢(3s)→慢(4s)→中(2s)給觀眾足夠時間感受情緒高潮爆發慢(4s)蓄力→→→快(0.5s)→快(0.5s)→定格(3s)長時間蓄力後瞬間爆發日常對話中(2s)→中(2s)→中(2s)穩定節奏，靠內容而非剪輯驅動資訊揭示中(2s)→慢(3s)→特寫(1s)→定格(2s)逐漸聚焦到關鍵資訊點夢境/幻覺慢(4s)→慢(3s)→疊化→慢(4s)超現實感，時間感模糊

**節奏鐵律**：

- 單鏡頭最短0.5秒，最長6秒（超過6秒觀眾注意力流失）
- 同一節奏模式連續使用不超過4個鏡頭
- 情緒轉折點必須配合節奏變化（快→慢 or 慢→快）
- 結尾定格鏡頭比正文鏡頭長30%-50%，製造餘韻

### 第5步：輸出完整運鏡方案

整合以上所有步驟，輸出可直接用於平臺影片生成的完整方案。

輸出結構：

1. **場景拆解卡**：空間/角色/情緒/敘事/節奏五維度定位
2. **運鏡方案表**：每鏡頭6維度（景別/運鏡/時長/情緒/轉場/平臺指令）
3. **轉場設計圖**：鏡頭間轉場型別+情緒效果+節奏說明
4. **節奏曲線**：文字版節奏波形 + 速度變化說明
5. **運鏡決策依據**：解釋每個運鏡選擇的心理依據
6. **平臺執行指令包**：每鏡頭可直接複製到影片生成工具的完整prompt

## 使用場景

- 寫好分鏡指令碼，需要為每個鏡頭設計專業級運鏡方案
- 知道想要的情緒效果，但不確定用什麼運鏡實現
- 需要為不同鏡頭生成平臺影片模型可識別的運鏡指令程式碼
- 多鏡頭專案需要統一運鏡風格和轉場節奏
- 想讓AI影片從"能看"升級到"有電影感"
- 不同型別專案（短劇/廣告/MV/漫劇）需要不同運鏡策略

## 如何使用

輸入你要拍攝的場景描述和情緒意圖。

示例輸入："深夜走廊，女主角獨自走向盡頭的房間，越來越害怕，推開門發現空無一人，情緒從壓抑到恐懼爆發。"

如果只給了場景沒給情緒，會主動分析場景中的情緒線索並追問確認。如果場景涉及多個情緒階段，會拆分為多個子場景分別設計。

然後自動完成：場景拆解→情緒運鏡對映→運鏡指令序列設計→轉場節奏編排→輸出完整運鏡方案。

支援輸入型別：文字描述 / 分鏡表 / 劇本片段。輸出語言跟隨輸入語言，預設中文。

## 輸出內容

1. **場景拆解卡**（空間型別/角色配置/情緒基調/敘事功能/節奏權重，五維度精確定位）
2. **運鏡方案表**（每鏡頭含：景別/運鏡指令程式碼/持續時間/情緒意圖/轉場方式/可直接執行的平臺生成prompt）
3. **轉場設計圖**（鏡頭間轉場型別選擇+情緒效果說明+節奏銜接邏輯）
4. **節奏曲線**（文字版節奏波形圖+速度變化節點標註+峰值谷值說明）
5. **運鏡決策依據**（每個運鏡選擇的心理依據和替代方案，解釋"為什麼這樣拍"）
6. **平臺執行指令包**（每鏡頭的完整可執行prompt，複製即可使用，含景別+運鏡+角色+環境+光影+氛圍一體化描述）
