# action-previs

做動作導演預演(PREVIS)時用本 skill。專攻**動作編排 previs**——火柴人動作分鏡+角色三檢視→逐板連續動作影片,重點處理動作節拍、板間鏡頭銜接、角色一致性、多板連續性。

> 本環境適配:GPT Image 2 → `generate_image_v3`(火柴人分鏡/場景圖 2K);Seedance 2.0 → `generate_video_v3`(全能參考、逐板≤15s);`resource_prepare_and_analyze` → `analyze`;`text_editor` → `write_file_v2`;`video_assembler` → `composite_video`;`<<<image_x>>>` → `reference_nodes`+`{{NodeKey}}`;角色一致 → 三檢視註冊持久錨點。生成失敗**不自動換模型**語義:分鏡圖 GPT Image 2 失敗可切 Nano Banana Pro 兜底(同類影象能力);影片 Seedance 失敗則停任務、向使用者說明、問是否換工具。cards/reply_to_user 互動 → 對話式暫停+選項列舉。

## 工作模式(優先詢問,必須使用者確認、不得自動降級)

- **模式 A 構思→分鏡→影片**:使用者給動作構思 → 先生成火柴人 PREVIS 分鏡圖,確認後再生成影片。
- **模式 B 分鏡→影片**:使用者已有 PREVIS 分鏡圖 → `analyze` 逐張逐幀解析後對齊 Storyboard,跳過分鏡生成直接進影片。判據:會話開始直接上傳分鏡圖或明確"我已有分鏡";**不得因未上傳而自動降級為 A,模式必須由使用者確認**。
- 任一模式:使用者給了角色三檢視立即 `analyze` 並註冊為角色 key_element;未給則在影片生成前提示上傳。場景圖入口同步確認(已提供/需生成/暫無——暫無則影片僅依賴分鏡圖+三檢視)。

## 流程與依賴

1. **鎖規格**(`write_file_v2`):專案名/總板數/比例(預設 16:9)/解析度(預設 720p)/視覺風格鎖定(極簡火柴人 PREVIS 手繪風)/每板時長上限 15s。
2. **分析輸入並立即註冊資產**(`analyze`+`generate_image_v3`):模式 A 分析三檢視/場景圖(分鏡尚未生成);模式 B 對所有分鏡圖逐張逐幀結構化解析輸出每板"Storyboard 對映",再分析三檢視/場景圖(順序:分鏡→三檢視→場景,全部完成後統一彙總)。**關鍵規則——分析後必須立即註冊**(不推遲):三檢視→註冊 asset_id→綁 element character、場景圖→綁 element scene、模式 B 分鏡圖→綁 shot(Storyboard 未建先註冊記錄對映待建後補綁);輸出資產註冊清單(素材名→asset_id→繫結目標)供核對,無法匹配的標 `[待繫結]` 並提示確認歸屬。
3. **建 Storyboard**(`storyboard_designer`):模式 A 預建 shot 佔位(留空待生成後繫結)+建 element character/scene;模式 B 逐板填入對映輸出,按識別角色數建 element character、按連續性預判推斷場景切換建 element scene。
4. **生成火柴人分鏡圖**(模式 A,`generate_image_v3`,GPT Image 2,2K):每板≤8 連續畫格、2×4 網格、統一畫幅;每板生成後暫停確認。
5. **場景圖**:已提供則註冊繫結;未提供按 element scene 描述生成(2K),生成後暫停確認。同一場景多板複用只生成一張、統一繫結。
6. **繫結資產**:確認的分鏡圖/三檢視/場景圖 asset_id 分別綁到對應 shot/character/scene。
7. **逐板生成動作影片**(`generate_video_v3` 全能參考):每板生成後暫停審閱確認再下一板。
8. **合成**(`composite_video`):按 Storyboard 順序拼接,處理板間銜接、音訊對齊。

**依賴關係**:3→1;4→3;5→3;6→3,4,5;7→6;8→7。

## 多板批次順序控制(5 板及以上)

- **嚴格順序生成**:Board 1→N 逐板,禁並行/亂序;每板確認後才將其 final_shot 納入下一板參考候選池。
- **奇偶分段策略(≥10 板啟用)**:拆 5 板一組(1–5、6–10…),每批逐板確認後做一次批次間一致性預檢(角色位置/外觀/場景),出預檢摘要、修復問題再推進下一批,避免問題累積到裝配爆發。
- **中途問題處理**:①質量不達標(外觀飄移/節拍錯序)→立即暫停不續,展示問題+修復方向(參考權重/提示詞/換參考),確認後重生當前板;②銜接斷層(位置/朝向與上板末幀不一致)→提示詞加強制起始位置約束重生,兩次仍斷層則讓使用者選(接受跳切標記裝配處理/上傳過渡幀作 start_frame/改銜接備註重試);③連續 3 板同類問題→判系統性,暫停批次說明根因(三檢視權重不足/描述模糊),補高質量三檢視或改 element character 後從首板重生;④單板失敗→跳過繼續、保留待處理列表,全部完成後統一重試,禁空板進裝配。

## 暫停點結構化摘要(每點須展示內容+決策選項,不得只出"是否繼續?")

- **暫停點 1(規格鎖定後)**:展示 專案名/總板數/比例/解析度/視覺風格/每板時長上限/場景圖來源(使用者提供/需生成/暫無)。選項:①確認進 Storyboard;②修改某項引數。
- **暫停點 2(每張分鏡圖生成後,模式 A)**:展示 板編號(Board 1/N)/生成圖預覽/該板幀編號(F1–F8)+簡要動作節拍。選項:①確認續下一板;②調描述重生;③跳過(標"待補充"先續)。若已上傳場景圖未確認繫結,此處同步確認。
- **暫停點 3(所有分鏡圖+場景圖就緒、Storyboard 建畢後)**:展示 完整 Storyboard 摘要——所有 element character(含來源:三檢視/待上傳)、element scene(含來源:使用者提供/生成/暫無)、shot 列表(板編號+核心動作一句話)、已繫結資產清單。選項:①確認進逐板影片;②改某 element/shot 描述;③**若有標"待補充"的 element character 缺三檢視,此步強制暫停必須等上傳後才繼續**。
- **暫停點 4(每板影片生成後)**:展示 板編號/時長/參考輸入列表(分鏡圖/各三檢視/場景圖 asset_id、是否用了上板 reference_video)/板間銜接備註執行情況。選項:①確認續;②重生(說明調整方向:鏡頭運動/動作節拍/角色外觀/其他);③接受但標記裝配階段人工處理點。
- **暫停點 5(所有板生成完畢、裝配前)**:展示 全部 final_shot 列表(板編號+時長+是否有標記問題點)、總時長合計、一致性預檢摘要(角色位置跳切/場景飄移/外觀飄移數量及位置)。選項:①確認進裝配;②定向重生某板;③接受現有問題直接裝配(蒙太奇跳切意圖明確時)。

## 分鏡圖逐幀解析(模式 B 核心,`analyze`)

逐張分鏡圖執行結構化解析,輸出須可直接對映為 Storyboard shot 欄位:

**① 畫格清點與佈局**:統計畫格數(≤16),確認排列(4×4 或其他);無編號則按從左到右、從上到下自動標 F1–FN 並註明;解析度過低/畫格模糊逐一標受影響幀編號+可信度("可解讀/部分可解讀/無法解讀"),**無法解讀的幀不得臆造,保留空位標 `[待使用者補充]`**。

**② 逐幀結構化提取(每幀必含全部欄位)**:
- **幀編號** F1–FN(自動或引用圖內標註)。
- **景別**:從 EXTREME WIDE / WIDE / MEDIUM / MEDIUM CLOSE-UP / CLOSE-UP / EXTREME CLOSE-UP 選最接近一項;圖內有標註則引用並括注對映詞(如 "WS → WIDE")。
- **鏡頭運動**:推/拉/搖(方向)/跟/俯拍/仰拍/靜止;依畫內箭頭、標註文字或透視線推斷;無法判斷標"靜止(推斷)"。
- **主動作節拍**:主動方(火柴人)核心動作,"部位+運動方向+幅度"格式(如"右臂向右上方大幅揮出");有速度感線/拖尾線則加 `[速度感:爆發/流暢/沉重]`。
- **受擊/反應動作**:有第二角色則描述其反應姿態與運動方向;無則標"單角色幀"。
- **畫面內標註摘錄**:逐字抄錄圖內所有文字標註(不論中英);無則標"無文字標註"。
- **運動軌跡箭頭**:描述箭頭起點/指向/含義推斷(如"角色從畫框左下向右上位移")。

**③ 整板鏡頭排程歸納**:彙總鏡頭運動總體節奏(起幅景別→中間變化→落幅景別一句話概括,如"從 WIDE 推進至 ECU,全板以跟隨運動為主");識別板內明確切換節點(切割線/"CUT"標註)並標位置;歸納整板動勢走向(主要運動方向+節奏強度:起伏/持續爆發/漸進蓄力)。

**④ 多板連續性預判**:多張分鏡圖時,分析完單板後額外輸出跨板連續性摘要——相鄰兩板落幅幀(前板 FN)與起幅幀(後板 F1)角色位置/朝向是否一致(不一致標 `[需板間銜接備註]`);跨板相同角色身份一致性(依體型比例/角色標註識別);跨板場景切換(背景幾何明顯變化)標新場景並建議建獨立 element scene。

**⑤ Storyboard 對映輸出格式**(欄位名對齊 shot 定義):
```
[Board N 對映]
- 關聯分鏡板: [使用者提供板編號或自動編號 Board_N]
- 幀範圍: F1–FN(共 N 幀)
- 動作節拍序列: F1: … ; F2: … ; … ; FN: …
- 鏡頭排程: 起幅[景別] → [運動方式] → 落幅[景別];板內切點: [無 / F_N→F_N+1]
- 板間銜接備註: [與上板末幀的角色位置/朝向連續性說明,首板填"首板,無前板參照"]
- 時長上限: 15s
- 待補充項: [列出所有 [待使用者補充] 或 [需板間銜接備註] 標記]
```

## 三檢視分析(`analyze`,提取跨板穩定複用視覺錨點)

每項須給具體描述而非"正常/無特殊":
- **① 面部身份錨點**:臉型輪廓(方形下頜/瓜子臉/寬顴骨);五官關鍵特徵(眉形粗細顏色、眼型眼距、鼻樑高寬、唇形唇色);膚色膚質(色號範圍,如 warm medium-tan / pale cool-toned);髮型結構(髮際線位置、分割槽、長度、質感 直/卷/蓬鬆/貼頭皮);髮色(主色+次色/挑染,避免僅寫"黑",補光澤傾向 啞光黑/藍黑光澤)。
- **② 體型比例**:整體身高體型分類(高挑/中等/矮壯/纖細);肩寬與腰臀比視覺印象;手部/頸部等區域性可識別特徵。
- **③ 服裝造型**:上裝(款式+主色+次色/圖案+領型袖型);下裝(款式+主色+長度+版型 修身/寬鬆);鞋履(型別+顏色+鞋底厚度);材質質感關鍵詞 2–3 個(matte cotton/shiny leather/worn denim);標誌性配件(型別+顏色+佩戴位置,如 right wrist silver chain bracelet)。
- **④ 三檢視一致性校驗**:對比正/側/背三圖,指出各視角顏色差異或細節不一致(如側面服裝偏暗、背面有揹包正面未體現),註明"以正面圖為準"或"以使用者說明為準";任一視角缺失則標缺失方向並說明對後續生成的影響。
- **輸出格式**:結構化文字按①–④分段、短句/關鍵片語列舉供直接複製引用,不輸出敘事段落。

**場景參考圖分析**:識別空間結構與關鍵視覺錨點(環境型別 室內/室外/特定地點、主構成元素 建築輪廓/地面材質/光源方向色調/背景層次、可跨板穩定複用的視覺特徵),輸出結構化 element scene description 基礎。

## Storyboard 設計(含節拍密度分檔)

- **Key Elements**:每出現角色建 element character(description 基於三檢視分析;未提供三檢視標"待補充"提示上傳);每主要場景/地點建 element scene(空間結構/光線方向/背景錨點/色調氛圍,有參考圖則須與圖一致不矛盾、無則給足細緻描述供生成)。
- **Shot 設計(每板=一 shot,≤8 動作節拍)**:含 關聯分鏡板(分鏡圖 asset_id 或板編號)、動作節拍序列(按幀序簡述核心動作/方向/動勢)、鏡頭排程(起幅/落幅、運動型別、景別變化)、板間銜接備註(與上板末幀連續性要求,首板留空)。
- **節拍密度標註(核心,非全統一 ≤15s)**:每板標 高密度(爆發板)/低密度(過渡板):
  - **爆發板**:連續打擊/衝撞/多人混戰,節拍因果緊密無停頓蓄力段;目標 **6–8s**。
  - **過渡板**:拉開距離/蓄力/喘息/鏡頭大幅推拉等慢節奏;目標 **10–15s**。
  - 混合板以主導內容判定,或備註說明分段節奏意圖。**時長目標據節拍密度填,不強制統一 15s 上限**。
- **模式 B 專項**:shot 欄位直接從"Storyboard 對映輸出"提取一一對應填入,**保持原始推斷不自行擴寫**;標 `[待使用者補充]`/`[無法解讀]` 的欄位保留相同標記待暫停點 3 補充或放棄、**不得用推測填充**;跨板 element scene 按分析工具場景切換識別新增(來源標"[分析工具推斷,待使用者確認]",未識別則預設共用同一 scene);角色 element 按識別的多角色分別建條目,description 空或僅填極簡特徵(如"高體型,右側主動方")待三檢視補全。
- **音訊軌**:需要則規劃 audio_layer,**動作 PREVIS 預設無旁白軌**。

## PREVIS 分鏡圖提示詞(generate_image_v3 — GPT Image 2)

**核心設計原則:自解釋**——圖應有足夠視覺資訊密度使 Seedance 能直接從圖讀取動作編排/空間關係/鏡頭意圖,儘量減少對文字依賴;每格須做到即便不讀提示詞也能從標註/箭頭/線條理解該幀發生了什麼。

**核心約束(每條提示必含,放最前)**:
- **風格鎖定**:極簡粗糲手繪分鏡風格,全部角色僅用火柴人(stick figures),禁真實人體結構/肌肉/服裝/褲子/鞋子/任何角色細節。
- **線條風格**:粗細不均手繪鉛筆/炭筆感線條、允許輕微抖動與不規則(速寫張力),禁光滑向量線條/數字清稿感;關鍵動勢用粗重線、輔助參考線(透視線/軌跡線)用細虛線。
- **背景處理**:極簡,僅用幾何輪廓線(方塊=建築/掩體、水平線=地面/臺階、斜線=斜面)示意空間關係,禁寫實紋理/填充色塊/細節貼圖;整體純白或極淺冷灰紙面色,只有線條、無漸變陰影填充。
- **標註語言**:所有鏡頭標註/動作說明/技術指令一律**英文**(PUSH IN、WIDE SHOT、POV、IMPACT、×2 SPEED),禁畫格內出現中文。
- **單圖多格佈局**:明確格數(≤16),排 4×4 網格,每格獨立構圖、格間細實線分隔,每格左上角可有小號灰色幀編號(F1–F16)。

**逐格視覺資訊密度 7 層(核心,缺任一層導致 Seedance 參考資訊不足)**:
- **① 運動向量箭頭**:為每個運動的肢體/部位繪獨立帶箭頭軌跡線,箭頭長度反映幅度(大幅=長箭頭)、粗細反映力度(爆發=粗箭頭);角色整體位移另繪全身移動軌跡弧線,與肢體箭頭用線型區分(肢體=實線、位移弧=虛線)。
- **② 動勢拖尾線**:運動肢體末端(拳/腳尖/膝)繪 2–4 條平行拖尾線,方向為運動反方向錶速度感;爆發動作(直拳/掃腿)拖尾延伸至畫格邊緣或極近處表穿越力度。
- **③ 衝擊/接觸標註**:任何接觸/即將接觸的幀在接觸點繪爆炸形放射線(星形/菊花形)+英文標註(IMPACT/HIT/BLOCK/GRAB);近距發力(貼身短打)額外繪同心圓或壓縮波紋線表力道傳導。
- **④ 空間深度標記**:所有幀有明確地平線(水平粗虛線);多角色場景每角色腳下有落地陰影圓點/小橫線(表站位);前景角色粗線條、背景角色細線條形成縱深層次。
- **⑤ 角色區分標籤**:≥2 角色時每角色頭部旁大寫字母標籤(A/B/C),主動方圈選(①)、被攻擊方方框(`[B]`);標籤貫穿全板所有畫格一致、不隨幀變動。
- **⑥ 鏡頭資訊欄**:每格底/頂留一條細橫向標註欄——景別縮寫(WS/MS/MCU/CU/ECU)+鏡頭運動(STATIC/PUSH/PULL/PAN-L/PAN-R/TRACK)+可選速度修飾詞(SLOW/NORMAL/SNAP);格式示例 `MCU | PUSH | SNAP`。
- **⑦ 幀間過渡指示**:相鄰格分隔線處——動作連續用小箭頭(→)指示流向;剪下標 CUT;鏡頭切換(場景改變)標 NEW SHOT 並用雙豎線替代單線分隔。

**提示詞結構(順序)**:1. 風格約束+7 層密度要求(壓縮為簡潔指令);2. 格數與佈局宣告(如 8-panel grid, 2 rows × 4 columns);3. 按格編號逐一描述(鏡頭資訊+角色標籤分配+主要動作向量方向+衝擊點位置+幀間過渡型別);4. 整板動作編排總體節奏(動作因果鏈一句話,如 A 突破防線→近身發力連打→B/C 相繼倒地);5. ImageToImage 模式則指明參考來源與參考維度(構圖/動勢/鏡頭語言),**排除角色外觀參考**。

## 影片提示詞(generate_video_v3 — Seedance 2.0)

**核心原則:分鏡圖主導,提示詞補漏**。PREVIS 分鏡圖(`<<<image_1>>>`)已透過運動向量箭頭/拖尾線/衝擊標註/鏡頭資訊欄編碼大量動作與鏡頭資訊——是 Seedance 的**首要參考源**;提示詞唯一職責是補分鏡圖無法編碼的:速度質感詞、角色因果關係、音效指令。

**【強制減法原則】** 凡分鏡圖已清晰表達的內容,提示詞**一律省略或只留 1–2 關鍵詞**,不展開:
- 已有運動向量箭頭 → 肢體動作描述**省略**,僅留速度質感詞(如 explosive)。
- 已有鏡頭資訊欄(MCU|PUSH|SNAP)→ 鏡頭運動**簡寫為一句**(medium close-up, push in),不展開。
- 已有衝擊標註(IMPACT)→ 接觸點描述**省略**,僅留音效標註(`<sharp impact crack>`)。
- 已有角色標籤和位置資訊 → 空間排程描述**省略**。
- ✅ 正確(分鏡已有箭頭):`F1: explosive; F2: recoils from impact, weight shifts back; F3: snapping`
- ❌ 錯誤(重複分鏡已有):`F1: right arm swings upward in a 120° arc at explosive speed, fist clenched, elbow leads`

違反(提示詞與分鏡圖高度重複)會導致文字權重壓制視覺參考、生成偏離分鏡意圖。

**參考輸入繫結**:`<<<image_1>>>`=PREVIS 分鏡圖(首要);`<<<image_2>>>, <<<image_3>>>…`=各角色三檢視(每角色一張,按出場順序);`<<<video_1>>>`=上一板 final_shot(僅連續性極強時,預設省略)。

**提示詞結構(運動棧順序,嚴格按層級)**:
- **① 鏡頭運動**:分鏡資訊欄已標的只寫一句概括不展開;補充價值在速度質感詞。格式 `[起幅景別] → [運動方式] → [落幅景別]`;景別鎖定 EXTREME WIDE/WIDE/MEDIUM/MEDIUM CLOSE-UP/CLOSE-UP/EXTREME CLOSE-UP;多鏡頭切換按節拍順序用"→ cut →"分隔、不用時間碼。示例:`WIDE SHOT, swift push in → cut → EXTREME CLOSE-UP on fist impact, lock-off`。
- **② 角色動作**:減法優先,分鏡箭頭已明確的只寫速度質感詞,只有因果關係(被擊後重心後移/對沖互鎖)才展開;多節拍按 F1→F8 順序、每節拍只寫【速度質感詞+因果關係(如有)】、分號分隔;多角色先主動作後受擊/反應,主從用 in response/simultaneously/recoils 明確。**速度質感標準詞**:explosive / snapping / fluid / heavy / weightless / sluggish;**禁 fast/slow 等模糊詞**。
- **③ 多角色場景專項(≥2 角色強制)**:
  - **主從順序**:按"主動方→受擊/反應方→次要旁觀"逐角色獨立成句、角色間用"—"或換行分隔,**禁兩角色動作混寫一句**。主動方=當前節拍發起力量/位移的一方;雙方同步對沖以畫面視覺重心(通常畫框中央偏近景)為主動方。
  - **因果連結詞**:受擊/反應方必須用明確因果詞引出——in response / simultaneously / recoils from / absorbs the impact / driven back by;**禁用 "and" 簡單並列**避免主從模糊。
  - **畫框空間分配**:每角色用獨立畫框位置詞鎖定,禁用相對詞("他們站一起")。兩角色預設 主動方 frame left/center-left、受擊方 frame right/center-right(分鏡圖相反則以分鏡圖為準並註明);三角色+按前景/中景/背景縱深分層(前景=主動方、中景=受擊/反應、背景=次要),各層有縱深距離感描述(如 pushed into the background, noticeably smaller in frame)。多角色同時運動每角色運動方向向量須區分(A drives forward toward frame right; B retreats toward frame left),禁模糊為"兩人激烈衝突"。
  - **參考圖一一繫結**:嚴格按角色一一繫結,順序固定 分鏡圖(`<<<image_1>>>`)→主動方三檢視(`<<<image_2>>>`)→受擊/反應方三檢視(`<<<image_3>>>`)→次要角色(`<<<image_4>>>` 遞增)→場景圖(最後 image 佔位);每張繫結後在對應角色描述句首用括號注來源佔位符,格式 `[ref:image_2] Character A: ...`;**禁將多角色三檢視合併為單個 image 佔位符,每角色獨立佔一槽位**保外觀提取權重獨立。
- **④ 空間排程**:角色畫框內位置變化(frame left/right/center/foreground/background/off-screen);與場景元素空間關係須與 PREVIS 背景幾何一致;有出入畫則明確方向(enters from frame left/exits top frame)。
- **⑤ 音效與對白(僅無獨立旁白軌衝突時)**:Seedance 官方語法放末尾——SFX `<sound of heavy footsteps on concrete>`/`<sharp impact crack>`/`<whooshing air burst>`;對白 `{EN: "Get down!"}`(語言程式碼前置);環境音 `<ambient urban noise, distant siren>`。**優先順序:動作衝擊音效 > 環境氛圍音 > 對白**,三類同時按此序末尾依次列出。
- **⑥ 節拍密度對應速度質感詞(據 Storyboard 標註,附在②末尾)**:爆發板追加 `snapping cuts, explosive action rhythm, no slow motion, rapid kinetic energy`;過渡板追加 `deliberate pacing, building tension, smooth camera movement`;兩類均禁用 fast/slow 代替標準詞。
- **⑦ 固定否定項(每條末尾必附)**:`no subtitles, no text overlay, no wardrobe change, no style shift between cuts`(no wardrobe change 保服裝與三檢視一致;no style shift between cuts 抑制 Seedance 多節拍板內自動改風格/色調)。

## 影片生成參考輸入 & 多板遞進策略

- **每板參考輸入**:①**PREVIS 分鏡圖**(該板 asset_id,**首要視覺參考、權重高於文字**;提示詞嚴格執行減法原則);②角色三檢視(所有出場角色 asset_id);③場景圖(該板 element scene asset_id,無則省略);④上一板 final_shot(可選,僅場景/角色狀態連續性極強時作 reference_video,否則省略避免多餘動作延續)。時長據節拍密度取整秒(爆發板靠近 6s、過渡板 10–15s),不超 15s。
- **多板遞進**:reference_video 門檻隨板數收緊——板數 ≤4 常規判斷,**≥5 僅銜接備註明確"強連續"的板才引 reference_video**,餘板省略避免誤差逐板放大;**element 參考圖權重保持一致**——無論第幾板,三檢視+場景圖繫結方式與輸入順序須與第 1 板完全一致,不因"前幾板已穩定"降低後續完整性;**待修復板不阻塞後續**——某板標"需重生"時後續可續(跳該板 reference_video 鏈、直接用最近一張已確認 final_shot 作連續性參考),修復完成後若直接後續板已生成則提示使用者評估是否因參考缺失需重生後續。

## 跨板一致性(影片生成階段)

- **場景圖複用**:同一 element scene 多板出現強制複用同一 asset_id,禁重複生成/替換新圖,僅使用者明確要求場景狀態變化(時段切換/破壞後場景)才生成新圖註冊獨立 asset_id;每板生成即使主動作與背景無關也須納入對應場景圖穩定色調空間結構。
- **角色位置連續性**:每板生成前讀"板間銜接備註"——標明上板末幀位置(如"角色A 畫框右側面朝左")則該板提示詞空間排程層將起始狀態對齊避免跳切;兩板明顯動作因果(擊打→倒地)則後板首個動作節拍(F1)**必須從被擊打角色受力姿態起寫**、而非重置中立站姿;無銜接備註(首板/明確場景切換)不強制對齊、按該板分鏡圖獨立排程。
- **三檢視兜底**:所有板生成均須附帶全部出場角色三檢視 asset_id,即使某板某角色戲份極少也不省略引用,防 Seedance 低權重下自行重繪外觀。

## 裝配一致性檢查(`composite_video`,裝配前必做)

- **板間拼接**:按 shot 順序拼接,**預設硬切**(無淡入淡出)保動作衝擊感;備註標"連續性極強"可用**極短疊化(≤4 幀)**輔助銜接避跳切感。
- **一致性檢查優先順序:角色位置跳切 > 場景視覺錨點漂移 > 角色外觀漂移**:
  - **角色位置連續性**:逐一核查相鄰兩板銜接幀(前板末幀 vs 後板首幀)每角色畫框位置與朝向,明顯跳切(左側瞬移右側/朝向無因果反轉)在切點加標記、暫停裝配提示使用者選(重生後板強制指定起始位置 / 接受跳切 蒙太奇意圖明確時)。
  - **場景視覺錨點**:核查同一 element scene 多板背景主要錨點(地平線高度/主光源方向/關鍵背景物體)是否穩定,明顯風格漂移/構圖突變則標記提示。
  - **角色外觀漂移**:相鄰板同角色服裝色系/髮型/標誌配件視覺差異則備註註明,提示使用者評估是否以更強三檢視權重重生對應板。
  - 三者分別處理不混同(前者影響敘事連貫、後兩者影響視覺穩定)。
- **音訊**:各板含 Seedance 動作音效預設保留;BGM 軌(如有)跨板連續鋪設不隨切點中斷;無旁白軌時動作音效軌音量適度提升增強衝擊。
- **匯出**:解析度跟隨 Final_Video_Spec(預設 720p),比例預設 16:9。
