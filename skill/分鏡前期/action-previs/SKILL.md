# action-previs

做动作导演预演(PREVIS)时用本 skill。专攻**动作编排 previs**——火柴人动作分镜+角色三视图→逐板连续动作视频,重点处理动作节拍、板间镜头衔接、角色一致性、多板连续性。

> 本环境适配:GPT Image 2 → `generate_image_v3`(火柴人分镜/场景图 2K);Seedance 2.0 → `generate_video_v3`(全能参考、逐板≤15s);`resource_prepare_and_analyze` → `analyze`;`text_editor` → `write_file_v2`;`video_assembler` → `composite_video`;`<<<image_x>>>` → `reference_nodes`+`{{NodeKey}}`;角色一致 → 三视图注册持久锚点。生成失败**不自动换模型**语义:分镜图 GPT Image 2 失败可切 Nano Banana Pro 兜底(同类图像能力);视频 Seedance 失败则停任务、向用户说明、问是否换工具。cards/reply_to_user 交互 → 对话式暂停+选项枚举。

## 工作模式(优先询问,必须用户确认、不得自动降级)

- **模式 A 构思→分镜→视频**:用户给动作构思 → 先生成火柴人 PREVIS 分镜图,确认后再生成视频。
- **模式 B 分镜→视频**:用户已有 PREVIS 分镜图 → `analyze` 逐张逐帧解析后对齐 Storyboard,跳过分镜生成直接进视频。判据:会话开始直接上传分镜图或明确"我已有分镜";**不得因未上传而自动降级为 A,模式必须由用户确认**。
- 任一模式:用户给了角色三视图立即 `analyze` 并注册为角色 key_element;未给则在视频生成前提示上传。场景图入口同步确认(已提供/需生成/暂无——暂无则视频仅依赖分镜图+三视图)。

## 流程与依赖

1. **锁规格**(`write_file_v2`):项目名/总板数/比例(默认 16:9)/分辨率(默认 720p)/视觉风格锁定(极简火柴人 PREVIS 手绘风)/每板时长上限 15s。
2. **分析输入并立即注册资产**(`analyze`+`generate_image_v3`):模式 A 分析三视图/场景图(分镜尚未生成);模式 B 对所有分镜图逐张逐帧结构化解析输出每板"Storyboard 映射",再分析三视图/场景图(顺序:分镜→三视图→场景,全部完成后统一汇总)。**关键规则——分析后必须立即注册**(不推迟):三视图→注册 asset_id→绑 element character、场景图→绑 element scene、模式 B 分镜图→绑 shot(Storyboard 未建先注册记录映射待建后补绑);输出资产注册清单(素材名→asset_id→绑定目标)供核对,无法匹配的标 `[待绑定]` 并提示确认归属。
3. **建 Storyboard**(`storyboard_designer`):模式 A 预建 shot 占位(留空待生成后绑定)+建 element character/scene;模式 B 逐板填入映射输出,按识别角色数建 element character、按连续性预判推断场景切换建 element scene。
4. **生成火柴人分镜图**(模式 A,`generate_image_v3`,GPT Image 2,2K):每板≤8 连续画格、2×4 网格、统一画幅;每板生成后暂停确认。
5. **场景图**:已提供则注册绑定;未提供按 element scene 描述生成(2K),生成后暂停确认。同一场景多板复用只生成一张、统一绑定。
6. **绑定资产**:确认的分镜图/三视图/场景图 asset_id 分别绑到对应 shot/character/scene。
7. **逐板生成动作视频**(`generate_video_v3` 全能参考):每板生成后暂停审阅确认再下一板。
8. **合成**(`composite_video`):按 Storyboard 顺序拼接,处理板间衔接、音频对齐。

**依赖关系**:3→1;4→3;5→3;6→3,4,5;7→6;8→7。

## 多板批量顺序控制(5 板及以上)

- **严格顺序生成**:Board 1→N 逐板,禁并行/乱序;每板确认后才将其 final_shot 纳入下一板参考候选池。
- **奇偶分段策略(≥10 板启用)**:拆 5 板一组(1–5、6–10…),每批逐板确认后做一次批次间一致性预检(角色位置/外观/场景),出预检摘要、修复问题再推进下一批,避免问题累积到装配爆发。
- **中途问题处理**:①质量不达标(外观飘移/节拍错序)→立即暂停不续,展示问题+修复方向(参考权重/提示词/换参考),确认后重生当前板;②衔接断层(位置/朝向与上板末帧不一致)→提示词加强制起始位置约束重生,两次仍断层则让用户选(接受跳切标记装配处理/上传过渡帧作 start_frame/改衔接备注重试);③连续 3 板同类问题→判系统性,暂停批次说明根因(三视图权重不足/描述模糊),补高质量三视图或改 element character 后从首板重生;④单板失败→跳过继续、保留待处理列表,全部完成后统一重试,禁空板进装配。

## 暂停点结构化摘要(每点须展示内容+决策选项,不得只出"是否继续?")

- **暂停点 1(规格锁定后)**:展示 项目名/总板数/比例/分辨率/视觉风格/每板时长上限/场景图来源(用户提供/需生成/暂无)。选项:①确认进 Storyboard;②修改某项参数。
- **暂停点 2(每张分镜图生成后,模式 A)**:展示 板编号(Board 1/N)/生成图预览/该板帧编号(F1–F8)+简要动作节拍。选项:①确认续下一板;②调描述重生;③跳过(标"待补充"先续)。若已上传场景图未确认绑定,此处同步确认。
- **暂停点 3(所有分镜图+场景图就绪、Storyboard 建毕后)**:展示 完整 Storyboard 摘要——所有 element character(含来源:三视图/待上传)、element scene(含来源:用户提供/生成/暂无)、shot 列表(板编号+核心动作一句话)、已绑定资产清单。选项:①确认进逐板视频;②改某 element/shot 描述;③**若有标"待补充"的 element character 缺三视图,此步强制暂停必须等上传后才继续**。
- **暂停点 4(每板视频生成后)**:展示 板编号/时长/参考输入列表(分镜图/各三视图/场景图 asset_id、是否用了上板 reference_video)/板间衔接备注执行情况。选项:①确认续;②重生(说明调整方向:镜头运动/动作节拍/角色外观/其他);③接受但标记装配阶段人工处理点。
- **暂停点 5(所有板生成完毕、装配前)**:展示 全部 final_shot 列表(板编号+时长+是否有标记问题点)、总时长合计、一致性预检摘要(角色位置跳切/场景飘移/外观飘移数量及位置)。选项:①确认进装配;②定向重生某板;③接受现有问题直接装配(蒙太奇跳切意图明确时)。

## 分镜图逐帧解析(模式 B 核心,`analyze`)

逐张分镜图执行结构化解析,输出须可直接映射为 Storyboard shot 字段:

**① 画格清点与布局**:统计画格数(≤16),确认排列(4×4 或其他);无编号则按从左到右、从上到下自动标 F1–FN 并注明;分辨率过低/画格模糊逐一标受影响帧编号+可信度("可解读/部分可解读/无法解读"),**无法解读的帧不得臆造,保留空位标 `[待用户补充]`**。

**② 逐帧结构化提取(每帧必含全部字段)**:
- **帧编号** F1–FN(自动或引用图内标注)。
- **景别**:从 EXTREME WIDE / WIDE / MEDIUM / MEDIUM CLOSE-UP / CLOSE-UP / EXTREME CLOSE-UP 选最接近一项;图内有标注则引用并括注映射词(如 "WS → WIDE")。
- **镜头运动**:推/拉/摇(方向)/跟/俯拍/仰拍/静止;依画内箭头、标注文字或透视线推断;无法判断标"静止(推断)"。
- **主动作节拍**:主动方(火柴人)核心动作,"部位+运动方向+幅度"格式(如"右臂向右上方大幅挥出");有速度感线/拖尾线则加 `[速度感:爆发/流畅/沉重]`。
- **受击/反应动作**:有第二角色则描述其反应姿态与运动方向;无则标"单角色帧"。
- **画面内标注摘录**:逐字抄录图内所有文字标注(不论中英);无则标"无文字标注"。
- **运动轨迹箭头**:描述箭头起点/指向/含义推断(如"角色从画框左下向右上位移")。

**③ 整板镜头调度归纳**:汇总镜头运动总体节奏(起幅景别→中间变化→落幅景别一句话概括,如"从 WIDE 推进至 ECU,全板以跟随运动为主");识别板内明确切换节点(切割线/"CUT"标注)并标位置;归纳整板动势走向(主要运动方向+节奏强度:起伏/持续爆发/渐进蓄力)。

**④ 多板连续性预判**:多张分镜图时,分析完单板后额外输出跨板连续性摘要——相邻两板落幅帧(前板 FN)与起幅帧(后板 F1)角色位置/朝向是否一致(不一致标 `[需板间衔接备注]`);跨板相同角色身份一致性(依体型比例/角色标注识别);跨板场景切换(背景几何明显变化)标新场景并建议建独立 element scene。

**⑤ Storyboard 映射输出格式**(字段名对齐 shot 定义):
```
[Board N 映射]
- 关联分镜板: [用户提供板编号或自动编号 Board_N]
- 帧范围: F1–FN(共 N 帧)
- 动作节拍序列: F1: … ; F2: … ; … ; FN: …
- 镜头调度: 起幅[景别] → [运动方式] → 落幅[景别];板内切点: [无 / F_N→F_N+1]
- 板间衔接备注: [与上板末帧的角色位置/朝向连续性说明,首板填"首板,无前板参照"]
- 时长上限: 15s
- 待补充项: [列出所有 [待用户补充] 或 [需板间衔接备注] 标记]
```

## 三视图分析(`analyze`,提取跨板稳定复用视觉锚点)

每项须给具体描述而非"正常/无特殊":
- **① 面部身份锚点**:脸型轮廓(方形下颌/瓜子脸/宽颧骨);五官关键特征(眉形粗细颜色、眼型眼距、鼻梁高宽、唇形唇色);肤色肤质(色号范围,如 warm medium-tan / pale cool-toned);发型结构(发际线位置、分区、长度、质感 直/卷/蓬松/贴头皮);发色(主色+次色/挑染,避免仅写"黑",补光泽倾向 哑光黑/蓝黑光泽)。
- **② 体型比例**:整体身高体型分类(高挑/中等/矮壮/纤细);肩宽与腰臀比视觉印象;手部/颈部等局部可识别特征。
- **③ 服装造型**:上装(款式+主色+次色/图案+领型袖型);下装(款式+主色+长度+版型 修身/宽松);鞋履(类型+颜色+鞋底厚度);材质质感关键词 2–3 个(matte cotton/shiny leather/worn denim);标志性配件(类型+颜色+佩戴位置,如 right wrist silver chain bracelet)。
- **④ 三视图一致性校验**:对比正/侧/背三图,指出各视角颜色差异或细节不一致(如侧面服装偏暗、背面有背包正面未体现),注明"以正面图为准"或"以用户说明为准";任一视角缺失则标缺失方向并说明对后续生成的影响。
- **输出格式**:结构化文本按①–④分段、短句/关键词组列举供直接复制引用,不输出叙事段落。

**场景参考图分析**:识别空间结构与关键视觉锚点(环境类型 室内/室外/特定地点、主构成元素 建筑轮廓/地面材质/光源方向色调/背景层次、可跨板稳定复用的视觉特征),输出结构化 element scene description 基础。

## Storyboard 设计(含节拍密度分档)

- **Key Elements**:每出现角色建 element character(description 基于三视图分析;未提供三视图标"待补充"提示上传);每主要场景/地点建 element scene(空间结构/光线方向/背景锚点/色调氛围,有参考图则须与图一致不矛盾、无则给足细致描述供生成)。
- **Shot 设计(每板=一 shot,≤8 动作节拍)**:含 关联分镜板(分镜图 asset_id 或板编号)、动作节拍序列(按帧序简述核心动作/方向/动势)、镜头调度(起幅/落幅、运动类型、景别变化)、板间衔接备注(与上板末帧连续性要求,首板留空)。
- **节拍密度标注(核心,非全统一 ≤15s)**:每板标 高密度(爆发板)/低密度(过渡板):
  - **爆发板**:连续打击/冲撞/多人混战,节拍因果紧密无停顿蓄力段;目标 **6–8s**。
  - **过渡板**:拉开距离/蓄力/喘息/镜头大幅推拉等慢节奏;目标 **10–15s**。
  - 混合板以主导内容判定,或备注说明分段节奏意图。**时长目标据节拍密度填,不强制统一 15s 上限**。
- **模式 B 专项**:shot 字段直接从"Storyboard 映射输出"提取一一对应填入,**保持原始推断不自行扩写**;标 `[待用户补充]`/`[无法解读]` 的字段保留相同标记待暂停点 3 补充或放弃、**不得用推测填充**;跨板 element scene 按分析工具场景切换识别新增(来源标"[分析工具推断,待用户确认]",未识别则默认共用同一 scene);角色 element 按识别的多角色分别建条目,description 空或仅填极简特征(如"高体型,右侧主动方")待三视图补全。
- **音频轨**:需要则规划 audio_layer,**动作 PREVIS 默认无旁白轨**。

## PREVIS 分镜图提示词(generate_image_v3 — GPT Image 2)

**核心设计原则:自解释**——图应有足够视觉信息密度使 Seedance 能直接从图读取动作编排/空间关系/镜头意图,尽量减少对文字依赖;每格须做到即便不读提示词也能从标注/箭头/线条理解该帧发生了什么。

**核心约束(每条提示必含,放最前)**:
- **风格锁定**:极简粗粝手绘分镜风格,全部角色仅用火柴人(stick figures),禁真实人体结构/肌肉/服装/裤子/鞋子/任何角色细节。
- **线条风格**:粗细不均手绘铅笔/炭笔感线条、允许轻微抖动与不规则(速写张力),禁光滑矢量线条/数字清稿感;关键动势用粗重线、辅助参考线(透视线/轨迹线)用细虚线。
- **背景处理**:极简,仅用几何轮廓线(方块=建筑/掩体、水平线=地面/台阶、斜线=斜面)示意空间关系,禁写实纹理/填充色块/细节贴图;整体纯白或极浅冷灰纸面色,只有线条、无渐变阴影填充。
- **标注语言**:所有镜头标注/动作说明/技术指令一律**英文**(PUSH IN、WIDE SHOT、POV、IMPACT、×2 SPEED),禁画格内出现中文。
- **单图多格布局**:明确格数(≤16),排 4×4 网格,每格独立构图、格间细实线分隔,每格左上角可有小号灰色帧编号(F1–F16)。

**逐格视觉信息密度 7 层(核心,缺任一层导致 Seedance 参考信息不足)**:
- **① 运动矢量箭头**:为每个运动的肢体/部位绘独立带箭头轨迹线,箭头长度反映幅度(大幅=长箭头)、粗细反映力度(爆发=粗箭头);角色整体位移另绘全身移动轨迹弧线,与肢体箭头用线型区分(肢体=实线、位移弧=虚线)。
- **② 动势拖尾线**:运动肢体末端(拳/脚尖/膝)绘 2–4 条平行拖尾线,方向为运动反方向表速度感;爆发动作(直拳/扫腿)拖尾延伸至画格边缘或极近处表穿越力度。
- **③ 冲击/接触标注**:任何接触/即将接触的帧在接触点绘爆炸形放射线(星形/菊花形)+英文标注(IMPACT/HIT/BLOCK/GRAB);近距发力(贴身短打)额外绘同心圆或压缩波纹线表力道传导。
- **④ 空间深度标记**:所有帧有明确地平线(水平粗虚线);多角色场景每角色脚下有落地阴影圆点/小横线(表站位);前景角色粗线条、背景角色细线条形成纵深层次。
- **⑤ 角色区分标签**:≥2 角色时每角色头部旁大写字母标签(A/B/C),主动方圈选(①)、被攻击方方框(`[B]`);标签贯穿全板所有画格一致、不随帧变动。
- **⑥ 镜头信息栏**:每格底/顶留一条细横向标注栏——景别缩写(WS/MS/MCU/CU/ECU)+镜头运动(STATIC/PUSH/PULL/PAN-L/PAN-R/TRACK)+可选速度修饰词(SLOW/NORMAL/SNAP);格式示例 `MCU | PUSH | SNAP`。
- **⑦ 帧间过渡指示**:相邻格分隔线处——动作连续用小箭头(→)指示流向;剪切标 CUT;镜头切换(场景改变)标 NEW SHOT 并用双竖线替代单线分隔。

**提示词结构(顺序)**:1. 风格约束+7 层密度要求(压缩为简洁指令);2. 格数与布局声明(如 8-panel grid, 2 rows × 4 columns);3. 按格编号逐一描述(镜头信息+角色标签分配+主要动作矢量方向+冲击点位置+帧间过渡类型);4. 整板动作编排总体节奏(动作因果链一句话,如 A 突破防线→近身发力连打→B/C 相继倒地);5. ImageToImage 模式则指明参考来源与参考维度(构图/动势/镜头语言),**排除角色外观参考**。

## 角色参考图 & 场景概念图提示词

## 视频提示词(generate_video_v3 — Seedance 2.0)

**核心原则:分镜图主导,提示词补漏**。PREVIS 分镜图(`<<<image_1>>>`)已通过运动矢量箭头/拖尾线/冲击标注/镜头信息栏编码大量动作与镜头信息——是 Seedance 的**首要参考源**;提示词唯一职责是补分镜图无法编码的:速度质感词、角色因果关系、音效指令。

**【强制减法原则】** 凡分镜图已清晰表达的内容,提示词**一律省略或只留 1–2 关键词**,不展开:
- 已有运动矢量箭头 → 肢体动作描述**省略**,仅留速度质感词(如 explosive)。
- 已有镜头信息栏(MCU|PUSH|SNAP)→ 镜头运动**简写为一句**(medium close-up, push in),不展开。
- 已有冲击标注(IMPACT)→ 接触点描述**省略**,仅留音效标注(`<sharp impact crack>`)。
- 已有角色标签和位置信息 → 空间调度描述**省略**。
- ✅ 正确(分镜已有箭头):`F1: explosive; F2: recoils from impact, weight shifts back; F3: snapping`
- ❌ 错误(重复分镜已有):`F1: right arm swings upward in a 120° arc at explosive speed, fist clenched, elbow leads`

违反(提示词与分镜图高度重复)会导致文字权重压制视觉参考、生成偏离分镜意图。

**参考输入绑定**:`<<<image_1>>>`=PREVIS 分镜图(首要);`<<<image_2>>>, <<<image_3>>>…`=各角色三视图(每角色一张,按出场顺序);`<<<video_1>>>`=上一板 final_shot(仅连续性极强时,默认省略)。

**提示词结构(运动栈顺序,严格按层级)**:
- **① 镜头运动**:分镜信息栏已标的只写一句概括不展开;补充价值在速度质感词。格式 `[起幅景别] → [运动方式] → [落幅景别]`;景别锁定 EXTREME WIDE/WIDE/MEDIUM/MEDIUM CLOSE-UP/CLOSE-UP/EXTREME CLOSE-UP;多镜头切换按节拍顺序用"→ cut →"分隔、不用时间码。示例:`WIDE SHOT, swift push in → cut → EXTREME CLOSE-UP on fist impact, lock-off`。
- **② 角色动作**:减法优先,分镜箭头已明确的只写速度质感词,只有因果关系(被击后重心后移/对冲互锁)才展开;多节拍按 F1→F8 顺序、每节拍只写【速度质感词+因果关系(如有)】、分号分隔;多角色先主动作后受击/反应,主从用 in response/simultaneously/recoils 明确。**速度质感标准词**:explosive / snapping / fluid / heavy / weightless / sluggish;**禁 fast/slow 等模糊词**。
- **③ 多角色场景专项(≥2 角色强制)**:
  - **主从顺序**:按"主动方→受击/反应方→次要旁观"逐角色独立成句、角色间用"—"或换行分隔,**禁两角色动作混写一句**。主动方=当前节拍发起力量/位移的一方;双方同步对冲以画面视觉重心(通常画框中央偏近景)为主动方。
  - **因果链接词**:受击/反应方必须用明确因果词引出——in response / simultaneously / recoils from / absorbs the impact / driven back by;**禁用 "and" 简单并列**避免主从模糊。
  - **画框空间分配**:每角色用独立画框位置词锁定,禁用相对词("他们站一起")。两角色默认 主动方 frame left/center-left、受击方 frame right/center-right(分镜图相反则以分镜图为准并注明);三角色+按前景/中景/背景纵深分层(前景=主动方、中景=受击/反应、背景=次要),各层有纵深距离感描述(如 pushed into the background, noticeably smaller in frame)。多角色同时运动每角色运动方向矢量须区分(A drives forward toward frame right; B retreats toward frame left),禁模糊为"两人激烈冲突"。
  - **参考图一一绑定**:严格按角色一一绑定,顺序固定 分镜图(`<<<image_1>>>`)→主动方三视图(`<<<image_2>>>`)→受击/反应方三视图(`<<<image_3>>>`)→次要角色(`<<<image_4>>>` 递增)→场景图(最后 image 占位);每张绑定后在对应角色描述句首用括号注来源占位符,格式 `[ref:image_2] Character A: ...`;**禁将多角色三视图合并为单个 image 占位符,每角色独立占一槽位**保外观提取权重独立。
- **④ 空间调度**:角色画框内位置变化(frame left/right/center/foreground/background/off-screen);与场景元素空间关系须与 PREVIS 背景几何一致;有出入画则明确方向(enters from frame left/exits top frame)。
- **⑤ 音效与对白(仅无独立旁白轨冲突时)**:Seedance 官方语法放末尾——SFX `<sound of heavy footsteps on concrete>`/`<sharp impact crack>`/`<whooshing air burst>`;对白 `{EN: "Get down!"}`(语言代码前置);环境音 `<ambient urban noise, distant siren>`。**优先级:动作冲击音效 > 环境氛围音 > 对白**,三类同时按此序末尾依次列出。
- **⑥ 节拍密度对应速度质感词(据 Storyboard 标注,附在②末尾)**:爆发板追加 `snapping cuts, explosive action rhythm, no slow motion, rapid kinetic energy`;过渡板追加 `deliberate pacing, building tension, smooth camera movement`;两类均禁用 fast/slow 代替标准词。
- **⑦ 固定否定项(每条末尾必附)**:`no subtitles, no text overlay, no wardrobe change, no style shift between cuts`(no wardrobe change 保服装与三视图一致;no style shift between cuts 抑制 Seedance 多节拍板内自动改风格/色调)。

## 视频生成参考输入 & 多板递进策略

- **每板参考输入**:①**PREVIS 分镜图**(该板 asset_id,**首要视觉参考、权重高于文字**;提示词严格执行减法原则);②角色三视图(所有出场角色 asset_id);③场景图(该板 element scene asset_id,无则省略);④上一板 final_shot(可选,仅场景/角色状态连续性极强时作 reference_video,否则省略避免多余动作延续)。时长据节拍密度取整秒(爆发板靠近 6s、过渡板 10–15s),不超 15s。
- **多板递进**:reference_video 门槛随板数收紧——板数 ≤4 常规判断,**≥5 仅衔接备注明确"强连续"的板才引 reference_video**,余板省略避免误差逐板放大;**element 参考图权重保持一致**——无论第几板,三视图+场景图绑定方式与输入顺序须与第 1 板完全一致,不因"前几板已稳定"降低后续完整性;**待修复板不阻塞后续**——某板标"需重生"时后续可续(跳该板 reference_video 链、直接用最近一张已确认 final_shot 作连续性参考),修复完成后若直接后续板已生成则提示用户评估是否因参考缺失需重生后续。

## 跨板一致性(视频生成阶段)

- **场景图复用**:同一 element scene 多板出现强制复用同一 asset_id,禁重复生成/替换新图,仅用户明确要求场景状态变化(时段切换/破坏后场景)才生成新图注册独立 asset_id;每板生成即使主动作与背景无关也须纳入对应场景图稳定色调空间结构。
- **角色位置连续性**:每板生成前读"板间衔接备注"——标明上板末帧位置(如"角色A 画框右侧面朝左")则该板提示词空间调度层将起始状态对齐避免跳切;两板明显动作因果(击打→倒地)则后板首个动作节拍(F1)**必须从被击打角色受力姿态起写**、而非重置中立站姿;无衔接备注(首板/明确场景切换)不强制对齐、按该板分镜图独立调度。
- **三视图兜底**:所有板生成均须附带全部出场角色三视图 asset_id,即使某板某角色戏份极少也不省略引用,防 Seedance 低权重下自行重绘外观。

## 装配一致性检查(`composite_video`,装配前必做)

- **板间拼接**:按 shot 顺序拼接,**默认硬切**(无淡入淡出)保动作冲击感;备注标"连续性极强"可用**极短叠化(≤4 帧)**辅助衔接避跳切感。
- **一致性检查优先级:角色位置跳切 > 场景视觉锚点漂移 > 角色外观漂移**:
  - **角色位置连续性**:逐一核查相邻两板衔接帧(前板末帧 vs 后板首帧)每角色画框位置与朝向,明显跳切(左侧瞬移右侧/朝向无因果反转)在切点加标记、暂停装配提示用户选(重生后板强制指定起始位置 / 接受跳切 蒙太奇意图明确时)。
  - **场景视觉锚点**:核查同一 element scene 多板背景主要锚点(地平线高度/主光源方向/关键背景物体)是否稳定,明显风格漂移/构图突变则标记提示。
  - **角色外观漂移**:相邻板同角色服装色系/发型/标志配件视觉差异则备注注明,提示用户评估是否以更强三视图权重重生对应板。
  - 三者分别处理不混同(前者影响叙事连贯、后两者影响视觉稳定)。
- **音频**:各板含 Seedance 动作音效默认保留;BGM 轨(如有)跨板连续铺设不随切点中断;无旁白轨时动作音效轨音量适度提升增强冲击。
- **导出**:分辨率跟随 Final_Video_Spec(默认 720p),比例默认 16:9。
