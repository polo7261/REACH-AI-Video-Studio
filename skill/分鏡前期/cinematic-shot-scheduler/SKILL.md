# 影视分镜到视频生成公式

## Skill 定位

只负责一件可复用的事：把一张影视参考图或一个影视场景想法，转化为可执行的电影故事板，再用故事板和原图生成视频，自动调度镜头执行。

核心目标：

- 降低用户制作分镜图的时间成本。
- 自动把一个画面扩展成 12 个电影镜头。
- 让故事板负责“镜头设计、运动方向、情绪、构图和调度”。
- 让原图负责“角色、场景、光影、质感和视觉风格”。
- 用 seedance 2.0 fast 或 seedance 2.0 生成与原图风格一致、镜头调度更清晰的视频。

## 模型限制

本 skill 只允许使用以下模型：

```json
{
  "image_model": "Lib image",
  "video_models": ["seedance 2.0 fast", "seedance 2.0"]
}
```

模型选择规则：

- 生图、故事板、参考图补全：只使用 `Lib image`。
- 生视频：优先使用 `seedance 2.0 fast`；如果不可用，再使用 `seedance 2.0`。
- 不使用其他图片模型。
- 不使用其他视频模型。
- 如果指定模型不可用，停止并告知用户，不要自动换成其他模型。

## 输入

用户可以提供以下任意一种输入：

- 一张参考图：作为角色、场景、风格和光影锚点。
- 一段文字场景：例如“雨夜巷子里，侦探追逐一个黑衣人”。
- 一张参考图 + 一段文字：最佳输入方式。
- 一个故事片段、广告概念、MV 场景、短剧桥段或影视情绪关键词。

可选补充信息：

- 类型：剧情片、悬疑、动作、爱情、喜剧、恐怖、广告、MV、纪录感等。
- 情绪：紧张、浪漫、孤独、史诗、荒诞、温暖、压迫、迷幻等。
- 视频时长：默认 8-12 秒；也可按 5 秒、10 秒、15 秒生成。
- 画幅：默认 16:9。
- 镜头强度：写实、电影感、手持感、动作感、梦境感、舞台感等。

## 输入使用

严格遵守：

- 参考图中的主角、主要场景、时代感、服装、光线和视觉风格。
- 故事板中的镜头顺序、景别变化、角色运动、摄影机运动和构图意图。
- 用户明确指定的故事事件、动作和情绪。

作为参考：

- 用户没有明确说明的剧情背景。
- 参考图之外不可见的角色关系。
- 未提供的对白、音乐、音效和剪辑节奏。

不要编造：

- 用户没有提供的 IP、品牌、真实人物、电影名称或版权角色。
- 参考图中不存在的关键角色身份。
- 与原图风格冲突的新世界观。

## 内部流程和 Knowhow

### 1. scene_intake

先判断用户输入属于哪种情况：

```json
{
  "has_reference_image": true,
  "has_text_scene": true,
  "needs_base_image": false,
  "target_video_duration": "8-12s",
  "aspect_ratio": "16:9"
}
```

如果用户只给文字，没有给图：

1. 先用 `Lib image` 生成一张影视场景原图。
2. 把这张图作为后续的 `Mixed 1` 原图参考。
3. 再进入故事板生成。

如果用户已经上传图：

1. 直接把用户上传图作为 `Mixed 1`。
2. 不重新设计角色和场景。
3. 只根据用户文字补充镜头事件和情绪。

### 2. base_image_prompt

仅在用户没有上传参考图时使用。用 `Lib image` 生成一张原始影视场景图。

输出一段适合 Lib image 的影视场景生图提示词，必须包含：

- 主体人物或主体事件。
- 场景空间。
- 情绪和戏剧冲突。
- 光线方向。
- 镜头感。
- 电影质感。
- 16:9 画幅。

避免一次生成复杂剧情，只生成一张能作为视觉锚点的关键帧。

### 3. storyboard_prompt_builder

根据 `Mixed 1` 原图和用户场景，重写一段给 `Lib image` 使用的故事板生图提示词。

固定系统提示必须保留：

```text
为故事板创建一个分镜头，专注于情绪表达和分镜景别策划。使用参考图像作为角色。

16:9 故事板表格，12 个电影风格面板。实际故事板绘图必须仅为黑白：粗糙的铅笔线条、最小细节、快速手势绘图能量、简单的解剖结构构建以及强烈的轮廓可读性。保持艺术作品轻量、动态且未完成，就像早期的编舞预览。

使用电影艺术风格的摄影技巧，带有手持能量、快速平移、环绕运动、头顶镜头、侧面轮廓、侵略性特写、长焦压缩以及极端的负空间。

标注颜色系统：
红色箭头 = 身体运动
蓝色箭头 = 摄影机运动
绿色标记 = 取景 / 构图笔记
橙色标记 = 灯光方向
紫色标记 = 声音 / 情感强调
黑色文本 = 简短镜头笔记和面板标签

无时间戳。
```

故事板生图提示词模板：

```text
文本节点中的提示词生成出来的 12 宫格分镜黑白故事板。现在根据文本节点中的提示词结构，重新编写一段生图提示词，主要内容是创建一个影视场景。

使用 @图片1 作为参考图像，保持角色、场景、时代感、服装、光影和视觉风格一致。

故事事件：{用户场景或自动补全的影视事件}
核心情绪：{情绪}
镜头调度目标：用 12 个电影风格面板表现角色动作、摄影机运动、情绪推进、构图变化和光线方向。

输出要求：
16:9 故事板表格，12 个电影风格面板。实际故事板绘图仅为黑白粗糙铅笔线条，最小细节，快速手势绘图能量，简单解剖结构，强轮廓可读性。保留轻量、动态、未完成的早期编舞预览感。

摄影技巧：
手持能量、快速平移、环绕运动、头顶镜头、侧面轮廓、侵略性特写、长焦压缩、极端负空间。

标注颜色系统：
红色箭头 = 身体运动
蓝色箭头 = 摄影机运动
绿色标记 = 取景 / 构图笔记
橙色标记 = 灯光方向
紫色标记 = 声音 / 情感强调
黑色文本 = 简短镜头笔记和面板标签

无时间戳。
```

### 4. storyboard_generation

使用 `Lib image` 生成 `Mixed 2` 故事板。

故事板必须符合：

- 16:9。
- 12 宫格。
- 黑白铅笔线条为主体。
- 只允许标注箭头和文字使用指定颜色。
- 每格都要有明确景别或摄影机意图。
- 不能生成彩色成片画面。
- 不能加时间戳。
- 不能把故事板画成精细漫画、海报或成片截图。

### 5. storyboard_interpreter

读取生成的故事板，把 12 个面板整理成镜头计划。

输出结构：

```json
{
  "panel_id": 1,
  "shot_size": "wide / medium / close-up / extreme close-up / overhead",
  "character_action": "",
  "camera_motion": "",
  "composition_note": "",
  "lighting_note": "",
  "emotion_or_sound_note": "",
  "video_use": "primary / optional"
}
```

如果用户只需要一个短视频，不一定逐格生成 12 个片段。应该选择最有连续性的 3-6 个核心面板，用它们指导 seedance 生成一个完整视频。

### 6. seedance_video_prompt_builder

根据 `Mixed 1` 原图和 `Mixed 2` 故事板生成 seedance 视频提示词。

基础提示词必须保留：

```text
参考 {{Mixed 2}} 的故事板，参考 {{Mixed 1}} 的画面，生成视觉风格一样的视频。
```

推荐扩展模板：

```text
参考 {{Mixed 2}} 的故事板，参考 {{Mixed 1}} 的画面，生成视觉风格一样的视频。

保持 {{Mixed 1}} 中的角色、服装、场景、时代感、光线、色彩、镜头质感和整体美术风格。
使用 {{Mixed 2}} 的 12 宫格故事板作为镜头调度参考：遵守角色运动方向、摄影机运动、景别变化、构图重心、灯光方向和情绪强调。

视频内容：
{用 1-3 句话概括故事事件}

镜头语言：
{从故事板提取 3-6 个关键镜头：开场、动作推进、情绪特写、空间关系、高潮动作、收束画面}

运动要求：
自然电影摄影机运动，避免突然变形，避免角色身份变化，避免场景跳变。动作要连续，光影要稳定，角色要和原图一致。

风格要求：
cinematic, live action, same visual style as reference image, coherent motion, dramatic composition, emotional performance, natural camera movement.
```

负面约束：

```text
do not change character identity, do not change costume, do not change location, no extra characters unless storyboard shows them, no distorted face, no deformed hands, no broken body, no flicker, no sudden style change, no cartoon style, no storyboard lines in final video, no timestamps, no subtitles, no text overlay
```

### 7. video_generation

使用视频模型生成视频：

1. 优先使用 `seedance 2.0 fast`。
2. 如果需要更高质量或 fast 不可用，使用 `seedance 2.0`。
3. 输入必须包含 `Mixed 1` 原图和 `Mixed 2` 故事板。
4. 不使用其他视频模型。

如果生成结果不稳定：

- 缩短视频时长。
- 减少镜头事件。
- 从故事板中选择 3-4 个关键面板生成单段视频。
- 或拆成多个 3-5 秒片段后再拼接。

## Prompt Guide

### Lib image 故事板 prompt 判断标准

好 prompt 应该：

- 明确是“故事板”，不是成片图。
- 明确 12 宫格、16:9、黑白铅笔线条。
- 明确保留参考图角色和场景。
- 明确电影镜头技巧。
- 明确颜色标注系统。
- 明确无时间戳。

差 prompt 通常会：

- 只说“生成分镜图”，没有镜头调度。
- 没有要求黑白铅笔故事板。
- 让画面过度精细或变成漫画。
- 没有解释箭头和颜色标注。
- 没有约束角色和场景一致性。

### seedance prompt 判断标准

好 prompt 应该：

- 同时引用原图和故事板。
- 明确原图负责视觉风格，故事板负责镜头调度。
- 用 1-3 句话说明视频事件。
- 提取 3-6 个核心镜头，不强迫模型完整执行 12 个面板。
- 明确禁止角色、服装、场景和风格漂移。

差 prompt 通常会：

- 只说“参考故事板生成视频”，没有说明参考原图。
- 要求一次执行太多镜头。
- 没有约束角色一致性。
- 把故事板线条、箭头、文字也带进最终视频。

## 自检

输出前检查：

- 是否只使用 `Lib image`、`seedance 2.0 fast`、`seedance 2.0`。
- 是否没有推荐或调用其他模型。
- 故事板是否明确为 16:9、12 宫格、黑白铅笔线条。
- 故事板是否保留彩色标注系统，但主体绘图仍为黑白。
- 是否无时间戳。
- seedance prompt 是否同时参考 `Mixed 1` 原图和 `Mixed 2` 故事板。
- 是否清楚区分“原图控制风格”和“故事板控制镜头调度”。
- 是否避免把故事板线条、箭头、文字带入最终视频。
- 是否避免角色、服装、场景和时代感漂移。

## Ask User

只有以下情况需要追问：

- 用户既没有上传图，也没有提供任何场景文字。
- 用户要求生成明确 IP、真实影视作品角色、名人或受版权保护角色。
- 用户想要很长视频，但没有说明剧情结构。
- 用户要求的视频动作过于复杂，必须确认拆成多段生成。

优先追问 1-3 个问题：

1. 你想用上传图作为原图，还是先生成一张新的影视场景图？
2. 这个片段的核心情绪是什么：紧张、浪漫、动作、悬疑、温暖、史诗，还是其他？
3. 最终视频想要几秒，是否接受拆成多个片段再拼接？
