# 影視分鏡到影片生成公式

## Skill 定位

只負責一件可複用的事：把一張影視參考圖或一個影視場景想法，轉化為可執行的電影故事板，再用故事板和原圖生成影片，自動排程鏡頭執行。

核心目標：

- 降低使用者製作分鏡圖的時間成本。
- 自動把一個畫面擴充套件成 12 個電影鏡頭。
- 讓故事板負責“鏡頭設計、運動方向、情緒、構圖和排程”。
- 讓原圖負責“角色、場景、光影、質感和視覺風格”。
- 用 seedance 2.0 fast 或 seedance 2.0 生成與原圖風格一致、鏡頭排程更清晰的影片。

## 模型限制

本 skill 只允許使用以下模型：

```json
{
  "image_model": "Lib image",
  "video_models": ["seedance 2.0 fast", "seedance 2.0"]
}
```

模型選擇規則：

- 生圖、故事板、參考圖補全：只使用 `Lib image`。
- 生影片：優先使用 `seedance 2.0 fast`；如果不可用，再使用 `seedance 2.0`。
- 不使用其他圖片模型。
- 不使用其他影片模型。
- 如果指定模型不可用，停止並告知使用者，不要自動換成其他模型。

## 輸入

使用者可以提供以下任意一種輸入：

- 一張參考圖：作為角色、場景、風格和光影錨點。
- 一段文字場景：例如“雨夜巷子裡，偵探追逐一個黑衣人”。
- 一張參考圖 + 一段文字：最佳輸入方式。
- 一個故事片段、廣告概念、MV 場景、短劇橋段或影視情緒關鍵詞。

可選補充資訊：

- 型別：劇情片、懸疑、動作、愛情、喜劇、恐怖、廣告、MV、紀錄感等。
- 情緒：緊張、浪漫、孤獨、史詩、荒誕、溫暖、壓迫、迷幻等。
- 影片時長：預設 8-12 秒；也可按 5 秒、10 秒、15 秒生成。
- 畫幅：預設 16:9。
- 鏡頭強度：寫實、電影感、手持感、動作感、夢境感、舞臺感等。

## 輸入使用

嚴格遵守：

- 參考圖中的主角、主要場景、時代感、服裝、光線和視覺風格。
- 故事板中的鏡頭順序、景別變化、角色運動、攝影機運動和構圖意圖。
- 使用者明確指定的故事事件、動作和情緒。

作為參考：

- 使用者沒有明確說明的劇情背景。
- 參考圖之外不可見的角色關係。
- 未提供的對白、音樂、音效和剪輯節奏。

不要編造：

- 使用者沒有提供的 IP、品牌、真實人物、電影名稱或版權角色。
- 參考圖中不存在的關鍵角色身份。
- 與原圖風格衝突的新世界觀。

## 內部流程和 Knowhow

### 1. scene_intake

先判斷使用者輸入屬於哪種情況：

```json
{
  "has_reference_image": true,
  "has_text_scene": true,
  "needs_base_image": false,
  "target_video_duration": "8-12s",
  "aspect_ratio": "16:9"
}
```

如果使用者只給文字，沒有給圖：

1. 先用 `Lib image` 生成一張影視場景原圖。
2. 把這張圖作為後續的 `Mixed 1` 原圖參考。
3. 再進入故事板生成。

如果使用者已經上傳圖：

1. 直接把使用者上傳圖作為 `Mixed 1`。
2. 不重新設計角色和場景。
3. 只根據使用者文字補充鏡頭事件和情緒。

### 2. base_image_prompt

僅在使用者沒有上傳參考圖時使用。用 `Lib image` 生成一張原始影視場景圖。

輸出一段適合 Lib image 的影視場景生圖提示詞，必須包含：

- 主體人物或主體事件。
- 場景空間。
- 情緒和戲劇衝突。
- 光線方向。
- 鏡頭感。
- 電影質感。
- 16:9 畫幅。

避免一次生成複雜劇情，只生成一張能作為視覺錨點的關鍵幀。

### 3. storyboard_prompt_builder

根據 `Mixed 1` 原圖和使用者場景，重寫一段給 `Lib image` 使用的故事板生圖提示詞。

固定系統提示必須保留：

```text
為故事板建立一個分鏡頭，專注於情緒表達和分鏡景別策劃。使用參考影象作為角色。

16:9 故事板表格，12 個電影風格面板。實際故事板繪圖必須僅為黑白：粗糙的鉛筆線條、最小細節、快速手勢繪圖能量、簡單的解剖結構構建以及強烈的輪廓可讀性。保持藝術作品輕量、動態且未完成，就像早期的編舞預覽。

使用電影藝術風格的攝影技巧，帶有手持能量、快速平移、環繞運動、頭頂鏡頭、側面輪廓、侵略性特寫、長焦壓縮以及極端的負空間。

標註顏色系統：
紅色箭頭 = 身體運動
藍色箭頭 = 攝影機運動
綠色標記 = 取景 / 構圖筆記
橙色標記 = 燈光方向
紫色標記 = 聲音 / 情感強調
黑色文字 = 簡短鏡頭筆記和麵板標籤

無時間戳。
```

故事板生圖提示詞模板：

```text
文字節點中的提示詞生成出來的 12 宮格分鏡黑白故事板。現在根據文字節點中的提示詞結構，重新編寫一段生圖提示詞，主要內容是建立一個影視場景。

使用 @圖片1 作為參考影象，保持角色、場景、時代感、服裝、光影和視覺風格一致。

故事事件：{使用者場景或自動補全的影視事件}
核心情緒：{情緒}
鏡頭排程目標：用 12 個電影風格面板表現角色動作、攝影機運動、情緒推進、構圖變化和光線方向。

輸出要求：
16:9 故事板表格，12 個電影風格面板。實際故事板繪圖僅為黑白粗糙鉛筆線條，最小細節，快速手勢繪圖能量，簡單解剖結構，強輪廓可讀性。保留輕量、動態、未完成的早期編舞預覽感。

攝影技巧：
手持能量、快速平移、環繞運動、頭頂鏡頭、側面輪廓、侵略性特寫、長焦壓縮、極端負空間。

標註顏色系統：
紅色箭頭 = 身體運動
藍色箭頭 = 攝影機運動
綠色標記 = 取景 / 構圖筆記
橙色標記 = 燈光方向
紫色標記 = 聲音 / 情感強調
黑色文字 = 簡短鏡頭筆記和麵板標籤

無時間戳。
```

### 4. storyboard_generation

使用 `Lib image` 生成 `Mixed 2` 故事板。

故事板必須符合：

- 16:9。
- 12 宮格。
- 黑白鉛筆線條為主體。
- 只允許標註箭頭和文字使用指定顏色。
- 每格都要有明確景別或攝影機意圖。
- 不能生成彩色成片畫面。
- 不能加時間戳。
- 不能把故事板畫成精細漫畫、海報或成片截圖。

### 5. storyboard_interpreter

讀取生成的故事板，把 12 個面板整理成鏡頭計劃。

輸出結構：

```json
{
  "panel_id": 1,
  "shot_size": "wide / medium / close-up / extreme close-up / overhead",
  "character_action": "",
  "camera_motion": "",
  "composition_note": "",
  "lighting_note": "",
  "emotion_or_sound_note": "",
  "video_use": "primary / optional"
}
```

如果使用者只需要一個短影片，不一定逐格生成 12 個片段。應該選擇最有連續性的 3-6 個核心面板，用它們指導 seedance 生成一個完整影片。

### 6. seedance_video_prompt_builder

根據 `Mixed 1` 原圖和 `Mixed 2` 故事板生成 seedance 影片提示詞。

基礎提示詞必須保留：

```text
參考 {{Mixed 2}} 的故事板，參考 {{Mixed 1}} 的畫面，生成視覺風格一樣的影片。
```

推薦擴充套件模板：

```text
參考 {{Mixed 2}} 的故事板，參考 {{Mixed 1}} 的畫面，生成視覺風格一樣的影片。

保持 {{Mixed 1}} 中的角色、服裝、場景、時代感、光線、色彩、鏡頭質感和整體美術風格。
使用 {{Mixed 2}} 的 12 宮格故事板作為鏡頭排程參考：遵守角色運動方向、攝影機運動、景別變化、構圖重心、燈光方向和情緒強調。

影片內容：
{用 1-3 句話概括故事事件}

鏡頭語言：
{從故事板提取 3-6 個關鍵鏡頭：開場、動作推進、情緒特寫、空間關係、高潮動作、收束畫面}

運動要求：
自然電影攝影機運動，避免突然變形，避免角色身份變化，避免場景跳變。動作要連續，光影要穩定，角色要和原圖一致。

風格要求：
cinematic, live action, same visual style as reference image, coherent motion, dramatic composition, emotional performance, natural camera movement.
```

負面約束：

```text
do not change character identity, do not change costume, do not change location, no extra characters unless storyboard shows them, no distorted face, no deformed hands, no broken body, no flicker, no sudden style change, no cartoon style, no storyboard lines in final video, no timestamps, no subtitles, no text overlay
```

### 7. video_generation

使用影片模型生成影片：

1. 優先使用 `seedance 2.0 fast`。
2. 如果需要更高質量或 fast 不可用，使用 `seedance 2.0`。
3. 輸入必須包含 `Mixed 1` 原圖和 `Mixed 2` 故事板。
4. 不使用其他影片模型。

如果生成結果不穩定：

- 縮短影片時長。
- 減少鏡頭事件。
- 從故事板中選擇 3-4 個關鍵面板生成單段影片。
- 或拆成多個 3-5 秒片段後再拼接。

## Prompt Guide

### Lib image 故事板 prompt 判斷標準

好 prompt 應該：

- 明確是“故事板”，不是成片圖。
- 明確 12 宮格、16:9、黑白鉛筆線條。
- 明確保留參考圖角色和場景。
- 明確電影鏡頭技巧。
- 明確顏色標註系統。
- 明確無時間戳。

差 prompt 通常會：

- 只說“生成分鏡圖”，沒有鏡頭排程。
- 沒有要求黑白鉛筆故事板。
- 讓畫面過度精細或變成漫畫。
- 沒有解釋箭頭和顏色標註。
- 沒有約束角色和場景一致性。

### seedance prompt 判斷標準

好 prompt 應該：

- 同時引用原圖和故事板。
- 明確原圖負責視覺風格，故事板負責鏡頭排程。
- 用 1-3 句話說明影片事件。
- 提取 3-6 個核心鏡頭，不強迫模型完整執行 12 個面板。
- 明確禁止角色、服裝、場景和風格漂移。

差 prompt 通常會：

- 只說“參考故事板生成影片”，沒有說明參考原圖。
- 要求一次執行太多鏡頭。
- 沒有約束角色一致性。
- 把故事板線條、箭頭、文字也帶進最終影片。

## 自檢

輸出前檢查：

- 是否只使用 `Lib image`、`seedance 2.0 fast`、`seedance 2.0`。
- 是否沒有推薦或呼叫其他模型。
- 故事板是否明確為 16:9、12 宮格、黑白鉛筆線條。
- 故事板是否保留彩色標註系統，但主體繪圖仍為黑白。
- 是否無時間戳。
- seedance prompt 是否同時參考 `Mixed 1` 原圖和 `Mixed 2` 故事板。
- 是否清楚區分“原圖控制風格”和“故事板控制鏡頭排程”。
- 是否避免把故事板線條、箭頭、文字帶入最終影片。
- 是否避免角色、服裝、場景和時代感漂移。

## Ask User

只有以下情況需要追問：

- 使用者既沒有上傳圖，也沒有提供任何場景文字。
- 使用者要求生成明確 IP、真實影視作品角色、名人或受版權保護角色。
- 使用者想要很長影片，但沒有說明劇情結構。
- 使用者要求的影片動作過於複雜，必須確認拆成多段生成。

優先追問 1-3 個問題：

1. 你想用上傳圖作為原圖，還是先生成一張新的影視場景圖？
2. 這個片段的核心情緒是什麼：緊張、浪漫、動作、懸疑、溫暖、史詩，還是其他？
3. 最終影片想要幾秒，是否接受拆成多個片段再拼接？
