# cinematic-motion-realism

要写实电影级运动（不是动画/动效/UGC）时，用本 skill 给视频 prompt 注入真实感。工艺全量内联、自足，无需外挂别的 skill。

> 本环境适配：Seedance 2.0 / MultiModalToVideo → `generate_video_v3`；材质物理/环境力/克制表演等真实感指令直接嵌入 prompt 文本，无独立工具调用。音频内嵌格式按 SP（音效 `<>`、台词 `{}`、字幕 `【】`、音乐 `()`）。源为 Seedance 电影级 prompt 工艺，本环境同引擎适用。

## 何时用

真实身体动作、自然人类行为、情绪特写（克制表演）、驾驶/亲密/打斗/动作场面、环境互动（风雨水阻尘重力）、写实运动生成。风格化 CGI/动画/动效不走本 skill。

## 核心原则：真实感来自克制，不是奇观

五根接地支柱：① **身体重量与物理**（演员有质量，动作有摩擦/动量/接触力）② **环境力**（风/水/重力/织物对演员反推）③ **情绪克制**（微表情/憋住的节拍/呼吸，不夸张预告）④ **相机作为观察者**（镜头有自己的物理存在）⑤ **连续性锚点**（光向/服装/时段跨镜延续）。

## 接地 prompt 六块结构

`[风格与情绪] [镜头方向] [演员行为] [环境力] [相机行为] [音频]`
1. **风格与情绪**（1 句）：摄影师词汇「35mm 变形镜、自然主义色彩、柔对比」，不堆形容词。**禁关键词汤**（"8k / masterpiece / trending"），用技术描述替代。
2. **镜头方向**（1 句）：主谓宾 + 地点，不要不做结构功的形容词。
3. **演员行为**（2–3 句）：**必含**重量线索 + 一个微动作 + 一个憋住的节拍。用流畅的过渡语言，不要"他跑然后停下"这类断裂动作。**禁**：「泪流满面」「他狂奔」「咧嘴大笑」。
4. **环境力**（1–2 句）：什么在反推演员——空气/水/重力/表面/光源。用物理关系触发模型推理（如"霓虹在雨湿沥青上的反光"），别写"好光线"。
5. **相机行为**（1 句）：默认词汇「锁定静帧」「缓慢手持呼吸」「步速推入」。别在同段里下矛盾指令（"静止相机"+"环绕"）。
6. **音频**（1 句）：先环境后人声，如「环境：仅室内声。无对白，无音乐」。**音频始终写一句**——引擎原生生成音频，不写则随机音不匹配画面。

## 场景模式

- **驾驶（车内）**：锁定或极轻手持；手在方向盘 9 点 3 点。
- **情绪特写（克制）**：无泪、无预告悲伤；表演在憋住的节拍与微动作里。
- **动作（脚步追逐）**：步幅紧凑、肩先行；用流畅衔接，别多动作塞进 4–5s。
- **打斗（肢体明确性）**：动作 = 意图 + 具名技法 + **明确肢体** + 接触点；绝不用含糊的"旋踢/spinning kick"（会让引擎混淆左右肢），写"右腿前踢""左臂格挡"。将受击的角色必须在**主动反应**（格挡/闪避/反制），不被动僵立。张力来自**剪切密度**而非单镜奇观——一镜内多 beat 打斗按秒分区、每秒一动作、镜别激进变化（勿连续两个 WIDE，每次 IMPACT 落在 CU/ECU）。
- **亲密（克制贴近）**：由"不动作"构建，克制加吻/泪/耳语。
- **环境互动（天气即角色）**：风要塑造多个元素（头发/外套/草/海鸥）。

## 连续性锚点（多镜序列，每镜逐字复制）

① 光照锚（同光源同方向）② 服装锚（完整描述、同措辞）③ 时段锚（显式）④ 地理锚（上镜结束时演员在哪）⑤ 音床锚（同环境签名）。避免在单镜里做复杂主体变形（"人变成鸟"），破真实感与时序一致性。

## 提交默认与失败模式

默认：`aspect_ratio` 21:9 或 16:9；单镜 `duration` 6–10s（一动作一 beat，10–15s 至多 3–4 beat）；音频始终开。
| 症状 | 病因 | 修 |
|---|---|---|
| 漂浮运动 | 无身体重量线索 | 加重量/质量线索 |
| 静止环境 | 无环境力 | 加风/重力/表面 |
| 过度表演的脸 | 用了"哭/暴怒"动词 | 换成微动作 |
| 飞天相机 | "横扫/史诗" | 换成具体镜头词汇 |
| 摄影棚感 | 无环境力+无音频 | 补第 4、6 块 |
| 连续性漂移 | 未复制锚点 | 五锚点逐镜复制 |
| 打斗动作糊/左右错 | 含糊技法词、单镜过载 | 具名肢体+接触点，一段一动作 |
| 音频不匹配 | 漏写音频指令 | 补音频块（引擎原生出音） |

## 用法

把上述写进 `generate_video_v3` 的 prompt；写实题材优先于风格化描述。多镜序列逐镜复制连续性锚点。
