# cinematic-motion-realism

要寫實電影級運動（不是動畫/動效/UGC）時，用本 skill 給影片 prompt 注入真實感。工藝全量內聯、自足，無需外掛別的 skill。

> 本環境適配：Seedance 2.0 / MultiModalToVideo → `generate_video_v3`；材質物理/環境力/剋制表演等真實感指令直接嵌入 prompt 文字，無獨立工具呼叫。音訊內嵌格式按 SP（音效 `<>`、臺詞 `{}`、字幕 `【】`、音樂 `()`）。源為 Seedance 電影級 prompt 工藝，本環境同引擎適用。

## 何時用

真實身體動作、自然人類行為、情緒特寫（剋制表演）、駕駛/親密/打鬥/動作場面、環境互動（風雨水阻塵重力）、寫實運動生成。風格化 CGI/動畫/動效不走本 skill。

## 核心原則：真實感來自剋制，不是奇觀

五根接地支柱：① **身體重量與物理**（演員有質量，動作有摩擦/動量/接觸力）② **環境力**（風/水/重力/織物對演員反推）③ **情緒剋制**（微表情/憋住的節拍/呼吸，不誇張預告）④ **相機作為觀察者**（鏡頭有自己的物理存在）⑤ **連續性錨點**（光向/服裝/時段跨鏡延續）。

## 接地 prompt 六塊結構

`[風格與情緒] [鏡頭方向] [演員行為] [環境力] [相機行為] [音訊]`
1. **風格與情緒**（1 句）：攝影師詞彙「35mm 變形鏡、自然主義色彩、柔對比」，不堆形容詞。**禁關鍵詞湯**（"8k / masterpiece / trending"），用技術描述替代。
2. **鏡頭方向**（1 句）：主謂賓 + 地點，不要不做結構功的形容詞。
3. **演員行為**（2–3 句）：**必含**重量線索 + 一個微動作 + 一個憋住的節拍。用流暢的過渡語言，不要"他跑然後停下"這類斷裂動作。**禁**：「淚流滿面」「他狂奔」「咧嘴大笑」。
4. **環境力**（1–2 句）：什麼在反推演員——空氣/水/重力/表面/光源。用物理關係觸發模型推理（如"霓虹在雨溼瀝青上的反光"），別寫"好光線"。
5. **相機行為**（1 句）：預設詞彙「鎖定靜幀」「緩慢手持呼吸」「步速推入」。別在同段裡下矛盾指令（"靜止相機"+"環繞"）。
6. **音訊**（1 句）：先環境後人聲，如「環境：僅室內聲。無對白，無音樂」。**音訊始終寫一句**——引擎原生生成音訊，不寫則隨機音不匹配畫面。

## 場景模式

- **駕駛（車內）**：鎖定或極輕手持；手在方向盤 9 點 3 點。
- **情緒特寫（剋制）**：無淚、無預告悲傷；表演在憋住的節拍與微動作裡。
- **動作（腳步追逐）**：步幅緊湊、肩先行；用流暢銜接，別多動作塞進 4–5s。
- **打鬥（肢體明確性）**：動作 = 意圖 + 具名技法 + **明確肢體** + 接觸點；絕不用含糊的"旋踢/spinning kick"（會讓引擎混淆左右肢），寫"右腿前踢""左臂格擋"。將受擊的角色必須在**主動反應**（格擋/閃避/反制），不被動僵立。張力來自**剪下密度**而非單鏡奇觀——一鏡內多 beat 打鬥按秒分割槽、每秒一動作、鏡別激進變化（勿連續兩個 WIDE，每次 IMPACT 落在 CU/ECU）。
- **親密（剋制貼近）**：由"不動作"構建，剋制加吻/淚/耳語。
- **環境互動（天氣即角色）**：風要塑造多個元素（頭髮/外套/草/海鷗）。

## 連續性錨點（多鏡序列，每鏡逐字複製）

① 光照錨（同光源同方向）② 服裝錨（完整描述、同措辭）③ 時段錨（顯式）④ 地理錨（上鏡結束時演員在哪）⑤ 音床錨（同環境簽名）。避免在單鏡裡做複雜主體變形（"人變成鳥"），破真實感與時序一致性。

## 提交預設與失敗模式

預設：`aspect_ratio` 21:9 或 16:9；單鏡 `duration` 6–10s（一動作一 beat，10–15s 至多 3–4 beat）；音訊始終開。
| 症狀 | 病因 | 修 |
|---|---|---|
| 漂浮運動 | 無身體重量線索 | 加重量/質量線索 |
| 靜止環境 | 無環境力 | 加風/重力/表面 |
| 過度表演的臉 | 用了"哭/暴怒"動詞 | 換成微動作 |
| 飛天相機 | "橫掃/史詩" | 換成具體鏡頭詞彙 |
| 攝影棚感 | 無環境力+無音訊 | 補第 4、6 塊 |
| 連續性漂移 | 未複製錨點 | 五錨點逐鏡複製 |
| 打鬥動作糊/左右錯 | 含糊技法詞、單鏡過載 | 具名肢體+接觸點，一段一動作 |
| 音訊不匹配 | 漏寫音訊指令 | 補音訊塊（引擎原生出音） |

## 用法

把上述寫進 `generate_video_v3` 的 prompt；寫實題材優先於風格化描述。多鏡序列逐鏡複製連續性錨點。
