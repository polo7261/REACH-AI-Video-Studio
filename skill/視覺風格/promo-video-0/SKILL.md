# promo-video —— 一图生成宣传短片（带创意选项）

## 定位

在 libtv-skill 之上加一层「创意引导 + 分步确认」：**本地** 分析参考图 → 给出 3-4 个差异化风格方向 → 用户选 → 走 **脚本 → 分镜 → 合成** 三步，每一步都让用户过一遍再进下一步。

不同于 libtv-skill 的「纯传话」定位，本 skill **允许在选风格这一步做本地创意工作**（用户明确要求）。但一旦风格选定，后续每一步的 prompt 依然按 libtv-skill 的规矩组装：只带用户目标 + 选中风格 + OSS URL / 上一步产物，不堆质量词、不自拆分镜（分镜由 libtv 后端出）。

## 前置条件

- `LIBTV_ACCESS_KEY` 已设置（libtv-skill 前置）。
- 用户已提供本地图片路径（`.jpg` / `.png` / `.webp` 等），大小 < 200MB。
- libtv-skill 的脚本存在于 `../libtv-skill/scripts/`（同一项目下）。若不在同一项目，需要用绝对路径找到 libtv-skill 的 scripts 目录。

## 工作流

**关键原则**：三步（脚本 / 分镜 / 合成）都在**同一个 sessionId** 里追加消息（`--session-id`），让 libtv 后端保留上下文，不要为每一步开新 session。

### 步骤 1：读图 = 读懂产品 + 想宣传方向

用 `Read` 工具打开用户给的图片路径。这一步的目标**不是评鉴画面美感**，而是**先把产品/主体搞明白**，再基于对产品的理解去想「怎么给它拍宣传片」。

**先做产品理解（本地默写下来，别输出给用户）**：

- **是什么**：品类 / 功能 / 形态（比如「一款陶瓷手冲杯」「一张城市文化地图海报」「一个开屏 UI」）
- **看得见的卖点**：从图里能读到的线索 —— 材质、工艺、设计语言、颜色、细节、比例、包装、logo / 品牌调性 …
- **谁会买 / 谁会用**：目标人群画像的合理推测（年龄段、审美取向、消费场景）
- **典型使用场景**：这东西一般在哪、什么时候、跟什么一起用
- **可讲的差异点**：跟同品类相比，这张图透露出的独特之处（哪怕只是猜测）

如果图里信息不足以判断产品（比如只是一张抽象素材、或者是宣传物本身而非产品），**先问用户「这是什么产品 / 你想推广什么？」** 再进入下一步。**不要凭空捏造产品定位**。

**再产出 3-4 个宣传方向**。每个方向要**根植于产品**，不是空谈风格。每个方向给三样东西：

- **风格标签**（1-3 词，比如「暗调电影感」「日系清新」「赛博霓虹」「极简高级」「纪录片式」）
- **卖点切入**（一句话，说这条片子**从产品的哪个卖点切入** —— 材质工艺 / 使用场景 / 情绪共鸣 / 反差对比 / 用户故事 / 数据事实 …）
- **一句 pitch**（一句话说清片子讲什么，写给用户看的「卖点」，必须体现出这个产品的名字或核心属性）

**差异化要求**：4 个方向要在「切入的卖点 / 情绪 / 叙事结构」至少 2 个维度上错开。不要出现 4 条方向都在讲「使用场景」只是换了风格皮。至少要有一条走情绪 / 故事 / 反差角度，跟单纯的「产品展示」拉开。

### 步骤 2：用 AskUserQuestion 让用户挑方向

用 `AskUserQuestion` 工具把 3-4 个方向作为 options 展示，每个 option：
- `label`：「风格标签 · 卖点切入关键词」（简短，1 行，比如「暗调电影感 · 手作工艺」）
- `description`：那句 pitch（要能让用户一眼看出片子讲的是**他的产品**在做什么，不是空泛的风格描述）

`header` 用「创意方向」。`multiSelect: false`。

如果用户对候选都不满意，他会走 Other → 直接把他补充的话作为最终风格描述。
