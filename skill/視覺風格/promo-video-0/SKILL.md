# promo-video —— 一圖生成宣傳短片（帶創意選項）

## 定位

在 base-skill 之上加一層「創意引導 + 分步確認」：**本地** 分析參考圖 → 給出 3-4 個差異化風格方向 → 使用者選 → 走 **指令碼 → 分鏡 → 合成** 三步，每一步都讓使用者過一遍再進下一步。

不同於 base-skill 的「純傳話」定位，本 skill **允許在選風格這一步做本地創意工作**（使用者明確要求）。但一旦風格選定，後續每一步的 prompt 依然按 base-skill 的規矩組裝：只帶使用者目標 + 選中風格 + OSS URL / 上一步產物，不堆質量詞、不自拆分鏡（分鏡由 平台後端出）。

## 前置條件

- 畫布平台金鑰已設定（base-skill 前置，由 base-skill 環境提供）。
- 使用者已提供本地圖片路徑（`.jpg` / `.png` / `.webp` 等），大小 < 200MB。
- base-skill 的指令碼存在於 `../base-skill/scripts/`（同一專案下）。若不在同一專案，需要用絕對路徑找到 base-skill 的 scripts 目錄。

## 工作流

**關鍵原則**：三步（指令碼 / 分鏡 / 合成）都在**同一個 sessionId** 裡追加訊息（`--session-id`），讓 平台後端保留上下文，不要為每一步開新 session。

### 步驟 1：讀圖 = 讀懂產品 + 想宣傳方向

用 `Read` 工具開啟使用者給的圖片路徑。這一步的目標**不是評鑑畫面美感**，而是**先把產品/主體搞明白**，再基於對產品的理解去想「怎麼給它拍宣傳片」。

**先做產品理解（本地默寫下來，別輸出給使用者）**：

- **是什麼**：品類 / 功能 / 形態（比如「一款陶瓷手衝杯」「一張城市文化地圖海報」「一個開屏 UI」）
- **看得見的賣點**：從圖裡能讀到的線索 —— 材質、工藝、設計語言、顏色、細節、比例、包裝、logo / 品牌調性 …
- **誰會買 / 誰會用**：目標人群畫像的合理推測（年齡段、審美取向、消費場景）
- **典型使用場景**：這東西一般在哪、什麼時候、跟什麼一起用
- **可講的差異點**：跟同品類相比，這張圖透露出的獨特之處（哪怕只是猜測）

如果圖裡資訊不足以判斷產品（比如只是一張抽象素材、或者是宣傳物本身而非產品），**先問使用者「這是什麼產品 / 你想推廣什麼？」** 再進入下一步。**不要憑空捏造產品定位**。

**再產出 3-4 個宣傳方向**。每個方向要**根植於產品**，不是空談風格。每個方向給三樣東西：

- **風格標籤**（1-3 詞，比如「暗調電影感」「日系清新」「賽博霓虹」「極簡高階」「紀錄片式」）
- **賣點切入**（一句話，說這條片子**從產品的哪個賣點切入** —— 材質工藝 / 使用場景 / 情緒共鳴 / 反差對比 / 使用者故事 / 資料事實 …）
- **一句 pitch**（一句話說清片子講什麼，寫給使用者看的「賣點」，必須體現出這個產品的名字或核心屬性）

**差異化要求**：4 個方向要在「切入的賣點 / 情緒 / 敘事結構」至少 2 個維度上錯開。不要出現 4 條方向都在講「使用場景」只是換了風格皮。至少要有一條走情緒 / 故事 / 反差角度，跟單純的「產品展示」拉開。

### 步驟 2：用 AskUserQuestion 讓使用者挑方向

用 `AskUserQuestion` 工具把 3-4 個方向作為 options 展示，每個 option：
- `label`：「風格標籤 · 賣點切入關鍵詞」（簡短，1 行，比如「暗調電影感 · 手作工藝」）
- `description`：那句 pitch（要能讓使用者一眼看出片子講的是**他的產品**在做什麼，不是空泛的風格描述）

`header` 用「創意方向」。`multiSelect: false`。

如果使用者對候選都不滿意，他會走 Other → 直接把他補充的話作為最終風格描述。
