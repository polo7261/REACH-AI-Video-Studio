# 主体可替换风格提取

## Skill 定位

本 Skill 用于从参考图片中拆分出两类信息：

1. **主体/内容提示词**：描述画面中可被替换的核心内容。
2. **风格提示词**：描述可迁移、可复用的视觉风格。

它不是普通的图片反推提示词。默认目标不是 1:1 复刻原图，而是在保留视觉风格的前提下，支持用户替换主体、重组场景或生成新的画面。

## 适用场景

当用户出现以下需求时使用本 Skill：

- 上传参考图，希望提取这种风格；
- 上传参考图，并要求“换成 XXX”；
- 上传参考图，并要求“用这种风格生成新的画面”；
- 需要把参考图拆成“可替换主体”和“可复用风格”两部分。

## 输入

用户可以提供：

- 一张参考图片；
- 可选的新主体、新画面需求或替换说明；
- 可选的保留要求，例如“背景不变”“只换人物”“构图不变”。

## 核心原则

- 默认用于二次创作，不用于复刻原图。
- 主体/内容提示词只描述可替换内容。
- 风格提示词描述可迁移视觉语言，也可以保留具有风格价值的视觉母题和空间语法；不要绑定原图中的具体人物、商品、车辆、动物、站台、轨道、交通设施等具体主体或物件。
- 当用户同时提供参考图和新画面需求时，以用户的新画面需求作为主体/内容提示词，参考图只作为风格来源。
- 如果用户只说“换成 XXX”，默认理解为全量替换原主体/内容；保留参考图的视觉风格、视觉母题和空间语法，但不默认保留原图具体场景、具体设施或具体物件组合。
- 只有用户明确要求保留场景、背景、空间结构或世界观时，才迁移参考图的场景骨架。
- 不默认输出负面提示词，除非用户明确要求。
- 不默认输出可迁移性分析，避免流程变长。
- 输出语言使用中文。

## 迁移模式判断

本 Skill 有两个迁移模式。先判断迁移模式，再提取主体/内容提示词和风格提示词。

### 默认模式：风格与视觉母题迁移

当用户说：

- “保留这种风格”
- “参考这张图的风格”
- “用这种风格生成……”
- “我想要这种感觉，但是画面改成……”
- “把主体换成 XXX”

默认只迁移参考图中的视觉风格、视觉母题和空间语法，不迁移原图具体主体、具体物件、具体场景身份或具体设施组合。

默认可迁移内容包括：

- 风格类型；
- 色彩特征；
- 光影特征；
- 材质/质感；
- 氛围情绪；
- 构图/镜头语言；
- 具有风格价值的视觉母题和空间语法；
- 画质/渲染方式。

视觉母题 / 空间语法指参考图中具有风格辨识度、且在替换主体后仍然成立的视觉组织方式，例如：

- 反复出现的形状语言；
- 标志性的线条走势；
- 空间层次组织方式；
- 材质组合方式；
- 建筑、自然、人物或物体之间的视觉关系；
- 画面中的节奏感、对称性、纵深感或装饰语言；
- 具有风格辨识度但不等同于具体主体的场景语法。

例如，当参考图是未来主义玻璃科幻风时，可以提取“流线型弧形结构、通透玻璃空间、香槟金属框架、镜面反射空间、乌托邦式未来感”等视觉母题。

默认不迁移内容包括：

- 原图具体人物、车辆、动物、商品；
- 原图具体主体或物件，例如“胶囊列车”；
- 原图具体设施，例如“站台”“轨道”“具体交通设施”；
- 原图具体场景身份，例如“交通站台”“某个未来城市街区”；
- 原图具体物体组合，例如“列车停靠在玻璃轨道旁”；
- 原图世界观元素，除非用户明确要求保留。

### 场景骨架迁移模式

只有当用户明确说：

- “保留这个场景”
- “背景不变”
- “保留这个世界观”
- “保留这种空间结构”
- “保留这个未来城市场景”
- “保留这个城市背景”
- “保留这种建筑空间结构”
- “只换人物/主体，其他不变”
- “按这个场景生成……”

才允许把参考图中的场景骨架、空间结构、建筑语言、世界观元素写入主体/内容提示词或相关描述中。

## 工作流程

### 1. 判断用户意图

根据用户输入选择处理方式：

- **只提取**：用户只提供参考图，未指定新主体或新画面。
- **替换主体**：用户要求保留风格，把主体换成新的对象。
- **风格迁移生成**：用户要求使用参考图风格生成一个新的画面或情境。

同时判断当前任务是默认风格与视觉母题迁移，还是场景骨架迁移。若用户没有明确要求保留场景骨架，按风格与视觉母题迁移处理。

### 2. 提取主体/内容提示词

主体/内容提示词应包含：

- 具体对象；
- 关键动作；
- 关键空间关系；
- 必要的场景关系。

主体/内容提示词不应包含：

- 风格词；
- 色彩、光影、材质、渲染方式等风格信息；
- 不影响二创成立的琐碎细节；
- 过细的位置关系。

在默认风格与视觉母题迁移模式下，主体/内容提示词应以用户的新需求为准，不要自动继承参考图原有具体场景。
