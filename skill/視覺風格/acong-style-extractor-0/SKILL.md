# 主體可替換風格提取

## Skill 定位

本 Skill 用於從參考圖片中拆分出兩類資訊：

1. **主體/內容提示詞**：描述畫面中可被替換的核心內容。
2. **風格提示詞**：描述可遷移、可複用的視覺風格。

它不是普通的圖片反推提示詞。預設目標不是 1:1 復刻原圖，而是在保留視覺風格的前提下，支援使用者替換主體、重組場景或生成新的畫面。

## 適用場景

當使用者出現以下需求時使用本 Skill：

- 上傳參考圖，希望提取這種風格；
- 上傳參考圖，並要求“換成 XXX”；
- 上傳參考圖，並要求“用這種風格生成新的畫面”；
- 需要把參考圖拆成“可替換主體”和“可複用風格”兩部分。

## 輸入

使用者可以提供：

- 一張參考圖片；
- 可選的新主體、新畫面需求或替換說明；
- 可選的保留要求，例如“背景不變”“只換人物”“構圖不變”。

## 核心原則

- 預設用於二次創作，不用於復刻原圖。
- 主體/內容提示詞只描述可替換內容。
- 風格提示詞描述可遷移視覺語言，也可以保留具有風格價值的視覺母題和空間語法；不要繫結原圖中的具體人物、商品、車輛、動物、站臺、軌道、交通設施等具體主體或物件。
- 當使用者同時提供參考圖和新畫面需求時，以使用者的新畫面需求作為主體/內容提示詞，參考圖只作為風格來源。
- 如果使用者只說“換成 XXX”，預設理解為全量替換原主體/內容；保留參考圖的視覺風格、視覺母題和空間語法，但不預設保留原圖具體場景、具體設施或具體物件組合。
- 只有使用者明確要求保留場景、背景、空間結構或世界觀時，才遷移參考圖的場景骨架。
- 不預設輸出負面提示詞，除非使用者明確要求。
- 不預設輸出可遷移性分析，避免流程變長。
- 輸出語言使用中文。

## 遷移模式判斷

本 Skill 有兩個遷移模式。先判斷遷移模式，再提取主體/內容提示詞和風格提示詞。

### 預設模式：風格與視覺母題遷移

當使用者說：

- “保留這種風格”
- “參考這張圖的風格”
- “用這種風格生成……”
- “我想要這種感覺，但是畫面改成……”
- “把主體換成 XXX”

預設只遷移參考圖中的視覺風格、視覺母題和空間語法，不遷移原圖具體主體、具體物件、具體場景身份或具體設施組合。

預設可遷移內容包括：

- 風格型別；
- 色彩特徵；
- 光影特徵；
- 材質/質感；
- 氛圍情緒；
- 構圖/鏡頭語言；
- 具有風格價值的視覺母題和空間語法；
- 畫質/渲染方式。

視覺母題 / 空間語法指參考圖中具有風格辨識度、且在替換主體後仍然成立的視覺組織方式，例如：

- 反覆出現的形狀語言；
- 標誌性的線條走勢；
- 空間層次組織方式；
- 材質組合方式；
- 建築、自然、人物或物體之間的視覺關係；
- 畫面中的節奏感、對稱性、縱深感或裝飾語言；
- 具有風格辨識度但不等同於具體主體的場景語法。

例如，當參考圖是未來主義玻璃科幻風時，可以提取“流線型弧形結構、通透玻璃空間、香檳金屬框架、鏡面反射空間、烏托邦式未來感”等視覺母題。

預設不遷移內容包括：

- 原圖具體人物、車輛、動物、商品；
- 原圖具體主體或物件，例如“膠囊列車”；
- 原圖具體設施，例如“站臺”“軌道”“具體交通設施”；
- 原圖具體場景身份，例如“交通站臺”“某個未來城市街區”；
- 原圖具體物體組合，例如“列車停靠在玻璃軌道旁”；
- 原圖世界觀元素，除非使用者明確要求保留。

### 場景骨架遷移模式

只有當使用者明確說：

- “保留這個場景”
- “背景不變”
- “保留這個世界觀”
- “保留這種空間結構”
- “保留這個未來城市場景”
- “保留這個城市背景”
- “保留這種建築空間結構”
- “只換人物/主體，其他不變”
- “按這個場景生成……”

才允許把參考圖中的場景骨架、空間結構、建築語言、世界觀元素寫入主體/內容提示詞或相關描述中。

## 工作流程

### 1. 判斷使用者意圖

根據使用者輸入選擇處理方式：

- **只提取**：使用者只提供參考圖，未指定新主體或新畫面。
- **替換主體**：使用者要求保留風格，把主體換成新的物件。
- **風格遷移生成**：使用者要求使用參考圖風格生成一個新的畫面或情境。

同時判斷當前任務是預設風格與視覺母題遷移，還是場景骨架遷移。若使用者沒有明確要求保留場景骨架，按風格與視覺母題遷移處理。

### 2. 提取主體/內容提示詞

主體/內容提示詞應包含：

- 具體物件；
- 關鍵動作；
- 關鍵空間關係；
- 必要的場景關係。

主體/內容提示詞不應包含：

- 風格詞；
- 色彩、光影、材質、渲染方式等風格資訊；
- 不影響二創成立的瑣碎細節；
- 過細的位置關係。

在預設風格與視覺母題遷移模式下，主體/內容提示詞應以使用者的新需求為準，不要自動繼承參考圖原有具體場景。
