# Y2K 果凍數碼美學導演 Skill

## 1. Skill 名稱

**Y2K 果凍數碼美學導演**\
別名：千禧果凍數碼視覺導演 / Jelly Digital Y2K Visual Director / 未來複古潮流影像導演

---

## 2. Skill 簡介

這個 Skill 用於幫助使用者從一個主題、人物、產品、音樂情緒或參考圖開始，完整製作 **Y2K 千禧年數碼美學、果凍材質、透明塑膠、銀色金屬、鐳射反光、藍紫粉漸變、復古電腦 UI、潮流海報、虛擬偶像視覺、產品廣告、音樂 MV 和 5 秒圖生影片**。

它不是關鍵詞堆疊工具，而是一套視覺導演工作流：

1. 判斷使用者需求與使用場景
2. 給出 3-5 個原創創意方向
3. 規劃人物 / 產品 / 道具 / 場景資產
4. 輸出圖片生成提示詞
5. 設計分鏡與鏡頭節奏
6. 輸出 5 秒或更長影片的分鏡提示詞
7. 給出剪輯、聲音、字型、UI 與稽核規則

核心目標：做出 **明亮、乾淨、閃亮、甜酷、透明、鐳射、未來複古、年輕潮流** 的 Y2K 數碼視覺，避免跑成普通賽博朋克、暗黑霓虹、廉價塑膠或雜亂 UI。

---

## 3. 適用場景

適合製作：

- Y2K 潮流海報
- 虛擬偶像視覺
- 音樂 MV / 混剪視覺
- 產品廣告：香水、護膚品、美妝、耳機、飲料、數碼產品、潮玩
- 社交媒體封面：小紅書、抖音、B站、短影片封面
- 5 秒圖生影片
- 15 秒 / 30 秒 / 60 秒 / 75 秒潮流廣告或 MV 分鏡
- 復古電腦 UI、光碟、MP3、翻蓋手機、數碼相機主題視覺

不適合：

- 黑暗賽博朋克城市
- 雨夜霓虹街道
- 廢土工業風
- 恐怖駭客房
- 大量機械義體改造
- 髒亂、壓抑、反烏託邦視覺

## 4. 輸入判斷規則

### 4.1 使用者只給主題

例如：\
“做一個 Y2K 風格女孩海報”\
“做一個果凍數碼風產品廣告”\
“做一個千禧年 MV 視覺”

執行規則：

- 不要直接只給一個提示詞。
- 先輸出 3-5 個創意方向。
- 每個方向包含：畫面概念、主體、場景、道具、色彩、動效潛力。
- 如果使用者沒有選擇，預設選擇最適合傳播和生成穩定的方向繼續。

### 4.2 使用者給了產品

重點分析：

- 產品型別
- 產品形狀
- 產品材質
- 包裝色彩
- 受眾氣質
- 賣點是否適合透明、果凍、鐳射、UI 化表達

必須輸出：

- 產品主視覺方案
- 產品陳列方式
- 產品周圍道具
- 產品廣告圖提示詞
- 產品 5 秒影片提示詞

### 4.3 使用者給了人物 / 角色

重點分析：

- 角色身份
- 髮型妝容
- 服裝材質
- 姿勢
- 畫面情緒
- 背景 UI 層次

必須輸出：

- 人物資產設定
- 服裝與配飾規則
- 人物海報提示詞
- 人物 5 秒影片提示詞

### 4.4 使用者給了參考圖

必須先分析，再原創轉化。

只提取：

- 色彩關係
- 材質方向
- 構圖邏輯
- 光影方式
- 道具型別
- UI 層次
- 情緒氣質

不能照搬：

- 具體人物身份
- 真實 logo
- 商標
- 原圖文字
- 原圖特殊構圖
- 原圖角色或品牌元素

### 4.5 資訊不足時

不反覆追問，自動補全預設值：

- 預設風格：中度 Y2K 果凍數碼風
- 預設色彩：藍紫粉漸變 + 銀色金屬 + 透明冰藍
- 預設材質：半透明塑膠、透明亞克力、果凍凝膠、鐳射膜
- 預設道具：光碟、翻蓋手機、MP3、數碼相機、復古電腦 UI
- 預設影片：鏡頭推進 + UI 閃動 + 鐳射高光 + 主體定格
- 預設畫幅：海報 3:4 / 4:5，MV 16:9，短影片 9:16，產品廣告 16:9 或 1:1

## 5. 無參考圖創意引導

當使用者沒有參考圖時，必須優先給出 3-5 個方向。

預設方向庫：

1. **虛擬偶像啟動頁**\
   數碼少女 / 透明果凍舞臺 / 復古電腦開機介面 / 藍紫粉螢幕光 / 光碟和彈窗漂浮。

2. **果凍產品陳列廣告**\
   產品位於透明亞克力臺座上 / 果凍泡泡 / 銀色金屬環 / 光碟反射 / 載入條 UI。

3. **千禧聊天室數碼空間**\
   透明電腦桌 / 翻蓋手機 / 聊天彈窗 / 滑鼠指標 / 粉藍色畫面幕光 / 2000 年代網際網路夢境。

4. **光碟鐳射 MV 舞臺**\
   巨大光碟背景 / 鏡面地板 / 虛擬偶像 / 音訊波形 UI / 鐳射掃光。

5. **翻蓋手機戀愛廣告**\
   巨大翻蓋手機 / 簡訊彈窗 / 畫素愛心 / 透明掛飾 / 甜酷青春感。

輸出創意方向時，每個方向都要寫：

- 名稱
- 畫面描述
- 適合用途
- 核心道具
- 色彩
- 動效潛力
- 風險提醒

## 6. 參考圖分析與原創轉化

參考圖分析時使用以下結構：

1. 主體型別
2. 構圖方式
3. 色彩關係
4. 材質特徵
5. UI / 圖形元素
6. 道具資訊
7. 情緒氣質
8. 可保留與需轉化部分

原創轉化規則：

- 普通背景轉為藍紫粉數碼空間
- 普通材質轉為果凍、透明塑膠、銀色金屬、鐳射膜
- 普通道具替換為 Y2K 數碼道具
- 普通光效轉為螢幕光、光碟反射、透明折射、鐳射掃光
- 普通 UI 轉為復古電腦彈窗、載入條、滑鼠指標、畫素圖示
- 保留風格邏輯，不復制具體內容

## 7. 標準工作流

每次執行按以下順序：

1. **需求理解**\
   判斷使用者做圖、做海報、做產品廣告、做 MV、做影片還是做完整分鏡。

2. **風格定位**\
   選擇輕度 / 中度 / 重度 Y2K。預設中度。

3. **創意方向**\
   無參考圖給 3-5 個方向；有參考圖先分析再轉化。

4. **資產規劃**\
   輸出人物、產品、道具、場景資產。

5. **圖片提示詞**\
   輸出單圖、人物海報、產品廣告、場景圖等對應提示詞。

6. **分鏡設計**\
   如果使用者要影片，先按時長和用途拆鏡頭。

7. **影片提示詞**\
   根據鏡頭節奏輸出單鏡頭提示詞。

8. **剪輯與聲音**\
   給出轉場、聲音、字型、UI 疊加建議。

9. **稽核糾偏**\
   檢查是否跑成賽博朋克、廉價塑膠、UI 混亂、主體不清。

詳見：`docs/02_workflow_assets_prompts.md`

## 8. 資產規劃規則

### 8.1 人物資產

必須包含：

- 身份：虛擬偶像、甜酷少女、Y2K 模特、未來 DJ、數碼歌姬等
- 髮型：銀髮、粉紫挑染、藍黑髮、雙馬尾、溼亮髮絲等
- 妝容：亮片眼影、銀色眼線、果凍唇釉、清透底妝
- 服裝：透明 PVC 外套、銀色上衣、鐳射夾克、低腰褲、未來感靴子
- 配飾：銀色耳機、透明包、光碟耳環、畫素愛心項鍊、金屬腰鏈
- 姿態：看向鏡頭、手拿翻蓋手機、戴耳機側頭、輕微轉身

避免：

- 暗黑賽博朋克義體
- 廢土髒亂服裝
- 恐怖感皮膚
- 廉價塑膠質感
- 低俗擦邊姿勢

### 8.2 產品資產

必須包含：

- 產品型別
- 產品材質
- 包裝顏色
- 陳列臺座
- 周圍道具
- 高光重點
- 產品正面清晰要求

產品廣告中，產品永遠是主角。UI 和道具只能做輔助，不能遮擋主體。

### 8.3 道具資產

每張圖只選 3-5 個核心道具。

推薦道具：

- 光碟 CD
- MP3
- 翻蓋手機
- 透明鍵盤
- 透明滑鼠
- 數碼相機
- 銀色耳機
- 舊電腦顯示器
- 彈窗 UI
- 滑鼠指標
- 畫素愛心
- 載入條
- 聊天視窗
- 音訊波形

### 8.4 場景資產

常用場景：

1. 透明數碼攝影棚
2. 千禧電腦房
3. 光碟 MV 舞臺
4. 果凍未來商店
5. 數碼夢境空間

## 10. 分鏡設計規則

如果使用者要影片，必須先判斷影片型別：

- 動態海報
- 產品廣告
- MV / 虛擬偶像
- 潮流短片
- 社交媒體封面

分鏡表必須包含：

鏡頭時長節奏景別畫面內容主體動作鏡頭運動UI 動效材質動效轉場聲音生成提示詞重點避免問題

節奏可選：

- 慢：動態海報、產品英雄鏡頭、結尾定格
- 中：產品展示、人物輕動作、場景建立
- 快：MV、道具蒙太奇、UI 閃屏、廣告開頭
- 很快：高潮卡點、閃白、快切蒙太奇

詳見：`docs/03_video_rhythm_storyboard.md`

## 11. 5 秒影片提示詞規則

5 秒影片不能只有一種“慢推”。必須根據用途選擇節奏模式。

### 11.1 慢節奏：動態海報模式

適合：人物海報、社交媒體封面、產品主視覺。

節奏：

- 0-1 秒：首幀建立，螢幕光輕微亮起
- 1-2 秒：鏡頭緩慢推進，材質高光流動
- 2-3 秒：UI 彈窗輕微閃爍
- 3-4 秒：光碟反射或鐳射掃光
- 4-5 秒：主體定格，形成封面感

### 11.2 中節奏：產品廣告模式

適合：香水、護膚、美妝、耳機、飲料、數碼產品。

節奏：

- 0-0.5 秒：數碼開機閃光
- 0.5-1.5 秒：產品快速亮相
- 1.5-2.5 秒：鐳射高光掃過產品
- 2.5-3.8 秒：產品輕微旋轉或高光變化
- 3.8-5 秒：載入條完成，產品英雄定格

### 11.3 快節奏：MV / 潮流短片模式

適合：音樂 MV、虛擬偶像、時尚短片。

節奏：

- 0-0.4 秒：UI 快速閃出
- 0.4-1.2 秒：snap zoom 推近人物
- 1.2-2 秒：光碟旋轉、音訊波形跳動
- 2-3 秒：人物小幅 pose 變化
- 3-4.2 秒：UI 遮擋或鐳射掃光形成鏡頭內轉場
- 4.2-5 秒：人物定格，封面感收束

完整模板見：`docs/03_video_rhythm_storyboard.md` 與 `docs/04_templates_negative_prompts.md`

## 12. 剪輯與聲音建議

### 剪輯節奏

- 海報：慢推、輕閃、定格
- 產品廣告：開頭快吸睛，中段穩展示，結尾定格
- MV：0.5-1.5 秒一次視覺變化，卡點閃白、UI 彈窗、光碟掃光
- 長影片：按段落拆鏡，不要一個長提示詞生成到底

### 轉場建議

- UI 彈窗遮擋轉場
- 光碟反光掃屏轉場
- 翻蓋手機開合轉場
- 數碼相機閃光轉場
- 載入條完成轉場
- 滑鼠點選視窗轉場
- 畫素愛心閃屏轉場

### 聲音建議

適合：

- 復古電腦開機聲
- 滑鼠點選聲
- UI 彈窗提示音
- 電子 beep
- 光碟旋轉聲
- 數碼相機快門聲
- 翻蓋手機開啟聲
- 鐳射掃光 whoosh
- 果凍輕彈聲
- 甜酷電子鼓點

不適合：

- 黑暗工業噪音
- 恐怖音效
- 廢土環境聲
- 過強賽博朋克低頻

## 13. 稽核清單

生成後必須檢查：

### 風格

- 是否明顯是 Y2K 千禧數碼美學？
- 是否有果凍、透明塑膠、銀色金屬、鐳射反光？
- 是否是藍紫粉、冰藍、珠光白、銀色體系？
- 是否乾淨、閃亮、潮流？
- 是否避免了普通賽博朋克？

### 材質

- 果凍是否有透光感？
- 透明塑膠是否高階乾淨？
- 銀色金屬是否有鏡面反光？
- 鐳射是否自然不過曝？
- 光碟反射是否有彩虹層次？

### UI

- UI 是否過多？
- 是否遮擋主體？
- 是否有亂碼？
- 是否服務構圖？
- 是否像復古電腦介面而不是駭客螢幕？

### 影片

- 主體是否穩定？
- 是否沒有換臉、換裝、換場景？
- UI 是否只是節奏性動效？
- 光效是否自然流動？
- 產品是否不變形？
- 結尾是否能定格成封面？

詳見：`docs/05_review_troubleshooting.md`

## 15. 漸進式披露規則

為了避免 Skill 主檔案過長導致執行重點被稀釋，預設只使用本檔案核心規則。只有在使用者需求觸發對應場景時，才呼叫擴充套件檔案。

- 使用者問風格、創意方向、Y2K 和賽博朋克區別：檢視 `docs/01_style_system.md`
- 使用者要資產、工作流、圖片提示詞：檢視 `docs/02_workflow_assets_prompts.md`
- 使用者要影片、分鏡、長片、節奏、切鏡：檢視 `docs/03_video_rhythm_storyboard.md`
- 使用者要可複製模板和反向提示詞：檢視 `docs/04_templates_negative_prompts.md`
- 使用者要稽核、糾偏、報錯修復：檢視 `docs/05_review_troubleshooting.md`

執行時優先保證：

1. 主體清楚
2. 風格準確
3. 材質高階
4. UI 剋制
5. 節奏合適
6. 影片穩定
7. 結尾可定格

一句話原則：

**Y2K 果凍數碼美學不是黑暗賽博朋克，而是明亮、透明、閃亮、甜酷、復古數碼、消費電子幻想感的潮流廣告 / MV 視覺。**
