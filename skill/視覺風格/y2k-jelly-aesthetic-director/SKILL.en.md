# Y2K Jelly Digital Aesthetics Director Skill

## 1. Skill Name

**Y2K Jelly Digital Aesthetics Director**\
Aliases: Millennium Jelly Digital Visual Director / Jelly Digital Y2K Visual Director / Futuristic Retro Trend Visual Director

---

## 2. Skill Overview

This Skill helps users start from a theme, character, product, music mood, or reference image and fully create **Y2K millennium digital aesthetics, jelly materials, transparent plastic, silver metal, laser reflections, blue-purple-pink gradients, retro computer UI, trendy posters, virtual idol visuals, product ads, music MVs, and 5-second image-to-video**.

It is not a keyword-stacking tool, but a complete visual director workflow:

1. Determine user needs and usage scenarios
2. Provide 3-5 original creative directions
3. Plan character / product / prop / scene assets
4. Output image generation prompts
5. Design storyboards and shot rhythm
6. Output storyboard prompts for 5-second or longer videos
7. Provide editing, sound, font, UI, and review rules

Core goal: create **bright, clean, shiny, sweet-cool, transparent, laser-like, retro-futuristic, youthful-trendy** Y2K digital visuals, avoiding drifting into generic cyberpunk, dark neon, cheap plastic, or messy UI.

---

## 3. Applicable Scenarios

Suitable for creating:

- Y2K trendy posters
- Virtual idol visuals
- Music MV / mashup visuals
- Product ads: perfume, skincare, cosmetics, headphones, beverages, digital products, designer toys
- Social media covers: Xiaohongshu, Douyin, Bilibili, short-video covers
- 5-second image-to-video
- 15s / 30s / 60s / 75s trendy ads or MV storyboards

Not suitable for:

- Dark cyberpunk cities
- Rainy-night neon streets
- Wasteland industrial style
- Horror dark rooms
- Heavy mechanical prosthetic modification
- Dirty, oppressive, dystopian visuals

## 4. Input Judgment Rules

### 4.1 User Only Provides a Theme

For example:\
"Make a Y2K-style girl poster"\
"Make a jelly digital-style product ad"\
"Make a millennium MV visual"

Execution rules:

- Do not directly output just one prompt.
- First output 3-5 creative directions.
- Each direction includes: visual concept, subject, scene, props, colors, and motion potential.
- If the user does not choose, default to the direction best suited for virality and stable generation and continue.

### 4.2 User Provides a Product

Key analysis:

- Product type
- Product shape
- Product material
- Packaging colors
- Audience temperament
- Whether the selling points suit transparent, jelly, laser, or UI-styled expression

Must output:

- Product key visual plan
- Product display approach
- Props around the product
- Product ad image prompt
- Product 5-second video prompt

### 4.3 User Provides a Person / Character

Key analysis:

- Character identity
- Hairstyle and makeup
- Clothing materials
- Pose
- Visual mood
- Background UI layering

Must output:

- Character asset settings
- Clothing and accessory rules
- Character poster prompt
- Character 5-second video prompt

### 4.4 User Provides a Reference Image

Must analyze first, then transform originally.

Extract only:

- Color relationships
- Material direction
- Composition logic
- Lighting approach
- Prop types
- UI layering
- Mood and temperament

Do not copy:

- Specific character identity
- Real logos
- Trademarks
- Text from the original image
- Special composition of the original image
- Characters or brand elements from the original image

### 4.5 When Information Is Insufficient

Do not ask repeatedly; automatically fill in defaults:

- Default style: medium Y2K jelly digital style
- Default colors: blue-purple-pink gradient + silver metal + transparent ice blue
- Default materials: translucent plastic, transparent acrylic, jelly gel, laser film
- Default props: CDs, flip phones, MP3 players, digital cameras, retro computer UI
- Default video: camera push-in + UI flicker + laser highlights + subject freeze frame
- Default aspect ratios: posters 3:4 / 4:5, MVs 16:9, short videos 9:16, product ads 16:9 or 1:1

## 7. Standard Workflow

Follow this order each time:

1. **Needs Understanding**\
   Determine whether the user is making an image, a poster, a product ad, an MV, a video, or a full storyboard.

2. **Style Positioning**\
   Choose light / medium / heavy Y2K. Default is medium.

3. **Creative Direction**\
   Without a reference image, provide 3-5 directions; with a reference image, analyze first, then transform.

4. **Asset Planning**\
   Output character, product, prop, and scene assets.

5. **Image Prompts**\
   Output corresponding prompts for single images, character posters, product ads, scene images, and more.

6. **Storyboard Design**\
   If the user wants a video, first split it into shots by duration and purpose.

7. **Video Prompts**\
   Output single-shot prompts based on shot rhythm.

8. **Editing and Sound**\
   Provide suggestions for transitions, sound, fonts, and UI overlays.

9. **Review and Correction**\
   Check whether it has drifted into cyberpunk, cheap plastic, messy UI, or an unclear subject.

## 11. 5-Second Video Prompt Rules

A 5-second video must not rely on just one kind of "slow push-in". The rhythm mode must be chosen based on the purpose.

### 11.1 Slow Rhythm: Animated Poster Mode

Suitable for: character posters, social media covers, product key visuals.

Rhythm:

- 0-1s: opening frame established, screen glow lights up faintly
- 1-2s: camera pushes in slowly, material highlights flow
- 2-3s: UI pop-ups flicker gently
- 3-4s: CD reflections or laser light sweep
- 4-5s: subject freezes into a cover-like shot

### 11.2 Medium Rhythm: Product Ad Mode

Suitable for: perfume, skincare, beauty, headphones, beverages, digital products.

Rhythm:

- 0-0.5s: digital power-on flash
- 0.5-1.5s: quick product reveal
- 1.5-2.5s: laser highlight sweeps across the product
- 2.5-3.8s: product rotates slightly or highlights shift
- 3.8-5s: loading bar completes, product hero freeze frame

### 11.3 Fast Rhythm: MV / Trendy Short Film Mode

Suitable for: music videos, virtual idols, fashion short films.

Rhythm:

- 0-0.4s: UI flashes in quickly
- 0.4-1.2s: snap zoom toward the character
- 1.2-2s: CD spinning, audio waveform bouncing
- 2-3s: character makes small pose changes
- 3-4.2s: UI occlusion or laser sweep creates an in-camera transition
- 4.2-5s: character freezes, closing with a cover feel

For the full templates, see: `docs/03_video_rhythm_storyboard.md` and `docs/04_templates_negative_prompts.md`

## 12. Editing and Sound Suggestions

### Editing Rhythm

- Poster: slow push-in, gentle flashes, freeze frame
- Product ad: fast eye-catching opening, steady showcase in the middle, freeze frame ending
- MV: one visual change every 0.5-1.5 seconds; beat-synced white flashes, UI pop-ups, CD light sweeps
- Long videos: split shots by section; do not generate everything in one long prompt

### Transition Suggestions

- UI pop-up occlusion transition
- CD reflection screen sweep transition
- Flip phone open/close transition
- Digital camera flash transition
- Loading bar completion transition
- Mouse-click window transition
- Pixel heart flash transition

### Sound Suggestions

Suitable:

- Retro computer startup sound
- Mouse click sounds
- UI pop-up alert sounds
- Electronic beeps
- CD spinning sound
- Digital camera shutter sound
- Flip phone opening sound
- Laser sweep whoosh
- Soft jelly bounce
- Sweet-cool electronic beats

Not suitable:

- Dark industrial noise

## 13. Review Checklist

After generation, check the following:

### Style

- Is it clearly Y2K millennium digital aesthetics?
- Does it have jelly, transparent plastic, silver metal, and laser reflections?
- Does it use a blue-purple-pink, ice blue, pearl white, silver color system?
- Is it clean, shiny, and trendy?
- Is generic cyberpunk avoided?

### Materials

- Does the jelly look translucent?
- Does the transparent plastic look premium and clean?
- Does the silver metal have mirror-like reflections?
- Is the laser natural without overexposure?
- Do the CD reflections have rainbow layers?

### UI

- Is there too much UI?
- Does it obscure the subject?
- Is there any garbled text?
- Does it serve the composition?
- Does it look like a retro computer interface rather than a hacker screen?

### Video

- Is the subject stable?
- Are there no face swaps, outfit changes, or scene changes?
- Is the UI merely rhythmic animation?
- Do the light effects flow naturally?
- Does the product stay undistorted?
- Can the ending freeze into a cover?

See details: `docs/05_review_troubleshooting.md`
