# time-freeze-effect

做"时间静止"特效短视频时用本 skill。经典结构:**场景中时间骤停 → 主角是唯一还在动的人、在凝固的世界里穿行 → 一个响指/一句话时间恢复**。上传主角参考图,全片外貌一致。一镜到底、图生视频完成。

> 本环境适配:图生视频走 `generate_video_v3`(引用主角参考图、生成内嵌音效);源 MIT,表达重写、非 1:1。

## 输入

- **主角参考图**(必填):清晰露脸的人脸/身形照,全片外貌须一致。
- **场景**(选填):时间将凝固的环境。选**人群能量足、且空中有大量可"冻住"的小物**(液体、彩纸、火花、爆米花)的场景效果最好——拥挤昏暗、带霓虹的运动酒吧/夜店/婚礼现场/体育场人群。
- **凝固瞬间视觉**(选填):时间停住那一刻悬在空中的标志画面(悬浮的金色啤酒弧线/漂浮静止的爆米花/定格在欢呼中的人群表情)。
- **收尾台词**(选填):主角恢复时间前低语的一个词/短句。
- **画幅**:16:9 电影感 / 9:16 竖屏社媒。
- **时长**:10 或 15s(竖屏社媒建议 10s、节奏更紧)。

## 工艺:一镜三段 + 响指机制 + 音效弧

**一镜内完成三段式**,图生视频(引用主角参考图、720p、开启内嵌音效)。

**超写实电影调(贯穿全片)**:仿电影机 + 35mm 镜头的超写实质感、体积雾(volumetric haze)、动态硬阴影、浅景深。这套质感是"冻住的世界"可信的前提,不可省。

三段时间线:

1. **常态与触发**:开场场景时间正常流动;斯坦尼康正面中景跟拍主角自信穿过人群,人群在其周围爆发欢呼;主角举起右手、打一个响指。
2. **凝固**:响指瞬间,指尖迸出一道球形冲击波——空气扭曲、光线折射向外涟漪扩散;万物骤然静止在动作中途;凝固瞬间视觉悬在空中(液体弧线/漂浮颗粒/定格表情);霓虹光打亮悬停的尘埃与液体;绝对静默。
3. **穿行**:只有主角在动;脚步声轻而带回响;镜头后退跟随主角平静地穿过凝固的场景、观察,并从空中拈起一个悬停的细节。
4. **恢复**:主角在一个表情狂喜、凝固的旁观者面前停下、侧头端详,低语出收尾台词;随后转身面向镜头、坏笑,再打一次响指——一道更强的反向冲击波向外扩散,运动瞬间恢复(声音炸回、跳起的人落地);主角走开,镜头穿过重新欢庆的人群推进。收黑。

**音效弧(本特效的签名,务必开启内嵌音效、不可静音)**:震耳的环境欢庆 → 响指 → 深沉冲击波/低频轰鸣 → 绝对静默 → 脚步声 → 低语 → 响指 → 反向冲击波 → 欢庆声炸回。这条"响指→静默→响指"的声音弧是整个效果的灵魂,若静音则效果崩塌。

**主角一致性**:在提示词里显式绑定"此人来自参考图,面部特征与身形比例在全片各镜保持一致"。若模型拒绝写实人脸,退到更宽松的身份匹配设定(不强绑写实相似度)重生成。

## 流程

1. 收主角图 + 场景/凝固视觉/收尾台词/画幅/时长;缺主角图先要。
2. `generate_video_v3` 图生视频:参考图绑主角;提示词按上面三段时间线写清(常态触发→凝固→穿行→恢复)、写清响指球形冲击波与反向冲击波、写清凝固瞬间的具体悬浮视觉、写清超写实电影调那套参数、把音效弧作为 sound design 段落写进提示词;开启内嵌音效;720p;画幅/时长按输入。
3. 展示成片;可调场景/凝固视觉/台词重生成。
