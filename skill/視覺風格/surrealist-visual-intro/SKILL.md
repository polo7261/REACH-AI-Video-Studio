## 阶段 2：脚本视图（N 帧链路 + 运镜方案）

### 2.1 确定分镜数量与每段时长分配

在输出脚本视图前，agent 先说明拟定的分镜总数 N、核心画面场景，以及每段的预设时长。

**分镜数量决策参考：**

决策因素参考值目标片头时长各段时长之和接近目标时长剧本核心意象数量每个意象演化节点通常需要 1–2 个分镜情感弧线复杂度弧线越复杂，节点越多；极简故事可用 8–10 张

**场景设计原则：场景不割裂，但允许跨越场景。**

- 片头不要求全程锁死在同一个场景里——场景可以跨越，但跨越必须有视觉上的连接逻辑（形状呼应、质感延续、光影过渡），不能是硬切
- 同一段落内相邻的分镜图必须在材质/光照体系上连续，不能突然切换美术风格
- 跨场景的跃迁通过"母题转场"实现：前帧的某个视觉元素（形状、纹路、光）在新场景中以变形方式延续，让观众潜意识中感知到连接 **典型参考**：30秒片头 ≈ 3–4张分镜；60秒片头 ≈ 5–7张分镜；75秒片头 ≈ 6–8张分镜；90秒片头 ≈ 7–10张分镜。每段8–15秒，整体有快有慢。

### 2.2 脚本视图格式

脚本视图以表格形式输出，不生成风格板：

```
帧号 | 时间码 | 预设段落时长 | 场景标题 | 核心意象（空间内部位置 + 局部形态描述）| 与前帧的视觉延续关系 | 运镜设计 | 景别 | 情感母题
```

**"与前帧的视觉延续关系"** 明确说明前后两帧之间的过渡关系类型。每对相邻分镜必须属于以下五种关系之一，在脚本视图中注明：

关系类型描述强制约束典型运镜**同环境·不同主体**空间、光照、材质完全连续，主体发生替换、出现或消解环境材质/光照必须与前帧一致`MORPH-LOCK` / `STATIC` / `PAN`**同主体·不同环境**主体形态连续，周围空间/材质发生缓慢形变主体轮廓必须可在前帧中辨认`MORPH-LOCK` / `BREATH-FLOAT`**光影变化**主体与空间基本不变，光源方向/强度/色温极缓慢迁移主体与空间构图与前帧基本一致`STATIC` / `BREATH-FLOAT` / `TILT`**同场景·不同角度或景别**完全同一空间同一主体，镜头切换视角或景别**同场景时必须有景别或角度的变化，禁止同景别同角度的相邻帧**`PAN` / `PUSH-S` / `ORBIT-S` / `TILT`**母题转场·场景跃迁**场景完全切换，但前帧的核心视觉母题（形状/质感/符号）在新场景中以变形方式嵌入新场景信息量必须与前帧明显不同，空间完整可读；母题元素以变形而非复制方式出现`MORPH-LOCK` / `STATIC`

### 2.4 运镜设计系统

速度原则

**全程以极缓/缓为唯一基调，禁止任何急速运镜。** 极缓+缓速段落合计占比≥80%，中速已是上限，急速全程禁止。

全局运镜叙事弧线（先规划整体，再设计每段）

**视频提示词的运镜设计必须从全局视角出发，先确定整条链路的运镜叙事走向，再为每段视频写具体指令。** 孤立设计每段镜头会导致方向感混乱、节奏断裂。

**全局规划的步骤：**

1. **为整条链路选定一条运镜主线**，作为贯穿全片的视觉叙事主干
2. **在主线内设计节奏变化**：速度的起伏、方向的转折、运动的暂停
3. **确定转折点位置**：哪几段是主线的"转向"，之前和之后的运镜方向各是什么
4. **每段视频的运镜设计从主线推导**，而不是独立决定 **典型运镜主线示例：**

主线类型描述适合情感弧线**持续推入→转折静止**全程缓慢推入画面深处，在情感核心处突然静止，让画面内容自己说话迷失、深陷执念**持续拉出→回归**从极端特写缓慢拉出，场景逐渐展开，呼应开场的初始景别觉醒、解脱**推入→暂停→拉出**前段推入深入，中段静止/形变，后段缓慢拉出释放进入-核心-释放的完整弧线**持续横移扫描**镜头在空间内缓慢横移，像在阅读一段叙事观察者视角、疏离感**形变主导**镜头几乎不动，靠画面内容的缓慢形变推进叙事宿命感、不可抗力

高级转场手法

转场简述**匹配转场**前后帧主体形状吻合，镜头锁定，形状缓慢滑变**遮挡转场**前景物体缓慢填满画面，揭开后变为下一帧**焦点转场**焦点从前景移至背景，背景即下一帧内容**光影淹没**光线扩展填满画面，消退后露出下一帧**材质渗透**前帧材质质感渗透覆盖画面，下一帧从中浮现**镜像对称**画面沿中轴折叠后展开为下一帧

**在脚本视图运镜列中标注，格式：** `缓缓推近 + 匹配转场`

**横向运动穿插规则：** 全链路中 PAN / TRACK / TILT / ORBIT-S / BREATH-FLOAT 类运镜总占比不低于 30%。脚本视图"运镜设计"列用人话描述（如"缓缓推近，转为向左缓摇"），不直接写代码。

允许与禁止

**允许：** 慢速形变、缓慢摇镜、微弱推移、光影渐变、材质呼吸、细节浮现、视差漂移、六种高级转场（匹配/遮挡/焦点/光影淹没/材质渗透/镜像对称）

**禁止：** 任何急速运镜（俯冲、快速滑轨、高速穿越、廉价旋转）、过度运动、弹跳/抖动、发光光晕光束等发光效果

### 3.1 生成策略：链式逐张生成，全部完成后一次确认

**强约束：分镜图必须用 Midjourney V8.1 生成，agent 在画布中全程操作（建节点、连线、触发生成），不交给用户手动执行。** 若环境未连接 Midjourney V8.1，告知用户并提供提示词由用户自行运行。

- 在 Midjourney V8.1 画布（Canvas）中创建 S01 节点，填入提示词，触发生成

**链式参考的目的与边界：**

2. **角度**：正面 / 侧面 / 背面 / 俯拍 / 仰拍 / 斜侧（明确写出）
3. **画面内容**：主体是什么，在场景的哪个位置，材质与状态
4. **参考前帧的哪一部分**：明确指出参考上一张图的哪个具体区域或元素（如"参考 S01 左侧壁面的纹路质感"、"参考 S02 中央光斑的冷色调"），不能只说"参考上一张"

## 阶段 4：视频提示词 + 画布节点搭建

### 4.1 核心原则：看图写提示词，agent 建好节点

**视频提示词必须基于画布上的实际分镜图画面来设计，不能照搬分镜图的文字提示词。** 用户调图后画面可能与文字描述有偏差，提示词要忠实于最终图像。

**流程：**

1. 用户确认所有分镜图后，agent 观察画布上每对相邻帧的实际画面，写出全部 N-1 段视频提示词（包含 VID_N-1，片名已在步骤1确认）
2. 实际图像与脚本方案不匹配时，以实际图像为准调整运镜
3. 将所有视频提示词展示给用户浏览，然后 agent 在画布中搭好全部节点并连接，直接逐段触发生成，无需用户再次确认
4. **全部视频生成完毕后，立即自动进入阶段5：先合成视频，再生成BGM并叠加，无需等待用户指令。视频比例：** 所有视频提示词中必须注明 `--ar 21:9`。

**首尾帧强约束：** 每段视频必须以实际 MJ V8.1 生成的分镜图作为首帧和尾帧输入视频模型，**禁止使用全能参考模式（单图参考/全图参考），必须是首尾帧模式**。不允许用文字描述替代图像，不允许只用单帧生成视频。没有首尾帧图像就不能生成视频。

### 4.2 段落结构

每一段视频对应一对相邻分镜：

```
VID_01：S01（首帧图）→ S02（尾帧图）
VID_02：S02（首帧图）→ S03（尾帧图）
……
VID_N-1：S(N-1)（首帧图）→ SN（尾帧图）
```

所有视频段必须使用用户最终确认的 MJ V8.1 生成图像作为首帧和尾帧，不使用文字描述替代。

### 4.4 视频提示词的写法：先全局规划，再逐段写作

**第一步：全局运镜叙事规划（收到所有分镜图后，写任何单段提示词之前先完成）**

观察全部 N 张分镜图，做出以下判断：

1. **选定全局运镜主线**：整条链路的镜头运动大方向是什么？（参考 §2.4 的典型主线示例）
2. **标出转折点**：哪几段是主线的"方向转换"？转换前和转换后各是什么运动状态？
3. **标出使用高级转场的位置**：哪对相邻帧适合做匹配转场、遮挡转场等？
4. **标出形变主导段**：哪些段落镜头几乎不动，靠画面内容缓慢形变推进？ 规划完成后直接逐段写提示词，无需输出运镜方案表给用户确认。

**视频提示词的唯一职责是描述镜头行为，不描述画面内容。** 首帧和尾帧的画面内容已经锁定在图像里，视频生成模型从图像本身读取，提示词里不需要重复描述。

**提示词只写四件事：**

1. 首帧图像引用
2. **画面内生动态**：首帧图里已有的元素如何轻微运动（粒子飘散、烟雾流动、人物缓步、光线微颤等）——只衍生图中已有的内容，绝不添加图中没有的东西，一句话即可
3. 镜头运动指令：方向、速度，以及高级转场手法的镜头行为描述（只说镜头怎么动）
4. 尾帧图像引用（作为镜头落点） 高级转场写法：匹配转场、遮挡转场、焦点转场、光影淹没、材质渗透、镜像对称——在提示词里用一句中文说明转场动作即可，不需要展开描述。

用户在步骤1已选定 BGM 风格，直接根据选定风格输出 Suno / Udio 提示词，BGM 时长与视频总时长一致。

### 5.2 合成

BGM 生成完毕后，在画布中将所有视频片段按顺序拼接并叠加 BGM：

```
VID_01 + VID_02 + … + VID_N-1
```

- 由 agent 在画布中操作完成，首尾帧对齐直接拼接，不添加任何转场特效
- 视频节点的声音开关必须开启，不要生成音乐/BGM，允许生成音效和环境音；BGM 由本阶段生成后叠加

## 设计原则

1. **禁止字面化** — 不直接呈现剧本中的经典场景，将其转化为视觉隐喻。
2. **禁止无逻辑的硬切** — 场景可以跨越，但每次跨越都要靠色调统一、材质语言连续、前后帧的视觉关联点来维持整体的连贯感。
