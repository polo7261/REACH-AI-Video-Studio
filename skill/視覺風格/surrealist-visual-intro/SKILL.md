```
步驟1：視覺風格/時長/比例/BGM風格/是否加片名——一次全確認         → 使用者確認

### 1.1 讀取劇本或故事

使用者可能以以下方式提供素材：上傳 PDF / TXT、貼上劇本文字、描述故事梗概、口述故事主題。**即使只有故事梗概或人物設定也足以開始設計**，不要求完整劇本。

讀取後內部提煉五個維度（作為後續設計基礎）：

## 階段 2：指令碼檢視（N 幀鏈路 + 運鏡方案）

### 2.1 確定分鏡數量與每段時長分配

在輸出指令碼檢視前，agent 先說明擬定的分鏡總數 N、核心畫面場景，以及每段的預設時長。

**分鏡數量決策參考：**

決策因素參考值目標片頭時長各段時長之和接近目標時長劇本核心意象數量每個意象演化節點通常需要 1–2 個分鏡情感弧線複雜度弧線越複雜，節點越多；極簡故事可用 8–10 張

**場景設計原則：場景不割裂，但允許跨越場景。**

- 片頭不要求全程鎖死在同一個場景裡——場景可以跨越，但跨越必須有視覺上的連線邏輯（形狀呼應、質感延續、光影過渡），不能是硬切
- 同一段落內相鄰的分鏡圖必須在材質/光照體繫上連續，不能突然切換美術風格
- 跨場景的躍遷透過"母題轉場"實現：前幀的某個視覺元素（形狀、紋路、光）在新場景中以變形方式延續，讓觀眾潛意識中感知到連線 **典型參考**：30秒片頭 ≈ 3–4張分鏡；60秒片頭 ≈ 5–7張分鏡；75秒片頭 ≈ 6–8張分鏡；90秒片頭 ≈ 7–10張分鏡。每段8–15秒，整體有快有慢。

### 2.2 指令碼檢視格式

指令碼檢視以表格形式輸出，不生成風格板：

```
幀號 | 時間碼 | 預設段落時長 | 場景標題 | 核心意象（空間內部位置 + 區域性形態描述）| 與前幀的視覺延續關係 | 運鏡設計 | 景別 | 情感母題
```

**"與前幀的視覺延續關係"** 明確說明前後兩幀之間的過渡關係型別。每對相鄰分鏡必須屬於以下五種關係之一，在指令碼檢視中註明：

關係型別描述強制約束典型運鏡**同環境·不同主體**空間、光照、材質完全連續，主體發生替換、出現或消解環境材質/光照必須與前幀一致`MORPH-LOCK` / `STATIC` / `PAN`**同主體·不同環境**主體形態連續，周圍空間/材質發生緩慢形變主體輪廓必須可在前幀中辨認`MORPH-LOCK` / `BREATH-FLOAT`**光影變化**主體與空間基本不變，光源方向/強度/色溫極緩慢遷移主體與空間構圖與前幀基本一致`STATIC` / `BREATH-FLOAT` / `TILT`**同場景·不同角度或景別**完全同一空間同一主體，鏡頭切換視角或景別**同場景時必須有景別或角度的變化，禁止同景別同角度的相鄰幀**`PAN` / `PUSH-S` / `ORBIT-S` / `TILT`**母題轉場·場景躍遷**場景完全切換，但前幀的核心視覺母題（形狀/質感/符號）在新場景中以變形方式嵌入新場景資訊量必須與前幀明顯不同，空間完整可讀；母題元素以變形而非複製方式出現`MORPH-LOCK` / `STATIC`

### 2.4 運鏡設計系統

速度原則

**全程以極緩/緩為唯一基調，禁止任何急速運鏡。** 極緩+緩速段落合計佔比≥80%，中速已是上限，急速全程禁止。

全域性運鏡敘事弧線（先規劃整體，再設計每段）

**影片提示詞的運鏡設計必須從全域性視角出發，先確定整條鏈路的運鏡敘事走向，再為每段影片寫具體指令。** 孤立設計每段鏡頭會導致方向感混亂、節奏斷裂。

**全域性規劃的步驟：**

1. **為整條鏈路選定一條運鏡主線**，作為貫穿全片的視覺敘事主幹
2. **在主線內設計節奏變化**：速度的起伏、方向的轉折、運動的暫停
3. **確定轉折點位置**：哪幾段是主線的"轉向"，之前和之後的運鏡方向各是什麼
4. **每段影片的運鏡設計從主線推導**，而不是獨立決定 **典型運鏡主線示例：**

主線型別描述適合情感弧線**持續推入→轉折靜止**全程緩慢推入畫面深處，在情感核心處突然靜止，讓畫面內容自己說話迷失、深陷執念**持續拉出→迴歸**從極端特寫緩慢拉出，場景逐漸展開，呼應開場的初始景別覺醒、解脫**推入→暫停→拉出**前段推入深入，中段靜止/形變，後段緩慢拉出釋放進入-核心-釋放的完整弧線**持續橫移掃描**鏡頭在空間內緩慢橫移，像在閱讀一段敘事觀察者視角、疏離感**形變主導**鏡頭幾乎不動，靠畫面內容的緩慢形變推進敘事宿命感、不可抗力

高階轉場手法

轉場簡述**匹配轉場**前後幀主體形狀吻合，鏡頭鎖定，形狀緩慢滑變**遮擋轉場**前景物體緩慢填滿畫面，揭開後變為下一幀**焦點轉場**焦點從前景移至背景，背景即下一幀內容**光影淹沒**光線擴充套件填滿畫面，消退後露出下一幀**材質滲透**前幀材質質感滲透覆蓋畫面，下一幀從中浮現**映象對稱**畫面沿中軸摺疊後展開為下一幀

**在指令碼檢視運鏡列中標註，格式：** `緩緩推近 + 匹配轉場`

**橫向運動穿插規則：** 全鏈路中 PAN / TRACK / TILT / ORBIT-S / BREATH-FLOAT 類運鏡總佔比不低於 30%。指令碼檢視"運鏡設計"列用人話描述（如"緩緩推近，轉為向左緩搖"），不直接寫程式碼。

允許與禁止

**允許：** 慢速形變、緩慢搖鏡、微弱推移、光影漸變、材質呼吸、細節浮現、視差漂移、六種高階轉場（匹配/遮擋/焦點/光影淹沒/材質滲透/映象對稱）

**禁止：** 任何急速運鏡（俯衝、快速滑軌、高速穿越、廉價旋轉）、過度運動、彈跳/抖動、發光光暈光束等發光效果

### 2.5 指令碼檢視確認後的暫停提示

## 階段 3：全部 N 張分鏡圖（鏈式生成，全部完成後一次確認）

**進入分鏡圖生成前，先告知使用者：**

> "好，現在開始生成分鏡圖。共 \[N\] 張，每張生成後會立即連結到下一張的參考輸入繼續生成，全部完成後一起展示給你確認。"

### 3.1 生成策略：鏈式逐張生成，全部完成後一次確認

**強約束：分鏡圖必須用 Midjourney V8.1 生成，agent 在畫布中全程操作（建節點、連線、觸發生成），不交給使用者手動執行。** 若環境未連線 Midjourney V8.1，告知使用者並提供提示詞由使用者自行執行。

S02必須等S01生成出圖後才能建節點連線生成，全程鏈式推進不中斷，所有 N 張全部生成完畢後一次性展示給使用者確認。

具體操作：

- 在 Midjourney V8.1 畫布（Canvas）中建立 S01 節點，填入提示詞，觸發生成
- S01 出圖後，立即建立 S02 節點，**將 S01 節點的輸出端連線連線到 S02 節點的圖片參考輸入端**（`--iw 0.3`），填入 S02 提示詞，觸發生成
- 以此類推連續生成至 SN，全部完成後一次性展示給使用者 **節點連線全部由 agent 在畫布中操作完成，不需要使用者手動連線。**

**鏈式參考的目的與邊界：**

- ✓ 延續：光源方向、主色調偏向、材質粗細、陰影密度
- ✗ 不照搬：構圖、主體位置、景別、具體畫面內容 **每張提示詞必須寫清楚以下四點：**

1. **景別**：遠景 / 全景 / 中景 / 近景 / 特寫 / 極端特寫 / 微觀（明確寫出）
2. **角度**：正面 / 側面 / 背面 / 俯拍 / 仰拍 / 斜側（明確寫出）
3. **畫面內容**：主體是什麼，在場景的哪個位置，材質與狀態
4. **參考前幀的哪一部分**：明確指出參考上一張圖的哪個具體區域或元素（如"參考 S01 左側壁面的紋路質感"、"參考 S02 中央光斑的冷色調"），不能只說"參考上一張"

### 3.2 全域性 MJ V8.1 規則

所有 Midjourney V8.1 提示詞：

- 必須附加：**階段1確認的完整風格種子程式碼**（寫入每一條提示詞的末尾，不得省略）

### 3.3 分鏡圖提示詞結構

**步驟1中關於片名的選擇僅影響最後一段影片提示詞，不影響分鏡圖生成。分鏡圖生成階段完全不考慮片名，提示詞中不出現任何與片名相關的內容。嚴禁專門為片名建立額外的分鏡幀（如"片名幀"、"標題幀"等）——片名只在最後一段影片 VID_N-1 的提示詞裡以淡入方式疊加在畫面上，不是一張獨立的分鏡圖。**

提示詞嚴禁包含：

- **任何字型設計、文字排版、標題設計元素**
- **與劇本時代背景不符的元素**
- agent 的內部分析說明（景別標籤、過渡型別標註等） **提示詞格式（不使用結構化標籤，直接描述畫面，寫成連續自然的電影攝影指令）：**

## 階段 4：影片提示詞 + 畫布節點搭建

### 4.1 核心原則：看圖寫提示詞，agent 建好節點

**影片提示詞必須基於畫布上的實際分鏡圖畫面來設計，不能照搬分鏡圖的文字提示詞。** 使用者調圖後畫面可能與文字描述有偏差，提示詞要忠實於最終影象。

**流程：**

1. 使用者確認所有分鏡圖後，agent 觀察畫布上每對相鄰幀的實際畫面，寫出全部 N-1 段影片提示詞（包含 VID_N-1，片名已在步驟1確認）
2. 實際影象與指令碼方案不匹配時，以實際影象為準調整運鏡
3. 將所有影片提示詞展示給使用者瀏覽，然後 agent 在畫布中搭好全部節點並連線，直接逐段觸發生成，無需使用者再次確認
4. **全部影片生成完畢後，立即自動進入階段5：先合成影片，再生成BGM併疊加，無需等待使用者指令。影片比例：** 所有影片提示詞中必須註明 `--ar 21:9`。

**首尾幀強約束：** 每段影片必須以實際 MJ V8.1 生成的分鏡圖作為首幀和尾幀輸入影片模型，**禁止使用全能參考模式（單圖參考/全圖參考），必須是首尾幀模式**。不允許用文字描述替代影象，不允許只用單幀生成影片。沒有首尾幀影象就不能生成影片。

### 4.2 段落結構

每一段影片對應一對相鄰分鏡：

```
VID_01：S01（首幀圖）→ S02（尾幀圖）
VID_02：S02（首幀圖）→ S03（尾幀圖）
……
VID_N-1：S(N-1)（首幀圖）→ SN（尾幀圖）
```

所有影片段必須使用使用者最終確認的 MJ V8.1 生成影象作為首幀和尾幀，不使用文字描述替代。

### 4.4 影片提示詞的寫法：先全域性規劃，再逐段寫作

**第一步：全域性運鏡敘事規劃（收到所有分鏡圖後，寫任何單段提示詞之前先完成）**

觀察全部 N 張分鏡圖，做出以下判斷：

1. **選定全域性運鏡主線**：整條鏈路的鏡頭運動大方向是什麼？（參考 §2.4 的典型主線示例）
2. **標出轉折點**：哪幾段是主線的"方向轉換"？轉換前和轉換後各是什麼運動狀態？
3. **標出使用高階轉場的位置**：哪對相鄰幀適合做匹配轉場、遮擋轉場等？
4. **標出形變主導段**：哪些段落鏡頭幾乎不動，靠畫面內容緩慢形變推進？ 規劃完成後直接逐段寫提示詞，無需輸出運鏡方案表給使用者確認。

**影片提示詞的唯一職責是描述鏡頭行為，不描述畫面內容。** 首幀和尾幀的畫面內容已經鎖定在影象裡，影片生成模型從影象本身讀取，提示詞裡不需要重複描述。

**提示詞只寫四件事：**

1. 首幀影象引用
2. **畫面內生動態**：首幀圖裡已有的元素如何輕微運動（粒子飄散、煙霧流動、人物緩步、光線微顫等）——只衍生圖中已有的內容，絕不新增圖中沒有的東西，一句話即可
3. 鏡頭運動指令：方向、速度，以及高階轉場手法的鏡頭行為描述（只說鏡頭怎麼動）
4. 尾幀影象引用（作為鏡頭落點） 高階轉場寫法：匹配轉場、遮擋轉場、焦點轉場、光影淹沒、材質滲透、映象對稱——在提示詞裡用一句中文說明轉場動作即可，不需要展開描述。

鏡頭運動寫法（用人話，不用程式碼）：

鏡頭動作寫法示例向前推近鏡頭極緩慢向前推近向後拉遠鏡頭緩緩向後拉遠向左/右搖移鏡頭極緩慢向左搖移向左/右平移跟隨鏡頭緩慢向左平移跟隨主體緩緩俯視/仰視鏡頭極緩慢向下傾斜緩緩環繞鏡頭極緩慢繞主體環繞穿越推入鏡頭緩緩穿入表面，過渡至內部靜止鏡頭完全靜止鎖定形變鏡頭鎖定不動，畫面內容緩慢變形呼吸浮動鏡頭無刻意運動，極輕微有機浮動

```

## 階段 5：BGM 生成 + 影片合成（影片全部生成後自動執行，無需使用者觸發）

### 5.3 BGM 設計

使用者在步驟1已選定 BGM 風格，直接根據選定風格輸出 Suno / Udio 提示詞，BGM 時長與影片總時長一致。

### 5.2 合成

BGM 生成完畢後，在畫布中將所有影片片段按順序拼接併疊加 BGM：

```
VID_01 + VID_02 + … + VID_N-1
```

- 由 agent 在畫布中操作完成，首尾幀對齊直接拼接，不新增任何轉場特效
- 影片節點的聲音開關必須開啟，不要生成音樂/BGM，允許生成音效和環境音；BGM 由本階段生成後疊加

## 階段 6：演職員表 Opening Credits（可選）

### 6.1 演職員表設計

影片合成完成後，用 ask_user_input_v0 工具詢問：

```
問題：需要演職員表嗎？
選項：
- 需要，所有名字生在一張圖裡
- 需要，一個名字一張圖
- 不需要
```

演職員表圖層**由 agent 直接用 image 生成**，不使用 Midjourney V8.1，不附加風格種子。

### 6.2 生成演職員表圖層

收集使用者需要顯示的內容（導演、編劇、主演等名單及順序），然後：

- 用 image 生成工具生成**純黑底**圖層，字的顏色根據最終影片的實際畫面色調設計——取自畫面的對比色或互補色，確保可讀且與整體視覺風格吻合
- 輸出使用者可直接在剪輯軟體中改變混合模式疊加的圖層檔案，無需摳圖

字型方案推薦

方案字型適用場景**工業雕刻**Bebas Neue / 站酷高階黑力量感**極簡現代**Futura PT / 思源黑體清晰易讀**有機手刻**Freight Display / 漢儀旗黑文藝質感**襯線古典**Trajan Pro / 方正宋刻本秀楷史詩感

## 設計原則

1. **禁止字面化** — 不直接呈現劇本中的經典場景，將其轉化為視覺隱喻。
2. **禁止無邏輯的硬切** — 場景可以跨越，但每次跨越都要靠色調統一、材質語言連續、前後幀的視覺關聯點來維持整體的連貫感。
