# award-ceremony-video

做"颁奖典礼"这类个性化荣誉/趣味视频时用本 skill。一条 15 秒电影感一镜：主持人在台上宣布 → 聚光灯扫到人群中的获奖者 → 起身走向领奖台 → 领奖 → LED 屏亮出名字与奖项。**图序 = 身份序：第一张 = 获奖者 =** `@image_1`**，第二张 = 主持人 =** `@image_2`**；调换会把"宣布者"与"上台者"对调。**

> 本环境适配：源为 MUAPI/Seedance 2.0 图生视频 recipe，表达已按 MIT 重写。Seedance → `generate_image_v3`（角色锚点）+ `generate_video_v3`（图生视频，一次调用 ≤15 秒）；`@image_1/@image_2` → `reference_nodes` + prompt 里 `{{NodeKey}}`；技术规格（`aspect_ratio`/`resolution`/`duration_sec`/生成音频）走字段，不写进 prompt 正文。

## 输入

名称必需默认说明获奖者照是—清晰正脸照。作 `@image_1`（第一张），全片身份严格锁定。主持人照是—清晰正脸照。作 `@image_2`（第二张），台上唯一主持人。获奖者名字否Olivia主持人念出，并渲染在 LED 屏 "THE BEST ACTOR" 之上。生成前先跟用户确认拼写（音频与 LED 屏两处都出现）。奖项名否THE BEST ACTORLED 屏显示的奖项标题。

## 流程

### 一、确认输入

两张照片任一缺失 → 请用户先上传。生成前确认获奖者名字与奖项名——两者都会在成片里出现（音频 + LED 屏文字），拼写错了要重烧。

### 二、注册双人锚点

用 `generate_image_v3` 为获奖者、主持人各出一张稳定角色设定图，作持久身份锚点（获奖者 `{{Winner}}`、主持人 `{{Host}}`）。**顺序即身份**：获奖者锚点先入 `reference_nodes`（映射 `@image_1`），主持人次之（映射 `@image_2`）。若两人此前已有可复用锚点，直接复用 node_key、跳过重建。

### 三、生成成片

用 `generate_video_v3` 图生视频，一步出片：`reference_nodes` 按 \[获奖者, 主持人\] 顺序传入；`aspect_ratio=16:9`、`resolution=720p`、`duration_sec=15`、开启生成音频。prompt 覆盖下述五轴 + 15 秒时间线：

**风格与基调**：极写实真人颁奖典礼现场，多机位广播质感——在精修的电视转播机位与贴身手持纪录片镜头之间切换；奥斯卡/格莱美级制作水准；真实人类反应，不过度表演。

**布光**：宏大室内颁奖场馆。戏剧性舞台光——舞台暖金聚光、观众席偏冷环境光、广播摄像机灯、LED 屏投出彩色光。宣布获奖者瞬间——一束暖光扫过并锁定人群中的获奖者。

**场景**：格莱美/奥斯卡规模的顶级颁奖场馆。高耸 LED 屏的大舞台、优雅讲台、现场乐池、成千正装观众成排就座、过道两侧的媒体摄像机、头顶大屏播直播画面——整个场馆散发气派与规模感。

**身份严格锁定**：

- `@image_1` 获奖者「{名字}」——以 @image_1 为严格身份，正装出席、无墨镜、不改脸不改身形，初始坐在观众席正装人群中。
- `@image_2` 主持人——以 @image_2 为严格身份，讲台唯一主持人，保持精确面部/身形/特征，正装、不改脸不改身形。

**音频**：优雅管弦背景乐、主持人话筒声经场馆扬声器投射、人群低语后转为爆发的掌声欢呼、椅动声、上台脚步声、奖杯/奖牌递接声、观众情绪反应。

**15 秒时间线（跨镜每处重标身份锚点，防漂移）**：

- **0–3s 宣布**：@image_2 面部广播特写（紧、电影感），立于讲台话筒前暖金聚光下，神情从容有魅力、刻意积蓄悬念；手持信封/卡片，最后瞥一眼，直视镜头，一拍静默，凑近话筒缓缓说"And the winner is..."；镜头锁在 @image_2 脸上——唇、表情、张力；背景人群低语。
- **3–6s 获奖者**：硬切到观众席——低角度电视机位穿过成排座位推进，找到坐在宾客中、放松未预期的 @image_1；@image_2 声音继续经扬声器轰响出名字；聚光从上方骤然锁定 @image_1，其表情由真实错愕（睁大眼、微张口）转为忘我笑容，左右看向身旁难以置信；全场掌声欢呼爆发，周围人起立鼓掌拍肩。
- **6–9s 起身与行进**：@image_1 挺身、平复、起立；手持纪录片镜头立刻从过道跟上——随人前行朝舞台移动，微晃、贴身、真实；掌声持续轰鸣；头顶广播大屏切到其面部直播；@image_1 从容前行——正装整洁、身姿挺直、神情温暖略动情。
- **9–12s 抵台**：手持镜头随 @image_1 登台阶，明亮舞台聚光在其登台时完全打上；@image_2 从讲台前迎、暖笑、双手捧奖牌；@image_1 抵讲台、双手接过、低头看一眼真实一刻；两人自然一笑与短握手；身后巨型 LED 屏：@image_1 面部大幅肖像、其名字以粗体优雅字体呈现「{名字}」、下方「{奖项名}」，屏面辉光并跳动庆祝图形。
- **12–15s 定格**：镜头落到全舞台广播全景——@image_1 立于讲台手持奖牌、@image_2 立其旁、身后 LED 墙以其名字与面部灼亮；聚光锁 @image_1；掌声充满全场、起立鼓掌层层扩散；@image_1 略举奖牌望向人群、笑容从容真诚；@image_2 在旁领掌；末帧定格——全舞台、灼亮 LED、轰鸣人群、@image_1 立于中心；不淡出黑场。

出片后把这条 15 秒成片交付用户。
