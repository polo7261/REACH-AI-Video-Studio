蘇聯粗野主義風格Skill SKILL: Soviet Brutalist Cinematic Short Film Skill ID: reach-industry/brutalist-film Version: 3.1 適用場景: 蘇聯粗野主義風格電影短片生成，保證人物一致性、風格穩定性與電影美學價值。
一、Skill 定位與目標 本 Skill 用於生成具備以下特徵的粗野主義風格短片：
🏗️ 風格錨定：Base Prompt + 色調規範 + 禁止項鎖死（不可動的風格核心） 🌊 最大發散：主題、故事、場景、角色、氛圍、敘事結構、道具、對白、音效、轉場全部由AI即興創作，不設固定素材庫 🧍 人物一致：主角形象透過 Lib Image 生成並鎖定，全鏡複用 🖼️ 環境定調：MJ V8.1 生成3張環境氛圍參考圖，鎖定全片場景基調和色調，後續分鏡以參考圖為錨 🎬 景別豐富：強制多景別分佈，禁止連續相同景別 💬 人物對白：每鏡可生成人物對白/獨白，支援中文/英文/俄語選擇 🎞️ 高密度分鏡：預設2.5秒/鏡快切換，Beat拆分微鏡頭，強化故事張力 🔊 音效契合：根據故事氛圍生成匹配的電影級環境音效（無背景音樂） 📦 流程可複用：6步標準流程，任何人按步驟均可生成高質量成片 二、風格核心錨點（全片必含，禁止隨機化） 這是唯一不可動的部分。錨點之外的一切由AI即興創作。
Base Prompt——每鏡必須包含 Soviet brutalist architecture, raw concrete texture, colossal geometric structures, monumental scale, cold grey atmosphere, volumetric fog, cinematic lighting, 8k resolution, photorealistic
色調規範 主色調：冷灰 / 鐵鏽紅 / 骨白 唯一暖色：遠處單窗琥珀光（象徵體制內部） 禁止出現：飽和暖色、綠植、現代元素 景別多樣性強制規則 6鏡短片必須覆蓋至少 4 種景別，8鏡及以上必須覆蓋至少 5 種 景別程式碼及人物佔比參考： ELS（極遠景）：人物佔畫面 ≤3%，強調環境壓迫 LS（遠景）：人物佔畫面 5–15%，人物可辨認但仍渺小 MS（中景）：人物腰部以上，佔畫面 30–50% MCU（中近景）：人物胸部以上，佔畫面 50–70% CU（特寫）：人物面部/手部/道具細節，佔畫面 70–90% ECU（大特寫）：眼神/材質紋理，佔畫面 90%+ 禁止連續 2 鏡使用相同景別 鏡頭運動規範 ✅ 允許：Hitchcock zoom / dolly zoom、push in、pull back / zoom out、tilt up/down、pan left/right、slow tracking、slow crane up/down、slow orbit ❌ 禁止：建築物移動/升高/倒塌/變形、地面塌陷/隆起/位移、天空旋轉、雲層快速位移、任何物體不合理的物理運動 近景/特寫優先 static 或極輕微 push in，禁止大幅運動 三、AI即興創作規則（風格核心之外最大發散） 不設固定素材庫。AI在風格錨點約束下即興創作所有內容。
創作原則 風格優先：所有即興內容必須符合粗野主義美學（混凝土巨構、體制壓迫、人的渺小、冷灰色調） 每次不同：每次執行Skill必須產出完全不同的故事/場景/角色/氛圍，禁止重複使用上次的方案 具體而非抽象：生成的故事必須有具體的人物、動作、空間、情感，不是抽象概念描述 粗野主義氣質檢查：AI生成的每個元素都應問"這屬於粗野主義世界嗎？"——如果否，重新生成 AI即興創作清單（每次執行全部重新生成） 創作維度 規則 風格約束 🎭 故事主題 AI即興創作一個完整故事，含一句話設定 + 5個Beat 必須發生在粗野主義建築環境中，人物渺小，體制壓迫感 🌫️ 環境氛圍 AI即興創作一個環境氛圍基調 必須是冷灰色調系，極端天氣/光照條件優先 🏛️ 場景 AI為每鏡即興創作一個粗野主義場景 必須是混凝土巨構/蘇聯式建築空間，每鏡場景不重複 🧑 角色設定 AI即興創作主角外貌/服裝/氣質 蘇聯時代服裝，氣質壓抑/隱忍/麻木/堅定 🗝️ 象徵道具 AI即興創作1-2件跨鏡道具 蘇聯時代物件，有象徵意義，承載敘事功能 📖 敘事弧 AI即興設計敘事結構 必須有明確情緒走向，結局可為悲劇/迴圈/虛無/覺醒 💬 對白 AI即興創作每鏡對白 短句冷硬風格，對白是畫面延伸而非解釋 🔊 音效 AI即興創作環境音效描述 純環境音無配樂，與氛圍匹配 🎞️ 轉場 AI為每鏡銜接即興選擇轉場 crossfade/fadeblack/dissolve，相鄰不重複 故事生成指導（非固定模板，AI參考但不限於此） AI創作故事時應考慮以下粗野主義典型母題（可組合/變異/顛覆，不限於這些）：
體制與個體：排隊/審批/等候/被拒絕/被遺忘 記憶與遺忘：舊地址/舊照片/舊物件/找不到的房間/消失的痕跡 迴圈與困境：重複路線/無盡走廊/永遠到不了的目的地/回到起點 孤獨與等待：空曠廣場/無人車站/等不到的人/永遠不會舉行的儀式 權力與渺小：巨型建築下的人/仰望穹頂/面對高牆/在體制深處 時間與衰敗：即將拆除的大樓/被遺忘的紀念碑/荒廢的公共空間/雪覆蓋一切 以上母題僅為參考方向，AI應自由發散創造新母題，只要符合粗野主義美學即可。
