# content-analyzer

工具型 skill——一组内容分析模式，逐步生长。每个模式把用户**已有的一件具体内容素材**（视频、片段、URL 指向的成片）解析成**结构化、面向下游用途**的分析。在分析阶段被工作流（或直接）调用，位于任何下游编辑/营销/生成步骤之前：当一件具体内容必须先被拆成结构化、面向用途的分析时用它。

按你的意图选**一个**模式，只跑匹配的那个，不要两个都拉。

## 模式选择

| 意图 | 产出 |
|---|---|
| 为营销分析一段视频 | 视频的营销拆解——钩子（视觉/听觉/语义）、留存节拍、CTA、可传播性（STEPPS） |
| 为编辑分析一段视频 | 针对单个增/删/改/替的改动点分析，落到重生成对应分镜的指令 |

先用 `analyze_video_clip_storyboard` 拿到分镜、节奏、镜头语言，作为两种模式共同的**结构底座**；再在结构之上做对应模式的提炼。

## 模式一 · 营销拆解（marketing-analyze）

在结构底座之上，逐层提炼：

- **钩子（前 1-3 秒抓人）**——分三路各自定位：
  - 视觉钩子：开场画面的反常/张力/信息缺口（谁/什么/异常状态）。
  - 听觉钩子：开场音效/口播/音乐的抓耳点。
  - 语义钩子：文案/口播抛出的悬念、承诺或冲突命题。
- **留存节拍（retention beats）**——沿时间轴标出维持观看的节点：信息释放的节奏、反转/揭晓点、视觉换挡、"再等一下就有"的悬置，指出哪几拍在防跳出。
- **CTA**——行动号召出现的时机、形式（画面/口播/字幕）、措辞与指向的下一步动作。
- **可传播性（STEPPS 六要素）**——逐条判定这条内容触发分享的机制：
  1. **社交货币 Social currency**：分享它能让人显得懂行/前卫/有品位吗？
  2. **触发物 Triggers**：有没有把内容与日常高频场景/物件绑定，让人反复被提醒？
  3. **情绪 Emotion**：唤起的是高唤醒情绪（惊叹/愤怒/好笑/焦虑）还是低唤醒（满足）？高唤醒更易被转发。
  4. **公开性 Public**：内容/产品的使用是否可见、可被模仿、留下公开痕迹？
  5. **实用价值 Practical value**：是否提供可转告他人的实用信息（省钱/省事/有用技巧）？
  6. **故事 Stories**：核心信息是否被包进一个会被复述的故事载体里？

输出为结构化要点（分条/表），而非散文式复述。

## 模式二 · 编辑改动分析（edit-video-analyze）

针对用户想对成片做的**单个改动点**（增加 / 删除 / 替换 / 修改某元素）做分析。

- 先在结构底座上**定位改动落在哪一分镜/哪一段时间轴**，说清改动的对象、位置、期望效果。
- **本环境无 video-to-video 直接编辑能力**：视频靠 `generate_video_v3` 用文本 + 锚点重新生成。因此改动分析的产出不是一条 v2v 编辑指令，而是**把受影响的分镜改写成新的生成指令**——保留不动的分镜锚点不变，只重写被改动分镜的提示词/构图/动作/时长，交给下游重生成该分镜后再拼接。
- 一次只处理一个改动点；多个改动点逐条拆开、各自落到对应分镜的重生成指令。

## 输出去向

两种模式的结构化分析都写进目标分镜表 / 锚点清单（`write_file_v2`），供 video-generation 或复刻流程直接消费。

## 边界（勿用本 skill，改道）

- 只针对**已有的具体内容**做分析；趋势 / 爆款 / 创作者发现类研究不在此。
- 产品输入预处理（把产品图/URL 解析成品类/用途/开场机制）→ product-analyzer。
- 品牌资产提取（从品牌主页拿 logo、配色）→ brand-analyzer。
- 图像 / 视频生成本身 → 对应生成能力或 workflow 流程。
