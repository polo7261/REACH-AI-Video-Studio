# 洗圖高畫質重繪

## 這個 Skill 是什麼

使用者提供一張原圖，Skill 自動走完"輔助圖生成 → 需求確認 → 多維度提示詞反推 → 雙模型高畫質重繪"完整流程，最終輸出兩張 2K 高畫質重繪圖（Seedream 5.0 Pro 版 + Lib Image 版）。

適用場景：想提升一張圖的畫質和寫實感，同時保留原圖的構圖、色調和氛圍，不是單純放大，而是重新生成一張更高質量的版本。

不適用場景：只需要無損放大/超分（不需要重繪）；需要大幅改變構圖或主體內容。

---

## 輸入

- 【原圖】：使用者上傳一張參考圖（任意畫幅比例，Skill 全程保持原圖比例不變）

---

## 第一步：生成三張輔助圖

使用 Lib Image 最低畫質最低質量選項，保持原圖構圖和畫幅比例，生成以下輔助圖：

### 1. Depth Map（黑白灰度深度圖）

使用以下固定提示詞，不得修改：

> 保持原圖的構圖、比例不變，輸出Depth Map（黑白灰度圖）

- 生成 1 張

### 2. 固有色圖（扁平化色塊蒙版）

使用以下固定提示詞，不得修改：

> 保持原圖的構圖、比例不變，生成一張專業的完整固有色圖片。包括細小道具，地上的羽毛等等。排除干擾：完全移除所有的光照、陰影、高光、反射、環境光遮蔽（AO）以及表面紋理細節。畫面應呈現為扁平化的 2D 向量風格。一致性：同一種材質必須使用完全相同的顏色程式碼；不同材質必須使用對比度強烈的顏色以便區分。色彩分佈均勻，無噪點，適合作為蒙版使用。禁止勾線，禁止出現線條，禁止勾線，禁止出現線條，禁止勾線，禁止出現線條，禁止勾線，禁止出現線條

- 生成 1 張

### 3. 高斯模糊圖（色調氛圍圖）

- 高度模糊處理，完全去除細節
- 只保留整體色調分佈和氛圍感
- 保持原圖構圖和比例不變
- 生成 1 張

## 第一步半：人物檢測

三張輔助圖生成完畢、使用者確認後，在進入需求確認之前，先對原圖進行人物檢測：

**檢測標準：** 分析原圖中是否存在可識別的清晰人物形象。以下情況不觸發此環節，直接跳過：

- 人群（無法區分個體）
- 背影（看不到面部或明顯特徵）
- 人物在畫面中佔比很小（遠景小人、路人等）
- 人物模糊看不清

**檢測到可識別人物時：**

1. 告知使用者檢測到了人物，並描述人物的位置關係（例如："畫面左側有一名人物 A，畫面右側有一名人物 B，前景中央有一名人物 C"）
2. 詢問使用者是否需要上傳人物參考圖，以便在重繪時保持人物形象一致
3. 如果有多個可識別人物，逐一明確每個人物的位置標識（畫左 / 畫右 / 前景 / 後景 / 中央等），請使用者對應上傳每個人物的參考圖
4. 等待使用者上傳參考圖後，將各人物參考圖與其位置標識繫結，作為第四步重繪時的人物一致性錨點

**使用者選擇不上傳，或圖中無可識別人物時：** 跳過此環節，直接進入第二步。

---

## 第二步：確認使用者需求

使用者選定主固有色圖後，向使用者提問，確認本次重繪的具體意圖：

向使用者詢問以下三個問題（可合併為一次提問）：

1. **內容修改意向**：對這張圖希望做哪些內容上的改動？（例如：替換背景、改變主體、調整構圖等）
2. **重繪模式**：還是不修改內容，只做寫實化 / 高畫質重繪？（保留原圖所有元素，只提升畫質和真實感）
3. **其他特殊要求**：有沒有風格偏好、禁止事項、或其他需要特別注意的要求？

等待使用者回答後，將使用者的需求作為約束條件，帶入第三步。

---

## 第三步：選擇反推提示詞方式

在進行反推分析之前，先詢問使用者選擇哪種方式來獲取提示詞：

**選項 A：由 Agent 反推提示詞**按照三層方法論 + 8 維度結構化分析流程執行（見下方第三步正文）。

**選項 B：使用者自己去 GPT 反推提示詞**輸出以下固定文字供使用者複製使用：

> 「\[你的需求\] + 反推這張影象的提示詞，要求反推提示詞非常精準，從構圖、主體、顏色、氛圍、光影、材質、質感、風格、濾鏡效果、年代感等方面深度分析，反推出來的提示詞，我要用它在 ChatGPT 中生成並還原參考圖片的視覺呈現效果」

輸出後等待使用者將 GPT 反推好的提示詞貼上回來，收到提示詞後直接跳轉至第四步執行重繪，跳過以下反推分析流程。

---

**以下內容僅在使用者選擇選項 A 時執行：**

反推不是"描述圖片"，而是三層邏輯遞進：

**第一層：診斷原圖的"假感來源**"找出哪些地方顯得不真實，例如：CG 感、模型感、光線不真實、材質過於乾淨、塑膠質感、遊戲渲染感等。逐條列出。

**第二層：定義目標調整方向**結合使用者在第二步中確認的需求，明確三件事：

- 保留什麼（構圖、主體、結構、色調方向）
- 改變什麼（質感、光影真實度、材質細節，以及使用者指定的內容修改）
- 對標什麼風格（給出具體參考作品或美術風格，如"《流浪地球2》真實工業科幻"、"A24 剋制攝影感"）

**第三層：按維度逐一重建描述**，輸出可直接用於生圖的結構化提示詞。

---

按以下 8 個維度逐一輸出，每個維度都要具體到可直接用於生圖的描述粒度（顏色不寫"灰色"，而寫"舊銀色機械結構"；材質不寫"金屬"，而寫"磨損鈦合金，表面有氧化痕跡和灰塵覆蓋"）：

### 1. 構圖分析

- 攝影機位置：高度（俯視 / 平視 / 仰視，具體角度估算）、機位距主體的距離感
- 鏡頭型別：焦距估算（廣角 / 標準 / 長焦，估算 mm 數）
- 前中後景關係：逐層描述每層的具體元素、位置、與主體的關係
- 透視關係：單點透視 / 兩點透視 / 對稱構圖 / 消失點位置
- 畫幅比例：精確比例（如 21:9 / 16:9）

### 2. 主體設計

- 核心主體是什麼（不只是字面描述，而是定義"這張圖在講什麼"，如"月球工業時代的人類能源基礎設施"）
- 主體的具體形態、數量、在畫面中的位置
- 關鍵詞提煉（3～5 個最能定義這張圖視覺語言的詞）
- 視覺參考作品（具體到作品名稱或導演/攝影師）

### 3. 顏色分析

- 主色：佔畫面面積最大的顏色，具體描述（如"冷灰黑月球表面"）
- 輔助色：第二、第三大面積顏色，具體描述
- 點綴色：小面積強調色，具體描述
- 整體色調定性：色溫（冷 / 暖 / 中性）、飽和度（高 / 中 / 低）
- 明確排除哪些顏色傾向（如"避免藍色科幻濾鏡、霓虹未來感、高飽和遊戲風"）

### 4. 光影設計

- 光源性質與方向（硬光 / 軟光，時鐘方位描述，如"左上方約 10 點鐘方向"）
- 真實環境光邏輯（基於場景物理特性，如"月面無大氣散射，單一強方向光，高對比"）
- 需要加入的補光邏輯（如"月壤反射補光、金屬環境反射、暗部保留細節"）
- 高光表現（剋制 / 強烈 / 有無高光滾降）
- 陰影深度與層次（濃重 / 輕柔，陰影內部是否有細節層次）
- 明確排除哪些光影錯誤（如"禁止純黑陰影、禁止遊戲硬邊光、禁止 HDR 過曝"）

### 5. 材質真實化方向

逐類列出畫面中主要材質，每類描述：

- 材質名稱（具體，如"航天級鋁合金"而非"金屬"）
- 磨損 / 老化程度（全新 / 輕微磨損 / 重度老化，具體表現如"微劃痕、氧化痕跡、灰塵覆蓋、長期維護留下的小修補痕跡"）
- 表面紋理特徵（粗糙 / 光滑 / 顆粒感 / 拼接縫隙 / 法蘭介面 / 螺栓細節等）
- 反光特性（啞光 / 半光澤 / 高光澤）

### 6. 電影攝影引數

- 攝影機型號（如 ARRI Alexa 35）
- 鏡頭型號（如 ARRI Signature Prime）
- 焦距（如 35mm 廣角）
- 光圈（如 T4-T5.6）
- 幀率（如 24fps）
- 膠片 / 色彩系統（如 Kodak Vision3 5219 色彩，效果：柔和高光、厚重黑位、真實膠片顆粒、輕微鏡頭呼吸）

### 7. 最終生成提示詞

基於以上分析整合為一段完整的正向提示詞，可直接用於生圖。輸出中英雙語：

- **中文版**：完整段落，按構圖 → 主體 → 色彩 → 光影 → 材質 → 攝影引數順序組織
- **英文版**：對應的英文提示詞，適配 Stable Diffusion / Midjourney / DALL-E 等模型語法

### 8. 負面約束詞

根據第一層診斷結果自動生成，分兩套：

- **中文版**：每條以"禁止"開頭，逐條列出
- **英文版**：negative prompt 格式，逗號分隔

---

## 第四步：雙模型高畫質重繪

以第三步的提示詞（無論來自 Agent 反推還是使用者自行提供）為基礎，同時將以下內容作為參考輸入：

- **Depth Map** → 提供空間關係和前後景層次
- **固有色圖** → 提供構圖結構和主體位置
- **高斯模糊圖** → 提供整體色調和氛圍
- **人物參考圖**（如有）→ 按位置標識逐一作為人物一致性錨點引用

分別使用以下兩個模型，標準畫質，各生成一張 2K 圖片，畫幅比例與原圖保持一致：

1. **Seedream 5.0 Pro** → 輸出重繪圖 A
2. **Lib Image（image2）** → 輸出重繪圖 B

**⚠️ 硬性規定：最終重繪圖的 reference_nodes 中嚴禁引用原圖。** 允許引用的節點僅限於：Depth Map、固有色圖、高斯模糊圖，以及使用者額外提供的參考圖（如人物參考圖）。原圖不得以任何形式出現在最終生成步驟的參考輸入中。

---

## 第五步：不滿意時的重試流程

重繪圖輸出後，如果使用者對結果不滿意，希望重新生成：

**直接複用已有的三張輔助圖**（Depth Map、固有色圖、高斯模糊圖），**不重新生成輔助圖**。

按以下順序重新執行：

1. **重新詢問需求**（回到第二步）：重新向使用者確認本次重繪的具體意圖，包括內容修改意向、重繪模式和其他特殊要求。
2. **重新反推提示詞**（回到第三步）：基於使用者新的需求，重新選擇反推方式並生成提示詞。
3. **重新執行重繪**（回到第四步）：使用新提示詞 + 原有三張輔助圖，重新生成兩張重繪圖。

**注意：** 人物參考圖（如有）同樣繼續複用，無需重新上傳。
