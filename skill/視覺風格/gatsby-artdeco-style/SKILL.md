# gatsby-artdeco-style

生成舊好萊塢金色調、Art Deco、Americana/Route 66 公路氛圍的影片/圖，或為歷史/美食/運動/愛情/懸疑/MV/夢境/公路等任意題材套用此美學時用本 skill。**風格致敬，不宣稱是任何具體版權作品/藝人。**

> 本環境適配：GPT Image/Seedance/MultiModalToVideo → `generate_image_v3`/`generate_video_v3`；text to narration/BGM → `generate_audio`；text_editor → `write_file_v2`；video_assembler → `composite_video`。提示詞引數（2K/720p/畫幅/膠片語彙）為工藝詞面，全部保留。超解析度後處理（Jimeng SR 4K/MediaKit 1080p）= 本環境無對應能力，刪。

## 流程（里程碑暫停，不一次跑完）

1. **引數**：`write_file_v2` 鎖 題材型別/時長/語言/畫幅(**2.39:1 優先**或 16:9)/視覺風格("金色懷舊")。
2. **分鏡**〔暫停〕：key elements / shot 列表 / audio layers；完成後掃描上下文，把使用者已上傳或已生成的素材繫結到對應槽位。
3. **視覺元素**〔暫停〕：為所有 key elements 出圖（已有參考圖直接綁）；**有臺詞角色在元素圖完成後立即處理 key_element_audio**（使用者提供聲線參考直接綁，否則按聲線風格生成短樣本）——須在任何含臺詞 shot 影片生成前完成。
4. **逐鏡影片**〔暫停〕：以 element 圖為主參考；僅當與上一鏡視覺連續性極強時才追加上一鏡 reference_video。
5. **音訊**（BGM + VO 旁白）〔暫停〕→ 6. `composite_video` 合成匯出。

依賴：2→1；3→2；4→3；5→2；6→3,4,5。每個主階段（Spec 鎖定/分鏡/元素圖/鏡頭影片/音訊）後暫停等確認。**使用者上傳素材優先繫結到對應槽位，避免重複生成。**

## 參考素材分析（6 項）

有上傳素材時逐項分析：① **色彩對齊**：提取主色調，判斷是否接近金色懷舊色盤，輸出與目標色盤偏差供提示詞校正。② **光影風格識別**：Golden Hour 逆光/體積光丁達爾/Anamorphic 水平光斑/淺景深是否具備，缺失則列入補足清單。③ **鏡頭語言識別**：畫幅/景別/運鏡型別作分鏡基線。④ **人物/場景元素提取**：服裝髮型妝容、建築陳設年代感、標誌性道具 → 結構化描述直接用於 key_element。⑤ **時代感核查**：排除破壞 1920s–1950s 的現代元素（手機/LED/現代建築/當代車型），存在則排除或推至虛化背景。⑥ **Americana 公路元素識別**：路面型別/地平線消失點佔比/沿途路牌加油站廣告牌 Diner/車型鉻飾年代/光線入射角 → 用於公路類 element scene。

## 美學基調（全域性鎖定）

- **融合色盤**：香檳金 + 菸草棕 + 翡翠綠 + 象牙白 + 落日茜紅。(Teal&Orange / Arri Alexa 調色非全域性預設，僅特定題材按鏡選用，不寫入全域性。)
- **畫幅**：優先 **2.39:1 Anamorphic 寬畫幅**，次選 16:9。
- **光影**：Golden Hour 逆光 / 體積光(可見光塵) / Anamorphic 水平橢圓光斑 / 室內燭光或琥珀鎢絲點光。
- **膠片質感場景分級**：豪宅/宴會/舞臺用細膩 **35mm** 顆粒(穩定曝光、黑位深但保服裝紋理)；回憶/公路/汽旅/私人影像切 **16mm** 顆粒(輕微曝光漂移、偶發跳幀、豎劃痕)。**同一場景型別內不混用兩套顆粒。**
- **核心情緒（須透過可見結果表現，非抽象氛圍詞）**：宴會後空酒杯+散落亮片；人物獨站寬闊房間邊緣；戀人同框但視線不相交；隔著車窗/門框/水面/人群望向對方；遠處燈光/人物始終無法真正靠近。

## 雙重視覺語法（全域性鎖定）

兩套視覺語言須在同一影片內交替，不得始終單一狀態：
- **公開場合**（宴會/豪宅/舞臺/上流社會空間）：穩定或緩慢移動鏡頭；Art Deco 對稱構圖；黑色與象牙白為底，香檳金僅作區域性高光點綴（不鋪滿）；人物表情剋制、動作收斂；35mm 細膩顆粒，不用手持抖動。
- **私人時刻**（回憶/公路/汽旅/獨處）：輕微手持或偏離中心構圖；褪色暖白與菸草棕主調；允許自然曝光漂移；16mm 顆粒加重，偶發跳幀與豎劃痕保留私人影像感。
- **強制對照節奏**：每出現宴會/豪宅/珠寶/名車場景後，須緊接一個人物獨處/空座位/喝剩酒杯/熄滅的燈/無人公路鏡頭——以視覺反差承載幻滅主題，不讓華麗狀態貫穿整段。

## Key Elements 設計規範

- **角色元素**：服化道細節(髮型/妝容/服裝材質)+ 情緒基調；多造型/年齡段逐一列出(造型 A/造型 B)。
- **聲線繫結（key_element_audio）**：凡 shot 中有臺詞的角色必須為其定義 key_element_audio，綁一段聲線參考音訊跨鏡保持音色，在描述中註明聲線風格（可引用 references/audio-voice-presets.md 預設）。**樣本 8–12 秒、須覆蓋該角色典型情緒區間**（平靜敘述+情緒起伏句+收尾低落），非單一情緒朗讀——單一情緒樣本會致 TTS 在不同情緒 shot 音色不穩。使用者上傳參考若情緒單一須註明以便補充多情緒覆蓋。
- **場景元素**：建築風格（Art Deco 豪宅/舊好萊塢片場/爵士夜總會/長島海灣碼頭）或 Americana 公路意象（Route 66 公路盡頭/沙漠高速逆光/1950s 加油站/褪色廣告牌/路邊 Diner/汽旅霓虹夜景）；註明主光源位置色溫 + 標誌性 Americana 細節（瀝青熱浪扭曲、路肩野草、地平線消失點、生鏽招牌褪色霓虹、旋轉吧檯點唱機）；公路場景須註明拍攝視角——車內主觀（擋風玻璃框架）還是車外低機位追拍（路面+輪胎）。
- **道具元素**（關鍵道具單獨立項便於特寫引用）：室內/派對類——香檳塔/老式留聲機/褪色舊相片情書/水晶燭臺/年代感白電話；公路 Americana 類——1950s 車頭鍍鉻飾/方向盤手套箱老儀表盤/鏽跡 Route 66 路牌/褪色廣告牌/Diner 霓虹招牌/公路地圖皮革手提箱/加油站風向標。
- **使用者上傳素材**：element 描述必須與圖中可見內容一致，不矛盾。

## Shot 設計規範

- **時長節奏**：普通敘事鏡頭 4–8 秒；僅完整舞蹈/連續行走/多回合對話等動作不可打斷時才延至 8–15 秒——不得僅因模型支援 15 秒就預設長鏡頭。**一 shot 只承擔一個主要動作或關係變化**；含多景別/多主體/多動作結果須拆分。
- **每 shot 四要素**：① 場景（引用 element scene ID）；② 故事節拍（人物動作/表演細節/對話臺詞，臺詞用 {臺詞} 標註保留原文並附情緒節拍標註，見下）；③ 鏡頭語言（景別+機位角度低角度仰拍/平視/荷蘭角+運鏡鎖定/慢推/搖臂上升/Dolly zoom/Rack focus）；④ 光影節拍（光源型別+色調階段：高飽和金色逆光/燭光暖調/畫面逐漸泛黃褪色）。

## 臺詞情緒節拍標註規範

shot 裡凡出現 {臺詞}，文字之外須緊隨情緒標註，否則下游模型平鋪朗讀失去層次。標註寫在臺詞括號外側：
- **情緒狀態**：（聲音發緊，強撐平靜）（低語，氣聲漸弱）（語氣驟然強硬，音量上揚）等。
- **節奏停頓**：臺詞內用「——」標中等停頓、「… …」標更長情緒間隙，句間換行代表自然斷句。
- **重音與氣聲**：（此詞咬重音）（整句氣聲出，幾乎耳語）（尾音刻意拖長，帶不甘）。
- **整句情緒弧線**：臺詞前標走向，如【從漫不經心 → 話到一半驟然哽住】。
- **與微表情節拍繫結**：臺詞標註須與同一故事節拍的微表情描述對應（如"嘴角輕揚但眼神落寞（輕描淡寫，尾音下沉）{……}"）。
- **與旁白標註的區別**：旁白情緒標註作用於獨立 audio_layer 生成提示詞；臺詞情緒標註作用於 shot 內表演節拍，經 key_element_audio 聲線參考+情緒指令共同驅動角色表演生成，兩套體系並行不替代。

## 慢動作與特效剋制

- **慢動作節拍**：僅情感高潮或敘事意義動作（汗水/蒸汽/回眸）標"120fps 慢動作"；普通走位/對話/過渡不標。餘韻空鏡標"12fps 輕微跳幀感"，不超過該鏡頭時長 20%。
- **特效剋制**：所有視效服務敘事、不為裝飾。Anamorphic 光斑僅強逆光直接入鏡時自然出現，不主動設計為"橫穿畫面"獨立事件；體積光須有現實光源依據（窗縫/門隙/舞臺燈）；膠片劃痕跳幀為點綴，不覆蓋主要敘事段落。

## 題材分鏡節奏偏好（10 模板）

**候選鏡頭庫，非固定順序**：從對應題材庫選 3–5 種鏡頭，不得為符合模板而加與劇情無關的道具特寫/停格/光斑/回眸；每鏡須完成一項明確功能（建立空間/推動動作/改變關係/揭示資訊/情緒反應），無功能的漂亮鏡頭不保留。完整 10 模板（歷史/美食/運動/愛情/懸疑/MV/奇幻夢境含聲音設計專項/懸疑×公路含色調覆蓋+5 段節奏+4 禁止項/公路片）見 **references/genre-templates.md**。

## OP/ED 音訊與跨鏡音軌

- **BGM**：至少一條全域性軌；長影片(3 分鐘以上)按段落情緒拆多段，各配 audio_id 與時間區間。
- **OP 基調**：能量入場、節奏密度高、匹配快速蒙太奇(0.5–1 秒/鏡)。**ED 基調**：憂傷餘韻、節奏舒緩、配合褪色與顆粒加重。
- **VO 旁白**：有旁白鬚在 audio_layer description 寫入 narration_speaker_profile 並 layout_instruction 繫結到 shot 區間。**預設音色二選一**：抒情憂鬱基調（預設，慵懶柔美女聲/氣聲高/夢囈感）適合 MV 意識流詩意獨白；敘事紀錄基調（次選，溫厚滄桑男聲/平穩/淡憂鬱電臺圓潤）適合故事驅動回憶多段旁白。夢境劇專項：優先夢境飄渺女聲，男性/引路人用夢境低語男聲，夢境段與現實段用不同 profile 在同一 audio_layer 分段繫結。
- **旁白情緒標註（必填）**：每段旁白鬚附情緒交付指令（情緒狀態/節奏停頓/重音氣聲/整段弧線），否則 TTS 平鋪朗讀。夢境段額外標「懸浮感」「消散感」，禁強收尾停頓，聲音須在空氣中自然蒸發不落地。（聲線預設 11 個 + 旁白情緒示例見 references/audio-voice-presets.md。）
- **OP/ED 分鏡結構模板 3 個**（ED 15s / ED 30s / OP 30s 秒級時間軸）見 references/genre-templates.md。

## 媒體生成規格

- **角色參考圖**：每角色一張**橫向並排圖**——左側頭肩近景(鎖面部/膚色/髮際線)+ 右側全身(服裝/髮型/妝容/鞋履剪影)。多造型用 ImageToImage 以第一版為參考保身份。
- **shot 影片參考輸入 3 類**：① Element 影象(必選，畫面所有角色 element + 相關場景/道具 element)；② key_element_audio(有臺詞必選，跨鏡引同一角色同一條聲線參考)；③ 上一鏡 reference_video(可選，僅視覺連續性極強時)。**連續性判斷**：同一人物同一地點無時間跳躍+動作直接銜接才算"連續性極強"；場景切換/時間跳躍/情緒轉折不需要。
- **寫實剋制降調**：優先膠片質感自然寫實非視覺奇觀；Storyboard 若有誇張特效語言（"光斑充滿畫面""粒子爆發"）傳入提示詞前降調為剋製版（保留特效存在但降低強度）。
- **音訊生成**：BGM 提示詞避知名藝人真名；**VO 旁白提示詞=兩部分**：① 完整 narration_speaker_profile 音色描述 + ② 從 audio_layer 情緒標註提取的情緒交付指令，缺一模型退回平鋪朗讀腔。**key_element_audio 樣本規範 4 條**：8–12 秒覆蓋典型情緒區間；樣本同樣寫入完整 profile + 情緒標註；同一角色全片引同一條 resource_id(不滿意則重生成更新繫結，不混用不同版本)；繫結前建議播放驗證音色是否與預設一致，偏差明顯須重生成。

## 提示詞寫作（影象/影片）

- **語言**：中文互動時提示詞正文中文書寫；臺詞/旁白按 Spec 輸出語言保留原文。
- **美學關鍵詞核心庫 + 單鏡選取 5 規則**（本 skill 提示詞質量核心閘門）：色彩/光影/光學/膠片分級/風格標籤五類候選詞庫，**每類只選最相關 1 項寫入、不疊加堆砌**；無逆光光源不寫 Anamorphic 光斑；無煙霧灰塵霧氣介質不寫 volumetric light shafts / floating dust motes；普通人物近景不預設加光塵光暈金色輪廓光；場景光線平淡則如實描述實際光源、不強套金色逆光。完整詞庫見 **references/prompt-keyword-library.md**。
- **調色氛圍控制 5 條**（氛圍來自陰影密度與色彩分離的精確控制，每條不省略）：crushed blacks + lifted shadow floor（陰影上抬保細節不純黑截斷，陰影向冷綠/深煙棕偏移）；warm highlight roll-off（高光向香檳金/琥珀溫和過渡不過曝）；冷暖色彩分離（暖高光+冷陰影互補，中間調飽和度適度壓低）；中景大氣霧化（非前景煙霧特效，光塵須像實拍塵埃非數字粒子）；參考色感錨點 Kodak Vision3 500T（夜/室內）或 250D（日光/Golden Hour）。
- **特效剋制 6 條 + 禁止詞**：Anamorphic 光斑禁寫"爆發/橫掃/充滿畫面"；慢動作僅高潮；膠片劃痕跳幀"偶發"、不覆蓋 >20% 時長；體積光光塵須有現實光源支撐；避飽和度驟增驟降/瞬間過曝/顏色反轉數字感過渡；**禁止詞**：neon glow / electric color / oversaturated / HDR tone-mapped / digital color grade / VFX particle burst。
- **影象提示詞結構**：按序寫為自然語言段落、不輸出分段標題——【主體+動作+場景環境】→【光影色調，從核心庫取匹配片語】→【鏡頭語言：景別+運鏡+構圖手法】→【畫幅與畫質：2.39:1，電影感，4K】→【風格標籤，從核心庫取】。只寫可見內容不寫心理；人物寫實電影感（非二次元）；衣物薄透改用"輕紗薄霧禮裙"等非敏感表達；畫面內文字引號內寫可渲染完整字串。
- **影片提示詞結構**：參考圖佔位 <<<image_1>>> 等在開頭/主體處標角色身份；運動堆疊順序 鏡頭運動→主體動作與表演節拍→空間環境變化→音訊標註；**Seedance 包裝語法**：音樂(...)、音效<...>、臺詞{臺詞原文}（非專案語言時括號前註明語言）、片名/字幕【...】，{}內只寫臺詞不加描述；**固定負向詞**：有獨立 VO 軌則末尾加 no narration voice over，始終加 no music、no subtitles；慢動作寫"慢動作 120fps"/"slow motion"，不用壁鐘時間段切割。
- **角色造型參考圖專項**（8 類年代造型詞庫 Gatsby Girl/Daisy/舊好萊塢女星/爵士歌手/公路浪人男女/財閥男/權貴男 + 通用年代感疊加詞，含雙檢視結構要求）見 **references/prompt-keyword-library.md**。
- **題材專項關鍵詞補充 10 組**（含懸疑×公路整段英文詞庫）見 **references/prompt-keyword-library.md**。

## 合成（video_assembler）

- **畫幅**：時間線優先 2.39:1；平臺限制改 16:9 時上下加黑邊（letterbox）保電影感。
- **節奏曲線**：ED 整體舒緩、空鏡佔 ED 總時長 60% 以上、亮度飽和度漸降（金色→泛黃→趨近黑白）、末尾黑屏字幕段 ≥5 秒；OP 前 5 秒慢節奏鋪墊（黑白/重顆粒）後切快速蒙太奇（0.5–1 秒/鏡、節拍對齊 BGM 鼓點）末尾停格+標題卡；正片過渡優先疊化(dissolve)或直切、情感轉折可慢推疊化、避免花哨轉場。
- **音訊混合**：BGM 在 ED 段持續淡出末 3 秒降至 0、OP 段從無到有漸入；**VO 旁白優先於 BGM，BGM 在旁白說話段自動降至 -12dB**；鏡頭內生成的音效/臺詞與 VO 旁白錯峰避免重疊。
- **膠片顆粒層**：720p 資產合成後建議整體提升畫質（本環境無 MediaKit 超分，如實告知）；最終時間線疊統一輕膠片顆粒層保全片質感一致。

## 邊界

通用多鏡敘事 → cinematic-flow；其他導演美學 → auteur-style-director 分流。（auteur 家族：wes-anderson-style / zhang-yimou-style / ang-lee-style / nolan-style 等，為同族路由、非依賴。）
