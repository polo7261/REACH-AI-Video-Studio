# gatsby-artdeco-style

生成旧好莱坞金色调、Art Deco、Americana/Route 66 公路氛围的视频/图，或为历史/美食/运动/爱情/悬疑/MV/梦境/公路等任意题材套用此美学时用本 skill。**风格致敬，不宣称是任何具体版权作品/艺人。**

> 本环境适配：GPT Image/Seedance/MultiModalToVideo → `generate_image_v3`/`generate_video_v3`；text to narration/BGM → `generate_audio`；text_editor → `write_file_v2`；video_assembler → `composite_video`。提示词参数（2K/720p/画幅/胶片语汇）为工艺词面，全部保留。超分辨率后处理（Jimeng SR 4K/MediaKit 1080p）= 本环境无对应能力，删。

## 流程（里程碑暂停，不一次跑完）

1. **参数**：`write_file_v2` 锁 题材类型/时长/语言/画幅(**2.39:1 优先**或 16:9)/视觉风格("金色怀旧")。
2. **分镜**〔暂停〕：key elements / shot 列表 / audio layers；完成后扫描上下文，把用户已上传或已生成的素材绑定到对应槽位。
3. **视觉元素**〔暂停〕：为所有 key elements 出图（已有参考图直接绑）；**有台词角色在元素图完成后立即处理 key_element_audio**（用户提供声线参考直接绑，否则按声线风格生成短样本）——须在任何含台词 shot 视频生成前完成。
4. **逐镜视频**〔暂停〕：以 element 图为主参考；仅当与上一镜视觉连续性极强时才追加上一镜 reference_video。
5. **音频**（BGM + VO 旁白）〔暂停〕→ 6. `composite_video` 合成导出。

依赖：2→1；3→2；4→3；5→2；6→3,4,5。每个主阶段（Spec 锁定/分镜/元素图/镜头视频/音频）后暂停等确认。**用户上传素材优先绑定到对应槽位，避免重复生成。**

## 参考素材分析（6 项）

有上传素材时逐项分析：① **色彩对齐**：提取主色调，判断是否接近金色怀旧色盘，输出与目标色盘偏差供提示词校正。② **光影风格识别**：Golden Hour 逆光/体积光丁达尔/Anamorphic 水平光斑/浅景深是否具备，缺失则列入补足清单。③ **镜头语言识别**：画幅/景别/运镜类型作分镜基线。④ **人物/场景元素提取**：服装发型妆容、建筑陈设年代感、标志性道具 → 结构化描述直接用于 key_element。⑤ **时代感核查**：排除破坏 1920s–1950s 的现代元素（手机/LED/现代建筑/当代车型），存在则排除或推至虚化背景。⑥ **Americana 公路元素识别**：路面类型/地平线消失点占比/沿途路牌加油站广告牌 Diner/车型铬饰年代/光线入射角 → 用于公路类 element scene。

## 美学基调（全局锁定）

- **融合色盘**：香槟金 + 烟草棕 + 翡翠绿 + 象牙白 + 落日茜红。(Teal&Orange / Arri Alexa 调色非全局默认，仅特定题材按镜选用，不写入全局。)
- **画幅**：优先 **2.39:1 Anamorphic 宽画幅**，次选 16:9。
- **光影**：Golden Hour 逆光 / 体积光(可见光尘) / Anamorphic 水平椭圆光斑 / 室内烛光或琥珀钨丝点光。
- **胶片质感场景分级**：豪宅/宴会/舞台用细腻 **35mm** 颗粒(稳定曝光、黑位深但保服装纹理)；回忆/公路/汽旅/私人影像切 **16mm** 颗粒(轻微曝光漂移、偶发跳帧、竖划痕)。**同一场景类型内不混用两套颗粒。**
- **核心情绪（须通过可见结果表现，非抽象氛围词）**：宴会后空酒杯+散落亮片；人物独站宽阔房间边缘；恋人同框但视线不相交；隔着车窗/门框/水面/人群望向对方；远处灯光/人物始终无法真正靠近。

## 双重视觉语法（全局锁定）

两套视觉语言须在同一视频内交替，不得始终单一状态：
- **公开场合**（宴会/豪宅/舞台/上流社会空间）：稳定或缓慢移动镜头；Art Deco 对称构图；黑色与象牙白为底，香槟金仅作局部高光点缀（不铺满）；人物表情克制、动作收敛；35mm 细腻颗粒，不用手持抖动。
- **私人时刻**（回忆/公路/汽旅/独处）：轻微手持或偏离中心构图；褪色暖白与烟草棕主调；允许自然曝光漂移；16mm 颗粒加重，偶发跳帧与竖划痕保留私人影像感。
- **强制对照节奏**：每出现宴会/豪宅/珠宝/名车场景后，须紧接一个人物独处/空座位/喝剩酒杯/熄灭的灯/无人公路镜头——以视觉反差承载幻灭主题，不让华丽状态贯穿整段。

## Key Elements 设计规范

- **角色元素**：服化道细节(发型/妆容/服装材质)+ 情绪基调；多造型/年龄段逐一列出(造型 A/造型 B)。
- **声线绑定（key_element_audio）**：凡 shot 中有台词的角色必须为其定义 key_element_audio，绑一段声线参考音频跨镜保持音色，在描述中注明声线风格（可引用 references/audio-voice-presets.md 预设）。**样本 8–12 秒、须覆盖该角色典型情绪区间**（平静叙述+情绪起伏句+收尾低落），非单一情绪朗读——单一情绪样本会致 TTS 在不同情绪 shot 音色不稳。用户上传参考若情绪单一须注明以便补充多情绪覆盖。
- **场景元素**：建筑风格（Art Deco 豪宅/旧好莱坞片场/爵士夜总会/长岛海湾码头）或 Americana 公路意象（Route 66 公路尽头/沙漠高速逆光/1950s 加油站/褪色广告牌/路边 Diner/汽旅霓虹夜景）；注明主光源位置色温 + 标志性 Americana 细节（沥青热浪扭曲、路肩野草、地平线消失点、生锈招牌褪色霓虹、旋转吧台点唱机）；公路场景须注明拍摄视角——车内主观（挡风玻璃框架）还是车外低机位追拍（路面+轮胎）。
- **道具元素**（关键道具单独立项便于特写引用）：室内/派对类——香槟塔/老式留声机/褪色旧相片情书/水晶烛台/年代感白电话；公路 Americana 类——1950s 车头镀铬饰/方向盘手套箱老仪表盘/锈迹 Route 66 路牌/褪色广告牌/Diner 霓虹招牌/公路地图皮革手提箱/加油站风向标。
- **用户上传素材**：element 描述必须与图中可见内容一致，不矛盾。

## Shot 设计规范

- **时长节奏**：普通叙事镜头 4–8 秒；仅完整舞蹈/连续行走/多回合对话等动作不可打断时才延至 8–15 秒——不得仅因模型支持 15 秒就默认长镜头。**一 shot 只承担一个主要动作或关系变化**；含多景别/多主体/多动作结果须拆分。
- **每 shot 四要素**：① 场景（引用 element scene ID）；② 故事节拍（人物动作/表演细节/对话台词，台词用 {台词} 标注保留原文并附情绪节拍标注，见下）；③ 镜头语言（景别+机位角度低角度仰拍/平视/荷兰角+运镜锁定/慢推/摇臂上升/Dolly zoom/Rack focus）；④ 光影节拍（光源类型+色调阶段：高饱和金色逆光/烛光暖调/画面逐渐泛黄褪色）。

## 台词情绪节拍标注规范

shot 里凡出现 {台词}，文字之外须紧随情绪标注，否则下游模型平铺朗读失去层次。标注写在台词括号外侧：
- **情绪状态**：（声音发紧，强撑平静）（低语，气声渐弱）（语气骤然强硬，音量上扬）等。
- **节奏停顿**：台词内用「——」标中等停顿、「… …」标更长情绪间隙，句间换行代表自然断句。
- **重音与气声**：（此词咬重音）（整句气声出，几乎耳语）（尾音刻意拖长，带不甘）。
- **整句情绪弧线**：台词前标走向，如【从漫不经心 → 话到一半骤然哽住】。
- **与微表情节拍绑定**：台词标注须与同一故事节拍的微表情描述对应（如"嘴角轻扬但眼神落寞（轻描淡写，尾音下沉）{……}"）。
- **与旁白标注的区别**：旁白情绪标注作用于独立 audio_layer 生成提示词；台词情绪标注作用于 shot 内表演节拍，经 key_element_audio 声线参考+情绪指令共同驱动角色表演生成，两套体系并行不替代。

## 慢动作与特效克制

- **慢动作节拍**：仅情感高潮或叙事意义动作（汗水/蒸汽/回眸）标"120fps 慢动作"；普通走位/对话/过渡不标。余韵空镜标"12fps 轻微跳帧感"，不超过该镜头时长 20%。
- **特效克制**：所有视效服务叙事、不为装饰。Anamorphic 光斑仅强逆光直接入镜时自然出现，不主动设计为"横穿画面"独立事件；体积光须有现实光源依据（窗缝/门隙/舞台灯）；胶片划痕跳帧为点缀，不覆盖主要叙事段落。

## 题材分镜节奏偏好（10 模板）

**候选镜头库，非固定顺序**：从对应题材库选 3–5 种镜头，不得为符合模板而加与剧情无关的道具特写/停格/光斑/回眸；每镜须完成一项明确功能（建立空间/推动动作/改变关系/揭示信息/情绪反应），无功能的漂亮镜头不保留。完整 10 模板（历史/美食/运动/爱情/悬疑/MV/奇幻梦境含声音设计专项/悬疑×公路含色调覆盖+5 段节奏+4 禁止项/公路片）见 **references/genre-templates.md**。

## OP/ED 音频与跨镜音轨

- **BGM**：至少一条全局轨；长视频(3 分钟以上)按段落情绪拆多段，各配 audio_id 与时间区间。
- **OP 基调**：能量入场、节奏密度高、匹配快速蒙太奇(0.5–1 秒/镜)。**ED 基调**：忧伤余韵、节奏舒缓、配合褪色与颗粒加重。
- **VO 旁白**：有旁白须在 audio_layer description 写入 narration_speaker_profile 并 layout_instruction 绑定到 shot 区间。**默认音色二选一**：抒情忧郁基调（默认，慵懒柔美女声/气声高/梦呓感）适合 MV 意识流诗意独白；叙事纪录基调（次选，温厚沧桑男声/平稳/淡忧郁电台圆润）适合故事驱动回忆多段旁白。梦境剧专项：优先梦境飘渺女声，男性/引路人用梦境低语男声，梦境段与现实段用不同 profile 在同一 audio_layer 分段绑定。
- **旁白情绪标注（必填）**：每段旁白须附情绪交付指令（情绪状态/节奏停顿/重音气声/整段弧线），否则 TTS 平铺朗读。梦境段额外标「悬浮感」「消散感」，禁强收尾停顿，声音须在空气中自然蒸发不落地。（声线预设 11 个 + 旁白情绪示例见 references/audio-voice-presets.md。）
- **OP/ED 分镜结构模板 3 个**（ED 15s / ED 30s / OP 30s 秒级时间轴）见 references/genre-templates.md。

## 媒体生成规格

- **角色参考图**：每角色一张**横向并排图**——左侧头肩近景(锁面部/肤色/发际线)+ 右侧全身(服装/发型/妆容/鞋履剪影)。多造型用 ImageToImage 以第一版为参考保身份。
- **shot 视频参考输入 3 类**：① Element 图像(必选，画面所有角色 element + 相关场景/道具 element)；② key_element_audio(有台词必选，跨镜引同一角色同一条声线参考)；③ 上一镜 reference_video(可选，仅视觉连续性极强时)。**连续性判断**：同一人物同一地点无时间跳跃+动作直接衔接才算"连续性极强"；场景切换/时间跳跃/情绪转折不需要。
- **写实克制降调**：优先胶片质感自然写实非视觉奇观；Storyboard 若有夸张特效语言（"光斑充满画面""粒子爆发"）传入提示词前降调为克制版（保留特效存在但降低强度）。
- **音频生成**：BGM 提示词避知名艺人真名；**VO 旁白提示词=两部分**：① 完整 narration_speaker_profile 音色描述 + ② 从 audio_layer 情绪标注提取的情绪交付指令，缺一模型退回平铺朗读腔。**key_element_audio 样本规范 4 条**：8–12 秒覆盖典型情绪区间；样本同样写入完整 profile + 情绪标注；同一角色全片引同一条 resource_id(不满意则重生成更新绑定，不混用不同版本)；绑定前建议播放验证音色是否与预设一致，偏差明显须重生成。

## 提示词写作（图像/视频）

- **语言**：中文交互时提示词正文中文书写；台词/旁白按 Spec 输出语言保留原文。
- **美学关键词核心库 + 单镜选取 5 规则**（本 skill 提示词质量核心闸门）：色彩/光影/光学/胶片分级/风格标签五类候选词库，**每类只选最相关 1 项写入、不叠加堆砌**；无逆光光源不写 Anamorphic 光斑；无烟雾灰尘雾气介质不写 volumetric light shafts / floating dust motes；普通人物近景不默认加光尘光晕金色轮廓光；场景光线平淡则如实描述实际光源、不强套金色逆光。完整词库见 **references/prompt-keyword-library.md**。
- **调色氛围控制 5 条**（氛围来自阴影密度与色彩分离的精确控制，每条不省略）：crushed blacks + lifted shadow floor（阴影上抬保细节不纯黑截断，阴影向冷绿/深烟棕偏移）；warm highlight roll-off（高光向香槟金/琥珀温和过渡不过曝）；冷暖色彩分离（暖高光+冷阴影互补，中间调饱和度适度压低）；中景大气雾化（非前景烟雾特效，光尘须像实拍尘埃非数字粒子）；参考色感锚点 Kodak Vision3 500T（夜/室内）或 250D（日光/Golden Hour）。
- **特效克制 6 条 + 禁止词**：Anamorphic 光斑禁写"爆发/横扫/充满画面"；慢动作仅高潮；胶片划痕跳帧"偶发"、不覆盖 >20% 时长；体积光光尘须有现实光源支撑；避饱和度骤增骤降/瞬间过曝/颜色反转数字感过渡；**禁止词**：neon glow / electric color / oversaturated / HDR tone-mapped / digital color grade / VFX particle burst。
- **图像提示词结构**：按序写为自然语言段落、不输出分段标题——【主体+动作+场景环境】→【光影色调，从核心库取匹配词组】→【镜头语言：景别+运镜+构图手法】→【画幅与画质：2.39:1，电影感，4K】→【风格标签，从核心库取】。只写可见内容不写心理；人物写实电影感（非二次元）；衣物薄透改用"轻纱薄雾礼裙"等非敏感表达；画面内文字引号内写可渲染完整字串。
- **视频提示词结构**：参考图占位 <<<image_1>>> 等在开头/主体处标角色身份；运动堆栈顺序 镜头运动→主体动作与表演节拍→空间环境变化→音频标注；**Seedance 包装语法**：音乐(...)、音效<...>、台词{台词原文}（非项目语言时括号前注明语言）、片名/字幕【...】，{}内只写台词不加描述；**固定负向词**：有独立 VO 轨则末尾加 no narration voice over，始终加 no music、no subtitles；慢动作写"慢动作 120fps"/"slow motion"，不用壁钟时间段切割。
- **角色造型参考图专项**（8 类年代造型词库 Gatsby Girl/Daisy/旧好莱坞女星/爵士歌手/公路浪人男女/财阀男/权贵男 + 通用年代感叠加词，含双视图结构要求）见 **references/prompt-keyword-library.md**。
- **题材专项关键词补充 10 组**（含悬疑×公路整段英文词库）见 **references/prompt-keyword-library.md**。

## 合成（video_assembler）

- **画幅**：时间线优先 2.39:1；平台限制改 16:9 时上下加黑边（letterbox）保电影感。
- **节奏曲线**：ED 整体舒缓、空镜占 ED 总时长 60% 以上、亮度饱和度渐降（金色→泛黄→趋近黑白）、末尾黑屏字幕段 ≥5 秒；OP 前 5 秒慢节奏铺垫（黑白/重颗粒）后切快速蒙太奇（0.5–1 秒/镜、节拍对齐 BGM 鼓点）末尾停格+标题卡；正片过渡优先叠化(dissolve)或直切、情感转折可慢推叠化、避免花哨转场。
- **音频混合**：BGM 在 ED 段持续淡出末 3 秒降至 0、OP 段从无到有渐入；**VO 旁白优先于 BGM，BGM 在旁白说话段自动降至 -12dB**；镜头内生成的音效/台词与 VO 旁白错峰避免重叠。
- **胶片颗粒层**：720p 资产合成后建议整体提升画质（本环境无 MediaKit 超分，如实告知）；最终时间线叠统一轻胶片颗粒层保全片质感一致。
