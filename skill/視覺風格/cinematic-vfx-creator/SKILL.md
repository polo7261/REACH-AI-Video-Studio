# 角色戰鬥場景特效影片生成

## 核心方法論

### 1. 敘事驅動的分鏡架構

分鏡是**單個影片內的時間敘事結構**，不是多個獨立影片檔案的集合。每個分鏡是服務於整體故事弧的時間段：

- **SB-01 建立鏡頭**：0-25% 時長 → 場景/氛圍建立
- **SB-02 衝突蓄力**：25-50% 時長 → 角色亮相，能量積累
- **SB-03 高潮交鋒**：50-75% 時長 → 核心戰鬥序列，特效密集
- **SB-04 終結畫面**：75-100% 時長 → 終極招式，環境破壞，英雄定格

每個分鏡必須：

1. **推進敘事動能**（不得靜態重複）
2. **遞進視覺強度**（特效複雜度逐鏡提升）
3. **保持空間/角色連續性**（鏡頭角度與位置符合電影邏輯）

---

### 2. 元素色彩語義體系

技能特效必須繫結明確的色彩-屬性對映，不同元素型別遵循固定的視覺語言：

元素屬性核心色彩情緒關鍵詞粒子形態火系烈紅/橙金/熾白熱烈、爆裂、威猛火焰團、爆炸光暈、熱浪扭曲冰系冰藍/青白/霜白冷冽、凝結、銳利冰晶折射、霜花擴散、寒霧瀰漫雷系黑紫/深藍/白電迅猛、暴烈、撕裂樹根狀電弧、靜電粒子、電光閃鏈暗影系紫黑/暗紅/血色詭異、吞噬、壓迫黑霧翻湧、血色煙塵、暗影觸鬚神聖系金白/淡青/聖光耀眼、神聖、淨化光羽飄散、聖光柱、體積光擴散自然系翠綠/木棕/金黃生機、蔓延、纏繞藤蔓纏繞、葉片旋舞、花粉光點

**應用規則**：

- 技能色彩必須與角色服裝/武器形成**高對比**或**高融合**二選一
- 同一技能最多使用 2 種主色調，避免色彩混亂
- 場景環境色調應反襯技能色彩（冰系技能搭配暗調場景，火系技能搭配冷灰場景）
- 色彩一旦確定全程保持一致，不得中途變更

---

### 3. 角色戰鬥型別分析

收到角色輸入後，執行**戰鬥角色分類**：

- **敏捷型**：鏈式武器、雜技動作 → 重點：運動軌跡、殘影、速度線
- **力量型**：重甲、震地打擊 → 重點：衝擊坑、衝擊波漣漪、碎石飛濺
- **法術型**：能量構造、召喚儀式 → 重點：粒子密度、發光強度、體積光

**跨型別互動規則**：

- 敏捷 vs 力量 → 速度線與衝擊波碰撞
- 法術 vs 敏捷 → 法術彈幕 vs 閃避殘影
- 力量 vs 法術 → 物理打擊擊碎能量屏障

---

### 4. 四層提示詞構建體系

每個戰鬥影片提示詞必須包含四個層級，缺一不可：

**① 風格質量宣告層**（10-15% 篇幅）\
定義渲染標準、整體風格、色調情緒基調。\
3D國漫玄幻風格 + 虛幻引擎5極致畫質 + \[色調:暗黑/明亮/冷峻\] + 電影級\[質感詞:寫實/史詩/夢幻\] 必含：渲染引擎名、色調定性詞、質感定性詞、對比度描述 示例："次世代國漫3D，虛幻引擎5渲染，暗黑史詩風，冷調高階質感，全域性光照+動態模糊+景深，60fps流暢度"

**② 運鏡系統層**（15-20% 篇幅）\
定義鏡頭運動邏輯、切換節奏、視角變化規律。\
分鏡節奏公式：\[蓄力段(穩定慢推)\] → \[爆發段(快速切換)\] → \[餘韻段(緩慢拉遠)\] 運鏡語法：推(push in)/拉(pull out)/跟(follow)/環繞(orbit)/仰拍(low angle)/俯拍(high angle) 切換強度：緩慢融合(淡入淡出) vs 快速跳切(硬切) vs 爆點閃白切換 示例："開場極近特寫慢推至全身，蓄力段低角度跟拍，爆發瞬間快速跳切至正面碰撞近景，終結段俯拍緩慢拉遠定格"

**③ 核心畫面層**（50-60% 篇幅，最關鍵）\
採用**微進式時序敘事**——將動作拆解為 0.5-1 秒粒度的連續畫面描述。

核心原則：

- **動詞密度法則**：每個動作必須用強動詞（轟然/迸發/炸裂/席捲/衝破），拒絕弱動詞（出現/顯示/發生）
- **感官疊加法則**：視覺+聽覺+動勢同時描述（"震耳咆哮+衝擊波轟然炸裂+地面龜裂擴散"）
- **尺度對比法則**：透過大小對比製造壓迫感（"渺小人影 vs 巨型能量球"）
- **VFX繫結法則**：特效必須附著於動作（"獠牙**迸發**紫色火焰" 而非 "紫色火焰出現"）

時序拆解模板：\
\[Initial state\] → \[Trigger action\] → \[Environmental response\] → \[Effect cascade\] → \[Climax beat\] → \[Resolution pose\]

示例（0.5秒粒度）： 0.0-0.5s: 角色擺出施法姿勢，雙手結印 0.5-1.0s: 掌心開始發光，眼瞳迸射元素光芒 1.0-2.0s: 地面符文陣列依次啟用（螺旋擴散） 2.0-3.0s: 能量柱從符文中心轟然升起 3.0-4.0s: 技能形態在能量柱內凝聚成形 4.0-5.0s: 技能爆發衝出，能量柱炸裂成粒子

**④ 技術細節強化層**（10-15% 篇幅）\
用材質、粒子、物理反饋細節拉滿真實感。\
粒子細節：冰晶折射光線/火花四濺軌跡/煙塵翻湧體積感/靜電遊絲纏繞 材質細節：冰面反光鏡面質感/金屬劃痕鏽跡/布料褶皺飄動/皮膚毛孔紋理 物理反饋：地面龜裂/碎石飛濺/熱浪扭曲空氣/衝擊波漣漪擴散 氛圍壓迫感：空氣凝結感/塵埃懸浮體積光/低頻震動嗡鳴感

---

### 5. 專業動畫衝擊幀技法（視覺化描述體系）

傳統數值型指令（如"亮度246/255"）AI 模型無法精確執行，必須轉換為**畫面內發生的視覺化動作描述**。

**閃白幀（白屏爆閃）—— 場景爆點轉場**用途：能量爆發瞬間 / 衝鋒轉交鋒 / 終極大招釋放\
基礎版："畫面爆閃至純白，如雷擊般刺目，瞬間切回戰鬥場景" 強化版："全屏白色強光瞬間吞沒畫面，衝擊波從中心向外高速環狀擴散，帶起漫天飛塵與碎石，強光消退後場景驟然切入" 震屏版："爆炸瞬間畫面爆白，攝像機劇烈震動，震幅先大後小，持續0.3秒後緩慢恢復穩定"

**黑白幀（去色幀）—— 蓄力與餘韻**用途：技能蓄力壓迫感 / 斬殺定格餘韻 / 暴風雨前的寧靜\
去色蓄力："畫面色彩驟然褪盡如墨染，僅剩明暗輪廓，元素電弧在黑白畫面中格外銳利" 斬殺定格："斬擊瞬間畫面凝固為黑白慢鏡，碎石與塵埃懸浮空中如時間靜止，僅角色眼瞳殘留一點幽光" 蓄力漸變："畫面色彩如潮水般緩緩退去，世界逐漸褪色為冷灰黑白，暴風雨前的死寂壓迫感瀰漫"

**衝擊幀（畫面劇變幀）—— 撞擊與能量爆發**用途：拳拳到肉的碰撞 / 能量球爆炸 / 武器交鋒\
單次撞擊："兩力相撞瞬間爆出耀眼白光，衝擊波環狀向外炸裂擴散，地面龜裂，飛塵橫飛" 能量二次爆發："能量在碰撞點積壓到極限，轟然二次爆發，畫面邊緣出現強烈鏡頭畸變，火花如雨四濺" 高頻連打："每一擊落下畫面猛烈一震，閃光與爆裂聲此起彼伏，節奏如戰鼓密集擂響"

**震屏效果分級**輕震：攝像機輕微顫抖，如遠處爆炸的餘震，持續0.2秒後自然恢復 中震：爆炸瞬間攝像機猛烈震動，震幅先大後小，持續0.3秒後緩慢穩定 重震：衝擊波正面命中，攝像機劇烈抖動如地震，畫面邊緣出現運動模糊，0.5秒內逐步恢復 極震：終極大招爆發，攝像機震動到極限，畫面短暫失焦+邊緣畸變，震動持續0.8秒後如餘震般緩緩平息

**完整衝擊節奏模板（可直接複用**）蓄力段：畫面色彩如潮水緩緩退去，褪為冷灰黑白，世界陷入死寂壓迫； 爆發點：全屏白色強光瞬間吞沒畫面，衝擊波從中心向外高速環狀擴散，帶起漫天飛塵與碎石，攝像機劇烈震動先大後小持續0.3秒； 衝擊連打：每一擊落下畫面猛烈一震，爆出耀眼白光與衝擊波漣漪，能量在碰撞點二次爆發，鏡頭畸變+火花四濺，節奏如戰鼓密集； 餘韻定格：斬擊後畫面凝固為黑白慢鏡，碎石懸浮如時間靜止，色彩如潮水緩緩回湧，殘留粒子在體積光中飄散消逝。

## 工作流程

### 第一步：準備階段（全部完成才可進入第二步）

**需求挖掘前置互動機制（強制，準備階段第一步）：**

使用者啟用 Skill 後，第一件事不是直接收集引數，而是先透過專業提問\
挖掘使用者的真實創作意圖。使用者往往無法準確描述特效風格，需要 Agent\
用專業知識引導使用者表達。

觸發條件：

- 使用者描述模糊（如"兩個女的打鬥，很華麗"）
- 使用者只說了角色/場景，沒有說特效風格
- 使用者沒有明確的技能/招式概念
- 使用者表達中缺少風格、元素、節奏等關鍵資訊

禁止行為：

- 收到模糊需求後直接套用預設模板生成 ❌
- 不經引導直接進入引數收集清單 ❌
- 用千篇一律的"玄幻3D史詩風"填充所有需求 ❌

正確執行流程：

STEP 1 — 風格定向提問（單次 ask_human，多個維度）

根據使用者需求，從以下維度中選擇 3-4 個最相關的提問：

【畫風維度】

- 偏寫實（真人質感/超寫實建模）還是偏二次元（國漫/日漫/3D卡通）？
- 色調偏暗黑壓抑還是明亮華麗？

【特效風格維度】

- 有沒有喜歡的遊戲/動漫技能參考？\
  （如：鬼滅之刃的呼吸技、火影的查克拉術、原神的元素爆發、\
  崩壞的終結技、王者榮耀的大招特效等）
- 偏向哪種元素屬性？\
  （火/冰/雷/暗影/神聖/自然/陰陽/機械/血系等）
- 特效風格偏「寫意飄逸」（如仙俠飄帶劍氣）還是「硬核爆炸」\
  （如衝擊波震地炸裂）？

【動作風格維度】

- 偏向哪種戰鬥節奏？\
  （快速凌厲連擊 / 蓄力一擊必殺 / 優雅流動舞步式 / 野蠻\*\*壓制）
- 角色戰鬥風格偏哪種？\
  （劍客/刺客/法師/武者/召喚師/槍手）

【敘事節奏維度】

- 想要有完整故事感（建立→蓄力→爆發→收束）\
  還是直接上高潮特效展示？
- 有沒有想復刻的具體場景或鏡頭感覺？\
  （如某部電影/動漫的某一幕）

STEP 2 — 整合使用者回答，生成個性化創作方案

根據使用者的回答，Agent 需要：

1. 用專業語言將使用者描述轉化為具體的視覺方案
2. 主動提出 1-2 個創意建議（基於使用者偏好延伸）
3. 向使用者說明將要呈現的效果，例如：

示例回覆：\
"根據您的偏好，我為您設計了以下方案：

- 風格：國漫3D寫實，暗金色調
- 技能特效：參考原神雷元素爆發風格，紫金雷電+衝擊波漣漪
- 戰鬥節奏：快速凌厲連擊，每擊帶殘影，終結一擊蓄力爆發
- 敘事結構：建立對峙→連擊纏鬥→終結大招→英雄定格\
  您覺得這個方向如何？有需要調整的地方嗎？"

STEP 3 — 使用者確認創作方向後，進入準備階段引數收集

使用者對創作方向滿意後，才進入6項引數收集清單。

注意事項：

- 每次提問聚焦 3-4 個維度，不要一次丟擲所有問題
- 用具體的參考案例引導（遊戲技能名/動漫招式名），\
  而非抽象的"您想要什麼風格"
- Agent 要主動給出選項和建議，降低使用者的表達門檻
- 根據使用者每一條回答實時調整後續提問方向，\
  而非機械走完所有問題
- 最終生成的指令碼必須體現使用者的個性化偏好，\
  禁止套用通用模板

- 解析度確認後直接進入生成 ❌

🔴 角色資產處理規則（強制）

IF 使用者提供了角色參考圖： → 直接使用參考圖作為角色錨點，進行角色分析，繼續收集其餘4項

IF 使用者沒有參考圖（包括"沒有參考圖"/"由AI自由設計"等回答）： → 不得跳過角色資產環節 → 必須先透過 generate_image 生成角色三檢視（正面/側面/背面） → 將三檢視展示給使用者，透過 ask_human 確認外觀是否滿意 → 使用者明確確認後，以確認圖作為角色錨點 → 禁止僅憑文字描述直接進入影片生成

角色分析維度（收到/確認角色圖後執行）

- 服裝配色與材質（布料/金屬/皮革）
- 武器型別與持握方式（劍/槍/鏈/拳套）
- 氣質定位（冷峻/妖嬈/威猛/神秘）
- 戰鬥風格歸類（敏捷型 / 力量型 / 法術型）
- 視覺標誌性元素（如"紅色鐵鏈" / "黃色重甲"）

場景設計決策樹

IF 使用者提供場景描述： → 提取：地點型別、時間、天氣、環境光 → 識別：可互動元素（可破壞道具、動態環境）

IF 使用者委託AI設計： → 根據角色衝突型別選擇： 法術決鬥 → 古代遺蹟、月夜、能量裂縫 武術對戰 → 庭院、雨夜、石柱 怪物戰鬥 → 荒原、暴風雨、崩塌結構 → 設計原則：環境必須參與動作（不只是背景）

技能設計清單

- \[ \] 元素屬性確定（從色彩語義體系中選擇）

- \[ \] 技能名稱與核心動作（如"天罡烈虎拳"=一拳衝擊）

- \[ \] 特效優先順序排序（如火系=衝擊波&gt;火焰團&gt;熱浪扭曲）

- \[ \] 環境反饋設計（地面龜裂/冰封擴散/風刃切痕）

- **角色參考圖質量評估規則（強制）：**

  無論使用者提供參考圖還是 AI 生成三檢視，都必須執行以下質量評估：

  評估維度：

  - \[ \] 圖片清晰度：是否存在模糊、壓縮失真、截圖噪點
  - \[ \] 細節完整度：服裝紋理、武器細節、面部特徵是否清晰可辨
  - \[ \] 視角完整度：是否包含正面/側面/背面三個視角
  - \[ \] 尺寸充足度：人物是否足夠大，細節是否可見

  IF 參考圖質量不足（模糊/截圖/細節缺失/視角不全）：\
  → 不得直接使用低質量圖作為唯一錨點\

### 慢鏡頭黃金時機

以下3個時機插入0.5倍速慢鏡頭可顯著提升視覺衝擊力：

1. 技能爆發瞬間（能量球離手的0.3秒）

"\[關鍵動作\]瞬間時間流速驟降，畫面進入0.5倍速慢鏡頭，\[細節放大描述\]，慢鏡結束後時間流速恢復正常"

### 終結定格英雄構圖

影片最後1-2秒必須交付**英雄構圖**：

- 角色處於主導位置（高處、居中、逆光）

# 動作特效影片生成

## 核心方法論

### 四層提示詞架構

從使用者實際創作中提煉的結構化提示詞體系,每層各司其職:

層級作用關鍵要素**① 風格質量宣告層**定基調、渲染標準、色調情緒虛幻引擎5、暗黑電影級、高對比度光影、3D國漫玄幻**② 運鏡系統層**定鏡頭運動、切換節奏、沉浸感動態跟拍、特寫與大場景無縫切換、低角度仰拍**③ 核心畫面層**時間微進式敘事,0.5秒粒度拆解動作轟然升起→符文綻放→石門開啟→衝出**④ 技術細節強化層**粒子/材質/模糊/氛圍壓迫感收尾模型精度拉滿、動態模糊自然、體積光細膩

**核心原則**: 用「畫面裡發生了什麼」替代「第X幀亮度值是多少」

### 法術系色彩語義體系

根據技能屬性鎖定主色調,保證視覺統一性:

顏色對應屬性情緒關鍵詞粒子特徵紅/橙火焰/怒氣熱烈、爆裂烈焰飛濺、氣霧翻湧藍/青冰霜/控制冷冽、凝結冰晶折射、霜花凝結紫/黑雷電/暗影詭異、吞噬電弧跳躍、黑霧瀰漫金/白神聖/能量耀眼、神聖光柱沖天、聖光灑落綠/翠自然/生命生機、蔓延藤蔓纏繞、葉片飛散

### 文學表達核心技法

- **動詞密度**: 衝破、轟然、磅礴、掀起、咆哮 → 拒絕「出現、顯示、發生」
- **感官疊加**: 視覺+聽覺+動勢同時描述(「震耳咆哮+磅礴滑落+轟然升起」)
- **尺度對比**: 角色渺小 vs 巨型生物/建築 → 壓迫感來源
- **特效繫結**: VFX必須附著於動作(「獠牙**進發**紫色火焰」而非「紫色火焰出現」)
- **材質細節**: 佈滿青苔、猙獰鬼首紋路、通體縈繞紫光 → 真實感來源

### 4. 衝擊幀視覺化描述 (核心技法)

**原則**: 用畫面動作替代幀數值

閃白幀視覺化寫法

效果意圖視覺化描述純白爆閃畫面爆閃至純白如雷擊般刺目,瞬間切回戰鬥場景強化閃白全屏白色強光瞬間吞沒畫面,衝擊波從中心向外高速環狀擴散,帶起漫天飛塵與碎石,強光消退後場景驟然切入震屏閃白爆炸瞬間畫面爆白,攝像機劇烈震動,震幅先大後小持續0.3秒後緩慢恢復穩定

黑白幀視覺化寫法

效果意圖視覺化描述去色蓄力畫面色彩驟然褪盡如墨染,僅剩明暗輪廓,雷電白色電弧在黑白畫面中格外銳利斬殺定格斬擊瞬間畫面凝固為黑白慢鏡,碎石與塵埃懸浮空中如時間靜止,僅角色眼瞳殘留一點幽光蓄力漸變畫面色彩如潮水般緩緩退去,世界逐漸褪色為冷灰黑白,暴風雨前的死寂壓迫感瀰漫

衝擊幀連打視覺化寫法

效果意圖視覺化描述單次撞擊兩力相撞瞬間爆出耀眼白光,衝擊波環狀向外炸裂擴散,地面龜裂飛塵橫飛二次爆發能量在碰撞點積壓到極限轟然二次爆發,畫面邊緣出現強烈鏡頭畸變,火花如雨四濺高頻連打每一擊落下畫面猛烈一震,閃光與爆裂聲此起彼伏,節奏如戰鼓密集擂響拳拳到肉

震屏四級體系

```
【輕震】攝像機輕微顫抖如遠處爆炸的餘震,持續0.2秒後自然恢復

【中震】爆炸瞬間攝像機猛烈震動,震幅先大後小,持續0.3秒後緩慢穩定

【重震】衝擊波正面命中,攝像機劇烈抖動如地震,
       畫面邊緣出現運動模糊,震動幅度從最大值快速衰減,
       0.5秒內逐步恢復穩定

【極震】終極大招爆發,攝像機震動到極限,
       畫面短暫失焦+邊緣畸變,塵土碎石鋪天蓋地,
       震動持續0.8秒後如餘震般緩緩平息
```

### 5. 體術連擊專屬技法

## 關鍵約束與標準

### 必須遵守的流程規則

1. **解析度確認**: 生成前必須詢問使用者解析度需求,這是阻塞性要求
2. **分鏡非節點**: 分鏡是同一條影片內的時間段劃分,不是多個獨立影片節點拼接
3. **一次生成**: 規劃好所有分鏡後,用一次`generate_video`生成包含完整敘事的影片

### 色彩一致性規則

- 火系全程鎖定橙金/焦紅/熾白,不出現藍綠色調
- 冰系全程鎖定冰藍/青白/霜白,不出現暖色調
- 雷系全程鎖定黑紫/紫白/電藍,不出現黃色閃電
- 體術衝擊波與角色服裝色調協調(橙黃戰袍配橙金衝擊波)

### 衝擊幀精準度規則

**AI影片模型侷限**: 目前對精確到0.1秒的幀級特效指令理解能力有限

**彌補方案**:

- 提示詞采用視覺化動作描述(「全屏白光吞沒畫面」)而非數值(「亮度246/255」)
- 關鍵衝擊幀未觸發時,透過後期編輯補強
- 震屏效果用持續時間描述(「0.3秒」)而非幀數(「18幀@60fps」)

### 慢鏡頭黃金時機

三個必插0.5倍速慢鏡頭的時機:

1. **能量球離手瞬間** - 強化技能釋放的儀式感
2. **武器交鋒瞬間** - 放大沖擊碰撞的力量感
3. **斬殺定格瞬間** - 凸顯終結一擊的決斷感

### 動詞質量標準

**禁用動詞**: 出現、顯示、發生、產生、形成

**必用動詞類別**:

- 爆發類: 轟然、迸發、炸裂、噴湧、爆開
- 運動類: 猛然、驟然、瞬間、暴起、橫掃
- 擴散類: 席捲、蔓延、擴散、湧動、翻湧
- 聲效類: 咆哮、震盪、呼嘯、轟鳴、撕裂

## 高階技法

### 多屬性融合技能

當技能涉及兩種屬性融合時(如雷火/冰風),採用「主色+點綴色」策略:

```
雷火融合示例:
主色調: 黑紫雷電(佔70%畫面)
點綴色: 焦紅火焰(佔30%,集中在碰撞點)
融合點: 紫紅色能量漩渦(兩者交匯處)
```

### 環境反饋強化

技能爆發必須有環境響應,強化真實感:

- 火系: 地面焦黑、空氣扭曲、熱浪升騰
- 冰系: 地面結冰、水汽凝結、霜花蔓延
- 雷系: 地面龜裂、靜電粒子、金屬共振
- 體術: 地面塌陷、氣浪橫飛、碎石飛濺

### 分鏡轉場技法

**硬切轉場**(用於爆發點): 閃白幀→直接切入下一鏡頭

**軟切轉場**(用於蓄力段): 鏡頭推進→焦點轉移→自然過渡

**衝擊轉場**(用於連擊): 每一擊震屏→畫面快速跳切→製造密集節奏感
