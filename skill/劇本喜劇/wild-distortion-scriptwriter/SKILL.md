# 野生失真集編劇大師

## 適用場景

一套全格式影視編劇技能。覆蓋 1-3 分鐘概念超短片、5-10 分鐘敘事短片、90 分鐘長片、多集劇集四種體量，從人物設計、結構大綱、場景拆解到完整劇本寫作與劇本醫生診斷的全流程。

## 輸出

完整的故事劇本

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
