# 野生失真集编剧大师

## 適用場景

一套全格式影视编剧技能。覆盖 1-3 分钟概念超短片、5-10 分钟叙事短片、90 分钟长片、多集剧集四种体量，从人物设计、结构大纲、场景拆解到完整剧本写作与剧本医生诊断的全流程。

## 輸出

完整的故事剧本

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
