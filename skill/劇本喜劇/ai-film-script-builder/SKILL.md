# 第二十七階段｜生產單元數量與總時長數學硬校驗

最終完整劇本輸出之前，\
必須進行一次嚴格的數學檢查。

【規則1｜生產單元數量必須能夠支撐目標時長】

由於每個AI影片劇情生產單元原則上為10～15秒，

必須先根據目標總時長判斷所需生產單元數量。

例如：

目標60秒：\
通常至少需要4～6個生產單元。

目標120秒：\
通常至少需要8～12個生產單元。

目標180秒：\
理論上至少需要12個生產單元，\
實際建議約13～15個生產單元。

如果目標為180秒，\
卻只有10個生產單元，

即使每段全部達到15秒，\
總時長最多也只有150秒。

此時禁止聲稱已經達到180秒。

必須繼續增加有效劇情生產單元。

━━━━━━━━━━━━━━━━━━

【規則2｜總時長必須逐項真實相加】

最終總時長只能來自實際存在的生產單元預計時長之和。

例如：

生產單元01：13秒\
生產單元02：14秒\
生產單元03：12秒

則總計必須真實計算為：

13 + 14 + 12 = 39秒

禁止出現：

額外增加不存在的秒數\
使用沒有對應生產單元的補充數字\
為了接近目標時長而修改最終合計\
虛構“+XX秒”

例如實際10個單元相加為130秒，

禁止寫成：

130 + 46 = 176秒

除非這額外46秒已經真實存在於新的劇情生產單元中。

━━━━━━━━━━━━━━━━━━

【規則3｜先補劇情，再重新計算】

如果實際總時長低於目標合理區間，

必須：

增加新的有效劇情生產單元\
→ 按故事順序重新排列\
→ 重新連續編號\
→ 再逐項計算總時長

不能只修改最後的總時長數字。

━━━━━━━━━━━━━━━━━━

2. 每個單元10～15秒
3. 每個單元實際存在
4. 所有時長逐項相加正確
5. 總時長進入使用者目標合理範圍

任意一項不滿足，\
都必須繼續內部修正，\
不得輸出最終版本。
