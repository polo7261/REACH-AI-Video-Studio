# 劇本邏輯和演繹最佳化SKILL

## 適用場景

當你有完整的劇本，但劇本有隱形的BUG。你不想手工檢測修復時或你無法發現潛在問題時。使用此技能幫你在拆解分鏡之前就規避掉絕大數問題，並且注入表演最佳化，讓你人物演繹的活靈活現。

## 輸出

可以得到最佳化後的完整劇本。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
