# 剧本逻辑和演绎优化SKILL

## 適用場景

当你有完整的剧本，但剧本有隐形的BUG。你不想手工检测修复时或你无法发现潜在问题时。使用此技能帮你在拆解分镜之前就规避掉绝大数问题，并且注入表演优化，让你人物演绎的活灵活现。

## 輸出

可以得到优化后的完整剧本。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
