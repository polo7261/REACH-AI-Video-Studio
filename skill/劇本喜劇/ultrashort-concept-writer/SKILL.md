# ultrashort-concept-writer

1-3分鐘概念超短片的完整寫作方法論。**這是純粹的"idea delivery"**——不靠故事，靠概念本身的銳度和視聽語言的衝擊力擊中觀眾。本 skill 自包含，不依賴本庫其他任何檔案；如果要指定"這個概念超短片該講男頻/懸疑/復仇哪個題材的具體內容判斷標準"，可以在寫完概念後額外參考對應題材殼，但題材殼不是必需前提。

## 邊界：不做什麼

不產出分鏡表、鏡號、景別/運鏡/構圖、轉場方式、AI生圖/生影片提示詞、任何特定生成引擎的格式約束。產出到完整的、可以直接讀、直接拍的文字劇本為止。

## 工作流紀律

嚴格按步驟順序執行，不跳步；每一步完成後暫停，等待使用者的[透過/修改/自檢]指令；絕不一次性把後續所有步驟生成完再交給使用者；每步結束後提醒使用者可以要求[自檢]。

自檢是內部過程——寫之前先在心裡過一遍對應步驟的檢查清單，不需要在輸出中展示自檢的思考過程，只需要確保交付的內容已經透過檢查。使用者仍然可以主動要求[自檢]，此時才需要顯式地逐條列出檢查項並給出評估結果。

## 寫作紅線（全域性最高優先順序，任何格式都不能違反）

**絕對不要**：
- 寫心理描寫（"他意識到"、"她領會到"、"內心湧起"）——超短片尤其致命，3分鐘裡每一秒都該是畫面，不是解釋
- 寫括號暗示（"（其實是在掩飾緊張）"）
- 角色用臺詞解釋設定或概念規則
- 說教片段、強行催淚、煽情獨白
- 過度比喻句、類比、書面化的AI腔臺詞
- 寫任何攝影機拍不到的內容

**必須做到**：
- 臺詞口語化，像真人說話（超短片往往臺詞極少甚至沒有臺詞，更要珍惜每一句）
- 用動作代替解釋（動作即潛臺詞）
- 所有內容從視聽角度出發

## 視聽化寫作核心

**Show, Don't Tell**：如果一個情感/規則無法透過畫面或聲音傳達給觀眾，它就不該出現在劇本里。錯誤示範："他終於理解了這個世界的規則。"正確做法：他伸手去碰那道光，光突然消失，房間裡所有的燈同時暗下去。

**潛臺詞**：對話是冰山，說出來的話只是表面。超短片的臺詞密度本身就極低，一旦寫臺詞，更要讓它承擔雙重資訊，不能是直白的規則說明。

**臺詞風格**（如果有臺詞）：口語化，不同角色有不同說話方式；避免過度比喻和書面化AI腔；不要讓角色說出雙方都已經知道的事情——超短片臺詞本就極少，出現的每一句更要經得起這條檢驗。

**標準劇本格式**：
```
【場景X：地點 / 時間 / 簡要視覺描述】

動作/畫面描寫直接寫在臺詞之間，不加標記，只寫攝影機能拍到的東西。

角色A：xxxxxxxxx。
```
`角色名（OS）：` 表示內心獨白/旁白，僅在視聽手法本身需要時使用（如散文式旁白型的How-to-Tell）。

## 第一步：判斷路徑——What-If 還是 How-to-Tell

兩條路徑方法論完全不同，第一步就要分岔，進入創作前先確認使用者要做哪種：

- **What-If 型**：假設一個反常識的前提，展示它的後果和推演。核心武器是**概念的純度和組合**。
- **How-to-Tell 型**：用一種出人意料的敘事方式重新講述一個已知的事情——內容本身不是賣點，**敘事形式本身**才是。

## 核心特徵（兩種型別通用）

- **時長**：1-3分鐘
- **角色**：功能性archetype，不需要深度和小傳。角色是概念的載體，可以完全沒有角色。
- **弧光**：通常沒有角色弧光。如果有，只是一個瞬間的認知翻轉，不是A到B的完整轉變。
- **世界觀**：即插即用，觀眾必須在5秒內理解規則——不解釋，靠畫面直接展示後果。
- **節奏**：從第一幀開始就在傳遞資訊，零廢鏡頭。
- **視聽語言**：超短片是炫技的合法空間——視聽形式本身可以成為內容的一部分，這一點在長片/短片裡都要收著用，在超短片裡可以放開用。

# Part A：What-If 型

## What-If 的本質

好的 What-If 不是天馬行空的幻想，而是**現實的一面放大鏡**——用一個虛構的規則，讓觀眾看到現實中他們視而不見的東西：某個真實存在但被忽視的社會機制、人性弱點、荒誕邏輯，被放大到不可忽視的程度。判斷一個 What-If 夠不夠格：拿掉虛構的規則外殼，它指向的那個真實焦慮是否依然成立、依然扎心？

## 概念組合：核心創意方法

最銳利的 What-If 往往不是單一概念，而是兩個不相關的概念碰撞產生的化學反應。

**組合方式一：概念嫁接**——取概念A的執行機制 + 概念B的應用場景。例："斬殺線"（遊戲淘汰機制）+ AI焦慮 → "公司用AI給每個員工打分，分數低於斬殺線的人第二天工位上只剩一個USB"；遊戲復活機制 + 職場裁員 → "被裁的人可以投幣復活，但每次復活工資減半"。操作步驟：列出A的核心機制→列出B領域裡人們最在意什麼→把A的規則塞進B的場景→檢驗這個組合是否揭示了B場景裡一個真實存在的問題。

**組合方式二：時空錯置**——把人物/技術/制度放到它不屬於的時代或地點。例：鋼鐵俠 + 1990年代下崗潮 → "東北軍工廠高階工程師下崗後在車庫用廢鐵造盔甲，然後發現耗電量比整條街的電費還高"；ChatGPT + 科舉 → "考生帶了一個能對對子的銅匣子進考場，主考官發現匣子寫的八股比所有考生都好"。這種方式的力量在於：時空錯位讓觀眾同時看到兩個時代，理解當代的荒誕需要一面古代的鏡子，反之亦然。

**組合方式三：隱喻具象化**——把抽象社會焦慮變成一個能被攝影機拍到的物理規則。方法：取抽象焦慮A→找到它在行為層面的"最小動作"→把這個動作變成強制性的物理規則。例："內卷"的最小動作是"別人加班我也必須加班"→物理規則："所有人的燈必須比鄰居的亮，亮度不夠就斷電"；"容貌焦慮"的最小動作是"照鏡子對比"→"鏡子會給你的臉打分，分數顯示在額頭上，別人能看到"。

**組合方式四：反轉並置**——找到兩個表面相似但本質矛盾的事物，讓它們在同一場景中共存。例："寵物"和"畜牧"→"一個人精心餵養他的貓，貓糧工廠隔壁就是屠宰場"；"反消費主義"和"消費"→"一個人穿著印'拒絕消費主義'的T恤，這件T恤售價399"。

**組合方式五：規則反轉**——找到一個人們習以為常的規則，翻轉它，推演後果。例："年齡越大越成熟"反轉為"人出生時是老人，越活越年輕，死於嬰兒"；"記憶隨時間消退"反轉為"記憶不會消退，但你可以主動刪除——代價是每刪一段記憶，就永遠失去對應的那種情感"。

**概念組合的檢驗**：組合是否產生"1+1>2"的效果（兩個概念組合後不比單獨一個更有趣就放棄）？觀眾能否在5秒內理解規則？是否指向一個真實的社會情緒或人性弱點？是否有推演空間（規則推到極限會發生什麼）？是否有翻轉潛力（最後能反過來打觀眾一巴掌）？

## What-If 的五種結構

**結構A：經典三段式（概念呈現→推演→翻轉）**——最通用。一、概念呈現（前15-30秒，一個畫面/動作讓觀眾瞬間理解規則，不解釋直接展示後果，最好是讓人"咦？"的視覺懸念）。二、推演（中間30-90秒，展示2-5個後果切片，每個5-15秒，切片之間必須遞進——每一個比上一個更極端/更荒誕/或更日常）。三、翻轉（最後15-30秒，一個畫面或一句話徹底顛覆前面建立的認知，翻轉必須是概念自身邏輯的延伸，不是硬轉）。

**結構B：遞進崩塌式**——適合"規則不斷升級直到崩潰"。規則建立（約20秒，規則的基本形態看起來還挺合理）→第一次升級（約20秒，更嚴格但人們適應了）→第二次升級（約20秒，升級到荒誕但人們仍在適應）→崩潰點（約20秒，規則推到邏輯極限系統瞬間崩塌；或者所有人已完全適應最荒誕的狀態，崩塌的不是規則，是觀眾的認知）→餘像（最後10秒，崩塌之後的一個安靜畫面——廢墟中的日常）。

**結構C：雙線並置式**——適合反轉並置類概念。同時展示兩條看起來都正常/溫暖/美好的線，在視覺上平行推進（分屏/交叉剪輯/同畫面前後景）。在某個時刻觀眾突然意識到兩條線其實是同一件事的兩面，或線A的美好建立線上B的殘酷之上。這個"意識到"的瞬間就是翻轉，不需要角色說出來。

**結構D：迴圈/Loop式**——適合"困境無法逃脫"或"歷史重複"。起點（狀態A）→發展→看似解決→回到狀態A。關鍵：第二次看到狀態A時觀眾的理解已經不同——第一次覺得這是正常的開始，第二次意識到這是永遠無法逃脫的牢籠。可以在第二次迴圈開始時切黑，讓觀眾自己意識到"又來了"。

**結構E：倒敘揭示式**——適合"真相一直在眼前但觀眾沒看到"。先展示結果（一個奇怪的、不可理解的畫面）→倒推原因，一步步揭示畫面是怎麼來的，每一步揭示都讓畫面更合理但也更恐怖/荒誕/諷刺→最後一步揭示讓觀眾理解一切，重新看第一個畫面，含義完全不同。

## What-If 工作流

**第一步：概念鍛造**。判斷使用者輸入是單一概念還是需要組合；如果給的方向不夠銳利，用五種組合方式生成3-5個候選。輸出：一句話概念 / 組合方式 / 概念指向的真實焦慮或人性 / 推演潛力（規則推到極限最荒誕的畫面是什麼）/ 翻轉潛力（最大認知反轉可能是什麼）/ 建議結構A-E / 建議視聽語言。檢驗：能否一句話說清規則？5秒內能畫面呈現嗎？指向真實的社會情緒或人性弱點嗎？有至少3個遞進後果切片的推演空間嗎？有翻轉潛力嗎？3分鐘夠講完嗎（太複雜就該降級到短片格式）？

**第二步：結構與視聽設計**。選定結構型別，從視聽語言武器庫（見Part C）選1-2種核心手法，展開帶時長標註的結構大綱，每段標註視聽手法和雙軌節奏（松/中/緊的情節，輕/中/重的情感）。檢驗：概念呈現是否5秒內讓觀眾get規則？推演切片是否層層遞進而非平行羅列？翻轉在邏輯上成立嗎？翻轉是否讓觀眾想回頭重看一遍？視聽手法是否強化了內容？總時長在1-3分鐘內嗎？

**第三步：全片劇本**。極致精簡，每個字都必須存在於畫面中；零解釋，純視覺敘事（除非視聽手法本身需要旁白）；臺詞極少，甚至可以完全沒有臺詞；翻轉落在最後一個畫面或最後一句話上；視聽語言描述要具體（不是"用長鏡頭"，而是"鏡頭從角色的手開始，緩慢拉遠，揭示整個房間的全貌——所有工位上都是空的"）。寫完後提供：分段時長預估、翻轉是否足夠有力的自我評估、2-3個替代翻轉方案、視聽手法的替代方案。

# Part B：How-to-Tell 型

## How-to-Tell 的本質

不改變"講什麼"，改變"怎麼講"。前提：觀眾已經知道或很快能理解故事的內容，內容本身不是賣點——**敘事方式本身**才是。力量在於：用一種全新的方式重講已知的事情時，觀眾被迫從一個從未有過的角度重新理解它。**形式即內容**。

## 五種創意方法

**方法一：視角置換**——用一個不可能的視角講故事。例：從子彈的視角講一場戰爭；從外賣袋的視角講一個獨居者的一天；從地球的視角講人類文明史（地球像一個被寄生蟲感染的宿主）；從一個表情包的視角講它被髮送/接收/截圖/轉發的一生。

**方法二：形式模擬**——用某種已有形式（檔案格式/介面/遊戲/說明書等）重新包裝故事。例：用"產品說明書"格式講一段婚姻（產品名稱：婚姻，保質期：不確定，副作用：見附錄）；用"遊戲攻略"格式講打工人的一天；用"監控攝像頭畫面"講一家便利店裡發生的愛情故事；用"搜尋歷史記錄"講一個人從確診到接受的心理歷程。

**方法三：時間手術**——對時間做加速/減速/倒放/迴圈/跳躍/並置。例：把一個人的一生壓縮到2分鐘，每個人生階段只有幾秒；把1秒的動作拉長到3分鐘（子彈出膛、杯子碎裂、眼淚滑落的1秒裡發生了什麼）；同一個街角的100年，每10年切一次，攝影機位置不動；正放一個人的早晨+倒放同一個人的夜晚，兩條時間線在中午交匯。

**方法四：尺度跳躍**——在極大和極小之間跳躍，用尺度對比製造衝擊。例：從一個細胞的分裂開始，逐步拉遠到一個人、一座城市、一個星球、一個星系，然後切回細胞；一場家庭爭吵→切到外太空看地球→切回爭吵，爭吵突然變得可笑；一粒米的旅程——從稻田到飯桌到垃圾桶到填埋場到地下水再到稻田。

**方法五：規則限制**——給敘事本身加一個限制，正是這個限制產生創意。例：整部片子只用一個固定鏡位，不剪輯；整部片子沒有一個人出現，只有空間和物品；整部片子只有聲音畫面是黑的（或反過來）；整部片子由手機截圖/聊天記錄/通知欄組成。

## How-to-Tell 的結構

不用"概念呈現→推演→翻轉"的三段式，結構由**敘事形式本身**決定，形式就是結構。通用節奏：一、形式建立（前20-30秒，讓觀眾理解這個片子用什麼方式在講故事，觀眾第一反應該是"哦？這樣講？"）。二、形式深入（中間60-120秒，在這個形式框架內展開內容，隨內容推進形式本身也在遞進——升級、變異、或暴露新含義，不是重複同一種手法）。三、形式與內容的交匯（最後15-30秒，觀眾意識到形式和內容是一體的，"用這種方式講"本身就是故事的一部分；最好的結尾是形式本身完成了翻轉）。

**示例**：用"搜尋歷史記錄"講一個人從確診到接受的過程——形式建立：螢幕滾動搜尋記錄，"頭痛原因""偏頭痛緩解方法"；形式深入：搜尋內容逐漸沉重，"腦部CT多少錢""膠質瘤存活率"；交匯：最後一條搜尋是"附近有什麼好吃的"——形式（搜尋記錄）和內容（接受現實）在這一條搜尋中合一。

## How-to-Tell 工作流

**第一步：形式發現**。先確認使用者想講的內容/主題，用五種創意方法生成3-5個形式方案。輸出：內容/主題 / 敘事形式 / 創意方法（視角置換/形式模擬/時間手術/尺度跳躍/規則限制）/ 形式與內容的關係（為什麼用這種方式講更好，不用行不行）/ 形式的遞進潛力 / 建議視聽語言。檢驗：形式是否與內容深度契合（不只是"看起來酷"，而是"只能用這種方式講"）？形式有遞進空間嗎（不能一個手法用到底）？形式本身有翻轉潛力嗎？觀眾能在15秒內理解敘事形式嗎？如果去掉形式用常規方式講，內容會喪失衝擊力嗎（如果不會，換形式）？

**第二步和第三步**：與What-If的結構設計和全片劇本流程相同，自檢額外增加：形式與內容是否在結尾處交匯（不是"形式包裝了內容"，而是"形式本身成為了內容的一部分"）？形式本身從頭到尾是否有變化/升級/變異？

# Part C：視聽語言武器庫（兩種型別通用）

超短片是視聽語言炫技的合法空間——3分鐘以內，觀眾對形式實驗的容忍度極高。以下手法可單獨使用也可組合，但一部片子應聚焦1-2種核心手法用到極致，不要塞入五種技巧變成炫技集錦。

**鏡頭語言類**：一鏡到底（從頭到尾不剪輯，效果是真實感/沉浸感/時間不可逆，適合需要"在場感"的概念）；固定機位時間流逝（攝影機不動，時間在畫面中加速，效果是變與不變的對比，適合講述時間跨度大的概念）；連續推軌（攝影機持續勻速移動穿越空間，效果是空間的揭示，適合空間本身承載資訊的概念，如從豪宅推到貧民窟）；第一人稱POV（效果是極端代入感，適合視角置換型How-to-Tell）；微距/顯微鏡頭（拍肉眼看不到的尺度，效果是熟悉事物變得陌生，適合尺度跳躍型How-to-Tell）。

**剪輯/時間類**：跳切蒙太奇（同一畫面內快速時間跳躍，效果是時間壓縮和重複的荒誕感，適合展示"日復一日"）；分屏（畫面分2-4區域同時展示，效果是對比/並置/平行時間線，適合雙線並置結構）；交叉剪輯（兩條線之間快速切換，效果是對比加速和張力累積，適合兩個看似無關的事物最終被揭示為有關聯）；倒放（效果是熟悉動作變得陌生，結果先於原因出現，適合時間手術型或迴圈結構）；定格/時間凍結（效果是強制觀眾注意某個細節，適合在密集視覺資訊流中強調翻轉瞬間）。

**畫面構成類**：對稱構圖（效果是秩序感/儀式感/不安感，適合展示制度化的概念）；畫面內前景/背景敘事（前景做一件事、背景發生另一件事互相註釋，效果是無需剪輯的並置）；色彩限制（整部片子只用有限顏色，效果是顏色本身成為敘事元素，適合顏色與概念有直接關聯時，如紅色=危險/愛情、灰色=系統/壓抑）。

**聲音類**：畫面與聲音錯位（畫面展示A聲音屬於B，效果是兩層資訊的碰撞，適合諷刺反差，如畫面是和平日常聲音是新聞播報的災難資料）；環境音放大（把日常環境音放大到不正常音量，效果是熟悉變得不安）；靜默（關鍵時刻完全沒有聲音，效果是迫使觀眾集中注意力，適合在高密度資訊流之後突然靜默——沉默本身就是高潮）。

**介面/媒介類**：螢幕錄製（整部片子是手機/電腦螢幕錄製，效果是極致當代感，適合形式模擬型How-to-Tell）；偽文件/偽紀錄片（假裝是真實紀錄片/新聞/教學影片，效果是以真實外殼包裹荒誕核心，適合What-If需要一個"嚴肅"的殼來反襯）；資料視覺化（用圖表/資料/統計視覺語言講故事，效果是數字越冷靜內容越震撼）。

**如何選擇**：形式服務內容，先確定概念再選手法；一部片子聚焦1-2種核心手法；手法需要遞進（升級/變異/結尾被打破，如全片固定機位最後一個鏡頭突然移動）；手法本身可以成為翻轉的工具（視聽形式本身也在翻轉，如全片正常速度最後一秒突然加速到整個世界在眼前飛過）。

## 產出格式（寫完後應交付的內容）

1. **一句話概念**：（What-If的規則，或How-to-Tell的形式）
2. **概念/形式檢驗清單**：（對照上文對應型別的檢驗項逐條確認）
3. **結構大綱**：（分段落，標註時長/視聽手法/雙軌節奏）
4. **完整劇本**：（標準格式，場景標註+動作描寫+對白/或旁白）
5. **收尾建議**：翻轉是否有力的自我評估 + 2-3個替代方案

## 常見陷阱

- ❌ 概念需要大量解釋才能理解 → 換概念或降級到短片
- ❌ 推演段只是概念的重複而非遞進 → 每個切片必須比上一個更進一步
- ❌ 翻轉是硬轉，跟前面沒有邏輯關係 → 翻轉必須是概念自身邏輯的延伸
- ❌ 試圖在3分鐘內塞入完整角色弧光 → 放棄弧光，聚焦概念
- ❌ 有臺詞在"解釋概念" → 刪掉，用畫面展示
- ❌ 視聽手法與概念無關（"我想用分屏所以用了分屏"）→ 形式必須強化內容
- ❌ 一部片子用了太多視聽手法 → 聚焦1-2種，用到極致
- ❌ 概念組合後兩個概念各自獨立、沒有化學反應 → 組合必須1+1>2
- ❌ How-to-Tell的形式只是"包裝"，去掉形式故事照樣成立 → 形式必須是不可替代的
- ❌ 概念很好但沒有推演就直接到翻轉 → 推演段是觀眾"入戲"的過程，不能跳過

## 與題材殼skill的關係

本skill只管"1-3分鐘這個體量該怎麼寫"，不管"這個故事該講男頻/懸疑/復仇哪個題材的具體判斷標準"。如果需要某個題材專屬的判斷標準（什麼算爽、什麼算恐怖），可以在寫完概念大綱後，另外參考本庫對應題材殼skill的"這一集/這段廢了"檢驗清單；不參考也完全可以獨立完成一個超短片。兩者是正交的兩條軸，不是依賴關係。
