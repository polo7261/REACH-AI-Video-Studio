# 古代监控爆款创意视频

## 適用場景

用户要做「古代监控」风格的爆款反差创意短视频（如孙悟空被师傅从「五指山看守所」带出塞进黑色桑塔纳），需要监控质感、固定机位、时间码与机位ID、无BGM时使用。

## 輸出

一份可直接生成古代监控风格视频的剧本、锚点清单与分镜提示词，并合成带清晰时间码与机位ID字幕的成片。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
