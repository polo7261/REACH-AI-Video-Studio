# 古代監控爆款創意影片

## 適用場景

使用者要做「古代監控」風格的爆款反差創意短影片（如孫悟空被師傅從「五指山看守所」帶出塞進黑色桑塔納），需要監控質感、固定機位、時間碼與機位ID、無BGM時使用。

## 輸出

一份可直接生成古代監控風格影片的劇本、錨點清單與分鏡提示詞，併合成帶清晰時間碼與機位ID字幕的成片。

## 使用方式

此 skill 為畫布平台的 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
