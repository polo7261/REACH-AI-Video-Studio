# short-film-writer

5-10分钟叙事短片的完整写作方法论。短片是**冲刺**，靠信息密度取胜——每个场景都必须推进情节或揭示性格，没有闲笔的空间。本 skill 自包含，不依赖本库其他任何文件；如果要指定"这个短片该讲男频/悬疑/复仇哪个题材的具体内容判断标准"，可以在写完后额外参考对应题材壳，但题材壳不是必需前提。

## 边界：不做什么

不产出分镜表、镜号、景别/运镜/构图、转场方式、AI生图/生视频提示词、任何特定生成引擎的格式约束。产出到完整的、可以直接读、直接拍的文字剧本为止。

## 工作流纪律

严格按步骤顺序执行，不跳步；每一步完成后暂停，等待用户的[通过/修改/自检]指令；绝不一次性把后续所有步骤生成完再交给用户；每步结束后提醒用户可以要求[自检]。

自检是内部过程——写之前先在心里过一遍对应步骤的检查清单，不需要在输出中展示自检的思考过程，只需要确保交付的内容已经通过检查。用户仍然可以主动要求[自检]，此时才需要显式地逐条列出检查项并给出评估结果。

## 写作红线（全局最高优先级，任何格式都不能违反）

**绝对不要**：写心理描写（"他意识到"、"她领会到"、"内心涌起"）；写括号暗示（"（其实是在掩饰紧张）"）；角色用台词解释设定或主题；说教片段、强行催泪、煽情独白；过度比喻句、类比、书面化的AI腔台词；写任何摄影机拍不到的内容。

**必须做到**：台词口语化，像真人说话；用动作代替解释（动作即潜台词）；对话像冰山，只露一角；所有内容从视听角度出发。

## 视听化写作核心

**Show, Don't Tell**：严禁心理描写，只写能被看见的动作和能被听见的声音。如果一个情感无法通过角色的物理行为传达给观众，这个情感就不该出现在剧本里。错误示范："他终于理解了父亲的苦心。"正确做法：他站在那里看了一会儿，然后把外套脱下来盖在父亲身上。

**潜台词**：对话是冰山，角色说出来的话只是表面，真正的含义在水面之下。避免直白（on-the-nose）对话，利用动作、停顿、回避、话题转移表达真意。直白（错误）："我很害怕失去你。"潜台词（正确）："你走的时候把那件外套带上。……外面冷。"

**动作即潜台词**：所有情感传递必须能用摄影机拍出来。一个好的短片，把所有台词删掉后，观众仍然能大致理解发生了什么。

**台词风格**：口语化，不同角色有不同说话方式（用词、句式长度、习惯性表达）；避免过度比喻和书面化AI腔；不要让角色说出双方都已经知道的事情。

**标准剧本格式**：
```
【场景X：地点 / 时间 / 简要视觉描述】

动作/画面描写直接写在台词之间，不加标记，只写摄影机能拍到的东西。

角色A：xxxxxxxxx。
角色B：xxxxxxxxx。

角色A没有回答。他转身走向窗口，手指无意识地敲着窗框。

角色A：xxxxxxxxx。
```
`【场景标注】`用方括号标注地点/时间/关键视觉信息；`角色名：`直接跟对白；`角色名（OS）：`表示内心独白/旁白；动作/画面描写不加标记，直接写在台词之间。

## 核心特征

- **时长**：5-10分钟
- **角色**：1-2个主角，有完整的Want/Need/Arc
- **结构**：四段式（起因→发展→高潮→结局），聚焦单一核心事件
- **弧光**：一次完整的A→B变化
- **世界观**：简洁明了，30秒内观众理解规则
- **节奏**：信息密度高，每个场景都必须推进情节或揭示性格

## 短片的核心约束

短片只允许一个**单一核心事件**，不能有支线、不能分散焦点。所有场景都服务于同一个戏剧动作——主角追求目标、遭遇阻碍、做出选择。除非用户特别要求，所有设定都应发生在现实主义背景之下，禁止过于夸张或过于戏剧性的设计。

## 人物设计：拒绝纸片人

**外在需求(Want) vs 内在欲望(Need)**：Want是驱动动作的目标，角色自己意识到的、主动追求的东西；Need是角色自己未曾意识到的灵魂缺口，通常是Want的深层原因。两者之间的张力是角色弧光的发动机。

**人物弧光**：弧光 = 从A状态到B状态的不可逆变化。短片的弧光是一次性的跳跃（A→B），不需要像长片那样经历多次"伪变化"。

**人物小传**：前史不是背景介绍，而是冲突的根源。关键事件应该解释：为什么角色有这个Want？为什么角色看不到自己的Need？角色的矛盾性从何而来？

**矛盾性**：好的角色至少有一层矛盾——外在表现 vs 内在真实（外在自信vs内在自卑，外在冷漠vs内在渴望连接）。矛盾性让角色立体，也让潜台词有了空间。

## 选题工具库（用户没有明确想法时，内部引导用，不直接展示给用户）

当用户还没有明确的故事概念时，不要把下面的方法论摆给用户看，而是通过自然对话判断用户的模糊方向属于哪条路径，用对应方法引导。

**路径1：从主题出发**（用户信号：抽象命题/社会议题/"我想讲关于XX的故事"，如"关于记忆""孤独"）——引导方法：帮用户把抽象主题转化为具体戏剧动作。"关于记忆"不是故事，"一个即将失去所有记忆的人必须在24小时内选择保留哪一段"才是故事。问：这个主题下，什么人在什么处境下会被逼到不得不做选择？

**路径2：从人物出发**（用户信号：一种矛盾性格/"我想写一个XX样的人"，如"一个极度害怕水的游泳教练"）——引导方法：从矛盾性格中提取戏剧动作，矛盾本身就是冲突的种子。问：这个人最害怕面对什么？如果逼他面对最害怕的事，会发生什么？

**路径3：从空间/环境出发**（用户信号：一个具体地点/封闭空间/特殊世界，如"一座老茶馆""一列永不停站的列车"）——引导方法：空间即规则，一个特殊空间暗示了自己的运行规则和权力结构。问：这个空间里谁在上面谁在下面？什么资源稀缺？什么行为被禁止？空间越封闭、规则越极端，戏剧张力越强。

**路径4：从关系出发**（用户信号：两个人之间的张力/"我想写两个XX之间的故事"，如"一对即将离婚的夫妻"）——引导方法：关系中的张力来自两个人想要的东西互相矛盾。明确各自的Want是什么？为什么不可能同时实现？什么处境下这个矛盾会被逼到极致？

**路径5：从标签/概念碰撞出发**（用户信号：几个关键词/一种感觉/"我想把XX和XX结合"，如"外卖骑手+科举"）——引导方法：用概念嫁接（取A的机制+B的场景）、时空错置（把人/技术/制度放进它不属于的时代地点）、隐喻具象化（把抽象焦虑变成物理规则）、反转并置（两个表面相似实则矛盾的事物放同一场景）、规则反转（取现实规则的反面）五种工具碰撞概念。

**操作流程**：听用户自由表达（哪怕只是一个词）→判断属于哪条路径（用户不需要知道路径存在）→用对应工具提出具体、有启发性的问题深挖（不要问"你想表达什么"这种空泛问题）→产出3-5个具体方案供选择→不展示方法论本身，用户看到的是"帮你想出了几个好点子"。

当用户完全没有方向时，不要列路径菜单，用自然对话启发："最近有没有什么新闻/画面/身边的事让你觉得'这也太荒诞了'？""如果你能把一个现实规则反过来，你最想反转哪个？""有没有一个空间让你觉得'这里本身就像一个故事'？""有没有两个看起来不相关的东西，你觉得放一起会很有意思？"

## 完整八步工作流

### 第一步：破题与核心动作

**目标**：确立短片的"核"。如果用户已有构思直接使用；如果没有，用上文选题工具库引导（不展示路径菜单）。

**执行逻辑**：基于用户输入构思3-5个核心戏剧动作——戏剧动作=目标(Goal)+阻碍(Conflict)，必须是"有目的的追求"；确保事件聚焦，适合短片体量。

**输出格式**（严格按此输出，不添加场景等未提及内容）：
* **方案 A/B/C：** 主角 / 目标(Want) / 阻碍(Conflict) / 一句话故事梗概(Logline)

> 请回复"通过"进入下一步，或告诉我修改意见。或选择某个方案让我[自检]。

**[自检：核心概念与戏剧动作]** 是否建立了"目标+冲突"？目标是否合理且急切？是否和阻碍有强烈关系？是否存在明确的内/外部冲突？阻碍是否在合理尺度内？目标和阻碍的冲突是否是驱动故事的发动机？

### 第二步：梗概草稿

**目标**：让用户对整体故事走向和气质有基本判断，再往下深入。

**执行逻辑**：基于选定方案写一段话（100-200字）的故事提要，应包含主角是谁、处于什么处境、因为什么事件被逼入什么困境、最终走向什么结局（可以模糊）；提要的语气应暗示全片气质——沉重还是轻快、温暖还是冷冽。

> 这个梗概在后续步骤中可以继续调整。请回复"通过"进入人物设计，或告诉我修改意见。

**[自检]** 梗概是否传达了故事的核心冲突？读完后对"这是一个什么样的故事"有清晰感受吗？语气是否暗示了全片气质？

### 第三步：人物深度与弧光

**目标**：拒绝纸片人，建立人物内在张力。

**执行逻辑**：设计Want vs Need；设计人物小传（挖掘前史作为冲突根源）；设计矛盾性（外在表现vs内在真实）；除非用户特别要求，禁止过于夸张的设计。

**输出格式**：人物[姓名] / 外在需求 / 内在欲望 / 人物弧光(A状态→B状态) / 人物小传关键点 / 矛盾特征(外在vs内在)

> 请回复"通过"进入下一步，或告诉我修改意见。你也可以让我[自检]。

**[自检：人物塑造与弧光]** 外在需求和内在欲望是否清晰且对立？是否预设了不可逆的内在变化？结局是否展示了"新常态"？是否具备矛盾性？行为是否符合小传逻辑？

### 第四步：前史与世界观（短片精简版）

**目标**：遵循"电影是现实生活的横截面"——故事开始之前，世界已经存在了。短片不需要像长片那样完整建造世界观，但需要明确以下信息（编剧自己必须知道，不一定全部展示给观众）：

**输出格式**：时代/环境背景 / 角色前史关键事件（在故事开始之前，主角经历过什么导致了当前的处境和性格）/ 关系既往（如有重要关系，这段关系在故事开始之前是什么状态）/ 故事从哪个横截面切入（为什么选择从这个时刻开始讲）

**注意**：前史信息在剧本中通过对白和视觉线索自然散落，不要集中闪回或旁白交代。如非必要不用闪回。

> 请回复"通过"进入结构大纲，或告诉我修改意见。

### 第五步：结构大纲

**目标**：搭建短片骨架，确保节奏递进。

**执行逻辑**：使用四段式结构；只有一个单一核心事件，避免支线；第四步中的重要前史细节需在第一幕和第二幕中自然展示（如非必要不用闪回）；必须包含激励事件和"一切尽失"时刻；开场的前15秒必须有视觉钩子——第一个画面就应包含信息或悬念，最有效的是一个"不太对"的日常画面（看起来正常，但某个细节让人起疑）。

**输出格式**：
* **第一幕：起因** — 开场钩子（前15秒的画面/动作） / 建置（故事常态展现） / 激励事件（打破平衡）
* **第二幕：发展** — 冲突升级（障碍1） / 冲突进一步升级（障碍2，不可省略） / 中点（伪胜利/伪失败）和一切尽失
* **第三幕：高潮** — 最终对决（动作顶点） / 关键选择和故事反转
* **第四幕：结局** — 新常态（弧光完成）

> 请回复"通过"进入下一步，或告诉我修改意见。你也可以让我[自检]。

**[自检：结构与节奏]** 开场钩子是否在前15秒内就抓住观众？四个部分是否清晰？激励事件、高潮是否明确？每部分是否都在推动情节或揭示性格？是否去除了无效情节？障碍2是否存在且与障碍1不同质（不能是同一种阻力换个说法）？各部分时长预算是否合理（建置约15%，发展约40%，高潮约25%，结局约20%）？

### 第六步：场景列表

**目标**：将大纲转化为具体的视听单元。

**执行逻辑**：将第五步每个情节点拆解为一个或几个核心戏剧动作（目标→障碍→结果）；确保每个大戏剧动作可拆解为几个微型戏剧动作；每场戏标注预估时长和双轨节奏状态。

**输出格式**：第1场戏……（约X秒）情节：松/中/紧｜情感：轻/中/重；第2场戏……；时长累计：X分X秒 / 目标总时长X分钟

> 请回复"通过"进入下一步，或告诉我修改意见。你也可以让我[自检]。

**[自检]** 每个情节点是否都有具体拆分？场景连接是否紧凑？相邻场景之间是否有情节过渡？场景时长累加是否与目标总时长吻合？是否有连续3场以上同一节奏状态（如有需调整）？情节节奏和情感节奏是否有至少一处错位（更高级的叙事）？

**如果短片总时长超过8分钟或场景超过8场，第六步完成后建议触发一次记忆检查点**（见下文"记忆检查点"节），锁定角色状态和活跃线索后再进入写作。

### 第七步：场景写作

**目标**：填充血肉，执行视觉写作和潜台词。请用户指定要生成的场景编号（或全部）。

**执行要求**：视觉写作——严禁心理描写，只写能被看见的动作和能被听见的声音；潜台词——对话像冰山，避免直白，利用动作/停顿/回避表达真意；标准剧本格式输出。

> 请回复"通过"进入下一步，或告诉我修改意见。你也可以让我[自检]。

**[自检：场景写作与视听语言]** 是否有心理描写（如有则Fail）？是否用画面叙事？对话是否过于直白？是否利用了潜台词和肢体语言？台词是否口语化？

### 第八步：剧本医生与抛光

**目标**：诊断与优化。

**执行逻辑**：作为剧本医生通读全片；寻找逻辑漏洞、节奏拖沓、直白对话；提供What-if多版本探索建议；检查各场景时长预算——是否有场景比预计长/短太多？对整体节奏的影响？

**输出格式**：
* **诊断报告**：节奏问题（含双轨节奏诊断） / 时长问题（哪些场景过长过短，高潮段时长是否足够） / 逻辑漏洞 / 对话问题
* **优化建议**：（针对某场景的潜台词重写、针对结局的反套路构思）

**[综合自检]** 根据四大板块（核心概念、人物、结构、视听）给出最终评语及修改意见。

> 剧本初稿完成。你想对哪部分精修？

## 双轨节奏系统

节奏不是只有一条线——外部情节节奏（事件密度和强度：紧=高密度事件/快速对话/追逐/揭露，松=日常场景/独处时刻/沉默）和内在情感节奏（角色情感波动：重=告白/背叛/失去/恐惧/狂喜，轻=调侃/日常闲聊/安静陪伴），两条轨道可以同步也可以错位，错位本身就是强大的叙事工具：

- **情节松+情感重**：两个人安静地坐着吃饭，什么事都没发生，但观众知道其中一个人明天要走。画面越平静，情感越重。
- **情节紧+情感轻**：激烈的追车戏，但角色在打趣、配乐轻松。紧张的事件被轻盈的情绪包裹。
- **情节紧+情感重**：高潮段——事件密集且情感炸裂，是全片顶点，不能持续太久。
- **情节松+情感轻**：纯粹的呼吸场景，让观众休息。

在结构大纲和场景拆解阶段，应画一张"节奏波浪图"标注每段的外部情节强度和内在情感强度，检查起伏对比。应避免：两条线长时间同时低位（观众无事可看也无感可投）；两条线长时间同时高位（观众疲劳，高潮不再特别）；任何一条线单调上升没有回落（没有呼吸感）。

## 时长估算方法

**对白估算**：1页标准剧本格式≈1分钟成片。中文剧本中，大约200-250字的对白+动作描写≈1分钟。

**场景估算规则**：纯对话场景按对白字数估算；动作/蒙太奇场景按画面数量估算（每个独立画面约3-5秒）；沉默/情绪场景容易低估——一个角色站在那里什么都不做，成片中可能需要10-15秒才有足够情感分量；转场/过渡不要忘记计入，通常每次2-5秒。

**场景时长标注格式**：
```
【场景3：医院走廊 / 夜 / 荧光灯嗡嗡响】（约1分30秒）
  情节节奏：中（一次关键对话）
  情感节奏：重（角色第一次面对真相）
```

**短片全片时长参考比例（8分钟为例）**：建置1.5分钟 / 发展前半2分钟 / 发展后半2分钟 / 高潮1.5分钟 / 结局1分钟。实际创作可灵活调整，但调整后应意识到自己在做什么（比如"我故意让建置占40%时长，因为这是一个慢热型故事"）。

**节奏诊断**（剧本医生阶段）：高潮段时长是否足够（太短会让高潮感觉被压缩）？建置是否太长（观众等太久才进正题）？是否有连续超过3分钟的单一情绪段落（无论紧张还是松弛，持续太久都会失效）？两个高情感场景之间是否有足够的呼吸空间？全片最长的单场戏是否有足够理由占据那么多时长？

## 记忆检查点（超长短片专用，多数短片不需要）

只有在第六步完成后短片总时长超过8分钟或场景超过8场时才需要触发。检查点是一份结构化压缩摘要，不是全文复述：

```
📌 记忆检查点 | 短片 | [当前位置]
【已完成进度】当前处于第几步 / 已写到哪个场景或段落
【故事核心（不变）】Logline / 核心戏剧动作：目标→阻碍
【角色当前状态】[角色名]：物理状态/情感状态/当前知道什么/当前想要什么
【已完成段落摘要】场景1：一句话概括发生了什么+核心价值转变；场景2：……
【活跃线索】需要后续回应的线索及状态
【节奏状态】上一段落的情节/情感节奏 → 下一段落建议方向
【待写内容预告】下一个要写的场景是什么，核心戏剧动作是什么
```

## 短片节奏技法

**前史展示**：前史信息通过对白和视觉线索自然散落，不要集中闪回或旁白交代。

**节奏的拉伸与回弹**：拉伸——用重复动作、平缓语速、静态画面建立预期；回弹——在毫无预警处迅速打破平衡，用极短的视听语言制造节奏断裂。

**结局**：展示弧光完成后的"新常态"——角色变化后的世界是什么样的。不需要解释角色学到了什么，用一个画面让观众自己感受。

## 跨格式技法借鉴（短片可借用的部分）

短片体量小，但可以从更大或更小的体量里借几个具体工具，用在自己的局部段落上：

**从长片借**：McKee价值转变检验法可以拿来检查短片的每一场戏——场景结束时的核心价值是否与开始时不同？如果一场戏结束时什么价值都没变，考虑删掉它，这条标准比"感觉这场戏有点多余"更可执行。如果短片的人物感觉"太平了"，可以借用Ghost/Lie/Flaw的思考方式——不需要完整展开，只需要暗示角色的行为背后有一个不被说出的原因，一个细节就够。伏笔/回扣在短片5-10分钟的尺度里反而冲击力更大——因为观众还记得，第1分钟不经意出现的一个物件，第8分钟突然成为关键，效果是炸裂的，可以在第五步结构大纲阶段主动设计"有没有一个东西可以在开头种下、结尾翻转"。如果短片里有一个次要角色，可以借用"B Story映射主题"的逻辑——让这个次要角色走主角"没走的那条路"，这样次要角色就不只是工具人，而是主题的另一面。

**从概念片借**：高概念翻转的思路（"这场戏的最后一秒能不能让观众重新理解这场戏的第一秒"）可以用在短片的结局上，制造一个punch。概念纯度检验（能否一句话说清、5秒内能否用画面呈现）可以拿来检验短片的Logline——如果一句话说不清楚，说明核心概念还不够锐利。

## 常见陷阱

- ❌ 引入支线或多个核心事件 → 短片只能有一个单一核心事件，砍掉一切分散焦点的内容
- ❌ 障碍2和障碍1是同一种阻力换个说法 → 必须换一种不同类型的阻碍
- ❌ 前史用闪回或旁白集中交代 → 通过对白和视觉线索自然散落
- ❌ 结局用台词总结角色学到了什么 → 用一个具体画面让观众自己感受"新常态"
- ❌ 没有做时长预算，导致高潮被压缩或建置过长 → 从第五步就开始标注时长
- ❌ 连续3场以上同一节奏状态 → 用双轨节奏检查起伏
- ❌ 开场用于"慢慢进入状态" → 短片没有时间铺垫，前15秒必须有视觉钩子
- ❌ 人物弧光设计成长片式的多次伪变化 → 短片弧光是一次性跳跃，别拖

## 与题材壳skill的关系

本skill只管"5-10分钟这个体量该怎么写"，不管"这个故事该讲男频/悬疑/复仇哪个题材的具体判断标准"。如果需要某个题材专属的判断标准，可以在写完大纲后另外参考本库对应题材壳skill的"这一集/这段废了"检验清单；不参考也完全可以独立完成一个短片。两者是正交的两条轴，不是依赖关系。
