## 一、分析框架（三块底座；细化见三/四/五节）

**1. 风格本质**：笑点靠**台词机锋 + 处境误会 + 现场反应**，不靠视觉变形；话剧 + 现场观众的多机位棚拍传统；表演略外放、说完梗留一拍等笑声、不破第四面墙。

**2. 画面与声音**：明亮偏暖、轻微高饱和的电视质感；**高调平光、几乎无阴影、全场可见**；固定主场景（客厅沙发/吧台/餐桌）+ 正面镜框舞台；制服化造型一眼看性格；多机位中宽景、稳定、靠剪辑在「说话 ↔ 反应」间切；**现场观众/罐头笑声**是身份标识、定节奏。

**3. 剧情（一梗到底，三拍）**：铺垫（正常处境）→ 转（离谱台词/误会/升级）→ 落（punchline，收在**反应 + 笑声**）。一条只一个笑点；引擎挑一个（升级/误会/反高潮/cringe）；压到两人——混乱制造者 + 正常人（捧哏），笑点长在「正常人怎么反应」。

## 二、工作流

### Step 1 · 前期确认（先敲定全部配置，再进 Step 2）

所有需要用户选的配置**必须在生成角色/场景之前全部确认**——角色三视图、场景图要花算力生成并绑定，配置一旦回改前面资产就白做；尤其**画幅由投放场景决定，必须先定**，否则三视图/场景图构图要重来。压成 **2 轮** `ask_user_input`（每轮 ≤3 题、都带默认值和"你帮我定"逃生口），别连环追问；用户说"全你定"就按默认一次跑完。

**先分流入口：**

- **A. 从零开始（最常见）** — 没角色/场景/段子/参考 → 走两轮确认 + 引导定段子。
- **B. 已有点子** — 给了一句话点子 → 只补缺的配置，已知项不重复问；笑点引擎从点子里推断、不问。
- **C. 反推参考视频** — 先跑第六节抽帧脚本读三拍/画风/机位，再产出同款；配置里能从视频看出的（画幅/时长/语言）直接沿用、只补没有的。

**第 1 轮 · 定框架（3 题）：**

1. **目的 + 投放场景 → 画幅与调性**：竖屏 9:16（抖音/TikTok/Reels，默认）｜横屏 16:9（YouTube/官网/横板）｜方形 1:1。目的（纯搞笑 / 品牌植入 / 角色 IP / 带货…）只影响调性轻重，不改画风。
2. **时长**：15s / 30s / 60s / 自填。**生成以 15s 为一段**，超 15s 分多段、每段一条独立连续 prompt（≈3-4 镜），共用同一套角色/场景绑定与风格锁定句，逐段生成后剪辑衔接：15s=1段、30s=2段、60s=4段、自填按 15s 取整。**每 15s 就是一个完整笑点**（自己的三拍 + punchline + 笑声），节奏紧凑；30s/60s＝同一对角色/同一场景下连着抖 2/4 个小段子，每段都落一次，别把一个梗硬拖长（拖长很尴尬）。
3. **笑点引擎**：升级 / 误会 / 反高潮 / cringe（**仅"从零开始"抛**；"已有点子"从点子推断）。

**第 2 轮 · 定语言与呈现（2 题）：** 4. **台词语言**：英文（默认，最贴美式情景喜剧口型）/ 中文。写进生成 prompt。 5. **字幕语言**：双语（默认，上中下英）/ 中文 / 英文。**字幕只在成片后剪辑烧录，不进生成 prompt**（见 Step 7）。

**制作方式固定图生视频**（本 skill 已生成三视图+场景图供绑定，不再询问）：生成时带上绑定图，prompt 侧重运镜/走位/动作/台词/切镜，外观布景交给参考图。

**旁白**：默认**关**（情景喜剧少用，单机位才有）；用户主动要才开，开则加画外音，不影响其余流程。

**分段生成节奏**（仅 &gt;15s 时问）：**一次性生成全部段** / **逐段确认**（生成一段、满意了再生下一段，更稳但慢）。默认逐段确认。

两轮确认完 → 从零开始再引导定段子：一轮抛 ① 场景（客厅/吧台/餐桌/办公室）② 二人组性格；据此从第四节点子库挑/改一个**一句话 premise** + 分配 {{Mixed N}}，确认即进 Step 2。

### Step 2 · 定角色与场景（三视图 + 场景图）

**先做选角引导（两问，用** `ask_user_input` **点选，留"你帮我定"逃生口）：**

1. **要几个角色**：1 / 2 / 3 / 自填。情景喜剧段子**建议 2 人**（混乱制造者 + 正常人/捧哏），但按用户选的来；人多时仍指定一个"正常人"负责反应。
2. **每个角色要哪种形象（含国籍）**：逐个确认 ① 形象原型（见第三节造型菜单：整洁书呆型/邋遢慵懒型/自信浮夸型/毒舌酷姐…）② **国籍/族裔**（如美国、亚裔/华裔、日裔、韩裔、拉丁裔、非裔、欧洲…，**开放选择，亚裔同样适用**）。可一题一角色或合并成一轮。

**再定角色来源（二选一）：**

- ① 用户**自行上传照片** → 直接绑定到对应 {{Mixed N}}，**跳过三视图生成**、以上传图为准。
- ② 没有图 → 按下面模板生成三视图设定图再绑定（把上面选的形象+国籍写进外观描述）。

**然后落到 token 与参考图：**

- 每个角色一个 token：`{{Mixed 1}}`（混乱制造者）、`{{Mixed 2}}`（正常人/捧哏）…。首现写全外观（含国籍/族裔特征 + 制服化标志装），之后只用 token、只写动作/表情；互动写清主宾。
- **（无上传时）给每个角色出一张三视图角色设定图**（版式：**左侧一张大头正脸特写，右侧并排全身正面 + 全身背面**，统一造型、纯净浅色背景），用作 Seedance 的 {{Mixed N}} 绑定参考图——这样多镜头里人物才稳定一致。三视图按**本风格的高调平光、明亮干净电视质感**渲染（不是日剧暖调胶片），模板与范例见第三节「三视图参考图」。原型菜单见第三节。
- **再出一张固定主场景的场景图**（无人定场全景 establishing shot，正面镜框、高调平光），用作 Seedance 的场景/背景绑定参考，保证多镜头里**同一套布景一致**。场景菜单与模板见第三节「场景图参考」。

### Step 3 · 设计段子

按「剧情内容」框架（第四节）：三拍落到多个编号镜头，从四类引擎选一个，套「混乱制造者 + 正常人」二人组。

### Step 4 · 套画面与声音元素

按框架（第三节）补全：明亮高调平光、几乎无阴影 + 暖调轻微高饱和的电视质感 + 固定主场景正面镜框 + 制服化造型 + 多机位中宽景、在说话/反应间切 + 收尾的罐头笑声拍子。

### Step 5 · 按 Seedance 2.0 格式输出

按第五节格式：中文风格锁定句 + 全局设定 → 「严格按 \[N\] 个镜头顺序：」编号分镜（景别，含 {{Mixed N}}，用 `【切】` 切反应）→ 中文收尾句。**prompt 用中文写（你能直接看懂）；台词按所选语言保留原文；明确"无字幕或屏幕文字"，字幕绝不进生成**。字幕另列「字幕清单」附后（Step 7 烧录）。prompt 包在代码块里。**时长 &gt;15s 时按 15s 分段，每段各出一条 prompt（段1/段2… 各一个代码块）+ 对应字幕清单**，共用角色/场景绑定与风格锁定句，**每段自成一个笑点、各自落 punchline**。

### Step 6 · 确认后上 平台画布生成

prompt（中文）出来后，**先让用户看懂内容，再问 OK 不 OK**：

- 不 OK → 按反馈改（换台词/引擎/造型/语言等），再给一版。
- OK → 在 **平台画布**上生成（每段带绑定的角色三视图/上传图 + 场景图），**按 Step 1 所选节奏**：一次性生成全部段 / 逐段确认（每段满意再生下一段）；最后按顺序剪辑衔接。

### Step 7 · 生成后加字幕（成片必备，字幕只在这一步出现）

平台出片（无任何字幕/屏幕文字）后，**成片必须带字幕**——在剪辑里按所选**字幕语言（中/英/双语）烧录，这是唯一**出字幕的环节、不省略：

- 用 Step 5 附的**字幕清单**逐句上字，按每镜台词的时间轴，在**底部居中**打上**白字、细黑描边**的电视字幕。双语＝上中下英，且**英文行明显小于中文行**（中文为主、英文为辅）。
- 文案按喜剧语感微调，落点那句务必在所选语言里都好笑。
- 生成阶段已禁字（`No subtitles or on-screen text`），所以画面干净，直接上剪辑版字幕即可。
- 同时可在这一步叠上标准罐头笑声/起哄声，让节奏更稳（见第三节「声音音效」）。

## 三、画面与声音元素细化（含 {{Mixed N}}、三视图、原型菜单）

始终守住：明亮高调平光、几乎无阴影、暖调轻微高饱和的电视质感、多机位中宽景。

### {{Mixed N}} 角色锚点

- 一个角色一个 token（`{{Mixed 1}}`、`{{Mixed 2}}`），绑定参考图保持一致。
- 首次出现写**全外观**（发型 + 制服化标志装 + 配饰）；之后只用 token、只写动作/表情。
- 互动写清主宾：`{{Mixed 1}} proudly announces the news to {{Mixed 2}}`。

### 三视图参考图（{{Mixed N}} 绑定用）

定完角色，先给每个 {{Mixed N}} 出一张三视图设定图，作为 Seedance 绑定的参考图，保证多镜头里人物不跑脸。**版式固定**：左侧一张大头正脸特写，右侧并排全身正面 + 全身背面。**按本风格渲染**（高调平光、明亮干净电视质感），不要日剧暖调胶片，否则会把色调带进成片。

模板（EN，单角色单图）：

```
Character reference sheet of one single character on a clean light seamless background, composed
as three panels: a large close-up head-and-shoulders portrait on the LEFT, then a full-body front
view and a full-body back view side by side on the RIGHT. Same outfit, same proportions, neutral
standing pose, gentle natural expression. [外观：国籍/族裔 + 发型发色 + 制服化标志装 + 配饰]. Bright high-key
even lighting with minimal shadows, clean glossy television look, consistent character design,
no props.
```

模板（ZH）：

```
单个角色的角色设定图，纯净浅色无缝背景，三栏构图：左侧一张大的头肩特写正脸，右侧并排
全身正面 + 全身背面。同一套服装、同样身材比例、自然站姿、柔和自然表情。[外观：国籍/族裔 + 发型发色 +
制服化标志装 + 配饰]。明亮高调均匀布光、阴影极弱，干净有光泽的电视质感，角色设定一致，无道具。
```

要点：版式＝左大头正脸 + 右全身正背；一张图只放一个角色（二人组分开出、防混脸）；外观描述跟 prompt 里 {{Mixed N}} 首现的写法**逐字保持一致**；出图工具 GPT Image-2 / Midjourney 均可，拿到后绑定到对应 token。

### 场景图参考（固定主场景绑定用）

角色定完，给**固定主场景**出一张场景图作为背景绑定参考，保证多镜头布景不变。默认**无人定场全景**（干净背景板便于复用），需要时也可放 {{Mixed N}} 出带人的定场帧。场景内容从下文「场景布置」菜单取（客厅 / 吧台 / 餐桌 / 办公室），渲染按本风格：正面镜框、高调平光、暖调电视质感。**画幅须与 Step 1 投放场景一致**（竖屏 9:16 / 横屏 16:9 / 方形 1:1），否则绑定后构图会错。

模板（EN，末尾按需加 `vertical 9:16 / 16:9 / 1:1 aspect ratio`）：

```
Establishing wide shot of a classic multi-camera American sitcom set: [场景，如 a cozy lived-in
apartment living room with a big couch, warm lamps, a cluttered coffee table and a small kitchenette
in the back], no people. Frontal proscenium staging, bright high-key three-point lighting, soft even
illumination with minimal shadows, warm slightly-saturated colors, clean glossy television look,
[vertical 9:16 / 16:9 / 1:1] aspect ratio.
```

模板（ZH）：

```
经典美式多机位情景喜剧布景的全景定场镜头：[场景，如 温馨有生活感的公寓客厅，大沙发、暖色台灯、
杂物茶几，后景小厨房]，画面无人。正面镜框式舞台调度，明亮高调三点布光、柔和均匀、阴影极弱，
暖调轻微高饱和，干净有光泽的电视质感，[竖屏 9:16 / 横屏 16:9 / 方形 1:1] 画幅。
```

要点：默认无人、正面镜框、和成片同一画风（高调平光暖调）**同一画幅**；一个段子一张主场景图；场景描述跟成片 prompt 的全局设定**逐字一致**；拿到后作为场景参考绑定。

### 色彩与质感

- 明亮、偏暖、轻微高饱和；干净有光泽的电视质感，不写实。
- 生成词：`bright high-key, warm slightly-saturated colors, clean glossy television look`。
- 避免：电影级低调暗部、纪录片去饱和发青、胶片颗粒（那是别的风格）。

### 光线和氛围（固定原则：高调平光、几乎无阴影）

- 三点均匀布光 `high-key three-point lighting`、低反差 `soft even illumination`。
- `minimal shadows / everything clearly visible`——为多机位任意角度服务，不藏暗部。
- 整体明亮、暖、安全轻松，**不**做戏剧性明暗对比。

### 场景布置（固定主场景、正面镜框）

- 客厅：大沙发、暖色台灯、杂物茶几、可见家居细节（lived-in）。
- 吧台 / 咖啡馆：固定吧台、卡座、霓虹招牌、常客位。
- 餐桌 / 厨房：餐桌、开放式厨房、端菜动线。
- 办公室（棚拍版）：会议桌、隔间、休息区——**注意**保持高调平光，别滑进伪纪录片荧光冷光。
- 一律 `frontal proscenium staging`、`shot on a studio set`，场景反复出现、观众熟悉。
- **背景群演**（增强美剧现场感）：酒吧客人/办公室同事/餐厅食客等，只做**低调环境活动**（喝酒、打字、走过），**不与主角互动、不看镜头、不抢戏、动作幅度小**，避免干扰"说话↔反应"切镜（英文写法见骨架可选项）。

### 人物造型（制服化、一眼看性格）

配「混乱制造者 + 正常人」二人组时，挑两个反差大的：

类型 造型要点（标志装，几乎不换） 整洁书呆型 整齐开衫/格纹衫、眼镜、规矩发型，认真拘谨 邋遢慵懒型 oversized 卫衣、乱发髻、拖鞋，deadpan 自信浮夸型 亮色衬衫、夸张配饰、油头，姿态张扬 朴素老好人 家常 T 恤牛仔裤、亲切日常 职场拘谨型 西装/职业套装、公文包，神情紧绷 戏精时髦型 浮夸时装、墨镜，时刻在演 怪咖宅男 印花卡通 T、运动外套，沉迷自己的世界 毒舌酷姐 利落穿搭、抱臂，随时准备吐槽

- 标志装意义：瞬间可读 + 强化原型，所以同一角色装扮基本不变。
- **国籍/族裔与形象原型是两回事**：原型（呆子/毒舌…）在这张菜单选，国籍/族裔（美国/亚裔/日裔/拉丁裔…）在 Step 2 单独问，两者组合写进角色外观。
- 肤质可省略或写 `natural healthy skin under bright studio light`，不追求 porcelain 磨皮。

### 镜头语言

- 机位：**多机位中景与宽景为主** `medium and wide shots`、稳定 `stable framing`、正面观众视角；无炫酷运镜、无手持、无急推。
- 切镜：靠剪辑在「说话的人 ↔ 反应的人」之间切——`Cut to Medium Shot` / `Cut to Reaction Close-up` / `Static Two-Shot`。

### 声音音效（这类剧的身份标识）

- **现场观众/罐头笑声**：落点处必到，提示何时笑、定节奏。
- **紧跟不拖**：punchline 一落笑声几乎立刻起（和反应几乎同拍），只留极短一拍，别磨蹭太久才响（拖久冷场）。
- **停顿写进表演**：说完梗 → 极短一拍 → 笑声立刻 → 收尾。
- 起哄声：接吻、反转、暧昧时刻。
- Seedance 声画同出但笑声"干净度"不稳；标准罐头笑声/起哄声更稳妥在剪辑时叠加。

## 四、剧情内容细化（一梗到底）

笑点在落差与时机，不在堆料、不在故事。**每个 15s 段只承载一个梗**，用不上单集骨架（冷开场/A线B线/片尾 tag 全不需要）。先想清「正常人为什么会做出这个反应」，再写镜头。**每 15s 一个完整笑点**、三拍打完就落 punchline + 笑声，节奏要紧（拖长会尴尬）；30s/60s＝同一对角色同一场景连着抖 2/4 个小段子，每段各自落一次。

### 三拍结构（落到多个编号镜头）

```
铺垫  约前 1/3：建立一个正常处境，一两句话/一个动作交代清楚（中宽景，正常表演）
转    中间：一句离谱台词 / 一个误会 / 一下升级（切到说话/出事的人）
落    最后 1/3：punchline，切回正常人的反应 + 一拍停顿 + 罐头笑声
```

> 黄金法则：铺垫越正常 + 转得越离谱 + 反应越克制 = 越好笑。落点几乎都在「正常人的脸」上，而不是混乱本身。

### 故事结构

- 极简，一条短片只承载一个笑点。
- 母版：「正常人和混乱制造者在某个熟悉场景里，发生一次错位。」

### 四类笑点引擎（挑一个）

- **升级 escalation**——小事突然失控。例：「我只是稍微动了一下」→ 镜头摇到一片狼藉。
- **误会 misunderstanding**——两人信息不对称、各说各的。例：A 宣布好消息，B 完全听成坏事。
- **反高潮 anticlimax**——铺得很隆重、一下戳破。例：庄严端出"大餐" → 是焦黑一坨 → 全桌沉默。
- **cringe**——说错话后的死亡沉默。例：A 想夸 B → 越夸越错 → 没人接话。

> 收尾手法：切到捧哏（正常人）的反应 + 停顿 + 罐头笑声。**不要**用对镜头一瞥/对镜头 deadpan（那是伪纪录片）；可用反应停顿，少用定格。

### 人物关系

- 压到**两人**：一个**混乱制造者**（说/做离谱事）+ 一个**正常人/捧哏**（负责反应）。
- 笑点几乎都长在「正常人怎么反应」上。
- 长期关系底色可借（找到的家人 / 暧昧拉扯 / 上司×下属），但一条短片只演**这一对的一次化学反应**，不铺关系线。

### 段子点子库（引导从零用户时直接抛/改）

按"场景 × 引擎"挑一条改成具体 premise（替换角色/台词即可）；没选场景就随机推一条。

**客厅沙发**

- 误会：A 兴奋宣布大好消息 →【切】B 完全误解成天塌了、抱枕痛哭 →【切回】A 笑容凝固成困惑 → 沉默 + 笑声。
- 升级：A 淡定说"我只是稍微整理了一下" →【切】镜头摇过去客厅一片狼藉 → B 表情凝固。

**吧台 / 咖啡馆**

- cringe：A 自信地对吧台另一头搭话 →【切】对方回一句让 A 社死的话 →【切回】A 僵在原地举着杯子 → 笑声。
- 反高潮：A 神秘兮兮说"我有个绝妙计划" →【切】下一拍计划当场翻车 → B 面无表情喝咖啡。

**餐桌 / 厨房**

- 反高潮：A 庄严揭开餐盖宣布"惊喜大餐" →【切】是焦黑一坨 →【切回】全桌死寂 → A 强行微笑 + 笑声。
- 误会：A 说"我做了你最爱吃的" →【切】端出 B 最讨厌的东西 → B 礼貌假笑逐渐崩塌。

**办公室（棚拍版，保持高调平光）**

- 升级：老板交代"就改一个小地方" →【切】下属理解成把整个项目推翻重做、抱来一摞文件 → 老板凝固。
- cringe：A 在会议上想拍马屁 →【切】把上司名字叫错 →【切回】满屋沉默 → A 想钻桌底 + 笑声。

变体钮：换场景、换二人组造型、换离谱台词、把单次错位升级成"误会套误会"（但仍是一个落点）。

## 五、Seedance 2.0 输出格式

最终交付 = **一条中文编号分镜式 prompt**（Seedance 支持中文，方便你看懂；**台词按所选语言保留原文**，说英文就写英文原句），包在可复制代码块。

### 标准骨架

生成 prompt 里**只写台词口型，绝不写任何字幕/屏幕文字**，并明确 `no subtitles or on-screen text`（防模型自己乱出字）。字幕另列清单，成片后在 Step 7 烧录。

```
[风格锁定句]。[全局设定：固定主场景 + 高调平光几乎无阴影 + 暖调电视质感 + 画幅（竖屏9:16/横屏16:9/方形1:1，按 Step 1）]。台词说[中文/英文]，画面无任何字幕或屏幕文字。角色相对位置固定（谁左谁右、谁坐谁站），切镜绝不互换。[可选：背景几位低调群演各做各的，不与主角互动、不看镜头。]
严格按 [N] 个镜头顺序：
1. [景别]：[铺垫——正常处境，{{Mixed N}} 首现写全外观，定好相对位置如"在左/在右"]。{{Mixed 1}} 说[所选语言]台词："[台词原文]"。
2. 【切】[景别]：[转]。{{Mixed 2}} 说[所选语言]台词："[台词原文]"。
3. 【切】反应特写：[正常人的反应放大]。
4. 静止双人镜头：[反应定格极短一拍，紧接现场观众笑声立刻涌起（别拖）]。
[收尾句：表演自然、节奏精准；无字幕或屏幕文字；多机位稳定构图。]
```

另附**字幕清单（后期烧录用，不进 prompt）**，默认双语上中下英：

```
字幕清单（双语，上中下英）：
1. [中文] / [EN line]
2. [中文] / [EN line]
...
```

要点：

- 编号镜头，每镜以景别开头；机位以**中景/宽景**为主，稳定、正面。**每 15s 一段、每段 ≈3-4 镜**；30s=2段、60s=4段，各一条 prompt（见 Step 1）。
- 用 `【切】` 切镜，核心节奏是**说话的人 ↔ 反应的人**之间切。
- **位置锁定**：一个段子里角色相对位置（谁左谁右、谁坐谁站）从头固定，切镜绝不互换（多机位来回切最易穿帮）；首镜写死"{{Mixed 1}} 在左、{{Mixed 2}} 在右，全程不变"。
- 角色用 `{{Mixed N}}`，首现写全外观，之后只写动作/表情。
- **台词写进 prompt 且按所选语言保留原文；字幕不进 prompt**（明确"无字幕或屏幕文字"），字幕另列清单、成片后烧录。
- 全局必带：风格锁定句、高调平光、**画幅**、"无字幕或屏幕文字"、收尾句、落点"轻微现场观众笑声"带节奏。

### 词汇（中文，括号附英文备用）

- 景别：定场全景 · 双人中景 · 中景 · 反应特写 · 静止大远景。
- 切镜：`【切】`（切至反应特写 / 静止双人镜头）。
- 表演：得意宣布 · 会错意 · 表情僵住 · deadpan 呆脸 · 强行假笑 · 停顿一拍。
- **禁用**（属伪纪录片）：对镜头一瞥、手持、急推 snap zoom、采访镜头。

### {{Mixed N}} 规则

一角色一 token，整条一致；互动写清主宾；二人组用 `{{Mixed 1}}`（混乱制造者）+ `{{Mixed 2}}`（正常人/捧哏）。

### 声音（罐头笑声是这类剧的标志）

- **笑声紧跟 punchline，不拖延**：落点一到、笑声几乎立刻起（和反应几乎同拍），只留极短一拍停顿，别等演员反应磨蹭半天才响——拖久就冷场。prompt 写"punchline 落下瞬间、现场观众笑声立刻涌起"。
- 起哄声（反转/暧昧时刻）；Seedance 笑声"干净度"不稳，prompt 带拍子即可，标准笑声/起哄声剪辑时叠加。

### 台词与字幕（语言可选；字幕一律后期）

默认**英文台词 + 双语字幕（上中下英）**。**字幕绝不在生成阶段出现，全部等成片后剪辑烧录（Step 7）。**

- **台词语言（中 / 英）**——决定口型/语音；**即使 prompt 是中文，台词也按所选语言保留原文**（说英文就在引号里写英文原句）。写"{{Mixed 1}} 说英文台词：…" 或 "说中文台词：…"。
- **生成 prompt 里明确"无字幕或屏幕文字"**——主动禁止模型出任何字（防乱码/缺字/糊字）。
- **字幕语言（中/英/双语，默认双语上中下英）**——只影响**后期字幕清单**（逐句、附在 prompt 后、供 Step 7 烧录），不进 prompt。
- 翻译不必逐字直译，按喜剧语感意译，落点那句务必在所选语言里都好笑。
- 后期字幕样式（Step 7）：底部居中、白字、细黑描边、电视字幕感；双语＝上中下英，**英文比中文小一号**（中文主、英文辅）。

### 绑定与旁白

- **固定图生视频**：带上三视图 + 场景图绑定，**prompt 侧重运镜/走位/动作/台词/切镜**，外观布景交给参考图（全局设定与场景图逐字一致）。
- **旁白**：默认关。开了才加画外音（也算台词、字幕后期）。

### 锁定风格块（中文，生成时原样用作风格锁定句）

```
经典美式多机位情景喜剧风格，在现场观众前的摄影棚布景内拍摄。明亮高调三点布光，
柔和均匀、阴影极弱，暖调、轻微高饱和，干净有光泽的电视质感，全场清晰可见。
多机位中景与宽景稳定覆盖，正面镜框式舞台调度。落点处带轻微现场观众笑声。
```

## 六、反推参考视频（抽帧脚本）

入口 C 用：先抽帧看清三拍与切镜，再写同款 prompt——不要凭空描述没看过的画面。把下面脚本存成 `extract_frames.sh` 运行，用法 `./extract_frames.sh <video> [outdir]`。它会读规格、按节奏抽帧、拼 contact sheet，并提示判断：① 三拍（铺垫/转/反应+笑声）② 切镜在「说话 ↔ 反应」之间怎么切、景别多大 ③ 画风是否高调平光暖调几乎无阴影、固定主场景（确认是棚拍情景喜剧而非伪纪录片）④ 二人组谁是混乱制造者、谁是正常人、造型标志。

```bash
#!/usr/bin/env bash
# 反推参考视频用：读规格 + 抽帧 + 拼接成 contact sheet，看清三拍与切镜节奏。
# 用法: ./extract_frames.sh <video> [outdir]
set -euo pipefail

VIDEO="${1:?用法: extract_frames.sh <video> [outdir]}"
OUT="${2:-./refframes}"
mkdir -p "$OUT"

echo "=== 规格 ==="
ffprobe -v error -show_entries format=duration,size,bit_rate \
  -show_entries stream=codec_type,codec_name,width,height,r_frame_rate \
  -of default=noprint_wrappers=0 "$VIDEO"

DUR=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$VIDEO" | cut -d. -f1)
echo "=== 时长约 ${DUR}s，按节奏抽帧 ==="

# 短片每 1.5s 一帧；过长则每 2.5s 一帧
if [ "${DUR:-0}" -le 35 ]; then RATE="1/1.5"; else RATE="1/2.5"; fi
ffmpeg -v error -i "$VIDEO" -vf "fps=${RATE}" "$OUT/f_%03d.jpg"

# 拼接 contact sheet 便于一眼看全片节奏与切镜
if command -v montage >/dev/null 2>&1; then
  N=$(ls "$OUT"/f_*.jpg | wc -l)
  COLS=5; ROWS=$(( (N + COLS - 1) / COLS ))
  montage "$OUT"/f_*.jpg -tile "${COLS}x${ROWS}" -geometry 320x180+2+2 \
    -background black "$OUT/contact.jpg"
  echo "contact sheet: $OUT/contact.jpg"
fi

echo "完成，查看 contact.jpg 判断三拍/切镜/画风/二人组（见上文）。"
echo "定位精确帧: ffmpeg -ss <start> -i <video> -t <len> -vf fps=4 ..."
```

## 七、通用约束

- **前期全部配置在 Step 1 敲定**（目的+投放场景/画幅、时长、笑点引擎、台词语言、字幕语言、旁白、分段节奏），再进 Step 2 出角色/场景；压成 2 轮点选、不连环追问。
- **画幅由投放场景定**（竖屏 9:16 / 横屏 16:9 / 方形 1:1）；三视图（版式固定）、场景图、成片 prompt 统一同一画幅。
- 一条 prompt 用一种主语言整条交付，需要时附镜像；包在可复制代码块。
- 角色：**先问数量**（建议 2 人）**再问每个的形象 + 国籍/族裔**（开放，含亚裔）；用 {{Mixed N}}，首现写全（含国籍/族裔 + 制服化标志装）、后续复用、互动主宾清晰；角色图可**用户上传照片**或生成三视图，二选一后绑定；每个段子先出固定主场景的场景图绑定。
- 多机位中宽景、稳定；切「说话 ↔ 反应」；**角色相对位置锁定不互换**；**不用**对镜头一瞥/手持/急推/采访。
- **每 15s 一个完整笑点**、三拍、收尾落反应 + 笑声，节奏紧凑；30s/60s＝连着抖 2/4 个小段子，每段各落一次。
- **prompt 用中文写**（台词按所选语言保留原文）；**字幕绝不在生成阶段出现**——prompt 明确"无字幕或屏幕文字"，字幕单列清单、仅成片后剪辑烧录。
- 确认 OK 后才上 **平台画布**生成（带绑定的角色/场景图）；背景可加低调群演（不互动/不看镜头/不抢戏）。
- 常配「混乱制造者 + 正常人」二人组。
- 不做涉及真实公众人物的内容；保持适当无害。
