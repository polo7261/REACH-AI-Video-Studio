# 微表情與情緒表演框架（去 AI 味）

一套約束 Agent 如何在任何含人物的圖片/影片提示詞中書寫表演的底層框架。它不產出內容本身，而是疊加在任意人物生成任務之上的寫作準則：換任何人物、任何鏡頭、任何故事、任何臺詞數量（零句到多句）都直接套用。

## 何時使用

- 生成任何含人物的圖片或影片提示詞，且希望表演像真人、沒有 AI 味。
- 使用者已給出人物設定、場景、劇情或臺詞，需要把它們落成可執行的表演描寫。
- 需要把一段劇情拆成有時間刻度的分鏡指令碼。

## 核心原則（七條，缺一不可）

### 一、拒絕靜態形容詞，用「動作」替代「狀態」（肌肉解構）

禁止在提示詞裡直接書寫情緒名詞（傷心、震驚、失望、決絕、溫柔、茫然……）。情緒只能以肌肉的即時運動出現，並寫成有先後次序的解剖清單。

- 每個情緒節拍拆成 2–4 個具體部位的獨立動作，按先後順序排列。
- 動詞優先：聚攏、翕動、隆起、垂合、顫動、收緊、滑落、別至耳後、抬升、舒展、內收。
- 不用狀態詞：悲傷的、茫然的、失落的、決絕的。
- 情緒收尾必須寫「回落 / 歸零」動作，而不是停在最強點。

句式模板：

> 「〔部位 A〕〔動作〕，〔部位 B〕〔動作〕，〔部位 C〕緩緩〔回落動作〕」

反例 → 正例：

> ✗ 她露出傷心的表情 ✓ 眉頭內側向中間輕收，下唇出現極細微顫抖，隨後眉心緩緩舒展

### 二、命令矛盾與不完整，打破對稱性

真實情緒從不純粹也從不完整。AI 感主要來自過度對稱與過度完成。三種手法至少各用一次：

1. **單側化**：只允許一側部位運動，並顯式禁止另一側與其餘區域參與。

   > 「只〔單側部位〕〔動作〕，〔對側部位〕與面部其餘區域完全靜止」

2. **未完成**：動作做到一半就停。

   > 「只有半弧」「未擴散至面部其他區域」「未抵達眼底」「話被咽回」

3. **對沖共存**：在同一時刻或指定極短間隔內疊加兩種相反狀態，並顯式標註是「同時發生」還是「若干秒內相繼轉換」。

   > 「〔狀態 A〕的同時，〔狀態 B〕，二者同時發生」／「〔狀態 A〕在 0.5 秒內轉為〔狀態 B〕」

### 三、量化生理指標，用數字殺死模糊

所有程度副詞（微微、輕輕、幾不可察、略微）必須換算成數字：

維度單位與寫法位移毫米 / 釐米（如「內收 2–3 釐米」）角度度（如「幅度不超過 15 度」「下沉半度」）時長秒（如「約 1 秒後鬆開」「持續 0.2 秒」）頻率每 N 秒一次（如「眨眼每 3–4 秒一次」）速度先快後慢 / 在第 N 度突然減速

數字要逼近生理真實尺度：1 毫米級顫抖、0.2 秒卡頓、半度下沉。

同時量化「不該出現的東西」——把負向約束也寫成可檢驗的指標：眉間距離保持不變、眼周膚色不發紅、液體不溢位邊界、不出現豎紋。

### 四、強調剋制與中斷，製造失序感

不寫情緒的全額釋放，寫它的壓抑與半途而廢。

- 動作結構：啟動 → 減速 → 停止。
- 湧上來的東西被強行鎖回；想做的動作在最後一刻收回。
- 每個高強度情緒都必須配一個「抑制動作」和一個「恢復鬆弛」的時間點。

句式模板：

> 「〔動作〕啟動後在第〔N〕度突然減速停止」／「〔生理反應〕被強行鎖住，〔部位〕緊繃顫動」

### 五、層級遞進 + 時間軸

情緒不是一次到位，而是分階段遞進的鏈條（如：錯愕 → 傷心 → 失望 → 決絕 → 釋然）。每個階段繫結明確的時間區間，區間內再排布微動作的先後。整段表演是一條有時間刻度的樂譜，不是一張靜態快照。

- 情緒鏈至少 2 個階段，禁止單點爆發。
- 每個階段寫明起止秒數，階段內部按先後順序排列微動作。

### 六、臺詞是微表情的觸發器

- 每條臺詞拆到詞級 / 音節級，標註說出哪個字時眼神、瞳孔、肌肉發生什麼變化。
- 說完之後必須有餘韻（合唇、搖頭、呼氣、目光滑落）。
- 臺詞之間的沉默也要寫內容：呼吸、空氣凝固感、微小動作。不允許出現「空轉」時間。
- 若全片無臺詞，則整段表演由事件與生理動作驅動，此條轉化為「每個時間區間都必須有可見的生理動作」。

### 七、全域性約束層 + 鏡頭匹配

在提示詞中單獨設一段全程有效的「防 AI 味」硬約束（見下方結構骨架第 3 段），必須包含：

- 全程放鬆的部位清單
- 幅度上限、持續時間上限
- 復位要求（動作後回到鬆弛狀態）
- 禁止清單（哭戲式表情、皺眉、八字眉、表情扭曲、多部位同時大幅運動等）

並讓鏡頭服務於表演：

- 景別與焦點要能承載毫米級微動作（淺景深、焦點死鎖面部）。
- 鏡頭運動剋制，避免用大動態運鏡抵消微表情。
- 機位與前景設計不得遮擋面部微動作。

## 提示詞結構骨架（輸出模板）

按以下五段組織，順序固定：

1. **人物與基礎設定**——外觀錨定 + 真實膚質要求（毛孔、紋理，不做柔光修飾）。
2. **氛圍與畫質**——光影、色調、質感基調（膠片顆粒、灰階過渡、空氣感）。
3. **表演基調**——全域性微表情硬約束 + 禁止清單（原則七的落地段）。
4. **運鏡規則**——景別、焦點、鏡頭數量、機位、是否一鏡到底。
5. **分鏡指令碼與時間線**——按秒分段，每段 = 事件 + 肌肉級微表情鏈 + 臺詞與觸發 + 回落。

第 5 段每段的內部寫法：

```
▶ 〔起-止〕秒 · 〔段落名〕
〔事件：發生了什麼，含環境與光位〕
〔微表情鏈：≥2 個部位的先後動作，全部量化〕
〔臺詞與觸發：逐詞標註觸發點；無臺詞則寫沉默區間的生理內容〕
〔回落：動作如何歸零、何時恢復鬆弛〕
```

## 落稿自檢清單

落稿前逐條核對，任一條不透過就回去改：

- \[ \] 是否還殘留任何情緒名詞？
- \[ \] 每個情緒是否拆成了 ≥2 個部位的順序動作？
- \[ \] 是否所有程度詞都換成了數字？
- \[ \] 是否有至少一處單側化或未完成的中斷？
- \[ \] 是否有至少一處矛盾共存並標註了同時 / 相繼？
- \[ \] 高強度情緒是否配了抑制動作與復位時間？
- \[ \] 情緒是否有遞進而非單點爆發？
- \[ \] 臺詞是否拆到詞級並帶出說完後的餘韻？沉默區間是否也有內容？
- \[ \] 是否存在全域性約束段與禁止清單？
- \[ \] 景別與焦點能否承載所寫的最小動作尺度？

## 使用方式

1. 先按結構骨架第 1–4 段搭好人物、氛圍、表演基調、運鏡。
2. 把使用者給的劇情 / 臺詞按時間軸切段，逐段套用第 5 段模板。
3. 每段寫完後立刻對照自檢清單逐條核對。
4. 全篇寫完後，再整體檢查一次情緒鏈遞進與全域性約束是否貫穿全程。
