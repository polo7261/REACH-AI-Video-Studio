# 电影感旅拍大师

## Skill 定位

这是根目录主 Skill，只负责路由、分配、门禁，不承载全部创作细节。

执行时必须按这个顺序工作：

1. 先判断用户当前要解决哪一类问题。
2. 按“主路由表”读取一个或多个精确的子 Agent 文件；不要自行猜测文件名。
3. 子 Skill 再按它自己的“必读技能参考”读取精确的规则文件。
4. 产出后读取或使用 `agents/sub-agent-travel-quality-reviewer.md` 做质检。
5. 质检不通过时，回到本轮已经读取过的精确子 Agent 文件修订，最多循环 3 次。

不要只停留在主 Skill；凡是进入具体创作、资产、提示词或交付，都必须读取“主路由表”列出的精确子 Agent 文件。`subskills/` 里的文件是规则参考，不是子 Agent 入口；除非子 Agent 点名某个精确文件，不要直接把 guide 文件当入口。

## 输入

用户可能提供：

- 目的地、旅行主题、短片用途、视频比例、视频时长、平台。
- 人物参考图、角色图、三视图、半身照。
- 真实场景参考图、场景资产需求、道具资产需求。
- 故事、散文、旅行笔记、原著片段、旁白文案。
- 想使用的视频生成模型、BGM 生成模型、配音生成模型、分辨率、视频提示词需求。
- 封面、标题、金句、平台宣发需求。

硬性规则必须保留并传递给所有子 Skill。

## 主路由

按用户最新消息选择一个或多个子 Skill。每次路由时，只能读取下表中的精确文件名，并把用户需求、已有素材、硬性规则和当前阶段一起传给该文件。

用户意图必须先读取的子 Skill 文件完整旅拍、从主题一路做成片、项目推进`agents/sub-agent-travel-production-controller.md`故事、散文、旅行笔记、原著片段、旁白、剧本改编`agents/sub-agent-story-script-director.md`人物图、角色资产、三视图、半身、人物一致`agents/sub-agent-character-asset-director.md`Seedance、Seedance2.0、fast、mini、15 秒视频提示词`agents/sub-agent-seedance-prompt-engineer.md`检查、自检、是否合格、不满意、重新生成、评估资产或提示词`agents/sub-agent-travel-quality-reviewer.md`封面、标题、宣发、小红书、抖音、视频号、交付`agents/sub-agent-travel-delivery-archivist.md`

### 1. 完整旅拍流程

当用户要“从主题一路做成片 / 完整旅拍 / 旅行大片 / 旅拍流程 / 项目推进”时：

先读取 `agents/sub-agent-travel-production-controller.md`。

这个子 Skill 负责阶段规划、生成门禁、用户确认和省积分顺序。

### 2. 故事和剧本

当用户给出故事、散文、旅行笔记、原著片段、旁白文案，或要求“更有情绪 / 改成视频 / 忠实原文 / 不要魔改 / 转成剧本”时：

先读取 `agents/sub-agent-story-script-director.md`。

这个子 Skill 负责自由改编、忠实剧本化、旁白和情绪曲线。

### 3. 角色资产

当用户上传人物图，或提到“角色资产 / 三视图 / 半身 / 人物一致 / 角色连续性”时：

先读取 `agents/sub-agent-character-asset-director.md`。

这个子 Skill 负责判断用户图是否可直接作为角色资产；如果需要生成角色资产，必须使用固定角色资产提示词；资产生成后必须评估是否合格，不合格或有风险时先问用户是否重新生成。

### 4. Seedance2.0 系列提示词

当用户提到“Seedance / Seedance2.0 / fast / mini / 提示词 / 15秒 / 分镜提示词 / 视频生成提示词”时：

先读取 `agents/sub-agent-seedance-prompt-engineer.md`。

这个子 Skill 负责让用户选择 Seedance2.0 系列具体模型和分辨率，并按固定格式写完整提示词。

### 5. 质检和返工

当用户要求“检查 / 自检 / 是否合格 / 不满意 / 重新生成 / 评估资产 / 评估提示词”，或任一阶段产出完成后：

读取 `agents/sub-agent-travel-quality-reviewer.md`。

这个子 Skill 负责阶段质检、连续性检查、生成门禁和最多 3 次返工循环。

### 6. 封面、宣发和交付

当用户提到“封面 / 标题 / 小红书 / 抖音 / 视频号 / 宣发 / 交付 / 归档”时：

读取 `agents/sub-agent-travel-delivery-archivist.md`。

这个子 Skill 负责整理最终方案、提示词、封面标题、平台文案和交付清单。

## 执行顺序

如果多个阶段同时匹配，除非用户明确要求后置阶段，否则从最早缺失的前置阶段开始：

```text
需求简报
→ 故事/旁白/剧本
→ 角色资产判断或生成
→ 真实场景参考判断或场景图生成
→ 时间轴和素材单元规划
→ Seedance2.0 系列模型与分辨率选择
→ 视频提示词逐条生成
→ 质检
→ 用户确认后再生成图片或视频
→ 封面宣发
→ 交付
```

## 生成门禁

图片和视频会消耗积分。进入图片或视频生成前，必须满足：

- 已询问并确认视频比例；用户未选择时，默认 16:9。可选比例为 16:9、9:16、21:9、3:4、4:3、1:1。
- 已询问并确认视频时长。
- 已询问并确认视频生成调用模型。
- 剧本、旁白或视觉叙事已通过质检。
- 角色资产已判定可用；如果新生成了角色资产，已完成生成后评估。
- 涉及真实场景时，已询问用户是否上传场景参考图；如果用户不上传，必须先生成场景图并完成质量评估，不得直接进入视频生成。
- 场景图必须具备电影级灯光设计、丰富色彩、清楚光影层次、纯净稳定的画面质感；不合格时先返工或询问用户。
- 时间轴和每个素材单元功能已经清楚。
- 视频提示词已经按目标模型格式写完并通过自检。
- 视频素材生成时必须开启视频音频生成，让环境声、脚步、风声、水声、衣料摩擦等音效随画面一起生成；视频素材里仍然禁止生成 BGM。
- 合成视频之前必须已生成 BGM，并且已让用户手动选择 BGM 生成模型；不得默认模型直接生成。
- 如需旁白，必须先让用户选择配音生成模型，再完成音色设计提示词；音色提示词必须按“职业 + 人物特征 + 声音特征 + 语速”写得足够详细，让旁白有情绪起伏、停顿和语速变化。
- 用户已经确认继续生成，或用户当前请求明确就是生成。

角色资产不合格或有风险时，不要继续生成视频；先提醒用户具体问题，并询问是否重新生成或接受当前资产继续。

## 质检循环

每个阶段都执行：

```text
生产 → 质检 → 修订 → 再质检 → 通过 → 下一阶段
```

质检失败时返回本轮已读取的精确子 Agent 文件修订，最多循环 3 次。第 3 次仍不通过时，停止推进，向用户说明卡点、风险和需要确认的信息。

## 输出

根据当前阶段输出：

- 项目进度检测。
- 已读取并执行的子 Skill。
- 当前阶段产物。
- 质检结论。
- 下一步建议。
- 需要用户确认的问题。

## 自检

输出前检查：

- 是否已经读取主路由表中的精确子 Agent 文件，而不是只根据主 Skill 直接创作？
- 子 Skill 是否按“必读技能参考”读取了精确的规则文件？
- 是否先剧本和提示词，后图片和视频生成？
- 是否已经询问用户视频比例、视频时长、视频生成模型；视频比例未选时是否按 16:9 默认？
- 是否已经询问 BGM 生成模型，并在合成前生成 BGM？
- 需要旁白时，是否已经询问配音生成模型，并完成职业、人物特征、声音特征、语速组成的详细音色设计？
- 涉及真实场景时，是否已询问场景参考图；用户未提供时是否先生成并评估场景图？
- 视频素材生成时是否明确开启视频音频生成，并禁止在素材里生成 BGM？
- 是否把用户硬性规则传给后续子 Skill？
- 是否完成质检；不通过时是否最多循环 3 次？
- 涉及角色资产时，是否完成“可直接用 / 需生成 / 生成后合格性”的判断？
- 涉及 Seedance2.0 系列提示词时，是否让用户选择模型和分辨率？

## Ask User

以下情况必须问用户：

- 缺少会改变成片方向的目的地、人物、用途、是否旁白。
- 视频比例未选择时，询问用户在 16:9、9:16、21:9、3:4、4:3、1:1 中选择；用户不选时默认 16:9。
- 视频时长未选择时，必须询问。
- 视频生成模型未选择时，必须询问；如果是 Seedance2.0 系列，再让用户选择 Seedance2.0、Seedance2.0 fast、Seedance2.0 mini 或其他兼容模型。
- BGM 生成模型未选择时，必须询问；不能默认模型直接生成 BGM。
- 需要旁白但配音生成模型未选择时，必须询问；不能默认模型直接生成配音。
- 需要旁白时，必须先给出详细音色设计提示词，等待用户确认或调整后再生成。
- 涉及真实场景时，必须询问用户是否上传场景参考图；用户不上传时，先生成场景图并评估。
- 分辨率未选择时，可以说明将按 720p 继续。
- 角色资产生成后不合格或有风险，需要用户决定是否重新生成。
- 用户给的故事/原文不清楚是自由改编还是忠实剧本化。
