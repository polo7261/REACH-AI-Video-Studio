# city-memory-film

做小城/舊街區人文敘事短片時用本 skill。**核心不是記錄苦難或懷舊，而是透過具體人物在城市空間中的真實行為、細節物件的復現、以及場與場之間的因果痕跡，讓觀眾自己感受到變化**——靠觀察積累情感，而非戲劇對抗。結尾不宣判，給觀眾一個變化後的空間或動作，不給完整答案。

> 本環境適配：GPT Image / Image 2 → `generate_image_v3`；Happy Horse(FirstFrameToVideo) / Seedance 2.0(MultiModalToVideo) → `generate_video_v3`(以「首幀驅動 vs 多參考+高動態」表達兩條路線)；resource_prepare_and_analyze → agent 自做解析；text_editor → `write_file_v2`；video_assembler → `composite_video`；旁白/BGM → `generate_audio`；`@資產` → `reference_nodes`+`{{NodeKey}}`。**旁白方式二(用 Seedance 生成旁白影片後多模態拆音訊、作後續音色參考鏈)本環境無對應能力，正當刪除**——本環境保留"長旁白超過 15s 需分段生成"的方法本身，分段統一走 `generate_audio` 同引數生成，不做音色鏈提取。運鏡/寫實/寫提示詞工藝全部內聯本 skill，不依賴外部工藝 skill。

## 一、全片流程與階段依賴

1. **故事命題獲取（二選一）**：
   - **使用者已上傳劇本/文字素材**：agent 自行解析，提取人物關係、核心衝突、場景列表、關鍵事件節點、關鍵物件。輸出一句簡潔的故事命題摘要，請使用者確認後再進入步驟 2。**確認前不得進入步驟 2。**
   - **使用者未上傳素材**：以卡片引導方式收集：故事發生的地點與時段、主角面臨的核心困境或決定、另一個關鍵人物及其與主角的關係。資訊不足時預設：時長 1–3 分鐘、型別"短劇情片"。收集後輸出一句簡潔的故事命題供使用者確認。
2. 和使用者確認並建立 Final_Video\_[Spec.md](http://Spec.md)（片名、型別基調、場景設定、畫幅比例、目標時長、視覺風格、輸出語言）→ `write_file_v2`
3. 生成故事板（關鍵元素、鏡頭列表、音訊層）。故事板就緒後，掃描上下文中使用者提供或已生成的資產，繫結至對應故事板槽位，再進行生成步驟。
4. 設定元素：
   - 使用者已上傳元素資產（人物參考圖、場景參考圖）：註冊為錨點並繫結至對應關鍵元素。
   - 否則：為所有關鍵人物和場景元素生成影象 → `generate_image_v3`。
5. 為每個鏡頭生成首幀圖（start_frame）→ `generate_image_v3`
6. 按鏡頭型別分路生成影片：
   - **敘事鏡頭〔平敘〕（約 80%）**：首幀驅動路線（Happy Horse 意圖）→ `generate_video_v3`，以對應鏡頭 start_frame 作為首幀輸入。
   - **高強度鏡頭〔動態〕（約 20%，不超過總鏡頭量 20%）**：多參考驅動路線（Seedance 2.0 意圖）→ `generate_video_v3`，引用對應元素圖作為 reference。
7. 生成 BGM / 旁白音效層 → `generate_audio`
   - 旁白：統一用 `generate_audio` 生成；若旁白超過 15s，拆成多個段落分別生成，保持同一角色引數一致（音色鏈提取本環境無對應能力，見上文適配說明）。
8. 完成全片時間線組裝，旁白按分段順序對齊至對應位置 → `composite_video`

**依賴順序**：2→1；3→2；4→3；5→3,4；6→3,5；7→3；8→6,7\
**暫停節點**：不得一次性跑完全部流程。在命題確認、故事板完成、元素圖/首幀圖完成、影片批次完成、音訊生成後各暫停，等待使用者確認再繼續。\
**使用者提供媒體時**：優先將其繫結至故事板對應槽位；不重複生成使用者已提供的內容。

### 建立 Final_Video\_[Spec.md](http://Spec.md) 的指南

- 片名調性：貼合故事型別與情緒，不做過度文藝化或商業化傾向。
- 畫幅比例：推薦 16:9；強調壓迫感或親密感時可選 4:3 或 2.35:1。
- 視覺風格：與故事型別匹配，可以是寫實、輕風格化或型別片視覺；**不強制低飽和**。

## 二、劇本解析規則

在使用者上傳了劇本檔案或文字素材時，解析上傳的檔案（圖片/PDF/文字，本環境按 agent 讀檔案能力處理），提取：人物關係（主角 + 親密但疏離的人 + 帶來變化的人）、空間列表、生活流事件鏈（5–8 個日常事件）、關鍵物件、關鍵動作與臺詞節點。輸出一句簡潔的故事命題摘要，以及結構化關鍵資訊，供 Final_Video_Spec 和分鏡設計使用。**不做年代判斷或價值定性。** 檔案無法解析或內容不完整時，向使用者說明並請求補充。

## 三、分鏡設計（storyboard 核心工藝）

### 3.1 核心氣質

- 強調人和人、人和環境的關係。場景並不是單純的背景板，而是角色之一：場景也是敘事表達的一部分。
- 戲劇衝突要低聲：少用爆發式爭吵，多用沉默、等待、繞路、沒說出口的話、突然中斷的日常。
- 情節像偶然發生的，要落在具體生活動作裡。
- 結尾不宣判：給觀眾一個變化後的空間或動作，不給完整答案。

### 3.2 劇本故事性構建（六法，核心敘事工藝，一條不可少）

城市人文敘事片不依賴戲劇對抗，而是靠**觀察積累情感**——透過人物在城市空間中的真實行為、細節物件的復現、以及場與場之間的因果痕跡，讓觀眾自己感受到變化。

- **開場埋一條懸而未決的線**：不解釋，不總結——一個動作、一個物件、一個眼神，讓觀眾帶著問題往下看。
- **人物之間有歷史**：即便是陌生人的相遇，也要有一個隱含的"為什麼是這兩個人"的理由——地點、時間、一件舊物。
- **關鍵物件至少出現兩次**：第一次建立存在感，第二次狀態已經變了——位置變了、損壞了、被人拿走了。
- **場與場之間留痕跡**：前一場發生的事，後一場的空間或人物身上有跡可循，不做無因果的跳切。
- **至少安排一次"預期落空"**：人物去做一件事，結果和預想的不一樣——不是戲劇翻轉，而是生活本來就這樣。
- **結尾動作有雙重含義**：最後的動作或畫面，可以是離開，可以是停留，可以是什麼都沒做——但要讓這個選擇有重量。

### 3.3 人物設計原則

- 人物動機要小，人物尊嚴要大：小目標背後是面子、舊情、身份、親情或"我還算不算一個有用的人"等。
- 臺詞要像繞路：人物很少直接說真實需求，常說"沒事""路過""你忙你的""改天吧"。
- 情緒靠動作表達：抽菸、整理衣領、摸舊手機、反覆開關打火機、抹桌子、等水燒開、看別人付款。

### 3.4 場景選擇

- 空間選擇服務於當前劇情關係與人物狀態，不做硬性規定。
- 任何空間都必須攜帶社會資訊：標語、價目表、收款碼、舊海報、施工噪音、電視新聞、廣場舞音樂、方言廣播——這些細節是敘事的一部分，不是裝飾。

### 3.5 關鍵元素設計

- 優先設計**人物元素**（年齡、外貌、著裝、正在做的事）和**場景元素**（地理環境、時段、光線條件、社會資訊載體）。
- 道具元素只在對多個鏡頭一致性有實質影響時才單獨建立（如反覆出現的舊手機、車票、收款碼牌）。
- 使用者提供參考素材時，元素描述必須與參考內容一致，不得矛盾。

### 3.6 鏡頭時長與節奏分層

每段敘事由三種時長鏡頭混合搭建，節奏變化本身即是敘事訊號——慢下來代表時間在這裡凝結，快起來代表人物或空間正在運動：

鏡頭型別時長功能與使用時機短鏡頭2–3s關鍵物件插入、情緒反應切、城市細節捕捉；製造節奏跳動或強調感中鏡頭6–10s人物行為展開、日常互動、空間內的移動與停留；敘事主幹，佔全片約 60%長鏡頭11–15s開場空間建立、情緒沉澱時刻、結尾餘韻收束；每段敘事最多 1–2 個

### 3.7 每段敘事的節奏結構（五段）

- **開場建立段**：1 箇中鏡頭或長鏡頭落地城市空間與人物處境——可以從一個行為開始，不必解釋背景。
- **觀察展開段**：中鏡頭為主，展示人物在空間中的具體行為；每隔 2–3 箇中鏡頭插入 1 個短鏡頭（物件特寫或環境細節），打破視線節奏，積累資訊密度。
- **情感轉折段**：用 1 個長鏡頭或慢節奏中鏡頭拉住時間，讓人物的某個細微反應或選擇有足夠空間被看見。
- **動態節奏段〔動態〕**：人物穿越城市空間、趕路、尋找時，用連續中短鏡頭推進節奏；標記為〔動態〕，走多參考驅動路線生成。
- **結尾收束段**：最後 1–2 個鏡頭用中鏡頭或長鏡頭——給結果或情緒足夠時間停留，不以短切收尾。

### 3.8 全片節奏控制

- 鏡頭總數建議 10–16 個（1–3 分鐘片長）。
- 避免全片時長均勻——節奏的疏密本身在說話。開場可以慢，中段跟隨人物節奏起伏，結尾留白。

### 3.9 景別

- 開場建立城市空間與人物處境：中遠景或全景，讓空間先說話。
- 人物互動或獨處時：雙人中景或單人中景，眼神與肢體可讀。
- 情緒積累或轉折時：近景或特寫，捕捉細微表情與手部動作。
- 關鍵物件：插入鏡頭（cut-in），短促、明確（2–3s）。

### 3.10 機位與運動

- 常規觀察性敘事：固定機位為主，或輕微手持跟隨人物，優先讓人物行為和空間自然呈現。
- 〔動態〕場景（人物穿越街道、趕路、尋找）：跟拍或運動鏡頭，註明方向感和運動幅度。
- **禁止**：炫技運鏡、旋轉鏡頭、純裝飾性航拍、無敘事功能的慢動作、多切鏡等。

### 3.11 構圖

- 人物可偏在畫面邊緣，留出大量牆面、街道、門框、窗戶或空椅子。
- 用門框、玻璃、欄杆、車窗、櫃檯把人物分隔開。
- 新舊物件並置時不刻意強調對比，讓它們自然共存在同一畫面裡。
- **允許畫面"髒"**：雜物、灰塵、舊瓷磚、塑膠凳、電線、廣告紙不要被清理掉。

### 3.12 色調與光線

- 日景：灰白天空、低飽和水泥色、舊紅色標語、褪色藍綠店招、塵土黃。
- 夜景：鈉燈橙、KTV 霓虹粉紫、手機屏冷光、路邊攤熒光燈。
- 室內：日光燈偏綠、電視冷光、窗外灰光；不要高階影棚質感。
- 調色：低飽和、輕微顆粒、真實動態範圍，保留暗部雜色。

### 3.13 shot 描述規則

- **每個鏡頭描述必須包含 4 維**：Scene（引用場景元素 + 時段光線）、主體動作（肢體/神態為主）、攝影語言（景別 + 運鏡 + 焦點策略）、聲音感（環境聲/畫內聲）。
- **鏡頭標籤**：在鏡頭描述末尾註明生成路線標籤——平敘鏡頭標〔平敘〕，強動態/切鏡鏡頭標〔動態〕；〔動態〕鏡頭不超過總鏡頭量的 20%。

### 3.14 臺詞規則

- 每場最多 3–6 句臺詞；每句儘量短，允許方言詞但不要堆砌。
- 重要資訊不要說全，讓觀眾從動作和空間補齊。不寫旁白解釋主題。
- 可用句式："你回來也不說一聲。" / "路過。" / "現在都掃這個。" / "我沒有那個。" / "那算了。" / "你先忙。"

### 3.15 音訊層設計

- BGM（可選）：若使用，選擇極簡器樂或無調性環境音景；禁止流行音樂節奏。
- 不以對白驅動敘事。

### 3.16 質檢清單（輸出前自檢）

- 是否至少 60% 鏡頭是中遠景、固定機位或緩慢運動？
- 是否有 2 個以上公共空間？
- 是否有畫內聲音而不是外加煽情配樂？
- 是否刪除了"他終於明白了""這是命運的安排"等直白總結句？
- 是否避免直接複用任何現成電影的角色、臺詞、場面和劇情？

### 3.17 禁止事項

- 不要把故事寫成苦難堆砌或價值宣判；人物要有幽默、虛榮、笨拙、體面和生活慣性。
- 不要用旁白解釋主題或時代意義。
- 不要讓每場戲都承擔劇情功能；允許無用的等待和偶然的路人，但它們必須增加空間真實感。
- 不要過度詩化世界。美感來自觀察，不來自金句和濾鏡。

## 四、素材生成策略（80/20 雙路，media 適配 13 工具）

### 4.1 元素圖生成

- `generate_image_v3`，2K。
- 若使用者已上傳參考圖（人物 / 場景），將其註冊為錨點並繫結至對應故事板元素槽位，優先用於替代生成。

### 4.2 首幀圖生成（每個鏡頭的 start_frame）

- `generate_image_v3`，2K。
- 首幀圖須與故事板鏡頭描述的景別、光線、主體姿態嚴格一致，作為影片生成的視覺錨點。

### 4.3 鏡頭影片生成（按路線分流）

- **平敘鏡頭〔平敘〕（約 80%）**：首幀驅動路線，以對應鏡頭 start_frame 作為首幀輸入，`generate_video_v3`。
- **動態鏡頭〔動態〕（不超過總鏡頭量 20%）**：多參考驅動路線，`generate_video_v3`；引用該鏡頭涉及的角色/場景元素圖作為參考，同時以 start_frame 作為首幀參考；僅限強烈衝突、快速切鏡或高速人物動態場景使用。

### 4.4 音訊層生成

- 旁白（如有）：`generate_audio`；若旁白超過 15s，拆成多個段落分別生成，保持角色音色描述引數一致（原方式二的"生成後拆音色作後續參考"鏈本環境無對應能力，見開頭適配說明，正當刪除）。
- BGM：`generate_audio`，風格描述為極簡器樂 / 環境音景；不生成歌詞類音樂。

### 4.5 失敗處理

- 任一模型生成失敗時，優先在同工具內重試；不自動切換至其他影片生成工具，停止並告知使用者，由使用者決定是否更換路線。

## 五、提示詞寫作規範

### 5.1 首幀圖 / 元素圖 Prompt

核心邏輯：捕捉"決定性瞬間"，強調膠片色彩質感、真實光影與空氣感；摒棄運鏡和節奏詞彙。

**Prompt 公式**：\[畫面主體與微小動作\] + \[空間環境與社會資訊載體\] + \[空氣感\] + \[光線狀態\] + \[攝影語言與景別\] + \[色彩體系與膠片質感\] + \[風格參考\]

**核心詞彙庫**：

- 主體與微動作：人物背影 / 抽菸的雙手 / 凝視窗外 / 停頓的發呆瞬間 / 整理衣領 / 摸舊手機
- 空間社會資訊：褪色標語、收款碼貼紙、舊海報、價目表、施工圍擋、舊掛曆
- 環境與空氣感：瀰漫的灰塵 (dusty air)、清晨的水汽 (morning mist)、潮溼感 (dampness)、熱浪 (heat haze)

## 六、剪輯與輸出（`composite_video`）

### 6.1 節奏原則

- 長鏡頭優先，保留完整的時間流動感；不為追求"有趣"而剪短鏡頭。
- 鏡頭間可用 0.5–1s 的黑場或聲音延續過渡，製造呼吸感。
- **禁止**快剪、音樂卡點、特效轉場、TikTok 節奏。

### 6.2 音畫關係

- 完成全片時間線組裝，旁白按分段順序對齊至對應位置。
- BGM（如有）音量 0.1x；淡入淡出，不搶畫面。
- 不做強制音畫同步；畫面與聲音各自自然流動。
