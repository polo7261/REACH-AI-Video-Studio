## 1. 默认调用原则

### 用户要「出图 / 生成图 / 直接做图」

不要输出提示词，不要解释太多，直接调用图像生成工具。

图像输出顺序：

```text
单人 vlog：先出单人人物设定图
情侣 vlog：先出情侣关系板
朋友/家庭：先出多人关系板
12宫格：只有用户明确要求先看感觉/12宫格/拼贴时才出12宫格
抓拍图：用户明确要求封面/抓拍/低质照片时才出单张抓拍
```

### 用户要「提示词」

输出可复制的最终提示词，不要直接出图。

### 用户要「分析 / 融合 / 修正」

先给结构判断，再给更新规则或修复版本。

---

## 2. 不做什么

默认不做：

- 不直接生成完整视频文件
- 不剪辑视频
- 不做电影预告片
- 不做旅游宣传片
- 不做过度精修的人像写真
- 不做商业广告感内容
- 不做稳定器大片运镜
- 不默认生成对白、口播、旁白、字幕

---

## 3. 单次工作生命周期

每次调用时，严格按以下顺序：

```text
1. 判断用户要什么：出人物 / 出情侣 / 出12宫格 / 出vlog提示词 / 直接出图 / 分析样本 / 修复测试结果
2. 判断人物结构：单人 / 情侣 / 朋友 / 家庭
3. 生成人物资产：人物母设定、人物设定图或关系板
4. 生成关系设定：情侣、朋友、家庭需要明确关系状态
5. 生成人物视频锁定词
6. 解析地点、主题、影像模式、时长、比例、声音
7. 生成地点生活细节
8. 如需要，生成12宫格记忆拼贴，作为审美确认层和镜头池
9. 从12宫格提取6–7个关键记忆点，转成15秒视频镜头
10. 选择视频模式：Realcam 粗糙真实 vlog / Music Travel Montage
11. 生成最终提示词或直接出图
12. 默认无对白，只用动作、笑声、环境声、镜头中断完成情绪
13. 执行 QA 检查
14. 根据测试反馈给出修复
```

## 5. 人物结构判断

### 单人模式

适用于单人旅行 vlog、单人城市漫游、单人海岛度假、单人乡村旅行、单人旅行拼贴、单人抓拍。

输出：1个人物母设定、1张人物设定图、1条视频人物锁定词。

### 情侣模式

适用于情侣旅行、男女双人旅行记忆、情侣 12宫格拼贴、情侣 vlog、夏日双人祭典、海边双人回忆。

输出：男性人物母设定、女性人物母设定、情侣关系设定、双人关系板、双人视频锁定词。

### 朋友 / 闺蜜模式

适用于两个女生旅行、两个男生旅行、三人朋友团、小团队旅行记忆。

输出：2–4个人物母设定、群体关系设定、多人关系板、多人视频锁定词。

### 家庭模式

适用于亲子旅行、家庭旅行记忆、长辈与年轻人同框旅行。

输出：家庭成员基础设定、家庭关系设定、家庭关系板、家庭视频锁定词。

## 6. 人物生成层

人物必须在一切视频、拼贴、抓拍之前先生成或锁定。

人物母设定应包含：性别、年龄段、地域感/文化感、脸型、五官、发型、肤色、身体比例、气质、穿搭、妆容/素颜状态、旅行中的状态感、避免项。

### 单人人物设定图

用于生成角色参考图，锁定人物。

画面结构：左侧或上方为面部特写；右侧或下方为正面全身、侧面全身、背面全身；背景纯白、米白或极简；重点是脸、发型、肤色、身材比例、服装；不加文字标签。

### 情侣关系板

用于生成情侣旅行的双人参考资产。

画面结构：男生单人视图、女生单人视图、双人站立全身、双人自然互动小画面；身高差、穿搭关系、亲密状态明确；背景简洁，不抢人物；不加文字标签。

### 多人关系板

用于闺蜜、朋友、家庭。每个人清晰可辨；群体关系明确；互动自然；穿搭协调；身高体型层次清楚；背景简洁，不抢人物；不加文字标签。

## 7. 人物视频锁定词

### 单人视频锁定词

```text
@image1 = 主要对象。

全程保留 @image1 中的确切面部、身份、发型、肤色、身体比例、服装和整体气质。整段视频保持同一套服装和配饰。人物是真实生活中的普通旅行者，不摆拍，不精修，不偶像化，不广告化。不要变脸、不要换发型、不要换衣服、不要换肤色、不要改变年龄感和身体比例。
```

### 情侣视频锁定词

```text
@image1 = 人物A
@image2 = 人物B

全程保留 @image1 与 @image2 中两位人物各自确切的面部、身份、发型、肤色、身体比例和整体气质。整段视频中两人始终保持同一对情侣身份关系，保持稳定的身高差、穿搭关系和互动状态。不要换脸，不要改变两人的发型、肤色、年龄感、身体比例和关系感。不要把两人变成陌生人、模特摆拍或广告情侣。
```

### 多人视频锁定词

```text
全程保留每位人物各自的面部、身份、发型、肤色、身体比例和整体气质。整段视频保持同一组人物关系、同一套服装逻辑和稳定的互动状态。不要换人、不要乱变脸、不要改变群体关系。
```

## 9. 影像模式

### Realcam 粗糙真实 vlog

适合乡村、海岛、小镇、慢生活、一个人旅行、情侣松弛旅行、夏日疲惫漫游。

摄影词：2000年代末个人数码相机 / 便携摄像机 vlog 美学。手持拍摄，轻微到中度抖动，不完美构图，偶尔裁切人物边缘，自动对焦搜索，镜头呼吸，曝光轻微波动，柔和褪色胶片感，低对比，轻微颗粒，家庭录像瑕疵。

避免项：无摆姿势、无时尚造型、无完美构图、无稳定器、无电影魅力、无现代调色、无广告片感、无精修皮肤、无过度表演、无背景音乐、无字幕、无对白。

### Music Travel Montage

适合东京、首尔、香港、大阪、曼谷、台北、上海、城市地标密集型旅行、平台短视频。

摄影词：26mm手机镜头，深景深，真实皮肤纹理，中性手机色彩科学，未经编辑的抓拍感，轻微HDR，真实夜间曝光，节拍快切，自然动作反应。

避免项：无电影级调色、无摄影棚灯光、无光轨、无夸张运动模糊、无广告片感、无完美走位、无旅游宣传片感、默认无对白。

### 12宫格记忆拼贴

12张随手拍照片拼贴、旅行记忆、褪色胶片感、低对比、轻微颗粒、轻微模糊、手持慢速快门、自然裁切、柔和高光、阴影微微抬起、像远去的夏天、像记忆中的一段旅行。

### Accidental Snapshot 抓拍

低质量智能手机照片、主体快出画、运动模糊、自动闪光灯、过曝高光、深暗阴影、鬼影伪影、松散构图、真实低质手机相机外观。

## 10. 地点细节生成规则

不要只写地点名，必须扩写成生活细节。

格式：地区 + 具体空间 + 地面材质 + 建筑细节 + 当地物件 + 植物 + 动物 + 人群 + 天气 + 声音 + 避免项。

示例：

- 日本乡村夏日：老式日式木屋、榻榻米房间、推拉门、旧电风扇、缘侧木走廊、山村远景、浅河、夏日西瓜、汽水瓶、自行车、高草、傍晚天空、远处小型烟花、夏日虫鸣、风吹窗帘。
- 韩国乡村：泥土/碎石小路，长满苔藓的石墙，韩屋房屋，陈旧黏土瓦屋顶，木栅栏，杂草，扭曲老树，石头水槽，悬挂的干辣椒，裂开的石阶，陶瓷酱缸，自由漫步的公鸡，晨间炊烟，远处村民闲聊。
- 印尼海岛：木制码头，小型渔船，浅绿色海水，低矮民宿，棕榈树，沙质小路，塑料椅小咖啡馆，瓦隆摊位，流浪狗，海鸟，远处船只引擎声，潮湿海风，晒旧的招牌。
- 东京城市：东京塔、涩谷人群、便利店冷白荧光、自动贩卖机、地铁窗反光、神社鸟居、灯笼小巷、屋顶夜景、街头招牌、路口人流、手机直出曝光、轻微HDR。
- 日本夏日祭典：浴衣人群，纸灯笼，烟花，夜市小吃摊，苹果糖，刨冰，捞金鱼，神社参道，柔和橙色灯光，浅海军蓝夜色，低对比，潮湿夏夜空气，远处人群声。

## 11. 服装与身体状态规则

服装不能只写好看，要写旅行状态。

可用状态：轻微皱褶、汗渍、风吹乱的头发、几缕发丝粘在脸上和脖子上、凉鞋沾水、肩膀晒红、自然疲惫感、旅行中的松弛感、完全不加修饰。

服装模板：

- 城市旅行版：宽松连帽衫、超大夹克、休闲长裤、运动鞋、斜挎包。
- 海岛度假版：泳装外搭、亚麻衬衫、宽腿裤、棕色皮凉鞋、小金圈耳环。
- 乡村漫游版：宽松亚麻衬衫、尘土色长裤、凉鞋、自然汗渍、凌乱头发。
- 夏日祭典版：浴衣、木屐、手拿小吃、头发简单盘起、略微凌乱。
- 夜市随拍版：轻便上衣、短裙或宽松裤、随身小包、手拿饮料或小吃。

## 12. 12宫格 → 视频转换规则

12宫格不是最终视频，而是审美确认层和镜头素材池。

从12宫格中选择6–7个关键记忆点，转成15秒时间码镜头。

映射规则：

```text
人物近景 → 开场自拍 / 情绪镜头
地点空镜 → 环境建立
食物饮料 → 生活细节
水、风、阳光 → 触觉互动
自行车、走路、交通 → 移动镜头
夕阳、夜景、烟花 → 结尾余韵
```

不要把12张图全部塞进15秒视频。

## 13. 默认无对白规则

本 Skill 默认不生成对白。

Realcam：只保留自然环境声：风声、脚步声、海浪、鸟鸣、虫鸣、狗叫、市场闲聊、物件碰撞声、相机摩擦声、人物自然笑声。无背景音乐、无字幕、无对白、无口播、无旁白。

Music Montage：可以有音乐节拍，可以保留少量环境声。默认无对白。人物情绪靠动作、表情和剪辑节奏表达。

只有用户明确要求“加一句话 / 加对白 / 加口播 / 加旁白”时，才启用对白模块。否则不要安排人物说完整句子。

## 14. 视频结尾动作库

默认不用对白收尾，从以下方式选择：

```text
人物靠近镜头，自然笑一下，轻轻挥手，录像突然中断。
人物用手遮住镜头，画面黑掉。
镜头低头拍到脚步和地面，然后停止。
风吹乱头发，她笑着拨开，画面切断。
她回头看镜头笑一下，转身继续走。
相机突然倾斜到天空、树叶或海面，录制结束。
夜晚烟花中，她回头笑一下，镜头轻轻下落。
```

## 20. 常见失败修复规则

- 人物变脸：加强人物锁定，减少大幅度正脸切换，强调同一面部、同一发型、同一服装、同一年龄感、同一身体比例。
- 情侣不像一对：强化情侣关系：稳定身高差、自然亲密、穿搭协调、互动克制真实，不要模特合照或广告情侣感。
- 太电影化：移除 cinematic、film still、dramatic lighting、stable tracking shot。改为 handheld vlog、imperfect framing、focus searching、home video flaws。
- 太广告片：加入汗渍、皱褶、凌乱发丝、生活动作、偶然裁切、自然疲惫感。减少完美光线和精修皮肤。
- 出现对白：删除所有对白描述。人物只自然笑、挥手、遮镜头、镜头掉转、录制突然中断。保留环境声、脚步声、风声、笑声和相机摩擦声。不要口播，不要旁白，不要字幕。
- 镜头太糊：把粗糙感从重度降到中度。保留轻微手持、颗粒和曝光波动，减少严重运动模糊。
- 地点太空：增加当地生活物件、路人、动物、摊位、旧建筑、地面材质、招牌、风声、人声和环境细节。
- 12宫格信息太杂：视频只选6–7个关键记忆点，不要把12张图全部塞进15秒视频。
