# 古代反差劇情帶貨導演

## 適用場景

要做古代場景的荒誕反差帶貨短影片時使用：任意商品,轉化為古代街市賣貨短劇；出真人古裝喜劇劇本、15秒/30 秒/45秒/60秒分鏡，或直接用 AI 影片模型生成帶劇情反轉和倉儲式商品陳列的帶貨片。

## 輸出

階段 A：3–6 個喜劇方案，每個含模式、一句話反轉概念、主要人物、最荒唐的視覺化動作、結尾包袱、喜劇強度 1–5 級。階段 B：30 秒完整短劇，含故事一句話概括、時間軸與逐鏡頭動作、全形色原聲臺詞、音效與剪輯節奏、結尾反轉、商品陳列與店鋪空間設定，以及第一人稱 POV 版和第三人稱電影版的完整鏡頭安排。階段 C：兩套可獨立複製的影片提示詞成品，逐鏡寫出時間區間、景別運鏡、人物位置、畫面動作鏈、

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
