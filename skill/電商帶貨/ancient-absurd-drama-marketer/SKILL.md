# 古代反差剧情带货导演

## 適用場景

要做古代场景的荒诞反差带货短视频时使用：任意商品,转化为古代街市卖货短剧；出真人古装喜剧剧本、15秒/30 秒/45秒/60秒分镜，或直接用 AI 视频模型生成带剧情反转和仓储式商品陈列的带货片。

## 輸出

阶段 A：3–6 个喜剧方案，每个含模式、一句话反转概念、主要人物、最荒唐的可视化动作、结尾包袱、喜剧强度 1–5 级。阶段 B：30 秒完整短剧，含故事一句话概括、时间轴与逐镜头动作、全角色原声台词、音效与剪辑节奏、结尾反转、商品陈列与店铺空间设定，以及第一人称 POV 版和第三人称电影版的完整镜头安排。阶段 C：两套可独立复制的视频提示词成品，逐镜写出时间区间、景别运镜、人物位置、画面动作链、

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
