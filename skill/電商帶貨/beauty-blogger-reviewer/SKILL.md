# Wander 真人感美妝 UGC 產品測評

## Skill 定位

把使用者上傳的護膚、彩妝、香氛或個人護理產品圖，轉化為一支像真實創作者親自拍攝、親自試用並給出有限結論的 Seedance 2.5 豎屏 UGC 測評影片。

成片必須同時滿足：

- 一位明確成年創作者，預設中國/東亞女性；
- 手機原生相機質感，不是棚拍廣告或精修 TVC；
- 先試用、再觀察、最後給有限結論；
- 使用者想表達的核心賣點必須被保留，但要轉譯成動作、質地、妝效或即時感受，不直接照讀廣告話術；
- 中文口語由當下觸感與觀察觸發，保留停頓、自我修正和剋制態度；
- 產品包裝、使用方式、人物、空間與光線連續。

預設成片：Seedance 2.5，參考圖片 + 文字提示詞，24 秒，9:16，720P，單一影片節點，多鏡頭時間戳，現場聲 + 輕量動作音，無 BGM，無隨機字幕。

明確不做：

- 高階商業 TVC、純產品渲染片、3×3 商業故事板強制流程；
- 直播帶貨、背誦式口播、無人稱旁白、第三人攝影；
- 無證據的醫學功效、絕對化承諾、精確持續時間或誇張前後對比；
- 30 秒以上、多段拼接、影片/音訊引用、首尾幀續寫或編輯鏈路。

## Reference 呼叫策略

按階段讀取：

1. 看完使用者素材後讀取 `references/asset-policy.md`，判斷最少充分資產與功效宣告邊界。
2. 確定測評角度時讀取 `references/beauty-review-engine.md`，建立“觀察—試用—證據—有限結論”鏈。
3. 使用者提供賣點，或 Agent 需要推薦賣點和內容鉤子時，必須讀取 `references/selling-point-to-ugc.md`，生成賣點轉譯卡。
4. 生成任何人物、場景或使用關係圖前讀取 `references/mobile-beauty-realism.md`。
5. 編寫口播前讀取 `references/live-review-dialogue.md`。
6. 寫時間戳提示詞時讀取 `references/timeline-patterns.md`。

主檔案只儲存流程和硬約束，不在對話中完整複述 references。

## 固定使用者引導

### 第 0 輪：功能介紹並索取核心圖片

固定開場：

> 這個 Skill 會把你的美妝或護理產品圖做成一支 4–30 秒、像真人創作者親自拍攝和試用的 UGC 測評影片。我會先判斷產品圖能否直接引用，並把你想突出的品牌賣點轉成真實動作、可見證據和自然口播；之後只用一輪確認內容方向、場景、時長和必要邊界。請先上傳最清晰的一張產品圖；如果已有指定達人參考圖或一句想突出的賣點，也可以一起發，但不是必需。

第一屏只把產品圖設為必需輸入；人物圖和一句原始賣點可選。不要要求使用者填寫完整營銷表、全部臺詞、音樂、字幕和鏡頭。

### 第 1 輪：自動判斷並一次確認專案邊界

先輸出簡短判斷：

1. 產品類別、包裝、質地或用法線索；
2. 產品圖能否直接作為 `product_reference`；
3. 是否已有 `creator_reference`；沒有時預設生成一張，普通使用動作不額外建立關係圖；
4. 哪些賣點可由畫面觀察，哪些來自使用者資訊，哪些屬於未經證實的功效宣告；
5. 推薦的一個核心測評問題、一條可拍證據鏈和一條自然口播方向；
6. 使用者原始賣點如何被保留、降級或改寫，避免使用者以為 Agent 擅自丟掉商業意圖。

隨後集中確認，預設方案為：

```text
測評路徑：第一次真實試用 + 即時體驗（推薦）
核心賣點：Agent 推薦 1 個視覺化賣點；使用者可以直接回復“想突出：……”替換
目標使用者 / 情境：Agent 根據產品給出一個合理假設；使用者可一次糾正
口播氣質：真實快測（推薦）；可改為朋友分享 / 輕反差種草 / 剋制專業
表達方式：保留賣點含義，不逐字照讀廣告話術；用動作、反應和個人結論表達
創作者：系統生成的明確成年中國/東亞女性
場景：真實居家梳妝檯或洗手檯
畫幅：9:16
時長：24 秒；允許 4–30 秒
聲音：創作者同期中文口播 + 室內環境音 + 使用動作音，無 BGM
字幕：無隨機字幕；準確字幕建議後期新增
必須保留：包裝結構、主色、Logo 位置、正確用法和使用者指定元素
禁止出現：醫療化結論、絕對承諾、誇張磨皮、硬廣背稿、第三人攝影
```

同時給出一張簡短的賣點轉譯預覽：

```text
使用者/推薦賣點：原始商業意圖
觀眾真實顧慮：這個人為什麼會在此刻測試它
可拍證據：鏡頭能直接看到什麼
口播方向：1 句由動作或觀察觸發的自然表達，不是最終逐字稿
表達邊界：哪些詞不能憑圖片或一次試用使用
```

使用者回覆“按預設來”即可確認推薦賣點、使用者假設和口播氣質；也可以只回復“想突出：……”或貼一段商品賣點，Agent 自動完成轉譯，不要求使用者自己寫口播。不得重複詢問已確認事項。使用者指定受監管功效、精確數字、對比結論或必須逐字出現的品牌話術時，先要求其提供最終合規文字。

## 輸入與自動判斷

### 產品圖

可直接引用需滿足大部分條件：產品主體完整、邊緣清楚、顏色與材質可辨、包裝比例未嚴重變形、主產品無歧義、關鍵使用結構未被遮擋。小字無需承諾逐字復現。

只有背景嚴重幹擾、關鍵結構缺失、多產品主次不明、強反光/手遮擋或低質量拼圖會破壞身份時，才生成新的乾淨 `product_reference`。Agent 自行判斷，不把清晰度判斷推給使用者。

### 資訊可信度

為每條資訊標記來源：

- `觀察`：圖片中可見的包裝、顏色、形態、質地與使用動作；
- `使用者資訊`：使用者明確提供的成分、賣點或品牌說明；
- `創意推斷`：為測評結構提出的合理假設，不能當事實口播；
- `需確認宣告`：醫學、持續時長、精確比例、認證、零刺激、適用所有膚質等強宣告。

只憑圖片不得確認醫學修復、抗敏、祛痘、抗老效果、持續小時數、防曬數值、絕對防水或“所有膚質適用”。沒有可信宣告時，改寫為可見質地、延展性、上臉過程、即時光澤、顏色、氣味偏好或個人主觀感受。

### 使用者自定義賣點

接受使用者以任何成熟度輸入賣點：一個詞、一句話、商品詳情頁文案、成分說明、目標人群或想解決的顧慮。Agent 不要求使用者先改寫成口語。

處理順序：

1. 提取使用者真正想讓觀眾記住的一個商業意圖；
2. 判斷它屬於可見事實、使用者提供事實、主觀體驗或需確認宣告；
3. 為它匹配一個真實使用情境和一個觀眾顧慮；
4. 把賣點改寫為能由鏡頭證明的動作或觀察；
5. 再把證據改寫為創作者當場會說的一句反應；
6. 檢查最終指令碼仍然表達使用者原意，而不是隻剩“真實感”卻失去賣點。

使用者一次提供多個賣點時，按“與產品相關性、可拍性、可信度、觀眾決策價值”排序，只選 1 個核心賣點，最多保留 1 個輔助觀察；其餘列為未採用，不靜默丟棄。

## 資產管線與確認閘門

採用最少充分資產和一次資產閘門。

### 語義資產名

- `product_reference`：始終需要；優先使用使用者原圖，鎖定包裝、比例、主色、材質與 Logo 位置。
- `creator_reference`：預設使用一張。使用者有合格達人圖時直接使用；沒有時生成一張成年創作者身份圖。
- `product_use_reference`：預設不建立。只有非常規工具、精確接觸位置、產品尺寸關係高風險，或首輪影片已經出現明顯握持/使用錯誤時才追加；普通口紅、精華、面霜、粉底和常規刷具僅用文字控制。
- `scene_reference`：只有使用者要求復刻特定空間時建立。
- `storyboard_reference`：只有嚴格鏡頭順序或複雜使用步驟多次失敗時才建立，不預設生成。

預設只用 2 張圖：使用者產品圖 + 一張成年創作者身份圖。使用者已有合格人物圖時不重新生成。簡單單主體且人物一致性風險低時可以只用產品圖；只有明確失敗風險才增加第 3 張關係圖或結構圖。

依賴關係：

```text
product_reference + creator_reference
    -> product_use_reference(失敗後或高風險時可選)
    -> storyboard_reference(失敗後可選)
    -> final_video_prompt
```

生成創作者身份圖後集中確認一次：產品是否正確、成年創作者是否符合預期、手機真實感是否成立。只有確實生成了關係圖時才確認使用關係。上游資產改變後同步更新下游資產與最終提示詞。

最終輸出前把語義名解析為實際上傳順序：

```text
@圖片1 = product_reference：鎖定產品包裝、比例、主色、材質和 Logo 位置
@圖片2 = creator_reference：鎖定同一成年創作者的臉、髮型、膚色、真實皮膚和服裝
@圖片3 = product_use_reference：僅在高風險或失敗回退時出現，鎖定精確取量、握持或接觸關係
```

最終提示詞只保留實際 `@圖片N`，不得留下內部資產名。

## 核心創作方法

### 1. 只測一個核心問題

每條影片只回答一個可被鏡頭驗證的問題，例如：

- 質地是否容易推開、是否厚重；
- 唇釉/粉底的顏色、遮蓋或光澤在自然光下怎樣；
- 泵頭、滴管、刷頭是否好控制取量；
- 產品在一次完整使用動作中的即時觀感；
- 香氛的第一印象與個人偏好，但不把氣味描述成客觀功效。

最多加入一個輔助觀察。不要在 24 秒裡堆成分、膚質、價格、持妝、氣味和包裝六個結論。

### 2. 先做賣點轉譯，不先寫口播

使用者賣點不能直接粘進臺詞。先讀取 `references/selling-point-to-ugc.md`，形成內部賣點轉譯卡：

```text
原始賣點
核心商業意圖
目標使用者與真實顧慮
可信度與宣告邊界
可拍動作 / 感官證據
開場預期或小衝突
即時反應
條件化個人結論
最終是否仍保留使用者原意
```

“自然”不等於弱化賣點，“網感”也不等於堆熱詞。有效網感來自：第一秒有具體顧慮、實際試用產生反差、人物會停頓或自我修正、結論帶個人條件、鏡頭和語言有快慢變化。

生成最終指令碼前，內部產出三種候選強度：最剋制、最自然、稍有態度。刪除畫面複述、品牌主播腔、無證據承諾和網路模板後，只輸出最符合已確認口播氣質的一版；不要把三套候選全部塞給使用者。

### 3. 建立證據鏈

預設順序：

```text
具體疑問或使用情境
→ 鏡頭看清產品身份
→ 正確取量或上妝
→ 近距離觀察質地/顏色/肌膚反應
→ 創作者身體與表情產生即時反應
→ 換到自然光或另一角度複核
→ 給出帶條件的個人結論
```

結論必須由前面的可見證據支援。把產品拿掉後，測評問題和結論若仍能原樣成立，說明產品只是道具，需重寫。

### 4. 真人 UGC 拍攝合同

- 所有鏡頭都能由創作者單人完成：手持前置自拍、鏡前自拍、手機固定在桌面/支架上，或創作者自己補拍的近距離產品/上臉插鏡；
- 允許不同 take 的自然硬切，但空間、人物、產品狀態與光線可連續；
- 保留手機自動曝光、輕微廣角、深景深、輕微銳化、區域性高光和小幅對焦呼吸；
- 保留毛孔、細紋、唇紋、碎髮、輕微泛紅和真實妝面，不磨皮、不液化、不生成塑膠皮膚；
- 產品特寫為證據，不是高階 hero shot；禁止轉檯、液體懸浮、棚拍輪廓光、電影推軌和廣告級慢動作。

### 5. 活人口播

口播先服務人物當下反應，同時必須完成已確認賣點。24 秒預設 3–5 個發聲點，每次通常 4–18 個漢字；允許半句、停頓、重複、自我修正和短暫沉默。

每句都要回答：“她上一秒看見、摸到或聞到了什麼，才會現在開口？”以及“這句話如何讓觀眾更理解已確認賣點？”前者答不出就刪，後者答不出就重寫或把賣點交給動作完成。禁止模板開場、產品說明書複述、品牌主播腔、工整金句、網路熱詞堆砌和無證據的極端評價。

### 6. 有限結論

收尾使用個人、條件化表達，例如“我這邊看起來……”“對我這種偏幹狀態……”“第一遍上臉我會更喜歡薄一點”。不得把一次即時試用說成長週期功效測試。需要長期結論時，改成“首日體驗/即時觀感”，或要求使用者提供真實長期素材與合規事實。

## 最終影片提示詞規則

- 模型固定為 Seedance 2.5，只使用參考圖片 + 文字提示詞。
- 4–30 秒使用一個影片節點，不因超過 15 秒拆段。
- 使用“參考素材 + 一句話概述 + 全域性設定 + 連續時間戳 + 全域性收束”五層結構。
- 第一段從 `00:00` 開始，最後一段結束於總時長；區間連續、無重疊、無空檔。
- 9–15 秒寫 3–5 段，16–24 秒寫 4–7 段，25–30 秒寫 5–8 段。
- 產品主要出現或使用的時間段再次引用對應 `@圖片N`。
- 明確總時長、9:16、720P、單節點、聲音和字幕策略。
- 預設聲音為同期中文口播 + 室內環境音 + 取蓋/按泵/塗抹等動作音，無 BGM、無旁白、無第二人聲。
- 預設無隨機字幕、貼紙、水印和無關文字；準確字幕建議後期新增。
- 全域性收束只列題材相關失敗模式：換臉、磨皮、產品變形、手指錯誤、用法錯誤、皮膚狀態跳變、第三人攝影、硬廣口播和無證據宣告。

## 輸出

### 配置/資產階段

輸出：素材判斷、賣點來源與宣告風險、賣點轉譯預覽、推薦測評問題、專案邊界確認、僅缺失且會進入最終節點的創作者身份圖提示詞。預設不生成使用關係圖或九宮格。

### 影片階段

確認透過後依次輸出：

1. 專案設定：模型、模式、時長、畫幅、720P、結構、聲音、字幕；
2. 賣點轉譯卡：原始賣點、觀眾顧慮、可拍證據、口播策略、表達邊界；
3. 最終口播指令碼：按時間順序列出唯一採用版本，並說明每句由什麼動作或觀察觸發；
4. 測評證據鏈：核心問題、可見證據、有限結論；
5. `@圖片N` 引用清單與鎖定用途；
6. 一條可直接複製的 Seedance 2.5 完整提示詞；
7. 資產閉環檢查：所有參考圖已引用、無無用中間圖、無內部資產名、上游修改已同步；
8. 按照下方“自檢”逐項檢查生成的提示詞，修復全部問題後再交付。
