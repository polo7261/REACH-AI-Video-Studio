# 抖音爆款开头带货短视频

## 適用場景

为抖音带货短视频设计、改写和评审开头钩子，覆盖猎奇揭秘、方法痛点、情感共鸣、直观效果、人群圈定、背书承诺、场景激发、剧情引入、促销优惠、国货情怀十类策略；适用于商品短视频开头创作、完整带货脚本输出、开头诊断与改写、开头测试方案；不用于直播整场话术或视频渲染。

## 輸出

①开头创作：默认输出 5 个不同角度候选，每个含目标人群与观看理由、首帧及前 1—3 秒动作、口播、屏幕短字幕、后续兑现方式、证据/拍摄前提，并推荐最值得先测的 2 个及理由；
②完整脚本：先说明受众、核心卖点与主钩子，再输出覆盖目标时长的分镜表（时间段、画面/动作与景别、口播/对话、屏幕字幕、演示证据/必要说明），结尾附关键道具与待核实信息；
③开头诊断或改写：按"原句/原画面 → 具体问题 →

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
