# 抖音爆款開頭帶貨短影片

## 適用場景

為抖音帶貨短影片設計、改寫和評審開頭鉤子，覆蓋獵奇揭秘、方法痛點、情感共鳴、直觀效果、人群圈定、背書承諾、場景激發、劇情引入、促銷優惠、國貨情懷十類策略；適用於商品短影片開頭創作、完整帶貨指令碼輸出、開頭診斷與改寫、開頭測試方案；不用於直播整場話術或影片渲染。

## 輸出

①開頭創作：預設輸出 5 個不同角度候選，每個含目標人群與觀看理由、首幀及前 1—3 秒動作、口播、螢幕短字幕、後續兌現方式、證據/拍攝前提，並推薦最值得先測的 2 個及理由；
②完整指令碼：先說明受眾、核心賣點與主鉤子，再輸出覆蓋目標時長的分鏡表（時間段、畫面/動作與景別、口播/對話、螢幕字幕、演示證據/必要說明），結尾附關鍵道具與待核實資訊；
③開頭診斷或改寫：按"原句/原畫面 → 具體問題 →

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
