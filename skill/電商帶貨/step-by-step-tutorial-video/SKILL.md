# ugc-tutorial-flow

做 UGC 風格教程影片（達人**分步演示某產品用法**、畫面帶「Step N」步驟字幕）時用本 skill。創作（人設 / 獨白 / 分鏡 prompt）由你自己做——源裡委託給後端 enhancer，本環境沒有。你管控制流、門控、時序、拼接。

一條管線覆蓋所有 UGC 教程 / 產品用法影片：**每個分鏡槽 = 使用產品的一個物理步驟**。

## 分鏡結構（教程專屬 · 與口播底不同）

- 每塊**分鏡板 = 一條 21:9 橫條，內含 4 個豎排 9:16 槽**（口播底是 16:9 含 3 槽；教程覆蓋為 21:9 含 4 槽）。
- 每槽顯示一個「Step N — Heading」字幕。
- **總步數 = 4 × 板數**；**步驟編號全域性連續**（跨板不重置）。
- **CTA 尾**只出現在**最後一板的最後一格**。

## 流程

1. **解析需求 + 產品用法分析**（product-analyzer）：從真實使用流程匯出步驟，產出 `step_captions` 陣列。**必做**。
2. **人設生成**：`generate_image_v3` 出達人角色錨點（或使用者給照片）。身份鎖定為**單一 character 錨點節點**（`character_media_id` 概念），全程複用同一 `{{NodeKey}}`，見 character-consistency。
3. **上傳 / 登記產品**為錨點。
4. **獨白指令碼**：寫完整口播詞，逐步對應各使用步驟。
5. **分鏡板生成**：按時長定板數（見下），`generate_image_v3` **序列**出板（後板參考前板保持連貫）——**21:9 橫條，內含 4 個豎 9:16 槽**，每槽帶「Step N — Heading」字幕。
6. **逐鏡寫 prompt + 生成**：並行寫各板 Seedance 風格 prompt（一批），`generate_video_v3` **一批並行提交**，`reference_nodes` 引人設 / 產品 / 分鏡板錨點。
7. **拼接**：N≥2 段 `composite_video`（見 montage）；配音用 `generate_audio`。
8. **報告**。

## 人設生成規則（Step 2 深度 · UGC 家族通用）

達人錨點要做成**真實手機自拍**質感，不是雜誌肖像：

- **構圖**：手臂伸直的前置自拍，頭肩填滿畫面，略微偏心 / 不完美構圖（非擺拍、非影棚居中），持手機的手 / 腕可在畫面邊緣隱約出現。
- **真實感**：保留手機感測器顆粒與皮膚毛孔紋理，不修圖、不磨皮濾鏡、無影棚光 / 專業光澤；主體清晰、背景自然虛化。
- **服裝**：全覆蓋胸前 / 軀幹，無 logo、無可見文字。
- **打光 / 環境**：柔和冷中性日光（側窗），乾淨、無暖調、無修飾光暈。

## 手數 / POV 規則（UGC 家族通用 · 關鍵）

- 角色**恰好兩隻手**。
- **Selfie POV**：一隻手拿手機（畫外或邊緣隱約可見），另一隻手做動作——**絕不在 selfie POV 裡同時拿兩個物體**。
- 需要**雙手**的動作（如實際操作 / 使用產品的步驟）→ 切 **Tripod POV**（手機不在畫面）。
- POV 可在鏡 / 槽間切換，切換**對齊硬切**。

## 鏡頭 / 渲染規則

- 每槽 = 演示的一個使用步驟；真實攝影風格 UGC、自然光、隨意真實感。
- 演示步驟按實際使用順序推進，槽內動作貼合該 Step 的 Heading。
- **握持物理**：產品的重 / 輕按實物表現，抓握、承重要真實。
- 產品呈現時 **label 朝前、不旋轉**，畫面恰好一個產品。
- **能量基調**：預設高能達人，**可按品牌調性調整**（不強制誇張尖叫）。
- 無鏡子 / 反射鏡頭；無變形手 / 第三隻手臂；畫面上**無任何多餘文字 / 品牌 / 標誌**（「Step N」步驟字幕除外）。

## 關鍵規則

- **English-only**：字幕、獨白、CTA 均英文；步驟字幕用「**Step N — Heading**」格式、**en-dash（—）分隔**。
- **產品用法分析必做**：步驟從真實使用流程匯出，不臆造。
- **CTA 尾**（末板末格最後約 0.5–1s）：達人出鏡 + 手勢 + "Link in bio" / "Subscribe!"。
- **人設身份鎖定**：單一 character 錨點節點貫穿全片，不要每鏡重生成達人。
- **板序列、片並行**：分鏡板序列生成（保連貫），Seedance 片段一批並行提交。
- **開場詞約束**：口播第一個詞**不要**用 OK / Okay / So / Um 等虛詞起頭，直接進鉤子。
- **音訊 / 穩定度**：自拍鏡手持微抖、三腳架鏡鎖定定幀；成片無畫面文字、無字幕、無水印（步驟字幕除外）。
- Seedance 逐鏡預設 `count: 2`。
