# 九斤线下课学员专用-ai skills

## 適用場景

带货短视频、口播、剧情反转、变装/变身、特效展示、游戏或影视感片头、旅拍、生活方式切片。

## 輸出

一条与原片同结构、同节奏、同运镜的复刻成片（MP4，常见 10–15 秒，比例与清晰度按确认值），并附逐镜头拉片表、改写脚本、分段生成提示词、交付说明（含替换点、保留点、已知差异）。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
