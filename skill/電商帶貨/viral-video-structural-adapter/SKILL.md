# 九斤線下課學員專用-ai skills

## 適用場景

帶貨短影片、口播、劇情反轉、變裝/變身、特效展示、遊戲或影視感片頭、旅拍、生活方式切片。

## 輸出

一條與原片同結構、同節奏、同運鏡的復刻成片（MP4，常見 10–15 秒，比例與清晰度按確認值），並附逐鏡頭拉片表、改寫指令碼、分段生成提示詞、交付說明（含替換點、保留點、已知差異）。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
