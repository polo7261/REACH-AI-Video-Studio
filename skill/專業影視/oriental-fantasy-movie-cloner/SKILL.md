# 國風仙俠電影風格復刻

## 適用場景

把一句話想法或一張參考圖，做成中式仙俠IMAX電影風動態短片。適合短影片、古風仙俠內容、廣告概念視覺：只有靈感文案想直接出片，或有圖想轉成飄逸唯美的真人質感仙俠畫面並動起來時用。覆蓋文生圖/圖生圖到動態影片全流程。

## 輸出

每張圖一條10秒以上多分鏡動態影片，中式仙俠IMAX風：乾淨明亮、飄逸大氣、衣物自然飄動、全元素真實攝影材質、影視級特效、無文字標題、無繪畫效果。附成圖、提示詞、風格精煉詞與分鏡說明。一張圖只生成一條10s的影片，不管有多少分鏡。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
