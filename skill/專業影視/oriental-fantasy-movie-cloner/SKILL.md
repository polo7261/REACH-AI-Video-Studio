# 国风仙侠电影风格复刻

## 適用場景

把一句话想法或一张参考图，做成中式仙侠IMAX电影风动态短片。适合短视频、古风仙侠内容、广告概念视觉：只有灵感文案想直接出片，或有图想转成飘逸唯美的真人质感仙侠画面并动起来时用。覆盖文生图/图生图到动态视频全流程。

## 輸出

每张图一条10秒以上多分镜动态视频，中式仙侠IMAX风：干净明亮、飘逸大气、衣物自然飘动、全元素真实摄影材质、影视级特效、无文字标题、无绘画效果。附成图、提示词、风格精炼词与分镜说明。一张图只生成一条10s的视频，不管有多少分镜。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
