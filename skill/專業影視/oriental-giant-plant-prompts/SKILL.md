# 巨物植物美學

## 適用場景

適合製作巨型花卉、植物、器物、自然異象、東方建築與人物共景。支援一句話原創造景、參考圖復刻、構圖遷移、失敗成圖返修、批次隨機發散，以及成圖後的圖生影片設計。

## 輸出

每組輸出畫面標題、一整段中文圖片提示詞和一整段mj英文提示詞，明確人物、道具、動作、場景、環境、巨物尺度、機位、光線與色彩。返修時附帶問題判斷和完整修正版；回傳成圖後輸出約5秒、單鏡頭、不切鏡的圖生影片提示詞。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
