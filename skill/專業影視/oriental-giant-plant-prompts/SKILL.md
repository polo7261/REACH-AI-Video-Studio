# 巨物植物美学

## 適用場景

适合制作巨型花卉、植物、器物、自然异象、东方建筑与人物共景。支持一句话原创造景、参考图复刻、构图迁移、失败成图返修、批量随机发散，以及成图后的图生视频设计。

## 輸出

每组输出画面标题、一整段中文图片提示词和一整段mj英文提示词，明确人物、道具、动作、场景、环境、巨物尺度、机位、光线与色彩。返修时附带问题判断和完整修正版；回传成图后输出约5秒、单镜头、不切镜的图生视频提示词。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
