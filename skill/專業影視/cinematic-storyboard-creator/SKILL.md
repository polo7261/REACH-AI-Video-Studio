# cinematic-dialogue-storyboard

## Skill 定位

- **只負責**：將使用者上傳或確定的**第一張“定稿圖”（Master Shot）作為全場戲的絕對空間與資產錨點**。深度解析定稿圖中的人物座標、視線方向以及**每個角色身後特定的背景物理參照物**（如：男主身後的窗戶、女主身側的沙發）。當景別發生推拉（如全景推進至男主中景/特寫）或機位旋轉時，精確計算並鎖定該特定角色視角下的背景元素透視，確保後續分鏡背景絕對合理、絕不穿幫。同時採用“單張推演、生成前確認”機制，結合多元影視構圖，輸出高融合度的 **Image 2 中文分鏡圖生成提示詞**。

---

## 輸入

- **首張定稿圖（絕對錨點圖）**：上傳的場景、人物位置關係定稿圖（例：前景為躺在沙發上的女主，後景為坐在餐桌前且身後有窗戶的男主）。
- **劇本臺詞與劇情動作**：角色臺詞、情感變化、微表情及肢體動作（例：男主停下手中動作，轉頭看向女主）。
- **鏡頭意圖**：使用者希望調整的景別與視角變化（例：切到男主看向女主的中景/特寫）。
- **畫幅比例**（必問項）：16:9（電影寬屏）、2.35:1（寬銀幕）、4:3等。
- **調色風格**（必問項）：青橙商業大片、暗調懸疑Noir、暖調復古膠片、賽博霓虹等。
- **單步確認反饋**：使用者對預覽構圖方案的“確認”或“修改意見”。

## 輸入使用

- **怎麼用（嚴格遵守與重中之重）**：
  - **背景空間防穿幫機制（核心重中之重）**：
    1. **角色背景繫結分析**：分析定稿圖時，必須建立“角色-背景專屬繫結矩陣”。例如：
       - **男主專屬背景**：餐桌、身後的窗戶、窗外的光線與景物。
       - **女主專屬背景**：沙發、附近的茶案或地毯。
    2. **景別切換時的透視繼承**：當鏡頭從定稿圖的全景/大景別**推進至某個角色的中景、近景或特寫時**，Prompt 必須**精確復刻該角色在定稿圖中的專屬背景**。
       - *錯誤示例*：男主切中景時憑空出現一面白牆或書架（穿幫）。
       - *正確示例*：男主切中景時，提示詞必須強調“**男主坐在餐桌前，正身後依然是定稿圖中的那扇窗戶，窗戶在淺景深下自然虛化，光線從窗外透入**”。
  - **首圖基準改動句式**：所有後續提示詞必須採用\*\*“在定稿圖的基礎上，保持場景空間與角色服裝光影一致，將鏡頭位置推進/改動至……”\*\*的標準前置約束句式。
  - **生成前強制確認**：每一張分鏡圖在輸出最終 Prompt 前，**必須**先輸出詳細的【構圖預判方案】與【定稿圖背景對應分析】，並向使用者提問確認。
  - **構圖多元化**：杜絕單一過肩鏡頭（OTS）。靈活交替使用正打近景、側面中景、低角度仰拍、特寫等，豐富鏡頭語言。

## 內部流程和 Knowhow

### 1. 定稿圖視覺資產深度解析 (Anchor Analysis Step)

當使用者上傳或確定首張定稿圖後，Skill 必須在內部執行並輸出以下空間拆解：

- **空間座標軸**：確定男主、女主的絕對位置（如：女主在前/左，男主在後/右）。
- **角色-背景對映**：
  - `角色A（如男主）` ↔ `專屬背景（如身後的窗戶、餐桌）`
  - `角色B（如女主）` ↔ `專屬背景（如躺著的沙發、客廳區域）`
- **環境主光源**：識別光線來源（如：從男主身後的窗戶透入的自然光/逆光）。

### 2. 景別推拉與透視計算 (Perspective Scaling)

當鏡頭從全景（Master Shot）切換至特定角色的中景/近景/特寫時：

- **近大遠小與景深虛化**：鏡頭靠近男主時，男主身後的窗戶在畫面中的比例放大，但透視結構不變，同時背景（窗戶）根據焦段產生大光圈淺景深（Bokeh）虛化。
- **視線方向（Look Direction）**：若男主看向女主（女主在前景/左側），男主的頭部與眼神必須朝向畫面左前方，符合 180 度軸線規則。

### 3. Prompt 構建公式（防止背景穿幫）

> `[在定稿圖的基礎上修改鏡頭景別與位置]` + `[畫幅與焦段]` + `[主體角色動作與微表情]` + `[精準繼承定稿圖中該角色身後的專屬背景元素]` + `[環境光影與邊緣光漫反射]` + `[統一電影調色與畫質]`

*示例（男主中景）*：

> 在第一張定稿圖的基礎上修改鏡頭位置與景別。電影劇照，2.35:1畫幅，中景鏡頭（85mm焦段，f/2.0淺景深）。攝像機向後景的男主推進。主體是坐在餐桌前的男主，他停下手中的動作，頭部微轉，眼神深邃地看向畫面左前方的女主方向。**男主的正身後完全繼承定稿圖中的那扇窗戶**，窗外的自然光從男主後方照入，在男主的頭髮和肩膀邊緣形成一道清晰的逆光輪廓（邊緣光）。背景中的窗戶與餐桌呈自然的大光圈虛化，與定稿圖的環境透視完全一致。光影過渡自然，沒有任何貼圖感，青橙電影調色，膠片質感。

## 構圖解析與預覽模板（每張生成前必須輸出）

在輸出最終 Image 2 提示詞之前，**必須**先向使用者展示以下構圖與背景解析，供使用者稽核：

> ### 🎬 鏡頭 \[鏡頭編號\] 構圖與背景對齊方案
>
> - **【定稿圖背景精準對齊】**：
>   - 當前鏡頭聚焦物件：**\[如：男主\]**
>   - 鎖定定稿圖專屬背景：**\[如：男主身後的窗戶與餐桌\]**（鏡頭推進至中景後，男主身後**嚴格保持窗戶元素**，並按透視放大虛化，絕不更改背景）。
> - **【鏡頭型別與景別】**：\[如：正打中景 / 85mm焦段 / 淺景深\] *(非過肩視角)*
> - **【前景設定】**：\[如：餐桌的一角或水杯微微虛化，增加空間縱深\]
> - **【中景/主體】**：\[如：男主胸部以上，側身轉頭，目光看向畫面左前側的女主方向，表情充滿疑慮\]
> - **【後景/背景】**：\[如：定稿圖中男主身後的窗戶，窗外光線形成逆光，背景大光圈虛化\]
> - **【光影與融合感】**：\[如：繼承定稿圖的光源，窗外透入的強光在男主輪廓上形成自然發光邊緣，環境光漫反射真實，絕無生硬P圖感\]
>
> ❓ **請確認**：您對這個鏡頭的**景別切換與背景鎖定方案**是否滿意？
>
> - 若滿意，請回復 **“確認”** 或 **“生成”**，我將立即為您輸出 Image 2 提示詞。
> - 若想調整，請告訴我修改意見（如：“希望能看到女主的肩膀前景”、“景別再近一點到特寫”等）。

## 輸出

- **產出什麼**：
  1. **定稿圖空間與背景繫結拆解**（上傳/確定定稿圖後輸出）。
  2. **單鏡頭構圖與背景對齊預判**（含前景、中景/主體、後景/特定背景、光影融合）。
  3. **互動確認提問**（必須獲得使用者許可）。
  4. **Image 2 中文提示詞**（確認後輸出，嚴格包含“在定稿圖的基礎上……”及專屬背景對齊指令）。

## 自檢

- \[ \] **背景防穿幫重中之重自檢**：當切到男主/女主單人景別時，提示詞中是否**精準寫明瞭定稿圖裡該角色身後的具體背景**（如男主身後的窗戶）？背景是否與定稿圖一致？
- \[ \] **透視與景深自檢**：景別縮小（如全景變中景/特寫）時，背景是否加上了大光圈虛化和透視放大的描述？
- \[ \] **單張生成與確認自檢**：是否僅輸出了當前這**一張**鏡頭？是否在輸出 Prompt 前輸出了預覽方案並**提問等待使用者確認**？
- \[ \] **構圖多樣性自檢**：本次視角是否避免了單一的掛肩視角？景別是否合理使用了中景/近景/特寫？
- \[ \] **光影融合自檢**：Prompt 是否包含了“逆光邊緣”、“環境光漫反射”、“光影自然過渡”等防 P 圖感詞彙？

## Ask User

- **初始階段**：
  - 若未指定，詢問**畫幅比例**（16:9 / 2.35:1 等）與**電影調色風格**（青橙 / 暗調懸疑 / 膠片等）。
  - 引導使用者上傳“第一張定稿圖”，或由 Skill 協助創作第一張交代人物與背景關係的定稿圖。
- **每張分鏡圖生成前（強制互動）**：
  - 展示【構圖與背景對齊方案】後，明確提問：“**請確認：您對該鏡頭的景別與背景鎖定方案是否滿意？確認後我將為您生成提示詞。**”
- **單張 Prompt 輸出後**：
  - 提示：“請使用以上提示詞去 Image 2 生成圖片。生成滿意後，請告訴我後續劇情或說‘下一步’，我們將開始推演下一個鏡頭。”
