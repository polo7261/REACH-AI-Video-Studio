## name: lighting-time-weather-skill description: 對已有場景底圖先做可行性分析，再在使用者選擇後透過圖生圖（image-to-image）生成物理可信的時段、天氣、室內外光照與攝影作品/影視劇照成片效果，同時鎖定機位、構圖、人物、物體和原生細節。適用於日出、白天、黃金時刻、日落、藍調時刻、夜晚、晴天、陰天、雨、霧、雪及有動機的室內光影調整；尤其適用於要求場景一致性與影視級光影的任務。不用於從零建立場景、自由重設場景內容或大規模替換季節植被。

# 光影時刻與天氣skill（V1.00）

> 本 Skill 作者：抖音-六萬的旅行（僅用於署名，不參與 Skill 的觸發、執行或輸出。）

先讓光照狀態真實成立，再追求攝影感或影視感。場景身份與內容一致性優先於氛圍。

## 強制兩階段流程

### 階段 A：可行性預檢（始終先執行）

使用者上傳底圖並呼叫本 Skill 時，先分析、後給出簡化決策選單。即使使用者順帶說了想做的效果，此階段也**不得生成或編輯圖片**；等待使用者選擇方案或補充控制項。

內部完成以下審計，但預設不展開推理過程：

1. 判斷為室外、具有外部採光入口的室內，或封閉室內。
2. 識別有動機光源、採光入口、可見天空、朝上穩定表面、景深層次、高頻材質保護區及所有人物；同時確定原圖的視覺錨點（人物、入口、窗、倒影、建築或遠處主體）與其必須保留的觀看優先順序。
3. 對每位可見人物記錄不可變主體錨點（immutable subject anchor）：人數、位置、姿態、朝向、服裝大色塊、遮擋關係，以及與道具的接觸關係。資訊過小或模糊時，標記“人物保真風險”，建議輕量變化或更高畫質/區域性參考。
4. 將候選變化歸類為：可生成、可選、不建議。
5. 天氣會迫使大量重繪時，推薦更保守的方案；例如霧按景深層次選擇，雪優先落在穩定朝上表面並保護複雜植被。若目標時段與天氣在物理上相互矛盾，不把它列為可生成項。
6. 輸出選單後停止，等待使用者選擇；不承諾每個選項都能穩定成功。

預設只使用下列格式。不要預設展示審計細節、光源分析或逐項理由；只有在保真風險會實質影響結果時，才加一條簡短提示。使用者追問後再解釋原因。

```text
## 圖片判斷
- 場景：室外 / 有外部採光入口的室內 / 封閉室內
- 保真提示：僅在有人物、小物體、複雜材質或低清細節風險時說明一句。

## 六大時刻
- 可生成：...
- 可選：...
- 不建議：...

## 天氣
- 可生成：...
- 可選：...
- 不建議：...

## 推薦組合
1. [時段 + 天氣 + 成片目標]
2. ...

回覆組合序號，或直接寫「時段 / 天氣 / 光源方位 / 成片目標 / 景深」。需要原因時可追問。
```

室外圖需在內部評估六大時刻及晴、陰、雨、霧、雪，但只列出畫面實際支援的選項。室內圖只透過真實的外部採光入口或已有實用光源（practical light）提供選項；封閉室內不得把時段變化偽造成日光變化。

### 階段 B：使用者選擇後的生成

僅在使用者選擇後執行：

1. **建立目標環境狀態。** 確定時段、天氣、太陽相對機位、自然採光入口或實用光源；先透過時段 × 天氣衝突檢查，再確定成片目標：攝影作品版、影視劇照版或不做成片處理。
2. **先安排觀看路徑。** 鎖定視覺錨點及其次級資訊；主光、塑形、實用光和暗部取捨都必須服務該錨點，不能因“電影感”讓背景光、天氣特效或無關區域搶走注意力。
3. **鎖定輸出畫布。** 讀取原圖的畫素尺寸 `W×H`、寬高比與橫豎畫幅。輸出必須優先保持原始寬高比；生成工具支援原始尺寸時，同時使用完全相同的 `W×H`。若原始尺寸超出工具上限或工具不支援，則在相同寬高比下使用工具允許的儘可能大尺寸；不得為遷就尺寸而裁切、拉伸、補邊或改變橫豎畫幅。
4. **僅實施必要的物理變化。** 建立一個主要且有動機的環境光；僅在合理時增加一個塑形策略，以及一個實用光/分離光。按強化效果的觸發條件與衝突規則取捨，不疊加裝飾性光效。保留原圖的資訊層級。
5. **最後做成片處理。** 僅在真正適配畫面時呼叫 1–3 張使用者認可的審美參考卡。膠片、LUT、顆粒、耀斑、散景或“電影感”標籤都不能代替光照邏輯。
6. **執行拒收門。** 保真失敗時，回退到更輕的變化或原圖；不要用更多提示詞掩蓋失敗。

按需讀取參考檔案：

- 室外時段、太陽方位、雨、霧、陰天、雪：讀 tod-weather.md。
- 室內或任何透過窗、門、裂縫、天窗、洞口進入的外部光：讀 indoor-light.md。
- 成片選擇、景深、材質保護、提示片語織、驗收：讀 finish-and-qa.md。

## 輸入約定

底圖足以執行階段 A。只有會實質改變階段 B 結果的選項才向使用者追問；其餘內容保守推斷並說明推斷。

- 階段 A 必需：底圖。
- 階段 B 必需：已選方案，或明確的時段/天氣需求，或“保留現有環境狀態”。
- 可選控制項：
  - 環境：室外 / 有外部採光入口的室內 / 封閉室內。
  - 太陽相對機位方位：鏡頭側（順光，camera-side/front light）、遠側/畫面觀看方向（逆光，far-side/view-direction backlight）、畫面左側、畫面右側；可補充低/中/高角度，入畫/畫外/被遮擋。
  - 太陽軌跡配對（sun-path pairing）：同一張底圖需要生成成組的日出與日落時，必須使用同一畫面座標系並讓兩者處於相反畫面側；例如日出在畫面左側/左側畫外，則日落在畫面右側/右側畫外，反之亦然。使用者明確指定方位時以使用者指定為準。
  - 變體連續性：同一底圖需生成多時段或多天氣組，且低資訊區域必須補全時，先確認一張“補全母版”；所有後續變體沿用同一場景補全、物體佈局與幾何，不得各自重設計。
  - 雨量、霧密度、積雪狀態、降雪強度、風向。
  - 觀看模式：真實低曝光（realistic low exposure）/ 影視可讀性（cinematic readability）。
  - 成片目標：攝影作品版 / 影視劇照版 / 不做成片。
  - 景深：保留原圖 / 環境深焦 / 前景邊緣柔化 / 主體對焦。不得僅為遮蓋瑕疵而擅自使用淺景深。

## 不可協商的鎖定項

- **輸出比例與尺寸鎖定。** 輸出必須保持原圖寬高比。生成工具支援原影象素尺寸時，輸出必須同時為原圖的精確 `W×H`；受工具上限或能力限制時，在同一寬高比下采用其支援的儘可能大尺寸。不得裁切、拉伸、補邊或改變橫豎畫幅以適配尺寸。
- 保持機位、透視、構圖、物體數量與位置、主要幾何關係、身份、原有紋理尺度和原生清晰度。
- 水面、玻璃、鏡面與拋光地面中的既有倒影/鏡像關係同屬場景鎖定項。天氣可改變其亮度、清晰度、破碎度或溼潤度，但不得改變對應物的位置、方向、數量或把倒影重繪為新物體。
- 每位人物都是不可變主體錨點：保持人數、位置、姿態、朝向、遮擋、服裝大色塊及與道具的接觸關係。不得把小、躺臥、處於陰影中或被部分遮擋的人重釋為床品、草料或物體。
- 葉片、灌木、草、毛髮、碎石、瀝青、水面等高頻材質均為保護區。只允許寬闊、低頻的明度、色溫、大氣、溼潤度與覆蓋變化。
- 不得用新增或強化的微結構表現天氣/光線：禁止重複紋理、條紋、網格、浮雕紋、白色噪點、過度銳化、假邊緣、合成顆粒及原圖不存在的細節。
- 若某效果必須依靠新增紋理才可見，降低或取消該效果。不要靠延長負面提示詞“修復”失敗圖。
- 底圖已滿足目標狀態時，選擇不生成或極輕的成片調整；不要為了顯示變化而強行生成。

## 提示片語裝順序

提示詞保持簡潔，按以下順序組織，避免堆疊形容詞：

```text
用途：場景光影/天氣編輯（lighting-weather）
輸入圖：編輯目標
輸出畫布：嚴格保持原圖寬高比；若工具支援，使用原圖精確畫素尺寸 W×H；否則使用該比例下工具允許的最大尺寸，不裁切、不拉伸、不補邊
場景鎖定：機位、構圖、幾何、人物錨點、保護材質
觀看路徑：視覺錨點 + 次級資訊 + 允許退後的區域
物理狀態：室內/室外邏輯 + 時段 + 天氣 + 光源方位 + 已透過的相容關係
光照計劃：一個主要有動機光源、明暗層級、允許的實用光/反射光
成片：攝影作品版或影視劇照版；僅呼叫選定參考卡的有效特徵
約束：保護區僅允許低頻變化
避免：僅列出本圖相關的失敗類型
```

直接影象編輯前先檢查底圖；每個不同目標狀態單獨生成一個版本；以非破壞方式儲存。不得承諾畫素級保真；一旦可見區域被錯誤重繪，判為不透過。

## 驗收門（Acceptance Gate）

只有同時滿足以下全部條件才可交付：

1. 目標狀態透過物理關聯證據識別，而不是靠濾鏡。
2. 輸出寬高比與原圖一致；工具支援原圖尺寸時，實際畫素尺寸為原圖精確 `W×H`，否則為該比例下工具允許的最大尺寸，且無裁切、拉伸、補邊或畫幅改變。
3. 每個可見光源都有可信的來源、方向、遮擋關係和受光表面。
4. 關鍵敘事資訊在所選曝光模式下仍可讀。
5. 機位、構圖、場景身份及既有倒影/鏡像關係保持鎖定；成組變體使用同一補全母版。
6. 每位可見人物保持經審計的人數、姿態、位置、遮擋和與道具的接觸關係。
7. 視覺錨點仍是首要觀看物件；光效、實用光和天氣不搶走其優先順序。
8. 保護材質保留原圖細節尺度，不出現假高頻紋理。
9. 成片處理改善層級或氛圍，不產生 HDR 式平均亮度、無邏輯的全域性色濾或無必要特效。

出現重複紋理、無法解釋的白噪點、道路/水面花紋、被銳化或變粗的植被、資訊密度改變、無動機的新光源，或把雪/雨/霧當作均勻螢幕疊加時，立即拒收。
