## AI電影打鬥、動作戲、近身格鬥、追逐戰、武器戰、一鏡到底、多人混戰、機甲戰、巨獸戰、戰場動作、動作分鏡提示詞，或需要修復動作混亂、人物瞬移、穿模、換臉、武器變化、打擊感不足、鏡頭亂晃和連續性錯誤。

# AI電影打鬥提示詞

把使用者的場景寫成可執行的動作排程。優先保證動作清楚、空間穩定和狀態連續，再補風格、光線與特效。

## 工作流程

### 1. 確認輸出規格

先從使用者材料中提取以下資訊。缺失且不會改變故事方向時，採用合理預設值，不追問。

- 時長和畫幅
- 一鏡到底或多鏡頭
- 寫實、武俠、超級英雄、機甲或巨獸等戰鬥型別
- 角色與參考圖的對應關係
- 場景、武器、勝負結果和暴力尺度
- 是否需要對白、音樂或純音效

常用預設值為15秒、16比9、24fps、電影寫實、環境音效優先。

### 2. 選擇鏡頭結構

根據戰鬥規模選擇一種結構，全文保持一致。

- 狹窄空間、近身格鬥和短追逐優先用一鏡到底
- 巨獸戰、空戰、大範圍戰場和強節奏蒙太奇優先用多鏡頭
- 使用者要求一鏡到底時，只允許攝影機連續跟隨、環繞、降低、升高和甩動，不得安排編輯切鏡
- 使用者要求多鏡頭時，為每個鏡頭寫獨立時間、景別、機位、動作任務和承接狀態

不要同時要求全程不切鏡和多個無法連續到達的機位。

### 3. 鎖定角色與物件

在時間線前建立連續性規則。

- 鎖定人臉、髮型、體型、服裝、盔甲和顯著配飾
- 說明每張參考圖控制哪個角色或物件
- 寫明武器由哪隻手持有，何時掉落、拾取、損壞或易手
- 多名對手使用A、B、C等固定稱呼，並要求外形彼此不同
- 記錄開場已有的傷勢、溼衣、灰塵、碎甲和裝備狀態

允許物理變化，例如衣服被雨淋溼、髮絲貼臉和盔甲出現裂紋。禁止無原因的換臉、換裝、武器複製和身體比例漂移。

### 4. 建立開場空間

先寫清以下關係，再寫交手。

- 主角在畫面中的位置和朝向
- 對手從哪個方向進入
- 雙方距離
- 門、牆、桌椅、車輛、積水或高低差的位置
- 人物的視線、落腳點和武器起始位置

空間複雜時使用畫面左側、畫面右側、前方、後方和具體距離。避免只寫“敵人突然出現”。

### 5. 按動作容量拆分時間

15秒一鏡到底通常安排4到6個主要動作。每2到4秒完成一個動作段。

每個動作段只承擔一個主要任務，例如突襲、繳械、受挫、反擊、決定性撞擊或殘局收束。給受擊反應、身體恢復和鏡頭追趕留出時間。

多鏡頭可適當提高事件密度，但每個鏡頭仍只保留一個視覺重點。慢動作通常只用於一次關鍵撞擊，持續約0.2到0.5秒。

### 6. 寫出動作因果

每個動作單元按以下順序組織。

```text
攻擊發起 → 防守或閃避 → 身體接觸 → 受擊反應 → 環境反饋 → 下一動作起點
```

優先寫可被演員實際完成的動詞與身體部位。

```text
對手右拳揮向女主面部。女主向左側頭避開，左手扣住其手腕，右肘擊中腹部。對手受擊後向前彎腰。女主順勢按住其後頸，將他推向旁邊的木桌。
```

使用“藉助前衝慣性”“落地後繼續旋轉”“受擊後踉蹌一步”“彎腰後暴露肩背”等連線動作。不要把踢、摔、翻滾和奪刀寫成互不相關的動作清單。

### 7. 讓環境顯示力量

每次關鍵撞擊至少安排一種可見環境反饋，反饋必須符合材質與方向。

- 教室使用課桌位移、書本飛散、粉筆灰和黑板擦痕
- 雨巷使用積水、磚牆水滴、垃圾桶、紙箱、蒸汽和金屬管道
- 雪地使用腳印、雪槽、雪粒、滑行痕跡和碎甲
- 巨獸戰使用浪牆、地面裂紋、霧氣擾動、建築震動和大範圍衝擊波

環境反饋負責說明力量大小和運動方向。避免所有碰撞都用火花、爆炸或無來源煙霧。

### 8. 讓鏡頭響應動作

鏡頭運動必須由人物或撞擊觸發。

```text
人物衝刺時，鏡頭從左後方貼身跟隨。
武器從右側進入時，鏡頭快速向右重新構圖。
人物被擊飛時，鏡頭先發生衝擊震動，隨後甩動追蹤其飛行方向。
兩人倒入積水後，鏡頭降低到近地面側位，短暫失焦後重新鎖定動作。
```

手持攝影可以有呼吸式抖動、撞擊震動、輕微滾動快門和一次短暫失焦。保持主體動作可讀，禁止持續無意義搖晃。

狹窄空間使用近距離跟拍和前景遮擋。巨獸戰增加大全景和遠景，持續顯示體型差與破壞範圍。

### 9. 用運動體現體型與能力差

不要只寫身高數字。把差異寫進運動速度、啟動方式、覆蓋範圍和環境結果。

```text
女主貼近海面高速改變方向。巨獸緩慢抬起手臂，手掌寬度接近女主整個身體長度。巨掌擊中海面後抬起環形浪牆。鏡頭在撞擊發生時迅速拉遠，同時顯示女主的小型輪廓、巨掌和擴散水體。
```

小型角色可輕快、頻繁變向。大型角色應有明顯啟動重量，動作幅度大，落點產生廣泛反饋。

### 10. 設計節奏和結束狀態

一段完整打鬥至少包含一次壓力變化。可以採用下列節奏。

```text
突襲 → 主角應對 → 對手增加壓力 → 主角受挫 → 決定性反擊 → 呼吸與殘局
```

結尾寫成可見狀態，不用抽象情緒代替畫面。

- 人物站、跪或倒在什麼位置
- 武器在哪裡，由誰持有
- 角色看向哪裡
- 哪些物體已經損壞或翻倒
- 傷勢、呼吸、衣服和天氣維持什麼狀態

需要開放結尾時，讓人物保持進攻或防守姿態，並讓下一名對手進入攻擊距離。

### 11. 編寫聲音

根據專案需要寫環境底聲、動作聲和接觸聲。

```text
不使用音樂。保留暴雨、腳步踩水、急促呼吸和溼衣摩擦聲。金屬棍撞管道時出現短促迴響，身體撞牆時為沉悶撞擊聲。環境雨聲持續存在，不因攻擊中斷。
```

寫實近身戰優先保留真實環境音。大型奇幻戰可增加低頻轟鳴、能量聚集和遠處爆炸，但不要讓聲音描述壓過動作時間線。

### 12. 新增有針對性的負面限制

只寫當前場景最可能發生的錯誤。

常用限制包括以下內容。

- 不得瞬移、穿模、肢體融合或無故飛起
- 不得複製人物、換臉、換裝或改變體型
- 不得交換左右手或憑空增加武器
- 不得讓倒地角色無原因重新出現
- 不得使用無意義慢動作、隨機切鏡和持續鏡頭亂晃
- 不得改變既定天氣、光源方向和環境破壞狀態

刪除重複限制和互相沖突的指令。關鍵動作寫清以後再補限制，不要用幾十條禁令代替動作設計。

## 輸出模板

根據使用者需要刪去不適用部分。交付可直接複製的成品提示詞，不把內部分析混入提示詞。

```text
[輸出規格]
時長、畫幅、幀率、一鏡到底或多鏡頭

[參考資產與角色鎖定]
參考圖分工、人物外形、服裝、體型、武器與開場狀態

[場景與空間]
地點、人物朝向、距離、入口、出口與可互動環境

[戰鬥規則]
雙方戰鬥方式、力量差、真實物理要求與暴力尺度

[動作時間線]
0到X秒 進攻、應對、接觸結果、環境反饋與鏡頭響應
X到X秒 承接上一狀態的下一組動作

[聲音]
持續環境聲、動作聲和關鍵接觸聲

[連續性與負面限制]
身份、服裝、武器、傷勢、方位和破壞狀態

[最終畫面]
人物位置、姿態、視線、武器和環境狀態
```

## 完整短案例

使用者需要示範時，可以按以下密度編寫，不要照抄角色與場景。

```text
超寫實雨夜巷戰，15秒，16比9，一鏡到底，全程不切鏡。

保持參考圖女主的面部、黑色短髮、身體比例、灰色機車夾克和黑色長褲一致。女主開場沒有武器。對手A右手持一把伸縮棍。武器掉落後必須經過明確拾取才能易手。

場景位於狹窄後巷。畫面左側是溼潤磚牆和金屬管道，右側有垃圾桶與紙箱，地面連續積水。雨水持續落下，巷道盡頭有模糊霓虹燈。

0到4秒。鏡頭從女主左後方貼身跟隨。對手A從正前方衝來，揮動伸縮棍橫掃她的頭部。女主壓低身體從棍下穿過，左手按住對手手腕，右肘擊中其腹部。對手向前彎腰。女主順勢用肩膀將他撞向左側磚牆。對手後背撞牆，牆面水滴散開，伸縮棍脫手落入積水。

4到9秒。鏡頭降低到腰部位置。女主用右腳將伸縮棍挑起，右手在半空接住。對手B從畫面右側揮拳擊中她的左肩。女主身體向左偏轉，踉蹌一步，隨後利用轉身讓伸縮棍擊中對手B大腿外側。對手失去平衡，撞翻垃圾桶。

9到13秒。對手A從牆邊重新撲來。女主向後跨步卸力，抓住其肩膀，借前衝慣性轉身將他推向金屬管道。對手肩背撞上管道，蒸汽晃動。女主用棍柄擊中其腹部，對手彎腰跪入積水。

13到15秒。鏡頭貼近地面，短暫被水滴遮擋後重新鎖定女主。她後退半步，右手仍持伸縮棍，低頭急促喘息。鏡頭緩慢後拉，展示倒地對手、翻倒的垃圾桶和持續落下的雨。女主轉身走向巷道深處。

全程使用近距離手持紀實攝影。鏡頭隨奔跑與撞擊自然抖動，允許一次短暫失焦，不得持續無意義搖晃。不要慢動作，不要編輯切鏡。只保留暴雨、踩水、喘息、溼衣摩擦、身體撞牆和金屬管道迴響。
```

## 交付前檢查

逐項檢查並直接修正，不把檢查過程交給使用者。

- 每個動作能否由演員連續完成
- 每次攻擊是否寫明方向、接觸點和受擊反應
- 下一動作是否繼承上一動作的姿勢、距離與重心
- 鏡頭能否在規定時間內到達下一機位
- 武器、傷勢、倒地人物和環境破壞是否連續
- 15秒內是否塞入過多動作、慢鏡頭或鏡頭變化
- 風格詞和導演參考是否搶佔了動作資訊
- 是否存在重複句、武器名稱變化或互相矛盾的限制

當使用者只提供一個故事概念時，先補齊合理的動作與空間設計，再交付成品。使用者要求診斷時，指出具體衝突與失敗原因，不擅自改寫。使用者要求最佳化或重寫時，直接修正並給出可複製版本。
