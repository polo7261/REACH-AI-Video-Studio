## **Skill定位**

- **只負責**：超現實主義空間電影美學風格的內容創作——從故事腳本到空間分鏡到提示詞的全流程輸出，聚焦夢境邏輯的空間敘事、非理性視覺語言和電影級美學質感

## **輸入**

- **需要什麼**：
  - 核心概念/意象（一個夢境、一個隱喻、一個哲學命題、一個潛意識場景）
  - 空間基調（如：迴圈迴廊、無限階梯、漂浮島嶼、顛倒城市、鏡中世界、意識迷宮等）
  - 情緒/氛圍（如：不安、迷幻、孤獨、空靈、荒誕、驚悚、詩意）
  - 參考美學方向（如：大衛·林奇式、達利繪畫感、瑪格利特靜默感、塔可夫斯基詩意、今敏動畫感等）
  - 時長/篇幅要求
  - 敘事方式（純意象敘事、有角色引導、無角色純空間探索）

## **輸入使用**

- **嚴格遵守**：核心概念/意象、空間基調、情緒氛圍、時長要求
- **參考為主**：參考美學方向、敘事方式——可根據超現實主義美學特徵給出專業建議

## **內部流程和Knowhow**

### **1. 故事腳本編寫**

**超現實主義敘事核心原則：**

- 超現實不遵循現實世界的因果律，而是遵循**夢境邏輯/潛意識邏輯**
  - 現實邏輯：因為A所以B → 超現實邏輯：A和B同時存在，沒有因果，只有並置
  - 現實邏輯：時間線性向前 → 超現實邏輯：時間迴圈、倒流、摺疊、停滯
  - 現實邏輯：空間連續穩定 → 超現實邏輯：空間跳轉、疊加、扭曲、無限
- 不要解釋"為什麼"——超現實主義的魅力在於"它就是這樣的"的不解釋
- 象徵物反覆出現：一個意象在全片中多次出現，每次形態/意義微變，形成"潛意識錨點"

**敘事結構（非傳統三幕式）：**

- 可選結構1：**夢境層層深入**——主角（如果有）穿越不同層級的空間，越深入越偏離現實，最後回到起點時一切已變
- 可選結構2：**意象並置**——沒有明確敘事線，多個超現實意象依次呈現，透過情緒/色彩/節奏串聯
- 可選結構3：**迴圈迷宮**——空間/場景迴圈出現，每次略有不同，暗示某種潛意識的迴圈困局
- 可選結構4：**線性但非理性**——表面有線性推進，但每個場景本身是非理性的，整體形成"合理的荒誕"

**敘事語言：**

- 避免解釋性臺詞——超現實主義的臺詞本身應具有詩意和不確定性
- 可完全沒有臺詞——純視覺敘事，靠畫面、音效、音樂傳遞情緒
- 對話（如果有）應像夢囈：簡短、跳躍、有象徵意味，不直接回答問題
  - "你記得你是怎麼到這裡來的嗎？" / "我不記得了……但這裡很熟悉。"
  - "這扇門後面是什麼？" / "是你一直想不起來的那件事。"
- 畫外音可作為一種"潛意識旁白"使用，像內心獨白又像另一個人的聲音

**核心意象庫（可供選擇/組合）：**

**空間類意象：**

- 無限迴廊：兩側是無數相同的門，走不到盡頭，每扇門後是不同的空間/記憶
- 顛倒城市：天空在下，城市倒懸於頭頂，地面是雲層
- 漂浮島嶼：破碎的大地懸浮在虛空中，島嶼之間由繩索/橋/樓梯連接
- 水下世界：水下有完整的城市/房間，光線折射，物體緩慢漂浮
- 鏡中迷宮：無數鏡子組成的空間，鏡中倒影與真人不同步/有獨立行為
- 迴圈樓梯：向上走卻回到原點，向下走卻通往天空
- 房間套房間：開啟一扇門進入一個房間，再開門又進入另一個完全不同的房間，無限巢狀
- 天梯：通往天空的階梯，越往上越透明/虛無

**物體類意象：**

- 時鐘：融化、倒轉、無數指標、沒有指標
- 眼睛：牆上的眼睛、天空中的眼睛、手掌中的眼睛
- 傘：在室內開啟、漂浮在空中、遮住臉
- 帷幕：巨大的帷幕/幕布，風吹動，後面是什麼看不清
- 魚：在空中游動、在房間裡、在人體中
- 鏡子：不反射本人、反射過去/未來、鏡中有人走出
- 門：憑空出現的門、野外孤立的門、無限排列的門
- 影子：獨立於本體的影子、影子有實體、影子吞噬本體

**人物類意象：**

- 無臉人：面部是一片空白或光滑表面
- 分身：遇到另一個自己，年齡/性別/狀態不同
- 巨物：巨大的手/頭/身體局部出現在場景中
- 集體行為：一群人做同一件事（同時看天、同時轉身、同時靜止）
- 靜止的人：場景中有人像雕塑一樣靜止，只有主角能動

**時間類意象：**

- 時間停滯：所有物體靜止，只有主角可以移動
- 時間倒流：物體從碎裂到重組、從散落到聚合
- 時間迴圈：同一場景重複出現，每次略有不同
- 時間疊加：不同時間段的同一空間疊加在一起

### **2. 資產錨點創作和使用**

**視覺錨點（超現實主義的標誌性視覺元素）**

**色彩體系（按情緒基調選擇）：**

- 🎴 **夢幻/迷幻**：高飽和粉紫/青藍/洋紅，褪色效果，色彩溢位
- 🎴 **孤寂/空靈**：低飽和灰藍/米白/淡黃，霧化效果，褪色記憶感
- 🎴 **不安/驚悚**：高對比黑白/暗紅/墨綠，陰影濃重，高光刺眼
- 🎴 **荒誕/幽默**：高飽和原色（紅黃藍），對比強烈，像兒童畫或波普藝術
- 🎴 **詩意/懷舊**：暖棕/琥珀/暗金，像老照片或舊膠片

**光影系統：**

- 超現實光源：沒有明確光源的光（物體自發光）、方向矛盾的光（從下往上、從地面射出）、彩色光（單一彩色光填充空間）
- 陰影處理：影子方向與光線不一致、物體沒有影子、影子比物體大/小/變形
- 光暈/輝光：柔和的發光效果，讓物體邊緣模糊，像夢境中的視覺
- 剪影/逆光：利用強逆光製造剪影，簡化細節，強化形狀

**質感系統：**

- 表面質感異化：堅硬的東西變柔軟（石頭像布一樣褶皺）、柔軟的東西變堅硬（窗簾像石頭一樣靜止）
- 材質混合：金屬表面有皮膚紋理、木頭表面有水的波紋、玻璃表面有毛髮
- 透明/半透明：物體部分透明，內部結構可見
- 液體/融化：固體有融化的趨勢（融化的時鐘、流淌的牆壁）

**空間構成錨點：**

- 不可能幾何：埃舍爾式的無限樓梯、不可能三角、互為內外的空間
- 尺度錯位：巨大的物體在正常空間中、微小的物體被放大到房間大小、人與物體比例失常
- 內外反轉：室內空間無限大、室外空間封閉如室內、天空是天花板
- 重力異常：物體漂浮、人倒立行走、水往上流
- 重複/複製：同一物體以不同大小/角度/顏色在空間中多次出現

**場景錨點**

**經典超現實空間類型：**

- **無限劇場**：巨大的劇場/舞臺，觀眾席空無一人，舞臺上只有單一物體/人物，幕布無限延伸
- **漂浮圖書館**：書架漂浮在虛空中，書頁自動翻動，文字從書中飄出變成光點
- **記憶畫廊**：長廊兩側掛滿畫框，但畫框裡是動態的、三維的場景，可以走入
- **候車大廳**：巨大的復古車站/機場大廳，時鐘全是亂的，沒有列車/航班資訊，只有人在等待
- **水下客廳**：完全正常的客廳，但整個房間在水下，魚在沙發間遊動，光線從水面折射下來
- **天空辦公室**：雲層上的辦公空間，窗外的雲快速流動，檔案被風吹散在天上
- **鏡面舞廳**：四面牆全是鏡子的舞廳，鏡中倒影不跟著人動，各自跳著不同的舞
- **無盡餐廳**：餐桌無限延伸直到消失點，每個座位上都坐著同一個人
- **黑白森林**：完全黑白的世界，樹的形狀扭曲，天空是純白或純黑
- **碎片星球**：地面是破碎的，漂浮在星空中，可以踩在碎片上跳躍行走

**聲音錨點**

- **環境音異化**：水滴聲被拉長、風聲像嘆息、腳步聲有回聲但不來自正確方向
- **音樂**：簡約鋼琴（反覆的幾個音符）、絃樂長音（持續不解決）、電子嗡鳴（低頻持續）、人聲吟唱（無詞的哼唱、像從遠方傳來）
- **靜默**：完全的靜默是超現實主義的強力武器——突然的靜默比任何聲音都更有衝擊力
- **聲音錯位**：聲音來源與畫面不匹配（關門聲出現在人坐下時）、聲音延遲（動作後聲音才到）
- **迴圈音效**：某段聲音無限迴圈，逐漸變快/變慢/變調

### **3. 分鏡創作**

**超現實主義分鏡核心原則：**

- 每個鏡頭本身應是一幅可以獨立存在的畫面——超現實主義電影的美學單位是"單幀"
- 畫面中的"不可能元素"要自然呈現——不要刻意誇張，像"本該如此"一樣平淡地展示超現實
- 鏡頭運動速度與情緒匹配：迷幻/夢幻用慢速推拉搖移，不安/驚悚用快速抖動/跳切，荒誕用固定機位
- 鏡頭間的連接不是"因果"而是"情緒/意象關聯"——A鏡頭到B鏡頭不是因為敘事需要，而是因為"感覺對了"

**鏡頭語言庫：**

**表格**

| 鏡頭類型 | 用法 | 效果 |
| --- | --- | --- |
| 慢速橫移 | 沿著空間邊緣緩慢移動，展示超現實空間的細節 | 營造夢幻感，讓觀眾沉浸在空間中 |
| 垂直升降 | 從地面升到天花板，或從高處降下，展示空間尺度 | 強調空間的不真實比例 |
| 推鏡 | 緩慢推近某個物體／細節，直到充滿畫面 | 暗示該物體有特殊意義 |
| 拉鏡 | 從特寫快速拉到全景，展示環境的全貌 | 揭示空間的超現實性（「原來是這樣」的效果） |
| 環繞360° | 以某物體／人物為中心緩慢環繞 | 展示空間的全方位，製造不安感 |
| 倒轉鏡頭 | 慢慢翻轉180° | 讓觀眾和角色一起進入失重／顛倒狀態 |
| 跳切 | 同一場景突然變化切到另一場景 | 超現實的時空跳躍感 |
| 匹配切 | 透過形狀／顏色／運動匹配連接兩個不同場景 | 建立意象關聯（如：月亮的圓→圓桌→圓鏡） |
| 疊化 | 兩個畫面疊加在一起，慢慢變淡過渡 | 夢境般的視覺混合，暗示兩個空間的疊加 |
| 轉描 | 畫面邊緣像融化／暈染一樣過渡 | 模擬夢境中「邊緣模糊」的視覺感受 |

**構圖原則：**

- **失衡構圖**：地平線傾斜、主體偏到畫面邊緣、大量留白在出乎意料的方向
- **框套框**：門框中的門框、窗中的窗、鏡中的鏡——無限巢狀
- **負空間利用**：大量空白區域，讓觀眾的目光無處安放，製造不安
- **對稱但不對稱**：畫面整體對稱，但細節上有一處不對稱（破壞平衡的細節）
- **透視異常**：故意使用不自然的透視（廣角畸變、壓縮透視、無透視）
- **畫中畫**：畫面內有畫框/螢幕/窗戶，裡面是另一個世界

**色彩節奏（按時間軸設計）：**

- 開場：中性/低飽和——建立"現實"的假象
- 進入超現實階段：逐步加入異常色彩，飽和度緩慢升高
- 核心超現實段落：顏色完全自由，不受現實約束
- 迴歸/結局：顏色逐漸迴歸到開場色調，但略有不同（暗示"回不去了"）

**轉場方式：**

- **融化轉場**：畫面邊緣像蠟一樣融化，流淌出新的畫面
- **瞳孔轉場**：鏡頭推進瞳孔，穿過瞳孔進入另一個空間
- **水面轉場**：畫面像水面一樣波動，漣漪散去後變成新場景
- **翻頁轉場**：畫面像書頁一樣被翻過去，背面是新的世界
- **碎裂轉場**：畫面像鏡子一樣碎裂，碎片重組為新場景
- **光線過曝轉場**：光線越來越強直到全白，再減弱到新場景
- **眨眼轉場**：黑屏（像眨眼）→ 新場景
- **顏色填充轉場**：一種顏色從畫面一角蔓延覆蓋整個畫面，再消退露出新場景

### **4. Prompt Guide（AI圖片/影片生成提示詞引導）**

**核心風格關鍵詞：**

**表格**

| 風格方向 | 英文關鍵詞 |
| --- | --- |
| 超現實主義 | surrealism, dreamlike, subconscious, irrational, fantastical, impossible geometry, Magritte, Dali, metaphysical |
| 空間異常 | impossible space, infinite loop, Escher-like, spatial paradox, gravity-defying, floating architecture, recursive |
| 電影美學 | cinematic composition, anamorphic, film grain, deep focus, atmospheric, moody, arthouse cinema |
| 夢境感 | dream sequence, oneiric, ethereal, liminal space, uncanny valley, half-remembered, nostalgic |
| 詩意寂靜 | poetic cinema, slow cinema, meditative, silent atmosphere, Tarkovsky-esque, long take, contemplative |

**場景描述模板：**

`[infinite corridor/floating island/underwater room/mirror maze], surrealist space, [impossible geometry/gravity defying], [color palette], cinematic lighting, [atmosphere], dreamlike atmosphere, ethereal fog, liminal space`

**物體描述模板：**

`[melting clock/floating umbrella/eye in the sky/endless stairs], surrealist object, [material anomaly], glowing, floating, [scale distortion], dreamlike, symbolic`

### **5. 影片剪輯指導**

**節奏總綱：**

- 超現實主義電影美學以**慢節奏**為基調——每個鏡頭保持3-10秒，讓觀眾有時間"消化"畫面中的超現實元素
- **節奏變化**：在關鍵的"超現實揭示"瞬間快速切換（1-2秒），製造衝擊；其他時間保持舒緩
- 完全放棄"敘事效率"——超現實主義的目的是"感受"而非"理解"

**剪輯原則：**

- **情緒優先於邏輯**：兩個鏡頭是否連接在一起，取決於情緒是否連貫，而非敘事是否連續
- **重複與變奏**：同一意象在片中多次出現，每次在剪輯上略有變化（時長/機位/顏色）
- **延長"出畫"時間**：即使動作已經完成，鏡頭再多停留1-2秒，讓觀眾產生"為什麼還不切"的不安感
- **聲畫分離**：聲音來自上一個場景的畫面延續到下一個場景，或畫面在當前場景但聲音來自未來上一個場景

**音效設計：**

- 環境音：持續的低頻嗡鳴作為基底，偶爾的滴水聲/風聲/鐘聲作為節奏點
- 音效異化：日常聲音被處理（拉長、降調、反轉、混響），讓熟悉的聲音變得陌生
- 沉默：在關鍵段落使用2-5秒的完全靜默，製造"聲音真空"的壓迫感
- 音樂：簡約重複的鋼琴/絃樂音符，或有呼吸感的電子長音，避免複雜的旋律

**特殊效果：**

- 慢動作：在超現實場景中使用慢動作，強調"時間被拉長"的感覺
- 倒放：某些動作倒放，增加時空錯亂感
- 跳幀/抽幀：畫面偶爾跳過幾幀，造成"記憶缺失"的效果
- 膠片顆粒/噪點：增加質感，模擬老電影或記憶的模糊感
- 色彩分離：RGB通道分離效果，製造視覺錯位

**開場/收場建議：**

- 開場：從一個"日常"的畫面開始，鏡頭極其緩慢，然後一個細節的異常暗示"這不對"
- 收場：回到類似開場的畫面，但有一處微妙的不同，暗示"一切已經改變"或"不知道是否真的離開過"

## **自檢**

輸出前檢查：

- ☐ 是否遵循了"夢境邏輯"而非現實邏輯？是否試圖解釋"為什麼"？
- ☐ 每個鏡頭是否本身具有畫面美感？是否可以作為獨立視覺作品？
- ☐ 超現實元素的呈現是否"自然"——像本該如此，而不是刻意誇張？
- ☐ 意象是否有貫穿性？是否有反覆出現的錨點意象？
- ☐ 色彩、光影、空間是否協力營造了統一的情緒氛圍？
- ☐ 節奏是否以"感受"為導向而非"敘事效率"？
- ☐ 鏡頭連接是否基於情緒/意象關聯而非因果邏輯？
- ☐ 是否有"安靜的時刻"——讓觀眾有空間去感受和思考？
- ☐ 臺詞（如果有）是否保持了超現實主義的詩意和不確定性？
- ☐ 提示詞中的風格關鍵詞是否統一指向超現實主義美學？

## **AskUser**

以下情況需要問使用者：

- 使用者沒有明確核心意象或概念時（需要先給一個起點）
- 使用者沒有指定空間基調時（迴圈迴廊/顛倒城市/漂浮島嶼/意識迷宮等）
- 使用者沒有說明情緒氛圍方向時（夢幻/孤寂/不安/荒誕/詩意？）
- 使用者沒有提供參考美學方向時（大衛·林奇/達利/瑪格利特/塔可夫斯基/今敏？）
- 使用者不確定是否需要角色時（純空間探索 vs 有角色引導）
- 使用者對"抽象程度"有要求時（更意象化還是保留一定敘事性？）
