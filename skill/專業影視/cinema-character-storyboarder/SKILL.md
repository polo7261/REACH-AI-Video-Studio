# 造梦片场

## 適用場景

平台短剧、品牌 TVC、游戏 CG 预告、小说改编试片、比赛投稿
时长 60 秒 – 10 分钟
单人创作或小团队，没有专职分镜师

## 輸出

一句题材，直出剧本、分镜、美术资产与逐镜提示词，拿到手就能开

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
