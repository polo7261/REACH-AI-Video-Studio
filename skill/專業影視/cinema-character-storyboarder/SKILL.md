# 造夢片場

## 適用場景

平台短劇、品牌 TVC、遊戲 CG 預告、小說改編試片、比賽投稿
時長 60 秒 – 10 分鐘
單人創作或小團隊，沒有專職分鏡師

## 輸出

一句題材，直出劇本、分鏡、美術資產與逐鏡提示詞，拿到手就能開

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
