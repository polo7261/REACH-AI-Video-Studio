# 爆款女频短剧实拍成片·全流程完整版 v2

## 適用場景

用户要创作并制作爆款女频短剧成片（重生复仇、豪门千金、古装虐恋、先婚后爱、萌宝甜宠、穿书女配、仙侠虐恋等），需要从剧本或灵感出发完成编剧框架、生图资产、量化镜头逐镜表提示词、运镜判定、站位锚方案与 Seedance 2.5 实拍工序时使用。

## 輸出

剧作导演工作台本：题材定位、爆款元素速查、人物小传、分集大纲、单集剧本、AI 生图资产提示词（人物／场景／道具三风格全套，含六区布局与逐字英文模板）、导演阐述（含运镜判定与站位锚方案）、四段式视频段落提示词、规范性自检表；外加站位锚搭建方案与生成工序清单。

## 使用方式

此 skill 為 OiiOii（LibTV）平台 composer 模板：在平台畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
