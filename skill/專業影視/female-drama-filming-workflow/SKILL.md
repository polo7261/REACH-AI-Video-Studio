# 爆款女頻短劇實拍成片·全流程完整版 v2

## 適用場景

使用者要創作並製作爆款女頻短劇成片（重生復仇、豪門千金、古裝虐戀、先婚後愛、萌寶甜寵、穿書女配、仙俠虐戀等），需要從劇本或靈感出發完成編劇框架、生圖資產、量化鏡頭逐鏡表提示詞、運鏡判定、站位錨方案與 Seedance 2.5 實拍工序時使用。

## 輸出

劇作導演工作臺本：題材定位、爆款元素速查、人物小傳、分集大綱、單集劇本、AI 生圖資產提示詞（人物／場景／道具三風格全套，含六區佈局與逐字英文模板）、導演闡述（含運鏡判定與站位錨方案）、四段式影片段落提示詞、規範性自檢表；外加站位錨搭建方案與生成工序清單。

## 使用方式

此 skill 為 OiiOii（LibTV）平臺 composer 模板：在平臺畫布選取此 skill 後，輸入主題或素材即可照其流程生成。本機掛載時，將上述定位與輸出規則提供給 agent 作為執行依據。
