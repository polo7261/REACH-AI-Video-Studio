## 爆点评估框架（挑段/定钩子的核心工艺，两路共用）

无论是从长素材里挑，还是从零写脚本，都按这套框架判"哪一段值得独立成片""前几秒放什么"：

一段素材/一个脚本点位越命中下面这些，越该被选中、越靠前排：

- **钩子瞬间**：开头 1 秒内能拽住人的强开场。
- **情绪峰值**：笑点、泪点、爽点、愤怒点等情绪冲高处。
- **观点炸弹 / 反直觉**：与常识相悖、敢下判断的强观点。
- **揭示时刻**："原来如此""其实是……"的信息翻转。
- **冲突**：对立、争执、打脸、反转。
- **金句**：可被单独截图/引用的一句话。
- **故事高潮**：叙事张力最高的节点。
- **实用价值**：可立刻上手的干货、清单、步骤。

对每个候选片段/脚本点位，给三样东西（这是排序与复盘依据，也是回报给用户的结构）：

- **评分**（0–100，命中越多越高）；
- **开场钩子句**（这条片子头 1 秒说/写什么）；
- **一句话"为什么行"**（命中了上面哪几点）。

重叠/雷同的候选按分数去重，只留最高的那条，不要输出内容高度重合的多条切片。

## A 路 · 长素材切片流程

1. **分析源视频**：把用户提供的长视频（可信 URL / 本地路径）交给源视频分析，得到分段结构（segments）与语义边界。此步是"读懂素材"，不产出成片。
2. **按爆点框架挑段**：对分段逐一按上面的评估框架打分、找钩子、写"为什么行"，去重后取 Top-N（N=平台基线或用户指定）。
3. **定切点**：每条切片确定起止时间，让它自带完整的"钩子→高潮"，头 1 秒即钩子；控制在平台时长甜区。
4. **竖屏化**：把选中片段裁成目标画幅（`9:16` / `1:1`）。主体不出画——把关键人物/主体保持在竖屏安全区中央；无自动人脸追踪能力时，按主体位置人工定裁切框，主体移动明显的段落分镜头跟裁。
5. **字幕**：给每条切片配台词/要点字幕（合成阶段叠加或内嵌，按 SP）。
6. **成片与合成**：用 `composite_video` 输出每条竖屏成片；如需重生成画面/转场，配 `generate_video_v3`。
7. **回报**：对每条切片给出 排名 / 评分 / 时间区间 / 标题 / 钩子句 / 成片，让用户一眼挑用。

> 说明：源工具那套服务端"转写+自动排名+去重+人脸追踪裁切"的托管切割在本环境没有对应能力——所以转写/排名/去重/裁切改为用源视频分析 + 上面的爆点框架 + 人工定切点/裁切框来承载，框架本身照搬。

## B 路 · 从零合成流程

1. **主题→脚本**：给定主题或文案，写旁白脚本；分段短句，按爆点框架安排——开头 1 秒给钩子，中段铺情绪/观点/揭示，收尾留金句或行动点。
2. **旁白**：`generate_audio`（TTS）按脚本生成旁白；音色、情绪、语速写清。
3. **画面**：逐句/逐段用 `generate_image_v3` 出配图，或 `generate_video_v3` 出动态画面——**无出镜真人**，靠 B-roll / 图示 / 场景 / 数据可视化承载；全片视觉风格统一。
4. **字幕**：台词/旁白字幕（合成阶段叠加，或视频内嵌，按 SP）。
5. **合成**：`composite_video` 按旁白时间线拼接，配 BGM；`generate_audio` 出配乐或音效。竖屏 `9:16`。

## 通用要点

- **faceless**：全程不依赖真人出镜/口型；画面靠配图 / B-roll / 生成场景 / 图示承载。
- **前 3 秒定生死**：钩子越早越好，Shorts/Reels 争取头 1 秒；节奏紧凑，不铺垫。
- **竖屏优先**：默认 `9:16`；主体居中、留字幕安全区。
- **批量**：多条需求按成片用 task 逐条跟踪进度。

## 常见坑

- **画幅错配**：竖屏平台一律 9:16，别用横屏素材直接发；平台预设已定好，除非明确理由否则不覆盖。
- **凑数塞废片**：够格爆点不足就少给，不要为凑条数输出低分切片。
- **重复切片**：内容高度重合的候选先按分数去重，只留最高一条。
- **主体出画**：竖屏裁切要保证关键主体始终在画面内、不被裁掉。
