## 爆點評估框架（挑段/定鉤子的核心工藝，兩路共用）

無論是從長素材裡挑，還是從零寫指令碼，都按這套框架判"哪一段值得獨立成片""前幾秒放什麼"：

一段素材/一個指令碼點位越命中下面這些，越該被選中、越靠前排：

- **鉤子瞬間**：開頭 1 秒內能拽住人的強開場。
- **情緒峰值**：笑點、淚點、爽點、憤怒點等情緒衝高處。
- **觀點炸彈 / 反直覺**：與常識相悖、敢下判斷的強觀點。
- **揭示時刻**："原來如此""其實是……"的資訊翻轉。
- **衝突**：對立、爭執、打臉、反轉。
- **金句**：可被單獨截圖/引用的一句話。
- **故事高潮**：敘事張力最高的節點。
- **實用價值**：可立刻上手的乾貨、清單、步驟。

對每個候選片段/指令碼點位，給三樣東西（這是排序與覆盤依據，也是回報給使用者的結構）：

- **評分**（0–100，命中越多越高）；
- **開場鉤子句**（這條片子頭 1 秒說/寫什麼）；
- **一句話"為什麼行"**（命中了上面哪幾點）。

重疊/雷同的候選按分數去重，只留最高的那條，不要輸出內容高度重合的多條切片。

## A 路 · 長素材切片流程

1. **分析源影片**：把使用者提供的長影片（可信 URL / 本地路徑）交給源影片分析，得到分段結構（segments）與語義邊界。此步是"讀懂素材"，不產出成片。
2. **按爆點框架挑段**：對分段逐一按上面的評估框架打分、找鉤子、寫"為什麼行"，去重後取 Top-N（N=平臺基線或使用者指定）。
3. **定切點**：每條切片確定起止時間，讓它自帶完整的"鉤子→高潮"，頭 1 秒即鉤子；控制在平臺時長甜區。
4. **豎屏化**：把選中片段裁成目標畫幅（`9:16` / `1:1`）。主體不出畫——把關鍵人物/主體保持在豎屏安全區中央；無自動人臉追蹤能力時，按主體位置人工定裁切框，主體移動明顯的段落分鏡頭跟裁。
5. **字幕**：給每條切片配臺詞/要點字幕（合成階段疊加或內嵌，按 SP）。
6. **成片與合成**：用 `composite_video` 輸出每條豎屏成片；如需重生成畫面/轉場，配 `generate_video_v3`。
7. **回報**：對每條切片給出 排名 / 評分 / 時間區間 / 標題 / 鉤子句 / 成片，讓使用者一眼挑用。

> 說明：源工具那套服務端"轉寫+自動排名+去重+人臉追蹤裁切"的託管切割在本環境沒有對應能力——所以轉寫/排名/去重/裁切改為用源影片分析 + 上面的爆點框架 + 人工定切點/裁切框來承載，框架本身照搬。

## B 路 · 從零合成流程

1. **主題→指令碼**：給定主題或文案，寫旁白指令碼；分段短句，按爆點框架安排——開頭 1 秒給鉤子，中段鋪情緒/觀點/揭示，收尾留金句或行動點。
2. **旁白**：`generate_audio`（TTS）按指令碼生成旁白；音色、情緒、語速寫清。
3. **畫面**：逐句/逐段用 `generate_image_v3` 出配圖，或 `generate_video_v3` 出動態畫面——**無出鏡真人**，靠 B-roll / 圖示 / 場景 / 資料視覺化承載；全片視覺風格統一。
4. **字幕**：臺詞/旁白字幕（合成階段疊加，或影片內嵌，按 SP）。
5. **合成**：`composite_video` 按旁白時間線拼接，配 BGM；`generate_audio` 出配樂或音效。豎屏 `9:16`。

## 通用要點

- **faceless**：全程不依賴真人出鏡/口型；畫面靠配圖 / B-roll / 生成場景 / 圖示承載。
- **前 3 秒定生死**：鉤子越早越好，Shorts/Reels 爭取頭 1 秒；節奏緊湊，不鋪墊。
- **豎屏優先**：預設 `9:16`；主體居中、留字幕安全區。
- **批次**：多條需求按成片用 task 逐條跟蹤進度。

## 常見坑

- **畫幅錯配**：豎屏平臺一律 9:16，別用橫屏素材直接發；平臺預設已定好，除非明確理由否則不覆蓋。
- **湊數塞廢片**：夠格爆點不足就少給，不要為湊條數輸出低分切片。
- **重複切片**：內容高度重合的候選先按分數去重，只留最高一條。
- **主體出畫**：豎屏裁切要保證關鍵主體始終在畫面內、不被裁掉。
