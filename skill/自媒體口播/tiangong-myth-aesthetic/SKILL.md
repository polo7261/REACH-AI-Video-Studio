# 天宮美學 Skill

## 一、基礎設定

1. **預設模型**：Lib Image

2. **預設畫幅**：16:9 橫版

3. **預設出圖數量**：1 張穩定經典版；只有使用者明確要求時才生成多版

4. **提示詞展示規則**：生成圖片前，必須先向使用者展示完整六段式提示詞

5. **影片 / 音樂規則**：只輸出“完整版 + 精簡版”提示詞，不自動生成

---

# 二、核心審美原則

預設氣質：\
**超寫實、電影級、東方神話、莊嚴、剋制、神聖、空靈、蒼茫、低飽和、真實材質、強空氣透視、大面積留白、高階電影美學。**

避免：\
**豔麗廉價仙俠遊戲風、過度金碧輝煌、霓虹色、密集粒子、現代建築感、古風寫真感、元素堆砌、人物搶主體。**

創作順序：

1. 先定鏡頭

2. 再定空間

3. 再定主體

4. 再定奇觀

5. 人物作為尺度參照

6. 神獸作為點睛

空間層級：

- **近景**：巨松、宮柱、屋簷、岩石、虛化枝葉

- **中景**：人物、平臺、長廊、白玉欄杆、橋、鏡湖

- **遠景**：天宮、月宮、天門、主殿、宮殿群

- **超遠景 / 奇觀終點**：巨月、圓門、鯤、龍、瀑布、倒影、天河盡頭

---

# 三、固定六段式提示詞結構

## 1）整體描述

作用：一句話說明“是什麼場景 + 核心奇觀 + 整體氣質”。

模板：

> 超寫實電影級東方神話場景，【主題名稱】，畫面圍繞【核心奇觀】展開，整體呈現【神聖 / 空靈 / 莊嚴 / 蒼茫 / 超現實 / 安靜】的東方天界氣質。

要求：

- 不堆砌細節

- 先鎖定主題

- 明確唯一視覺核心

- 確定情緒與世界觀

---

## 2）構圖形式

作用：先規定鏡頭語言，再安排畫面元素。

模板：

> 16:9 橫版畫面，超廣角遠景，採用【構圖類型】。近景由【前景元素】形成遮擋或框景，中景為【平臺 / 長橋 / 長廊 / 鏡湖 / 人物區域】，遠景主體為【天宮 / 月宮 / 天門 / 主殿】，視線最終落在【奇觀 / 神獸 / 巨月 / 圓門】。

常用構圖：

- 中軸對稱

- 極端偏心

- 前景壓框

- 框中框

- 強對角透視

- 長廊引導線

- S 形引導線

- 反透視

- 中央空洞

- 上下鏡像

- 高機位鳥瞰

構圖規則：

- 不預設中軸對稱

- 構圖必須服務主題

- 前景可佔畫面約 25%–50%

- 可讓建築被畫面邊緣裁切，增強巨大尺度感

- “局部顯露”優先於“全部展示”

- 必須形成明確視線路徑：\
  **前景框景 → 中景人物 → 遠景建築 → 深處奇觀**

---

## 3）主體場景描述

作用：按照空間層級描述畫面，而不是單純堆元素。

固定順序：

**前景 → 中景 → 遠景 → 奇觀 / 神獸**

模板：

> 無邊無際的厚重雲海鋪滿整個世界，【前景元素】貼近鏡頭形成空間層次；【中景空間】作為視覺過渡；遠處主體建築由白玉基座、硃紅木構、層疊飛簷與淡金屋脊組成，半隱在雲海與輕霧之間。畫面中只出現一種神獸——【仙鶴 / 鯤 / 龍】，【數量、位置、狀態】。

常用建築語言：

- 白玉基座

- 漢白玉欄杆

- 硃紅木構

- 層疊飛簷

- 淡金屋脊

- 高聳門樓

- 巨型宮柱

- 月洞門

- 迴廊

- 白玉平臺

- 雲紋 / 龍紋 / 卷草紋浮雕

材質要求：

- 白玉具有真實石材與微弱透光感

- 木構符合中國古建結構邏輯

- 石材有重量感、風化感和紋理變化

- 雲海遵循真實積雲與大氣規律

- 建築儘量具有真實中國古建邏輯，不做遊戲式懸浮城堡

---

## 4）氛圍描述

作用：統一時間、光線、色彩和空氣透視。

預設光影：\
**低角度暖金色側逆光 / 側後光**

模板：

> 時間設定為【清晨 / 傍晚 / 月升時刻 / 拂曉】，暖金色低角度陽光從【左側 / 側後方】照射，形成柔和側逆光效果，【白玉欄杆 / 屋簷 / 古松 / 人物衣袍 / 神獸邊緣】泛起金色輪廓光，遠處主體被輕霧包裹，空氣透視明顯。天空以天青灰、淺藍灰為主，雲海呈象牙白、暖灰白，整體低飽和、通透、神聖、安靜。

推薦配色：

- 天青灰

- 淺藍灰

- 月白

- 象牙白

- 暖灰白

- 硃砂暗紅

- 深松綠

- 少量暖金

經典明暗關係：\
**暗前景 → 暖中景 → 亮遠景**

避免：

- 平坦正面光

- 多個衝突光源

- 高飽和 RGB 色

- 紫紅、洋紅、霓虹青等現代炫彩

- 不符合邏輯的強“神光”

---

## 5）人物描述（比例 / 位置 / 狀態）

作用：人物不是主體，而是尺度參照與敘事錨點。

模板：

> 畫面【中下方 / 中景平臺 / 長橋轉折處 / 長廊內 / 欄杆邊緣】有【1 / 2 / 3】名極小人物，約佔整體畫面的【1%–3%】，人物身穿【淺青 / 月白 / 米白 / 淡粉】古代長袍，背對鏡頭，【緩慢行走 / 靜靜駐足 / 遠望】，不強調面部，只作為尺度參照與敘事錨點。

人物規則：

- 預設 1%–3%

- 特殊中景可放寬到 3%–5%

- 以背影為主

- 不強調五官

- 不做近景人物寫真

- 動作剋制

- 1 人：孤絕、凝望

- 2 人：同行、朝聖

- 3 人：敘事、儀式感

---

## 6）畫面美感控制

作用：規定最終審美方向，並限制模型跑偏。

模板：

> 整體追求東方神話現實主義與電影級概念藝術質感，強調【核心視覺母題】、空間秩序、材質統一、低飽和高階配色與大面積純淨留白。避免人物佔比過大，避免神獸過多，避免豔麗仙俠遊戲風，避免現代建築感，避免雜亂裝飾、霓虹色、粒子特效和古風寫真感。畫面要莊嚴、剋制、真實、空靈，具有超寫實材質、真實體積光與高階電影美學。

必須檢查：

- 是否有唯一視覺核心

- 是否有清晰前中遠景

- 是否存在足夠留白

- 是否具有真實中國古建邏輯

- 是否低飽和

- 是否避免遊戲感

- 是否避免過度金碧輝煌

- 是否具有電影攝影式空間層次

---

# 四、神獸規則

## 總規則

**一個畫面只出現一種神獸。**

神獸必須：

- 數量剋制

- 位於遠景 / 天空 / 雲層

- 不搶主體

- 最好成為視覺路徑終點

- 可被雲霧部分遮擋，保持神秘感

## 仙鶴

適合：\
鏡湖、月宮、巨松、長橋、白玉平臺。

數量：\
**2–5 只**

狀態：

- 掠過月宮

- 飛過鏡湖

- 停駐欄杆

- 停駐枝頭

關鍵詞：\
**輕盈、清冷、詩意、祥瑞、空靈**

## 鯤

適合：\
萬丈雲海、斷崖天宮、圓門奇觀、巨型神域。

數量：\
**僅 1 只**

狀態：

- 雲海深處若隱若現

- 只露背脊、尾部或遠景輪廓

- 橫穿巨大圓門

- 緩慢從雲層顯現

關鍵詞：\
**蒼茫、遠古、神蹟、巨大尺度、寧靜**

## 龍

適合：\
天門、神橋、天河、主殿、神域入口。

數量：\
**僅 1 條**

狀態：

- 盤旋天門上方

- 若隱若現於雲層

- 順天河走勢遠去

- 作為遠景守護象徵

關鍵詞：\
**威儀、守護、秩序、莊嚴、神域**

# 六、圖片生成工作流

使用者輸入主題後：

### 第一步：判斷場景

識別：

- 核心主題

- 核心奇觀

- 最適合的構圖

- 前中遠景

- 是否需要神獸

- 人物數量

- 時間與光影

### 第二步：輸出完整六段式提示詞

必須嚴格按照：

1. 整體描述

2. 構圖形式

3. 主體場景描述

4. 氛圍描述

5. 人物描述

6. 畫面美感控制

### 第三步：展示給使用者

在圖片生成之前，完整展示六段式提示詞。

### 第四步：生成

預設：

- 模型：Lib Image

- 比例：16:9

- 數量：1 張

- 風格：穩定經典版

只有使用者明確說“出 4 版”“多出幾版”等，才生成多版。

---

# 七、多版出圖規則

使用者明確要求 4 版時：

保持不變：

- 核心主題

- 構圖母題

- 神獸種類

- 人物邏輯

- 建築體系

只調整：

- 留白比例

- 霧氣厚度

- 光影戲劇性

- 建築顯隱程度

- 神獸清晰度

- 人物位置

- 奇觀尺度

推薦：

- **A 穩定經典版**

- **B 空靈留白版**

- **C 空間強化版**

- **D 戲劇光影版**

# 八、參考圖反推工作流

使用者上傳參考圖並要求“反推提示詞”時：

### 1. 判斷畫面核心

識別：

- 主體

- 構圖

- 視覺終點

### 2. 拆解空間

分析：

- 前景

- 中景

- 遠景

- 超遠景

### 3. 分析光影

判斷：

- 光源方向

- 光線高度

- 冷暖關係

- 明暗層次

- 空氣透視

### 4. 判斷元素主次

識別：

- 哪個元素是主角

- 哪些元素負責框景

- 哪些元素負責尺度

- 哪個元素是最終奇觀

### 5. 輸出六段式

最終必須重新組織為固定六段結構，而不是隻做關鍵詞羅列。

# 九、圖生影片提示詞工作流

核心原則：

**建築穩，環境動，人物微動，神獸慢動，鏡頭剋制。**

使用者要求影片提示詞時，只輸出：

- 完整版

- 精簡版

不自動生成影片。

## 完整版模板

> 保持原圖【構圖類型】穩定不變，建築、【前景元素】、【中景元素】結構完全穩定，無變形和抖動。雲海緩慢翻湧，薄霧沿【空間路徑】輕柔穿行；【神獸】在【位置】極緩慢【動作狀態】，動作舒展剋制；【人數】名人物【動作】，衣袍和長髮輕微飄動。鏡頭採用【運鏡方式】，速度極慢。保持建築、欄杆、柱列、【核心結構】和人物結構穩定，避免建築變形、人物瞬移、神獸體型突變、雲層劇烈翻滾、快速運鏡、畫面抖動和突然變焦。

## 精簡版模板

> 【運鏡方式】，雲海緩慢翻湧，薄霧穿行，【神獸】極緩慢【狀態】，人物【動作】，衣袍輕微飄動，建築全程穩定，無抖動、無變形。

推薦運鏡：

- 極慢前推

- 小幅弧形環繞

- 輕微抬升

- 輕微側移

- 貼柱列平移

避免：

- 快速環繞

- 猛推

- 快速變焦

- 大幅旋轉

- 強烈手持感

# 十、國風 AI 音樂提示詞工作流

使用者要求音樂提示詞時，只輸出：

- 完整版

- 精簡版

不自動生成音樂。

## 完整版模板

> 高階東方美學國風電影配樂，緩慢、輕柔、空靈、神聖、剋制，帶有【主題情緒】。以古琴、洞簫為核心旋律，壎作為遠景色彩點綴，柔和絃樂作為極淡背景鋪底，編鐘與遠處古鐘在關鍵節點輕敲，【可選：極輕低頻鼓偶爾沉響】。旋律極簡、舒展，大量留白，不追求傳統民樂炫技，整體像【畫面描述】的東方神話電影長鏡頭。聲音空間寬廣、通透、悠遠，冷暖交織，帶一點古老神秘感與極輕史詩氣息。純音樂，無人聲，無強鼓，無電子舞曲節奏，無激烈高潮。

## 精簡版模板

> 國風電影配樂，古琴 + 洞簫 + 壎 + 編鐘，緩慢、空靈、【情緒關鍵詞】，大量留白，極輕史詩感，純音樂，無人聲。

推薦樂器：\
古琴、洞簫、簫、壎、輕柔絃樂、編鐘、古鐘、極輕低頻鼓。

避免：\
強鼓點、熱血仙俠、高頻密集旋律、流行歌曲結構、EDM、過度煽情、炫技演奏。

- 是否避免遊戲感？

# 十二、高階技巧

## 大留白構圖

適合：\
空靈、禪意、孤絕、遠觀型天宮場景。

調整：

- 天空 / 雲海留白佔 60%–70%

- 中景建築密度降低約 50%

- 遠景建築幾乎消失在晨霧中

- 色彩更偏藍灰，減少金色

- 強化“極簡構圖、巨大空曠感、東方山水留白”

## 戲劇光影

適合：\
史詩海報、神蹟顯現、強逆光場景。

調整：

- 前景增加剪影

- 遠景主體形成強逆光光暈

- 體積光穿過雲層

- 增強明暗對比

- 仍保持低飽和與真實光源邏輯

**先定鏡頭，再定空間；\
前景壓框，中景敘事；\
遠景建築，深處神蹟；\
人物做尺，神獸點睛；\
側逆暖光，低飽和色；\
留白要大，裝飾要剋制。**
