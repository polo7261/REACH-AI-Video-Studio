# animal-vlogger

做"擬人動物博主"這類病毒式搞笑內容時用本 skill：一隻穿著衣服、直立行走、帶人類表情的動物，像人類 Vlogger 一樣舉著自拍杆在真實場景裡對鏡說話。核心賣點是**超寫實 + 擬人反差 + 生活化吐槽**的喜劇感。

> 本環境適配：影象/圖生影片引擎 → `generate_image_v3`（出擬人動物形象圖）+ `generate_video_v3`（圖生影片、對鏡說話、臺詞內嵌對口型）。源為 muapi 配方（MIT），表達已重寫、工具詞彙已適配；自足，無外部依賴。

## 輸入

名稱必填預設說明動物型別否猴子狗 / 貓 / 熊 等；越有表情張力越好所在地否熱鬧市井街頭真實生活場景（鬧市、集市、地鐵口…），提供環境細節與煙火氣穿著否亮紅 T 恤單件亮色好記的服裝，強化擬人反差對白否—供對口型的臺詞，可任意語言/方言；生活化吐槽腔調最出效果

缺輸入就用預設或向使用者補一句，不空等。

## 流程（兩階段，圖生影片）

### 階段 A — 出擬人動物形象圖（`generate_image_v3`）

一次呼叫生成基底形象圖，構圖要點全部內聯進 prompt：

- **主體**：超寫實、電影感的 {動物型別} 特寫；**擬人化**——直立、穿著 {穿著}、手持自拍杆，神態像個可信的博主。
- **喜劇微表情**：按場景給"入戲"的細節（如天熱就"微微冒汗、略顯煩躁"），這是搞笑感的來源，別隻給中性表情。
- **場景與背景**：置於 {所在地}，背景填滿生活細節（路邊攤、吃東西的人群、鮮豔的城市街景），製造真實煙火氣。
- **畫質**：photorealistic、高細節、電影級質感。
- **畫幅**：`aspect_ratio` = 9:16（豎屏 vlog）。技術規格走欄位，不寫進 prompt 正文。

出圖後 ⏸ 呈現給使用者確認，再進階段 B。

### 階段 B — 圖生影片成片（`generate_video_v3`）

以階段 A 確認的圖為參考圖（`role: image` 首幀/參考），一次呼叫動起來：

- **動作與鏡頭**：開場自拍模式、鏡頭略廣角；{動物型別} 表情豐富、可帶"略顯不滿/嫌棄"的喜劇情緒，自然說話；穿插對不滿臉的快速推近特寫；平滑的雲臺式運鏡。
- **對白對口型**：把 {對白} 臺詞內嵌進 prompt 的 `Audio:` 段驅動口型與配音（引擎原生渲染音訊）；同段補環境聲（街市嘈雜聲）。**沒有獨立 lipsync 工具——口型靠內嵌臺詞生成。** BGM 不內嵌，如需另用音訊生成後合成階段混音。
- **基調**：超寫實 + 搞笑，環境聲在場。
- **時長/畫幅**：`duration_sec` 整數 ≤15（單鏡；要更長的段落拆成獨立鏡、用上段末幀作下段首幀錨點銜接）；`aspect_ratio` = 9:16。

出片後呈現最終成片。
