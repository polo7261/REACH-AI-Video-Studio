# animal-vlogger

做"拟人动物博主"这类病毒式搞笑内容时用本 skill：一只穿着衣服、直立行走、带人类表情的动物，像人类 Vlogger 一样举着自拍杆在真实场景里对镜说话。核心卖点是**超写实 + 拟人反差 + 生活化吐槽**的喜剧感。

> 本环境适配：图像/图生视频引擎 → `generate_image_v3`（出拟人动物形象图）+ `generate_video_v3`（图生视频、对镜说话、台词内嵌对口型）。源为 muapi 配方（MIT），表达已重写、工具词汇已适配；自足，无外部依赖。

## 输入

名称必填默认说明动物类型否猴子狗 / 猫 / 熊 等；越有表情张力越好所在地否热闹市井街头真实生活场景（闹市、集市、地铁口…），提供环境细节与烟火气穿着否亮红 T 恤单件亮色好记的服装，强化拟人反差对白否—供对口型的台词，可任意语言/方言；生活化吐槽腔调最出效果

缺输入就用默认或向用户补一句，不空等。

## 流程（两阶段，图生视频）

### 阶段 A — 出拟人动物形象图（`generate_image_v3`）

一次调用生成基底形象图，构图要点全部内联进 prompt：

- **主体**：超写实、电影感的 {动物类型} 特写；**拟人化**——直立、穿着 {穿着}、手持自拍杆，神态像个可信的博主。
- **喜剧微表情**：按场景给"入戏"的细节（如天热就"微微冒汗、略显烦躁"），这是搞笑感的来源，别只给中性表情。
- **场景与背景**：置于 {所在地}，背景填满生活细节（路边摊、吃东西的人群、鲜艳的城市街景），制造真实烟火气。
- **画质**：photorealistic、高细节、电影级质感。
- **画幅**：`aspect_ratio` = 9:16（竖屏 vlog）。技术规格走字段，不写进 prompt 正文。

出图后 ⏸ 呈现给用户确认，再进阶段 B。

### 阶段 B — 图生视频成片（`generate_video_v3`）

以阶段 A 确认的图为参考图（`role: image` 首帧/参考），一次调用动起来：

- **动作与镜头**：开场自拍模式、镜头略广角；{动物类型} 表情丰富、可带"略显不满/嫌弃"的喜剧情绪，自然说话；穿插对不满脸的快速推近特写；平滑的云台式运镜。
- **对白对口型**：把 {对白} 台词内嵌进 prompt 的 `Audio:` 段驱动口型与配音（引擎原生渲染音频）；同段补环境声（街市嘈杂声）。**没有独立 lipsync 工具——口型靠内嵌台词生成。** BGM 不内嵌，如需另用音频生成后合成阶段混音。
- **基调**：超写实 + 搞笑，环境声在场。
- **时长/画幅**：`duration_sec` 整数 ≤15（单镜；要更长的段落拆成独立镜、用上段末帧作下段首帧锚点衔接）；`aspect_ratio` = 9:16。

出片后呈现最终成片。
